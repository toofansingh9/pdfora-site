About Toofan

Toofan Singh is the founder of PDFora. He launched the site in July 2026 to put free, private PDF tools in one place — tools that do their work inside your web browser instead of uploading your documents to someone else's server.

PDFora is built for people who need to get an everyday PDF job done quickly: merge a few scans for an application, shrink a file so it fits an email limit, sign a form, or pull one page out of a long report. Toofan decides which tools the site offers, checks each one before it goes live, and handles bug reports and corrections.

How PDFora's tools are built

  • Browser-first. 38 of the 47 tools run entirely on your device. They use open-source libraries — pdf-lib, Mozilla's PDF.js, Tesseract.js (OCR) and JSZip — which load only when you choose a file.
  • Clear about the exceptions. Converting between PDF and Word, Excel or PowerPoint, and HTML to PDF, needs office-grade software that browsers don't have. Those tools send the file to CloudConvert over an encrypted connection; details are in the Privacy Policy. Every tool page states which kind of tool it is.
  • Tested on real documents. Before a tool is published it is run on sample PDFs — multi-page files, scans, forms, rotated pages — and the output is opened again to check it is a valid document.
  • No accounts, no watermarks. The tools work without signup and don't stamp anything onto your files.

Corrections and bug reports

If a tool gives you a broken file, a page says something that isn't accurate, or a translation reads badly, please tell us on the contact page. Include the tool name and what happened; fixes are made as quickly as possible.

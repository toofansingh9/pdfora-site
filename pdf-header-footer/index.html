Sometimes a PDF needs to carry a line of context on every page: the client's name, a case reference, 'Prepared for the 14 November meeting', a version number or a short confidentiality notice. Retyping the document to add a running header is out of the question when all you have is the exported PDF, and editing it page by page in a viewer is slow and uneven. This tool adds that line in one pass.

You type a header, a footer, or both, and pick a font size (10 points by default). Each line is centred horizontally and drawn in dark grey Helvetica: the header with its baseline 26 points (about 9 mm) below the top edge, the footer about 6 mm above the bottom edge. Either field can be left empty. The same text goes on every page; there are no page-number fields or date codes inside the text, so if you need numbers as well, run Add Page Numbers in a separate step with a position that does not collide.

The existing page content is not touched. The text is added as a new drawing on top, so body text remains searchable and scanned pages are not recompressed. Processing happens in the browser tab with pdf-lib, and the file downloads as yourfile-stamped.pdf.

How to add a header or footer to a PDF

  1. Open Header & Footer and choose one PDF.
  2. Type the header text, the footer text, or both. Leave a field empty to skip it.
  3. Set the font size. 8 to 10 points suits most documents; bigger text starts to compete with the body.
  4. Click Add header / footer and wait a moment; long documents take a few seconds.
  5. Download yourfile-stamped.pdf and check a page with content close to the top or bottom margin for overlaps.

When to use this tool

  • Freelancers sending a deliverable to a client, with 'Prepared for Northfield Bakery - v2 - October 2026' along the top.
  • Legal and HR files where every page must carry a case or employee reference in case the pages are separated.
  • School worksheets assembled from several sources, given a common footer with the class and term.
  • NGO reports shared with partners, footed with 'Draft for partner review - do not circulate'.
  • Exhibits and annexes in a bundle, each headed 'Annex C' so a loose page can be traced back.
  • Price lists or menus with a footer stating the date the prices are valid from.

What to know before you start

  • Text is always centred. There is no left- or right-aligned option, and no way to put different text in the left and right corners of the same header.
  • The same header and footer are printed on every page, including the cover. To leave the cover clean, split it off, stamp the rest, and merge again.
  • There are no placeholders: typing {page} or a date code prints exactly those characters. Use Add Page Numbers or Bates Numbering for automatic numbers.
  • Long text is not wrapped. A line wider than the page will be cut off at both edges, so keep it to roughly 80 characters at 10 points on an A4 or Letter page. If you need two pieces of information, put one in the header and the other in the footer instead of joining them into one long line.
  • The built-in Helvetica font only covers basic Western characters. Accented Western letters generally work, but non-Latin scripts and emoji cause an error.
  • If the document already has a header or footer, the new text is drawn over it, not instead of it. The tool cannot remove existing content; check the margins before you choose the wording.

Tips for the best results

  • Keep it short and specific. 'ACME / Q3 audit / v3' is easier to scan than a full sentence.
  • If you also need page numbers, put the header-footer text at the bottom and the page number at the top right, or the other way round, so the two never collide.
  • Use a smaller size than the body text. A header that looks as big as the content reads as part of the content.
  • Add the header after merging and compressing, so the stamp is the last change and appears on every page of the final file.
  • Save the wording you used in a note. Re-stamping a revised version with exactly the same text keeps a series of documents consistent.

Example: a freelance designer's brand guide

A freelance designer delivers a 22-page brand guide exported from a layout app. The client's marketing team will forward pages individually to printers and agencies, and the designer wants each page to say who it belongs to and which version it is.

She sets the header to 'Riverside Dental - Brand Guidelines v1.2' and the footer to 'Questions: studio@example.com', font size 8. On most pages this works immediately. On two pages a full-bleed photo runs right to the top edge, and the grey header text is hard to read over the dark image.

Rather than raise the font size everywhere, she accepts it on those two pages, because the version number is still visible on close inspection and those pages are image references, not text that gets forwarded. The stamped file goes to the client; the clean export stays in her project folder for the next revision.

A useful habit came out of this job: she now keeps the header wording in a text file alongside each project, so when the client asks for version 1.3 two months later she can paste the exact same line, change only the version number, and every edition of the guide looks consistent.

Troubleshooting

Nothing appeared on the pages
Both fields were probably empty, or the page has a crop box that hides the top and bottom margins. Type at least one line, and if the margins are cropped, check the result in a different viewer.
The text is cut off at both sides
The line is wider than the page. Shorten the text or lower the font size; the tool does not wrap long lines.
The header covers my document's own header
The tool draws on top of what is already there. Change the wording to fit around it, use the footer only, or reduce the size.
The tool shows an error with my text
The text contains characters the built-in font cannot encode, such as non-Latin script or emoji. Use plain Latin characters.
The header is on the side of some pages
Those pages are stored rotated. Fix the orientation with Rotate PDF first and stamp the corrected file.
I typed {page} and it printed literally
The tool has no placeholders. Leave the page number out of the header and run Add Page Numbers afterwards.

Frequently asked questions

Can I use different headers on odd and even pages?

No. Every page gets the same header and footer. Alternating headers are best set in the program that created the document, before exporting to PDF.

Can I add a logo to the header?

Not with this tool, which only adds text. Use Edit PDF to place an image on a page.

Can I change the font or colour?

No. Text is always dark grey Helvetica, centred. You can change the font size.

Will the header be searchable?

Yes, it is added as real text, so it can be selected and found with search, like the rest of a text-based PDF.

Can I remove a header I added by mistake?

Not with this tool. Keep your original file and stamp it again with the corrected text.

Does the tool change the layout of my pages?

No. Nothing is moved or resized; the text is added in the existing top and bottom margins. If your document's own content runs right to the top or bottom edge, the new text will overlap it, because nothing is shifted to make room.

File names matter more than people expect. "scan_20261003_0007.pdf" or "Document (3) final FINAL.pdf" tells the recipient nothing, gets lost in a downloads folder, and is sometimes rejected outright by upload portals that dislike spaces, brackets or very long names. Renaming on a desktop is trivial, but on a phone, a locked-down work computer or inside a browser-only workflow it can be surprisingly fiddly.

This tool does one thing: you type a new name and it gives you the PDF back under that name. Characters that Windows, macOS and most portals refuse in file names (backslash, slash, colon, asterisk, question mark, quotes, angle brackets and the vertical bar) are removed automatically, and .pdf is added if you leave it out. If the box is left empty, the original name is kept; if what remains after cleaning is empty, the file is called document.pdf. Leading and trailing spaces are trimmed as well, so a name pasted from an email with a stray space at the end does not produce a file called 'invoice .pdf'.

One detail is worth knowing. The tool does not merely relabel the download; it opens the PDF with pdf-lib and saves it again. The pages and their content are unchanged, but the file is rewritten, so its size can differ slightly and the document's internal metadata is updated: pdf-lib sets the modification date and records itself as producer. The document title shown in a viewer's title bar, which is a separate field inside the PDF, is not changed by renaming.

How to rename a PDF file

  1. Open Rename PDF and add the PDF you want to rename.
  2. Type the new name in the New file name box, for example 2026-10-invoice-0142. You can include or omit the .pdf ending.
  3. Click Rename & download. The file is loaded and saved again under the new name.
  4. Save the download where you need it; your browser may ask for a location or put it in the Downloads folder.
  5. Check the name in your file manager and delete the old copy if you no longer need it.

When to use this tool

  • Freelancers sending invoices with a consistent pattern such as client-year-month-number, so both sides can find them later. A predictable name also lets the client's accounts team match the file to their purchase order without opening it.
  • Students submitting coursework to a portal that requires a specific format like surname-studentnumber-assignment.
  • Landlords filing tenancy agreements and inspection reports by property address and date instead of scanner-generated names.
  • Renaming files on a phone or tablet where the file manager makes it awkward.
  • Removing characters such as colons, slashes or quotes that stop a file from being uploaded or synced to another system.
  • Giving a downloaded statement or e-ticket a meaningful name before forwarding it.

What to know before you start

  • Forbidden characters \ / : * ? " < > | are removed, not replaced, so a name like Report: Q3 becomes Report Q3. Spaces are kept; replace them yourself with hyphens if a portal does not accept spaces.
  • The .pdf extension is added automatically if it is missing. A name that already ends in .pdf (in any letter case) is left as typed.
  • The PDF is re-saved by pdf-lib, which updates the modification date and producer fields in the file's metadata. The title, author and page content stay as they were.
  • Digitally signed PDFs should not be renamed with this tool. Re-saving rewrites the file, which invalidates the signature even though the visible content is identical. Rename signed files in your file manager instead.
  • Password-protected PDFs are not suitable either. The tool may load them, but the saved copy is unlikely to open correctly. Rename such files in your file manager.
  • One file per run. To rename a batch, repeat the steps for each file, or use your operating system's bulk-rename feature. If you rename the same file twice, each run produces a new download; the tool never changes the file on your disk. The original stays exactly where it was, under its old name, until you delete it.

Tips for the best results

  • Start names with a date in year-month-day order (2026-10-22) so files sort chronologically in any folder.
  • Use hyphens instead of spaces; they survive email systems, URLs and command-line tools without being turned into %20.
  • Keep names under about 60 characters. Some portals and older systems truncate longer names.
  • Put the most important word first: client name, then document type, then number. That is what people scan when they look at a list.
  • If the visible title in PDF viewers also needs to change, edit the document properties in the application that created the file; renaming does not touch it. Upload portals sometimes have their own naming rules, such as lowercase only or no spaces. The tool does not enforce those, so type the name in the format the portal asks for.

A worked example: a landlord organising tenancy paperwork

A landlord with three flats scans inspection reports with a phone app, which produces names like Scan 14 Oct 2026 10:42.pdf. Uploading these to a letting agent's portal fails, because the portal rejects colons in file names, and the folder on her laptop is a list of near-identical dates.

She renames each report on her phone with the pattern flat-b-inspection-2026-10-14. The tool strips any stray colon if she copies part of the old name, adds .pdf, and the portal accepts the upload. In the folder, the files now sort by flat and then by date.

For the signed tenancy agreements she does something different. Those were signed with a digital signature, and re-saving would invalidate it, so she renames them in the phone's file manager instead. The rename tool is best for ordinary PDFs; anything with a signature or password should be renamed at file-system level.

Troubleshooting

The downloaded file still has the old name
The browser may have added a number because a file with that name already exists, or it may be set to rename duplicates. Check the Downloads folder and remove older copies.
Some characters disappeared from my new name
Characters not allowed in file names on common systems (\ / : * ? " < > |) are removed automatically. Use a hyphen or underscore where you wanted them.
The file size changed slightly
The PDF is re-saved by pdf-lib, which can store objects differently. The pages are the same; only the internal structure is rewritten.
My PDF's digital signature now shows as invalid
Re-saving changed the bytes the signature covers. Use the original signed file and rename it in your file manager.
The renamed file will not open
The source was probably encrypted or damaged. Rename the original in your file manager, or repair it first with Repair PDF.
My viewer still shows the old title at the top
Viewers display the title stored inside the PDF, not the file name. That field is not changed by renaming.
The new name was cut short on my phone
Some mobile browsers shorten very long download names. Keep the name brief and put the identifying parts first.

Frequently asked questions

Does renaming change the content of the PDF?

No. The pages are identical. The file is re-saved, so the modification date and producer metadata are updated.

Which characters are not allowed?

Backslash, slash, colon, asterisk, question mark, double quote, angle brackets and vertical bar are removed from the name.

Do I need to type .pdf at the end?

No. It is added if you leave it out.

Can I rename several PDFs at once?

No, one file per run. For larger batches, your operating system's bulk rename is faster.

Will renaming break a digital signature?

Yes, it can, because the file is rewritten. Rename signed PDFs in your file manager instead.

Is there any cost or sign-up?

No. Renaming is free and does not need an account.

Crop PDF

Wide white borders are a nuisance on a phone screen and a waste of space when a document is printed several pages to a sheet. Scanned book pages often carry a dark band along the gutter, and slides exported to PDF sometimes come with a thick frame of nothing. Cropping takes that empty space away so the content fills more of the screen or the paper.

PDFora's crop tool works on one number: a margin in points that is removed from all four sides of every page. A point is 1/72 of an inch, so the default of 30 points is a little over 10 mm. The tool does not cut pixels out of an image. It writes a new CropBox for each page, which is the PDF instruction that tells viewers and printers which rectangle of the page to show. Everything outside that rectangle is hidden, but it is still stored in the file.

Because nothing is redrawn, text stays selectable, vector drawings stay sharp, and the file size barely changes. The flip side is that cropping is not a way to remove sensitive content: someone with a PDF editor can reset the crop box and see the hidden edges again. The processing runs in your browser using pdf-lib, and the result downloads as yourfile-cropped.pdf.

How to crop PDF margins

  1. Open Crop PDF and select a single PDF file.
  2. Enter the margin in points. 30 is the default; 72 points equals one inch and roughly 28 points equals one centimetre.
  3. Remember the same amount is taken from the top, bottom, left and right of every page, so choose a value that suits the page with the narrowest margins.
  4. Click Crop margins and wait for the download, named after the original with -cropped added.
  5. Open the result and check the pages with the tightest layout: headers, footers and page numbers near the edge are the first things to disappear.

When to use this tool

  • Reading an A4 report on a phone or e-reader, where the text becomes noticeably larger once the white frame is gone.
  • Cleaning up scanned book pages that show a grey shadow or the edge of the scanner glass around the text.
  • Preparing pages for 2-up or 4-up printing, so the content uses more of each small cell instead of shrinking further.
  • Trimming exported presentation slides that were saved with a wide border.
  • Removing the empty band around a chart or drawing before inserting the PDF page into another document.
  • Making exam papers or worksheets easier to project on a classroom screen.

What to know before you start

  • The crop is uniform. There is no separate value for each side and no per-page setting, so a document with uneven margins will be trimmed by the same amount everywhere.
  • The hidden area is not deleted. Text and images outside the new box remain in the file and can be revealed again. To actually get rid of the edges, crop first, then convert the pages to images with PDF to JPG and rebuild the file with Images to PDF; the images only contain the visible area.
  • The margin is capped so a page can never shrink to nothing: on each axis the tool will leave at least about 2 points of visible area even if you type a very large number.
  • The new box is measured from the page's full media size. If a page already had its own crop box, it is replaced, not tightened further.
  • The page size reported by viewers will be smaller after cropping. When you print, the printer may scale the cropped page up to fill the paper, which changes the apparent size of the text.
  • Bookmarks, links and form fields are left in place because the pages are edited in their original file, not copied into a new one.

Tips for the best results

  • Measure first: in your viewer, note how far the text sits from the nearest edge on the busiest page, then pick a margin slightly smaller than that distance.
  • Start with a modest value such as 20 to 30 points. It is quicker to run the tool again on the original with a larger number than to discover a missing page number later.
  • Always crop the original file, not an already cropped copy, because the second run starts again from the full page and the results will not add up the way you expect.
  • For scans with a dark edge on only one side, a uniform crop will also trim the other three sides. Check that the opposite margin can afford to lose the same amount.
  • If the document will be shared outside your organisation and the edges contained notes or internal references, do not rely on cropping; remove that content properly before sharing.

A worked example: a scanned textbook chapter for a tablet

A student has a 40-page scanned chapter on A4 pages. Each scan shows a 15 mm grey border from the copier lid, and the printed text block starts about 25 mm from the edges. On a 10-inch tablet, the text is small enough that she keeps zooming in and scrolling sideways.

Fifteen millimetres is about 43 points, so she enters 45. The grey border disappears on every page, and the text block now fills most of the screen when the page is fitted to width. A test with 70 points (about 25 mm) clipped the running header on several pages, so she went back to the original and used 45.

The file size is unchanged, because the scans themselves were not touched. If she later needs the full pages back, for example to print them, she can still use the original file she kept.

Troubleshooting

Page numbers or headers were cut off
The margin was larger than the space between the content and the edge on those pages. Run the original file again with a smaller value.
The hidden content is still visible in another program
Some editors and print workflows ignore the crop box and show the full media box. Cropping hides content; it does not remove it. If the edges must really go, convert the cropped pages to images (PDF to JPG, then Images to PDF).
Some pages look over-cropped and others barely changed
The tool applies the same margin to pages of different sizes. A small page loses proportionally more. Split the mixed-size pages into a separate file and crop each group with its own value.
Text prints larger than before
Your print dialog is scaling the smaller cropped page to fit the paper. Choose actual size or 100% scaling if you want the original text size.
Nothing seems to happen
Check the margin is not 0. Also note that a page that was already cropped tighter than your value will now show more, because the new box is measured from the full page.
The file will not open in the tool
It may be damaged. Run it through Repair PDF and crop the repaired copy.

Frequently asked questions

Does cropping reduce the file size?

Hardly at all. The content outside the crop area is still stored in the file. To make the file smaller, use Compress PDF.

What unit is the margin in?

PDF points. 72 points make one inch and about 28.35 points make one centimetre, so the default of 30 points is roughly 10.6 mm.

Can I crop different amounts from each side?

Not with this tool. It removes the same margin from all four sides of every page.

Can I crop only some pages?

Not directly. Extract the pages you want to crop with Split or Extract Pages, crop that file, and merge it back with the rest.

Is the text still selectable after cropping?

Yes. The pages are not re-rendered, so text, links and vector graphics are unchanged inside the visible area.

Is cropping safe for hiding confidential information?

No. The cropped-away area can be restored by anyone with a PDF editor. For content that must not be seen, use a proper redaction tool, or rasterise the cropped pages with PDF to JPG and Images to PDF.

Workflows

Chain several PDF tools into one sequence and run them on a file in a single pass, using each tool's default settings.

🔒 Your files are processed locally in your browser and never uploaded.

Some PDF chores always come in the same combination. A scanned contract needs straightening, page numbers and a watermark; an outgoing report needs its form fields flattened, comments stripped and the file made smaller. Doing that one tool at a time means downloading and re-uploading the file three or four times, with an intermediate file each round. Workflows strings the steps together: you build a list, drop in a PDF, and get one finished file back named yourfile-workflow.pdf.

Twelve tools can be chained: Compress, Grayscale, Rotate 90°, Watermark, Page numbers, Crop margins, Resize to A4, Flatten, Repair, Remove annotations, Flip and Touch metadata. They run top to bottom, and the output of each step becomes the input of the next. You can move a step up with the ↑ button or remove it with ✕, and add the same tool more than once.

The trade-off for speed is that there are no per-step settings. Each step uses that tool's defaults, listed below, so a workflow is only useful when the defaults are what you want. If you need a custom watermark text or a different rotation, run that single tool separately. In practice the defaults suit routine office jobs well: a standard confidentiality mark, simple page numbers, A4 output and a balanced compression level.

How to run several PDF tools in one go

  1. Open Workflows. Choose a tool from the 'Add a step…' list and click Add. Repeat for each step.
  2. Check the order. Steps run from 1 downwards; use ↑ to move a step earlier and ✕ to delete one.
  3. Drop a single PDF onto the box under the step list, or click it to choose a file.
  4. Watch the status line: it shows 'Step 2/4: Watermark…' and so on as each tool runs.
  5. When it reports 'Done', open the downloaded -workflow.pdf and check that every step did what you expected.

When to use this tool

  • A small business stamping 'CONFIDENTIAL' on quotes and numbering the pages before sending them to a client.
  • An office clearing out reviewer comments and flattening completed forms before archiving.
  • Preparing scans for a portal that wants small greyscale files: Grayscale then Compress.
  • Normalising mixed-size documents to A4 and adding page numbers so they print consistently.
  • Fixing a sideways-scanned batch where every page needs rotating and the result needs compressing.
  • Running Repair as the first step on files from an old system that other tools sometimes refuse.

What to know before you start

  • The defaults are fixed: Compress uses the Recommended level; Rotate turns every page 90° clockwise; Watermark writes 'CONFIDENTIAL' at 50 pt, 30% opacity, diagonally; Page numbers puts plain 1, 2, 3 at the bottom centre in 11 pt, starting at 1; Crop margins removes 30 points (about 10.5 mm) from every side; Resize fits pages to A4; Flip mirrors horizontally.
  • Compress, Grayscale and Flip redraw every page as a JPEG image. Any step after them works on pictures of pages, and the final file has no selectable text, links or form fields. Put these steps last unless that is what you want.
  • Touch metadata with no values only updates the file's modification date. It does not change the title or author, because there is nowhere to type them in a workflow.
  • Only one PDF can be processed per run. To treat several files the same way, drop them in one after another; the step list stays in place between runs.
  • The step list is not saved. Reloading or closing the page clears it, so note down a workflow you use regularly. That makes it practical for a batch of a dozen similar files, even though each still has to be dropped in by hand.
  • If any step fails, the run stops with that step's error and nothing is downloaded. Earlier steps are not saved separately.

Tips for the best results

  • Run Repair first if a file has given you trouble elsewhere, so every later step receives a cleanly rebuilt document.
  • Order matters for stamps: put Page numbers and Watermark after Resize to A4 and Crop margins, otherwise the stamp may be shrunk or cut off by the later step.
  • Put Flatten before Compress. Compress turns the pages into images anyway, but flattening first makes sure filled-in form values are actually visible in that image.
  • Test a new workflow on a short file before you run a 200-page document through it. Two or three pages are enough to see whether the stamps sit where you expect and the quality after compression is acceptable.
  • Adding Rotate 90° twice gives a 180° turn; three times gives 90° anticlockwise.

Example: a legal assistant preparing disclosure copies

A legal assistant has to send a set of signed agreements to the other side. Each must be A4, carry page numbers, be marked as confidential, have internal review comments removed, and be small enough to email. There are nine files, so doing four tools by hand on each would mean 36 separate runs.

The workflow is built as: 1 Remove annotations, 2 Resize to A4, 3 Watermark, 4 Page numbers, 5 Compress. Comments go first so they do not end up baked into the image later; resizing comes before the stamps so they sit at A4 positions; Compress comes last because it turns each page into a picture. Each agreement is dropped in once and comes out as, for example, supply-agreement-workflow.pdf. Nine files take only a few minutes in total, most of it spent on the Compress step, which renders every page.

The catch to notice: because Compress is in the chain, the outgoing copies are no longer text-searchable. That suits copies that should not be easily edited, but if the other side needs to search them, remove step 5 and compress only the files that are too big to email.

Troubleshooting

'Add at least one step first'
The step list is empty. Choose a tool in the 'Add a step…' list and click Add before dropping the PDF.
The watermark or page numbers are in the wrong place
A later step changed the page geometry. Move Resize to A4, Crop margins and Rotate above Watermark and Page numbers with the ↑ button, and run it again.
My text is no longer selectable
Compress, Grayscale or Flip is in the chain; these produce image-only pages. Remove them, or move them to the end and accept image pages in the result.
The run stops at one step with an error
That tool could not process the file at that point, often because it is password-protected or damaged. Add Repair as step 1 or fix the file first, then run the workflow again. The status line names the failing step, which tells you which tool to test on its own.
My steps vanished
The list exists only while the page is open. Rebuild it; keep a short written note of the order for workflows you repeat.
I need a different watermark text or rotation
Workflows always use default settings. Run the Watermark or Rotate tool on its own with your settings, then use Workflows for the remaining steps.

Frequently asked questions

Can I change the settings of a step?

No. Each step runs with the tool's default settings. For custom options use the individual tool.

Can I run a workflow on several PDFs at once?

Not in one run. The tool processes one file at a time, but the step list stays ready, so you can drop the next file straight away.

Can I save a workflow for later?

Not at the moment. The steps are kept only while the page is open.

Why are only some tools available as steps?

A step must take one PDF and return one PDF. Tools that need several files, produce a ZIP, export images or text, or need a server conversion cannot be chained.

Will the file be processed on a server?

No. All twelve chainable tools run inside your browser tab; the PDF is passed from step to step in memory and only the final result is downloaded.

What happens if I add the same tool twice?

It runs twice. Two Rotate steps turn pages 180°; two Compress steps usually save little extra and cost more quality.

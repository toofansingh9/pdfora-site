Flatten PDF

Turn the fillable fields of a PDF form into fixed page content, so the answers stay as typed and can no longer be edited in a form field.

A filled-in PDF form is two layers pretending to be one. The page shows a box with your answer in it, but behind that box sits an interactive field whose value any viewer can change, and which different viewers sometimes display differently. Send that file on and the recipient may see empty boxes, a font substitution, or a field someone has accidentally retyped. Flattening removes the interactive layer and keeps only what is drawn on the page.

Here is what the tool does in practice. It opens the PDF with pdf-lib, takes the form's fields, draws each field's current appearance (the text, tick or selection that is visible) into the page itself, and then deletes the fields. Everything else in the document is saved as it was, so ordinary text stays selectable and images keep their quality. The output is saved with -flattened added to the file name.

Flattening is one-way. Once a field is part of the page, nobody can fill it again or read its value as data, including you. That is exactly what you want for a signed application or a submitted return, and exactly what you do not want for a template you will reuse. A good habit is to treat the flattened file as the copy you send and the fillable file as the copy you keep.

How to flatten a PDF form

  1. Fill in the form completely in your PDF viewer or with Fill & Sign, and save it.
  2. Open the Flatten tool and add the filled PDF.
  3. Click Flatten forms. The fields are drawn into the pages and removed; this normally takes a moment.
  4. Download the file, for example application-flattened.pdf.
  5. Open it in a different viewer from the one you filled it in and check that every answer, tick and signature appears.

When to use this tool

  • Locking a completed rental application before emailing it to a letting agent, so values cannot be altered.
  • Submitting school admission or scholarship forms to portals that reject PDFs with active fields.
  • Preparing filled forms for merging, since fields with the same names in different files can clash when combined.
  • Archiving signed HR or onboarding forms as fixed records.
  • Making sure a filled form prints the same on every printer and viewer, including phone viewers that ignore form fields.
  • Sending a completed questionnaire to an NGO or survey team who will print and file it rather than process field data.

What to know before you start

  • Flattening only affects interactive form fields. Comments, highlights and sticky notes are annotations of a different kind and are left alone; use Remove Annotations for those.
  • What you see is what gets kept. The tool draws each field's saved appearance. If your viewer did not save an appearance for a field, that answer can come out blank.
  • The result can no longer be filled in, and the field values cannot be exported as data afterwards.
  • If the PDF has no form fields, the tool still produces a copy; nothing on the pages changes.
  • Text that is already part of the page is not touched, so the rest of the document stays searchable. Text drawn from fields becomes page content as well.
  • Password-protected or digitally signed files are not suitable. Encryption is ignored when loading, so a protected file may come out unreadable, and a certified digital signature will no longer validate after any change to the file.

Tips for the best results

  • Save a fillable copy before flattening. If a detail turns out wrong, you will want to correct the field, not start the form again.
  • Click out of the last field before saving in your viewer. Some viewers only store the value of a field when focus leaves it.
  • Check drop-down and checkbox fields in particular after flattening; these are the ones most likely to depend on a viewer-specific appearance.
  • If several filled forms need to be combined, flatten each one first and then merge the flattened copies.
  • If the document also needs an image-only lock-down (no selectable text anywhere), run it through Grayscale or Compress afterwards, which both rebuild pages as images.

A worked example: a small business supplier form

A small catering business is asked by a new client to complete a 4-page supplier registration form: company details, bank reference, insurance policy number, and a set of tick-boxes about food-safety certificates. The client's procurement portal states that only non-editable PDFs are accepted.

The owner fills the form in the browser's PDF viewer, saves it, and runs it through Flatten. In the flattened copy the company name, policy number and ticks all appear on the page, but clicking them does nothing, and the portal accepts the upload. Opening the same file on a phone shows the answers too, which the fillable version did not, because that phone's viewer ignored form fields.

One check catches a problem: a drop-down for business type came out blank. The viewer had not saved an appearance for it. Re-opening the fillable copy, picking the option again, clicking elsewhere, saving and flattening once more fixes it.

The business keeps both versions in its client folder: the fillable copy for next year's renewal, when most answers will be the same, and the flattened copy as the record of what was actually submitted. Naming them clearly, with the date in the file name, avoids sending the editable one by mistake.

Troubleshooting

Some answers are missing after flattening
The viewer you filled the form in did not store an appearance for those fields. Open the fillable copy, re-enter the values, click out of each field, save, and flatten again; or fill it with Fill & Sign.
Nothing changed in my file
The PDF probably has no interactive fields; the boxes are just printed lines. Use Fill & Sign or Edit PDF to place text on it instead.
The text in fields looks different from what I typed
Fields are drawn using their stored appearance and font settings. A field with an unusual font or auto-size may render slightly differently; check spacing and redo the field if it overflows.
My comments and highlights are still there
That is expected. Flattening handles form fields only. Run Remove Annotations as well if those should go.
The flattened file looks scrambled
The source was probably password-protected. Remove the protection in the program that created it or with Unlock PDF if you know the password, then flatten the unprotected copy.
The digital signature is now invalid
Any change to a signed file breaks a certificate-based signature. Flatten before signing, or send the signed file as it is.

Frequently asked questions

What is the difference between a flattened and a fillable PDF?

A fillable PDF has interactive fields whose values can be changed. A flattened PDF has the same answers drawn on the page as ordinary content, with no fields left.

Can I unflatten a PDF?

No. The fields are removed. Keep the fillable version if you might need to change answers.

Does flattening remove annotations too?

No. Comments, highlights and stamps stay. Use Remove Annotations to delete those separately.

Will the rest of my document lose quality?

No. Pages are not re-rendered; only the form fields are converted, and other text and images are saved unchanged.

Is flattened text still searchable?

Generally yes, since field text is drawn as page text rather than as an image, though the exact result depends on how the field's appearance was built.

Is flattening enough to protect a document from changes?

It stops casual edits in form fields, but anyone with a PDF editor can still change page content. For legal integrity, use a digital signature after flattening.

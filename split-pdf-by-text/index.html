Split by Text

Start a new PDF every time a page contains a word or phrase you choose, so a batch of documents separates itself.

Counting pages works when every document in a batch has the same length. Real batches rarely do. A month of supplier invoices exported as one PDF might hold a one-page invoice, then a three-page one, then two single pages. What they do share is a word that appears at the top of each new document: Invoice, Statement, Dear, Case No. Split by Text uses that word as the cut marker. Choosing the right marker is most of the work; the cutting itself is automatic.

The tool reads the text layer of every page with PDF.js. Whenever a page contains your search text, the current group is closed and a new file starts with that page. Everything up to the next match belongs to the same file. The first page always opens the first file, even if it does not contain the text. The pages themselves are then copied unchanged with pdf-lib into numbered outputs: batch.pdf becomes batch-1.pdf, batch-2.pdf and so on, in batch-bytext.zip.

The important condition is that the text must actually exist as text. A PDF exported from accounting software, a word processor or a browser has a text layer. A PDF made by a scanner or a phone camera usually contains only pictures of text, and the tool will find nothing in it. For scans, run OCR PDF with Searchable PDF output first, then split the searchable copy by text.

How to split a PDF wherever a word appears

  1. Open Split by Text and add the PDF.
  2. Type the marker text. Choose something that appears once on the first page of each document and nowhere else, such as 'Invoice number' rather than just 'Invoice'.
  3. Leave Ignore upper/lower case ticked unless capitalisation is what distinguishes the marker (for example 'STATEMENT' in a heading versus 'statement' in body text).
  4. Click Split by text. Each page is read before anything is cut.
  5. Download the parts and spot-check a few to confirm that each one begins where a new document begins. The number of files should equal the number of documents in the batch.

When to use this tool

  • Separating a bulk export of invoices or receipts into one file per invoice for bookkeeping uploads.
  • Dividing a merged set of bank or utility statements into individual months.
  • Breaking a batch of generated letters (each starting with 'Dear') into one letter per recipient for mailing. A marker such as the opening salutation works when each letter starts on a fresh page.
  • Splitting payslips produced as one long run into one file per employee.
  • Separating exam scripts or answer sheets that each start with a heading such as 'Candidate number'.
  • Cutting court bundles or case files where each exhibit begins with a fixed label like 'Exhibit'.

What to know before you start

  • A page is checked for whether the marker appears anywhere on it, header, body or footer. If your word also appears in footers or running text, you will get a cut on every such page. Pick a phrase unique to the start of each document.
  • Scanned pages have no text layer, so nothing matches and you see 'That text marks 0 or 1 split points'. For a scan, run OCR PDF (Searchable PDF output) first, then split that copy by text.
  • Text is assembled from fragments separated by spaces. Most phrases match normally, but a word that the PDF stores in pieces (sometimes the case with letter-spaced headings) may not be found; try a shorter marker or a different word. Line breaks inside a phrase are joined with a space, so a two-word marker that wraps across lines usually still matches.
  • Only plain substring matching is done: no wildcards, no regular expressions, no whole-word option. 'Invoice' also matches 'Invoices' and 'Pro-forma Invoice'.
  • The tool needs at least two groups. If the marker is found only on page 1, or not at all, it stops with an error instead of producing one file identical to the original.
  • Outputs keep page content but not bookmarks, and links between pages that end up in different files stop working.

Tips for the best results

  • Open the PDF in your viewer and use its search function with the marker first. The number of hits on first pages should equal the number of documents you expect. If the counts differ, change the marker before splitting rather than fixing the parts afterwards.
  • Prefer labels with a colon or number nearby, such as 'Invoice No' or 'Account summary', which tend to appear only once per document.
  • If the first few pages are a cover sheet without the marker, they become file 1. Delete them beforehand or simply discard that part. The same applies to a trailing summary page.
  • Batches from one system usually use identical wording. If a few documents come from another system, check them separately.
  • After splitting, rename files using the invoice or account number shown on their first page.

Example: a landlord's annual utility statements

A landlord with four flats downloads a year of water and electricity statements from a supplier's portal. The portal offers only one export: a single 61-page PDF in which each statement is one to three pages long, depending on how many meter readings it lists. The accountant wants one file per statement.

Every statement opens with the heading 'Statement of account', which also appears in no footer. With that phrase entered, the tool finds 24 matches and returns 24 files. The landlord opens the PDF in a viewer first and searches the phrase: 24 hits, matching two suppliers times twelve months, so the count is right before the split is even run.

Searching for 'Account' alone would have been a mistake: the word appears in every page footer ('Account number') and would have produced 61 one-page files. A quick search in the viewer before splitting is the cheapest check there is.

Troubleshooting

Error: 'That text marks 0 or 1 split points'
The text was not found on any page after the first. Check the spelling, try a shorter phrase, and confirm the PDF has selectable text. If you cannot select text in your viewer, the file is a scan; split it by page numbers with Split PDF instead.
I got one file per page
Your marker appears on every page, often in a header or footer. Choose a phrase that only appears at the start of each document.
Some documents were not separated
Those pages do not contain the exact marker, perhaps because of different wording, a scanned page in the batch, or a word stored in fragments. Split the leftover file again with another marker.
Error: 'Enter some text to split on'
The text box is empty or contains only spaces. Type the marker and run again.
The split stopped on a password-protected file
Encrypted PDFs cannot be read reliably. Remove the password in the application that created it or with Unlock PDF if you know the password, then try again.
OCR'd pages split in odd places
OCR can misread words, so the marker may be missing on some pages. Use a short marker made of clearly printed letters, and check the results.

Frequently asked questions

Does the page with the marker go into the new file or the previous one?

Into the new file. The matching page is always the first page of the next part.

Is the search case-sensitive?

Only if you untick Ignore upper/lower case. It is ticked by default.

Can I use several markers at once?

No, one marker per run. Split by the first marker, then split individual parts again by a second one if needed.

Does it work on scanned PDFs?

Not directly. A scan without a text layer gives the tool nothing to match, so run OCR PDF with Searchable PDF output first and split the searchable copy by text.

Are the pages changed in any way?

No. The text is only read to decide where to cut; the pages are then copied unchanged.

How are the output files named?

With the original name plus a sequence number, for example batch-1.pdf, inside batch-bytext.zip.

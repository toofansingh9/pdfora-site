PDF to Word

A PDF is built for showing a page exactly as it was laid out, not for editing it. Every line of text sits at fixed coordinates, there are usually no real paragraphs, and a table is often just lines drawn next to loose words. Turning that back into a Word document means a converter has to guess where paragraphs start and end, which runs of text belong to the same column, and which lines form a table. Most of the time the guesses are good. Sometimes they are not, and knowing why saves a lot of frustration.

PDFora's PDF to Word tool hands this reconstruction to a conversion engine running on a server, because doing it properly needs layout analysis and font handling that a browser tab cannot match. You pick one PDF, it is uploaded over an encrypted connection to the conversion service (CloudConvert, reached through our own small relay), converted to .docx, and the finished file comes back as a download. The upload is deleted from the service after the job; still, this is the one kind of tool on the site where your file does leave your computer, so do not use it for documents you are not allowed to send to a third party.

What you get is a normal .docx that opens in Microsoft Word, LibreOffice Writer, Google Docs or Pages. The tool has no settings to choose: it converts the whole document, every page, in one pass. Your job afterwards is to check it, because a converted document is a very good first draft of the original, not a guaranteed copy of it.

How to convert a PDF to Word

  1. Open PDF to Word and choose a single PDF. The tool takes one file per job; convert several files one after another.
  2. Click Convert. The status line moves through Preparing, Uploading, Converting and Downloading as the job runs.
  3. Wait while the server works. Short text documents usually finish quickly; long or image-heavy files take longer, and the tool gives up after roughly three minutes of waiting.
  4. Save the .docx. It normally keeps your original file name with the new extension, for example report.pdf becomes report.docx.
  5. Open it in your word processor and compare it page by page with the PDF before you edit, paying particular attention to tables, headers and footnotes.

When to use this tool

  • Updating an old contract or policy when only the signed PDF survived and the original Word file is lost.
  • A teacher reusing a worksheet that a colleague shared as a PDF, changing the questions for a new class.
  • Translators who need the source text in an editable format their translation tools can read.
  • Pulling several paragraphs from a published report into your own document without retyping and without copy-paste line breaks.
  • Correcting a typo in a CV or brochure when the designer who made it is no longer available.
  • Turning a PDF form letter back into a template you can mail-merge.

What to know before you start

  • The conversion happens on a server, not in your browser. The PDF is uploaded encrypted, converted and then deleted from the conversion service once the job is done.
  • Scanned pages have no text layer, only a picture of text. Without a text layer there is nothing to turn into editable words, so a scan typically comes through as an image inside the document. If you need editable text from a scan, run it through OCR PDF first: the searchable PDF gives the converter real text to work with, though the layout may need tidying. The .txt output is the simpler fallback.
  • Layout is rebuilt, not copied. Multi-column pages, text boxes, sidebars and pull quotes may end up as floating text frames, and line spacing can shift so page breaks move.
  • Fonts that are not installed on your computer are substituted when you open the .docx, which changes line lengths and can push text onto another page.
  • Password-protected PDFs cannot be converted. Remove the protection first with Unlock PDF or in the program that created the file.
  • Only one PDF per job, with no page-range option. If you only need two pages of a 90-page report, extract those pages first; the job is faster and the result easier to check.

Tips for the best results

  • Before converting, try selecting text in the PDF viewer. If you cannot highlight individual words, the file is a scan; run OCR PDF first and convert the searchable copy.
  • Extract just the pages you need with Extract Pages, then convert that smaller file; it uploads and converts faster.
  • Turn on formatting marks (the paragraph symbol) in Word straight away. It shows hard line breaks and stray section breaks the converter inserted.
  • If a table comes out as tab-separated text, try PDF to Excel on the same page; spreadsheet output often handles grids better.
  • Keep the PDF open next to the Word file while you edit, so you notice any missing line or footnote immediately.

Example: a landlord updating a tenancy agreement

A landlord has a six-page tenancy agreement from three years ago. The original Word file was on a laptop that has since died, and only the signed PDF export from the old letting agent remains. The new lease needs a different rent, new dates and one added clause about bicycle storage.

She extracts pages 1 to 5 (page 6 is the signature page, which will be redone anyway) and converts that file. The .docx opens with the clauses as normal paragraphs and the numbered headings intact. Two things need fixing: the rent schedule, which was a small table, has become lines separated by tabs, and the footer with the property address has turned into a text box. She rebuilds the table with Word's Insert Table, moves the address into a real footer, makes her changes and saves a new PDF with Word to PDF.

The whole job takes about twenty minutes instead of an evening of retyping. The point is that the conversion did roughly 90 percent of the work, and the remaining 10 percent was predictable: tables and page furniture are where converted documents most often need hand repair.

Troubleshooting

The Word file shows each page as one big picture
The PDF is scanned or was saved from an image. Run it through OCR PDF first and convert the searchable copy, or paste the .txt output into Word.
The text is there but every line ends with a hard break
The PDF stored lines rather than paragraphs. In Word use Find and Replace to replace manual line breaks (^l) or paragraph marks inside paragraphs with spaces, working one section at a time.
Columns are mixed together or appear in odd text boxes
Multi-column layouts are hard to rebuild. Copy the text out of the boxes into a fresh single-column document, or set Word's column layout yourself and paste the text back in.
The conversion says it timed out
The tool stops waiting after about three minutes. Very long or image-heavy PDFs can exceed that. Split the file with Split PDF or Extract Pages and convert the parts.
It says the conversion failed on the server
The PDF is most likely password-protected, damaged or not really a PDF. Open it in a viewer to check, run it through Repair PDF if it opens with errors, and try again.
Fonts look different from the PDF
The original fonts are not installed on your computer, so Word substituted them. Install the font or select all text and choose a similar font you have.

Frequently asked questions

Will the Word file look exactly like my PDF?

Usually close, rarely identical. Body text and headings convert well; tables, columns, text boxes and exact page breaks are where differences appear.

Can it convert a scanned document into editable text?

Not by itself. A scan has no text layer; run OCR PDF first so the converter has real text to work with, and expect to fix some layout and recognition errors.

Which Word format do I get?

A .docx file, which opens in Microsoft Word 2007 and later, LibreOffice, Google Docs and Apple Pages.

Can I convert only some pages?

The tool converts the whole file. Use Extract Pages first to make a PDF containing just the pages you want.

Why does this tool upload my file when others do not?

Rebuilding a Word document from a PDF needs a full conversion engine, which runs on a server. The file is sent encrypted and deleted from the service after conversion.

Is there a charge or sign-up?

No. You choose a file and convert it without creating an account.

Rotate PDF

Rotating a page in your PDF viewer usually only changes how you are looking at it on that screen. Close the file, send it to someone, or open it on another device, and the landscape table is sideways again. To fix it for everyone the rotation has to be saved into the file itself, which is what this tool does.

Every page in a PDF carries a rotation setting, a number that tells viewers and printers to turn the page by 0, 90, 180 or 270 degrees when displaying it. PDFora's Rotate tool opens your file with pdf-lib, adds the angle you chose to that setting on the pages you selected, and saves the document. The page content itself is not touched: no text is re-flowed, no image is recompressed, and nothing is converted to a picture. That is why rotation is instant and lossless even on large scans.

Because the tool modifies the existing document rather than building a new one from copied pages, it also keeps more of the file's structure than the page-shuffling tools do. Bookmarks, internal links and form fields stay where they were. The download is saved as yourfile-rotated.pdf.

How to rotate PDF pages

  1. Open Rotate PDF and choose one file.
  2. Pick the rotation: 90 degrees clockwise, 180 degrees, or 90 degrees counter-clockwise.
  3. Leave the Pages box empty to rotate every page, or type the pages to turn, for example 3, 7-9, 15-.
  4. Click Rotate & download. The angle is added to each selected page's existing rotation and the file is saved.
  5. Open yourfile-rotated.pdf and check the turned pages. If one went the wrong way, run the same tool on the result with the opposite direction.

When to use this tool

  • Fixing a phone-scanned receipt bundle where the app saved every page sideways.
  • Turning the landscape spreadsheet pages inside an otherwise portrait financial report so they read correctly on screen.
  • Correcting pages that came out of a document feeder upside down, by rotating just those pages 180 degrees.
  • Preparing an architectural or engineering drawing set so every sheet opens with the title block in the right corner.
  • Making a PDF of slides or certificates display upright on tablets and in e-readers, which often ignore temporary viewer rotation.
  • Straightening a contract where only the signature page was scanned in the wrong orientation.

What to know before you start

  • Rotation only comes in quarter turns. The tool cannot fix a scan that is tilted by a few degrees; for that, use Deskew, which straightens slightly crooked scanned pages.
  • The angle you choose is added to the page's current rotation. A page already rotated 90 degrees and rotated 90 degrees again ends up at 180, not 90.
  • An empty Pages box means all pages. Numbers past the last page are ignored, and a range written backwards, such as 8-5, selects nothing, which leaves those pages unrotated.
  • Only the display rotation changes. Text extraction and search still work as before, and copied text comes out in its normal reading order.
  • Some older or very simple viewers handle rotated pages poorly when printing, for example scaling them down. If print output looks wrong, use the print dialog's auto-rotate or fit-to-page option.
  • To rotate different pages by different amounts, run the tool more than once, or use Organize Pages, which lets you turn each page on its own with thumbnails in view.

Tips for the best results

  • Before rotating, make a quick list: pages that need clockwise, pages that need counter-clockwise, pages that need 180. Then do one run per group on the same file.
  • Clockwise vs counter-clockwise is easy to mix up. Look at where the top of the text is: if it points left, rotate 90 degrees clockwise; if it points right, rotate counter-clockwise.
  • Rotate before running OCR. Text recognition works far better on upright pages.
  • If a page looks right in one viewer and wrong in another, the file may contain conflicting settings. Rotate it to the right orientation in our tool and test in both viewers again.
  • Since rotation is lossless, you can rotate the same file several times without any quality cost; there is no reason to go back to the original.

A worked example: a freelancer's expense receipts

A freelance photographer has photographed 23 receipts with a scanning app for a quarterly expense claim. The app saved pages 1 to 18 sideways with the top pointing left, pages 19 and 22 upside down, and the rest correctly. The accountant has asked for one PDF that can be read without turning the screen.

The first run selects 90 degrees clockwise with 1-18 in the Pages box. The second run takes that result, selects 180 degrees and types 19, 22. Two runs, a few seconds each, and every page is upright. Because rotation only edits a setting on each page, the 23-page file is effectively the same size afterwards, and the receipt photos are not recompressed, so small print such as tax numbers stays as legible as the original capture.

Had the receipts also been in the wrong order, it would have made more sense to use Organize Pages once to rotate and reorder together, rather than rotating here and reordering in a second tool.

Troubleshooting

Nothing changed in the output
Check the Pages box. Pages that do not exist and backwards ranges are silently ignored. Leave it empty if you meant all pages.
The pages turned the wrong way
Run the tool on the output with 180 degrees if they are now upside down, or with the opposite 90-degree option if they are sideways. Each run is lossless.
The pages look upright in my browser but sideways in another app
Some apps apply their own saved view rotation. Reset the view in that app, or open the file fresh; the page's real rotation is now stored in the file.
The scan is still slightly crooked
Rotate only does quarter turns. Use Deskew for small tilts after the page is the right way up.
The file will not load
The PDF may be damaged or password-protected. Try Repair PDF, or remove the protection in the application that created the file, then rotate the copy.
The rotated page prints small or cut off
Turn on auto-rotate and fit to page in the print dialog. Mixed portrait and landscape pages are handled per page by most modern printer drivers.

Frequently asked questions

Does rotating a PDF reduce its quality?

No. Only the page rotation setting is changed. Text, images and vector graphics are not re-rendered or recompressed.

Can I rotate only some pages?

Yes. Type the pages or ranges, for example 2, 5-8. Leave the box empty to rotate them all.

Will my bookmarks and links still work after rotating?

Yes. The tool edits the existing document instead of building a new one, so bookmarks, internal links and form fields are kept.

Why did my page end up at the wrong angle?

The chosen angle is added to the rotation the page already had. A page that was already turned will move from its current position, not from upright.

Can I rotate by 45 degrees?

No. PDF page rotation only supports multiples of 90 degrees. For slightly tilted scans use Deskew.

Is my file sent to a server to be rotated?

No. The rotation is applied with pdf-lib in your browser; the file stays on your device.

A long PDF is often the wrong shape for the job in front of you. A teacher needs to hand each student only their own report card out of a 32-page export; a tenant wants to send the landlord pages 4 to 6 of a lease, not all 40; a scanner has produced one huge file for a stack of unrelated letters. Splitting turns that single document into several independent PDFs, each of which can be named, emailed or archived on its own.

PDFora's Split tool offers three modes. Every page produces one PDF per page. Every N pages cuts the document into equal chunks (the default is 2 pages per file; the last chunk simply holds whatever is left). Custom ranges lets you type groups such as 1-3, 4-6, 7-10, where every comma starts a new output file. In all three modes the pages are copied as they are with pdf-lib: text stays selectable, images keep their resolution, and nothing is redrawn, so a page in the output prints exactly like the same page in the original.

The result arrives as numbered files named after your original: contract.pdf becomes contract-1.pdf, contract-2.pdf and so on. You can download everything at once as contract-split.zip or click individual files in the list. Because the copying happens in the browser tab, the speed depends on your device rather than on a server queue.

How to split a PDF into separate files

  1. Open Split PDF and add one file. The tool works on a single document at a time.
  2. Choose a mode: Every page, Every N pages, or Custom ranges.
  3. For Every N pages, enter the chunk size. For Custom ranges, type the groups separated by commas, for example 1-2, 3, 4-9. Each group becomes one file.
  4. Click Split PDF and wait for the progress bar; one output file is built per group.
  5. Click Download all (.zip) or download the parts one by one, then open a couple of them to confirm the cut points.

When to use this tool

  • Schools: separating a bulk export of report cards or certificates into one file per student before sending them to parents.
  • Rental paperwork: pulling the signed signature pages or a single annex out of a long lease to send to the other party.
  • Accounts payable: breaking a scanned batch of single-page invoices into one PDF per invoice for upload into bookkeeping software.
  • Self-publishing: cutting a manuscript into chapter files for beta readers who only need the part they are reviewing.
  • Portals with page limits: some application systems accept only a few pages per upload, so chunks of N pages fit their rules.
  • Printing jobs: sending only the colour pages of a report to a print shop as their own file.

What to know before you start

  • In Custom ranges mode a range such as 4-6 means pages 4, 5 and 6 inclusive. You can leave one end open: -5 means pages 1 to 5 and 8- means page 8 to the last page.
  • Numbers beyond the end of the document are trimmed rather than rejected. Typing 20-30 on a 25-page file produces pages 20 to 25. A part that contains no valid page at all is skipped, and if nothing valid is left you see the message to enter at least one valid range.
  • Ranges may overlap. 1-5, 3-8 produces two files that both contain pages 3 to 5. This is useful when every recipient needs a shared cover page, but easy to do by accident.
  • Each output keeps only pages. The bookmark outline is not copied, links that jumped to pages now in another file stop working, and fillable form fields may not survive. Web links on a page still work.
  • Fonts and images used on several pages are stored again in every part that needs them, so the parts added together are usually somewhat larger than the original file.
  • The results list shows individual download buttons for up to 50 files. Splitting a 300-page document page by page still works, but use the zip download to get all of them.

Tips for the best results

  • Write the ranges down from the page thumbnails in your viewer before you start; the page numbers the tool uses are the physical positions in the file, not the numbers printed in the footer.
  • If you only need one block of pages, Extract Pages gives you a single file directly instead of a zip with one item.
  • Rename the parts right after unzipping. contract-3.pdf means nothing in a month; contract-annex-B.pdf does.
  • For a scanner batch where each document has a different length, split by text or by bookmarks instead of counting pages by hand.
  • Keep the original. A split cannot be undone, but you can always rejoin the parts with Merge PDF if you cut in the wrong place.

Example: a class set of report cards

A form tutor downloads the end-of-term reports for 28 pupils from the school's management system. It arrives as one 56-page PDF: two pages per pupil, always in the same order, with the pupil's name on the first page of each pair. Emailing the whole file to every family is obviously not an option.

Choosing Every N pages with 2 pages per file produces 28 files, reports-1.pdf to reports-28.pdf, in the same order as the class list. The tutor checks reports-1 and reports-28 to make sure the pairing did not drift (if one pupil had a three-page report, every file after that would be shifted by a page and Split by Text on the word that heads each report would be the safer choice). With the pairing confirmed, each file is renamed after the pupil and attached to the right message.

Troubleshooting

I get 'Enter at least one valid range'
None of the ranges matched a real page. Check for typos such as 1–3 typed with a long dash from a word processor, letters, or page numbers higher than the document has. Use plain hyphens and commas.
The parts are shifted by one page
The tool counts pages by position in the file. If your document has a cover or an unnumbered front page, printed page 1 may be physical page 2. Adjust the ranges by the offset.
I asked for ranges but got one big file
Groups are separated only by commas. 1-3 4-6 written with a space is read as a single malformed range. Write 1-3, 4-6.
The output pages are blank or the tool errors on load
The source is probably encrypted or damaged. Remove the password in the app that created it, or run Repair PDF first, then split the clean copy.
Bookmarks and internal links no longer work
Splitting copies page content only. If the parts need navigation, add bookmarks to each with Add Bookmarks; internal links pointing to other parts cannot be preserved.
The browser slows down on a very large file
Every output is built in memory. Close other tabs or split in larger chunks first, then split those chunks again.

Frequently asked questions

Does splitting change the quality of the pages?

No. Pages are copied object by object, not rendered to images, so text, vector drawings and photos are identical to the original.

How are the output files named?

After the original file plus a number in output order: report.pdf gives report-1.pdf, report-2.pdf and so on, delivered together in report-split.zip.

Can one page appear in more than one output file?

Yes, in Custom ranges mode. Overlapping ranges like 1-2, 1, 3-5 put page 1 into the first two files.

What happens to the last chunk in Every N pages mode?

It holds the remaining pages. A 10-page document split every 3 pages gives files of 3, 3, 3 and 1 pages.

Can I split several PDFs in one go?

No, the tool takes one file per run. Split each document separately, or merge them first if they should be cut as one sequence.

Do I need an account?

No. There is no sign-up and no limit on the number of splits.

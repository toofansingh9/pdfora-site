Split by Bookmarks

Turn each top-level bookmark of a PDF into its own file, named after the bookmark, so chapters and sections come out ready to share.

Well-made long PDFs already know where their sections begin. Handbooks, theses, annual reports and manuals exported from a word processor usually carry an outline, the bookmark panel your viewer shows on the side, with one entry per chapter. Split by Bookmarks reads that outline and cuts the document at every top-level bookmark, so you do not have to look up page numbers or type ranges. If the outline was carefully built, the split usually matches the structure the author intended.

The tool uses PDF.js to read the outline and to find the page each bookmark points to. It then sorts the bookmarks by page and creates one file per bookmark, running from its page up to the page before the next bookmark; the last bookmark runs to the end of the document. The pages are copied unchanged with pdf-lib, so text stays searchable and images keep their quality.

Files are named after the bookmark itself, which is the main advantage over a numbered split. A file called handbook.pdf with bookmarks Introduction, Safety and Appendix gives 'handbook - Introduction.pdf', 'handbook - Safety.pdf' and 'handbook - Appendix.pdf', bundled as handbook-bookmarks.zip. Characters that file systems refuse, such as / : * ? " < > |, are removed, and titles are shortened to 40 characters.

How to split a PDF by its bookmarks

  1. Open the PDF in your usual viewer and look at the bookmark or outline panel; this is what the tool will use.
  2. Open Split by Bookmarks and add the file. There are no options.
  3. Click Split by bookmarks.
  4. Download the zip or individual files; each is named after its bookmark.
  5. Check the first file: if your document has pages before the first bookmark, read the note on cover pages below. Pages before the first bookmark are not exported.

When to use this tool

  • Breaking a staff handbook into chapters so each team receives only the policies that apply to it.
  • Separating a thesis or dissertation into chapters for a supervisor who reviews one at a time. Each chapter file keeps its original page layout and footnotes.
  • Pulling individual sections out of a long tender or contract that was assembled with bookmarks per schedule.
  • Splitting an exported legal bundle into its tabs when each tab is a bookmark.
  • Dividing a technical manual into product sections for publishing on a support page.
  • Separating a conference proceedings volume into individual papers, where each paper has a bookmark.

What to know before you start

  • Only top-level bookmarks are used. Nested entries (sub-chapters under a chapter) stay inside their parent's file and do not cause their own cut.
  • Pages before the first bookmark are not included in any output. If the first bookmark points to page 3, the cover and contents on pages 1 and 2 are left out. Add a bookmark on page 1 with Add Bookmarks first if you need them. This is the most common surprise with this tool, so check the page that the first bookmark opens.
  • If two bookmarks point to the same page, the earlier one has no pages of its own and is skipped; the later one gets the section.
  • Bookmarks that open a web address or run an action instead of pointing to a page cannot be resolved and are ignored. If none resolve, the tool reports that it could not resolve the bookmark destinations.
  • Bookmarks are sorted by page, not by their order in the panel, so an outline listed out of order still produces sections in document order.
  • The output files themselves have no bookmark outline; sub-bookmarks are not recreated inside each part.

Tips for the best results

  • No bookmarks? Add them in a minute with Add Bookmarks (one line per section, as page, Title), then run this tool on the result. Bookmarks created that way are top-level, which is exactly what this tool splits on.
  • Rename bookmarks before splitting if their titles are long. Only the first 40 characters reach the file name, and two titles that start identically become hard to tell apart.
  • If your outline has a single top-level entry with everything nested below it, you will get one file. Use Split PDF with ranges taken from the nested entries instead.
  • Give file-system-safe titles in the source document (avoid slashes and colons) so the names come out exactly as written.
  • Check a part in the middle as well as the first and last; a bookmark pointing to a wrong page in the source shows up as a section that starts too early or too late. Clicking each top-level bookmark in your viewer before splitting shows you exactly where every file will begin.

Example: a law firm's hearing bundle

A paralegal receives a 412-page hearing bundle as one PDF. Its outline has nine top-level bookmarks, Tab A Pleadings through Tab I Correspondence, each with sub-bookmarks for individual documents. The client only needs Tabs C and F, and the expert witness only Tab G.

Split by Bookmarks gives nine files such as 'bundle - Tab C Witness statements.pdf', each with every page of that tab and its sub-documents together. The paralegal sends the relevant tabs without counting a single page. The index on pages 1 to 4, which sat before the Tab A bookmark, is not in any of the files, which suits this purpose; had the index been needed, adding a bookmark called Index on page 1 before splitting would have given it its own file. The sub-bookmarks for individual witness statements were not used as cut points, so each tab remained a single coherent file.

The bundle was not uploaded anywhere to do this: the outline was read and the pages copied inside the browser tab, which matters for privileged material.

Troubleshooting

Error: 'This PDF has no bookmarks to split on'
The file has no outline. Add bookmarks with the Add Bookmarks tool, or split by page ranges or by text instead.
Error: 'Could not resolve the bookmark destinations'
The bookmarks exist but do not point to pages, for example because they are links or scripts, or because the outline is damaged. Run Repair PDF, or recreate the bookmarks with Add Bookmarks.
My cover and contents pages are missing
They come before the first bookmark and are not assigned to any section. Add a bookmark on page 1, then split again.
I only got one file
All your sections are nested under a single top-level bookmark. Use Split PDF with Custom ranges based on the nested entries.
A section is missing
Its bookmark probably points to the same page as the next one, or to a web link. Correct the bookmark in the source and run the split again.
File names are cut off or look different
Titles are shortened to 40 characters and characters like / : ? are removed. Rename the files after downloading if needed. The original document is not changed.

Frequently asked questions

Are sub-bookmarks used as split points?

No. Only the top level of the outline creates new files; nested sections stay with their parent chapter.

What happens to pages before the first bookmark?

They are not included in any output file. Bookmark page 1 first if you need them.

Can I choose which bookmarks to split on?

Not in this tool. Split on all of them and keep the files you need, or use Split PDF with custom ranges.

Do the output files keep their own bookmarks?

No. The outline is used to decide the cuts but is not copied into the parts.

Is page quality affected?

No. Pages are copied as they are, not re-rendered.

Does it work on scanned documents?

Yes, as long as the scan has bookmarks. Bookmarks are independent of whether the pages contain real text. Bookmarks added to a scanned PDF with Add Bookmarks work the same way.

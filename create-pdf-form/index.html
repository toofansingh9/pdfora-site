Create Forms

Turn a flat PDF into a fillable form by placing text fields and checkboxes on its pages.

A form that has to be printed, filled in by hand and scanned back wastes everybody's time, and the scans are often hard to read. If you already have the form as a PDF, you can make it fillable: draw real input boxes over the blank lines so that anyone opening it in a normal PDF reader can click and type. That is what Create Forms does, and it keeps the job deliberately simple.

There are two kinds of field: a text field and a checkbox. Click on a page and a field appears there, 130 × 28 pixels for text and 26 × 26 for a checkbox; drag it to move it and pull the corner handle to resize it to the space on the form. A Move mode lets you rearrange fields without accidentally creating new ones. There are no dropdowns, radio buttons, date pickers, signature fields or calculation rules in this tool.

When you click Save form, pdf-lib adds genuine AcroForm fields to the original document at the positions you chose, converted from screen pixels to PDF points. The page content itself is left as it was, so the printed questions stay as sharp, selectable text. The file is saved as yourfile-form.pdf.

How to make a PDF fillable

  1. Open Create Forms and drop in the flat PDF. Each page is shown full-width, one below the other.
  2. With Text field selected, click on each blank line. Drag the field so it sits on the line and resize it from the corner to match the available width.
  3. Switch to Checkbox and click on every tick box printed on the form, resizing them to cover the printed square.
  4. Use Move if you need to rearrange fields; the × on a field deletes it.
  5. Click Save form, then open the -form.pdf in a PDF reader and tab through the fields to test them before you share the file.

When to use this tool

  • A sports club's paper membership form that members should be able to complete on a laptop.
  • Internal request forms in a small office: leave requests, equipment requests, expense claims.
  • A charity's volunteer registration sheet that is currently photocopied and posted.
  • Teachers turning a worksheet into a version students can type answers into.
  • Landlords and letting agents making a fillable property inspection checklist with tick boxes.
  • Event organisers collecting dietary needs and contact details from a one-page PDF.

What to know before you start

  • Fields get automatic names: text_0, text_1 and so on, and chk_0, chk_1 for checkboxes, numbered page by page in the order they were placed. You cannot rename them here. If you plan to export the data or connect the form to another system, rename the fields afterwards in a full form editor.
  • If the PDF already contains form fields, a new field can collide with an existing one of the same name (for example a field already called text_0), and saving will fail. This tool is meant for flat PDFs with no existing fields.
  • Only two field types are available. A question with several exclusive options has to be built from separate checkboxes, and nothing stops someone ticking two of them.
  • There is no validation: text fields accept any input, cannot be made required and have no maximum length or number format.
  • How empty fields look depends on the reader. Some show a highlighted or bordered box, others show nothing until you click. Test the result in the reader your recipients are most likely to use.
  • The tool needs at least one field; saving with none shows 'Add at least one field first.'

Tips for the best results

  • Make text fields the full height of the line space, not just the line itself. A field that is too short squeezes the typed text into a tiny font in some readers.
  • Place fields in the order people should fill them. The names follow that order, and many readers use it for Tab navigation too.
  • For a long text answer, make one tall text field rather than several stacked narrow ones; it is easier to type into.
  • Zoom out in your browser to see a whole page while placing fields, then zoom in to fine-tune the edges.
  • Once someone has filled the form and you want to archive it unchangeable, run their copy through Flatten PDF.

Example: an NGO's volunteer sign-up form

A small food-bank charity has a one-page volunteer form designed years ago as a printed sheet: name, phone, email, address, three lines for 'Why would you like to volunteer?', and six tick boxes for the days of the week someone is available. Volunteers currently print it, fill it in by hand and drop it off.

The coordinator opens the PDF in Create Forms and clicks once on each of the four contact lines, stretching each text field to the full width of its line. For the motivation question she makes a single tall field covering all three lines. Then she switches to Checkbox and clicks on each of the six day boxes, shrinking them to cover the printed squares exactly. Saved as volunteer-form-form.pdf, it has ten fields: text_0 to text_4 and chk_0 to chk_5.

She sends it to two colleagues first. One opens it in a desktop reader, the other on a phone, and both confirm they can type and tick. Only then does it go on the website, with the note 'Fill in, save and email back'.

Troubleshooting

Clicking on the page does not add a field
Move mode is active. Select Text field or Checkbox again in the toolbar. Clicking on an existing field selects it instead of creating a new one.
Save fails with an error about a field name
The PDF already had form fields with the same names. Use Flatten PDF on the original to turn its existing fields into plain content, then add new fields to the flattened copy.
The fields are slightly off the lines in the saved file
Positions are converted from the on-screen page size to PDF points, so tiny offsets can appear. Make fields a few pixels larger than the line and check the result; move and resave if needed.
Text typed into a field is tiny or cut off
The field is too small for the default font size in that reader. Make the field taller and wider and save again.
Recipients cannot see the fields at all
Some browsers' built-in viewers and older apps do not show form field outlines or do not support forms. Ask them to open the file in a full PDF reader.
The checkbox will not tick in the browser preview
Some lightweight viewers do not support interactive checkboxes. Download the file and open it in a desktop or mobile PDF app to test.

Frequently asked questions

Which field types can I add?

Text fields and checkboxes. Dropdowns, radio button groups, signature fields and buttons are not available in this tool.

Will the people filling the form need special software?

No, any PDF reader with form support can fill it in, including most desktop and mobile PDF apps. Some basic built-in viewers have limited form support.

Can I rename the fields?

Not in this tool. Fields are named text_0, text_1, chk_0 and so on in the order you placed them. Rename them in a full form editor if the names matter to you.

Can I make a field required or limit what is typed?

No. Fields have no validation, required flags, character limits or formatting rules.

Can I add fields to a scanned form?

Yes. A scanned page is treated like any other page; place the fields over the blank spaces in the image.

Can I lock a filled-in form so it cannot be changed?

Run the completed file through Flatten PDF. The values become part of the page and the fields disappear.

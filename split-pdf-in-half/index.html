Split in Half

Cut a PDF into two files at the middle page in one click, with the extra page going to the first half when the count is odd.

Sometimes there is no clever rule for where a document should be cut: it is simply too big for one attachment, one upload slot or one reviewer, and two pieces would do. Split in Half exists for exactly that case. It has no options to set. You give it a PDF, it finds the middle, and you get two files back.

The arithmetic is fixed. The tool takes the page count, divides it by two and rounds up, and that many pages go into the first file. A 20-page document becomes 10 and 10; a 21-page document becomes 11 and 10. The pages are copied unchanged with pdf-lib, so text remains searchable and images keep their resolution. Nothing is resampled or rasterised.

The two outputs are named after the source with -part1 and -part2 added, so thesis.pdf becomes thesis-part1.pdf and thesis-part2.pdf, packaged together as thesis-halves.zip. Because the split is by page count, not by file size, the two halves are not guaranteed to weigh the same. If one half contains all the photographs, it will be the heavy one. If you need to know the exact cut before you start, take the page count shown in your viewer, add one if it is odd, and halve it: that is the last page of part1.

How to split a PDF in half

  1. Open Split in Half and add the PDF. Only one file is accepted per run.
  2. There is nothing to configure; check that you added the right document.
  3. Click Split in half.
  4. Download the zip, or each half separately from the list of files.
  5. Open part1 and check its last page and part2's first page to see where the cut fell. For odd page counts, part1 will be one page longer.

When to use this tool

  • Email attachments that are just over a size limit, where two messages are acceptable.
  • Dividing a long reading pack between two study partners or two teaching assistants for marking.
  • Upload forms that offer two separate document slots of limited size.
  • Sharing a draft for review in two sittings, so the reviewer gets a manageable first half today and the rest tomorrow.
  • Printing a thick booklet on two different printers at once to save time before a meeting.
  • Testing: a quick way to check whether a problem in a broken PDF lives in the first or second half of the document. Repeat on the faulty half to narrow it down.

What to know before you start

  • The cut is always at the middle page by count. If you need the break at a chapter boundary, use Split PDF with Custom ranges, Split by Bookmarks or Split by Text instead. Halving ignores the content entirely; it never looks for headings or blank pages.
  • For an odd number of pages the first half receives the extra page.
  • A one-page PDF cannot be halved: you get a single file, part1, containing that page, and no part2.
  • Page count and file size are different things. A document whose first ten pages are scans and last ten are plain text can produce a 9 MB half and a 200 KB half. Use Split by Size when the goal is a size limit.
  • The bookmark outline is not copied into either half, and links that jump from one half to a page in the other half stop working.
  • Shared fonts and images are stored in both halves when both use them, so part1 plus part2 can be slightly larger than the original. For documents made mostly of text, the overhead is the embedded fonts, which are typically tens to a few hundred kilobytes per half.

Tips for the best results

  • Before splitting for an email limit, compare the file size to the limit. If it is more than twice the limit, halves will still be too large; compress first or use Split by Size. Two halves each under the limit is the target; one half under and one over means the split solved nothing.
  • Rename the halves descriptively before sending, for example application-pages-1-12.pdf, so the recipient knows the range without opening them.
  • If a chapter straddles the middle, consider Split PDF with ranges such as 1-14, 15-26 so the break falls between chapters.
  • Use the halving trick repeatedly to find a corrupt page: split, test each half, split the faulty half again. Each round halves the number of pages to inspect, so even a 500-page file narrows to one page in about nine rounds.
  • Keep the original file; rejoining with Merge PDF is possible but adds a step you do not need.

Example: a charity grant report and a two-slot upload form

A small NGO is submitting its annual report to a funder whose portal has two attachment fields, Report part A and Report part B, each capped at 8 MB. The final report is 46 pages and 12 MB, and the designer who produced it has already left for the day.

Split in Half produces annual-report-part1.pdf with pages 1 to 23 and annual-report-part2.pdf with pages 24 to 46. The coordinator checks the sizes before uploading: part1 is 7.1 MB because it holds the photo-heavy project stories, and part2 is 4.9 MB because it is mostly financial tables. Both fit. Had part1 come out at 9 MB, the fix would have been to compress just that half rather than redoing the split.

Page 23 happened to fall in the middle of the programme section, which the funder will not mind, but a note in the covering message saying 'part B continues from page 24' saves the reader a moment of confusion. The same two files also work if the funder later asks for a single document: Merge PDF puts part1 and part2 back together in the original order, with no change to the pages.

Troubleshooting

I only got one file
Your PDF has a single page, so there is nothing to put in a second half. Check the page count in your viewer.
One half is still too large to send
Halving goes by pages, not megabytes. Compress the larger half, or use Split by Size and set the limit you need.
The cut is in the middle of a section
That is how a pure halving works. Use Split PDF with Custom ranges and choose the boundary yourself.
The file will not load
It is probably password-protected or damaged. Remove the protection in the software that created it or run Repair PDF, then try again.
The halves together are bigger than the original
Fonts and images used on both sides of the cut are stored in each half. The overhead is usually small; compress if it matters.
The second half starts with a blank page
The source document itself has a blank page at that position, often a deliberate left-hand page in a print layout. Remove it with Delete Pages before or after splitting.

Frequently asked questions

Where exactly is the cut made?

After page ceil(N/2). For 30 pages that is after page 15; for 31 pages, after page 16.

Can I choose a different split point?

Not in this tool, which deliberately has no options. Use Split PDF with Custom ranges for any split point.

Is the quality of the pages affected?

No. Pages are copied, not re-rendered, so text, vectors and images are unchanged.

What are the output files called?

The original name plus -part1 and -part2, bundled as name-halves.zip.

Can I split it into thirds or quarters?

Use Split PDF in Every N pages mode with N equal to a third or a quarter of the page count, rounded up. For a 30-page file split into thirds, that means N = 10.

Are my bookmarks kept?

No, the outline is not copied. Add bookmarks to each half afterwards with Add Bookmarks if needed.

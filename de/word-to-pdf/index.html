Word in PDF

Wandeln Sie eine DOC- oder DOCX-Datei auf einem Konvertierungsserver in PDF um – so ist das Layout fixiert, und das Dokument sieht bei allen gleich aus.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Eine Word-Datei ist eine Bauanleitung, keine fertige Seite. Wo eine Zeile umbricht, auf welcher Seite eine Überschrift landet und wie breit eine Tabellenspalte ist, berechnet jedes Programm, das die Datei öffnet, neu – mit den Schriften, die auf diesem Rechner gerade installiert sind. Deshalb kommt ein Lebenslauf, der auf Ihrem Laptop ordentlich aussah, beim Empfänger manchmal mit einer verwaisten Überschrift unten auf Seite eins an. Ein PDF speichert dagegen die fertigen Seiten, und genau darum verlangen Bewerbungsportale, Gerichte und Druckereien eines.

Anders als die meisten PDFora-Tools läuft dieses nicht in Ihrem Browser. Um aus DOCX gesetzte Seiten zu machen, braucht es eine vollständige Textverarbeitungs-Engine. Ihre Datei wird deshalb über das Relay von PDFora zum Konvertierungsdienst CloudConvert hochgeladen, dort umgewandelt, und das fertige PDF wird zu Ihnen zurück heruntergeladen. Die Übertragung ist verschlüsselt, und die Dateien werden nach dem Auftrag beim Dienst gelöscht. Darf ein Dokument Ihren Rechner niemals verlassen, nutzen Sie stattdessen „Als PDF speichern“ in Word oder LibreOffice.

Das Tool konvertiert eine Datei pro Durchgang und nimmt .doc und .docx an. Einstellungen gibt es keine: Das PDF übernimmt Seitenformat, Ränder, Kopf- und Fußzeilen aus dem Dokument. Das Ergebnis heißt wie Ihr Original, aus Angebot.docx wird also Angebot.pdf. Da das Layout auf einem anderen Rechner berechnet wird, hängt die Qualität des Ergebnisses vor allem davon ab, wie das Dokument aufgebaut ist; die folgenden Abschnitte erklären, was erhalten bleibt und was Sie prüfen sollten.

So wandeln Sie Word in PDF um

  1. Speichern und schließen Sie das Dokument zuerst in Word, damit die Datei Ihre letzten Änderungen enthält und alle Überarbeitungen, die Sie annehmen wollten, angenommen sind.
  2. Öffnen Sie „Word in PDF“ und wählen Sie die .docx- oder .doc-Datei aus. Pro Durchgang wird eine Datei umgewandelt.
  3. Klicken Sie auf „Konvertieren“. Die Statuszeile zeigt nacheinander „Wird vorbereitet…“, „Wird hochgeladen…“ und „Wird konvertiert…“; die meisten Dokumente sind in deutlich unter einer Minute fertig.
  4. Laden Sie das PDF herunter, sobald es erscheint. Es trägt denselben Namen wie Ihr Dokument mit der Endung .pdf.
  5. Öffnen Sie es und vergleichen Sie Seitenumbrüche, Tabellen und besondere Schriften mit dem Original, bevor Sie es verschicken.

Wann Sie dieses Tool nutzen sollten

  • Rechnungen und Angebote von Selbstständigen, die in einer Word-Vorlage entstehen und als PDF rausgehen, damit der Kunde die Summen nicht versehentlich ändert.
  • Lebenslauf und Anschreiben für Portale, die nur PDF annehmen, oder wenn das Layout genau so bleiben soll, wie Sie es gestaltet haben.
  • Abschluss- und Hausarbeiten, die über ein Hochschulsystem eingereicht werden, das PDF verlangt.
  • In Word erstellte Verträge und Briefe, die gedruckt, unterschrieben oder in fester Form archiviert werden müssen.
  • Dokumente auf dem Handy oder an einem gemeinsam genutzten Rechner ohne Office-Installation umwandeln.
  • Eine alte .doc-Datei aus einem Altsystem in etwas verwandeln, das jedes Gerät öffnen kann.

Das sollten Sie vorher wissen

  • Schriften sind die häufigste Ursache für Abweichungen. Der Server kann nur Schriften verwenden, die er selbst hat oder die in der DOCX eingebettet sind. Eine individuelle oder gekaufte Schrift, die auf Ihrem Rechner installiert, aber nicht eingebettet ist, wird durch eine ähnliche ersetzt – das kann Zeilenumbrüche und Seitenzahl verschieben. In Word können Sie vor dem Konvertieren unter Optionen > Speichern „Schriftarten in der Datei einbetten“ aktivieren.
  • Überarbeitungen und Kommentare können im PDF erscheinen, wenn sie noch im Dokument stehen. Nehmen Sie alle Änderungen an oder lehnen Sie sie ab und löschen Sie die Kommentare vorher, wenn der Empfänger eine saubere Fassung sehen soll.
  • Überschriften werden meist nur dann zu einer anklickbaren Gliederung, wenn sie die integrierten Überschrift-Formatvorlagen von Word nutzen; Text, der nur fett und groß ist, bleibt einfacher Text.
  • Links zu Websites bleiben normalerweise anklickbar. Felder wie ein Inhaltsverzeichnis oder Seitenverweise werden so umgewandelt, wie sie zuletzt aktualisiert wurden; drücken Sie in Word also F9 vor dem Speichern, wenn Sie das Dokument danach noch bearbeitet haben.
  • Das umgewandelte PDF ist nicht ausfüllbar. Inhaltssteuerelemente, Dropdowns und Kontrollkästchen werden zu festem Text. Brauchen Sie Felder, nutzen Sie „Formulare erstellen“ für das PDF.
  • Sehr lange Dokumente oder Dateien mit vielen großen Bildern brauchen länger. Das Tool wartet etwa drei Minuten auf den Server; ist der Auftrag bis dahin nicht fertig, meldet es eine Zeitüberschreitung.

Tipps für beste Ergebnisse

  • Verwenden Sie für Überschriften und Listen die integrierten Formatvorlagen von Word. Sie werden verlässlicher umgewandelt als manuelle Formatierung und liefern Ihnen eine navigierbare Gliederung.
  • Bleiben Sie bei verbreiteten Schriften (Calibri, Arial, Times New Roman, Cambria), wenn das Dokument auf einem anderen Rechner umgewandelt wird, oder betten Sie Ihre Schriften ein.
  • Komprimieren Sie große Bilder in Word (Bildformat > Bilder komprimieren) vor dem Umwandeln, wenn das PDF unter eine Upload-Grenze passen muss.
  • Prüfen Sie das Papierformat unter Layout > Format. Ein Dokument, das auf US Letter eingestellt ist, ergibt Letter-Seiten – auch wenn Sie in einem Land leben, in dem A4 üblich ist.
  • Behalten Sie die .docx. Ein PDF ist zum Lesen und Drucken da; spätere Änderungen sind im Original viel einfacher.

Praxisbeispiel: ein Angebot mit eigener Hausschrift

Eine freiberufliche Übersetzerin aus Dresden schreibt in Word ein dreiseitiges Angebot, mit einer gekauften Display-Schrift für die Überschriften und Calibri für den Fließtext. Hier umgewandelt, kommt das PDF vierseitig zurück: Der Server hat die Display-Schrift nicht, ersetzt sie durch eine breitere, und die Preistabelle rutscht auf eine eigene Seite.

Die Lösung dauert zwei Minuten. In Word öffnet sie Datei > Optionen > Speichern, setzt das Häkchen bei „Schriftarten in der Datei einbetten“ (und lässt „Allgemeine Systemschriftarten nicht einbetten“ aktiv, damit die Datei klein bleibt), speichert und wandelt erneut um. Diesmal haben die Überschriften die richtige Schrift, und das Dokument ist wieder dreiseitig, mit der Tabelle unter ihrer Überschrift. Hätte die Schriftlizenz das Einbetten verboten, wäre die Alternative eine weit verbreitete Schrift für die Überschriften gewesen.

Vor dem Versand nimmt sie alle Überarbeitungen an und löscht einen Randkommentar einer Kollegin mit dem Inhalt „Preis zu niedrig?“, der sonst für den Kunden sichtbar am Rand des PDFs gestanden hätte.

Fehlerbehebung

Das PDF hat mehr Seiten als das Word-Dokument
Eine Schrift wurde ersetzt, oder das Papierformat weicht ab. Betten Sie die Schriften im Dokument ein oder wechseln Sie zu einer verbreiteten Schrift, und prüfen Sie, ob Layout > Format Ihren Erwartungen entspricht.
Im PDF erscheinen Kommentare oder rote Überarbeitungen
Sie sind noch Teil des Dokuments. Wählen Sie in Word Überprüfen > Alle Änderungen annehmen, löschen Sie alle Kommentare, speichern Sie und wandeln Sie erneut um.
Das Tool meldet, die Konvertierung sei fehlgeschlagen
Die Datei ist vielleicht beschädigt, passwortgeschützt oder trotz Endung gar keine Word-Datei. Öffnen Sie sie in Word, entfernen Sie ein eventuelles Passwort, legen Sie mit „Speichern unter“ eine frische .docx an und versuchen Sie es mit dieser Kopie.
Zeitüberschreitung bei der Konvertierung
Das Dokument ist sehr groß, meist wegen hochaufgelöster Bilder. Komprimieren Sie die Bilder in Word oder teilen Sie das Dokument auf, wandeln Sie jeden Teil um und verbinden Sie sie mit „PDF zusammenführen“.
Das Inhaltsverzeichnis zeigt falsche Seitenzahlen
Das Feld wurde vor dem Speichern nicht aktualisiert. Klicken Sie in Word mit der rechten Maustaste auf das Inhaltsverzeichnis, wählen Sie Felder aktualisieren > Gesamtes Verzeichnis aktualisieren, speichern Sie und wandeln Sie erneut um.
Nach „Wird hochgeladen…“ passiert nichts
Meist liegt es an einer Netzwerkunterbrechung oder an einer Browser-Erweiterung, die den Upload blockiert. Laden Sie die Seite neu, deaktivieren Sie Inhaltsblocker für die Website und versuchen Sie es über eine stabile Verbindung erneut.

Häufig gestellte Fragen

Wird meine Word-Datei hochgeladen?

Ja. Diese Umwandlung braucht eine serverseitige Engine; die Datei wird verschlüsselt an den Konvertierungsdienst geschickt und nach der Verarbeitung gelöscht. Für Dokumente, die offline bleiben müssen, nutzen Sie „Als PDF speichern“ in Word.

Werden .doc und .docx unterstützt?

Ja, beide werden angenommen. Beim älteren .doc-Format treten eher kleine Layoutabweichungen auf, prüfen Sie das Ergebnis also genau.

Funktionieren Hyperlinks im PDF noch?

Weblinks bleiben normalerweise anklickbar. Interne Querverweise hängen davon ab, wie sie in Word angelegt wurden – testen Sie sie.

Kann ich mehrere Word-Dateien auf einmal umwandeln?

Nein, eine Datei pro Umwandlung. Wandeln Sie jedes Dokument einzeln um und fügen Sie die PDFs mit „PDF zusammenführen“ zusammen, wenn Sie eine einzige Datei brauchen.

Warum hat das PDF eine andere Schrift als mein Dokument?

Die Schrift war auf dem Konvertierungsserver nicht vorhanden und nicht in der DOCX eingebettet, daher wurde eine ähnliche verwendet. Betten Sie die Schriften in Word ein und wandeln Sie erneut um.

Kann ich das PDF wieder in eine bearbeitbare Word-Datei verwandeln?

„PDF in Word“ kann eine DOCX erzeugen, rekonstruiert dabei aber das Layout und trifft das Original selten genau. Ihre ursprüngliche .docx zu behalten, ist immer die bessere Lösung.

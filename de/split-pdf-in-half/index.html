In der Mitte teilen

Zerlegen Sie ein Dokument mit einem Klick in zwei gleich große Hälften.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Manche Aufgaben brauchen keine Optionen, sondern nur einen Knopf. Das Halbieren-Werkzeug von PDFora zerschneidet ein PDF mit einem einzigen Klick in zwei gleich große Teile. Aus einer 200-seitigen Datei werden die Seiten 1-100 und 101-200 – keine Bereiche zum Eintippen, keine Einstellungen zum Auswählen. Ist die Seitenzahl ungerade, kümmert sich das Werkzeug um die mittlere Seite, sodass auch ein 101-seitiges Dokument in sinnvolle Hälften zerfällt.

Wie bei jedem PDFora-Werkzeug führt Ihr Browser den Schnitt auf Ihrem Rechner aus. Das Dokument wird nie hochgeladen, ein Due-Diligence-Bündel oder ein Mitarbeiterhandbuch zu halbieren heißt also nicht, es einem Server anzuvertrauen. Diese lokale Verarbeitung macht die Sache außerdem schnell: Es fällt keine Übertragungszeit an, nur die ein bis zwei Sekunden, die Ihr Gerät zum Schreiben der beiden neuen Dateien braucht.

Es ist vollständig kostenlos: keine Registrierung, kein Wasserzeichen auf einer der beiden Hälften, keine Nutzungsgrenze. Teilen Sie heute eine Datei und morgen fünfzig – das Werkzeug behandelt Sie genauso.

So halbieren Sie ein PDF online

  1. Öffnen Sie das Werkzeug „PDF halbieren“ auf getpdfora.com – ein Konto ist nicht nötig.
  2. Fügen Sie Ihr PDF hinzu, indem Sie es per Klick auswählen oder hineinziehen.
  3. Vergewissern Sie sich, dass es das richtige Dokument ist; das Werkzeug zeigt die geladene Datei an.
  4. Klicken Sie auf die Schaltfläche zum Teilen. Das ist die gesamte Konfiguration.
  5. Ihr Browser trennt das Dokument an der Mitte in zwei PDFs.
  6. Laden Sie beide Hälften herunter und benennen Sie sie bei Bedarf um, etwa in Teil-1 und Teil-2.

When to use this tool

  • Einen Bericht unter die Anhangsgrenze eines E-Mail-Anbieters bringen, indem Sie ihn in zwei Hälften verschicken.
  • Einen gescannten Doppelband trennen, bei dem jedes Werk ungefähr die Hälfte der Datei einnimmt.
  • Ein langes Schulungshandbuch auf zwei Termine verteilen und den Teilnehmenden jeweils nur die Hälfte geben, die diese Woche dran ist.
  • Einen Korrekturauftrag in der Mitte teilen, damit zwei Lektorinnen parallel arbeiten können.
  • Einen großen Druckauftrag zweiteilen, damit sich die Warteschlange des Bürodruckers nicht an einem einzigen Riesenjob verschluckt.
  • Ein zu großes PDF halbieren, das ein Webportal oder Lernmanagementsystem am Stück nicht annimmt.

Tips for the best results

  • Sehen Sie sich vorher die Gesamtseitenzahl an, damit Sie wissen, wo der Schnitt landet – die Mitte einer 61-seitigen Datei kann mitten im Kapitel liegen.
  • Liegt die natürliche Trennstelle nicht in der Mitte, nehmen Sie das reguläre Teilen-Werkzeug mit eigenen Bereichen; dieses hier ist auf Tempo gebaut, nicht auf Präzision.
  • Halbieren ist eine schnelle Lösung für Größenbeschränkungen, aber wenn die Datei vor allem durch Scans aufgebläht ist, erspart Ihnen Komprimieren die Teilung womöglich ganz.
  • Benennen Sie die Downloads sofort um – zwei Dateien mit fast identischen Namen sind schnell verwechselt.
  • Sie können eine Hälfte erneut durch das Werkzeug schicken und ein Dokument so mit zwei Klicks vierteln.

Häufig gestellte Fragen

Was passiert, wenn mein PDF eine ungerade Seitenzahl hat?

Das Werkzeug teilt es trotzdem sauber – eine Hälfte bekommt schlicht die zusätzliche Seite. Aus einer 25-seitigen Datei werden beispielsweise ein 13-seitiger und ein 12-seitiger Teil.

Kann ich bestimmen, wo das PDF getrennt wird?

Mit diesem Werkzeug nicht – es schneidet immer genau in der Mitte, und genau das macht den einen Klick möglich. Soll die Trennung an einer bestimmten Seite liegen, akzeptiert das Haupt-Teilen-Werkzeug von PDFora eigene Bereiche wie 1-40, 41-90.

Behalten beide Hälften die ursprüngliche Qualität?

Ja. Die Seiten werden unverändert übernommen, Text, Bilder und Formatierung sind in beiden Hälften identisch mit dem Ausgangsdokument.

Wird die Datei beim Teilen irgendwohin hochgeladen?

Nein. Die Trennung geschieht lokal in Ihrem Browser, und weder das Original noch die beiden Hälften verlassen Ihr Gerät. Vertrauliche Dokumente sind hier so sicher wie auf Ihrem eigenen Schreibtisch.

Ist das wirklich kostenlos, ohne Haken?

Ist es. Keine Registrierung, keine Wasserzeichen, keine Seitenlimits und keine Grenze dafür, wie viele Dateien Sie halbieren. Das Werkzeug läuft mit der Rechenleistung Ihres Geräts, es gibt also keine Serverrechnung, die wir weiterreichen müssten.

Wie groß darf ein PDF sein, das ich halbieren möchte?

Wir setzen keine Obergrenze. Da Ihr Browser die Arbeit erledigt, begrenzt bei sehr großen Dateien allein der Arbeitsspeicher Ihres Geräts – ein tausendseitiges Dokument teilt sich auf den meisten modernen Rechnern problemlos, ältere Handys brauchen eventuell länger.

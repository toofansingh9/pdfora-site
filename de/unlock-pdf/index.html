Passwortgeschützte PDF-Dateien sind eine gute Sache — bis es die eigenen sind und die Passwortabfrage zum zwanzigsten Mal erscheint. Kontoauszüge, Gehaltsabrechnungen, Versicherungsunterlagen: Vieles kommt gesperrt an, und das Passwort bei jedem Öffnen einzutippen wird schnell lästig. Das Entsperren-Werkzeug von PDFora entfernt ein bekanntes Passwort aus einem PDF, das Ihnen gehört, und liefert Ihnen eine saubere Fassung, die sich wie jede normale Datei öffnet.

Ganz offen gesagt: Das Entsperren-Werkzeug ist auf PDFora derzeit als „demnächst verfügbar“ gekennzeichnet und noch in Arbeit. Diese Seite erklärt, wie es funktionieren wird, sobald es da ist — kostenlos, ohne Registrierung, ohne Wasserzeichen, ohne Limits. Und weil das Entsperren lokal im Browser stattfindet, bleiben das geschützte Dokument und das von Ihnen eingegebene Passwort von Anfang bis Ende auf Ihrem Gerät. Nichts wird hochgeladen.

Eines ist dieses Werkzeug ausdrücklich nicht: ein Passwortknacker. Sie müssen das aktuelle Passwort kennen, um es zu entfernen, und Sie sollten nur PDF-Dateien entsperren, die Ihnen gehören oder für die Sie eine eindeutige Erlaubnis haben. Den Schutz eines fremden Dokuments ohne Befugnis aufzuheben, kann rechtswidrig sein. Das Entsperren existiert für legitime Bequemlichkeit, nicht zum Umgehen von Sicherheitsmaßnahmen.

So entfernen Sie ein Passwort aus einem PDF online

  1. Öffnen Sie das Entsperren-Werkzeug auf getpdfora.com und wählen Sie Ihr passwortgeschütztes PDF aus. Es bleibt auf Ihrem Gerät — kein Upload.
  2. Geben Sie das aktuelle Passwort des Dokuments ein, wenn Sie dazu aufgefordert werden. Damit weisen Sie nach, dass Sie es öffnen dürfen.
  3. Bestätigen Sie, dass der Schutz entfernt werden soll.
  4. Das Werkzeug entschlüsselt die Datei lokal in Ihrem Browser und erzeugt eine entsperrte Kopie.
  5. Laden Sie das neue PDF herunter. Es öffnet sich in jedem Viewer sofort und ohne Passwortabfrage.
  6. Behalten oder löschen Sie die ursprüngliche gesperrte Fassung, je nachdem, ob Sie weiterhin eine geschützte Kopie brauchen.

When to use this tool

  • Das Passwort monatlicher Kontoauszüge entfernen, damit die Software Ihres Steuerberaters sie zur Steuerzeit einlesen kann.
  • Gehaltsabrechnungen entsperren, die Ihr Arbeitgeber mit Ihrem Geburtsdatum schützt, bevor Sie sie in Ihrem Unterlagenordner ablegen.
  • Das Passwort aus einer Versicherungspolice entfernen, damit sie sich schnell öffnet, wenn Sie sie wirklich dringend brauchen.
  • E-Tickets oder Buchungsbestätigungen entsperren, damit sie am Check-in-Schalter sofort aufgehen, ohne dass Sie erst das Passwort suchen müssen.
  • Gesperrte Berichte zum Zusammenführen oder Komprimieren vorbereiten — die meisten PDF-Werkzeuge können eine verschlüsselte Datei erst nach dem Entsperren verarbeiten.
  • Alte geschützte Archive, deren Passwörter Sie noch kennen, in gewöhnliche Dateien überführen, bevor Sie die Passwörter irgendwann vergessen.

Tips for the best results

  • Entsperren Sie Auszüge gleich bei Erhalt. In drei Jahren wissen Sie nicht mehr, welches Quartal welches Passwortformat verwendet hat.
  • Hat eine Bank die Datei gesperrt, steht das Passwort oft in der E-Mail — meist ein Geburtsdatum oder ein Teil der Kontonummer.
  • Bewahren Sie die Datei nach dem Entsperren an einem geschützten Ort auf; das Passwort war das Einzige, was sie bewacht hat.
  • Behalten Sie das gesperrte Original, falls das Dokument je wieder per E-Mail verschickt werden muss.
  • Erst entsperren, dann bearbeiten, zusammenführen oder komprimieren — die Entschlüsselung ist das Tor, hinter dem jeder andere Vorgang wartet.

Häufig gestellte Fragen

Ist das Entsperren-Werkzeug schon verfügbar?

Es ist als „demnächst verfügbar“ gekennzeichnet und wird gerade ausgerollt. Wenn Sie heute dringend ein PDF-Passwort entfernen müssen, funktioniert ein bewährter Weg am Desktop: Öffnen Sie die Datei mit dem Passwort in einem PDF-Reader und drucken bzw. exportieren Sie sie anschließend ohne Schutz in ein neues PDF.

Kann das Werkzeug ein PDF entsperren, dessen Passwort ich nicht kenne?

Nein, und das ist Absicht. Sie müssen das richtige Passwort eingeben, um es zu entfernen — das Werkzeug entschlüsselt Ihre Datei, es knackt sie nicht. Eine Wiederherstellung vergessener Passwörter leistet es nicht und behauptet es auch nicht.

Ist es legal, ein PDF-Passwort zu entfernen?

Das Passwort aus eigenen Dokumenten zu entfernen oder aus solchen, für deren Öffnen Sie befugt sind, ist in der Regel unproblematisch. Den Schutz von Dateien zu umgehen, an denen Sie keine Rechte haben, kann gegen Urheberrecht und Computerstrafrecht verstoßen. Entsperren Sie nur PDF-Dateien, bei denen Sie dazu berechtigt sind.

Werden meine Datei oder mein Passwort hochgeladen?

Nein. Die Entschlüsselung läuft vollständig in Ihrem Browser, sowohl das gesperrte PDF als auch das eingegebene Passwort bleiben also auf Ihrem Gerät. Bei Finanz- und Ausweisdokumenten ist das ein spürbarer Unterschied zu Entsperrdiensten, die auf Uploads setzen.

Verändert das Entsperren das Aussehen des PDFs?

Nein. Das Entfernen der Verschlüsselung rührt den Inhalt nicht an — Text, Bilder, Layout und Seitenreihenfolge kommen genau so heraus, wie sie waren. Die einzige Änderung: Die Passwortabfrage ist weg.

Und was ist mit PDF-Dateien, die sich zwar öffnen, aber Drucken oder Kopieren blockieren?

Dabei handelt es sich um einen Berechtigungsschutz und nicht um ein Öffnungspasswort. Solche Einschränkungen legt die Erstellerin des Dokuments fest, und Sie sollten sie respektieren, sofern das Dokument nicht Ihnen gehört oder der Urheber die Aufhebung erlaubt hat.

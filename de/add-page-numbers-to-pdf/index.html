Seitenzahlen

Seitenzahlen in jeder beliebigen Ecke einfügen, in mehreren Formaten.

Herunterladen

Fügen Sie Seitenzahlen in Sekunden in PDF-Dokumente ein, direkt in Ihrem Browser. Ein zusammengeführter Bericht, eine eingescannte Abschlussarbeit, ein aus drei Quellen zusammengesetzter Vertrag – solche Dokumente kommen oft ganz ohne Nummerierung daher, und achtzig lose Blätter ohne Seitenzahlen zu drucken heißt, Ärger geradezu einzuladen. PDFora stempelt saubere, durchgängige Zahlen auf jede Seite, während die Datei auf Ihrem Gerät bleibt. Es wird nichts hochgeladen, denn das gesamte Werkzeug arbeitet mit lokaler Verarbeitung.

Sie bestimmen, wo die Zahlen sitzen und wie sie sich lesen. Zur Auswahl stehen unten mittig, unten rechts, unten links, oben mittig und oben rechts, sodass die Nummerierung Kopfzeilen, Fußzeilen oder dem Bundsteg aus dem Weg gehen kann. Als Formate gibt es die schlichte „1“, das ausführlichere „1 von N“ oder „Seite 1“ für eine förmlichere Wirkung. Ist Ihr Dokument ein Kapitel, das mitten im Buch beginnt, legen Sie einfach eine eigene Startzahl fest, ab der weitergezählt wird.

Wie jedes Werkzeug von PDFora ist auch dieses kostenlos: keine Registrierung, keine Wasserzeichen im Ergebnis, keine Begrenzung der Dateizahl. Gerichtsunterlagen, Dissertationen, Vorstandsmappen – die Nummerierung, die Sie erhalten, ist genau die Nummerierung, die Sie behalten, ganz ohne fremdes Logo in der Ecke.

So fügen Sie online Seitenzahlen in eine PDF-Datei ein

  1. Rufen Sie auf getpdfora.com das Werkzeug für Seitenzahlen auf und legen Sie Ihre PDF-Datei darin ab.
  2. Wählen Sie eine Position: unten mittig, unten rechts, unten links, oben mittig oder oben rechts.
  3. Wählen Sie ein Format – eine reine Zahl wie „1“, das gesamtseitenbewusste „1 von N“ oder das beschriftete „Seite 1“.
  4. Legen Sie die Startzahl fest. Belassen Sie sie bei 1 oder beginnen Sie bei 47, wenn diese Datei einen früheren Abschnitt fortsetzt.
  5. Wenden Sie die Nummerierung an und lassen Sie Ihren Browser die Datei lokal verarbeiten – kein Upload, kein Warten in einer Serverwarteschlange.
  6. Laden Sie die nummerierte PDF-Datei herunter und prüfen Sie die erste und die letzte Seite, bevor Sie drucken oder verschicken.

When to use this tool

  • Eine Abschlussarbeit oder Dissertation vor der Abgabe nummerieren, wenn die Hochschule eine fortlaufende Nummerierung jeder Seite verlangt.
  • Anlagen oder Gerichtsakten vorbereiten, bei denen Verweise im Stil „Seite 12 von 240“ dafür sorgen, dass alle buchstäblich auf derselben Seite sind.
  • Eine aus mehreren Berichten zusammengefügte PDF-Datei in Ordnung bringen, damit sich die kombinierte Datei als ein durchgehendes Dokument liest.
  • Eingescannte Archivbestände – alte Protokolle, Kassenbücher, Korrespondenz – nachträglich nummerieren, weil sie nie Seitenzahlen hatten.
  • Schulungshandbücher und Mitarbeiterhandbücher nummerieren, damit Beschäftigte „Seite 34“ zitieren können, statt eine Stelle ungefähr zu umschreiben.
  • Die Nummerierung über geteilte Bände hinweg fortsetzen, indem die zweite Datei bei der Zahl beginnt, bei der die erste endete.

Tips for the best results

  • Nutzen Sie „1 von N“ für alles, was gedruckt und herumgereicht wird – ein fehlendes Blatt fällt sofort auf, wenn die letzte Seite „80 von 80“ trägt.
  • Haben die Seiten bereits eine Fußzeile, setzen Sie die Zahlen oben mittig oder oben rechts, damit sich nichts überlappt.
  • Wählen Sie für Dokumente, die gelocht und gebunden werden, unten links oder unten rechts statt mittig, damit die Zahlen vom Bund wegrücken.
  • Wenn Sie ein aus einem längeren Werk herausgelöstes Kapitel nummerieren, setzen Sie die Startzahl passend zur ursprünglichen Paginierung, damit Zitate weiterhin stimmen.
  • Nummerieren Sie erst die endgültige Fassung, also nach dem Zusammenführen und Löschen von Seiten – neu nummerieren ist zwar leicht, aber veraltete Zahlen auf einer umsortierten Datei stiften Verwirrung.

Häufig gestellte Fragen

Wird meine Datei auf einen Server hochgeladen?

Nein. Das Werkzeug arbeitet mit lokaler Verarbeitung vollständig in Ihrem Browser. Ihre PDF-Datei bleibt von Anfang bis Ende auf Ihrem Computer, was sie für vertrauliche Verträge und unveröffentlichte Arbeiten geeignet macht.

Kann ich die Nummerierung bei einer anderen Zahl als 1 beginnen?

Ja. Geben Sie eine beliebige Startzahl ein, und die Zählung beginnt dort. Das ist praktisch für Kapitel, Anhänge oder die zweite Hälfte eines zuvor geteilten Dokuments.

Welche Nummerierungsformate stehen zur Verfügung?

Drei: eine schlichte Zahl wie „1“, das Format „1 von N“, das die Gesamtseitenzahl einschließt, und „Seite 1“. Wählen Sie, was zum Stil Ihres Dokuments passt.

An welchen Stellen der Seite können die Zahlen erscheinen?

Fünf Positionen werden unterstützt: unten mittig, unten rechts, unten links, oben mittig und oben rechts. Wählen Sie eine, die vorhandenen Kopf- oder Fußzeilen ausweicht.

Ist das Werkzeug wirklich kostenlos, und markiert es meine Datei?

Es ist kostenlos, ohne Registrierung und ohne Nutzungsgrenze, und PDFora fügt Ihrem Dokument nichts Eigenes hinzu – kein Wasserzeichen, kein Branding. Das Ergebnis enthält Ihre Seiten plus Ihre Zahlen, sonst nichts.

Kann ich sehr große PDF-Dateien nummerieren?

Ja. Das Werkzeug gibt keine Seitenbegrenzung vor. Da alles lokal läuft, wird eine Datei mit mehreren hundert Seiten so schnell verarbeitet, wie Ihr eigenes Gerät es zulässt – ganz ohne Uploadzeit.

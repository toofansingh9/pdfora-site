Formulare erstellen

Interaktive Textfelder und Kontrollkästchen an beliebiger Stelle in Ihrer PDF-Datei platzieren.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Die meisten Formulare beginnen als statisches Dokument: ein Word-Export, ein Scan, eine hübsch gestaltete PDF-Datei, die andere Menschen irgendwie ausfüllen sollen. Also wird gedruckt, per Hand ausgefüllt und wieder eingescannt – oder umständlich in einem Editor überschrieben. Mit diesem Werkzeug endet dieser Kreislauf. Sie erstellen aus Ihrem bestehenden Dokument ein ausfüllbares PDF-Formular, indem Sie echte interaktive Textfelder und Kontrollkästchen an genau den Stellen platzieren, an die sie gehören.

Der Ablauf ist erfreulich direkt. Ihre PDF-Datei erscheint auf dem Bildschirm, Sie klicken dorthin, wo eine Antwort stehen soll, und dort entsteht ein Feld. Ziehen Sie Felder, um sie exakt auszurichten, ändern Sie ihre Größe passend zur darunterliegenden Linie, setzen Sie Kontrollkästchen neben die Ja-Nein-Optionen. Beim Export erhalten Sie ein echtes AcroForm-PDF – das interaktive Standardformat, das Adobe Acrobat, Browser und mobile Reader gleichermaßen ausfüllen können.

Das Dokument, das Sie umwandeln, verlässt Ihren Computer nie, denn alles läuft lokal in Ihrem Browser. Es gibt keine Registrierung, kein Wasserzeichen auf Ihrem Formular, keine Gebühr und keine Begrenzung, wie viele Formulare Sie erstellen.

So erstellen Sie online ein ausfüllbares PDF-Formular

  1. Öffnen Sie die PDF-Datei, die ausfüllbar werden soll – einen Antrag, einen Vertrag oder einen Fragebogen. Sie wird lokal in Ihrem Browser geladen.
  2. Klicken Sie auf der Seite überall dort, wo eine getippte Antwort hingehört. An dieser Stelle entsteht ein Textfeld.
  3. Ergänzen Sie Kontrollkästchen neben Ja-Nein-Punkten oder Auswahlmöglichkeiten, indem Sie an die passende Stelle klicken.
  4. Ziehen Sie jedes Feld genau auf die gedruckte Linie und passen Sie die Größe an, damit auch längere Antworten Platz finden.
  5. Wiederholen Sie das auf allen Seiten, bis zu jeder Frage ein Feld gehört.
  6. Exportieren Sie die Datei – Sie erhalten ein echtes ausfüllbares AcroForm-PDF, das Empfänger in jedem gängigen PDF-Reader ausfüllen können.

Wann Sie dieses Tool nutzen sollten

  • Eine Mietbewerbung, die Interessenten bisher ausdrucken und einscannen mussten, in ein Formular verwandeln, das sie am Handy ausfüllen.
  • Ein Vereins- oder Veranstaltungsanmeldeblatt ausfüllbar machen, damit Rückmeldungen getippt statt handschriftlich zurückkommen.
  • Einen Anamnesebogen in ein interaktives Formular umwandeln, das die Praxis schon vor dem Termin per E-Mail verschickt.
  • Eine Vertragsvorlage für Freiberufler mit Feldern versehen, sodass Name, Zeitraum und Honorar jedes neuen Kunden sauber eingetragen werden.
  • Eine alte, eingescannte Einverständniserklärung als ausfüllbares PDF neu aufbauen, das Eltern per E-Mail zurücksenden.
  • Einer internen Spesenabrechnung oder einem Urlaubsantrag richtige Felder und Kontrollkästchen geben, statt darauf zu hoffen, dass alle die Datei sauber bearbeiten.

Tipps für beste Ergebnisse

  • Legen Sie Textfelder großzügig an – eine E-Mail-Adresse braucht mehr Breite, als man denkt, und zu enge Felder frustrieren die Ausfüllenden.
  • Richten Sie die Felder an den gedruckten Linien und Beschriftungen aus: Das darunterliegende Dokument liefert die Bezeichnungen, Ihre Felder liefern die Eingabe.
  • Nutzen Sie Kontrollkästchen für alles mit festen Auswahlmöglichkeiten, statt zu erwarten, dass jemand ein X in ein Textfeld tippt.
  • Füllen Sie das exportierte Formular einmal selbst aus, bevor Sie es verschicken – ein zweiminütiger Test entlarvt verrutschte oder fehlende Felder.
  • Bewahren Sie die exportierte ausfüllbare Fassung als Ihre Hauptvorlage auf und überlegen Sie, ausgefüllte Rückläufer später zu reduzieren, damit die Antworten nicht mehr verändert werden können.

Häufig gestellte Fragen

Was ist ein AcroForm?

AcroForm ist das Standardformat für interaktive PDF-Formulare und wird praktisch von jedem PDF-Reader unterstützt – Acrobat, Browser-Ansichten, Vorschau, mobile Apps. Dieses Werkzeug exportiert echte AcroForm-Felder und nicht eine nachgebaute Überlagerung, Ihr Formular ist also überall ausfüllbar und speicherbar.

Brauche ich eine bestehende PDF-Datei als Ausgangspunkt?

Ja – dieses Werkzeug ergänzt Felder auf einem Dokument, das Sie bereits haben, etwa einem gestalteten Formular, einem Vertrag oder einem Scan. Entwerfen Sie das Layout in einer beliebigen Anwendung, exportieren Sie es als PDF und setzen Sie die Felder anschließend hier.

Kann ich ein Feld nachträglich anpassen?

Ja. Jedes Feld lässt sich verschieben und an den Kanten in der Größe ändern, bis es exakt über der Linie oder dem Kästchen sitzt, zu dem es gehört. Ein verrutschtes Feld ist eine Sache von zwei Sekunden, kein Grund für einen Neuanfang.

Welche Feldtypen kann ich einfügen?

Textfelder für getippte Antworten und Kontrollkästchen für Auswahlmöglichkeiten – die beiden Bausteine, mit denen sich die meisten realen Formulare abdecken lassen: Anträge, Aufnahmebögen, Verträge, Anmeldungen und Freigaben.

Können Empfänger ihre eingetragenen Antworten speichern?

Ja. Da der Export ein standardkonformes ausfüllbares PDF-Formular ist, öffnen Empfänger es in jedem modernen Reader, tippen ihre Antworten, setzen die Häkchen und speichern oder senden die Datei mitsamt den Daten zurück.

Bleibt das hochgeladene Dokument privat?

Es gibt gar keinen Upload – die PDF-Datei wird vollständig in Ihrem Browser verarbeitet und berührt nie einen Server. Zusammen mit dem Verzicht auf Registrierung, Wasserzeichen und Nutzungsgrenzen können Sie kostenlos so viele ausfüllbare Formulare bauen, wie Sie brauchen.

Lesezeichen erstellen

Fügen Sie anklickbare Lesezeichen (ein Inhaltsverzeichnis) hinzu, damit Leser direkt zum gewünschten Abschnitt springen können.

Sich durch ein 90-seitiges PDF zu scrollen, nur um einen einzigen Abschnitt zu finden, wird schnell mühsam. Genau dafür gibt es Lesezeichen: ein anklickbares Inhaltsverzeichnis in der Seitenleiste des Readers, das direkt zu jedem Kapitel oder jeder Überschrift springt. Sorgfältig erstellte PDF-Dateien bringen so etwas mit, die meisten exportierten oder eingescannten Dokumente jedoch nicht. Mit diesem Werkzeug versehen Sie jedes beliebige PDF nachträglich mit Lesezeichen und geben ihm damit eine richtige, navigierbare Gliederung.

Das Format ist denkbar einfach. Sie schreiben eine Zeile pro Lesezeichen: die Seitenzahl, ein Komma, dann den Titel — in der ersten Zeile also „1, Deckblatt“, in der nächsten „3, Kapitel 1“, weiter unten „12, Anhang A“. Das Werkzeug erstellt aus Ihrer Liste die Gliederung und schreibt sie in das PDF. Leser sehen die Struktur anschließend in ihrer Seitenleiste und springen mit einem Klick an jede beliebige Stelle.

Wie bei jedem Werkzeug von PDFora wird die Datei lokal in Ihrem Browser verarbeitet und niemals hochgeladen — interne Handbücher und Mandantenberichte bleiben also vertraulich. Der Dienst ist kostenlos, erfordert kein Konto, setzt kein Wasserzeichen und funktioniert mit Dokumenten jeder Länge.

So fügen Sie einem PDF online Lesezeichen hinzu

  1. Öffnen Sie Ihr PDF im Werkzeug — es wird im Browser geladen und an keinen Server geschickt.
  2. Überfliegen Sie das Dokument und notieren Sie, auf welcher Seite jeder Abschnitt beginnt.
  3. Tippen Sie im Lesezeichenfeld pro Zeile einen Eintrag im Format „Seite, Titel“ — zum Beispiel „1, Deckblatt“ und darunter „3, Kapitel 1“.
  4. Ergänzen Sie eine Zeile für jeden Abschnitt, der in der Gliederung auftauchen soll: Kapitel, Anhänge, wichtige Anlagen.
  5. Klicken Sie auf Übernehmen — das Werkzeug schreibt die anklickbare Gliederung in das PDF.
  6. Laden Sie die Datei herunter und öffnen Sie die Lesezeichenleiste in Ihrem Reader, um jeden Sprung kurz zu testen.

When to use this tool

  • Einem selbst veröffentlichten E-Book eine Kapitelgliederung geben, damit Leser darin navigieren können wie in einem professionell produzierten Buch.
  • Ein 120-seitiges Mitarbeiterhandbuch mit einem Inhaltsverzeichnis in der Seitenleiste versehen — Richtlinien, Urlaub, Zusatzleistungen, Verhaltenskodex —, damit niemand mehr nachfragen muss, wo etwas steht.
  • Jede Anlage einer zusammengeführten Gerichtsakte mit einem Lesezeichen versehen, damit die Geschäftsstelle direkt zu Anlage C springen kann.
  • Vorlesungsmitschriften nach Wochen strukturieren, bevor Sie sie mit dem Kurs teilen — so gelangen Studierende sofort zu dem Thema, das sie verpasst haben.
  • Ein eingescanntes Gerätehandbuch nachträglich mit Abschnittslesezeichen versehen, nachdem die ursprüngliche Navigation beim Scannen verloren ging.
  • Einen umfangreichen Finanzbericht nach Quartalen und Abschlussarten gliedern, bevor er im Aufsichtsrat zirkuliert.

Tips for the best results

  • Verwenden Sie die Seitenzahlen der PDF-Datei selbst, nicht die auf den Seiten gedruckten Nummern — ein Vorwort verschiebt beides schnell gegeneinander.
  • Halten Sie Titel kurz und überfliegbar: „Kapitel 4: Preise“ funktioniert in einer schmalen Seitenleiste besser als ein ganzer Satz.
  • Listen Sie die Einträge in Seitenreihenfolge auf, damit sich die Gliederung von oben nach unten wie ein echtes Inhaltsverzeichnis liest.
  • Setzen Sie auch auf das Deckblatt und eine eventuelle Inhaltsseite ein Lesezeichen — Leser erwarten einen Weg zurück zum Anfang.
  • Bei sehr langen Dokumenten sollten Sie jede größere Überschrift verlinken, nicht nur die Kapitel: Eine 200-Seiten-Datei verdient 20 Einträge, nicht 5.

Häufig gestellte Fragen

Was genau sind PDF-Lesezeichen?

Lesezeichen — oft auch Gliederung genannt — sind die anklickbare Navigationsleiste, die die meisten PDF-Reader seitlich einblenden. Jeder Eintrag ist ein Titel, der mit einer Seite verknüpft ist; ein Klick auf „Kapitel 3“ springt also direkt dorthin. Sie stecken in der Datei selbst, sodass jeder Empfänger dieselbe Navigation erhält.

Wie muss ich die Lesezeichenliste formatieren?

Ein Lesezeichen pro Zeile, geschrieben als Seitenzahl, Komma, Titel. Zum Beispiel: „1, Deckblatt“ in der ersten Zeile, „3, Kapitel 1“ in der zweiten, „15, Kapitel 2“ in der dritten. Mehr Syntax gibt es nicht.

Ist das dasselbe wie eine gedruckte Inhaltsverzeichnisseite?

Der Zweck ist derselbe, aber die Gliederung lebt in der Seitenleiste des Readers statt auf einer gedruckten Seite — und jeder Eintrag ist anklickbar. Viele Nutzer fügen Lesezeichen gerade deshalb hinzu, weil ihr PDF zwar ein gedrucktes Inhaltsverzeichnis hat, dieses sich aber nicht anklicken lässt.

Verändern die Lesezeichen die Seiten meines PDFs?

Nein. Seiten, Text und Layout bleiben unangetastet. Lesezeichen liegen in einer separaten Navigationsstruktur innerhalb der Datei, das Dokument wird also genauso gedruckt und angezeigt wie zuvor — es lässt sich nur deutlich leichter durchsuchen.

Funktionieren die Lesezeichen in jedem PDF-Reader?

Ja. Das Werkzeug schreibt eine standardkonforme PDF-Gliederung, die Adobe Acrobat, Browser-Viewer, die Vorschau auf dem Mac und mobile PDF-Apps gleichermaßen verstehen. Je nach Programm heißt die Leiste Lesezeichen, Gliederung oder Inhalt.

Bleibt mein Dokument vertraulich?

Ja. Das PDF wird vollständig in Ihrem Browser verarbeitet und niemals hochgeladen — vertrauliche Berichte und Handbücher bleiben auf Ihrem Rechner. Zudem ist das Werkzeug kostenlos, ohne Registrierung und ohne Wasserzeichen.

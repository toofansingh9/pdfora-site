PowerPoint in PDF

Wandeln Sie eine PPT- oder PPTX-Präsentation auf einem Konvertierungsserver in ein PDF um – eine Folie pro Seite, bereit zum Teilen oder Drucken.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Eine Präsentation ist zum Vortragen gemacht. Sobald sie per E-Mail verschickt, auf eine Lernplattform hochgeladen oder als Handout gedruckt werden soll, ist ein PDF für alle bequemer: Es öffnet sich auf jedem Handy, niemand braucht PowerPoint, und die Folien verrutschen nicht wegen einer anderen Bildschirmgröße oder einer fehlenden Schrift. Außerdem verhindert es, dass jemand vor dem Weiterleiten still Ihre Zahlen ändert.

Dieses Tool wandelt eine .ppt- oder .pptx-Datei um. Die Präsentation wird über eine verschlüsselte Verbindung und das Relay von PDFora an den Dienst CloudConvert hochgeladen, dort von einer Präsentations-Engine gerendert, und das PDF kommt mit demselben Namen wie das Original zu Ihnen zurück. Ihr Browser übernimmt die Umwandlung nicht, und die Datei wird beim Dienst gelöscht, sobald der Auftrag fertig ist.

Sie erhalten ein statisches Dokument: Jede Folie wird zu einer Seite im Seitenverhältnis der Folie, meist 16:9. Alles, was nur beim Vortragen passiert – Animationen, Übergänge, eingebettete Videos oder Audio und Einblendungen per Klick –, kann es auf einer Seite nicht geben. Der Großteil dieser Seite dreht sich darum, was Sie vor der Umwandlung mit diesen Teilen tun, damit das PDF auch für jemanden verständlich ist, der Ihren Vortrag nie gesehen hat.

So wandeln Sie PowerPoint in PDF um

  1. Speichern und schließen Sie die Präsentation. Löschen oder verbergen Sie Folien, die nicht ins PDF sollen.
  2. Öffnen Sie PowerPoint in PDF und wählen Sie die .pptx- oder .ppt-Datei aus.
  3. Klicken Sie auf „Konvertieren“ und warten Sie, während hochgeladen und umgewandelt wird. Präsentationen mit vielen großen Fotos dauern länger.
  4. Laden Sie das PDF herunter; es behält den Dateinamen der Präsentation.
  5. Scrollen Sie durch jede Seite: Prüfen Sie Folien, die auf Animationen angewiesen waren, und achten Sie auf Text, der über sein Feld hinausläuft oder die Schrift gewechselt hat.

Wann Sie dieses Tool nutzen sollten

  • Vorlesungs- oder Unterrichtsfolien, die auf eine Lernplattform wie Moodle gestellt werden, damit Schüler und Studierende sie lesen und kommentieren können.
  • Vertriebs- und Investorenpräsentationen, die nach einem Termin per E-Mail rausgehen, damit der Empfänger genau das sieht, was gezeigt wurde.
  • Konferenzvorträge für Veranstalter, die die Folien der Referierenden als PDF veröffentlichen.
  • Schulungsunterlagen, die für die Teilnehmenden eines Workshops gedruckt werden.
  • Eine Präsentation an jemanden schicken, der nur ein Handy oder ein Chromebook hat.
  • Eine Präsentation so festhalten, wie sie an einem bestimmten Datum gehalten wurde.

Das sollten Sie vorher wissen

  • Animationen werden flachgeklopft. Eine Folie, auf der Aufzählungspunkte nacheinander erscheinen, zeigt im PDF alle auf einmal. Objekte, die übereinandergestapelt sind, um nacheinander aufzutauchen, überlappen sich auf der Seite.
  • Video und Audio lassen sich im PDF nicht abspielen. Meist bleibt nur das Vorschaubild eines Videos übrig. Setzen Sie einen Link zur Online-Fassung auf die Folie, wenn der Empfänger sie braucht.
  • Sprechernotizen sind nicht enthalten; der Konverter erzeugt Folienseiten. Sind die Notizen wichtig, übernehmen Sie sie in die Folien oder exportieren Sie eine Notizenfassung direkt aus PowerPoint.
  • Ausgeblendete Folien fehlen in der Regel im PDF – praktisch, um Reservefolien privat zu halten. Prüfen Sie aber, ob die Seitenzahl Ihren Erwartungen entspricht.
  • Schriften, die der Server nicht hat, werden ersetzt. Eine Präsentation mit einer speziellen Hausschrift kann daher andere Zeilenumbrüche oder über die Felder laufenden Text zeigen. Betten Sie die Schriften ein (Datei > Optionen > Speichern > Schriftarten in der Datei einbetten) oder verwenden Sie gängige Schriften.
  • Links auf Websites bleiben in der Regel anklickbar. Interaktive Schaltflächen, die zwischen Folien springen, hängen davon ab, wie sie angelegt wurden – testen Sie sie.

Tipps für beste Ergebnisse

  • Für eine Lesefassung ergänzen Sie ein, zwei Folien mit dem Kontext, den Sie sonst mündlich liefern würden – ein PDF hat keinen Vortragenden.
  • Duplizieren Sie Folien mit schrittweisem Aufbau in mehrere Folien, eine pro Stufe, wenn die Abfolge fürs Verständnis wichtig ist.
  • Komprimieren Sie die Bilder in PowerPoint (Bildformat > Bilder komprimieren) vor der Umwandlung, wenn das PDF unter einem E-Mail-Limit bleiben muss.
  • Nehmen Sie ein kontrastreiches Design, wenn das PDF schwarzweiß gedruckt wird; dunkle Folien verbrauchen viel Toner und verlieren Details.
  • Brauchen Sie mehrere Folien pro gedruckter Seite, wandeln Sie zuerst um und setzen Sie dann mit N-up zwei oder vier Folien auf jedes Blatt.

Praxisbeispiel: eine Biologiestunde für fehlende Schüler

Eine Biologielehrerin an einem Gymnasium möchte eine Stunde mit 28 Folien zur Fotosynthese für Schülerinnen und Schüler hochladen, die gefehlt haben. Im Unterricht bauen sich mehrere Folien Schritt für Schritt auf: ein Blattdiagramm, dessen Beschriftungen einzeln hereinfliegen, und eine Folie, auf der erst eine falsche Antwort erscheint und dann von der richtigen überdeckt wird. Außerdem gibt es einen zweiminütigen Videoclip und ihre Notizen dazu, was sie jeweils sagt.

Unverändert umgewandelt zeigt das PDF das Blattdiagramm mit allen Beschriftungen gleichzeitig – das ist in Ordnung –, auf der Antwortfolie liegen aber beide Antworten übereinander, und vom Video bleibt nur ein Standbild. Also dupliziert sie die Antwortfolie und löscht in der Kopie die falsche Antwort, setzt die Webadresse des Videos als Text unter das Standbild und überträgt die zwei wichtigsten Punkte aus ihren Notizen in ein Textfeld auf den passenden Folien.

Die zweite Umwandlung ergibt ein 29-seitiges PDF, dem man auch allein am Handy folgen kann. Da das PDF das 16:9-Format behält, liest es sich am Bildschirm gut; für die wenigen, die lieber Papier möchten, druckt sie es mit N-up zwei Folien pro Seite.

Eine weitere Kontrolle deckte ein Problem auf, mit dem sie nicht gerechnet hatte. Eine Grafik des Chloroplasten bestand aus einem Dutzend gruppierter Formen, und eine Beschriftung war in einer verspielten Handschrift-Schrift gesetzt, die sie heruntergeladen hatte. Auf der umgewandelten Seite war diese Beschriftung durch eine schlichte Schrift ersetzt und ragte jetzt über ihren Pfeil hinaus. Statt eine Schrift einzubetten, bei der sie nicht sicher war, ob sie sie weitergeben darf, stellte sie die Beschriftung auf dieselbe Schrift wie den Rest der Präsentation um und wandelte noch einmal um. Jede Seite mit der Originalfolie zu vergleichen, kostet ein paar Minuten – und ist der einzige verlässliche Weg, solche kleinen Ersetzungen zu entdecken, bevor dreißig Schülerinnen und Schüler sie sehen.

Fehlerbehebung

Text auf manchen Folien überlappt oder läuft aus seinem Feld
Eine Schrift wurde durch eine breitere ersetzt. Betten Sie die Schriften in die Präsentation ein oder wechseln Sie zu einer gängigen Schrift und wandeln Sie erneut um.
Mehrere Objekte liegen übereinander
Diese Objekte wurden per Animation nacheinander eingeblendet. Teilen Sie die Folie in mehrere Folien auf, eine pro Stufe, oder entfernen Sie die Objekte, die verschwinden sollten.
Mein Video fehlt
Medien lassen sich in einem PDF nicht abspielen. Setzen Sie einen Link zum Video auf die Folie oder teilen Sie das Video separat.
Im PDF fehlen einige Folien
Vermutlich sind es ausgeblendete Folien. Blenden Sie sie in PowerPoint wieder ein (Rechtsklick auf die Miniatur > Folie ausblenden), wenn sie enthalten sein sollen.
Konvertierung fehlgeschlagen oder Zeitüberschreitung
Sehr große Präsentationen mit vielen hochauflösenden Bildern können langsam sein, beschädigte oder passwortgeschützte Dateien scheitern. Komprimieren Sie die Bilder, entfernen Sie das Passwort, speichern Sie eine frische .pptx-Kopie und versuchen Sie es erneut.
Die PDF-Datei ist riesig
Fotos werden in voller Auflösung übernommen. Komprimieren Sie die Bilder vor der Umwandlung in PowerPoint oder schicken Sie das PDF durch PDF komprimieren.

Häufig gestellte Fragen

Wird meine Präsentation hochgeladen?

Ja, die Datei wird verschlüsselt an den Konvertierungsdienst übertragen und nach der Verarbeitung gelöscht. Für Präsentationen, die Ihren Rechner nicht verlassen dürfen, nutzen Sie den Export von PowerPoint selbst.

Sind Sprechernotizen enthalten?

Nein. Jede Folie wird ohne ihre Notizen zu einer Seite. Übertragen Sie wichtige Notizen vor der Umwandlung auf die Folien.

Funktionieren Animationen und Übergänge im PDF?

Nein. Eine PDF-Seite ist statisch, jedes animierte Element erscheint daher in seiner Endposition.

Behält das PDF meine Foliengröße?

Ja. Die Seiten übernehmen die Foliengröße der Präsentation: Aus 16:9 werden breite Seiten, aus 4:3 eher quadratische.

Kann ich Dateien aus Google Präsentationen oder Keynote umwandeln?

Laden Sie eine Google-Präsentation als .pptx herunter oder exportieren Sie eine Keynote-Präsentation ins PowerPoint-Format und wandeln Sie dann diese Datei um.

Kann ich mehrere Folien auf eine Seite setzen?

Nicht bei der Umwandlung. Wandeln Sie zuerst um und setzen Sie dann mit dem Tool N-up zwei oder vier Folien auf jede Seite.

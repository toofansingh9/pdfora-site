PDF teilen

Teilen Sie ein PDF nach Seitenbereichen, nach je N Seiten oder in eine Datei pro Seite.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Ein 90-seitiges PDF ist als 90-seitiges PDF selten zu gebrauchen. Meist brauchen Sie Kapitel zwei für eine Kollegin, die Seiten 40 bis 55 für einen Kunden oder jede Seite als eigene Datei fürs Archiv. Das Teilen-Werkzeug von PDFora zerlegt ein PDF in mehrere und bietet Ihnen dafür drei Wege an: jede Seite als eigenes PDF, selbst eingetippte Seitenbereiche oder automatische Blöcke von je N Seiten.

Alles läuft in Ihrem Browser ab. Die Datei, die Sie teilen, wird lokal auf Ihrem Rechner geöffnet und verarbeitet – sie wird nie an einen Server geschickt, in einem Cloud-Speicher abgelegt oder durch irgendeine Warteschlange geschleust. Bei juristischen Aktenbündeln, Personalunterlagen oder allem anderen, was Sie nicht auf einen fremden Rechner laden möchten, wiegt dieser Unterschied schwerer als jede andere Funktion.

Das Werkzeug ist kostenlos, verlangt keine Registrierung und setzt keine Wasserzeichen. Wenn beim Teilen mehrere Dateien entstehen, kommen sie gebündelt in einem einzigen ZIP, sodass Sie einen ordentlichen Download statt eines Dutzends erhalten. Nutzen Sie es einmal oder hundertmal – es läuft kein Zähler mit.

So teilen Sie ein PDF online

  1. Rufen Sie das Werkzeug „PDF teilen“ auf getpdfora.com auf und wählen Sie Ihr PDF aus oder ziehen Sie es hinein.
  2. Wählen Sie einen Modus: jede Seite als eigenes PDF, eigene Seitenbereiche oder je N Seiten.
  3. Für eigene Bereiche tippen Sie sie so, wie Sie sie aussprechen würden – 1-3, 4-6 erzeugt zum Beispiel zwei Dateien.
  4. Für feste Blöcke geben Sie die Seitenzahl pro Datei an, etwa 10, und das Werkzeug teilt das Dokument automatisch auf.
  5. Klicken Sie auf „Teilen“. Ihr Browser zerschneidet das PDF binnen Augenblicken lokal.
  6. Laden Sie die ZIP-Datei mit allen entstandenen PDFs herunter und entpacken Sie sie, wo Sie möchten.

When to use this tool

  • Einen gescannten Stapel unterschriebener Formulare vor der Ablage in ein PDF pro Formular zerlegen.
  • Ein Lehrbuch oder Skript nach Kapiteln teilen, damit Studierende nur herunterladen, was sie brauchen.
  • Eine umfangreiche Sitzungsunterlage aufteilen, sodass jede Abteilung nur ihren eigenen Abschnitt erhält.
  • Einen Kontoauszugsexport in Monatsdateien schneiden, weil die Buchhaltungssoftware jeweils einen Auszug erwartet.
  • Einen Konferenzband in einzelne Beiträge trennen, um sie zu zitieren und weiterzugeben.
  • Einen großen Bericht in Zehn-Seiten-Blöcke zerlegen, um an einer Größenbeschränkung für E-Mail-Anhänge vorbeizukommen.

Tips for the best results

  • Überfliegen Sie das PDF und notieren Sie die Seitenzahlen, an denen die Abschnitte beginnen, bevor Sie Ihre Bereiche eintippen – das spart einen zweiten Durchlauf.
  • Bereiche dürfen ungleich lang sein: 1-3, 4-6, 7-20 ist völlig in Ordnung, wenn Ihre Abschnitte unterschiedlich umfangreich sind.
  • Wählen Sie den N-Seiten-Modus, wenn die Struktur regelmäßig ist, etwa bei wiederholten Formularen oder Auszügen fester Länge.
  • Brauchen Sie nur einen Abschnitt statt aller, geht es mit dem Werkzeug „Seiten extrahieren“ schneller, als alles zu teilen.
  • Ein sehr langes gescanntes Dokument zu teilen kostet Arbeitsspeicher auf Ihrem Gerät, geben Sie älteren Rechnern also einen Moment Zeit.

Häufig gestellte Fragen

Wie teile ich ein PDF in einzelne Seiten auf?

Wählen Sie den Modus, der jede Seite als eigenes PDF speichert, und klicken Sie auf „Teilen“. Aus einem 30-seitigen Dokument werden 30 einzelne Dateien, die gemeinsam als ein ZIP heruntergeladen werden.

Kann ich nach eigenen Seitenbereichen teilen?

Ja. Tippen Sie Bereiche wie 1-3, 4-6 ein, und jeder Bereich wird zu einem eigenen PDF. Sie dürfen beliebig viele Bereiche festlegen, und sie müssen nicht gleich lang sein.

Warum kommt mein Ergebnis als ZIP-Datei?

Beim Teilen entstehen meist mehrere PDFs auf einmal, und ein ZIP hält sie in einem geordneten Download zusammen, statt Dutzende einzelner Speichervorgänge auszulösen. Entpacken Sie es, und alle PDFs liegen darin, der Reihe nach benannt.

Wird mein Dokument beim Teilen hochgeladen?

Nein. PDFora verarbeitet die Datei lokal in Ihrem Browser, das PDF verlässt Ihr Gerät also nicht. Damit eignet sich das Werkzeug auch für vertrauliches Material wie Verträge und Personalakten.

Gibt es beim Teilen eine Dateigrößenbeschränkung?

Wir geben keine vor. Da Ihr eigenes Gerät die Verarbeitung übernimmt, hängen sehr große Dateien vom verfügbaren Arbeitsspeicher ab – die meisten Dokumente sind in Sekunden geteilt, riesige gescannte Bände können länger dauern.

Verschlechtert das Teilen die Qualität meines PDFs?

Nein. Die Seiten werden unverändert in die neuen Dateien kopiert, ohne erneute Komprimierung. Text bleibt scharf und durchsuchbar, und Bilder behalten ihre ursprüngliche Auflösung.

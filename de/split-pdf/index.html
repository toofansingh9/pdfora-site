PDF teilen

Teilen Sie ein PDF in mehrere kleinere PDFs auf: eine Datei pro Seite, gleich große Abschnitte oder genau die Seitenbereiche, die Sie eintippen.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Ein langes PDF passt oft nicht zu dem, was Sie gerade vorhaben. Eine Klassenlehrerin will jedem Kind nur das eigene Zeugnis aus einem 32-seitigen Export geben; ein Mieter möchte dem Vermieter die Seiten 4 bis 6 des Mietvertrags schicken, nicht alle 40; der Scanner hat aus einem Stapel unzusammenhängender Briefe eine einzige riesige Datei gemacht. Durch das Teilen wird aus dem einen Dokument eine Reihe eigenständiger PDFs, die sich jeweils einzeln benennen, verschicken oder ablegen lassen.

Das Teilen-Tool von PDFora bietet drei Modi. „Jede Seite“ erzeugt ein PDF pro Seite. „Alle N Seiten“ schneidet das Dokument in gleich große Abschnitte (voreingestellt sind 2 Seiten pro Datei; der letzte Abschnitt enthält einfach den Rest). „Eigene Bereiche“ lässt Sie Gruppen wie 1-3, 4-6, 7-10 eintippen, wobei jedes Komma eine neue Ausgabedatei beginnt. In allen drei Modi werden die Seiten mit pdf-lib unverändert kopiert: Text bleibt markierbar, Bilder behalten ihre Auflösung, nichts wird neu gezeichnet – eine Seite in der Ausgabe druckt also genau wie dieselbe Seite im Original.

Das Ergebnis sind nummerierte Dateien, benannt nach Ihrem Original: Aus vertrag.pdf werden vertrag-1.pdf, vertrag-2.pdf und so weiter. Sie können alles auf einmal als vertrag-split.zip herunterladen oder einzelne Dateien in der Liste anklicken. Da das Kopieren im Browser-Tab passiert, hängt die Geschwindigkeit von Ihrem Gerät ab und nicht von einer Server-Warteschlange.

So teilen Sie ein PDF in einzelne Dateien auf

  1. Öffnen Sie „PDF teilen“ und fügen Sie eine Datei hinzu. Das Tool bearbeitet jeweils ein Dokument.
  2. Wählen Sie den Teilungsmodus: „Jede Seite“, „Alle N Seiten“ oder „Eigene Bereiche“.
  3. Bei „Alle N Seiten“ geben Sie die Seiten pro Datei ein. Bei „Eigene Bereiche“ tippen Sie die Gruppen durch Kommas getrennt ein, zum Beispiel 1-2, 3, 4-9. Jede Gruppe wird eine eigene Datei.
  4. Klicken Sie auf „PDF teilen“ und warten Sie auf den Fortschrittsbalken; pro Gruppe entsteht eine Ausgabedatei.
  5. Klicken Sie auf „Alle herunterladen (.zip)“ oder laden Sie die Teile einzeln herunter, und öffnen Sie dann ein paar davon, um die Schnittstellen zu prüfen.

Wann Sie dieses Tool nutzen sollten

  • Schule: einen Sammelexport von Zeugnissen oder Urkunden in eine Datei pro Schülerin und Schüler aufteilen, bevor sie an die Eltern gehen.
  • Mietunterlagen: die unterschriebenen Seiten oder eine einzelne Anlage aus einem langen Mietvertrag herausnehmen und der Gegenseite schicken.
  • Kreditorenbuchhaltung: einen gescannten Stapel einseitiger Rechnungen in ein PDF pro Rechnung zerlegen, um sie in die Buchhaltungssoftware hochzuladen.
  • Selbstverlag: ein Manuskript in Kapiteldateien für Testleser aufteilen, die nur ihren Teil prüfen.
  • Portale mit Seitenbegrenzung: Manche Bewerbungssysteme nehmen pro Upload nur wenige Seiten an – Abschnitte zu N Seiten passen dann in die Vorgaben.
  • Druckaufträge: nur die Farbseiten eines Berichts als eigene Datei an den Copyshop schicken.

Das sollten Sie vorher wissen

  • Im Modus „Eigene Bereiche“ bedeutet ein Bereich wie 4-6 die Seiten 4, 5 und 6 einschließlich. Ein Ende darf offen bleiben: -5 heißt Seite 1 bis 5, 8- heißt Seite 8 bis zur letzten Seite.
  • Zahlen jenseits des Dokumentendes werden gekürzt statt abgelehnt. 20-30 bei einer 25-seitigen Datei ergibt die Seiten 20 bis 25. Ein Teil ganz ohne gültige Seite wird übersprungen, und bleibt gar nichts Gültiges übrig, erscheint die Meldung, mindestens einen gültigen Bereich einzugeben.
  • Bereiche dürfen sich überschneiden. 1-5, 3-8 erzeugt zwei Dateien, die beide die Seiten 3 bis 5 enthalten. Praktisch, wenn jeder Empfänger dasselbe Deckblatt braucht – passiert aber auch leicht aus Versehen.
  • Jede Ausgabe enthält nur die Seiten. Die Lesezeichen werden nicht kopiert, Links, die auf Seiten in einer anderen Datei sprangen, funktionieren nicht mehr, und ausfüllbare Formularfelder überleben eventuell nicht. Weblinks auf einer Seite funktionieren weiterhin.
  • Schriften und Bilder, die auf mehreren Seiten vorkommen, werden in jedem Teil, der sie braucht, erneut gespeichert. Zusammengerechnet sind die Teile daher meist etwas größer als die Originaldatei.
  • Die Ergebnisliste zeigt einzelne Download-Buttons für bis zu 50 Dateien. Ein 300-seitiges Dokument seitenweise zu teilen, funktioniert trotzdem – holen Sie sich dann alles über den ZIP-Download.

Tipps für beste Ergebnisse

  • Notieren Sie die Bereiche vorher anhand der Seitenminiaturen in Ihrem Viewer; das Tool zählt die tatsächliche Position in der Datei, nicht die Seitenzahl in der Fußzeile.
  • Brauchen Sie nur einen einzigen Seitenblock, liefert „Seiten extrahieren“ direkt eine Datei statt einer ZIP mit nur einem Eintrag.
  • Benennen Sie die Teile direkt nach dem Entpacken um. vertrag-3.pdf sagt Ihnen in einem Monat nichts mehr, vertrag-anlage-B.pdf schon.
  • Bei einem Scanstapel, in dem jedes Dokument eine andere Länge hat, teilen Sie lieber nach Text oder nach Lesezeichen, statt Seiten von Hand zu zählen.
  • Behalten Sie das Original. Ein Teilen lässt sich nicht rückgängig machen, aber mit „PDF zusammenführen“ können Sie die Teile jederzeit wieder verbinden, wenn Sie an der falschen Stelle geschnitten haben.

Praxisbeispiel: die Zeugnisse einer ganzen Klasse

Ein Klassenlehrer an einer Gesamtschule in Hannover lädt die Halbjahreszeugnisse für 28 Kinder aus der Schulverwaltungssoftware herunter. Heraus kommt ein einziges 56-seitiges PDF: zwei Seiten pro Kind, immer in derselben Reihenfolge, mit dem Namen auf der ersten Seite jedes Paars. Die ganze Datei an jede Familie zu mailen, kommt natürlich nicht infrage.

Mit „Alle N Seiten“ und 2 Seiten pro Datei entstehen 28 Dateien, zeugnisse-1.pdf bis zeugnisse-28.pdf, in der Reihenfolge der Klassenliste. Er prüft zeugnisse-1 und zeugnisse-28, um sicherzugehen, dass sich die Paare nicht verschoben haben (hätte ein Kind ein dreiseitiges Zeugnis gehabt, wäre jede folgende Datei um eine Seite versetzt, und „Nach Text teilen“ mit dem Wort, das jedes Zeugnis einleitet, wäre die sicherere Wahl gewesen). Als die Zuordnung stimmt, benennt er jede Datei nach dem Kind und hängt sie an die richtige Nachricht.

Fehlerbehebung

Ich bekomme „Geben Sie mindestens einen gültigen Bereich ein“
Keiner der Bereiche passte zu einer echten Seite. Prüfen Sie auf Tippfehler – etwa 1–3 mit einem langen Gedankenstrich aus einem Textverarbeitungsprogramm, Buchstaben oder Seitenzahlen, die über das Dokument hinausgehen. Verwenden Sie einfache Bindestriche und Kommas.
Die Teile sind um eine Seite verschoben
Das Tool zählt Seiten nach ihrer Position in der Datei. Hat Ihr Dokument ein Deckblatt oder eine unnummerierte erste Seite, ist die gedruckte Seite 1 womöglich die physische Seite 2. Passen Sie die Bereiche um diesen Versatz an.
Ich habe Bereiche angegeben, aber eine große Datei erhalten
Gruppen werden nur durch Kommas getrennt. 1-3 4-6 mit Leerzeichen wird als ein einziger fehlerhafter Bereich gelesen. Schreiben Sie 1-3, 4-6.
Die Ausgabeseiten sind leer oder das Tool meldet beim Laden einen Fehler
Die Quelle ist vermutlich verschlüsselt oder beschädigt. Entfernen Sie das Passwort in der Anwendung, mit der sie erstellt wurde, oder lassen Sie zuerst „PDF reparieren“ laufen und teilen Sie dann die saubere Kopie.
Lesezeichen und interne Links funktionieren nicht mehr
Beim Teilen wird nur der Seiteninhalt kopiert. Brauchen die Teile eine Navigation, versehen Sie sie mit „Lesezeichen erstellen“; interne Links, die auf andere Teile zeigen, lassen sich nicht erhalten.
Bei einer sehr großen Datei wird der Browser langsam
Jede Ausgabe wird im Arbeitsspeicher aufgebaut. Schließen Sie andere Tabs oder teilen Sie zuerst in größere Abschnitte und diese dann erneut.

Häufig gestellte Fragen

Verändert das Teilen die Qualität der Seiten?

Nein. Die Seiten werden Objekt für Objekt kopiert, nicht in Bilder umgewandelt; Text, Vektorzeichnungen und Fotos sind identisch mit dem Original.

Wie heißen die Ausgabedateien?

Wie das Original plus eine Nummer in Ausgabereihenfolge: Aus bericht.pdf werden bericht-1.pdf, bericht-2.pdf und so weiter, gemeinsam geliefert in bericht-split.zip.

Kann eine Seite in mehreren Ausgabedateien vorkommen?

Ja, im Modus „Eigene Bereiche“. Überschneidende Bereiche wie 1-2, 1, 3-5 legen Seite 1 in die ersten beiden Dateien.

Was passiert mit dem letzten Abschnitt bei „Alle N Seiten“?

Er enthält die restlichen Seiten. Ein 10-seitiges Dokument, das alle 3 Seiten geteilt wird, ergibt Dateien mit 3, 3, 3 und 1 Seite.

Kann ich mehrere PDFs in einem Rutsch teilen?

Nein, das Tool nimmt pro Durchgang eine Datei. Teilen Sie jedes Dokument einzeln, oder führen Sie sie vorher zusammen, wenn sie als eine Folge geschnitten werden sollen.

Brauche ich ein Konto?

Nein. Es gibt keine Anmeldung und keine Begrenzung, wie oft Sie teilen.

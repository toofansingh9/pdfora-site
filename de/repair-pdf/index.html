PDF reparieren

Lesen Sie ein PDF, an dem andere Programme scheitern, neu ein und speichern Sie es mit einer sauber neu aufgebauten Dateistruktur.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Ein PDF ist kein durchgehender Inhaltsstrom, sondern eine Sammlung nummerierter Objekte plus eine Querverweistabelle, die dem Reader sagt, wo jedes Objekt beginnt. Bricht ein Download ab, schreibt ein Programm diese Tabelle fehlerhaft oder wird eine Datei nacheinander von mehreren Tools bearbeitet, kann die Tabelle an die falschen Stellen zeigen. Manche Viewer kommen stillschweigend damit klar, andere zeigen leere Seiten, und Upload-Portale lehnen die Datei oft mit einer nichtssagenden Fehlermeldung ab. Genau für diesen Zwischenbereich ist „PDF reparieren“ gedacht: Dateien, deren Struktur unordentlich ist, deren Inhalt aber noch vorhanden ist.

Was das Tool tut, lässt sich genau benennen. Es lädt die Datei mit der Bibliothek pdf-lib, die die auffindbaren Objekte einliest und die Struktur selbst ermittelt, statt einer kaputten Tabelle zu vertrauen, und speichert dann eine frische Kopie. Die neue Datei erhält eine neu geschriebene Querverweistabelle, und jedes Objekt wird einzeln geschrieben statt in komprimierte Objektströme gepackt – ein älteres Layout, das strenge oder alte Reader bereitwilliger akzeptieren. Der Seiteninhalt wird kopiert, nicht neu gerendert; Text, Schriften und Bilder bleiben also exakt, wie sie waren.

Zur Ehrlichkeit gehört auch die Grenze: Das ist ein Neuaufbau, keine Datenrettung. Fehlen tatsächlich Bytes, etwa die zweite Hälfte eines abgebrochenen Downloads, gibt es nichts, woraus diese Seiten rekonstruiert werden könnten, und kein Tool kann sie erfinden. Dann hilft nur eine neue Kopie der Datei aus der Quelle.

So reparieren Sie eine PDF-Datei

  1. Öffnen Sie „PDF reparieren“ und fügen Sie die problematische Datei hinzu. Pro Durchgang wird eine Datei verarbeitet.
  2. Klicken Sie auf „Reparieren & neu aufbauen“. Die Datei wird eingelesen und neu gespeichert; bei den meisten Dokumenten dauert das ein bis zwei Sekunden.
  3. Meldet das Tool einen Fehler, ließ sich die Datei gar nicht einlesen; lesen Sie dann unten bei der Fehlerbehebung weiter.
  4. Laden Sie das Ergebnis herunter. Es trägt den Originalnamen mit dem Zusatz -repaired, zum Beispiel vertrag-repaired.pdf.
  5. Öffnen Sie die reparierte Kopie in dem Viewer oder Portal, das vorher gestreikt hat, und blättern Sie durch, um zu prüfen, ob jede Seite Inhalt hat.

Wann Sie dieses Tool nutzen sollten

  • Das Abgabeportal der Hochschule lehnt die Abschlussarbeit als ungültiges PDF ab, obwohl sie auf dem eigenen Laptop problemlos aufgeht.
  • Eine Datei aus einem älteren Scanner oder einer alten Buchhaltungssoftware öffnet sich in einem Viewer und zeigt in einem anderen leere Seiten.
  • Ein PDF, das viele Male mit verschiedenen Programmen bearbeitet wurde, ist träge geworden oder meldet beim Öffnen, es sei beschädigt.
  • Eine Datei für eine Druckerei oder ein elektronisches Einreichungssystem vorbereiten, dessen Prüfung strenger ist als ein normaler Viewer.
  • Ein Dokument vor dem Zusammenfügen oder Teilen normalisieren, wenn diese Tools das Original nicht laden wollen.
  • Schnell prüfen, ob eine Datei strukturell lesbar ist, bevor Sie den Absender um einen neuen Export bitten.

Das sollten Sie vorher wissen

  • Die Reparatur baut die Struktur neu auf, stellt aber keine verlorenen Inhalte wieder her. Eine abgeschnittene Datei kommt bestenfalls mit den Seiten zurück, die vollständig waren.
  • Die Ausgabe wird ohne komprimierte Objektströme geschrieben. Das macht sie kompatibler, aber oft etwas größer als die Eingabe – bei Dateien, die stark auf Objektströme gesetzt haben, manchmal um 10 bis 30 Prozent.
  • Seiten werden so kopiert, wie sie sind. Sah eine Seite falsch aus, weil ihr eigener Inhaltsstrom beschädigt ist, kann sie auch nach dem Neuaufbau falsch aussehen.
  • Die Datei wird mit abgeschalteter Verschlüsselungsprüfung geöffnet. Ein passwortgeschütztes PDF lädt vielleicht, der Inhalt bleibt aber verschlüsselt, und die gespeicherte Kopie wird kaum richtig angezeigt; entfernen Sie das Passwort zuerst an der Quelle.
  • Formulare, Lesezeichen und Anmerkungen, die pdf-lib lesen kann, wandern in die neue Datei, weil das ganze Dokument gespeichert wird und nicht nur die Seiten.
  • Die Verarbeitung läuft in Ihrem Browser – auch eine Datei, die Sie keinem Online-Wiederherstellungsdienst schicken würden, können Sie hier also ausprobieren.

Tipps für beste Ergebnisse

  • Behalten Sie das Original immer neben der reparierten Kopie, bis Sie das Ergebnis Seite für Seite geprüft haben.
  • Vergleichen Sie die Seitenzahl der reparierten Datei mit der erwarteten. Eine niedrigere Zahl ist das deutlichste Zeichen, dass die Quelle abgeschnitten war.
  • Lehnt ein Portal die reparierte Datei weiterhin ab, drucken Sie sie aus Ihrem Viewer als PDF; das rendert jede Seite neu und behebt Fehler im Seiteninhalt, die ein Neuaufbau nicht erreicht.
  • Kam die Datei per E-Mail oder Download, fordern Sie sie erst noch einmal an, bevor Sie Zeit in die Reparatur stecken. Eine saubere Kopie schlägt jede Reparatur.
  • Ist die Datei nach einer erfolgreichen Reparatur größer geworden und besteht vor allem aus Scans, lassen Sie anschließend „PDF komprimieren“ laufen.

Praxisbeispiel: die Rechnungssammlung eines Freiberuflers

Ein freiberuflicher Übersetzer aus Bremen exportiert für die Steuererklärung zwölf Monatsrechnungen aus einem alten Rechnungsprogramm in ein einziges PDF. Im eingebauten Viewer des Browsers öffnet sich die Datei, das Upload-Formular des Finanzamts lehnt sie aber als ungültiges Dokument ab, und „PDF zusammenführen“ weigert sich, sie zu den übrigen Unterlagen hinzuzufügen.

Nach „PDF reparieren“ lädt die Datei, bekommt eine neu geschriebene Querverweistabelle und wird ohne Objektströme gespeichert. Das Upload-Formular nimmt die reparierte Kopie an, und auch das Zusammenführen klappt jetzt. Die Datei ist von 410 KB auf etwa 460 KB gewachsen – der Preis für das konservativere Layout, der hier keine Rolle spielt.

Vor dem Einreichen zählt er die Seiten: zwölf Rechnungen, zwölf Seiten. Wären es neun gewesen, wäre schon der ursprüngliche Export unvollständig gewesen, und die einzige echte Lösung wäre ein neuer Export aus dem Rechnungsprogramm.

Fehlerbehebung

Das Tool zeigt einen Fehler und erzeugt nichts
Die Datei ließ sich überhaupt nicht einlesen – typischerweise, weil sie gar kein echtes PDF ist (zum Beispiel eine HTML-Fehlerseite, die mit der Endung .pdf gespeichert wurde) oder stark abgeschnitten ist. Öffnen Sie sie in einem Texteditor: Ein echtes PDF beginnt mit %PDF. Andernfalls besorgen Sie sich eine neue Kopie.
In der reparierten Datei fehlen Seiten
Diese Seiten waren in der Quelle nicht in lesbarer Form vorhanden, meist weil ein Download abgebrochen ist. Laden oder exportieren Sie das Dokument erneut.
Seiten sind weiterhin leer oder verstümmelt
Der Seiteninhalt selbst ist beschädigt, und den berührt ein struktureller Neuaufbau nicht. Drucken Sie das Original aus dem Viewer, der es am besten darstellt, als PDF, oder bitten Sie den Absender um einen neuen Export.
Die reparierte Datei ist größer als das Original
Das Tool schreibt Objekte einzeln statt in komprimierten Objektströmen. Das ist der Kompatibilität wegen so gewollt; komprimieren Sie das Ergebnis, wenn die Größe wichtig ist.
Die reparierte Kopie zeigt unlesbaren Inhalt
Die Quelle war vermutlich verschlüsselt. Die Verschlüsselung wird beim Laden ignoriert, der Inhalt bleibt also verwürfelt. Entfernen Sie das Passwort in dem Programm, mit dem die Datei erstellt wurde, und reparieren Sie diese Kopie.
Das Portal lehnt die Datei immer noch ab
Die Prüfung stört sich vielleicht an etwas anderem als der Struktur, etwa an Dateigröße, Seitenformat oder eingebetteten Schriften. Prüfen Sie die Vorgaben des Portals und ändern Sie die Seitengröße, komprimieren Sie oder drucken Sie als PDF.

Häufig gestellte Fragen

Was genau verändert „PDF reparieren“?

Es liest die Objekte des Dokuments neu ein, schreibt eine neue Querverweistabelle und speichert jedes Objekt einzeln ohne Objektströme. Der Seiteninhalt wird unverändert übernommen.

Kann es ein PDF retten, das sich nirgends öffnen lässt?

Manchmal. Sind die Objekte intakt und nur die Struktur kaputt, ja. Fehlen die Daten selbst oder ist die Datei gar kein PDF, kann kein Reparatur-Tool sie zurückholen.

Leidet die Qualität unter der Reparatur?

Nein. Nichts wird neu gerendert oder neu komprimiert, Text und Bilder sehen genau aus wie vorher.

Warum ist die Datei größer geworden?

In der Ausgabe werden keine komprimierten Objektströme verwendet. Dadurch wird die Datei etwas größer, aber für ältere und strengere Software lesbar.

Entfernt die Reparatur ein Passwort?

Nein. Es wird nichts entschlüsselt, und eine verschlüsselte Datei wird nach dem Neuaufbau in der Regel nicht korrekt angezeigt.

Kann ich mehrere Dateien gleichzeitig reparieren?

Das Tool nimmt pro Durchgang eine Datei. Verarbeiten Sie die Dateien nacheinander; bei normalen Dokumenten geht das schnell.

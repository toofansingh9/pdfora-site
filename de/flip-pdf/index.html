PDF spiegeln

Jede Seite eines PDFs von links nach rechts oder von oben nach unten spiegeln – für Bügelbilder, hinterleuchtete Drucke und Scans, die seitenverkehrt herauskamen.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Die häufigste Verwechslung zuerst: Wer eine Seite „umdrehen“ will, weil sie quer oder kopfüber im PDF steht, braucht Drehen, nicht Spiegeln. Beim Drehen kreist die Seite um ihren Mittelpunkt, und der Text bleibt ganz normal lesbar. Beim Spiegeln entsteht dagegen ein Spiegelbild – die Schrift läuft rückwärts. Genau das braucht man gelegentlich: für Bügelbilder auf Transferpapier, für Folien, die von hinten bedruckt und von vorn durch die Scheibe gelesen werden, für Schilder hinter Glas oder für den Scan, den die Frontkamera des Handys seitenverkehrt abgespeichert hat. Greifen Sie also nur dann zu diesem Tool, wenn am Ende wirklich ein Spiegelbild stehen muss, und machen Sie vor dem Druck auf Transferpapier, Folie oder anderem Material, das nur einmal benutzt werden kann, einen Probedruck auf normalem Papier.

„PDF spiegeln“ kennt zwei Richtungen. „Horizontal (spiegeln)“ vertauscht auf jeder Seite links und rechts, das ist die übliche Einstellung für Transfers. „Vertikal“ vertauscht oben und unten – und das ist nicht dasselbe, als würde man die Seite auf den Kopf stellen, denn der Text steht danach kopfüber und ist zusätzlich seitenverkehrt. Den Seitenrahmen dreht keine der beiden Optionen: Hochformat bleibt Hochformat, der gespiegelte Inhalt nimmt exakt dieselbe Fläche ein wie zuvor. Ein Rand, der links war, liegt anschließend rechts.

Dafür rendert PDF.js jede Seite in doppelter Normalgröße auf eine Zeichenfläche. Dieses Bild wird gespiegelt, als JPEG mit der Qualität 0,9 gespeichert und auf eine Seite im Originalformat gesetzt. In der Ausgabedatei ihredatei-flipped.pdf stecken folglich Bilder Ihrer Seiten, kein Text mehr. Das Ganze läuft im Browser. Der Umweg über das Bild hat einen Grund: Nur so werden Text, Vektorgrafiken, eingebettete Fotos und Formulardarstellungen alle gemeinsam umgekehrt, ohne dass irgendein Element falsch herum stehen bleibt. Für eine Transfer- oder Folienvorlage ist das ideal. Für ein Dokument, in dem noch gesucht oder gearbeitet werden soll, dagegen nicht – die gespiegelte Kopie ist eine reine Druckdatei, Ihr Original bleibt die Arbeitsfassung.

So spiegeln Sie ein PDF

  1. Öffnen Sie „PDF spiegeln“ und wählen Sie ein PDF aus.
  2. Wählen Sie die Richtung: „Horizontal (spiegeln)“ ist voreingestellt, „Vertikal“ spiegelt von oben nach unten.
  3. Klicken Sie auf „Seiten spiegeln“. Ein Fortschrittsbalken läuft, während jede Seite gerendert wird.
  4. Laden Sie die gespiegelte Datei herunter und sehen Sie sich die erste Seite an: Der Text sollte rückwärts zu lesen sein.
  5. Drucken Sie eine Testseite auf Normalpapier, bevor Sie teures Transferpapier oder Folie verwenden.

Wann Sie dieses Tool nutzen sollten

  • Bügelbilder für Junggesellenabschied, Vereinsfahrt oder Familienfeier auf Transferpapier drucken, damit der Schriftzug auf dem Shirt richtig herum steht.
  • Öffnungszeiten oder ein Logo für die Schaufensterscheibe auf transparente Folie drucken, die von innen aufgeklebt und von außen gelesen wird.
  • Eine Vorlage für Linolschnitt oder Stempel anlegen, die spiegelverkehrt auf den Druckstock übertragen werden muss.
  • Scans oder Handyfotos von Dokumenten korrigieren, die seitenverkehrt gespeichert wurden.
  • Für die Grundschule Arbeitsblätter mit Spiegelschrift oder Rätseln vorbereiten, die man nur mit einem Spiegel lesen kann.
  • Motive für Siebdruck oder ähnliche Verfahren aufbereiten, die eine umgekehrte Vorlage brauchen.

Das sollten Sie vorher wissen

  • Jede Seite wird gespiegelt. Eine Seitenauswahl gibt es nicht; trennen Sie benötigte Seiten vorher ab. Ausgelassene Seiten können Sie danach ungespiegelt wieder einfügen.
  • Die Ausgabe ist bildbasiert. Text lässt sich nicht markieren, kopieren oder durchsuchen, und Links, Lesezeichen und Formularfelder sind weg.
  • Die Seiten werden in doppelter PDF-Normalgröße gerendert, was etwa 144 dpi entspricht. Für die meisten Transfers und Schilder reicht das, aber Kleingedrucktes und feine Linien werden weicher als im Original. Bei Motiven, die Sie vergrößern oder auf einem Plotter schneiden wollen, spiegeln Sie lieber die Original-Designdatei.
  • Weil jede Seite zu einem JPEG wird, kann die Datei bei überwiegend textbasierten Dokumenten deutlich wachsen, und sehr feine Details können leichte Komprimierungsartefakte zeigen.
  • Die Seitenformate bleiben erhalten: Jede Ausgabeseite hat dieselben Maße wie die Originalseite.
  • Eine gespiegelte Datei in derselben Richtung erneut zu spiegeln ergibt wieder eine lesbare Seite – allerdings als Bild zweiter Generation mit etwas geringerer Qualität. Behalten Sie das Original.

Tipps für beste Ergebnisse

  • Viele Druckertreiber haben eine Option „Spiegelbild“ oder „Transfer“. Nutzen Sie entweder die Treiberoption oder dieses Tool, nicht beides, sonst wird doppelt gespiegelt. Wenn Sie nicht wissen, was Copyshop oder Drucker anwenden, fragen Sie vor dem Versand der Datei nach.
  • Soll eine Seite nur auf dem Kopf stehen, nehmen Sie „PDF drehen“ mit 180 Grad statt vertikalem Spiegeln.
  • Setzen Sie Motive für Transfers auf eine Seite mit großzügigen Rändern; der Druckbereich von Heimdruckern endet ein paar Millimeter vor der Kante.
  • Behalten Sie das ungespiegelte Original für Änderungen und spätere Nachdrucke.
  • Ist die gespiegelte Datei groß, verkleinert „PDF komprimieren“ sie meist weiter – auf Kosten etwas Schärfe.

Praxisbeispiel: Öffnungszeiten für die Schaufensterscheibe

Die Inhaberin eines kleinen Cafés in Basel will ihre neuen Öffnungszeiten auf transparente Klebefolie drucken. Die Folie kommt innen an die Scheibe, bedruckt wird deshalb die Seite, die später am Glas liegt – von der Straße aus muss die Schrift trotzdem richtig herum zu lesen sein. Gestaltet hat sie das Ganze als A4-Seite in Word und als PDF exportiert. Ihr Drucker bietet im Treiber keine Spiegeloption.

Sie wählt in „PDF spiegeln“ die Einstellung „Horizontal (spiegeln)“ und klickt auf „Seiten spiegeln“. Den ersten Ausdruck macht sie auf normalem Papier und hält ihn mit der bedruckten Seite gegen die Scheibe: Von draußen betrachtet stimmt alles. Erst dann legt sie die Folie ein.

Bei dem Probedruck fällt ihr allerdings auf, dass die kleine Zeile mit der Website am unteren Rand weicher wirkt als im Original, weil die Seite mit etwa 144 dpi als Bild gerendert wird. Sie vergrößert diese Zeile im Word-Dokument, exportiert neu und spiegelt die frische PDF-Datei noch einmal – statt die bereits gespiegelte Datei weiterzuverwenden.

Für den Sommer, wenn sich die Zeiten wieder ändern, behält sie beide Dateien: das Word-Original zum Bearbeiten und das gespiegelte PDF als Druckvorlage für Ersatzfolien, falls eine beim Fensterputzen beschädigt wird.

Fehlerbehebung

Der Text ist nach dem Spiegeln noch richtig herum lesbar
Ihr Drucker oder Viewer spiegelt womöglich ein zweites Mal. Schalten Sie die Spiegel- bzw. Transferoption im Druckdialog aus.
Ich wollte die Seite auf dem Kopf, nicht gespiegelt
Nutzen Sie „PDF drehen“ und wählen Sie 180 Grad. Vertikales Spiegeln kehrt zusätzlich den Text um.
Im Ergebnis kann ich keinen Text markieren
So arbeitet das Tool: Die Seiten werden in Bilder umgewandelt. Behalten Sie das Original für alles, wofür Text nötig ist.
Die Ausgabe ist viel größer als die Eingabe
Jede Seite wird als JPEG-Bild gespeichert. Schicken Sie das Ergebnis durch „PDF komprimieren“ oder spiegeln Sie nur die Seiten, die Sie brauchen.
Kleiner Text wirkt unscharf
Gerendert wird mit etwa 144 dpi. Vergrößern Sie das Motiv vor dem Spiegeln im Original oder nutzen Sie die Spiegelfunktion Ihres Druckertreibers, die mit dem ursprünglichen Vektorinhalt arbeitet.
Bei einem langen Dokument wird der Tab langsam
Jede Seite wird im Arbeitsspeicher gerendert. Teilen Sie das Dokument und spiegeln Sie es in kleineren Teilen.

Häufig gestellte Fragen

Spiegeln oder drehen – was brauche ich?

Beim Drehen kreist die Seite um ihren Mittelpunkt, der Text bleibt normal lesbar. Beim Spiegeln entsteht ein Spiegelbild, die Schrift läuft rückwärts. Steht eine Seite nur quer oder auf dem Kopf, ist Drehen die richtige Wahl.

Kann ich nur eine bestimmte Seite spiegeln?

In diesem Tool nicht. Extrahieren Sie die betreffende Seite, spiegeln Sie sie und fügen Sie sie anschließend wieder ins Dokument ein.

Warum lässt sich im gespiegelten PDF kein Text mehr markieren?

Gespiegelt wird ein gerendertes Bild jeder Seite. Das Ergebnis besteht deshalb aus Bildern und enthält keine Textobjekte mehr.

Wie hoch ist die Auflösung der gespiegelten Seiten?

Gerendert wird in doppelter PDF-Standardgröße, das sind rund 144 dpi. Gespeichert wird als JPEG mit der Qualität 0,9.

Kann ich gleichzeitig horizontal und vertikal spiegeln?

Ja, indem Sie das Tool zweimal laufen lassen, einmal pro Richtung. Das Ergebnis entspricht allerdings einer Drehung um 180 Grad, und die schafft „PDF drehen“ ohne Umwandlung in Bilder.

Muss ich meine Datei dafür hochladen?

Nein. Rendern und Spiegeln laufen in Ihrem Browser-Tab, das PDF verlässt Ihr Gerät nicht.

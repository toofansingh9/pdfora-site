PDF spiegeln

Jede Seite eines PDFs von links nach rechts oder von oben nach unten spiegeln – für Bügelbilder, hinterleuchtete Drucke und Scans, die seitenverkehrt herauskamen.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Spiegeln ist nicht dasselbe wie Drehen. Beim Drehen wird eine Seite um ihren Mittelpunkt gedreht; beim Spiegeln entsteht ein Spiegelbild, der Text liest sich also rückwärts. Klingt nutzlos, bis man es braucht: Transferpapier für T-Shirts, Fensteraufkleber, die auf die Rückseite transparenter Folie gedruckt werden, Schilder, die man durch Glas liest, und gelegentlich ein Scan oder Foto, das die Frontkamera seitenverkehrt aufgenommen hat. Es ist aber auch ein Werkzeug, zu dem man versehentlich greift. Steht eine Seite nur quer oder auf dem Kopf, brauchen Sie Drehen – dabei bleibt der Text intakt und lesbar. Spiegeln Sie nur, wenn das Endergebnis wirklich ein Spiegelbild sein muss, und prüfen Sie die Richtung mit einem Testdruck auf Normalpapier, bevor Sie Transferpapier, Folie oder anderes Material verwenden, das sich nicht wiederverwenden lässt.

Das Spiegel-Tool von PDFora bietet zwei Richtungen. „Horizontal (spiegeln)“ spiegelt jede Seite von links nach rechts – die übliche Wahl für Transfers. „Vertikal“ spiegelt von oben nach unten, was nicht dasselbe ist, wie die Seite auf den Kopf zu stellen: Der Text steht dann auf dem Kopf und ist zugleich seitenverkehrt. Keine der beiden Optionen dreht den Seitenrahmen: Eine Hochformatseite bleibt Hochformat, und der gespiegelte Inhalt belegt genau dieselbe Fläche wie vorher – Ränder, die links waren, sind jetzt rechts.

Dazu zeichnet PDF.js jede Seite in doppelter Normalgröße auf eine Leinwand, sie wird gespiegelt, als JPEG mit Qualität 0,9 gespeichert und dann auf eine Seite in Originalgröße gesetzt. Die Ausgabe, ihredatei-flipped.pdf, enthält also Bilder Ihrer Seiten, keinen Text. Das alles passiert im Browser. Die Umwandlung in ein Bild ist der Preis dafür, jede Art von Inhalt einheitlich zu spiegeln: Text, Vektorzeichnungen, eingebettete Fotos und Formulardarstellungen werden gemeinsam umgekehrt, kein Element bleibt falsch herum. Für einen Transfer oder Aufkleber ist das genau richtig; für ein Dokument, das noch durchsucht oder bearbeitet werden soll, nicht. Behandeln Sie die gespiegelte Kopie daher als Druckdatei und behalten Sie das Original als Arbeitsversion.

So spiegeln Sie ein PDF

  1. Öffnen Sie „PDF spiegeln“ und wählen Sie ein PDF aus.
  2. Wählen Sie die Richtung: „Horizontal (spiegeln)“ ist voreingestellt, „Vertikal“ spiegelt von oben nach unten.
  3. Klicken Sie auf „Seiten spiegeln“. Ein Fortschrittsbalken läuft, während jede Seite gerendert wird.
  4. Laden Sie die gespiegelte Datei herunter und sehen Sie sich die erste Seite an: Der Text sollte rückwärts zu lesen sein.
  5. Drucken Sie eine Testseite auf Normalpapier, bevor Sie teures Transferpapier oder Folie verwenden.

Wann Sie dieses Tool nutzen sollten

  • Motive auf Bügeltransferpapier drucken, das spiegelverkehrt bedruckt werden muss, damit es auf dem Stoff richtig herum erscheint.
  • Fenster- oder Glasschilder herstellen, die auf die Rückseite transparenter Folie gedruckt und von vorn gelesen werden.
  • Scans oder Handyaufnahmen von Dokumenten korrigieren, die seitenverkehrt herauskamen.
  • Vorlagen für Siebdruck oder andere Verfahren vorbereiten, die ein umgekehrtes Bild erfordern.
  • Arbeitsblätter oder Rätsel in Spiegelschrift für eine Unterrichtsaktivität erstellen.
  • Umgekehrte Schnittmuster für Bastelvorlagen anlegen, bei denen auf der Rückseite des Materials geschnitten wird.

Das sollten Sie vorher wissen

  • Jede Seite wird gespiegelt. Eine Seitenauswahl gibt es nicht; trennen Sie benötigte Seiten vorher ab. Ausgelassene Seiten können Sie danach ungespiegelt wieder einfügen.
  • Die Ausgabe ist bildbasiert. Text lässt sich nicht markieren, kopieren oder durchsuchen, und Links, Lesezeichen und Formularfelder sind weg.
  • Die Seiten werden in doppelter PDF-Normalgröße gerendert, was etwa 144 dpi entspricht. Für die meisten Transfers und Schilder reicht das, aber Kleingedrucktes und feine Linien werden weicher als im Original. Bei Motiven, die Sie vergrößern oder auf einem Plotter schneiden wollen, spiegeln Sie lieber die Original-Designdatei.
  • Weil jede Seite zu einem JPEG wird, kann die Datei bei überwiegend textbasierten Dokumenten deutlich wachsen, und sehr feine Details können leichte Komprimierungsartefakte zeigen.
  • Die Seitenformate bleiben erhalten: Jede Ausgabeseite hat dieselben Maße wie die Originalseite.
  • Eine gespiegelte Datei in derselben Richtung erneut zu spiegeln ergibt wieder eine lesbare Seite – allerdings als Bild zweiter Generation mit etwas geringerer Qualität. Behalten Sie das Original.

Tipps für beste Ergebnisse

  • Viele Druckertreiber haben eine Option „Spiegelbild“ oder „Transfer“. Nutzen Sie entweder die Treiberoption oder dieses Tool, nicht beides, sonst wird doppelt gespiegelt. Wenn Sie nicht wissen, was Copyshop oder Drucker anwenden, fragen Sie vor dem Versand der Datei nach.
  • Soll eine Seite nur auf dem Kopf stehen, nehmen Sie „PDF drehen“ mit 180 Grad statt vertikalem Spiegeln.
  • Setzen Sie Motive für Transfers auf eine Seite mit großzügigen Rändern; der Druckbereich von Heimdruckern endet ein paar Millimeter vor der Kante.
  • Behalten Sie das ungespiegelte Original für Änderungen und spätere Nachdrucke.
  • Ist die gespiegelte Datei groß, verkleinert „PDF komprimieren“ sie meist weiter – auf Kosten etwas Schärfe.

Praxisbeispiel: Team-Shirts für das Schulsportfest

Eine Lehrerin in Erfurt hat ein einseitiges PDF mit dem Teamlogo und dem Schriftzug „Team Blau 2026“ für Bügelbilder. Unverändert gedruckt, wäre die Schrift nach dem Aufbügeln auf den Shirts spiegelverkehrt. Ihr Druckertreiber hat keine Spiegeloption, und das Logo hat ein Elternteil als PDF geliefert – das Motiv selbst zu bearbeiten kam also nicht infrage.

Sie spiegelt das PDF horizontal und druckt das Ergebnis zuerst auf Normalpapier. Von hinten gegen das Fenster gehalten, liest sich das Testblatt richtig, die Richtung stimmt also. Dann druckt sie auf Transferpapier, die Spiegeloption des Druckers ausgeschaltet.

Die feine Kontur des Logos ist etwas weicher als in der Original-Vektordatei, weil die Seite als Bild gerendert wurde – in T-Shirt-Größe fällt das aber nicht auf.

Da die Teamfarben auf Shirts in vier verschiedenen Farbtönen gedruckt wurden, behielt sie das gespiegelte PDF als Master-Druckdatei und druckte für jeden Stapel davon nach, statt das Motiv jedes Mal neu zu spiegeln. Eine Datei, einmal geprüft – das ersparte eine zweite Runde Testdrucke.

Fehlerbehebung

Der Text ist nach dem Spiegeln noch richtig herum lesbar
Ihr Drucker oder Viewer spiegelt womöglich ein zweites Mal. Schalten Sie die Spiegel- bzw. Transferoption im Druckdialog aus.
Ich wollte die Seite auf dem Kopf, nicht gespiegelt
Nutzen Sie „PDF drehen“ und wählen Sie 180 Grad. Vertikales Spiegeln kehrt zusätzlich den Text um.
Im Ergebnis kann ich keinen Text markieren
So arbeitet das Tool: Die Seiten werden in Bilder umgewandelt. Behalten Sie das Original für alles, wofür Text nötig ist.
Die Ausgabe ist viel größer als die Eingabe
Jede Seite wird als JPEG-Bild gespeichert. Schicken Sie das Ergebnis durch „PDF komprimieren“ oder spiegeln Sie nur die Seiten, die Sie brauchen.
Kleiner Text wirkt unscharf
Gerendert wird mit etwa 144 dpi. Vergrößern Sie das Motiv vor dem Spiegeln im Original oder nutzen Sie die Spiegelfunktion Ihres Druckertreibers, die mit dem ursprünglichen Vektorinhalt arbeitet.
Bei einem langen Dokument wird der Tab langsam
Jede Seite wird im Arbeitsspeicher gerendert. Teilen Sie das Dokument und spiegeln Sie es in kleineren Teilen.

Häufig gestellte Fragen

Was ist der Unterschied zwischen Spiegeln und Drehen?

Beim Drehen wird eine Seite um ihren Mittelpunkt gedreht, und der Text liest sich weiterhin normal. Beim Spiegeln entsteht ein Spiegelbild, der Text liest sich rückwärts.

Kann ich nur eine einzelne Seite spiegeln?

Nicht innerhalb dieses Tools. Extrahieren Sie die Seite, spiegeln Sie sie und fügen Sie sie wieder ins Dokument ein.

Warum verliert das gespiegelte PDF seinen Text?

Gespiegelt wird ein gerendertes Bild jeder Seite, das Ergebnis enthält also Bilder statt Textobjekte.

Welche Auflösung haben die gespiegelten Seiten?

Die Seiten werden in doppelter PDF-Standardgröße gerendert, etwa 144 dpi, und als JPEG mit Qualität 0,9 gespeichert.

Kann ich horizontal und vertikal zugleich spiegeln?

Lassen Sie das Tool zweimal laufen, einmal in jede Richtung. Das Ergebnis entspricht einer Drehung um 180 Grad – und die erledigt „PDF drehen“, ohne in Bilder umzuwandeln.

Wird meine Datei hochgeladen?

Nein. Rendern und Spiegeln passieren in Ihrem Browser-Tab; das PDF bleibt auf Ihrem Gerät.

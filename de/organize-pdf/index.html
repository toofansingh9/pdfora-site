Seitenzahlen genügen, solange Sie genau wissen, was zu ändern ist. Wenn nicht, wollen Sie das Dokument sehen. Das Organisieren-Werkzeug von PDFora legt jede Seite Ihres PDFs als Miniaturansicht auf eine Übersichtsfläche: Sie ordnen Seiten durch Ziehen neu, drehen die quer eingescannten gerade und markieren andere zum Löschen — alles in einer Ansicht, am Ende exportiert als eine einzige korrigierte Datei.

Die gesamte Übersicht läuft in Ihrem Browser. Ihr PDF wird lokal gerendert und neu aufgebaut, niemals hochgeladen — Sie können also die Seiten eines Mietvertrags, einer Patientenakte oder eines Lohnlaufs umsortieren, ohne dass das Dokument jemals einen fremden Server berührt. Das bedeutet außerdem: kein Warten auf den Upload. Selbst eine dicke Datei öffnet sich so schnell, wie Ihr Gerät sie zeichnen kann.

All das ist kostenlos, ohne Konto, und das exportierte PDF trägt kein Wasserzeichen. Korrigieren Sie eine einzelne Seite oder krempeln Sie fünfzig um — so oft, bis das Dokument stimmt.

So sortieren und organisieren Sie PDF-Seiten online

  1. Öffnen Sie das Werkzeug „PDF organisieren“ auf getpdfora.com und laden Sie Ihre Datei.
  2. Warten Sie einen Moment, bis jede Seite als Miniaturansicht auf der Fläche erscheint.
  3. Ziehen Sie eine beliebige Miniatur an eine neue Position, um die Seiten umzusortieren — das Layout aktualisiert sich sofort.
  4. Klicken Sie bei quer oder kopfstehenden Seiten auf das Drehsymbol, bis die Seite richtig steht.
  5. Markieren Sie unerwünschte Seiten zum Löschen; sie werden auf der Fläche gekennzeichnet, sodass Sie es sich vor dem Export noch anders überlegen können.
  6. Klicken Sie auf Exportieren und laden Sie das fertige PDF mit neuer Seitenreihenfolge, Drehungen und Löschungen herunter.

When to use this tool

  • Einen Scan korrigieren, bei dem der Papierstapel verkehrt herum oder durcheinander durch den Einzug gelaufen ist.
  • Die beiden querformatigen Diagramme in einem ansonsten hochformatigen Bericht gerade stellen, ohne andere Seiten anzufassen.
  • Den Anhang vor das Literaturverzeichnis ziehen, weil die Einreichungsrichtlinien es so verlangen.
  • Ein Präsentationshandout neu aufbauen, nachdem beim Zusammenführen mehrerer Foliensätze die Abschnitte verschachtelt wurden.
  • Eine 40-seitige Bewerbungsmappe visuell durchsehen und Doubletten vor der Einreichung entfernen.
  • Portfolioseiten so umsortieren, dass Ihre stärksten Arbeiten bei jedem Pitch zuerst kommen.

Tips for the best results

  • Erledigen Sie Drehen, Umsortieren und Löschen in einer Sitzung — ein einziger Export schlägt drei separate Werkzeugdurchläufe.
  • Die Drehung wirkt seitenweise, Sie können also einen schiefen Scan korrigieren, ohne das gesamte Dokument zu kippen.
  • Zum Löschen markierte Seiten sind erst nach dem Export wirklich weg — behandeln Sie die Markierungen als Vorauswahl, die Sie jederzeit ändern können.
  • Miniaturansichten sind klein; wenn sich zwei Seiten ähneln, zoomen Sie hinein oder öffnen Sie das Original daneben, um sicher die richtige zu verschieben.
  • Drehen Sie am Smartphone das Gerät ins Querformat, dann passt beim Ziehen mehr von der Übersicht auf den Bildschirm.

Häufig gestellte Fragen

Wie ordne ich PDF-Seiten ohne Acrobat neu?

Laden Sie Ihre Datei in das Organisieren-Werkzeug von PDFora, ziehen Sie die Seitenminiaturen in die gewünschte Reihenfolge und exportieren Sie. Das funktioniert in jedem modernen Browser, kostenlos und ohne Software-Installation.

Kann ich nur eine einzelne Seite drehen statt des ganzen PDFs?

Ja. Jede Miniatur hat ein eigenes Drehsymbol, Sie können also einen einzelnen quer liegenden Scan aufrichten, während alle anderen Seiten unverändert bleiben.

Kann ich Seiten löschen und gleichzeitig umsortieren?

Ja. Markieren Sie Seiten zum Löschen, ziehen Sie die übrigen an ihren Platz, drehen Sie Schiefes gerade — alle Änderungen werden gemeinsam in einem exportierten PDF umgesetzt.

Wird mein Dokument während des Organisierens hochgeladen?

Nein. Die Miniaturansichten werden von Ihrem eigenen Browser gezeichnet, und das bearbeitete PDF wird lokal zusammengesetzt — die Datei verlässt Ihr Gerät zu keinem Zeitpunkt.

Warum dauert es bei großen Dateien, bis die Miniaturen erscheinen?

Ihr Browser zeichnet für jede Seite eine Vorschau, und ein langes oder bildlastiges PDF bedeutet schlicht mehr Arbeit. Das Tempo hängt von Ihrem Gerät ab, nicht von einem Server — und sobald die Übersicht steht, reagiert das Ziehen ohne Verzögerung.

Verändert der Export die Qualität meiner Seiten?

Nein. Umsortieren, Drehen und Löschen sind strukturelle Änderungen; der Seiteninhalt selbst wird nicht neu komprimiert, Text und Bilder kommen also genau so heraus, wie sie hineingegangen sind.

Nach Text teilen

Beginnen Sie immer dann ein neues PDF, wenn eine Seite ein von Ihnen gewähltes Stichwort enthält — ideal zum Trennen von Auszügen oder Rechnungen.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Stapelweise zu scannen ist effizient — bis zu dem Moment, in dem Sie die Dokumente wieder einzeln brauchen. Schicken Sie 40 Rechnungen durch den Scanner, erhalten Sie ein einziges langes PDF ohne erkennbare Nahtstellen. Das Werkzeug „Nach Text teilen" von PDFora findet diese Nahtstellen für Sie: Wählen Sie ein Stichwort wie „Rechnung", und jede Seite, die es enthält, wird zur ersten Seite einer neuen Datei. Ein Durchgang, und aus dem Stapel sind wieder 40 einzelne Dokumente geworden.

Da die Textsuche lokal in Ihrem Browser läuft, werden die Rechnungen, Gehaltsabrechnungen oder Mandantenauszüge, die Sie trennen, nirgendwohin hochgeladen. Das ist ein echter Unterschied zu serverbasierten Werkzeugen, bei denen Finanzunterlagen während der Verarbeitung auf einem fremden Rechner liegen. PDFora ist kostenlos, verlangt keine Anmeldung, setzt keine Wasserzeichen und begrenzt weder die Zahl der Dateien noch der Trennstellen.

Eine Option zur Groß- und Kleinschreibung sorgt dafür, dass „RECHNUNG", „Rechnung" und „rechnung" dieselbe Trennung auslösen — praktisch, wenn Dokumente von verschiedenen Anbietern mit unterschiedlichen Vorlagen stammen. Wählen Sie ein Wort, das zuverlässig auf der ersten Seite jedes Dokuments steht und sonst nirgends.

So teilen Sie ein PDF online nach Stichwort

  1. Öffnen Sie das Werkzeug „Nach Text teilen" auf getpdfora.com. Ihre Datei wird vollständig im Browser verarbeitet.
  2. Fügen Sie das zusammengefasste PDF hinzu, zum Beispiel einen eingescannten Stapel Rechnungen oder Auszüge.
  3. Geben Sie das Stichwort ein, das den Beginn jedes Dokuments markiert, etwa „Rechnung" oder „Kontoauszug".
  4. Schalten Sie die Option zum Ignorieren der Groß- und Kleinschreibung ein, wenn die Schreibweise zwischen den Dokumenten schwankt.
  5. Klicken Sie auf „Teilen". An jeder Seite, auf der das Stichwort vorkommt, beginnt eine neue Datei.
  6. Prüfen Sie, ob die Anzahl der Ausgabedateien der erwarteten Dokumentenzahl entspricht, und laden Sie sie dann herunter.

When to use this tool

  • Einen eingescannten Stapel Lieferantenrechnungen mit dem Wort „Rechnung" als Trennmarke in je eine Datei pro Rechnung zerlegen.
  • Einen Lohnlauf in einzelne Gehaltsabrechnungen aufteilen, indem an „Personalnummer" getrennt wird, damit jede Person nur ihre eigenen Seiten erhält.
  • Ein ganzes Jahr zusammengefasster Kontoauszüge für einen Kreditantrag an der Formulierung „Auszugszeitraum" auseinandernehmen.
  • Ein als einzelnes PDF exportiertes Bündel Bestellungen am Text „Bestellnummer" aufteilen.
  • Einen Versicherungsstapel an „Versicherungsnummer" trennen, damit die Police jedes Kunden gesondert abgelegt werden kann.
  • Eine zusammengeführte Datei mit Versandetiketten vor dem Druck an „Sendungsverfolgung" zerschneiden, um die Etiketten einzeln auszugeben.

Tips for the best results

  • Das Stichwort muss als durchsuchbarer Text vorliegen. Ist Ihr PDF ein reiner Bildscan ohne OCR-Ebene, lassen Sie zuerst OCR laufen, sonst findet die Suche nichts.
  • Wählen Sie eine Formulierung, die nur auf ersten Seiten vorkommt. „Rechnung" funktioniert, wenn es allein die Überschrift jedes Dokuments bildet; taucht es auch in Fußzeilen auf, teilen Sie besser an etwas wie „Rechnungsnummer:".
  • Eine Wortgruppe ist oft sicherer als ein Einzelwort; „Steuerrechnung" führt zu weniger Fehltreffern als „Steuer" allein.
  • Testen Sie an einer kleinen Stichprobe, bevor Sie einen Stapel mit 500 Seiten verarbeiten, und gleichen Sie die Zahl der Ausgabedateien mit der Zahl der gescannten Dokumente ab.
  • Erhalten Sie eine Datei zu viel, steht das Stichwort vermutlich auf der allerersten Seite — das ist zu erwarten; kommen darüber hinaus weitere hinzu, trifft Ihr Stichwort auch Seiten mitten im Dokument.

Häufig gestellte Fragen

Wie funktioniert das Teilen eines PDF nach Text?

Das Werkzeug liest die Textebene jeder Seite und beginnt jedes Mal eine neue Ausgabedatei, wenn eine Seite Ihr Stichwort enthält. Die Seiten zwischen zwei Treffern bleiben zusammen, jede Ausgabedatei enthält also ein vollständiges Dokument — von der Stichwortseite bis zur Seite vor dem nächsten Treffer.

Warum wird mein Stichwort nicht gefunden?

In neun von zehn Fällen ist das PDF ein eingescanntes Bild ohne markierbaren Text. Versuchen Sie, im PDF-Betrachter Text zu markieren; lässt sich kein Wort hervorheben, schicken Sie die Datei zuerst durch OCR und teilen Sie sie anschließend.

Spielt die Option zur Groß- und Kleinschreibung eine Rolle?

Häufig ja. Anbietervorlagen sind sich bei der Schreibweise selten einig, „RECHNUNG" auf dem einen und „Rechnung" auf dem anderen Dokument würden sonst zu uneinheitlichen Trennungen führen. Lassen Sie die Option eingeschaltet, sofern Sie nicht ausdrücklich exakt auf die Schreibweise achten müssen.

Sind meine Finanzunterlagen bei diesem Werkzeug sicher?

Ja, denn sie verlassen Ihr Gerät nie. Sowohl die Suche als auch das Teilen laufen lokal in Ihrem Browser — ohne Upload, ohne Speicherung auf einem Server und ohne Konto, das mit Ihren Dateien verknüpft wäre.

Kann ich an einer mehrteiligen Wortgruppe teilen?

Ja, Formulierungen wie „Kontoauszug für den Zeitraum" funktionieren und sind meist treffsicherer als Einzelwörter. Je länger und spezifischer die Wortgruppe, desto geringer die Gefahr versehentlicher Trennungen auf Seiten, die den Begriff nur beiläufig erwähnen.

Gibt es eine Grenze für Dateigröße oder Anzahl der Trennungen?

Nein. PDFora ist kostenlos und ohne Anmeldung nutzbar, setzt keine Wasserzeichen und begrenzt weder Seiten noch Ausgabedateien noch die Zahl der verarbeiteten Stapel. Sehr große Dateien dauern schlicht länger, weil Ihr eigener Computer die Arbeit übernimmt.

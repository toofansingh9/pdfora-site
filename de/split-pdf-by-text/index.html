Nach Text teilen

Beginnen Sie jedes Mal ein neues PDF, wenn eine Seite ein bestimmtes Wort oder eine Wortgruppe enthält – so sortiert sich ein Dokumentenstapel von selbst.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Seiten zu zählen funktioniert, wenn alle Dokumente in einem Stapel gleich lang sind. Echte Stapel sind das selten. Ein Monat Lieferantenrechnungen, exportiert als ein PDF, enthält vielleicht eine einseitige Rechnung, dann eine dreiseitige, dann zwei einzelne Seiten. Gemeinsam haben sie aber ein Wort, das oben auf jedem neuen Dokument steht: Rechnung, Kontoauszug, Sehr geehrte, Aktenzeichen. „Nach Text teilen“ nutzt dieses Wort als Schnittmarke. Die richtige Marke zu finden, ist der größte Teil der Arbeit; das Schneiden selbst läuft automatisch.

Das Tool liest mit PDF.js die Textebene jeder Seite. Sobald eine Seite Ihren Suchtext enthält, wird die aktuelle Gruppe abgeschlossen und mit dieser Seite eine neue Datei begonnen. Alles bis zum nächsten Treffer gehört in dieselbe Datei. Die erste Seite eröffnet immer die erste Datei, auch wenn sie den Text nicht enthält. Anschließend werden die Seiten mit pdf-lib unverändert in nummerierte Ausgaben kopiert: Aus stapel.pdf werden stapel-1.pdf, stapel-2.pdf und so weiter, in stapel-bytext.zip.

Die entscheidende Voraussetzung: Der Text muss tatsächlich als Text vorhanden sein. Ein PDF aus einer Buchhaltungssoftware, einer Textverarbeitung oder einem Browser hat eine Textebene. Ein PDF vom Scanner oder aus der Handykamera enthält meist nur Bilder von Text – darin findet das Tool nichts, bis Sie eine OCR durchgeführt haben.

So teilen Sie ein PDF überall dort, wo ein Wort vorkommt

  1. Öffnen Sie „Nach Text teilen“ und fügen Sie das PDF hinzu.
  2. Tippen Sie den Markierungstext ein. Wählen Sie etwas, das einmal auf der ersten Seite jedes Dokuments steht und sonst nirgends, also eher „Rechnungsnummer“ als nur „Rechnung“.
  3. Lassen Sie „Groß-/Kleinschreibung ignorieren“ angehakt, es sei denn, gerade die Schreibweise unterscheidet die Marke (etwa „KONTOAUSZUG“ in einer Überschrift gegenüber „Kontoauszug“ im Fließtext).
  4. Klicken Sie auf „Nach Text teilen“. Jede Seite wird gelesen, bevor geschnitten wird.
  5. Laden Sie die Teile herunter und prüfen Sie stichprobenartig, ob jeder dort beginnt, wo ein neues Dokument anfängt. Die Zahl der Dateien sollte der Zahl der Dokumente im Stapel entsprechen.

Wann Sie dieses Tool nutzen sollten

  • Einen Sammelexport von Rechnungen oder Belegen in eine Datei pro Rechnung für den Upload in die Buchhaltung aufteilen.
  • Zusammengefasste Kontoauszüge oder Nebenkostenabrechnungen in einzelne Monate zerlegen.
  • Einen Stapel erzeugter Serienbriefe (die alle mit „Sehr geehrte“ beginnen) in einen Brief pro Empfänger aufteilen. Die Anrede funktioniert als Marke, wenn jeder Brief auf einer neuen Seite beginnt.
  • Gehaltsabrechnungen, die als ein langer Lauf erzeugt wurden, in eine Datei pro Mitarbeiter aufteilen.
  • Klausuren oder Antwortbögen trennen, die jeweils mit einer Überschrift wie „Prüfungsnummer“ beginnen.
  • Gerichtsakten oder Fallunterlagen zerlegen, bei denen jede Anlage mit einer festen Bezeichnung wie „Anlage“ beginnt.

Das sollten Sie vorher wissen

  • Geprüft wird, ob die Marke irgendwo auf der Seite vorkommt – in Kopfzeile, Fließtext oder Fußzeile. Steht Ihr Wort auch in Fußzeilen oder im laufenden Text, gibt es auf jeder solchen Seite einen Schnitt. Wählen Sie eine Wendung, die nur am Anfang jedes Dokuments steht.
  • Gescannte Seiten haben keine Textebene, nichts passt, und Sie sehen „Dieser Text ergibt 0 oder 1 Teilungspunkte – nichts zu teilen.“ Lassen Sie zuerst „OCR-PDF“ laufen und teilen Sie dann die OCR-Ausgabe.
  • Der Text wird aus Fragmenten zusammengesetzt, die durch Leerzeichen getrennt sind. Die meisten Wendungen werden normal gefunden, aber ein Wort, das im PDF in Stücken gespeichert ist (manchmal bei gesperrt gesetzten Überschriften), wird eventuell nicht erkannt; versuchen Sie dann eine kürzere Marke oder ein anderes Wort. Zeilenumbrüche innerhalb einer Wendung werden durch ein Leerzeichen ersetzt, eine zweiteilige Marke über zwei Zeilen passt also meist trotzdem.
  • Es gibt nur einfache Teilstring-Suche: keine Platzhalter, keine regulären Ausdrücke, keine Option „nur ganze Wörter“. „Rechnung“ passt also auch zu „Rechnungen“ und „Proforma-Rechnung“.
  • Das Tool braucht mindestens zwei Gruppen. Wird die Marke nur auf Seite 1 oder gar nicht gefunden, bricht es mit einer Fehlermeldung ab, statt eine einzige, mit dem Original identische Datei zu erzeugen.
  • Die Ausgaben behalten den Seiteninhalt, aber keine Lesezeichen, und Links zwischen Seiten, die in verschiedenen Dateien landen, funktionieren nicht mehr.

Tipps für beste Ergebnisse

  • Öffnen Sie das PDF vorher im Viewer und suchen Sie dort nach der Marke. Die Zahl der Treffer auf ersten Seiten sollte der Zahl der erwarteten Dokumente entsprechen. Weichen die Zahlen ab, ändern Sie die Marke vor dem Teilen, statt hinterher die Teile zu reparieren.
  • Bevorzugen Sie Bezeichnungen mit Doppelpunkt oder Nummer in der Nähe, etwa „Rechnungs-Nr.“ oder „Kontoübersicht“; die kommen meist nur einmal pro Dokument vor.
  • Sind die ersten Seiten ein Deckblatt ohne Marke, werden sie zu Datei 1. Löschen Sie sie vorher oder verwerfen Sie diesen Teil einfach. Dasselbe gilt für eine abschließende Übersichtsseite.
  • Stapel aus einem einzigen System verwenden meist identische Formulierungen. Stammen einige Dokumente aus einem anderen System, prüfen Sie diese gesondert.
  • Benennen Sie die Dateien nach dem Teilen anhand der Rechnungs- oder Kundennummer auf ihrer ersten Seite um.

Praxisbeispiel: die Jahresabrechnungen eines Vermieters

Ein Vermieter mit vier Wohnungen in Leipzig lädt ein Jahr Wasser- und Stromabrechnungen aus dem Kundenportal seines Versorgers herunter. Das Portal bietet nur einen Export an: ein einziges 61-seitiges PDF, in dem jede Abrechnung ein bis drei Seiten lang ist, je nachdem, wie viele Zählerstände sie aufführt. Sein Steuerberater möchte eine Datei pro Abrechnung.

Jede Abrechnung beginnt mit der Überschrift „Ihre Abrechnung“, die in keiner Fußzeile vorkommt. Mit dieser Wendung findet das Tool 24 Treffer und liefert 24 Dateien. Vorher hat er das PDF im Viewer geöffnet und nach der Wendung gesucht: 24 Treffer, passend zu zwei Versorgern mal zwölf Monaten – die Zahl stimmt also schon, bevor überhaupt geteilt wird.

Nur nach „Kunden“ zu suchen, wäre ein Fehler gewesen: Das Wort steht in jeder Fußzeile („Kundennummer“) und hätte 61 einseitige Dateien erzeugt. Eine kurze Suche im Viewer vor dem Teilen ist die billigste Kontrolle, die es gibt.

Fehlerbehebung

Fehler: „Dieser Text ergibt 0 oder 1 Teilungspunkte – nichts zu teilen.“
Der Text wurde auf keiner Seite nach der ersten gefunden. Prüfen Sie die Schreibweise, versuchen Sie eine kürzere Wendung und stellen Sie sicher, dass das PDF markierbaren Text hat. Lässt sich im Viewer kein Text markieren, lassen Sie zuerst „OCR-PDF“ laufen.
Ich habe eine Datei pro Seite bekommen
Ihre Marke kommt auf jeder Seite vor, oft in Kopf- oder Fußzeile. Wählen Sie eine Wendung, die nur am Anfang jedes Dokuments steht.
Einige Dokumente wurden nicht getrennt
Diese Seiten enthalten die Marke nicht exakt – etwa wegen anderer Formulierung, einer gescannten Seite im Stapel oder eines in Fragmenten gespeicherten Wortes. Teilen Sie die übrig gebliebene Datei mit einer anderen Marke noch einmal.
Fehler: „Geben Sie einen Text zum Teilen ein.“
Das Textfeld ist leer oder enthält nur Leerzeichen. Tippen Sie die Marke ein und starten Sie erneut.
Das Teilen bricht bei einer passwortgeschützten Datei ab
Verschlüsselte PDFs lassen sich nicht zuverlässig lesen. Entfernen Sie das Passwort in der Anwendung, mit der die Datei erstellt wurde, und versuchen Sie es erneut.
Seiten mit OCR werden an seltsamen Stellen geteilt
Die OCR kann Wörter falsch erkennen, sodass die Marke auf manchen Seiten fehlt. Verwenden Sie eine kurze Marke aus klar gedruckten Buchstaben und prüfen Sie die Ergebnisse.

Häufig gestellte Fragen

Landet die Seite mit der Marke in der neuen oder in der vorherigen Datei?

In der neuen. Die Trefferseite ist immer die erste Seite des nächsten Teils.

Wird zwischen Groß- und Kleinschreibung unterschieden?

Nur wenn Sie das Häkchen bei „Groß-/Kleinschreibung ignorieren“ entfernen. Standardmäßig ist es gesetzt.

Kann ich mehrere Marken gleichzeitig verwenden?

Nein, eine Marke pro Durchgang. Teilen Sie nach der ersten Marke und bei Bedarf einzelne Teile erneut nach einer zweiten.

Funktioniert das bei gescannten PDFs?

Erst nach einer OCR. Ein Scan ohne Textebene bietet dem Tool nichts zum Vergleichen. „OCR-PDF“ fügt eine unsichtbare Textebene hinzu, die dieses Tool dann lesen kann.

Werden die Seiten irgendwie verändert?

Nein. Der Text wird nur gelesen, um die Schnittstellen festzulegen; die Seiten werden anschließend unverändert kopiert.

Wie heißen die Ausgabedateien?

Wie das Original plus eine laufende Nummer, zum Beispiel stapel-1.pdf, in stapel-bytext.zip.

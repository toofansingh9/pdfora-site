PDF in Text

Ziehen Sie den gesamten markierbaren Text aus einem PDF in eine .txt-Datei.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Extrahieren Sie Text aus PDF-Dateien und speichern Sie ihn als einfaches .txt-Dokument, das sich überall öffnen lässt. Wer im PDF-Betrachter von Hand kopiert, zerschießt regelmäßig Zeilenumbrüche, verliert Zeichen und braucht bei langen Dokumenten eine Ewigkeit. Dieses Werkzeug holt jede Zeile markierbaren Textes von jeder Seite in einem einzigen Durchgang heraus und übergibt Ihnen eine saubere Datei — kostenlos, ohne Anmeldung und ohne Begrenzung der Dokumentlänge.

Die Extraktion läuft lokal in Ihrem Browser. Das PDF wird auf Ihrem eigenen Gerät ausgewertet, ein Vertrag, eine Abschlussarbeit oder ein Finanzbericht wandert also nicht auf einen Server, bloß um an die Wörter darin zu kommen. Dieses rein lokale Vorgehen macht das Ganze zudem schnell: Es gibt keine Wartezeit für einen Upload, selbst bei Dateien mit Hunderten von Seiten. Sobald Sie den Tab schließen, bleibt nirgendwo etwas von Ihrem Dokument zurück.

Eine Einschränkung sei ehrlich genannt: Dieses Werkzeug liest die Textebene im PDF aus. Eingescannte Dokumente und abfotografierte Seiten sind reine Bilder und besitzen keine Textebene, das Ergebnis wäre also leer. Nutzen Sie in solchen Fällen stattdessen das OCR-Werkzeug, das die Zeichen im Bild erkennt und daraus echten Text macht.

So extrahieren Sie online Text aus einem PDF

  1. Öffnen Sie das PDF-zu-Text-Werkzeug und ziehen Sie Ihr PDF auf die Seite oder wählen Sie es auf Ihrem Gerät aus.
  2. Die Datei wird direkt in Ihrem Browser ausgewertet; dabei wird nichts hochgeladen.
  3. Kurze Probe: Wenn Sie in einem normalen PDF-Betrachter Text markieren und kopieren können, funktioniert auch die Extraktion. Bestehen die Seiten aus Scans, wechseln Sie zum OCR-Werkzeug.
  4. Klicken Sie auf „Extrahieren", um den Text aller Seiten der Reihe nach herauszuholen.
  5. Laden Sie die erzeugte .txt-Datei herunter.
  6. Öffnen Sie sie in einem beliebigen Texteditor und räumen Sie Abstände oder Zeilenumbrüche auf, falls Ihr nächster Arbeitsschritt sauberen Text verlangt.

When to use this tool

  • Den vollständigen Text eines Fachaufsatzes in eine .txt-Datei holen, um ihn in der eigenen Notiz-App zu durchsuchen, zu zitieren und zu kommentieren.
  • Den Wortlaut eines Vertrags extrahieren, um zwei Fassungen im Vergleichswerkzeug Zeile für Zeile gegenüberzustellen, statt PDFs nebeneinander abzugleichen.
  • Ein E-Book oder einen Bericht als reinen Text bereitstellen, für einen Screenreader oder eine Vorlese-App auf dem langen Arbeitsweg.
  • Den Text eines langen Dokuments an ein Übersetzungswerkzeug oder eine KI-Zusammenfassung übergeben, die reinen Text annimmt, aber keine PDF-Uploads.
  • Den Text aus einem alten PDF zurückgewinnen, wenn die ursprüngliche Word-Datei längst verschwunden ist und Sie wieder daran arbeiten müssen.
  • Produktbeschreibungen oder technische Angaben aus dem PDF-Katalog eines Lieferanten übernehmen, um sie in einen Shop-Eintrag einzufügen.

Tips for the best results

  • Prüfen Sie das PDF zuerst: Öffnen Sie es und versuchen Sie, einen Satz zu markieren. Wird nichts hervorgehoben, handelt es sich um einen Scan — dann brauchen Sie OCR statt Textextraktion.
  • Bei mehrspaltigen Layouts, etwa in wissenschaftlichen Aufsätzen, kann die Lesereihenfolge zwischen den Spalten hin und her springen. Überfliegen Sie das Ergebnis, bevor Sie sich darauf verlassen.
  • Kopf- und Fußzeilen sowie Seitenzahlen kommen zusammen mit dem Fließtext mit. Mit „Suchen und Ersetzen" in Ihrem Editor sind wiederkehrende Elemente schnell entfernt.
  • Reines .txt verwirft jede Formatierung — so ist es gedacht. Behalten Sie das ursprüngliche PDF, falls Sie Fettungen, Tabellen oder das Layout je wieder brauchen.
  • Suchen Sie bei sehr langen Dokumenten in der .txt-Ausgabe nach einer Formulierung, von der Sie wissen, dass sie gegen Ende steht — so bestätigen Sie im Handumdrehen, dass alle Seiten erfasst wurden.

Häufig gestellte Fragen

Warum hat mein PDF eine leere Textdatei ergeben?

Mit ziemlicher Sicherheit handelt es sich um einen Scan oder ein Foto, das Bilder von Wörtern statt echten Text enthält. Schicken Sie es durch das OCR-Werkzeug, das Zeichen in Bildern erkennt und daraus bearbeitbaren Text erzeugt.

Wird mein Dokument bei der Extraktion hochgeladen?

Nein. Das PDF wird vollständig in Ihrem Browser auf Ihrem Gerät gelesen. Nichts wird übertragen, gespeichert oder auf einem Server protokolliert — genau das, was man sich bei juristischen und finanziellen Unterlagen wünscht.

Bleiben Formatierungen wie Fettdruck, Schriften und Tabellen erhalten?

Nein. Das Ergebnis ist reiner Text, Gestaltung und Layout fallen also weg, und Tabellen werden zu einfachen Zeilen. Genau dieser Kompromiss macht .txt universell verwendbar und leicht weiterzuverarbeiten.

Kann ich Text aus einem sehr großen PDF extrahieren?

Ja. Es gibt keine Seitenobergrenze, und da kein Upload nötig ist, sind selbst Dokumente mit 500 Seiten rasch verarbeitet. Die einzige praktische Grenze ist der Arbeitsspeicher Ihres Geräts.

Kommt der Text in der richtigen Reihenfolge heraus?

Bei üblichen einspaltigen Dokumenten ja, Seite für Seite. Komplexe Layouts mit Spalten, Randleisten oder Textkästen können in einer anderen Reihenfolge ausgelesen werden, als das Auge sie liest — solche Dateien sollten Sie kurz durchsehen.

Ist das wirklich kostenlos und ohne Konto?

Ja. Keine Anmeldung, nirgends ein Wasserzeichen und keine Begrenzung, wie viele PDFs Sie in Text umwandeln. Es funktioniert in jedem modernen Browser, am Rechner wie auf dem Mobilgerät.

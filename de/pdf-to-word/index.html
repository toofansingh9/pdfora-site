PDF in Word

Wandeln Sie ein PDF in eine bearbeitbare Word-Datei (.docx) um, damit Sie den Text ändern können, statt ihn neu abzutippen.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Ein PDF ist dafür gemacht, eine Seite genau so zu zeigen, wie sie gesetzt wurde – nicht dafür, sie zu bearbeiten. Jede Textzeile sitzt an festen Koordinaten, echte Absätze gibt es meist nicht, und eine Tabelle besteht oft nur aus Linien neben lose platzierten Wörtern. Um daraus wieder ein Word-Dokument zu machen, muss ein Konverter erraten, wo Absätze beginnen und enden, welche Textstücke zur selben Spalte gehören und welche Linien eine Tabelle bilden. Meistens liegt er richtig. Manchmal nicht – und wer weiß, warum, erspart sich viel Ärger.

Das Tool PDF in Word von PDFora überlässt diesen Nachbau einer Konvertierungs-Engine auf einem Server, denn dafür braucht es Layoutanalyse und Schriftverarbeitung, mit denen ein Browser-Tab nicht mithalten kann. Sie wählen ein PDF, es wird über eine verschlüsselte Verbindung an den Konvertierungsdienst hochgeladen (CloudConvert, erreicht über unser eigenes kleines Relay), in .docx umgewandelt, und die fertige Datei kommt als Download zurück. Der Upload wird nach dem Auftrag beim Dienst gelöscht. Trotzdem gehört dieses Tool zu der Art Werkzeug auf der Website, bei der Ihre Datei Ihren Rechner tatsächlich verlässt – nutzen Sie es also nicht für Dokumente, die Sie nicht an Dritte weitergeben dürfen.

Sie erhalten eine ganz normale .docx-Datei, die sich in Microsoft Word, LibreOffice Writer, Google Docs oder Pages öffnen lässt. Einstellungen gibt es keine: Das Tool wandelt das ganze Dokument, jede Seite, in einem Durchgang um. Ihre Aufgabe danach ist die Kontrolle, denn ein umgewandeltes Dokument ist ein sehr guter erster Entwurf des Originals, keine garantierte Kopie.

So wandeln Sie ein PDF in Word um

  1. Öffnen Sie PDF in Word und wählen Sie ein einzelnes PDF aus. Das Tool nimmt eine Datei pro Auftrag; mehrere Dateien wandeln Sie nacheinander um.
  2. Klicken Sie auf „Konvertieren“. Die Statuszeile zeigt nacheinander „Wird vorbereitet…“, „Wird hochgeladen…“, „Wird konvertiert…“ und „Wird heruntergeladen…“.
  3. Warten Sie, während der Server arbeitet. Kurze Textdokumente sind meist schnell fertig; lange oder bildlastige Dateien dauern länger, und nach etwa drei Minuten Wartezeit gibt das Tool auf.
  4. Speichern Sie die .docx-Datei. Sie behält normalerweise Ihren ursprünglichen Dateinamen mit der neuen Endung, aus bericht.pdf wird also bericht.docx.
  5. Öffnen Sie sie in Ihrem Textprogramm und vergleichen Sie sie Seite für Seite mit dem PDF, bevor Sie bearbeiten – besonders Tabellen, Kopfzeilen und Fußnoten.

Wann Sie dieses Tool nutzen sollten

  • Einen alten Vertrag oder eine Richtlinie aktualisieren, wenn nur das unterschriebene PDF übrig ist und die Word-Datei verloren ging.
  • Eine Lehrerin nutzt ein Arbeitsblatt weiter, das eine Kollegin als PDF geteilt hat, und ändert die Aufgaben für eine neue Klasse.
  • Übersetzerinnen und Übersetzer, die den Ausgangstext in einem bearbeitbaren Format brauchen, das ihre Übersetzungstools lesen können.
  • Mehrere Absätze aus einem veröffentlichten Bericht in das eigene Dokument übernehmen – ohne Abtippen und ohne die Zeilenumbrüche, die beim Kopieren entstehen.
  • Einen Tippfehler in einem Lebenslauf oder einer Broschüre korrigieren, wenn die Grafikerin, die sie gestaltet hat, nicht mehr erreichbar ist.
  • Aus einem PDF-Serienbrief wieder eine Vorlage für den Seriendruck machen.

Das sollten Sie vorher wissen

  • Die Umwandlung findet auf einem Server statt, nicht in Ihrem Browser. Das PDF wird verschlüsselt hochgeladen, umgewandelt und nach Abschluss des Auftrags beim Konvertierungsdienst gelöscht.
  • Gescannte Seiten haben keine Textebene, nur ein Bild von Text. Ohne Textebene gibt es nichts, was sich in bearbeitbare Wörter verwandeln ließe – ein Scan kommt daher meist als Bild im Dokument an. Brauchen Sie bearbeitbaren Text aus einem Scan, schicken Sie die Datei zuerst durch das OCR-Tool von PDFora.
  • Das Layout wird nachgebaut, nicht kopiert. Mehrspaltige Seiten, Textfelder, Randspalten und hervorgehobene Zitate landen womöglich in schwebenden Textrahmen, und der Zeilenabstand kann sich verschieben, sodass Seitenumbrüche wandern.
  • Schriften, die auf Ihrem Rechner nicht installiert sind, werden beim Öffnen der .docx ersetzt. Das verändert die Zeilenlänge und kann Text auf eine andere Seite schieben.
  • Passwortgeschützte PDFs lassen sich nicht umwandeln. Entfernen Sie den Schutz zuerst im Ursprungsprogramm.
  • Nur ein PDF pro Auftrag, ohne Auswahl von Seitenbereichen. Brauchen Sie von einem 90-seitigen Bericht nur zwei Seiten, extrahieren Sie diese vorher – der Auftrag geht schneller, und das Ergebnis ist leichter zu prüfen.

Tipps für beste Ergebnisse

  • Versuchen Sie vor der Umwandlung, im PDF-Viewer Text zu markieren. Lassen sich einzelne Wörter nicht markieren, ist die Datei ein Scan und braucht zuerst OCR.
  • Extrahieren Sie mit Seiten extrahieren nur die benötigten Seiten und wandeln Sie diese kleinere Datei um; sie ist schneller hochgeladen und umgewandelt.
  • Schalten Sie in Word sofort die Formatierungszeichen ein (das Absatzzeichen ¶). So sehen Sie harte Zeilenumbrüche und überflüssige Abschnittswechsel, die der Konverter eingefügt hat.
  • Kommt eine Tabelle als tabulatorgetrennter Text an, probieren Sie PDF in Excel für dieselbe Seite; die Tabellenausgabe kommt mit Rastern oft besser zurecht.
  • Lassen Sie beim Bearbeiten das PDF neben der Word-Datei geöffnet, dann fällt Ihnen eine fehlende Zeile oder Fußnote sofort auf.

Beispiel: eine Vermieterin aktualisiert ihren Mietvertrag

Eine private Vermieterin aus Dresden hat einen sechsseitigen Mietvertrag von vor drei Jahren. Die Word-Datei lag auf einem Laptop, der inzwischen kaputt ist; übrig ist nur der unterschriebene PDF-Export der damaligen Hausverwaltung. Der neue Vertrag braucht eine andere Miete, neue Daten und eine zusätzliche Klausel zum Fahrradkeller.

Sie extrahiert die Seiten 1 bis 5 (Seite 6 ist die Unterschriftenseite, die ohnehin neu entsteht) und wandelt diese Datei um. Die .docx öffnet sich mit den Paragrafen als normale Absätze, die nummerierten Überschriften sind intakt. Zwei Dinge müssen repariert werden: Die Mietaufstellung, eine kleine Tabelle, ist zu tabulatorgetrennten Zeilen geworden, und die Fußzeile mit der Adresse der Wohnung ist jetzt ein Textfeld. Sie baut die Tabelle mit Einfügen > Tabelle neu, verschiebt die Adresse in eine echte Fußzeile, nimmt ihre Änderungen vor und speichert mit Word in PDF ein neues PDF.

Das Ganze dauert etwa zwanzig Minuten statt eines Abends voller Tipparbeit. Entscheidend: Die Umwandlung hat rund 90 Prozent der Arbeit erledigt, und die restlichen 10 Prozent waren vorhersehbar. Tabellen sowie Kopf- und Fußzeilen sind die Stellen, an denen umgewandelte Dokumente am häufigsten Handarbeit brauchen.

Fehlerbehebung

Die Word-Datei zeigt jede Seite als ein großes Bild
Das PDF ist gescannt oder wurde aus einem Bild gespeichert. Schicken Sie es durch das OCR-Tool, damit es eine Textebene bekommt, und wandeln Sie die OCR-Kopie um.
Der Text ist da, aber jede Zeile endet mit einem harten Umbruch
Das PDF hat Zeilen statt Absätze gespeichert. Ersetzen Sie in Word mit Suchen und Ersetzen manuelle Zeilenumbrüche (^l) bzw. Absatzmarken innerhalb von Absätzen durch Leerzeichen, Abschnitt für Abschnitt.
Spalten laufen durcheinander oder stecken in seltsamen Textfeldern
Mehrspaltige Layouts sind schwer nachzubauen. Kopieren Sie den Text aus den Feldern in ein neues, einspaltiges Dokument, oder legen Sie das Spaltenlayout in Word selbst an und fügen den Text wieder ein.
Die Umwandlung meldet eine Zeitüberschreitung
Das Tool wartet etwa drei Minuten. Sehr lange oder bildlastige PDFs können das überschreiten. Teilen Sie die Datei mit PDF teilen oder Seiten extrahieren und wandeln Sie die Teile um.
Es heißt, die Konvertierung auf dem Server sei fehlgeschlagen
Das PDF ist höchstwahrscheinlich passwortgeschützt, beschädigt oder gar kein echtes PDF. Prüfen Sie es in einem Viewer, schicken Sie es durch PDF reparieren, falls es sich mit Fehlern öffnet, und versuchen Sie es erneut.
Die Schriften sehen anders aus als im PDF
Die Originalschriften sind auf Ihrem Rechner nicht installiert, Word hat sie also ersetzt. Installieren Sie die Schrift oder markieren Sie den gesamten Text und wählen Sie eine ähnliche Schrift, die Sie haben.

Häufig gestellte Fragen

Sieht die Word-Datei genauso aus wie mein PDF?

Meist sehr ähnlich, selten identisch. Fließtext und Überschriften werden gut umgewandelt; Unterschiede zeigen sich bei Tabellen, Spalten, Textfeldern und exakten Seitenumbrüchen.

Kann das Tool ein gescanntes Dokument in bearbeitbaren Text verwandeln?

Allein nicht. Ein Scan hat keine Textebene – schicken Sie ihn zuerst durch das OCR-Tool und wandeln Sie das Ergebnis um.

Welches Word-Format bekomme ich?

Eine .docx-Datei, die Microsoft Word ab Version 2007, LibreOffice, Google Docs und Apple Pages öffnen.

Kann ich nur einige Seiten umwandeln?

Das Tool wandelt immer die ganze Datei um. Erstellen Sie vorher mit Seiten extrahieren ein PDF mit genau den gewünschten Seiten.

Warum lädt dieses Tool meine Datei hoch, andere aber nicht?

Ein Word-Dokument aus einem PDF nachzubauen, erfordert eine vollwertige Konvertierungs-Engine, und die läuft auf einem Server. Die Datei wird verschlüsselt übertragen und nach der Umwandlung beim Dienst gelöscht.

Kostet das etwas oder muss ich mich anmelden?

Nein. Sie wählen eine Datei und wandeln sie um, ohne ein Konto anzulegen.

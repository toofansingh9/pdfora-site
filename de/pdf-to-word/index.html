PDF in Word

Wandeln Sie ein PDF in eine bearbeitbare Word-Datei (.docx) um, damit Sie den Text ändern können, statt ihn neu abzutippen.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

„Können Sie mir das bitte als Word-Datei schicken?“ – leichter gesagt als getan, wenn nur noch das PDF existiert. Ein PDF soll eine Seite exakt so wiedergeben, wie sie gesetzt wurde; zum Weiterbearbeiten ist es nicht gedacht. Jede Textzeile steht an festen Koordinaten, richtige Absätze gibt es meistens nicht, und eine Tabelle ist häufig nur eine Ansammlung von Linien mit lose daneben gesetzten Wörtern. Wer daraus wieder ein Word-Dokument machen will, muss erschließen, wo ein Absatz anfängt und aufhört, welche Textstücke in dieselbe Spalte gehören und welche Linien zusammen eine Tabelle ergeben. Meist gelingt das gut. Wenn nicht, hilft es sehr zu wissen, woran es liegt.

„PDF in Word“ überlässt diesen Nachbau einer Konvertierungs-Engine auf einem Server. Für eine ordentliche Umwandlung braucht es Layoutanalyse und Schriftbehandlung, die ein Browser-Tab nicht leisten kann. Sie wählen ein PDF aus, es geht über eine verschlüsselte Verbindung an den Konvertierungsdienst CloudConvert (über unser eigenes kleines Relay), wird dort in .docx umgewandelt und kommt als Download zurück. Nach dem Auftrag wird die hochgeladene Datei beim Dienst gelöscht. Trotzdem ist das eines der Tools auf dieser Website, bei denen Ihre Datei Ihren Rechner tatsächlich verlässt. Dokumente, die Sie nicht an Dritte weitergeben dürfen, gehören deshalb nicht hierher.

Zurück bekommen Sie eine gewöhnliche .docx-Datei, die Microsoft Word, LibreOffice Writer, Google Docs und Pages öffnen. Einstellungen gibt es keine; umgewandelt wird immer das ganze Dokument mit allen Seiten in einem Durchgang. Danach ist Kontrolle angesagt, denn das Ergebnis ist ein sehr guter erster Entwurf des Originals, aber keine garantierte Eins-zu-eins-Kopie.

So wandeln Sie ein PDF in Word um

  1. Öffnen Sie PDF in Word und wählen Sie ein einzelnes PDF aus. Das Tool nimmt eine Datei pro Auftrag; mehrere Dateien wandeln Sie nacheinander um.
  2. Klicken Sie auf „Konvertieren“. Die Statuszeile zeigt nacheinander „Wird vorbereitet…“, „Wird hochgeladen…“, „Wird konvertiert…“ und „Wird heruntergeladen…“.
  3. Warten Sie, während der Server arbeitet. Kurze Textdokumente sind meist schnell fertig; lange oder bildlastige Dateien dauern länger, und nach etwa drei Minuten Wartezeit gibt das Tool auf.
  4. Speichern Sie die .docx-Datei. Sie behält normalerweise Ihren ursprünglichen Dateinamen mit der neuen Endung, aus bericht.pdf wird also bericht.docx.
  5. Öffnen Sie sie in Ihrem Textprogramm und vergleichen Sie sie Seite für Seite mit dem PDF, bevor Sie bearbeiten – besonders Tabellen, Kopfzeilen und Fußnoten.

Wann Sie dieses Tool nutzen sollten

  • Den eigenen Lebenslauf aktualisieren, wenn nur noch das PDF aus der letzten Bewerbung da ist und die Word-Datei fehlt.
  • Die Satzung oder Geschäftsordnung eines Vereins nach einem Beschluss der Mitgliederversammlung anpassen, wenn nur die PDF-Fassung existiert.
  • Einen Musterbrief, den es nur als PDF gibt – etwa eine Vorlage für eine Kündigung oder einen Widerspruch –, an die eigene Situation anpassen.
  • Als Lehrkraft ein Arbeitsblatt, das eine Kollegin als PDF geteilt hat, mit neuen Aufgaben für die eigene Klasse weiterverwenden.
  • Als Übersetzerin den Ausgangstext in einem Format erhalten, das das eigene Übersetzungsprogramm einlesen kann.
  • Aus einem als PDF gespeicherten Serienbrief wieder eine Vorlage für den Seriendruck machen.

Das sollten Sie vorher wissen

  • Die Umwandlung findet auf einem Server statt, nicht in Ihrem Browser. Das PDF wird verschlüsselt hochgeladen, umgewandelt und nach Abschluss des Auftrags beim Konvertierungsdienst gelöscht.
  • Gescannte Seiten haben keine Textebene, nur ein Bild von Text. Ohne Textebene gibt es nichts, was sich in bearbeitbare Wörter verwandeln ließe – ein Scan kommt daher meist als Bild im Dokument an. Brauchen Sie bearbeitbaren Text aus einem Scan, schicken Sie ihn zuerst durch „OCR-PDF“: Das durchsuchbare PDF gibt dem Konverter echten Text, auch wenn das Layout danach Nacharbeit brauchen kann. Einfacher ist der Umweg über die .txt-Ausgabe.
  • Das Layout wird nachgebaut, nicht kopiert. Mehrspaltige Seiten, Textfelder, Randspalten und hervorgehobene Zitate landen womöglich in schwebenden Textrahmen, und der Zeilenabstand kann sich verschieben, sodass Seitenumbrüche wandern.
  • Schriften, die auf Ihrem Rechner nicht installiert sind, werden beim Öffnen der .docx ersetzt. Das verändert die Zeilenlänge und kann Text auf eine andere Seite schieben.
  • Passwortgeschützte PDFs lassen sich nicht umwandeln. Entfernen Sie den Schutz zuerst mit „PDF entsperren“ oder im Ursprungsprogramm.
  • Nur ein PDF pro Auftrag, ohne Auswahl von Seitenbereichen. Brauchen Sie von einem 90-seitigen Bericht nur zwei Seiten, extrahieren Sie diese vorher – der Auftrag geht schneller, und das Ergebnis ist leichter zu prüfen.

Tipps für beste Ergebnisse

  • Versuchen Sie vor der Umwandlung, im PDF-Viewer Text zu markieren. Lassen sich einzelne Wörter nicht markieren, ist die Datei ein Scan; lassen Sie dann zuerst „OCR-PDF“ laufen und wandeln Sie die durchsuchbare Kopie um.
  • Extrahieren Sie mit Seiten extrahieren nur die benötigten Seiten und wandeln Sie diese kleinere Datei um; sie ist schneller hochgeladen und umgewandelt.
  • Schalten Sie in Word sofort die Formatierungszeichen ein (das Absatzzeichen ¶). So sehen Sie harte Zeilenumbrüche und überflüssige Abschnittswechsel, die der Konverter eingefügt hat.
  • Kommt eine Tabelle als tabulatorgetrennter Text an, probieren Sie PDF in Excel für dieselbe Seite; die Tabellenausgabe kommt mit Rastern oft besser zurecht.
  • Lassen Sie beim Bearbeiten das PDF neben der Word-Datei geöffnet, dann fällt Ihnen eine fehlende Zeile oder Fußnote sofort auf.

Beispiel: die Satzung eines Tennisvereins

Die Schriftführerin eines Tennisvereins in Salzburg soll nach der Generalversammlung die Satzung anpassen: Der Paragraf zu den Mitgliedsbeiträgen bekommt eine neue Fassung, und ein Paragraf zur Platzreservierung kommt dazu. Die Satzung hat neun Seiten und liegt nur als PDF vor; wer die Word-Datei vor Jahren erstellt hat, weiß niemand mehr.

Sie wandelt das PDF mit „PDF in Word“ um. Die Paragrafen erscheinen als normale Absätze, die Überschriften mit „§ 1“ bis „§ 14“ sind vollständig. Drei Dinge fallen beim Durchsehen auf: Das Vereinslogo im Kopf ist in einem schwebenden Textrahmen gelandet, die Fußnoten stehen als gewöhnlicher Text am Seitenende, und in mehreren Absätzen endet jede Zeile mit einem harten Umbruch, an manchen Stellen samt Trennstrich wie „Mitglieder- versammlung“. Mit eingeschalteten Formatierungszeichen findet sie diese Stellen schnell und bereinigt sie mit Suchen und Ersetzen.

Nach gut einer halben Stunde ist die neue Fassung fertig und wird als PDF gespeichert. Die Mitgliederliste mit Namen und Adressen, die ebenfalls nur als PDF existiert, wandelt sie bewusst nicht hier um, weil die Datei dafür an einen externen Dienst gehen würde; die tippt sie lieber selbst in eine neue Tabelle.

Fehlerbehebung

Die Word-Datei zeigt jede Seite als ein großes Bild
Das PDF ist gescannt oder wurde aus einem Bild gespeichert. Schicken Sie es zuerst durch „OCR-PDF“ und wandeln Sie die durchsuchbare Kopie um, oder fügen Sie die .txt-Ausgabe in Word ein.
Der Text ist da, aber jede Zeile endet mit einem harten Umbruch
Das PDF hat Zeilen statt Absätze gespeichert. Ersetzen Sie in Word mit Suchen und Ersetzen manuelle Zeilenumbrüche (^l) bzw. Absatzmarken innerhalb von Absätzen durch Leerzeichen, Abschnitt für Abschnitt.
Spalten laufen durcheinander oder stecken in seltsamen Textfeldern
Mehrspaltige Layouts sind schwer nachzubauen. Kopieren Sie den Text aus den Feldern in ein neues, einspaltiges Dokument, oder legen Sie das Spaltenlayout in Word selbst an und fügen den Text wieder ein.
Die Umwandlung meldet eine Zeitüberschreitung
Das Tool wartet etwa drei Minuten. Sehr lange oder bildlastige PDFs können das überschreiten. Teilen Sie die Datei mit PDF teilen oder Seiten extrahieren und wandeln Sie die Teile um.
Es heißt, die Konvertierung auf dem Server sei fehlgeschlagen
Das PDF ist höchstwahrscheinlich passwortgeschützt, beschädigt oder gar kein echtes PDF. Prüfen Sie es in einem Viewer, schicken Sie es durch PDF reparieren, falls es sich mit Fehlern öffnet, und versuchen Sie es erneut.
Die Schriften sehen anders aus als im PDF
Die Originalschriften sind auf Ihrem Rechner nicht installiert, Word hat sie also ersetzt. Installieren Sie die Schrift oder markieren Sie den gesamten Text und wählen Sie eine ähnliche Schrift, die Sie haben.

Häufig gestellte Fragen

Sieht die Word-Datei hinterher genauso aus wie das PDF?

Meistens sehr ähnlich, aber selten völlig identisch. Fließtext und Überschriften gelingen gut; Abweichungen gibt es vor allem bei Tabellen, Spalten, Textfeldern und genauen Seitenumbrüchen.

Wird aus einem eingescannten Dokument bearbeitbarer Text?

Nicht direkt. Ein Scan hat keine Textebene; lassen Sie zuerst „OCR-PDF“ laufen, damit der Konverter echten Text bekommt, und rechnen Sie damit, einige Layout- und Erkennungsfehler zu korrigieren.

In welchem Format kommt die Word-Datei?

Als .docx. Diese Dateien öffnen Microsoft Word ab Version 2007, LibreOffice, Google Docs und Apple Pages.

Kann ich auch nur ein paar Seiten umwandeln?

Umgewandelt wird immer die ganze Datei. Erstellen Sie vorher mit „Seiten extrahieren“ ein PDF, das nur die gewünschten Seiten enthält.

Wieso muss die Datei hier hochgeladen werden, bei anderen Tools aber nicht?

Um aus einem PDF ein Word-Dokument nachzubauen, braucht es eine vollwertige Konvertierungs-Engine, und die läuft auf einem Server. Die Übertragung ist verschlüsselt, und nach der Umwandlung wird die Datei beim Dienst gelöscht.

Kostet das etwas, oder brauche ich ein Konto?

Weder noch. Sie wählen eine Datei aus und wandeln sie um, ganz ohne Anmeldung.

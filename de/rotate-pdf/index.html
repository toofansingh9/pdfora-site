PDF drehen

Drehen Sie alle oder ausgewählte Seiten um 90, 180 oder 270 Grad und speichern Sie das Ergebnis.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.

Anpassen

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Ein eingescannter Vertrag, der quer aufgeht. Ein Diagramm im Querformat, gefangen in einem Hochformat-Dokument. Seiten, die irgendwo zwischen Scanner und Postfach auf dem Kopf gelandet sind. Das Drehen-Werkzeug von PDFora bringt das in Sekunden in Ordnung: Drehen Sie jede Seite — oder nur die von Ihnen gewählten — um 90 Grad im Uhrzeigersinn, 90 Grad gegen den Uhrzeigersinn oder volle 180 Grad. Die Drehung wird fest in die Datei geschrieben, die Seiten stehen also überall aufrecht, wohin das PDF auch weitergereicht wird.

Anders als die meisten Online-Konverter lädt PDFora Ihr Dokument nie auf einen Server. Die gesamte Drehung findet lokal in Ihrem Browser per JavaScript statt, ein unterschriebener Mietvertrag oder ein Arztbericht verlässt Ihren Computer also nie. Es gibt nichts zu installieren, kein Konto anzulegen und hinterher kein Wasserzeichen quer über Ihren Seiten. Drehen Sie eine Datei oder fünfzig hintereinander; Tageslimits gibt es keine.

Ihr eigentliches Können zeigt die Funktion beim gezielten Drehen. Geben Sie einen Seitenbereich wie „1,3-5" ein, und nur diese Seiten drehen sich, während der Rest unangetastet bleibt. So richten Sie eine einzelne quer liegende Tabelle mitten in einem vierzigseitigen Hochformat-Bericht auf, ohne einen kostenpflichtigen PDF-Editor zu öffnen.

So drehen Sie ein PDF online

  1. Öffnen Sie das Werkzeug „PDF drehen" auf getpdfora.com in einem beliebigen modernen Browser.
  2. Ziehen Sie Ihr PDF auf die Seite oder wählen Sie es per Klick aus. Die Datei wird lokal geladen und nie hochgeladen.
  3. Wählen Sie den Winkel: 90° im Uhrzeigersinn, 180° oder 90° gegen den Uhrzeigersinn.
  4. Entscheiden Sie, ob alle Seiten gedreht werden sollen oder nur bestimmte. Für einzelne Seiten geben Sie einen Bereich wie „1,3-5" ein.
  5. Klicken Sie auf „Drehen" und prüfen Sie in der Vorschau, ob nun jede Seite richtig herum steht.
  6. Laden Sie das korrigierte PDF herunter. Die neue Ausrichtung ist dauerhaft in der Datei gespeichert.

When to use this tool

  • Einen Stapel Belege geraderücken, die eine Scanner-App auf dem Handy quer erfasst hat, bevor die Reisekostenabrechnung eingereicht wird.
  • Die quer liegenden Finanztabellen in einem Geschäftsbericht aufrichten, damit die Prüfenden sie lesen können, ohne den Kopf zu neigen.
  • Eine auf dem Kopf stehende Seite in einer unterschriebenen Vereinbarung korrigieren, die verkehrt herum in den Scanner eingezogen wurde.
  • Vorlesungsfolien mit gemischter Ausrichtung so vorbereiten, dass sie einheitlich als Hochformat-Handouts gedruckt werden.
  • Architekturzeichnungen um 90 Grad drehen, damit das Schriftfeld dort sitzt, wo die Druckerei es erwartet.
  • Eine per Fax eingegangene Bestellung aufrichten, bevor sie an die Buchhaltung weitergeleitet wird.

Tips for the best results

  • Gedreht wird in 90-Grad-Schritten. Ist eine Seite vom Scannen nur leicht schief, handelt es sich um eine Schieflage — dann hilft nur erneutes Scannen oder ein Geraderücken.
  • Unsicher, in welche Richtung? Stellen Sie sich die Oberkante der Seite vor: im Uhrzeigersinn wandert sie nach rechts, gegen den Uhrzeigersinn nach links.
  • Für kopfüber gescannte Dokumente nehmen Sie 180°; zwei 90°-Drehungen führen zwar zum selben Ziel, ein Klick ist aber schneller.
  • Seitenbereiche verstehen Kommas ebenso wie Bindestriche, „2,6-9,14" dreht also genau diese fünf Seiten und sonst nichts.
  • Drehen Sie, bevor Sie zusammenführen oder teilen. Wer die Ausrichtung zuerst korrigiert, gibt die Korrektur an jede spätere Kopie weiter.

Häufig gestellte Fragen

Ist die Drehung dauerhaft oder nur eine Anzeigeeinstellung?

Sie ist dauerhaft. PDFora schreibt die Seitenausrichtung neu in die Datei, die Seiten bleiben also im Adobe Reader, auf dem Handy, im Druckdialog und überall sonst gedreht. Sie müssen nicht bei jedem Öffnen erneut drehen.

Kann ich nur einzelne Seiten eines PDF drehen?

Ja. Wechseln Sie in den Modus für ausgewählte Seiten und geben Sie einen Bereich wie „1,3-5" ein. Nur diese Seiten drehen sich; der Rest des Dokuments behält seine ursprüngliche Ausrichtung.

Werden meine Dateien auf einen Server hochgeladen?

Nein. Das Werkzeug läuft vollständig in Ihrem Browser, das PDF wird also auf Ihrem eigenen Gerät verarbeitet und geht nie durchs Internet. Das macht es sicher für Verträge, Ausweisscans und andere vertrauliche Unterlagen.

Gibt es eine Begrenzung für Dateigröße oder Nutzung?

PDFora ist kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Tageslimits. Da die Verarbeitung lokal geschieht, hängen sehr große Dateien vom Arbeitsspeicher Ihres Geräts ab und nicht von einem Serverkontingent — die meisten Dokumente sind in ein bis zwei Sekunden gedreht.

Leidet die Qualität meines PDF unter dem Drehen?

Nein. Beim Drehen ändert sich lediglich die Ausrichtungsangabe jeder Seite; Text, Bilder und Vektorinhalte bleiben unangetastet. Das Ergebnis hat dieselbe Qualität wie das Original, meist bei nahezu gleicher Dateigröße.

Kann ich ein passwortgeschütztes PDF drehen?

Verlangt die Datei zum Öffnen ein Passwort, müssen Sie es zuerst eingeben oder den Schutz entfernen, denn der Browser kann verschlüsselte Inhalte ohne Passwort nicht lesen. Sobald das PDF normal aufgeht, funktioniert das Drehen wie bei jeder anderen Datei.

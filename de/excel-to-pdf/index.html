Excel in PDF

Machen Sie aus Tabellenkalkulationen saubere, unveränderliche PDF-Dokumente.

Tabellen sind Arbeitsdokumente — Zellen verrutschen, Formeln rechnen neu, und ein versehentlicher Tastendruck verändert klammheimlich eine Summe. Solange Sie an den Zahlen arbeiten, ist das gut so; in dem Moment, in dem Sie sie weitergeben, wird es riskant. Der Excel-zu-PDF-Konverter von PDFora macht aus Ihrer XLS- oder XLSX-Datei ein sauberes, unveränderliches PDF: eine Momentaufnahme Ihrer Daten, an der niemand mehr etwas verschieben kann.

Das Layout, das Sie in Excel sehen, bekommen auch alle anderen zu sehen. Spaltenbreiten bleiben erhalten, Kopfzeilen wiederholen sich dort, wo Sie es festgelegt haben, und Diagramme werden genau so gedruckt, wie sie gestaltet wurden. Die Umwandlung läuft über die sichere Cloud-Engine von PDFora: Ihre Tabelle wird über eine verschlüsselte Verbindung übertragen, zu PDF gerendert und nach Abschluss der Verarbeitung automatisch gelöscht. Während der übrige Werkzeugkasten von PDFora im Browser arbeitet, braucht das Rendern von Tabellen einen Server — dieses Werkzeug nutzt daher diesen verschlüsselten Weg.

Wie alles auf der Seite ist auch das kostenlos. Keine Anmeldung, kein Wasserzeichen quer über Ihren Zahlen, keine Seitenbegrenzung. Arbeitsmappe hochladen, PDF herunterladen — und Ihre Zahlen gehen in einem Format hinaus, das sich benimmt.

So wandeln Sie Excel online in PDF um

  1. Räumen Sie Ihre Tabelle in Excel auf — legen Sie den Druckbereich und bei breiten Blättern die Seitenausrichtung fest.
  2. Öffnen Sie das Excel-zu-PDF-Werkzeug auf getpdfora.com.
  3. Laden Sie Ihre XLS- oder XLSX-Datei hoch, indem Sie sie auf die Seite ziehen oder über den Dateidialog auswählen.
  4. Die sichere Engine rendert Ihre Tabellenblätter zu PDF und behält dabei Spaltenbreiten, Zellformatierung und Diagramme bei.
  5. Laden Sie das fertige PDF auf Ihr Gerät herunter.
  6. Öffnen Sie es und prüfen Sie die Seitenumbrüche — breite Tabellen lesen sich oft im Querformat besser, wofür eine Einstellung und ein erneuter Durchlauf genügen.

When to use this tool

  • Eine in Excel erstellte Rechnung als PDF verschicken, damit der Kunde eine ordentliche Rechnung sieht und kein Raster aus bearbeitbaren Zellen.
  • Ein Projektbudget mit Beteiligten teilen, die die Zahlen lesen und nicht versehentlich umschreiben sollen.
  • Reisekostenabrechnungen oder Stundenzettel in einem festen Format einreichen, das die prüfende Stelle direkt zu den Akten nehmen kann.
  • Eine Preisliste oder einen Produktkatalog, der als Tabelle gepflegt wird, als sauberes PDF für Kunden veröffentlichen.
  • Monatsabschlüsse als PDF archivieren und die Zahlen exakt so einfrieren, wie sie berichtet wurden.
  • Einen Dienstplan, eine Teilnehmerliste oder einen Sitzplan drucken, ohne sich auf einem fremden Rechner mit Excels Druckvorschau herumzuschlagen.

Tips for the best results

  • Legen Sie den Druckbereich vor der Umwandlung in Excel fest — er sagt dem Renderer genau, welche Zellen ins PDF gehören, und hält verirrte Spalten draußen.
  • Breite Tabellen sehen im Querformat fast immer besser aus; stellen Sie das unter „Seitenlayout" um, bevor Sie hochladen.
  • Nutzen Sie bei kleinen Tabellen Excels Skalierung „Blatt auf einer Seite darstellen", damit im PDF nicht eine große Seite mit einer winzigen Tabelle in der Ecke landet.
  • Wiederholen Sie Kopfzeilen über „Seitenlayout > Drucktitel", damit mehrseitige Tabellen bis zum Schluss lesbar bleiben.
  • Denken Sie daran: Das PDF hält Werte fest, keine Formeln — behalten Sie die XLSX als Arbeitsfassung und betrachten Sie das PDF als veröffentlichte Momentaufnahme.

Häufig gestellte Fragen

Bleiben Formatierung und Diagramme bei der Umwandlung erhalten?

Ja. Zellfarben, Rahmen, Schriften, verbundene Zellen und eingebettete Diagramme werden genau so ins PDF gerendert, wie sie in Excel erscheinen. Aufpassen müssen Sie vor allem bei sehr breiten Tabellenblättern, da diese über mehrere Seiten umbrechen können.

Wie verhindere ich, dass sich meine Tabelle über viele PDF-Seiten verteilt?

Steuern Sie das vor der Umwandlung in Excel: Druckbereich festlegen, auf Querformat wechseln oder mit den Skalierungsoptionen die Spalten auf eine Seitenbreite bringen. Das PDF folgt genau der Seiteneinrichtung, die die Arbeitsmappe mitbringt.

Verarbeitet das Werkzeug sowohl XLS als auch XLSX?

Ja, sowohl das moderne XLSX-Format als auch alte XLS-Dateien aus früheren Excel-Versionen werden zuverlässig umgewandelt. Auch Dateien aus Google Sheets oder LibreOffice, die als XLSX gespeichert wurden, funktionieren.

Sind meine Finanzdaten hier sicher?

Die Umwandlung läuft über die sichere Cloud-Engine von PDFora: Ihre Arbeitsmappe wird über eine verschlüsselte Verbindung übertragen, umgewandelt und nach der Verarbeitung automatisch gelöscht. Es werden keine Kopien aufbewahrt und nichts weitergegeben.

Sind die Formeln im PDF sichtbar?

Nein — das PDF zeigt ausschließlich die berechneten Ergebnisse, genau so, wie die Zellen sie anzeigen. Beim Weitergeben ist das meist ein Vorteil, denn Ihre Rechenlogik bleibt in der Originaldatei und damit privat.

Fallen Kosten, eine Anmeldung oder ein Wasserzeichen an?

Nichts davon. Der Excel-zu-PDF-Konverter ist kostenlos, funktioniert ohne Konto und liefert sauberes Ergebnis ohne jede Werbung auf Ihren Seiten.

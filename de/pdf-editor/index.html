PDF bearbeiten

Text, Bilder, Freihandmarkierungen und weiße Abdeckflächen auf jede PDF-Seite setzen und eine neue Kopie speichern.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Wer nach einem PDF-Editor sucht, will meist kein Dokument umschreiben. Es geht darum, ein fehlendes Datum nachzutragen, ein Logo auf ein Angebot zu setzen, etwas durchzustreichen oder eine kurze Notiz an den Rand zu schreiben. „PDF bearbeiten“ von PDFora ist genau für solche Aufgaben gebaut: Sie platzieren Neues auf einer Seite. Die bereits gedruckten Wörter in der Datei können Sie damit nicht ändern – und das sollten Sie besser vorher als hinterher wissen.

Beim Öffnen einer Datei zeichnet PDF.js jede Seite mit einer Breite von bis zu 880 Pixeln auf den Bildschirm. Über jeder Seite liegt eine transparente Ebene, auf der Sie arbeiten. Die Werkzeugleiste hat sechs Modi: Verschieben, Text, Unterschrift, Bild, Zeichnen und Abdecken, dazu eine Farbauswahl und ein Feld für die Textgröße (Standard 18, von 6 bis 96). Textfelder, Unterschriften und Bilder lassen sich verschieben und mit dem kleinen × löschen; Bilder und Unterschriften können Sie zusätzlich über die Ecke vergrößern oder verkleinern.

Bei „PDF speichern“ malt das Tool alles, was Sie auf einer Seite hinzugefügt haben, in ein transparentes PNG in der Größe der Bildschirmseite, und pdf-lib stempelt dieses PNG über die Originalseite. Der ursprüngliche Inhalt darunter bleibt unangetastet: Sein Text bleibt markierbar, seine Vektorgrafiken bleiben scharf. Heruntergeladen wird das Ergebnis als ihredatei-edited.pdf.

So fügen Sie einem PDF Text und Bilder hinzu

  1. Öffnen Sie „PDF bearbeiten“ und ziehen Sie ein einzelnes PDF hinein. Warten Sie, bis alle Seiten gezeichnet sind; bei langen Dokumenten dauert das kurz, weil jede Seite gerendert wird, bevor Sie damit arbeiten können.
  2. Wählen Sie „Text“, legen Sie Farbe und Größe fest und klicken Sie dorthin, wo der Text beginnen soll. Tippen Sie direkt ins Feld. Mit Enter beginnt eine neue Zeile; lange Zeilen brechen nicht von selbst um.
  3. Mit „Bild“ setzen Sie ein Logo oder einen Stempel von Ihrem Rechner ein, mit „Zeichnen“ freihändige Haken, Pfeile und Kreise. Über den Eckgriff ändern Sie die Größe von Bildern.
  4. Mit „Abdecken“ ziehen Sie ein Rechteck über alles, was nicht mehr zu sehen sein soll; ersetzen Sie es durch eine Korrektur, setzen Sie anschließend ein Textfeld darauf.
  5. Klicken Sie auf „PDF speichern“, öffnen Sie die heruntergeladene -edited.pdf und zoomen Sie auf jede Änderung, bevor Sie die Datei weitergeben.

Wann Sie dieses Tool nutzen sollten

  • Ein fehlendes Datum, Aktenzeichen oder eine Raumnummer auf einem Aushang nachtragen, bevor er erneut verteilt wird.
  • Ein Firmenlogo oder ein „BEZAHLT“-Stempelbild auf eine Lieferantenrechnung setzen, die als PDF kam.
  • Einen Grundriss oder ein Arbeitsblatt mit freihändigen Kreisen, Pfeilen und kurzen Notizen versehen.
  • Einen Tippfehler in einem Flyer korrigieren, wenn die Word- oder Canva-Datei verloren ist: abdecken, richtiges Wort darüber tippen.
  • Einen Kommentar im Stil einer Handnotiz auf eine eingescannte Seite setzen, die ohnehin keine Textebene hat.
  • Ein Bild mit Ihrem Kürzel in die Ecke jeder Seite einer kurzen Vereinbarung setzen.

Das sollten Sie vorher wissen

  • Vorhandener Text lässt sich nicht direkt bearbeiten. Das Tool legt eine Ebene darüber; es bricht nichts neu um und tippt nichts neu. Um einen Absatz sauber zu ändern, brauchen Sie das Quelldokument.
  • „Abdecken“ verbirgt Inhalte nur optisch. Das weiße Rechteck ist Teil des darübergestempelten Bildes; der Originaltext steckt weiterhin in der Datei darunter und lässt sich markieren, kopieren oder per Suche finden. Nutzen Sie es niemals, um vertrauliche Informationen zu entfernen.
  • Alles, was Sie hinzufügen, wird zu einem Bild zusammengeführt. Getippter Text wird zu Pixeln – er ist nicht durchsuchbar, nicht kopierbar und wird von Screenreadern nicht vorgelesen.
  • Die zusätzliche Ebene entsteht in Bildschirmauflösung (höchstens 880 Pixel über die Seitenbreite). Auf einer A4-Seite sind das rund 100 Pixel pro Zoll – getippter Text sieht am Bildschirm gut aus, kann aber gedruckt oder stark gezoomt etwas weich wirken.
  • Beim Speichern bekommt jede Seite eine PNG-Ebene, auch Seiten, die Sie nicht verändert haben. Eine leere Ebene komprimiert gut, rechnen Sie aber mit einer etwas größeren Ausgabe als dem Original.
  • Die Schrift am Bildschirm und die gespeicherte Schrift können leicht abweichen: Beim Speichern wird Text in Helvetica oder Arial in der gewählten Größe gezeichnet. Prüfen Sie die Zeilenpositionen in der heruntergeladenen Datei, vor allem bei Text, den Sie in eine enge Lücke gequetscht haben.

Tipps für beste Ergebnisse

  • Stellen Sie Farbe und Größe ein, bevor Sie klicken, um Text zu platzieren. Die Werte werden beim Anlegen des Feldes übernommen; spätere Änderungen gestalten bereits vorhandene Felder nicht um.
  • Für eine Korrektur zuerst das Abdeck-Rechteck setzen, dann den Ersatztext – so liegt der Text sichtbar auf der weißen Fläche.
  • Nehmen Sie für Logos und Stempel ein transparentes PNG. Ein JPG bringt seinen weißen rechteckigen Hintergrund mit und verdeckt alles dahinter.
  • Stellen Sie den Browser-Zoom vor dem Öffnen der Datei auf eine angenehme Größe ein; die Seite wird an die in diesem Moment verfügbare Breite angepasst.
  • Brauchen Sie für den Druck schärferen Zusatztext, halten Sie Notizen kurz und wählen Sie eine größere Schrift (14 oder mehr) statt winziger Schrift, die unter der Bildschirmauflösung am meisten leidet.

Beispiel: eine Vermieterin korrigiert eine Mieterhöhung

Eine Vermieterin aus Bremen hat ein zweiseitiges Schreiben zur Mieterhöhung, das sie vor Monaten aus einem Textprogramm exportiert hat, das nicht mehr installiert ist. Die neue Miete stimmt, aber als Stichtag steht dort der 1. März statt des 1. April, und vor dem Versand per E-Mail an vier Mietparteien soll noch das Logo der Hausverwaltung in die obere Ecke.

In „PDF bearbeiten“ zieht sie ein Abdeck-Rechteck über „März“, wechselt zu „Text“, stellt Größe 12 in Schwarz ein und klickt direkt über die weiße Fläche, um „April“ zu tippen. Dann wählt sie „Bild“, klickt in die rechte obere Ecke von Seite eins, wählt das Logo-PNG und verkleinert es über den Eckgriff. Nach dem Speichern kommt die Datei als mieterhoehung-edited.pdf zurück und liest sich am Bildschirm genau wie gewünscht.

Was sie nicht vergessen sollte: Das Wort „März“ steckt unter dem weißen Kasten weiterhin in der Datei. Wer im PDF nach „März“ sucht, findet es. Für eine formlose Korrektur ist das in Ordnung; bei allem, was in einem Streit landen könnte, ist es besser, das Schreiben neu aufzusetzen oder zumindest eine kurze Zeile zur Korrektur hinzuzufügen.

Fehlerbehebung

Die Seite erscheint, aber beim Klicken passiert nichts
Prüfen Sie, welcher Modus gewählt ist. Im Modus „Verschieben“ bewirkt ein Klick auf eine leere Stelle nichts; wechseln Sie zu „Text“, „Bild“ oder „Zeichnen“. Klicken Sie außerdem auf eine freie Seitenfläche, nicht auf ein bereits platziertes Element.
Mein Text steht in der gespeicherten Datei an einer anderen Stelle
Beim Speichern wird der Text mit einer serifenlosen Standardschrift neu gezeichnet, die Zeilenbreite kann sich also um einige Pixel verschieben. Lassen Sie um Text in engen Kästen etwas Luft und prüfen Sie die Ausgabe erneut.
Abgedeckter Text taucht bei der Suche in der Datei noch auf
So arbeitet das Tool: Abdecken ist ein gemaltes Rechteck, kein Löschen. Um Inhalte wirklich zu entfernen, erstellen Sie das Dokument aus der Quelle neu oder drucken die bearbeitete Datei in ein neues PDF und schicken es durch ein Tool, das die Seite rastert.
Mein Logo hat einen weißen Kasten drumherum
Das verwendete Bild ist ein JPG oder ein PNG ohne Transparenz. Exportieren Sie das Logo als PNG mit transparentem Hintergrund und setzen Sie es neu ein.
Dieses PDF konnte nicht gerendert werden
Die Datei ist passwortgeschützt, beschädigt oder gar kein echtes PDF. Entfernen Sie das Passwort in der App, mit der sie erstellt wurde, oder schicken Sie sie zuerst durch „PDF reparieren“ und öffnen Sie dann die reparierte Kopie.
Das Speichern dauert lange oder der Tab friert ein
Beim Speichern wird jede Seite zu einem ganzseitigen PNG, bei einem langen Dokument liegen also viele davon gleichzeitig im Speicher. Lösen Sie mit „Seiten extrahieren“ nur die benötigten Seiten heraus, bearbeiten Sie diese und führen Sie sie danach wieder zusammen.

Häufig gestellte Fragen

Kann ich die vorhandenen Wörter in meinem PDF ändern?

Nein. Dieses Tool fügt neue Inhalte auf der Seite hinzu. Vorhandenen Text können Sie mit „Abdecken“ verdecken und einen Ersatz darüber tippen, die ursprünglichen Wörter bleiben aber darunter in der Datei.

Ist der hinzugefügte Text durchsuchbar?

Nein. Hinzugefügter Text, Unterschriften und Zeichnungen werden beim Speichern zu einer Bildebene zusammengeführt und lassen sich weder markieren noch per Suche finden. Der Originaltext des Dokuments bleibt durchsuchbar.

Verschlechtert das Bearbeiten die Qualität meiner Originalseiten?

Nein. Der ursprüngliche Seiteninhalt bleibt, wie er war, die neue Ebene liegt darüber. Nur Ihre Ergänzungen haben Bildschirmauflösung.

Kann ich eine Änderung vor dem Speichern rückgängig machen?

Textfelder, Bilder und Unterschriften entfernen Sie mit dem × am jeweiligen Element. Freihandlinien und Abdeck-Rechtecke werden direkt gemalt und lassen sich nicht einzeln entfernen; laden Sie die Datei neu, um von vorn zu beginnen.

Kann ich ein eingescanntes Dokument bearbeiten?

Ja. Ein Scan ist einfach ein Bild pro Seite, Text, Stempel und Markierungen funktionieren also genauso. Die gescannten Wörter selbst können Sie trotzdem nicht ändern, nur abdecken und ergänzen.

Ist „PDF bearbeiten“ kostenlos?

Ja, ohne Konto und ohne Wasserzeichen. Der gesamte Ablauf, vom Rendern der Seiten bis zum Erstellen der neuen Datei, findet in Ihrem Browser-Tab statt.

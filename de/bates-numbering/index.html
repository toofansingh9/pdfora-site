Bates-Nummerierung

Versehen Sie jede Seite mit einer fortlaufenden Bates-Nummerierung — mit eigenem Präfix und führenden Nullen, wie es im Rechtswesen üblich ist.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

In Gerichtsverfahren braucht jede Seite, die im Rahmen der Beweisoffenlegung herausgegeben wird, eine eindeutige Kennung — und genau dafür hat sich die Bates-Nummerierung als Standard etabliert. Ein Präfix, eine fortlaufende Zahl, und schon wird aus „der E-Mail wegen der Rechnung" die Seite ABC-000147: zitierfähig in der Zeugenvernehmung, nachvollziehbar in jedem Aktenverzeichnis, im Gerichtssaal unmissverständlich. Mit diesem Werkzeug vergeben Sie die Bates-Nummerierung direkt online und stempeln jede Seite Ihres PDF in Sekunden.

Das Format bestimmen Sie selbst. Legen Sie ein eigenes Präfix fest, etwa „SMITH-" oder Ihr Aktenzeichen, wählen Sie die Startnummer, damit eine neue Herausgabe genau dort weiterläuft, wo die vorherige geendet hat, und entscheiden Sie, mit wie vielen führenden Nullen aufgefüllt werden soll — also 000001 statt schlicht 1. Anschließend bestimmen Sie die Position des Stempels: unten rechts, unten links oder unten mittig. Das Werkzeug nummeriert alle Seiten der Reihe nach und gibt Ihnen die gestempelte Datei zurück.

Für Kanzleien zählt vor allem der Datenschutz: Das PDF wird vollständig in Ihrem Browser verarbeitet und niemals hochgeladen, sodass mandatsbezogene und vertrauliche Unterlagen Ihren Rechner nie verlassen. Kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Seitenbegrenzung.

So fügen Sie online eine Bates-Nummerierung hinzu

  1. Ziehen Sie Ihr PDF in das Werkzeug — es wird lokal in Ihrem Browser geöffnet, Mandantenunterlagen werden also zu keinem Zeitpunkt übertragen.
  2. Geben Sie Ihr Präfix ein, zum Beispiel „ABC-" oder ein Aktenzeichen wie „DOE2026-".
  3. Legen Sie die Startnummer fest. Für eine erste Herausgabe nehmen Sie 1, für eine ergänzende setzen Sie hinter Ihrer zuletzt gestempelten Seite fort.
  4. Wählen Sie die Anzahl der Stellen für die führenden Nullen — sechs Stellen ergeben ABC-000001, ABC-000002 und so weiter.
  5. Bestimmen Sie die Position des Stempels: unten rechts, unten links oder unten mittig.
  6. Stempeln Sie mit einem Klick alle Seiten, laden Sie das nummerierte PDF herunter und vermerken Sie den vergebenen Nummernbereich in Ihrem Herausgabeverzeichnis.

When to use this tool

  • Eine Rechtsanwaltsfachangestellte stempelt vor einer Beweisherausgabe 400 Seiten ausgedruckter E-Mails als PLAINTIFF-000001 bis PLAINTIFF-000400.
  • Ein Einzelanwalt versieht ein PDF mit Behandlungsunterlagen mit Bates-Nummern, damit die Gegenseite in einer Personenschadensache einzelne Seiten präzise zitieren kann.
  • Eine Rechtsabteilung nummeriert interne Dokumente, die auf eine behördliche Anordnung hin herauszugeben sind, und setzt die Zählung aus einer früheren Teillieferung fort.
  • Ein Wirtschaftsprüfer versieht Arbeitspapiere mit fortlaufenden Nummern, damit im Abschlussbericht jede Seite eindeutig referenziert werden kann.
  • Eine Sachbearbeiterin nummeriert Anlagen für eine Verwaltungsanhörung und verwendet dabei für jeden Anlagenkonvolut ein eigenes Präfix.
  • Ein Compliance-Beauftragter stempelt Richtlinienordner Seite für Seite, damit Änderungen gegen eine feste Seitenkennung nachverfolgt werden können.

Tips for the best results

  • Führen Sie pro Mandat Buch über die zuletzt vergebene Bates-Nummer — die nächste Herausgabe beginnt bei der darauffolgenden Zahl, eine Nummer darf nie doppelt vergeben werden.
  • Sechs Stellen sind die gängige Konvention in der US-Beweisoffenlegung; so bleiben die Nummern bündig und sortieren sich in jeder Dateiliste korrekt.
  • Wählen Sie ein Präfix, das die herausgebende Partei erkennbar macht, etwa „SMITH-" oder „DEF-", damit sich Seiten verschiedener Parteien niemals überschneiden.
  • Die Position ist nicht nebensächlich: Nehmen Sie eine Ecke, in der weder Fußzeilen noch bereits gedruckte Seitenzahlen überdeckt werden.
  • Stempeln Sie stets eine Kopie und nicht Ihr einziges Original — bewahren Sie die saubere Fassung auf, falls sich die Formatvorgaben im laufenden Verfahren ändern.

Häufig gestellte Fragen

Was ist eine Bates-Nummerierung?

Bei der Bates-Nummerierung erhält jede Seite eines Dokumentenbestands eine eindeutige fortlaufende Kennung, typischerweise ein Präfix plus eine mit Nullen aufgefüllte Zahl wie ABC-000123. Ihren Ursprung hat sie in einer handbetriebenen Stempelmaschine, die in den 1890er-Jahren patentiert wurde — bis heute ist sie die übliche Methode, mit der Juristen Seiten in der Beweisoffenlegung identifizieren.

Ist das Werkzeug für vertrauliche Mandatsunterlagen geeignet?

Ja, und genau darin liegt der entscheidende Unterschied zu den meisten Online-Stempeldiensten: Das PDF wird lokal in Ihrem Browser verarbeitet und niemals auf einen Server hochgeladen. Geschützte oder vertrauliche Inhalte bleiben von Anfang bis Ende auf Ihrem Computer.

Kann ich die Nummerierung einer früheren Herausgabe fortsetzen?

Ja. Setzen Sie die Startnummer einfach dort an, wo die letzte Lieferung geendet hat — endete sie bei ABC-000400, beginnen Sie diese Datei bei 401 mit identischem Präfix und gleicher Nullenauffüllung. So bleibt über das gesamte Mandat hinweg eine durchgehende Nummernfolge erhalten.

Wo auf der Seite erscheint der Bates-Stempel?

Das entscheiden Sie: unten rechts, unten links oder unten mittig. Unten rechts ist in der US-Praxis am gebräuchlichsten, doch Gerichte und Verfahrensabsprachen unterscheiden sich — prüfen Sie also vorab Ihre Verfahrensanordnung oder die Vereinbarung zur Herausgabe.

Ist der Bates-Stempel dauerhaft?

Die Nummer wird als Seiteninhalt direkt auf die Seite gezeichnet und bleibt daher in jedem PDF-Betrachter fest an ihrem Platz — auch beim Drucken und Kopieren. Es handelt sich nicht um eine Anmerkung, die sich mit einem Klick wieder entfernen ließe.

Kostet das Werkzeug etwas oder begrenzt es die Seitenzahl?

Nein. Es ist kostenlos, verlangt kein Konto, setzt kein Wasserzeichen und kennt keine Obergrenze für Seiten oder Dokumente — eine Herausgabe mit 2.000 Seiten wird genauso verarbeitet wie ein Dokument mit zehn Seiten.

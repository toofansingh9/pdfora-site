Bringen Sie PDF-Seiten auf ein Standardpapierformat – A4, US Letter, A5 oder A3 – ganz ohne Desktop-Software. Dokumente, die aus verschiedenen Quellen zusammengesetzt sind, passen selten zusammen: Eine Datei entstand in den USA auf US Letter, eine andere in Europa auf A4, eine dritte wurde in irgendeinem krummen Sonderformat exportiert. PDFora skaliert jede Seite auf das von Ihnen gewählte Format, wobei der Inhalt proportional angepasst und zentriert wird, sodass nichts abgeschnitten wird. Alles läuft mit lokaler Verarbeitung in Ihrem Browser; die Datei wird nie hochgeladen.

Damit löst sich ein hartnäckiges Alltagsproblem. Drucken Sie eine PDF-Datei im Format US Letter auf A4-Papier, verkleinert der Drucker sie entweder unvorhersehbar oder schneidet die Ränder ab. Führen Sie Seiten unterschiedlicher Größe zu einer Datei zusammen, wirkt das Ergebnis in jedem Betrachter unsauber. Wenn Sie das gesamte Dokument auf ein einziges Zielformat bringen – eine A4-PDF für den Druck in Europa, US Letter für die USA –, verhält es sich überall gleich.

PDFora ist kostenlos, ohne Registrierung, ohne Wasserzeichen im Ergebnis und ohne Begrenzung von Dateien oder Seiten. Da die Größenanpassung auf Ihrem eigenen Rechner passiert, ist ein 300-seitiges Archiv mit gemischten Formaten in der Zeit umgewandelt, die andere Seiten allein für den Upload brauchen.

So ändern Sie online die Seitengröße einer PDF-Datei

  1. Öffnen Sie auf getpdfora.com das Werkzeug zur Größenanpassung und legen Sie die PDF-Datei ab, die vereinheitlicht werden soll.
  2. Wählen Sie das Zielpapierformat: A4, US Letter, A5 oder A3.
  3. Bestätigen Sie Ihre Wahl – jede Seite des Dokuments wird auf dieses eine Format umgestellt.
  4. Lassen Sie das Werkzeug den Inhalt neu skalieren. Jede Seite wird passend verkleinert oder vergrößert und auf dem neuen Blatt zentriert, die Proportionen bleiben also erhalten.
  5. Die Verarbeitung läuft lokal in Ihrem Browser, es gibt daher keinen Upload-Schritt und kein Warten in einer Serverwarteschlange.
  6. Laden Sie die angepasste PDF-Datei herunter und prüfen Sie ein paar Seiten, bevor Sie sie in den Druck geben.

When to use this tool

  • Einen Vertrag im Format US Letter in eine A4-PDF umwandeln, bevor er in Europa, Asien oder anderswo gedruckt wird, wo A4 der Bürostandard ist.
  • Ein zusammengeführtes Dokument vereinheitlichen, dessen Kapitel aus unterschiedlichen Programmen und Ländern stammen, sodass jede Seite gleich groß ist.
  • Einen Bericht auf A3 vergrößern für eine Besprechung, in der die Beteiligten großformatige Ausdrucke kommentieren möchten.
  • Ein Dokument auf A5 verkleinern, um eine kompakte Leseausgabe im Broschürenstil zu erzeugen.
  • Scans mit schrägen, nicht standardisierten Abmessungen so korrigieren, dass sie randgenau auf normalem Papier ausgedruckt werden.
  • Dateien für eine Druckerei vorbereiten, die nach Standardbogengrößen kalkuliert und PDF-Dateien mit gemischten Formaten ablehnt.

Tips for the best results

  • Stimmen Sie das Zielformat auf das Papier ab, das im Zieldrucker tatsächlich liegt – A4 für den größten Teil der Welt, US Letter für Nordamerika –, und die meisten Druckprobleme verschwinden von selbst.
  • Der Inhalt wird proportional skaliert und zentriert; eine auf A4 übertragene US-Letter-Seite bekommt an einigen Kanten also kleine Ränder, statt gestreckt oder verzerrt zu werden.
  • Passen Sie die Seitengröße an, bevor Sie Seitenzahlen, Kopfzeilen oder Wasserzeichen ergänzen, damit diese Elemente an den endgültigen Seitenmaßen ausgerichtet werden.
  • Der Weg von A4 auf A5 halbiert die Blattfläche; prüfen Sie, ob Fußnoten und Kleingedrucktes im kleineren Format noch bequem lesbar sind.
  • Behalten Sie Ihre Originaldatei unangetastet als Hauptfassung. Das Werkzeug verändert sie nie, Sie können also heute eine A4-Version und morgen eine A3-Version aus derselben Quelle erzeugen.

Häufig gestellte Fragen

Auf welche Papierformate kann ich umstellen?

Vier Standardformate werden unterstützt: A4, US Letter, A5 und A3. Jede Seite Ihres Dokuments wird auf das eine von Ihnen gewählte Format umgestellt.

Werden meine Seiten dabei gestreckt oder verzerrt?

Nein. Der Inhalt wird proportional auf die neue Seite skaliert und anschließend zentriert. Weichen die Seitenverhältnisse von Ausgangs- und Zielformat leicht voneinander ab, entstehen gleichmäßige Ränder statt gestauchter Schrift.

Wird meine PDF-Datei bei der Größenanpassung hochgeladen?

Nein. Das Werkzeug läuft mit lokaler Verarbeitung vollständig in Ihrem Browser, die Datei verlässt Ihren Computer also nie. Damit entfällt auch bei großen Dokumenten jede Wartezeit für den Upload.

Was passiert, wenn meine PDF-Datei Seiten unterschiedlicher Größe enthält?

Das ist einer der besten Anwendungsfälle für dieses Werkzeug. Jede Seite kommt – gleich welche Ausgangsmaße sie hatte – im selben Zielformat heraus, sodass ein einheitliches Dokument entsteht.

Begrenzt die kostenlose Version Seiten oder fügt sie Branding hinzu?

Es gibt nur eine Version, und die ist kostenlos: keine Registrierung, keine Seitenbegrenzung, kein Nutzungskontingent und kein Wasserzeichen im Ergebnis.

Verliert mein Dokument durch die Größenanpassung an Qualität?

Text und Vektorinhalte in PDF-Dateien skalieren ohne jeden Qualitätsverlust. Fotos werden zusammen mit der Seite angepasst und behalten ihre ursprüngliche Auflösung im Verhältnis zum Inhalt.

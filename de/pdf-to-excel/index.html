PDF in Excel

Holen Sie Tabellen aus einem PDF in eine Excel-Arbeitsmappe (.xlsx), in der Sie sortieren, filtern und rechnen können.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Wer ein PDF in Excel haben will, meint fast immer eine Tabelle: einen Kontoauszug, eine Preisliste, einen Berichtsanhang, eine Notenübersicht. Im PDF sehen die Zahlen ordentlich aus, aber darunter liegt kein Raster. Jede Zahl ist ein eigenes Textstück an einer bestimmten Position auf der Seite, und die Linien, die wie Zellrahmen aussehen, sind bloß Zeichnungen. Kopiert man aus dem PDF-Viewer in eine Tabellenkalkulation, landet deshalb gern alles in einer einzigen Spalte.

Ein richtiger Konverter schaut, wo der Text sitzt, entscheidet, welche Elemente senkrecht zu Spalten und waagerecht zu Zeilen gehören, und schreibt das in echte Tabellenzellen. PDFora schickt das PDF dafür an eine serverseitige Konvertierungs-Engine (CloudConvert, über unser eigenes Relay), denn diese Analyse geht weit über das hinaus, was eine Webseite zuverlässig leisten kann. Die Datei wird über eine verschlüsselte Verbindung hochgeladen, in .xlsx umgewandelt und zu Ihnen zurück heruntergeladen; die hochgeladene Kopie wird nach dem Auftrag beim Dienst entfernt.

Einstellungen gibt es keine: ein PDF rein, eine Arbeitsmappe raus, für das gesamte Dokument. Saubere Ergebnisse dürfen Sie bei PDFs erwarten, die aus Buchhaltungssoftware oder Tabellenkalkulationen exportiert wurden; gestaltete Berichte, gedrehte Tabellen oder Scans brauchen mehr Nacharbeit. Vor allem Zahlen sollten Sie prüfen, denn ein Wert, der richtig aussieht, kann trotzdem als Text gespeichert sein.

So wandeln Sie ein PDF in Excel um

  1. Öffnen Sie PDF in Excel und wählen Sie ein PDF aus. Brauchen Sie nur eine einzelne Tabelle, extrahieren Sie vorher deren Seiten, damit die Arbeitsmappe nichts anderes enthält.
  2. Klicken Sie auf „Konvertieren“ und verfolgen Sie, wie der Status von „Wird hochgeladen…“ zu „Wird konvertiert…“ wechselt.
  3. Warten Sie auf den Download. Das Tool fragt alle paar Sekunden beim Server nach und bricht nach etwa drei Minuten ab, wenn der Auftrag bis dahin nicht fertig ist.
  4. Speichern Sie die .xlsx-Datei (Name der Originaldatei mit Endung .xlsx, sofern der Server keinen anderen Namen liefert).
  5. Öffnen Sie die Arbeitsmappe, markieren Sie die Zahlenspalten und prüfen Sie, ob Excel sie als Zahlen behandelt – zum Beispiel, indem Sie eine Spalte summieren und die Summe mit dem PDF vergleichen.

Wann Sie dieses Tool nutzen sollten

  • Ein kleiner Laden macht aus der PDF-Preisliste eines Lieferanten eine Tabelle, in die er eine eigene Spalte für den Aufschlag einfügen kann.
  • Einen Konto- oder Kreditkartenauszug mit den Buchungen in der Buchhaltung abgleichen.
  • Ein Verein sammelt Auswertungen von Umfragen, die Ortsgruppen als PDF-Berichte geschickt haben.
  • Studierende werten Tabellen aus einer veröffentlichten Statistik-Publikation im PDF-Format aus.
  • Einen Stunden- oder Dienstplan, der als PDF kam, so umbauen, dass er sich nach Person oder Tag filtern lässt.
  • Bestandslisten aus alten Berichten herausholen, deren ursprüngliche Tabelle nicht mehr existiert.

Das sollten Sie vorher wissen

  • Die Datei wird auf einem Server verarbeitet, nicht in Ihrem Browser: verschlüsselt hochgeladen, umgewandelt und danach beim Konvertierungsdienst gelöscht.
  • Gescannte Tabellen sind Bilder. Ohne Textebene gibt es keine Zahlen, die in Zellen kommen könnten – nutzen Sie zuerst das OCR-Tool. Prüfen Sie auch danach jede Zahl, denn OCR kann Ziffern wie 1 und 7 oder 0 und 8 verwechseln.
  • Zahlenformate kommen womöglich als Text an. Tausendertrennzeichen, Währungssymbole, ein Minus in Form von Klammern oder ein nachgestelltes CR können verhindern, dass Excel einen Wert als Zahl erkennt.
  • Verbundene Überschriften, umbrochener Zellentext und Zeilen, die im PDF über zwei Zeilen laufen, werden oft auf mehrere Tabellenzeilen verteilt.
  • Auch Inhalte, die keine Tabelle sind (Absätze, Fußnoten, Seitenköpfe), landen in Zellen – rechnen Sie also mit etwas Aufräumarbeit.
  • Passwortgeschützte PDFs lassen sich nicht umwandeln; entfernen Sie den Schutz vorher im Ursprungsprogramm. Eine Formel für den laufenden Saldo neben der umgewandelten Saldospalte zeigt die erste Zeile, in der beide Zahlen voneinander abweichen – meist genau die Zeile, die der Konverter verschoben hat.

Tipps für beste Ergebnisse

  • Extrahieren Sie vor der Umwandlung nur die Seiten mit der Tabelle. Das hält die Arbeitsmappe klein und die Nacharbeit überschaubar.
  • Stehen Zahlen linksbündig in ihren Zellen, sind sie Text. Mit Daten > Text in Spalten ohne Änderungen oder durch Multiplizieren mit 1 werden daraus Zahlen.
  • Achten Sie auf die Ländereinstellung: Ein PDF mit Punkt als Dezimaltrennzeichen bringt eine auf Komma eingestellte deutsche Tabellenkalkulation leicht durcheinander – und umgekehrt.
  • Wiederholte Kopfzeilen (eine pro PDF-Seite) löschen Sie besser per Filter auf den Kopfzeilentext als von Hand.
  • Vergleichen Sie immer mindestens eine Spaltensumme mit dem PDF, bevor Sie den umgewandelten Zahlen trauen.

Beispiel: eine Freiberuflerin gleicht ihre Quartalsübersicht ab

Eine freiberufliche Designerin aus Hamburg bekommt von ihrem Zahlungsdienstleister eine vierseitige PDF-Übersicht mit 63 Zahlungseingängen für das Quartal. Ihr Steuerberater möchte die Daten als Tabelle, mit Kundenname, Datum, Bruttobetrag und Gebühr in getrennten Spalten.

Sie wandelt das PDF um und öffnet die Arbeitsmappe. Die Zeilen sind da, aber jede Seite beginnt mit einer wiederholten Kopfzeile, und in der Gebührenspalte stehen Abzüge wie (2.40), die Excel als Text liest. Sie filtert die Kopfzeilen heraus, macht mit Suchen und Ersetzen aus den Klammern ein vorangestelltes Minus und wandelt die Spalte in Zahlen um. Weil Punkt und Komma bei ihr deutsch eingestellt sind, ersetzt sie dabei auch den Dezimalpunkt durch ein Komma. Die Datumsangaben kamen als echte Datumswerte an, weil das PDF das eindeutige Format Jahr-Monat-Tag verwendete.

Zum Schluss summiert sie die Bruttospalte und vergleicht das Ergebnis mit der Summe auf der letzten Seite der Übersicht. Es stimmt auf den Cent – also ist keine Zeile verloren gegangen oder zerteilt worden. Dieser eine Vergleich lohnt sich bei jeder umgewandelten Tabelle. Bei Kontoauszügen ist besondere Vorsicht geboten. Viele Banken drucken den laufenden Saldo in einer eigenen Spalte und lassen Zellen leer, wenn eine Buchung keine Soll- oder keine Habenseite hat. Nach der Umwandlung fallen solche Leerzellen manchmal weg, und in genau dieser Zeile rutscht eine Gutschrift in die Lastschriftspalte. Sortieren oder Filtern deckt das nicht auf, nur eine Summe oder eine Saldoformel im Vergleich mit dem gedruckten Saldo. Bauen Sie diese Prüfung einmal ein, dann können Sie die Tabelle für jeden folgenden Monat wiederverwenden.

Fehlerbehebung

Alles steht in Spalte A
Der Konverter konnte keine Spalten erkennen, oft weil das PDF Text mit Leerzeichen statt über Positionen ausgerichtet hat. Nutzen Sie Daten > Text in Spalten mit Leerzeichen als Trenner oder fester Breite.
Die Zahlen lassen sich nicht summieren
Sie sind als Text gespeichert. Entfernen Sie Währungssymbole und Tausendertrennzeichen und wandeln Sie die Zellen in Zahlen um; achten Sie auf Klammern, die als Minuszeichen dienen.
Aus einer PDF-Zeile wurden zwei Tabellenzeilen
Eine Zelle im PDF ist in eine zweite Zeile umgebrochen. Verbinden Sie die Teile mit einer Formel wie =A2&" "&A3 oder von Hand und löschen Sie dann die überzählige Zeile.
Die Arbeitsmappe enthält Bilder statt Zahlen
Das PDF ist ein Scan. Schicken Sie es zuerst durch OCR, wandeln Sie das Ergebnis um und prüfen Sie die Ziffern.
Der Auftrag ist in eine Zeitüberschreitung gelaufen
Große Berichte können länger dauern als die etwa drei Minuten, die das Tool wartet. Extrahieren Sie die Seiten mit den Tabellen und wandeln Sie nur diese um.
Konvertierung auf dem Server fehlgeschlagen
Prüfen Sie, ob das PDF nach einem Passwort fragt oder beschädigt ist. Entfernen Sie den Schutz oder nutzen Sie PDF reparieren und versuchen Sie es erneut.

Häufig gestellte Fragen

Bekomme ich ein Tabellenblatt pro Seite oder eines für alles?

Das hängt davon ab, wie die Konvertierungs-Engine Ihr Dokument liest; mehrseitige Tabellen werden oft nach Seiten aufgeteilt. Bei Bedarf fügen Sie sie per Kopieren und Einfügen oder mit Power Query zusammen.

Kommen die Formeln aus der ursprünglichen Tabelle zurück?

Nein. Ein PDF speichert nur die angezeigten Werte. Die Arbeitsmappe enthält also Zahlen und Text, nicht die Formeln, die sie erzeugt haben.

Kann das Tool Tabellen aus gescannten Dokumenten lesen?

Erst nach OCR. Nutzen Sie zuerst das OCR-Tool, wandeln Sie dann um und prüfen Sie die Zahlen sorgfältig.

Funktioniert das mit Google Tabellen oder LibreOffice?

Ja. Die Ausgabe ist eine Standard-.xlsx-Datei, die beide öffnen können.

Warum sind manche Datumsangaben falsch?

Angaben wie 03/04 sind mehrdeutig. Excel deutet sie nach Ihren Ländereinstellungen – vergleichen Sie also ein paar Daten mit dem PDF.

Wird die Datei hochgeladen?

Ja, dieses Tool nutzt einen serverseitigen Konverter. Das PDF wird verschlüsselt übertragen und nach der Umwandlung beim Dienst gelöscht.

PDF zuschneiden

Schneiden Sie Weißraum und Ränder auf allen Seiten gleichmäßig weg.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Mit diesem Werkzeug beschneiden Sie PDF-Seiten online, indem auf allen vier Seiten jeder Seite ein Rand Ihrer Wahl entfernt wird. Scans bringen schwarze Ränder mit, exportierte Folien schleppen riesige leere Flächen mit sich, und Fachartikel verstecken kleine Schrift in überbreiten Stegen — ein einziger Durchgang räumt damit auf. PDFora erledigt das direkt in Ihrem Browser mit lokaler Verarbeitung, das Dokument, das Sie zuschneiden, wird also nirgendwohin hochgeladen.

Das Werkzeug braucht nur eine Zahl: wie viele Punkte an jeder Kante abgeschnitten werden sollen. Ein Punkt entspricht 1/72 Zoll, ein Zuschnitt von 36 Punkten nimmt also oben, unten, links und rechts jeweils einen halben Zoll weg — und das auf einen Schlag für alle Seiten. Weil an jeder Kante derselbe Betrag verschwindet, bleibt die Seite zentriert und das Dokument durchgängig einheitlich, ohne von Seite zu Seite springende Ränder.

Das Werkzeug ist kostenlos, verlangt kein Konto und setzt kein Wasserzeichen auf das Ergebnis. Es gibt weder eine Seitenbegrenzung noch ein Tageslimit. Wurde beim ersten Durchgang zu wenig entfernt, schicken Sie das Ergebnis einfach mit einem größeren Wert erneut durch — jeder Durchlauf dauert nur Sekunden, denn nichts wandert zu einem Server.

So beschneiden Sie ein PDF online

  1. Öffnen Sie das Zuschneide-Werkzeug auf getpdfora.com und fügen Sie Ihr PDF per Klick oder Drag-and-drop hinzu.
  2. Überlegen Sie, wie viel Rand weg soll — 72 Punkte entsprechen einem Zoll, 28 Punkte etwa einem Zentimeter.
  3. Tragen Sie den Randwert ein. Derselbe Betrag wird auf jeder Seite oben, unten, links und rechts entfernt.
  4. Wenden Sie den Zuschnitt an und lassen Sie Ihren Browser die Datei lokal verarbeiten — ohne Upload, ohne Warteschlange.
  5. Laden Sie das beschnittene PDF herunter und prüfen Sie, dass weder Text noch Abbildungen angeschnitten wurden.
  6. Sind die Ränder immer noch zu breit, schicken Sie die beschnittene Datei mit einem höheren Wert erneut durch, bis das Ergebnis passt.

Wann Sie dieses Tool nutzen sollten

  • Die dunklen Ränder und Scannerschatten rund um eingescannte Seiten entfernen, damit das Dokument sauber ausgedruckt wird.
  • Bei wissenschaftlichen Aufsätzen die PDF-Ränder kürzen, bevor man sie auf Tablet oder E-Reader liest — der Text wird auf dem Bildschirm spürbar größer.
  • Als PDF exportierte Foliensätze straffen, indem der leere Rahmen um jede Folie wegfällt und der Inhalt die Seite füllt.
  • Vom Drucker hinzugefügten Weißraum aus Dokumenten schneiden, die mit den Standardrändern „als PDF gedruckt" wurden, um die niemand gebeten hatte.
  • Fahnenabzüge eines E-Books aufräumen, indem Beschnitt- und Anschnittzonen vor dem Versand eines Leseexemplars wegfallen.
  • Zeichnungen oder Formulare für den maßstabsgetreuen Nachdruck vorbereiten, indem der Rahmen aus dem ursprünglichen Layout entfernt wird.

Tipps für beste Ergebnisse

  • Fangen Sie vorsichtig an. Schneiden Sie zuerst 20 bis 30 Punkte weg und sehen Sie sich das Ergebnis an — nachschneiden können Sie jederzeit, angeschnittener Text zwingt Sie dagegen zurück zum Original.
  • Rechnen Sie kurz im Kopf um, bevor Sie tippen: 72 Punkte sind ein Zoll, 28,35 Punkte ein Zentimeter. Ein üblicher Büro-Seitenrand liegt bei etwa 72 Punkten.
  • Achten Sie auf Seitenzahlen und Fußzeilen dicht an der Kante; sie sind meist das Erste, was ein zu beherzter Zuschnitt schluckt.
  • Gleichmäßiges Beschneiden passt am besten zu einheitlich gesetzten Dokumenten; hat eine Seite ungewöhnlich enge Ränder, prüfen Sie sie vor dem Herunterladen gesondert.
  • Schneiden Sie zu, bevor Sie mit anderen PDFora-Werkzeugen Seitenzahlen oder Kopfzeilen einfügen — so richten sich die neuen Elemente an den endgültigen Seitenkanten aus.

Häufig gestellte Fragen

Wird meine Datei beim Zuschneiden hochgeladen?

Nein. Das Beschneiden geschieht vollständig in Ihrem Browser durch lokale Verarbeitung. Das PDF bleibt die ganze Zeit auf Ihrem Gerät, was das Werkzeug auch für vertrauliche oder unveröffentlichte Dokumente unbedenklich macht.

Wie funktioniert der Randwert?

Sie geben eine Breite in Punkten an, und dieser Betrag wird auf jeder Seite von allen vier Kanten entfernt. Ein Punkt entspricht 1/72 Zoll, ein Wert von 72 nimmt also genau einen Zoll pro Kante weg.

Kann ich jede Seite unterschiedlich stark beschneiden?

In diesem Werkzeug nicht — es entfernt oben, unten, links und rechts denselben Rand. Das hält die Seiten zentriert und ist genau das richtige Verhalten für Scans und einheitlich formatierte Dokumente.

Wird der weggeschnittene Inhalt dauerhaft gelöscht?

Der Zuschnitt verändert den sichtbaren Seitenbereich, und Ihre Ausgangsdatei wird dabei nie angetastet. Fällt das Ergebnis zu knapp aus, gehen Sie einfach zum Original zurück und schneiden mit einem kleineren Wert erneut zu.

Gibt es eine Grenze für Dateigröße oder Nutzungshäufigkeit?

Nein. Das Werkzeug ist kostenlos, unbegrenzt nutzbar und benötigt keine Anmeldung. Da alles lokal läuft, setzt allein Ihr eigenes Gerät die Grenze — kein Upload-Limit.

Enthält das beschnittene PDF ein Wasserzeichen?

Nein. PDFora druckt Ihrem Ergebnis niemals Werbung auf. Die heruntergeladene Datei ist Ihr Dokument mit engeren Rändern, sonst nichts.

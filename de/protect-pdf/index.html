PDF schützen

Eine PDF-Datei mit einem Passwort verschlüsseln, damit nur die richtigen Personen sie öffnen können.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Manche PDF-Dateien sollten sich nicht für jeden öffnen lassen: Gehaltsmitteilungen, Verträge, Befunde, Jahresabschlüsse. Das Werkzeug „Schützen“ von PDFora versieht eine PDF-Datei mit einer Passwortverschlüsselung, sodass sie nur öffnen kann, wer das Passwort kennt. Sie legen ein Passwort fest, laden die verschlüsselte Datei herunter und geben sie in dem Wissen weiter, dass eine weitergeleitete E-Mail oder ein verlorener USB-Stick den Inhalt nicht preisgibt.

Eine ehrliche Anmerkung vorweg: „Schützen“ wird bei PDFora gerade eingeführt und ist derzeit als demnächst verfügbar gekennzeichnet. Diese Seite beschreibt genau, wie das Werkzeug zum Start funktionieren wird, damit Sie wissen, was Sie erwartet. Wie jedes PDFora-Werkzeug wird es kostenlos sein, ohne Registrierung und ohne Wasserzeichen, und die Verschlüsselung wird lokal im Browser stattfinden – Ihr Dokument und Ihr Passwort gelangen nie zu einem Server.

Dieser letzte Punkt verdient Nachdruck. Es wäre reichlich seltsam, eine PDF-Datei mit einem Passwort zu schützen, indem man sie zunächst ungeschützt auf den Computer eines Fremden hochlädt. Der Ansatz von PDFora hält den gesamten Vorgang auf Ihrem Gerät: Die Datei wird in Ihrem Browser verschlüsselt, und nur die gesperrte Kopie verlässt Ihren Rechner – dann, wenn Sie sie bewusst weitergeben.

So schützen Sie eine PDF-Datei online mit einem Passwort

  1. Öffnen Sie auf getpdfora.com das Werkzeug „Schützen“ und wählen Sie die PDF-Datei aus, die verschlüsselt werden soll. Sie wird ohne Upload in Ihrem Browser geladen.
  2. Tippen Sie das Passwort ein, das zum Öffnen des Dokuments nötig sein soll.
  3. Geben Sie es ein zweites Mal zur Bestätigung ein – ein Tippfehler an dieser Stelle würde Sie aus Ihrer eigenen Datei aussperren.
  4. Wenden Sie den Schutz an. Das Werkzeug verschlüsselt die PDF-Datei lokal auf Ihrem Gerät.
  5. Laden Sie die geschützte Kopie herunter. Wer sie öffnet, wird nun nach dem Passwort gefragt.
  6. Geben Sie das Passwort getrennt von der Datei weiter – per Telefonat oder über einen anderen Messenger, niemals in derselben E-Mail.

Wann Sie dieses Tool nutzen sollten

  • Eine Gehaltsabrechnung oder Arbeitgeberbescheinigung als PDF verschlüsseln, bevor sie per E-Mail an eine Finanzierungsberatung geht.
  • Einen Kundenvertrag sperren, sodass nur die Gegenseite, die das Passwort erhält, die Konditionen lesen kann.
  • Exportierte Krankenunterlagen oder Laborbefunde schützen, bevor sie in einem geteilten Cloud-Ordner abgelegt werden.
  • Vorstandsunterlagen oder Jahresabschlüsse mit einem Passwort versehen, die an einen Verteiler geschickt werden.
  • Eine Kopie Ihres Reisepasses oder Ausweisscans absichern, bevor Sie sie an eine Buchungsagentur senden.
  • Personalunterlagen – Abmahnungen, Gehaltsgespräche – verschlüsseln, bevor sie auf einem gemeinsamen Bürolaufwerk landen.

Tipps für beste Ergebnisse

  • Nutzen Sie lieber eine Passphrase aus drei oder vier zusammenhanglosen Wörtern als ein kurzes Passwort; sie ist stärker und lässt sich am Telefon leichter durchgeben.
  • Schicken Sie das Passwort nie über denselben Kanal wie die Datei. Die PDF-Datei per E-Mail, das Passwort per SMS.
  • Bewahren Sie das Passwort an einem zuverlässigen Ort auf, etwa in einem Passwortmanager – ein vergessenes PDF-Passwort ist konstruktionsbedingt meist nicht wiederherstellbar.
  • Behalten Sie eine unverschlüsselte Kopie an einem sicheren, privaten Ort, damit Sie sich nie aus dem eigenen Dokument aussperren.
  • Verschlüsseln Sie, bevor Sie irgendetwas hochladen: erst die Datei schützen, dann in den Cloudspeicher oder in die E-Mail.

Häufig gestellte Fragen

Ist das Werkzeug „Schützen“ schon verfügbar?

Es ist als demnächst verfügbar gekennzeichnet und wird bei PDFora gerade eingeführt. Wenn Sie in der Zwischenzeit dringend eine PDF-Datei verschlüsseln müssen, erledigt das heute auch eine vertrauenswürdige Desktop-Anwendung wie LibreOffice (Export als PDF mit Passwort) oder Adobe Acrobat.

Wird es wie die anderen Werkzeuge kostenlos sein?

Ja. Zum Start wird „Schützen“ denselben Regeln folgen wie der Rest von PDFora: kostenlos, unbegrenzt nutzbar, ohne Registrierung und ohne Wasserzeichen auf Ihren verschlüsselten Dateien.

Werden meine Datei oder mein Passwort an einen Server gesendet?

Nein. Die Verschlüsselung wird lokal im Browser laufen, die PDF-Datei wird also auf Ihrem eigenen Gerät verschlüsselt und das Passwort verlässt es nie. Nur die fertige, gesperrte Datei landet in Ihrem Download-Ordner.

Wie stark ist die Passwortverschlüsselung bei PDF?

Moderne PDF-Verschlüsselung verwendet AES, dieselbe Verschlüsselungsfamilie, die im Banken- und Behördenumfeld zum Einsatz kommt. Der praktische Schwachpunkt ist fast immer das Passwort selbst – wählen Sie also ein langes, das sich nicht aus Ihrem Namen oder Geburtsdatum erraten lässt.

Was passiert, wenn ich das Passwort vergesse?

Eine ordentliche Verschlüsselung hat keine Hintertür, es gibt also keinen Wiederherstellungslink, und PDFora kann sie nicht für Sie zurücksetzen. Behandeln Sie PDF-Passwörter wie Haustürschlüssel: in einem Passwortmanager festhalten und von wichtigen Dokumenten eine unverschlüsselte Kopie an einem sicheren Ort behalten.

Kann ich ein Passwort später wieder entfernen, wenn ich es nicht mehr brauche?

Ja. Das ergänzende Werkzeug „Entsperren“ von PDFora ist genau dafür gedacht – ein bekanntes Passwort aus einer PDF-Datei zu entfernen, die Ihnen gehört, damit Sie es nicht bei jedem Öffnen eintippen müssen. Es wird parallel zu „Schützen“ eingeführt.

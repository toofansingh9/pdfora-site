Arbeitsabläufe

Verketten Sie mehrere PDF-Tools zu einer Abfolge und wenden Sie sie in einem Durchgang auf eine Datei an – jeweils mit den Standardeinstellungen des Tools.

🔒 Ihre Dateien werden lokal in Ihrem Browser verarbeitet und niemals hochgeladen.
1

Hochladen

Wählen Sie Ihre Datei aus oder ziehen Sie sie per Drag-and-drop.

2

Anpassen

Wählen Sie Ihre Optionen — alles geschieht in Ihrem Browser.

3

Herunterladen

Speichern Sie die fertige Datei sofort. Keine Wasserzeichen.

Wie oft laden Sie eigentlich dieselbe Datei dreimal hintereinander hoch und wieder herunter? Bei vielen Büroaufgaben ist das die Regel, denn sie kommen immer im Paket: Ein gescannter Vertrag braucht Seitenzahlen, ein Wasserzeichen und eine kleinere Datei; ein Bericht, der das Haus verlässt, soll reduzierte Formularfelder haben, keine Kommentare mehr enthalten und per Mail verschickbar sein. Tool für Tool heißt das: drei, vier Runden mit je einer Zwischendatei. „Arbeitsabläufe“ hängt die Schritte aneinander. Sie stellen eine Liste zusammen, legen ein PDF ab und bekommen eine fertige Datei namens ihredatei-workflow.pdf zurück.

Verketten lassen sich zwölf Tools: Komprimieren, Graustufen, 90° drehen, Wasserzeichen, Seitenzahlen, Ränder zuschneiden, Auf A4 skalieren, Reduzieren, Reparieren, Anmerkungen entfernen, Spiegeln und Metadaten aktualisieren. Abgearbeitet wird von oben nach unten, wobei die Ausgabe jedes Schritts die Eingabe des nächsten ist. Mit ↑ rückt ein Schritt nach oben, mit ✕ verschwindet er, und dasselbe Tool darf auch mehrfach in der Liste stehen.

Für das Tempo zahlen Sie einen Preis: Einstellungen pro Schritt gibt es nicht. Jeder Schritt arbeitet mit den weiter unten aufgeführten Standardwerten seines Tools, ein Arbeitsablauf lohnt sich also nur, wenn genau diese passen. Brauchen Sie einen eigenen Wasserzeichentext oder eine andere Drehrichtung, nehmen Sie das jeweilige Tool einzeln. Für Routinearbeit im Büro reichen die Standardwerte meist völlig: ein gängiges Vertraulichkeitskennzeichen, schlichte Seitenzahlen, A4 als Ausgabeformat und eine ausgewogene Komprimierung.

So wenden Sie mehrere PDF-Tools in einem Durchgang an

  1. Öffnen Sie „Arbeitsabläufe“. Wählen Sie in der Liste „Schritt hinzufügen…“ ein Tool und klicken Sie auf „Hinzufügen“. Wiederholen Sie das für jeden Schritt.
  2. Prüfen Sie die Reihenfolge. Die Schritte laufen ab 1 abwärts; mit ↑ ziehen Sie einen Schritt nach vorn, mit ✕ löschen Sie ihn.
  3. Legen Sie ein einzelnes PDF im Feld unter der Schrittliste ab oder klicken Sie darauf, um eine Datei auszuwählen.
  4. Behalten Sie die Statuszeile im Blick: Sie zeigt „Schritt 2/4: Wasserzeichen…“ usw., während die Tools nacheinander laufen.
  5. Meldet sie „Fertig ✓ — 4 Schritte angewendet.“, öffnen Sie die heruntergeladene -workflow.pdf und prüfen Sie, ob jeder Schritt das getan hat, was Sie erwartet haben.

Wann Sie dieses Tool nutzen sollten

  • Ein Handwerksbetrieb stempelt „CONFIDENTIAL“ auf Angebote und nummeriert die Seiten, bevor sie an den Bauherrn gehen.
  • Eine Hausverwaltung bringt Rechnungen und Protokolle aus verschiedenen Quellen auf A4, entfernt interne Kommentare und versieht alles mit Seitenzahlen, bevor es ins Eigentümerportal geht.
  • Ein Sekretariat entfernt Prüferkommentare und reduziert ausgefüllte Formulare, bevor die Akten archiviert werden.
  • Scans für ein Behördenportal vorbereiten, das kleine Graustufen-Dateien erwartet: erst Graustufen, dann Komprimieren.
  • Einen quer eingescannten Stapel korrigieren, bei dem jede Seite gedreht und das Ergebnis anschließend komprimiert werden muss.
  • Reparieren als ersten Schritt für Dateien aus einem Altsystem, die andere Tools gelegentlich ablehnen.

Das sollten Sie vorher wissen

  • Die Standardwerte sind fest: Komprimieren nutzt die Stufe „Empfohlen“; 90° drehen dreht jede Seite um 90° im Uhrzeigersinn; Wasserzeichen schreibt „CONFIDENTIAL“ in 50 pt, 30 % Deckkraft, diagonal; Seitenzahlen setzt schlicht 1, 2, 3 unten mittig in 11 pt, beginnend bei 1; Ränder zuschneiden entfernt 30 Punkt (etwa 10,5 mm) an jeder Seite; Auf A4 skalieren passt die Seiten in A4 ein; Spiegeln spiegelt horizontal.
  • Komprimieren, Graustufen und Spiegeln zeichnen jede Seite als JPEG-Bild neu. Jeder Schritt danach arbeitet mit Bildern von Seiten, und die fertige Datei hat keinen markierbaren Text, keine Links und keine Formularfelder. Stellen Sie diese Schritte ans Ende, sofern Sie genau das nicht wollen.
  • Metadaten aktualisieren ohne Werte ändert nur das Änderungsdatum der Datei. Titel und Autor bleiben unverändert, weil es in einem Arbeitsablauf kein Feld gibt, um sie einzutragen.
  • Pro Durchgang lässt sich nur ein PDF verarbeiten. Sollen mehrere Dateien gleich behandelt werden, legen Sie sie nacheinander ab; die Schrittliste bleibt zwischen den Durchgängen stehen.
  • Die Schrittliste wird nicht gespeichert. Neuladen oder Schließen der Seite leert sie, notieren Sie sich also Abläufe, die Sie regelmäßig nutzen. Für einen Stapel von einem Dutzend ähnlicher Dateien ist das trotzdem praktisch, auch wenn jede einzeln abgelegt werden muss.
  • Schlägt ein Schritt fehl, bricht der Durchgang mit dessen Fehlermeldung ab, und es wird nichts heruntergeladen. Frühere Schritte werden nicht separat gespeichert.

Tipps für beste Ergebnisse

  • Setzen Sie Reparieren an den Anfang, wenn eine Datei anderswo schon Ärger gemacht hat; dann bekommt jeder spätere Schritt ein sauber neu aufgebautes Dokument.
  • Bei Stempeln zählt die Reihenfolge: Setzen Sie Seitenzahlen und Wasserzeichen hinter Auf A4 skalieren und Ränder zuschneiden, sonst wird der Stempel vom späteren Schritt verkleinert oder abgeschnitten.
  • Reduzieren gehört vor Komprimieren. Komprimieren macht die Seiten ohnehin zu Bildern, aber durch vorheriges Reduzieren sind ausgefüllte Formularwerte sicher auch im Bild zu sehen.
  • Testen Sie einen neuen Arbeitsablauf an einer kurzen Datei, bevor Sie ein 200-seitiges Dokument durchschicken. Zwei, drei Seiten genügen, um zu sehen, ob die Stempel richtig sitzen und die Qualität nach dem Komprimieren in Ordnung ist.
  • Zweimal 90° drehen ergibt eine Drehung um 180°, dreimal ergibt 90° gegen den Uhrzeigersinn.

Praxisbeispiel: Monatsunterlagen einer Hausverwaltung

Eine Sachbearbeiterin bei einer Hausverwaltung in Wien stellt jeden Monat für die Eigentümer mehrerer Wohnhäuser die Unterlagen zusammen: Handwerkerrechnungen, Protokolle und Angebote, teils eingescannt, teils als PDF vom Lieferanten, teils mit Kommentaren der Kollegen versehen. Bevor die Dateien ins Eigentümerportal gehen, sollen alle auf A4 gebracht, durchnummeriert und frei von internen Anmerkungen sein. Diesen Monat sind es 14 Dateien – mit drei Tools einzeln wären das 42 Durchgänge.

Sie baut den Ablauf so: 1 Reparieren, 2 Anmerkungen entfernen, 3 Auf A4 skalieren, 4 Seitenzahlen. Reparieren steht vorne, weil ein paar Scans aus dem alten Kopierer in anderen Programmen schon Probleme gemacht haben. Die Kommentare fliegen vor dem Skalieren raus, und die Seitenzahlen kommen zuletzt, damit sie auf der fertigen A4-Seite unten mittig sitzen und nicht durch das Skalieren verkleinert oder verschoben werden. Jede Datei legt sie einmal ab, heraus kommt etwa rechnung-dachrinne-workflow.pdf. Ein Wasserzeichen lässt sie bewusst weg: Der Standardtext „CONFIDENTIAL“ wirkt auf Unterlagen für Wohnungseigentümer fehl am Platz, und ein eigener Text ist im Arbeitsablauf nicht einstellbar.

Komprimieren nimmt sie ebenfalls nicht in die Kette, obwohl einige Scans recht groß sind. Der Schritt würde jede Seite in ein Bild verwandeln, und die Eigentümer sollen in den Rechnungen nach Beträgen und Firmennamen suchen können. Die drei Dateien, die für das Portal zu groß sind, komprimiert sie hinterher einzeln. So bleibt der Großteil durchsuchbar, und nur wo es nötig ist, wird die Datei kleiner.

Fehlerbehebung

„Fügen Sie zuerst mindestens einen Schritt hinzu.“
Die Schrittliste ist leer. Wählen Sie in der Liste „Schritt hinzufügen…“ ein Tool und klicken Sie auf „Hinzufügen“, bevor Sie das PDF ablegen.
Wasserzeichen oder Seitenzahlen sitzen an der falschen Stelle
Ein späterer Schritt hat die Seitengeometrie verändert. Schieben Sie Auf A4 skalieren, Ränder zuschneiden und Drehen mit dem Button ↑ über Wasserzeichen und Seitenzahlen und starten Sie erneut.
Mein Text lässt sich nicht mehr markieren
Komprimieren, Graustufen oder Spiegeln steckt in der Kette; diese erzeugen reine Bildseiten. Entfernen Sie sie, oder stellen Sie sie ans Ende und nehmen Sie Bildseiten im Ergebnis in Kauf.
Der Durchgang bricht bei einem Schritt mit einem Fehler ab
Dieses Tool konnte die Datei an dieser Stelle nicht verarbeiten, oft weil sie passwortgeschützt oder beschädigt ist. Fügen Sie Reparieren als Schritt 1 hinzu oder beheben Sie das Problem vorher, und starten Sie den Ablauf erneut. Die Statuszeile nennt den fehlgeschlagenen Schritt – so wissen Sie, welches Tool Sie einzeln testen sollten.
Meine Schritte sind verschwunden
Die Liste existiert nur, solange die Seite geöffnet ist. Bauen Sie sie neu auf und notieren Sie sich bei wiederkehrenden Abläufen kurz die Reihenfolge.
Ich brauche einen anderen Wasserzeichentext oder eine andere Drehung
Arbeitsabläufe nutzen immer die Standardeinstellungen. Lassen Sie „Wasserzeichen“ oder „PDF drehen“ einzeln mit Ihren Einstellungen laufen und nutzen Sie „Arbeitsabläufe“ für die übrigen Schritte.

Häufig gestellte Fragen

Kann ich für einen einzelnen Schritt andere Einstellungen wählen?

Nein. Jeder Schritt läuft mit den Standardeinstellungen seines Tools. Wer eigene Optionen braucht, nimmt das Tool einzeln.

Lässt sich ein Arbeitsablauf auf mehrere PDFs zugleich anwenden?

Nicht in einem Durchgang. Die Dateien werden nacheinander verarbeitet, die Schrittliste bleibt aber stehen, sodass Sie gleich die nächste Datei ablegen können.

Kann ich meinen Ablauf speichern und später wiederverwenden?

Im Moment nicht. Die Schritte bleiben nur erhalten, solange die Seite geöffnet ist.

Warum kann ich nicht jedes Tool als Schritt einfügen?

Ein Schritt muss ein PDF entgegennehmen und ein PDF zurückgeben. Tools, die mehrere Dateien brauchen, eine ZIP erzeugen, Bilder oder Text exportieren oder auf eine Serverkonvertierung angewiesen sind, lassen sich nicht verketten.

Wird meine Datei dabei auf einen Server geladen?

Nein. Alle zwölf verkettbaren Tools laufen in Ihrem Browser-Tab; das PDF wandert im Arbeitsspeicher von Schritt zu Schritt, und nur das Endergebnis wird heruntergeladen.

Was passiert, wenn dasselbe Tool zweimal in der Liste steht?

Es läuft zweimal. Zwei Drehschritte ergeben 180°; zwei Komprimierschritte bringen meist kaum noch Ersparnis, kosten aber zusätzlich Qualität.

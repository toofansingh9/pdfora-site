Grayscale PDF

Turn a colour PDF into a black-and-white one by redrawing every page in shades of grey, ready for cheap mono printing or strict upload rules.

Some portals and print shops want grayscale only. A court e-filing system may reject colour scans, a school may ask for black-and-white handouts to save toner, and a printer billing per colour page will charge you for a single blue logo in the footer. PDFora's grayscale tool removes every trace of colour from a PDF so that it prints and uploads as a true mono document. This page explains how it does that, because the method has consequences you should know about before you rely on it.

The tool does not edit colour values inside the PDF. It renders each page to an image at twice the PDF's base resolution (about 144 pixels per inch), converts every pixel to grey using the standard luminance weights of 29.9% red, 58.7% green and 11.4% blue, and then places that grey image on a new page of exactly the original size as a JPEG at 85% quality. The weights matter: a pure red heading becomes a fairly dark grey, while a bright yellow highlight turns into a pale grey that can almost vanish on paper.

Because every page becomes a picture, the result is visually faithful but structurally simpler than the original. Text can no longer be selected or searched, links stop being clickable, and form fields and bookmarks are gone. For printing that rarely matters; for a document someone will search later, it does, and the tips below show how to get around it.

How to convert a PDF to grayscale

  1. Open the Grayscale tool and add one PDF by dropping it on the box or clicking to choose it.
  2. Click Convert to grayscale. Each page is rendered, converted and re-embedded in turn; the progress bar moves page by page.
  3. Wait for the download to appear. A 10-page document finishes in seconds, a 200-page scan takes noticeably longer on a phone.
  4. Download the file, which is saved with -gray added to the original name, for example report-gray.pdf.
  5. Open it at 100% zoom and check small print, coloured charts and any highlighted passages before you print or upload it.

When to use this tool

  • Court and government filings that accept only black-and-white PDF attachments.
  • School worksheets and exam papers printed in bulk on a mono photocopier, where colour pages slow the queue or cost extra.
  • Preparing a proof copy to see whether a design still reads without colour, for example a chart that relies on red versus green.
  • Archiving receipts and statements where colour adds nothing and a uniform look is preferred.
  • Sending documents to a print shop that charges per colour page, so a stray coloured logo does not turn a 60-page job into a colour job.
  • Making slides readable for someone who prints them on a home laser printer without colour toner.

What to know before you start

  • Every page is rasterised. The output contains one JPEG image per page and no live text, so copy-paste, search and screen readers will not find anything until you run OCR.
  • Resolution is fixed at about 144 pixels per inch. That is comfortable for reading and normal printing, but very small text (6 pt and below) and fine line drawings can look softer than in the original.
  • File size can go up or down. A digital, text-only PDF of 200 KB often grows several times over because text becomes pictures; a colour scan usually shrinks because the grey JPEG carries less data.
  • Links, bookmarks, form fields, comments and attachments are not carried into the new file. The page appearance is kept, the structure behind it is not.
  • Colours with similar brightness become the same grey. A red line and a green line of similar luminance on a chart will be indistinguishable; add labels or patterns at the source if that matters.
  • Only one file is processed at a time. To convert several documents, run them one after another or merge them first and convert the merged file.

Tips for the best results

  • Keep the colour original. The grayscale copy cannot be turned back into colour, and it has lost its text layer.
  • If the grey version must stay searchable, run the result through OCR to extract its text, or convert only the pages that really need it after splitting the file.
  • Check yellow and light-green highlighting. These map to very light greys; if the highlight is the point of the page, darken it in the source before converting.
  • For a text-only document headed to a mono printer, you may not need this tool at all: most print dialogs have a grayscale option that keeps the PDF intact.
  • If the grey file is too big for an upload limit, run it through Compress PDF afterwards; it is already an image-based file, so compression works well on it.

A worked example: a landlord's inspection report

A landlord prepares a 14-page move-in inspection report with colour photos of each room and a red-amber-green condition rating in a table. The tenancy deposit scheme asks for the report as a black-and-white PDF, and the landlord will also print two copies on an office laser printer that only has black toner.

Converted to grayscale, the room photos keep their detail and look like ordinary mono prints. The rating table is the weak spot: green and red cells of similar brightness come out as almost the same mid-grey, so the colour code no longer carries meaning. The fix is in the source document, not in the converter: add the words Good, Fair and Poor to each cell, export again, then convert. The words survive, the colours do not need to.

The landlord also keeps the colour PDF. If a dispute arises later and a photo of a damp patch needs to be shown in colour, the original is still there, and its text can still be searched for room names.

Troubleshooting

I can no longer select or search the text
That is a direct result of how the tool works: each page is now a single grey image. Run the grey file through OCR to get its text, or keep the colour original for searching.
Small text looks blurry when I zoom in
Pages are rendered at about 144 pixels per inch, which is softer than vector text at high zoom. It prints fine at normal size; for documents with tiny footnotes, a print-dialog grayscale option will keep the text sharp.
The grey file is much bigger than the original
The original was probably a digital PDF where text is stored as characters, which is tiny. As images the same pages take more space. Compress the result, or use your printer's grayscale setting instead of converting.
Highlighted passages disappeared
Yellow and other bright colours convert to very light grey. Darken the highlight colour or underline the passage in the source, then convert again.
The tool fails or the tab stops responding
Very long or very large documents are rendered one page at a time in your browser's memory. Close other tabs, try a desktop computer, or split the file and convert the parts separately.
The file will not open in the tool
It may be damaged or password-protected. Try Repair PDF first; for a protected file, remove the password in the program that created it.

Frequently asked questions

Does the tool change colours inside the PDF or redraw the pages?

It redraws them. Each page is rendered to an image, every pixel is converted to grey with luminance weights, and the grey image is placed on a new page of the same size.

Will the page size and layout stay the same?

Yes. Each new page uses the width and height of the original page, and the image fills it exactly, so margins and positions do not move.

Is the result true grayscale or just desaturated colour?

Each pixel has equal red, green and blue values, so it looks grey everywhere. The embedded JPEG is stored in RGB, so a strict prepress check that demands a DeviceGray colour space may still flag it.

Can I convert only some pages?

Not directly. Split out the pages you want with Split PDF, convert those, then merge them back with the untouched pages.

Does it keep hyperlinks and bookmarks?

No. The output is built from page images, so links, bookmarks and form fields are not included.

Are my files uploaded during conversion?

No. Rendering and the grey conversion happen in your browser with PDF.js and pdf-lib, so the document stays on your computer or phone.

Sblocca PDF

Togli la password di apertura e le restrizioni su stampa, copia e modifica da un PDF che hai il diritto di sbloccare, direttamente nel browser.

🔒 I tuoi file vengono elaborati localmente nel browser e non vengono mai caricati.
1

Carica

Seleziona il tuo file o trascinalo.

2

Regola

Scegli le tue opzioni — tutto avviene nel tuo browser.

3

Scarica

Salva subito il file finito. Nessuna filigrana.

Cedolini, estratti conto e comunicazioni dell'assicurazione arrivano spesso bloccati da una password ricavata dal codice fiscale, dalla data di nascita o da un numero di pratica. Ha senso finché il file viaggia per e-mail, ma dopo diventa un ostacolo: i portali di agenzie e banche rifiutano i caricamenti crittografati, e gli strumenti per unire, comprimere o fare l'OCR non riescono ad aprirli. Sblocca PDF salva una copia senza password, che si apre subito e funziona con tutti gli altri strumenti del sito.

Sbloccare non significa forzare. Se il PDF chiede una password all'apertura, lo strumento ha bisogno di quella password: la verifica, la usa per decifrare il contenuto e scrive una copia senza crittografia e senza restrizioni. Se la password è sbagliata te lo dice e si ferma, senza tentare di indovinarla. I file che si aprono senza richieste ma bloccano stampa, copia o modifica sono un caso diverso: il loro contenuto è già leggibile, quindi lo strumento può togliere quelle restrizioni senza alcuna password.

Il lavoro lo svolge qpdf, una libreria PDF open source compilata in WebAssembly, che viene caricata nella scheda del browser da questo sito al primo utilizzo (circa 1,3 MB). Il file e la password che digiti restano sul tuo dispositivo. Le pagine non vengono ridisegnate, quindi il testo resta selezionabile, link e segnalibri continuano a funzionare e il risultato è identico all'originale protetto.

Come togliere la password a un PDF

  1. Apri Sblocca PDF e aggiungi un file protetto.
  2. Se il PDF chiede una password quando lo apri, digitala in Password attuale. Se si apre senza richieste e blocca solo stampa o copia, lascia il campo vuoto.
  3. Clicca su Sblocca PDF. Lo strumento controlla prima se il file è davvero protetto e se la password è giusta.
  4. Scarica tuofile-unlocked.pdf.
  5. Apri la nuova copia per verificare che non chieda più la password, poi prosegui con Unisci PDF, Comprimi PDF o lo strumento che ti serviva.

Quando usare questo strumento

  • Cedolini protetti con il codice fiscale che l'agenzia immobiliare o la banca vuole ricevere in un unico PDF.
  • Estratti conto o certificazioni che un portale per il mutuo, l'affitto o una pratica online rifiuta perché crittografati.
  • Tuoi vecchi documenti, protetti anni fa con una password che ricordi ancora ma che non vuoi più digitare a ogni apertura.
  • Una relazione che si apre liberamente ma ha la stampa disattivata, quando ne sei l'autore o hai il consenso del proprietario per stamparla.
  • File che devono passare da Comprimi PDF, OCR PDF, Dividi PDF o Numeri di pagina, che non funzionano sui PDF crittografati.
  • Archivi personali in cui l'accesso futuro non deve dipendere dal ricordare una password diversa per ogni file.

Cosa sapere prima di iniziare

  • Se il PDF richiede una password per aprirsi, devi fornirla. Lo strumento la verifica prima e mostra «Password errata — il file non è stato sbloccato.» invece di scrivere un file rovinato.
  • Non può recuperare né forzare una password dimenticata. Un file crittografato a dovere resta chiuso senza la sua password; chiedi al mittente la password o una copia non protetta.
  • I file che si aprono senza password ma hanno restrizioni sui permessi vengono sbloccati senza chiederne una, e le restrizioni su stampa, copia e modifica vengono rimosse tutte.
  • Se il file non ha alcuna protezione, lo strumento ti avvisa con «Questo PDF non è protetto da password — non c'è nulla da rimuovere.» invece di produrre una copia identica.
  • La rimozione è totale: se ne vanno la crittografia e tutte le restrizioni. Non c'è modo di conservarne solo alcune; se le rivuoi, passa la copia sbloccata in Proteggi PDF con le nuove impostazioni.
  • Usalo solo sui file che hai il diritto di sbloccare: documenti tuoi o di cui il proprietario è d'accordo. Le restrizioni di un e-book o di un report a pagamento di solito sono volute, e toglierle può violare le condizioni d'uso o il diritto d'autore.

Consigli per risultati migliori

  • Rileggi l'e-mail o la lettera che accompagnava il file protetto: il formato della password, per esempio il codice fiscale in maiuscolo o la data di nascita in GGMMAAAA, di solito è spiegato lì.
  • Digita la password invece di incollarla. Le password incollate spesso si portano dietro uno spazio finale invisibile, che basta a renderle sbagliate.
  • Sblocca una copia di lavoro e tieni l'originale protetto come documento di riferimento.
  • Se un portale rifiuta il caricamento con parole come «crittografato», «protetto» o «password», la soluzione è sbloccare il file.
  • Elimina le copie sbloccate che ti servivano solo per poco e, se devi inoltrare il risultato per e-mail, proteggilo di nuovo con Proteggi PDF.

Esempio: tre cedolini per l'affitto di un bilocale

Una giovane infermiera che si trasferisce a Milano deve caricare sul portale di un'agenzia immobiliare gli ultimi tre cedolini e la Certificazione Unica, riuniti in un solo PDF. I cedolini arrivano dal portale dell'ospedale, ciascuno protetto da una password che coincide con il suo codice fiscale. Ogni cedolino è di 2 pagine e circa 180 KB, e il portale dell'agenzia rifiuta i file crittografati.

Passa i tre cedolini in Sblocca PDF digitando ogni volta lo stesso codice. Il primo file richiede qualche secondo, il tempo di caricare il motore; gli altri due sono pronti quasi subito, con il testo ancora selezionabile e dimensioni praticamente invariate. Al secondo cedolino scrive il codice fiscale in minuscolo e lo strumento risponde «Password errata — il file non è stato sbloccato.»; lo riscrive in maiuscolo e tutto va a buon fine. Le tre copie finiscono poi in Unisci PDF insieme alla Certificazione Unica, che non era protetta, e ne esce un file di 10 pagine da circa 900 KB che il portale accetta.

Una volta inviata la domanda, elimina dalla cartella Download le copie sbloccate e il file unito, e conserva i cedolini protetti originali sul portale dell'ospedale come documenti ufficiali. La password ha fatto il suo lavoro finché i cedolini viaggiavano; sul suo computer, toglierla da una copia di lavoro è un passaggio normale, purché il file sbloccato non riparta senza protezione.

Risoluzione dei problemi

Dice che il PDF richiede la password di apertura
Il file è crittografato con una password di apertura. Digitala in Password attuale e avvia di nuovo lo strumento.
Dice «Password errata»
Controlla il blocco delle maiuscole, il layout della tastiera e un eventuale spazio finale, e rileggi il formato indicato dal mittente. Alcuni enti usano lettere maiuscole, altri minuscole.
Dice che il PDF non è protetto da password
Non c'è nulla da togliere. Se un altro strumento continua a rifiutare il file, probabilmente è danneggiato più che protetto; prova Ripara PDF.
Non conosco la password
Lo strumento non può trovarla né indovinarla. Cercala nell'e-mail o nella lettera arrivata con il file, oppure chiedi al mittente la password o una copia non protetta.
Il motore di crittografia non si carica
Viene scaricato da questo sito al primo utilizzo. Un blocco degli script, un filtro aziendale o una connessione molto lenta possono impedirlo; ricarica la pagina e riprova.
Dice che non è possibile sbloccare questo PDF
Probabilmente il file è danneggiato. Aprilo nel tuo lettore con la password e usa Stampa in PDF o salvane una copia, poi sblocca o ripara quella copia.

Domande frequenti

Sblocca PDF può togliere una password che non conosco?

No. Per i file che la chiedono serve la password di apertura, e lo strumento non indovina né forza le password. Toglie le restrizioni senza password solo quando il file si apre già liberamente.

Il mio file o la mia password vengono caricati?

No. Il motore di sblocco funziona dentro il browser. Il PDF e la password restano sul tuo dispositivo e non resta nulla dopo che chiudi la scheda.

Toglie anche le restrizioni su stampa e copia?

Sì. La copia sbloccata non ha crittografia né restrizioni sui permessi, quindi si può stampare, copiare e modificare con qualsiasi lettore.

Lo sblocco cambia il contenuto o la qualità?

No. Le pagine non vengono ridisegnate. Testo, immagini, link e segnalibri restano com'erano; sparisce solo la crittografia.

È legale togliere la password a un PDF?

Togliere la protezione ai propri documenti, o con il permesso del proprietario, in genere non è un problema. Rimuovere le restrizioni da contenuti su cui non hai diritti può violare le condizioni dell'editore o il diritto d'autore.

Posso sbloccare più cedolini insieme?

Lo strumento lavora su un file alla volta. Dopo il primo passaggio il motore è già caricato, quindi ogni file successivo richiede solo un attimo.

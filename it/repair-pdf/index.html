Ripara PDF

Rileggi un PDF su cui altri programmi si bloccano e salvalo di nuovo con una struttura del file pulita e ricostruita.

🔒 I tuoi file vengono elaborati localmente nel browser e non vengono mai caricati.
1

Carica

Seleziona il tuo file o trascinalo.

2

Regola

Scegli le tue opzioni — tutto avviene nel tuo browser.

3

Scarica

Salva subito il file finito. Nessuna filigrana.

Un PDF non è un unico flusso di contenuto: è un insieme di oggetti numerati più una tabella dei riferimenti incrociati che indica al lettore dove comincia ciascun oggetto. Quando un download si interrompe, un programma scrive male la tabella o un file passa per le mani di diversi strumenti uno dopo l'altro, quella tabella può puntare ai posti sbagliati. Alcuni visualizzatori se la cavano in silenzio, altri mostrano pagine bianche, e i portali di caricamento spesso rifiutano il file con un errore generico. Ripara PDF è pensato proprio per questa via di mezzo: file disordinati nella struttura, ma con il contenuto ancora presente.

Lo strumento fa una cosa precisa. Carica il file con la libreria pdf-lib, che legge gli oggetti che riesce a trovare e ricostruisce la struttura da sé invece di fidarsi di una tabella rotta, poi salva una copia nuova. Il nuovo file ha una tabella dei riferimenti incrociati scritta da zero, e ogni oggetto viene scritto singolarmente invece di essere impacchettato in flussi di oggetti compressi: una disposizione più tradizionale che i lettori più vecchi o più rigidi accettano meglio. Il contenuto delle pagine viene copiato, non ridisegnato, quindi testo, font e immagini restano identici.

Meglio essere chiari sui limiti. È una ricostruzione, non un recupero dati. Se mancano davvero dei byte, per esempio la seconda metà di un download interrotto, non c'è nulla da cui ricostruire quelle pagine, e nessuno strumento può inventarle. In quel caso la soluzione giusta è procurarsi una copia nuova del file dalla fonte.

Come riparare un file PDF

  1. Apri Ripara PDF e carica il file che dà problemi. Si elabora un solo file per volta.
  2. Fai clic su Ripara e ricostruisci. Il file viene analizzato e salvato di nuovo; per la maggior parte dei documenti bastano un paio di secondi.
  3. Se lo strumento segnala un errore, il file non è stato proprio letto: vai alla sezione sui problemi più sotto.
  4. Scarica il risultato, salvato con il nome originale più -repaired, per esempio contratto-repaired.pdf.
  5. Apri la copia riparata nel visualizzatore o nel portale che prima non funzionava e sfogliala per verificare che ogni pagina abbia il suo contenuto.

Quando usare questo strumento

  • La piattaforma dell'università rifiuta il PDF della tesi come non valido, anche se sul tuo portatile si apre senza problemi.
  • Un file esportato da un vecchio scanner o da un gestionale contabile si apre in un visualizzatore e mostra pagine bianche in un altro.
  • Un PDF modificato tante volte con programmi diversi è diventato lento o all'apertura avvisa che è danneggiato.
  • Preparare un file per una copisteria o per un sistema di deposito telematico il cui validatore è più severo di un normale visualizzatore.
  • Normalizzare un documento prima di unirlo o dividerlo, quando quegli strumenti si rifiutano di caricare l'originale.
  • Controllare in fretta se un file è leggibile a livello di struttura prima di chiedere al mittente di esportarlo di nuovo.

Cosa sapere prima di iniziare

  • La riparazione ricostruisce la struttura, non recupera il contenuto perso. Un file troncato tornerà, nel migliore dei casi, con le sole pagine che erano complete.
  • Il file in uscita viene scritto senza flussi di oggetti compressi. Questo lo rende più compatibile ma spesso un po' più pesante dell'originale, a volte del 10-30 percento nei file che usavano molto i flussi di oggetti.
  • Le pagine vengono copiate così come sono. Se una pagina appariva sbagliata perché il suo flusso di contenuto è corrotto, può continuare ad apparire sbagliata anche dopo la ricostruzione.
  • Il file viene aperto con i controlli di cifratura disattivati. Un PDF protetto da password potrebbe caricarsi, ma il contenuto resta cifrato e difficilmente la copia salvata si vedrà correttamente; togli prima la password all'origine.
  • Moduli, segnalibri e annotazioni che pdf-lib riesce a leggere passano nel nuovo file, perché viene salvato l'intero documento e non solo le pagine.
  • Tutto avviene nel tuo browser, quindi puoi provare anche con un file che non manderesti mai a un servizio di recupero online.

Consigli per risultati migliori

  • Tieni sempre l'originale accanto alla copia riparata finché non hai controllato il risultato pagina per pagina.
  • Confronta il numero di pagine del file riparato con quello che ti aspettavi. Un numero più basso è il segnale più chiaro che l'originale era troncato.
  • Se un portale rifiuta ancora il file riparato, prova a stamparlo in PDF dal tuo visualizzatore: così ogni pagina viene ridisegnata e si risolvono problemi interni al contenuto che una ricostruzione non tocca.
  • Se il file ti è arrivato per email o da un download, chiedilo di nuovo prima di perdere tempo a ripararlo. Una copia integra vale più di qualsiasi riparazione.
  • Dopo una riparazione riuscita, usa Comprimi PDF se il file è cresciuto ed è composto soprattutto da scansioni.

Un esempio concreto: le fatture di un traduttore freelance

Marco, traduttore freelance a Padova, esporta da un vecchio programma di fatturazione le dodici fatture mensili in un unico PDF da allegare alla documentazione per la dichiarazione dei redditi. Il file si apre nel visualizzatore del browser, ma il modulo di caricamento lo rifiuta come documento non valido e Unisci PDF non riesce ad aggiungerlo al resto delle carte.

Passato in Ripara PDF, il file si carica, riceve una tabella dei riferimenti incrociati riscritta e viene salvato senza flussi di oggetti. Il modulo di caricamento accetta la copia riparata e lo strumento di unione ora la legge. Il file è passato da 410 KB a circa 460 KB: è il prezzo della disposizione più tradizionale e qui non ha alcuna importanza.

Prima di inviarlo, Marco conta le pagine: dodici fatture, dodici pagine. Se fossero state nove, l'esportazione originale sarebbe stata incompleta, e l'unica vera soluzione sarebbe stata esportarla di nuovo dal programma di fatturazione.

Risoluzione dei problemi

Lo strumento mostra un errore e non produce nulla
Il file non è stato proprio letto, di solito perché non è davvero un PDF (per esempio una pagina di errore HTML salvata con estensione .pdf) o è troncato in modo grave. Aprilo con un editor di testo: un vero PDF inizia con %PDF. Altrimenti procurati una copia nuova.
Nel file riparato mancano alcune pagine
Quelle pagine non erano presenti in forma leggibile nell'originale, di solito perché il download si è interrotto. Scarica o esporta di nuovo il documento.
Le pagine sono ancora bianche o illeggibili
È danneggiato il contenuto stesso della pagina, che una ricostruzione della struttura non tocca. Prova a stampare l'originale in PDF dal visualizzatore che lo mostra meglio, oppure chiedi al mittente una nuova esportazione.
Il file riparato è più grande dell'originale
Lo strumento scrive gli oggetti uno per uno invece che in flussi di oggetti compressi. È voluto, per compatibilità; se il peso conta, comprimi il risultato.
La copia riparata mostra contenuto illeggibile
Probabilmente l'originale era cifrato. La cifratura viene ignorata in fase di caricamento, quindi il contenuto resta incomprensibile. Togli la password nel programma che ha creato il file e ripara quella copia.
Il portale rifiuta ancora il file
Il validatore potrebbe contestare altro, come il peso del file, il formato delle pagine o i font incorporati. Controlla i requisiti indicati dal portale e, a seconda dei casi, ridimensiona, comprimi o stampa in PDF.

Domande frequenti

Cosa cambia esattamente Ripara PDF?

Rilegge gli oggetti del documento, scrive una nuova tabella dei riferimenti incrociati e salva ogni oggetto singolarmente, senza flussi di oggetti. Il contenuto delle pagine viene copiato invariato.

Può recuperare un PDF che non si apre da nessuna parte?

A volte. Se gli oggetti sono integri e solo la struttura è rotta, sì. Se mancano proprio i dati o il file non è un PDF, nessuno strumento di riparazione può riportarlo indietro.

La riparazione peggiora la qualità?

No. Nulla viene ridisegnato o ricompresso, quindi testo e immagini restano identici.

Perché il file è diventato più grande?

Nel file in uscita non si usano flussi di oggetti compressi: il file pesa un po' di più, ma lo leggono anche programmi più vecchi e più rigidi.

La riparazione toglie la password?

No. Non decifra nulla, e un file cifrato di solito non si vedrà correttamente dopo la ricostruzione.

Posso riparare più file insieme?

Lo strumento accetta un file alla volta. Elaborali uno dopo l'altro: con documenti normali è un'operazione rapida.

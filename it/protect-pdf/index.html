Proteggi PDF

Come funziona la protezione con password di un PDF, cosa farà il futuro strumento Proteggi di PDFora e come mettere una password già oggi.

Partiamo dalla situazione reale: lo strumento Proteggi PDF non funziona ancora. Se scegli un file e premi il pulsante, compare un messaggio che dice che la protezione con password arriverà presto. Serve un percorso di elaborazione dedicato che è ancora in costruzione, e preferiamo dirlo chiaramente piuttosto che offrire uno strumento che produce un file solo in apparenza protetto. In questa pagina trovi come funzionano le password dei PDF, cosa farà lo strumento e come proteggere un file subito con programmi che con ogni probabilità hai già sul computer.

La sicurezza dei PDF prevede due password diverse, e confonderle è l'errore più frequente. La password di apertura (detta anche password utente) cifra il file: senza di essa il contenuto non si legge proprio. La password dei permessi (password proprietario) lascia aprire il file a chiunque, ma chiede al programma di lettura di limitare alcune azioni, come stampare, copiare il testo o modificare. La prima è una protezione vera; la seconda funziona solo se il lettore PDF rispetta quei vincoli, e parecchi programmi li ignorano.

Il livello di protezione dipende dalla cifratura usata. I programmi PDF moderni usano AES con chiavi a 128 o 256 bit; i file più vecchi possono usare RC4, considerato debole. Con AES-256 il vero punto debole è la password: se è corta o facile da indovinare, si può trovare provando molte combinazioni, qualunque sia l'algoritmo.

Come mettere una password a un PDF già oggi

  1. In Microsoft Word scegli File > Salva con nome, seleziona PDF, apri Opzioni e spunta «Crittografa il documento con una password» prima di salvare.
  2. In LibreOffice usa File > Esporta nel formato PDF, apri la scheda Sicurezza e imposta una password di apertura, una dei permessi o entrambe.
  3. Su Mac apri il PDF con Anteprima, scegli File > Esporta, spunta Codifica (oppure usa le opzioni dei permessi) e inserisci una password.
  4. In altri editor PDF cerca Sicurezza, Proteggi o Crittografa nel menu File o Strumenti e, se è disponibile, scegli AES-256.
  5. Chiudi il file, riaprilo e verifica che venga chiesta la password prima di inviarlo.

Quando usare questo strumento

  • Buste paga e lettere sulla retribuzione inviate per email ai dipendenti, da aprire con una password concordata a parte.
  • Referti medici o atti legali spediti a un cliente che deve essere l'unico a leggerli.
  • Referenze e copie dei documenti d'identità di un inquilino che il proprietario deve conservare, ma che non dovrebbero restare leggibili su una cartella condivisa.
  • Compiti in classe preparati in anticipo e condivisi con i colleghi prima della data della verifica.
  • Dichiarazioni dei redditi ed estratti conto mandati via email al commercialista.
  • Scoraggiare la copia occasionale di un opuscolo pubblicato con una password dei permessi (sapendo che è un deterrente, non un lucchetto).

Cosa sapere prima di iniziare

  • Per ora lo strumento Proteggi mostra «In arrivo» e non modifica il file. Fino al lancio usa uno dei metodi descritti sopra.
  • La password di apertura cifra il contenuto: senza di essa il file non si legge. È l'opzione giusta per i documenti riservati.
  • La password dei permessi imposta solo dei vincoli. Il testo resta leggibile e alcuni programmi non li applicano.
  • Se perdi la password di apertura di un file cifrato correttamente, non esistono scorciatoie per recuperarla. Conservala in un gestore di password, non nella stessa email del file.
  • Cifrare un PDF non ne nasconde l'esistenza né il nome, e a seconda del programma alcuni metadati possono restare visibili. Se il nome stesso è delicato, rinomina il file.
  • Gli altri strumenti di PDFora non possono aprire PDF cifrati: unisci, comprimi o modifica prima, e aggiungi la password per ultima. Un file protetto finito all'indirizzo sbagliato resta illeggibile per chi lo riceve, ed è questo il vantaggio pratico principale di una password di apertura rispetto a un normale allegato.

Consigli per risultati migliori

  • Usa una frase lunga, quattro o più parole senza legami tra loro, invece di una password corta piena di simboli.
  • Invia la password su un canale diverso da quello del file: per esempio il PDF via email e la password via SMS o al telefono.
  • Quando il programma lo permette, scegli AES-256; evita le opzioni a 40 bit o RC4, che esistono solo per lettori molto vecchi.
  • Tieni una copia originale non protetta in un posto sicuro, così potrai modificarla in futuro senza dover sbloccare nulla.
  • Proteggi il file come ultimo passaggio: prima finisci di modificare, comprimere e unire, poi cifra.

Esempio: uno studio di commercialisti che invia documenti fiscali

Uno studio di Bergamo con due commercialisti manda a ogni cliente la dichiarazione dei redditi già compilata da controllare. Finora la spedivano via email così com'era: chiunque vedesse la casella di posta, un messaggio inoltrato o il portatile di famiglia poteva leggerla.

Cambiano un solo passaggio. La dichiarazione viene esportata dal gestionale come sempre, poi aperta in LibreOffice ed esportata di nuovo con una password di apertura e cifratura AES. La password è una frase scelta dal cliente, concordata una volta al telefono all'inizio dell'incarico e mai inviata per email. L'email con il PDF parte come prima; il cliente lo apre con una frase che conoscono solo lui e lo studio.

La procedura richiede circa un minuto per cliente. Non protegge da un cliente che inoltra il file insieme alla password, e una frase debole potrebbe comunque essere indovinata, quindi lo studio chiede almeno quattro parole. Quando lo strumento Proteggi di PDFora sarà disponibile si inserirà nello stesso passaggio; nel frattempo la strada dei programmi desktop funziona. Conviene anche decidere fin dall'inizio chi custodisce le password. In un ufficio piccolo, una voce per cliente in un gestore di password condiviso evita che solo una persona riesca ad aprire i file dell'anno precedente. Scrivere la password nel testo dell'email, nel nome del file o su un post-it attaccato al monitor vanifica tutto. La cifratura è la parte facile; è nella gestione della password che, nella pratica, la protezione cede più spesso, qualunque strumento si usi per applicarla.

Risoluzione dei problemi

Lo strumento Proteggi dice «In arrivo»
È lo stato attuale dello strumento: per ora non elabora file. Usa Word, LibreOffice, Anteprima o un altro editor PDF come descritto sopra.
Il destinatario apre il file senza password
Probabilmente hai impostato solo la password dei permessi. Imposta una password di apertura (utente), così il documento viene cifrato.
L'app del destinatario non accetta la password
I lettori molto vecchi potrebbero non supportare AES-256. Chiedigli di usare un lettore PDF aggiornato invece di abbassare la cifratura.
Non riesco più a unire o comprimere il file
La maggior parte degli strumenti, compresi quelli di PDFora, non può elaborare PDF cifrati. Lavora sulla copia originale non protetta e proteggila di nuovo alla fine.
Il divieto di stampa viene ignorato
I permessi dipendono dal programma di lettura. Se un documento non deve essere stampato o copiato, la password dei permessi non basta: limita chi lo riceve.
Ho dimenticato la password di apertura
Con una cifratura robusta non c'è modo di recuperarla. Riparti dall'originale non protetto o dal programma che ha creato il file.

Domande frequenti

Lo strumento Proteggi PDF funziona già?

Non ancora. Per ora mostra un messaggio «In arrivo» e non modifica il file.

Che differenza c'è tra password di apertura e password dei permessi?

La password di apertura cifra il file, che senza di essa non si legge. Quella dei permessi chiede solo al programma di lettura di limitare stampa, copia o modifica.

Un PDF protetto da password è davvero sicuro?

Con la cifratura AES e una password lunga è molto difficile da violare. Il vero punto debole sono le password corte o comuni.

Posso proteggere un PDF dal telefono?

Alcune app PDF per smartphone lo permettono, di solito dal menu di condivisione, sicurezza o esportazione. Sul computer lo fanno Word, LibreOffice e Anteprima.

Proteggere il PDF cambia il suo aspetto?

No. La cifratura non tocca contenuto né impaginazione, ma solo chi può aprire il file o cosa consente l'app di lettura.

Lo strumento sarà gratuito quando uscirà?

Sì, è previsto gratuito come il resto del sito.

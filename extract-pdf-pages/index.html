Most people who need a few pages from a long PDF end up printing to PDF, taking screenshots, or sending the whole 80-page document and writing "see page 47" in the email. Extracting is the cleaner answer: you type the page numbers you want, and you get a separate PDF that contains only those pages, exactly as they were. The source file is not modified at all, so there is nothing to undo if you pick the wrong pages; you simply run it again.

Under the hood the tool opens your PDF with the pdf-lib library, reads the page list you typed, and copies those page objects into a brand-new document. Copying is not the same as re-rendering: text stays selectable, vector drawings stay sharp at any zoom, and embedded images are carried over at their original resolution. The new file is saved as yourfile-extracted.pdf. Because only the selected pages and the fonts and images they use are copied, the result is usually much smaller than the original, though a page that contains a large photo will still be large.

The page box accepts single numbers, ranges and open-ended ranges separated by commas, and it respects the order you type. That last detail is easy to miss and quite useful: typing 5, 1-3 gives you a four-page file that starts with page 5 and then continues with pages 1, 2 and 3. Extraction can therefore double as a quick reorder when you only need a handful of pages in a particular sequence.

How to extract pages from a PDF

  1. Open the Extract Pages tool and choose one PDF. The tool works on a single file at a time.
  2. Find the page numbers you need in your PDF viewer. Use the viewer's page counter, not the numbers printed in the footer, which often differ (a report's printed "page 1" may be the third physical page).
  3. Type them into the Pages to extract box, for example 1-3, 5, 8, or 12- to take page 12 through to the end. Leaving the box empty extracts every page.
  4. Click Extract pages. The selected pages are copied into a new document in the order you listed them.
  5. Download yourfile-extracted.pdf and check the page count and the first and last pages before you send or file it.

When to use this tool

  • Sending a tenant only the signed signature pages and the house-rules schedule from a long lease, instead of the whole agreement.
  • Pulling one chapter out of a course reader so a study group can annotate just the assigned reading.
  • Taking the summary table and the two pages of findings from an annual report for a board pack.
  • Separating a single payslip or bank statement month from a combined year-end download for a loan or rental application.
  • Submitting only the relevant exhibit pages from a bundle of evidence to a tribunal portal with a strict page or size limit.
  • Building a short handout from a slide-deck PDF by picking the five slides that matter, in the order you want to present them.

What to know before you start

  • Page numbers mean physical positions in the file, counted from 1. Printed page labels such as "iv" or "Page 3 of 10" are ignored; only the position in the viewer's sidebar counts.
  • Numbers outside the document are silently skipped. In a 20-page file, typing 18-25 gives you pages 18, 19 and 20 with no warning, and typing only 30 gives the error "No valid pages selected."
  • A range must run low to high. 7-3 matches nothing; write 3-7, or list the pages one by one (7, 6, 5, 4, 3) if you want them reversed.
  • Repeated numbers are not removed. 1, 1, 1 produces a three-page file with page 1 three times, which is handy for duplicating a form page and annoying if it happens by accident.
  • Bookmarks are not carried into the new file, and links that jump to other pages inside the document can stop working because the target page may not exist in the extract. Links to websites keep working.
  • Form fields and annotations that live on the selected pages usually come across, but fillable forms are fragile when pages are copied between documents. If the extract must stay fillable, test one field before relying on it.

Tips for the best results

  • Write the page list down before you start, using the viewer's thumbnail sidebar. It takes less time than correcting a wrong extract.
  • Use open-ended ranges for the back of a document: 41- means page 41 to the last page, whatever the total is.
  • If you need several separate extracts from the same file (one per client, say), run the tool once per extract, or use Split PDF with custom ranges to get them all in one zip.
  • If the pages you want are mostly the whole document minus a few, it is quicker to use Delete Pages and type the handful you want to lose.
  • Rename the download straight away. Three files called report-extracted.pdf in one Downloads folder are an easy way to send the wrong one.

A worked example: a landlord answering a deposit query

A landlord receives an email from a former tenant asking why part of the deposit was kept. The full tenancy file is a 46-page PDF: the lease is pages 1 to 18, the check-in inventory with photos is pages 19 to 38, the check-out report is pages 39 to 44, and two invoices for cleaning and repairs are pages 45 and 46. Sending the whole thing buries the answer, and the photo-heavy inventory makes it about 25 MB.

What the tenant actually needs is the clause about cleaning (page 11), the inventory pages for the kitchen and carpet (pages 27 and 31), the matching check-out pages (41 and 42) and both invoices. Typing 11, 27, 41, 31, 42, 45-46 into the box puts each before-and-after pair next to each other, followed by the invoices. The result is a seven-page file of roughly 4 to 6 MB, depending on how large the photos are, that can be read top to bottom as an explanation.

The original 46-page file is not changed, so it remains the complete record if the dispute goes further. Only the short extract is sent.

Troubleshooting

I get the error "No valid pages selected."
None of the numbers you typed exist in this file, or a range was written high-to-low. Check the total page count in your viewer and write ranges as low-high, for example 3-7.
The extract has the wrong pages
You probably used the printed page numbers from the footer. Count physical pages instead, using the thumbnail sidebar of your viewer, and run the extraction again.
Some pages I asked for are missing
Pages beyond the end of the document are dropped without a message. If you typed 10-60 in a 50-page file, you get pages 10 to 50. Check the total, then extract again.
The extracted file is almost as big as the original
The pages you picked contain most of the heavy content, usually scanned images or photos. Run the extract through Compress PDF afterwards; text-only pages are already small and will not change much.
The file loads but the extract comes out blank or garbled
The source is probably encrypted. The tool opens files with encryption checks disabled, which can produce unreadable pages instead of an error. Remove the protection in the program that created the file or with Unlock PDF if you know the password, then extract from the unprotected copy.
The links in the table of contents no longer work
Internal links point to pages by position in the original document; in the extract those targets are missing or have moved. Remove the contents page from your extract, or add new bookmarks with the Add Bookmarks tool.

Frequently asked questions

Does extracting pages change my original PDF?

No. The tool reads the original and writes a separate new file, yourfile-extracted.pdf. The source file on your disk is never written to.

Can I extract pages in a different order from the original?

Yes. Pages are added in the order you type them, so 9, 2, 4 produces a file that starts with page 9.

Can I extract the same page more than once?

Yes. Duplicates are kept, so typing 3, 3 gives two copies of page 3. Check your list if you did not intend that.

Will the text in the extracted pages still be searchable?

Yes, if it was searchable before. Pages are copied as they are, not converted to images. A scanned page stays an image; run OCR PDF on the extracted file if you need it searchable.

How is this different from Split PDF?

Extract makes one new file from the pages you list. Split makes several files at once (one per page, per range, or per N pages) and gives you a zip.

Is the PDF uploaded anywhere?

No. pdf-lib runs inside the browser tab, so the pages are copied on your own computer and the download is created locally.

Merging is the most common PDF job there is, and it is also the one people get wrong most often: files end up in the wrong order, a page that should have been deleted goes out to a client, or the combined document is suddenly too big for the email it was meant for. This page explains exactly what PDFora's merge tool does to your files, what it keeps, what it does not keep, and how to avoid the mistakes that cost you a second attempt.

Technically, a merge copies the page objects from each source PDF into a new document, one after another. Text stays as real text (it remains selectable and searchable), vector graphics stay vector, and images are copied once at their original resolution. Nothing is re-rendered or recompressed, so the merged file looks identical to the originals page for page. It also means the output is roughly the sum of the input sizes: three 4 MB scans become a 12 MB file, give or take a few kilobytes.

The work happens inside your browser with the pdf-lib library. Your documents are read from disk into memory, combined there, and the result is handed back to you as a download. There is no upload step, which is why there is also no queue, no size cap set by a server, and nothing for us to delete afterwards.

How to merge PDF files online

  1. Open the Merge PDF tool and drop all the files in at once, or click the box and select them. You can add more later.
  2. Drag the rows into the order you want. The top row becomes page 1 of the result. The grip handle on the left is there to drag by.
  3. Check the file sizes shown next to each name; if the total is close to an attachment limit, compress the biggest files first (see the example below).
  4. Click Merge PDFs. A progress bar runs through the files; large scans take a few seconds each.
  5. Download merged.pdf, open it, and page through the joins between documents before you send it.

When to use this tool

  • Job applications: cover letter, CV and certificates as one attachment, in the order the employer listed them.
  • Visa and immigration packs: passport scan, photos, bank statements and sponsor letters that must be uploaded as a single PDF.
  • Month-end bookkeeping: all of a supplier's invoices for the period in one file for the accountant.
  • Course material: lecture handouts or a manuscript's chapters combined into a single readable document.
  • Property and legal files: contract, annexes and signed pages gathered after each party has returned their part.
  • Scanner batches: front and back sides scanned as separate files, joined so the pages follow each other (use Alternate & Mix if the backs come as a second file in reverse order).

What to know before you start

  • Bookmarks (the outline panel) are not carried over. The merged file has no outline even if the sources did. Use the Add Bookmarks tool afterwards if you need one.
  • Fillable form fields can break when documents are combined, especially if two files use the same field names. If a form must stay fillable, merge only PDFs that have no forms, or flatten the forms first and merge the flattened copies.
  • Password-protected files cannot be opened by the merge tool. Remove the password first with Unlock PDF (you need the password if the file asks for one), then merge the unlocked copy.
  • Different page sizes are kept as they are: an A4 letter followed by a US Letter scan followed by a landscape spreadsheet stays exactly that. Use Resize Pages if you want a uniform size.
  • Links inside a document that point to another page of the same document may stop working after the merge, because the page they pointed to now has a different number. Links to websites are unaffected.
  • The combined file is built in your browser's memory. Merging a handful of normal documents is instant; merging several hundred-megabyte scans can exhaust memory on a phone or an older laptop. If the tab freezes, do it on a desktop or merge in two rounds.

Tips for the best results

  • Name files with a number prefix (01-letter.pdf, 02-cv.pdf) before adding them; the order is then obvious at a glance and survives if you have to start over.
  • Fix the order before clicking Merge. Changing the order afterwards means redoing the whole merge; there is no undo on the output file.
  • Remove unwanted pages from a source file first with Delete Pages, then merge the cleaned copy. It is far easier than hunting for the page in the long result.
  • Keep the originals until you have opened the merged PDF and checked the page count: it should equal the sum of the source page counts.
  • If one source is a scan and the others are digital documents, the scanned pages are not searchable in the merged file until you run it through OCR PDF, which adds a text layer to the scanned pages and leaves the digital ones as they are.

A worked example: a 10 MB attachment limit

Say you are sending a job application through a recruiter's portal that allows one attachment of 10 MB. You have a cover letter (120 KB, digital), a CV (300 KB, digital) and three scanned certificates at about 4 MB each. Merged as they are, the result is around 12.4 MB and the upload will be rejected.

The digital documents are not the problem; they are tiny because their text is stored as text. The scans are large because each page is a photograph. Run each certificate through Compress PDF on the Recommended level first (a 4 MB page scan usually comes down to roughly 0.5 to 1 MB), then merge the five files. The result lands around 2 to 3.5 MB with the certificates still perfectly legible, and the cover letter and CV remain crisp, searchable text because they were never touched by the compressor.

The order matters too: put the cover letter first, the CV second and the certificates in the order the posting asked for. A recruiter reading on a phone sees the letter immediately instead of scrolling past three pages of certificate scans.

Troubleshooting

The merge button is greyed out
The tool needs at least two files. Add a second PDF, or if you only want to reorder pages within one file, use Organize Pages instead.
One of my files refuses to load
It is most likely password-protected or damaged. Open it in your PDF viewer: if it asks for a password, remove the protection first with Unlock PDF; if it will not open at all, run it through Repair PDF and merge the repaired copy.
The merged PDF is bigger than the originals combined
A small overhead is normal because shared resources (fonts, colour profiles) are copied once per source rather than de-duplicated. If the result is much larger than expected, one source probably contains very high-resolution images; compress that file first.
The pages are in the wrong order
The order of the rows in the file list is the order of the output. Drag the rows into place and merge again; the download only reflects the order at the moment you clicked Merge.
My bookmarks or form fields disappeared
That is expected: the merge copies pages, not the document-level outline or form structure. Add bookmarks afterwards with the Add Bookmarks tool, and flatten forms before merging if they only need to be readable.
The tab froze on a large job
Your device ran out of memory while holding every source in RAM. Close other tabs, merge on a desktop computer, or merge in two rounds (first half, then the rest with the first result).

Frequently asked questions

Does merging reduce the quality of my PDFs?

No. Pages are copied, not re-rendered. Text stays text, images keep their original resolution, and the merged document prints identically to the sources.

Is there a limit on how many files or pages I can merge?

The tool sets no limit. The practical limit is your device's memory: hundreds of ordinary pages are fine, while many very large scans may need to be merged in two rounds.

Can I merge PDFs with different page sizes or orientations?

Yes. Each page keeps its own size and orientation in the result. If you want everything on one size, run the merged file through Resize Pages.

Will the merged file keep my bookmarks and form fields?

Bookmarks are not copied and form fields may break. Add bookmarks afterwards with the Add Bookmarks tool; flatten forms before merging unless they must stay fillable.

Can I merge a password-protected PDF?

Not while it is protected. Remove the password first with Unlock PDF, then merge the unlocked copy. The merge tool itself never asks for or stores passwords.

Is it safe to merge confidential documents here?

The merge runs entirely in your browser with the pdf-lib library; the files are never uploaded. Close the tab and nothing remains anywhere but on your own device.

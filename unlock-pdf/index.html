The Unlock PDF tool is not available yet. Choosing a file and clicking the button returns a 'coming soon' message and nothing else happens to your document. It depends on a processing route that is still being built. Meanwhile this page covers how removing a PDF password actually works, what the tool will and will not do, and how to remove protection today from a file you have the password for.

Removing protection is not the same as cracking it. To decrypt a PDF that has an open password, software needs that password: it uses it to derive the key, decrypts the content and saves a copy without encryption. A properly encrypted file with a strong password cannot simply be unlocked without it, and PDFora's tool is not designed to guess passwords. Its purpose will be convenience for files you are entitled to open, such as a bank statement protected with your date of birth.

Files that only carry a permissions password are different. They open without any prompt, but printing, copying or editing may be blocked. Many programs can save an unrestricted copy of such a file. Whether you should do that depends on why the restriction is there, which is covered below. A practical note: the password for a statement is the same each month, so once you have the format right the job becomes routine.

How to remove a PDF password today

  1. Open the protected PDF in your usual reader and enter the password to confirm you have the right one.
  2. Use Print and choose 'Save as PDF' or 'Microsoft Print to PDF' as the printer. The new file is not encrypted, although links and form fields may be lost.
  3. Alternatively, on a Mac open the file in Preview, choose File > Export and leave Encrypt unticked to save an unprotected copy.
  4. In a full PDF editor, open the security or protection settings and choose to remove security; the editor will ask for the password.
  5. Open the new copy to confirm there is no password prompt, then store or delete the protected original as appropriate.

When to use this tool

  • Bank, card and utility statements protected with an account number or birth date, which you want to merge into one file for a loan application.
  • Payslips from a payroll system that you need to upload to a portal that rejects encrypted PDFs.
  • Your own old documents, protected years ago with a password you still know.
  • A school receiving password-protected reports that must be combined into a pupil file.
  • Files that need to go through other PDF tools, such as compression or OCR, which cannot open encrypted documents.
  • Archiving records where future access should not depend on remembering many separate passwords.

What to know before you start

  • The Unlock tool currently shows 'coming soon' and does not process files.
  • Removing an open password requires the password. Without it, a well-encrypted PDF cannot be opened by any legitimate tool.
  • Print to PDF produces a new file without encryption, but it may drop links, bookmarks and form fields, and some readers will not print a file whose permissions forbid it.
  • Permission restrictions are usually set by the publisher on purpose. Only remove them where you have the right to, for instance from your own documents or with the owner's agreement.
  • An unlocked copy is readable by anyone who gets it. Keep it in a safe place, and delete it if you only needed it temporarily.
  • Once a PDF is unlocked, other PDFora tools such as Merge, Compress and OCR can work on it. If a lender or employer later asks for the documents again, export fresh unlocked copies from the protected originals rather than keeping unlocked files lying around.

Tips for the best results

  • Check the email that came with a protected statement; the password format (for example the first four letters of your name plus birth year) is usually explained there.
  • If a portal rejects your PDF, look for messages such as 'encrypted' or 'secured' in the error; that is the clue that the password needs removing.
  • Unlock only the copy you need to process, and keep the original protected file as the record.
  • After unlocking and merging statements, consider protecting the combined file again before emailing it.
  • If Print to PDF loses form fields you need, use a PDF editor's 'remove security' option instead, which keeps the document structure.

Example: a mortgage application with six statements

A couple applying for a mortgage needs to upload six months of bank statements as one PDF. Each monthly statement from their bank is protected with an open password made of part of the account holder's name and birth date, and the lender's upload portal refuses encrypted files.

They open each statement in Preview on their Mac, enter the password and export an unencrypted copy. The six copies then go through PDFora's Merge tool in date order, and the merged file is uploaded. The originals stay in their email, still protected, so the bank's copies are unchanged.

Two cautions they take: the unprotected copies are deleted from the Downloads folder after the upload, and the merged file is not sent by plain email to anyone else. When the Unlock tool is available it will replace the Preview step; the rest of the workflow stays the same. It also helps to understand why banks and payroll providers protect statements in the first place. Email is often stored unencrypted on several servers, and a forwarded thread can travel far beyond the intended reader. The password protects the file in transit. Once it is safely on your own computer and you need to work with it, removing the protection from a working copy is a normal step, provided the unlocked copy does not then travel back out by email unprotected.

Troubleshooting

The Unlock tool says 'coming soon'
The tool is not functional yet. Use Print to PDF, Preview's export or a PDF editor's security settings as described above.
I do not know the password
Look for it in the email or letter that came with the file, or ask the sender for an unprotected copy. Strong encryption cannot be removed without the password.
Print is greyed out
The file's permissions forbid printing. Use a PDF editor's 'remove security' option with the permissions password, or ask the owner for an unrestricted copy.
The unlocked copy lost its links and form fields
Print to PDF flattens the document. Use Preview's export or a full PDF editor instead, which keep more of the structure.
The portal still says the file is encrypted
You may have uploaded the original by mistake. Check that the new copy opens without a prompt, and rename it clearly, for example statement-unlocked.pdf.
Other tools on this site cannot open my PDF
It is still protected. Remove the protection first, then use Merge, Compress or OCR on the unlocked copy.

Frequently asked questions

Does the Unlock PDF tool work yet?

Not yet. It shows a 'coming soon' message and does not change your file.

Can it remove a password I do not know?

No. The planned tool will need the password. It is not designed to guess or crack passwords.

Is it legal to remove a PDF password?

Removing protection from your own documents, or with the owner's permission, is generally fine. Removing restrictions from content you do not have rights to may break the publisher's terms or copyright law.

What is the difference between unlocking an open password and permissions?

An open password encrypts the file; removing it needs the password. Permission restrictions only limit actions like printing and copying in reader software.

Will unlocking change the content of my PDF?

Removing security with a proper editor keeps the content as it is. Print to PDF may lose links, bookmarks and form fields.

Will the tool cost anything when it launches?

It is planned as a free tool like the rest of PDFora.

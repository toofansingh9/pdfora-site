Bank statements, payslips and insurance letters often arrive locked with a password made from your name, account number or date of birth. That is sensible while the file travels by email, but it gets in the way afterwards: loan portals reject encrypted uploads, and merge, compress and OCR tools cannot open them. Unlock PDF saves a copy without the password, so the file opens straight away and works with every other tool on the site.

Unlocking is not cracking. If a PDF asks for a password when you open it, the tool needs that password: it checks it, uses it to decrypt the content, and writes a copy with the encryption and all restrictions removed. If the password is wrong, it says so and stops; it does not try to guess. Files that open without a prompt but block printing, copying or editing are a different case: their content is readable already, so the tool can remove those restrictions without any password.

The work is done by qpdf, an open-source PDF library compiled to WebAssembly, which loads into your browser tab from this site the first time you use the tool (about 1.3 MB). Your file and the password you type stay on your device. The pages are not re-rendered, so text stays selectable, links and bookmarks keep working, and the result looks exactly like the protected original.

How to remove a password from a PDF

  1. Open Unlock PDF and add one protected file.
  2. If the PDF asks for a password when you open it, type that password into Current password. If it opens without a prompt and only blocks printing or copying, leave the field empty.
  3. Click Unlock PDF. The tool first checks whether the file is protected at all and whether the password is right.
  4. Download yourfile-unlocked.pdf.
  5. Open the new copy to confirm there is no password prompt, then carry on with Merge, Compress or whichever tool you needed it for.

When to use this tool

  • Monthly bank or card statements protected with a birth-date password, which a lender wants uploaded as one merged file.
  • Payslips from a payroll system that an HR or visa portal refuses because they are encrypted.
  • Your own old documents, protected years ago with a password you still know but no longer want to type every time.
  • A report that opens freely but has printing switched off, when you are its author or have the owner's agreement to print it.
  • Files that must go through Compress, OCR, Split or Page Numbers, which cannot work on encrypted PDFs.
  • Archives where future access should not depend on remembering a different password for every file.

What to know before you start

  • If the PDF needs a password to open, you must supply it. The tool checks it first and reports 'Wrong password — the file was not unlocked.' rather than writing a broken file.
  • It cannot recover or crack a forgotten password. A properly encrypted file without its password stays locked; ask the sender for the password or an unprotected copy.
  • Files that open without a password but carry permission restrictions are unlocked without one, and the printing, copying and editing restrictions are all removed.
  • If the file has no protection at all, the tool tells you 'This PDF is not password-protected' instead of producing an identical copy.
  • Removal is complete: encryption and every restriction go. There is no option to keep some restrictions; if you want them back, run the unlocked copy through Protect PDF with new settings.
  • Use it only on files you are entitled to unlock: your own documents, or ones whose owner agrees. Restrictions on a publisher's e-book or a paid report are usually there on purpose, and removing them can break its terms or copyright.

Tips for the best results

  • Check the email or letter that came with a protected statement; the password format, such as the first four letters of your name plus your birth year, is usually explained there.
  • Type the password rather than pasting it. Pasted passwords often carry an invisible trailing space, which counts as a wrong password.
  • Unlock a working copy and keep the protected original as the record.
  • If a portal rejects your upload with words like 'encrypted', 'secured' or 'password', unlocking is the fix.
  • Delete unlocked copies you only needed temporarily, and if you have to email the result onward, protect it again with Protect PDF.

A worked example: six statements for a home loan

A couple applying for a home loan must upload six months of bank statements as a single PDF. Each statement is 3 to 5 pages and about 250 KB, and the bank protects every one with an open password made of the first four letters of the account holder's name and their birth year. The lender's upload portal rejects encrypted files.

They run each statement through Unlock PDF, typing the same password each time. The first file takes a few seconds while the engine loads; the other five are done almost instantly, and each unlocked copy is close to the original size, with the text still selectable. On the third statement they mistype the year and the tool answers 'Wrong password — the file was not unlocked.', so they correct it and run it again. The six copies then go through Merge PDF in date order, giving one 26-page file of about 1.5 MB, which the portal accepts.

Afterwards they delete the six unlocked copies and the merged file from the Downloads folder, and keep the bank's protected originals in their email as the record. The bank's password did its job while the statements travelled by email; once they were on the couple's own laptop, removing it from a working copy was a normal step, as long as the unlocked file does not travel back out unprotected.

Troubleshooting

It says the PDF needs its open password
The file is encrypted with an open password. Type it into Current password and run the tool again.
It says 'Wrong password'
Check Caps Lock, the keyboard layout and any trailing space, and re-read the password format the sender gave you. Some banks use upper-case letters, others lower-case.
It says the PDF is not password-protected
There is nothing to remove. If another tool still refuses the file, it is probably damaged rather than protected; try Repair PDF.
I do not know the password
The tool cannot find or guess it. Look in the email or letter that came with the file, or ask the sender for the password or an unprotected copy.
The encryption engine does not load
It is loaded from this site on first use. A script blocker, a corporate filter or a very slow connection can stop it; reload the page and try again.
It says it could not unlock this PDF
The file is probably damaged. Open it in your viewer with the password and use Print to PDF or save a copy, then unlock or repair that copy.

Frequently asked questions

Can Unlock PDF remove a password I do not know?

No. It needs the open password for files that ask for one, and it does not guess or crack passwords. It only removes restrictions without a password when the file already opens freely.

Is my file or password uploaded?

No. The unlocking engine runs inside your browser. The PDF and the password stay on your device and nothing is kept after you close the tab.

Does it remove printing and copying restrictions too?

Yes. The unlocked copy has no encryption and no permission restrictions, so it can be printed, copied and edited in any reader.

Will unlocking change the content or quality?

No. The pages are not re-rendered. Text, images, links and bookmarks stay as they were; only the encryption is removed.

Is it legal to remove a PDF password?

Removing protection from your own documents, or with the owner's permission, is generally fine. Removing restrictions from content you do not have rights to may break the publisher's terms or copyright law.

Can I unlock several statements at once?

The tool takes one file at a time. After the first run the engine is already loaded, so each further file takes only a moment.

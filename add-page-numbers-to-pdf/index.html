Page Numbers

Print a page number on every page of a PDF, as 1, 1 of N or Page 1, in one of five positions.

Unnumbered PDFs cause small, annoying problems: a reviewer writes 'see the table on the fourth page' and nobody agrees which page that is, a printed handout gets dropped and cannot be put back in order, or a tutor asks for page references the document simply does not have. Adding numbers fixes all of that, but only if they land where they will not clash with the existing footer and start from the right value.

This tool draws a number in 11-point Helvetica, dark grey, on each page of a single PDF. You choose the position (bottom centre, bottom right, bottom left, top centre or top right), the format (a bare 1, 2, 3; '1 of 12'; or 'Page 1') and the starting number. The number sits 28 points, a little under 10 mm, in from the side edge; at the bottom its baseline is about 7 mm above the edge, at the top about 10 mm below it. Nothing else on the page is moved, resized or re-rendered.

The numbers are stamped by the pdf-lib library on a copy held in your browser tab, and the result downloads as yourfile-numbered.pdf. Because the original content stays as it was, a text-based PDF stays searchable and a scan stays exactly as sharp as before.

How to add page numbers to a PDF

  1. Open Add Page Numbers and choose the PDF. Only one file is processed per run.
  2. Pick a position. Look at your document first: if it already has a footer in the centre, choose bottom right or top right instead.
  3. Choose the format: 1, 2, 3 for most documents; '1 of N' when readers need to know the document is complete; 'Page 1' for forms and printed packs.
  4. Set the font size and the number to start at, for example 5 if this file continues a report whose first four pages are separate.
  5. Click Add page numbers, download the file and check the first, last and any landscape page.

When to use this tool

  • Theses and dissertations assembled from separately exported chapters, numbered once the final merge is done.
  • Board and committee packs, where everyone in the meeting needs to say 'page 14' and mean the same page.
  • Scanned contracts and agreements, numbered '1 of N' so a missing page is obvious to both parties.
  • Teaching handouts and workbooks printed double-sided, so dropped sheets can be put back in order.
  • Tender and grant submissions with a strict page limit, where the assessor checks the count against the rules.
  • Insurance and medical claims bundles, where a case handler refers back to specific pages of receipts and reports.

What to know before you start

  • Every page gets a number, including the cover. There is no option to skip the first page or number only a range. To leave the cover blank, split it off, number the rest starting at 2, and merge the cover back on.
  • The lowest practical start value is 1. A start of 0 is treated as empty and the tool begins at 1 anyway.
  • '1 of N' uses the last number actually printed as N. If you start at 5 on a 10-page file, page labels run from '5 of 14' to '14 of 14'.
  • The numbers are added as a visible stamp only. The page labels shown in a viewer's page box (i, ii, 1, 2…) are not changed, and roman numerals are not available.
  • The format words are fixed in English: 'of' and 'Page' cannot be translated, so a document in another language gets English labels unless you use the bare 1, 2, 3 format.
  • Position is worked out from each page's full size. Pages stored rotated or with a reduced crop box may show the number sideways, in the wrong corner, or outside the visible area.

Tips for the best results

  • Number after the final merge, never before. Numbering parts separately produces duplicate 1s and gaps once they are joined.
  • For a document that will be bound or stapled on the left, use bottom centre or bottom right so the number is not lost in the binding.
  • If the existing document has a small footer, set the font size to 9 or 10 so the number does not look heavier than the footer text.
  • When a file continues another (Part 2 of a report), note the last page of Part 1 and start Part 2 at that number plus one.
  • Do a quick test print of one page: a number that looks fine on screen can fall into the unprintable margin on some office printers.

Example: a student's 46-page dissertation

A master's student exports her title page, abstract, five chapters and appendices from three different editors and merges them into one 46-page PDF. Her department wants the title page unnumbered and the main text numbered from the abstract onwards, at the bottom centre.

She splits off page 1 with Split PDF, runs the remaining 45 pages through Add Page Numbers with position bottom centre, format 1, 2, 3, font size 10 and start at 2, then merges the title page back in front. The submission now reads 2 to 46 on the numbered pages, matching the contents page she wrote by hand.

One appendix is a landscape table that her spreadsheet exported rotated. On that page the number appears down the side. She fixes the orientation with Rotate PDF on the merged file, numbers again from the cleaned copy, and the problem disappears. Before sending, she opens the final file and jumps to the last page: it reads 46, the same as the page count her viewer reports, which confirms nothing was dropped during the split and merge.

Troubleshooting

The number overlaps my existing footer
Choose a different position, such as bottom right or top right, or reduce the font size. The tool cannot move the existing footer.
Numbering starts at 1 even though I typed 0
A start value of 0 is treated as empty. Start at 1, or if you truly need a page 0, number from 1 and accept the offset.
The number is sideways on some pages
Those pages are stored rotated. Correct them with Rotate PDF, save, and number the corrected file.
I cannot see the number at all
The page may have a crop box smaller than the full page, hiding the margin where the number is drawn, or a dark image underneath. Try a top position, or a bottom-centre position on a lighter part of the page.
The cover page has a number I do not want
Split the cover off, number the remaining pages starting at 2, and merge the two files again.
My viewer's page box still shows different numbers
The tool only stamps visible numbers; it does not edit the document's internal page labels. Most viewers will still show 1 to N in their navigation box.

Frequently asked questions

Can I use roman numerals for the front matter?

No. The formats are 1, '1 of N' and 'Page 1'. Number the front matter in your word processor before exporting if you need roman numerals.

Can I skip the first page?

Not directly. Split the first page off, number the rest from 2, and merge them back together.

Can I choose the font or colour of the numbers?

No. Numbers are always dark grey Helvetica. Only the size and position are adjustable.

Will adding numbers reduce the quality of my scans?

No. The number is drawn on top as a small piece of text; the scanned images underneath are not recompressed or re-rendered.

Does it work on documents with mixed page sizes?

Yes. The position is worked out separately for each page, so an A4 page and a landscape page each get the number in their own corner or centre.

Can I number several PDFs in one go?

Not in one run. Merge them first if they belong to one document, or process each file separately with the right start number.

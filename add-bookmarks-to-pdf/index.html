A 60-page report without bookmarks forces every reader to scroll and guess. With them, the sidebar of any PDF reader shows a table of contents and one click jumps to the right page. Many PDFs lose their bookmarks along the way: exported from an app that did not create them, assembled by merging several files, or scanned from paper. Create Bookmarks puts an outline back without needing the original source document.

You do not drag anything around. You type one line per bookmark in the form page, Title, for example '1, Cover' or '12, Section 3: Budget'. Lines can be separated by new lines or by semicolons. Everything after the first comma is the title, so titles may themselves contain commas. The bookmarks appear in the reader in exactly the order you type them. Because the list is plain text, you can keep it in a note and reuse it every time a new edition of the same document comes out, adjusting only the page numbers that moved.

The tool reads the PDF with pdf-lib, builds a new outline in the document catalogue that points each entry at the page you named, and saves the file as yourfile-bookmarks.pdf. The pages themselves are copied unchanged: text, images, links and form fields are not touched.

How to add bookmarks to a PDF

  1. Open the PDF in any reader first and note the page number where each section starts. Use the reader's own page counter (page 1 is the first page of the file), not the numbers printed on the pages.
  2. Open Create Bookmarks and drop in the PDF.
  3. In the box, type one entry per line, like 1, Cover then 3, Introduction then 9, Findings. A semicolon between entries works too.
  4. Click Add bookmarks. The note under the button tells you how many bookmarks were added.
  5. Open the -bookmarks.pdf download, show the bookmarks or outline sidebar and click each entry to confirm it lands on the right page.

When to use this tool

  • Annual reports and grant applications assembled by merging separately written sections.
  • Course readers where a teacher combined several chapters and handouts into a single PDF.
  • Legal bundles and evidence packs where exhibits must be found quickly during a meeting or hearing.
  • Scanned manuals or old books with no digital structure at all.
  • Board meeting packs with an agenda followed by a dozen attached papers.
  • Theses and dissertations exported from tools that produced no outline.

What to know before you start

  • The outline is flat. Every bookmark is at the same level; there are no nested chapters with sub-sections underneath.
  • Any outline the file already had is replaced, not extended. If you want to keep existing bookmarks, include them in your list.
  • Page numbers refer to the position in the file, starting at 1. Printed page numbers, roman-numeral front matter and page labels are ignored.
  • A number larger than the page count is quietly changed to the last page, and 0 becomes page 1. A typo will therefore not cause an error; it will just point somewhere unexpected. The success message counts the bookmarks created, not whether each one landed where you meant.
  • Lines that have no comma, or no number before the comma, or no title after it, are skipped without a warning. Compare the count in the success message with the number of lines you typed.
  • Each bookmark opens its page without forcing a zoom level, so the reader keeps the zoom the user is already at. Bookmarks cannot point to a specific paragraph partway down a page.

Tips for the best results

  • Write the list in a text editor first, check it, and paste it in. It is easier to fix than in the small input box and you keep a copy for next time.
  • Do the bookmarks last. Merging, splitting or deleting pages afterwards will either drop the outline or shift pages under it.
  • Keep titles short; reader sidebars are narrow and long titles get cut off. Section numbers at the start ('3. Methods') help readers scan.
  • If the PDF has a printed table of contents, use it as your list, but add the offset between printed and real page numbers to every entry. For example, if printed page 1 is the fifth page of the file, add 4 to every number in the printed contents.
  • Most readers only show bookmarks if the sidebar is open. Mention 'see bookmarks' in your email for readers who do not know to look.

Example: a freelance consultant's client report

A freelance consultant has produced a 42-page market report by merging five files: a cover and summary, the main analysis, three appendices and a set of scanned survey sheets. The merge dropped any structure, and the client has asked for something easier to navigate on screen.

In a reader, the consultant notes where each part starts in the file: cover on 1, executive summary on 2, analysis on 5, appendix A on 28, appendix B on 31, appendix C on 35 and survey scans on 38. Note that the analysis's own printed numbering starts at 1 on file page 5, so the printed table of contents cannot be copied as it is. The list typed into the tool is: 1, Cover; 2, Executive summary; 5, Analysis; 28, Appendix A – Data tables; 31, Appendix B – Method; 35, Appendix C – Sources; 38, Survey sheets.

The tool reports '7 bookmarks added.' Opening market-report-bookmarks.pdf, the consultant clicks each entry once, finds them all correct and sends the file. Total time, about five minutes. Next quarter, when the updated report arrives with two extra pages in the analysis, the same list is reused with the last four page numbers increased by two.

Troubleshooting

Add at least one line like 2, Chapter One
None of the lines could be read. Each line needs a page number, then a comma, then a title. Check that you used a comma rather than a full stop or a dash.
Fewer bookmarks were added than I typed
Some lines were skipped because they lacked a comma, a number or a title. Fix those lines and run the tool again on the original file.
A bookmark goes to the wrong page
You probably used the printed page number. Use the page position shown by your reader's page counter, then rerun the tool on the original file.
My old bookmarks have disappeared
The tool writes a new outline and replaces the old one. Rebuild the full list including the bookmarks you want to keep, checking the original file in a reader to see what it had.
I cannot see any bookmarks in the downloaded file
Open the bookmarks or outline panel in your reader; many hide it by default. Some basic browser viewers do not show bookmarks at all.
Accented or non-Latin titles look wrong
Titles are stored as Unicode text, which current readers display correctly. Try a different PDF reader if a particular app shows garbled characters.

Frequently asked questions

Can I create nested bookmarks with sub-levels?

No. All bookmarks are created at one level. For a hierarchy you would need a full PDF editor.

Will my existing bookmarks be kept?

No, they are replaced by your new list. Include any you want to keep in the list you type.

Can a bookmark title contain a comma?

Yes. Only the first comma separates the page number from the title; everything after it is the title.

Does adding bookmarks change the pages?

No. The pages, text, images and links are saved unchanged; only the document outline is added. The file is re-saved by pdf-lib, so its size can differ slightly from the original even though the content is the same.

What happens if I enter page 100 in a 40-page file?

The bookmark is pointed at the last page instead. No error is shown, so double-check your numbers.

Will bookmarks survive if I merge this file later?

No. Merging copies pages but not the outline. Add bookmarks as the final step, after merging.

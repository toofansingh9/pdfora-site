Δημιουργία φορμών

Τοποθετήστε διαδραστικά πεδία κειμένου και πλαίσια ελέγχου οπουδήποτε στο PDF σας.

Λήψη

Αποθηκεύστε το έτοιμο αρχείο αμέσως. Χωρίς υδατογραφήματα.

Οι περισσότερες φόρμες ξεκινούν τη ζωή τους ως στατικό έγγραφο: μια εξαγωγή από Word, μια σάρωση, ένα καλοσχεδιασμένο PDF που κάποιοι υποτίθεται ότι πρέπει να συμπληρώσουν. Το εκτυπώνουν, γράφουν πάνω του, το σαρώνουν ξανά — ή πληκτρολογούν άβολα από πάνω σε κάποιον επεξεργαστή. Αυτό το εργαλείο τερματίζει τον κύκλο. Σας επιτρέπει να δημιουργήσετε μια συμπληρώσιμη φόρμα PDF τοποθετώντας πραγματικά διαδραστικά πεδία κειμένου και πλαίσια ελέγχου οπουδήποτε στο υπάρχον έγγραφό σας.

Η ροή εργασίας είναι άμεση. Το PDF σας εμφανίζεται στην οθόνη· κάνετε κλικ εκεί όπου πρέπει να μπει μια απάντηση και ένα πεδίο τοποθετείται στο σημείο αυτό. Σύρετε τα πεδία για να ρυθμίσετε με ακρίβεια τη θέση τους, αλλάξτε το μέγεθός τους ώστε να ταιριάζουν στο κενό πάνω από το οποίο κάθονται, προσθέστε πλαίσια ελέγχου δίπλα στις επιλογές ναι/όχι. Όταν κάνετε εξαγωγή, παίρνετε ένα γνήσιο PDF τύπου AcroForm — την πρότυπη διαδραστική μορφή που ξέρουν να συμπληρώνουν το Adobe Acrobat, τα προγράμματα περιήγησης και οι εφαρμογές ανάγνωσης σε κινητά.

Το έγγραφο που μετατρέπετε δεν φεύγει ποτέ από τον υπολογιστή σας, γιατί τα πάντα εκτελούνται τοπικά στο πρόγραμμα περιήγησής σας. Δεν υπάρχει εγγραφή, ούτε υδατογράφημα σφραγισμένο στη φόρμα σας, ούτε χρέωση, ούτε όριο στο πόσες φόρμες θα φτιάξετε.

Πώς να δημιουργήσετε μια συμπληρώσιμη φόρμα PDF online

  1. Ανοίξτε το PDF που θέλετε να κάνετε συμπληρώσιμο — μια αίτηση, ένα συμβόλαιο ή ένα ερωτηματολόγιο. Φορτώνεται τοπικά στο πρόγραμμα περιήγησής σας.
  2. Κάντε κλικ στη σελίδα όπου ανήκει μια πληκτρολογημένη απάντηση· ένα πεδίο κειμένου εμφανίζεται σε εκείνο το σημείο.
  3. Προσθέστε πλαίσια ελέγχου δίπλα σε στοιχεία ναι/όχι ή σε επιλογές πολλαπλής απάντησης, κάνοντας κλικ στη θέση τους.
  4. Σύρετε κάθε πεδίο για να το ευθυγραμμίσετε με το τυπωμένο κενό και αλλάξτε το μέγεθός του ώστε οι μεγαλύτερες απαντήσεις να έχουν χώρο.
  5. Επαναλάβετε σε κάθε σελίδα, μέχρι κάθε ερώτηση να έχει το πεδίο της.
  6. Κάντε εξαγωγή του αρχείου — παίρνετε ένα πραγματικό συμπληρώσιμο PDF τύπου AcroForm, έτοιμο για αποστολή, το οποίο οι παραλήπτες συμπληρώνουν σε οποιοδήποτε τυπικό πρόγραμμα ανάγνωσης PDF.

When to use this tool

  • Μετατρέψτε μια αίτηση ενοικίασης που οι ενοικιαστές παλιά εκτύπωναν και σάρωναν σε μια φόρμα που συμπληρώνουν από το κινητό τους.
  • Κάντε συμπληρώσιμο ένα έντυπο εγγραφής μέλους σε σύλλογο ή συμμετοχής σε εκδήλωση, ώστε οι απαντήσεις να γυρίζουν πληκτρολογημένες αντί για χειρόγραφες.
  • Μετατρέψτε ένα ερωτηματολόγιο εισαγωγής ασθενούς σε διαδραστική φόρμα που η κλινική μπορεί να στέλνει με email πριν από τα ραντεβού.
  • Προσθέστε πεδία σε ένα πρότυπο σύμβασης ελεύθερου επαγγελματία, ώστε το όνομα, οι ημερομηνίες και η αμοιβή κάθε νέου πελάτη να πληκτρολογούνται καθαρά.
  • Ξαναφτιάξτε μια παλιά σαρωμένη υπεύθυνη δήλωση σχολικής εκδρομής ως συμπληρώσιμο PDF που οι γονείς επιστρέφουν με email.
  • Δώστε σε ένα εσωτερικό έντυπο αποζημίωσης εξόδων ή αίτησης άδειας κανονικά πεδία και πλαίσια ελέγχου, αντί να βασίζεστε στο ότι ο καθένας θα επεξεργάζεται το αρχείο.

Tips for the best results

  • Δώστε γενναιόδωρο μέγεθος στα πεδία κειμένου — μια διεύθυνση email χρειάζεται περισσότερο πλάτος απ' όσο νομίζετε, και τα στριμωγμένα πεδία εκνευρίζουν τον κόσμο.
  • Ευθυγραμμίστε τα πεδία με τα τυπωμένα κενά και τις ετικέτες της σελίδας· το υποκείμενο έγγραφο δίνει τις λεζάντες, τα δικά σας πεδία δίνουν την εισαγωγή δεδομένων.
  • Χρησιμοποιήστε πλαίσια ελέγχου για οτιδήποτε έχει σταθερές επιλογές, αντί να περιμένετε από τον κόσμο να πληκτρολογήσει ένα Χ σε πεδίο κειμένου.
  • Συμπληρώστε μία φορά μόνοι σας την εξαγόμενη φόρμα πριν τη στείλετε — μια δοκιμή δύο λεπτών εντοπίζει λάθος τοποθετημένα ή ξεχασμένα πεδία.
  • Κρατήστε τη συμπληρώσιμη έκδοση ως βασικό σας πρότυπο και σκεφτείτε να ισοπεδώνετε αργότερα τα συμπληρωμένα αντίγραφα, ώστε οι απαντήσεις να μην μπορούν να αλλάξουν.

Συχνές ερωτήσεις

Τι είναι το AcroForm;

Το AcroForm είναι η πρότυπη μορφή για διαδραστικές φόρμες PDF, την οποία υποστηρίζει σχεδόν κάθε πρόγραμμα ανάγνωσης PDF — Acrobat, προβολείς προγραμμάτων περιήγησης, Preview, εφαρμογές κινητών. Αυτό το εργαλείο εξάγει γνήσια πεδία AcroForm, όχι μια απομίμηση επικάλυψης, οπότε η φόρμα σας συμπληρώνεται και αποθηκεύεται παντού.

Χρειάζομαι ένα υπάρχον PDF για να ξεκινήσω;

Ναι — αυτό το εργαλείο προσθέτει πεδία πάνω σε ένα έγγραφο που ήδη έχετε, όπως μια σχεδιασμένη φόρμα, ένα συμβόλαιο ή μια σάρωση. Σχεδιάστε τη διάταξη σε όποια εφαρμογή θέλετε, κάντε εξαγωγή σε PDF και μετά τοποθετήστε εδώ τα πεδία.

Μπορώ να προσαρμόσω ένα πεδίο αφού το τοποθετήσω;

Ναι. Κάθε πεδίο μπορεί να συρθεί σε νέα θέση και να αλλάξει μέγεθος από τις άκρες του, μέχρι να κάθεται ακριβώς πάνω από την κενή γραμμή ή το πλαίσιο όπου ανήκει. Ένα λάθος τοποθετημένο πεδίο διορθώνεται σε δύο δευτερόλεπτα, δεν σας αναγκάζει να ξεκινήσετε από την αρχή.

Τι τύπους πεδίων μπορώ να προσθέσω;

Πεδία κειμένου για πληκτρολογημένες απαντήσεις και πλαίσια ελέγχου για επιλογές — τα δύο δομικά στοιχεία που καλύπτουν τις περισσότερες πραγματικές φόρμες: αιτήσεις, έντυπα εισαγωγής, συμβόλαια, εγγραφές και εγκρίσεις.

Μπορούν οι παραλήπτες να αποθηκεύσουν τις συμπληρωμένες απαντήσεις τους;

Ναι. Επειδή η εξαγωγή είναι μια τυπική συμπληρώσιμη φόρμα PDF, οι παραλήπτες την ανοίγουν σε οποιοδήποτε σύγχρονο πρόγραμμα ανάγνωσης, πληκτρολογούν τις απαντήσεις τους, τσεκάρουν τα πλαίσια και αποθηκεύουν ή επιστρέφουν το αρχείο με τα δεδομένα διατηρημένα.

Παραμένει ιδιωτικό το έγγραφο που ανεβάζω;

Δεν υπάρχει καθόλου ανέβασμα — το PDF επεξεργάζεται εξ ολοκλήρου στο πρόγραμμα περιήγησής σας και δεν αγγίζει ποτέ διακομιστή. Σε συνδυασμό με τη μηδενική εγγραφή, τα μηδενικά υδατογραφήματα και την απουσία ορίων χρήσης, μπορείτε να φτιάξετε όσες συμπληρώσιμες φόρμες χρειάζεστε χωρίς κόστος.

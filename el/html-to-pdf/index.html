HTML σε PDF

Μετατρέψτε ένα αποθηκευμένο αρχείο HTML σε PDF μέσω διακομιστή μετατροπής, ώστε μια ιστοσελίδα ή μια εξαγωγή HTML να γίνει σταθερές σελίδες έτοιμες για εκτύπωση.

Πολλά χρήσιμα έγγραφα υπάρχουν μόνο ως HTML: μια επιβεβαίωση παραγγελίας αποθηκευμένη από τον browser, μια αναφορά που εξάγει κάποια εφαρμογή, ένα newsletter, τεκμηρίωση σε μία μεγάλη σελίδα ή μια σελίδα που φτιάξατε μόνοι σας. Το HTML προσαρμόζεται σε όποιο παράθυρο ανοίξει, και αυτό ακριβώς δεν θέλετε όταν το έγγραφο πρέπει να αρχειοθετηθεί, να τυπωθεί ή να επισυναφθεί σε μια αίτηση. Το PDF το «παγώνει» σε ένα μέγεθος σελίδας.

Το εργαλείο δέχεται ένα αρχείο .html ή .htm από τον υπολογιστή σας, όχι διεύθυνση ιστοσελίδας. Το αρχείο ανεβαίνει κρυπτογραφημένο στην υπηρεσία CloudConvert μέσω του ενδιάμεσου διακομιστή του PDFora, όπου μια μηχανή απόδοσης στήνει τη σελίδα και την τυπώνει σε PDF· το αποτέλεσμα επιστρέφει με το όνομα του αρχείου σας και διαγράφεται μετά από την υπηρεσία. Η μετατροπή δεν γίνεται στον browser σας και στη σελίδα του εργαλείου δεν υπάρχουν ρυθμίσεις για μέγεθος σελίδας ή περιθώρια.

Η μεγαλύτερη έκπληξη για τους περισσότερους είναι τι γίνεται με όλα όσα «δείχνει» το αρχείο HTML. Μια ιστοσελίδα σπάνια είναι ένα αρχείο: εικόνες, φύλλα στυλ και γραμματοσειρές είναι συνήθως ξεχωριστά αρχεία που αναφέρονται μέσα στο HTML. Ανεβαίνει μόνο το ένα αρχείο που επιλέγετε, οπότε ό,τι αναφέρεται με σχετική διαδρομή στον δίσκο σας δεν μπορεί να το βρει ο διακομιστής. Για πιστό PDF, λοιπόν, το βασικό είναι να κάνετε το HTML αυτόνομο πριν το μετατρέψετε.

Πώς να μετατρέψετε HTML σε PDF

  1. Βεβαιωθείτε ότι το αρχείο HTML είναι αυτόνομο ή χρησιμοποιεί πλήρεις διευθύνσεις (https://...) για εικόνες και φύλλα στυλ· δείτε τις σημειώσεις παρακάτω.
  2. Ανοίξτε το HTML σε PDF και επιλέξτε το αρχείο .html ή .htm.
  3. Πατήστε Μετατροπή και περιμένετε όσο το αρχείο ανεβαίνει και αποδίδεται στον διακομιστή.
  4. Κατεβάστε το PDF, που κρατά το όνομα του αρχείου σας με κατάληξη .pdf.
  5. Ελέγξτε ότι πέρασαν σωστά εικόνες, χρώματα και διάταξη, και ότι δεν κόβεται περιεχόμενο στη δεξιά άκρη.

Πότε να χρησιμοποιήσετε αυτό το εργαλείο

  • Αποδείξεις και επιβεβαιώσεις κρατήσεων αποθηκευμένες από τον browser, που κρατάτε ως PDF για το λογιστήριο ή ως αποδεικτικό.
  • Αναφορές που βγάζει ένα πρόγραμμα σε HTML και πρέπει να μπουν σε email ή στο αρχείο.
  • Προγραμματιστές που μετατρέπουν ένα πρότυπο τιμολογίου, βεβαίωσης ή επιστολής σε HTML σε PDF για να δουν πώς τυπώνεται.
  • Τεκμηρίωση ή εγχειρίδιο χρήσης σε μία μεγάλη σελίδα HTML, τυπωμένο για ανάγνωση εκτός σύνδεσης.
  • Άρθρα από το διαδίκτυο που κρατάτε για έρευνα σε μορφή που δεν αλλάζει αν αλλάξει ο ιστότοπος.
  • Newsletter αποθηκευμένα ως HTML και μετατρεμμένα, ως αρχείο του τι στάλθηκε.

Τι πρέπει να ξέρετε πριν ξεκινήσετε

  • Οι σχετικοί σύνδεσμοι σπάνε. Αν το HTML γράφει <img src="images/logo.png"> ή <link href="style.css">, αυτά τα αρχεία μένουν στον υπολογιστή σας και ο διακομιστής δεν τα βλέπει. Το PDF τότε έχει κενά στη θέση των εικόνων και κείμενο χωρίς μορφοποίηση. Χρησιμοποιήστε απόλυτες διευθύνσεις https://, ή ενσωματώστε το CSS σε μπλοκ <style> και τις εικόνες ως data URI.
  • Πόροι με απόλυτες διευθύνσεις μπορεί να ανακτηθούν από τον διακομιστή κατά την απόδοση, οπότε δημόσια διαθέσιμες εικόνες και φύλλα στυλ συνήθως εμφανίζονται. Ό,τι βρίσκεται πίσω από σύνδεση χρήστη, σε εσωτερικό δίκτυο ή στο localhost, όχι.
  • Δεν υπάρχει πεδίο για URL. Για να μετατρέψετε μια ζωντανή σελίδα, αποθηκεύστε την πρώτα· η επιλογή Αποθήκευση ως > Ιστοσελίδα, ενιαίο αρχείο (.mhtml) δεν γίνεται δεκτή, οπότε διαλέξτε Ιστοσελίδα, μόνο HTML και υπολογίστε ότι οι εικόνες με σχετικές διαδρομές θα λείπουν, ή χρησιμοποιήστε την Εκτύπωση > Αποθήκευση ως PDF του browser.
  • Ισχύουν τα στυλ εκτύπωσης. Αν η σελίδα έχει CSS για @media print, ο μετατροπέας συνήθως το χρησιμοποιεί, κάτι που μπορεί να κρύψει μενού πλοήγησης ή να αλλάξει χρώματα σε σχέση με την οθόνη. Οι αλλαγές σελίδας ελέγχονται με break-before και break-inside στο CSS.
  • Περιεχόμενο που φτιάχνει η JavaScript δεν είναι αξιόπιστο. Σελίδες που φέρνουν το περιεχόμενό τους με scripts μετά τη φόρτωση μπορεί να βγουν άδειο κέλυφος. Αποθηκεύστε τη σελίδα αφού φορτώσει πλήρως, ή αποδώστε το περιεχόμενο μέσα στο HTML από την πλευρά του διακομιστή.
  • Διατάξεις φαρδύτερες από μια τυπωμένη σελίδα, όπως σταθερά σχέδια 1400 pixel ή πλατιοί πίνακες, μπορεί να κοπούν ή να μικρύνουν. Μια responsive διάταξη ή ένα max-width στο κύριο περιεχόμενο συνήθως το λύνει.

Συμβουλές για τα καλύτερα αποτελέσματα

  • Στα δικά σας πρότυπα, βάλτε όλο το CSS σε μπλοκ <style> μέσα στο <head>· είναι ο πιο σίγουρος τρόπος για μορφοποιημένο PDF.
  • Προσθέστε @page { size: A4; margin: 15mm; } στο CSS αν θέλετε συγκεκριμένο μέγεθος σελίδας ή περιθώρια.
  • Χρησιμοποιήστε break-inside: avoid σε γραμμές πινάκων, κάρτες και εικόνες ώστε να μη μοιράζονται σε δύο σελίδες.
  • Κρατήστε τις εικόνες σε λογικά μεγέθη: μια εικόνα 5 MB ενσωματωμένη ως data URI βγάζει ούτως ή άλλως PDF 5 MB.
  • Ανοίξτε πρώτα το αρχείο HTML στην προεπισκόπηση εκτύπωσης του browser· αν φαίνεται λάθος εκεί, μάλλον θα φαίνεται λάθος και στο PDF.

Πρακτικό παράδειγμα: το πρότυπο τιμολογίου ενός μικρού e-shop

Ένα e-shop δύο ατόμων στο Ηράκλειο βγάζει τιμολόγια ως αρχεία HTML από ένα απλό script. Κάθε αρχείο συνδέεται με τα invoice.css και logo.png στον ίδιο φάκελο. Αν μετατραπεί απευθείας, το PDF βγαίνει σκέτο μαύρο κείμενο σε προεπιλεγμένη γραμματοσειρά, χωρίς λογότυπο και με τον πίνακα συνόλων απλωμένο σε όλο το πλάτος, επειδή ο διακομιστής πήρε το HTML χωρίς το φύλλο στυλ και την εικόνα.

Η λύση είναι να γίνει το αρχείο αυτόνομο. Το script πλέον αντιγράφει το περιεχόμενο του invoice.css σε μπλοκ <style>, προσθέτει @page { size: A4; margin: 18mm; } και break-inside: avoid στις γραμμές του πίνακα με τα είδη, και δείχνει το λογότυπο στη δημόσια διεύθυνση https του ιστότοπου αντί για τοπική διαδρομή. Τίποτε άλλο δεν αλλάζει.

Στη νέα μετατροπή το τιμολόγιο βγαίνει PDF μίας σελίδας A4, με λογότυπο, τα χρώματα του καταστήματος και πίνακα συνόλων που δεν σπάει πια όταν μια παραγγελία έχει πολλές γραμμές. Επειδή το πρότυπο είναι πλέον αυτόνομο, κάθε τιμολόγιο που βγάζει το script μετατρέπεται με τον ίδιο τρόπο.

Αντιμετώπιση προβλημάτων

Το PDF δεν έχει μορφοποίηση, μόνο σκέτο κείμενο
Το φύλλο στυλ αναφερόταν με σχετική διαδρομή και δεν ανέβηκε. Ενσωματώστε το CSS σε μπλοκ <style> ή συνδέστε το με πλήρη διεύθυνση https://.
Λείπουν εικόνες
Οι εικόνες του δίσκου σας με σχετικές διαδρομές δεν είναι προσβάσιμες. Χρησιμοποιήστε δημόσια URL https:// ή ενσωματώστε τις ως data URI και μετατρέψτε ξανά.
Η σελίδα κόβεται δεξιά
Η διάταξη έχει σταθερό πλάτος μεγαλύτερο από τη σελίδα. Προσθέστε max-width: 100% στα κύρια πλαίσια και στις εικόνες, ή ένα φύλλο στυλ εκτύπωσης που στενεύει τη διάταξη.
Το PDF είναι κενό ή σχεδόν κενό
Το περιεχόμενο μάλλον δημιουργείται από JavaScript μετά τη φόρτωση, ή το αρχείο είναι απλώς ανακατεύθυνση. Αποθηκεύστε τη σελίδα αφού αποδοθεί πλήρως, ή βάλτε το περιεχόμενο μέσα στο ίδιο το HTML.
Το κείμενο βγαίνει σε άλλη γραμματοσειρά
Οι γραμματοσειρές web που αναφέρονταν τοπικά δεν ήταν διαθέσιμες. Συνδέστε τη γραμματοσειρά από δημόσιο URL, ενσωματώστε τη με @font-face και data URI ή χρησιμοποιήστε μια κοινή σειρά γραμματοσειρών.
Το εργαλείο απορρίπτει το αρχείο μου
Γίνονται δεκτά μόνο .html και .htm. Τα αποθηκευμένα .mhtml ή .webarchive πρέπει να αποθηκευτούν ξανά ως μόνο HTML.

Ανεβαίνει το αρχείο HTML;

Ναι. Στέλνεται κρυπτογραφημένο στην υπηρεσία μετατροπής, αποδίδεται εκεί και διαγράφεται μετά. Αποφύγετε να μετατρέπετε σελίδες με προσωπικά δεδομένα που δεν θέλετε να επεξεργαστεί τρίτος.

Γιατί λείπουν οι εικόνες και το CSS μου;

Ανεβαίνει μόνο το ίδιο το αρχείο HTML. Τα αρχεία που αναφέρει με σχετικές διαδρομές μένουν στον υπολογιστή σας· χρησιμοποιήστε απόλυτους συνδέσμους https:// ή ενσωματώστε τα στο HTML.

Μπορώ να ορίσω μέγεθος σελίδας ή περιθώρια;

Όχι από τη σελίδα του εργαλείου. Ορίστε τα μέσα στο HTML με κανόνα CSS @page, για παράδειγμα @page { size: A4; margin: 15mm; }.

Οι σύνδεσμοι προς διευθύνσεις web κανονικά μένουν ενεργοί. Οι σχετικοί σύνδεσμοι προς άλλα τοπικά αρχεία δεν θα οδηγούν κάπου χρήσιμα.

Εκτελείται JavaScript κατά τη μετατροπή;

Μπορεί να εκτελεστεί εν μέρει, αλλά περιεχόμενο που φορτώνει αργά ή εξαρτάται από αλληλεπίδραση του χρήστη συχνά λείπει. Για αξιόπιστο αποτέλεσμα, το HTML πρέπει να περιέχει ήδη το τελικό περιεχόμενο.

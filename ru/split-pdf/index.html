Разделить PDF

Разрежьте один PDF на несколько файлов поменьше: по одному на страницу, равными частями или ровно по тем диапазонам, которые вы укажете.

🔒 Ваши файлы обрабатываются локально в браузере и никогда не загружаются на сервер.
1

Загрузите

Выберите файл или перетащите его сюда.

2

Настройте

Выберите параметры — всё происходит прямо в вашем браузере.

3

Скачайте

Мгновенно сохраните готовый файл. Без водяных знаков.

Длинный PDF часто неудобен для конкретной задачи. Классному руководителю нужно отдать каждому ученику только его табель из выгрузки на 32 страницы; жилец хочет отправить хозяину квартиры страницы 4–6 договора, а не все 40; сканер выдал один огромный файл из стопки никак не связанных писем. Разделение превращает один документ в несколько самостоятельных PDF, каждый из которых можно отдельно назвать, отправить по почте или убрать в архив.

В «Разделить PDF» три режима. «Каждая страница» даёт по одному PDF на страницу. «Каждые N страниц» режет документ на равные части (по умолчанию 2 страницы в файле; в последней части просто остаётся то, что осталось). «Свои диапазоны» позволяет вписать группы вроде 1-3, 4-6, 7-10, где каждая запятая начинает новый файл. Во всех трёх режимах страницы копируются как есть через pdf-lib: текст по-прежнему выделяется, изображения сохраняют разрешение, ничего не перерисовывается, так что страница в результате печатается точно так же, как в оригинале.

Результат приходит пронумерованными файлами с именем вашего оригинала: из contract.pdf получатся contract-1.pdf, contract-2.pdf и так далее. Можно скачать всё сразу архивом contract-split.zip или нажимать на отдельные файлы в списке. Копирование идёт во вкладке браузера, поэтому скорость зависит от вашего устройства, а не от очереди на сервере.

Как разделить PDF на отдельные файлы

  1. Откройте «Разделить PDF» и добавьте один файл. Инструмент работает с одним документом за раз.
  2. Выберите режим: «Каждая страница», «Каждые N страниц» или «Свои диапазоны».
  3. Для «Каждые N страниц» укажите размер части. Для «Своих диапазонов» впишите группы через запятую, например 1-2, 3, 4-9. Каждая группа станет отдельным файлом.
  4. Нажмите «Разделить PDF» и дождитесь индикатора: для каждой группы собирается свой файл.
  5. Нажмите «Скачать всё (.zip)» или скачайте части по одной, а затем откройте пару из них и проверьте места разреза.

Когда использовать этот инструмент

  • Школа: разделить общую выгрузку табелей или грамот на отдельные файлы для каждого ученика перед рассылкой родителям.
  • Аренда: вынуть из длинного договора подписанные страницы с подписями или одно приложение, чтобы отправить другой стороне.
  • Бухгалтерия: разбить отсканированную пачку одностраничных счетов на отдельные PDF для загрузки в учётную программу.
  • Самиздат: нарезать рукопись на главы для бета-ридеров, которым нужна только та часть, которую они читают.
  • Порталы с лимитом страниц: некоторые системы подачи заявлений принимают лишь несколько страниц за раз, и части по N страниц укладываются в их правила.
  • Печать: отправить в копицентр отдельным файлом только цветные страницы отчёта.

Что важно знать заранее

  • В режиме «Свои диапазоны» диапазон 4-6 означает страницы 4, 5 и 6 включительно. Один конец можно оставить открытым: -5 — это страницы с 1 по 5, а 8- — с 8-й до последней.
  • Номера за пределами документа обрезаются, а не отклоняются. 20-30 на файле из 25 страниц даст страницы с 20 по 25. Часть, в которой нет ни одной допустимой страницы, пропускается, а если не осталось ничего, вы увидите просьбу ввести хотя бы один корректный диапазон.
  • Диапазоны могут пересекаться. 1-5, 3-8 даст два файла, в обоих будут страницы 3–5. Это удобно, когда каждому получателю нужна общая титульная страница, но так легко сделать и случайно.
  • В каждой части остаются только страницы. Оглавление-закладки не копируется, ссылки на страницы, ушедшие в другой файл, перестают работать, а заполняемые поля форм могут не сохраниться. Веб-ссылки на странице работают как прежде.
  • Шрифты и изображения, используемые на нескольких страницах, заново сохраняются в каждой части, где они нужны, поэтому части в сумме обычно несколько больше исходного файла.
  • В списке результатов отдельные кнопки скачивания показываются максимум для 50 файлов. Разбить по страницам документ на 300 страниц всё равно можно, но забирайте их архивом zip.

Советы для лучшего результата

  • Прежде чем начать, выпишите диапазоны по миниатюрам в просмотрщике: инструмент считает страницы по их физическому положению в файле, а не по номерам в колонтитуле.
  • Если нужен только один блок страниц, «Извлечь страницы» сразу даст один файл вместо архива с одним файлом внутри.
  • Переименуйте части сразу после распаковки. Через месяц contract-3.pdf ни о чём не скажет, а contract-prilozhenie-B.pdf — скажет.
  • Для пачки со сканера, где документы разной длины, делите по тексту или по закладкам, а не считайте страницы вручную.
  • Сохраните оригинал. Разделение не отменить, но если разрезали не там, части всегда можно снова собрать через «Объединить PDF».

Пример: табели для всего класса

Классный руководитель из Твери выгружает из электронного журнала итоговые табели за четверть на 28 учеников. Приходит один PDF на 56 страниц: по две страницы на ученика, всегда в одном порядке, с фамилией ученика на первой странице каждой пары. Рассылать весь файл каждой семье, разумеется, нельзя.

Режим «Каждые N страниц» с 2 страницами в файле даёт 28 файлов, с reports-1.pdf по reports-28.pdf, в том же порядке, что и список класса. Учитель проверяет reports-1 и reports-28, чтобы убедиться, что пары не съехали (если бы у одного ученика табель занял три страницы, все файлы после него сдвинулись бы на страницу, и надёжнее было бы «Разделить по тексту» по слову, с которого начинается каждый табель). Убедившись, что всё ровно, он переименовывает каждый файл по фамилии ученика и прикрепляет к нужному письму.

Решение проблем

Пишет «Введите хотя бы один корректный диапазон»
Ни один диапазон не совпал с реальной страницей. Проверьте опечатки: например, 1–3 с длинным тире из текстового редактора, буквы или номера больше, чем страниц в документе. Используйте обычный дефис и запятые.
Части сдвинуты на одну страницу
Инструмент считает страницы по положению в файле. Если у документа есть обложка или ненумерованная первая страница, напечатанная страница 1 может быть физической страницей 2. Сдвиньте диапазоны на эту разницу.
Указал диапазоны, а получил один большой файл
Группы разделяются только запятыми. 1-3 4-6 через пробел читается как один неправильный диапазон. Пишите 1-3, 4-6.
Страницы в результате пустые или инструмент выдаёт ошибку при загрузке
Исходник, вероятно, зашифрован или повреждён. Снимите пароль в программе, где он создан, или сначала запустите «Восстановить PDF», а потом делите чистую копию.
Закладки и внутренние ссылки больше не работают
При разделении копируется только содержимое страниц. Если частям нужна навигация, добавьте закладки в каждую через «Создать закладки»; внутренние ссылки на другие части сохранить нельзя.
Браузер тормозит на очень большом файле
Каждая часть собирается в памяти. Закройте другие вкладки или сначала разделите на крупные части, а потом делите их ещё раз.

Часто задаваемые вопросы

Меняется ли качество страниц при разделении?

Нет. Страницы копируются объект за объектом, а не превращаются в картинки, поэтому текст, векторные рисунки и фото идентичны оригиналу.

Как называются получившиеся файлы?

По исходному файлу плюс номер в порядке вывода: из report.pdf получатся report-1.pdf, report-2.pdf и так далее, всё вместе в report-split.zip.

Может ли одна страница попасть в несколько файлов?

Да, в режиме «Свои диапазоны». Пересекающиеся диапазоны вроде 1-2, 1, 3-5 поместят страницу 1 в первые два файла.

Что происходит с последней частью в режиме «Каждые N страниц»?

В ней остаются оставшиеся страницы. Документ из 10 страниц, разделённый по 3, даст файлы на 3, 3, 3 и 1 страницу.

Можно разделить несколько PDF за раз?

Нет, инструмент берёт один файл за запуск. Делите каждый документ отдельно или сначала объедините их, если резать нужно как одну последовательность.

Нужна ли регистрация?

Нет. Регистрации нет, и количество разделений не ограничено.

Разделить по закладкам

Создайте отдельный PDF для каждой закладки верхнего уровня в структуре документа.

🔒 Ваши файлы обрабатываются локально в браузере и никогда не загружаются на сервер.

У грамотно подготовленных PDF есть собственное оглавление — панель закладок слева в программе для чтения. Инструмент разделения по закладкам от PDFora воспринимает эти записи как линии разреза. Каждая закладка верхнего уровня начинает новый файл, и каждый результат называется по заголовку своей закладки, так что «Глава 3. Методология» превращается в файл ровно с таким именем. Весь набор скачивается одним ZIP-архивом.

Ничего из того, что вы разделяете, никуда не загружается. Структура закладок читается, а страницы разделяются локально в вашем браузере, поэтому материалы для совета директоров, юридические записки и неопубликованные рукописи от начала и до конца остаются на вашем компьютере. Инструмент бесплатный, работает без аккаунта, не оставляет водяных знаков и справится с любым количеством документов.

Альтернатива выглядит уныло: открыть панель закладок, выписать начальную страницу каждой главы, десяток раз запустить разделение по диапазонам страниц, а потом вручную переименовать все файлы. Разделение по закладкам сжимает всё это до одного щелчка, причём имена файлов проставляются за вас.

Как разделить PDF по закладкам онлайн

  1. Откройте инструмент разделения по закладкам на getpdfora.com. Обработка остаётся локальной, внутри браузера.
  2. Добавьте PDF, в котором есть структура закладок, — отчёт, руководство или электронную книгу.
  3. Инструмент прочитает закладки верхнего уровня: каждая из них отмечает начало нового файла.
  4. Нажмите «Разделить». Страницы от одной закладки до следующей соберутся в отдельный PDF.
  5. Каждый файл автоматически получит имя по заголовку своей закладки, так что переименовывать вручную ничего не придётся.
  6. Скачайте ZIP-архив и распакуйте его, чтобы получить каждый раздел отдельным файлом с осмысленным именем.

Когда использовать этот инструмент

  • Разделить годовой отчёт на 300 страниц по закладанным разделам, чтобы каждый руководитель направления получил только свою главу.
  • Разбить техническое руководство на PDF по модулям для учебной платформы, которой нужен один файл на урок.
  • Разложить пакет материалов совета директоров на отдельные пункты повестки, каждый с именем своей закладки, для рассылки членам комитета.
  • Разделить судебный пакет на приложения по закладкам, чтобы на каждое приложение можно было ссылаться и отправлять его отдельно.
  • Превратить рукопись кулинарной книги с закладками в отдельные файлы по главам для редакторов, работающих над разными разделами.
  • Выделить главы корпоративного справочника, чтобы HR мог обновить один раздел, не трогая остальные.

Советы для лучшего результата

  • Загляните в панель закладок в своей программе для чтения перед разделением: то, что вы видите на верхнем уровне, — это ровно места будущих разрезов.
  • Разделение запускают только закладки верхнего уровня. Вложенные подзакладки остаются внутри файла своего родителя, что обычно и соответствует логике глав и подразделов.
  • Если в PDF нет закладок, сначала добавьте их в редакторе PDF или воспользуйтесь разделением по тексту либо по диапазонам страниц.
  • По возможности избегайте в заголовках закладок символов вроде косой черты или двоеточия: заголовки становятся именами файлов внутри архива.
  • Длинные документы дают большие ZIP-архивы; загрузки на сервер здесь нет, но не закрывайте вкладку, пока скачивание не завершится.

Часто задаваемые вопросы

Что такое закладки PDF на самом деле?

Закладки, которые иногда называют структурой документа, — это кликабельное оглавление в боковой панели большинства программ для чтения PDF. Авторы и инструменты экспорта вроде Word или InDesign добавляют их, чтобы отметить главы и разделы, а этот инструмент использует те же метки как точки разделения.

Как называются итоговые файлы?

Каждый файл получает заголовок закладки, с которой он начинается, так что закладка «Приложение Б» даёт файл с соответствующим именем. Символы, недопустимые в именах файлов, автоматически корректируются, чтобы всё аккуратно распаковалось из архива.

В моём PDF нет закладок. Инструмент всё равно подойдёт?

Напрямую — нет, ведь именно структура задаёт точки разделения. Либо сначала добавьте закладки в редакторе PDF, либо воспользуйтесь разделением по тексту от PDFora, если начало разделов помечено повторяющимся ключевым словом.

Почему результат скачивается ZIP-архивом?

Документ с закладками часто распадается на десять, двадцать и более частей, и один архив скачать намного проще, чем щёлкать по каждому файлу по очереди. Распакуйте его — и все PDF с осмысленными именами окажутся в одной папке.

Разделяет ли инструмент по вложенным закладкам?

Нет, новые файлы начинают только записи верхнего уровня, а всё вложенное путешествует вместе со своей закладкой. Так подразделы остаются внутри своей главы, а документ не рассыпается на десятки обрывков.

Это действительно бесплатно и остаётся ли документ приватным?

И то и другое — да. Нет ни регистрации, ни водяных знаков, ни ограничений по использованию, а файл разбирается и разделяется целиком в вашем браузере, поэтому он никогда не передаётся на сервер. Время обработки зависит от вашего устройства и размера документа.

Разделить по тексту

Начинайте новый PDF каждый раз, когда на странице встречается выбранное вами ключевое слово, — идеально для разделения выписок и счетов.

🔒 Ваши файлы обрабатываются локально в браузере и никогда не загружаются на сервер.

Загрузите

Выберите файл или перетащите его сюда.

Настройте

Выберите параметры — всё происходит прямо в вашем браузере.

3

Скачайте

Мгновенно сохраните готовый файл. Без водяных знаков.

Пакетное сканирование экономит время ровно до того момента, когда документы снова нужно разделить. Прогоните через сканер 40 счетов — и получите один длинный PDF без каких-либо видимых границ. Инструмент разделения по тексту от PDFora находит эти границы за вас: выберите ключевое слово, например «Счёт», и каждая страница, где оно встречается, станет первой страницей нового файла. Один проход — и пачка снова превращается в 40 отдельных документов.

Поскольку поиск по тексту выполняется локально в вашем браузере, счета, расчётные листки или выписки клиентов, которые вы разделяете, никуда не загружаются. Это принципиальное отличие от серверных сплиттеров, где финансовые документы во время обработки лежат на чужой машине. PDFora бесплатна, не требует регистрации, не ставит водяных знаков и не ограничивает ни количество файлов, ни количество разделений.

Режим без учёта регистра означает, что «СЧЁТ», «Счёт» и «счёт» одинаково запускают разделение, — это выручает, когда документы приходят от разных поставщиков с разными шаблонами. Выбирайте слово, которое надёжно встречается на первой странице каждого документа и только там.

Как разделить PDF по ключевому слову онлайн

  1. Откройте инструмент «Разделить по тексту» на getpdfora.com. Ваш файл будет обработан целиком в браузере.
  2. Добавьте объединённый PDF — например, отсканированную пачку счетов или выписок.
  3. Введите ключевое слово, которое отмечает начало каждого документа, скажем «Счёт» или «Выписка по счёту».
  4. Включите режим без учёта регистра, если написание слова с заглавной буквы в разных документах отличается.
  5. Нажмите «Разделить». Новый файл будет начинаться на каждой странице, где встречается ключевое слово.
  6. Проверьте, что количество полученных файлов совпадает с ожидаемым числом документов, и скачайте их.

When to use this tool

  • Разделить отсканированную стопку счетов от поставщиков на отдельные файлы, используя слово «Счёт» в качестве разделителя.
  • Разобрать зарплатную ведомость на отдельные расчётные листки, разделяя по фразе «Табельный номер», чтобы каждый сотрудник получил только свои страницы.
  • Разбить годовую подборку банковских выписок по фразе «Период выписки» для заявки на кредит.
  • Разделить комплект заказов на поставку, выгруженный одним PDF, по тексту «Заказ на поставку №».
  • Разбить страховой пакет по фразе «Номер полиса», чтобы сертификат каждого клиента можно было подшить отдельно.
  • Разрезать объединённый файл транспортных этикеток по слову «Трек-номер» перед тем, как печатать наклейки поштучно.

Tips for the best results

  • Ключевое слово должно существовать как доступный для поиска текст. Если ваш PDF — обычный скан-картинка без слоя OCR, сначала прогоните его через OCR, иначе поиск ничего не найдёт.
  • Выбирайте фразу, уникальную для первых страниц. «Счёт» подойдёт, если это слово стоит только в заголовке каждого документа; если оно встречается и в колонтитулах, разделяйте по чему-то вроде «Номер счёта:».
  • Фраза обычно надёжнее одного слова: «Налоговый счёт» даст меньше ложных разделений, чем просто «Налог».
  • Проверьте настройки на небольшой выборке, прежде чем запускать пакет на 500 страниц, и сверьте число полученных файлов с тем, сколько документов вы отсканировали.
  • Если файлов оказалось на один больше, ключевое слово, скорее всего, встречается на самой первой странице — это ожидаемо; если лишних файлов больше, значит ваше слово находится и на страницах внутри документов.

Часто задаваемые вопросы

Как работает разделение PDF по тексту?

Инструмент считывает текстовый слой каждой страницы и начинает новый файл всякий раз, когда на странице встречается ваше ключевое слово. Страницы между совпадениями остаются вместе, поэтому каждый результат содержит один полный документ — от страницы с ключевым словом до страницы перед следующим совпадением.

Почему моё ключевое слово не находится?

В девяти случаях из десяти дело в том, что PDF представляет собой отсканированное изображение без выделяемого текста. Попробуйте выделить текст в программе просмотра PDF: если слова не выделяются, сначала прогоните файл через OCR, а уже потом разделяйте.

Важен ли режим без учёта регистра?

Часто — да. Шаблоны поставщиков расходятся в написании заглавных букв, поэтому «СЧЁТ» в одном документе и «Счёт» в другом иначе привели бы к неровному разделению. Включайте этот режим, если вам специально не нужно точное совпадение регистра.

Безопасны ли мои финансовые документы в этом инструменте?

Да, потому что они не покидают ваше устройство. И поиск, и разделение выполняются локально в вашем браузере: без загрузки на сервер, без хранения на стороне сервера и без аккаунта, привязанного к вашим файлам.

Можно ли разделять по фразе из нескольких слов?

Да, фразы вроде «Выписка по счёту» работают и обычно точнее отдельных слов. Более длинные и конкретные фразы снижают вероятность случайных разделений на страницах, где слово просто упоминается.

Есть ли ограничение на размер файла или количество разделений?

Нет. PDFora бесплатна и не требует регистрации, не добавляет водяных знаков и не устанавливает потолка ни по страницам, ни по итоговым файлам, ни по количеству обработанных пакетов. Очень большие файлы просто обрабатываются дольше, поскольку всю работу выполняет ваш собственный компьютер.

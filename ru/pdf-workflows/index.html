Рабочие процессы

Соберите несколько PDF-инструментов в цепочку и прогоните через неё файл за один раз — каждый шаг работает с настройками по умолчанию.

🔒 Ваши файлы обрабатываются локально в браузере и никогда не загружаются на сервер.
1

Загрузите

Выберите файл или перетащите его сюда.

2

Настройте

Выберите параметры — всё происходит прямо в вашем браузере.

3

Скачайте

Мгновенно сохраните готовый файл. Без водяных знаков.

Некоторые рутинные задачи с PDF всегда идут одним набором. Отсканированный договор нужно выровнять, пронумеровать и поставить водяной знак; исходящий отчёт — свести поля форм, убрать комментарии и уменьшить размер. Делать это по одному инструменту — значит скачивать и снова загружать файл три-четыре раза, каждый раз с промежуточным файлом. «Рабочие процессы» связывают шаги вместе: вы составляете список, бросаете PDF и получаете один готовый файл под именем вашфайл-workflow.pdf.

В цепочку можно поставить двенадцать инструментов: «Сжать», «Оттенки серого», «Повернуть на 90°», «Водяной знак», «Номера страниц», «Обрезать поля», «Привести к A4», «Сделать плоским», «Восстановить», «Удалить аннотации», «Отразить» и «Обновить метаданные». Они выполняются сверху вниз, и результат каждого шага становится входом следующего. Шаг можно поднять кнопкой ↑ или удалить кнопкой ✕, а один и тот же инструмент — добавить несколько раз.

Плата за скорость — отсутствие настроек у отдельных шагов. Каждый шаг использует настройки инструмента по умолчанию (они перечислены ниже), так что цепочка полезна, только когда эти настройки вас устраивают. Если нужен свой текст водяного знака или другой поворот, запустите этот инструмент отдельно. На практике умолчания хорошо подходят для обычной офисной рутины: стандартная пометка о конфиденциальности, простые номера страниц, вывод в A4 и сбалансированный уровень сжатия.

Как запустить несколько PDF-инструментов за один раз

  1. Откройте «Рабочие процессы». Выберите инструмент в списке «Добавить шаг…» и нажмите «Добавить». Повторите для каждого шага.
  2. Проверьте порядок. Шаги выполняются начиная с первого; кнопкой ↑ шаг поднимается выше, кнопкой ✕ удаляется.
  3. Перетащите один PDF в поле под списком шагов или нажмите на него, чтобы выбрать файл.
  4. Следите за строкой состояния: по мере работы она показывает «Шаг 2/4: Водяной знак…» и так далее.
  5. Когда появится «Готово», откройте скачанный файл -workflow.pdf и проверьте, что каждый шаг сделал то, что вы ожидали.

Когда использовать этот инструмент

  • Небольшая компания ставит на коммерческие предложения пометку CONFIDENTIAL и нумерует страницы перед отправкой клиенту.
  • Офис убирает комментарии рецензентов и сводит заполненные формы перед сдачей в архив.
  • Подготовка сканов для портала, которому нужны небольшие файлы в оттенках серого: «Оттенки серого», затем «Сжать».
  • Приведение документов разного формата к A4 и добавление номеров страниц, чтобы всё печаталось единообразно.
  • Исправление пачки, отсканированной боком, где каждую страницу нужно повернуть, а результат — сжать.
  • «Восстановить» первым шагом для файлов из старой системы, которые другие инструменты иногда отказываются открывать.

Что важно знать заранее

  • Настройки по умолчанию фиксированы: «Сжать» использует уровень «Рекомендуемая»; поворот разворачивает каждую страницу на 90° по часовой стрелке; водяной знак пишет «CONFIDENTIAL» размером 50 pt с непрозрачностью 30% по диагонали; номера страниц — простые 1, 2, 3 снизу по центру, 11 pt, начиная с 1; «Обрезать поля» срезает 30 пунктов (около 10,5 мм) с каждой стороны; «Привести к A4» вписывает страницы в A4; «Отразить» зеркалит по горизонтали.
  • «Сжать», «Оттенки серого» и «Отразить» перерисовывают каждую страницу как изображение JPEG. Все шаги после них работают уже с картинками страниц, и в итоговом файле не будет выделяемого текста, ссылок и полей форм. Ставьте эти шаги в конец, если только вам не нужно именно это.
  • «Обновить метаданные» без значений обновляет только дату изменения файла. Название и автора он не меняет — в рабочем процессе их просто негде ввести.
  • За один запуск обрабатывается один PDF. Чтобы одинаково обработать несколько файлов, бросайте их по очереди: список шагов между запусками сохраняется.
  • Список шагов не сохраняется насовсем. Перезагрузка или закрытие страницы его очищает, так что запишите себе процесс, которым пользуетесь регулярно. Благодаря этому удобно обработать пачку из десятка похожих файлов, хотя каждый всё равно нужно бросить вручную.
  • Если какой-то шаг завершился ошибкой, запуск останавливается с ошибкой этого шага и ничего не скачивается. Результаты предыдущих шагов отдельно не сохраняются.

Советы для лучшего результата

  • Если файл уже капризничал в других инструментах, ставьте «Восстановить» первым шагом — тогда все последующие шаги получат чисто пересобранный документ.
  • Для штампов порядок важен: ставьте «Номера страниц» и «Водяной знак» после «Привести к A4» и «Обрезать поля», иначе следующий шаг может уменьшить или срезать штамп.
  • Ставьте «Сделать плоским» перед «Сжать». «Сжать» всё равно превращает страницы в изображения, но предварительное сведение гарантирует, что заполненные значения форм действительно будут видны на этой картинке.
  • Проверяйте новый процесс на коротком файле, прежде чем прогонять через него документ на 200 страниц. Двух-трёх страниц достаточно, чтобы увидеть, там ли стоят штампы и приемлемо ли качество после сжатия.
  • Два шага «Повернуть на 90°» дают поворот на 180°, три — на 90° против часовой стрелки.

Пример: помощник юриста готовит копии для передачи другой стороне

Помощнику юриста нужно отправить другой стороне комплект подписанных соглашений. Каждое должно быть в формате A4, с номерами страниц, пометкой о конфиденциальности, без внутренних комментариев рецензентов и достаточно лёгким для отправки по почте. Файлов девять, и четыре инструмента вручную на каждый означали бы 36 отдельных запусков.

Процесс собирается так: 1 «Удалить аннотации», 2 «Привести к A4», 3 «Водяной знак», 4 «Номера страниц», 5 «Сжать». Комментарии идут первыми, чтобы потом не «впечататься» в изображение; изменение размера стоит до штампов, чтобы они легли на позиции A4; «Сжать» — последним, потому что превращает каждую страницу в картинку. Каждое соглашение бросается один раз и выходит, например, как supply-agreement-workflow.pdf. Девять файлов занимают в сумме всего несколько минут, и большая часть уходит на шаг сжатия, который отрисовывает каждую страницу.

Подвох, который стоит заметить: раз в цепочке есть «Сжать», по исходящим копиям больше нельзя искать текст. Для копий, которые не должны легко редактироваться, это нормально, но если другой стороне нужен поиск, уберите шаг 5 и сжимайте только те файлы, которые не пролезают в письмо.

Решение проблем

«Сначала добавьте хотя бы один шаг»
Список шагов пуст. Выберите инструмент в списке «Добавить шаг…» и нажмите «Добавить», прежде чем бросать PDF.
Водяной знак или номера страниц не на своём месте
Следующий шаг изменил геометрию страницы. Кнопкой ↑ поднимите «Привести к A4», «Обрезать поля» и поворот выше водяного знака и номеров страниц и запустите снова.
Текст больше не выделяется
В цепочке есть «Сжать», «Оттенки серого» или «Отразить» — они дают страницы-картинки. Уберите их или перенесите в конец, смирившись с тем, что в результате страницы будут изображениями.
Запуск останавливается на одном шаге с ошибкой
Этот инструмент не смог обработать файл на этом этапе — часто потому, что он защищён паролем или повреждён. Добавьте «Восстановить» первым шагом или сначала исправьте файл, а затем запустите процесс снова. Строка состояния называет шаг со сбоем, так что вы знаете, какой инструмент проверить отдельно.
Мои шаги пропали
Список существует, только пока открыта страница. Соберите его заново; для повторяющихся процессов держите короткую записку с порядком шагов.
Нужен другой текст водяного знака или другой поворот
Рабочие процессы всегда используют настройки по умолчанию. Запустите «Водяной знак» или «Повернуть PDF» отдельно со своими настройками, а для остальных шагов используйте рабочий процесс.

Часто задаваемые вопросы

Можно изменить настройки шага?

Нет. Каждый шаг выполняется с настройками инструмента по умолчанию. Для своих параметров используйте отдельный инструмент.

Можно запустить процесс сразу на нескольких PDF?

Не за один запуск. Инструмент обрабатывает по одному файлу, но список шагов остаётся готовым, так что следующий файл можно бросить сразу же.

Можно сохранить рабочий процесс на потом?

Пока нет. Шаги хранятся, только пока открыта страница.

Почему шагами можно сделать не все инструменты?

Шаг должен принимать один PDF и возвращать один PDF. Инструменты, которым нужно несколько файлов, которые выдают ZIP, экспортируют изображения или текст либо требуют серверной конвертации, в цепочку не встраиваются.

Файл обрабатывается на сервере?

Нет. Все двенадцать инструментов для цепочек работают во вкладке браузера; PDF передаётся от шага к шагу в памяти, а скачивается только итоговый результат.

Что будет, если добавить один инструмент дважды?

Он выполнится дважды. Два шага поворота развернут страницы на 180°; два шага сжатия обычно почти ничего не экономят, зато сильнее бьют по качеству.

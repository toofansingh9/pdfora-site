Bates Numbering

Bates numbering gives every page in a set of documents its own identifier, so that people can refer to 'page SMITH-000412' instead of 'the third invoice in the second folder'. It is standard in litigation, regulatory responses and audits, where thousands of pages are exchanged and each one must be citable without ambiguity. Unlike ordinary page numbers, a Bates number does not restart with each document; it continues across the whole production.

PDFora's tool stamps one PDF at a time. You set a prefix (for example ABC- or a matter code), a start number and the number of digits; the number is zero-padded to that width, so a start of 1 with 6 digits gives ABC-000001, ABC-000002 and so on. The label is drawn in 10-point Helvetica, near-black, about 6 mm from the bottom edge, in the bottom right, left or centre. A start of 0 is allowed.

The original pages are left as they are and the label is added on top with pdf-lib in your browser, so a production set containing privileged or personal material can be stamped before it leaves your machine. The output is yourfile-bates.pdf. Whether the result meets the rules of your court, regulator or agreement is for you or your lawyer to confirm; the tool only applies the stamp.

How to add Bates numbers to a PDF

  1. Open Bates Numbering and choose the PDF that should receive the next block of numbers.
  2. Type the prefix exactly as agreed, including any hyphen or underscore, for example DEF_ or SMITH-.
  3. Enter the start number: 1 for the first file of a production, or the last number used plus one for a later file.
  4. Set the number of digits (6 by default) and the position. Bottom right is the most common convention.
  5. Click Add Bates numbers, download the file, and write down the first and last label before stamping the next document.

When to use this tool

  • Disclosure or discovery productions, where each page handed to the other side must have a unique reference.
  • Responses to a regulator or ombudsman, so the investigator can cite specific pages in their findings.
  • Internal investigations and HR grievances, keeping evidence bundles traceable page by page.
  • Audit and grant-compliance files, with receipts and statements numbered across a whole reporting period.
  • Tenancy deposit or small-claims disputes, where a tenant or landlord sends a numbered evidence pack.
  • Records requests and freedom-of-information releases, letting the requester refer back to exact pages.

What to know before you start

  • Numbering covers one file per run. To number a set of files continuously, process them in order and set each start number to the previous file's last number plus one. Alternatively, merge the set first and stamp it once.
  • The prefix, digits and position are adjustable; the font size (10 points), colour and margin are fixed. There is no suffix field and no option for a second line such as 'CONFIDENTIAL'; add that with Header & Footer.
  • Zero-padding only adds zeros. If a number grows beyond the digit count, for example page 1,000,000 with 6 digits, it simply becomes longer; nothing is cut off.
  • The label is drawn as ordinary visible text. It is not tamper-proof and can be edited in a PDF editor. Keep an unmodified stamped master copy and record its checksum if integrity matters.
  • The label is placed from the full page size. Pages stored rotated or with a reduced crop box can show the number sideways or outside the visible area; normalise such pages first.
  • Any material already in the bottom margin, such as a footer or a scan border, is not moved. The Bates label is drawn over it, which can make both harder to read.

Tips for the best results

  • Agree the prefix and digit count with the other side before stamping anything. Changing them halfway makes the production inconsistent.
  • Keep a simple log: file name, first label, last label, page count. It turns a later 'which file is SMITH-000731 in?' into a quick lookup.
  • Run OCR on scanned documents before stamping, not after, so the bundle is searchable as well as numbered.
  • Do redactions before Bates numbering. A page removed after stamping leaves a gap that will need explaining.
  • Choose a position away from existing footers. Bottom left or centre is a good fallback if letterheads print reference codes in the right corner.

Example: a small-claims evidence pack in three files

A small business owner is preparing evidence for a payment dispute: a 12-page contract, 31 pages of emails and a 7-page set of invoices. The court guidance asks for consecutively numbered pages, and the business decides on the prefix CLM- with 5 digits.

The contract goes first, start 1, producing CLM-00001 to CLM-00012. The emails start at 13 and end at CLM-00043. The invoices start at 44 and end at CLM-00050. After each run the owner writes the first and last label in a simple table and checks the last page of each output against it.

Two of the email pages turn out to have a long signature block that fills the bottom right corner. Rather than start over, the owner re-runs only the email file with the position set to bottom left and the same start number, 13. The numbering stays continuous, and the label is now clear on every page.

When the other side later asks about 'the invoice at CLM-00047', the owner looks at the log, sees that the invoice file runs from 44 to 50, and opens page 4 of that file. Without the numbering, the same question would have meant paging through three separate documents.

Troubleshooting

Each file starts again at 000001
The tool numbers one file per run and uses the start number you enter each time. Set the start to the previous file's last number plus one, or merge the files first.
The label clashes with an existing footer
Change the position to bottom left or bottom centre. The size and margin are fixed, so position is the only adjustment.
Some labels appear sideways
Those pages are stored rotated. Correct them with Rotate PDF and stamp the corrected file with the same start number.
The prefix causes an error
The built-in font cannot encode non-Latin characters or unusual symbols. Use letters, digits, hyphens or underscores.
I need to stamp CONFIDENTIAL next to the number
Use Header & Footer after Bates numbering, placing the text in the header so the two stamps do not overlap.
The labels are lighter than the page text on a scan
They are drawn near-black at 10 points. If the scan has a dark grey background, the contrast can look weak on screen; print a test page to confirm it is legible.

Frequently asked questions

What is the difference between Bates numbers and page numbers?

Page numbers restart in each document. Bates numbers carry an agreed prefix and continue across all the documents in a set, so each page has a unique reference.

Can I Bates-number several PDFs at once?

Not in a single run. Stamp them one by one, starting each where the last ended, or merge them and stamp the merged file.

Can I start from zero?

Yes. A start of 0 with 6 digits produces ABC-000000 on the first page. Some parties prefer to start at 1 so that the label matches the count of pages produced; agree the convention before you begin.

Can I change the font size of the Bates label?

No. It is fixed at 10 points, which is the usual size for a reference stamp. You can choose the prefix, digits, start and position.

Is this suitable for a formal court production?

It applies a standard prefix-plus-number stamp, but production rules differ by court and agreement. Check the required format, position and any load-file requirements with your lawyer.

Does stamping change the content of the pages?

No. The label is added on top; the existing text and images are left as they were, and text-based pages remain searchable.

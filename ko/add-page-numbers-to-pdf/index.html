다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

브라우저에서 몇 초 만에 PDF에 페이지 번호를 넣을 수 있습니다. 병합한 보고서, 스캔한 논문, 세 군데서 모아 만든 계약서. 이런 문서에는 번호가 아예 없는 경우가 많은데, 번호 없는 80장을 인쇄한다는 건 사고를 자초하는 일이죠. PDFora는 파일이 기기에 머무는 상태로 모든 페이지에 깔끔하고 일관된 번호를 찍습니다. 도구 전체가 로컬 처리 방식으로 동작하므로 아무것도 업로드되지 않습니다.

번호가 놓일 위치와 표기 방식을 직접 고를 수 있습니다. 위치는 아래 가운데, 아래 오른쪽, 아래 왼쪽, 위 가운데, 위 오른쪽까지 지원하므로 머리글이나 바닥글, 제본 여백을 피해 배치할 수 있습니다. 형식은 단순한 '1', 총 페이지를 함께 보여 주는 '1 of N', 좀 더 격식 있는 'Page 1' 중에서 고를 수 있습니다. 책 중간부터 시작하는 챕터라면 시작 번호를 직접 지정해 그 지점부터 이어서 셀 수 있습니다.

다른 PDFora 도구와 마찬가지로 이것도 무료이며 가입도, 결과물에 찍히는 워터마크도, 번호를 매길 수 있는 파일 수 제한도 없습니다. 법원 제출 서류, 학위 논문, 이사회 자료. 어떤 문서든 넣은 번호가 그대로 남고, 모서리에 로고가 붙는 일도 없습니다.

온라인에서 PDF에 페이지 번호 넣는 방법

  1. getpdfora.com의 페이지 번호 도구로 이동해 PDF 파일을 끌어다 놓습니다.
  2. 위치를 고릅니다. 아래 가운데, 아래 오른쪽, 아래 왼쪽, 위 가운데, 위 오른쪽 중에서 선택하세요.
  3. 형식을 고릅니다. 숫자만 나오는 '1', 총 페이지가 함께 나오는 '1 of N', 라벨이 붙는 'Page 1' 중 하나입니다.
  4. 시작 번호를 설정합니다. 1로 두어도 되고, 앞선 부분에 이어지는 파일이라면 47부터 시작해도 됩니다.
  5. 번호를 적용하고 브라우저가 파일을 로컬에서 처리하도록 둡니다. 업로드도, 서버를 기다리는 시간도 없습니다.
  6. 번호가 들어간 PDF를 내려받고, 인쇄하거나 공유하기 전에 첫 페이지와 마지막 페이지를 확인합니다.

When to use this tool

  • 모든 페이지에 연속 번호를 요구하는 대학 규정에 맞춰, 제출 전 학위 논문에 번호 넣기.
  • '240쪽 중 12쪽' 식의 참조로 모두가 같은 페이지를 보게 만드는 법정 증거 자료나 소송 자료집 준비하기.
  • 여러 보고서를 이어 붙여 만든 PDF를 정리해, 합쳐진 파일이 하나의 연속된 문서로 읽히게 하기.
  • 애초에 번호가 없던 스캔 아카이브, 예를 들어 옛 회의록, 장부, 서신에 번호 넣기.
  • 교육 매뉴얼과 사규집에 번호를 넣어, 직원들이 위치를 대충 설명하는 대신 '34쪽'이라고 인용할 수 있게 하기.
  • 분권한 문서의 두 번째 파일을 첫 번째가 끝난 번호부터 시작해 번호를 이어 가기.

Tips for the best results

  • 인쇄해서 돌려 볼 문서에는 '1 of N'을 쓰세요. 마지막 장에 80 of 80이라고 적혀 있으면 한 장이 빠진 걸 바로 알 수 있습니다.
  • 페이지에 이미 바닥글이 있다면 번호를 위 가운데나 위 오른쪽에 놓아 텍스트가 겹치지 않게 하세요.
  • 구멍을 뚫어 제본할 문서라면 가운데 대신 아래 왼쪽이나 아래 오른쪽을 골라 번호가 제본선 쪽에서 멀어지게 하세요.
  • 긴 저작물에서 뽑아낸 챕터에 번호를 매길 때는 시작 번호를 원본 쪽수에 맞춰, 인용이 계속 들어맞게 하세요.
  • 병합과 페이지 삭제를 끝낸 최종본에 번호를 넣으세요. 다시 매기는 건 쉽지만, 순서가 바뀐 파일에 남은 옛 번호는 혼란을 부릅니다.

자주 묻는 질문

제 파일이 서버로 업로드되나요?

아니요. 이 도구는 로컬 처리 방식으로 전부 브라우저 안에서 동작합니다. PDF는 시작부터 끝까지 컴퓨터에 남아 있어 기밀 계약서나 미공개 원고에도 안전합니다.

1이 아닌 숫자부터 번호를 시작할 수 있나요?

네. 원하는 시작 번호를 입력하면 거기서부터 세기 시작합니다. 챕터나 부록, 앞서 분할해 둔 문서의 뒷부분에 유용합니다.

어떤 번호 형식이 있나요?

세 가지입니다. '1' 같은 숫자만 표시하는 형식, 전체 페이지 수를 포함하는 '1 of N', 그리고 'Page 1'입니다. 문서 스타일에 맞는 것을 고르세요.

번호가 페이지의 어디에 들어갈 수 있나요?

아래 가운데, 아래 오른쪽, 아래 왼쪽, 위 가운데, 위 오른쪽까지 다섯 가지 위치를 지원합니다. 기존 머리글이나 바닥글을 피하는 위치를 고르세요.

정말 무료인가요? 파일에 표시가 남나요?

가입도 사용량 상한도 없이 무료이고, PDFora는 문서에 자체 요소를 전혀 넣지 않습니다. 워터마크도 브랜딩도 없습니다. 결과물에는 사용자의 페이지와 번호만 담깁니다.

아주 큰 PDF에도 번호를 넣을 수 있나요?

네. 도구가 정한 페이지 제한은 없습니다. 모든 처리가 로컬에서 이뤄지므로 수백 페이지짜리 파일도 기기 성능이 허락하는 만큼 빠르게 처리되고 업로드 시간은 아예 들지 않습니다.

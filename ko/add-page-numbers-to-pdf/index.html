페이지 번호

PDF의 모든 페이지에 1, 1 of N, Page 1 형식 중 하나로, 다섯 가지 위치 중 한 곳에 쪽 번호를 찍습니다.

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

쪽 번호 없는 PDF는 작지만 성가신 문제를 일으킵니다. 검토자가 '네 번째 페이지 표 참고'라고 적으면 그게 어느 페이지인지 의견이 갈리고, 인쇄한 유인물을 떨어뜨리면 순서를 되돌릴 수 없고, 지도 교수가 쪽수를 물어도 문서에는 없습니다. 번호를 넣으면 다 해결되지만, 기존 바닥글과 겹치지 않는 곳에, 올바른 숫자부터 시작해야 의미가 있습니다.

이 도구는 PDF 한 개의 각 페이지에 11포인트 진한 회색 Helvetica로 번호를 그립니다. 위치(하단 가운데, 오른쪽 하단, 왼쪽 하단, 상단 가운데, 오른쪽 상단), 형식(1, 2, 3 숫자만 / '1 of 12' / 'Page 1'), 시작 번호를 고를 수 있습니다. 번호는 옆 가장자리에서 28포인트, 10 mm가 약간 안 되는 거리만큼 안쪽에 놓이고, 아래쪽이면 기준선이 가장자리에서 약 7 mm 위, 위쪽이면 약 10 mm 아래에 놓입니다. 페이지의 다른 것은 옮기거나, 크기를 바꾸거나, 다시 렌더링하지 않습니다.

번호는 브라우저 탭 안에 있는 사본에 pdf-lib 라이브러리가 찍으며, 결과는 yourfile-numbered.pdf 형태로 다운로드됩니다. 원래 내용이 그대로이므로 텍스트 기반 PDF는 계속 검색되고, 스캔본도 이전과 똑같이 선명합니다.

PDF에 쪽 번호 넣는 방법

  1. 페이지 번호 추가 도구를 열고 PDF를 선택합니다. 한 번에 파일 하나만 처리합니다.
  2. 위치를 고릅니다. 먼저 문서를 살펴보고, 가운데에 이미 바닥글이 있다면 오른쪽 하단이나 오른쪽 상단을 고르세요.
  3. 형식을 고릅니다. 대부분의 문서는 1, 2, 3, 독자가 문서가 빠짐없는지 알아야 하면 '1 of N', 서식과 인쇄 묶음에는 'Page 1'이 어울립니다.
  4. 글꼴 크기와 시작 번호를 정합니다. 예를 들어 앞 네 페이지가 별도 파일인 보고서의 뒷부분이라면 5부터 시작합니다.
  5. 페이지 번호 추가를 누르고 파일을 다운로드해 첫 페이지, 마지막 페이지, 가로 페이지를 확인합니다.

이 도구가 필요한 경우

  • 따로 내보낸 장들을 모아 만든 학위 논문에 최종 병합을 마친 뒤 한 번에 번호를 넣을 때.
  • 이사회·위원회 회의 자료처럼 모두가 '14페이지'라고 말할 때 같은 페이지를 가리켜야 할 때.
  • 스캔한 계약서와 합의서에 '1 of N'을 넣어 페이지가 빠지면 양쪽 모두 바로 알 수 있게 할 때.
  • 양면 인쇄한 수업 유인물과 워크북에 번호를 넣어 떨어뜨린 종이를 다시 순서대로 맞출 수 있게 할 때.
  • 페이지 수 제한이 엄격한 입찰·지원 사업 제출 서류에서 심사자가 쪽수를 규정과 대조할 때.
  • 보험·의료비 청구 서류 묶음에서 담당자가 영수증과 진단서의 특정 페이지를 다시 짚어야 할 때.

시작하기 전에 알아둘 점

  • 표지를 포함해 모든 페이지에 번호가 들어갑니다. 첫 페이지를 건너뛰거나 일부 범위에만 넣는 옵션은 없습니다. 표지를 비워 두려면 표지를 분리하고 나머지를 2부터 번호 매긴 뒤 표지를 다시 합치세요.
  • 실제로 쓸 수 있는 가장 작은 시작 값은 1입니다. 0을 입력하면 빈 값으로 처리되어 결국 1부터 시작합니다.
  • '1 of N'의 N은 실제로 찍히는 마지막 번호입니다. 10페이지 파일에서 5부터 시작하면 '5 of 14'부터 '14 of 14'까지 찍힙니다.
  • 번호는 보이는 스탬프로만 추가됩니다. 뷰어의 페이지 상자에 보이는 페이지 레이블(i, ii, 1, 2…)은 바뀌지 않으며, 로마 숫자는 지원하지 않습니다.
  • 형식에 쓰이는 단어는 영어로 고정되어 있습니다. 'of'와 'Page'는 번역할 수 없으므로, 한국어 문서에서 영어가 보이는 게 싫다면 숫자만 있는 1, 2, 3 형식을 쓰세요.
  • 위치는 각 페이지의 전체 크기를 기준으로 계산됩니다. 회전된 상태로 저장되었거나 자르기 상자가 줄어든 페이지는 번호가 옆으로 눕거나, 엉뚱한 모서리에 가거나, 보이는 영역 밖에 찍힐 수 있습니다.

더 좋은 결과를 위한 팁

  • 번호는 반드시 최종 병합 후에 넣으세요. 부분마다 따로 번호를 넣으면 합쳤을 때 1이 여러 번 나오고 번호가 비게 됩니다.
  • 왼쪽을 제본하거나 스테이플러로 묶을 문서라면 번호가 제본선에 묻히지 않게 하단 가운데나 오른쪽 하단을 쓰세요.
  • 기존 문서에 작은 바닥글이 있다면 글꼴 크기를 9나 10으로 해서 번호가 바닥글보다 무거워 보이지 않게 하세요.
  • 파일이 다른 파일에 이어지는 경우(보고서 2부 등) 1부의 마지막 쪽 번호를 확인하고 2부는 그 번호 더하기 1부터 시작하세요.
  • 한 장만 시험 인쇄해 보세요. 화면에서는 괜찮던 번호가 일부 사무실 프린터에서는 인쇄 불가 여백에 걸릴 수 있습니다.

예시: 대학원생의 46페이지 학위 논문

석사과정생 윤지아 씨는 표지, 초록, 다섯 개 장, 부록을 세 가지 편집기에서 각각 내보내 46페이지 PDF 하나로 합쳤습니다. 학과 규정은 표지에는 번호를 넣지 않고, 초록부터 본문까지 하단 가운데에 번호를 넣으라는 것입니다.

PDF 분할로 1페이지를 떼어 내고, 나머지 45페이지를 위치 하단 가운데, 형식 1, 2, 3, 글꼴 크기 10, 시작 번호 2로 페이지 번호 도구에 돌린 뒤, 표지를 다시 앞에 합칩니다. 이제 번호가 있는 페이지는 2부터 46까지로, 직접 작성한 목차와 일치합니다.

부록 하나는 스프레드시트 프로그램이 회전된 상태로 내보낸 가로 표입니다. 그 페이지에서는 번호가 옆면을 따라 찍힙니다. 병합된 파일에서 PDF 회전 도구로 방향을 바로잡고 정리된 사본에 다시 번호를 넣자 문제가 사라집니다. 제출 전에 최종 파일을 열어 마지막 페이지로 가 보니 46이 찍혀 있고, 뷰어가 알려 주는 전체 페이지 수와 같아서 분할과 병합 과정에서 빠진 페이지가 없음을 확인합니다.

문제 해결

번호가 기존 바닥글과 겹쳐요
오른쪽 하단이나 오른쪽 상단처럼 다른 위치를 고르거나 글꼴 크기를 줄이세요. 이 도구는 기존 바닥글을 옮길 수 없습니다.
0을 입력했는데 1부터 시작해요
시작 값 0은 빈 값으로 처리됩니다. 1부터 시작하세요. 정말 0페이지가 필요하다면 1부터 매기고 한 칸 차이를 감수하세요.
일부 페이지에서 번호가 옆으로 누워 있어요
그 페이지들이 회전된 상태로 저장되어 있습니다. PDF 회전 도구로 바로잡아 저장한 뒤 그 파일에 번호를 넣으세요.
번호가 아예 안 보여요
페이지의 자르기 상자가 전체 페이지보다 작아 번호가 찍힌 여백을 가리거나, 아래에 어두운 이미지가 있을 수 있습니다. 위쪽 위치를 쓰거나, 페이지에서 밝은 부분에 해당하는 하단 가운데를 시도해 보세요.
원치 않는데 표지에 번호가 찍혀요
표지를 분리하고 나머지 페이지를 2부터 번호 매긴 뒤 두 파일을 다시 합치세요.
뷰어의 페이지 상자에는 여전히 다른 번호가 보여요
이 도구는 보이는 번호만 찍고 문서 내부의 페이지 레이블은 수정하지 않습니다. 대부분의 뷰어는 이동 상자에 계속 1부터 N까지 보여 줍니다.

자주 묻는 질문

앞부분에 로마 숫자를 쓸 수 있나요?

아니요. 형식은 1, '1 of N', 'Page 1'입니다. 로마 숫자가 필요하면 내보내기 전에 워드프로세서에서 앞부분에 번호를 넣으세요.

첫 페이지를 건너뛸 수 있나요?

직접은 안 됩니다. 첫 페이지를 분리하고, 나머지를 2부터 번호 매긴 뒤 다시 합치세요.

번호의 글꼴이나 색상을 고를 수 있나요?

아니요. 번호는 항상 진한 회색 Helvetica입니다. 크기와 위치만 조정할 수 있습니다.

번호를 넣으면 스캔본 화질이 떨어지나요?

아니요. 번호는 작은 텍스트로 위에 그려질 뿐, 아래의 스캔 이미지는 재압축되거나 다시 렌더링되지 않습니다.

페이지 크기가 섞인 문서에서도 되나요?

네. 위치가 페이지마다 따로 계산되므로 A4 페이지와 가로 페이지가 각자의 모서리나 가운데에 번호를 받습니다.

여러 PDF에 한 번에 번호를 넣을 수 있나요?

한 번 실행으로는 안 됩니다. 한 문서에 속한다면 먼저 합치고, 아니면 파일마다 알맞은 시작 번호로 따로 처리하세요.

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

완벽하게 스캔하는 사람은 없습니다. 종이를 살짝 비뚤게 넣거나 문서를 대충 기울여 촬영하면 글자가 페이지를 가로질러 비스듬히 흘러내리죠. PDFora의 기울기 보정 도구는 브라우저 안에서 삐뚤어진 스캔본을 바로 세웁니다. 각 페이지가 얼마나 기울었는지 측정해 수평으로 되돌리므로 결과물이 제대로 된 평판 스캐너에서 나온 것처럼 보입니다.

작업 방식은 두 가지입니다. 자동 감지는 페이지를 분석해 기울기 각도를 스스로 찾아 보정하며, 대부분의 스캔본을 클릭 한 번으로 처리합니다. 수동 모드는 대신 각도 조절 기능을 제공하는데, 감지기가 잡아낼 글자가 적은 페이지이거나 소수점 단위로 직접 미세 조정하고 싶을 때 유용합니다.

보정은 로컬에서 실행되므로 스캔한 계약서와 기록이 어디로도 업로드되지 않습니다. 기울기 보정은 무료이고, 가입이 필요 없으며, 워터마크가 남지 않고, 사용 횟수 제한도 없습니다. 이후 작업에도 도움이 됩니다. 반듯한 페이지는 OCR 정확도가 높고, 인쇄도 깔끔하며, 무엇보다 공들인 티가 납니다.

온라인에서 PDF 기울기 보정하는 방법

  1. 브라우저에서 PDFora의 기울기 보정 도구를 엽니다.
  2. PDF를 끌어다 놓거나 기기에서 선택해 삐뚤어진 스캔본을 추가합니다.
  3. 자동 감지를 선택해 각 페이지의 기울기 각도를 찾게 하거나, 수동 모드로 전환합니다.
  4. 수동 모드에서는 미리보기의 글자가 수평이 될 때까지 회전 각도를 조정합니다.
  5. 보정을 적용하고 브라우저가 모든 페이지를 로컬에서 바로 세우도록 둡니다.
  6. 미리보기를 원본과 비교한 뒤 보정된 PDF를 내려받습니다.

When to use this tool

  • 집주인에게 보내기 전에 휴대폰으로 비스듬히 찍은 임대차 계약서 바로 세우기
  • 낱장 스캐너를 살짝 비뚤게 통과한 영수증 묶음을 고쳐 경비 시스템에 깔끔하게 정리하기
  • 상자에서 꺼내 디지털화한 오래된 가족 편지와 증명서를 정리하기. 페이지마다 기울기가 제각각인 경우가 많습니다
  • 글줄이 수평이 아니면 인식률이 크게 떨어지므로 OCR 전에 삐뚤어진 스캔본 준비하기
  • 책등 근처에서 종이가 휘어 기울어진 채로 스캔된 책 챕터 정리하기
  • 담당자가 화면으로 보고 인쇄할 공식 포털에 제출하기 전에 서명된 양식 반듯하게 맞추기

Tips for the best results

  • 기울기 보정은 언제나 OCR 전에 하세요. 2도만 기울어도 문자 인식에 눈에 띄게 나쁜 영향을 주며, 반듯한 입력은 가장 값싼 정확도 향상 수단입니다.
  • 글자가 많은 페이지에서는 자동 감지를 믿어도 됩니다. 글줄을 읽어 각도를 찾기 때문에 평범한 편지, 양식, 보고서는 안정적으로 스스로 보정됩니다.
  • 내용이 성긴 페이지에서는 수동으로 바꾸세요. 도면, 사진, 단어 몇 개뿐인 페이지는 감지기가 참고할 단서가 적어 직접 각도를 지정하는 편이 빠릅니다.
  • 작은 각도도 중요합니다. 1도만 보정해도 인쇄물에서 차이가 보이므로 화면에서 기울기가 사소해 보인다고 건너뛰지 마세요.
  • 기울기 보정은 회전을 바로잡을 뿐 원근은 고치지 못합니다. 비스듬히 찍은 사진에는 회전으로는 해결되지 않는 사다리꼴 왜곡이 있으니, 페이지가 사다리꼴로 보이면 평평하게 다시 스캔하세요.

자주 묻는 질문

기울기 보정은 제 PDF에 실제로 무엇을 하나요?

각 페이지의 내용을 정확한 각도만큼 회전시켜 기울어진 글자를 다시 수평으로 만듭니다. 자동 감지가 기울기를 대신 측정해 주고, 수동 모드에서는 정확한 각도를 직접 입력할 수 있습니다. 결과물은 페이지가 반듯해진 일반 PDF입니다.

자동 감지는 각도를 어떻게 알아내나요?

페이지 이미지를 분석해 글줄과 가장자리의 주된 방향을 찾은 뒤, 그것이 수평에서 얼마나 벗어났는지 계산합니다. 일반적인 문서에서는 소수점 단위 오차 안으로 맞히며, 페이지마다 따로 측정합니다.

수동 모드는 언제 써야 하나요?

페이지에 글자가 아주 적을 때, 내용이 대부분 이미지일 때, 또는 자동 결과가 마음에 들지 않을 때 쓰세요. 회전 각도를 직접 지정하고 미리보기가 만족스러울 때까지 미세 조정할 수 있습니다.

스캔본을 바로 세우면 화질이 나빠지나요?

회전은 페이지를 다시 렌더링하는 과정이라 약간의 재샘플링이 일어나지만, 보통의 스캔본에서는 읽거나 인쇄할 때 알아챌 만한 차이가 아닙니다. 글자가 수평이 되면서 얻는 가독성이 그보다 훨씬 큽니다.

처리하는 동안 제 문서는 비공개로 유지되나요?

네. 각도 감지와 회전 모두 사용자 기기의 브라우저에서 실행되므로 파일이 업로드되지 않습니다. 여러 페이지짜리 큰 스캔본도 마찬가지이며, 그래서 페이지를 한 번 불러온 뒤에는 오프라인에서도 동작합니다.

비용이 드나요? 파일을 여러 개 보정할 수 있나요?

이 도구는 무료이고 계정도, 워터마크도, 제한도 없습니다. 기울어진 스캔본이 폴더째 있어도 할당량에 걸리지 않고 하나씩 이어서 처리할 수 있습니다.

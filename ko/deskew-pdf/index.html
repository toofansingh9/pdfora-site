다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

스캐너에 종이가 살짝 비스듬히 들어가면 모든 글줄이 기울어진 스캔본이 나옵니다. 읽기도 불편하고, 고객이나 법원에 보내면 성의 없어 보이며, OCR 소프트웨어도 인식하기 더 어려워집니다. 기울기 보정은 페이지를 되돌려 글줄이 수평이 되게 합니다. 글이 가득한 페이지에서는 1~2도만 기울어도 오차가 줄마다 쌓이기 때문에 눈에 띕니다. 그러니 스캔본을 화면으로 읽거나, 다시 인쇄하거나, OCR에 넣을 때는 바로잡아 두는 게 좋고, 처리도 빨라서 스캔한 서류 묶음마다 습관처럼 돌려도 됩니다.

PDFora의 기울기 보정 도구에는 두 가지 모드가 있습니다. 자동 감지는 각 페이지를 작은 저해상도 이미지로 렌더링해 어두운 픽셀을 모은 다음, -6도부터 +6도까지 0.5도 간격으로 각도를 시험합니다. 각도마다 어두운 픽셀이 가로줄에 얼마나 모이는지 세어, 줄이 가장 또렷한 각도, 즉 글줄이 가장 잘 정렬되는 각도를 고릅니다. 수동 모드는 감지를 건너뜁니다. 기울기를 도 단위로 입력하면(양수는 페이지가 시계 방향으로 기운 상태) 모든 페이지를 그만큼 되돌립니다.

보정은 각 페이지를 기본 배율의 두 배로 렌더링한 이미지에 적용되며, 회전된 페이지는 원래 크기의 페이지 위에 품질 0.9의 JPEG 이미지로 저장됩니다. 회전 때문에 드러난 모서리는 흰색으로 채워집니다. 결과 파일 yourfile-deskewed.pdf는 페이지 이미지 묶음이라 텍스트 레이어가 없습니다. 스캔본 기울기 보정에서는 흔한 절충입니다. 스캔본은 원래 페이지를 찍은 그림이므로 잃는 것은 주로 그 위에 덧붙였던 OCR 텍스트뿐이고, 보정한 뒤 OCR PDF를 돌리면 새 텍스트 레이어를 다시 넣을 수 있습니다.

비뚤어진 스캔 PDF를 바로잡는 방법

  1. 기울기 보정을 열고 스캔한 PDF 하나를 선택합니다.
  2. 한 장씩 스캔해서 페이지마다 기울기가 다를 수 있는 문서라면 기울기 각도를 자동 감지로 둡니다.
  3. 모든 페이지가 같은 만큼 기울었다면 수동을 고르고 기울기를 입력합니다. 양수는 내용이 시계 방향으로 기울었다는 뜻이며, 도구가 반대 방향으로 되돌립니다.
  4. 기울기 보정 후 다운로드를 누르고, 각 페이지가 렌더링·측정·회전되는 동안 기다립니다.
  5. 결과를 열어 표지나 서명 페이지처럼 글자가 적은 페이지를 몇 장 확인합니다. 자동 감지가 가장 덜 정확한 곳이 이런 페이지입니다.

이 도구가 필요한 경우

  • 사무실 자동 급지 스캐너가 비스듬히 끌어들인 계약서나 거래 명세서를 정돈할 때.
  • 휴대폰으로 스캔한 영수증과 세금계산서를 세무사에게 보내기 전에 바로 세울 때.
  • 수평 글줄에서 더 잘 작동하는 OCR에 넣기 전에 스캔 페이지를 준비할 때.
  • 보관해 온 편지나 기록물을 공유 폴더에 올리기 전에 정리할 때.
  • 스캐너 유리 위에 평평하게 펼쳐지지 않는 책이나 제본 보고서의 페이지를 고칠 때.
  • 소송이나 입찰 제출 서류에 들어가는 스캔 증빙을 보기 좋게 만들 때.

시작하기 전에 알아둘 점

  • 자동 감지는 -6도에서 +6도 사이를 0.5도 간격으로만 찾습니다. 그보다 더 기울었거나 간격 사이의 미세한 각도로 기운 페이지는 일부만 보정됩니다.
  • 감지는 어두운 글줄에 의존합니다. 대부분 사진이거나, 아주 흐리거나, 거의 비어 있는 페이지는 보정되지 않거나 잘못 보정될 수 있습니다. 작은 미리보기에서 어두운 픽셀이 약 100개 미만인 페이지는 0도로 그대로 둡니다.
  • 자동 감지에서는 페이지마다 따로 측정합니다. 수동 모드는 모든 페이지에 같은 각도를 적용합니다.
  • 결과는 이미지로만 구성됩니다. 원본 스캔본에 OCR 텍스트 레이어가 있었더라도 텍스트 선택, 검색, 링크, 책갈피가 사라집니다. 보정한 파일에 OCR PDF를 돌리면 새 텍스트 레이어가 더해져 다시 검색할 수 있습니다.
  • 회전해도 페이지 크기는 그대로이므로 내용의 모서리가 가장자리에서 살짝 잘리고 반대쪽 모서리에는 흰 쐐기 모양이 생깁니다. 다루는 각도가 작아서 보통 몇 밀리미터 정도입니다.
  • 페이지는 약 144dpi로 렌더링되어 JPEG로 저장되므로, 고해상도 원본 스캔본은 디테일이 조금 줄고 파일 크기는 커질 수도 작아질 수도 있습니다.

더 좋은 결과를 위한 팁

  • 먼저 자동 감지를 써 보세요. 몇 페이지가 잘못 나오면 그 기울기를 적어 두었다가 해당 페이지만 수동 모드로 따로 고치면 됩니다.
  • 수동 각도를 어림하려면 글줄 하나가 길이에 비해 얼마나 올라가는지 재 보세요. 19cm 길이에서 1cm 올라가면 약 3도입니다.
  • 기울기 보정은 OCR 전에 하세요. OCR은 반듯한 글줄을 더 정확하게 읽고, OCR 뒤에 보정하면 새로 넣은 텍스트 레이어가 버려집니다.
  • 원본 스캔에 여백이 넉넉했다면 모서리가 잘려도 내용에는 닿지 않습니다. 글자가 가장자리에 붙어 있다면 여백을 조금 더 두고 다시 스캔하세요.
  • 원본 스캔본은 보관하세요. 기울기 보정은 페이지를 다시 렌더링하므로, 결과물에 또 돌리면 그때마다 화질이 떨어집니다.

실제 예시: 프리랜서가 돌려받은 계약서 스캔본

프리랜서 디자이너 최유나 씨가 고객사로부터 서명된 9페이지짜리 계약서를 돌려받았습니다. 자동 급지 스캐너로 스캔한 파일입니다. 대부분의 페이지가 오른쪽으로 조금씩, 그것도 제각각 기울어 있고, 9페이지는 글자가 거의 없는 서명 페이지입니다.

최유나 씨는 파일을 자동 감지로 기울기 보정에 넣습니다. 글이 빽빽한 1~8페이지는 반듯하게 나옵니다. 9페이지는 감지할 글자가 적어서 거의 바뀌지 않았습니다. 그래서 원본의 9페이지만 추출해, 서명란 선에서 잰 2도 기울기로 수동 모드에서 보정한 뒤 다시 병합합니다.

마지막으로 보정한 파일에 OCR PDF를 돌려 검색 가능한 PDF를 받아 두고, 나중에 대금 지급 조건은 그 파일에서 검색합니다. 원본 스캔본은 서명된 기록으로 따로 보관합니다.

세무사에게 보내는 건 보정한 사본입니다. 인쇄해도 반듯하고 화면에서도 읽기 편하기 때문입니다. 서명 페이지를 따로 고친 것까지 포함해도 브라우저에서 몇 분이면 끝났습니다.

문제 해결

페이지가 반대 방향으로 돌아갔습니다
감지기가 잘못된 각도를 골랐습니다. 주로 글자가 적거나 이미지 속에 강한 선이 있는 페이지에서 생깁니다. 그 페이지는 직접 정한 각도로 수동 모드에서 처리하세요.
페이지가 여전히 조금 비뚤어져 있습니다
자동 감지는 0.5도 간격으로, 최대 6도까지만 찾습니다. 정확한 값을 넣어 수동 모드를 쓰거나, 페이지를 더 반듯하게 다시 스캔하세요.
모서리 근처의 글자가 잘렸습니다
회전된 내용도 원래 페이지 크기를 유지하므로 모서리가 잘릴 수 있습니다. 보정 각도를 줄이거나, 글자 주위에 여백을 더 두고 다시 스캔하세요.
문서에서 더 이상 검색이 안 됩니다
결과는 이미지로만 구성됩니다. 텍스트가 필요하다면 보정한 파일에 OCR PDF를 돌려 다시 검색 가능하게 만드세요.
어느 페이지도 바뀌지 않았습니다
페이지가 이미 수평에서 0.5도 이내이거나, 너무 흐려서 감지가 안 되었을 수 있습니다. 수동 모드를 써 보거나 스캔 대비를 확인하세요.
처리가 느립니다
각 페이지를 브라우저에서 두 번 렌더링하고 회전하기 때문입니다. 긴 스캔본은 시간이 걸리니, 아주 큰 파일은 여러 부분으로 나누세요.

자주 묻는 질문

자동 감지는 각도를 어떻게 찾나요?

-6도부터 +6도까지 0.5도 간격으로 각도를 시험하고, 어두운 픽셀이 가장 뚜렷한 가로줄로 모이는 각도를 고릅니다. 그 각도가 글줄이 수평인 상태입니다.

수동 각도에서 양수는 어느 방향인가요?

입력란은 보정 방향이 아니라 기울기를 뜻합니다. 시계 방향으로 기운 페이지라면 양수를 입력하세요. 도구가 그만큼 시계 반대 방향으로 돌리며, 반대 경우도 마찬가지입니다. 결과가 더 나빠지면 부호를 바꾸세요.

기울기를 보정하면 OCR 텍스트 레이어가 사라지나요?

네. 페이지가 이미지로 다시 렌더링됩니다. 보정한 뒤 OCR PDF를 돌리면 다시 검색 가능한 PDF를 얻을 수 있습니다.

스캔본이 아닌 디지털 PDF에도 쓸 수 있나요?

실행은 되지만 디지털 문서에는 바로잡을 기울기가 없고, 실제 텍스트만 잃게 됩니다. 스캔본에 쓰세요.

옆으로 눕거나 위아래가 뒤집힌 페이지도 고칠 수 있나요?

아니요. 작은 기울기만 다룹니다. 90도나 180도 회전은 PDF 회전을 쓰세요.

보정한 파일의 크기가 왜 달라졌나요?

각 페이지가 약 144dpi의 JPEG로 저장되기 때문입니다. 원본 스캔본의 해상도와 압축 방식에 따라 더 작아질 수도, 커질 수도 있습니다.

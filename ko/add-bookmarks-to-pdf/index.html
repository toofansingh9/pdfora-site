다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

90페이지짜리 PDF를 스크롤해 가며 섹션 하나를 찾는 일은 금방 지겨워집니다. 북마크가 그 문제를 해결합니다. 뷰어 사이드바에 나타나는 클릭 가능한 개요로 어떤 장이나 제목으로든 바로 건너뛸 수 있죠. 잘 만든 PDF에는 처음부터 들어 있지만, 내보내거나 스캔한 파일 대부분에는 없습니다. 이 도구를 쓰면 어떤 PDF에든 북마크를 넣어 제대로 이동 가능한 목차를 만들 수 있습니다.

형식은 더없이 단순합니다. 북마크마다 한 줄씩 입력하면 됩니다. 페이지 번호, 쉼표, 제목 순서로요. 첫 줄에 "1, 표지", 다음 줄에 "3, 1장", 아래에 "12, 부록 A" 하는 식입니다. 도구가 이 목록으로 개요를 만들어 PDF 안에 기록합니다. 그러면 독자는 사이드바에서 문서 구조를 보고 클릭 한 번으로 어디든 이동할 수 있습니다.

다른 모든 PDFora 도구와 마찬가지로 파일은 브라우저 안에서 로컬로 처리되고 업로드되지 않으므로 사내 매뉴얼과 고객 보고서가 외부에 노출되지 않습니다. 무료이고, 계정이 필요 없으며, 워터마크도 붙지 않고, 길이에 상관없이 어떤 문서에서도 동작합니다.

온라인에서 PDF에 북마크 추가하는 방법

  1. 도구에서 PDF를 엽니다. 어떤 서버로도 전송되지 않고 브라우저 안에서 불러옵니다.
  2. 문서를 훑어보며 각 섹션이 시작되는 페이지 번호를 적어 둡니다.
  3. 북마크 입력란에 한 줄에 하나씩 "페이지, 제목" 형식으로 입력합니다. 예를 들어 "1, 표지" 다음에 "3, 1장"처럼요.
  4. 개요에 넣고 싶은 모든 섹션에 한 줄씩 추가합니다. 장, 부록, 주요 첨부 자료 등이요.
  5. 적용을 누르면 도구가 클릭 가능한 개요를 PDF 안에 기록합니다.
  6. 파일을 내려받고 뷰어의 북마크 패널을 열어 각 이동이 제대로 되는지 확인합니다.

When to use this tool

  • 1인 출판 전자책에 장별 개요를 넣어 독자가 제대로 만든 책처럼 이동할 수 있게 하기
  • 120페이지 임직원 안내서에 정책, 휴가, 복리후생, 행동강령 같은 사이드바 목차를 달아 직원들이 어디에 뭐가 있는지 묻지 않게 하기
  • 병합된 법원 제출 서류의 첨부 자료마다 북마크를 달아 법원 직원이 첨부 C로 바로 갈 수 있게 하기
  • 강의 노트를 주차별로 구조화해 학생들이 빠진 주제로 바로 건너뛰게 하기
  • 스캔 과정에서 원래 목차 기능을 잃은 장비 매뉴얼에 섹션 북마크 추가하기
  • 긴 재무 보고서를 이사회에 돌리기 전에 분기와 재무제표 종류별로 개요 잡기

Tips for the best results

  • 페이지에 인쇄된 번호가 아니라 PDF 파일 자체의 페이지 번호를 쓰세요. 머리말이 있으면 둘이 어긋나는 경우가 많습니다.
  • 제목은 짧고 눈에 잘 들어오게 쓰세요. 좁은 사이드바에서는 긴 문장보다 "4장: 가격 정책"이 낫습니다.
  • 항목을 페이지 순서대로 나열해 개요가 실제 목차처럼 위에서 아래로 읽히게 하세요.
  • 표지와 목차 페이지에도 북마크를 다세요. 독자는 처음으로 돌아갈 길을 기대합니다.
  • 아주 긴 문서라면 장뿐 아니라 주요 제목마다 북마크를 다세요. 200페이지 파일에는 5개가 아니라 20개쯤이 어울립니다.

자주 묻는 질문

PDF 북마크란 정확히 무엇인가요?

북마크(개요라고도 합니다)는 대부분의 PDF 뷰어 사이드바에 나타나는 클릭 가능한 이동 패널입니다. 각 항목은 페이지에 연결된 제목이라 "3장"을 누르면 바로 그곳으로 이동합니다. 파일 안에 함께 담겨 이동하므로 전달받은 사람 모두 같은 이동 기능을 사용할 수 있습니다.

북마크 목록은 어떤 형식으로 쓰나요?

한 줄에 북마크 하나씩, 페이지 번호와 쉼표, 제목 순으로 씁니다. 예를 들어 첫 줄에 "1, 표지", 둘째 줄에 "3, 1장", 셋째 줄에 "15, 2장"처럼요. 문법은 그게 전부입니다.

목차 페이지와 같은 건가요?

목적은 같지만 인쇄된 페이지가 아니라 뷰어 사이드바에 있고, 모든 항목을 클릭할 수 있습니다. 많은 사람이 북마크를 추가하는 이유가 바로 PDF에 클릭되지 않는 인쇄 목차만 있기 때문입니다.

북마크를 넣으면 PDF 페이지가 바뀌나요?

아니요. 페이지, 텍스트, 레이아웃은 그대로입니다. 북마크는 파일 안의 별도 이동 구조에 저장되므로 문서는 이전과 똑같이 인쇄되고 표시되며, 이동만 훨씬 편해집니다.

모든 PDF 뷰어에서 북마크가 동작하나요?

네. 이 도구는 표준 PDF 개요를 기록하며 Adobe Acrobat, 브라우저 뷰어, Mac의 미리보기, 모바일 PDF 앱이 모두 이를 이해합니다. 패널 이름은 뷰어에 따라 북마크, 개요, 목차 등으로 다르게 표시될 수 있습니다.

제 문서는 비공개로 유지되나요?

네. PDF는 전적으로 브라우저 안에서 처리되고 업로드되지 않으므로 기밀 보고서와 매뉴얼이 사용자 기기에 머뭅니다. 또한 무료이며 가입도 워터마크도 없습니다.

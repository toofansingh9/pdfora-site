책갈피 만들기

페이지 번호와 제목을 간단한 목록으로 입력해, PDF에 클릭으로 이동할 수 있는 책갈피 목차를 추가합니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

책갈피가 없는 60페이지짜리 보고서는 읽는 사람마다 스크롤하며 위치를 짐작하게 만듭니다. 책갈피가 있으면 어떤 PDF 뷰어든 사이드바에 목차가 나타나고 클릭 한 번으로 원하는 페이지로 이동합니다. 그런데 책갈피를 만들어 주지 않는 앱에서 내보냈거나, 여러 파일을 병합했거나, 종이를 스캔한 PDF라면 책갈피가 중간에 사라지기 쉽습니다. 책갈피 만들기는 원본 작업 파일이 없어도 목차를 다시 넣어 줍니다.

무언가를 끌어다 놓을 필요는 없습니다. '1, 표지'나 '12, 3장: 예산'처럼 '페이지, 제목' 형식으로 책갈피 하나당 한 줄씩 입력하면 됩니다. 줄바꿈 대신 세미콜론으로 구분해도 됩니다. 첫 번째 쉼표 뒤의 내용은 모두 제목으로 처리되므로 제목 안에 쉼표가 있어도 괜찮습니다. 뷰어에는 입력한 순서 그대로 책갈피가 표시됩니다. 목록이 일반 텍스트라서 메모장에 보관해 두었다가, 같은 문서의 새 판이 나올 때마다 위치가 바뀐 페이지 번호만 고쳐 다시 쓸 수 있습니다.

도구는 pdf-lib로 PDF를 읽고, 각 항목이 지정한 페이지를 가리키도록 문서 카탈로그에 새 목차(outline)를 만든 뒤 yourfile-bookmarks.pdf로 저장합니다. 페이지 자체는 그대로 복사되며 텍스트, 이미지, 링크, 양식 필드는 건드리지 않습니다.

PDF에 책갈피를 추가하는 방법

  1. 먼저 아무 뷰어에서나 PDF를 열고 각 섹션이 시작하는 페이지 번호를 적어 둡니다. 페이지에 인쇄된 번호가 아니라 뷰어의 페이지 표시(파일의 첫 페이지가 1)를 기준으로 하세요.
  2. 책갈피 만들기를 열고 PDF를 끌어다 놓습니다.
  3. 입력란에 '1, 표지', '3, 들어가며', '9, 조사 결과'처럼 한 줄에 하나씩 입력합니다. 항목 사이를 세미콜론으로 구분해도 됩니다.
  4. 책갈피 추가를 누릅니다. 버튼 아래 메시지에 추가된 책갈피 개수가 표시됩니다.
  5. 다운로드한 -bookmarks.pdf를 열고 책갈피(또는 개요) 사이드바를 켠 뒤, 항목을 하나씩 클릭해 올바른 페이지로 가는지 확인합니다.

이 도구가 필요한 경우

  • 따로 작성한 부분들을 병합해 만든 연차 보고서나 지원사업 신청서.
  • 교사가 여러 단원과 유인물을 PDF 하나로 묶은 수업 자료집.
  • 회의나 심리 중에 증거 자료를 빨리 찾아야 하는 법률 서류 묶음.
  • 디지털 구조가 전혀 없는 스캔 매뉴얼이나 오래된 책.
  • 안건 뒤에 첨부 자료가 열 건 넘게 붙는 이사회 회의 자료.
  • 목차를 만들어 주지 않는 프로그램에서 내보낸 학위 논문.

시작하기 전에 알아둘 점

  • 목차는 한 단계뿐입니다. 모든 책갈피가 같은 수준에 놓이며, 장 아래에 하위 절이 들어가는 계층 구조는 만들 수 없습니다.
  • 파일에 이미 있던 목차는 이어 붙는 게 아니라 교체됩니다. 기존 책갈피를 남기고 싶다면 입력 목록에 함께 넣으세요.
  • 페이지 번호는 1부터 시작하는 파일 안의 위치를 뜻합니다. 인쇄된 쪽 번호, 로마 숫자로 매긴 앞부분, 페이지 레이블은 무시됩니다.
  • 전체 페이지 수보다 큰 번호는 조용히 마지막 페이지로 바뀌고, 0은 1페이지가 됩니다. 그래서 오타가 있어도 오류가 나지 않고 엉뚱한 곳을 가리킬 뿐입니다. 완료 메시지는 만들어진 책갈피 개수를 세는 것이지, 각각이 의도한 위치에 갔는지까지 확인하지는 않습니다.
  • 쉼표가 없거나, 쉼표 앞에 숫자가 없거나, 쉼표 뒤에 제목이 없는 줄은 경고 없이 건너뜁니다. 완료 메시지의 개수와 입력한 줄 수를 비교해 보세요.
  • 책갈피를 누르면 배율을 강제로 바꾸지 않고 해당 페이지를 열기 때문에, 사용자가 쓰던 배율이 그대로 유지됩니다. 페이지 중간의 특정 문단을 가리키는 책갈피는 만들 수 없습니다.

더 좋은 결과를 위한 팁

  • 목록은 먼저 텍스트 편집기에 작성해 확인한 다음 붙여 넣으세요. 작은 입력란에서 고치는 것보다 쉽고, 다음에 쓸 사본도 남습니다.
  • 책갈피는 마지막에 넣으세요. 그 뒤에 병합, 분할, 페이지 삭제를 하면 목차가 사라지거나 페이지가 어긋납니다.
  • 제목은 짧게 쓰세요. 뷰어 사이드바는 좁아서 긴 제목은 잘립니다. 앞에 '3. 연구 방법'처럼 번호를 붙이면 훑어보기 편합니다.
  • PDF에 인쇄된 목차가 있다면 그대로 목록으로 써도 되지만, 인쇄된 쪽 번호와 실제 페이지 위치의 차이를 모든 항목에 더해야 합니다. 예를 들어 인쇄된 1쪽이 파일의 다섯 번째 페이지라면 목차의 모든 번호에 4를 더하세요.
  • 대부분의 뷰어는 사이드바를 열어야 책갈피가 보입니다. 이 기능을 잘 모르는 사람을 위해 이메일에 '책갈피를 참고하세요'라고 한 줄 적어 주세요.

예시: 프리랜서 컨설턴트의 고객 보고서

서울에서 일하는 프리랜서 컨설턴트 박지훈 씨가 파일 다섯 개를 병합해 42페이지짜리 시장 보고서를 만들었습니다. 표지와 요약, 본문 분석, 부록 세 개, 스캔한 설문지 묶음입니다. 병합 과정에서 구조가 전부 사라졌고, 고객사는 화면에서 보기 편하게 해 달라고 요청했습니다.

박지훈 씨는 뷰어에서 각 부분이 파일의 몇 페이지에서 시작하는지 적습니다. 표지 1, 요약 2, 분석 5, 부록 A 28, 부록 B 31, 부록 C 35, 설문지 스캔 38입니다. 분석 부분은 파일의 5페이지에서 자체 쪽 번호 1로 시작하기 때문에, 인쇄된 목차를 그대로 옮겨 쓸 수는 없습니다. 도구에 입력한 목록은 다음과 같습니다. 1, 표지; 2, 요약; 5, 분석; 28, 부록 A – 데이터 표; 31, 부록 B – 조사 방법; 35, 부록 C – 출처; 38, 설문지.

도구에 '책갈피 7개를 추가했습니다.'라는 메시지가 뜹니다. market-report-bookmarks.pdf를 열어 항목을 하나씩 눌러 보니 모두 맞아서 그대로 보냅니다. 걸린 시간은 5분 남짓입니다. 다음 분기에 분석 부분이 두 페이지 늘어난 개정판이 나오자, 같은 목록에서 마지막 네 항목의 번호만 2씩 올려 다시 사용합니다.

문제 해결

"2, 1장"과 같은 줄을 하나 이상 입력하라는 메시지가 나옵니다
읽을 수 있는 줄이 하나도 없습니다. 각 줄은 페이지 번호, 쉼표, 제목 순이어야 합니다. 쉼표 대신 마침표나 대시를 쓰지 않았는지 확인하세요.
입력한 것보다 책갈피가 적게 추가되었습니다
쉼표, 숫자, 제목 중 하나가 빠진 줄은 건너뛰었습니다. 해당 줄을 고친 뒤 원본 파일로 다시 실행하세요.
책갈피가 엉뚱한 페이지로 이동합니다
인쇄된 쪽 번호를 썼을 가능성이 큽니다. 뷰어의 페이지 표시에 나오는 위치를 사용해 원본 파일로 다시 실행하세요.
기존 책갈피가 사라졌습니다
이 도구는 새 목차를 써서 기존 목차를 교체합니다. 원본 파일을 뷰어에서 열어 어떤 책갈피가 있었는지 확인하고, 남길 항목까지 포함해 전체 목록을 다시 만드세요.
다운로드한 파일에서 책갈피가 보이지 않습니다
뷰어에서 책갈피 또는 개요 패널을 여세요. 기본적으로 숨겨 두는 뷰어가 많습니다. 일부 간단한 브라우저 뷰어는 책갈피를 아예 표시하지 않습니다.
한글 제목이 깨져 보입니다
제목은 유니코드 텍스트로 저장되며 최신 뷰어에서는 정상적으로 표시됩니다. 특정 앱에서 글자가 깨진다면 다른 PDF 뷰어로 열어 보세요.

자주 묻는 질문

하위 단계가 있는 계층형 책갈피를 만들 수 있나요?

아니요. 모든 책갈피는 한 단계로 만들어집니다. 계층 구조가 필요하다면 본격적인 PDF 편집기를 써야 합니다.

기존 책갈피는 유지되나요?

아니요. 새로 입력한 목록으로 교체됩니다. 남기고 싶은 책갈피는 입력 목록에 포함하세요.

책갈피 제목에 쉼표를 넣어도 되나요?

네. 페이지 번호와 제목을 나누는 건 첫 번째 쉼표뿐이고, 그 뒤의 내용은 모두 제목이 됩니다.

책갈피를 추가하면 페이지가 바뀌나요?

아니요. 페이지, 텍스트, 이미지, 링크는 그대로 저장되고 문서 목차만 추가됩니다. 다만 pdf-lib로 다시 저장하기 때문에 내용은 같아도 파일 크기가 원본과 조금 다를 수 있습니다.

40페이지짜리 파일에 100페이지를 입력하면 어떻게 되나요?

그 책갈피는 대신 마지막 페이지를 가리킵니다. 오류가 표시되지 않으니 번호를 꼭 다시 확인하세요.

나중에 이 파일을 병합해도 책갈피가 남나요?

아니요. 병합은 페이지만 복사하고 목차는 복사하지 않습니다. 책갈피는 병합을 마친 뒤 마지막 단계에서 넣으세요.

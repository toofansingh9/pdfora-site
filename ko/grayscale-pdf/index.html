그레이스케일 PDF

모든 페이지를 회색 톤으로 다시 그려 컬러 PDF를 흑백 PDF로 바꿉니다. 저렴한 흑백 인쇄나 까다로운 업로드 규정에 맞출 때 씁니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

흑백만 받는 접수 사이트나 인쇄소가 있습니다. 전자 소송 시스템이 컬러 스캔본을 거부하기도 하고, 학교가 토너를 아끼려고 흑백 유인물을 요청하기도 하며, 컬러 페이지 단위로 요금을 매기는 인쇄소는 바닥글의 파란 로고 하나 때문에 컬러 요금을 청구합니다. PDFora의 그레이스케일 PDF 도구는 PDF에서 색을 모두 없애, 진짜 흑백 문서로 인쇄하고 업로드할 수 있게 합니다. 이 방법에는 믿고 쓰기 전에 알아야 할 결과가 따르기 때문에, 어떻게 동작하는지 이 페이지에서 설명합니다.

도구는 PDF 안의 색상 값을 고치지 않습니다. 각 페이지를 PDF 기본 해상도의 두 배(인치당 약 144픽셀)로 이미지 렌더링하고, 모든 픽셀을 빨강 29.9%, 초록 58.7%, 파랑 11.4%라는 표준 휘도 가중치로 회색으로 바꾼 다음, 그 회색 이미지를 원래와 똑같은 크기의 새 페이지에 품질 85%의 JPEG로 넣습니다. 이 가중치가 중요합니다. 순수한 빨간 제목은 꽤 짙은 회색이 되지만, 밝은 노란색 형광펜 표시는 연한 회색이 되어 종이에서 거의 사라질 수 있습니다.

모든 페이지가 그림이 되므로 결과는 보기에는 원본에 충실하지만 구조는 더 단순합니다. 텍스트를 더 이상 선택하거나 검색할 수 없고, 링크는 클릭되지 않으며, 양식 필드와 책갈피도 사라집니다. 인쇄할 때는 거의 상관없지만 나중에 누군가 검색해야 할 문서라면 문제가 되며, 아래 팁에서 해결 방법을 설명합니다.

PDF를 흑백으로 변환하는 방법

  1. 그레이스케일 PDF 도구를 열고, 상자에 끌어다 놓거나 클릭해서 PDF 하나를 추가합니다.
  2. 흑백으로 변환을 누릅니다. 페이지마다 차례로 렌더링, 변환, 재삽입이 이뤄지며 진행 표시줄이 페이지 단위로 움직입니다.
  3. 다운로드가 나타날 때까지 기다립니다. 10페이지 문서는 몇 초면 끝나지만, 200페이지 스캔본은 휴대폰에서 꽤 오래 걸립니다.
  4. 원래 이름에 -gray가 붙은 파일(예: report-gray.pdf)을 다운로드합니다.
  5. 인쇄하거나 업로드하기 전에 100% 배율로 열어 작은 글씨, 컬러 차트, 형광펜 표시 부분을 확인합니다.

이 도구가 필요한 경우

  • 흑백 PDF 첨부만 받는 법원·관공서 제출 서류.
  • 흑백 복사기로 대량 인쇄하는 학교 학습지와 시험지. 컬러 페이지가 있으면 대기열이 느려지거나 추가 비용이 듭니다.
  • 빨강과 초록 구분에 의존하는 차트처럼, 색이 없어도 디자인이 읽히는지 보려고 교정용 사본을 만들 때.
  • 색이 아무 의미 없고 통일된 모양이 나은 영수증과 거래 명세서를 보관할 때.
  • 컬러 페이지 단위로 요금을 받는 인쇄소에 보낼 때. 엉뚱한 컬러 로고 하나 때문에 60페이지 작업 전체가 컬러 요금이 되는 걸 막습니다.
  • 컬러 토너 없는 가정용 레이저 프린터로 인쇄하는 사람을 위해 슬라이드를 읽기 좋게 만들 때.

시작하기 전에 알아둘 점

  • 모든 페이지가 래스터화됩니다. 결과에는 페이지당 JPEG 이미지 한 장만 있고 살아 있는 텍스트가 없어, OCR을 실행하기 전까지는 복사·붙여넣기, 검색, 화면 낭독기가 아무것도 찾지 못합니다.
  • 해상도는 인치당 약 144픽셀로 고정입니다. 읽거나 보통 인쇄하기에는 충분하지만, 아주 작은 글씨(6포인트 이하)와 가는 선 그림은 원본보다 부드러워 보일 수 있습니다.
  • 파일 크기는 커질 수도 작아질 수도 있습니다. 텍스트만 있는 200KB짜리 디지털 PDF는 텍스트가 그림이 되면서 몇 배로 커지는 경우가 많고, 컬러 스캔본은 회색 JPEG에 담기는 데이터가 적어 보통 작아집니다.
  • 링크, 책갈피, 양식 필드, 댓글, 첨부 파일은 새 파일로 옮겨지지 않습니다. 페이지의 겉모습은 유지되지만 그 뒤의 구조는 남지 않습니다.
  • 밝기가 비슷한 색은 같은 회색이 됩니다. 차트에서 휘도가 비슷한 빨간 선과 초록 선은 구별할 수 없게 되니, 중요하다면 원본에서 라벨이나 무늬를 추가하세요.
  • 한 번에 파일 하나만 처리합니다. 여러 문서를 변환하려면 차례로 하나씩 돌리거나, 먼저 병합한 뒤 병합본을 변환하세요.

더 좋은 결과를 위한 팁

  • 컬러 원본은 보관하세요. 흑백 사본은 다시 컬러로 되돌릴 수 없고 텍스트 레이어도 잃었습니다.
  • 흑백본의 텍스트가 필요하다면 결과에 OCR PDF를 돌려 .txt 파일로 받거나, 파일을 나눈 뒤 정말 필요한 페이지만 변환하세요.
  • 노란색과 연두색 형광펜 표시를 확인하세요. 아주 연한 회색이 됩니다. 그 표시가 페이지의 핵심이라면 변환 전에 원본에서 색을 진하게 바꾸세요.
  • 텍스트만 있는 문서를 흑백 프린터로 보낼 거라면 이 도구가 아예 필요 없을 수도 있습니다. 대부분의 인쇄 대화상자에는 PDF를 그대로 둔 채 흑백으로 인쇄하는 옵션이 있습니다.
  • 흑백 파일이 업로드 용량 제한보다 크다면 이어서 PDF 압축을 돌리세요. 이미 이미지 기반 파일이라 압축이 잘 됩니다.

실제 예시: 집주인의 입주 상태 점검 보고서

집주인 임동현 씨가 방마다 컬러 사진을 넣고, 상태를 빨강·노랑·초록으로 표시한 표가 들어간 14페이지짜리 입주 상태 점검 보고서를 만들었습니다. 계약을 맡은 중개사무소는 보고서를 흑백 PDF로 보내 달라고 했고, 임동현 씨도 검은색 토너만 있는 사무실 레이저 프린터로 두 부를 인쇄할 예정입니다.

흑백으로 변환하자 방 사진은 디테일이 살아 있어 평범한 흑백 사진처럼 보입니다. 약점은 상태 표입니다. 밝기가 비슷한 초록 칸과 빨강 칸이 거의 같은 중간 회색으로 나와, 색깔 표시가 더는 의미를 전달하지 못합니다. 해결은 변환기가 아니라 원본 문서에서 합니다. 각 칸에 '양호', '보통', '불량'이라는 글자를 넣고 다시 내보낸 뒤 변환하는 것입니다. 글자는 살아남고, 색은 없어도 됩니다.

임동현 씨는 컬러 PDF도 보관합니다. 나중에 분쟁이 생겨 곰팡이 자국 사진을 컬러로 보여 줘야 할 때 원본이 남아 있고, 방 이름으로 텍스트를 검색할 수도 있습니다.

문제 해결

텍스트를 더 이상 선택하거나 검색할 수 없습니다
도구의 동작 방식에서 바로 나오는 결과입니다. 이제 각 페이지가 회색 이미지 한 장입니다. 흑백 파일에 OCR을 적용해 텍스트를 얻거나, 검색용으로는 컬러 원본을 쓰세요.
확대하면 작은 글씨가 흐립니다
페이지가 인치당 약 144픽셀로 렌더링되어, 높은 배율에서는 벡터 텍스트보다 부드럽게 보입니다. 보통 크기로 인쇄하면 괜찮습니다. 작은 각주가 있는 문서라면 인쇄 대화상자의 흑백 옵션을 쓰면 글자가 선명하게 유지됩니다.
흑백 파일이 원본보다 훨씬 큽니다
원본이 텍스트를 문자로 저장하는, 아주 작은 디지털 PDF였을 가능성이 큽니다. 같은 페이지도 이미지가 되면 용량을 더 차지합니다. 결과를 압축하거나, 변환하지 말고 프린터의 흑백 설정을 쓰세요.
형광펜 표시가 사라졌습니다
노란색처럼 밝은 색은 아주 연한 회색으로 바뀝니다. 원본에서 형광펜 색을 진하게 하거나 밑줄을 그은 뒤 다시 변환하세요.
도구가 실패하거나 탭이 응답하지 않습니다
아주 길거나 큰 문서는 브라우저 메모리에서 한 페이지씩 렌더링됩니다. 다른 탭을 닫거나, 데스크톱 컴퓨터를 쓰거나, 파일을 나눠 따로 변환하세요.
도구에서 파일이 열리지 않습니다
손상되었거나 비밀번호로 보호되어 있을 수 있습니다. 먼저 PDF 복구를 시도하고, 보호된 파일이라면 파일을 만든 프로그램에서 비밀번호를 해제하세요.

자주 묻는 질문

PDF 안의 색을 바꾸나요, 페이지를 다시 그리나요?

다시 그립니다. 각 페이지를 이미지로 렌더링하고, 모든 픽셀을 휘도 가중치로 회색으로 바꾼 다음, 그 회색 이미지를 같은 크기의 새 페이지에 넣습니다.

페이지 크기와 레이아웃은 그대로인가요?

네. 새 페이지마다 원래 페이지의 너비와 높이를 쓰고 이미지가 정확히 채우므로, 여백과 위치가 움직이지 않습니다.

결과는 진짜 그레이스케일인가요, 채도만 뺀 컬러인가요?

모든 픽셀의 빨강, 초록, 파랑 값이 같아서 어디서나 회색으로 보입니다. 다만 삽입된 JPEG는 RGB로 저장되므로, DeviceGray 색 공간을 요구하는 엄격한 인쇄 전 검사에서는 걸릴 수 있습니다.

일부 페이지만 변환할 수 있나요?

직접은 안 됩니다. PDF 분할로 원하는 페이지를 떼어 내 변환한 뒤, 손대지 않은 페이지와 다시 병합하세요.

하이퍼링크와 책갈피가 유지되나요?

아니요. 결과는 페이지 이미지로 만들어지기 때문에 링크, 책갈피, 양식 필드는 들어가지 않습니다.

변환하는 동안 파일이 업로드되나요?

아니요. 렌더링과 회색 변환은 브라우저 안에서 PDF.js와 pdf-lib로 이뤄지므로, 문서는 컴퓨터나 휴대폰에 그대로 남습니다.

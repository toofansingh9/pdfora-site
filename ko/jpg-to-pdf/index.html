JPG / PNG를 PDF로

JPG와 PNG 이미지를 한 장당 한 페이지씩 PDF 하나로 묶습니다. 이미지 원래 크기 그대로, 또는 A4나 US Letter 페이지 가운데에 배치할 수 있습니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

휴대폰으로 찍은 영수증, 오류 화면 캡처, JPG로 저장한 신분증 스캔 같은 것들을 언젠가는 누군가 'PDF 하나로' 달라고 합니다. 까다로운 건 변환 자체가 아니라, 사진이 옆으로 누워 나오거나, 페이지 크기가 제각각이거나, 파일이 메일로 보내기엔 너무 무겁다는 점이죠. 이 페이지에서는 JPG / PNG를 PDF로 도구가 각 사진을 정확히 어떻게 처리하는지 설명하니, 버튼을 누르기 전에 결과를 예상할 수 있습니다.

이미지 한 장이 한 페이지가 되며, 순서는 파일 목록에 보이는 순서를 따릅니다. 사진은 있는 그대로 들어갑니다. JPG는 같은 JPEG 데이터로, PNG는 PNG로 들어가며 크기 조정이나 재압축을 하지 않습니다. 그래서 화질은 원본과 똑같지만, PDF 용량도 이미지들을 합친 만큼 나옵니다. 3 MB짜리 휴대폰 사진 열 장이면 PDF는 약 30 MB가 됩니다.

설정은 '페이지' 하나뿐이고 선택지는 세 가지입니다. 기본값인 이미지 크기에 맞춤은 각 페이지를 그림과 정확히 같은 크기로 만듭니다. A4 페이지와 US Letter는 각 이미지를 표준 용지에 올리되, 20포인트(약 7 mm) 테두리 안에 들어가도록 비율을 유지한 채 줄여서 가운데에 놓습니다. 결과는 images.pdf로 다운로드되며, 작업은 브라우저 탭 안에서 pdf-lib 라이브러리가 처리하므로 사진이 먼저 서버로 전송되지 않습니다.

이미지를 PDF로 만드는 방법

  1. JPG / PNG를 PDF로 도구를 열고 JPG나 PNG 파일을 추가합니다. 파일 선택 창에서 여러 개를 한 번에 고르거나 상자에 끌어다 놓으면 됩니다.
  2. 행을 드래그해 읽는 순서대로 맞춥니다. 첫 번째 행이 1페이지가 됩니다.
  3. 페이지 설정을 고릅니다. 화면으로 볼 거라면 이미지 크기에 맞춤을 그대로 두고, 인쇄하거나 표준 페이지를 요구하는 양식에 올릴 거라면 A4나 US Letter를 고르세요.
  4. PDF 만들기를 누르고 진행 표시줄을 기다립니다. 큰 사진은 한 장마다 잠깐씩 걸립니다.
  5. images.pdf를 다운로드해 알아보기 쉬운 이름으로 바꾸고, 거꾸로 되었거나 빠진 페이지가 없는지 훑어봅니다.

이 도구가 필요한 경우

  • 경비 정산: 출장 동안 모은 종이 영수증 사진을 문서 하나로 재무팀에 제출할 때.
  • 과제 제출: 손으로 쓴 과제를 찍은 사진을 PDF만 받는 학교 시스템에 파일 하나로 올릴 때.
  • 전월세 서류: 서명한 계약서 페이지, 계량기 수치, 방마다 상태를 찍은 사진을 함께 보관할 때.
  • 버그 신고·고객 문의: 화면 캡처 여러 장을 순서대로 묶어, 받는 사람이 첨부 파일 열 개를 열지 않고도 단계를 따라갈 수 있게 할 때.
  • 신분증: 신분증이나 운전면허증 앞뒷면을 따로 찍어 A4 페이지에 올려 신청서에 붙일 때.
  • 포트폴리오: 디자이너가 PNG로 내보낸 작업물을 고객이 어떤 기기에서든 넘겨 볼 수 있는 PDF 하나로 모을 때.

시작하기 전에 알아둘 점

  • JPG와 PNG만 처리합니다. 이 도구는 PNG가 아닌 파일을 모두 JPEG로 넣으려 하므로 WebP, HEIC, GIF, BMP, TIFF 파일은 실패합니다. 먼저 JPG나 PNG로 바꾸세요. 아이폰이라면 카메라 형식을 '높은 호환성'으로 설정하면 JPG로 저장됩니다.
  • 이미지 크기에 맞춤에서는 이미지 1픽셀이 PDF 1포인트(1/72인치)가 됩니다. 그래서 4000 x 3000 휴대폰 사진은 약 141 x 106 cm 페이지가 됩니다. 뷰어가 화면에 맞게 확대·축소하니 화면에서는 멀쩡해 보이지만, 인쇄하거나 작은 캡처 화면과 섞으면 페이지 크기가 들쭉날쭉해집니다. 그게 문제라면 A4나 Letter를 쓰세요.
  • A4와 Letter에서는 이미지가 맞춤 축소만 될 뿐, 잘리거나 회전되지 않습니다. 가로 사진을 세로 A4 페이지에 놓으면 위아래로 여백이 있는 가로 띠 모양으로 들어갑니다.
  • 휴대폰이 사진의 EXIF 데이터에 기록하는 회전 정보는 적용되지 않습니다. 갤러리 앱에서 그 정보 덕분에 똑바로 보이는 사진이라면 PDF에서는 옆으로 누울 수 있습니다. 편집기에서 회전해 저장하거나, 나중에 PDF 회전 도구로 해당 페이지를 바로잡으세요.
  • PNG 투명도는 투명한 그대로 유지되며, 대부분의 뷰어는 흰색으로 보여 줍니다. PNG는 무손실이라 큰 스크린샷은 한 장에 몇 MB씩 될 수 있습니다.
  • 페이지가 그림이므로 텍스트를 선택하거나 검색할 수 없습니다. 텍스트를 복사해야 한다면 완성된 PDF를 OCR에 돌리세요.

더 좋은 결과를 위한 팁

  • 추가하기 전에 사진을 잘라 내세요. 식탁 위에서 찍은 영수증 사진은 식탁 전체가 PDF와 파일 용량에 그대로 들어갑니다.
  • 인쇄하거나 공식 서류로 올릴 거라면 A4(북미는 US Letter)를 고르세요. 모든 페이지 크기가 같아지고 프린터가 배율을 추측할 필요가 없습니다.
  • PDF가 너무 크면 변환 전에 사진의 긴 쪽을 2000픽셀 정도로 줄이거나, 완성된 파일을 PDF 압축 도구로 처리하세요.
  • 추가하기 전에 이미지 이름을 01, 02, 03으로 붙여 두면 목록이 처음부터 거의 올바른 순서로 들어와 확인하기 쉽습니다.
  • 문서는 밝은 곳에서, 평평하게 놓고, 바로 위에서 찍으세요. 글자가 잘 읽히는 데는 도구의 어떤 설정보다 깨끗한 사진이 훨씬 중요합니다.

실제 예시: NGO 현장 담당자의 경비 정산

작은 NGO의 현장 담당자 이수민 씨가 나흘간의 지방 마을 방문을 마치고 종이 영수증 14장을 들고 돌아옵니다. 버스표, 숙소 영수증, 식비, 출력비입니다. 재무팀은 정산 양식에 첨부할 A4 인쇄 가능한 PDF 하나를 원하고, 공용 메일함은 10 MB가 넘는 첨부 파일을 거부합니다. 영수증은 휴대폰으로 찍어서 JPG 한 장이 4000 x 3000 픽셀에 약 2.5 MB이고, 원본 합계는 약 35 MB입니다.

먼저 휴대폰 갤러리 편집기에서 사진마다 영수증 테두리에 맞게 잘라 사본으로 저장합니다. 그러면 탁자 배경이 사라지고 대부분 1 MB 아래로 줄어듭니다. 시험 삼아 변환했을 때 옆으로 누워 나온 사진 두 장은 편집기에서 회전해 다시 저장해, 회전이 EXIF 정보가 아니라 픽셀 자체에 반영되게 합니다. 파일에 날짜순으로 번호를 붙이고 14장을 모두 도구에 추가한 뒤 A4 페이지를 고릅니다.

결과는 약 9 MB의 14페이지 PDF입니다. 모든 페이지 크기가 같고 영수증마다 좁은 흰 테두리와 함께 가운데에 놓여 사무실 프린터에서도 깔끔하게 인쇄됩니다. 한도에 여유를 두려고 PDF 압축 도구의 권장 수준으로 한 번 더 줄였는데, 흐려진 감열지 버스표의 금액까지 여전히 읽힙니다.

문제 해결

PDF 만들기를 누르자마자 오류가 나요
파일 중 하나가 실제 JPG나 PNG가 아닐 가능성이 큽니다. 아이폰의 HEIC 사진, 웹사이트에서 저장한 WebP, GIF는 지원하지 않습니다. 이미지 편집기에서 열어 JPG나 PNG로 내보낸 뒤 새 사본을 추가하세요.
PDF에서 사진이 옆으로 눕거나 뒤집혀 있어요
휴대폰이 픽셀을 회전하지 않고 방향을 EXIF 정보로만 저장했는데, 이 도구는 그 정보를 읽지 않습니다. 편집기에서 사진을 회전해 저장하거나, 나중에 PDF 회전 도구로 그 페이지만 돌리세요.
페이지 크기가 전부 달라요
이미지 크기에 맞춤이 원래 그렇게 동작합니다. 각 페이지가 이미지에 맞춰집니다. 모든 이미지를 같은 크기 용지에 놓으려면 A4 페이지나 US Letter를 고르세요.
PDF가 생각보다 훨씬 커요
이미지를 재압축하지 않고 넣기 때문에 PDF 용량은 사진을 합친 것과 비슷합니다. 이미지를 먼저 자르고 줄이거나, 완성된 PDF를 압축하세요.
페이지 순서가 틀렸어요
PDF 만들기를 누른 순간의 목록 순서가 페이지 순서입니다. 행을 제자리로 끌어 놓고 PDF를 다시 만드세요.
PDF에서 텍스트를 검색하거나 복사할 수 없어요
각 페이지는 텍스트가 아니라 텍스트를 찍은 그림입니다. OCR 도구로 PDF를 처리해 글자를 추출하세요.

자주 묻는 질문

어떤 이미지 형식을 변환할 수 있나요?

JPG(JPEG)와 PNG입니다. HEIC, WebP, GIF, TIFF 같은 다른 형식은 먼저 JPG나 PNG로 바꿔야 합니다.

도구가 이미지 화질을 떨어뜨리나요?

아니요. JPEG와 PNG 데이터를 크기 조정이나 재압축 없이 그대로 넣으므로 각 페이지에 원래 해상도의 이미지가 표시됩니다.

PDF 페이지 크기는 어떻게 되나요?

기본 설정에서는 각 페이지가 이미지의 픽셀 크기를 포인트로 잰 크기가 됩니다. 작은 흰 테두리가 있는 표준 페이지를 원하면 A4(595 x 842포인트)나 US Letter(612 x 792포인트)를 고르세요.

세로 사진과 가로 사진을 섞어도 되나요?

네. 이미지 크기에 맞춤에서는 각 페이지가 이미지 방향을 따릅니다. A4나 Letter에서는 모든 페이지가 세로이고, 가로 이미지는 너비에 맞게 축소됩니다.

나중에 PDF에 이미지를 더 추가할 수 있나요?

이 도구에서 images.pdf를 수정하는 방식으로는 안 됩니다. 새 이미지로 PDF를 하나 더 만든 뒤 PDF 병합 도구로 두 파일을 합치세요.

문서를 찍은 사진이 PDF에서 왜 흐릿하죠?

도구는 사진에 없던 디테일을 만들어 낼 수 없습니다. 갤러리에서 원본 크기로 봤을 때 흐리거나 어둡다면 PDF에서도 똑같습니다. 밝은 곳에서 휴대폰을 흔들리지 않게 잡고 다시 찍으세요.

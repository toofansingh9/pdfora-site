OCR PDF

스캔한 PDF의 원래 페이지에 보이지 않는 텍스트 레이어를 더해 검색 가능한 PDF로 만들거나, 인식한 텍스트를 .txt 파일로 받습니다. 모든 처리는 내 기기 안에서 이루어집니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

스캔한 PDF는 문서처럼 보이지만 실제로는 사진첩처럼 동작합니다. 각 페이지가 글자를 찍은 그림일 뿐이라 단어를 검색할 수도, 문장을 선택할 수도, 숫자를 복사할 수도 없습니다. 광학 문자 인식(OCR)은 그 그림을 보고 어떤 글자가 있는지 알아내는 기술입니다. PDFora의 OCR PDF는 그 결과를 두 가지로 쓸 수 있습니다. 보이지 않는 텍스트 레이어로 PDF에 다시 넣어 같은 파일을 검색 가능하게 만들거나, 글자만 따로 일반 .txt 파일로 받는 것입니다.

기본 출력은 검색 가능한 PDF입니다. 원래 페이지는 다시 렌더링하거나 재압축하지 않고 그대로 두므로 스캔본의 모양과 선명도가 똑같이 유지됩니다. 그 위에 각 페이지마다 이미지 속 글자 위치에 맞춘 보이지 않는 텍스트 레이어를 얹어서, 검색·선택·복사 붙여넣기가 눈에 보이는 그 자리에서 글자를 찾습니다. 회전된 상태로 저장된 페이지에서도 작동합니다. 이미 실제 텍스트가 있는 페이지(약 40자 초과)는 건너뛰고 그대로 두므로, 섞여 있는 문서에서 텍스트가 이중으로 들어가지 않습니다. 파일 이름은 원래 이름 뒤에 -searchable이 붙고, .txt 옵션을 고르면 대신 yourfile-ocr.txt를 받습니다.

인식은 브라우저에서 실행되는 오픈소스 OCR 엔진 Tesseract.js 5.1.1이 맡습니다. 각 페이지를 약 144ppi로 렌더링해 내 기기의 프로세서로 분석합니다. 처음 실행할 때는 엔진과 언어 데이터를 jsDelivr CDN에서 내려받기 때문에 연결이 느리면 잠시 걸릴 수 있습니다. 이 다운로드에 PDF는 포함되지 않으며, 파일은 업로드되지 않습니다.

스캔한 PDF를 검색 가능하게 만드는 방법

  1. OCR PDF를 열고 PDF 하나를 추가합니다. 스캐너 출력물, 휴대폰으로 찍어 PDF로 저장한 것, 이미지로만 내보낸 파일 등이 해당합니다.
  2. 언어에서 문서의 언어를 고릅니다. 영어, 힌디어, 스페인어, 프랑스어 중에서 고를 수 있고 기본값은 영어입니다.
  3. 출력 형식을 고릅니다. 페이지를 그대로 두고 텍스트 레이어를 더하려면 검색 가능한 PDF, 글자만 필요하면 텍스트 파일(.txt)을 선택합니다.
  4. OCR 실행을 누릅니다. 상태 줄에 지금 읽고 있는 페이지가 표시됩니다. 노트북에서는 페이지당 몇 초, 휴대폰에서는 더 오래 걸립니다.
  5. yourfile-searchable.pdf 또는 yourfile-ocr.txt를 내려받아 페이지에 보이는 단어로 검색해 보고, 이름과 숫자는 믿고 쓰기 전에 꼭 대조하세요.

이 도구가 필요한 경우

  • 스캔한 영문 계약서를 검색 가능하게 만들어, 페이지를 넘기는 대신 Ctrl+F로 조항을 바로 찾을 때.
  • 학과에서 복사본을 스캔해 나눠 준 영어 논문 묶음을 인용문을 찾아 복사할 수 있는 PDF로 바꿀 때.
  • 실제 텍스트가 있어야 작동하는 텍스트별 분할, PDF를 텍스트로, PDF를 Word로에 넣기 전에 스캔 페이지를 준비할 때.
  • 해외에서 온 서신과 영수증을 스캔해 보관하면서, 컴퓨터 검색이나 문서 관리 프로그램이 참조 번호로 찾을 수 있게 할 때.
  • 스페인어나 프랑스어 스캔본을 일반 텍스트로 바꿔 번역 도구에 붙여 넣을 때.
  • 스캔한 영문 명세서의 숫자를 .txt 출력으로 스프레드시트에 옮기고, 하나하나 페이지와 대조할 때.

시작하기 전에 알아둘 점

  • 검색 가능한 PDF는 원래 페이지를 전혀 건드리지 않고 그 위에 숨은 텍스트를 얹습니다. 눈에 보이는 것은 스캔 이미지이고 검색과 선택에는 인식된 텍스트가 쓰이므로, 인식 오류는 복사하거나 검색해 보기 전까지 보이지 않습니다.
  • 이미 실제 텍스트가 약 40자 넘게 있는 페이지는 검색 가능한 PDF에서 건너뛰고 그대로 둡니다. 반면 .txt 출력은 모든 페이지에 OCR을 실행합니다.
  • 지원 언어는 영어, 힌디어, 스페인어, 프랑스어 네 가지이며 한국어 문서는 지원하지 않습니다. 다른 언어로 된 문서는 맞지 않는 문자 모델로 읽게 되어 결과가 좋지 않습니다.
  • 정확도는 주로 스캔 품질에 달려 있습니다. 반듯하고 대비가 뚜렷한 깨끗한 인쇄물은 대개 잘 나오지만, 손글씨, 흐린 복사본, 글자 위에 찍힌 도장, 비스듬히 찍은 휴대폰 사진은 오류가 많습니다.
  • 인식을 위해 페이지를 약 144ppi로 렌더링합니다. 8포인트 미만의 각주처럼 아주 작은 글자는 이 해상도에서 엔진이 안정적으로 읽지 못할 수 있습니다.
  • 레이아웃은 재구성하지 않습니다. .txt 파일에서는 표와 단이 그냥 텍스트 줄이 됩니다. 검색 가능한 PDF에서는 페이지 모양은 그대로지만, 단을 가로질러 선택하면 텍스트 순서가 뒤섞일 수 있습니다.

더 좋은 결과를 위한 팁

  • 스캐너를 직접 다룰 수 있다면 300dpi 회색조나 흑백으로 스캔하세요. 나중에 무엇을 하든 이것보다 인식에 더 도움이 되는 것은 없습니다.
  • 기울기 보정, PDF 압축, 그레이스케일 PDF는 OCR 전에 하고, 후에는 하지 마세요. 이 도구들은 페이지를 새 이미지로 바꾸기 때문에 먼저 넣은 텍스트 레이어가 사라집니다.
  • 옆으로 눕거나 뒤집힌 스캔본은 먼저 PDF 회전으로 바로 세우세요. 엔진은 왼쪽에서 오른쪽으로 흐르는 글줄을 전제로 합니다.
  • 긴 문서는 필요한 페이지만 떼어 내 OCR을 돌리세요. 인식 시간은 페이지 수만큼 늘어납니다.
  • 숫자는 꼭 대조하세요. 0과 O, 1과 l, 5와 S를 혼동하는 것이 가장 흔한 OCR 오류이고, 청구서나 ID 번호에서는 가장 큰 손해로 이어집니다.

실제 예시: 복사본을 스캔한 26페이지 영어 강의 자료

국제정치학을 공부하는 대학원생이 학과에서 복사본을 스캔해 올려 준 26페이지짜리 영어 강의 자료를 받았습니다. 약 11MB에 텍스트가 전혀 없는 PDF입니다. 기말 보고서에 쓸 인용문 열 개 남짓이 필요하고, 자료 전체를 다시 읽지 않고 Bretton Woods가 나오는 곳을 모두 찾고 싶습니다.

언어는 영어, 출력 형식은 검색 가능한 PDF로 두고 OCR PDF에 넣었더니 노트북에서 약 3분, 페이지당 7초 정도 걸렸습니다. 내려받은 reader-searchable.pdf는 스캔본과 똑같아 보이고 크기도 조금 늘었을 뿐이지만, 이제 Ctrl+F로 Bretton Woods를 검색하면 8페이지에서 찾아지고, 문단을 선택해 뷰어에 보이는 페이지 번호와 함께 노트에 붙여 넣을 수 있습니다.

비스듬히 복사된 두 페이지는 붙여 넣으면 뒤죽박죽인 결과가 나왔습니다. 원본 자료를 기울기 보정에 넣은 뒤 반듯해진 파일로 OCR을 다시 돌리자 그 페이지들도 깨끗하게 나왔습니다. 같은 파일을 텍스트 파일(.txt) 출력으로도 한 번 더 돌려, 인명을 훑어보기 위한 전체 텍스트도 따로 받아 두었습니다.

인용하기 전에는 모든 문장을 페이지 이미지와 대조했습니다. 그 과정에서 1944년이 1914년으로 읽힌 곳을 하나 찾았습니다. 큰 글씨로 된 장 제목은 완벽했고 오류는 거의 다 작은 각주에 몰려 있었기 때문에, 각주는 스캔본을 직접 보며 확인했습니다.

문제 해결

검색 가능한 PDF에서 검색해도 아무것도 안 나옵니다
원본이 아니라 내려받은 -searchable.pdf를 열었는지 확인하세요. 그래도 일부 페이지가 검색되지 않는다면 글자가 너무 흐리거나 작거나 기울어 인식되지 않은 것입니다. 다시 스캔하거나 반듯하게 고친 뒤 OCR을 다시 실행하세요.
복사한 텍스트가 이상한 문자투성이입니다
언어 설정이 문서와 맞는지, 페이지가 똑바로 서 있는지 확인하세요. 옆으로 눕거나 뒤집힌 스캔본은 쓸모없는 결과를 냅니다. 먼저 회전하세요.
일부 페이지가 그대로 남았습니다
그 페이지에는 이미 실제 텍스트가 있어서 두 번째 레이어를 넣지 않았습니다. 뷰어에서 해당 페이지의 텍스트가 선택되는지 확인하세요. 기존 텍스트 품질이 나쁘다면 모든 페이지를 읽는 .txt 출력을 쓰세요.
도구가 시작 단계에서 멈춥니다
처음 실행할 때 OCR 엔진과 언어 데이터를 cdn.jsdelivr.net에서 내려받습니다. 느리거나 필터링된 네트워크, 스크립트 차단 프로그램 때문에 멈출 수 있으니 해당 도메인을 허용하고 다시 시도하세요.
휴대폰에서 너무 느립니다
OCR은 기기 프로세서로 하는 무거운 작업입니다. 긴 문서는 컴퓨터에서 처리하거나, 파일을 나눠 필요한 페이지만 OCR을 돌리세요.
나중에 파일을 압축했더니 검색이 안 됩니다
PDF 압축, 그레이스케일 PDF, 기울기 보정은 페이지를 이미지로 다시 렌더링하므로 텍스트 레이어가 사라집니다. 이 작업들을 먼저 하고 OCR은 마지막에 하세요.

자주 묻는 질문

OCR PDF로 스캔한 PDF를 검색 가능하게 만들 수 있나요?

네. 검색 가능한 PDF를 선택하면 원래 페이지를 유지한 채 보이지 않는 텍스트 레이어를 더하므로, 텍스트를 검색하고 선택하고 복사할 수 있습니다.

스캔본의 모양이 달라지거나 화질이 떨어지나요?

아니요. 원래 페이지는 다시 렌더링하거나 재압축하지 않으며, 인식된 텍스트만 보이지 않게 위에 더해집니다.

어떤 언어를 지원하나요?

영어, 힌디어, 스페인어, 프랑스어입니다. OCR을 실행하기 전에 문서와 맞는 언어를 고르세요. 한국어 문서는 지원하지 않습니다.

인식을 위해 문서가 업로드되나요?

아니요. 엔진과 언어 데이터가 jsDelivr CDN에서 브라우저로 내려받아지고 인식은 브라우저 안에서 이루어집니다. PDF 자체는 기기를 떠나지 않습니다.

손글씨도 읽을 수 있나요?

잘 읽지 못합니다. 엔진은 인쇄된 글자로 학습되어 있어서, 또박또박 쓴 대문자 정도는 가끔 되지만 필기체는 대개 안 됩니다.

표와 서식이 유지되나요?

검색 가능한 PDF에서는 스캔본을 그대로 두므로 페이지가 이전과 똑같아 보입니다. .txt 출력은 읽는 순서대로 나열한 일반 텍스트이며, 표 구조나 글꼴, 이미지는 없습니다.

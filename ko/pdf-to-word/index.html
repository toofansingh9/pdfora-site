PDF를 Word로

PDF를 편집 가능한 Word(.docx) 파일로 바꿔, 다시 타이핑하지 않고 텍스트를 고칠 수 있게 합니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

PDF는 배치된 모습 그대로 페이지를 보여 주려고 만든 형식이지, 편집하려고 만든 형식이 아닙니다. 텍스트 한 줄 한 줄이 고정된 좌표에 놓여 있고, 진짜 문단은 대개 없으며, 표는 흩어진 단어 옆에 선을 그어 놓은 것에 불과한 경우가 많습니다. 이것을 Word 문서로 되돌리려면 변환기가 문단이 어디서 시작하고 끝나는지, 어떤 텍스트가 같은 단에 속하는지, 어떤 선이 표를 이루는지 추측해야 합니다. 대부분은 잘 맞히지만 가끔은 틀리고, 그 이유를 알면 답답함이 크게 줄어듭니다.

PDFora의 PDF를 Word로 도구는 이 재구성 작업을 서버의 변환 엔진에 맡깁니다. 제대로 하려면 브라우저 탭으로는 따라갈 수 없는 레이아웃 분석과 글꼴 처리가 필요하기 때문입니다. PDF 하나를 고르면 암호화된 연결로 변환 서비스(저희 작은 중계 서버를 거친 CloudConvert)에 업로드되어 .docx로 변환되고, 완성된 파일이 다운로드로 돌아옵니다. 업로드된 파일은 작업 후 서비스에서 삭제되지만, 이 사이트에서 파일이 실제로 내 컴퓨터를 떠나는 종류의 도구라는 점은 분명하니, 제3자에게 보내면 안 되는 문서에는 쓰지 마세요.

결과는 Microsoft Word, LibreOffice Writer, 구글 문서, Pages에서 열리는 평범한 .docx입니다. 고를 설정은 없고, 문서 전체의 모든 페이지를 한 번에 변환합니다. 그다음 할 일은 확인입니다. 변환된 문서는 원본의 아주 좋은 초안이지, 원본과 똑같은 사본이 보장되는 건 아니기 때문입니다.

PDF를 Word로 변환하는 방법

  1. PDF를 Word로 도구를 열고 PDF 하나를 선택합니다. 작업 한 번에 파일 하나이니 여러 파일은 차례로 변환하세요.
  2. 변환을 누릅니다. 작업이 진행되면서 상태 줄이 준비 중, 업로드 중, 변환 중, 다운로드 중으로 바뀝니다.
  3. 서버가 작업하는 동안 기다립니다. 짧은 텍스트 문서는 보통 금방 끝나고, 길거나 이미지가 많은 파일은 더 걸리며, 도구는 약 3분을 기다린 뒤 포기합니다.
  4. .docx를 저장합니다. 보통 원래 파일 이름에 확장자만 바뀌어, 예를 들어 report.pdf는 report.docx가 됩니다.
  5. 워드프로세서에서 열어 편집하기 전에 PDF와 페이지별로 비교하고, 특히 표, 머리글, 각주를 주의해서 보세요.

이 도구가 필요한 경우

  • 서명된 PDF만 남고 원본 Word 파일은 잃어버린 옛 계약서나 사내 규정을 고칠 때.
  • 동료 교사가 PDF로 공유한 학습지를 새 반에 맞게 문제만 바꿔 다시 쓸 때.
  • 번역 도구가 읽을 수 있는 편집 가능한 형식의 원문이 필요한 번역가.
  • 공개된 보고서의 여러 문단을 다시 타이핑하지 않고, 복사·붙여넣기 줄바꿈 문제 없이 내 문서로 가져올 때.
  • 만든 디자이너와 연락이 닿지 않을 때 이력서나 브로슈어의 오타를 고칠 때.
  • PDF 안내문을 메일 병합에 쓸 수 있는 템플릿으로 되돌릴 때.

시작하기 전에 알아둘 점

  • 변환은 브라우저가 아니라 서버에서 이루어집니다. PDF는 암호화되어 업로드되고 변환된 뒤, 작업이 끝나면 변환 서비스에서 삭제됩니다.
  • 스캔 페이지에는 텍스트 레이어가 없고 글자를 찍은 그림만 있습니다. 텍스트 레이어가 없으면 편집 가능한 글자로 바꿀 것이 없으니, 스캔본은 대개 문서 안의 이미지로 들어옵니다. 스캔본에서 편집 가능한 텍스트가 필요하면 먼저 OCR PDF를 돌리세요. 검색 가능한 PDF로 만들면 변환기가 실제 텍스트를 다룰 수 있고, .txt 파일로 받아 Word에 붙여 넣을 수도 있습니다.
  • 레이아웃은 복사되는 게 아니라 다시 만들어집니다. 다단 페이지, 텍스트 상자, 사이드바, 인용 박스는 떠 있는 텍스트 프레임이 될 수 있고, 줄 간격이 달라져 페이지 나눔 위치가 바뀔 수 있습니다.
  • 내 컴퓨터에 설치되지 않은 글꼴은 .docx를 열 때 대체되어 줄 길이가 달라지고 텍스트가 다음 페이지로 밀릴 수 있습니다.
  • 비밀번호로 보호된 PDF는 변환할 수 없습니다. 파일을 만든 프로그램에서 먼저 보호를 해제하세요.
  • 작업 한 번에 PDF 하나이며 페이지 범위 옵션은 없습니다. 90페이지 보고서에서 두 페이지만 필요하다면 그 페이지만 먼저 추출하세요. 작업이 빨라지고 결과 확인도 쉬워집니다.

더 좋은 결과를 위한 팁

  • 변환하기 전에 PDF 뷰어에서 텍스트를 선택해 보세요. 단어 하나하나를 드래그할 수 없다면 스캔본이니, 먼저 OCR PDF를 돌리고 검색 가능해진 사본을 변환하세요.
  • 페이지 추출로 필요한 페이지만 뽑아 그 작은 파일을 변환하세요. 업로드와 변환이 더 빠릅니다.
  • Word에서 편집 기호(문단 기호) 표시를 바로 켜세요. 변환기가 넣은 강제 줄바꿈과 엉뚱한 구역 나누기가 보입니다.
  • 표가 탭으로 구분된 텍스트로 나왔다면 같은 페이지로 PDF를 Excel로를 시도해 보세요. 격자는 스프레드시트 출력이 더 잘 다루는 경우가 많습니다.
  • 편집하는 동안 Word 파일 옆에 PDF를 열어 두면 빠진 줄이나 각주를 바로 알아챌 수 있습니다.

예시: 임대차 계약서를 갱신하는 집주인

집주인 임혜원 씨에게는 3년 전 작성한 6페이지짜리 임대차 계약서가 있습니다. 원본 Word 파일은 이미 고장 난 노트북에 있었고, 예전 중개사무소에서 받은 서명본 PDF만 남았습니다. 새 계약서에는 바뀐 월세, 새 기간, 자전거 보관에 관한 특약 한 줄이 들어가야 합니다.

1~5페이지를 추출해(6페이지는 어차피 새로 서명할 서명란입니다) 그 파일을 변환합니다. .docx를 열어 보니 조항은 일반 문단으로, 번호 붙은 제목도 그대로 들어와 있습니다. 고칠 것은 두 가지입니다. 작은 표였던 월세 납부 일정이 탭으로 구분된 줄이 되었고, 주소가 들어간 바닥글이 텍스트 상자로 바뀌었습니다. Word의 표 삽입으로 표를 다시 만들고, 주소는 실제 바닥글로 옮기고, 내용을 고친 뒤 Word를 PDF로 도구로 새 PDF를 저장합니다.

저녁 내내 다시 타이핑할 일이 20분 정도로 끝납니다. 요점은 변환이 일의 90퍼센트쯤을 해 주었고, 나머지 10퍼센트는 예상 가능했다는 것입니다. 변환된 문서에서 손으로 고쳐야 하는 곳은 대개 표와 머리글·바닥글 같은 페이지 장식입니다.

문제 해결

Word 파일에서 각 페이지가 큰 그림 한 장으로 나와요
PDF가 스캔본이거나 이미지에서 저장된 것입니다. 먼저 OCR PDF로 검색 가능한 사본을 만들어 변환하거나, .txt 출력의 텍스트를 Word에 붙여 넣으세요.
텍스트는 있는데 줄마다 강제 줄바꿈이 있어요
PDF가 문단이 아니라 줄 단위로 저장했기 때문입니다. Word의 찾기 및 바꾸기로 문단 안의 수동 줄바꿈(^l)이나 문단 기호를 공백으로 바꾸되, 구역별로 하나씩 작업하세요.
단이 섞이거나 이상한 텍스트 상자에 들어가 있어요
다단 레이아웃은 재구성하기 어렵습니다. 상자 속 텍스트를 새 단일 단 문서로 복사하거나, Word에서 직접 단을 설정하고 텍스트를 다시 붙여 넣으세요.
변환 시간이 초과되었다고 나와요
도구는 약 3분 뒤 기다리기를 멈춥니다. 아주 길거나 이미지가 많은 PDF는 그보다 오래 걸릴 수 있습니다. PDF 분할이나 페이지 추출로 나눠 부분별로 변환하세요.
서버에서 변환에 실패했다고 나와요
PDF가 비밀번호로 보호되었거나, 손상되었거나, 실제로는 PDF가 아닐 가능성이 큽니다. 뷰어로 열어 확인하고, 오류와 함께 열린다면 PDF 복구 도구를 거친 뒤 다시 시도하세요.
글꼴이 PDF와 달라 보여요
원래 글꼴이 내 컴퓨터에 없어서 Word가 대체했습니다. 그 글꼴을 설치하거나, 텍스트 전체를 선택해 비슷한 보유 글꼴을 고르세요.

자주 묻는 질문

Word 파일이 PDF와 똑같이 보이나요?

대개 비슷하지만 똑같은 경우는 드뭅니다. 본문과 제목은 잘 변환되고, 차이는 표, 단, 텍스트 상자, 정확한 페이지 나눔에서 나타납니다.

스캔 문서를 편집 가능한 텍스트로 바꿀 수 있나요?

이 도구만으로는 안 됩니다. 스캔본에는 텍스트 레이어가 없으니 먼저 OCR PDF를 돌려 변환기가 다룰 실제 텍스트를 만드세요. 레이아웃과 인식 오류는 어느 정도 직접 고쳐야 합니다.

어떤 Word 형식으로 받나요?

.docx 파일이며 Microsoft Word 2007 이상, LibreOffice, 구글 문서, Apple Pages에서 열립니다.

일부 페이지만 변환할 수 있나요?

도구는 파일 전체를 변환합니다. 먼저 페이지 추출로 원하는 페이지만 담은 PDF를 만드세요.

다른 도구와 달리 이 도구는 왜 파일을 업로드하나요?

PDF에서 Word 문서를 다시 만들려면 서버에서 돌아가는 완전한 변환 엔진이 필요합니다. 파일은 암호화되어 전송되고 변환 후 서비스에서 삭제됩니다.

요금이나 가입이 필요한가요?

아니요. 계정을 만들지 않고 파일을 골라 변환하면 됩니다.

PDF 압축

적당한 품질을 유지하면서 PDF 용량을 줄여 보세요. 이메일 첨부에 딱 좋습니다.

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

40MB짜리 PDF는 그 자체로 골칫거리입니다. 메일 서버는 반송하고, 채용 사이트는 거부하고, 관공서 업로드 양식은 아무 설명 없이 2MB에서 딱 잘라 버리죠. PDFora의 압축 도구는 브라우저 안에서 바로 PDF 용량을 줄여 주고, 압축 전후 크기와 절감된 정확한 비율까지 보여 줍니다. 파일이 원하는 곳에 들어갈지 바로 알 수 있어요.

압축 단계는 세 가지입니다. 낮음은 원본에 최대한 가까운 품질을 유지하면서 용량만 적당히 줄입니다. 권장은 용량과 선명도의 균형을 맞춘 설정으로, 대부분의 문서에 가장 알맞습니다. 강함은 가능한 한 작게 압축하는 설정이라 이미지가 조금 뭉개져도 상관없는 스캔 서류에 적합합니다. 하나 고르고, 압축하고, 비교하면 끝입니다.

모든 처리는 로컬에서 이뤄집니다. PDF는 사용자의 브라우저가 직접 처리하며 서버로 업로드되지 않습니다. 계약서, 진료 기록, 은행 거래내역서를 압축할 때 특히 중요한 부분이죠. 이 도구는 무료이고, 계정이 필요 없으며, 워터마크도 붙지 않고, 하루에 처리할 수 있는 파일 수에도 제한이 없습니다.

온라인에서 PDF 압축하는 방법

  1. 데스크톱이든 모바일이든 최신 브라우저에서 PDFora의 PDF 압축 도구를 엽니다.
  2. PDF를 드롭 영역에 끌어다 놓거나, 클릭해서 기기에서 파일을 선택합니다.
  3. 압축 단계를 고릅니다. 품질 우선이면 낮음, 균형을 원하면 권장, 최소 용량이 목표라면 강함을 선택하세요.
  4. 압축 버튼을 누르고 브라우저가 로컬에서 페이지를 다시 렌더링하는 동안 몇 초 기다립니다.
  5. 결과 패널에서 원본 크기, 압축 후 크기, 절감 비율을 확인합니다.
  6. 압축된 PDF를 내려받습니다. 여전히 용량이 크다면 강함 설정으로 한 번 더 돌려 보세요.

When to use this tool

  • 스캔한 임대차 계약서를 25MB에서 2MB 이하로 줄여 비자 신청이나 정부 포털 업로드를 통과시키기
  • Gmail과 Outlook의 10MB 첨부 제한에 맞춰 디자인 포트폴리오 용량 낮추기
  • 휴대폰으로 찍은 영수증 묶음을 파일 용량 제한이 빡빡한 사내 시스템에 경비 정산으로 올리기 전에 줄이기
  • 모바일 데이터 속도가 느린 학생들도 빠르게 받을 수 있도록 강의 노트와 슬라이드 유인물 압축하기
  • 제품 카탈로그를 웹사이트에 올리기 전에 줄여서 페이지 로딩을 빠르게 하고 방문자 데이터도 아껴 주기
  • 서명된 계약서를 WhatsApp이 거부하지 않을 만큼 작게 만들어 전송하기

Tips for the best results

  • 스캔 PDF가 가장 많이 줄어듭니다. 각 페이지를 다시 렌더링하는 방식이라 300DPI 고해상도 스캔은 70~90%까지 줄기도 하지만, 이미 가벼운 텍스트 PDF는 조금밖에 줄지 않습니다.
  • 먼저 권장으로 시작하세요. 결과가 여전히 용량 제한을 넘을 때만 강함으로 올리고, 공식 제출 전에는 작은 글씨가 있는 페이지를 꼭 확인하세요.
  • 원본은 보관해 두세요. 압축은 되돌릴 수 없으므로 원본 품질 파일은 저장해 두고 압축본만 공유하는 편이 안전합니다.
  • 큰 문서에서 몇 페이지만 필요하다면 먼저 분할한 뒤 압축하세요. 페이지가 적으면 압축을 시작하기도 전에 파일이 이미 작아집니다.
  • 50페이지가 넘는 문서라면 보통 휴대폰보다 노트북에서 압축하는 쪽이 빠릅니다. 작업이 사용자 기기의 성능으로 처리되기 때문입니다.

자주 묻는 질문

여기서 PDF를 압축하는 게 정말 무료인가요?

네. 결제 단계도, 가입도, 결과물 워터마크도, 하루 파일 제한도 없습니다. 브라우저에서 실행되기 때문에 사용자에게 넘길 서버 비용 자체가 발생하지 않습니다.

PDF를 압축하면 품질이 떨어지나요?

품질 손실은 압축의 본질이지만 정도는 선택한 단계에 따라 다릅니다. 낮음은 원본과 거의 구분되지 않고, 권장은 읽기와 인쇄에 깔끔한 수준이며, 강함은 눈에 보이는 선명도를 내주고 가장 작은 파일을 얻습니다.

압축한 뒤에도 텍스트를 선택하고 복사할 수 있나요?

아니요, 이 부분은 솔직히 말씀드릴 트레이드오프입니다. 이 도구는 용량을 크게 줄이기 위해 모든 페이지를 이미지로 다시 렌더링하므로 선택 가능하던 텍스트가 페이지 이미지의 일부가 됩니다. 텍스트 선택이 계속 필요하다면 압축본과 함께 원본도 보관하세요.

파일이 얼마나 작아지나요?

내용에 따라 다릅니다. 스캔 문서나 이미지가 많은 파일은 흔히 60~90% 줄어들고, 대부분 일반 텍스트로 된 PDF는 감소폭이 작습니다. 내려받기 전에 결과 화면에서 정확한 절감 비율을 확인할 수 있습니다.

제 문서가 서버에 업로드되나요?

아니요. 압축 전 과정이 사용자 기기의 프로세서를 이용해 브라우저 안에서 실행됩니다. 파일이 컴퓨터나 휴대폰을 떠나지 않기 때문에 기밀 계약서, 신분증 스캔본, 금융 서류에도 안심하고 쓸 수 있습니다.

최대 파일 크기 제한이 있나요?

저희가 정해 둔 제한은 없습니다. 작업을 사용자 기기가 직접 처리하기 때문입니다. 수백 메가바이트에 달하는 아주 큰 파일은 사용 가능한 메모리에 좌우됩니다. 100MB 이하의 PDF는 평범한 노트북에서 대부분 무리 없이 압축됩니다.

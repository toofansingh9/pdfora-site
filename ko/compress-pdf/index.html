PDF 압축

PDF의 각 페이지를 더 낮은 해상도의 JPEG 이미지로 다시 저장해, 이메일 첨부나 업로드 용량 제한에 맞게 파일을 줄입니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

PDF 압축은 모든 페이지를 해상도를 낮춘 JPEG 그림으로 다시 만들어 파일 크기를 줄입니다. 이 한 문장에 스캔본에서는 효과가 뛰어나고 일부 문서에서는 맞지 않는 이유가 모두 담겨 있으니, 버튼을 누르기 전에 알아 두는 것이 좋습니다. 스캔한 계약서나 사진이 많은 안내 책자라면 용량이 60~90% 줄어드는 일이 흔합니다. 반면 대부분이 텍스트인 PDF라면 오히려 파일이 커지고, 선택 가능한 텍스트가 글자를 찍은 그림으로 바뀝니다.

내부 동작은 이렇습니다. 각 페이지를 브라우저에서 비트맵으로 렌더링하고(렌더링은 PDF.js가 맡습니다), 그 비트맵을 선택한 품질의 JPEG로 저장한 다음, 원래 페이지 크기 그대로 페이지당 JPEG 한 장씩 넣어 새 PDF를 조립합니다. 낮음은 디테일을 가장 많이 남기고(약 162dpi, JPEG 품질 82), 권장은 용량과 가독성의 균형을 맞추며(약 124dpi, 품질 65), 강함은 가장 작은 파일을 목표로 합니다(약 97dpi, 품질 50). 모든 처리는 사용자 기기에서 이뤄지며 아무것도 업로드되지 않습니다.

결과물이 이미지 묶음이기 때문에 압축된 PDF에는 선택 가능한 텍스트, 클릭되는 링크, 책갈피, 양식 필드가 남지 않습니다. 스캔본이라면 잃는 것이 전혀 없습니다. 스캔본은 원래 그림이니까요. 하지만 디지털 문서라면 분명한 손해가 있으므로, 아래에서 언제 감수해도 되고 언제 다른 방법을 택해야 하는지 설명합니다.

온라인에서 PDF 용량을 줄이는 방법

  1. PDF 압축을 열고 파일을 끌어다 놓습니다. 파일 이름 옆에 현재 용량이 표시됩니다.
  2. 압축 수준을 고릅니다. 처음에는 권장으로 시작하고, 작은 글씨나 가는 선 도면이 있으면 낮음을, 화면으로 읽기만 하면 되면 강함을 고르세요.
  3. PDF 압축 버튼을 누릅니다. 진행 표시줄이 페이지 단위로 올라가며, 50페이지짜리 스캔본은 노트북 기준 대략 10~20초 걸립니다.
  4. 결과 줄을 확인합니다. 원래 용량, 새 용량, 줄어든 비율이 표시됩니다. 새 용량이 더 크다면 멈추고 아래 문제 해결 항목을 읽어 보세요.
  5. 파일을 다운로드해 열고, 가장 작은 글씨를 확대해 본 뒤에 사용하세요.

이 도구가 필요한 경우

  • 온라인 접수 사이트의 업로드 용량 제한에 맞춰야 하는 스캔 서류(계약서, 신분증 사본, 증명서).
  • 이메일로 보내는 사진 위주의 안내 책자, 매물 소개 자료, 포트폴리오.
  • 페이지마다 원본 크기 이미지가 들어간 채로 PowerPoint에서 내보낸 강의 슬라이드.
  • 휴대폰 카메라로 스캔해 페이지당 3~8MB씩 나오는 영수증과 신청서.
  • 편집 가능 여부보다 읽을 수 있는지가 중요한 오래된 종이 서류의 보관용 파일.
  • 큰 첨부 파일을 압축해 버리거나 아예 거부하는 메신저 앱에 올릴 파일.

시작하기 전에 알아둘 점

  • 결과는 이미지로만 구성됩니다. 텍스트를 선택·검색·복사할 수 없고, 링크가 작동하지 않으며, 책갈피와 양식 필드가 사라집니다. 이 중 하나라도 중요하다면 디지털 문서를 이 방식으로 압축하지 마세요.
  • 텍스트만 있는 PDF는 보통 작아지지 않고 커집니다. 300KB짜리 전자 청구서가 작은 이유는 텍스트가 문자로 저장되어 있기 때문인데, 페이지마다 JPEG로 바뀌면 페이지당 150~400KB가 됩니다. 이런 파일은 이미 그대로 보내도 충분히 작습니다.
  • 스캔본을 줄이는 핵심은 품질보다 해상도입니다. 300dpi 휴대폰 스캔본을 124dpi로 다시 렌더링하면 픽셀 수가 약 6분의 1이 되고, 절감 효과의 대부분이 여기서 나옵니다.
  • 색상은 그대로 유지됩니다. PDF 압축은 흑백으로 바꾸지 않습니다. 컬러 스캔본을 더 줄이고 싶다면 먼저 그레이스케일 PDF를 적용하세요.
  • 페이지 크기와 페이지 수는 바뀌지 않습니다. A4는 A4 그대로, 40페이지는 40페이지 그대로라서 쪽 나눔과 인쇄 결과가 이전과 똑같습니다.
  • 각 페이지를 브라우저에서 렌더링하므로 아주 큰 파일은 기기 메모리에 따라 한계가 있습니다. 데스크톱에서는 수백 페이지도 문제없지만, 휴대폰에서는 아주 긴 스캔본을 먼저 나누세요.

더 좋은 결과를 위한 팁

  • 디지털 문서가 아니라 스캔본을 압축하세요. 잘 모르겠다면 뷰어에서 텍스트를 드래그해 보세요. 단어가 선택되면 디지털 파일이고, 아마 이 도구가 필요 없을 겁니다.
  • 먼저 권장을 써 보고, 꼭 필요할 때만 강함으로 가세요. 권장에서 강함으로 내려가면 줄어드는 용량은 비교적 적은데 가독성은 가장 많이 떨어집니다.
  • 스캔 부분과 디지털 부분이 섞인 문서는 나눈 뒤 스캔 페이지만 압축하고, 두 부분을 다시 병합하세요.
  • 결과를 쓰기 전에 가장 작은 글씨(각주, 일련번호, 도장)가 있는 페이지를 200%로 확대해 확인하세요.
  • 원본은 꼭 보관하세요. 압축은 되돌릴 수 없으며, 압축본에서 잃어버린 디테일을 되살릴 방법은 없습니다.

실제 예시: 38MB 스캔본과 25MB 이메일 제한

휴대폰으로 스캔한 12페이지짜리 월세 계약서가 38MB로 나왔습니다. 페이지마다 300dpi 컬러 사진이라 한 장에 약 3MB입니다. Gmail은 25MB가 넘는 첨부 파일을 받지 않으니 적어도 3분의 1은 줄여야 하고, 집주인 휴대폰에서도 빨리 열리려면 훨씬 더 줄이는 게 좋습니다.

PDF 압축을 권장 수준으로 돌리면 각 페이지가 약 124dpi, JPEG 품질 65로 렌더링됩니다. 3MB짜리 페이지는 보통 250~500KB로 줄어 계약서 전체가 3~6MB 정도, 즉 85~90% 줄어듭니다. 서명, 도장, 9포인트 크기의 조항 번호도 보통 배율에서 잘 읽힙니다. 강함으로 하면 같은 파일이 2~3MB에 가까워지지만 작은 글씨가 뭉개지기 시작해, 법적 문서에는 적합하지 않습니다.

만약 이 계약서가 Word에서 내보낸 400KB짜리 PDF였다면 정답은 그대로 보내는 것입니다. 이미 용량 제한에 들어가고, 압축하면 선명하고 검색 가능한 텍스트가 글자 그림으로 바뀔 뿐입니다.

문제 해결

압축한 파일이 원본보다 커졌습니다
원본이 텍스트 기반의 디지털 PDF였습니다. 문자로 효율적으로 저장되던 텍스트가 JPEG 이미지로 바뀐 것입니다. 결과는 버리고 원본을 보내세요. 원래부터 작은 파일이었습니다.
글씨가 흐려지거나 읽기 어려워졌습니다
글자 크기에 비해 해상도가 너무 낮습니다. 원본으로 돌아가 낮음(약 162dpi)으로 다시 실행하세요. 6포인트 글씨나 가는 설계 도면 선이 있는 문서라면 낮음만이 현실적인 선택입니다.
텍스트를 더 이상 선택하거나 검색할 수 없습니다
이 도구는 원래 페이지를 이미지로 바꿉니다. 검색 가능한 텍스트가 필요하다면 디지털 원본 PDF를 그대로 쓰세요. 압축한 사본을 다시 검색 가능하게 만들려면 나중에 OCR PDF를 돌리면 됩니다. 페이지는 바꾸지 않고 보이지 않는 텍스트 레이어만 더합니다.
용량이 거의 줄지 않았습니다
이미 압축된 PDF(이전에 압축했거나 스캐너가 처음부터 100dpi JPEG로 저장한 경우)이거나 대부분 텍스트인 파일입니다. 결과 줄을 보세요. 절감률이 10% 미만이면 줄일 여지가 거의 없었다는 뜻입니다.
링크, 책갈피, 양식 필드가 사라졌습니다
정상입니다. 결과물에는 페이지 이미지만 들어 있습니다. 이것들이 필요하다면 스캔 페이지만 압축하고(분할, 압축, 병합) 상호작용 요소가 있는 페이지는 그대로 두세요.
브라우저 탭이 멈추거나 꺼졌습니다
페이지를 하나씩 메모리에서 렌더링하므로, 휴대폰이나 메모리가 적은 노트북에서 아주 긴 스캔본을 처리하면 메모리가 부족해질 수 있습니다. 문서를 50~100페이지 단위로 나눠 각각 압축한 뒤 병합하세요.

자주 묻는 질문

PDF가 얼마나 작아지나요?

스캔본과 사진이 많은 파일은 권장 수준에서 보통 60~90% 줄어듭니다. 텍스트 기반 디지털 PDF는 텍스트가 이미 압축적으로 저장되어 있어 줄지 않고, 오히려 커질 수 있습니다.

압축하면 화질이 떨어지나요?

네, 의도적으로 떨어뜨립니다. 페이지를 더 낮은 해상도로 다시 렌더링해 JPEG로 저장하기 때문입니다. 낮음은 일반적인 글자 크기라면 원본과 거의 비슷하고, 강함은 화면으로 읽는 용도로만 적합합니다.

압축 후에도 텍스트 검색이 되나요?

아니요. 결과물은 이미지로만 이루어져 있습니다. 다시 검색되게 하려면 압축한 파일에 OCR PDF(출력 형식: 검색 가능한 PDF)를 돌리세요.

파일 크기나 페이지 수 제한이 있나요?

정해진 제한은 없습니다. 브라우저에서 처리하므로 실질적인 한계는 기기 메모리입니다. 탭이 멈춘다면 아주 긴 스캔본을 여러 부분으로 나누세요.

이미지로 바꾸지 않고 PDF를 압축할 수 있나요?

이 도구로는 안 됩니다. 디지털 PDF라면 솔직히 대부분 압축할 필요가 없습니다. 아주 큰 사진 몇 장이 들어 있다면 원본 문서에서 그 사진들을 줄인 뒤 다시 내보내세요.

문서가 어딘가에 업로드되나요?

아니요. 렌더링과 재인코딩은 모두 브라우저 안에서 PDF.js와 pdf-lib로 처리됩니다. 파일은 기기를 벗어나지 않습니다.

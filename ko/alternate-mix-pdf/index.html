교차 및 병합

두 개의 PDF를 한 페이지씩 번갈아 끼워 넣어 합칩니다. 홀수 면과 짝수 면을 따로 스캔한 파일을 합칠 때 딱 맞습니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

단면 스캐너를 쓰다 보면 늘 같은 문제에 부딪힙니다. 양면 인쇄물을 한 번 훑어 앞면을 스캔하고, 뭉치를 뒤집어 다시 훑어 뒷면을 스캔하고 나면 홀수 페이지만 든 PDF와 짝수 페이지만 든 PDF, 이렇게 두 개가 남죠. PDFora의 번갈아 합치기 도구는 이 둘을 다시 엮어 줍니다. A 파일 1페이지, B 파일 1페이지, A 파일 2페이지, B 파일 2페이지 순으로 이어 붙여 원래 순서대로 읽히는 문서를 만들어 냅니다.

이 끼워 넣기 작업은 전부 브라우저 안에서 실행됩니다. 두 PDF 모두 업로드되지 않으므로 스캔한 은행 거래내역서나 진료 기록, 서명된 계약서도 내 컴퓨터 안에서만 정리되고 다른 어디에도 남지 않습니다. 무료이고 이메일 주소를 요구하지 않으며 결과물에 워터마크도 찍히지 않습니다. 하루에 몇 쌍을 합치든 제한이 없습니다.

손으로 페이지를 재정렬하는 방법도 있지만, 60페이지짜리 스캔이라면 조심스러운 드래그 앤 드롭을 서른 번 해야 하고 그만큼 실수할 여지도 많습니다. 번갈아 합치기는 한 번에, 그리고 매번 정확하게 끝냅니다.

온라인에서 두 PDF를 번갈아 합치는 방법

  1. getpdfora.com에서 번갈아 합치기 도구를 엽니다. 두 파일 모두 브라우저에서 로컬로 처리됩니다.
  2. 첫 번째 PDF를 추가합니다. 보통 스캔한 뭉치의 홀수 페이지, 즉 앞면 파일입니다.
  3. 두 번째 PDF를 추가합니다. 보통 짝수 페이지, 즉 뒷면 파일입니다.
  4. 순서를 확인합니다. 합쳐진 파일은 첫 번째 문서의 1페이지로 시작하므로, 문서의 맨 앞에 와야 할 면을 첫 번째 자리에 넣으세요.
  5. 합치기를 클릭합니다. 두 파일이 페이지 단위로 번갈아 끼워져 하나의 PDF가 됩니다.
  6. 미리보기로 순서가 제대로 읽히는지 확인한 뒤 내려받습니다.

When to use this tool

  • 단면 사무용 스캐너로 찍은 양면 문서의 스캔 페이지를 정리하는, 가장 전형적인 홀수·짝수 합치기.
  • 앞면과 뒷면을 따로 스캔한 양면 서명 계약서를 원래 형태로 되돌리기.
  • 번역문과 원문을 번갈아 배치해 영어 페이지 뒤에 스페인어 페이지가 오도록 만들어 나란히 검토하기.
  • 문제 페이지와 해설 페이지를 합쳐 문제, 해설, 문제, 해설 순으로 읽히는 시험지 만들기.
  • 색인 카드 아카이브의 앞면 스캔과 뒷면 스캔을 한 파일로 합쳐 편하게 넘겨 보기.
  • 병원 스캐너가 반으로 나눠 놓은 양면 초진 서류 묶음을 원래대로 복원하기.

Tips for the best results

  • 단면 스캐너 상당수는 뒤집은 뭉치를 역순으로 읽어 들입니다. 짝수 페이지 파일이 거꾸로 되어 있다면 먼저 페이지 순서를 뒤집은 뒤 합치세요.
  • 합치기 전에 간단히 점검하세요. 두 파일의 페이지 수가 같거나, 마지막 장 뒷면이 백지였다면 딱 하나만 차이 나야 정상입니다.
  • 내려받은 뒤 앞의 네 페이지를 읽어 보세요. 1, 2, 3, 4 순으로 이어지면 제대로 된 것이고, 아니라면 어느 파일을 먼저 넣을지 바꿔서 다시 실행하세요.
  • 짝수 페이지 스캔에서 백지 뒷면은 미리 지우세요. 그러지 않으면 인쇄된 페이지 사이사이에 빈 페이지가 끼어듭니다.
  • 스캔할 때 report-odd.pdf, report-even.pdf처럼 이름을 지어 두면 나중에 어느 쪽이 어느 절반인지 고민할 일이 없습니다.

자주 묻는 질문

PDF에서 번갈아 합치기란 무엇인가요?

뒤에 이어 붙이는 대신 끼워 넣는 방식의 병합입니다. A 문서 1페이지, B 문서 1페이지, A 문서 2페이지 하는 식으로 이어집니다. 일반 병합은 A 전체 뒤에 B 전체를 붙이는데, 스캔 페이지를 정리할 때는 그 순서가 맞지 않습니다.

스캔한 홀수 페이지와 짝수 페이지가 왜 파일이 따로 생기나요?

단면 스캐너는 한 번에 한쪽 면만 읽을 수 있어서 양면 문서는 면마다 한 번씩, 총 두 번 스캔하게 됩니다. 그때마다 PDF가 하나씩 생기죠. 번갈아 합치기 도구는 바로 이 두 절반을 다시 맞물리게 하려고 있는 기능입니다.

합친 파일이 1, 3, 2, 5, 4 순서로 나옵니다. 뭐가 잘못된 건가요?

두 번째 파일이 역순으로 스캔됐을 가능성이 큽니다. 뒤집은 뭉치가 마지막 장부터 급지될 때 흔히 생기는 일입니다. 짝수 파일의 페이지 순서를 뒤집은 다음 다시 합쳐 보세요.

제 문서는 안전하게 보호되나요?

네. 두 PDF 모두 브라우저에서 로컬로 읽고 합쳐지며 어떤 서버로도 전송되지 않습니다. 탭을 닫으면 내려받은 파일 외에는 어디에도 사본이 남지 않습니다.

두 PDF의 페이지 수가 똑같아야 하나요?

같은 것이 정상이고, 마지막 뒷면이 백지였다면 하나 차이까지는 괜찮습니다. 그보다 크게 어긋난다면 대개 스캐너가 한 장을 건너뛰었거나 두 장을 겹쳐 넘긴 경우이니 합치기 전에 다시 스캔하는 편이 좋습니다.

요금이나 워터마크가 있나요?

둘 다 없습니다. 무료이고 가입도 필요 없으며 페이지에 아무것도 덧붙이지 않습니다. 정리할 수 있는 문서 수에도 제한이 없습니다.

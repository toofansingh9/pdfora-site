PDF를 텍스트로

PDF에서 선택 가능한 텍스트를 모두 뽑아 .txt 파일로 저장하세요.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

파일을 선택하거나 끌어다 놓으세요.

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

PDF에서 텍스트를 추출해 어디서든 열 수 있는 일반 .txt 문서로 저장하세요. PDF 뷰어에서 손으로 복사하면 줄바꿈이 엉키고 글자가 빠지기 일쑤이며, 긴 문서에서는 시간이 한없이 걸립니다. 이 PDF → 텍스트 도구는 모든 페이지에서 선택 가능한 텍스트를 한 번에 전부 뽑아 깔끔한 파일로 건네줍니다. 무료이고 가입도 필요 없으며 문서 길이 제한도 없습니다.

추출은 브라우저에서 로컬로 실행됩니다. PDF가 사용자 기기에서 파싱되므로, 계약서나 학위 논문, 재무 보고서를 단지 글자를 꺼내려고 서버에 올릴 일이 없습니다. 이 로컬 전용 설계 덕분에 속도도 빠릅니다. 수백 페이지짜리 파일이라도 업로드를 기다릴 필요가 없죠. 탭을 닫으면 문서에 관한 어떤 흔적도 어디에도 남지 않습니다.

한 가지는 솔직히 말씀드립니다. 이 도구는 PDF 안의 텍스트 레이어를 읽습니다. 스캔한 문서나 촬영한 페이지는 그저 이미지일 뿐이라 추출할 텍스트 레이어가 없고, 결과가 비어 있게 됩니다. 그런 경우에는 이미지 속 글자를 인식해 진짜 텍스트로 바꿔 주는 OCR 도구를 쓰세요.

온라인에서 PDF에서 텍스트 추출하는 방법

  1. PDF → 텍스트 도구를 열고 PDF를 페이지 위로 끌어다 놓거나 기기에서 찾아 선택합니다.
  2. 파일은 브라우저에서 바로 파싱되며 그동안 아무것도 업로드되지 않습니다.
  3. 간단한 확인: 일반 PDF 뷰어에서 텍스트를 선택하고 복사할 수 있다면 추출이 됩니다. 페이지가 스캔본이라면 OCR 도구로 옮겨 가세요.
  4. 추출을 클릭해 모든 페이지의 텍스트를 순서대로 뽑아냅니다.
  5. 생성된 .txt 파일을 내려받습니다.
  6. 아무 텍스트 편집기에서나 열어, 다음 작업에 필요하다면 간격이나 줄바꿈을 정리합니다.

When to use this tool

  • 연구 논문 전문을 .txt 파일로 뽑아, 내가 쓰는 메모 앱에서 검색하고 인용하고 주석을 달기.
  • PDF 두 개를 나란히 눈으로 비교하는 대신, 계약서 문구를 추출해 diff 도구에서 줄 단위로 두 버전 비교하기.
  • 긴 통근 시간에 쓸 화면 낭독기나 음성 변환 앱을 위해 전자책이나 보고서를 일반 텍스트로 만들기.
  • PDF 업로드는 안 되지만 일반 텍스트는 받는 번역 도구나 AI 요약 도구에 긴 문서의 텍스트 넣기.
  • 원본 Word 파일이 사라진 지 오래인 옛 PDF에서 글을 되살려 다시 편집하기.
  • 공급업체의 PDF 카탈로그에서 제품 설명이나 사양을 가져와 쇼핑몰 상품 페이지에 붙여 넣기.

Tips for the best results

  • 먼저 PDF를 확인하세요. 파일을 열어 문장을 선택해 보고 아무것도 표시되지 않으면 스캔본입니다. 텍스트 추출 대신 OCR을 돌리세요.
  • 학술 논문처럼 다단 레이아웃은 추출 순서가 단 사이를 오갈 수 있습니다. 결과를 그대로 쓰기 전에 훑어보세요.
  • 머리글, 바닥글, 페이지 번호도 본문과 함께 따라옵니다. 편집기의 찾아 바꾸기로 반복되는 것들을 빠르게 정리할 수 있습니다.
  • 일반 .txt는 설계상 모든 서식을 버립니다. 굵은 글씨나 표, 레이아웃이 나중에 다시 필요할 수 있다면 원본 PDF를 보관하세요.
  • 아주 긴 문서라면 .txt 결과에서 끝부분에 나오는 것으로 아는 문구를 검색해 보세요. 모든 페이지가 담겼는지 빠르게 확인하는 방법입니다.

자주 묻는 질문

왜 제 PDF에서 빈 텍스트 파일이 나왔나요?

그 문서는 거의 확실히 스캔본이나 사진이며, 실제 텍스트가 아니라 글자 그림을 담고 있습니다. 이미지 속 글자를 인식해 편집 가능한 텍스트를 만들어 주는 OCR 도구로 처리하세요.

추출 중에 문서가 업로드되나요?

아니요. PDF는 전부 사용자 기기의 브라우저 안에서 읽힙니다. 서버로 전송되거나 저장되거나 기록되는 것이 없으니, 법률 및 재무 서류에는 딱 필요한 방식입니다.

굵은 글씨, 글꼴, 표 같은 서식이 유지되나요?

아니요. 결과물은 일반 텍스트라서 스타일과 레이아웃은 사라지고 표는 줄로 평평해집니다. 그 대가로 .txt는 어디서나 열리고 처리하기 쉬운 형식이 됩니다.

아주 큰 PDF에서도 텍스트를 추출할 수 있나요?

네. 페이지 상한이 없고 업로드 단계도 없어서 500페이지짜리 문서도 빠르게 처리됩니다. 실질적인 한계는 기기 메모리뿐입니다.

텍스트가 올바른 순서로 나오나요?

일반적인 단일 단 문서라면 네, 페이지 순서대로 나옵니다. 다단, 사이드바, 텍스트 상자가 섞인 복잡한 레이아웃은 눈으로 읽는 순서와 다르게 나올 수 있으니 한 번 확인하세요.

정말 계정 없이 무료인가요?

네. 가입도, 어떤 워터마크도, 텍스트로 변환할 수 있는 PDF 개수 제한도 없습니다. 데스크톱이든 모바일이든 최신 브라우저라면 어디서나 동작합니다.

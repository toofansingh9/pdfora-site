PDF를 텍스트로

PDF의 텍스트 레이어를 꺼내 검색, 붙여넣기, 가공이 쉬운 일반 .txt 파일로 저장합니다.

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

PDF에서 텍스트를 손으로 복사하면 느리고 지저분합니다. 선택 영역이 단을 넘나들고, 머리글이 페이지마다 반복되며, 긴 문서는 전체 선택을 수십 번 해야 하죠. 이 도구는 PDF 안에 이미 저장된 텍스트를 읽어, 페이지 순서대로 전부 일반 텍스트 파일 하나에 씁니다. 텍스트 편집기, 스프레드시트, 스크립트에 바로 쓸 수 있습니다.

여기서 '텍스트'가 무엇을 뜻하는지 알아 두는 게 중요합니다. 워드프로세서, 브라우저, 회계 프로그램이 만든 PDF에는 위치 정보가 붙은 실제 문자가 들어 있습니다. PDF.js가 그 문자를 페이지별로 읽어 각 페이지의 조각을 공백으로 잇고, 페이지 사이는 빈 줄로 구분합니다. 반면 스캔한 페이지는 종이를 찍은 사진이라 문자가 전혀 없으므로 이 도구는 아무것도 돌려주지 않습니다. 스캔본에는 이미지 속 글자를 인식하는 OCR이 필요합니다.

결과는 일부러 단순하게 만듭니다. 굵은 글씨, 글꼴, 표, 이미지가 없고, 페이지 안의 원래 줄바꿈도 재현하지 않아 각 페이지가 긴 텍스트 한 덩어리로 들어옵니다. 그래서 검색하거나 다른 도구에 넣기는 쉽지만, 문서 레이아웃을 되살리는 방법은 아닙니다. 레이아웃이 중요하다면 PDF를 Word로가 더 나은 선택입니다.

PDF에서 텍스트를 추출하는 방법

  1. PDF를 텍스트로 도구를 열고 PDF 파일 하나를 선택합니다.
  2. 텍스트 추출을 누릅니다. 각 페이지의 텍스트를 차례로 읽으며 진행 표시줄이 페이지마다 움직입니다.
  3. 끝나면 처리한 페이지 수가 표시됩니다. PDF 이름을 딴 .txt 파일을 다운로드하세요(thesis.pdf라면 thesis.txt).
  4. 텍스트 편집기로 파일을 열고, 문서에 분명히 있는 문구를 검색해 텍스트가 제대로 들어왔는지 확인합니다.
  5. 통째로 빈 페이지가 있다면 그 페이지는 이미지입니다. PDF를 OCR 도구로 처리한 뒤 다시 추출하세요.

이 도구가 필요한 경우

  • 논문이나 보고서의 구절을 다시 타이핑하지 않고 내 노트에 인용할 때.
  • 긴 계약서나 약관에서 특정 용어가 나오는 곳을 텍스트 편집기의 찾기 기능으로 모두 찾을 때.
  • 글자 수 세기 도구, 번역기, 일반 텍스트를 받는 스크립트에 문서를 넣을 때.
  • 원래 편집 파일을 잃어버린 문서의 문구를 되찾아 새 버전의 출발점으로 삼을 때.
  • 스크린 리더나 검색 엔진이 PDF에서 무엇을 보게 될지 확인할 때. 이들도 같은 텍스트 레이어에 의존합니다.
  • 거래내역서에서 숫자를 꺼내 스프레드시트에 붙여 넣고 정리할 때.

시작하기 전에 알아둘 점

  • 텍스트 레이어만 읽습니다. 스캔 페이지, 문서를 찍은 사진, 윤곽선으로 변환된 텍스트는 결과에서 빈 페이지나 거의 빈 페이지가 됩니다.
  • 한 페이지의 텍스트 조각은 공백 하나로 이어지고, 페이지 사이는 빈 줄로 구분됩니다. 페이지 안의 줄바꿈은 유지되지 않으므로 문단과 표의 행이 한데 이어집니다.
  • 읽는 순서는 PDF에 텍스트가 저장된 순서를 따르며, 대개 보이는 순서와 같지만 항상 그렇지는 않습니다. 2단 레이아웃, 사이드바, 각주는 서로 섞여 나올 수 있습니다.
  • 머리글, 바닥글, 쪽 번호도 PDF에게는 평범한 텍스트라서 페이지마다 포함됩니다.
  • 어떤 PDF는 단어를 글자 단위로 저장하거나 간격이 이상해서 단어 중간에 공백이 더 생길 수 있습니다. 문자 매핑이 제대로 없는 글꼴을 쓰는 PDF는 글자 대신 깨진 기호가 나옵니다.
  • 이미지, 차트, 도표 속 글자는 추출되지 않으며, 페이지에 평면화되지 않은 양식 필드 안의 텍스트도 마찬가지입니다. PDF에서 두 줄에 걸쳐 하이픈으로 나뉜 영어 단어는 대개 하이픈과 공백이 낀 채 나뉜 상태로 남습니다. '- '를 검색하면 대부분 찾을 수 있습니다.

더 좋은 결과를 위한 팁

  • 결과가 엉망이거나 비어 있다면 먼저 일반 PDF 뷰어에서 텍스트를 선택해 보세요. 거기서 선택이 안 되면 추출도 안 되고, 답은 OCR입니다.
  • 반복되는 머리글과 바닥글은 페이지마다 손으로 고치지 말고 편집기의 찾아 바꾸기로 한 번에 지우세요.
  • 표라면 PDF를 Excel로가 행과 열을 나눠 줍니다. 일반 텍스트는 각 행을 한 줄로 몰아넣습니다.
  • 편집기가 물으면 .txt를 UTF-8로 저장하세요. PDF에서 추출한 한글이나 악센트 문자는 유니코드로 유지됩니다.
  • 한 장(章)만 필요하다면 큰 PDF를 먼저 분할하세요. 작은 텍스트 파일이 다루기 쉽습니다. 스캔 이미지 밑에 OCR이 깔아 둔 텍스트 레이어처럼 숨은 텍스트도 다른 텍스트와 똑같이 추출됩니다. 바로 그래서 스캔본은 OCR을 거친 뒤 이 도구를 쓰면 됩니다.

실제 예시: 판례를 정리하는 법학전문대학원생

법학전문대학원생 서예린 씨는 법원 사이트에서 내려받은 60페이지짜리 판결문 PDF에서 특정 선행 판례를 인용한 문단을 모두 찾아 노트에 옮기려 합니다. PDF 뷰어에서 스크롤하며 복사하면 문단마다 반복되는 머리글까지 같이 잡힙니다.

텍스트를 추출해 judgment.txt를 일반 편집기로 엽니다. 판례 이름을 검색하니 열한 곳이 나옵니다. 페이지마다 텍스트 한 덩어리라서 빈 줄 구분을 세어 각 검색 결과가 대략 몇 페이지인지 알 수 있고, 머리글 줄은 각 페이지 덩어리 맨 앞에 나와 쉽게 무시할 수 있습니다.

한 페이지는 비어 있습니다. PDF를 다시 열어 보니 판결문 중간에 끼워 넣은 스캔 별지입니다. 그 별지만 OCR로 처리하고 다시 추출하자 빠졌던 텍스트가 나타납니다. 일반적인 교훈입니다. PDF 하나에 실제 텍스트 페이지와 이미지 페이지가 섞여 있을 수 있고, 바로 추출되는 건 앞의 것뿐입니다.

문제 해결

텍스트 파일이 비어 있거나 빈 줄만 있어요
PDF가 스캔본이거나 이미지로 이루어져 있습니다. OCR 도구로 텍스트 레이어를 추가한 뒤 다시 추출하세요.
결과에 이상한 기호가 가득해요
PDF가 쓸 만한 문자 매핑이 없는 글꼴을 써서 문자를 글자로 되돌릴 수 없습니다. 추출이 실패하는 경우에도 렌더링된 페이지에 OCR을 하면 대개 됩니다.
단어가 공백으로 쪼개져 있어요
PDF가 텍스트를 작은 조각으로 저장하고, 도구가 조각을 공백으로 잇기 때문입니다. 편집기의 찾아 바꾸기로 자주 나오는 패턴을 정리하세요.
단이 서로 섞여요
텍스트는 저장된 순서대로 읽히는데, 다단 페이지는 그 순서가 단 사이를 오갈 수 있습니다. PDF 뷰어에서 필요한 단만 복사하거나, 레이아웃을 고려하는 PDF를 Word로 변환을 쓰세요.
도구에서 PDF가 열리지 않아요
비밀번호로 보호되었거나 손상되었을 수 있습니다. 만든 프로그램에서 비밀번호를 해제하거나 먼저 PDF 복구 도구를 실행하세요.
문단 안의 줄바꿈이 사라졌어요
도구가 원래 그렇게 동작합니다. 각 페이지가 텍스트 한 덩어리가 됩니다. 워드프로세서에 붙여 넣고 필요한 곳에 줄을 바꾸거나, 구조가 중요하다면 PDF를 Word로를 쓰세요.

자주 묻는 질문

스캔한 PDF도 읽을 수 있나요?

아니요. 스캔본에는 문자가 아니라 이미지가 들어 있습니다. 먼저 OCR 도구를 쓴 뒤 텍스트를 추출하세요.

굵은 글씨나 제목 같은 서식이 유지되나요?

아니요. 결과는 글꼴, 스타일, 표, 이미지가 없는 일반 텍스트입니다.

왜 모든 페이지가 같은 줄로 시작하나요?

그 줄은 PDF의 반복 머리글입니다. 평범한 텍스트라서 페이지마다 추출됩니다.

어떤 언어를 지원하나요?

PDF에 문자가 올바르게 저장되어 있다면 어떤 언어든 됩니다. 텍스트는 유니코드로 유지됩니다. 오른쪽에서 왼쪽으로 쓰는 텍스트는 표시 순서가 아니라 저장 순서로 나올 수 있습니다.

.txt 파일에서 페이지는 어떻게 구분되나요?

각 페이지 텍스트 뒤에 빈 줄이 붙어서 페이지가 별도의 덩어리로 보입니다.

추출이 서버에서 이루어지나요?

아니요. PDF.js가 브라우저 안에서 텍스트를 읽고 .txt 파일도 그곳에서 만들어집니다. 업로드하고 싶지 않은 계약서 초안이나 시험지라면 이 점이 중요합니다.

메타데이터 편집

PDF 안에 저장되는 제목, 작성자, 주제, 키워드를 설정합니다. 뷰어, 검색, 파일 관리자가 보여 주는 바로 그 정보입니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

설정

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

모든 PDF에는 페이지와 별개로 자기 자신에 대한 작은 기록이 들어 있습니다. 제목, 작성자, 주제, 키워드, 만든 프로그램, 생성일과 수정일 같은 것들이죠. 대부분의 사람은 이걸 들여다볼 일이 없지만 다른 소프트웨어는 봅니다. 브라우저 탭과 여러 PDF 뷰어는 파일 이름 대신 저장된 제목을 보여 주고, 문서 관리 시스템은 작성자와 키워드로 색인을 만들며, 템플릿에서 내보낸 파일은 'Microsoft Word - Document1'이나 몇 년 전 템플릿을 만든 사람의 이름을 조용히 드러내기도 합니다.

이 도구에서 새 제목, 작성자, 주제, 쉼표로 구분한 키워드를 입력하면 문서의 정보 사전(information dictionary)에 저장됩니다. 입력한 칸만 바뀌고, 비워 둔 칸은 기존 값이 그대로 남습니다. 수정일은 저장하는 순간으로 바뀝니다. 페이지 자체는 건드리지 않으므로 텍스트, 이미지, 링크, 양식 필드는 그대로입니다. 결과는 yourfile-meta.pdf 형태의 이름으로 다운로드됩니다.

편집은 브라우저 안에서 pdf-lib 라이브러리로 이루어집니다. 이 라이브러리의 부작용 하나는 알아 두는 게 좋습니다. 저장할 때 자기 자신을 Producer와 Creator로 기록하고 생성일도 새로 고칩니다. 원래 생성일이나 소프트웨어 이름이 중요하다면, 예를 들어 증빙 자료라면, 원본 파일을 보관하세요.

PDF 메타데이터 편집하는 방법

  1. 메타데이터 편집 도구를 열고 PDF 한 개를 선택합니다.
  2. 제목을 입력합니다. 파일 이름이 아니라 '2025 연차 보고서'처럼 문서의 실제 제목을 쓰세요.
  3. 작성자와 주제는 독자나 문서 시스템에 도움이 될 때 채웁니다. 비워 두면 기존 값이 유지됩니다.
  4. 키워드를 쉼표로 구분해 입력합니다. 예: '연차 보고서, 재무, 2025'. 쉼표 앞뒤 공백은 자동으로 정리됩니다.
  5. 메타데이터 저장을 누르고 파일을 다운로드한 뒤, 뷰어의 문서 속성(보통 Ctrl+D 또는 Cmd+D)에서 확인합니다.

이 도구가 필요한 경우

  • 브라우저 탭이나 검색 결과에 제목이 'Untitled'나 'Document1'로 뜨는 보고서를 고칠 때.
  • 문서를 외부로 보내기 전에 작성자 칸에 남은 퇴사자나 템플릿 제작자 이름을 바꿀 때.
  • 학교 홈페이지에 올리기 전에 학교 규정 문서들의 제목과 키워드를 통일할 때.
  • NGO 문서 보관함에서 키워드로 찾을 수 있도록 지원 사업 보고서에 사업 코드를 달 때.
  • 전자책이나 안내서에 제대로 된 제목을 넣어, 독자의 앱이 파일 이름 대신 제목으로 목록에 보여 주게 할 때.
  • 제목과 작성자 입력을 요구하는 기록물 보관 시스템에 올릴 문서를 준비할 때.

시작하기 전에 알아둘 점

  • 빈 칸은 지워지는 게 아니라 무시됩니다. 이 도구로 칸을 비울 수는 없고, 값을 비어 있지 않은 다른 값으로 바꾸는 것만 됩니다. 공백 한 칸을 입력하는 방법도 확실한 우회책이 아닙니다.
  • 전통적인 정보 사전만 갱신됩니다. 많은 PDF에는 XMP 메타데이터 블록도 들어 있습니다. 일부 문서 관리 시스템처럼 XMP를 먼저 읽는 뷰어는 전문 편집기로 XMP를 다시 쓰기 전까지 예전 제목이나 작성자를 계속 보여 줄 수 있습니다.
  • Producer와 Creator는 이전 값과 상관없이 pdf-lib 라이브러리로 설정되고, 생성일과 수정일도 새로 고쳐집니다. 이는 옵션이 아니라 라이브러리의 특성입니다.
  • 메타데이터는 숨겨진 내용과 다릅니다. 댓글, 이전 수정본, 양식 데이터, 레이어, 첨부 파일은 이 도구로 지워지지 않습니다. 그런 건 주석 제거나 PDF 평면화 도구를 쓰고, 민감한 파일은 공유 전에 결과를 확인하세요.
  • 키워드는 목록으로 저장됩니다. 검색 엔진은 키워드 필드를 거의 무시하며, 주로 사내 문서함이나 PC 검색에 쓸모가 있습니다. 긴 목록보다 정확한 단어 몇 개가 더 유용합니다.
  • 암호화된 파일은 복호화하지 않은 채 열리므로 결과물이 손상될 수 있습니다. 메타데이터를 편집하기 전에 파일을 만든 프로그램에서 보호를 해제하세요.

더 좋은 결과를 위한 팁

  • 제목은 사람이 말하듯이 쓰세요. 'tenant_handbook_FINAL_v3'보다 '입주자 안내서 2026'이 낫습니다.
  • 공개 문서라면 작성자에 개인 이름 대신 기관 이름을 쓰세요. 담당자가 바뀌어도 파일이 낡지 않습니다.
  • 메타데이터 편집은 마지막 단계에 하세요. 이후에 쓰는 도구가 Producer나 날짜 같은 필드를 다시 바꿀 수 있습니다.
  • 분쟁처럼 생성일이나 작성 소프트웨어가 중요해질 수 있다면 원본 사본을 남겨 두세요.
  • 저장 후에는 파일 이름도 알기 쉽게 바꾸세요. 뷰어마다 제목을 보여 주기도 하고 파일 이름을 보여 주기도 합니다.

예시: 학교 규정 문서

한 초등학교 행정실이 새 홈페이지에 규정 PDF 14개를 올리고 있습니다. 학부모가 파일을 열면 브라우저 탭에 'Microsoft Word - Template_2019' 같은 글자가 뜨고, 작성자 칸에는 몇 년 전에 전근 간 선생님의 이름이 아직 남아 있습니다.

행정실장은 파일마다 메타데이터 편집 도구로 제목을 규정 이름('학교폭력 예방 규정, 2026년 9월 개정')으로, 작성자를 학교 이름으로, 주제를 '학교 규정'으로, 키워드를 '규정, 안전, 학부모' 등으로 설정합니다. 파일 하나에 1분도 걸리지 않고, 페이지는 바뀌지 않습니다.

결과를 확인하다 보니 한 PDF는 특정 뷰어에서 여전히 예전 제목이 보입니다. 그 파일에는 이 도구가 다시 쓰지 않는 XMP 메타데이터 블록이 들어 있었습니다. 원래 워드프로세서에서 문서 제목을 올바르게 설정해 다시 내보내자 문제가 사라집니다.

나머지 파일은 다운로드한 뒤 새 제목에 맞춰 이름도 바꿉니다. 예를 들면 school-violence-prevention-2026.pdf처럼요. 그러면 학부모의 브라우저가 제목과 파일 이름 중 무엇을 보여 주든 둘이 일치합니다.

문제 해결

뷰어에 예전 제목이 계속 보여요
뷰어가 이 도구가 갱신하지 않는 XMP 메타데이터 블록을 읽고 있을 가능성이 큽니다. 원본 프로그램에서 올바른 제목으로 다시 내보내거나, 전문 PDF 편집기로 XMP를 갱신하세요.
칸을 비워 뒀는데 예전 값이 그대로예요
도구가 원래 그렇게 동작합니다. 빈 칸은 건너뜁니다. 값을 바꾸려면 새 값을 입력하세요.
생성일이 바뀌었어요
pdf-lib 라이브러리가 저장할 때 생성일과 수정일을 새로 고칩니다. 원래 날짜가 중요하다면 원본 파일을 보관하세요.
Producer가 pdf-lib로 바뀌었어요
라이브러리가 Producer와 Creator에 자기 이름을 씁니다. 문서가 보이거나 인쇄되는 방식에는 영향이 없습니다.
브라우저 탭에 여전히 파일 이름이 보여요
어떤 브라우저와 뷰어는 PDF가 요청할 때만 저장된 제목을 보여 주고, 어떤 것은 항상 파일 이름을 보여 줍니다. 파일 이름도 함께 바꾸세요.
결과 파일이 열리지 않아요
원본이 암호화되어 있었을 가능성이 큽니다. 파일을 만든 프로그램에서 비밀번호를 해제한 뒤, 보호되지 않은 사본을 편집하세요.

자주 묻는 질문

PDF 메타데이터가 뭔가요?

파일 안에 저장된 작은 필드 묶음으로, 제목, 작성자, 주제, 키워드, Producer, 날짜 등이 있습니다. 문서를 설명하지만 페이지에는 표시되지 않습니다.

PDF의 메타데이터를 전부 지울 수 있나요?

이 도구로는 안 됩니다. 제목, 작성자, 주제, 키워드를 새 값으로 바꿀 수는 있지만 비우거나 XMP 블록을 제거할 수는 없습니다.

메타데이터를 편집하면 페이지 내용이 바뀌나요?

아니요. 텍스트, 이미지, 링크, 양식은 그대로입니다. 정보 필드와 날짜만 바뀝니다.

PDF 메타데이터가 구글 검색 순위에 도움이 되나요?

검색 엔진이 PDF를 보여 줄 때 저장된 제목을 쓸 수 있으므로, 명확한 제목은 사람들이 파일을 알아보는 데 도움이 됩니다. 키워드 필드는 웹 검색에 거의 또는 전혀 영향이 없습니다.

바꾸기 전에 현재 메타데이터를 볼 수 있나요?

PDF 뷰어의 문서 속성 창에서 볼 수 있습니다. 이 도구는 기존 값을 표시하지 않습니다. 대부분의 데스크톱 뷰어에서는 파일 > 속성의 설명 탭에 있으며, 제목, 작성자, 주제, 키워드, Producer, 두 날짜가 나옵니다.

여러 파일의 메타데이터를 한 번에 편집할 수 있나요?

아니요. 파일을 하나씩 처리하세요. 파일당 몇 초면 됩니다.

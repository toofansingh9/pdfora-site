다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

모든 PDF에는 눈에 보이지 않는 정보 계층이 담겨 있습니다. 제목, 작성자 이름, 주제, 키워드 같은 것들이죠. 검색 도구, 파일 관리자, 문서 라이브러리는 다른 무엇보다 이 필드들을 먼저 읽습니다. 메타데이터가 잘못되어 있으면, 예를 들어 보고서 제목이 "Untitled"이거나 작성자가 "user123"이면 파일이 성의 없어 보이고 찾기도 어려워집니다. 이 도구를 쓰면 브라우저에서 바로 PDF 메타데이터를 편집할 수 있습니다.

파일을 열면 현재의 제목, 작성자, 주제, 키워드가 일반 텍스트 상자에 나타납니다. 필요한 것만 바꾸고 나머지는 그대로 둔 뒤 깔끔한 사본을 내려받으면 됩니다. 많은 PDF가 몇 년 전 템플릿을 만든 사람의 메타데이터를 그대로 물려받기 때문에, 고객 제안서에 퇴사한 직원이 작성자로 남아 있기도 합니다. 여기서는 30초면 고칠 수 있고 설치할 소프트웨어도 없습니다.

모든 처리는 브라우저에서 로컬로 이뤄집니다. PDF는 컴퓨터를 벗어나지 않으며, 계약서나 진료 기록 등 기밀 문서를 정리할 때 이 점이 중요합니다. 무료이고 가입도 필요 없으며 워터마크도 붙지 않고 처리 가능한 파일 수에도 제한이 없습니다.

온라인에서 PDF 메타데이터 편집하는 방법

  1. 업로드 영역을 클릭하거나 PDF를 끌어다 놓습니다. 파일은 로컬에서 열리며 서버로 전송되지 않습니다.
  2. 자동으로 불러온 기존 메타데이터, 즉 제목, 작성자, 주제, 키워드를 확인합니다.
  3. 새 제목을 입력합니다. 대부분의 검색 도구와 뷰어가 표시하는 텍스트이므로 내용을 잘 설명하도록 쓰세요.
  4. 작성자 필드를 수정하고, 나중에 찾기 쉽게 하려면 주제와 키워드도 손봅니다.
  5. 비워 두고 싶은 항목은 지웁니다. 잘못된 값보다는 빈 값이 낫습니다.
  6. 적용을 클릭하고 수정된 PDF를 내려받습니다.

When to use this tool

  • 모든 PDF 뷰어에서 제목이 "Microsoft Word - draft_v3_FINAL.docx"로 표시되는 보고서 고치기.
  • 고객에게 제안서를 보내기 전에 작성자 필드에 남아 있는 퇴사한 동료 이름 바꾸기.
  • 보관해 둔 수백 건의 청구서에 키워드를 넣어, 문서 관리 시스템이 실제로 검색해 낼 수 있게 하기.
  • 전자책이나 백서를 게시하기 전에 제대로 된 PDF 제목과 작성자 설정하기. 일부 검색 엔진은 메타데이터 제목을 결과에 표시하니까요.
  • 외부에 공유하기 전에 PDF의 주제와 키워드 필드를 지워 내부 프로젝트 코드명 없애기.
  • 스캐너에서 모두 "Scan0001"로 나온 스캔 문서 묶음의 제목과 작성자를 일괄 정리하기.

Tips for the best results

  • 메타데이터 제목은 파일 이름과 다릅니다. 일부 PDF 뷰어는 창 제목 표시줄에 메타데이터 제목을 보여 주므로 둘 다 설정하세요.
  • 키워드는 쉼표로 구분하세요. 긴 문장보다 짧고 구체적인 표현이 잘 작동합니다.
  • 익명으로 게시하는 문서는 작성자 필드를 비우세요. PDF 제작 소프트웨어가 아무 말 없이 채워 넣는 경우가 많습니다.
  • 온라인에 게시할 파일이라면 제목을 페이지 제목 쓰듯이 작성하세요. 검색 결과에 문서가 어떻게 보이는지에 영향을 줄 수 있습니다.
  • "마케팅팀, Acme Ltd"처럼 조직 전체에서 작성자 표기 형식을 통일하면 파일 정렬이 예측 가능해집니다.

자주 묻는 질문

PDF 메타데이터란 무엇인가요?

메타데이터는 PDF 내부에 저장된 설명 정보로 제목, 작성자, 주제, 키워드 등이 있습니다. 페이지에는 나타나지 않지만 파일 관리자, 검색 도구, PDF 뷰어가 이를 표시하고 색인합니다. 말하자면 문서 겉면에 붙은 라벨입니다.

메타데이터를 수정하면 PDF 모양이 바뀌나요?

아니요. 페이지, 글꼴, 이미지, 레이아웃은 그대로입니다. 눈에 보이지 않는 설명 필드만 다시 쓰이므로 내려받은 문서는 원본과 똑같이 인쇄되고 표시됩니다.

파일이 서버로 업로드되나요?

아니요. 이 도구는 로컬 처리 방식으로 전부 브라우저에서 실행되므로 PDF가 기기를 벗어나지 않습니다. 기밀 계약서, 재무제표, 개인 기록에도 안심하고 쓸 수 있습니다.

제 PDF가 뷰어에서 왜 엉뚱한 제목으로 나오나요?

대부분의 PDF 생성 프로그램이 원본 문서의 파일 이름이나 템플릿 제목을 메타데이터에 자동으로 복사하기 때문입니다. 원본 Word 파일이 "draft_v3"였다면 그 문자열이 PDF까지 따라옵니다. 여기서 제목 필드를 수정하면 영구적으로 바뀝니다.

메타데이터를 수정하는 대신 삭제할 수도 있나요?

네. 원하는 필드를 비우고 저장하면 내려받은 파일에서 그 항목이 비어 있게 됩니다. 작성자 이름이나 내부 키워드를 노출하고 싶지 않은 문서를 게시하기 전에 흔히 거치는 단계입니다.

비용이나 파일 개수 제한이 있나요?

완전히 무료이며 가입도, 워터마크도, 편집 가능한 PDF 수 제한도 없습니다. 파일이 하나든 백 개든 달라지는 것은 없습니다.

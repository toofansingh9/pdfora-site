책갈피별 분할

PDF의 최상위 책갈피마다 별도 파일로 나누고 책갈피 이름을 파일 이름으로 붙여, 장과 절을 바로 공유할 수 있게 만듭니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.
1

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

잘 만든 긴 PDF는 각 섹션이 어디서 시작하는지 이미 알고 있습니다. 워드프로세서에서 내보낸 업무 매뉴얼, 학위논문, 연차보고서, 제품 설명서에는 보통 뷰어 옆에 표시되는 책갈피 패널, 즉 장마다 항목이 하나씩 있는 목차가 들어 있습니다. 책갈피별 분할은 이 목차를 읽어 최상위 책갈피마다 문서를 자르므로, 페이지 번호를 찾아보거나 범위를 입력할 필요가 없습니다. 목차가 꼼꼼하게 만들어졌다면 대개 작성자가 의도한 구조대로 나뉩니다.

도구는 PDF.js로 목차를 읽고 각 책갈피가 가리키는 페이지를 찾습니다. 그런 다음 책갈피를 페이지순으로 정렬해 책갈피마다 파일 하나를 만드는데, 그 책갈피의 페이지부터 다음 책갈피 바로 앞 페이지까지가 한 파일이 되고, 마지막 책갈피는 문서 끝까지 이어집니다. 페이지는 pdf-lib로 그대로 복사되므로 텍스트 검색이 계속 되고 이미지 화질도 유지됩니다.

파일 이름에 책갈피 제목이 그대로 들어간다는 점이 번호로 나누는 방식보다 좋은 점입니다. handbook.pdf에 서론, 안전, 부록이라는 책갈피가 있으면 'handbook - 서론.pdf', 'handbook - 안전.pdf', 'handbook - 부록.pdf'가 만들어져 handbook-bookmarks.zip에 담깁니다. 파일 시스템이 허용하지 않는 / : * ? " < > | 같은 문자는 지워지고, 제목은 40자로 줄어듭니다.

책갈피 기준으로 PDF를 나누는 방법

  1. 평소 쓰는 뷰어로 PDF를 열어 책갈피(목차) 패널을 확인합니다. 도구가 사용할 것이 바로 이 목차입니다.
  2. 책갈피별 분할 도구를 열고 파일을 추가합니다. 따로 설정할 옵션은 없습니다.
  3. 책갈피 기준 분할을 누릅니다.
  4. zip 파일이나 개별 파일을 다운로드합니다. 각 파일에는 해당 책갈피 이름이 붙어 있습니다.
  5. 첫 번째 파일을 확인하세요. 첫 책갈피 앞에 페이지가 있는 문서라면 아래 표지 관련 안내를 읽어 보세요. 첫 책갈피 앞의 페이지는 내보내지지 않습니다.

이 도구가 필요한 경우

  • 사내 업무 매뉴얼을 장별로 나눠 팀마다 해당 규정만 전달할 때.
  • 한 장씩 검토하는 지도교수에게 학위논문을 장별로 나눠 보낼 때. 각 장 파일은 원래 페이지 레이아웃과 각주를 그대로 유지합니다.
  • 별표마다 책갈피가 달린 긴 입찰 서류나 계약서에서 특정 부분만 꺼낼 때.
  • 탭마다 책갈피가 있는 소송 서류철을 탭 단위로 나눌 때.
  • 기술 매뉴얼을 제품별 섹션으로 나눠 고객 지원 페이지에 올릴 때.
  • 논문마다 책갈피가 있는 학술대회 논문집을 개별 논문으로 나눌 때.

시작하기 전에 알아둘 점

  • 최상위 책갈피만 사용됩니다. 장 아래의 하위 항목 같은 중첩 책갈피는 상위 항목의 파일 안에 남고, 따로 자르는 기준이 되지 않습니다.
  • 첫 책갈피 앞의 페이지는 어떤 결과 파일에도 들어가지 않습니다. 첫 책갈피가 3페이지를 가리키면 1~2페이지의 표지와 목차가 빠집니다. 그 페이지가 필요하면 먼저 책갈피 만들기로 1페이지에 책갈피를 추가하세요. 이 도구에서 가장 흔히 놀라는 부분이니 첫 책갈피가 여는 페이지를 꼭 확인하세요.
  • 두 책갈피가 같은 페이지를 가리키면 앞의 책갈피는 자기 페이지가 없어 건너뛰고, 뒤의 책갈피가 그 섹션을 가져갑니다.
  • 페이지가 아니라 웹 주소를 열거나 동작을 실행하는 책갈피는 위치를 확인할 수 없어 무시됩니다. 확인되는 것이 하나도 없으면 책갈피 대상 위치를 확인할 수 없다는 안내가 나옵니다.
  • 책갈피는 패널에 나열된 순서가 아니라 페이지순으로 정렬되므로, 순서가 뒤섞인 목차라도 섹션은 문서 순서대로 나옵니다.
  • 결과 파일 자체에는 책갈피 목차가 없습니다. 각 파일 안에 하위 책갈피가 다시 만들어지지 않습니다.

더 좋은 결과를 위한 팁

  • 책갈피가 없다면 책갈피 만들기로 1분이면 추가할 수 있습니다(섹션마다 한 줄씩 '페이지, 제목' 형식). 그 결과 파일에 이 도구를 실행하세요. 그렇게 만든 책갈피는 최상위 책갈피라 이 도구가 나누는 기준과 정확히 맞습니다.
  • 책갈피 제목이 길다면 나누기 전에 이름을 바꾸세요. 파일 이름에는 앞 40자만 들어가서, 시작이 같은 두 제목은 구별하기 어려워집니다.
  • 목차에 최상위 항목이 하나뿐이고 나머지가 모두 그 아래에 있다면 파일이 하나만 나옵니다. 이럴 때는 하위 항목의 페이지를 보고 PDF 분할의 사용자 지정 범위를 쓰세요.
  • 원본 문서에서 제목에 슬래시나 콜론을 피하면 파일 이름이 쓴 그대로 나옵니다.
  • 처음과 마지막 파일뿐 아니라 중간 파일도 확인하세요. 원본에서 책갈피가 잘못된 페이지를 가리키면 섹션이 너무 일찍 또는 늦게 시작합니다. 나누기 전에 뷰어에서 최상위 책갈피를 하나씩 눌러 보면 각 파일이 어디서 시작할지 정확히 알 수 있습니다.

예시: 법무법인의 변론 서류철

법무법인 직원이 412페이지짜리 변론 서류철을 PDF 하나로 받았습니다. 목차에는 'A 소장'부터 'I 서신'까지 최상위 책갈피 아홉 개가 있고, 각각 아래에 개별 서류의 하위 책갈피가 달려 있습니다. 의뢰인은 C와 F 탭만, 감정인은 G 탭만 있으면 됩니다.

책갈피별 분할을 실행하면 'bundle - C 진술서.pdf' 같은 파일 아홉 개가 나오고, 각 파일에는 해당 탭의 모든 페이지와 하위 서류가 함께 들어 있습니다. 직원은 페이지를 한 장도 세지 않고 필요한 탭만 보냅니다. A 탭 책갈피 앞에 있던 1~4페이지의 색인은 어느 파일에도 들어가지 않았는데, 이번 용도에는 오히려 맞습니다. 색인이 필요했다면 나누기 전에 1페이지에 '색인' 책갈피를 추가해 별도 파일로 받았을 겁니다. 개별 진술서의 하위 책갈피는 자르는 기준으로 쓰이지 않아, 각 탭이 하나의 온전한 파일로 남았습니다.

이 작업을 위해 서류철을 어디에도 업로드하지 않았습니다. 목차를 읽고 페이지를 복사하는 일이 모두 브라우저 탭 안에서 이루어졌고, 비밀유지가 중요한 자료에서는 이 점이 중요합니다.

문제 해결

'이 PDF에는 분할에 사용할 책갈피가 없습니다' 오류
파일에 목차가 없습니다. 책갈피 만들기 도구로 책갈피를 추가하거나, 페이지 범위나 텍스트 기준으로 나누세요.
'책갈피 대상 위치를 확인할 수 없습니다' 오류
책갈피는 있지만 페이지를 가리키지 않습니다. 링크나 스크립트이거나 목차가 손상된 경우입니다. PDF 복구를 실행하거나 책갈피 만들기로 책갈피를 다시 만드세요.
표지와 목차 페이지가 없어졌어요
첫 책갈피 앞에 있어서 어느 섹션에도 배정되지 않았습니다. 1페이지에 책갈피를 추가한 뒤 다시 나누세요.
파일이 하나만 나왔어요
모든 섹션이 최상위 책갈피 하나 아래에 중첩되어 있습니다. 하위 항목을 기준으로 PDF 분할의 사용자 지정 범위를 쓰세요.
섹션 하나가 빠졌어요
그 책갈피가 다음 책갈피와 같은 페이지를 가리키거나 웹 링크일 가능성이 큽니다. 원본에서 책갈피를 고친 뒤 다시 나누세요.
파일 이름이 잘리거나 다르게 보여요
제목은 40자로 줄어들고 / : ? 같은 문자는 지워집니다. 필요하면 다운로드한 뒤 파일 이름을 바꾸세요. 원본 문서는 바뀌지 않습니다.

자주 묻는 질문

하위 책갈피도 나누는 기준이 되나요?

아니요. 목차의 최상위 항목만 새 파일을 만들고, 중첩된 섹션은 상위 장과 함께 남습니다.

첫 책갈피 앞의 페이지는 어떻게 되나요?

어떤 결과 파일에도 들어가지 않습니다. 필요하다면 먼저 1페이지에 책갈피를 추가하세요.

나눌 책갈피를 골라서 지정할 수 있나요?

이 도구에서는 안 됩니다. 전부 나눈 뒤 필요한 파일만 쓰거나, PDF 분할의 사용자 지정 범위를 사용하세요.

결과 파일에도 책갈피가 남나요?

아니요. 목차는 자를 위치를 정하는 데만 쓰이고 나눈 파일에는 복사되지 않습니다.

페이지 화질에 영향이 있나요?

없습니다. 페이지를 다시 렌더링하지 않고 있는 그대로 복사합니다.

스캔 문서에도 쓸 수 있나요?

네, 스캔본에 책갈피가 있다면 됩니다. 책갈피는 페이지에 실제 텍스트가 있는지와 무관합니다. 책갈피 만들기로 스캔 PDF에 추가한 책갈피도 똑같이 작동합니다.

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

잘 만든 PDF에는 자체 목차가 들어 있습니다. 뷰어 왼쪽에 보이는 북마크 패널이죠. PDFora의 북마크 기준 분할 도구는 그 항목들을 자르는 선으로 삼습니다. 최상위 북마크마다 새 파일이 시작되고, 각 결과물에는 북마크 제목이 이름으로 붙습니다. 그래서 "3장: 연구 방법"은 정말 그 이름의 파일이 됩니다. 전체 결과는 ZIP 하나로 내려받습니다.

분할하는 파일은 어느 것도 업로드되지 않습니다. 북마크 개요를 읽고 페이지를 나누는 일이 브라우저 안에서 로컬로 이뤄지므로 이사회 자료, 법률 서면, 미공개 원고가 처음부터 끝까지 사용자 컴퓨터에 머뭅니다. 무료이고, 계정 없이 동작하며, 워터마크를 남기지 않고, 문서를 몇 개 넣든 분할할 수 있습니다.

대안은 암울합니다. 북마크 패널을 열어 장마다 시작 페이지를 적고, 페이지 범위 분할을 열두 번쯤 돌린 뒤, 결과 파일 이름을 하나하나 손으로 바꿔야 하죠. 북마크 분할은 이 모든 과정을 클릭 한 번으로 줄이고 이름까지 대신 붙여 줍니다.

온라인에서 북마크 기준으로 PDF 분할하는 방법

  1. getpdfora.com의 북마크 기준 분할 도구를 엽니다. 처리는 브라우저 안에서만 이뤄집니다.
  2. 보고서, 매뉴얼, 전자책처럼 북마크 개요가 들어 있는 PDF를 추가합니다.
  3. 도구가 최상위 북마크를 읽어 들입니다. 각 북마크가 새 파일이 시작될 지점을 표시합니다.
  4. 분할을 누릅니다. 한 북마크부터 다음 북마크 직전까지의 페이지가 각각의 PDF로 모입니다.
  5. 결과 파일마다 북마크 제목이 자동으로 이름으로 붙으므로 손으로 이름을 바꿀 필요가 없습니다.
  6. ZIP 파일을 내려받아 압축을 풀면 각 섹션이 알아보기 쉬운 이름의 개별 파일로 나옵니다.

When to use this tool

  • 300페이지 연차보고서를 북마크된 섹션별로 나눠 각 부서장이 자기 장만 받도록 하기
  • 수업당 파일 하나를 요구하는 학습 플랫폼을 위해 기술 매뉴얼을 모듈별 PDF로 나누기
  • 이사회 자료를 안건별로 분리하고 각 파일에 북마크 이름을 붙여 위원들에게 배포하기
  • 법원 제출 서류를 북마크된 첨부 자료별로 나눠 각각을 따로 인용하고 공유하기
  • 북마크가 달린 요리책 원고를 장별 파일로 만들어 편집자들이 서로 다른 부분을 검토하게 하기
  • 회사 규정집의 각 장을 뽑아 인사팀이 나머지는 건드리지 않고 한 섹션만 갱신하게 하기

Tips for the best results

  • 분할 전에 PDF 뷰어의 북마크 패널을 확인하세요. 최상위에 보이는 항목이 바로 잘릴 지점입니다.
  • 분할은 최상위 북마크에서만 일어납니다. 하위 북마크는 상위 항목의 파일 안에 남는데, 대개 장과 절이 묶여야 하는 방식과 잘 맞습니다.
  • PDF에 북마크가 없다면 먼저 PDF 편집기에서 북마크를 추가하거나, 텍스트 기준 분할이나 페이지 범위 분할을 쓰세요.
  • 북마크 제목에는 가능하면 슬래시나 콜론 같은 문자를 넣지 마세요. 제목이 ZIP 안의 파일명이 되기 때문입니다.
  • 긴 문서는 큰 ZIP을 만듭니다. 업로드는 없지만 다운로드가 끝날 때까지 탭을 열어 두세요.

자주 묻는 질문

PDF 북마크란 정확히 무엇인가요?

북마크(개요라고도 합니다)는 대부분의 PDF 뷰어에서 사이드바에 표시되는 클릭 가능한 목차입니다. 저자나 Word, InDesign 같은 내보내기 도구가 장과 절을 표시하려고 넣으며, 이 도구는 그 표시를 분할 지점으로 사용합니다.

결과 파일의 이름은 어떻게 정해지나요?

각 파일은 시작 지점 북마크의 제목을 이름으로 가져갑니다. 그래서 "부록 B"라는 북마크는 그 이름의 파일이 됩니다. 파일명에 쓸 수 없는 문자는 자동으로 조정되어 모든 파일이 ZIP에서 깔끔하게 풀립니다.

제 PDF에는 북마크가 없어요. 그래도 쓸 수 있나요?

바로는 어렵습니다. 분할 지점을 정하는 것이 바로 개요이기 때문입니다. PDF 편집기에서 먼저 북마크를 추가하거나, 반복되는 키워드가 섹션 시작을 표시한다면 PDFora의 텍스트 기준 분할 도구를 쓰세요.

결과가 왜 ZIP 파일로 내려받아지나요?

북마크가 달린 문서는 열 개, 스무 개 이상으로 나뉘는 경우가 많은데, ZIP 하나가 파일마다 클릭하는 마라톤보다 훨씬 편하기 때문입니다. 압축을 풀면 이름이 붙은 PDF가 한 폴더에 모두 나타납니다.

하위 북마크에서도 분할하나요?

아니요. 최상위 항목만 새 파일을 시작하며, 그 아래에 중첩된 내용은 함께 딸려갑니다. 덕분에 절이 자기 장 안에 남고 문서가 수십 개 조각으로 흩어지지 않습니다.

정말 무료인가요? 제 문서는 비공개로 유지되나요?

둘 다 그렇습니다. 가입도, 워터마크도, 사용 제한도 없으며, 파일은 전적으로 브라우저 안에서 해석되고 분할되므로 서버로 전송되지 않습니다. 처리 시간은 기기 성능과 문서 크기에 따라 달라집니다.

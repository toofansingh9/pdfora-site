워크플로우

여러 PDF 도구를 하나의 순서로 이어, 각 도구의 기본 설정으로 파일 하나를 한 번에 처리합니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.
1

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

어떤 PDF 작업은 늘 같은 조합으로 찾아옵니다. 스캔한 계약서는 기울기를 바로잡고 페이지 번호와 워터마크를 넣어야 하고, 외부로 나가는 보고서는 양식 필드를 평면화하고 댓글을 지우고 용량을 줄여야 합니다. 이걸 도구 하나씩 하면 파일을 서너 번 다운로드했다가 다시 올려야 하고, 그때마다 중간 파일이 생깁니다. 워크플로우는 이 단계들을 한 줄로 엮습니다. 목록을 만들고 PDF를 놓으면 yourfile-workflow.pdf라는 완성 파일 하나가 나옵니다.

연결할 수 있는 도구는 12가지입니다. 압축, 흑백, 90° 회전, 워터마크, 페이지 번호, 여백 자르기, A4로 크기 변경, 평면화, 복구, 주석 제거, 뒤집기, 메타데이터 갱신입니다. 위에서 아래로 실행되며, 각 단계의 결과가 다음 단계의 입력이 됩니다. ↑ 버튼으로 단계를 위로 올리거나 ✕로 지울 수 있고, 같은 도구를 여러 번 넣을 수도 있습니다.

속도를 얻는 대신 단계별 설정은 없습니다. 각 단계는 아래에 정리한 도구별 기본값을 쓰므로, 기본값이 원하는 바와 맞을 때만 워크플로우가 쓸모 있습니다. 워터마크 문구를 바꾸거나 회전 방향을 달리해야 한다면 그 도구만 따로 실행하세요. 실제로는 기본값이 일상적인 사무 작업에 잘 맞습니다. 표준 대외비 표시, 간단한 페이지 번호, A4 출력, 균형 잡힌 압축 수준이니까요.

여러 PDF 도구를 한 번에 실행하는 방법

  1. 워크플로우를 엽니다. '단계 추가…' 목록에서 도구를 고르고 추가를 누릅니다. 단계마다 반복합니다.
  2. 순서를 확인합니다. 단계는 1번부터 아래로 실행됩니다. ↑로 단계를 앞으로 옮기고 ✕로 지웁니다.
  3. 단계 목록 아래 상자에 PDF 하나를 끌어다 놓거나, 상자를 클릭해 파일을 고릅니다.
  4. 상태 표시를 지켜봅니다. 도구가 실행될 때마다 '단계 2/4: 워터마크…' 같은 진행 상황이 나옵니다.
  5. '완료'가 표시되면 다운로드된 -workflow.pdf를 열어 모든 단계가 예상대로 적용됐는지 확인합니다.

이 도구가 필요한 경우

  • 작은 회사가 견적서에 'CONFIDENTIAL'을 찍고 페이지 번호를 매긴 뒤 고객에게 보낼 때.
  • 사무실에서 보관하기 전에 검토 댓글을 지우고 작성이 끝난 양식을 평면화할 때.
  • 작은 흑백 파일을 요구하는 제출 사이트용 스캔본 준비: 흑백 다음 압축.
  • 크기가 섞인 문서를 A4로 통일하고 페이지 번호를 넣어 일관되게 인쇄할 때.
  • 모든 페이지를 돌려야 하고 결과도 압축해야 하는, 옆으로 스캔된 묶음을 바로잡을 때.
  • 다른 도구가 가끔 거부하는 예전 시스템의 파일에 첫 단계로 복구를 실행할 때.

시작하기 전에 알아둘 점

  • 기본값은 고정되어 있습니다. 압축은 권장 단계, 회전은 모든 페이지를 시계 방향 90°, 워터마크는 'CONFIDENTIAL'을 50pt·불투명도 30%·대각선으로, 페이지 번호는 1부터 시작하는 1, 2, 3을 하단 가운데에 11pt로, 여백 자르기는 사방에서 30포인트(약 10.5 mm)를 잘라 내고, 크기 변경은 페이지를 A4에 맞추며, 뒤집기는 좌우로 반전합니다.
  • 압축, 흑백, 뒤집기는 모든 페이지를 JPEG 이미지로 다시 그립니다. 그 뒤의 단계는 페이지 그림을 대상으로 작동하고, 최종 파일에는 선택 가능한 텍스트, 링크, 양식 필드가 없습니다. 이게 의도한 바가 아니라면 이 단계들은 맨 뒤에 두세요.
  • 값 없이 실행하는 메타데이터 갱신은 파일의 수정 날짜만 바꿉니다. 워크플로우에는 입력할 칸이 없어서 제목이나 작성자는 바뀌지 않습니다.
  • 한 번에 PDF 하나만 처리합니다. 여러 파일을 똑같이 처리하려면 하나씩 차례로 놓으세요. 단계 목록은 실행 사이에도 그대로 남아 있습니다.
  • 단계 목록은 저장되지 않습니다. 페이지를 새로 고치거나 닫으면 사라지니, 자주 쓰는 워크플로우는 적어 두세요. 그래도 파일마다 손으로 놓아야 하긴 하지만, 비슷한 파일 열두 개 정도라면 충분히 실용적입니다.
  • 어느 단계든 실패하면 그 단계의 오류와 함께 실행이 멈추고 아무것도 다운로드되지 않습니다. 앞 단계의 결과는 따로 저장되지 않습니다.

더 좋은 결과를 위한 팁

  • 다른 곳에서 말썽을 부린 파일이라면 복구를 첫 단계로 두세요. 이후 모든 단계가 깔끔하게 재구성된 문서를 받습니다.
  • 도장류는 순서가 중요합니다. 페이지 번호와 워터마크는 A4로 크기 변경과 여백 자르기 뒤에 두세요. 그렇지 않으면 뒤 단계에서 도장이 줄어들거나 잘릴 수 있습니다.
  • 평면화는 압축 앞에 두세요. 압축이 어차피 페이지를 이미지로 바꾸지만, 먼저 평면화해야 입력한 양식 값이 그 이미지에 확실히 보입니다.
  • 새 워크플로우는 200페이지 문서에 돌리기 전에 짧은 파일로 시험하세요. 두세 페이지면 도장이 예상한 위치에 찍히는지, 압축 후 화질이 괜찮은지 충분히 알 수 있습니다.
  • 90° 회전을 두 번 넣으면 180° 회전이 되고, 세 번 넣으면 시계 반대 방향 90°가 됩니다.

예시: 법무팀의 상대방 제출용 사본 준비

법무팀 직원이 서명된 계약서 묶음을 상대방에게 보내야 합니다. 모든 파일은 A4여야 하고, 페이지 번호가 있어야 하며, 대외비 표시를 하고, 내부 검토 댓글을 지우고, 이메일로 보낼 수 있을 만큼 작아야 합니다. 파일이 아홉 개라서 파일마다 도구 네 개를 손으로 돌리면 36번을 실행해야 합니다.

워크플로우는 1 주석 제거, 2 A4로 크기 변경, 3 워터마크, 4 페이지 번호, 5 압축 순서로 만듭니다. 댓글을 먼저 지워야 나중에 이미지에 박혀 버리지 않고, 크기 변경을 도장보다 앞에 둬야 도장이 A4 기준 위치에 찍히며, 압축은 각 페이지를 그림으로 바꾸므로 맨 마지막에 둡니다. 계약서마다 한 번씩 놓으면 supply-agreement-workflow.pdf 같은 파일이 나옵니다. 아홉 개 파일이 다 합쳐 몇 분이면 끝나고, 시간 대부분은 모든 페이지를 렌더링하는 압축 단계에 쓰입니다.

주의할 점이 하나 있습니다. 압축이 연결되어 있어서 보내는 사본은 더 이상 텍스트 검색이 되지 않습니다. 쉽게 편집되면 안 되는 사본이라면 오히려 적합하지만, 상대방이 검색해야 한다면 5단계를 빼고 이메일로 보내기에 너무 큰 파일만 따로 압축하세요.

문제 해결

'먼저 단계를 하나 이상 추가하세요'라고 나와요
단계 목록이 비어 있습니다. PDF를 놓기 전에 '단계 추가…' 목록에서 도구를 고르고 추가를 누르세요.
워터마크나 페이지 번호가 엉뚱한 곳에 있어요
뒤쪽 단계가 페이지 형태를 바꿨습니다. ↑ 버튼으로 A4로 크기 변경, 여백 자르기, 회전을 워터마크와 페이지 번호보다 위로 옮기고 다시 실행하세요.
텍스트를 더 이상 선택할 수 없어요
압축, 흑백, 뒤집기 중 하나가 연결되어 있습니다. 이 단계들은 이미지로만 된 페이지를 만듭니다. 빼거나, 맨 뒤로 옮기고 결과가 이미지 페이지인 것을 감수하세요.
한 단계에서 오류와 함께 멈춰요
그 시점에서 해당 도구가 파일을 처리하지 못한 것으로, 대개 비밀번호가 걸렸거나 손상된 경우입니다. 복구를 1단계로 넣거나 먼저 파일을 고친 뒤 다시 실행하세요. 상태 표시에 실패한 단계가 나오므로 어떤 도구를 따로 시험해 봐야 할지 알 수 있습니다.
단계가 사라졌어요
목록은 페이지가 열려 있는 동안만 존재합니다. 다시 만드시고, 반복해서 쓰는 워크플로우는 순서를 짧게 적어 두세요.
다른 워터마크 문구나 회전이 필요해요
워크플로우는 항상 기본 설정을 씁니다. 워터마크나 PDF 회전 도구를 원하는 설정으로 따로 실행한 뒤, 나머지 단계에 워크플로우를 쓰세요.

자주 묻는 질문

단계별 설정을 바꿀 수 있나요?

아니요. 각 단계는 해당 도구의 기본 설정으로 실행됩니다. 옵션을 바꾸려면 개별 도구를 쓰세요.

PDF 여러 개에 한 번에 워크플로우를 돌릴 수 있나요?

한 번의 실행으로는 안 됩니다. 한 번에 파일 하나씩 처리하지만 단계 목록이 그대로 남아 있어 다음 파일을 바로 놓을 수 있습니다.

워크플로우를 저장해 두었다가 쓸 수 있나요?

현재는 안 됩니다. 단계는 페이지가 열려 있는 동안만 유지됩니다.

왜 일부 도구만 단계로 쓸 수 있나요?

단계가 되려면 PDF 하나를 받아 PDF 하나를 돌려줘야 합니다. 여러 파일이 필요하거나, ZIP을 만들거나, 이미지나 텍스트를 내보내거나, 서버 변환이 필요한 도구는 연결할 수 없습니다.

파일이 서버에서 처리되나요?

아닙니다. 연결 가능한 12개 도구는 모두 브라우저 탭 안에서 실행되며, PDF는 메모리 안에서 단계에서 단계로 넘겨지고 최종 결과만 다운로드됩니다.

같은 도구를 두 번 넣으면 어떻게 되나요?

두 번 실행됩니다. 회전 단계 두 개는 페이지를 180° 돌리고, 압축 단계 두 개는 보통 용량은 거의 더 줄지 않고 화질만 더 떨어집니다.

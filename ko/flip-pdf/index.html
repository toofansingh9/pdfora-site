PDF 뒤집기

PDF의 모든 페이지를 좌우 또는 상하로 거울 반전합니다. 열전사지, 뒷면 조명용 인쇄물, 좌우가 뒤집혀 스캔된 문서에 씁니다.

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

뒤집기는 회전과 다릅니다. 회전은 페이지를 중심축으로 돌리는 것이고, 뒤집기는 거울에 비친 모습을 만들어 글자가 거꾸로 읽히게 합니다. 쓸모없어 보이지만 필요할 때가 있습니다. 티셔츠용 열전사지, 투명 필름 뒷면에 인쇄하는 유리창 시트지, 유리 너머로 읽는 안내판, 그리고 가끔 휴대폰 전면 카메라 때문에 좌우가 뒤집혀 찍힌 스캔본이나 사진이 그렇습니다. 반대로 잘못 고르기 쉬운 도구이기도 합니다. 페이지가 옆으로 눕거나 위아래가 뒤집혀 보일 뿐이라면 필요한 건 회전이며, 회전은 글자를 온전하고 읽을 수 있게 유지합니다. 뒤집기는 최종 결과물이 정말로 거울상이어야 할 때만 쓰고, 열전사지나 필름처럼 다시 쓸 수 없는 재료에 인쇄하기 전에는 일반 종이로 시험 인쇄해 방향을 확인하세요.

PDFora의 PDF 뒤집기 도구는 두 방향을 지원합니다. 가로는 페이지를 좌우로 반전하며, 전사용으로 흔히 쓰는 방식입니다. 세로는 위아래로 반전하는데, 이는 페이지를 거꾸로 돌리는 것과 다릅니다. 글자가 위아래로 뒤집히는 동시에 좌우로도 반전됩니다. 두 옵션 모두 페이지 틀 자체는 회전시키지 않습니다. 세로 페이지는 세로 그대로이고, 반전된 내용은 이전과 똑같은 영역을 차지하므로 왼쪽에 있던 여백이 이제 오른쪽에 옵니다.

이를 위해 각 페이지를 PDF.js로 기본 배율의 두 배 크기 캔버스에 그린 뒤 반전하고, 품질 0.9의 JPEG 이미지로 저장해 원래 크기의 페이지에 넣습니다. 그래서 결과 파일 yourfile-flipped.pdf에는 텍스트가 아니라 페이지를 찍은 그림이 들어 있습니다. 모든 과정은 브라우저에서 이뤄집니다. 이미지로 바꾸는 것은 모든 종류의 내용을 일관되게 반전하기 위한 대가입니다. 텍스트, 벡터 그림, 삽입된 사진, 양식 모양이 모두 함께 반전되어 엉뚱한 방향으로 남는 요소가 없습니다. 전사지나 시트지에는 바로 원하는 결과지만, 계속 검색하거나 편집해야 하는 문서에는 아닙니다. 그러니 뒤집은 사본은 인쇄용 파일로 쓰고, 원본은 작업용으로 보관하세요.

PDF를 뒤집거나 거울 반전하는 방법

  1. PDF 뒤집기를 열고 PDF 하나를 선택합니다.
  2. 방향을 고릅니다. 기본값은 가로(거울 반전)이며, 세로는 위아래로 반전합니다.
  3. 페이지 뒤집기를 누릅니다. 페이지마다 렌더링되는 동안 진행 표시줄이 움직입니다.
  4. 뒤집힌 파일을 다운로드해 첫 페이지를 확인합니다. 글자가 거꾸로 읽혀야 합니다.
  5. 비싼 전사지나 필름을 쓰기 전에 일반 종이에 한 장 시험 인쇄합니다.

이 도구가 필요한 경우

  • 천에 붙였을 때 바르게 읽히도록 반전해서 인쇄해야 하는 다림질용 열전사지에 디자인을 인쇄할 때.
  • 투명 필름 뒷면에 인쇄해 앞에서 읽는 유리창·유리문 안내 시트를 만들 때.
  • 좌우가 뒤집혀 나온 문서 스캔본이나 휴대폰 촬영본을 바로잡을 때.
  • 실크스크린처럼 반전된 이미지가 필요한 인쇄 작업용 원고를 준비할 때.
  • 수업 활동용 거울 글씨 학습지나 퍼즐을 만들 때.
  • 재료 뒷면에서 재단하는 공예 도안을 위해 반전된 패턴을 만들 때.

시작하기 전에 알아둘 점

  • 모든 페이지가 뒤집힙니다. 페이지 선택 기능은 없으니 필요한 페이지를 먼저 떼어 내세요. 빼 둔 페이지는 나중에 뒤집지 않은 상태로 다시 병합하면 됩니다.
  • 결과는 이미지 기반입니다. 텍스트를 선택, 복사, 검색할 수 없고 링크, 책갈피, 양식 필드도 사라집니다.
  • 페이지는 PDF 기본 배율의 두 배로 렌더링되며, 대략 144dpi에 해당합니다. 대부분의 전사지와 안내판에는 충분하지만 작은 글씨와 가는 선은 원본보다 부드러워집니다. 크게 확대하거나 커팅 플로터로 자를 원고라면 원본 디자인 파일에서 반전하세요.
  • 페이지마다 JPEG가 되기 때문에, 대부분 텍스트였던 문서는 파일이 꽤 커질 수 있고 아주 세밀한 부분에는 약간의 압축 흔적이 보일 수 있습니다.
  • 페이지 크기는 유지됩니다. 결과의 각 페이지는 원래 페이지와 크기가 같습니다.
  • 뒤집은 파일을 같은 방향으로 한 번 더 뒤집으면 다시 읽을 수 있는 페이지가 되지만, 2세대 이미지라 화질이 조금 떨어집니다. 원본을 보관하세요.

더 좋은 결과를 위한 팁

  • 프린터 드라이버에 '거울 이미지'나 '전사' 옵션이 있는 경우가 많습니다. 드라이버 옵션과 이 도구 중 하나만 쓰세요. 둘 다 쓰면 두 번 반전됩니다. 인쇄소나 프린터 쪽에서 어느 것을 적용할지 모르겠다면 파일을 보내기 전에 물어보세요.
  • 페이지를 위아래로 뒤집기만 하고 싶다면 세로 뒤집기 대신 PDF 회전에서 180도를 쓰세요.
  • 전사용 디자인은 여백을 넉넉히 둔 페이지에 배치하세요. 가정용 프린터는 가장자리에서 몇 밀리미터 안쪽까지만 인쇄됩니다.
  • 편집과 나중의 재인쇄를 위해 뒤집지 않은 원본을 보관하세요.
  • 뒤집은 파일이 크다면 PDF 압축으로 보통 더 줄일 수 있지만, 선명도는 어느 정도 떨어집니다.

실제 예시: 운동회용 반 티셔츠

초등학교 교사 서지원 씨에게 열전사지용으로 받은 한 페이지짜리 PDF가 있습니다. 팀 로고와 '청팀 2026'이라는 글자가 들어 있습니다. 그대로 인쇄하면 티셔츠에 다림질했을 때 글자가 거꾸로 읽힙니다. 프린터 드라이버에는 반전 옵션이 없고, 로고는 학부모 자원봉사자가 PDF로만 보내 줘서 원본 디자인을 고치기도 어렵습니다.

서지원 씨는 PDF를 가로로 뒤집은 뒤 먼저 일반 종이에 인쇄합니다. 시험 인쇄한 종이를 창문에 대고 뒷면에서 보니 글자가 바르게 읽혀 방향이 맞다는 걸 확인합니다. 그런 다음 프린터 자체의 반전 옵션은 끈 채로 전사지에 인쇄합니다.

페이지를 이미지로 렌더링했기 때문에 로고의 가는 윤곽선이 원래 벡터 파일보다 약간 부드럽지만, 티셔츠 크기에서는 눈에 띄지 않습니다.

팀 색깔 디자인을 네 가지 색상의 티셔츠에 찍어야 했기 때문에, 서지원 씨는 매번 디자인을 다시 반전하는 대신 뒤집은 PDF를 기준 인쇄 파일로 두고 묶음마다 그 파일로 다시 인쇄했습니다. 한 번 확인한 파일 하나 덕분에 두 번째 시험 인쇄를 할 필요가 없었습니다.

문제 해결

뒤집은 뒤에도 글자가 바르게 읽힙니다
프린터나 뷰어가 한 번 더 반전하고 있을 수 있습니다. 인쇄 대화상자에서 거울 이미지나 전사 옵션을 끄세요.
거울 반전이 아니라 위아래만 뒤집고 싶었습니다
PDF 회전에서 180도를 고르세요. 세로 뒤집기는 글자까지 반전합니다.
결과에서 텍스트를 선택할 수 없습니다
이 도구는 원래 페이지를 이미지로 바꿉니다. 텍스트가 필요한 용도에는 원본을 쓰세요.
결과 파일이 원본보다 훨씬 큽니다
페이지마다 JPEG 이미지로 저장되기 때문입니다. 결과를 PDF 압축에 넣거나, 필요한 페이지만 뒤집으세요.
작은 글씨가 흐릿해 보입니다
약 144dpi로 렌더링되기 때문입니다. 뒤집기 전에 원본에서 디자인을 키우거나, 원래의 벡터 내용을 그대로 다루는 프린터 드라이버의 반전 기능을 쓰세요.
긴 문서에서 탭이 느려집니다
모든 페이지를 메모리에서 렌더링합니다. 문서를 나눠 더 작은 단위로 뒤집으세요.

자주 묻는 질문

뒤집기와 회전은 무엇이 다른가요?

회전은 페이지를 중심축으로 돌리며 글자는 그대로 정상적으로 읽힙니다. 뒤집기는 거울상을 만들어 글자가 거꾸로 읽힙니다.

한 페이지만 뒤집을 수 있나요?

이 도구 안에서는 안 됩니다. 그 페이지를 추출해 뒤집은 뒤 문서에 다시 병합하세요.

뒤집은 PDF에서 텍스트가 사라지는 이유는 무엇인가요?

반전은 각 페이지를 렌더링한 그림에 적용되므로, 결과에는 텍스트 객체가 아니라 이미지가 들어갑니다.

뒤집은 페이지의 해상도는 얼마인가요?

PDF 기본 배율의 두 배, 대략 144dpi로 렌더링되어 품질 0.9의 JPEG로 저장됩니다.

가로와 세로를 모두 뒤집을 수 있나요?

방향마다 한 번씩, 도구를 두 번 실행하세요. 결과는 180도 회전과 같으며, PDF 회전은 이미지로 바꾸지 않고 같은 결과를 냅니다.

파일이 업로드되나요?

아니요. 렌더링과 반전은 브라우저 탭 안에서 이뤄지고, PDF는 기기에 그대로 남습니다.

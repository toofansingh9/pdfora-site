반으로 나누기

클릭 한 번으로 PDF를 가운데 페이지에서 두 파일로 나눕니다. 페이지 수가 홀수면 남는 한 페이지는 앞쪽 파일에 들어갑니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.
1

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

문서를 어디서 잘라야 할지 딱히 기준이 없을 때가 있습니다. 첨부 파일 하나나 업로드 칸 하나, 검토자 한 명에게 맡기기엔 너무 크고, 두 덩어리면 충분한 경우입니다. 반으로 나누기는 바로 그런 상황을 위한 도구입니다. 설정할 옵션이 없습니다. PDF를 넣으면 가운데를 찾아 파일 두 개로 돌려줍니다.

계산 방식은 정해져 있습니다. 페이지 수를 2로 나누고 올림한 만큼의 페이지가 첫 번째 파일에 들어갑니다. 20페이지 문서는 10과 10, 21페이지 문서는 11과 10이 됩니다. 페이지는 pdf-lib로 그대로 복사되므로 텍스트 검색이 계속 되고 이미지 해상도도 유지됩니다. 다시 샘플링하거나 래스터화하는 부분은 없습니다.

두 결과 파일에는 원래 이름에 -part1, -part2가 붙습니다. thesis.pdf는 thesis-part1.pdf와 thesis-part2.pdf가 되어 thesis-halves.zip에 함께 담깁니다. 파일 크기가 아니라 페이지 수로 나누기 때문에 두 파일의 용량이 같다는 보장은 없습니다. 사진이 한쪽에 몰려 있으면 그쪽이 무거워집니다. 시작하기 전에 정확히 어디서 잘릴지 알고 싶다면, 뷰어에 표시된 페이지 수에 홀수면 1을 더하고 2로 나누세요. 그 페이지가 part1의 마지막 페이지입니다.

PDF를 반으로 나누는 방법

  1. 반으로 나누기 도구를 열고 PDF를 추가합니다. 한 번에 파일 하나만 받습니다.
  2. 설정할 것은 없습니다. 올바른 문서를 넣었는지만 확인하세요.
  3. 반으로 나누기를 누릅니다.
  4. zip 파일을 받거나, 파일 목록에서 두 파일을 따로 받습니다.
  5. part1의 마지막 페이지와 part2의 첫 페이지를 열어 어디서 나뉘었는지 확인합니다. 페이지 수가 홀수면 part1이 한 페이지 더 깁니다.

이 도구가 필요한 경우

  • 용량 제한을 살짝 넘는 이메일 첨부를 메일 두 통으로 나눠 보내도 괜찮을 때.
  • 긴 읽기 자료를 스터디 파트너 두 명이나 채점을 맡은 조교 두 명에게 나눠 줄 때.
  • 용량 제한이 있는 첨부 칸이 두 개 있는 업로드 양식.
  • 검토자가 오늘은 앞부분을, 내일은 나머지를 볼 수 있도록 초안을 두 번에 나눠 공유할 때.
  • 회의 전에 시간을 아끼려고 두꺼운 자료집을 프린터 두 대로 동시에 인쇄할 때.
  • 문제 찾기: 깨진 PDF의 문제가 앞쪽 절반에 있는지 뒤쪽 절반에 있는지 빠르게 확인할 때. 문제가 있는 쪽을 다시 나누면 범위가 좁혀집니다.

시작하기 전에 알아둘 점

  • 항상 페이지 수 기준 가운데에서 자릅니다. 장이 바뀌는 곳에서 끊어야 한다면 PDF 분할의 사용자 지정 범위, 책갈피별 분할, 텍스트별 분할을 쓰세요. 반으로 나누기는 내용을 전혀 보지 않으며, 제목이나 빈 페이지를 찾지도 않습니다.
  • 페이지 수가 홀수면 앞쪽 파일이 한 페이지를 더 가져갑니다.
  • 한 페이지짜리 PDF는 반으로 나눌 수 없습니다. 그 페이지가 든 part1 파일 하나만 나오고 part2는 없습니다.
  • 페이지 수와 파일 크기는 다릅니다. 앞 10페이지가 스캔이고 뒤 10페이지가 일반 텍스트인 문서는 9 MB짜리 절반과 200 KB짜리 절반이 될 수 있습니다. 용량 제한이 목적이라면 크기별 분할을 쓰세요.
  • 책갈피 목차는 어느 쪽에도 복사되지 않고, 한쪽에서 다른 쪽 페이지로 이동하던 링크는 작동하지 않습니다.
  • 양쪽에서 함께 쓰는 글꼴과 이미지는 두 파일 모두에 저장되므로 part1과 part2를 합치면 원본보다 조금 클 수 있습니다. 텍스트 위주 문서라면 늘어나는 부분은 포함된 글꼴이고, 보통 파일당 수십~수백 KB 정도입니다.

더 좋은 결과를 위한 팁

  • 메일 용량 때문에 나눈다면 먼저 파일 크기와 한도를 비교하세요. 한도의 두 배가 넘으면 반으로 나눠도 여전히 너무 큽니다. 먼저 압축하거나 크기별 분할을 쓰세요. 두 파일 모두 한도 아래가 목표이고, 한쪽만 한도 아래라면 나눈 의미가 없습니다.
  • 보내기 전에 application-pages-1-12.pdf처럼 알아보기 쉽게 이름을 바꾸세요. 받는 사람이 열지 않고도 범위를 알 수 있습니다.
  • 한 장(章)이 가운데에 걸쳐 있다면 1-14, 15-26처럼 PDF 분할의 범위를 써서 장 사이에서 끊는 것을 고려하세요.
  • 손상된 페이지를 찾을 때는 반으로 나누기를 반복하세요. 나누고, 각각 확인하고, 문제 있는 쪽을 다시 나눕니다. 매번 확인할 페이지가 절반으로 줄어서 500페이지 파일도 약 아홉 번이면 한 페이지로 좁혀집니다.
  • 원본은 남겨 두세요. PDF 병합으로 다시 합칠 수는 있지만 굳이 필요 없는 단계가 하나 늘어납니다.

예시: 첨부 칸이 두 개인 지원사업 결과보고서

작은 비영리단체가 지원 재단에 연간 결과보고서를 제출합니다. 재단 사이트에는 '보고서 A'와 '보고서 B' 두 개의 첨부 칸이 있고, 각각 8 MB 제한입니다. 최종 보고서는 46페이지, 12 MB인데 보고서를 디자인한 담당자는 이미 퇴근했습니다.

반으로 나누기를 실행하면 1~23페이지가 든 annual-report-part1.pdf와 24~46페이지가 든 annual-report-part2.pdf가 나옵니다. 담당자는 올리기 전에 크기를 확인합니다. part1은 사진이 많은 사업 사례가 들어 있어 7.1 MB, part2는 대부분 재무 표라 4.9 MB입니다. 둘 다 들어갑니다. part1이 9 MB였다면 다시 나눌 필요 없이 그쪽만 압축하면 됐을 겁니다.

23페이지가 마침 사업 내용 섹션 중간이었는데, 재단에서 문제 삼지는 않겠지만 제출 메시지에 'B 파일은 24페이지부터 이어집니다'라고 한 줄 적어 두면 읽는 사람이 헷갈리지 않습니다. 나중에 재단이 파일 하나로 달라고 해도 이 두 파일이면 됩니다. PDF 병합으로 part1과 part2를 원래 순서대로 다시 합치면 페이지는 하나도 바뀌지 않습니다.

문제 해결

파일이 하나만 나왔어요
PDF가 한 페이지짜리라 두 번째 파일에 넣을 것이 없습니다. 뷰어에서 페이지 수를 확인하세요.
한쪽이 여전히 너무 커서 보낼 수 없어요
반으로 나누기는 메가바이트가 아니라 페이지 기준입니다. 큰 쪽을 압축하거나, 크기별 분할로 필요한 한도를 설정하세요.
섹션 중간에서 잘렸어요
단순히 반으로 나누면 그렇게 됩니다. PDF 분할의 사용자 지정 범위로 경계를 직접 정하세요.
파일이 열리지 않아요
비밀번호가 걸려 있거나 손상되었을 가능성이 큽니다. 파일을 만든 프로그램에서 보호를 해제하거나 PDF 복구를 실행한 뒤 다시 시도하세요.
두 파일을 합친 크기가 원본보다 커요
자른 곳 양쪽에서 쓰는 글꼴과 이미지가 각 파일에 저장되기 때문입니다. 늘어나는 양은 보통 작으니, 중요하다면 압축하세요.
두 번째 파일이 빈 페이지로 시작해요
원본 문서의 그 위치에 빈 페이지가 있는 것입니다. 인쇄용 레이아웃에서 일부러 넣은 왼쪽 페이지인 경우가 많습니다. 나누기 전이나 후에 페이지 삭제로 지우세요.

자주 묻는 질문

정확히 어디서 잘리나요?

ceil(N/2)페이지 다음입니다. 30페이지면 15페이지 다음, 31페이지면 16페이지 다음입니다.

자르는 위치를 바꿀 수 있나요?

이 도구에서는 안 됩니다. 일부러 옵션을 두지 않았습니다. 원하는 위치에서 자르려면 PDF 분할의 사용자 지정 범위를 쓰세요.

페이지 화질에 영향이 있나요?

없습니다. 페이지를 다시 렌더링하지 않고 복사하므로 텍스트, 벡터, 이미지가 그대로입니다.

결과 파일 이름은 무엇인가요?

원래 이름에 -part1, -part2가 붙고 name-halves.zip으로 묶입니다.

3등분이나 4등분도 할 수 있나요?

PDF 분할의 N페이지마다 방식에서 N을 페이지 수의 3분의 1이나 4분의 1로(올림) 설정하세요. 30페이지 파일을 3등분하려면 N = 10입니다.

책갈피는 유지되나요?

아니요, 목차는 복사되지 않습니다. 필요하면 나중에 책갈피 만들기로 각 파일에 책갈피를 추가하세요.

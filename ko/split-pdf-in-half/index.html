반으로 나누기

클릭 한 번으로 문서를 똑같은 크기의 두 부분으로 나눕니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

어떤 작업에는 선택지가 아니라 버튼 하나만 있으면 됩니다. PDFora의 반으로 나누기 도구는 클릭 한 번으로 PDF를 균등한 두 부분으로 자릅니다. 200페이지 파일은 1~100쪽과 101~200쪽이 되고, 범위를 입력할 필요도 설정을 고를 필요도 없습니다. 페이지 수가 홀수라면 가운데 페이지를 알아서 처리하므로 101페이지 문서도 자연스럽게 절반으로 나뉩니다.

다른 모든 PDFora 도구와 마찬가지로 이 작업도 사용자 컴퓨터의 브라우저가 수행합니다. 문서는 업로드되지 않으므로 실사 자료 묶음이나 임직원 안내서를 반으로 나눈다고 해서 서버를 믿고 맡길 필요가 없습니다. 로컬 처리 덕분에 속도도 빠릅니다. 전송 시간 없이 기기가 새 파일 두 개를 쓰는 1~2초면 끝납니다.

완전히 무료입니다. 가입도, 양쪽 파일의 워터마크도, 사용 횟수 제한도 없습니다. 오늘 한 개를 나누든 내일 쉰 개를 나누든 똑같이 동작합니다.

온라인에서 PDF를 반으로 나누는 방법

  1. getpdfora.com의 반으로 나누기 도구를 엽니다. 계정은 필요 없습니다.
  2. 클릭해서 파일을 찾거나 끌어다 놓아 PDF를 추가합니다.
  3. 올바른 문서인지 확인합니다. 불러온 파일이 화면에 표시됩니다.
  4. 나누기 버튼을 누릅니다. 설정은 그것으로 끝입니다.
  5. 브라우저가 문서를 중간 지점에서 두 개의 PDF로 나눕니다.
  6. 두 파일을 모두 내려받고 원하면 part-1, part-2처럼 이름을 바꿉니다.

When to use this tool

  • 보고서를 두 부분으로 나눠 보내 이메일 첨부 용량 제한 통과하기
  • 각 저작이 파일의 대략 절반씩 차지하는, 두 권을 함께 스캔한 자료 나누기
  • 긴 교육 매뉴얼을 두 차수로 나눠 참가자에게 그 주에 필요한 절반만 주기
  • 교정 작업을 가운데에서 나눠 검토자 두 명이 동시에 진행하게 하기
  • 사무실 프린터 대기열이 거대한 작업 하나로 막히지 않도록 대량 인쇄물을 둘로 나누기
  • 웹 포털이나 학습관리시스템이 통째로는 받아 주지 않는 대용량 PDF 반으로 줄이기

Tips for the best results

  • 먼저 전체 페이지 수를 확인해 어디가 잘릴지 가늠하세요. 61페이지 파일의 중간 지점은 장 한가운데일 수 있습니다.
  • 자연스러운 분기점이 중간이 아니라면 일반 분할 도구에서 범위를 직접 지정하세요. 이 도구는 정밀함이 아니라 속도를 위해 만들어졌습니다.
  • 반으로 나누기는 용량 제한을 넘기는 빠른 해법이지만, 스캔 이미지 때문에 파일이 부풀었다면 압축만으로 분할 자체를 피할 수도 있습니다.
  • 내려받은 파일의 이름은 바로 바꾸세요. 이름이 거의 똑같은 파일 두 개는 금세 헷갈립니다.
  • 나눈 절반을 다시 이 도구에 넣으면 클릭 두 번으로 문서를 4등분할 수 있습니다.

자주 묻는 질문

PDF 페이지 수가 홀수면 어떻게 되나요?

그래도 깔끔하게 나뉩니다. 한쪽이 한 페이지를 더 가져갈 뿐입니다. 예를 들어 25페이지 파일은 13페이지와 12페이지 두 개가 됩니다.

어디에서 잘릴지 직접 정할 수 있나요?

이 도구로는 안 됩니다. 항상 중간 지점에서 자르기 때문에 클릭 한 번으로 끝나는 것이죠. 특정 페이지에서 나눠야 한다면 PDFora의 기본 분할 도구가 1-40, 41-90 같은 범위 지정을 받습니다.

나뉜 두 파일 모두 원래 품질을 유지하나요?

네. 페이지가 그대로 옮겨지므로 양쪽 파일의 텍스트, 이미지, 서식이 원본 문서와 동일합니다.

나누는 동안 파일이 어딘가로 업로드되나요?

아니요. 분할이 브라우저 안에서 로컬로 이뤄지며, 원본도 나뉜 두 파일도 기기를 떠나지 않습니다. 기밀 문서를 여기서 다루는 것은 자기 책상 위에서 다루는 것만큼 안전합니다.

정말 무료인가요, 숨은 조건은 없나요?

정말 무료입니다. 가입도, 워터마크도, 페이지 제한도 없고 나눌 수 있는 파일 수에도 제한이 없습니다. 사용자 기기의 연산 능력으로 실행되기 때문에 넘길 서버 비용 자체가 없습니다.

얼마나 큰 PDF까지 반으로 나눌 수 있나요?

정해 둔 상한은 없습니다. 브라우저가 작업을 처리하므로 아주 큰 파일도 기기 메모리에만 제한을 받습니다. 천 페이지짜리 문서도 요즘 컴퓨터라면 대부분 무리 없이 나뉘지만, 오래된 휴대폰에서는 더 오래 걸릴 수 있습니다.

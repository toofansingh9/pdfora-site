PDF 복구

다른 프로그램에서 제대로 열리지 않는 PDF를 다시 읽어 들여, 파일 구조를 깔끔하게 새로 짜서 저장합니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

설정

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

PDF는 내용이 한 줄로 이어진 파일이 아닙니다. 번호가 붙은 여러 객체와, 각 객체가 어디서 시작하는지 알려 주는 상호 참조 표(cross-reference table)로 이루어져 있습니다. 다운로드가 중간에 끊기거나, 프로그램이 이 표를 잘못 쓰거나, 여러 도구로 연달아 편집하다 보면 표가 엉뚱한 위치를 가리키게 됩니다. 어떤 뷰어는 아무렇지 않게 넘어가지만 어떤 뷰어는 빈 페이지를 보여 주고, 업로드 사이트는 애매한 오류와 함께 파일을 거부하곤 합니다. PDF 복구는 바로 이 중간 지대, 즉 구조는 엉망이지만 내용은 아직 남아 있는 파일을 위한 도구입니다.

도구가 하는 일은 분명합니다. pdf-lib 라이브러리로 파일을 불러오는데, 이 라이브러리는 깨진 표를 그대로 믿지 않고 찾을 수 있는 객체를 읽어 구조를 스스로 파악합니다. 그런 다음 새 사본을 저장합니다. 새 파일에는 상호 참조 표가 새로 쓰이고, 모든 객체가 압축된 객체 스트림에 묶이지 않고 하나씩 따로 기록됩니다. 이렇게 오래된 방식의 배치는 까다롭거나 오래된 뷰어도 더 잘 받아들입니다. 페이지 내용은 다시 렌더링하지 않고 복사하므로 텍스트, 글꼴, 이미지가 원래 그대로 유지됩니다.

한계도 솔직하게 말씀드립니다. 이것은 재구성이지 데이터 복원이 아닙니다. 중간에 끊긴 다운로드의 뒷부분처럼 바이트가 실제로 없다면 그 페이지를 다시 만들어 낼 재료가 없고, 어떤 도구도 이를 지어낼 수 없습니다. 이럴 때는 원래 출처에서 파일을 새로 받는 것이 정답입니다.

PDF 파일을 복구하는 방법

  1. PDF 복구 도구를 열고 문제가 있는 파일을 추가합니다. 한 번에 파일 하나만 처리합니다.
  2. 복구 및 재구성을 누릅니다. 파일을 분석해 다시 저장하며, 대부분의 문서는 1~2초면 끝납니다.
  3. 오류가 표시되면 파일을 전혀 분석할 수 없었다는 뜻입니다. 아래 문제 해결 항목을 참고하세요.
  4. 결과를 다운로드합니다. 원래 이름 뒤에 -repaired가 붙어 저장됩니다. 예: contract-repaired.pdf.
  5. 이전에 실패했던 뷰어나 업로드 사이트에서 복구된 사본을 열고, 모든 페이지에 내용이 있는지 넘겨 가며 확인합니다.

이 도구가 필요한 경우

  • 내 노트북에서는 잘 열리는 학위논문 PDF를 대학 제출 시스템이 유효하지 않은 파일이라며 거부할 때.
  • 오래된 스캐너나 회계 프로그램에서 내보낸 파일이 한 뷰어에서는 열리고 다른 뷰어에서는 빈 페이지로 나올 때.
  • 여러 프로그램으로 수없이 편집한 PDF가 느려졌거나 열 때마다 손상되었다는 경고가 뜰 때.
  • 일반 뷰어보다 검사가 엄격한 인쇄소나 전자 제출 시스템에 보낼 파일을 준비할 때.
  • PDF 병합이나 PDF 분할 도구가 원본을 불러오지 못할 때, 먼저 문서를 정리해 두는 용도로.
  • 보낸 사람에게 다시 내보내 달라고 부탁하기 전에 파일 구조를 읽을 수 있는지 빠르게 확인할 때.

시작하기 전에 알아둘 점

  • 복구는 구조를 다시 짤 뿐 잃어버린 내용을 되살리지 않습니다. 중간에 끊긴 파일은 잘해야 온전했던 페이지까지만 돌아옵니다.
  • 결과물은 압축된 객체 스트림 없이 저장됩니다. 그래서 호환성은 좋아지지만 입력보다 조금 커지는 경우가 많고, 객체 스트림을 많이 쓴 파일이라면 10~30% 정도 커지기도 합니다.
  • 페이지는 있는 그대로 복사됩니다. 페이지 자체의 콘텐츠 스트림이 손상되어 이상하게 보였다면 재구성 후에도 이상하게 보일 수 있습니다.
  • 파일을 열 때 암호화 검사는 꺼져 있습니다. 비밀번호가 걸린 PDF도 불러올 수는 있지만 내용은 여전히 암호화되어 있어 저장된 사본이 제대로 보이지 않을 가능성이 큽니다. 먼저 원본에서 비밀번호를 해제하세요.
  • 페이지만이 아니라 문서 전체를 저장하므로 pdf-lib가 읽을 수 있는 양식, 책갈피, 주석은 새 파일에도 그대로 옮겨집니다.
  • 작업이 브라우저 안에서 이루어지므로, 온라인 복구 서비스에 보내기 꺼려지는 파일도 여기서는 시도해 볼 수 있습니다.

더 좋은 결과를 위한 팁

  • 결과를 페이지별로 확인하기 전까지는 복구된 사본 옆에 원본을 꼭 남겨 두세요.
  • 복구된 파일의 페이지 수를 예상했던 수와 비교하세요. 페이지가 적다면 원본이 중간에 잘렸다는 가장 확실한 신호입니다.
  • 복구한 파일도 업로드 사이트가 거부한다면 뷰어에서 PDF로 인쇄해 보세요. 모든 페이지를 다시 렌더링하므로 재구성으로는 고칠 수 없는 페이지 내부 문제가 해결됩니다.
  • 이메일로 받거나 다운로드한 파일이라면 복구에 시간을 쓰기 전에 다시 받아 보세요. 깨끗한 사본이 어떤 복구보다 낫습니다.
  • 복구에 성공했는데 크기가 커졌고 주로 스캔 문서라면 PDF 압축을 이어서 실행하세요.

예시: 프리랜서의 1년 치 청구서 묶음

프리랜서 번역가가 종합소득세 신고를 위해 오래된 청구서 프로그램에서 열두 달 치 청구서를 PDF 하나로 내보냈습니다. 파일은 브라우저 기본 뷰어에서는 열리지만, 세무 신고 사이트의 업로드 양식은 유효하지 않은 문서라며 거부하고, PDF 병합 도구도 이 파일을 나머지 서류와 합치지 못합니다.

PDF 복구에 넣자 파일이 불러와지고, 상호 참조 표가 새로 쓰이며, 객체 스트림 없이 저장됩니다. 업로드 양식은 복구된 사본을 받아들이고 PDF 병합 도구도 이제 파일을 읽습니다. 파일 크기는 410 KB에서 약 460 KB로 늘었는데, 보수적인 배치 방식의 대가이고 이 경우에는 문제가 되지 않습니다.

제출하기 전에 번역가는 페이지 수를 셉니다. 청구서 열두 장, 페이지 열두 장입니다. 만약 아홉 장이었다면 처음 내보낸 파일 자체가 불완전했다는 뜻이고, 유일한 해결책은 청구서 프로그램에서 다시 내보내는 것이었을 겁니다.

문제 해결

오류만 나오고 아무것도 생성되지 않아요
파일을 전혀 분석하지 못했습니다. 보통 실제로는 PDF가 아니거나(예: .pdf 이름으로 저장된 HTML 오류 페이지) 심하게 잘린 경우입니다. 텍스트 편집기로 열어 보세요. 진짜 PDF는 %PDF로 시작합니다. 아니라면 파일을 새로 받으세요.
복구된 파일에서 일부 페이지가 빠졌어요
그 페이지들은 원본에 읽을 수 있는 형태로 존재하지 않았습니다. 대개 다운로드가 중간에 끊긴 경우입니다. 문서를 다시 다운로드하거나 내보내세요.
페이지가 여전히 비어 있거나 깨져 보여요
페이지 내용 자체가 손상된 것이고, 구조 재구성은 이 부분을 건드리지 않습니다. 원본을 가장 잘 보여 주는 뷰어에서 PDF로 인쇄하거나, 보낸 사람에게 새로 내보내 달라고 하세요.
복구된 파일이 원본보다 커요
객체를 압축된 객체 스트림에 넣지 않고 하나씩 기록하기 때문입니다. 호환성을 위한 의도된 동작이니 크기가 중요하다면 결과를 압축하세요.
복구된 사본의 내용이 알아볼 수 없게 나와요
원본이 암호화되어 있었을 가능성이 큽니다. 불러올 때 암호화를 무시하므로 내용이 뒤섞인 채 남습니다. 파일을 만든 프로그램에서 비밀번호를 해제하고 그 사본을 복구하세요.
업로드 사이트가 여전히 파일을 거부해요
구조가 아니라 파일 크기, 페이지 크기, 포함된 글꼴 같은 다른 부분이 문제일 수 있습니다. 사이트의 요구 사항을 확인하고 그에 맞게 크기 조정, 압축, PDF로 인쇄를 해 보세요.

자주 묻는 질문

PDF 복구는 정확히 무엇을 바꾸나요?

문서의 객체를 다시 읽고, 상호 참조 표를 새로 쓰고, 모든 객체를 객체 스트림 없이 하나씩 저장합니다. 페이지 내용은 바뀌지 않고 복사됩니다.

어디서도 열리지 않는 PDF도 살릴 수 있나요?

경우에 따라 다릅니다. 객체는 멀쩡하고 구조만 깨졌다면 가능합니다. 데이터 자체가 없거나 PDF가 아닌 파일이라면 어떤 복구 도구로도 되살릴 수 없습니다.

복구하면 화질이 떨어지나요?

아닙니다. 다시 렌더링하거나 재압축하지 않으므로 텍스트와 이미지는 원래 모습 그대로입니다.

파일 크기가 왜 커졌나요?

결과물에 압축된 객체 스트림을 쓰지 않기 때문입니다. 조금 커지는 대신 오래되거나 까다로운 프로그램에서도 읽을 수 있습니다.

복구하면 비밀번호가 풀리나요?

아닙니다. 아무것도 복호화하지 않으며, 암호화된 파일은 재구성 후 대개 제대로 표시되지 않습니다. 알고 있는 비밀번호를 없애려면 PDF 잠금 해제를 쓰세요.

여러 파일을 한꺼번에 복구할 수 있나요?

한 번에 파일 하나씩 처리합니다. 일반 문서는 금방 끝나니 차례대로 처리하세요.

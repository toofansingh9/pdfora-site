PDF를 JPG로

PDF의 각 페이지를 화면용, 표준, 인쇄용 해상도의 개별 JPG 이미지로 바꿉니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

사진을 기대하는 곳에서 PDF는 다루기 불편합니다. 메신저에서는 파일 아이콘으로만 보이고, 슬라이드에는 이미지로 넣을 수 없으며, 많은 웹 양식과 SNS는 JPG나 PNG만 받습니다. 페이지를 JPG로 바꾸면 해결됩니다. 각 페이지가 평범한 사진 같은 이미지가 되어 어떤 휴대폰, 브라우저, 편집기에서든 PDF 리더 없이 열립니다.

도구가 하는 일은 간단하지만 알아 둘 만합니다. PDF.js가 뷰어에서 보이는 그대로 각 페이지를 캔버스에 그리고, 그 캔버스를 품질 0.92의 JPEG로 저장합니다. 품질 메뉴는 압축률이 아니라 픽셀 크기를 정합니다. 화면용은 페이지 포인트 크기의 1.5배(약 108 dpi), 표준은 2배(약 144 dpi), 높음은 3배(약 216 dpi)로 렌더링합니다. 그래서 A4 페이지는 화면용에서 약 893 x 1263픽셀, 표준에서 1191 x 1684, 높음에서 1786 x 2526픽셀이 됩니다.

결과는 평면 그림이므로 페이지를 PDF답게 만들던 것들은 사라집니다. 텍스트를 선택하거나 검색할 수 없고, 링크는 클릭되지 않으며, 양식 필드는 상자 그림일 뿐입니다. JPEG 압축은 흰 바탕의 작은 검은 글씨 같은 날카로운 경계 주변에 희미한 번짐도 남깁니다. 사진과 스캔본에서는 눈에 띄지 않지만, 선 도면, 차트, 코드 화면에는 대개 PNG 변환이 더 낫습니다.

PDF를 JPG 이미지로 변환하는 방법

  1. PDF를 JPG로 도구를 열고 PDF 한 개를 추가합니다. 한 번에 파일 하나만 처리하니 다른 파일은 차례로 변환하세요.
  2. 품질 설정을 고릅니다. 메신저나 메일 미리보기는 화면용(낮음), 대부분의 용도는 표준(기본값), 인쇄하거나 확대해서 볼 이미지는 높음(인쇄용)입니다.
  3. 변환을 누릅니다. 페이지가 한 장씩 렌더링되고 진행 표시줄이 페이지마다 움직이므로 긴 문서는 조금 걸립니다.
  4. 모두 다운로드 (.zip)로 전부 받거나, 개별 파일 버튼을 눌러 한 페이지만 저장합니다. 목록에는 처음 50페이지까지 버튼이 표시됩니다.
  5. 이미지 몇 장을 100% 배율로 열어 작은 글씨도 읽히는지 확인한 뒤 올리거나 보내세요.

이 도구가 필요한 경우

  • 한 장짜리 행사 전단, 메뉴, 공지를 인스타그램이나 카카오톡 단체방에 올릴 때. 그림은 바로 보이지만 PDF는 그렇지 않습니다.
  • 보고서 한 페이지를 파워포인트나 구글 프레젠테이션에 이미지로 넣어, 다른 사람 컴퓨터에서도 레이아웃이 틀어지지 않게 할 때.
  • 자격증 스캔본을 이미지로 요구하는 시험·채용·공공 사이트처럼 JPG만 받는 웹 양식에 문서를 올릴 때.
  • 상품 페이지나 블로그 글에 쓸 브로슈어나 전자책의 썸네일, 미리보기 이미지를 만들 때.
  • 모든 걸 휴대폰으로 보고 PDF 첨부 파일을 힘들어하는 사람에게 서명한 페이지를 보낼 때.
  • 페이지를 사진 편집기에 넣어 자르고, 표시하고, 다른 그래픽과 합칠 때.

시작하기 전에 알아둘 점

  • 모든 페이지가 변환됩니다. 페이지 범위 옵션이 없으니 4~6페이지만 필요하다면 먼저 페이지 추출로 작은 파일을 만들어 변환하세요.
  • 결과 파일은 PDF 이름에 세 자리 쪽 번호가 붙습니다. report.pdf는 report-001.jpg, report-002.jpg 식으로 나오고 report-jpg.zip에 담깁니다. 자릿수를 맞췄기 때문에 이름순 정렬에서도 순서가 유지됩니다.
  • JPEG에는 투명도가 없습니다. 페이지는 흰 바탕 위에 렌더링되므로 배경이 투명하거나 비어 있는 PDF는 비치는 영역이 아니라 흰 영역으로 나옵니다.
  • 표준이 아닌 크기의 페이지도 비율을 유지합니다. 가로 스프레드시트 페이지는 넓은 이미지가, 영수증 모양 페이지는 길쭉한 이미지가 됩니다.
  • dpi 수치는 PDF에 저장된 페이지 크기를 기준으로 합니다. 특이한 페이지 크기로 저장된 스캔본은 원래 스캔 해상도가 아니라 그 페이지 크기를 따르는 픽셀 크기로 렌더링됩니다.
  • 렌더링은 브라우저에서 하므로 아주 긴 문서를 높음으로 변환하면 메모리를 많이 씁니다. 200페이지를 216 dpi로 변환하면 큰 이미지를 한꺼번에 많이 들고 있어야 하니, 휴대폰은 느려지거나 탭이 새로 고쳐질 수 있습니다.

더 좋은 결과를 위한 팁

  • 화면으로 볼 용도라면 표준을 쓰세요. 높음은 화면용보다 픽셀이 4배 많아, 대부분 아무도 확대하지 않는 큰 파일만 남깁니다.
  • 글자나 가는 선 도표가 대부분인 페이지라면 PDF를 PNG로도 해서 비교해 보세요. JPG가 흐리게 만드는 경계를 PNG는 선명하게 유지합니다.
  • 사이트에 파일 크기 제한이 있다면 이미지 편집기를 쓰지 않고 한도 아래로 맞추는 가장 빠른 방법이 화면용 품질입니다.
  • 이미지를 하나씩 따로 올릴 거라면 다운로드 후 이름을 바꾸세요. report-003.jpg는 받는 사람에게 아무 의미가 없습니다.
  • 원본 PDF는 보관하세요. JPG를 다시 PDF로 만들면 텍스트를 선택할 수 없는 이미지 전용 문서가 됩니다.

실제 예시: 인스타그램과 매장 게시판용 카페 메뉴

작은 카페를 운영하는 오수아 씨는 워드프로세서로 만든 두 페이지짜리 메뉴를 A4 PDF로 내보냈습니다. 1페이지는 인스타그램 게시물로, 두 페이지 모두는 계산대 옆 액자 게시판에 걸고 싶습니다. PDF를 그대로 올릴 수는 없고, 휴대폰 화면 캡처는 흐리고 구석에 상태 표시줄까지 찍힙니다.

인스타그램용으로는 표준으로 PDF를 JPG로 변환합니다. 1페이지가 약 1191 x 1684픽셀로 나오는데, 앱에 필요한 것보다 크고 어떤 휴대폰에서도 충분히 선명합니다. 게시판용으로는 높음으로 다시 변환해 페이지당 약 1786 x 2526픽셀을 얻습니다. A4로 인쇄하면 약 216 dpi로, 1미터 거리에서 읽는 글씨에는 충분합니다. 두 번의 변환 모두 menu-001.jpg와 menu-002.jpg를 만들기 때문에 web, print라는 폴더에 따로 보관합니다.

그녀가 확인한 건 작은 글씨로 된 가격표 하나입니다. 화면용에서는 읽히긴 해도 흐릿했고, 표준에서는 깨끗했습니다. 전형적인 결과입니다. 가장 작은 글씨가 작을수록 더 높은 설정이 필요합니다.

문제 해결

이미지 속 글씨가 흐릿해요
품질을 높음으로 올리세요. 그래도 흐리다면 원본 페이지 자체가 저해상도 스캔일 수 있습니다. 렌더링으로 PDF에 없는 디테일을 만들 수는 없습니다. 선명한 글씨와 선에는 PDF를 PNG로를 쓰세요.
PDF가 불러와지지 않아요
비밀번호로 보호되었거나 손상된 파일일 수 있습니다. 만든 프로그램에서 비밀번호를 해제하거나 PDF 복구 도구를 거친 뒤 다시 시도하세요.
일부 페이지만 개별 다운로드 버튼이 생겼어요
결과 목록은 처음 50페이지까지만 개별 버튼을 보여 줍니다. 모두 다운로드 (.zip)에는 항상 모든 페이지가 들어 있습니다.
이미지가 너무 커서 업로드가 안 돼요
화면용으로 다시 변환하거나 이미지 편집기에서 줄이세요. JPEG 품질은 0.92로 고정이라, 여기서 조절할 수 있는 건 해상도 설정입니다.
일부 글꼴이나 기호가 PDF 뷰어와 다르게 보여요
PDF에 글꼴이 포함되지 않으면 PDF.js가 대체 글꼴을 씁니다. 글꼴을 포함해 PDF를 다시 내보낸 뒤 변환하세요.
브라우저가 느려지거나 탭이 새로 고쳐졌어요
긴 문서를 높음으로 변환하면 메모리를 많이 씁니다. PDF를 작게 나누거나 표준을 쓰고, 다른 무거운 탭은 닫으세요.

자주 묻는 질문

JPG 파일의 해상도는 얼마인가요?

화면용은 PDF 페이지 포인트 크기의 1.5배, 표준은 2배, 높음은 3배로, 약 108, 144, 216 dpi입니다. A4 페이지를 표준으로 하면 약 1191 x 1684픽셀입니다.

JPEG 압축 수준을 고를 수 있나요?

아니요. 압축은 품질 0.92로 고정되어 눈에 띄는 손상이 적습니다. 파일 크기는 해상도 설정으로 조절합니다.

이미지 속 텍스트가 검색되나요?

아니요. 각 페이지는 평면 그림입니다. 나중에 텍스트가 필요하면 PDF를 보관하거나 이미지에 OCR을 돌리세요.

특정 페이지만 변환할 수 있나요?

이 도구에서는 안 되고 모든 페이지를 변환합니다. 페이지 추출로 필요한 페이지만 담은 PDF를 만든 뒤 그것을 변환하세요.

PDF에서 투명했던 부분이 왜 흰 배경이 되나요?

JPEG는 투명도를 저장할 수 없어서 페이지를 흰 바탕 위에 그립니다. 투명도가 필요하다면 그 페이지에 JPG는 맞지 않는 형식입니다.

변환할 때 PDF가 업로드되나요?

아니요. PDF.js가 브라우저 탭 안에서 페이지를 렌더링하고 JPG도 그곳에서 만들어지므로, 이 변환에서는 문서가 서버로 전송되지 않습니다.

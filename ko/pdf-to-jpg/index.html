PDF를 JPG로

PDF의 모든 페이지를 고화질 JPG 이미지로 변환합니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.
1

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

PDF를 JPG로 변환하면 문서의 각 페이지가 개별 이미지 파일이 됩니다. 생각보다 자주 쓸모가 있죠. 이미지는 PowerPoint 슬라이드, WhatsApp 대화, 인스타그램 게시물, 웹페이지에 한 번에 넣을 수 있지만, PDF는 대개 내려받기와 별도 뷰어를 요구하니까요. 화질 프리셋을 고르고 변환을 누른 뒤 JPG를 받으세요. 여러 페이지 파일은 ZIP 하나로 깔끔하게 묶여 나옵니다.

모든 과정은 브라우저 안에서 실행됩니다. PDF는 서버가 아니라 사용자 기기에서 이미지로 렌더링되므로 계약서, 청구서, 진료 기록이 변환 때문에 인터넷을 오갈 일이 없습니다. 계정을 만들 필요도 없고, 결과물에 워터마크가 찍히지도 않으며, 하루에 처리할 수 있는 파일 수에도 제한이 없습니다.

세 가지 화질 프리셋이 용도에 맞는 결과를 만들어 줍니다. 화면용은 채팅과 웹에 쓰기 좋게 가볍고 빠르며, 표준은 대부분의 문서에서 용량과 선명도의 균형을 맞추고, 고화질은 확대하거나 인쇄할 페이지를 위해 인쇄 해상도로 렌더링합니다. 한 번 고르면 모든 페이지에 적용됩니다.

온라인에서 PDF를 JPG로 변환하는 방법

  1. PDF to JPG 도구를 열고 파일을 선택하거나 페이지 위로 바로 끌어다 놓습니다.
  2. 브라우저가 로컬에서 페이지를 읽는 동안 잠시 기다립니다. 업로드되는 것은 없습니다.
  3. 화질 프리셋을 고릅니다. 가벼운 파일은 화면용, 일상적인 용도는 표준, 인쇄용 이미지는 고화질을 선택하세요.
  4. 변환을 눌러 PDF의 모든 페이지를 개별 JPG로 렌더링합니다.
  5. 결과를 내려받습니다. 한 페이지짜리 PDF는 JPG 한 장으로, 여러 페이지 파일은 ZIP 하나로 나옵니다.
  6. 필요하면 압축을 풀고, 공유하기 전에 한두 페이지를 원본 크기로 확인합니다.

When to use this tool

  • PDF로만 있는 전단지나 행사 포스터를 PDF 업로드를 받지 않는 인스타그램이나 페이스북 그룹에 올리기
  • 보고서 페이지를 이미지로 PowerPoint나 Google Slides에 넣어 발표 중에 레이아웃이 틀어지지 않게 하기
  • 이미지는 바로 미리보기가 되지만 PDF는 그렇지 않은 WhatsApp 대화에서 메뉴판, 가격표, 시간표 보내기
  • 랜딩 페이지나 온라인 스토어 목록에 쓸 백서나 전자책의 미리보기 썸네일 만들기
  • PDF 편집 프로그램 없이 아무 사진 편집기에서 표시할 수 있도록 PDF 양식을 JPG로 변환하기
  • 블로그 글이나 보도자료 페이지에 쓰려고 뉴스레터의 개별 페이지를 이미지로 보관하기

Tips for the best results

  • 쓰임새에 맞는 프리셋을 고르세요. 채팅 앱이나 웹 삽입용은 화면용, 인쇄하거나 확대할 이미지에만 고화질을 쓰면 됩니다.
  • JPG는 사진 압축에는 강하지만 작은 글자를 흐리게 만들 수 있습니다. 페이지가 대부분 작은 글씨나 선 도해라면 PDF to PNG 도구가 더 또렷한 결과를 냅니다.
  • 긴 PDF를 고화질로 변환하면 파일이 커집니다. 100페이지 문서는 먼저 표준으로 돌리고, 정말 필요한 페이지만 고화질로 다시 변환하세요.
  • ZIP 안의 이미지는 페이지 번호로 이름이 붙으므로 폴더를 이름순으로 정렬해도 순서가 유지됩니다.
  • 긴 문서에서 한 페이지만 필요하다면 먼저 그 페이지를 분할하거나 추출해 따로 변환하세요. 더 빠르고 ZIP을 뒤질 일도 없습니다.

자주 묻는 질문

PDF 페이지마다 별도의 JPG가 만들어지나요?

네. 변환 도구가 선택한 화질로 모든 페이지를 개별 이미지로 렌더링합니다. 여러 페이지 문서는 ZIP 하나로 제공되어 수십 번 대신 한 번만 내려받으면 됩니다.

제 PDF가 서버로 업로드되나요?

아니요. 렌더링이 브라우저 안에서 로컬로 이뤄지므로 파일이 컴퓨터나 휴대폰을 떠나지 않습니다. 그래서 은행 거래내역서, 계약서 같은 민감한 서류도 안심하고 변환할 수 있습니다.

어떤 화질 프리셋을 골라야 하나요?

대부분의 문서에는 표준이 적합합니다. 세부 묘사보다 작은 용량이 중요하면 화면용을, 이미지를 인쇄하거나 가까이서 들여다볼 거라면 고화질을 고르세요.

JPG에 워터마크가 들어가나요?

아니요. 결과 이미지는 로고나 도장, 하단 문구 없이 깨끗하며, 파일을 아무리 많이 변환해도 달라지지 않습니다.

비밀번호가 걸린 PDF도 변환할 수 있나요?

먼저 파일을 열 수 있어야 합니다. 비밀번호를 묻는다면 알고 있는 비밀번호로 잠금을 해제한 뒤, 해제된 사본을 변환 도구에 넣으세요.

페이지나 파일 수 제한이 있나요?

저희가 정한 제한은 없습니다. 작업을 사용자 기기가 처리하므로 아주 큰 파일은 기기 메모리에만 좌우되며, 수백 페이지 문서도 대체로 무리 없이 변환됩니다.

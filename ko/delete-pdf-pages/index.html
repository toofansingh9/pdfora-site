다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

스캐너가 끼워 넣은 빈 페이지, 중복된 슬라이드, 절대 고객에게 가면 안 되는 내부 단가표. 어떤 PDF든 빼야 할 페이지가 한두 장씩 생기기 마련이고, PDFora의 삭제 도구는 그런 페이지를 깔끔하게 걷어냅니다. 제외할 페이지를 예를 들어 2, 5-7처럼 입력하면 나머지가 모두 담긴 새 PDF를 받을 수 있습니다.

대부분의 웹 도구와 달리 PDFora는 파일을 받지 않습니다. 페이지 삭제는 사용자 컴퓨터의 브라우저가 처리하므로 이름과 숫자, 협상 내용이 가득한 문서도 원래 자리에 그대로 머뭅니다. 페이지를 지우는 이유는 대개 공유하면 안 될 내용을 없애기 위해서인데, 그 과정에서 문서를 외부 서버에 넘긴다면 앞뒤가 맞지 않겠죠.

무료이고 계정을 만들 필요도 없습니다. 내려받은 파일에는 워터마크가 없고, 지우는 페이지 수나 정리하는 문서 수에도 제한이 없습니다. 나중에 지운 페이지가 다시 필요해질 경우를 대비해 원본 PDF는 손대지 않고 그대로 둡니다.

온라인에서 PDF 페이지 삭제하는 방법

  1. getpdfora.com의 페이지 삭제 도구로 이동합니다. 로그인 없이 바로 열립니다.
  2. 정리할 PDF를 선택하거나 페이지 위로 바로 끌어다 놓습니다.
  3. 지울 페이지를 입력합니다. 2, 5-7처럼 개별 번호와 범위를 함께 쓸 수 있습니다.
  4. 다음 단계로 넘어가기 전에 번호를 확인하세요. 표지 페이지를 잘못 세는 것이 가장 흔한 실수입니다.
  5. 삭제를 누릅니다. 브라우저가 해당 페이지를 뺀 PDF를 로컬에서 다시 만듭니다.
  6. 정리된 파일을 내려받습니다. 입력하지 않은 페이지는 순서 그대로 모두 남아 있습니다.

When to use this tool

  • 양면 스캐너가 실제 페이지 사이마다 끼워 넣은 빈 뒷면 제거하기
  • 새 잠재 고객에게 보내기 전에 브로슈어에서 오래된 가격 페이지 빼기
  • 보관용으로 정리하는 잡지 PDF에서 광고와 구독 신청 카드 잘라내기
  • 최종본만 돌아다니도록 계약서에서 초안이나 대체된 페이지 삭제하기
  • 학생들에게 나눠 주기 전에 학습지 PDF에서 정답 페이지 빼기
  • 업로드 용량 제한에 맞추기 위해 보고서에서 상투적인 약관 페이지 덜어내기

Tips for the best results

  • 연속된 구간을 자를 때는 번호를 하나씩 쓰지 말고 범위를 쓰세요. 12-19 한 줄이 여덟 개를 손으로 입력하는 것보다 낫습니다.
  • 페이지 삭제는 페이지 추출의 거울상입니다. 문서의 절반 이하만 남길 거라면 남길 페이지를 추출하는 쪽이 빠릅니다.
  • 공유하기 전에 결과를 열어 한 번 훑어보세요. 특히 페이지에 쪽번호가 인쇄되어 있던 경우에 중요합니다.
  • 긴 파일에서 여기저기 흩어진 페이지를 지울 때는 정리 도구의 썸네일 보기를 쓰면 번호 대신 눈으로 보면서 삭제할 페이지를 표시할 수 있습니다.
  • 정리한 파일이 제 역할을 다 할 때까지는 손대지 않은 원본을 보관해 두세요.

자주 묻는 질문

PDF에서 여러 페이지를 한 번에 지우려면 어떻게 하나요?

쉼표로 구분해 한꺼번에 입력하면 됩니다. 2, 5-7, 11이라고 쓰면 2쪽, 5~7쪽, 11쪽이 한 번에 삭제됩니다. 페이지마다 작업을 반복할 필요가 없습니다.

새 파일에서 삭제된 페이지를 복구할 수 있나요?

아니요, 그게 바로 핵심입니다. 내려받은 PDF는 애초에 그 페이지 없이 만들어지므로 받는 사람이 되살릴 수 없습니다. 원본 파일에는 모든 페이지가 그대로 남아 있으니 사용자 쪽에서 잃는 것은 없습니다.

민감한 문서의 페이지를 온라인에서 지워도 안전한가요?

PDFora에서는 안전합니다. 파일이 브라우저를 벗어나지 않기 때문입니다. 처리가 로컬에서 이뤄지므로 기밀 페이지를 지우려고 기밀 문서를 어딘가에 업로드할 일이 없습니다.

PDF 페이지를 지우면 링크나 북마크가 깨지나요?

남은 페이지의 내용과 서식은 그대로 유지됩니다. 삭제된 페이지를 가리키던 북마크나 내부 링크는 목적지를 잃게 되는데, 이는 어떤 페이지 삭제 도구를 쓰더라도 마찬가지입니다.

소프트웨어를 설치하거나 가입해야 하나요?

둘 다 필요 없습니다. 데스크톱이든 모바일이든 최신 브라우저에서 무료로 실행되며, 계정도 필요 없고 결과물에 워터마크도 없습니다.

아주 큰 PDF도 처리할 수 있나요?

네, 서버 할당량이 아니라 사용자 기기의 성능 범위 안에서 가능합니다. 브라우저가 작업을 처리하기 때문에 수백 페이지짜리 파일도 대부분의 기기에서 빠르게 끝나지만, 용량이 엄청난 스캔 문서는 메모리를 더 요구합니다.

페이지 삭제

빈 페이지, 중복 페이지, 기밀 페이지의 번호를 입력해 PDF에서 지우고, 그 페이지가 빠진 깔끔한 사본을 다운로드합니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.
1

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

양면 스캐너가 끼워 넣은 빈 페이지, 아무도 필요 없는 표지, 고객 계좌 정보가 나온 계약서의 한 페이지처럼 원치 않는 페이지는 문서 전체의 문제는 아니어도 문서를 허술해 보이게 하고, 더 나쁘게는 사무실 밖으로 나가서는 안 될 정보를 내보내기도 합니다. 페이지 삭제는 바로 그 일만을 위한 도구입니다. 지울 페이지를 입력하면, 나머지 페이지가 원래 순서대로 담긴 새 PDF가 만들어집니다.

이 도구는 파일을 직접 고치지 않습니다. pdf-lib로 PDF를 열어 입력하지 않은 페이지 목록을 계산한 뒤, 그 페이지만 yourfile-edited.pdf라는 새 문서에 복사합니다. 남는 페이지는 다시 그리지 않고 복사하므로 텍스트, 글꼴, 이미지 품질이 원래와 똑같습니다. 지운 페이지는 새 파일에 아예 기록되지 않고, 그 페이지에서만 쓰던 이미지와 글꼴도 함께 빠집니다. 스캔 페이지 몇 장만 지워도 파일이 눈에 띄게 작아지는 이유가 이것입니다.

이런 구조 덕분에 미리 알아 둘 점이 하나 있습니다. 여기서 삭제는 페이지를 숨기거나 가리는 게 아니라 결과 파일에서 실제로 없애는 것입니다. 새 PDF를 연 사람은 지운 페이지를 되살릴 수 없습니다. 다만 원본은 내 디스크에 그대로 남아 있으니, 보관할지 지울지 신경 써서 정하세요.

PDF에서 페이지를 삭제하는 방법

  1. 페이지 삭제 도구를 열고 정리할 PDF를 선택합니다.
  2. 뷰어의 썸네일 패널에서 지울 페이지가 파일에서 몇 번째에 있는지 적어 둡니다. 페이지에 인쇄된 쪽 번호는 무시하세요.
  3. 삭제할 페이지 입력란에 쉼표로 구분해 입력하고, 필요하면 범위를 씁니다. 예: 2, 5-7, 30-.
  4. 페이지 삭제를 누릅니다. 남은 페이지가 원래 순서대로 새 문서에 복사됩니다.
  5. yourfile-edited.pdf를 다운로드하고, 페이지 수가 원본 페이지 수에서 지운 페이지 수를 뺀 값과 같은지 확인합니다.

이 도구가 필요한 경우

  • 단면 원본을 양면으로 스캔했을 때 양면 스캐너가 덧붙인 빈 뒷면을 걷어 낼 때.
  • 문서를 업무 관리 시스템에 등록하기 전에 팩스 표지나 이메일을 PDF로 저장할 때 붙은 머리 페이지를 뺄 때.
  • 파일의 나머지를 제3자와 공유하기 전에 계좌번호나 진료 기록이 담긴 페이지를 빼낼 때.
  • 관공서 서류 묶음에서 작성 안내 페이지를 빼고 작성한 서식만 제출할 때.
  • 다른 고객사에 다시 보내는 제안서에서 지난 가격표나 부록을 잘라 낼 때.
  • PDF로 내보낸 긴 웹 페이지나 채팅 기록을 실제로 필요한 부분이 있는 페이지만 남기고 줄일 때.

시작하기 전에 알아둘 점

  • 입력란을 비워 둔다고 '아무것도 지우지 않음'이 되지 않습니다. 빈칸은 모든 페이지로 해석되므로 도구가 "이렇게 하면 모든 페이지가 삭제됩니다."라며 거부합니다. 항상 숫자를 하나 이상 입력해야 합니다.
  • 모든 페이지를 지울 수는 없으며, 최소 한 페이지는 남아야 합니다. 빈 문서에서 시작하고 싶다면 PDF 만들기 계열 도구가 더 적합합니다.
  • 마지막 페이지보다 큰 번호는 경고 없이 무시되고, 9-4처럼 거꾸로 쓴 범위는 아무 페이지와도 일치하지 않습니다. 지우려던 페이지가 결과에 남아 있다면 이 두 가지 실수부터 확인하세요.
  • 입력한 순서와 상관없이 이 도구는 남는 페이지의 순서를 절대 바꾸지 않습니다. 순서도 바꾸고 싶다면 페이지 정리를 쓰세요. 페이지 삭제, 회전, 드래그 정렬을 한 번에 할 수 있습니다.
  • 새 파일에는 책갈피가 유지되지 않으며, 삭제된 페이지(또는 위치가 바뀐 페이지)를 가리키던 문서 내부 링크는 작동하지 않게 됩니다. 웹사이트 링크는 영향이 없습니다.
  • 페이지를 지워도 다른 곳에 반복된 텍스트까지 지워지지는 않습니다. 기밀 수치가 2페이지 요약표에도 나온다면 14페이지의 상세 페이지를 지워도 2페이지에는 여전히 보입니다. 원본 문서에서 지운 뒤 PDF를 새로 내보내세요.

더 좋은 결과를 위한 팁

  • 여기저기 흩어진 빈 페이지를 많이 지울 때는 썸네일을 크게 보여 주는 뷰어로 파일을 열고, 스크롤하면서 목록을 적으세요. 작은 썸네일에서는 빈 페이지를 놓치기 쉽습니다.
  • 25-처럼 입력하면 25페이지부터 끝까지 모두 지웁니다. 길이를 모르는 부록을 통째로 잘라 낼 때 편합니다.
  • 입력할 번호가 대부분의 페이지라면 방향을 바꿔, 남길 몇 페이지만 페이지 추출로 지정하세요.
  • 민감한 문서라면 여기서 페이지를 지운 뒤 결과를 열어 뷰어의 검색 기능으로 기밀 이름이나 번호가 남은 페이지에 나오지 않는지 확인하세요.
  • 스캔 파일을 정리했다면 PDF 압축도 고려해 보세요. 페이지를 지우면 그 이미지는 빠지지만, 남은 스캔 페이지는 여전히 필요 이상으로 클 수 있습니다.

실제 예시: 비영리단체의 사업 보고서 공유

한 작은 비영리단체가 32페이지짜리 지원사업 결과 보고서를 두 번째 후원 기관에 보내야 합니다. 보고서에는 그 기관이 보면 안 되는 내용이 세 군데 있습니다. 4페이지에는 첫 번째 후원 기관의 협약 번호와 담당자가, 17~18페이지에는 개별 수혜자의 이름과 나이가 있고, 29~32페이지는 첫 번째 기관이 준 자체 평가 양식입니다. 게다가 스캐너가 23번째 위치에 빈 페이지를 남겼습니다.

입력란에 4, 17-18, 23, 29-를 입력하면 여덟 페이지가 한 번에 지워집니다. 다운로드한 파일은 24페이지이고, 첫 번째 확인은 페이지 수입니다. 32에서 8을 빼면 24입니다. 두 번째 확인이 더 중요합니다. 수혜자 수치는 9페이지 요약 차트에도 나오지만 이름이 없으니 그대로 둬도 됩니다. 새 파일에서 수혜자 한 명의 성을 검색하면 아무것도 나오지 않으므로, 신원이 드러나는 페이지가 정말로 사라졌음을 확인할 수 있습니다.

원래 보고서 바닥글에 '32쪽 중 x쪽'이 인쇄되어 있었기 때문에 이제 쪽 번호가 건너뜁니다. 받는 쪽이 무엇이 빠졌는지 궁금해하게 두는 것보다, 보내는 이메일에 발췌본이라고 한 줄 적어 두는 편이 깔끔합니다.

문제 해결

"이렇게 하면 모든 페이지가 삭제됩니다."라는 메시지가 나옵니다
입력란이 비어 있어 모든 페이지로 해석되었거나, 입력한 목록이 모든 페이지를 포함합니다. 지울 페이지만 입력하고 문서에 최소 한 페이지는 남기세요.
입력한 페이지가 결과에 그대로 있습니다
인쇄된 쪽 번호가 아니라 파일 안의 실제 위치를 썼는지, 모든 범위를 작은 수에서 큰 수 순으로 썼는지 확인하세요. 12-10 같은 범위는 통째로 무시됩니다.
엉뚱한 페이지가 삭제되었습니다
원본 파일은 바뀌지 않았으니 편집된 사본이 아니라 원본에서 다시 시작하세요. 썸네일 사이드바를 보며 세면 표지 때문에 한 칸씩 어긋나는 흔한 실수를 피할 수 있습니다.
새 파일 크기가 이전과 거의 같습니다
지운 페이지가 대개 텍스트뿐이라 가벼웠기 때문에 줄어든 용량이 적습니다. 파일 크기는 이미지가 좌우합니다. 용량을 줄이는 게 진짜 목적이라면 PDF 압축을 쓰세요.
결과 페이지가 비어 있거나 읽을 수 없습니다
대개 원본 PDF가 암호화되어 있다는 뜻입니다. 파일을 만든 프로그램에서 비밀번호나 제한을 해제해 보호되지 않은 사본을 저장한 뒤, 그 사본에서 페이지를 지우세요.
클릭하면 이동하던 목차 항목이 이제 엉뚱한 곳으로 갑니다
내부 링크는 페이지 위치로 연결되는데, 삭제 후에는 위치가 밀립니다. 목차 페이지를 지우거나 다시 만들고, 책갈피 만들기 도구로 새 책갈피를 추가하세요.

자주 묻는 질문

삭제한 페이지를 누군가 복구할 수 있나요?

새 파일에서는 불가능합니다. 삭제된 페이지는 아예 복사되지 않습니다. 다만 원본에는 그대로 있으니 원본 파일은 따로 관리하세요.

페이지를 지우면 남은 페이지의 화질이 떨어지나요?

아니요. 남은 페이지는 객체 단위로 그대로 복사되어 텍스트는 텍스트로 남고 이미지는 다시 압축되지 않습니다.

여러 PDF에서 한 번에 페이지를 지울 수 있나요?

아니요. 한 번에 파일 하나만 처리합니다. 여러 파일이라면 하나씩 실행하거나, 먼저 병합한 뒤 병합본에서 지우세요.

왜 입력란을 비우면 '아무것도 지우지 않음'이 아닌가요?

페이지 입력란은 다른 페이지 도구와 같은 해석 방식을 쓰며, 거기서는 빈칸이 모든 페이지를 뜻합니다. 삭제에서 그렇게 하면 문서가 비어 버리므로 대신 오류를 띄우고 멈춥니다.

페이지 삭제와 가림 처리(비식별화)는 같은 건가요?

아니요. 삭제는 페이지 전체를 없앱니다. 남겨 둘 페이지에서 일부 단어만 지우는 건 가림 처리인데, 이 도구는 그 기능이 없습니다. PDF에서 텍스트 위에 상자를 덮으면 밑에 텍스트가 남을 수 있으니, 원본 문서를 고쳐 다시 내보내세요.

페이지를 지우려면 계정이 필요한가요?

아니요. 무료이고 회원가입 없이 쓸 수 있으며, 편집된 파일은 브라우저에서 만들어집니다.

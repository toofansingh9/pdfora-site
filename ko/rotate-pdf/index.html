PDF 회전

PDF의 전체 또는 일부 페이지를 90도, 180도, 270도로 돌리고, 화질 손실 없이 회전 상태를 파일에 영구 저장합니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

PDF 뷰어에서 페이지를 돌리면 보통 그 화면에서 보는 방향만 바뀝니다. 파일을 닫거나, 다른 사람에게 보내거나, 다른 기기에서 열면 가로로 된 표는 다시 옆으로 누워 있습니다. 누구에게나 바로 보이게 하려면 회전을 파일 자체에 저장해야 하는데, 이 도구가 바로 그 일을 합니다.

PDF의 모든 페이지에는 회전 설정이 있습니다. 화면에 표시하거나 인쇄할 때 페이지를 0도, 90도, 180도, 270도 중 얼마나 돌릴지 뷰어와 프린터에 알려 주는 숫자입니다. PDFora의 회전 도구는 pdf-lib로 파일을 열어 선택한 페이지의 이 설정에 고른 각도를 더한 뒤 문서를 저장합니다. 페이지 내용은 건드리지 않습니다. 텍스트를 다시 배치하지도, 이미지를 재압축하지도, 그림으로 바꾸지도 않습니다. 그래서 용량이 큰 스캔본도 회전이 즉시, 손실 없이 끝납니다.

이 도구는 페이지를 복사해 새 문서를 만드는 대신 기존 문서를 수정하기 때문에, 페이지를 재배치하는 도구들보다 파일 구조를 더 많이 유지합니다. 책갈피, 내부 링크, 양식 필드가 그대로 남습니다. 다운로드 파일 이름은 yourfile-rotated.pdf입니다.

PDF 페이지를 회전하는 방법

  1. PDF 회전 도구를 열고 파일 하나를 선택합니다.
  2. 회전 방향을 고릅니다. 시계 방향 90°, 180°, 시계 반대 방향 90° 중 하나입니다.
  3. 모든 페이지를 돌리려면 페이지 칸을 비워 두고, 일부만 돌리려면 3, 7-9, 15- 처럼 입력합니다.
  4. 회전 후 다운로드를 누릅니다. 선택한 각 페이지의 기존 회전값에 각도가 더해지고 파일이 저장됩니다.
  5. yourfile-rotated.pdf를 열어 돌린 페이지를 확인합니다. 반대로 돌아간 페이지가 있으면 결과 파일에 같은 도구를 반대 방향으로 한 번 더 실행하세요.

이 도구가 필요한 경우

  • 휴대폰 스캔 앱이 모든 페이지를 옆으로 눕혀 저장한 영수증 묶음을 바로잡을 때.
  • 세로 방향 재무 보고서 사이에 끼어 있는 가로 엑셀 표 페이지를 화면에서 바로 읽히게 돌릴 때.
  • 자동 급지 스캐너에서 거꾸로 나온 페이지만 골라 180도 돌릴 때.
  • 건축·설계 도면 묶음을 열었을 때 모든 시트의 표제란이 올바른 모서리에 오도록 정리할 때.
  • 임시 화면 회전을 무시하는 경우가 많은 태블릿이나 전자책 리더에서 슬라이드나 상장 PDF가 똑바로 보이게 할 때.
  • 서명 페이지 한 장만 방향이 잘못 스캔된 계약서를 바로잡을 때.

시작하기 전에 알아둘 점

  • 회전은 90도 단위로만 됩니다. 몇 도 정도 비뚤어진 스캔은 이 도구로 고칠 수 없으니, 살짝 기울어진 스캔 페이지를 바로 세워 주는 기울기 보정을 사용하세요.
  • 선택한 각도는 페이지의 현재 회전값에 더해집니다. 이미 90도 돌아간 페이지를 다시 90도 돌리면 90도가 아니라 180도가 됩니다.
  • 페이지 칸이 비어 있으면 전체 페이지입니다. 마지막 페이지를 넘는 번호는 무시되고, 8-5처럼 거꾸로 쓴 범위는 아무 페이지도 선택하지 않아 해당 페이지가 회전되지 않습니다.
  • 바뀌는 것은 표시 방향뿐입니다. 텍스트 추출과 검색은 이전처럼 작동하고, 복사한 텍스트도 정상적인 읽기 순서로 나옵니다.
  • 오래되었거나 아주 단순한 일부 뷰어는 회전된 페이지를 인쇄할 때 축소하는 등 제대로 처리하지 못합니다. 인쇄 결과가 이상하면 인쇄 대화상자의 자동 회전이나 페이지에 맞춤 옵션을 사용하세요.
  • 페이지마다 다른 각도로 돌리려면 도구를 여러 번 실행하거나, 썸네일을 보면서 페이지마다 따로 돌릴 수 있는 페이지 정리 도구를 사용하세요.

더 좋은 결과를 위한 팁

  • 돌리기 전에 시계 방향, 시계 반대 방향, 180도가 필요한 페이지를 간단히 적어 두세요. 그런 다음 같은 파일에 그룹별로 한 번씩 실행하면 됩니다.
  • 시계 방향과 시계 반대 방향은 헷갈리기 쉽습니다. 글자의 윗부분이 어디를 향하는지 보세요. 왼쪽을 향하면 시계 방향 90°, 오른쪽을 향하면 시계 반대 방향으로 돌립니다.
  • OCR보다 회전을 먼저 하세요. 문자 인식은 똑바로 선 페이지에서 훨씬 잘 됩니다.
  • 한 뷰어에서는 맞게, 다른 뷰어에서는 틀리게 보인다면 파일 안의 설정이 서로 충돌하는 것일 수 있습니다. 이 도구로 올바른 방향으로 돌린 뒤 두 뷰어에서 다시 확인하세요.
  • 회전은 손실이 없으므로 같은 파일을 여러 번 돌려도 화질이 떨어지지 않습니다. 원본으로 돌아갈 필요가 없습니다.

예시: 프리랜서의 분기별 경비 영수증

프리랜서 사진작가가 분기별 경비 정리를 위해 스캔 앱으로 영수증 23장을 찍었습니다. 앱이 1~18페이지는 윗부분이 왼쪽을 향하도록 옆으로, 19페이지와 22페이지는 거꾸로 저장했고 나머지는 제대로 저장했습니다. 세무사는 화면을 돌리지 않고 읽을 수 있는 PDF 하나를 요청했습니다.

첫 번째 실행에서는 시계 방향 90°를 고르고 페이지 칸에 1-18을 입력합니다. 두 번째 실행에서는 그 결과 파일에 180°를 고르고 19, 22를 입력합니다. 각각 몇 초면 끝나는 두 번의 실행으로 모든 페이지가 똑바로 섭니다. 회전은 각 페이지의 설정만 고치므로 23페이지 파일의 크기는 사실상 그대로이고, 영수증 사진도 재압축되지 않아 사업자등록번호 같은 작은 글씨도 처음 찍었을 때만큼 또렷합니다.

영수증 순서까지 뒤섞여 있었다면 여기서 돌리고 다른 도구에서 다시 순서를 바꾸기보다, 페이지 정리 도구로 회전과 재배치를 한 번에 하는 편이 나았을 겁니다.

문제 해결

결과물에 아무 변화가 없어요
페이지 칸을 확인하세요. 존재하지 않는 페이지와 거꾸로 쓴 범위는 아무 안내 없이 무시됩니다. 전체 페이지를 돌리려 했다면 칸을 비워 두세요.
페이지가 반대로 돌아갔어요
거꾸로 되었다면 결과 파일에 180°로 다시 실행하고, 옆으로 누웠다면 반대쪽 90° 옵션으로 실행하세요. 몇 번을 돌려도 손실은 없습니다.
브라우저에서는 똑바른데 다른 앱에서는 옆으로 보여요
일부 앱은 자체적으로 저장한 보기 회전을 적용합니다. 그 앱에서 보기를 초기화하거나 파일을 새로 여세요. 페이지의 실제 회전값은 이제 파일에 저장되어 있습니다.
스캔이 아직 살짝 비뚤어져 있어요
회전은 90도 단위로만 됩니다. 페이지 방향을 바로잡은 다음 작은 기울기는 기울기 보정으로 고치세요.
파일이 열리지 않아요
PDF가 손상되었거나 비밀번호가 걸려 있을 수 있습니다. PDF 복구를 해 보거나, 파일을 만든 프로그램에서 보호를 해제한 뒤 그 사본을 돌리세요.
돌린 페이지가 작게 인쇄되거나 잘려요
인쇄 대화상자에서 자동 회전과 페이지에 맞춤을 켜세요. 요즘 프린터 드라이버는 대부분 세로와 가로가 섞인 페이지를 페이지별로 처리합니다.

자주 묻는 질문

PDF를 회전하면 화질이 떨어지나요?

아닙니다. 페이지 회전 설정만 바뀌고 텍스트, 이미지, 벡터 그래픽은 다시 렌더링하거나 재압축하지 않습니다.

일부 페이지만 돌릴 수 있나요?

네. 2, 5-8처럼 페이지나 범위를 입력하세요. 칸을 비워 두면 모든 페이지가 회전합니다.

회전한 뒤에도 책갈피와 링크가 작동하나요?

네. 새 문서를 만들지 않고 기존 문서를 수정하므로 책갈피, 내부 링크, 양식 필드가 유지됩니다.

왜 페이지가 엉뚱한 각도로 돌아갔나요?

선택한 각도가 페이지에 이미 있던 회전값에 더해지기 때문입니다. 이미 돌아가 있던 페이지는 똑바른 상태가 아니라 현재 위치에서부터 회전합니다.

45도로 돌릴 수 있나요?

아니요. PDF 페이지 회전은 90도의 배수만 지원합니다. 살짝 기울어진 스캔은 기울기 보정을 사용하세요.

회전하려고 파일을 서버로 보내나요?

아닙니다. 회전은 브라우저 안에서 pdf-lib로 적용되며 파일은 기기를 떠나지 않습니다.

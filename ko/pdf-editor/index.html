완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

PDFora 편집기를 쓰면 브라우저 탭 안에서 바로 PDF를 무료로 편집할 수 있습니다. 파일을 열면 전체 도구 모음이 나타납니다. 원하는 색과 크기로 텍스트 상자를 넣고, 이미지를 얹고, 자유롭게 그리고, 지우고 싶은 부분을 화이트아웃으로 덮고, 서명을 배치할 수 있습니다. 계정을 만들 필요도 없고 작업물에 워터마크도 찍히지 않습니다. 가입 없이 쓰는 진짜 PDF 편집기입니다.

많은 분이 가장 신경 쓰는 부분은 이겁니다. 파일이 컴퓨터를 벗어나지 않는다는 것. 모든 처리가 브라우저 로컬에서 이뤄지므로 PDF를 열고 편집하고 저장하는 일을 어딘가의 서버가 아니라 내 컴퓨터가 합니다. 문서가 임대차 계약서나 진료 서류, 신분증 스캔본일 때 이 차이는 큽니다. 데스크톱 앱과 같은 수준의 프라이버시로 민감한 서류를 다룰 수 있습니다.

작업을 마치면 모든 변경 사항이 저장된 PDF 안으로 플래튼됩니다. 텍스트, 이미지, 그림, 화이트아웃이 모두 페이지 자체의 일부가 되므로 어디서 열어도 똑같이 보입니다. 한 페이지든 200페이지든, 파일이 몇 개든 상관없습니다. 처리가 우리 쪽이 아니라 사용자 기기에서 이뤄지기 때문에 무료이고 제한이 없습니다.

온라인에서 PDF 편집하는 방법

  1. getpdfora.com에서 PDF 편집기를 열고 파일을 선택하거나 페이지 위로 바로 끌어다 놓습니다. 로컬에서 열리며 아무것도 업로드되지 않습니다.
  2. 도구 모음에서 이동, 텍스트, 서명, 이미지, 그리기, 화이트아웃 중 원하는 도구를 고릅니다.
  3. 페이지 아무 곳이나 클릭해 텍스트 상자를 추가한 뒤, 문서에 어울리도록 글꼴 크기와 색을 지정합니다.
  4. 화이트아웃으로 예전 전화번호나 잘못된 숫자를 덮고, 그 위에 텍스트 상자를 올려 올바른 내용을 적습니다.
  5. 필요한 자리에 이미지나 서명을 넣고, 이동 도구로 바꿔 원하는 위치까지 정확히 끌어다 놓습니다.
  6. 저장을 클릭합니다. 모든 편집이 PDF에 플래튼되고 파일이 기기로 내려받아집니다.

When to use this tool

  • 원본 Word 파일이 없을 때, PDF로 받은 계약서의 오타 고치기.
  • 소득 증빙으로 임대인에게 보내기 전에 은행 거래내역서의 계좌번호를 화이트아웃으로 가리기.
  • 거래처 제품 시트에 우리 로고와 수정된 가격을 넣어 고객에게 전달하기.
  • 스캔한 증명서의 잘못된 날짜를 덮고 같은 크기로 올바른 날짜를 타이핑해 고치기.
  • 시공업체와 통화하기 전에 평면도에 손으로 화살표와 메모를 그려 넣기.
  • 인쇄하지 않고 휴대폰에서 동의서나 면책 확인서에 서명하고 날짜 적기.

Tips for the best results

  • 텍스트 상자를 넣기 전에 확대하세요. 기존 인쇄물과 글자를 맞추기가 훨씬 수월해집니다.
  • 먼저 문서의 글꼴 크기를 맞춘 다음 색을 미세 조정하세요. 스캔본에서는 완전한 검정보다 살짝 어두운 회색이 더 자연스럽게 섞입니다.
  • 화이트아웃은 내용을 시각적으로 덮고 저장 시 페이지에 플래튼됩니다. 다만 가려진 정보가 나중에 필요할 수 있으니 원본 파일 사본은 남겨 두세요.
  • 요소를 배치한 뒤 위치를 다듬을 때는 지웠다 다시 만들지 말고 이동 도구로 조금씩 옮기세요.
  • 긴 문서를 작업 중인가요? 중간중간 저장하고 저장된 파일을 다시 열어 이어서 작업하세요. 여기까지의 편집은 확정된 상태로 남습니다.

자주 묻는 질문

PDFora의 PDF 편집기는 정말 무료인가요?

네. 텍스트, 이미지, 그리기, 화이트아웃, 서명 등 편집기의 모든 도구가 무료이며 페이지 제한도, 가입도, 결과물 워터마크도 없습니다. 쓸 만한 기능을 숨겨 둔 유료 등급 같은 것은 없습니다.

파일이 서버로 업로드되나요?

아니요. 편집기는 전부 브라우저에서 실행되므로 PDF는 열 때부터 저장할 때까지 사용자 기기에 머뭅니다. 그래서 계약서, 신분증, 진료 기록처럼 낯선 사람에게 이메일로 보내고 싶지 않은 문서도 안심하고 다룰 수 있습니다.

PDF에 이미 있는 텍스트를 편집할 수 있나요?

화이트아웃 도구로 기존 텍스트를 덮고 그 위에 비슷한 크기와 색으로 대체 텍스트를 입력할 수 있습니다. 원본 텍스트 레이어를 직접 인라인 편집하는 기능은 지원하지 않지만, 덮고 다시 쓰는 방식으로 수정 작업은 깔끔하게 처리됩니다.

저장할 때 "플래튼"된다는 게 무슨 뜻인가요?

플래튼은 텍스트 상자, 이미지, 그림, 화이트아웃을 페이지 내용 자체에 병합하는 것입니다. 결과는 어떤 뷰어에서든 똑같이 보이는 평범한 PDF이며, 편집 내용이 실수로 옮겨지거나 지워질 일이 없습니다.

편집기에서 서명을 추가할 수 있나요?

네, 도구 모음에 서명 도구가 있습니다. 페이지 어디에나 서명을 놓고 크기를 조절할 수 있으며, 저장하면 문서에 플래튼됩니다. 다른 편집을 하는 김에 서명까지 해결하기에 편리합니다.

휴대폰이나 태블릿에서도 되나요?

됩니다. 편집기는 최신 모바일 브라우저라면 어디서든 실행되고, 그리기와 서명 도구는 손가락으로도 자연스럽게 쓸 수 있습니다. 텍스트를 정밀하게 배치하기에는 큰 화면이 편하지만, 데스크톱이 꼭 필요한 것은 아닙니다.

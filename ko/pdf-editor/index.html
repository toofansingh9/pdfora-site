PDF 편집

어떤 PDF 페이지 위에든 텍스트, 이미지, 손글씨 표시, 흰색 가림 상자를 얹은 뒤 새 사본으로 저장합니다.

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

PDF 편집기를 찾는 사람 대부분은 문서를 새로 쓰려는 게 아닙니다. 빠진 날짜를 적거나, 견적서에 로고를 넣거나, 무언가에 줄을 긋거나, 여백에 짧은 메모를 남기고 싶을 뿐입니다. PDFora의 PDF 편집은 딱 그런 작업용으로, 페이지 위에 새로운 요소를 올려놓게 해 줍니다. 파일에 이미 인쇄된 글자를 고치는 기능은 없으니, 작업을 마친 뒤가 아니라 시작하기 전에 알아 두세요.

파일을 열면 모든 페이지가 PDF.js로 최대 880픽셀 너비까지 화면에 그려지고, 각 페이지 위에는 작업용 투명 레이어가 놓입니다. 도구 모음에는 이동, 텍스트, 서명, 이미지, 그리기, 화이트아웃의 여섯 가지 모드와 색상 선택, 글자 크기 입력란(기본 18, 6~96)이 있습니다. 텍스트 상자, 서명, 그림은 드래그로 옮기고 각 요소의 작은 ×로 지울 수 있으며, 이미지와 서명은 모서리를 당겨 크기도 바꿀 수 있습니다.

PDF 저장을 누르면 도구가 한 페이지에 추가한 모든 요소를 화면상 페이지 크기의 투명 PNG 한 장에 그려 넣고, pdf-lib가 그 PNG를 원본 페이지 위에 찍습니다. 아래에 있는 원본 내용은 건드리지 않으므로 텍스트는 계속 선택할 수 있고 벡터 그림도 선명하게 유지됩니다. 결과는 yourfile-edited.pdf로 다운로드됩니다.

PDF에 텍스트와 이미지를 넣는 방법

  1. PDF 편집을 열고 PDF 하나를 끌어다 놓습니다. 모든 페이지가 그려질 때까지 기다리세요. 작업 전에 페이지마다 렌더링하므로 긴 문서는 조금 걸립니다.
  2. 텍스트를 고르고 색상과 크기를 정한 뒤, 글이 시작될 위치를 클릭해 상자에 바로 입력합니다. 줄을 바꾸려면 Enter를 누르세요. 긴 줄은 자동으로 줄바꿈되지 않습니다.
  3. 컴퓨터에 있는 로고나 도장 이미지는 이미지로, 체크 표시·화살표·동그라미 같은 손그림은 그리기로 넣습니다. 그림 크기는 모서리 핸들을 끌어 조절합니다.
  4. 가리고 싶은 부분은 화이트아웃으로 사각형을 드래그해 덮고, 고친 내용으로 바꾸려면 그 위에 텍스트 상자를 놓습니다.
  5. PDF 저장을 누르고, 다운로드한 -edited.pdf 파일을 열어 어디로 보내기 전에 수정한 곳을 하나하나 확대해 확인합니다.

이 도구가 필요한 경우

  • 인쇄된 공지문을 다시 내보내기 전에 빠진 날짜, 문서 번호, 호실 번호를 채워 넣을 때.
  • PDF로 받은 거래처 청구서에 회사 로고나 '지급 완료' 도장 이미지를 찍을 때.
  • 평면도나 학습지에 손으로 그린 동그라미, 화살표, 짧은 메모를 남길 때.
  • 원본 Word나 Canva 파일을 잃어버린 전단지의 오타를 고칠 때. 화이트아웃으로 가리고 그 위에 맞는 글자를 입력합니다.
  • 원래 텍스트 레이어가 없는 스캔 페이지에 손글씨 느낌의 코멘트를 달 때.
  • 짧은 계약서의 모든 페이지 구석에 이니셜 이미지를 넣을 때.

시작하기 전에 알아둘 점

  • 기존 텍스트를 그 자리에서 고칠 수는 없습니다. 이 도구는 레이어를 더할 뿐, 이미 있는 글을 다시 배치하거나 다시 입력하지 않습니다. 문단을 제대로 고치려면 원본 작업 파일이 필요합니다.
  • 화이트아웃은 눈에 안 보이게 가릴 뿐입니다. 흰 상자는 위에 찍히는 이미지의 일부이고, 원래 텍스트는 그 아래 파일에 남아 있어 선택·복사·검색이 됩니다. 기밀 정보를 지우는 용도로는 절대 쓰지 마세요.
  • 추가한 모든 요소는 이미지로 합쳐집니다. 입력한 텍스트도 픽셀이 되므로 검색되지 않고, 복사할 수 없으며, 화면 낭독기가 읽지 못합니다.
  • 추가 레이어는 화면 해상도(페이지 너비 최대 880픽셀)로 만들어집니다. A4 페이지 기준 대략 인치당 100픽셀이라, 입력한 글자가 화면에서는 괜찮아도 인쇄하거나 크게 확대하면 약간 흐릿해 보일 수 있습니다.
  • 저장할 때는 수정하지 않은 페이지를 포함해 모든 페이지에 PNG 레이어가 들어갑니다. 빈 레이어는 잘 압축되지만, 결과물이 원본보다 다소 커진다고 생각하세요.
  • 화면의 글꼴과 저장된 글꼴은 조금 다를 수 있습니다. 저장 단계에서 텍스트를 선택한 크기의 Helvetica나 Arial로 그리기 때문입니다. 특히 좁은 공간에 끼워 넣은 글은 다운로드한 파일에서 줄 위치를 확인하세요.

더 좋은 결과를 위한 팁

  • 텍스트를 놓으려고 클릭하기 전에 색상과 크기를 먼저 정하세요. 값은 상자가 만들어질 때 적용되므로, 나중에 바꿔도 이미 있는 상자의 모양은 바뀌지 않습니다.
  • 수정할 때는 화이트아웃 사각형을 먼저 놓고, 바꿀 텍스트를 그다음에 놓으세요. 그래야 글자가 흰 영역 위에 보입니다.
  • 로고와 도장에는 투명 배경 PNG를 쓰세요. JPG는 흰색 사각형 배경까지 함께 들어와 뒤에 있는 내용을 덮습니다.
  • 파일을 열기 전에 브라우저 배율을 편한 크기로 맞춰 두세요. 페이지는 그 순간 사용할 수 있는 너비에 맞춰 렌더링됩니다.
  • 인쇄용으로 더 선명한 글자가 필요하다면, 화면 해상도 레이어의 영향을 가장 크게 받는 작은 글씨 대신 짧은 메모를 큰 크기(14 이상)로 쓰세요.

예시: 임대료 인상 안내문을 고치는 집주인

수원에서 원룸 건물을 운영하는 집주인 정미경 씨에게 몇 달 전 문서 프로그램에서 내보낸 두 페이지짜리 임대료 인상 안내문이 있습니다. 그 프로그램은 이제 컴퓨터에 없습니다. 새 임대료 금액은 맞는데 적용일이 4월 1일이어야 할 것이 3월 1일로 되어 있고, 세입자 네 명에게 이메일로 보내기 전에 위쪽 구석에 건물 로고도 넣어야 합니다.

정미경 씨는 PDF 편집에서 '3월' 위로 화이트아웃 사각형을 드래그하고, 텍스트로 바꿔 크기 12, 검정으로 정한 뒤 흰 부분 바로 위를 클릭해 '4월'을 입력합니다. 이어서 이미지를 고르고 첫 페이지 오른쪽 위 구석을 클릭해 로고 PNG를 선택한 뒤, 모서리 핸들로 크기를 줄입니다. 저장하면 rent-notice-edited.pdf가 나오고, 화면에서는 의도한 대로 정확히 읽힙니다.

잊지 말아야 할 점이 있습니다. '3월'이라는 글자는 흰 상자 아래 파일 안에 그대로 있습니다. 세입자가 PDF에서 '3월'을 검색하면 찾을 수 있습니다. 가벼운 정정이라면 괜찮지만, 나중에 분쟁으로 이어질 수 있는 문서라면 안내문을 처음부터 다시 만들거나 최소한 정정했다는 설명을 한 줄 덧붙이는 편이 좋습니다.

문제 해결

페이지는 보이는데 클릭해도 아무 일이 없습니다
어떤 모드가 선택되어 있는지 확인하세요. 이동 모드에서는 빈 곳을 클릭해도 아무 일도 일어나지 않으니 텍스트, 이미지, 그리기로 바꾸세요. 이미 놓은 요소가 아니라 페이지의 빈 곳을 클릭하고 있는지도 확인하세요.
저장한 파일에서 입력한 글자 위치가 달라졌습니다
저장할 때 표준 산세리프 글꼴로 텍스트를 다시 그리기 때문에 줄 너비가 몇 픽셀 달라질 수 있습니다. 좁은 칸에 넣은 글 주위에는 여유를 조금 두고, 결과를 다시 확인하세요.
화이트아웃으로 가린 글자가 검색하면 나옵니다
원래 그렇게 동작합니다. 화이트아웃은 칠한 사각형이지 삭제가 아닙니다. 내용을 정말로 없애려면 원본 작업 파일에서 문서를 다시 만들거나, 편집한 파일을 새 PDF로 인쇄한 뒤 페이지를 이미지로 바꾸는 도구에 넣으세요.
로고 주위에 흰 상자가 생깁니다
사용한 이미지가 JPG이거나 투명도가 없는 PNG입니다. 로고를 투명 배경 PNG로 내보낸 뒤 다시 넣으세요.
'이 PDF를 표시할 수 없습니다'라는 메시지가 나옵니다
파일에 비밀번호가 걸려 있거나, 손상되었거나, 실제로는 PDF가 아닙니다. 파일을 만든 앱에서 비밀번호를 해제하거나, 먼저 PDF 복구에 넣은 뒤 복구된 사본을 여세요.
저장이 오래 걸리거나 탭이 멈춥니다
저장할 때 페이지마다 페이지 전체 크기의 PNG를 만들기 때문에, 긴 문서는 한꺼번에 많은 이미지가 메모리에 올라갑니다. 페이지 추출로 필요한 페이지만 떼어 내 편집한 뒤 다시 병합하세요.

자주 묻는 질문

PDF에 있는 기존 글자를 바꿀 수 있나요?

아니요. 이 도구는 페이지 위에 새 내용을 더합니다. 기존 텍스트를 화이트아웃으로 덮고 그 위에 바꿀 내용을 입력할 수는 있지만, 원래 글자는 아래 파일에 남아 있습니다.

추가한 텍스트도 검색되나요?

아니요. 추가한 텍스트, 서명, 그림은 저장할 때 그림 레이어로 합쳐지므로 선택하거나 검색할 수 없습니다. 문서의 원래 텍스트는 계속 검색됩니다.

편집하면 원본 페이지의 화질이 떨어지나요?

아니요. 원본 페이지 내용은 그대로 두고 그 위에 새 레이어를 얹습니다. 화면 해상도로 만들어지는 건 추가한 요소뿐입니다.

저장하기 전에 수정한 것을 되돌릴 수 있나요?

텍스트 상자, 이미지, 서명은 각 요소의 ×로 지울 수 있습니다. 손으로 그린 선과 화이트아웃 사각형은 바로 칠해지기 때문에 하나씩 지울 수 없으니, 처음부터 다시 하려면 파일을 다시 불러오세요.

스캔한 문서도 편집할 수 있나요?

네. 스캔본은 페이지마다 이미지 한 장일 뿐이라 텍스트, 도장, 표시를 똑같이 추가할 수 있습니다. 다만 스캔된 글자 자체는 바꿀 수 없고, 가리거나 주석을 달 수만 있습니다.

PDF 편집은 무료인가요?

네, 계정도 워터마크도 없습니다. 페이지 렌더링부터 새 파일 생성까지 모든 과정이 브라우저 탭 안에서 이뤄집니다.

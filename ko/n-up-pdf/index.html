N-up (시트당 페이지)

PDF 페이지를 가로 방향 A4 한 장에 2개 또는 4개씩 나란히 배치해, 긴 문서를 더 적은 종이로 인쇄합니다.

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

슬라이드 60장짜리 강의 자료를 한 장에 하나씩 인쇄하면 종이 60장이 들고, 교실 끝에서도 읽힐 만큼 큰 슬라이드가 나옵니다. 모아찍기(N-up)는 여러 페이지를 한 장에 넣습니다. PDFora의 N-up 도구는 원본 페이지를 시트마다 2개 또는 4개씩 담은 새 PDF를 만들어, 프린터 드라이버 설정을 만지지 않고도 어떤 프린터에서든 바로 인쇄할 수 있게 해 줍니다. 인쇄 대화상자 대신 PDF 자체에서 하면 실용적인 장점이 있습니다. 레이아웃이 파일에 고정되므로 집의 잉크젯, 사무실 복합기, 인쇄소 기계 어디서든 똑같이 인쇄되고, 종이 한 장 쓰기 전에 화면에서 확인할 수 있습니다. 또 N-up 버전을 다른 사람에게 메일로 보내면서 드라이버 설정을 설명할 필요도 없습니다.

레이아웃은 고정되어 있고 예측 가능합니다. 결과 시트는 모두 가로 방향 A4(842 x 595포인트)입니다. 2-up은 시트를 두 칸으로, 4-up은 2 x 2 격자로 나누며 윗줄부터 왼쪽에서 오른쪽으로 채웁니다. 각 원본 페이지는 왜곡 없이 칸에 맞게 축소된 뒤, 페이지 사이에 약간의 간격이 생기도록 칸의 95%로 줄여 가운데에 놓입니다.

페이지를 그림으로 바꾸지 않습니다. pdf-lib가 각 원본 페이지를 벡터 객체로 새 시트에 넣으므로, 원래 크기의 4분의 1로 줄어도 텍스트와 선은 선명하게 인쇄됩니다. 작업은 브라우저 안에서 이루어지고 다운로드 파일 이름은 yourfile-nup.pdf 형태입니다. 배율은 페이지마다 따로 계산되므로, 세로 텍스트 페이지와 가로 차트가 섞인 문서도 각 페이지가 자기 칸에 들어가는 가장 큰 크기로 배치됩니다.

PDF 여러 페이지를 한 장에 모아 넣는 방법

  1. N-up 도구를 열고 PDF 한 개를 선택합니다.
  2. 시트당 페이지 수에서 2-up 또는 4-up을 고릅니다. 기본값은 2-up입니다.
  3. N-up 만들기를 누릅니다. 긴 문서는 모든 페이지를 넣는 동안 잠시 걸립니다.
  4. 결과를 열어 시트 하나를 확대해 보고, 가장 작은 글씨가 그 크기에서도 읽히는지 판단합니다.
  5. A4 용지에 100% 또는 '페이지에 맞춤'으로 인쇄합니다. Letter 용지라면 잘리지 않도록 페이지에 맞춤을 고르세요.

이 도구가 필요한 경우

  • 강의 슬라이드를 한 장에 2개나 4개씩 유인물로 인쇄하고, 여백에 필기할 공간을 남길 때.
  • 긴 초안을 종이로 교정하면서 종이를 절반이나 4분의 1만 쓰고 싶을 때.
  • 매뉴얼, 서식, 체크리스트를 바인더에 넣어 둘 작은 참고용 사본으로 만들 때.
  • 연속된 두 페이지를 펼침면처럼 나란히 놓고 레이아웃을 빠르게 눈으로 확인할 때.
  • 큰 제목과 도표 위주인 회의 자료의 인쇄 비용을 줄일 때.
  • 페이지마다 하나씩 저장된 작은 영수증이나 티켓을 한 장에 모아 인쇄해 보관할 때.

시작하기 전에 알아둘 점

  • 2-up과 4-up만 제공합니다. 6-up, 8-up, 사용자 지정 격자는 없습니다.
  • 결과 시트는 원본 페이지 크기와 상관없이 항상 가로 방향 A4입니다. US Letter로 인쇄한다면 인쇄 대화상자에서 페이지에 맞춤을 고르세요.
  • 세로 페이지는 2-up에서는 나란히 놓여 시트 높이를 거의 채웁니다. 4-up에서는 꽤 작아져서, A4 페이지가 원래 너비와 높이의 약 3분의 1 크기가 됩니다.
  • 페이지는 읽는 순서를 유지합니다. 4-up에서 1페이지는 왼쪽 위, 2는 오른쪽 위, 3은 왼쪽 아래, 4는 오른쪽 아래입니다. 페이지 수가 2나 4의 배수가 아니면 마지막 시트에 빈 칸이 생깁니다. 빈 칸은 흰색으로 남고, 무언가를 반복해 채우지 않습니다.
  • 링크, 양식 필드, 댓글, 책갈피는 옮겨지지 않습니다. 페이지 내용이 그림처럼 복사되고 원본의 상호작용 요소는 남겨집니다.
  • 원본 파일에 설정된 페이지 회전 값이 반영되지 않을 수 있어, 회전 정보 때문에만 옆으로 보이던 페이지가 옆으로 누워 나올 수 있습니다. 그럴 땐 PDF 회전 도구로 먼저 바로잡아 저장하세요.

더 좋은 결과를 위한 팁

  • 슬라이드는 가로 방향에 글씨가 커서 보통 4-up이 잘 맞습니다. 세로 텍스트 문서는 2-up이 종이 절약과 가독성 사이에서 더 나은 선택입니다.
  • 넓은 흰 여백은 PDF 자르기 도구로 먼저 잘라 내세요. 내용이 칸을 더 많이 채워 글씨가 크게 인쇄됩니다.
  • N-up 파일을 만들기 전에 빈 페이지나 필요 없는 페이지를 지우세요. 그대로 두면 칸 하나를 차지합니다.
  • 유인물 순서를 바꾸고 싶다면 페이지 정리 도구로 먼저 정렬하세요. N-up은 페이지를 엄격히 순서대로 배치합니다.
  • 긴 인쇄 작업을 보내기 전에 한 장만 시험 인쇄해 보세요.

실제 예시: NGO 교육의 워크숍 유인물

한 작은 NGO가 자원봉사자 25명을 대상으로 하루 교육을 열면서, 슬라이드 48장짜리 자료를 모두에게 종이로 나눠 주려고 합니다. 한 장에 슬라이드 하나면 1인당 48장, 총 1,200장입니다.

담당자 최유진 씨는 자료를 PDF로 내보내 4-up으로 N-up 도구를 실행합니다. 결과는 1인당 가로 A4 12장입니다. 슬라이드에 큰 제목과 단순한 도표가 쓰여서 4분의 1 크기로도 읽힙니다. 양면 인쇄하면 자원봉사자 1인당 종이 6장, 총 150장입니다.

슬라이드 두 장에는 촘촘한 표가 있어 4-up에서는 너무 작았습니다. 담당자는 자료 전체를 2-up으로 바꿔 종이를 두 배로 쓰는 대신, 그 두 페이지만 추출해 원래 크기로 따로 인쇄했습니다. 그리고 N-up 유인물과 원래 크기 두 페이지를 합쳐 자원봉사자마다 스테이플러로 묶은 한 세트를 나눠 주고, 원본 자료는 당일 화면에 띄우는 용도로 남겨 두었습니다.

문제 해결

글씨가 너무 작아 읽을 수 없어요
4-up에서 2-up으로 바꾸거나, 원본의 흰 여백을 먼저 잘라 내거나, 촘촘한 페이지만 원래 크기로 따로 인쇄하세요.
인쇄물 가장자리가 잘려요
프린터 용지가 A4가 아니거나 프린터가 가장자리까지 인쇄하지 못하는 경우입니다. 인쇄 대화상자에서 페이지에 맞춤이나 큰 페이지 축소를 고르세요.
일부 페이지가 옆으로 누워 있어요
원본 페이지가 회전 설정에 의존하고 있을 수 있습니다. 원본 페이지를 똑바로 회전해 저장한 뒤 N-up을 다시 실행하세요.
원본의 링크가 더 이상 작동하지 않아요
정상입니다. N-up은 페이지 내용만 복사합니다. 화면으로 읽을 때는 원본 파일을 쓰세요.
마지막 시트가 반쯤 비어 있어요
페이지 수가 시트당 페이지 수의 배수가 아니기 때문입니다. 그대로 두거나, N-up 파일을 만들기 전에 페이지를 빼거나 더하세요.
특정 파일에서 도구가 실패해요
손상되었거나 특이한 PDF는 넣기에 실패할 수 있습니다. PDF 복구 도구로 처리한 사본으로 다시 시도하세요.

자주 묻는 질문

N-up 후에도 텍스트가 선명한가요?

네. 각 페이지가 이미지가 아니라 벡터 내용으로 들어가므로 축소되어도 텍스트와 선이 선명하게 인쇄됩니다.

결과 용지 크기를 고를 수 있나요?

아니요. 결과는 항상 가로 방향 A4입니다. 다른 용지에는 인쇄 대화상자의 페이지에 맞춤 옵션을 쓰세요.

한 장에 6개나 9개 페이지를 넣을 수 있나요?

현재는 안 됩니다. 이 도구는 2-up과 4-up만 제공합니다. 더 많이 넣으려면 프린터 드라이버의 모아찍기 옵션이 도움이 될 수 있습니다.

페이지 사이에 테두리를 그려 주나요?

선은 그리지 않습니다. 각 페이지가 칸의 95%로 줄어들어 페이지 사이에 작은 흰 간격이 생깁니다.

크기가 다른 페이지는 어떻게 되나요?

각 페이지가 비율을 유지한 채 자기 칸에 맞게 따로 축소되므로, 크기가 섞여 있으면 시트에서 서로 다른 배율로 보입니다.

계정이 필요한가요?

아니요. 가입 없이 브라우저에서 바로 작동합니다.

N-up (시트당 페이지)

여러 페이지를 한 장에 모아 배치해 인쇄할 때 종이를 아끼세요.

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

N-up 인쇄는 인쇄소의 오래된 기법입니다. 여러 페이지를 축소해 한 장에 배치하는 것이죠. PDFora의 N-up 도구는 이 기법을 브라우저로 가져왔습니다. 한 장에 2페이지 또는 4페이지를 고르면 도구가 문서를 가로 방향 A4에 배치해 인쇄할 준비를 마칩니다. 60페이지 슬라이드 자료가 15장이 되고, 40페이지 매뉴얼이 10장이 됩니다. 종이도 토너도 덜 들고, 결과물이 서류철에 실제로 들어갑니다.

모든 작업은 사용자 컴퓨터에서 이뤄집니다. PDF를 읽고 다시 구성하는 일을 서버가 아니라 브라우저가 하므로, 기밀 이사회 자료나 미공개 원고가 있던 자리에 그대로 남습니다. 무료이고 가입도 필요 없으며 워터마크도 붙지 않고, 하루에 몇 개의 문서를 처리하든 제한이 없습니다.

프린터 드라이버에도 모아 찍기 기능이 있지만, 그 설정은 프린터마다 다른 곳에 숨어 있고 파일을 공유하는 순간 사라집니다. N-up 레이아웃을 PDF 자체에 넣어 두면 파일을 받은 사람은 누구나 기본으로 압축된 형태를 인쇄하게 됩니다.

온라인에서 한 장에 여러 PDF 페이지 모아 배치하는 방법

  1. getpdfora.com에서 N-up 도구를 열고 PDF를 끌어다 놓거나 찾아서 추가합니다. 업로드 없이 브라우저에서 열립니다.
  2. 레이아웃을 고릅니다. 한 장에 2페이지(나란히) 또는 한 장에 4페이지(2×2 격자) 중에서 선택하세요.
  3. 결과물 용지는 가로 방향 A4입니다. 두 설정 모두에서 세로 페이지가 읽기 좋게 유지됩니다.
  4. 버튼을 클릭해 N-up 버전을 생성합니다. 페이지가 자동으로 축소되고 배치됩니다.
  5. 미리보기로 페이지 순서와 크기가 용도에 맞는지 확인합니다.
  6. 새 PDF를 내려받아 평범한 문서처럼 인쇄합니다. 종이 한 장이 결과물 한 페이지입니다.

When to use this tool

  • 강의 슬라이드를 4-up 유인물로 인쇄해, 세미나 전체 자료가 얇은 바인더에 들어가게 하기.
  • 100페이지 보고서를 2-up으로 압축 출력해 메모용 교정본을 만들고, 전체 인쇄의 절반만 종이 쓰기.
  • 악보를 압축해 연주자가 두 페이지를 한 번에 볼 수 있게 하고, 악구 중간에 페이지를 넘기지 않게 하기.
  • 소프트웨어 요약표 네 페이지를 한 장에 배치한 뒤 4등분해 휴대용 참고 카드 만들기.
  • 참석자 30명이 모이는 워크숍에서 배포할 교육 매뉴얼의 종이 비용 줄이기.
  • 전면 인쇄물을 넘겨 가며 보는 대신 스토리보드 프레임을 나란히 놓고 검토하기.

Tips for the best results

  • 4-up에서는 작은 글씨가 읽기 어려워집니다. 원본이 10pt 이하 글꼴을 쓴다면 보통 한 장에 2페이지가 낫습니다.
  • 글씨가 큰 슬라이드는 4-up도 잘 견디지만 빽빽한 법률 문서는 대개 그렇지 않습니다. 전체를 돌리기 전에 테스트로 한 장만 인쇄해 보세요.
  • N-up과 양면 인쇄를 함께 쓰면 4-up 레이아웃으로 종이 한 장에 여덟 페이지가 들어갑니다.
  • 빈 페이지나 채움 페이지는 먼저 지우세요. 그러지 않으면 격자의 자리를 차지해 매 장마다 공간을 낭비합니다.
  • 화면으로 읽을 때는 원래의 한 페이지짜리 PDF를 쓰고, N-up 버전은 인쇄 전용으로 두세요. 형식마다 어울리는 매체가 있습니다.

자주 묻는 질문

N-up이란 정확히 무슨 뜻인가요?

N은 한 장에 배치되는 페이지 수를 뜻합니다. 2-up은 한 장에 두 페이지, 4-up은 격자 형태로 네 페이지입니다. 인쇄업계에서 종이를 아끼려고 수십 년간 써 온 표준 조판 기법입니다.

결과물이 왜 가로 방향 A4인가요?

세로 페이지 두 장이나 네 장은 가로 방향 용지에 자연스럽게 들어갑니다. 그래서 이 방향이 여유 있는 배율과 읽기 좋은 글자 크기를 유지해 줍니다. 결과물을 인쇄할 때 프린터를 가로 방향으로 설정하는 것만 잊지 마세요.

제 문서가 어딘가로 업로드되나요?

아니요. PDFora는 N-up 레이아웃을 전부 브라우저 안에서 구성하므로 파일이 기기를 벗어나지 않습니다. 처리 속도는 서버가 아니라 컴퓨터 성능에 달려 있으며 대부분의 문서는 몇 초면 끝납니다.

N-up 인쇄로 종이를 얼마나 아낄 수 있나요?

2-up 레이아웃은 페이지 수를 절반으로, 4-up은 4분의 1로 줄입니다. 양면 인쇄와 함께 쓰면 200페이지 문서가 25장으로 나올 수 있습니다.

축소한 뒤에도 페이지가 읽히나요?

2-up이라면 대개 그렇습니다. 각 페이지가 원래 치수의 70% 정도를 유지하니까요. 4-up에서는 각 페이지가 가로세로 절반 크기가 되는데, 슬라이드에는 잘 맞지만 작은 글씨는 눈에 부담이 될 수 있습니다.

비용이 들거나 워터마크가 붙나요?

아니요. N-up 도구는 완전히 무료이고 계정도 필요 없으며 결과물에 워터마크를 넣지 않고 파일 수나 사용량에 상한도 없습니다.

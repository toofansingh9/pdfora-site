PDF 분할

PDF를 페이지 범위별로, N페이지마다, 또는 한 페이지씩 개별 파일로 분할합니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

90페이지짜리 PDF가 90페이지 그대로 쓸모 있는 경우는 드뭅니다. 보통은 동료에게 줄 2장, 고객에게 보낼 40~55쪽, 또는 보관용으로 페이지마다 하나씩 나눈 파일이 필요하죠. PDFora의 분할 도구는 PDF 하나를 여러 개로 나누며, 방법도 세 가지를 제공합니다. 페이지마다 개별 PDF로 나누기, 직접 입력한 페이지 범위로 나누기, N페이지 단위로 자동 분할하기입니다.

모든 처리는 브라우저 안에서 실행됩니다. 분할할 파일은 사용자 컴퓨터에서 열리고 처리되며, 서버로 전송되거나 클라우드 저장소에 보관되거나 누군가의 처리 대기열을 거치지 않습니다. 법률 자료 묶음, 인사 서류처럼 남의 컴퓨터에 올리고 싶지 않은 문서라면 이 차이가 다른 어떤 기능보다 중요합니다.

이 도구는 무료이고, 가입이 필요 없으며, 워터마크도 붙이지 않습니다. 분할 결과가 여러 파일이면 하나의 ZIP으로 묶여 나오므로 열두 번 대신 한 번만 깔끔하게 내려받으면 됩니다. 한 번을 쓰든 백 번을 쓰든 횟수를 세지 않습니다.

온라인에서 PDF 분할하는 방법

  1. getpdfora.com의 PDF 분할 도구로 가서 PDF를 선택하거나 끌어다 놓습니다.
  2. 분할 방식을 고릅니다. 페이지마다 개별 PDF, 직접 지정한 범위, N페이지 단위 중에서 선택하세요.
  3. 범위를 직접 지정할 때는 말하듯 입력하면 됩니다. 예를 들어 1-3, 4-6이라고 쓰면 파일 두 개가 만들어집니다.
  4. 고정 단위로 나눌 때는 파일당 페이지 수를 10처럼 입력하면 도구가 문서를 자동으로 나눕니다.
  5. 분할을 누릅니다. 브라우저가 로컬에서 순식간에 PDF를 자릅니다.
  6. 결과 PDF가 모두 담긴 ZIP 파일을 내려받아 원하는 곳에 풀면 됩니다.

When to use this tool

  • 스캔한 서명 양식 묶음을 보관하기 전에 양식마다 하나의 PDF로 나누기
  • 교재나 강의 자료집을 장별로 나눠 학생들이 필요한 부분만 내려받게 하기
  • 긴 이사회 자료를 나눠 각 부서가 자기 부분만 받도록 하기
  • 한 번에 하나의 명세서만 받는 회계 소프트웨어를 위해 은행 거래내역 내보내기 파일을 월별로 나누기
  • 학술대회 자료집 PDF를 개별 논문으로 분리해 인용하고 공유하기
  • 이메일 첨부 용량 제한을 넘기기 위해 큰 보고서를 10페이지 단위로 자르기

Tips for the best results

  • 범위를 입력하기 전에 PDF를 훑어보며 각 섹션이 시작되는 페이지 번호를 적어 두세요. 두 번 작업하는 수고를 덜어 줍니다.
  • 범위 길이가 제각각이어도 됩니다. 섹션 길이가 다르다면 1-3, 4-6, 7-20처럼 써도 전혀 문제없습니다.
  • 중복된 양식이나 길이가 일정한 명세서처럼 구조가 규칙적이면 N페이지 단위 모드를 쓰세요.
  • 전부가 아니라 한 섹션만 필요하다면 전체를 분할하기보다 페이지 추출 도구를 쓰는 편이 빠릅니다.
  • 아주 긴 스캔 문서를 분할하면 기기 메모리를 많이 쓰므로 오래된 컴퓨터에서는 잠시 기다려 주세요.

자주 묻는 질문

PDF를 페이지별로 나누려면 어떻게 하나요?

모든 페이지를 개별 PDF로 저장하는 모드를 고른 뒤 분할을 누르세요. 30페이지 문서가 30개의 파일이 되어 하나의 ZIP으로 함께 제공됩니다.

원하는 페이지 범위로 나눌 수 있나요?

네. 1-3, 4-6처럼 범위를 입력하면 각 범위가 개별 PDF가 됩니다. 범위는 원하는 만큼 정의할 수 있고 길이가 같을 필요도 없습니다.

결과가 왜 ZIP 파일로 내려받아지나요?

분할하면 대개 여러 PDF가 한꺼번에 만들어지는데, ZIP으로 묶으면 저장 창이 수십 번 뜨는 대신 정리된 파일 하나로 받을 수 있기 때문입니다. 압축을 풀면 순서대로 이름이 붙은 PDF가 모두 들어 있습니다.

분할할 때 제 문서가 업로드되나요?

아니요. PDFora는 파일을 브라우저 안에서 로컬로 처리하므로 PDF가 기기를 떠나지 않습니다. 그래서 계약서나 인사 파일 같은 기밀 자료에도 안전합니다.

분할할 수 있는 파일 크기 제한이 있나요?

저희가 정한 제한은 없습니다. 처리를 사용자 기기가 담당하므로 아주 큰 파일은 사용 가능한 메모리에 좌우됩니다. 대부분의 문서는 몇 초 만에 나뉘지만, 방대한 스캔 자료는 더 오래 걸릴 수 있습니다.

분할하면 PDF 품질이 떨어지나요?

아니요. 페이지는 재압축 없이 있는 그대로 새 파일에 복사됩니다. 텍스트는 선명하고 검색 가능한 상태로 유지되며 이미지도 원래 해상도를 그대로 지킵니다.

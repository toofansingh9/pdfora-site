PDF 분할

PDF 하나를 여러 개의 작은 PDF로 나눕니다. 페이지마다 한 파일, 일정한 페이지 수 단위, 또는 직접 입력한 범위대로 나눌 수 있습니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

긴 PDF는 당장 해야 할 일에 맞지 않는 경우가 많습니다. 담임 선생님은 32페이지짜리 출력물에서 학생마다 자기 성적표만 나눠 줘야 하고, 세입자는 40페이지 계약서 전체가 아니라 4~6페이지만 집주인에게 보내고 싶고, 스캐너는 서로 관계없는 우편물 한 묶음을 거대한 파일 하나로 만들어 버립니다. 분할은 이런 문서 하나를 독립된 여러 PDF로 바꿔, 각각 따로 이름 붙이고 메일로 보내고 보관할 수 있게 해 줍니다.

PDFora의 PDF 분할 도구에는 세 가지 방식이 있습니다. '모든 페이지'는 페이지마다 PDF 하나를 만듭니다. 'N페이지마다'는 문서를 같은 크기 묶음으로 자릅니다(기본값은 파일당 2페이지이고, 마지막 묶음에는 남은 페이지만 들어갑니다). '사용자 지정 범위'는 1-3, 4-6, 7-10처럼 그룹을 입력하는 방식으로, 쉼표마다 새 파일이 시작됩니다. 세 방식 모두 pdf-lib로 페이지를 있는 그대로 복사합니다. 텍스트는 계속 선택할 수 있고 이미지 해상도도 유지되며, 다시 그리는 부분이 없어서 결과물의 페이지는 원본의 같은 페이지와 똑같이 인쇄됩니다.

결과는 원래 파일 이름에 번호가 붙은 파일로 나옵니다. contract.pdf라면 contract-1.pdf, contract-2.pdf 식입니다. contract-split.zip으로 한꺼번에 받거나 목록에서 파일을 하나씩 받을 수 있습니다. 복사 작업이 브라우저 탭 안에서 이루어지므로 속도는 서버 대기열이 아니라 사용하는 기기 성능에 달려 있습니다.

PDF를 여러 파일로 나누는 방법

  1. PDF 분할 도구를 열고 파일 하나를 추가합니다. 한 번에 문서 하나만 처리합니다.
  2. 분할 방식을 고릅니다. 모든 페이지, N페이지마다, 사용자 지정 범위 중 하나입니다.
  3. N페이지마다는 묶음 크기를 입력합니다. 사용자 지정 범위는 1-2, 3, 4-9처럼 쉼표로 구분해 그룹을 입력하며, 그룹 하나가 파일 하나가 됩니다.
  4. PDF 분할을 누르고 진행 표시줄이 끝날 때까지 기다립니다. 그룹마다 결과 파일이 하나씩 만들어집니다.
  5. 모두 다운로드 (.zip)를 누르거나 파일을 하나씩 받은 뒤, 두어 개를 열어 나뉜 위치가 맞는지 확인합니다.

이 도구가 필요한 경우

  • 학교: 성적표나 상장을 일괄 출력한 파일을 학생별 파일로 나눠 학부모에게 보낼 때.
  • 임대차 서류: 긴 계약서에서 서명 페이지나 특약 사항 한 부분만 뽑아 상대방에게 보낼 때.
  • 경리 업무: 한꺼번에 스캔한 한 장짜리 거래명세서를 건별 PDF로 나눠 회계 프로그램에 올릴 때.
  • 출판 준비: 원고를 장별 파일로 잘라, 자기 담당 부분만 보면 되는 베타 리더에게 보낼 때.
  • 페이지 수 제한이 있는 사이트: 업로드 한 번에 몇 페이지만 받는 접수 시스템에 맞춰 N페이지씩 나눌 때.
  • 인쇄: 보고서에서 컬러 페이지만 따로 파일로 만들어 인쇄소에 보낼 때.

시작하기 전에 알아둘 점

  • 사용자 지정 범위에서 4-6은 4, 5, 6페이지를 모두 포함한다는 뜻입니다. 한쪽 끝을 비워 둘 수도 있습니다. -5는 1~5페이지, 8-은 8페이지부터 마지막 페이지까지입니다.
  • 문서 끝을 넘는 번호는 거부되지 않고 잘려 나갑니다. 25페이지 파일에 20-30을 입력하면 20~25페이지가 나옵니다. 유효한 페이지가 하나도 없는 그룹은 건너뛰고, 남는 게 전혀 없으면 유효한 범위를 하나 이상 입력하라는 안내가 나옵니다.
  • 범위는 겹쳐도 됩니다. 1-5, 3-8은 3~5페이지가 둘 다 들어간 파일 두 개를 만듭니다. 받는 사람 모두에게 같은 표지가 필요할 때 유용하지만, 실수로 그렇게 되기도 쉽습니다.
  • 결과 파일에는 페이지만 담깁니다. 책갈피 목차는 복사되지 않고, 다른 파일로 간 페이지를 가리키던 링크는 작동하지 않으며, 입력 가능한 양식 필드는 남지 않을 수 있습니다. 페이지 안의 웹 링크는 계속 작동합니다.
  • 여러 페이지에서 쓰는 글꼴과 이미지는 그것이 필요한 각 파일에 다시 저장되므로, 나눈 파일을 모두 합친 크기는 보통 원본보다 다소 큽니다.
  • 결과 목록에는 최대 50개 파일까지 개별 다운로드 버튼이 표시됩니다. 300페이지 문서를 페이지별로 나누는 것도 가능하지만, 전부 받으려면 zip 다운로드를 사용하세요.

더 좋은 결과를 위한 팁

  • 시작하기 전에 뷰어의 페이지 썸네일을 보며 범위를 적어 두세요. 도구가 쓰는 페이지 번호는 바닥글에 인쇄된 번호가 아니라 파일 안에서의 실제 위치입니다.
  • 한 덩어리의 페이지만 필요하다면 페이지 추출을 쓰세요. 파일이 하나뿐인 zip 대신 파일 하나를 바로 받을 수 있습니다.
  • 압축을 풀자마자 파일 이름을 바꾸세요. 한 달 뒤에는 contract-3.pdf가 무엇인지 모르지만 계약서-특약.pdf는 바로 알 수 있습니다.
  • 문서마다 길이가 다른 스캔 묶음이라면 페이지를 손으로 세지 말고 텍스트 기준이나 책갈피 기준으로 나누세요.
  • 원본은 남겨 두세요. 분할은 되돌릴 수 없지만, 잘못 나눴다면 PDF 병합으로 언제든 다시 합칠 수 있습니다.

예시: 한 반 전체의 성적표

담임 선생님이 학교 업무 시스템에서 학생 28명의 학기말 성적표를 내려받았습니다. 받은 파일은 56페이지짜리 PDF 하나로, 학생마다 2페이지씩 늘 같은 순서이며 각 쌍의 첫 페이지에 학생 이름이 있습니다. 이 파일을 통째로 모든 가정에 보낼 수는 당연히 없습니다.

N페이지마다를 고르고 파일당 2페이지로 설정하자, 출석부 순서 그대로 reports-1.pdf부터 reports-28.pdf까지 28개 파일이 만들어집니다. 선생님은 reports-1과 reports-28을 열어 짝이 어긋나지 않았는지 확인합니다(만약 한 학생의 성적표가 3페이지였다면 그 뒤의 모든 파일이 한 페이지씩 밀렸을 테고, 그럴 때는 각 성적표 머리에 나오는 단어로 텍스트 기준 분할을 하는 편이 안전합니다). 짝이 맞는 것을 확인한 뒤 파일마다 학생 이름으로 바꾸고 해당 가정에 보내는 메시지에 첨부합니다.

문제 해결

'유효한 범위를 하나 이상 입력하세요'라고 나와요
입력한 범위 중 실제 페이지와 맞는 것이 하나도 없습니다. 워드프로세서에서 복사한 긴 대시(1–3), 문자, 문서보다 큰 페이지 번호 같은 오타가 있는지 확인하세요. 일반 하이픈과 쉼표를 쓰세요.
나뉜 파일이 한 페이지씩 밀려 있어요
도구는 파일 안에서의 위치로 페이지를 셉니다. 표지나 번호 없는 앞장이 있으면 인쇄된 1페이지가 실제로는 2페이지일 수 있습니다. 그만큼 범위를 조정하세요.
범위를 입력했는데 큰 파일 하나만 나왔어요
그룹은 쉼표로만 구분됩니다. 공백으로 띄운 1-3 4-6은 잘못된 범위 하나로 읽힙니다. 1-3, 4-6처럼 쓰세요.
결과 페이지가 비어 있거나 불러올 때 오류가 나요
원본이 암호화되었거나 손상되었을 가능성이 큽니다. 파일을 만든 앱에서 비밀번호를 해제하거나 먼저 PDF 복구를 실행한 뒤 깨끗한 사본을 나누세요.
책갈피와 내부 링크가 작동하지 않아요
분할은 페이지 내용만 복사합니다. 나눈 파일에 탐색 기능이 필요하면 책갈피 만들기로 각각 책갈피를 추가하세요. 다른 파일을 가리키는 내부 링크는 유지할 수 없습니다.
아주 큰 파일에서 브라우저가 느려져요
결과 파일은 모두 메모리 안에서 만들어집니다. 다른 탭을 닫거나, 먼저 큰 묶음으로 나눈 뒤 그 묶음을 다시 나누세요.

자주 묻는 질문

분할하면 페이지 화질이 달라지나요?

아닙니다. 페이지를 이미지로 렌더링하지 않고 객체 단위로 복사하므로 텍스트, 벡터 그림, 사진이 원본과 똑같습니다.

결과 파일 이름은 어떻게 정해지나요?

원래 파일 이름에 결과 순서대로 번호가 붙습니다. report.pdf라면 report-1.pdf, report-2.pdf 식이고 report-split.zip에 함께 담깁니다.

한 페이지가 여러 결과 파일에 들어갈 수 있나요?

네, 사용자 지정 범위에서 가능합니다. 1-2, 1, 3-5처럼 겹치게 입력하면 1페이지가 처음 두 파일에 모두 들어갑니다.

N페이지마다 방식에서 마지막 묶음은 어떻게 되나요?

남은 페이지가 들어갑니다. 10페이지 문서를 3페이지마다 나누면 3, 3, 3, 1페이지짜리 파일이 나옵니다.

PDF 여러 개를 한 번에 나눌 수 있나요?

아니요, 한 번에 파일 하나씩입니다. 문서마다 따로 나누거나, 하나의 흐름으로 잘라야 한다면 먼저 병합하세요.

계정이 필요한가요?

아니요. 가입이 필요 없고 분할 횟수 제한도 없습니다.

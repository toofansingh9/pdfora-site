PDF 병합 처리

대화형 양식 필드를 페이지에 병합해 더 이상 수정할 수 없게 만드세요.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

작성이 끝난 PDF 양식도 여전히 편집이 가능합니다. 파일을 연 사람은 누구나 필드를 클릭해 금액을 바꾸고 다른 항목에 체크한 뒤 다시 저장할 수 있죠. 대개 아무 흔적도 남지 않습니다. 플래튼(평면화)이 이 문제를 해결합니다. PDF를 플래튼하면 대화형 양식 필드가 페이지 자체에 병합되어, 입력한 답이 주변 인쇄 텍스트만큼이나 고정된 문서의 일부가 됩니다.

이 도구는 브라우저에서 한 번에 PDF 양식을 플래튼합니다. 파일을 끌어다 놓고 한 번 클릭한 뒤, 모든 텍스트 필드와 체크박스, 드롭다운 선택이 페이지에 새겨진 버전을 내려받으면 됩니다. 눈에 보이는 내용은 똑같고, 달라진 점은 더 이상 그 위에 타이핑할 수 없다는 것입니다. 연필 대신 잉크로 서명하는 것과 같은 셈이죠.

처리가 사용자 기기에서 로컬로 이뤄지므로 양식과 거기에 입력한 모든 내용이 비공개로 유지되며 아무것도 업로드되지 않습니다. 무료이고 계정도 필요 없으며 워터마크도 붙지 않고, 양식을 몇 개를 넣든 처리할 수 있습니다.

온라인에서 PDF 플래튼하는 방법

  1. 작성이 끝난 PDF 양식을 선택하거나 업로드 영역으로 끌어다 놓습니다. 어디로도 전송되지 않고 브라우저에서 바로 열립니다.
  2. 도구가 양식을 읽고 대화형 필드를 감지하는 동안 잠시 기다립니다.
  3. 표시되는 필드 개수를 확인해 양식이 제대로 인식됐는지 확인합니다.
  4. 플래튼 버튼을 클릭합니다. 모든 필드 값이 페이지에 영구적으로 그려지고 대화형 레이어가 제거됩니다.
  5. 플래튼된 PDF를 내려받습니다.
  6. 아무 뷰어에서나 열어 예전 필드 자리를 클릭해 보고, 답변이 고정됐는지 확인합니다.

When to use this tool

  • 서명된 임대차 계약서를 잠가, 양측이 사본을 가진 뒤에 세입자 정보나 날짜가 바뀌지 않게 하기.
  • 작성이 끝난 입사 지원서를 보관하기 전에 플래튼해, 인사 기록이 제출된 그대로 유지되게 하기.
  • 입력형 템플릿으로 만든 청구서를 준비해, 고객이 실수로 합계를 고치지 못하게 하기.
  • 세무나 관공서 양식을 이메일로 보내기 전에 고정하기. 일부 기관 시스템은 살아 있는 양식 필드가 있는 PDF를 거부합니다.
  • PDF 양식으로 수집한 설문 응답을 플래튼해, 검토 중에 데이터가 수정되지 않게 하기.
  • 인쇄 문제 해결하기. 일부 프린터는 양식 필드 내용을 아예 건너뛰는데, 플래튼하면 답변이 확실히 인쇄됩니다.

Tips for the best results

  • 원본 입력형 버전은 템플릿으로 남겨 두고, 누군가 작성할 때마다 사본을 플래튼하세요.
  • 양식을 다른 문서와 병합하기 전에 먼저 플래튼하세요. 병합 과정에서 중복된 필드 이름이 뒤엉킬 수 있습니다.
  • 작성된 양식이 다른 사람의 뷰어에서 비어 보인다면 대개 플래튼으로 해결됩니다. 값이 모든 뷰어가 표시할 수 있는 일반 페이지 내용이 되니까요.
  • 플래튼하기 전에 모든 필드가 채워졌는지 다시 확인하세요. 이후에는 필드에 입력할 수 없습니다.
  • 필드가 많은 양식은 대화형 레이어가 제거되면서 파일 크기도 조금 줄어듭니다.

자주 묻는 질문

PDF를 플래튼한다는 게 무슨 뜻인가요?

플래튼은 텍스트 필드, 체크박스, 드롭다운 같은 대화형 요소를 정적인 페이지 내용에 병합하는 것입니다. 입력한 답은 원래 자리에 그대로 보이지만, 편집 가능한 필드가 아니라 페이지 자체의 일부가 됩니다. 결과물은 스캔하거나 인쇄한 문서처럼 동작합니다.

플래튼된 PDF 양식을 다시 편집할 수 있나요?

양식 필드로는 안 됩니다. 필드 자체가 더 이상 존재하지 않으니까요. 본격적인 PDF 편집기를 가진 사람이라면 다른 PDF와 마찬가지로 페이지 내용을 손댈 수는 있지만, 답변을 손쉽게 고치는 일은 불가능해집니다. 대부분의 계약서와 제출 서류에는 바로 그 정도의 보호가 필요합니다.

플래튼하면 양식 모양이 바뀌나요?

아니요. 도구가 각 필드의 현재 값을 같은 위치와 같은 글자 크기로 페이지에 그리므로, 플래튼된 파일은 작성된 양식과 똑같이 보입니다. 사라지는 것은 상호작용 기능뿐입니다.

작성한 양식이 어딘가로 업로드되나요?

아니요. 전 과정이 브라우저에서 실행되므로 이름, 주소 등 민감한 답변까지 포함한 양식이 컴퓨터를 벗어나지 않습니다. 서버 기반 변환기에 비해 확실한 장점입니다.

왜 어떤 수신자에게는 제 양식 필드가 비어 보이나요?

일부 뷰어, 특히 휴대폰이나 일부 이메일 미리보기는 양식 필드 값을 렌더링하지 않습니다. 플래튼하면 답변이 일반 페이지 내용으로 바뀌어 어떤 PDF 뷰어에서도 제대로 표시됩니다.

서명이나 체크박스에도 플래튼이 적용되나요?

네. 체크박스 상태, 드롭다운 선택, 그리거나 입력한 서명 필드가 텍스트 필드와 함께 모두 페이지에 병합됩니다. 작성된 양식에서 보이던 모든 것이 플래튼된 상태로 보존됩니다.

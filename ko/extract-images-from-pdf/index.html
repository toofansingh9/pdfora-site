이미지 추출

PDF 안에 들어 있는 래스터 이미지를 추출해 PNG 파일로 내려받으세요.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

설정

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

정작 필요한 사진은 그 PDF 어딘가에 들어 있습니다. 제품 사진, 로고, 차트 같은 것들이죠. 화면을 캡처하면 잘리고 압축된 사본만 얻게 됩니다. 추출은 다릅니다. 이 도구는 PDF에 삽입된 원본 이미지를 문서를 만들 때 배치된 해상도 그대로 PNG 파일로 꺼내 줍니다. 찾아낸 이미지는 모두 ZIP으로 묶여 한 번에 내려받을 수 있습니다.

추출은 전부 브라우저 안에서 진행됩니다. PDF는 사용자 기기에서 열리고 읽히며 업로드되지 않으므로, 대외비 자료나 진료 기록, 미공개 브로슈어에서 이미지를 꺼내려고 파일을 서버에 먼저 넘길 필요가 없습니다. 계정을 만들 필요도 없고, 추출된 파일에 워터마크도 붙지 않으며, 문서 수나 이미지 수에 제한도 없습니다.

무엇이 이미지로 잡히는지 알아 두면 좋습니다. 이 도구는 문서에 이미지 파일로 삽입된 사진과 그래픽을 되살립니다. 텍스트, 벡터 로고, 그려진 도형은 그림이 아니라 명령이기 때문에 결과에 나타나지 않습니다. 그리고 스캔 PDF는 사실상 페이지당 커다란 이미지 한 장이므로 딱 그 형태로 추출됩니다.

온라인에서 PDF 이미지 추출하는 방법

  1. 이미지 추출 도구를 열고 PDF를 페이지 위에 끌어다 놓거나 클릭해서 선택합니다.
  2. 브라우저가 로컬에서 문서를 훑어 삽입된 이미지를 찾습니다. 파일 자체는 어디로도 전송되지 않습니다.
  3. 전체 페이지에서 몇 개의 이미지를 찾았는지 확인합니다.
  4. 추출을 눌러 각 이미지를 PNG 파일로 꺼냅니다.
  5. 추출된 이미지가 모두 담긴 ZIP 파일을 내려받습니다.
  6. 압축을 풀고 필요한 사진만 골라 쓰고 나머지는 지웁니다.

When to use this tool

  • 중개인이 원본을 보내 주지 않았을 때 부동산 매물이나 건물 브로슈어 PDF에서 사진 되찾기
  • 새 발표 자료에 쓰려고 예전 보도자료 키트에서 회사 로고나 제품 이미지 꺼내기
  • 노트북을 바꾸면서 원본 파일을 잃어버린 뒤, 몇 년 전에 쓴 보고서에서 도표와 사진 추출하기
  • 페이지마다 화면을 캡처하지 않고 공급업체의 PDF 카탈로그에서 온라인 스토어용 제품 사진 한꺼번에 모으기
  • PDF로 내보낸 슬라이드에서 도해를 저장해 이미지 편집기에서 수정하거나 다시 자르기
  • 행사 프로그램이나 뉴스레터에 실린 사진을 꺼내 SNS에 올리기

Tips for the best results

  • 추출된 이미지는 삽입 당시의 해상도로 나옵니다. 페이지에서 보이던 것보다 큰 경우가 많아 인쇄용으로 쓰기에 반가운 결과가 되곤 합니다.
  • 이미지를 하나도 찾지 못했다면 그 화면 요소는 벡터 그래픽이거나 순수 텍스트일 가능성이 큽니다. 그럴 때는 PDF to PNG로 페이지를 변환해 그림으로 담아내세요.
  • PDF는 같은 이미지를 여러 페이지에 재사용하기도 하므로 ZIP 안에 중복이 섞여 있을 수 있습니다. 가장 좋은 사본만 남기세요.
  • 스캔 문서는 페이지마다 전체 페이지 이미지 한 장이 나옵니다. 그것이 스캔본 자체이며 오류가 아니라 정상입니다.
  • 작은 아이콘까지 수십 개 들어 있는 문서라면 압축을 푼 폴더를 이미지 크기순으로 정렬하세요. 고해상도 사진을 빠르게 찾을 수 있습니다.

자주 묻는 질문

어느 정도 화질로 나오나요?

각 이미지는 삽입될 때의 해상도로 추출되고 PNG로 저장되므로 내보내는 과정에서 다시 압축되지 않습니다. 문서를 만든 사람이 고해상도 사진을 넣었다면 페이지에서 작게 보였더라도 그 고해상도 파일을 그대로 받게 됩니다.

화면 캡처보다 추출이 나은 이유는 뭔가요?

화면 캡처는 화면의 확대 배율 그대로 담기기 때문에 원본보다 작고 흐릿한 경우가 많습니다. 추출은 실제로 삽입된 파일을 원래 크기 그대로 깔끔하게 가져옵니다.

추출하는 동안 제 PDF가 업로드되나요?

아니요. 파일은 사용자 기기의 브라우저가 해석하며, 이미지도 사용자 컴퓨터 밖에는 존재하지 않습니다. 그래서 사내 문서나 기밀 문서에도 적합합니다.

일부 그래픽이 결과에 나오지 않는 이유는요?

벡터 그래픽으로 그려진 차트, 로고, 도형은 삽입된 이미지 파일이 아니므로 추출할 대상 자체가 없습니다. 그런 요소는 PDF to PNG 도구로 해당 페이지를 렌더링해 이미지로 담으세요.

추출된 이미지는 어떤 형태로 받나요?

모든 이미지는 PNG로 저장되어 하나의 ZIP 파일로 묶입니다. 사진이 마흔 장인 문서라도 내려받기는 한 번이면 됩니다. 압축을 풀어 살펴보고 필요한 것만 남기면 됩니다.

제한이나 요금이 있나요?

없습니다. 이 도구는 무료이고, 가입이 필요 없으며, 워터마크도 붙지 않고, PDF 개수나 그 안의 이미지 개수를 제한하지도 않습니다.

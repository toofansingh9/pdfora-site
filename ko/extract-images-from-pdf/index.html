이미지 추출

PDF 안에 들어 있는 사진과 그림을 저장된 픽셀 크기 그대로 개별 PNG 파일로 저장합니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

때로는 PDF 파일 자체보다 그 속에 담긴 그림이 목적일 때가 있습니다. 거래처 카탈로그의 상품 사진, 소식지 속 사진, 레터헤드의 로고 같은 것들이죠. 화면을 캡처하면 그때 화면에 보이는 크기대로 이미지를 얻고 손으로 잘라 내야 합니다. 추출하면 주변 페이지 없이, 파일에 저장된 원래 해상도 그대로 그림을 얻을 수 있습니다.

이 도구가 그림을 찾는 방식은 이렇습니다. 페이지마다 PDF.js가 그리기 명령 목록을 만들면, 도구는 그중 이미지 객체를 그리는 명령을 골라냅니다. 찾은 이미지는 각각 디코딩되어 원래 픽셀 너비와 높이 그대로 PNG 파일로 저장됩니다. 문서에 2000 x 1500픽셀로 들어간 사진은 페이지에서 작은 썸네일로 보였더라도 2000 x 1500으로 나옵니다. 파일 이름은 PDF 이름 뒤에 일련번호가 붙는 형식(예: catalogue-img-001.png)이며, catalogue-images.zip으로 묶입니다.

페이지 변환기는 아닙니다. 텍스트, 벡터 그림, 선과 도형으로 그린 차트, 색을 채워 만든 배경은 PDF 기준으로 이미지가 아니어서 추출되지 않습니다. 벡터로 저장된 로고는 나오지 않으며, 스캔 문서는 페이지마다 그림 한 장으로 저장되기 때문에 보통 페이지당 큰 이미지 하나가 나옵니다.

PDF에서 이미지를 추출하는 방법

  1. 이미지 추출을 열고 PDF 하나를 추가합니다.
  2. 이미지 추출 버튼을 누릅니다. 도구가 모든 페이지를 돌며 이미지 객체를 찾고, 진행 표시줄이 페이지를 따라 올라갑니다.
  3. 끝나면 찾은 파일 개수가 표시됩니다. ZIP 하나로 모두 다운로드하거나 목록에서 파일을 하나씩 고르세요(버튼은 최대 50개까지 표시됩니다).
  4. PNG를 열어 보고 필요 없는 건 지우세요. 글머리 기호나 배경 질감 같은 장식 요소도 함께 나오는 경우가 많습니다.
  5. 페이지에 보이는 그대로, 즉 잘린 상태에 글자가 겹쳐진 모습이 필요하다면 PDF를 PNG로를 쓰고 페이지 이미지를 잘라 내세요.

이 도구가 필요한 경우

  • 원본 이미지 파일을 끝내 받지 못한 작은 온라인 쇼핑몰이 거래처의 PDF 카탈로그에서 상품 사진을 되살릴 때.
  • 작년 연차 보고서를 만든 디자이너가 떠난 뒤, 비영리단체가 그 보고서의 사진을 새 발표 자료에 다시 쓸 때.
  • 연구 논문의 그림을 꺼내 원래 해상도로 자세히 볼 때.
  • 편지나 증명서에 그림으로 들어간 로고나 서명 이미지를 저장할 때.
  • 스캔한 PDF에서 페이지별 스캔 이미지를 꺼내 이미지 편집기에서 쓸 때.
  • 인쇄소에 넘기기 전에 인쇄용 파일 속 사진의 실제 해상도를 확인할 때.

시작하기 전에 알아둘 점

  • 페이지가 그리는 이미지 객체만 찾습니다. 벡터 로고, 선으로 그린 차트, 텍스트는 이미지가 아니라서 추출되지 않습니다.
  • 원래 형식과 상관없이 모든 결과 파일은 PNG입니다. PDF 속 JPEG 사진도 디코딩한 뒤 무손실 PNG로 저장하므로 원래 JPEG 데이터보다 커지는 경우가 많습니다.
  • 이미지는 페이지에 보이는 크기가 아니라 저장된 픽셀 크기로 저장됩니다. 페이지 레이아웃에서 적용한 자르기는 반영되지 않아, 페이지에서 보이던 것보다 사진이 더 넓게 나올 수 있습니다.
  • 여러 페이지에 쓰인 이미지는 쓰인 횟수만큼 저장됩니다. 20페이지에 들어간 로고라면 똑같은 파일이 20개 나옵니다.
  • 별도 객체가 아니라 페이지 내용 안에 직접 그려진 인라인 이미지와 일부 흔치 않은 색상 형식은 건너뜁니다. 또 이미지마다 디코딩 제한 시간이 4초라서, 그보다 오래 걸리는 이미지는 도구가 멈추지 않도록 건너뜁니다.
  • 소프트 마스크와 클리핑이 페이지에서 보이는 대로 적용되지 않을 수 있어, 오려 낸 모양의 이미지가 사각형 배경 전체를 단 채 나올 수 있습니다. 투명도가 있는 이미지는 PDF.js가 디코딩한 색상으로 PNG에 저장되며, CMYK 같은 색 공간은 그 과정에서 RGB로 바뀌기 때문에 인쇄 교정본과 비교하면 색이 약간 달라질 수 있습니다.

더 좋은 결과를 위한 팁

  • 압축하지 않은 원본 PDF로 실행하세요. 이미 압축을 거친 파일에는 축소된 이미지가 들어 있고, 추출해도 그 축소된 이미지가 나옵니다.
  • 추출한 파일을 크기순으로 정렬하면 진짜 사진을 빨리 찾을 수 있습니다. 아주 작은 파일은 대개 아이콘, 글머리 기호, 질감입니다.
  • 웹용 JPG가 필요하면 추출한 뒤 이미지 편집기나 일괄 변환 도구에서 원하는 압축률로 PNG를 변환하세요.
  • 벡터 로고는 원본 작업 파일을 요청하세요. 추출로는 벡터 도형을 이미지로 되살릴 수 없습니다.
  • 다른 사람 문서의 사진을 다시 쓰기 전에 사용 권한을 확인하세요. 이미지를 추출했다고 해서 저작권자가 바뀌지는 않습니다. 추출은 모든 페이지를 순서대로 읽으므로, 사진이 가득한 긴 카탈로그는 시간이 걸리고 다운로드할 때까지 디코딩한 이미지를 메모리에 들고 있습니다.

실제 예시: 쇼핑몰 사장님과 거래처 카탈로그

주방용품 온라인 쇼핑몰을 운영하는 오세영 씨가 신상품 30개를 등록하려고 합니다. 거래처는 24페이지짜리 PDF 카탈로그만 보냈을 뿐 사진 파일은 보내지 않았고, 여러 번 요청해도 답이 없습니다.

이미지 추출을 돌리자 PNG 파일 41개가 나옵니다. 30개는 상품 사진으로, 각각 너비 1200~1600픽셀이라 카탈로그 격자에서 보이던 것보다 훨씬 큽니다. 나머지는 여러 페이지에 반복된 거래처 로고와 배경 무늬 몇 개입니다. 파일 크기순으로 정렬하니 1분 만에 구분됩니다. 사진이 무손실 PNG라 쇼핑몰 상품 페이지에 쓰기엔 필요 이상으로 크기 때문에, 올리기 전에 직접 정한 품질의 JPG로 내보냅니다.

상품 두 개가 빠졌습니다. 확인해 보니 그 페이지의 '사진'은 벡터 그래픽으로 그린 일러스트라서 추출할 이미지 객체가 없었습니다. 이 두 개는 PDF를 PNG로에서 높음으로 페이지를 변환한 뒤, 페이지 이미지에서 상품 부분을 잘라 냅니다.

문제 해결

추출할 수 있는 이미지를 찾지 못했다고 나옵니다
PDF가 모든 것을 텍스트와 벡터 도형으로 그리거나, 도구가 읽지 않는 인라인 이미지를 씁니다. PDF를 PNG로나 PDF를 JPG로로 페이지를 변환한 뒤 필요한 부분을 잘라 내세요.
같은 로고가 수십 개 나왔습니다
로고가 모든 페이지에 그려져 있고, 쓰인 횟수마다 저장되었습니다. 중복 파일을 지우거나, 파일 이름순으로 정렬해 하나만 남기세요.
추출한 사진에 페이지에서는 잘려 있던 부분이 보입니다
페이지 레이아웃은 이미지를 표시할 때 자르거나 가리지만, 추출되는 건 저장된 이미지 전체입니다. 이미지 편집기에서 다시 잘라 주세요.
이미지가 기대보다 작습니다
PDF에 그 해상도로만 들어 있기 때문입니다. 이메일용으로 압축된 파일인 경우가 많습니다. 원본 파일이나 원본 이미지를 요청하세요.
PNG 파일들이 PDF보다 훨씬 큽니다
PDF 속 JPEG 사진을 디코딩해 무손실 PNG로 저장했기 때문입니다. 용량이 중요하면 JPG로 다시 저장하세요.
파일이 불러와지지 않습니다
비밀번호로 보호되어 있거나 손상되었을 수 있습니다. 원래 프로그램에서 비밀번호를 해제하거나, 먼저 PDF 복구를 실행하세요.

자주 묻는 질문

추출한 이미지는 어떤 형식인가요?

PDF에 어떻게 저장되어 있었든 모든 이미지는 PNG로 저장됩니다.

이미지가 원래 해상도로 추출되나요?

네. PDF에 저장된 픽셀 크기 그대로이며, 페이지에 보이는 것보다 클 수 있습니다.

추출된 파일 중에 로고가 없는 이유는 무엇인가요?

대부분 삽입된 그림이 아니라 벡터 그래픽이기 때문입니다. PDF를 PNG로를 써서 페이지 이미지의 일부로 저장하세요.

스캔한 PDF에서도 이미지를 추출할 수 있나요?

네. 스캔 페이지는 보통 그림 한 장으로 저장되어 있어서 페이지마다 이미지 하나씩 나옵니다.

일부 이미지가 빠진 이유는 무엇인가요?

인라인 이미지, 일부 특이한 색상 형식, 디코딩에 4초 넘게 걸리는 이미지는 건너뜁니다.

이미지가 어딘가에 업로드되나요?

아니요. 디코딩과 PNG 생성은 브라우저 탭 안에서 PDF.js로 이뤄지고, 파일은 바로 다운로드로 넘어옵니다.

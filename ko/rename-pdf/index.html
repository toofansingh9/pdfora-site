완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

scan_20260114_093412(3).pdf라는 이름은 첫인상이 좋을 리 없습니다. 이 도구는 메일에 첨부하거나 공유 폴더에 올리기 전에 PDF 이름을 Invoice-2041-March.pdf, Lease-Agreement-Signed.pdf처럼 명확하고 단정하게 바꿔 줍니다. 새 이름을 입력하고 사본을 내려받으면 끝입니다. 무료이고, 가입이 필요 없으며, 첫 번째 파일이든 열 번째 파일이든 똑같이 동작합니다.

보기 좋은 것 말고도 실용적인 이유가 있습니다. /, :, ?, 따옴표 같은 문자가 들어간 파일명은 시스템에 따라 저장이나 열기가 실패할 수 있고, 이상한 기호가 섞인 이름은 다운로드 링크나 동기화 도구를 망가뜨리기도 합니다. 여기서 PDF 이름을 바꾸면 문제가 되는 문자가 자동으로 제거되므로, 받는 사람이 어떤 기기를 쓰든 파일이 깔끔하게 열립니다.

다른 모든 PDFora 도구와 마찬가지로 이름 변경도 브라우저 안에서 로컬로 이뤄집니다. PDF는 어디로도 업로드되지 않으며, 같은 파일을 새 이름으로 돌려줄 뿐입니다. 내용, 품질, 페이지 수는 그대로이고, 워터마크도 없으며, 정리할 수 있는 파일 수에도 제한이 없습니다.

온라인에서 PDF 이름 바꾸는 방법

  1. PDF 이름 변경 도구를 열고 파일을 선택하거나 페이지 위로 끌어다 놓습니다. 현재 파일명이 표시됩니다.
  2. 원하는 새 이름을 입력합니다. 예를 들어 Q2-Sales-Report나 Smith-CV-2026처럼요.
  3. 슬래시나 콜론처럼 일부 시스템에서 문제를 일으키는 문자는 자동으로 제거되거나 다른 문자로 바뀝니다.
  4. 최종 파일명 미리보기를 확인합니다. .pdf 확장자는 알아서 처리됩니다.
  5. 이름 변경을 누르고 새 이름으로 파일을 내려받습니다.
  6. 이름을 바꾼 사본을 첨부하거나 공유하세요. 기기에 있는 원본은 그대로 남아 있습니다.

When to use this tool

  • 하루에 이력서 쉰 개를 내려받는 채용 담당자에게 보내기 전에 resume-final-v7(2).pdf를 Priya-Sharma-CV.pdf로 바꾸기
  • 고객 납품물에 ClientName-Project-Date.pdf 같은 일관된 규칙을 적용해 몇 달 뒤에도 보낸 편지함에서 검색되게 하기
  • 숫자와 밑줄만 가득한 스캐너 자동 파일명을 동료가 열어 보지 않고도 알아볼 수 있는 이름으로 고치기
  • 고객사의 오래된 시스템이나 까다로운 업로드 양식이 계속 거부하는, 악센트나 기호가 든 파일명 정리하기
  • 은행 거래내역서를 Statement-2026-06.pdf 형식으로 바꿔 보관 폴더에서 날짜순으로 정렬되게 하기
  • 수업 포털에 올리기 전에 강의 유인물 묶음을 Week-01-Notes.pdf부터 번호가 붙은 이름으로 준비하기

Tips for the best results

  • 공백 대신 하이픈이나 밑줄을 쓰세요. 일부 웹 서버와 오래된 도구는 파일명의 공백을 여전히 제대로 처리하지 못합니다.
  • 날짜는 2026-07-12처럼 YYYY-MM-DD 형식으로 넣으면 파일이 자동으로 시간순 정렬됩니다.
  • 이름은 60자 안팎으로 유지하세요. 지나치게 긴 파일명은 이메일 프로그램이나 일부 동기화 서비스에서 잘립니다.
  • 수정 이력이 아니라 파일이 무엇인지 적으세요. Contract-Signed.pdf가 contract_final_FINAL_use-this-one.pdf보다 언제나 낫습니다.
  • 이름 변경은 파일명만 바꿉니다. 문서를 만든 사람이 지정한 내부 제목이 따로 있다면 그 메타데이터는 그대로 남습니다.

자주 묻는 질문

이름을 바꾸면 PDF 내부도 달라지나요?

아니요. 페이지, 텍스트, 이미지, 품질이 바이트 단위로 그대로입니다. 폴더나 메일 첨부에서 보이는 파일명만 바뀝니다.

그냥 컴퓨터에서 이름을 바꾸면 안 되나요?

물론 그래도 되고, 대개 그게 낫습니다. 이 도구는 보안이 걸린 회사 컴퓨터나 파일 관리자가 불편한 휴대폰과 태블릿에서 유용하고, 다른 시스템에서 문제를 일으키는 문자까지 걸러 준다는 장점도 있습니다.

파일명에서 어떤 문자가 제거되나요?

운영체제 전반에서 사용할 수 없거나 불안정한 문자, 즉 / \ : * ? " < > | 등입니다. 도구가 이런 문자를 바꾸거나 지워서 Windows, macOS, Linux 어디서든 안전한 이름을 만듭니다.

이름을 바꿀 때 제 PDF가 업로드되나요?

아니요. 모든 작업이 브라우저 안에서 실행되므로 문서가 서버에 닿지 않습니다. 아무것도 저장되지 않으며, 탭을 닫으면 작업 흔적이 모두 사라집니다.

.pdf 확장자를 직접 입력해야 하나요?

아니요. 확장자는 자동으로 붙고, 직접 입력하더라도 중복되지 않습니다. 이름 자체만 신경 쓰면 됩니다.

여러 개의 PDF 이름을 바꿀 수 있나요?

네, 하루 제한이나 계정 없이 하나씩 이어서 처리하면 됩니다. 이름이 바뀌는 즉시 각 파일이 내려받아지므로 몇 개 정도는 1~2분이면 끝납니다.

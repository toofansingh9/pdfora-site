PDF 이름 변경

PDF에 깔끔하고 일관된 파일 이름을 붙여 새 사본으로 다운로드합니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.
1

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

파일 이름은 생각보다 중요합니다. "scan_20261003_0007.pdf"나 "문서 (3) 최종 진짜최종.pdf" 같은 이름은 받는 사람에게 아무 정보도 주지 못하고, 다운로드 폴더에서 묻혀 버리며, 공백이나 괄호, 너무 긴 이름을 싫어하는 업로드 사이트에서는 아예 거부되기도 합니다. 컴퓨터에서 이름을 바꾸는 건 일도 아니지만, 휴대폰이나 권한이 막힌 회사 PC, 브라우저만 쓰는 작업 환경에서는 의외로 번거롭습니다.

이 도구가 하는 일은 하나입니다. 새 이름을 입력하면 그 이름으로 PDF를 돌려줍니다. Windows, macOS, 대부분의 업로드 사이트가 파일 이름에 허용하지 않는 문자(역슬래시, 슬래시, 콜론, 별표, 물음표, 따옴표, 꺾쇠괄호, 세로 막대)는 자동으로 지워지고, .pdf를 빼먹으면 붙여 줍니다. 입력란을 비워 두면 원래 이름이 유지되고, 정리하고 나서 남은 글자가 없으면 파일 이름은 document.pdf가 됩니다. 앞뒤 공백도 잘라 내기 때문에 이메일에서 복사한 이름 끝에 공백이 하나 섞여 있어도 'invoice .pdf' 같은 파일이 생기지 않습니다.

알아 두면 좋은 점이 하나 있습니다. 이 도구는 다운로드 이름표만 바꾸는 게 아니라 pdf-lib로 PDF를 열어 다시 저장합니다. 페이지와 내용은 그대로지만 파일이 새로 쓰이므로 크기가 조금 달라질 수 있고, 문서 내부 메타데이터도 갱신됩니다. pdf-lib가 수정 날짜를 설정하고 자신을 생성 프로그램(producer)으로 기록합니다. 뷰어 제목 표시줄에 나오는 문서 제목은 PDF 안의 별도 항목이라 이름을 바꿔도 달라지지 않습니다.

PDF 파일 이름을 바꾸는 방법

  1. PDF 이름 변경 도구를 열고 이름을 바꿀 PDF를 추가합니다.
  2. 새 파일 이름 칸에 원하는 이름을 입력합니다. 예: 2026-10-견적서-0142. .pdf는 붙여도 되고 빼도 됩니다.
  3. 이름 변경 후 다운로드를 누릅니다. 파일을 불러와 새 이름으로 다시 저장합니다.
  4. 다운로드한 파일을 필요한 곳에 저장합니다. 브라우저에 따라 저장 위치를 묻거나 다운로드 폴더에 바로 넣습니다.
  5. 파일 탐색기에서 이름을 확인하고, 필요 없다면 이전 사본을 지웁니다.

이 도구가 필요한 경우

  • 프리랜서가 거래처-연도-월-번호처럼 일정한 규칙으로 세금계산서 사본이나 청구서를 보내 양쪽 모두 나중에 쉽게 찾을 수 있게 할 때. 이름이 예측 가능하면 거래처 경리 담당자도 파일을 열지 않고 발주서와 맞춰 볼 수 있습니다.
  • 대학생이 이름-학번-과제명처럼 정해진 형식을 요구하는 학습관리시스템(LMS)에 과제를 제출할 때.
  • 집주인이 임대차 계약서와 점검 보고서를 스캐너가 붙인 이름 대신 주소와 날짜로 정리할 때.
  • 파일 관리가 불편한 휴대폰이나 태블릿에서 파일 이름을 바꿀 때.
  • 콜론, 슬래시, 따옴표처럼 업로드나 다른 시스템과의 동기화를 막는 문자를 없앨 때.
  • 다운로드한 거래내역서나 전자 항공권을 전달하기 전에 알아보기 쉬운 이름을 붙일 때.

시작하기 전에 알아둘 점

  • 금지 문자 \ / : * ? " < > |는 다른 문자로 바뀌는 게 아니라 지워집니다. 그래서 보고서: 3분기는 보고서 3분기가 됩니다. 공백은 유지되니 공백을 받지 않는 사이트라면 직접 하이픈으로 바꾸세요.
  • .pdf 확장자가 없으면 자동으로 붙습니다. 이미 .pdf로 끝나는 이름은(대소문자 상관없이) 입력한 그대로 둡니다.
  • PDF는 pdf-lib로 다시 저장되며, 이때 파일 메타데이터의 수정 날짜와 생성 프로그램 항목이 갱신됩니다. 제목, 작성자, 페이지 내용은 그대로입니다.
  • 전자서명이 된 PDF는 이 도구로 이름을 바꾸지 마세요. 다시 저장하면 파일이 새로 쓰여, 보이는 내용이 같아도 서명이 무효가 됩니다. 서명된 파일은 파일 탐색기에서 이름을 바꾸세요.
  • 비밀번호가 걸린 PDF도 적합하지 않습니다. 불러올 수는 있어도 저장된 사본이 제대로 열리지 않을 가능성이 큽니다. 이런 파일도 파일 탐색기에서 이름을 바꾸세요.
  • 한 번에 파일 하나씩 처리합니다. 여러 개를 바꾸려면 파일마다 같은 과정을 반복하거나 운영체제의 일괄 이름 바꾸기 기능을 쓰세요. 같은 파일 이름을 두 번 바꾸면 매번 새 다운로드가 생기며, 이 도구는 디스크에 있는 파일을 절대 건드리지 않습니다. 원본은 지우기 전까지 원래 이름으로 그 자리에 그대로 있습니다.

더 좋은 결과를 위한 팁

  • 이름을 연-월-일 순서의 날짜(2026-10-22)로 시작하면 어느 폴더에서든 날짜순으로 정렬됩니다.
  • 공백 대신 하이픈을 쓰세요. 이메일 시스템, URL, 명령줄 도구를 거쳐도 %20으로 바뀌지 않습니다.
  • 이름은 60자 정도 이내로 하세요. 일부 사이트나 오래된 시스템은 긴 이름을 잘라 버립니다.
  • 가장 중요한 단어를 앞에 두세요. 거래처 이름, 문서 종류, 번호 순서가 좋습니다. 목록을 훑어볼 때 사람들이 보는 부분이 바로 앞쪽입니다.
  • PDF 뷰어에 보이는 제목까지 바꿔야 한다면 파일을 만든 프로그램에서 문서 속성을 수정하세요. 이름 변경으로는 바뀌지 않습니다. 업로드 사이트마다 소문자만, 공백 금지 같은 자체 규칙이 있기도 한데, 이 도구는 그런 규칙을 적용하지 않으니 사이트가 요구하는 형식대로 직접 입력하세요.

예시: 원룸 세 채를 관리하는 집주인의 서류 정리

원룸 세 채를 세놓는 집주인이 휴대폰 스캔 앱으로 시설 점검 보고서를 찍었더니 'Scan 14 Oct 2026 10:42.pdf' 같은 이름이 붙었습니다. 이 파일을 부동산 중개사무소의 업로드 페이지에 올리려 하자 파일 이름에 콜론이 있다는 이유로 실패하고, 노트북 폴더에는 비슷비슷한 날짜만 줄지어 있습니다.

그녀는 휴대폰에서 보고서마다 201호-점검-2026-10-14 같은 규칙으로 이름을 바꿉니다. 예전 이름 일부를 복사해 붙이다 콜론이 섞여도 도구가 지워 주고 .pdf도 붙여 주어, 업로드가 문제없이 됩니다. 폴더에서도 이제 호실별, 날짜별로 정렬됩니다.

서명한 임대차 계약서는 다르게 처리합니다. 전자서명이 된 파일이라 다시 저장하면 서명이 무효가 되므로, 휴대폰 파일 관리 앱에서 이름을 바꿉니다. 이 도구는 일반 PDF에 가장 잘 맞고, 서명이나 비밀번호가 있는 파일은 파일 시스템에서 이름을 바꾸는 게 맞습니다.

문제 해결

다운로드한 파일이 아직 예전 이름이에요
같은 이름의 파일이 이미 있어서 브라우저가 번호를 붙였거나, 중복 파일 이름을 바꾸도록 설정되어 있을 수 있습니다. 다운로드 폴더를 확인하고 예전 사본을 지우세요.
새 이름에서 글자 일부가 사라졌어요
일반적인 시스템에서 파일 이름에 쓸 수 없는 문자(\ / : * ? " < > |)는 자동으로 지워집니다. 그 자리에는 하이픈이나 밑줄을 쓰세요.
파일 크기가 조금 바뀌었어요
PDF를 pdf-lib로 다시 저장하면서 내부 객체를 다르게 저장할 수 있습니다. 페이지는 같고 내부 구조만 새로 쓰였습니다.
PDF의 전자서명이 유효하지 않다고 나와요
다시 저장하면서 서명이 보호하는 바이트가 바뀌었습니다. 서명된 원본 파일을 파일 탐색기에서 이름만 바꾸세요.
이름을 바꾼 파일이 열리지 않아요
원본이 암호화되었거나 손상되었을 가능성이 큽니다. 원본을 파일 탐색기에서 이름만 바꾸거나, 먼저 PDF 복구로 고치세요.
뷰어 상단에 아직 예전 제목이 보여요
뷰어는 파일 이름이 아니라 PDF 안에 저장된 제목을 보여 줍니다. 이 항목은 이름을 바꿔도 달라지지 않습니다.
휴대폰에서 새 이름이 잘렸어요
일부 모바일 브라우저는 아주 긴 다운로드 이름을 줄여 버립니다. 이름을 짧게 하고 알아보는 데 필요한 부분을 앞에 두세요.

자주 묻는 질문

이름을 바꾸면 PDF 내용이 달라지나요?

아닙니다. 페이지는 똑같습니다. 파일을 다시 저장하므로 수정 날짜와 생성 프로그램 메타데이터만 갱신됩니다.

어떤 문자를 쓸 수 없나요?

역슬래시, 슬래시, 콜론, 별표, 물음표, 큰따옴표, 꺾쇠괄호, 세로 막대는 이름에서 지워집니다.

끝에 .pdf를 꼭 입력해야 하나요?

아니요. 빼먹으면 자동으로 붙습니다.

여러 PDF 이름을 한꺼번에 바꿀 수 있나요?

아니요, 한 번에 파일 하나씩입니다. 파일이 많다면 운영체제의 일괄 이름 바꾸기가 더 빠릅니다.

이름을 바꾸면 전자서명이 깨지나요?

네, 파일이 새로 쓰이기 때문에 깨질 수 있습니다. 서명된 PDF는 파일 탐색기에서 이름을 바꾸세요.

비용이나 가입이 필요한가요?

아니요. 이름 변경은 무료이고 계정도 필요 없습니다.

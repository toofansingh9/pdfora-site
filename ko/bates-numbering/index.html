베이츠 번호

PDF의 모든 페이지에 ABC-000001처럼 0으로 자릿수를 채운 고유 식별 번호를 찍습니다. 법무·기록 관리 업무용입니다.

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

베이츠 번호(Bates numbering)는 문서 묶음의 모든 페이지에 저마다 고유한 번호를 붙이는 방식입니다. 덕분에 '두 번째 폴더의 세 번째 청구서' 대신 'KIM-000412 페이지'라고 정확히 가리킬 수 있습니다. 수천 페이지가 오가고 페이지마다 헷갈림 없이 인용할 수 있어야 하는 소송, 규제기관 대응, 감사 업무에서 널리 쓰입니다. 일반 페이지 번호와 달리 베이츠 번호는 문서가 바뀌어도 1부터 다시 시작하지 않고 제출 자료 전체에 걸쳐 이어집니다.

PDFora의 도구는 한 번에 PDF 하나에 번호를 찍습니다. 접두사(예: ABC- 또는 사건 코드), 시작 번호, 자릿수를 정하면 번호가 그 자릿수만큼 0으로 채워집니다. 시작 번호 1, 자릿수 6이면 ABC-000001, ABC-000002 식으로 이어집니다. 라벨은 거의 검정에 가까운 색의 10포인트 Helvetica로, 아래쪽 가장자리에서 약 6mm 위, 오른쪽 하단·왼쪽 하단·하단 가운데 중 한 곳에 그려집니다. 시작 번호는 0도 가능합니다.

원본 페이지는 그대로 두고 브라우저 안에서 pdf-lib로 라벨만 위에 덧그리기 때문에, 비밀유지 대상이나 개인정보가 담긴 제출 자료도 내 컴퓨터를 벗어나기 전에 번호를 찍을 수 있습니다. 결과 파일 이름은 yourfile-bates.pdf입니다. 결과물이 법원, 규제기관 또는 당사자 간 합의의 형식 요건을 충족하는지는 본인이나 담당 변호사가 확인해야 하며, 이 도구는 번호를 찍는 일만 합니다.

PDF에 베이츠 번호를 넣는 방법

  1. 베이츠 번호 도구를 열고 다음 번호 구간을 받을 PDF를 선택합니다.
  2. 하이픈이나 밑줄까지 포함해 합의한 그대로 접두사를 입력합니다. 예: DEF_ 또는 KIM-.
  3. 시작 번호를 입력합니다. 제출 자료의 첫 파일이면 1, 그다음 파일이면 앞에서 마지막으로 쓴 번호에 1을 더한 값입니다.
  4. 자릿수(기본값 6)와 위치를 정합니다. 가장 흔히 쓰는 위치는 오른쪽 하단입니다.
  5. 베이츠 번호 추가를 누르고 파일을 다운로드한 뒤, 다음 문서에 번호를 찍기 전에 첫 번째와 마지막 라벨을 적어 둡니다.

이 도구가 필요한 경우

  • 상대방에게 넘기는 모든 페이지에 고유 참조 번호가 필요한 증거 제출·자료 공개 절차.
  • 조사관이 결과 보고서에서 특정 페이지를 인용할 수 있도록 규제기관이나 고충처리기관에 자료를 제출할 때.
  • 사내 조사나 인사 고충 처리에서 증거 자료를 페이지 단위로 추적할 수 있게 할 때.
  • 영수증과 거래 내역을 보고 기간 전체에 걸쳐 일련번호로 정리하는 감사·보조금 정산 서류.
  • 보증금 반환이나 소액 분쟁에서 세입자나 집주인이 번호를 매긴 증거 묶음을 보낼 때.
  • 정보공개 청구에 대한 자료 제공에서 청구인이 정확한 페이지를 다시 짚을 수 있게 할 때.

시작하기 전에 알아둘 점

  • 한 번 실행할 때 파일 하나에만 번호를 매깁니다. 여러 파일에 번호를 이어서 매기려면 순서대로 처리하면서 각 파일의 시작 번호를 앞 파일의 마지막 번호 + 1로 설정하세요. 아니면 먼저 파일들을 병합한 뒤 한 번에 찍어도 됩니다.
  • 접두사, 자릿수, 위치는 바꿀 수 있지만 글꼴 크기(10포인트), 색상, 여백은 고정입니다. 접미사 입력란이나 'CONFIDENTIAL' 같은 두 번째 줄 옵션은 없으니, 필요하면 머리글 및 바닥글 도구로 추가하세요.
  • 0 채우기는 앞에 0을 더할 뿐입니다. 자릿수 6에서 1,000,000번째 페이지처럼 번호가 자릿수를 넘으면 번호가 그냥 길어지며 잘리는 부분은 없습니다.
  • 라벨은 눈에 보이는 일반 텍스트로 그려집니다. 위변조 방지 기능이 아니므로 PDF 편집기에서 수정할 수 있습니다. 무결성이 중요하다면 번호를 찍은 원본을 손대지 않고 보관하고 체크섬을 기록해 두세요.
  • 라벨 위치는 전체 페이지 크기를 기준으로 정해집니다. 회전된 상태로 저장된 페이지나 자르기 영역(crop box)이 줄어든 페이지에서는 번호가 옆으로 눕거나 보이는 영역 밖에 찍힐 수 있으니, 그런 페이지는 먼저 정리하세요.
  • 아래 여백에 이미 있는 바닥글이나 스캔 테두리 같은 요소는 옮겨지지 않습니다. 베이츠 라벨이 그 위에 겹쳐 그려지므로 둘 다 읽기 어려워질 수 있습니다.

더 좋은 결과를 위한 팁

  • 번호를 찍기 전에 상대방과 접두사와 자릿수를 미리 합의하세요. 중간에 바꾸면 제출 자료 전체의 일관성이 깨집니다.
  • 파일 이름, 첫 라벨, 마지막 라벨, 페이지 수를 적은 간단한 기록표를 만들어 두세요. 나중에 'KIM-000731은 어느 파일에 있나요?'라는 질문에 바로 답할 수 있습니다.
  • 번호를 찍어도 스캔 문서가 검색되게 바뀌지는 않습니다. 검토용 색인에 텍스트가 필요하다면 번호를 찍은 자료 묶음에 OCR PDF를 돌려 검색 가능한 사본을 만드세요.
  • 가림 처리(비식별화)는 베이츠 번호를 찍기 전에 끝내세요. 번호를 찍은 뒤 페이지를 빼면 번호에 구멍이 생기고 따로 설명해야 합니다.
  • 기존 바닥글과 겹치지 않는 위치를 고르세요. 회사 레터헤드의 오른쪽 구석에 문서 번호가 인쇄돼 있다면 왼쪽 하단이나 하단 가운데가 무난합니다.

예시: 파일 세 개로 된 소액 분쟁 증거 자료

인천에서 작은 인테리어 업체를 운영하는 사장님이 공사 대금 분쟁에 쓸 증거를 준비합니다. 12페이지짜리 계약서, 31페이지 분량의 이메일, 7페이지짜리 청구서 묶음입니다. 페이지에 일련번호를 매겨 달라는 안내를 받았고, 접두사는 CLM-, 자릿수는 5로 정했습니다.

계약서가 먼저입니다. 시작 번호 1로 CLM-00001부터 CLM-00012까지 찍힙니다. 이메일은 13에서 시작해 CLM-00043에서 끝나고, 청구서는 44에서 시작해 CLM-00050에서 끝납니다. 한 파일을 처리할 때마다 사장님은 첫 라벨과 마지막 라벨을 간단한 표에 적고, 결과 파일의 마지막 페이지를 표와 대조합니다.

그런데 이메일 중 두 페이지는 긴 서명란이 오른쪽 하단을 꽉 채우고 있었습니다. 처음부터 다시 하는 대신, 이메일 파일만 위치를 왼쪽 하단으로 바꾸고 같은 시작 번호 13으로 다시 실행합니다. 번호는 그대로 이어지고, 이제 모든 페이지에서 라벨이 또렷하게 보입니다.

나중에 상대방이 'CLM-00047에 있는 청구서'에 대해 묻자, 사장님은 기록표를 보고 청구서 파일이 44부터 50까지라는 걸 확인한 뒤 그 파일의 4페이지를 엽니다. 번호가 없었다면 같은 질문에 답하려고 문서 세 개를 한 장씩 넘겨야 했을 겁니다.

문제 해결

파일마다 다시 000001부터 시작합니다
이 도구는 한 번에 파일 하나에 번호를 매기며 매번 입력한 시작 번호를 씁니다. 시작 번호를 앞 파일의 마지막 번호 + 1로 설정하거나, 먼저 파일들을 병합하세요.
라벨이 기존 바닥글과 겹칩니다
위치를 왼쪽 하단이나 하단 가운데로 바꾸세요. 크기와 여백은 고정이라 조정할 수 있는 건 위치뿐입니다.
일부 라벨이 옆으로 누워 있습니다
그 페이지들이 회전된 상태로 저장되어 있습니다. PDF 회전으로 바로잡은 뒤 같은 시작 번호로 다시 찍으세요.
접두사 때문에 오류가 납니다
내장 글꼴은 한글 같은 비라틴 문자나 특수 기호를 표현하지 못합니다. 영문자, 숫자, 하이픈, 밑줄만 사용하세요.
번호 옆에 CONFIDENTIAL을 찍어야 합니다
베이츠 번호를 넣은 뒤 머리글 및 바닥글 도구로 그 문구를 머리글에 넣으세요. 그러면 두 표시가 겹치지 않습니다.
스캔본에서 라벨이 본문 글자보다 흐리게 보입니다
라벨은 거의 검정색 10포인트로 그려집니다. 스캔 배경이 짙은 회색이면 화면에서 대비가 약해 보일 수 있으니, 시험 삼아 한 장 인쇄해 읽을 수 있는지 확인하세요.

자주 묻는 질문

베이츠 번호와 페이지 번호는 무엇이 다른가요?

페이지 번호는 문서마다 다시 시작합니다. 베이츠 번호는 합의한 접두사를 달고 묶음 안의 모든 문서에 걸쳐 이어지기 때문에 페이지마다 고유한 참조 번호가 됩니다.

여러 PDF에 한 번에 베이츠 번호를 넣을 수 있나요?

한 번 실행으로는 안 됩니다. 앞 파일이 끝난 번호에서 이어 가며 하나씩 찍거나, 파일을 병합한 뒤 병합본에 찍으세요.

0부터 시작할 수 있나요?

네. 시작 번호 0, 자릿수 6이면 첫 페이지에 ABC-000000이 찍힙니다. 라벨이 제출한 페이지 수와 일치하도록 1부터 시작하는 쪽을 선호하는 경우도 있으니, 시작하기 전에 방식을 합의하세요.

베이츠 라벨의 글꼴 크기를 바꿀 수 있나요?

아니요. 참조 번호에 흔히 쓰는 크기인 10포인트로 고정되어 있습니다. 접두사, 자릿수, 시작 번호, 위치는 직접 정할 수 있습니다.

정식 법원 제출 자료에도 쓸 수 있나요?

표준적인 '접두사 + 번호' 형식의 표시를 찍어 주지만, 제출 규칙은 법원과 합의 내용에 따라 다릅니다. 요구되는 형식, 위치, 로드 파일(load file) 필요 여부는 담당 변호사와 확인하세요.

번호를 찍으면 페이지 내용이 바뀌나요?

아니요. 라벨은 위에 덧붙여질 뿐이고 기존 텍스트와 이미지는 그대로입니다. 텍스트 기반 페이지는 계속 검색할 수 있습니다.

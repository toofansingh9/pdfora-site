베이츠 번호

접두어와 자릿수 맞춤(0 채우기)이 적용된 연속 Bates 번호를 찍습니다. 법률 문서의 표준 방식입니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

소송에서는 증거개시로 제출되는 모든 페이지에 고유 식별자가 필요하고, 법조계는 그 일을 Bates 넘버링으로 해결합니다. 접두어와 일련번호가 붙는 순간 "그 청구서 관련 이메일"은 ABC-000147이 됩니다. 증인신문에서 인용할 수 있고, 특권 목록에서 추적할 수 있으며, 법정에서 오해의 여지가 없죠. 이 도구는 온라인에서 Bates 넘버링을 적용해 PDF의 모든 페이지에 몇 초 만에 번호를 찍습니다.

형식은 사용자가 정합니다. "SMITH-"나 사건 번호 같은 접두어를 설정하고, 새 제출분이 지난번 끝난 지점부터 이어지도록 시작 번호를 정하고, 자릿수를 몇 자리로 채울지 고르면 됩니다. 1이 아니라 000001처럼요. 그런 다음 도장이 놓일 위치를 아래 오른쪽, 아래 왼쪽, 아래 가운데 중에서 고릅니다. 도구가 모든 페이지에 순서대로 번호를 매겨 찍힌 파일을 돌려줍니다.

로펌에는 프라이버시 모델이 가장 중요합니다. PDF는 전부 브라우저에서 처리되고 업로드되지 않으므로, 특권 자료와 기밀 문서가 내 컴퓨터에 머뭅니다. 무료이고 가입도, 워터마크도, 페이지 제한도 없습니다.

온라인에서 Bates 번호 넣는 방법

  1. PDF를 도구로 끌어다 놓습니다. 브라우저에서 로컬로 열리므로 고객 문서가 전송되는 일은 없습니다.
  2. 접두어를 입력합니다. 예를 들어 "ABC-"나 "DOE2026-" 같은 사건 식별자를 쓰세요.
  3. 시작 번호를 설정합니다. 첫 제출분이면 1을, 추가 제출분이면 마지막으로 찍은 페이지에서 이어지는 번호를 쓰세요.
  4. 0으로 채울 자릿수를 고릅니다. 여섯 자리면 ABC-000001, ABC-000002 식으로 나옵니다.
  5. 도장 위치를 아래 오른쪽, 아래 왼쪽, 아래 가운데 중에서 고릅니다.
  6. 클릭해 모든 페이지에 번호를 찍고 Bates 번호가 들어간 PDF를 내려받은 뒤, 제출 목록에 번호 범위를 기록합니다.

이 도구가 필요한 경우

  • 법무 보조원이 증거개시 제출 전 이메일 출력물 400페이지에 PLAINTIFF-000001부터 PLAINTIFF-000400까지 번호를 찍기.
  • 개인 상해 사건 증인신문에서 상대측 변호인이 특정 페이지를 인용할 수 있도록, 단독 개업 변호사가 진료 기록 PDF에 Bates 번호 찍기.
  • 기업 법무팀이 소환장에 대응하는 내부 문서에 번호를 매기며, 앞선 순차 제출분의 번호를 이어 가기.
  • 회계사가 감사 조서에 연속 번호를 찍어 최종 보고서에서 모든 페이지를 명확히 참조할 수 있게 하기.
  • 기록 담당자가 행정 심판용 증거물에 번호를 매기며 증거 묶음마다 다른 접두어를 사용하기.
  • 준법 담당자가 정책 바인더에 페이지별로 번호를 찍어, 고정된 페이지 식별자를 기준으로 개정 내역을 추적하기.

더 좋은 결과를 위한 팁

  • 사건마다 마지막으로 사용한 Bates 번호를 계속 기록해 두세요. 다음 제출분은 그다음 번호부터 시작해야 하며 번호를 재사용해서는 안 됩니다.
  • 미국 증거개시에서는 여섯 자리 채움이 일반적인 관행입니다. 번호가 가지런히 정렬되고 어떤 파일 목록에서도 올바르게 정렬됩니다.
  • "SMITH-"나 "DEF-"처럼 제출 당사자를 식별할 수 있는 접두어를 고르세요. 그래야 서로 다른 당사자의 페이지가 겹치지 않습니다.
  • 도장 위치가 중요합니다. 문서에 이미 인쇄된 바닥글이나 페이지 번호를 가리지 않을 모서리를 고르세요.
  • 원본 하나뿐인 파일 말고 사본에 Bates 도장을 찍으세요. 사건 진행 중 서식 요건이 바뀔 수 있으니 깨끗한 버전을 남겨 두세요.

자주 묻는 질문

Bates 넘버링이란 무엇인가요?

Bates 넘버링은 문서 묶음의 모든 페이지에 고유한 연속 식별자를 찍는 방식으로, 보통 접두어에 자릿수를 채운 번호를 붙여 ABC-000123처럼 표기합니다. 1890년대에 특허받은 수동 번호 찍는 기계에서 유래했으며, 지금도 법무팀이 증거개시에서 페이지를 식별하는 표준 방식입니다.

특권이 인정되는 법률 문서에도 안전한가요?

네, 그리고 이 점이 대부분의 온라인 스탬프 도구와 결정적으로 다릅니다. PDF는 브라우저에서 로컬로 처리되며 서버로 업로드되지 않습니다. 특권 자료나 기밀 자료가 처음부터 끝까지 내 컴퓨터에 머뭅니다.

이전 제출분에서 번호를 이어 갈 수 있나요?

네. 시작 번호를 지난 제출분이 끝난 지점으로 설정하면 됩니다. ABC-000400에서 끝났다면 같은 접두어와 자릿수로 401부터 시작해, 사건 전체에서 하나의 연속된 번호 체계를 유지하세요.

Bates 도장은 페이지의 어디에 찍히나요?

사용자가 고릅니다. 아래 오른쪽, 아래 왼쪽, 아래 가운데 중에서 선택할 수 있습니다. 미국 실무에서는 아래 오른쪽이 가장 흔한 관행이지만 법원과 절차마다 다르므로 ESI 명령이나 제출 합의서를 먼저 확인하세요.

Bates 도장은 영구적인가요?

번호는 각 페이지에 페이지 내용으로 그려지므로 어떤 PDF 뷰어에서도 고정되어 있고 인쇄하거나 복사해도 남습니다. 클릭 한 번으로 지울 수 있는 주석 같은 것이 아닙니다.

비용이 들거나 페이지 수 제한이 있나요?

아니요. 무료이고 계정도 필요 없으며 워터마크도 붙지 않고 페이지나 문서 수에 상한도 없습니다. 2,000페이지 제출분도 10페이지짜리와 똑같이 처리됩니다.

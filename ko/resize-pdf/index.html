PDF 크기 조정

PDF의 모든 페이지를 A4, US Letter, A5, A3 중 하나에 비율을 유지한 채 맞추고 가운데 정렬해, 문서 전체를 한 가지 페이지 크기로 통일합니다.

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

여러 곳에서 모은 PDF는 페이지 크기가 제각각인 경우가 많습니다. 국내 서류는 A4인데 미국 지사에서 스캔한 문서는 Letter이고, 휴대폰 사진을 PDF로 바꾸면 어떤 모양이 나올지 모릅니다. 그러면 표준 크기 하나만 받는 제출 사이트나 인쇄소에서 통째로 거부되기도 합니다. PDF 크기 조정은 모든 페이지를 원하는 크기의 새 용지 위에 올려 이 문제를 해결합니다. 페이지 하나하나에는 문제가 없어도 크기가 섞여 있어서 나중에 곤란해질 때도 쓸모가 있습니다. 예를 들어 프린터가 다른 용지함을 달라며 멈추거나, 소책자 레이아웃이 들쭉날쭉하거나, 페이지 번호가 크기가 다른 페이지마다 다른 위치에 찍히는 경우입니다.

선택할 수 있는 크기는 네 가지입니다. A4(595×842포인트), US Letter(612×792), A5(420×595), A3(842×1191)이며 모두 세로 방향입니다. 원래 페이지는 비율을 유지한 채 새 용지 안에 완전히 들어가도록 크기가 조정된 뒤 가운데에 놓입니다. 모양이 다르면 남는 공간은 위아래나 좌우의 흰 여백이 됩니다. 늘어나거나 잘리는 부분은 없습니다.

페이지 내용은 pdf-lib로 새 용지에 벡터 콘텐츠로 삽입되므로 텍스트와 도형은 어떤 배율에서도 선명합니다. 새 문서를 만드는 방식이라 결과물은 보이는 페이지만 깔끔하게 담은 사본이 되고, 파일 이름은 원래 이름에 크기가 붙어 contract-A4.pdf처럼 저장됩니다. 그래서 예전 자르기 설정처럼 원본에 남아 있던 특이한 페이지 상자도 정리되어, 새 파일에는 원래 보이던 그대로가 선택한 크기의 용지 위에 나타납니다.

PDF 페이지 크기를 바꾸는 방법

  1. PDF 크기 조정 도구를 열고 PDF 하나를 선택합니다.
  2. 대상 페이지 크기를 고릅니다. A4, US Letter, A5, A3 중 하나이며 기본값은 A4입니다.
  3. 페이지 크기 변경을 누릅니다. 각 페이지가 새 용지에 맞게 크기 조정되어 가운데에 놓입니다.
  4. 파일을 다운로드합니다. 이름에 크기가 들어가 report-Letter.pdf처럼 저장됩니다.
  5. 가로 페이지와 출처가 다른 페이지를 확인하세요. 흰 여백이나 눈에 띄는 배율 변화가 생기기 쉬운 페이지입니다.

이 도구가 필요한 경우

  • A4나 Letter 한 가지만 받는 기관이나 법원 제출 사이트에 서류를 올릴 때.
  • 한국과 미국 사무실 사이에 파일을 주고받을 때. A4와 Letter는 몇 밀리미터 차이지만 프린터가 용지가 맞지 않는다며 멈춥니다.
  • 스캔본과 사진이 섞인 묶음을 페이지 크기가 하나로 통일된 깔끔한 문서로 만들 때.
  • A4 페이지를 A5로 줄여 소책자나 휴대용 안내서를 인쇄할 때.
  • A4 도면이나 설계도를 A3로 키워 종이로 보기 편하게 할 때.
  • 모든 페이지가 하나의 표준 크기이기를 요구하는 인쇄소에 넘길 문서를 준비할 때.

시작하기 전에 알아둘 점

  • 페이지는 맞춤 방식으로 조정될 뿐 늘어나거나 잘리지 않습니다. 원본 모양이 대상과 다르면 두 변에 흰 여백이 생깁니다.
  • 네 가지 크기 모두 세로 방향입니다. 가로 페이지는 세로 용지 안에 맞춰지므로 작아지고 위아래에 넓은 흰 여백이 생깁니다. 용지를 꽉 채워야 한다면 먼저 회전하세요.
  • 작은 페이지는 커지고 큰 페이지는 작아집니다. 휴대폰 크기 페이지를 A3로 키우면 벡터 텍스트는 크고 선명해지지만 해상도가 낮은 스캔은 흐릿해 보입니다.
  • 각 페이지를 새 용지에 콘텐츠로 다시 그리기 때문에 링크, 양식 필드, 주석, 책갈피는 결과 파일에 복사되지 않습니다. 필요하다면 원본을 보관하세요.
  • A4에서 Letter로, 또는 그 반대로 바꾸면 배율은 아주 조금만 바뀌지만 흰 여백은 여전히 생깁니다. Letter 용지 위의 A4는 좌우에 작은 여백이, A4 용지 위의 Letter는 위아래에 여백이 생깁니다. 실제로는 변환 후에도 A4와 Letter 내용이 거의 똑같아 보이며, 차이는 가독성이 아니라 여백에 있습니다.
  • 크기를 바꿔도 스캔 이미지의 해상도는 달라지지 않습니다. 페이지에 그려지는 크기만 바뀝니다.

더 좋은 결과를 위한 팁

  • 가로로 된 엑셀 표 페이지가 몇 장 있다면 크기를 바꾸기 전에 PDF 회전으로 세로로 돌리거나, 작게 나오는 것을 감수하세요.
  • A5로 줄일 때는 넓은 여백을 먼저 잘라 내면 작은 페이지를 내용이 더 많이 채웁니다.
  • A5 소책자를 만든다면 원본에서 가장 작은 글씨가 약 70% 크기에서도 읽히는지 확인하세요. A4에서 A5로 가면 그만큼 줄어듭니다.
  • 크기 조정은 마지막 단계 중 하나로 하세요. 페이지 번호나 머리글은 크기를 바꾼 뒤에 넣어야 최종 페이지 크기에 맞는 위치에 찍힙니다.
  • 받는 쪽에서 'A4로 달라'고 하면 세로만 괜찮은지도 물어보세요. 이 도구는 항상 세로 용지로 만듭니다.

예시: 관리사무소 제출용 임대 서류 묶음

오피스텔을 세놓은 집주인이 A4만 받는 건물 관리 시스템에 임대 서류 묶음을 올려야 합니다. 파일에는 계약서(A4), 사무실 복사기에서 US Letter 설정으로 잘못 스캔한 가스 안전 점검표, 그리고 PDF로 저장한 계량기 사진 세 장이 들어 있는데, 사진은 세로로 길쭉한 특이한 모양입니다.

그는 묶음 파일을 A4로 선택해 PDF 크기 조정에 넣습니다. 계약서 페이지는 겉보기에 그대로입니다. Letter 스캔본은 더 좁은 A4 폭에 맞게 살짝 줄어들고 위아래에 얇은 흰 여백이 생깁니다. 길쭉한 휴대폰 사진은 A4 높이에 맞춰지고 좌우에 흰 여백이 생깁니다.

시스템은 tenancy-A4.pdf를 한 번에 받아 줍니다. 잃은 것은 계약서 안에 있던 보증보험 안내 사이트 링크가 더 이상 클릭되지 않는다는 점 하나뿐이라, 그는 첨부 메시지에 주소를 직접 적어 넣습니다.

크기가 섞인 원본도 보관해 둡니다. 나중에 가스 점검표만 따로 달라고 하면, A4 폭에 맞춰 줄어든 사본이 아니라 원본에서 원래 스캔 화질 그대로 추출할 수 있기 때문입니다.

문제 해결

페이지 둘레에 흰 여백이 생겼어요
원래 페이지 모양이 대상 크기와 다르기 때문입니다. 이 도구는 늘이거나 자르지 않고 맞추므로 남는 공간은 흰색으로 남습니다. 원래 있던 여백 때문이라면 먼저 원본을 자르세요.
가로 페이지가 아주 작아졌어요
대상 용지가 세로 방향이기 때문입니다. 해당 페이지를 먼저 세로로 회전하거나, 원래 크기 그대로 별도 파일로 두세요.
링크나 양식 필드가 작동하지 않아요
대화형 요소는 새 용지로 옮겨지지 않습니다. 양식은 크기를 바꾸기 전에 작성하고 평면화하거나, 화면용으로는 원본을 보관하세요.
확대한 스캔 페이지가 흐릿해요
크기 조정은 기존 이미지를 늘릴 뿐 디테일을 더하지 못합니다. A3로 키워야 한다면 더 높은 해상도로 다시 스캔하세요.
결과물이 여전히 엉뚱한 크기로 인쇄돼요
인쇄 대화상자를 확인하세요. '인쇄 가능 영역에 맞춤' 같은 옵션이 페이지를 다시 줄일 수 있습니다. 실제 크기로 인쇄하세요.
도구가 파일을 열지 못해요
PDF가 손상되었을 수 있습니다. PDF 복구를 먼저 실행하고 복구된 사본의 크기를 바꾸세요.

자주 묻는 질문

크기를 바꾸면 페이지가 찌그러지나요?

아닙니다. 가로와 세로 배율이 같아서 비율이 유지됩니다. 남는 공간은 흰색이 됩니다.

원하는 크기를 직접 지정할 수 있나요?

현재는 안 됩니다. A4, US Letter, A5, A3 중에서 선택할 수 있습니다.

가로 방향으로 바꿀 수 있나요?

아니요. 모든 대상 크기는 세로입니다. 가로 원본은 세로 용지 안에 맞춰집니다.

크기를 바꾼 뒤에도 텍스트 검색이 되나요?

대부분의 파일은 됩니다. 페이지가 벡터 콘텐츠로 삽입되므로 실제 텍스트는 텍스트로 남습니다. OCR을 거치지 않은 스캔 페이지는 원래부터 검색이 되지 않았습니다.

파일이 커지나요?

보통은 조금만 커집니다. 페이지 내용을 다시 렌더링하지 않고 재사용하므로 크기는 원본과 비슷합니다.

휴대폰에서도 되나요?

네. 모바일 브라우저에서도 작동하며, 아주 긴 문서는 시간이 조금 더 걸릴 뿐입니다.

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

아무나 열어서는 안 되는 PDF가 있습니다. 급여 통지서, 계약서, 검사 결과, 재무제표 같은 것들이죠. PDFora의 보호 도구는 PDF에 비밀번호 암호화를 걸어 비밀번호를 아는 사람만 열 수 있게 합니다. 비밀번호를 지정하고 암호화된 파일을 내려받아 공유하면, 이메일이 전달되거나 USB를 잃어버려도 내용이 노출되지 않습니다.

읽기 전에 한 가지 솔직히 말씀드릴 게 있습니다. 보호 도구는 PDFora에서 순차 배포 중이며 현재는 '준비 중'으로 표시되어 있습니다. 이 페이지는 출시 시점에 어떻게 동작할지를 그대로 설명하니 무엇을 기대할 수 있는지 알아 두세요. 다른 PDFora 도구와 마찬가지로 무료이며 가입도 워터마크도 없고, 암호화는 브라우저 로컬에서 이뤄집니다. 문서도 비밀번호도 서버로 가지 않습니다.

이 마지막 부분은 강조할 만합니다. PDF에 비밀번호를 걸겠다고 보호되지 않은 파일을 먼저 남의 컴퓨터에 올린다면 이상한 일이니까요. PDFora의 방식은 전 과정을 사용자 기기에 둡니다. 파일은 브라우저에서 암호화되고, 기기를 벗어나는 것은 잠긴 사본뿐이며 그것도 사용자가 공유하기로 결정했을 때만 그렇습니다.

온라인에서 PDF에 비밀번호 거는 방법

  1. getpdfora.com에서 보호 도구를 열고 암호화할 PDF를 선택합니다. 업로드 없이 브라우저에서 열립니다.
  2. 문서를 열 때 요구할 비밀번호를 입력합니다.
  3. 확인을 위해 한 번 더 입력합니다. 여기서 오타가 나면 내 파일에서 나 자신이 잠겨 버립니다.
  4. 보호를 적용합니다. 도구가 사용자 기기에서 로컬로 PDF를 암호화합니다.
  5. 보호된 사본을 내려받습니다. 이제 이 파일을 여는 사람에게는 비밀번호를 묻는 창이 뜹니다.
  6. 비밀번호는 파일과 별도 경로로 전달하세요. 전화나 다른 메신저를 쓰고, 같은 이메일에 함께 담지는 마세요.

When to use this tool

  • 주택담보대출 상담사에게 보내기 전에 급여명세서나 재직증명서 PDF 암호화하기.
  • 고객 계약서를 잠가, 비밀번호를 받은 계약 상대방만 조건을 읽을 수 있게 하기.
  • 공유 클라우드 폴더에 저장하기 전에 내보낸 진료 기록이나 검사 결과 보호하기.
  • 메일링 리스트로 배포하는 이사회 자료나 재무제표에 비밀번호 걸기.
  • 예약 대행사에 보내기 전에 여권이나 신분증 스캔본 사본 보호하기.
  • 징계 통지서나 급여 평가서 같은 인사 문서를 사무실 공유 드라이브에 저장하기 전에 암호화하기.

Tips for the best results

  • 짧은 비밀번호보다는 서로 관련 없는 단어 서너 개로 만든 패스프레이즈를 쓰세요. 더 강력하면서 전화로 불러 주기도 쉽습니다.
  • 비밀번호를 파일과 같은 경로로 보내지 마세요. PDF는 이메일로, 비밀번호는 문자로 보내세요.
  • 비밀번호는 암호 관리자처럼 믿을 만한 곳에 보관하세요. 잊어버린 PDF 비밀번호는 설계상 복구가 불가능한 경우가 많습니다.
  • 암호화하지 않은 사본을 안전한 개인 공간에 보관해, 내 문서에서 스스로 잠기는 일이 없게 하세요.
  • 어디에 올리기 전에 먼저 암호화하세요. 파일을 보호한 다음 클라우드 저장소나 이메일로 옮기는 순서입니다.

자주 묻는 질문

보호 도구를 지금 쓸 수 있나요?

현재 '준비 중'으로 표시되어 있으며 PDFora에서 순차 배포하고 있습니다. 그동안 급히 PDF를 암호화해야 한다면 LibreOffice(비밀번호를 걸어 PDF로 내보내기)나 Adobe Acrobat 같은 믿을 만한 데스크톱 프로그램으로 오늘 바로 처리할 수 있습니다.

다른 도구처럼 무료인가요?

네. 출시되면 보호 도구도 나머지 PDFora 도구와 같은 원칙을 따릅니다. 무료, 무제한 사용, 가입 없음, 암호화된 파일에 워터마크 없음입니다.

제 파일이나 비밀번호가 서버로 전송되나요?

아니요. 암호화는 브라우저 로컬에서 실행됩니다. 즉 PDF는 사용자 기기에서 암호화되고 비밀번호는 기기를 벗어나지 않습니다. 다운로드 폴더에 저장되는 것은 완성된 잠긴 파일뿐입니다.

PDF 비밀번호 암호화는 얼마나 강력한가요?

최신 PDF 암호화는 은행과 정부 시스템 전반에서 쓰이는 것과 같은 계열의 암호인 AES를 사용합니다. 실제 취약점은 거의 언제나 비밀번호 자체이므로, 이름이나 생일로 추측할 수 없는 긴 비밀번호를 고르세요.

비밀번호를 잊어버리면 어떻게 되나요?

제대로 된 암호화에는 뒷문이 없습니다. 복구 링크도 없고 PDFora가 대신 재설정해 줄 수도 없습니다. PDF 비밀번호는 집 열쇠처럼 다루세요. 암호 관리자에 기록해 두고, 중요한 문서는 잠기지 않은 사본을 안전한 곳에 보관하세요.

나중에 필요 없어지면 비밀번호를 해제할 수 있나요?

네. PDFora의 짝꿍 도구인 잠금 해제 기능이 바로 그런 용도입니다. 내가 소유한 PDF에서 알고 있는 비밀번호를 제거해, 열 때마다 입력하지 않아도 되게 해 줍니다. 보호 도구와 함께 순차 배포 중입니다.

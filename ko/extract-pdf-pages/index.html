다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

문서 전체가 아니라 중간의 세 페이지만 필요할 때가 있습니다. PDFora의 추출 도구는 어떤 PDF에서든 원하는 페이지를 뽑아 새 파일로 저장하게 해 줍니다. 1-3, 5, 8처럼 입력하면 딱 그 페이지들이 그 순서대로 담긴 새 PDF가 만들어집니다. 원본은 그대로 남습니다.

추출은 전적으로 사용자 기기에서 이뤄집니다. PDF는 원격 서버가 아니라 브라우저가 읽고 다시 구성하므로, 서명된 계약서나 세금 신고서, 감정평가서에서 무언가를 뽑아내더라도 어디로도 전송되지 않습니다. 민감한 파일에 온라인 PDF 도구를 쓰기가 망설여졌다면 이것이 해법입니다. 여기서 '온라인'인 것은 웹페이지일 뿐 데이터가 아닙니다.

가입도, 요금도, 결과물 워터마크도 없습니다. 두 페이지를 뽑든 이백 페이지를 뽑든, 문서 한 개에서든 스무 개에서든 필요할 때마다 쓰세요. 어떤 것도 할당량에 계산되지 않습니다.

온라인에서 PDF 페이지 추출하는 방법

  1. 최신 브라우저에서 getpdfora.com의 페이지 추출 도구를 엽니다.
  2. 선택 버튼을 누르거나 파일을 페이지 위로 끌어다 놓아 PDF를 추가합니다.
  3. 선택 입력란에 원하는 페이지를 입력합니다. 1-3, 5, 8처럼 개별 페이지와 범위를 섞어도 됩니다.
  4. 실제 문서와 번호를 다시 대조해 보세요. 인쇄된 쪽번호가 PDF의 페이지 순서와 항상 일치하지는 않습니다.
  5. 추출을 누르면 브라우저가 선택한 페이지를 모아 새 PDF를 만듭니다.
  6. 결과를 내려받습니다. 원본 파일은 있던 그대로 남아 있습니다.

When to use this tool

  • 긴 계약서에서 서명 페이지만 뽑아 상대방 서명을 받으러 보내기
  • 나머지는 읽지 않을 사람들을 위해 60페이지 보고서에서 요약본만 추출하기
  • 학술지 한 호나 학술대회 자료집 PDF에서 자기 논문만 저장하기
  • 법원 제출 서류 묶음 전체를 전달하는 대신 관련 첨부 페이지만 골라내기
  • 구입한 전자책에서 레시피, 학습지, 도안 하나만 뽑아 인쇄하기
  • 제품 매뉴얼에서 사양 페이지만 꺼내 고객지원 티켓에 첨부하기

Tips for the best results

  • 범위와 개별 페이지를 자유롭게 섞으세요. 2, 5-9, 14는 기대한 대로 동작합니다.
  • 새 PDF에는 입력한 순서대로 페이지가 들어가므로, 원하는 순서대로 선택을 작성하세요.
  • 먼저 뷰어에서 PDF를 열어 뷰어상의 페이지 위치를 확인하세요. 표지 한 장 때문에 전체가 하나씩 밀릴 수 있습니다.
  • 몇 페이지를 남기는 게 아니라 몇 페이지를 빼고 싶다면 페이지 삭제 도구가 더 빠른 반대 방법입니다.
  • 병합 전에 추출하세요. 여러 문서에서 필요한 페이지만 먼저 뽑아 두면 훨씬 깔끔한 결합본이 나옵니다.

자주 묻는 질문

PDF에서 연속되지 않은 페이지도 추출할 수 있나요?

네. 쉼표로 구분하면 됩니다. 1, 4, 9-11이라고 쓰면 1쪽, 4쪽, 9~11쪽이 하나의 새 PDF로 묶입니다. 개별 페이지와 범위를 어떻게 조합해도 괜찮습니다.

페이지를 추출하면 원본 PDF가 바뀌나요?

아니요. 도구는 파일을 읽어 선택한 페이지로 완전히 새로운 PDF를 만듭니다. 기기에 있는 원본 문서는 전혀 수정되지 않습니다.

세금이나 법률 문서에 쓸 만큼 안전한가요?

네. 추출이 브라우저 안에서 로컬로 실행되고 파일이 업로드되지 않으므로 PDFora를 포함해 누구도 내용을 볼 수 없습니다. 자기 컴퓨터에서 파일을 여는 것만큼이나 안전합니다.

추출된 페이지는 서식을 유지하나요?

유지합니다. 페이지가 있는 그대로 복사되므로 글꼴, 이미지, 링크, 레이아웃이 그대로 넘어옵니다. 평면화되거나 재압축되지 않습니다.

비밀번호가 걸린 PDF에서도 페이지를 추출할 수 있나요?

잠긴 상태에서는 안 됩니다. 브라우저가 암호화된 파일의 페이지를 읽을 수 없기 때문입니다. 먼저 비밀번호를 제거한 뒤(비밀번호를 알고 있어야 합니다) 평소처럼 추출하세요.

추출할 수 있는 페이지 수에 제한이 있나요?

정해진 제한도 요금도 없습니다. 작업이 사용자 기기에서 이뤄지므로 아주 큰 파일에서 대량으로 추출하는 경우는 사용 가능한 메모리에 좌우될 뿐이며, 보통의 작업은 몇 초면 끝납니다.

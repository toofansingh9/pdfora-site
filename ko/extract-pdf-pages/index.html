페이지 추출

원본은 그대로 둔 채, PDF에서 고른 페이지를 입력한 순서대로 뽑아 더 작은 새 파일로 만듭니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.
1

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

긴 PDF에서 몇 페이지만 필요할 때, 많은 사람이 PDF로 인쇄하거나 화면을 캡처하거나, 80페이지 문서를 통째로 보내면서 이메일에 '47페이지 참고'라고 적습니다. 더 깔끔한 방법은 추출입니다. 원하는 페이지 번호를 입력하면 그 페이지만 원래 모습 그대로 담긴 별도의 PDF가 생깁니다. 원본 파일은 전혀 바뀌지 않기 때문에, 페이지를 잘못 골랐다고 되돌릴 것도 없이 그냥 다시 실행하면 됩니다.

내부적으로는 pdf-lib 라이브러리로 PDF를 열고, 입력한 페이지 목록을 읽어 그 페이지 객체를 완전히 새 문서로 복사합니다. 복사는 다시 렌더링하는 것과 다릅니다. 텍스트는 선택 가능한 상태로 남고, 벡터 그림은 어떤 배율에서도 선명하며, 삽입된 이미지는 원래 해상도 그대로 옮겨집니다. 새 파일은 yourfile-extracted.pdf로 저장됩니다. 선택한 페이지와 그 페이지가 쓰는 글꼴·이미지만 복사되므로 결과는 보통 원본보다 훨씬 작지만, 큰 사진이 들어간 페이지라면 여전히 클 수 있습니다.

페이지 입력란은 쉼표로 구분한 단일 번호, 범위, 끝이 열린 범위를 받으며, 입력한 순서를 그대로 따릅니다. 이 마지막 부분은 놓치기 쉽지만 꽤 쓸모가 있습니다. 5, 1-3을 입력하면 5페이지로 시작해 1, 2, 3페이지가 이어지는 4페이지짜리 파일이 나옵니다. 그래서 몇 페이지만 특정 순서로 필요할 때는 추출이 간단한 순서 바꾸기 역할도 합니다.

PDF에서 페이지를 추출하는 방법

  1. 페이지 추출 도구를 열고 PDF 하나를 고릅니다. 한 번에 파일 하나만 처리합니다.
  2. PDF 뷰어에서 필요한 페이지 번호를 찾습니다. 바닥글에 인쇄된 번호가 아니라 뷰어의 페이지 표시를 기준으로 하세요. 둘은 다른 경우가 많습니다(보고서에 인쇄된 '1쪽'이 실제로는 세 번째 페이지일 수 있습니다).
  3. 추출할 페이지 입력란에 1-3, 5, 8처럼 입력하거나, 12페이지부터 끝까지라면 12-라고 입력합니다. 비워 두면 모든 페이지가 추출됩니다.
  4. 페이지 추출을 누릅니다. 선택한 페이지가 입력한 순서대로 새 문서에 복사됩니다.
  5. yourfile-extracted.pdf를 다운로드하고, 보내거나 보관하기 전에 페이지 수와 첫 페이지, 마지막 페이지를 확인합니다.

이 도구가 필요한 경우

  • 긴 임대차 계약서 전체 대신, 서명한 페이지와 생활 규칙 별지만 세입자에게 보낼 때.
  • 스터디 모임이 해당 범위만 메모할 수 있도록 수업 자료집에서 한 단원만 뽑을 때.
  • 이사회 자료용으로 연차 보고서에서 요약표와 조사 결과 두 페이지를 가져올 때.
  • 대출이나 전월세 계약 서류용으로, 1년 치를 한꺼번에 받은 파일에서 한 달 치 급여 명세서나 통장 거래 내역만 떼어 낼 때.
  • 페이지 수나 용량 제한이 엄격한 온라인 제출 시스템에 증거 묶음 중 관련 페이지만 올릴 때.
  • 슬라이드 PDF에서 중요한 다섯 장을 발표할 순서대로 골라 짧은 유인물을 만들 때.

시작하기 전에 알아둘 점

  • 페이지 번호는 1부터 센 파일 안의 실제 위치를 뜻합니다. 'iv'나 '10쪽 중 3쪽' 같은 인쇄된 쪽 표시는 무시되고, 뷰어 사이드바에서의 위치만 중요합니다.
  • 문서 범위를 벗어난 번호는 조용히 건너뜁니다. 20페이지 파일에 18-25를 입력하면 경고 없이 18, 19, 20페이지가 나오고, 30만 입력하면 "선택된 유효한 페이지가 없습니다."라는 오류가 납니다.
  • 범위는 작은 수에서 큰 수 순이어야 합니다. 7-3은 아무 페이지와도 일치하지 않으니 3-7로 쓰거나, 거꾸로 원한다면 7, 6, 5, 4, 3처럼 하나씩 나열하세요.
  • 반복된 번호는 제거되지 않습니다. 1, 1, 1을 입력하면 1페이지가 세 번 들어간 3페이지짜리 파일이 됩니다. 서식 페이지를 복제할 때는 편리하지만, 실수로 그랬다면 곤란합니다.
  • 새 파일에는 책갈피가 옮겨지지 않으며, 문서 안의 다른 페이지로 이동하는 링크는 대상 페이지가 추출본에 없을 수 있어 작동하지 않을 수 있습니다. 웹사이트 링크는 그대로 작동합니다.
  • 선택한 페이지에 있는 양식 필드와 주석은 보통 함께 옮겨지지만, 작성 가능한 양식은 문서 간에 페이지를 복사할 때 깨지기 쉽습니다. 추출본이 계속 작성 가능해야 한다면 쓰기 전에 필드 하나를 시험해 보세요.

더 좋은 결과를 위한 팁

  • 시작하기 전에 뷰어의 썸네일 사이드바를 보면서 페이지 목록을 적어 두세요. 잘못 추출한 파일을 고치는 것보다 시간이 덜 듭니다.
  • 문서 뒷부분은 끝이 열린 범위를 쓰세요. 41-은 전체가 몇 페이지든 41페이지부터 마지막 페이지까지를 뜻합니다.
  • 같은 파일에서 여러 개의 추출본(예: 고객별로 하나씩)이 필요하다면 추출본마다 도구를 한 번씩 돌리거나, PDF 분할의 사용자 지정 범위로 ZIP 하나에 모두 받으세요.
  • 원하는 페이지가 전체에서 몇 장만 뺀 나머지라면, 페이지 삭제를 써서 뺄 몇 장만 입력하는 편이 빠릅니다.
  • 다운로드한 파일은 바로 이름을 바꾸세요. 다운로드 폴더에 report-extracted.pdf가 세 개 있으면 엉뚱한 파일을 보내기 쉽습니다.

실제 예시: 보증금 문의에 답하는 집주인

집주인 윤재민 씨가 전 세입자로부터 왜 보증금 일부를 돌려주지 않았는지 묻는 이메일을 받았습니다. 전체 임대 서류는 46페이지 PDF입니다. 계약서가 1~18페이지, 사진이 들어간 입주 시 상태 점검표가 19~38페이지, 퇴거 시 점검 보고서가 39~44페이지, 청소와 수리 영수증 두 장이 45, 46페이지입니다. 전부 보내면 정작 답이 묻히고, 사진이 많은 점검표 때문에 용량도 25MB쯤 됩니다.

세입자에게 실제로 필요한 건 청소 관련 조항(11페이지), 주방과 바닥재 입주 점검 페이지(27, 31페이지), 대응하는 퇴거 점검 페이지(41, 42페이지), 그리고 영수증 두 장입니다. 입력란에 11, 27, 41, 31, 42, 45-46을 입력하면 입주 전후 비교 페이지가 한 쌍씩 나란히 오고 그 뒤에 영수증이 붙습니다. 결과는 사진 크기에 따라 대략 4~6MB인 7페이지 파일로, 위에서 아래로 읽기만 하면 설명이 됩니다.

원래의 46페이지 파일은 바뀌지 않으므로, 분쟁이 더 커지더라도 전체 기록으로 남아 있습니다. 보내는 건 짧은 추출본뿐입니다.

문제 해결

"선택된 유효한 페이지가 없습니다."라는 오류가 납니다
입력한 번호 중 이 파일에 있는 페이지가 하나도 없거나, 범위를 큰 수에서 작은 수 순으로 썼습니다. 뷰어에서 전체 페이지 수를 확인하고, 범위는 3-7처럼 작은 수-큰 수로 쓰세요.
엉뚱한 페이지가 추출되었습니다
바닥글에 인쇄된 쪽 번호를 썼을 가능성이 큽니다. 뷰어의 썸네일 사이드바로 실제 페이지 위치를 세서 다시 추출하세요.
요청한 페이지 중 일부가 빠졌습니다
문서 끝을 넘어선 페이지는 메시지 없이 빠집니다. 50페이지 파일에 10-60을 입력하면 10~50페이지가 나옵니다. 전체 페이지 수를 확인하고 다시 추출하세요.
추출한 파일이 원본만큼 큽니다
고른 페이지에 무거운 내용, 대개 스캔 이미지나 사진이 대부분 들어 있기 때문입니다. 추출본을 PDF 압축에 넣으세요. 텍스트뿐인 페이지는 이미 작아서 별로 달라지지 않습니다.
파일은 열리는데 추출본이 비어 있거나 깨져서 나옵니다
원본이 암호화되어 있을 가능성이 큽니다. 도구는 암호화 검사를 끈 채 파일을 열기 때문에, 오류 대신 읽을 수 없는 페이지가 나올 수 있습니다. 파일을 만든 프로그램에서 보호를 해제한 뒤, 보호되지 않은 사본에서 추출하세요.
목차의 링크가 더 이상 작동하지 않습니다
내부 링크는 원본 문서 안의 위치로 페이지를 가리키는데, 추출본에서는 그 대상이 없거나 위치가 바뀌었습니다. 추출본에서 목차 페이지를 빼거나, 책갈피 만들기 도구로 새 책갈피를 추가하세요.

자주 묻는 질문

페이지를 추출하면 원본 PDF가 바뀌나요?

아니요. 도구는 원본을 읽기만 하고 yourfile-extracted.pdf라는 별도의 새 파일을 씁니다. 디스크의 원본 파일에는 아무것도 기록하지 않습니다.

원본과 다른 순서로 페이지를 추출할 수 있나요?

네. 페이지는 입력한 순서대로 들어가므로, 9, 2, 4를 입력하면 9페이지로 시작하는 파일이 됩니다.

같은 페이지를 두 번 이상 추출할 수 있나요?

네. 중복도 그대로 유지되므로 3, 3을 입력하면 3페이지가 두 장 들어갑니다. 의도한 게 아니라면 목록을 확인하세요.

추출한 페이지의 텍스트도 검색되나요?

원래 검색되던 텍스트라면 네. 페이지를 이미지로 바꾸지 않고 그대로 복사합니다. 스캔 페이지는 그대로 이미지이므로, 검색이 필요하면 추출한 파일에 OCR PDF를 돌리세요.

PDF 분할과는 무엇이 다른가요?

추출은 입력한 페이지로 새 파일 하나를 만듭니다. 분할은 여러 파일(페이지마다, 범위마다, N페이지마다)을 한 번에 만들어 ZIP으로 줍니다.

PDF가 어딘가에 업로드되나요?

아니요. pdf-lib가 브라우저 탭 안에서 실행되므로 페이지 복사는 내 컴퓨터에서 이뤄지고, 다운로드 파일도 로컬에서 만들어집니다.

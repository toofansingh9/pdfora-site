PDF를 PNG로

PDF의 모든 페이지를 무손실 PNG 이미지로 저장합니다. 도면, 차트, 작은 글씨도 선명하게 남습니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

페이지가 사진보다 선과 경계로 이루어져 있다면 PNG를 고르세요. 평면도, 회로도, 스프레드시트, 수학 학습지, 가는 선이 가득한 슬라이드는 JPEG 압축을 거치면 검은 선 주변에 회색 테두리가 생깁니다. PNG는 모든 픽셀을 정확히 저장하므로, 렌더링된 페이지가 PDF 뷰어 화면에서 보던 것과 똑같이 이미지에 남습니다.

변환은 페이지 단위로 진행됩니다. Firefox에 쓰이는 렌더링 엔진인 PDF.js가 각 페이지를 캔버스에 그리고, 그 캔버스를 PNG 파일로 씁니다. 캔버스의 픽셀 수는 직접 고릅니다. 화면용은 페이지 포인트 크기의 1.5배(약 108 dpi), 표준은 2배(약 144 dpi, 기본값), 높음은 3배(약 216 dpi)로 그립니다. PNG는 무손실이라 화질에 영향을 주는 건 이 설정뿐이고, 파일 크기에는 큰 영향을 줍니다.

대신 무게가 문제입니다. 텍스트 페이지를 PNG로 저장하면 넓은 흰 영역이 잘 압축되어 보통 아담하지만, 컬러 사진이 가득한 페이지는 같은 페이지의 JPG보다 몇 배 커질 수 있습니다. 스캔 문서나 사진첩 같은 PDF라면 대개 JPG 변환이 더 실용적이고, PNG는 선명한 그래픽과 텍스트에서 그 용량만큼의 값을 합니다.

PDF 페이지를 PNG로 변환하는 방법

  1. PDF를 PNG로 도구를 열고 PDF 파일 하나를 끌어다 놓습니다.
  2. 품질을 고릅니다. 문서화와 웹용으로는 표준이 알맞고, 인쇄나 확대해서 보기, 다른 프로그램에서 OCR을 할 거라면 높음(인쇄용)이 낫습니다.
  3. 변환을 누르고 각 페이지가 렌더링되는 동안 기다립니다. 진행 표시줄은 페이지마다 한 칸씩 움직입니다.
  4. 모두 다운로드 (.zip)로 전체 페이지를 받거나, 파일 버튼 하나를 눌러 PNG 한 장만 받습니다.
  5. 이미지 한 장에서 치수 표기나 각주처럼 가장 작은 부분을 확대해, 설정이 충분히 높았는지 확인합니다.

이 도구가 필요한 경우

  • 가는 선이 읽혀야 하는 기술 도면이나 배선도를 위키, 이슈 티켓, README에 넣을 때.
  • PDF로 내보낸 강의 슬라이드를 이미지 업로드만 받는 학습 플랫폼용으로 바꿀 때.
  • 셀 테두리마다 회색 JPEG 번짐이 생기지 않는 깔끔한 표 이미지를 보고서나 메신저에 붙일 때.
  • 디자이너에게 이미지 편집기에서 따라 그리거나, 자르거나, 합성할 고해상도 페이지 이미지를 줄 때.
  • 서명한 양식처럼 페이지의 정확한 모습을 나중에 비교하려고 보관할 때. 압축 손상이 있으면 곤란한 경우입니다.
  • 선명하고 손상 없는 이미지에서 더 잘 작동하는 OCR 프로그램이나 번역 도구에 넣을 페이지 이미지를 준비할 때.

시작하기 전에 알아둘 점

  • 페이지는 흰 바탕 위에 그려지므로, 형식 자체는 투명도를 지원하지만 PNG 파일은 투명하지 않습니다.
  • PDF의 모든 페이지를 내보냅니다. 몇 페이지만 변환하려면 페이지 추출로 먼저 잘라 내세요.
  • 파일 이름은 원래 이름에 자릿수를 맞춘 쪽 번호가 붙어 plans-001.png, plans-002.png처럼 되고, ZIP 이름은 plans-png.zip입니다.
  • 선택 가능한 텍스트, 하이퍼링크, 책갈피, 양식 필드는 남지 않습니다. PNG는 페이지가 어떻게 보였는지만 보여 줍니다.
  • 픽셀 크기는 PDF에 저장된 페이지 크기를 따릅니다. A3 도면은 표준에서 약 1684 x 2382픽셀, A4 페이지는 약 1191 x 1684픽셀입니다.
  • 파일 크기 편차가 JPG보다 훨씬 큽니다. 단순한 텍스트 페이지는 작지만, 사진이 많거나 노이즈 낀 어두운 배경의 페이지는 높음에서 한 장에 몇 MB씩 될 수 있습니다. 어두운 슬라이드와 그라데이션 페이지는 PNG로 잘 압축되지 않습니다. 모든 슬라이드가 검은 배경인 자료라면 높음에서 파일이 클 것을 예상하고 표준을 고려하세요.

더 좋은 결과를 위한 팁

  • 섞인 문서라면 두 번 변환하세요. 도면 페이지는 PNG, 사진 페이지는 JPG로 만든 뒤 페이지마다 맞는 파일을 남기면 됩니다.
  • 누군가 이미지를 인쇄하거나 6포인트 글씨를 읽어야 한다면 높음을 쓰세요. 화면으로 볼 거라면 표준이면 충분합니다.
  • 웹사이트에 쓰기엔 PNG가 너무 무겁다면 PNG 그대로 이미지 최적화 도구에 넣으세요. 픽셀 손실 없이 줄일 수 있습니다.
  • 벡터 도면은 높음으로 확인하세요. 108 dpi에서 끊겨 보이던 가는 선이 216 dpi에서는 이어진 선으로 렌더링되는 경우가 많습니다.
  • 이미지와 함께 PDF도 보관하세요. 검색과 확대가 되는 원본은 여전히 PDF입니다. 이미지는 변환하는 순간 렌더링되므로, 뷰어에 보이는 주석과 댓글은 PDF.js가 그리는 경우에만 포함되고 기본으로 꺼져 있는 숨은 레이어는 계속 숨겨집니다.

실제 예시: 도면을 공유하는 인테리어 시공업자

인테리어 시공업체 대표 강도현 씨가 건축사무소에서 A3 평면도를 벡터 PDF로 받았습니다. 방마다 치수를 타일 기사에게 메신저로 공유해야 하는데, 기사님은 모든 걸 휴대폰으로 보고 PDF를 만지작거리고 싶어 하지 않습니다.

JPG로 변환하자 가는 선 옆의 작은 회색 치수 글씨 가장자리가 얼룩져서, 확대하면 3과 8을 구분하기 어렵습니다. 높음으로 PNG 변환을 하면 페이지가 약 2526 x 3573픽셀로 렌더링되고, 손실 압축이 없어 모든 치수 표기가 선명하게 남습니다. 파일은 JPG보다 크지만 보내기엔 여전히 무리가 없습니다.

그는 도면의 가는 해칭 무늬가 화면용 품질에서는 사라진다는 것도 알아챕니다. 도면 문제가 아니라, 108 dpi에서는 그 선들이 1픽셀보다 가늘기 때문입니다. 높음을 고르면 해결되고, 이것이 설정이 세 가지인 주된 이유입니다. 만약 도면이 벡터 내보내기가 아니라 종이 도면을 스캔한 것이었다면 결과가 달랐을 겁니다. PNG가 종이 결이나 회색 노이즈까지 충실히 재현해 파일이 무거워지죠. 스캔본에는 대개 표준 JPG가 적당한 타협이고, PNG는 작은 표기를 꼭 읽어야 하는 페이지에 쓰는 게 좋습니다.

문제 해결

PNG 파일이 너무 커요
PNG는 무손실이라 사진이 많은 페이지는 큽니다. 더 낮은 설정을 쓰거나, 그런 페이지는 PDF를 JPG로 변환하세요.
가는 선이 사라지거나 끊겨 있어요
선택한 해상도에서 1픽셀보다 가는 선입니다. 높음으로 다시 변환하세요.
투명 배경을 기대했어요
페이지가 흰 바탕 위에 렌더링되므로 결과는 불투명합니다. 투명도가 필요하면 이미지 편집기에서 배경을 지우세요.
도구가 PDF를 열지 못해요
대개 비밀번호나 파일 손상이 원인입니다. 원래 프로그램에서 보호를 해제하거나 PDF 복구 도구를 시도한 뒤, 고친 사본을 변환하세요.
긴 문서인데 다운로드 버튼이 50개만 보여요
가독성을 위해 목록 버튼은 50개까지입니다. ZIP 다운로드에는 모든 페이지가 들어 있습니다.
글자가 원본과 조금 다르게 보여요
PDF가 포함되지 않은 글꼴을 써서 PDF.js가 비슷한 글꼴로 대체했을 가능성이 큽니다. 글꼴을 포함해 PDF를 다시 내보내세요.

자주 묻는 질문

PDF 페이지에는 PNG가 JPG보다 좋은가요?

텍스트, 차트, 선 도면이라면 그렇습니다. PNG는 경계를 정확히 유지합니다. 사진과 스캔본은 JPG가 훨씬 작은 용량으로 비슷한 화질을 내는 경우가 많습니다.

각 설정은 몇 dpi에 해당하나요?

PDF에 저장된 페이지 크기 기준으로 화면용은 약 108 dpi, 표준은 약 144 dpi, 높음은 약 216 dpi입니다.

PNG를 투명 배경으로 만들 수 있나요?

아니요. 렌더러가 저장 전에 페이지를 흰 바탕에 그리므로 모든 PNG는 불투명합니다.

PNG에서 텍스트를 복사할 수 있나요?

아니요. 텍스트가 픽셀이 됩니다. 복사용으로는 PDF를 보관하고, PDF가 없다면 이미지에 OCR을 쓰세요.

변환에 계정이나 결제가 필요한가요?

아니요. 로그인 없이 무료로 쓸 수 있습니다.

비슷해 보이는 페이지인데 PNG 파일 크기가 왜 다르죠?

PNG는 단색 영역은 아주 잘, 노이즈 많은 영역은 잘 못 압축합니다. 같은 해상도라도 사진, 그라데이션, 스캔 질감이 있는 페이지는 흰 바탕 텍스트 페이지보다 훨씬 큰 파일이 됩니다.

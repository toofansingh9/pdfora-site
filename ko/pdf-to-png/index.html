PDF를 PNG로

PDF 페이지를 무손실 PNG 이미지로 변환합니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.
1

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

PDF 페이지에 텍스트, 표, 차트, 선 그림이 들어 있다면 PNG가 정답입니다. JPG와 달리 PNG 압축은 무손실이라 글자의 날카로운 가장자리가 유지되고 얇은 도해 선에도 압축 잡티가 끼지 않습니다. 이 도구는 PDF의 모든 페이지를 PNG 이미지로 변환하며, 여러 페이지 문서는 페이지 번호가 순서대로 붙은 ZIP 파일 하나로 제공됩니다.

변환은 전적으로 브라우저가 처리합니다. PDF는 업로드되지 않으므로 법률 계약서, 시험지, 재무제표가 내내 사용자 기기에 머뭅니다. 서버에 저장되는 것이 없으니 나중에 만료되거나 삭제할 것도 없습니다. 이 도구는 무료이고, 계정이 필요 없으며, 워터마크나 페이지 제한도 두지 않습니다.

결과가 픽셀 단위로 정확하기 때문에 PDF to PNG는 문서용 화면 캡처, 디자인 도구로 옮길 슬라이드, 선명한 인터페이스 텍스트 옆에 놓일 이미지에 표준처럼 쓰입니다. 사진이 많은 페이지를 변환하면서 파일을 더 작게 만들고 싶다면 PDF to JPG 도구가 더 잘 맞습니다.

온라인에서 PDF를 PNG로 변환하는 방법

  1. PDF to PNG 도구를 열고 파일을 페이지 위로 끌어다 놓거나, 클릭해서 기기에서 고릅니다.
  2. 브라우저가 문서를 로컬에서 읽도록 둡니다. 잠시 후 인식된 페이지가 표시됩니다.
  3. 변환을 시작합니다. 각 페이지가 무손실 PNG 이미지로 렌더링됩니다.
  4. 결과를 내려받습니다. 한 페이지짜리 PDF는 PNG 한 장으로, 여러 페이지 파일은 ZIP으로 나옵니다.
  5. ZIP을 풀고 필요한 페이지가 100% 배율에서 제대로 보이는지 확인합니다.
  6. 이미지를 이름을 바꾸거나 프로젝트로 옮기세요. 문서, 슬라이드, 웹에 바로 쓸 수 있습니다.

When to use this tool

  • 화면 캡처와 UI 글자가 또렷해야 하는 고객센터용으로 소프트웨어 매뉴얼 페이지를 PNG로 만들기
  • PDF 보고서에 있는 아키텍처 도해나 순서도를 Confluence, Notion, 위키에 넣을 이미지로 변환하기
  • PDF로 저장된 슬라이드를 PNG로 내보내 Figma, Canva, 새 발표 자료에서 다시 그리지 않고 재사용하기
  • JPG 압축이면 가는 선이 뭉개질 악보, 뜨개 도안, 기술 도면을 온라인에 게시하기
  • LinkedIn 게시물이나 개인 사이트에 올릴 수료증이나 졸업장 페이지를 깔끔한 이미지로 준비하기
  • 직접 다시 만들 만한 가치가 없을 때 논문의 표를 발표 자료용 이미지로 담아내기

Tips for the best results

  • 텍스트, 도해, 화면 캡처에는 PNG를 쓰고, 대부분 사진인 페이지에는 JPG를 쓰세요. 후자에서 PNG는 눈에 보이는 이득 없이 파일만 커집니다.
  • 긴 문서의 PNG는 금세 용량이 불어납니다. 파일이 수백 페이지라면 필요한 장이나 페이지만 변환하세요.
  • 결과를 확인할 때는 100% 배율로 보세요. 축소했을 때 흐릿해 보이는 페이지는 대개 뷰어가 줄여서 표시했을 뿐입니다.
  • PNG는 투명도를 지원하지만 PDF 페이지는 보통 흰색인 배경과 함께 렌더링됩니다. 투명한 버전이 필요하면 편집기에서 배경을 지우세요.
  • 작업이 끝날 때까지는 ZIP에 붙은 번호 파일명을 유지하세요. 이미지가 어느 페이지에서 왔는지 추적하기 쉽습니다.

자주 묻는 질문

PDF to PNG와 PDF to JPG는 무엇이 다른가요?

PNG는 무손실이라 텍스트와 선 그림이 완벽하게 또렷하게 남지만 파일이 커집니다. JPG는 더 강하게 압축하며 사진 위주 페이지에 적합합니다. 읽을 자료에는 PNG를, 그저 보기만 할 자료에는 PNG든 JPG든 고르면 됩니다.

변환이 제 기기에서 이뤄지나요?

네. PDF는 브라우저가 로컬에서 이미지로 렌더링하며 서버로 전송되지 않습니다. 기밀 문서가 기기를 떠나지 않으므로 기밀로 남습니다.

여러 페이지 PDF는 어떤 형태로 받나요?

모든 페이지가 개별 PNG가 되고, 전부 하나의 ZIP 파일로 묶입니다. 파일에는 페이지 번호가 붙으므로 폴더를 이름순으로 정렬하면 문서 순서가 그대로 복원됩니다.

이미지에 워터마크가 붙거나 제한이 있나요?

워터마크도, 하루 할당량도, 가입도 없습니다. 이 도구는 무료이며 백 번째 변환도 첫 번째와 똑같이 처리합니다.

PDF 전체가 아니라 한 페이지만 변환할 수 있나요?

이 도구는 제공한 파일의 모든 페이지를 변환합니다. 한 페이지만 얻으려면 먼저 그 페이지를 추출하거나 분할한 뒤 그 작은 PDF를 변환하세요.

왜 PNG 파일이 PDF보다 훨씬 큰가요?

PDF는 텍스트를 간결한 명령으로 저장하지만 PNG는 렌더링된 페이지의 모든 픽셀을 저장하기 때문입니다. 정상적인 현상이며, 화면에서 어떤 크기로 보든 PNG가 원본과 똑같아 보이는 이유이기도 합니다.

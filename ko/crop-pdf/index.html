PDF 자르기

모든 페이지에서 여백과 빈 공간을 균일하게 잘라 내세요.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

모든 페이지의 네 변에서 지정한 폭만큼 여백을 잘라 내는 방식으로 온라인에서 PDF 페이지를 자를 수 있습니다. 스캔본에는 검은 테두리가 따라오고, 내보낸 슬라이드에는 빈 공간이 넓게 남고, 학술 논문은 커다란 여백 안에 작은 글씨를 묻어 두죠. 자르기 한 번이면 전부 해결됩니다. PDFora는 로컬 처리 방식으로 브라우저 안에서 작업하므로, 다듬는 문서가 어디로도 업로드되지 않습니다.

이 도구는 숫자 하나만 받습니다. 각 가장자리에서 몇 포인트를 덜어 낼지죠. 1포인트는 1/72인치이므로 36포인트를 자르면 모든 페이지의 위, 아래, 왼쪽, 오른쪽에서 각각 0.5인치가 한 번에 사라집니다. 네 변에서 같은 여백을 덜어 내기 때문에 페이지는 가운데를 유지하고 문서 전체가 균일하게 남습니다. 페이지마다 가장자리가 들쭉날쭉해지는 일이 없습니다.

무료이고 계정도 필요 없으며 결과물에 워터마크도 붙지 않습니다. 페이지 제한도 일일 할당량도 없습니다. 처음에 너무 조금 잘렸다면 결과물을 더 큰 숫자로 한 번 더 돌리면 됩니다. 서버로 오가는 것이 없으니 매번 몇 초면 끝납니다.

온라인에서 PDF 자르는 방법

  1. getpdfora.com에서 자르기 도구를 열고 클릭하거나 끌어다 놓아 PDF를 추가합니다.
  2. 여백을 얼마나 덜어 낼지 정합니다. 72포인트가 1인치이고, 28포인트가 대략 1센티미터입니다.
  3. 여백 값을 입력합니다. 모든 페이지의 위, 아래, 왼쪽, 오른쪽에서 같은 양이 잘려 나갑니다.
  4. 자르기를 적용하고 브라우저가 파일을 로컬에서 처리하도록 둡니다. 업로드도 대기열도 없습니다.
  5. 잘린 PDF를 내려받아 텍스트나 그림이 잘려 나가지 않았는지 확인합니다.
  6. 여백이 여전히 넓다면 잘린 파일을 더 큰 값으로 다시 돌려 보기 좋을 때까지 조절합니다.

이 도구가 필요한 경우

  • 스캔한 페이지 주변에 생기는 어두운 테두리와 스캐너 그림자를 없애 문서를 깔끔하게 인쇄하기.
  • 태블릿이나 전자책 단말기로 읽기 전에 학술 논문의 PDF 여백을 잘라, 화면에서 글자가 눈에 띄게 커지게 하기.
  • PDF로 내보낸 슬라이드 자료를 조여, 슬라이드 주변의 빈 테두리를 없애고 내용이 페이지를 꽉 채우게 하기.
  • 요청한 적도 없는 기본 여백으로 'PDF로 인쇄'된 문서에서 프린터가 더한 빈 공간 잘라 내기.
  • 읽기용 사본을 공유하기 전에 전자책 교정지의 재단 여백과 도련을 정리하기.
  • 원래 레이아웃에서 남은 테두리를 없애 도면이나 양식을 실제 크기로 다시 인쇄할 수 있게 준비하기.

더 좋은 결과를 위한 팁

  • 처음에는 보수적으로 시작하세요. 20~30포인트를 먼저 자르고 결과를 확인하세요. 다시 자르는 건 언제든 가능하지만, 텍스트가 잘리면 원본부터 다시 해야 합니다.
  • 입력하기 전에 머릿속으로 환산하세요. 72포인트는 1인치, 28.35포인트는 1센티미터입니다. 일반적인 사무 문서 여백은 72포인트 정도입니다.
  • 가장자리 가까이에 있는 페이지 번호와 바닥글을 주의하세요. 과감하게 자를 때 가장 먼저 사라지는 요소입니다.
  • 균일한 자르기는 레이아웃이 일정한 문서에 가장 잘 맞습니다. 어떤 페이지의 여백이 유독 좁다면 내려받기 전에 확인하세요.
  • 다른 PDFora 도구로 페이지 번호나 머리글을 넣기 전에 먼저 자르세요. 그래야 새 요소가 최종 페이지 가장자리를 기준으로 배치됩니다.

자주 묻는 질문

자를 때 파일이 업로드되나요?

아니요. 자르기는 로컬 처리 방식으로 전부 브라우저에서 이뤄집니다. PDF는 내내 기기에 머물기 때문에 비공개 문서나 미공개 원고에도 안전합니다.

여백 값은 어떻게 동작하나요?

포인트 단위로 폭을 입력하면 모든 페이지의 네 변에서 그만큼 잘려 나갑니다. 1포인트는 1/72인치이므로 72를 넣으면 각 가장자리에서 정확히 1인치가 사라집니다.

각 변마다 다른 값으로 자를 수 있나요?

이 도구에서는 안 됩니다. 위, 아래, 왼쪽, 오른쪽에 같은 여백을 하나로 적용합니다. 그래야 페이지가 가운데를 유지하며, 스캔본이나 서식이 일정한 문서에는 이 방식이 맞습니다.

자르면 잘려 나간 내용이 영구적으로 삭제되나요?

자르기는 보이는 페이지 영역을 조정하며, 원본 파일은 절대 수정되지 않습니다. 너무 많이 잘렸다면 원본으로 돌아가 더 작은 값으로 다시 자르면 됩니다.

파일 크기나 사용 횟수에 제한이 있나요?

없습니다. 무료이고 무제한이며 가입도 필요 없습니다. 처리가 로컬에서 이뤄지므로 큰 파일은 업로드 상한이 아니라 사용자 기기 성능만이 한계입니다.

잘린 PDF에 워터마크가 붙나요?

아니요. PDFora는 결과물에 브랜딩을 절대 찍지 않습니다. 내려받는 파일은 여백만 좁아진 내 문서일 뿐, 더해진 것은 없습니다.

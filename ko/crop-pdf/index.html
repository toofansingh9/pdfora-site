PDF 자르기

아무것도 다시 렌더링하지 않고, 보이는 영역만 새로 지정해 모든 페이지의 네 변에서 같은 폭의 여백을 잘라 냅니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

넓은 흰 여백은 휴대폰 화면에서 거슬리고, 한 장에 여러 페이지를 모아 인쇄할 때는 공간 낭비입니다. 스캔한 책 페이지에는 제본 쪽을 따라 검은 띠가 생기기 쉽고, PDF로 내보낸 슬라이드에는 아무것도 없는 두꺼운 테두리가 붙어 나오기도 합니다. 여백을 자르면 그 빈 공간이 사라져 내용이 화면이나 종이를 더 넓게 채웁니다.

PDFora의 PDF 자르기 도구는 숫자 하나로 동작합니다. 모든 페이지의 네 변에서 똑같이 잘라 낼 여백을 포인트 단위로 입력하는 것입니다. 1포인트는 1/72인치이므로 기본값 30포인트는 10mm가 조금 넘습니다. 이 도구는 이미지에서 픽셀을 오려 내지 않습니다. 대신 페이지마다 새 CropBox를 기록하는데, 이는 뷰어와 프린터에게 페이지의 어느 사각형 영역을 보여 줄지 알려 주는 PDF 명령입니다. 그 사각형 바깥은 숨겨지지만 파일 안에는 여전히 저장되어 있습니다.

다시 그리는 과정이 없으니 텍스트는 선택 가능한 상태로 남고, 벡터 그림은 선명하며, 파일 크기도 거의 변하지 않습니다. 반대로 말하면 자르기는 민감한 내용을 지우는 방법이 아닙니다. PDF 편집기만 있으면 누구든 자르기 영역을 원래대로 돌려 숨겨진 가장자리를 다시 볼 수 있습니다. 처리는 브라우저 안에서 pdf-lib로 이뤄지며, 결과는 yourfile-cropped.pdf로 다운로드됩니다.

PDF 여백을 자르는 방법

  1. PDF 자르기를 열고 PDF 파일 하나를 선택합니다.
  2. 여백을 포인트 단위로 입력합니다. 기본값은 30이며, 72포인트가 1인치, 약 28포인트가 1센티미터입니다.
  3. 모든 페이지의 위, 아래, 왼쪽, 오른쪽에서 같은 양이 잘린다는 점을 기억하고, 여백이 가장 좁은 페이지에 맞는 값을 고르세요.
  4. 여백 자르기를 누르고, 원래 파일 이름에 -cropped가 붙은 파일이 다운로드될 때까지 기다립니다.
  5. 결과를 열어 내용이 가장자리까지 꽉 찬 페이지를 확인합니다. 가장자리 근처의 머리글, 바닥글, 페이지 번호가 가장 먼저 잘려 나갑니다.

이 도구가 필요한 경우

  • A4 보고서를 휴대폰이나 전자책 단말기로 읽을 때. 흰 테두리가 사라지면 글자가 눈에 띄게 커집니다.
  • 글자 주위에 회색 그림자나 스캐너 유리 가장자리가 찍힌 책 스캔 페이지를 정리할 때.
  • 2-up이나 4-up 인쇄를 준비할 때. 내용이 작은 칸을 더 넓게 써서 더 작아지지 않습니다.
  • 넓은 테두리가 붙은 채 저장된 발표 슬라이드를 다듬을 때.
  • PDF 페이지를 다른 문서에 넣기 전에 차트나 도면 주위의 빈 띠를 없앨 때.
  • 시험지나 학습지를 교실 화면에 띄워 보기 편하게 만들 때.

시작하기 전에 알아둘 점

  • 자르기는 균일하게 적용됩니다. 변마다 다른 값이나 페이지별 설정이 없어서, 여백이 들쭉날쭉한 문서도 모든 곳이 같은 양만큼 잘립니다.
  • 숨겨진 영역은 삭제되지 않습니다. 새 영역 바깥의 텍스트와 이미지는 파일에 남아 있고 다시 드러날 수 있습니다. 가장자리를 실제로 없애려면 먼저 자른 뒤 PDF를 JPG로 도구로 페이지를 이미지로 바꾸고, JPG / PNG를 PDF로 도구로 파일을 다시 만드세요. 이미지에는 보이는 영역만 담깁니다.
  • 페이지가 아예 사라지지 않도록 여백에는 상한이 있습니다. 아무리 큰 숫자를 입력해도 가로세로 각각 최소 약 2포인트의 보이는 영역은 남깁니다.
  • 새 영역은 페이지의 전체 용지 크기(media box)를 기준으로 계산됩니다. 페이지에 이미 자체 자르기 영역이 있었다면 거기서 더 좁히는 것이 아니라 교체됩니다.
  • 자른 뒤에는 뷰어에 표시되는 페이지 크기가 작아집니다. 인쇄할 때 프린터가 잘린 페이지를 종이에 맞게 확대할 수 있어, 글자가 커 보일 수 있습니다.
  • 페이지를 새 파일로 복사하지 않고 원래 파일 안에서 수정하기 때문에 책갈피, 링크, 양식 필드는 그대로 남습니다.

더 좋은 결과를 위한 팁

  • 먼저 재 보세요. 뷰어에서 내용이 가장 꽉 찬 페이지의 글자가 가장 가까운 가장자리에서 얼마나 떨어져 있는지 확인하고, 그보다 조금 작은 여백을 고르세요.
  • 20~30포인트 정도의 무난한 값으로 시작하세요. 나중에 페이지 번호가 잘린 걸 발견하는 것보다 원본에 더 큰 값을 넣어 다시 돌리는 편이 빠릅니다.
  • 이미 자른 사본이 아니라 항상 원본 파일을 자르세요. 두 번째 실행은 다시 전체 페이지에서 계산을 시작하므로 기대한 대로 누적되지 않습니다.
  • 한쪽에만 검은 테두리가 있는 스캔본도 균일하게 자르면 나머지 세 변까지 잘립니다. 반대쪽 여백도 같은 양을 잃어도 괜찮은지 확인하세요.
  • 회사 밖으로 공유할 문서의 가장자리에 메모나 내부 참조 정보가 있었다면 자르기에 기대지 마세요. 공유하기 전에 그 내용을 제대로 지워야 합니다.

실제 예시: 태블릿용 교재 스캔본

대학생 김하늘 씨에게 A4로 스캔한 40페이지 분량의 교재 한 단원이 있습니다. 스캔본마다 복사기 덮개 때문에 15mm 폭의 회색 테두리가 있고, 인쇄된 본문은 가장자리에서 약 25mm 안쪽에서 시작합니다. 10인치 태블릿에서는 글자가 작아서 계속 확대하고 옆으로 스크롤해야 합니다.

15mm는 약 43포인트이므로 45를 입력합니다. 모든 페이지에서 회색 테두리가 사라지고, 페이지를 너비에 맞추면 본문이 화면 대부분을 채웁니다. 70포인트(약 25mm)로 시험했을 때는 여러 페이지에서 상단의 단원 제목이 잘려서, 원본으로 돌아가 45를 썼습니다.

스캔 이미지 자체는 건드리지 않았기 때문에 파일 크기는 그대로입니다. 나중에 인쇄 등을 위해 전체 페이지가 다시 필요하면 보관해 둔 원본 파일을 쓰면 됩니다.

문제 해결

페이지 번호나 머리글이 잘렸습니다
해당 페이지에서 내용과 가장자리 사이 간격보다 여백 값이 컸습니다. 원본 파일로 더 작은 값을 넣어 다시 실행하세요.
다른 프로그램에서는 숨긴 내용이 그대로 보입니다
일부 편집기와 인쇄 과정은 자르기 영역을 무시하고 전체 용지 영역을 보여 줍니다. 자르기는 내용을 숨길 뿐 없애지 않습니다. 가장자리를 정말로 없애야 한다면 자른 페이지를 이미지로 바꾸세요(PDF를 JPG로, 이어서 JPG / PNG를 PDF로).
어떤 페이지는 너무 많이 잘리고 어떤 페이지는 거의 그대로입니다
크기가 다른 페이지에 같은 여백을 적용하기 때문입니다. 작은 페이지일수록 비율상 더 많이 잘립니다. 크기가 다른 페이지를 별도 파일로 나눠 그룹마다 맞는 값으로 자르세요.
인쇄하면 글자가 전보다 크게 나옵니다
인쇄 대화상자가 더 작아진 페이지를 종이에 맞게 확대하고 있습니다. 원래 글자 크기로 인쇄하려면 실제 크기 또는 100% 배율을 선택하세요.
아무 변화가 없는 것 같습니다
여백 값이 0이 아닌지 확인하세요. 또한 입력한 값보다 이미 더 좁게 잘려 있던 페이지는 새 영역이 전체 페이지 기준으로 계산되기 때문에 오히려 더 넓게 보이게 됩니다.
도구에서 파일이 열리지 않습니다
파일이 손상되었을 수 있습니다. PDF 복구로 고친 뒤 복구된 사본을 자르세요.

자주 묻는 질문

자르면 파일 크기가 줄어드나요?

거의 줄지 않습니다. 자르기 영역 밖의 내용도 파일에 그대로 저장되어 있기 때문입니다. 파일을 작게 만들려면 PDF 압축을 사용하세요.

여백 단위는 무엇인가요?

PDF 포인트입니다. 72포인트가 1인치, 약 28.35포인트가 1센티미터이므로 기본값 30포인트는 대략 10.6mm입니다.

변마다 다른 양을 자를 수 있나요?

이 도구로는 안 됩니다. 모든 페이지의 네 변에서 같은 여백을 잘라 냅니다.

일부 페이지만 자를 수 있나요?

직접은 안 됩니다. PDF 분할이나 페이지 추출로 자를 페이지만 꺼내 그 파일을 자른 뒤, 나머지와 다시 병합하세요.

자른 뒤에도 텍스트를 선택할 수 있나요?

네. 페이지를 다시 렌더링하지 않으므로 보이는 영역 안의 텍스트, 링크, 벡터 그래픽은 그대로입니다.

기밀 정보를 숨기는 데 자르기를 써도 안전한가요?

아니요. 잘려 나간 영역은 PDF 편집기만 있으면 누구나 복원할 수 있습니다. 보여서는 안 되는 내용이라면 제대로 된 가림 처리 도구를 쓰거나, 자른 페이지를 PDF를 JPG로와 JPG / PNG를 PDF로 도구로 이미지화하세요.

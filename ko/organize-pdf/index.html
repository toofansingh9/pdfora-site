페이지 정리

PDF의 모든 페이지를 썸네일로 보면서 드래그로 순서를 바꾸고, 회전하거나 삭제한 뒤 새 파일로 저장합니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

페이지 번호를 입력하는 방식은 번호를 이미 알고 있을 때나 통합니다. 스캔 순서가 뒤죽박죽이거나 긴 문서에서 여러 군데를 한꺼번에 고쳐야 할 때는 페이지를 직접 봐야 하죠. 페이지 정리 도구는 파일의 모든 페이지를 작은 썸네일로 그려 보드에 올려놓고, 각 카드를 끌어서 옮기거나 왼쪽·오른쪽으로 돌리거나 삭제 표시를 할 수 있게 해 줍니다. 적용 후 다운로드를 누르기 전까지는 파일에 아무 일도 일어나지 않습니다.

썸네일은 PDF.js로 페이지 기본 표시 크기의 약 3분의 1로 그려지며, 레이아웃으로 어떤 페이지인지 알아보기엔 충분하지만 작은 글씨를 읽기엔 부족합니다. 어디까지나 미리보기입니다. 변경 사항을 적용하면 도구는 원본 PDF로 돌아가 pdf-lib로 실제 페이지를 보드 순서대로 새 문서에 복사합니다. 회전한 페이지는 다시 그리지 않고 회전 설정만 바꾸며, 삭제 표시한 페이지는 건너뜁니다. 결과는 yourfile-organized.pdf 형태로 저장되고 텍스트, 웹사이트 링크, 이미지 화질은 그대로입니다.

긴 문서는 보드가 나타나기 전에 모든 페이지를 그려야 해서 시간이 걸립니다. 20페이지짜리 편지는 거의 바로 뜨지만, 400페이지짜리 스캔 책은 꽤 걸리고 휴대폰에서는 메모리를 많이 씁니다. 번호를 짐작하는 대신 페이지를 직접 볼 수 있는 대가입니다.

PDF 페이지 순서를 바꾸는 방법

  1. 페이지 정리 도구를 열고 PDF 한 개를 선택합니다. '페이지 렌더링 중…' 메시지가 썸네일로 바뀔 때까지 기다립니다.
  2. 페이지 카드를 끌어서 원하는 자리에 놓습니다. 각 카드에는 원래 페이지 번호가 라벨로 남아 있어 어느 페이지였는지 언제든 알 수 있습니다.
  3. 카드의 화살표 버튼 두 개로 해당 페이지를 왼쪽이나 오른쪽으로 90도 돌립니다. 180도는 두 번 누르면 됩니다.
  4. 휴지통 버튼을 눌러 삭제 표시를 합니다. 카드는 회색으로 바뀌지만 보드에 남아 있고, 휴지통을 다시 누르면 되살아납니다.
  5. 적용 후 다운로드를 누르고, 원본을 지우거나 바꾸기 전에 뷰어에서 yourfile-organized.pdf를 확인합니다.

이 도구가 필요한 경우

  • 스캐너에 종이가 걸려 다시 넣는 바람에 순서가 뒤섞인 학교 시험지를 문제 순서대로 되돌릴 때.
  • 일부는 거꾸로, 일부는 옆으로 누운 스캔본을 바로잡고 빈 종이까지 한 번에 지울 때.
  • 위원회에 올리기 전에 보고서 맨 뒤의 요약을 맨 앞으로 옮길 때.
  • 특정 고객에게 맞춰 가장 강한 프로젝트가 먼저 나오도록 포트폴리오 PDF를 다시 구성할 때.
  • 아무 순서로나 찍힌 레시피 모음이나 필기 파일을 정리할 때.
  • 보내기 전에 문서를 한 장씩 눈으로 점검할 때. 결국 엉뚱한 페이지 하나만 지우게 되더라도요.

시작하기 전에 알아둘 점

  • 한 번에 PDF 하나만 정리할 수 있습니다. 여러 파일에 걸쳐 페이지 순서를 바꾸려면 먼저 PDF 병합 도구로 합친 뒤 병합된 파일을 정리하세요.
  • 여기서의 회전은 페이지의 회전 값을 바꾸는 것으로, PDF 뷰어에서 페이지를 돌리고 저장할 때 쓰는 것과 같은 설정입니다. 화질 손실이 없고, 페이지에 이미 있던 회전에 더해집니다.
  • 삭제한 카드는 적용 전까지 회색으로 계속 보입니다. 모든 페이지에 삭제 표시를 하면 도구가 '내보낼 페이지가 없습니다.'라는 메시지와 함께 멈춥니다.
  • 순서 변경은 브라우저 기본 드래그 앤 드롭을 사용합니다. 데스크톱 브라우저에서 마우스로는 잘 되지만, 많은 휴대폰·태블릿 브라우저는 이런 드래그를 지원하지 않으므로 순서를 많이 바꿔야 한다면 컴퓨터가 확실합니다.
  • 페이지를 새 문서로 복사하기 때문에 책갈피는 빠지고, 문서 안에서 다른 페이지로 이동하는 링크는 깨질 수 있습니다. 입력 가능한 양식 필드도 남지 않을 수 있습니다.
  • 실행 취소 기록은 없습니다. 처음부터 다시 하려면 페이지를 새로 고치고 파일을 다시 추가하세요. 원본 파일은 바뀌지 않았습니다.

더 좋은 결과를 위한 팁

  • 삭제부터 먼저 하세요. 회색 카드도 보드에서 자리를 차지하지만, 정리할 대상이 줄어들면 머릿속으로 순서를 잡기가 쉬워집니다.
  • 긴 문서는 큰 이동(구간 통째로 대략적인 위치로)을 먼저 하고, 그다음 이웃한 페이지를 세밀하게 맞추세요.
  • 브라우저를 축소하면 화면에 썸네일이 더 많이 들어옵니다. 여러 줄을 지나 카드를 끄는 것보다 보이는 위치에 바로 놓는 게 빠릅니다.
  • 한두 페이지만 옆으로 누워 있고 다른 건 바꿀 게 없다면 PDF 회전 도구가 더 빠르고 책갈피도 유지됩니다. 파일을 다시 만들지 않고 수정하기 때문입니다.
  • 결과를 열어 한 번 넘겨 보세요. 잘못 놓인 페이지는 파일이 나간 뒤보다 지금 찾는 게 훨씬 덜 아픕니다.

실제 예시: 교사의 잘못 들어간 스캔

한 중학교 과학 교사가 결석한 학생을 위해 14페이지짜리 실험 활동지를 스캔합니다. 6페이지 다음에 급지 장치에 종이가 걸려 7~10페이지를 다시 넣었더니, 그 네 장이 11~14페이지 뒤, 스캔 맨 끝에 들어갔습니다. 두 장은 거꾸로 들어갔고, 더미 맨 아래의 빈 종이 한 장이 15번째에 섞여 들어왔습니다.

보드에서는 문제가 바로 보입니다. 7~10 라벨이 붙은 카드가 14 뒤에 있고, 썸네일 두 개는 글자가 거꾸로입니다. 네 장의 카드를 6페이지 뒤로 옮기는 데 드래그 네 번이면 됩니다. 거꾸로 된 카드마다 회전 버튼을 두 번 눌러 180도 돌리고, 15번 카드의 휴지통을 눌러 회색으로 만듭니다.

적용 후 다운로드를 누르면 순서도 방향도 맞는 14페이지짜리 booklet-organized.pdf가 나옵니다. 페이지 번호를 여러 도구에 따로 입력했다면 세 번에 걸쳐 작업하며 계산도 꼼꼼히 해야 했겠지만, 여기서는 고치는 동시에 눈으로 확인할 수 있습니다.

문제 해결

보드가 '페이지 렌더링 중…'에서 오래 멈춰 있어요
보드가 나타나기 전에 모든 페이지를 그리므로 길거나 이미지가 많은 파일은 오래 걸립니다. 기다리거나, 다른 탭을 닫거나, 파일을 여러 부분으로 나눠 각각 정리한 뒤 다시 합치세요.
휴대폰에서 페이지를 끌 수 없어요
많은 모바일 브라우저는 보드가 쓰는 드래그 앤 드롭 이벤트를 지원하지 않습니다. 순서 변경은 데스크톱 브라우저에서 하세요. 버튼으로 하는 회전과 삭제는 터치 화면에서도 됩니다.
회전한 페이지가 결과에서 여전히 옆으로 누워 있어요
회전은 페이지에 원래 있던 회전 값에 더해집니다. 이미 돌아가 있던 페이지라면 다른 잘못된 방향으로 돌렸을 수 있습니다. 클릭 수를 세어 보세요. 한 번은 90도, 두 번은 180도입니다.
'내보낼 페이지가 없습니다.'라는 메시지가 떠요
모든 카드에 삭제 표시가 되어 있습니다. 최소 한 카드의 휴지통을 다시 눌러 되살린 뒤 다시 적용하세요.
책갈피가 사라졌어요
페이지 정리는 복사한 페이지로 문서를 다시 만들며, 책갈피는 복사되지 않습니다. 책갈피 만들기 도구로 다시 넣거나, 회전만 필요했다면 PDF 회전 도구를 쓰세요.
썸네일이 비어 있거나 파일이 불러와지지 않아요
PDF가 암호화되었거나 손상되었을 수 있습니다. 먼저 PDF 복구 도구를 시도하거나, 파일을 만든 프로그램에서 보호를 해제한 뒤 새 사본을 정리하세요.

자주 묻는 질문

썸네일이 최종 파일에 쓰이나요?

아니요. 저해상도 미리보기일 뿐입니다. 결과는 원본 페이지로 만들어지므로 화질은 원본과 같습니다.

이 보드에 다른 PDF의 페이지를 추가할 수 있나요?

아니요. 보드에는 파일 하나만 표시됩니다. 먼저 파일들을 합친 뒤 병합된 PDF를 정리하세요.

180도로 회전할 수 있나요?

네. 회전 버튼 중 하나를 두 번 누르세요. 한 번 누를 때마다 90도씩 돌아갑니다.

정리하면 원본 파일이 바뀌나요?

아니요. yourfile-organized.pdf라는 새 파일을 다운로드하며, 디스크의 원본은 그대로입니다.

페이지 수 제한이 있나요?

도구 자체에는 없지만 모든 페이지를 썸네일로 렌더링하므로, 아주 긴 파일은 느리고 메모리를 많이 씁니다. 특히 휴대폰에서 그렇습니다.

스캔 페이지가 검색 가능해지나요?

아니요. 정리는 페이지를 옮기고, 돌리고, 지울 뿐입니다. 스캔 페이지를 검색 가능하게 하려면 정리한 파일에 OCR PDF를 돌리세요.

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

무엇을 고쳐야 할지 정확히 알 때는 페이지 번호로도 충분합니다. 그렇지 않을 때는 문서를 눈으로 봐야 하죠. PDFora의 정리 도구는 PDF의 모든 페이지를 썸네일 보드로 펼쳐 줍니다. 페이지를 끌어서 순서를 바꾸고, 옆으로 스캔된 페이지를 돌리고, 지울 페이지를 표시하는 일을 한 화면에서 처리한 뒤 수정된 파일 하나로 내보낼 수 있습니다.

보드 전체가 브라우저 안에서 동작합니다. PDF는 로컬에서 렌더링되고 다시 만들어지며 업로드되지 않으므로, 임대차 계약서나 환자 파일, 급여 자료 묶음의 페이지 순서를 바꿔도 그 문서가 누군가의 서버에 닿지 않습니다. 덕분에 업로드를 기다릴 일도 없습니다. 두꺼운 파일도 기기가 그려 낼 수 있는 속도만큼 빠르게 열립니다.

이 모든 기능이 계정 없이 무료로 제공되며, 내보낸 PDF에는 워터마크가 없습니다. 한 페이지만 고치든 쉰 페이지를 뜯어고치든, 문서가 마음에 들 때까지 몇 번이든 작업하세요.

온라인에서 PDF 페이지 순서 바꾸고 정리하는 방법

  1. getpdfora.com의 PDF 정리 도구를 열고 파일을 불러옵니다.
  2. 모든 페이지가 보드에 썸네일로 나타날 때까지 잠시 기다립니다.
  3. 썸네일을 새 위치로 끌어 페이지 순서를 바꿉니다. 배치는 옮기는 대로 즉시 반영됩니다.
  4. 옆으로 누웠거나 거꾸로 된 페이지의 회전 버튼을 눌러 제대로 놓일 때까지 돌립니다.
  5. 필요 없는 페이지를 삭제 대상으로 표시합니다. 보드에 표시로 남으므로 확정 전에 마음을 바꿔도 됩니다.
  6. 내보내기를 눌러 새 페이지 순서와 회전, 삭제가 적용된 완성 PDF를 내려받습니다.

When to use this tool

  • 종이 뭉치가 급지대를 거꾸로 또는 뒤섞인 순서로 통과한 스캔 결과 바로잡기
  • 다른 페이지는 건드리지 않고, 세로 문서 안에 있는 가로 차트 두 장만 똑바로 세우기
  • 제출 지침이 요구하는 대로 부록을 참고문헌 앞으로 옮기기
  • 여러 발표 자료를 병합하면서 섹션이 뒤엉킨 유인물 다시 구성하기
  • 40페이지짜리 지원 서류 묶음을 눈으로 검토하며 제출 전에 중복 페이지 빼내기
  • 제안할 때마다 가장 좋은 작업이 먼저 보이도록 포트폴리오 페이지 순서 바꾸기

Tips for the best results

  • 회전, 순서 변경, 삭제를 한 번에 처리하세요. 도구 세 개를 따로 돌리는 것보다 한 번 내보내는 편이 낫습니다.
  • 회전은 페이지별로 적용되므로 문서 전체를 돌리지 않고 삐뚤어진 스캔 한 장만 고칠 수 있습니다.
  • 삭제 표시한 페이지는 내보내기 전까지는 사라지지 않으므로, 표시는 언제든 수정 가능한 후보 목록이라고 생각하세요.
  • 썸네일은 작습니다. 비슷해 보이는 페이지가 둘 있다면 확대하거나 원본을 옆에 띄워 두고 올바른 페이지를 옮기는지 확인하세요.
  • 휴대폰에서는 기기를 가로로 돌리면 보드가 화면에 더 많이 들어와 끌어 옮기기 편합니다.

자주 묻는 질문

Acrobat 없이 PDF 페이지 순서를 바꾸려면 어떻게 하나요?

PDFora의 정리 도구에 파일을 불러와 페이지 썸네일을 원하는 순서로 끌어다 놓고 내보내면 됩니다. 최신 브라우저라면 어디서든 무료로 동작하며 설치할 소프트웨어도 없습니다.

PDF 전체가 아니라 한 페이지만 회전할 수 있나요?

네. 썸네일마다 회전 버튼이 따로 있어서 가로로 스캔된 한 장만 똑바로 돌리고 나머지 페이지는 그대로 둘 수 있습니다.

페이지 삭제와 순서 변경을 동시에 할 수 있나요?

가능합니다. 지울 페이지를 표시하고, 나머지를 원하는 자리로 끌어 놓고, 삐뚤어진 페이지를 돌리면 모든 변경이 한 번에 적용되어 하나의 PDF로 내보내집니다.

정리하는 동안 제 문서가 업로드되나요?

아니요. 썸네일은 사용자 브라우저가 그리고 편집된 PDF도 로컬에서 조립되므로 파일이 어느 시점에도 기기를 떠나지 않습니다.

큰 파일은 왜 썸네일이 뜨는 데 시간이 걸리나요?

브라우저가 모든 페이지의 미리보기를 그리기 때문이며, 길거나 이미지가 많은 PDF는 그릴 것이 그만큼 많습니다. 속도는 서버가 아니라 기기에 달려 있고, 보드가 한 번 뜨면 끌어 옮기는 동작은 즉각적입니다.

내보내면 페이지 품질이 달라지나요?

아니요. 순서 변경, 회전, 삭제는 구조적인 변경이라 페이지 내용 자체는 재압축되지 않습니다. 텍스트와 이미지가 넣은 그대로 나옵니다.

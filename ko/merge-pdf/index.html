PDF 병합

PDF 두 개 이상을 원하는 순서대로 하나의 파일로 합칩니다. 업로드는 전혀 하지 않습니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.
1

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

PDF 작업 중 가장 자주 하는 일이 병합이고, 동시에 가장 많이 실수하는 일이기도 합니다. 파일 순서가 뒤바뀌거나, 지웠어야 할 페이지가 그대로 거래처에 가거나, 합친 파일이 메일에 첨부하기엔 너무 커져 버리곤 하죠. 이 페이지에서는 PDFora의 PDF 병합 도구가 파일에 실제로 어떤 일을 하는지, 무엇이 유지되고 무엇이 사라지는지, 그리고 두 번 작업하지 않으려면 무엇을 조심해야 하는지 정리했습니다.

기술적으로 병합은 각 원본 PDF의 페이지 객체를 새 문서에 차례로 복사하는 작업입니다. 텍스트는 실제 텍스트로 남아 선택과 검색이 그대로 되고, 벡터 그래픽은 벡터로, 이미지는 원래 해상도 그대로 한 번만 복사됩니다. 다시 렌더링하거나 재압축하지 않으므로 결과물은 페이지마다 원본과 똑같이 보입니다. 그 대신 용량은 대략 원본 용량의 합이 됩니다. 4 MB짜리 스캔 파일 세 개를 합치면 몇 KB 차이로 12 MB 정도가 나옵니다.

모든 작업은 브라우저 안에서 pdf-lib 라이브러리로 처리됩니다. 문서는 디스크에서 메모리로 읽혀 그 자리에서 합쳐지고, 결과는 다운로드로 바로 전달됩니다. 업로드 단계가 없으니 대기열도, 서버가 정한 용량 제한도, 나중에 저희가 지워야 할 파일도 없습니다.

PDF 파일을 온라인에서 합치는 방법

  1. PDF 병합 도구를 열고 파일을 한꺼번에 끌어다 놓거나, 상자를 클릭해 선택합니다. 나중에 더 추가해도 됩니다.
  2. 행을 드래그해 원하는 순서로 맞춥니다. 맨 위 행이 결과물의 1페이지가 됩니다. 왼쪽 손잡이 부분을 잡고 끌면 됩니다.
  3. 파일 이름 옆에 표시되는 용량을 확인합니다. 합계가 첨부 한도에 가깝다면 가장 큰 파일부터 먼저 압축하세요(아래 예시 참고).
  4. PDF 병합 버튼을 누릅니다. 진행 표시줄이 파일을 차례로 지나가며, 큰 스캔 파일은 하나에 몇 초씩 걸립니다.
  5. merged.pdf를 다운로드해 열어 보고, 보내기 전에 문서와 문서가 이어지는 부분을 넘겨 가며 확인합니다.

이 도구가 필요한 경우

  • 입사 지원: 자기소개서, 이력서, 자격증 사본을 채용 공고에 적힌 순서대로 첨부 파일 하나로 만들 때.
  • 비자·출입국 서류: 여권 사본, 사진, 은행 잔고 증명서, 초청장을 PDF 한 개로 올려야 할 때.
  • 월말 정산: 한 거래처의 해당 월 세금계산서와 영수증을 세무사에게 파일 하나로 넘길 때.
  • 강의 자료: 강의 유인물이나 원고의 각 장을 읽기 편한 문서 하나로 묶을 때.
  • 부동산·법률 서류: 계약서, 별첨, 각 당사자가 서명해 돌려준 페이지를 한데 모을 때.
  • 스캐너 묶음: 앞면과 뒷면을 따로 스캔한 파일을 페이지 순서대로 이어 붙일 때(뒷면이 역순으로 된 별도 파일이라면 교차 및 병합 도구를 쓰세요).

시작하기 전에 알아둘 점

  • 책갈피(개요 패널)는 옮겨지지 않습니다. 원본에 책갈피가 있어도 병합된 파일에는 없습니다. 필요하면 나중에 책갈피 만들기 도구로 넣으세요.
  • 입력 가능한 양식 필드는 문서를 합칠 때 깨질 수 있으며, 특히 두 파일이 같은 필드 이름을 쓰면 그렇습니다. 양식을 계속 입력 가능하게 둬야 한다면 양식이 없는 PDF끼리만 합치거나, 먼저 양식을 평면화한 사본으로 병합하세요.
  • 비밀번호가 걸린 파일은 PDF 병합 도구가 열 수 없습니다. 먼저 PDF 잠금 해제로 비밀번호를 없애고(열 때 비밀번호를 묻는 파일이라면 그 비밀번호가 필요합니다), 잠금 해제한 사본을 병합하세요.
  • 페이지 크기가 달라도 그대로 유지됩니다. A4 문서 다음에 US Letter 스캔, 그 다음에 가로 방향 스프레드시트가 오면 결과도 정확히 그렇게 나옵니다. 크기를 통일하려면 PDF 크기 조정 도구를 쓰세요.
  • 문서 안에서 같은 문서의 다른 페이지로 이동하는 링크는 병합 후 작동하지 않을 수 있습니다. 가리키던 페이지의 번호가 바뀌었기 때문입니다. 웹사이트로 가는 링크는 영향이 없습니다.
  • 합쳐진 파일은 브라우저 메모리 안에서 만들어집니다. 평범한 문서 몇 개는 순식간이지만, 수백 MB짜리 스캔 여러 개를 합치면 휴대폰이나 오래된 노트북은 메모리가 부족할 수 있습니다. 탭이 멈추면 데스크톱에서 하거나 두 번에 나눠 합치세요.

더 좋은 결과를 위한 팁

  • 추가하기 전에 파일 이름 앞에 번호를 붙이세요(01-자기소개서.pdf, 02-이력서.pdf). 순서가 한눈에 보이고, 처음부터 다시 해야 할 때도 그대로 쓸 수 있습니다.
  • PDF 병합 버튼을 누르기 전에 순서를 확정하세요. 결과 파일에는 실행 취소가 없어서, 나중에 순서를 바꾸려면 병합을 처음부터 다시 해야 합니다.
  • 원본에서 필요 없는 페이지는 페이지 삭제 도구로 먼저 지운 뒤 정리된 사본을 합치세요. 긴 결과물에서 그 페이지를 찾아 헤매는 것보다 훨씬 쉽습니다.
  • 병합된 PDF를 열어 페이지 수를 확인할 때까지는 원본을 지우지 마세요. 페이지 수는 원본 페이지 수의 합과 같아야 합니다.
  • 원본 중 하나가 스캔본이고 나머지가 디지털 문서라면, 병합만 해서는 스캔 페이지가 검색되지 않습니다. 병합한 파일에 OCR PDF를 돌리면 스캔 페이지에 텍스트 레이어가 더해지고 디지털 페이지는 그대로 남습니다.

실제 예시: 첨부 한도 10 MB

지원자 김서연 씨가 채용 대행사 포털로 입사 지원서를 낸다고 해 봅시다. 포털은 10 MB 이하 첨부 파일 한 개만 받습니다. 자기소개서(120 KB, 디지털 문서), 이력서(300 KB, 디지털 문서), 그리고 각각 4 MB쯤 되는 스캔 자격증 세 장이 있습니다. 이대로 합치면 약 12.4 MB가 되어 업로드가 거절됩니다.

문제는 디지털 문서가 아닙니다. 텍스트가 텍스트로 저장되어 있어서 아주 작습니다. 용량이 큰 건 페이지마다 사진인 스캔본입니다. 자격증 파일을 각각 PDF 압축 도구의 권장 수준으로 먼저 줄이면(4 MB짜리 스캔 한 페이지는 보통 0.5~1 MB 정도로 줄어듭니다), 그 다음 다섯 파일을 합칩니다. 결과는 2~3.5 MB 정도이고 자격증은 여전히 또렷하게 읽히며, 자기소개서와 이력서는 PDF 압축 도구를 거치지 않았으니 선명하고 검색 가능한 텍스트 그대로입니다.

순서도 중요합니다. 자기소개서를 맨 앞에, 이력서를 두 번째에, 자격증은 공고에서 요구한 순서대로 놓으세요. 휴대폰으로 서류를 보는 담당자가 스캔 이미지 세 장을 넘기지 않고도 자기소개서를 바로 보게 됩니다.

문제 해결

PDF 병합 버튼이 회색으로 비활성화되어 있어요
이 도구는 파일이 두 개 이상 있어야 합니다. PDF를 하나 더 추가하세요. 파일 하나 안에서 페이지 순서만 바꾸고 싶다면 페이지 정리 도구를 쓰세요.
파일 하나가 불러와지지 않아요
비밀번호가 걸려 있거나 손상된 파일일 가능성이 큽니다. PDF 뷰어로 열어 보세요. 비밀번호를 물으면 먼저 보호를 해제하고, 아예 열리지 않으면 PDF 복구 도구를 거친 사본으로 병합하세요.
병합된 PDF가 원본을 합친 것보다 커요
약간 커지는 건 정상입니다. 글꼴이나 색상 프로필 같은 공유 리소스가 중복 제거되지 않고 원본마다 한 번씩 복사되기 때문입니다. 예상보다 훨씬 크다면 원본 중 하나에 해상도가 매우 높은 이미지가 들어 있을 테니, 그 파일을 먼저 압축하세요.
페이지 순서가 틀렸어요
파일 목록의 행 순서가 곧 결과 순서입니다. 행을 제자리로 끌어 놓고 다시 병합하세요. 다운로드 파일은 PDF 병합 버튼을 누른 순간의 순서만 반영합니다.
책갈피나 양식 필드가 사라졌어요
정상입니다. 병합은 페이지만 복사하고 문서 단위의 개요나 양식 구조는 복사하지 않습니다. 책갈피는 나중에 책갈피 만들기 도구로 넣고, 양식을 읽기만 하면 된다면 병합 전에 평면화하세요.
큰 작업 중에 탭이 멈췄어요
모든 원본을 RAM에 올려 두는 동안 기기 메모리가 부족해진 것입니다. 다른 탭을 닫거나, 데스크톱 컴퓨터에서 하거나, 두 번에 나눠 합치세요(앞쪽 절반을 먼저 합친 뒤, 그 결과에 나머지를 합칩니다).

자주 묻는 질문

병합하면 PDF 품질이 떨어지나요?

아니요. 페이지는 다시 렌더링되지 않고 복사됩니다. 텍스트는 텍스트로, 이미지는 원래 해상도로 남고, 병합된 문서는 원본과 똑같이 인쇄됩니다.

합칠 수 있는 파일 수나 페이지 수에 제한이 있나요?

도구 자체에는 제한이 없습니다. 실제 한계는 기기 메모리입니다. 일반 페이지 수백 장은 문제없지만, 아주 큰 스캔 파일이 많다면 두 번에 나눠 합쳐야 할 수 있습니다.

페이지 크기나 방향이 다른 PDF도 합칠 수 있나요?

네. 결과물에서도 각 페이지가 원래 크기와 방향을 유지합니다. 모두 같은 크기로 맞추고 싶다면 병합된 파일을 PDF 크기 조정 도구로 처리하세요.

병합된 파일에 책갈피와 양식 필드가 남나요?

책갈피는 복사되지 않고 양식 필드는 깨질 수 있습니다. 책갈피는 나중에 책갈피 만들기 도구로 넣고, 계속 입력해야 하는 양식이 아니라면 병합 전에 평면화하세요.

비밀번호가 걸린 PDF도 합칠 수 있나요?

보호된 상태로는 안 됩니다. 먼저 PDF 잠금 해제로 비밀번호를 없앤 뒤 잠금 해제한 사본을 병합하세요. PDF 병합 도구는 비밀번호를 묻지도, 저장하지도 않습니다.

기밀 문서를 여기서 합쳐도 안전한가요?

병합은 pdf-lib 라이브러리로 브라우저 안에서만 실행되며 파일은 업로드되지 않습니다. 탭을 닫으면 내 기기 말고는 어디에도 아무것도 남지 않습니다.

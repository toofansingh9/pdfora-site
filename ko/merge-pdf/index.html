PDF 병합

PDF를 원하는 순서로 끌어다 놓고 몇 초 만에 하나의 문서로 병합하세요.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.
1

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

PDF를 합치는 일은 간단해 보이지만 막상 하려면 그렇지 않습니다. 자기소개서가 한 파일에, 이력서가 다른 파일에, 스캔한 자격증 세 장이 따로 있는데 이 모두를 첨부 파일 하나로 보내야 하는 상황 같은 거죠. PDFora의 병합 도구는 PDF 파일을 몇 개든 받아 브라우저에서 바로 깔끔한 문서 하나로 이어 붙입니다. 계정도, 페이지를 가로지르는 워터마크도, 업로드 대기열도 없습니다.

대부분이 놓치는 부분은 이것입니다. 파일이 컴퓨터를 떠나지 않는다는 것이죠. 다른 병합 도구는 문서를 서버로 보내 거기서 처리한 뒤 결과를 메일이나 링크로 돌려줍니다. PDFora는 브라우저의 연산 능력을 이용해 로컬에서 병합합니다. 계약서든 진료 기록이든 급여명세서든 인터넷을 오가지 않으므로, 기밀 자료에 쓰기에 합리적인 선택입니다.

무료이며 페이지 제한도 하루 사용 제한도 없습니다. 파일을 넣고, 원하는 순서로 끌어다 놓고, 합쳐진 PDF를 내려받으면 됩니다. 월말 청구서, 원고의 각 장, 강의 유인물처럼 매주 문서를 합쳐야 한다면 결제 요구 없이 원하는 만큼 다시 오면 됩니다.

온라인에서 PDF 파일 병합하는 방법

  1. getpdfora.com의 PDF 병합 도구를 엽니다. 설치할 것도, 가입 화면도 없습니다.
  2. 업로드 영역을 클릭하거나 PDF 파일을 끌어다 놓습니다. 필요한 만큼 추가할 수 있습니다.
  3. 파일 목록을 확인합니다. 각 PDF가 이름이 표시된 카드로 나타납니다.
  4. 카드를 끌어 순서를 바꿉니다. 위에서 아래로의 순서가 최종 문서에서 페이지가 나타나는 순서입니다.
  5. 병합을 누릅니다. 브라우저가 몇 초 만에 로컬에서 파일을 합칩니다.
  6. 병합된 PDF 하나를 내려받으면 끝입니다.

이 도구가 필요한 경우

  • 자기소개서, 이력서, 추천서를 합쳐 입사 지원 서류를 파일 하나로 보내기
  • 한 달 치 개별 청구서 PDF를 하나의 문서로 묶어 회계 담당자에게 전달하기
  • 페이지마다 별도 PDF로 저장하는 휴대폰 스캔 앱의 결과물 합치기
  • 가격표, 포트폴리오 샘플, 계약서 초안을 모아 고객 제안서 구성하기
  • 따로 내보낸 책이나 논문의 각 장을 검토용 원고 하나로 만들기
  • 항공권, 호텔 예약 확인서, 보험 증서 같은 여행 서류를 공항에서 바로 찾을 수 있는 파일 하나로 묶기

더 좋은 결과를 위한 팁

  • 추가하기 전에 파일명을 숫자로 바꿔 두세요(01-intro.pdf, 02-body.pdf). 의도한 순서가 한눈에 들어옵니다.
  • 병합을 누르기 전에 끌어서 순서를 정하세요. 나중에 순서를 고치려면 작업을 처음부터 다시 해야 합니다.
  • 원본 PDF에 빼고 싶은 페이지가 있다면 먼저 페이지 삭제 도구를 거친 뒤 정리된 버전을 병합하세요.
  • 큰 스캔 파일을 여러 개 병합하면 기기 메모리를 많이 쓰므로, 느리게 느껴지면 안 쓰는 탭을 닫으세요.
  • 병합 결과를 열어 확인할 때까지는 원본 파일을 보관해 두세요.

자주 묻는 질문

기밀 PDF를 온라인에서 병합해도 안전한가요?

PDFora에서는 안전합니다. 병합이 전적으로 브라우저 안에서 이뤄지며 파일이 서버로 업로드되지 않습니다. 계약서, 재무제표, 진료 기록이 처음부터 끝까지 기기에 머뭅니다.

합칠 수 있는 PDF 개수에 제한이 있나요?

정해진 제한은 없습니다. 브라우저가 작업을 처리하므로 실제 성능은 기기에 달려 있지만, 평범한 문서 수십 개를 합치는 정도는 보통의 노트북이나 휴대폰에서 문제없습니다.

병합된 PDF에 워터마크가 들어가나요?

아니요. 결과물은 아무것도 추가되지 않은 깨끗한 PDF입니다. 파일을 몇 개 합치든 얼마나 자주 쓰든 워터마크도, 브랜드 표시도, 체험판 도장도 없습니다.

병합 전에 파일 순서를 바꿀 수 있나요?

네. 파일을 추가한 뒤 원하는 순서로 끌어다 놓으면 됩니다. 최종 PDF는 목록에 표시된 위에서 아래 순서를 따릅니다.

계정을 만들거나 결제해야 하나요?

아니요. 병합 도구는 무료이고 가입 없이 동작합니다. 하루 제한이 없으므로 필요할 때마다 PDF 파일을 합칠 수 있습니다.

파일이 아주 크면 어떻게 되나요?

처리가 로컬에서 이뤄지므로 대용량 병합은 서버 할당량이 아니라 기기의 메모리에 좌우됩니다. 대부분의 파일은 몇 초면 합쳐지지만, 큼직한 스캔 PDF가 잔뜩 쌓여 있으면 오래된 하드웨어에서는 시간이 더 걸릴 수 있습니다.

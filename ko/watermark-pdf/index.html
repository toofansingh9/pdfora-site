워터마크

원하는 텍스트 워터마크를 넣으세요. 대각선 여부, 크기, 투명도까지 취향대로 조절할 수 있습니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

아무것도 설치하지 않고, 문서를 낯선 서버에 맡기지도 않고 PDF에 워터마크를 넣을 수 있습니다. PDFora는 DRAFT, CONFIDENTIAL, 회사명, 고객 참조번호 등 원하는 텍스트를 문서의 모든 페이지에 찍어 줍니다. 전 과정이 로컬 처리 방식으로 브라우저 안에서 실행되므로 파일이 컴퓨터를 벗어나지 않습니다. 표시를 넣으려는 PDF가 바로 밖으로 돌아다니면 곤란한 종류의 문서일 때, 이 점이 중요합니다.

워터마크의 모양은 사용자가 정합니다. 원하는 텍스트를 입력하고, 페이지에 맞게 글자 크기를 조절하고, 투명도를 0.1의 희미한 그림자부터 완전히 불투명한 굵은 도장까지 자유롭게 설정하세요. 45도 대각선 옵션을 켜면 예전 DRAFT 도장처럼 텍스트가 페이지를 가로질러 놓입니다. 표시는 모든 페이지에 일관되게 적용되므로 200페이지 계약서도 두 페이지 메모와 똑같이 몇 초면 끝납니다.

PDFora는 무료이며 가입도 파일 제한도 없습니다. 분명히 말해 둘 만한 점이 있습니다. 많은 워터마크 도구가 결과물에 자기네 브랜딩을 넣습니다. 우리는 절대 그러지 않습니다. 완성된 PDF에 남는 워터마크는 사용자가 직접 정한 것 하나뿐입니다. 하루에 한 번을 쓰든 백 번을 쓰든 세거나 제한하지 않습니다.

온라인에서 PDF에 워터마크 넣는 방법

  1. getpdfora.com에서 워터마크 도구를 열고 PDF를 선택하거나 파일을 페이지 위로 바로 끌어다 놓습니다.
  2. 모든 페이지에 찍을 워터마크 텍스트를 입력합니다. 예를 들어 CONFIDENTIAL, DRAFT 또는 상호명이 좋습니다.
  3. 아래 내용을 묻어 버리지 않으면서 표시가 잘 읽히도록 글자 크기를 정합니다.
  4. 투명도 슬라이더를 0과 1 사이에서 조절합니다. 0.2~0.3 정도면 본문이 읽히면서도 은은한 표시가 됩니다.
  5. 텍스트를 45도로 기울여 페이지를 가로지르게 하려면 대각선 옵션을 체크하고, 가로 방향 도장을 원하면 그대로 두세요.
  6. 적용을 클릭한 뒤 워터마크가 들어간 PDF를 내려받습니다. 모든 작업은 브라우저에서 로컬로 이뤄집니다.

이 도구가 필요한 경우

  • 상대방에게 보내기 전 계약서에 DRAFT를 찍어, 최종본이 아닌 버전에 서명하는 일이 없게 하기.
  • 직속 팀 밖으로 돌리기 전에 내부 보고서에 CONFIDENTIAL 표시하기.
  • 디자인 시안과 제안서에 스튜디오나 회사 이름을 넣어, 슬쩍 다른 곳에서 자기 것처럼 쓰이지 못하게 하기.
  • 전자책의 샘플 챕터나 미리보기 사본에 NOT FOR DISTRIBUTION 표시하기.
  • 청구서나 명세서에 PAID나 COPY를 붙여 원본과 사본이 헷갈리지 않게 하기.
  • 학생 유인물이나 시험지에 과목 코드와 학기를 표시해 지난 버전을 쉽게 가려내기.

더 좋은 결과를 위한 팁

  • 문서를 꼼꼼히 읽어야 한다면 투명도를 0.15~0.3으로 낮게 두세요. 0.6 이상은 사본으로 쓸 수 없게 만들 페이지에 쓰는 편이 좋습니다.
  • 45도 대각선은 한 줄의 텍스트로 페이지를 더 넓게 덮어, 잘라 내기 어렵게 만듭니다.
  • 작은 글씨의 긴 문장보다 큰 글씨의 짧은 텍스트가 잘 읽힙니다. 긴 고지문보다 'DRAFT — v3'가 낫습니다.
  • 원본 하나뿐인 파일 말고 사본에 워터마크를 넣으세요. 도구가 원본을 건드리지는 않지만, 깨끗한 마스터를 남겨 두는 건 어차피 좋은 습관입니다.
  • 법률 문서나 고객 문서라면 워터마크에 수신자 이름을 넣으세요. 유출된 사본이 스스로 출처를 밝혀 줍니다.

자주 묻는 질문

워터마크를 넣을 때 PDF가 업로드되나요?

아니요. 이 도구는 로컬 처리 방식으로 전부 브라우저에서 실행됩니다. 파일을 열고 표시를 찍고 저장하는 일이 모두 사용자 컴퓨터에서 이뤄지며 PDFora 서버로는 아무것도 전송되지 않습니다.

PDFora가 제 파일에 자체 워터마크를 넣나요?

절대 넣지 않습니다. 많은 무료 도구와 달리 우리는 결과물에 브랜딩을 하지 않습니다. 완성된 PDF에 있는 워터마크는 사용자가 직접 입력한 텍스트뿐입니다.

워터마크의 투명도를 조절할 수 있나요?

네. 투명도는 0에서 1까지 조절할 수 있습니다. 0.2 같은 낮은 값은 희미한 배경 표시가 되고, 1은 완전히 불투명한 단단한 텍스트가 됩니다.

워터마크가 모든 페이지에 들어가나요?

네. 입력한 텍스트가 문서의 각 페이지에 자동으로 찍힙니다. 파일이 두 페이지든 수백 페이지든 마찬가지입니다.

워터마크를 대각선으로 넣을 수 있나요?

네. 텍스트를 45도로 회전하는 옵션이 있어 모서리에서 모서리로 뻗는 고전적인 DRAFT 느낌을 낼 수 있습니다. 체크를 해제하면 가로 방향 도장이 됩니다.

파일 크기나 개수에 제한이 있나요?

정해진 상한도 일일 할당량도 없습니다. 가입 없이 무료로 무제한 사용할 수 있습니다. 처리가 로컬에서 이뤄지므로 아주 큰 파일은 기기 메모리만이 유일한 한계입니다.

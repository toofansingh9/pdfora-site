워터마크

반투명한 회색 텍스트 한 줄을 PDF의 모든 페이지에 가로 또는 45도 대각선으로 찍습니다.

🔒 파일은 브라우저 안에서 로컬로 처리되며 절대 업로드되지 않습니다.

업로드

파일을 선택하거나 끌어다 놓으세요.

2

설정

원하는 옵션을 선택하세요 — 모든 작업이 브라우저 안에서 처리됩니다.

3

다운로드

완성된 파일을 즉시 저장하세요. 워터마크가 없습니다.

워터마크는 보안 기능이라기보다 페이지에 붙인 인쇄 스티커에 가깝다고 생각하세요. 파일을 연 사람에게 이것이 초안인지, 검토용 사본인지, 대외비인지 알려 주고, 캡처 화면이나 인쇄물이 어떤 맥락에서 나온 것인지 추적할 수 있게 해 줍니다. 하지만 누군가 복사하거나 편집하거나 워터마크를 지우는 것까지 막지는 못합니다. 이 차이를 미리 알면 실제로는 비밀번호나 가림 처리가 필요한 일에 워터마크를 믿고 맡기는 실수를 피할 수 있습니다.

PDFora의 워터마크 도구는 입력한 텍스트를 기존 내용 위에 그리는 새 레이어로 모든 페이지에 씁니다. 내장 글꼴 Helvetica Bold를 중간 회색으로, 설정한 크기와 불투명도(기본값 50포인트, 0.3)로 각 페이지 가운데 부근에 배치합니다. '대각선'을 체크하면 45도로 기울어지고, 해제하면 가로로 찍힙니다. 원래 페이지 내용은 이미지로 렌더링되거나 바뀌지 않으므로 아래 텍스트는 계속 선택할 수 있고, 파일 크기도 몇 KB만 늘어납니다.

문서가 브라우저 메모리에 있는 동안 pdf-lib 라이브러리로 워터마크를 넣기 때문에, 계약서 초안이나 공개 전 보고서를 누구에게도 먼저 보내지 않고 표시할 수 있습니다. 결과는 yourfile-watermarked.pdf로 다운로드되고 원본은 그대로 남습니다.

PDF에 텍스트 워터마크를 넣는 방법

  1. 워터마크 도구를 열고 PDF 하나를 선택합니다. 한 번에 파일 하나씩 처리합니다.
  2. 워터마크 텍스트를 입력합니다. DRAFT, COPY, SAMPLE처럼 짧은 단어가 가장 잘 보입니다. 긴 문장은 아주 작아지거나 페이지 밖으로 나갑니다.
  3. 글꼴 크기와 불투명도를 정합니다. 아래 내용이 읽혀야 한다면 불투명도는 0.15~0.35 정도로 두세요.
  4. 전형적인 45도 도장을 원하면 '대각선'을 체크한 채로 두고, 가운데를 가로지르는 가로줄을 원하면 해제합니다.
  5. 워터마크 추가를 누르고 yourfile-watermarked.pdf를 다운로드한 뒤, 1페이지만이 아니라 내용이 가장 빽빽한 페이지도 확인합니다.

이 도구가 필요한 경우

  • 의견을 받으려고 보내는 계약서 초안에 DRAFT를 찍어 아무도 잘못된 버전에 서명하거나 보관하지 않게 할 때.
  • 시험 전에 다른 선생님과 공유하는 시험지나 정답지에 NOT FOR STUDENTS를 표시할 때.
  • 아직 대금을 받지 않은 고객에게 보내는 디자인 시안이나 포트폴리오 샘플에 SAMPLE이나 PROOF를 찍을 때.
  • 집주인이나 부동산에 건네는 신분증·공과금 고지서 사본에 FOR LEASE APPLICATION 2026처럼 용도와 날짜를 표시할 때.
  • 이사회나 위원회에 돌리는 내부 보고서에 CONFIDENTIAL을 찍어 취급 방법을 상기시킬 때.
  • 보관함에 남겨 둔 예전 규정이나 가격표에 SUPERSEDED를 찍어 옛 사본을 현행 버전으로 착각하지 않게 할 때.

시작하기 전에 알아둘 점

  • 워터마크는 별도 그리기 레이어에 들어간 일반 PDF 텍스트입니다. PDF 편집기만 있으면 누구나 선택해서 지울 수 있고, 보통 복사·붙여넣기나 검색 결과에도 나타납니다. 복사를 제대로 막으려면 비밀번호를 걸거나, 문서를 이미지로 평면화하거나, 둘 다 하세요.
  • 텍스트 워터마크만 지원합니다. 이미지나 로고 옵션, 페이지 전체 반복 배치, 색상 선택은 없고, 도장은 항상 중간 회색 Helvetica Bold입니다.
  • 내장 Helvetica 글꼴은 기본 서양 문자만 지원합니다. 한글, 한자, 일본어, 아랍어, 키릴 문자나 특수 기호가 든 텍스트는 인코딩할 수 없어 도구가 오류를 내고 멈춥니다. 영문자, 숫자, 일반 문장 부호만 쓰세요.
  • 위치는 각 페이지의 전체 크기를 기준으로 계산합니다. 자르기 상자가 특이하거나 회전된 상태로 저장된 페이지(뷰어에서 돌린 스캔본에 흔함)에서는 도장이 가운데에서 벗어나거나 옆으로 찍힐 수 있습니다.
  • 대각선 모드에서는 텍스트가 시작점을 기준으로 회전하는데, 시작점은 페이지 가운데보다 왼쪽에 놓입니다. 그래서 줄이 정확히 가운데에 오지 않고 가운데에서 오른쪽 위로 올라가며, 작은 페이지에 큰 글꼴을 쓰면 끝이 잘릴 수 있습니다.
  • 도장은 모든 것 위에 그려집니다. 어두운 사진이나 차트가 있는 페이지에서는 회색 워터마크가 묻힐 수 있고, 밝은 페이지에서는 불투명도가 높으면 내용을 읽기 어려워집니다.

더 좋은 결과를 위한 팁

  • 전면 사진이나 빽빽한 표처럼 극단적인 페이지가 있는 사본으로 먼저 시험해 본 뒤 불투명도를 정하세요.
  • 페이지에 맞는 크기를 쓰세요. 대략 7글자 단어를 50포인트로 쓰면 약 7.5cm 정도라 A4나 Letter에 적당합니다. A5나 영수증 크기 페이지라면 절반으로 줄이세요.
  • 워터마크가 편집 후에도 남아야 한다면 워터마크를 넣은 파일을 평면화하세요(PDF를 JPG로 바꾼 뒤 JPG / PNG를 PDF로 도구로 다시 PDF로). 도장이 페이지 그림의 일부가 되는 대신 텍스트 선택은 할 수 없게 됩니다.
  • SHARED WITH J. KIM 22/10처럼 날짜나 받는 사람 이름을 넣으면, 유출된 사본이 누구에게 갔던 것인지 알 수 있습니다.
  • 워터마크는 마지막에 넣으세요. 병합, 순서 변경, 압축이 남아 있다면 먼저 하세요. 워터마크 뒤에 압축하는 건 괜찮지만, 도장이 가로지른 상태에서는 페이지 내용을 나중에 편집하기가 더 어렵습니다.

예시: 집주인의 임대차 계약 서류

집주인이 계약일 전에 예비 세입자에게 9페이지짜리 임대차 계약서를 검토용으로 보냅니다. 가장 피하고 싶은 일은 세입자가 검토용 사본을 출력해 서명한 뒤 이전 문구가 적용된다고 주장하는 상황입니다. 그래서 REVIEW COPY - NOT FOR SIGNATURE라는 텍스트를 36포인트, 불투명도 0.2, 대각선으로 넣습니다. 한글은 내장 글꼴이 지원하지 않아 영문으로 적었습니다.

1페이지에서는 줄이 잘 맞습니다. 그런데 휴대폰 앱으로 스캔한 가로 평면도인 7페이지에서는 스캔이 회전된 상태로 저장되어 있어 도장이 한쪽으로 치우칩니다. 집주인은 이 스캔을 PDF 회전에 다시 넣어 페이지가 똑바로 저장되게 한 뒤 다시 합치고, 워터마크를 한 번 더 넣습니다. 이번에는 모든 페이지에서 같은 자리에 찍힙니다.

도장은 텍스트 레이어일 뿐이므로, 집주인은 워터마크 없는 원본을 따로 보관하고 서명용 계약서는 직접 만나서만 건넵니다. 워터마크는 보안 수단인 척하지 않고, 이 종이가 어떤 상태인지 한눈에 알게 해 주는 제 역할을 합니다.

문제 해결

워터마크 추가를 누르자마자 오류가 나요
텍스트에 내장 글꼴이 인코딩할 수 없는 문자, 예를 들어 한글 같은 비라틴 문자, 이모지, 특수 기호가 들어 있을 가능성이 높습니다. 일반 영문자와 숫자로 다시 쓰세요.
워터마크가 페이지 밖으로 나가요
페이지에 비해 글꼴이 너무 크거나 텍스트가 너무 깁니다. 크기를 줄이거나, 텍스트를 줄이거나, '대각선'을 해제하세요. 가로줄은 페이지 폭 전체를 씁니다.
일부 페이지에서 워터마크가 옆으로 눕거나 구석에 찍혀요
그 페이지들은 회전값이나 자르기 상자를 가진 채 저장되어 있습니다. PDF 회전으로 방향을 바로잡거나 PDF 자르기·PDF 크기 조정으로 페이지를 정리한 뒤, 고친 파일에 다시 워터마크를 넣으세요.
사진 페이지에서 워터마크가 안 보여요
낮은 불투명도의 중간 회색은 어둡거나 복잡한 이미지에 묻힙니다. 그 문서는 불투명도를 0.45 정도로 올리거나, 먼저 파일을 나눠 텍스트 페이지에만 워터마크를 넣으세요.
누군가 워터마크를 지웠어요
텍스트 워터마크라면 누구나 지울 수 있습니다. 파일이 재사용되면 안 된다면 도장을 찍은 뒤 이미지로 평면화하거나, 파일을 만든 앱에서 비밀번호를 걸거나, 저해상도 버전만 공유하세요.
결과물이 깨지거나 비어 보여요
원본이 암호화되어 있었을 가능성이 큽니다. 이 도구는 일부 암호화 파일을 열 수는 있지만 제대로 다시 암호화하지는 못하므로, 파일을 만든 앱에서 보호를 해제하고 보호 없는 사본에 워터마크를 넣으세요.

자주 묻는 질문

이미지나 로고를 워터마크로 넣을 수 있나요?

이 도구로는 안 됩니다. 텍스트만 그립니다. 로고를 넣으려면 개별 페이지에 이미지를 추가할 수 있는 PDF 편집을 사용하세요.

워터마크를 넣으면 PDF가 안전해지나요?

아닙니다. 일반 텍스트로 그린 눈에 보이는 표시일 뿐이라 PDF 편집기에서 선택해 지울 수 있습니다. 내용이 재사용되면 안 된다면 평면화나 비밀번호와 함께 쓰세요.

워터마크를 넣은 뒤에도 텍스트 검색이 되나요?

네. 원래 페이지 내용은 건드리지 않고 이미지로 렌더링하지도 않으므로 텍스트를 계속 선택하고 검색할 수 있습니다. 워터마크 텍스트도 검색 결과에 나올 수 있습니다.

일부 페이지에만 워터마크를 넣을 수 있나요?

도구는 모든 페이지에 찍습니다. 표시할 페이지만 분할해서 워터마크를 넣은 뒤, 올바른 순서로 다시 병합하세요.

대각선 워터마크가 왜 가운데에서 살짝 벗어나 보이나요?

텍스트가 가운데가 아니라 시작점을 기준으로 회전해서, 가운데 근처에서 오른쪽 위로 올라가기 때문입니다. 텍스트를 줄이거나 크기를 작게 하면 페이지 안에 잘 들어옵니다.

비용이 들거나 계정이 필요한가요?

아니요. 무료이고 가입이 필요 없으며, 파일에 자체 로고나 표시를 추가하지도 않습니다.

Edit Metadata

Every PDF carries a small record of facts about itself, separate from the pages: a title, an author, a subject, keywords, the program that produced it and the dates it was created and modified. Most people never look at it, but other software does. Browser tabs and many PDF viewers show the stored title instead of the file name, document management systems index the author and keywords, and a file exported from a template can quietly announce 'Microsoft Word - Document1' or the name of whoever built the template years ago.

This tool lets you type a new Title, Author, Subject and comma-separated Keywords and save them into the document's information dictionary. Only the fields you fill in are changed; empty fields leave the existing value in place. The modification date is set to the moment you save. The pages themselves are not touched, so text, images, links and form fields are exactly as they were. The result downloads as yourfile-meta.pdf.

The edit is done with the pdf-lib library in your browser. One side effect of that library is worth knowing: it also records itself as the Producer and Creator and refreshes the creation date when it saves. If the original creation date or software name matters, for example as evidence, keep the original file.

How to edit PDF metadata

  1. Open Edit Metadata and choose one PDF.
  2. Type a Title. Use the document's real title, such as 'Annual Report 2025', not the file name.
  3. Fill in Author and Subject if they are useful to your readers or to a document system; leave them empty to keep what is already there.
  4. Enter keywords separated by commas, for example 'annual report, finance, 2025'. Spaces around the commas are trimmed.
  5. Click Save metadata, download the file and check it in your viewer's Document Properties (often Ctrl+D or Cmd+D).

When to use this tool

  • Fixing a report whose title shows up as 'Untitled' or 'Document1' in a browser tab or search result.
  • Replacing a former employee's or template designer's name in the Author field before a document goes out.
  • Giving a set of school policies consistent titles and keywords before they are uploaded to the school website.
  • Tagging grant reports with project codes so an NGO's document library can find them by keyword.
  • Setting a proper title on an ebook or guide so readers' apps list it by name rather than by file name.
  • Preparing documents for an archive or records system that requires Title and Author to be filled in.

What to know before you start

  • Blank fields are ignored, not cleared. You cannot use this tool to empty a field; it can only replace a value with another non-empty value. Typing a single space is not a reliable workaround.
  • Only the classic information dictionary is updated. Many PDFs also carry an XMP metadata block. Viewers that read XMP first, including some document management systems, may still show the old title or author until the XMP is rewritten by a full editor.
  • Producer and Creator are set to the pdf-lib library, and the creation and modification dates are refreshed, whatever they were before. This is a property of the library, not an option.
  • Metadata is not the same as hidden content. Comments, earlier revisions, form data, layers and embedded files are not removed by this tool. Use Remove Annotations or Flatten for those, and check the result before sharing sensitive files.
  • Keywords are saved as a list. Search engines largely ignore the keywords field; it is mostly useful for internal libraries and desktop search. A handful of precise terms is more useful than a long list.
  • Encrypted files are opened without decrypting them, which can produce a damaged output. Remove the protection in the program that created the file before editing metadata.

Tips for the best results

  • Write the title the way a person would say it. 'Tenant Handbook 2026' is better than 'tenant_handbook_FINAL_v3'.
  • Use the organisation as Author for public documents, rather than an individual's name, so the file does not go out of date when people change roles.
  • Edit metadata as the last step. Later tools in a chain may rewrite fields such as Producer and the dates again.
  • Keep a copy of the original if the creation date or authoring software could ever matter, for example in a dispute.
  • After saving, also rename the file sensibly; viewers differ on whether they show the title or the file name.

Example: a school's policy documents

A school office is uploading 14 policy PDFs to its new website. When parents open them, the browser tab says things like 'Microsoft Word - Template_2019' and the Author field still shows the name of a teacher who left years ago.

The office manager runs each file through Edit Metadata, setting the Title to the policy's name ('Anti-Bullying Policy, reviewed September 2026'), the Author to the school's name, the Subject to 'School policy' and keywords such as 'policy, safeguarding, parents'. Each file takes under a minute, and the pages are unchanged.

Checking the results, she notices that one PDF still shows the old title in a particular viewer. That file contains an XMP metadata block the tool does not rewrite. She re-exports it from the original word processor with the correct document title set there, and the problem disappears.

For the remaining files she also renames each download to match its new title, for example anti-bullying-policy-2026.pdf, so the name and the stored title agree whichever one a parent's browser chooses to display.

Troubleshooting

The old title still shows in my viewer
The viewer is probably reading the XMP metadata block, which this tool does not update. Re-export from the source program with the correct title, or use a full PDF editor to update XMP.
I left a field empty but the old value is still there
That is how the tool works: empty fields are skipped. To change a value, type a new one.
The creation date changed
The pdf-lib library refreshes the creation and modification dates when it saves. Keep the original file if the original dates matter.
Producer now says pdf-lib
The library writes its own name to Producer and Creator. This does not affect how the document looks or prints.
The browser tab still shows the file name
Some browsers and viewers only show the stored title when the PDF asks them to, and others always show the file name. Rename the file as well.
The output will not open
The source was probably encrypted. Remove the password in the program that created it, then edit the unprotected copy.

Frequently asked questions

What is PDF metadata?

A small set of fields stored in the file, such as Title, Author, Subject, Keywords, Producer and dates. It describes the document but is not shown on the pages.

Can I remove all metadata from a PDF?

Not with this tool. It can replace Title, Author, Subject and Keywords with new values but cannot clear them or remove the XMP block.

Does editing metadata change the content of the pages?

No. Text, images, links and forms are left exactly as they were. Only the information fields and dates change.

Does PDF metadata help with Google rankings?

Search engines may use the stored Title when listing a PDF, so a clear title helps people recognise the file. The keywords field has little or no effect on web search.

Can I see the current metadata before changing it?

Your PDF viewer's Document Properties window shows it. This tool does not display the existing values. In most desktop viewers it is under File, then Properties, on the Description tab, which lists title, author, subject, keywords, producer and both dates.

Can I edit metadata on several files at once?

No. Process each file in turn; it only takes a few seconds per file.

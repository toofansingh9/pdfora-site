A stray blank page from a duplex scanner, a cover sheet nobody needs, the one page of a contract that shows a client's bank details: unwanted pages are rarely the whole problem, but they make a document look careless or, worse, share something that was never meant to leave the office. Delete Pages exists for that narrow job. You type which pages should go, and you get a new PDF with everything else in its original order.

The tool does not edit your file in place. It opens the PDF with pdf-lib, works out the list of pages you did not mention, and copies only those into a new document named yourfile-edited.pdf. The kept pages are copied, not redrawn, so their text, fonts and image quality are exactly what they were. The deleted pages are simply never written to the new file, and the images and fonts that only they used are not carried across either, which is why removing a few scanned pages often makes a file noticeably smaller.

That design has one practical consequence worth knowing up front: deletion here is real removal from the output file, not a hidden or covered page. Someone opening the new PDF cannot recover a deleted page from it. Your original, however, is untouched on your disk, so keep or discard it deliberately.

How to delete pages from a PDF

  1. Open the Delete Pages tool and select the PDF you want to clean up.
  2. In your viewer's thumbnail panel, note the physical position of every page you want gone. Ignore the numbers printed on the pages themselves.
  3. Type them into Pages to remove, separated by commas, with ranges where it helps: 2, 5-7, 30-.
  4. Click Delete pages. The remaining pages are copied, in their original order, into a new document.
  5. Download yourfile-edited.pdf and confirm the page count equals the original count minus the pages you removed.

When to use this tool

  • Stripping the blank backs that a duplex scanner adds when one-sided originals are scanned on both sides.
  • Removing a fax cover sheet or email-to-PDF header page before filing a document in a case management system.
  • Taking out a page containing account numbers or a medical note before sharing the rest of a file with a third party.
  • Dropping the instructions pages from a government form pack so only the completed form goes to the office.
  • Cutting an outdated price list or appendix out of a proposal you are sending again to a different client.
  • Trimming a long exported web page or chat log to the pages that actually contain the relevant part.

What to know before you start

  • An empty box does not mean "delete nothing". Blank input is read as every page, so the tool refuses with "That would remove every page." You always need to type at least one number.
  • You cannot delete every page; at least one page must remain. If you want an empty starting document, the Create PDF tools are the better route.
  • Numbers beyond the last page are ignored without a warning, and a reversed range such as 9-4 matches nothing. If your output still has a page you meant to delete, check for these two slips first.
  • The order of the pages that remain is never changed by this tool, regardless of the order you type. To change the order as well, use Organize Pages, which lets you delete, rotate and drag pages in one pass.
  • Bookmarks are not kept in the new file, and in-document links pointing to a deleted page (or a page that has moved) stop working. Website links are unaffected.
  • Deleting a page does not remove text that also appears elsewhere. If a confidential figure is repeated in a summary table on page 2, removing the detailed page 14 leaves it showing on page 2; remove it in the source document and export a new PDF.

Tips for the best results

  • When removing many scattered blank pages, open the file in a viewer with large thumbnails and write the list as you scroll; small blank pages are easy to miss at a glance.
  • Use 25- to delete everything from page 25 to the end, for example to cut off an appendix of unknown length.
  • If you would be typing most of the page numbers, flip the approach and use Extract Pages to list the few you want to keep.
  • For sensitive documents, delete the page here, then open the result and use your viewer's search to confirm the confidential names or numbers do not appear on any remaining page.
  • After cleaning a scanned file, consider Compress PDF; deleting pages removes their images, but the remaining scan pages may still be larger than necessary.

A worked example: an NGO sharing a grant report

A small NGO needs to send its 32-page grant report to a second funder. The report includes three things that second funder should not see: page 4 lists the first funder's contract reference and contact, pages 17 and 18 contain the names and ages of individual beneficiaries, and pages 29 to 32 are the first funder's own feedback form. The scanner also left a blank page at position 23.

Typing 4, 17-18, 23, 29- into the box removes all eight pages in one go. The download has 24 pages, and the page count is the first check: 32 minus 8 equals 24. The second check matters more. The beneficiary numbers also appear in a summary chart on page 9, but without names, so it can stay; a search for one beneficiary's surname in the new file returns nothing, which confirms the identifying pages are really gone.

Because the report was originally laid out with "Page x of 32" in the footer, the printed numbers now jump. A one-line note in the covering email explains this is an excerpt, which is cleaner than leaving the recipient to wonder what is missing.

Troubleshooting

I get "That would remove every page."
Either the box is empty, which the tool reads as all pages, or your list covers every page. Type only the pages you want removed and leave at least one page in the document.
A page I listed is still in the output
Check that you used physical page positions, not printed numbers, and that every range is written low-to-high. A range like 12-10 is ignored entirely.
The wrong page was deleted
Your original file is unchanged, so start again from it rather than from the edited copy. Counting from the thumbnail sidebar avoids the most common off-by-one mistakes caused by cover pages.
The new file is about the same size as before
The deleted pages were light, typically text-only, so removing them saves little. File size is driven by images; use Compress PDF if size is the actual goal.
The output pages are blank or unreadable
This usually means the source PDF is encrypted. Remove the password or restrictions in the program that created it, save an unprotected copy, and delete pages from that.
Clickable contents entries now go to the wrong place
Internal links refer to pages by position, which shifts after a deletion. Remove or regenerate the contents page, or add fresh bookmarks with the Add Bookmarks tool.

Frequently asked questions

Can someone recover the pages I deleted?

Not from the new file. Deleted pages are never copied into it. They do still exist in your original, so manage that file separately.

Does deleting pages reduce quality on the remaining pages?

No. Remaining pages are copied object for object; text stays text and images are not recompressed.

Can I delete pages from several PDFs at once?

No, the tool takes one file per run. For several files, run it on each, or merge them first and delete from the merged result.

Why does the empty box not mean "delete nothing"?

The page box uses the same reader as the other page tools, where blank means all pages. For deletion that would empty the document, so the tool stops with an error instead.

Is deleting a page the same as redacting it?

No. Deleting removes whole pages. Removing only some words from a page you keep is redaction, which this tool does not do; edit the original document and re-export it, because drawing a box over text in a PDF can leave the text underneath.

Do I need an account to delete pages?

No. The tool is free and works without sign-up; the edited file is generated in your browser.

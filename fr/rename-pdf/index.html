Renommer un PDF

Donnez à un PDF un nom de fichier propre et cohérent, et téléchargez-le sous forme de nouvelle copie.

🔒 Vos fichiers sont traités localement dans votre navigateur et ne sont jamais téléversés.

Importer

Sélectionnez votre fichier ou glissez-déposez-le.

Télécharger

Enregistrez instantanément le fichier terminé. Sans filigrane.

Le nom d'un fichier compte plus qu'on ne le croit. « scan_20261003_0007.pdf » ou « Document (3) final FINAL.pdf » n'apprend rien au destinataire, se perd dans le dossier Téléchargements et se fait parfois refuser par des plateformes de dépôt qui n'aiment ni les espaces, ni les parenthèses, ni les noms trop longs. Renommer sur un ordinateur est trivial, mais sur un téléphone, sur un poste de travail verrouillé ou dans un flux qui se passe entièrement dans le navigateur, c'est souvent étonnamment laborieux.

Cet outil fait une seule chose : vous tapez un nouveau nom et il vous rend le PDF sous ce nom. Les caractères que Windows, macOS et la plupart des plateformes refusent dans un nom de fichier (barre oblique inverse, barre oblique, deux-points, astérisque, point d'interrogation, guillemets, chevrons et barre verticale) sont supprimés automatiquement, et .pdf est ajouté si vous l'omettez. Si le champ reste vide, le nom d'origine est conservé ; si rien ne reste après nettoyage, le fichier s'appelle document.pdf. Les espaces en début et en fin sont également retirés : un nom copié depuis un e-mail avec une espace parasite à la fin ne donnera pas un fichier « facture .pdf ».

Un détail mérite d'être connu. L'outil ne se contente pas de changer l'étiquette du téléchargement : il ouvre le PDF avec pdf-lib et l'enregistre de nouveau. Les pages et leur contenu sont identiques, mais le fichier est réécrit : sa taille peut varier légèrement et ses métadonnées internes sont mises à jour, pdf-lib renseignant la date de modification et s'inscrivant comme producteur. Le titre du document affiché dans la barre de titre de la visionneuse, qui est un champ distinct à l'intérieur du PDF, n'est pas modifié par le renommage.

Renommer un fichier PDF

  1. Ouvrez Renommer un PDF et ajoutez le PDF à renommer.
  2. Tapez le nouveau nom dans le champ Nouveau nom de fichier, par exemple 2026-10-facture-0142. L'extension .pdf est facultative.
  3. Cliquez sur Renommer et télécharger. Le fichier est chargé puis enregistré sous le nouveau nom.
  4. Enregistrez le téléchargement à l'endroit voulu ; selon le navigateur, un emplacement vous sera demandé ou le fichier ira dans Téléchargements.
  5. Vérifiez le nom dans votre gestionnaire de fichiers et supprimez l'ancienne copie si vous n'en avez plus besoin.

Quand utiliser cet outil

  • Freelances qui envoient leurs factures selon un modèle fixe, du type client-année-mois-numéro, pour que chacun les retrouve facilement. Un nom prévisible permet aussi au service comptable du client de rapprocher le fichier de son bon de commande sans l'ouvrir.
  • Étudiants qui déposent un devoir sur une plateforme exigeant un format précis, comme nom-numéroétudiant-devoir.
  • Propriétaires bailleurs qui classent baux et états des lieux par adresse du logement et par date, plutôt que sous le nom généré par le scanner.
  • Renommer des fichiers sur un téléphone ou une tablette dont le gestionnaire de fichiers rend l'opération pénible.
  • Retirer deux-points, barres obliques ou guillemets qui empêchent l'envoi d'un fichier ou sa synchronisation avec un autre système.
  • Donner un nom parlant à un relevé ou à un billet électronique téléchargé avant de le transférer.

À savoir avant de commencer

  • Les caractères interdits \ / : * ? " < > | sont supprimés, pas remplacés : un nom comme Rapport: T3 devient Rapport T3. Les espaces sont conservées ; remplacez-les vous-même par des tirets si une plateforme les refuse.
  • L'extension .pdf est ajoutée automatiquement si elle manque. Un nom qui se termine déjà par .pdf (majuscules ou minuscules) est laissé tel quel.
  • Le PDF est réenregistré par pdf-lib, qui met à jour la date de modification et le champ producteur des métadonnées. Le titre, l'auteur et le contenu des pages restent inchangés.
  • Ne renommez pas avec cet outil un PDF signé électroniquement. Le réenregistrement réécrit le fichier, ce qui invalide la signature même si le contenu visible est identique. Renommez plutôt les fichiers signés dans votre gestionnaire de fichiers.
  • Les PDF protégés par mot de passe ne conviennent pas non plus. L'outil peut les charger, mais la copie enregistrée risque fort de ne pas s'ouvrir correctement. Renommez-les dans votre gestionnaire de fichiers.
  • Un fichier par opération. Pour un lot, répétez les étapes pour chaque fichier ou utilisez la fonction de renommage par lot de votre système. Si vous renommez deux fois le même fichier, chaque opération produit un nouveau téléchargement ; l'outil ne modifie jamais le fichier sur votre disque. L'original reste à sa place, sous son ancien nom, jusqu'à ce que vous le supprimiez.

Conseils pour de meilleurs résultats

  • Commencez les noms par une date au format année-mois-jour (2026-10-22) : les fichiers se trient alors chronologiquement dans n'importe quel dossier.
  • Utilisez des tirets plutôt que des espaces ; ils passent sans encombre dans les messageries, les URL et les outils en ligne de commande, sans se transformer en %20.
  • Restez sous une soixantaine de caractères. Certaines plateformes et certains systèmes anciens tronquent les noms plus longs.
  • Placez le mot le plus important en premier : le client, puis le type de document, puis le numéro. C'est ce que l'œil parcourt dans une liste.
  • Si le titre visible dans les visionneuses PDF doit aussi changer, modifiez les propriétés du document dans l'application qui l'a créé ; le renommage n'y touche pas. Les plateformes de dépôt ont parfois leurs propres règles, comme tout en minuscules ou pas d'espaces. L'outil ne les applique pas : tapez le nom dans le format demandé.

Exemple concret : une propriétaire qui range ses documents de location

Une propriétaire de trois appartements à Bordeaux scanne ses états des lieux avec une application de téléphone, qui produit des noms comme Scan 14 oct. 2026 10:42.pdf. L'envoi sur l'espace en ligne de son agence immobilière échoue, car la plateforme refuse les deux-points dans les noms de fichiers, et le dossier de son ordinateur n'est qu'une liste de dates presque identiques.

Elle renomme chaque état des lieux depuis son téléphone selon le modèle appart-b-etat-des-lieux-2026-10-14. L'outil retire les deux-points éventuels si elle recopie une partie de l'ancien nom, ajoute .pdf, et la plateforme accepte l'envoi. Dans le dossier, les fichiers se trient désormais par appartement puis par date.

Pour les baux signés, elle procède autrement. Ils portent une signature électronique, que le réenregistrement invaliderait : elle les renomme donc dans le gestionnaire de fichiers du téléphone. L'outil de renommage convient aux PDF ordinaires ; tout fichier signé ou protégé par mot de passe se renomme au niveau du système de fichiers.

Résolution des problèmes

Le fichier téléchargé porte encore l'ancien nom
Le navigateur a peut-être ajouté un numéro parce qu'un fichier du même nom existe déjà, ou il est réglé pour renommer les doublons. Vérifiez le dossier Téléchargements et supprimez les anciennes copies.
Des caractères ont disparu de mon nouveau nom
Les caractères interdits dans les noms de fichiers sur les systèmes courants (\ / : * ? " < > |) sont supprimés automatiquement. Mettez un tiret ou un tiret bas à leur place.
La taille du fichier a légèrement changé
Le PDF est réenregistré par pdf-lib, qui peut stocker les objets différemment. Les pages sont les mêmes ; seule la structure interne est réécrite.
La signature électronique de mon PDF apparaît comme non valide
Le réenregistrement a modifié les octets couverts par la signature. Reprenez le fichier signé d'origine et renommez-le dans votre gestionnaire de fichiers.
Le fichier renommé ne s'ouvre pas
La source était probablement chiffrée ou endommagée. Renommez l'original dans votre gestionnaire de fichiers, ou réparez-le d'abord avec Réparer un PDF.
Ma visionneuse affiche toujours l'ancien titre en haut
Les visionneuses affichent le titre stocké dans le PDF, pas le nom du fichier. Ce champ n'est pas modifié par le renommage.
Le nouveau nom a été raccourci sur mon téléphone
Certains navigateurs mobiles tronquent les noms de téléchargement très longs. Faites court et placez les éléments d'identification en tête.

Questions fréquentes

Le renommage modifie-t-il le contenu du PDF ?

Non, les pages sont identiques. Le fichier est réenregistré, donc la date de modification et le producteur sont mis à jour dans les métadonnées.

Quels caractères sont interdits ?

La barre oblique inverse, la barre oblique, les deux-points, l'astérisque, le point d'interrogation, les guillemets droits, les chevrons et la barre verticale sont retirés du nom.

Dois-je taper .pdf à la fin ?

Non. L'extension est ajoutée si vous l'oubliez.

Puis-je renommer plusieurs PDF d'un coup ?

Non, un fichier par opération. Pour de gros lots, le renommage par lot de votre système d'exploitation est plus rapide.

Le renommage peut-il casser une signature électronique ?

Oui, car le fichier est réécrit. Renommez les PDF signés dans votre gestionnaire de fichiers.

Est-ce payant ou faut-il un compte ?

Non. Le renommage est gratuit et ne demande aucun compte.

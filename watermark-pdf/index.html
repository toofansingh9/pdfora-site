Think of a watermark as a printed sticker on the page rather than a security feature. It tells whoever opens the file that it is a draft, a copy for review, or confidential material, and it makes a screenshot or printout traceable to its context. What it does not do is stop anyone from copying, editing or removing it. Knowing that difference up front saves you from relying on a watermark for a job that actually needs a password or a redaction.

PDFora's watermark tool writes your text onto every page as a new layer drawn on top of the existing content. It uses the built-in Helvetica Bold font in mid-grey, at the size and opacity you set (50 points and 0.3 by default), positioned around the middle of each page. With the Diagonal box ticked the line is rotated 45 degrees; untick it for a horizontal stamp. The original page content is not rendered to an image or altered, so the text underneath stays selectable and the file size grows by only a few kilobytes.

Because the stamp is added with the pdf-lib library while the document sits in your browser's memory, a draft contract or an unreleased report can be marked without being sent to anyone first. The result downloads as yourfile-watermarked.pdf next to the original, which is left untouched.

How to add a text watermark to a PDF

  1. Open the Watermark tool and select one PDF. The tool works on a single file at a time.
  2. Type the watermark text. Short words such as DRAFT, COPY or SAMPLE read best; long sentences become tiny or run off the page.
  3. Set the font size and opacity. Keep opacity between about 0.15 and 0.35 if the page must stay readable underneath.
  4. Leave Diagonal ticked for the classic 45-degree stamp, or untick it for a horizontal line across the middle.
  5. Click Add watermark, download yourfile-watermarked.pdf and check the busiest page of the document, not just page 1.

When to use this tool

  • Contract drafts sent out for comment, marked DRAFT so nobody signs or files the wrong version.
  • Exam papers or answer keys shared with other teachers before the test date, marked NOT FOR STUDENTS.
  • Design proofs and portfolio samples for a client who has not paid yet, marked SAMPLE or PROOF.
  • Copies of an ID or a utility bill given to a landlord or agency, marked with the purpose and date, for example COPY FOR TENANCY APPLICATION 2026.
  • Internal reports circulated to a board or committee, marked CONFIDENTIAL as a plain reminder of how to handle them.
  • Superseded policies or price lists kept in an archive, marked SUPERSEDED so an old copy is never mistaken for the current one.

What to know before you start

  • The watermark is ordinary PDF text in a separate drawing layer. Anyone with a PDF editor can select and delete it, and it will usually appear in copy-paste and in search results. For real protection against copying, use a password, flatten the document to images, or both.
  • Only text watermarks are supported. There is no image or logo option, no tiling across the page and no choice of colour; the stamp is always mid-grey Helvetica Bold.
  • The built-in Helvetica font only covers basic Western characters. Text in Hindi, Chinese, Arabic, Cyrillic or with unusual symbols cannot be encoded and the tool will stop with an error. Stick to Latin letters, digits and common punctuation.
  • Placement is calculated from each page's full size. On a page with an unusual crop box or a page that is stored rotated (common with scans turned in a viewer), the stamp can sit off-centre or run sideways.
  • In diagonal mode the text is rotated around its starting point, which is placed left of the page centre. The line therefore climbs from the centre towards the upper right rather than being perfectly centred; with a large font on a small page the end can be cut off.
  • The stamp is drawn on top of everything. On pages with dark photos or charts a grey watermark can disappear; on pale pages a high opacity can make the content hard to read.

Tips for the best results

  • Test on a copy with an extreme page first, such as a full-page photo or a dense table, and only then decide on opacity.
  • Use a size that fits: as a rough guide, a 7-letter word at 50 points spans about 3 inches, comfortable on A4 or Letter. Halve the size for A5 or receipt-sized pages.
  • If the watermark must survive editing, flatten the watermarked file (PDF to JPG, then JPG back to PDF with Images to PDF) so the stamp becomes part of the page picture. You lose selectable text by doing this.
  • Put a date or recipient name in the text, for example SHARED WITH J. RAO 22/10, so a leaked copy points back to who received it.
  • Watermark last. If you still need to merge, reorder or compress, do that first; compressing after watermarking is fine, but editing page content later is harder with a stamp across it.

Example: a landlord's tenancy pack

A landlord is sending a 9-page tenancy agreement to a prospective tenant for review before the signing meeting. The last thing they want is the tenant printing and signing the review copy, then claiming the earlier wording applies. They watermark the file with the text REVIEW COPY - NOT FOR SIGNATURE at 36 points, opacity 0.2, diagonal on.

On page 1 the line fits. On page 7, which is a landscape floor plan scanned in a phone app, it sits off to one side because the scan is stored rotated. The landlord re-runs the scan through Rotate PDF so the page is stored upright, merges it back, and watermarks again; this time the stamp lands in the same place on every page.

Because the stamp is just a text layer, the landlord also keeps the unmarked original and only ever sends the signing version in person. The watermark does its job, which is making the status of the paper obvious at a glance, without pretending to be a security measure.

Troubleshooting

I get an error as soon as I click Add watermark
The text almost certainly contains characters the built-in font cannot encode, such as non-Latin script, curly emoji or special symbols. Rewrite it with plain Latin letters and digits.
The watermark runs off the edge of the page
The font size is too large for the page or the text is too long. Lower the size, shorten the text, or untick Diagonal; a horizontal line uses the full page width.
On some pages the watermark is sideways or in a corner
Those pages are stored with a rotation or a crop box. Use Rotate PDF to fix the orientation, or Crop PDF/Resize Pages to normalise the page, then add the watermark again to the corrected file.
The watermark is invisible on photo pages
Mid-grey at low opacity disappears on dark or busy images. Raise the opacity to around 0.45 for that document, or watermark only the text pages by splitting the file first.
Someone removed my watermark
That is possible with any text watermark. If the file must not be reused, flatten it to images after stamping, add a password with Protect PDF, or share only a low-resolution version.
The output looks garbled or blank
The source was probably encrypted. The tool can open some encrypted files but cannot re-encrypt them properly, so remove the protection with Unlock PDF or in the app that made the file, watermark the unprotected copy, then protect the result again with Protect PDF if needed.

Frequently asked questions

Can I add an image or logo as a watermark?

Not with this tool; it only draws text. To place a logo, use Edit PDF, which lets you add images to individual pages.

Does the watermark make the PDF secure?

No. It is a visible label drawn as ordinary text, and it can be selected and deleted in a PDF editor. Combine it with flattening or a password if the content must not be reused.

Will my text still be searchable after watermarking?

Yes. The original page content is not touched or rendered to an image, so its text stays selectable and searchable. The watermark text itself may also show up in searches.

Can I put the watermark only on some pages?

The tool stamps every page. Split off the pages you want marked, watermark them, then merge the parts back together in the right order.

Why does the diagonal watermark look slightly off-centre?

The text is rotated around its starting point rather than its middle, so it rises from near the centre towards the top right. A shorter text or a smaller size keeps it well inside the page.

Does it cost anything or need an account?

No. The tool is free, needs no sign-up, and does not add any branding of its own to the file.

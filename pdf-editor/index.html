Most people who search for a PDF editor do not want to rewrite a document. They want to add a missing date, put a logo on a quote, cross something out, or write a short note in a margin. PDFora's Edit PDF tool is built for exactly that kind of job: it lets you place new things on top of a page. It does not let you change the words that are already printed in the file, and it is worth knowing that before you start rather than after.

When you open a file, every page is drawn on screen by PDF.js at a width of up to 880 pixels. Above each page sits a transparent layer where you work. The toolbar has six modes: Move, Text, Signature, Image, Draw and Whiteout, plus a colour picker and a text-size box (default 18, from 6 to 96). Text boxes, signatures and pictures can be dragged around and deleted with the small × on each one; images and signatures can also be resized from the corner.

On Save PDF, the tool paints everything you added for a page into one transparent PNG the size of that on-screen page, and pdf-lib stamps that PNG over the original page. The original content underneath is not touched: its text stays selectable, its vector drawings stay sharp. The output is downloaded as yourfile-edited.pdf.

How to add text and images to a PDF

  1. Open Edit PDF and drop in a single PDF. Wait until every page has been drawn; long documents take a moment because each page is rendered before you can work on it.
  2. Choose Text, pick a colour and size, then click where the text should start. Type straight into the box. Press Enter for a new line; long lines do not wrap by themselves.
  3. Use Image to place a logo or stamp from your computer, or Draw for freehand ticks, arrows and circles. Drag the corner handle to resize pictures.
  4. Use Whiteout by dragging a rectangle over something you want hidden from view, then place a Text box on top if you are replacing it with a correction.
  5. Click Save PDF, open the downloaded -edited.pdf file and zoom in on each change before you send it anywhere.

When to use this tool

  • Filling in a missing date, reference number or room number on a printed notice before it goes out again.
  • Putting a company logo or a 'PAID' stamp image onto a supplier invoice that arrived as a PDF.
  • Marking up a floor plan or a school worksheet with freehand circles, arrows and short notes.
  • Correcting a typo in a flyer when the original Word or Canva file has been lost: white it out, type the correct word on top.
  • Adding a handwritten-style comment to a scanned page that has no text layer anyway.
  • Placing an initials image in the corner of every page of a short agreement.

What to know before you start

  • Existing text cannot be edited in place. The tool adds a layer; it does not reflow or retype what is already there. To change a paragraph properly you need the source document.
  • Whiteout only hides things visually. The white box is part of the image stamped on top; the original text is still in the file underneath and can be selected, copied or found with search. Never use it to remove confidential information.
  • Everything you add is flattened into an image. Text you type becomes pixels, so it is not searchable, cannot be copied and is not read by screen readers.
  • The added layer is built at screen resolution (at most 880 pixels across the page). On an A4 page that is roughly 100 pixels per inch, so typed text looks fine on screen but can look slightly soft when printed or zoomed in hard.
  • Every page receives a PNG layer on save, including pages you did not change. A blank layer compresses well, but expect the output to be somewhat larger than the original.
  • The on-screen font and the saved font can differ slightly: the save step draws text with Helvetica or Arial at the size you chose. Check line positions in the downloaded file, especially for text you squeezed into a narrow gap.

Tips for the best results

  • Set the colour and size before you click to place text. The values are read when the box is created, so changing them afterwards does not restyle boxes that already exist.
  • For a correction, place the Whiteout rectangle first and the replacement text second, so the text sits visibly on top of the white area.
  • Use a transparent PNG for logos and stamps. A JPG will bring its white rectangular background with it and cover whatever is behind it.
  • Zoom your browser to a comfortable size before opening the file; the page is rendered to fit the width available at that moment.
  • If you need sharper added text for print, keep notes short and use a larger size (14 or more) rather than tiny text, which suffers most from the screen-resolution layer.

Example: a landlord correcting a rent notice

A landlord has a two-page rent increase notice exported months ago from a word processor that is no longer installed. The new rent figure is right, but the effective date reads 1 March when it should be 1 April, and the letter needs the property's logo in the top corner before it is emailed to four tenants.

In Edit PDF she drags a Whiteout rectangle over 'March', switches to Text, sets size 12 in black and clicks just over the white patch to type 'April'. She then chooses Image, clicks the top-right corner of page one and picks the logo PNG, shrinking it with the corner handle. Saved, the file comes back as rent-notice-edited.pdf, and on screen it reads exactly as intended.

What she should not forget: the word 'March' is still in the file under the white box. A tenant searching the PDF for 'March' would find it. For an informal correction that is acceptable; for anything that might end up in a dispute, it is better to rebuild the letter from scratch or at least add a short line explaining the correction.

Troubleshooting

The page appears but nothing happens when I click
Check which mode is selected. In Move mode clicks on empty space do nothing; switch to Text, Image or Draw. Also make sure you are clicking on empty page area, not on an element you already placed.
My typed text is in a different place in the saved file
The text is redrawn at save time with a standard sans-serif font, so the width of each line can shift a few pixels. Leave a little room around text placed in tight boxes and recheck the output.
The whited-out text still shows up when I search the file
That is how the tool works: whiteout is a painted rectangle, not a deletion. To truly remove content, re-create the document from its source or print the edited file to a new PDF and run it through a tool that rasterises the page.
My logo has a white box around it
The image you used is a JPG or a PNG without transparency. Export the logo as a PNG with a transparent background and place it again.
Could not render this PDF
The file is password-protected, damaged, or not really a PDF. Remove the password in the app that created the file, or run it through Repair PDF first, then open the repaired copy.
Saving takes a long time or the tab freezes
Each page is turned into a full-page PNG at save, and a long document means many of them in memory at once. Split off only the pages you need with Extract Pages, edit those, then merge them back.

Frequently asked questions

Can I change the existing words in my PDF?

No. This tool adds new content on top of the page. To change existing text you can cover it with Whiteout and type a replacement over it, but the original words remain in the file underneath.

Will the text I add be searchable?

No. Added text, signatures and drawings are merged into a picture layer when you save, so they cannot be selected or found with search. The document's original text stays searchable.

Does editing lower the quality of my original pages?

No. The original page content is kept as it was and the new layer is placed over it. Only the things you added are at screen resolution.

Can I undo a change before saving?

Text boxes, images and signatures can be removed with the × on each one. Freehand lines and whiteout rectangles are painted directly and cannot be removed individually; reload the file to start over.

Can I edit a scanned document?

Yes. A scan is just an image per page, so adding text, stamps and marks works the same way. You still cannot change the scanned words, only cover and annotate them.

Is Edit PDF free?

Yes, there is no account and no watermark. The whole process, from rendering the pages to building the new file, happens in your browser tab.

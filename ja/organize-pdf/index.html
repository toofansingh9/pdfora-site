ページ整理

全ページをサムネイルで一覧表示し、ドラッグして並べ替え、回転、削除ができます。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

何を変えればよいかがはっきりしているなら、ページ番号の指定で十分です。そうでないときは、文書そのものを見たくなります。PDForaの整理ツールは、PDFの全ページをサムネイルのボードとして並べます。ドラッグでページを並べ替え、横向きにスキャンされたページを回転させ、不要なページに削除の印を付ける、といった作業を1つの画面でまとめて行い、修正済みのファイルを1つ書き出せます。

このボードはすべてブラウザ内で動作します。PDFはローカルで描画・再構築され、アップロードされることはありません。つまり賃貸借契約書、患者ファイル、給与処理の書類のページを、誰かのサーバーに触れさせることなく並べ替えられます。アップロードの待ち時間もないので、分厚いファイルでも端末が描画できる速さで開きます。

これらすべてが無料で、アカウントも不要、書き出したPDFに透かしも入りません。1ページだけの修正でも、50ページの全面的な入れ替えでも、納得のいく文書になるまで何度でもやり直せます。

オンラインでPDFのページを並べ替え・整理する方法

  1. getpdfora.com のPDF整理ツールを開き、ファイルを読み込みます。
  2. 全ページがサムネイルとしてボードに並ぶまで、少し待ちます。
  3. サムネイルをドラッグして別の位置に移動し、ページを並べ替えます。レイアウトはその場で更新されます。
  4. 横向きや上下逆のページは、正しい向きになるまで回転ボタンをクリックします。
  5. 不要なページに削除の印を付けます。ボード上で印が表示されるので、確定する前に考え直せます。
  6. 「書き出し」をクリックし、新しいページ順、回転、削除が反映されたPDFをダウンロードします。

When to use this tool

  • 用紙の束が逆順やばらばらの順序でフィーダーを通ってしまったスキャンを修正する。
  • 縦向きのレポートの中にある2枚の横向きの図表だけを、他のページに触れずに正しい向きにする。
  • 提出要領の指定に合わせて、付録を参考文献の前に移動する。
  • 複数のスライド資料を結合した結果、セクションが入り混じってしまった配布資料を組み直す。
  • 40ページの申請書類一式を目で確認し、提出前に重複を取り除く。
  • 提案ごとに最も自信のある作品が先頭に来るよう、ポートフォリオのページを並べ替える。

Tips for the best results

  • 回転、並べ替え、削除は1回の作業でまとめて行いましょう。3つのツールを別々に使うより、1回の書き出しで済むほうが効率的です。
  • 回転はページ単位で適用されるので、文書全体を回すことなく1枚の曲がったスキャンだけを直せます。
  • 削除の印を付けたページは書き出すまで消えないので、印は見直せる候補リストだと考えてください。
  • サムネイルは小さいので、似たページが2枚あるときは拡大するか元のファイルを並べて開き、動かす対象を間違えないようにしましょう。
  • スマートフォンでは端末を横向きにすると、ドラッグ中に画面へ表示できるボードの範囲が広がります。

よくある質問

Acrobatを使わずにPDFのページを並べ替えるには。

PDForaの整理ツールにファイルを読み込み、ページのサムネイルを好きな順番にドラッグして書き出すだけです。最近のブラウザなら動作し、無料で、インストールするソフトもありません。

PDF全体ではなく1ページだけ回転できますか。

はい。各サムネイルに回転ボタンがあるので、他のページはそのままに、1枚の横向きスキャンだけを正しい向きにできます。

ページの削除と並べ替えを同時にできますか。

できます。ページに削除の印を付け、残りをドラッグして配置し、曲がっているものを回転させれば、すべての変更が1つの書き出しPDFにまとめて反映されます。

整理している間、文書はアップロードされますか。

いいえ。サムネイルはお使いのブラウザが描画し、編集後のPDFもローカルで組み立てられるため、ファイルはどの段階でも端末から出ません。

大きなファイルではサムネイルの表示に時間がかかるのはなぜですか。

ブラウザが全ページのプレビューを描画するため、長い文書や画像の多いPDFはそれだけ描画量が多くなります。速度はサーバーではなく端末次第で、ボードが表示されてしまえばドラッグは瞬時です。

書き出すとページの品質は変わりますか。

いいえ。並べ替え、回転、削除はいずれも構造上の変更で、ページの内容自体は再圧縮されないため、テキストも画像も元のまま出力されます。

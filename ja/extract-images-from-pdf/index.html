画像抽出

PDFに埋め込まれたラスター画像を抽出し、PNGファイルとしてダウンロードします。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

そのPDFのどこかに、本当に必要な写真が入っています。商品写真、ロゴ、グラフなどです。スクリーンショットで得られるのは、切り取られて圧縮された複製にすぎません。抽出はそれとは違います。このツールは、PDFに埋め込まれた元の画像をPNGファイルとして取り出します。しかも、書類が作られたときに配置された解像度のままです。見つかった画像はすべてZIPにまとめられ、一度でダウンロードできます。

抽出はすべてブラウザ内で実行されます。PDFはお使いの端末で開かれて読み込まれ、アップロードされることはありません。社外秘の資料、診断書、未公開のパンフレットから画像を取り出すときにも、まずファイルをサーバーに預ける必要はないということです。アカウントの作成も不要で、抽出したファイルに透かしが入ることもなく、書類数や画像数の上限もありません。

ここでいう画像が何を指すのかを知っておくと役立ちます。このツールが取り出せるのは、画像ファイルとして書類に挿入された写真やグラフィックです。文字、ベクター形式のロゴ、描画された図形は絵ではなく描画命令なので、結果には現れません。またスキャンしたPDFは実質的に1ページにつき1枚の大きな画像であり、そのとおりに抽出されます。

オンラインでPDFから画像を抽出する手順

  1. 画像抽出ツールを開き、PDFをページ上にドロップするか、クリックして選択します。
  2. 書類はブラウザ内でローカルに走査され、埋め込み画像が探されます。ファイル自体はどこにも送られません。
  3. 全ページで何枚の画像が見つかったかを確認します。
  4. 「抽出」をクリックし、各画像をPNGファイルとして取り出します。
  5. 抽出されたすべての画像が入ったZIPアーカイブをダウンロードします。
  6. 展開して必要な画像を選び、残りは削除します。

When to use this tool

  • 不動産の物件情報やパンフレットのPDFから写真を取り戻す。担当者が元データを送ってくれなかったときに役立つ。
  • 古いプレスキットから企業ロゴや製品画像を取り出し、新しいプレゼン資料で再利用する。
  • パソコンの買い替えで元データを失った後、何年も前に自分が書いたレポートから図版や写真を取り出す。
  • ページごとにスクリーンショットを撮らずに、仕入先のPDFカタログから商品写真をまとめて集め、ネットショップで使う。
  • PDFに書き出されたスライド資料から図解を取り出し、画像編集ソフトで加工したりトリミングし直したりする。
  • イベントのプログラムやニュースレターから写真を取り出し、SNSに投稿する。

Tips for the best results

  • 抽出された画像は埋め込み時の解像度で出力されます。紙面での見た目より大きいことが多く、印刷用途ではうれしい誤算になることもあります。
  • 画像が1枚も見つからない場合、その視覚要素はおそらくベクターグラフィックか文字です。PDFからPNGへの変換ツールでページごと変換すれば、画像として取り込めます。
  • PDFでは同じ画像が複数ページで使い回されていることがあるため、ZIPの中に重複が含まれることがあります。状態の良いものを残しましょう。
  • スキャンした書類からは、1ページにつき1枚のページ全体の画像が得られます。それがスキャン画像そのものであり、異常ではありません。
  • 小さなアイコンが大量に含まれる書類では、展開したフォルダーを画像サイズで並べ替えると、高解像度の写真をすばやく見つけられます。

よくある質問

どのくらいの画質で取り出せますか。

各画像は埋め込まれたときの解像度で抽出され、PNGとして保存されるため、書き出しの過程で再圧縮されることはありません。書類の作成者が高解像度の写真を配置していれば、紙面上では小さく表示されていてもその高解像度のまま手に入ります。

スクリーンショットより抽出のほうが良いのはなぜですか。

スクリーンショットは画面の表示倍率のままの画像で、元より小さく、眠い仕上がりになりがちです。抽出では埋め込まれている実際のファイルを、元のサイズできれいなまま取り出せます。

抽出中にPDFはアップロードされますか。

いいえ。ファイルはお使いの端末のブラウザが解析し、画像もお使いの機器の中にしか存在しません。そのため社内資料や社外秘の書類にも適しています。

一部のグラフィックが結果に出てこないのはなぜですか。

ベクターグラフィックとして描かれたグラフ、ロゴ、図形は埋め込み画像ファイルではないため、抽出できるものがありません。PDFからPNGへの変換ツールでそのページを描画すれば、画像として取り込めます。

抽出した画像はどのように渡されますか。

すべての画像がPNGとして保存され、1つのZIPアーカイブにまとめられます。40枚の写真を含む書類でも、ダウンロードは1回で済みます。展開して中身を確認し、必要なものを残してください。

制限や料金はありますか。

ありません。無料で、登録も不要、透かしも入らず、PDFの数にも含まれる画像の枚数にも上限はありません。

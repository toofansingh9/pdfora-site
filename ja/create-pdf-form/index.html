フォーム作成

PDFの好きな位置に、入力可能なテキストフィールドやチェックボックスを配置できます。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

多くのフォームは、静的な文書として生まれます。Wordから書き出したもの、スキャンした紙、きれいにデザインされたPDF。そして受け取った人は、なぜかそこに記入することを期待されます。印刷して手書きし、また取り込む。あるいはエディタで無理やり文字を重ねる。このツールは、その繰り返しを終わらせます。既存の文書の好きな位置に、本物の入力可能なテキストフィールドやチェックボックスを配置して、記入できるPDFフォームを作れます。

操作はシンプルです。画面にPDFが表示されたら、回答を書き込ませたい場所をクリックするだけで、そこにフィールドが置かれます。ドラッグして位置を微調整し、記入欄の大きさに合わせてサイズを変え、はい・いいえの選択肢の横にはチェックボックスを追加します。書き出すと、本物のAcroForm形式のPDFが得られます。Adobe Acrobatもブラウザもモバイルのビューアも扱える、標準的な入力可能フォーマットです。

処理はすべてブラウザ内でローカルに実行されるため、変換する文書がパソコンの外に出ることはありません。登録は不要、フォームにウォーターマークは入らず、料金もかからず、作成できるフォームの数にも制限はありません。

入力可能なPDFフォームをオンラインで作成する方法

  1. 入力可能にしたいPDF（申込書、契約書、アンケートなど）を開きます。ブラウザ内にローカルで読み込まれます。
  2. ページ上の、入力してほしい位置をクリックします。その場所にテキストフィールドが表示されます。
  3. はい・いいえの項目や選択式の設問の横には、クリックしてチェックボックスを追加します。
  4. 各フィールドをドラッグして印刷された記入欄に合わせ、長い回答にも余裕があるようにサイズを調整します。
  5. すべての設問にフィールドが割り当てられるまで、各ページで同じ作業を繰り返します。
  6. ファイルを書き出します。そのまま送信できる本物の入力可能なAcroForm PDFになり、受け取った人は標準的なPDFビューアで記入できます。

When to use this tool

  • 以前は印刷してスキャンしてもらっていた賃貸の入居申込書を、入居希望者がスマートフォンで記入できるフォームにする。
  • クラブの入会申込書やイベントの参加登録用紙を入力可能にして、手書きではなく入力済みの状態で回答を受け取る。
  • 初診の問診票を対話型フォームに変換し、クリニックが予約前にメールで送れるようにする。
  • フリーランス向けの契約書テンプレートにフィールドを追加し、新しいクライアントごとに氏名・日付・料金をきれいに入力できるようにする。
  • 古いスキャン済みの承諾書を入力可能なPDFに作り直し、保護者がメールで返送できるようにする。
  • 社内の経費精算書や休暇申請書に、ファイルを直接編集させるのではなく、きちんとしたフィールドとチェックボックスを用意する。

Tips for the best results

  • テキストフィールドは余裕をもって大きめに。メールアドレスは想像より横幅が必要で、窮屈なフィールドは記入する人をいらだたせます。
  • フィールドはページ上の記入欄や項目名に合わせて配置します。説明文は元の文書が担い、入力部分をフィールドが担う形です。
  • 選択肢が決まっている項目は、テキストフィールドにXを打ってもらうのではなく、チェックボックスを使いましょう。
  • 送る前に、書き出したフォームに自分で一度記入してみてください。2分のテストで、位置のずれや付け忘れが見つかります。
  • 書き出した入力可能版はマスターのテンプレートとして保管し、記入済みのコピーは後から統合（フラット化）して、回答を変更できないようにするとよいでしょう。

よくある質問

AcroFormとは何ですか。

AcroFormは対話型PDFフォームの標準形式で、Acrobat、ブラウザのビューア、Preview、モバイルアプリなど、ほぼすべてのPDFリーダーが対応しています。このツールは見た目だけの重ね書きではなく、本物のAcroFormフィールドを書き出すので、どこでも記入・保存が可能です。

元になるPDFが必要ですか。

はい。このツールは、すでにお持ちの文書（デザイン済みのフォーム、契約書、スキャンなど）の上にフィールドを追加するものです。レイアウトは好きなアプリで作ってPDFに書き出し、そのうえでここでフィールドを配置してください。

配置した後にフィールドを調整できますか。

できます。どのフィールドもドラッグして位置を変えられますし、端をつかんでサイズを変更し、記入欄や枠にぴったり重ねられます。位置がずれても、やり直しではなく数秒の修正で済みます。

どんな種類のフィールドを追加できますか。

入力用のテキストフィールドと、選択用のチェックボックスです。この2つの部品で、申込書、問診票、契約書、参加登録、承認欄など、実務で使うフォームの大半をカバーできます。

受け取った人は入力内容を保存できますか。

はい。書き出されるのは標準的な入力可能PDFフォームなので、受け取った人は最近のビューアで開いて回答を入力し、チェックを付け、そのデータを保持したまま保存または返送できます。

アップロードした文書のプライバシーは守られますか。

そもそもアップロード自体がありません。PDFはすべてブラウザ内で処理され、サーバーに触れることはありません。登録不要、ウォーターマークなし、利用回数の制限なしと合わせて、必要なだけ入力可能フォームを無料で作成できます。

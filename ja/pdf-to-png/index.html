PDFからPNG

PDFのページを可逆圧縮のPNG画像に変換します。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

PDFのページにテキスト、表、図表、線画が含まれているなら、選ぶべき形式はPNGです。JPGと違いPNGの圧縮は可逆なので、文字の輪郭は鮮明なまま保たれ、細い図の線に圧縮ノイズが乗ることもありません。このツールはPDFの全ページをPNG画像に変換し、複数ページの文書はページ順に番号を振った1つのZIPファイルとして受け取れます。

変換はすべてブラウザが処理します。PDFがアップロードされることはないため、法的な契約書、試験問題、財務諸表もずっと端末に留まります。サーバーに保存されるものは何もなく、後から期限切れや削除を気にする必要もありません。無料でアカウント不要、変換に透かしもページ数の上限もありません。

出力がピクセル単位で正確なため、PDFからPNGへの変換はドキュメント用のスクリーンショット、デザインツールに取り込むスライド、鮮明なUIテキストの隣に置く画像などで標準的な選択肢になっています。写真の多いページを変換してファイルを小さくしたい場合は、PDFからJPGへのツールのほうが適しています。

オンラインでPDFをPNGに変換する方法

  1. PDFからPNGへの変換ツールを開き、ファイルをページ上にドラッグするか、クリックして端末から選びます。
  2. ブラウザが文書をローカルで読み込むのを待ちます。まもなく検出されたページが表示されます。
  3. 変換を開始します。各ページが可逆圧縮のPNG画像として描画されます。
  4. 結果をダウンロードします。1ページのPDFなら1つのPNG、複数ページならZIPアーカイブになります。
  5. ZIPを展開し、必要なページが100%表示で問題ないかを確認します。
  6. 画像の名前を変更したりプロジェクトに移動したりします。ドキュメント、スライド、Web用にそのまま使えます。

When to use this tool

  • スクリーンショットやUIの文字を極めて鮮明に保つ必要があるヘルプセンター向けに、ソフトウェアマニュアルのページをPNGにする。
  • レポートPDF内の構成図やフローチャートを画像に変換し、Confluence、Notion、社内wikiに掲載する。
  • PDFとして保存したスライドをPNGに書き出し、描き直すことなくFigmaやCanva、新しい資料で再利用する。
  • JPG圧縮では細い線がにじんでしまう楽譜、編み物の図表、技術図面をWebに公開する。
  • 賞状や卒業証書のページをきれいな画像にし、LinkedInの投稿や個人サイトに載せる。
  • 手作業で作り直す手間に見合わないとき、研究論文の表を画像として取り込み、プレゼンで使う。

Tips for the best results

  • テキスト、図表、スクリーンショットにはPNGを、ほぼ写真のページにはJPGを使いましょう。写真ではPNGにしても見た目は変わらないままファイルだけが大きくなります。
  • 長い文書のPNGはすぐに容量がかさみます。数百ページに及ぶファイルなら、必要な章やページだけを変換しましょう。
  • 出力を確認するときは100%表示にしましょう。縮小表示でぼやけて見えるのは、たいていビューアーが縮小しているだけです。
  • PNGは透過に対応していますが、PDFのページは背景(通常は白)ごと描画されます。透過が必要な場合は画像編集ソフトで背景を取り除いてください。
  • 作業が終わるまでZIP内の番号付きファイル名はそのままにしておきましょう。どの画像がどのページ由来かをたどりやすくなります。

よくある質問

PDFからPNGとPDFからJPGの違いは何ですか。

PNGは可逆圧縮なので、テキストや線画が完全に鮮明なまま保たれる代わりにファイルは大きくなります。JPGは圧縮率が高く、写真中心のページに向いています。読ませるものにはPNGを、眺めるだけのものにはPNGでもJPGでも構いません。

変換は自分の端末で行われますか。

はい。PDFはお使いのブラウザによってローカルで画像に描画され、サーバーに送信されることはありません。機密文書は端末から出ないため、機密のまま保たれます。

複数ページのPDFはどのように受け取れますか。

各ページがそれぞれのPNGになり、すべてが1つのZIPアーカイブにまとめられます。ファイルにはページ番号が振られているので、フォルダを名前順に並べれば文書の順序が再現されます。

画像に透かしが入ったり、制限があったりしますか。

透かしも、1日の割り当ても、登録もありません。ツールは無料で、100回目の変換も1回目とまったく同じように扱われます。

PDF全体ではなく1ページだけ変換できますか。

このツールは渡されたファイルの全ページを変換します。1ページだけがほしい場合は、先にそのページを抽出または分割してから、小さくなったPDFを変換してください。

PNGファイルがPDFよりずっと大きくなるのはなぜですか。

PDFはテキストをコンパクトな命令として保存しますが、PNGは描画されたページのすべてのピクセルを保存するためです。これは正常なことで、画面上でどの大きさに表示しても元の見た目と変わらない理由でもあります。

PDFフラット化

対話型のフォームフィールドをページに統合し、編集できないようにします。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

記入済みのPDFフォームは、まだ編集できる状態にあります。開いた人は誰でもフィールドをクリックして金額を変え、別のチェックを付けて保存し直せます。しかも多くの場合、痕跡すら残りません。フラット化（統合）はこれを解決します。PDFをフラット化すると、対話型のフォームフィールドがページそのものに統合され、記入内容は周囲の印字と同じくらい固定された、文書の一部になります。

このツールは、ブラウザ内で一度の処理でPDFフォームをフラット化します。ファイルをドロップしてクリックするだけで、すべてのテキストフィールド、チェックボックス、ドロップダウンの選択がページに焼き込まれた版をダウンロードできます。見た目の内容は同じで、違いは、もはや上書き入力ができないという点です。鉛筆ではなくインクで署名するのと同じことを、デジタルで行うわけです。

処理がご自身の端末上でローカルに行われるため、フォームも、そこに入力されたすべての内容も非公開のままです。何もアップロードされません。無料で、アカウントも不要、ウォーターマークも入らず、いくつフォームを処理してもかまいません。

PDFをオンラインでフラット化する方法

  1. 記入済みのPDFフォームを選ぶか、アップロード領域にドラッグします。どこにも送信されることなく、ブラウザ内で直接開かれます。
  2. ツールがフォームを読み取り、対話型のフィールドを検出するまで少し待ちます。
  3. 表示されるフィールド数を確認し、フォームが正しく認識されたことを確かめます。
  4. フラット化のボタンをクリックします。各フィールドの値がページ上に恒久的に描画され、対話型のレイヤーが取り除かれます。
  5. フラット化したPDFをダウンロードします。
  6. 任意のビューアで開き、以前フィールドだった場所をクリックしてみて、記入内容が固定されていることを確認します。

When to use this tool

  • 署名済みの賃貸借契約書をロックし、両当事者がコピーを持った後で入居者の情報や日付が変更されないようにする。
  • 記入済みの求人応募フォームをフラット化してから保管し、人事の記録が提出時のまま保たれるようにする。
  • 入力可能なテンプレートから作成した請求書を用意し、クライアントが誤って合計金額を編集できないようにする。
  • 記入済みの税務書類や行政の申請書をメールで送る前に凍結する。行政機関のシステムには、有効なフォームフィールドを含むPDFを受け付けないものもあります。
  • PDFフォームとして集めたアンケートの回答をフラット化し、確認作業の途中でデータが変更されないようにする。
  • 印刷の問題を解決する。プリンターによってはフォームフィールドの内容をまったく印刷しないことがあり、フラット化すれば記入内容が確実に印刷されます。

Tips for the best results

  • 入力可能な元の版はテンプレートとして残し、誰かが記入するたびにそのコピーをフラット化しましょう。
  • フォームを他の文書と結合する前にフラット化してください。結合処理では、重複したフィールド名が混線することがあります。
  • 記入済みのフォームが他の人のビューアで空に見える場合、たいていフラット化で解決します。値が通常のページ内容になり、どのビューアでも表示できるようになるからです。
  • フラット化した後はフィールドに入力できなくなるので、すべての項目が記入されているか事前によく確認してください。
  • フォームの内容が多い場合、対話型のレイヤーが取り除かれる分、フラット化でファイルサイズがわずかに小さくなります。

よくある質問

PDFをフラット化するとはどういう意味ですか。

フラット化とは、テキストフィールド、チェックボックス、ドロップダウンといった対話型の要素を、静的なページの内容に統合することです。入力された回答は同じ位置に見えたままですが、編集可能なフィールドではなくページそのものの一部になります。結果として、スキャンした文書や印刷物のような振る舞いになります。

フラット化したPDFフォームを再び編集できますか。

フォームフィールドはもう存在しないため、そこからは編集できません。本格的なPDFエディタを持つ人であれば、他のPDFと同様にページ内容を変更することは可能ですが、回答を気軽に書き換えることはできなくなります。多くの契約書や提出書類にとっては、まさに求めていた保護です。

フラット化するとフォームの見た目は変わりますか。

いいえ。ツールは各フィールドの現在の値を、同じ位置・同じ文字サイズでページ上に描画するので、フラット化したファイルは記入済みのフォームとまったく同じに見えます。失われるのは対話性だけです。

記入済みのフォームはどこかにアップロードされますか。

いいえ。処理全体がブラウザ内で実行されるため、氏名や住所、入力した機微な回答を含むフォームがパソコンから出ることはありません。サーバー方式の変換サービスに対する明確な利点です。

受け取った人にフォームの項目が空白に見えるのはなぜですか。

一部のビューア、とくにスマートフォンや一部のメールのプレビューでは、フォームフィールドの値が描画されません。フラット化すると回答が通常のページ内容に変わり、どのPDFビューアでも正しく表示されます。

署名やチェックボックスにもフラット化は効きますか。

はい。チェックボックスの状態、ドロップダウンの選択、手書きまたは入力した署名のフィールドも、テキストフィールドと一緒にページへ統合されます。記入済みフォームで見えているものはすべて、フラット化された状態で保持されます。

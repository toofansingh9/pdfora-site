ベイツナンバリング

接頭辞とゼロ埋めを指定して、連番のBates番号を各ページに刻印します。法務文書の標準的な手法です。

訴訟では、証拠開示で提出されるすべてのページに固有の識別子が必要です。法務の世界でそれを担ってきたのがBates番号です。接頭辞と連番を付けるだけで、「請求書についてのあのメール」がABC-000147になります。証言録取で引用でき、秘匿特権リストでたどることができ、法廷で曖昧さがなくなります。このツールはオンラインでBates番号を付与し、PDFのすべてのページに数秒で刻印します。

書式は自由に指定できます。「SMITH-」や案件番号などの接頭辞を設定し、新しい提出分が前回の続きから始まるように開始番号を選び、ゼロ埋めの桁数を決めます。1ではなく000001とする、といった具合です。そのうえで刻印の位置を、下右・下左・下中央から選びます。ツールはすべてのページに順番に番号を振り、刻印済みのファイルを返します。

法律事務所にとって最も重要なのはプライバシーの仕組みです。PDFは完全にブラウザ内で処理され、アップロードされることはないため、秘匿特権のある文書や機密文書はご自身の端末に留まります。無料で、登録不要、ウォーターマークなし、ページ数の制限もありません。

Bates番号をオンラインで追加する方法

  1. PDFをツールにドラッグします。ブラウザ内でローカルに開かれるため、依頼者の文書が送信されることはありません。
  2. 接頭辞を入力します。たとえば「ABC-」や、「DOE2026-」のような案件の識別子です。
  3. 開始番号を設定します。最初の提出なら1、追加提出なら前回刻印した最後のページの続きから始めます。
  4. ゼロ埋めの桁数を選びます。6桁ならABC-000001、ABC-000002のようになります。
  5. 刻印の位置を、下右・下左・下中央から選びます。
  6. クリックして全ページに刻印し、Bates番号入りのPDFをダウンロードします。その後、提出目録に番号の範囲を記録しておきましょう。

When to use this tool

  • パラリーガルが証拠開示の提出前に、印刷したメール400ページにPLAINTIFF-000001からPLAINTIFF-000400まで刻印する。
  • 個人開業の弁護士が診療記録のPDFにBates番号を付け、人身傷害事件の証言録取で相手方の弁護士が特定のページを引用できるようにする。
  • 企業の法務チームが召喚状に対応する社内文書に番号を振り、以前の段階的提出からの連番を継続する。
  • 会計士が監査調書に連番を刻印し、最終報告書ですべてのページを一意に参照できるようにする。
  • 記録係が行政審判用の証拠に番号を付け、証拠のまとまりごとに異なる接頭辞を使う。
  • コンプライアンス担当者が方針集を1ページずつ刻印し、固定のページ識別子に対して改訂を追跡できるようにする。

Tips for the best results

  • 案件ごとに最後に使ったBates番号の記録を残しておきましょう。次の提出はその次の番号から始めるべきで、同じ番号を再利用してはいけません。
  • 米国の証拠開示では6桁のゼロ埋めが一般的な慣行です。番号の桁がそろい、どのファイル一覧でも正しく並びます。
  • 「SMITH-」や「DEF-」のように、提出する当事者がわかる接頭辞を選びましょう。異なる当事者のページ番号が衝突しなくなります。
  • 刻印の位置は重要です。文書にすでに印字されているフッターやページ番号を覆わない隅を選んでください。
  • 原本ではなくコピーにBates番号を刻印しましょう。案件の途中で書式の要件が変わる場合に備えて、きれいな版を残しておきます。

よくある質問

Bates番号とは何ですか。

Bates番号とは、文書一式のすべてのページに固有の連番の識別子を刻印する手法で、通常はABC-000123のように接頭辞とゼロ埋めした番号を組み合わせます。1890年代に特許を取得した手回し式の刻印機に由来し、今も法務チームが証拠開示でページを特定する標準的な方法として使われています。

秘匿特権のある法務文書に使っても安全ですか。

はい。そしてこれが大半のオンライン刻印ツールとの決定的な違いです。PDFはブラウザ内でローカルに処理され、サーバーにアップロードされることは一切ありません。秘匿特権のある資料や機密資料は、最初から最後までお使いのパソコンに留まります。

以前の提出分から番号を続けられますか。

はい。前回の提出が終わった番号を開始番号に設定してください。ABC-000400で終わっていたなら、同じ接頭辞と桁数で401から始めれば、案件全体を通して一続きの連番を保てます。

Bates刻印はページのどこに配置されますか。

下右、下左、下中央から選べます。米国の実務では下右が最も一般的な慣行ですが、裁判所や取り決めによって異なるため、まずはESIオーダーや提出に関する合意内容をご確認ください。

Bates刻印は恒久的なものですか。

番号はページの内容として各ページに描画されるため、どのPDFビューアでも位置が固定され、印刷やコピーをしても残ります。ワンクリックで削除できる、取り外し可能な注釈ではありません。

料金やページ数の制限はありますか。

ありません。無料で、アカウントも不要、ウォーターマークも入らず、ページ数や文書数の上限もありません。2,000ページの提出分も10ページの文書とまったく同じように処理されます。

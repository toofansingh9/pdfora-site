メタデータ編集

文書のタイトル、作成者、サブタイトル、キーワードを編集できます。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

すべてのPDFは、目に見えない情報の層を持っています。タイトル、作成者名、サブタイトル、そして一連のキーワードです。検索ツールやファイル管理ソフト、文書ライブラリは、他の何よりも先にこれらの項目を読み取ります。メタデータが正しくないと（たとえばタイトルが「無題」だったり、作成者が「user123」だったり）、ファイルは雑な印象を与え、見つけるのも難しくなります。このツールを使えば、ブラウザ上で直接PDFのメタデータを編集できます。

ファイルを開くと、現在のタイトル、作成者、サブタイトル、キーワードがそのままテキストボックスに表示されます。必要な箇所だけ書き換え、残りはそのままにして、きれいになったコピーをダウンロードするだけです。多くのPDFは、何年も前にテンプレートを作った人のメタデータをそのまま引き継いでいます。そのため、クライアント向けの提案書の作成者が退職した社員のままということも起こります。ここなら、その修正が30秒ほどで済み、ソフトのインストールも不要です。

処理はすべてブラウザ内でローカルに実行されます。PDFがパソコンから出ることはなく、契約書や診療記録など機密性の高い書類を整理するときに大きな意味を持ちます。無料で、登録は不要、ウォーターマークも入らず、処理できるファイル数に制限もありません。

PDFのメタデータをオンラインで編集する方法

  1. アップロード領域をクリックするか、PDFをそこにドラッグします。ファイルはローカルで開かれ、サーバーには何も送信されません。
  2. 自動的に読み込まれる既存のメタデータ（タイトル、作成者、サブタイトル、キーワード）を確認します。
  3. 新しいタイトルを入力します。これは多くの検索ツールやビューアが表示するテキストなので、内容がわかるものにしましょう。
  4. 作成者の項目を更新し、後で見つけやすくしたい場合はサブタイトルとキーワードも調整します。
  5. 空欄にしておきたい項目は消去します。間違った値が入っているより、空のほうが優れています。
  6. 変更を適用してクリックし、更新されたPDFをダウンロードします。

When to use this tool

  • どのPDFビューアでもタイトルが「Microsoft Word - draft_v3_FINAL.docx」と表示されてしまうレポートを修正する。
  • 提案書をクライアントに送る前に、作成者の項目に残っている退職した同僚の名前を差し替える。
  • 保管済みの請求書数百件にキーワードを追加し、文書管理システムの検索で実際に見つけられるようにする。
  • 電子書籍やホワイトペーパーを公開する前に、適切なPDFのタイトルと作成者を設定する。一部の検索エンジンは検索結果にメタデータのタイトルを表示します。
  • 社外に共有する前にPDFのサブタイトルとキーワードの項目を削除し、社内プロジェクトのコードネームを取り除く。
  • スキャナーからすべて「Scan0001」として出てきた文書のまとまりについて、タイトルと作成者を統一する。

Tips for the best results

  • メタデータのタイトルはファイル名とは別物です。ウィンドウのタイトルバーにメタデータのタイトルを表示するPDFビューアもあるので、両方を設定しておきましょう。
  • キーワードはカンマで区切ります。長い文よりも、短く具体的な語句のほうが効果的です。
  • 匿名で公開する文書では、作成者の項目を空にしてください。PDF作成ソフトは何も言わずにこの項目を埋めてしまうことがよくあります。
  • オンラインで公開する予定のファイルでは、ページの見出しを書くつもりでタイトルを付けましょう。検索結果での見え方に影響することがあります。
  • 「マーケティング部、Acme株式会社」のように、組織内で作成者の書き方を統一しておくと、ファイルの並びが予測しやすくなります。

よくある質問

PDFのメタデータとは何ですか。

メタデータとは、PDFそのものの中に保存されている説明情報のことで、タイトル、作成者、サブタイトル、キーワードなどが含まれます。ページ上には表示されませんが、ファイル管理ソフト、検索ツール、PDFビューアがこれを表示し、索引に登録します。いわば文書の外側に貼られたラベルです。

メタデータを編集するとPDFの見た目は変わりますか。

いいえ。ページ、フォント、画像、レイアウトはそのままです。書き換えられるのは目に見えない説明用の項目だけなので、ダウンロードした文書は元のものとまったく同じように表示・印刷されます。

ファイルはサーバーにアップロードされますか。

いいえ。このツールはローカル処理により完全にブラウザ内で動作するため、PDFが端末から出ることはありません。機密性の高い契約書、財務諸表、個人記録でも安心して扱えます。

PDFビューアで間違ったタイトルが表示されるのはなぜですか。

多くのPDF作成ソフトは、元の文書のファイル名やテンプレートのタイトルを自動的にメタデータへコピーします。元のWordファイルが「draft_v3」という名前だったなら、その文字列がPDFに付いて回ります。ここでタイトルの項目を編集すれば、恒久的に置き換えられます。

編集ではなくメタデータを削除できますか。

はい。項目を空にして保存するだけで、ダウンロードしたファイルではその項目が空になります。作成者名や社内キーワードを見せたくない文書を公開する前によく行われる手順です。

料金やファイル数の制限はありますか。

このツールは完全に無料で、登録も不要、ウォーターマークもなく、編集できるPDFの数にも上限はありません。1ファイルでも100ファイルでも、条件は変わりません。

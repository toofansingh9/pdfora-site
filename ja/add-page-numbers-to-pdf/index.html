ページ番号

ページ番号を好きな位置に、複数の書式から選んで挿入できます。

ブラウザ上で、数秒のうちにPDFへページ番号を追加できます。結合したレポート、スキャンした論文、3つの資料をつなぎ合わせた契約書。こうした文書にはページ番号がまったく付いていないことが多く、番号のない80枚の紙を印刷するのはトラブルのもとです。PDForaは、ファイルを端末に置いたまま、すべてのページにすっきりと統一された番号を挿入します。ツール全体がローカル処理で動作するため、アップロードは一切ありません。

番号の位置と表示形式は自由に選べます。位置は下中央、下右、下左、上中央、上右に対応しているので、ヘッダーやフッター、綴じ代を避けて配置できます。書式は、単純な「1」、総ページ数を含む「1 / N」、より正式な印象の「Page 1」から選べます。本の途中から始まる章のような文書なら、開始番号を指定すれば、そこから連番が続きます。

PDForaの他のツールと同じく、これも無料で、登録は不要、出力にウォーターマークは入らず、番号を付けられるファイル数にも制限はありません。裁判所への提出書類、学位論文、取締役会の資料。付けた番号はそのまま残り、隅にロゴが入ることもありません。

PDFにページ番号をオンラインで追加する方法

  1. getpdfora.comのページ番号ツールを開き、PDFファイルをドロップします。
  2. 位置を選びます。下中央、下右、下左、上中央、上右から選択できます。
  3. 書式を選びます。「1」のような数字だけの表記、総ページ数を含む「1 / N」、ラベル付きの「Page 1」があります。
  4. 開始番号を設定します。1のままにするか、前のセクションの続きなら47などから始めます。
  5. 番号付けを適用し、ブラウザにファイルをローカル処理させます。アップロードもサーバー待ちもありません。
  6. 番号入りのPDFをダウンロードし、印刷や共有の前に最初のページと最後のページを確認します。

When to use this tool

  • すべてのページに連番を求める大学の規定に合わせて、提出前の学位論文に番号を付ける。
  • 「240ページ中の12ページ」といった参照で全員が文字どおり同じページを見られるよう、訴訟の証拠資料や裁判用の一式を準備する。
  • 複数のレポートをつなぎ合わせた結合PDFを、ひと続きの文書として読めるように整える。
  • そもそも番号のなかった古い議事録、帳簿、書簡などのスキャン資料に番号を追加する。
  • 研修マニュアルや従業員ハンドブックに番号を付け、おおよその場所を説明する代わりに「34ページ」と示せるようにする。
  • 分冊にまたがって番号を続けるため、2つ目のファイルを1つ目が終わった番号から開始する。

Tips for the best results

  • 印刷して配る資料には「1 / N」を使いましょう。最後のページが「80 / 80」であれば、1枚欠けていることがすぐにわかります。
  • すでにフッターがあるページでは、テキストと重ならないように番号を上中央または上右に配置してください。
  • 穴を開けて綴じる文書では、中央ではなく下左または下右を選び、番号を綴じ側から離しておきます。
  • 長い著作から抜き出した章に番号を付けるときは、元のページ付けに合わせて開始番号を指定すると、引用時の対応関係が保てます。
  • 番号付けは、結合やページ削除がすべて終わった最終版に対して行いましょう。付け直しは簡単ですが、並べ替えたファイルに古い番号が残っていると混乱を招きます。

よくある質問

ファイルはサーバーにアップロードされますか。

いいえ。このツールはローカル処理により完全にブラウザ内で動作します。PDFは最初から最後までパソコンの中に留まるので、機密性の高い契約書や未公開の作品でも安心です。

1以外の番号から始められますか。

はい。任意の開始番号を入力すれば、そこから連番が始まります。章や付録、あるいは以前に分割した文書の後半部分に便利です。

どんな書式が使えますか。

3種類あります。「1」のような数字だけの表記、総ページ数を含む「1 / N」、そして「Page 1」です。文書のスタイルに合うものをお選びください。

番号はページのどこに配置できますか。

下中央、下右、下左、上中央、上右の5か所に対応しています。既存のヘッダーやフッターと重ならない位置を選んでください。

本当に無料ですか。ファイルに何か印が付きますか。

無料で、登録も利用回数の上限もありません。PDForaが独自のものを文書に追加することはなく、ウォーターマークもブランド表示もありません。出力に含まれるのは、あなたのページとあなたの番号だけです。

非常に大きなPDFにも番号を付けられますか。

はい。このツールにページ数の制限はありません。すべてがローカルで動作するため、数百ページのファイルもお使いの端末の性能なりの速さで処理され、アップロードの待ち時間は一切ありません。

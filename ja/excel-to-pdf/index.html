ExcelからPDF

XLS または XLSX のブックを変換サーバーでPDFにし、シートを印刷できる固定のページに変えます。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

見積書や会計報告をExcelからPDFにしたら、右端の数列だけが別のページに飛んでいた、見出しが1ページ目にしか出ていない、グラフが1枚のページにぽつんと載っていた。こんな経験がある人は多いはずです。理由は単純で、表計算のシートはそもそも「ページ」を前提に作られていません。1枚のシートが横40列、縦3,000行あっても構わず、Excel はどこで区切るかを印刷する瞬間に初めて決めます。ブックからきれいなPDFを作るコツは、つまるところ「どう印刷するか」をあらかじめブックに教えておくことです。

「ExcelからPDF」は、.xls か .xlsx のファイルを1つ受け取り、PDForaの中継サーバーを通して暗号化された接続で CloudConvert のサービスにアップロードし、ブックと同じ名前のPDFを返します。レイアウトの計算はサーバー側の表計算エンジンが行うので、ブラウザの中では何も変換されません。処理が終わったファイルはサービスから削除されます。このページには設定項目がなく、仕上がりはブックに保存されているページ設定どおりになります。

つまり、出来ばえを決めるのは変換前の準備です。印刷範囲、印刷の向き、「すべての列を1ページに印刷」などの拡大縮小、各ページに繰り返す見出し行、ヘッダー、フッター、手動の改ページは、どれもファイルの中に保存されています。うまくいくまで何度も変換し直すより、変換前に Excel の「ページレイアウト」タブで数分かけるほうが、結果的にずっと早く片付きます。

ExcelをPDFに変換する手順

  1. Excel で「ページレイアウト」を開き、PDFに入れたい各シートの印刷範囲、印刷の向き、拡大縮小を設定してから、ブックを保存して閉じます。
  2. 「ExcelからPDF」を開き、.xlsx か .xls のファイルを選びます。
  3. 「変換」をクリックします。ファイルがアップロードされてサーバーで変換され、状況の行に進み具合が表示されます。
  4. PDFをダウンロードします。ファイル名はブックの名前に .pdf の拡張子が付いたものです。
  5. ページをめくり、列が切り離されていないか、数値、特に数式の結果がブックと一致しているかを確認します。

このツールを使う場面

  • フリーランスがExcelのテンプレートで作った請求書や見積書を、書き換えられないPDFにして取引先へメールで送る。
  • PTA、町内会、マンション管理組合の会計報告を、総会の配布資料としてPDFにする。
  • 数式や原価の計算を見せずに、価格表だけを取引先に渡す。
  • 店舗のシフト表、教室の時間割、座席表を印刷して休憩室や掲示板に貼る。
  • 年度末の数字を、何年後に開いても同じ見た目で表示される形で保管しておく。
  • Excel の書き出し機能がない、または使いにくいスマホやタブレットから、表をレポートとして共有する。

始める前に知っておきたいこと

  • 印刷範囲を設定していないと、変換ツールは基本的に各シートで使われている範囲全体を印刷します。表から遠く離れた、以前に値が入っていたセルまで含まれます。何を載せるかを正確に決めるには印刷範囲を設定してください。
  • 横に広いシートは、拡大縮小を設定しない限り列ごとに複数ページへ分割されます。15列程度までの表なら、たいてい「すべての列を1ページに印刷」（ページ設定の拡大縮小）が正解です。それより多い場合は横向きも併用するか、文字が小さくなるのを受け入れてください。
  • 複数のシートは、通常PDFの中で順番に並びます。非表示のシート、行、列は通常含まれないので、作業用のシートを出力から外すには非表示にするのが手軽です。
  • 数式はサーバーのエンジンで再計算されます。標準的な関数なら同じ結果になりますが、マクロ、アドイン、外部リンクに依存したブックでは、古い値やエラーが表示されることがあります。確実にしたいなら、コピーしたブックに値だけを貼り付けてください。
  • グラフや条件付き書式は通常そのまま反映されますが、フォントや細かい部分は Excel 自体の表示とわずかに異なることがあります。
  • 1回の処理で変換できるブックは1つで、ツールはサーバーの処理を約3分待ちます。数万行もある非常に大きなブックでは、それを超えることがあります。

きれいに仕上げるコツ

  • 「ページレイアウト」→「印刷タイトル」で、見出し行を各ページの上部に繰り返し表示させましょう。見出しのない12ページの表はほとんど読めません。
  • Excel の「表示」→「改ページプレビュー」をオンにして青い線をドラッグしましょう。そこで見える区切りは、PDFのページ割りとほぼ同じです。
  • PDFに入れたいシートを先頭に並べ、変換前に作業用のシートは非表示にするか削除しておきましょう。
  • ページ番号入りのフッター（&[ページ番号] / &[総ページ数] ページ）を付けておくと、印刷した紙がばらばらになっても順番を戻せます。
  • 必要なのが1枚のシートだけなら、新しいブックにコピーしてそれを変換しましょう。すべてのシートを調整するより早く済みます。

具体例：PTAの会計担当が年度末の収支報告を配る

小学校のPTAで会計を担当する村上さんは、1年分のお金の流れを1つのブックで管理しています。「収支報告」シート、月ごとの12枚のシート、家庭ごとの会費の納入状況をまとめたシート、それに自分用のメモのシートです。総会の資料として収支報告だけをPDFにしたいのですが、そのまま変換すると31ページになりました。月別シートも納入状況もメモも全部入り、11列ある報告表は「備考」の列だけが別のページに切り離されています。

村上さんはまず「収支報告」シートを新しいブックにコピーしました。こうすれば、家庭名の入った納入状況はファイルにそもそも含まれません。コピーしたシートで印刷範囲を A1:K90 にし、「すべての列を1ページに印刷」を選び、4行目の見出しを印刷タイトルに設定して、ページ番号入りのフッターを付けました。向きは縦のままで、保存してからもう一度変換しています。

できあがったPDFは縦向き2ページで、どちらのページにも見出しがあり、「備考」も各行の右端に収まっていて、家庭ごとの情報は一切含まれていません。肝心だったのは最初のコピーです。納入状況のシートを非表示にするだけでも見た目のPDFからは消えますが、その場合ブックの中には各家庭のデータが残ったままになっていたからです。

トラブルシューティング

列が切れて別のページに分かれる
シートがページより横に広いためです。Excel で「ページ設定」の拡大縮小を「すべての列を1ページに印刷」にし、横向きに切り替えて保存してから、もう一度変換してください。
ほとんど白紙のページが何十枚もある
データのずっと下や右にある不要な書式や値が、使用範囲を広げています。印刷範囲を設定するか、データの下と横の使っていない行と列を削除して保存してください。
PDFで一部のセルが #NAME? や #REF! になる
サーバーが評価できない関数、アドイン、マクロ、外部リンクがブックで使われています。シートをコピーして値だけを貼り付け、そのコピーを変換してください。
不要なシートがPDFに入っている
通常、表示されているシートはすべて変換されます。不要なシートを非表示にするか削除するか、必要なシートを新しいブックにコピーしてください。
変換がすぐに失敗する
ブックに開くためのパスワードがかかっている、破損している、または .xls / .xlsx 以外の形式（.xlsm や .csv など）の可能性があります。パスワードを外し、新しく .xlsx として保存したコピーで試してください。
タイムアウトした
非常に大きなブックは、ツールが待つ時間より長くかかることがあります。必要なシートだけを変換するか、データを小さなブックに分けてください。

よくある質問

Excelのファイルはサーバーに送られるのですか？

送られます。ブックは暗号化されて変換サービスに届き、そこで変換された後に削除されます。社外に一切出してはいけないデータなら、Excel 自体の「PDFとして保存」を使ってください。

ブックの中の1シートだけをPDFにしたいのですが。

シートを選ぶ機能はありません。ほかのシートを非表示にするか、必要なシートだけを新しいブックにコピーして、そのファイルを変換してください。

PDFにしたあとも数式は生きていますか？

生きていません。PDFに残るのは計算結果の値だけで、数式そのものは含まれません。価格や合計を渡すときには、むしろそのほうが好都合なことが多いでしょう。

CSVファイルやGoogle スプレッドシートもPDFにできますか？

このツールが受け付けるのは .xls と .xlsx だけです。CSVは表計算ソフトで開いて .xlsx で保存し直し、Google スプレッドシートは .xlsx 形式でダウンロードしてから変換してください。

2ページ目以降にも表の見出しを出すにはどうすればいいですか？

Excel の「ページレイアウト」→「印刷タイトル」→「タイトル行」で見出しの行を指定し、保存してから変換してください。この設定はブックに保存され、変換時にもそのまま使われます。

グラフやフォントの見た目がExcelと微妙に違うのはなぜですか？

サーバーは独自の表計算エンジンとフォントを使うため、細かな描画が異なることがあります。データとレイアウトは一致するはずです。できるだけ近づけたい場合は、一般的なフォントを使ってください。

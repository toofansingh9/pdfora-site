傾き補正

スキャンしたページの傾きを自動的に検出して補正し、まっすぐに整えます。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

完璧にスキャンできる人はいません。スキャナーに少し斜めに用紙を通したり、書類を適当な角度から撮影したりすれば、文字がページを斜めに下っていきます。PDForaの傾き補正ツールは、曲がったスキャンをブラウザ内でまっすぐにします。各ページの傾き具合を測定して水平まで回転させるので、きちんとしたフラットベッドスキャナーで取り込んだような仕上がりになります。

使い方は2通りあります。自動検出はページを解析して傾き角度を自ら判定し、補正します。ほとんどのスキャンはこれでワンクリックで済みます。手動モードでは角度を自分で指定できるので、検出の手がかりになる文字が少ないページや、1度未満の微調整を自分で行いたい場合に便利です。

補正はローカルで実行されるため、スキャンした契約書や記録がどこかにアップロードされることはありません。傾き補正は無料で、登録不要、透かしも入らず、利用回数の制限もありません。後工程でも効果があり、まっすぐになったページはOCRの精度が上がり、印刷もきれいで、単純に丁寧な仕事に見えます。

オンラインでPDFの傾きを補正する方法

  1. ブラウザでPDForaの傾き補正ツールを開きます。
  2. 曲がったスキャンPDFをドラッグするか、端末から選択して追加します。
  3. 各ページの傾き角度をツールに判定させるなら自動検出を選び、そうでなければ手動モードに切り替えます。
  4. 手動モードでは、プレビューの文字が水平になるまで回転角度を度単位で設定します。
  5. 補正を適用し、ブラウザがすべてのページをローカルでまっすぐにするのを待ちます。
  6. プレビューを元の状態と見比べてから、補正済みのPDFをダウンロードします。

When to use this tool

  • スマートフォンで斜めに撮影した賃貸借契約書を、貸主に送る前にまっすぐにする。
  • シートフィード式スキャナーで少し回転して取り込まれた領収書の束を補正し、経費システムにきれいに登録する。
  • 箱にしまっていた古い家族の手紙や証書をデジタル化した際、ページごとに傾きが違うものを水平に整える。
  • 文字の行が水平でないと認識精度が大きく下がるため、OCRの前に曲がったスキャンを整える。
  • ページがのど側で湾曲して傾きが生じたスキャン済みの書籍の一章を整える。
  • 職員が閲覧・印刷する公的なポータルに提出する前に、署名済みの書類をまっすぐに整える。

Tips for the best results

  • 傾き補正はOCRの前に必ず実行しましょう。わずか2度の傾きでも文字認識に目に見える悪影響があり、まっすぐな入力は最も手軽な精度向上策です。
  • 文字の多いページでは自動検出を信頼してください。文字行を読み取って角度を求めるため、通常の書簡、フォーム、レポートは確実に補正されます。
  • 文字の少ないページでは手動に切り替えましょう。図面や写真、単語がわずかしかないページでは検出の手がかりが乏しく、自分で角度を指定するほうが早く済みます。
  • わずかな角度でも侮れません。1度の補正でも印刷では見て分かるので、画面上で傾きが小さく見えても補正を省かないでください。
  • 傾き補正が直せるのは回転であって、遠近のゆがみではありません。斜めから撮影した写真には回転では直せない台形ゆがみがあるため、ページが台形に見える場合は平らに置いて撮り直してください。

よくある質問

傾き補正はPDFに対して実際に何をしていますか。

各ページの内容を正確な角度で回転させ、傾いた文字を水平に戻します。自動検出が傾きを測定してくれるほか、手動モードでは角度を度単位で指定できます。出力はページがまっすぐになった通常のPDFです。

自動検出はどうやって角度を判定しているのですか。

ページ画像を解析し、文字行やエッジの支配的な方向を探して、それが水平からどれだけずれているかを計算します。一般的な文書なら1度未満の精度に収まり、各ページは個別に測定されます。

手動モードを使うべきなのはどんなときですか。

ページの文字が非常に少ないとき、内容がほとんど画像のとき、または自動の結果に納得できないときです。回転角度を度単位で指定し、プレビューが良くなるまで微調整できます。

スキャンをまっすぐにすると画質は落ちますか。

回転にはページの再描画が伴うためわずかな再サンプリングが発生しますが、通常のスキャンであれば閲覧や印刷で気づくほどの差ではありません。文字が水平になることで得られる読みやすさのほうがはるかに大きな利点です。

処理中、文書のプライバシーは守られますか。

はい。角度の検出も回転も、お使いの端末のブラウザ内で実行されるため、ファイルがアップロードされることはありません。これは複数ページの大きなスキャンでも同じで、ページを読み込んだ後はオフラインでも動作する理由でもあります。

料金はかかりますか。多くのファイルを補正できますか。

ツールは無料で、アカウントも透かしも制限もありません。傾いたスキャンがフォルダいっぱいにあっても、割り当てを気にせず次々に処理できます。

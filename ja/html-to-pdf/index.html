HTMLからPDF

保存したHTMLファイルを変換サーバーでPDFにし、WebページやHTML形式の書き出しを、印刷できる固定レイアウトのページに変えます。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

ネット通販の注文確認画面を保存したら、HTMLファイルになっていた。会計ソフトのレポートを書き出したら、拡張子が .html だった。経費精算や申請書類に添付したいのに、このままでは開く人の画面幅によってレイアウトが変わってしまいます。HTMLはウィンドウに合わせて形を変える前提の形式なので、保管や印刷、提出には向きません。PDFにしておけば、決まったページサイズの中で見た目が固定されます。

「HTMLからPDF」が受け付けるのは、パソコンに保存された .html または .htm ファイルです。Webアドレスを入力して変換するツールではありません。選んだファイルは暗号化された接続でPDForaの中継サーバーを経由してCloudConvertへ送られ、そこでレンダリングエンジンがページを組み立ててPDFに書き出します。できあがったPDFは元のファイル名のまま返され、変換サービス側のデータはそのあと削除されます。つまり変換はブラウザの中ではなくサーバーで行われ、ツールの画面にページサイズや余白の設定はありません。

つまずきやすいのは、HTMLファイルが外部のファイルを参照している場合です。普通のWebページは、画像、スタイルシート、フォントを別ファイルとして読み込んでいます。ところがアップロードされるのは選んだHTMLファイル1つだけなので、パソコン上の相対パスで指定された画像やCSSはサーバーからは見えません。きれいなPDFにするコツは、ほぼこの一点、変換する前にHTMLファイルだけで完結する形にしておくことです。

HTMLをPDFに変換する手順

  1. HTMLファイルが単体で完結しているか、画像やスタイルシートを完全なWebアドレス（https://...）で指定しているかを確認します（下の注意点を参照）。
  2. 「HTMLからPDF」を開き、.html または .htm ファイルを選びます。
  3. 「変換」をクリックし、ファイルのアップロードとサーバーでのレンダリングが終わるまで待ちます。
  4. PDFをダウンロードします。ファイル名は元の名前のまま、拡張子が .pdf になります。
  5. 画像や色、レイアウトが反映されているか、右端で内容が切れていないかを確認します。

このツールを使う場面

  • ネット通販の注文確認や領収書の画面をHTMLで保存してあるものを、経費精算や確定申告の控えとしてPDFにしておく。
  • 会計ソフトや業務システムがHTMLで書き出した月次レポートを、上司へのメール添付や保管用にPDFにする。
  • 社内のエンジニアが、HTMLテンプレートで作った請求書や修了証が印刷したときにどう見えるかをPDFで確かめる。
  • 1枚の長いHTMLページで提供されている機器のマニュアルを、通勤中にオフラインで読めるようにする。
  • 調べものの途中で保存した解説記事を、元のサイトが更新されても内容が変わらない形で手元に残す。
  • 配信したメールマガジンのHTMLを、配信記録としてPDFで保管する。

始める前に知っておきたいこと

  • 相対パスのリンクは切れます。HTMLに <img src="images/logo.png"> や <link href="style.css"> と書かれていても、そのファイルはパソコンに残ったままでサーバーからは見えません。その結果、PDFでは画像が欠け、スタイルの当たっていないテキストになります。https:// から始まる絶対アドレスを使うか、CSSは <style> ブロックに、画像はデータURIとして埋め込んでください。
  • 絶対Webアドレスで指定したリソースは、レンダリング時にサーバーが取得しに行くことがあるため、公開されている画像やスタイルシートは通常反映されます。ログインが必要なページ、社内ネットワーク、localhost上のものは反映されません。
  • URLを入力する欄はありません。公開中のページを変換するには、まず保存してください。ブラウザの「名前を付けてページを保存」で選べる「Webページ、単一ファイル（.mhtml）」は受け付けないため、「Webページ、HTMLのみ」で保存してください（相対パスの画像は欠ける前提です）。または、ブラウザの「印刷」→「PDFに保存」を使ってください。
  • 印刷用スタイルが適用されます。ページに @media print のCSSがあれば、変換時には通常そちらが使われるため、画面で見たときと比べてナビゲーションバーが消えたり色が変わったりすることがあります。改ページはCSSの break-before や break-inside で制御できます。
  • JavaScriptで生成されるコンテンツは確実に変換されるとは限りません。読み込み後にスクリプトで内容を取得するページは、中身のない枠だけのPDFになることがあります。完全に読み込まれてからページを保存するか、サーバー側でHTMLに内容を書き出しておいてください。
  • 固定幅1400ピクセルのデザインや横に長い表など、印刷ページより幅の広いレイアウトは、切れたり縮小されたりすることがあります。レスポンシブなレイアウトにするか、メインコンテンツに max-width を設定すると、たいてい解決します。

きれいに仕上げるコツ

  • 自作のテンプレートなら、CSSはすべて <head> 内の <style> ブロックにまとめましょう。スタイルの当たったPDFを得るには、これがいちばん確実な方法です。
  • 特定のページサイズや余白が必要なら、CSSに @page { size: A4; margin: 15mm; } を追加してください。
  • 表の行、カード、図には break-inside: avoid を指定すると、2ページにまたがって分断されません。
  • 画像サイズは適度に。5 MBのメイン画像をデータURIで埋め込めば、PDFもやはり5 MBになります。
  • まずブラウザの印刷プレビューでHTMLファイルを開いてみましょう。そこで崩れているなら、変換後のPDFもおそらく崩れます。

具体例：PTAの学年だよりをHTMLで作っている場合

ある中学校のPTA広報係は、ブラウザで編集できるテンプレートを使って学年だよりをHTMLで作っています。写真は同じフォルダの images/ に入れ、本文は幅1200ピクセル固定の2段組みです。これをそのまま変換したところ、写真はすべて空白になり、右側の段がページの外にはみ出して途中で切れていました。

原因は2つありました。写真はHTMLから images/ という相対パスで指定されていたため、サーバーには届いていませんでした。そして2段組みの固定幅が、A4の印刷幅より広すぎたのです。広報係は写真をPTAの公開ブログにアップロードして https:// から始まるアドレスに差し替え、本文の枠に max-width: 100% を指定し、<style> に @page { size: A4; margin: 12mm; } を加えました。

もう一つ気をつけたのが個人情報です。ファイルは外部の変換サービスを通るので、変換用のコピーでは表彰欄の生徒の氏名をクラス名だけに置き換えました。修正後に変換し直すと、写真の入ったA4・2ページのPDFになり、右端が切れることもなくなりました。テンプレート自体を直したので、次の号からは同じ手順で変換できます。

トラブルシューティング

PDFにスタイルがなく、ただのテキストになっている
スタイルシートが相対パスで参照されていて、アップロードされていません。CSSを <style> ブロックに埋め込むか、完全な https:// アドレスでリンクしてください。
画像が表示されない
ディスク上の画像を相対パスで参照していると、サーバーから取得できません。公開されている https:// のURLを使うか、画像をデータURIとして埋め込んでから、もう一度変換してください。
ページの右側が切れている
レイアウトがページより広い固定幅になっています。メインのコンテナと画像に max-width: 100% を指定するか、レイアウトを狭める印刷用スタイルシートを追加してください。
PDFが真っ白、またはほぼ空白
内容が読み込み後にJavaScriptで生成されているか、ファイルがリダイレクトだけのものだと考えられます。ページが完全に表示されてから保存するか、HTML自体に内容を含めてください。
文字が別のフォントで表示される
ローカルで参照していたWebフォントが使えませんでした。公開URLからフォントを読み込む、@font-face とデータURIで埋め込む、または一般的なフォント指定を使ってください。
ファイルを受け付けてもらえない
対応しているのは .html と .htm だけです。.mhtml や .webarchive で保存したファイルは、「HTMLのみ」で保存し直してください。

よくある質問

URLを貼り付けて、Webサイトをそのまま変換できますか？

できません。変換できるのはパソコンに保存したHTMLファイルです。先にページをHTMLとして保存するか、公開中のページであればブラウザの「印刷」から「PDFに保存」を選んでください。

HTMLファイルは外部に送信されますか？

送信されます。暗号化された接続で変換サービスに送られ、PDFに変換されたあとで削除されます。第三者のサーバーを通したくない個人情報が含まれるページは、変換しないか、その部分を消してから変換してください。

変換したら画像やデザインが消えてしまいました。なぜですか？

送られるのがHTMLファイル本体だけだからです。相対パスで参照している画像やCSSはパソコンに残ったままなので、https:// で始まる絶対アドレスに書き換えるか、HTMLの中に埋め込んでください。

用紙サイズや余白を指定する方法はありますか？

ツールの画面には設定がありません。HTML内のCSSで @page ルールを使って指定します。たとえば @page { size: A4; margin: 15mm; } のように書きます。

PDFにしたあとも、リンクはクリックできますか？

Webアドレスへのリンクは、たいていクリックできる状態で残ります。パソコン内のほかのファイルを指す相対リンクは、PDFの中ではどこにもつながりません。

JavaScriptで表示している部分も変換されますか？

一部は実行されることもありますが、あとから読み込まれる内容やクリックで表示される内容は抜け落ちることがよくあります。確実にしたいなら、最終的な内容がHTMLに書き込まれた状態で保存してください。

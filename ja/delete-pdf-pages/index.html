ページ削除

不要なページを削除して、すっきりした書類をダウンロードできます。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

スキャナーが吐き出した白紙のページ。重複したスライド。絶対に取引先へ渡してはいけない社内向けの価格表。PDFにはなぜか消したいページが1枚や2枚紛れ込むもので、PDForaの削除ツールはそれをきれいに取り除きます。「2, 5-7」のように削除したいページを入力すれば、それ以外がすべて入った新しいPDFをダウンロードできます。

多くのウェブツールと違い、PDForaがファイルを受け取ることはありません。ページの削除はお使いの端末のブラウザが行うため、氏名や金額、交渉の記録が詰まった書類は手元から動きません。ページの削除は多くの場合、共有すべきでない内容を取り除くための作業です。その過程で書類を第三者のサーバーに預けるのは、そもそも筋が通りません。

無料で、アカウントの作成も不要です。ダウンロードしたファイルに透かしは入らず、削除できるページ数にも、整理できる書類の数にも制限はありません。元のPDFはそのまま残るので、削除したページがやはり必要になっても安心です。

オンラインでPDFのページを削除する手順

  1. getpdfora.comのページ削除ツールを開きます。ログイン不要ですぐに利用できます。
  2. 整理したいPDFを選ぶか、ページ上に直接ドラッグします。
  3. 削除するページを入力します。「2, 5-7」のように、単独の番号と範囲を組み合わせて指定できます。
  4. 先に進む前に番号を確認しましょう。表紙のページ数を数え違えるのがよくある失敗です。
  5. 「削除」をクリックします。ブラウザがローカルで、そのページを除いたPDFを組み直します。
  6. 整理されたファイルをダウンロードします。指定しなかったページは、すべて元の順序で残っています。

When to use this tool

  • 両面スキャナーが実際のページの間に挟み込む白紙の裏面を取り除く。
  • 新しい見込み客に送る前に、パンフレットから古い価格ページを削除する。
  • 保存用に取っておく雑誌のPDFから、広告や購読申込カードのページを切り落とす。
  • 契約書から下書きや差し替え前のページを削除し、最終版だけが出回るようにする。
  • 生徒に配る前に、ワークシートのPDFから解答ページを外す。
  • レポートから定型の規約ページを削り、アップロードのサイズ制限に収める。

Tips for the best results

  • 連続したページをまとめて削除するときは、番号を1つずつ書くより範囲指定を使いましょう。「12-19」と書けば、8ページ分を手入力せずに済みます。
  • ページの削除は抽出の裏返しです。残すページが全体の半分に満たないなら、残したいページを抽出するほうが早く済みます。
  • 共有する前に結果を開いて目を通しましょう。ページ番号が紙面に印字されている場合はとくに重要です。
  • 長いファイルのあちこちから削除する場合は、整理ツールのサムネイル表示を使うと、番号ではなく見た目で削除するページを指定できます。
  • 整理後の版が役目を果たすまでは、手を加えていない元のファイルを残しておきましょう。

よくある質問

PDFから複数のページを一度に削除するにはどうすればよいですか。

カンマ区切りでまとめて入力してください。「2, 5-7, 11」と指定すれば、2ページ目、5〜7ページ目、11ページ目が一度の処理で削除されます。ページごとに操作を繰り返す必要はありません。

新しいファイルから、削除したページを復元できますか。

できません。それがこのツールの目的です。ダウンロードされるPDFはそれらのページを含まない形で作られるため、受け取った人が掘り出すことはできません。元のファイルには全ページが残っているので、手元では何も失われません。

機微な書類のページをオンラインで削除しても安全ですか。

PDForaなら安全です。ファイルがブラウザの外に出ないからです。処理はローカルで行われるため、社外秘のページを削除するために、その社外秘の書類をどこかにアップロードする必要はありません。

ページを削除すると、リンクやしおりが壊れますか。

残ったページの内容と書式はそのまま保たれます。削除されたページを指していたしおりや内部リンクは、リンク先を失います。これはページを削除するツールであれば共通の挙動です。

ソフトのインストールや登録は必要ですか。

どちらも不要です。パソコンでもスマートフォンでも、最近のブラウザで動作し、無料で、アカウントも出力への透かしもありません。

とても大きなPDFも扱えますか。

はい。サーバーの割り当てではなく、お使いの端末の性能の範囲で処理できます。作業を行うのはブラウザなので、数百ページのファイルでもたいていの機器で短時間で処理できますが、極端に大きなスキャン書類にはより多くのメモリが必要です。

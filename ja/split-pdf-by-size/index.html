サイズで分割

大きなPDFを、それぞれが指定した上限サイズに収まる小さなファイルに分割します。アップロードの容量制限対策に最適です。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

「添付ファイルのサイズが大きすぎます」。Gmailの上限は25MB、多くの企業のメールサーバーは10MB、行政のアップロード用サイトには5MB以下というところもあります。スキャンしたファイルがその線を越えてしまったとき、PDForaの「サイズで分割」ツールが、指定したメガバイトの上限に各パーツが収まるよう、順番どおりに分割します。10MBと設定すれば、48MBのスキャンは送信可能な5つのファイルになります。

分割はサーバーではなくブラウザ内で行われます。PDFがアップロードされることはなく、容量オーバーのファイルが住宅ローンの申込書や患者の記録、訴訟の証拠資料であるときに大きな意味を持ちます。PDForaはアカウント不要で無料、出力にウォーターマークもなく、分割するファイルの数や頻度にも制限はありません。

このツールはページを元の順序のまま保ち、指定した上限を超えない範囲で、各パーツにできるだけ多くのページを詰め込みます。どこで区切るかを考える必要はありません。数値を決めれば、計算はツールが引き受けます。

PDFをファイルサイズで分割する方法

  1. ブラウザでgetpdfora.comの「サイズで分割」ツールを開きます。
  2. 大きなPDFをページにドラッグするか、端末から選んで追加します。アップロードなしでローカルに読み込まれます。
  3. 各パーツの上限サイズをMB単位で入力します。たとえば、一般的な企業メールの制限をクリアするなら10と入力します。
  4. 「分割」をクリックします。ツールが処理しながらページのサイズを測り、上限を超える直前で新しいパーツを開始します。
  5. 生成されたパーツの一覧と、それぞれのサイズを確認します。
  6. 分割されたファイルをダウンロードします。受け取った人が順番どおりに読めるよう、通し番号が付いています。

When to use this tool

  • 10MBを超えるものを受け付けないメールサーバー経由で、60MBのスキャンした不動産関連ファイルを送る。
  • 1ファイルあたり5MBの上限があるビザや行政のサイトに、添付書類をアップロードする。
  • 1ファイルあたりの容量制限が厳しい大学のシステムに、論文の付録を提出する。
  • 大きな添付ファイルを黙って破棄してしまうメールゲートウェイを使っている相手方の弁護士に、開示資料を送る。
  • 回線の遅い環境でも中断・再開しやすいよう、高解像度の商品カタログを小さく分けて共有する。
  • 容量オーバーの保険金請求書類一式を、保険会社のWebフォームのアップロード上限内に収める。

Tips for the best results

  • 目標値は公式の上限より少し低めに設定しましょう。メールのエンコードで3分の1ほどのオーバーヘッドが加わるため、Gmailの25MB制限をクリアするには18MB程度を狙ってください。
  • 1つのパーツだけがまだ大きすぎる場合は、そのページ単体で上限を超えているのが原因です。たいていはページ全面の写真スキャンです。先にPDFを圧縮してから分割してください。
  • 分割前に圧縮しておくと、二重に得をすることがよくあります。パーツの数が減ることもあれば、そもそも分割が不要になることもあります。
  • 複数のパーツは、1通のメールにまとめて添付するのではなく、別々のメールで送りましょう。制限はメッセージ全体に適用されるのが普通だからです。
  • 受け取る人に、いくつのパーツが届くかを伝えておきましょう。そうすれば、締め切り間際ではなくその場で欠落に気づけます。

よくある質問

PDFをサイズで分割するとは、実際にはどういう処理ですか。

ツールはファイルサイズの累計を追跡しながらページを1枚ずつパーツに追加し、指定したMBの上限を超える直前でそのパーツを閉じます。ページが途中で切られることはなく、各パーツは連続した完全なページからなる正しいPDFになります。

各パーツはちょうど指定したサイズになりますか。

いいえ。各パーツは指定した上限以下になり、通常は少し下回ります。ページごとにサイズが異なるため、次のページを加えると上限を超えてしまう時点で追加が止まるからです。

大きなファイルは御社のサーバーにアップロードされますか。

いいえ。分割はすべてブラウザ内でローカルに実行されるため、数百MBのスキャンでも端末から出ることはありません。速度は端末の性能によりますが、ほとんどのファイルは数秒で分割されます。

そもそもPDFがこんなに大きいのはなぜですか。

スキャンした文書は各ページを画像として保存し、しかも多くの場合300 DPI以上の解像度なので、容量がすぐにふくらみます。分割前にPDF圧縮ツールにかけると大幅に小さくなり、必要なパーツの数も減らせます。

受け取った人はパーツを1つのファイルに戻せますか。

はい。各パーツは元のページ順と通し番号付きの名前を保っているので、PDForaのものを含めどの結合ツールでも、数クリックで元の完全な文書に組み立て直せます。

メール添付の上限として妥当なサイズはどれくらいですか。

GmailとYahooは1通あたり25MB、Outlook.comは20MB、企業のサーバーでは10MBしか許可されていないことも少なくありません。エンコードのオーバーヘッドも考えると、1パーツあたり8〜10MBにしておけば、ほぼすべてのメールシステムを問題なく通過できます。

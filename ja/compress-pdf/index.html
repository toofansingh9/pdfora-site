PDF圧縮

画質を実用的な水準に保ちながらPDFのファイルサイズを小さくします。メール添付に最適です。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

40MBのPDFは厄介です。メールサービスには送信を弾かれ、求人サイトには受け付けてもらえず、行政の申請フォームでは説明もなく2MBで打ち切られます。PDForaの圧縮ツールは、ブラウザ内でPDFのファイルサイズを小さくします。圧縮前後のサイズと削減率まで表示されるので、目的の場所にアップロードできるかどうかがその場で分かります。

圧縮レベルは3段階です。「低」は元の品質にできるだけ近づけつつ、サイズを控えめに減らします。「推奨」はサイズと鮮明さのバランスをとったもので、ほとんどの書類にはこれが適しています。「強」は可能な限り小さくするので、画像が多少やわらかくなっても差し支えないスキャン書類に向いています。レベルを選んで圧縮し、結果を見比べれば完了です。

処理はすべてローカルで行われます。PDFはお使いのブラウザが処理し、サーバーにアップロードされることはありません。契約書、診療記録、銀行明細を圧縮するときには、これが重要な意味を持ちます。ツールは無料で、アカウントなしで使え、透かしも入らず、1日に処理できるファイル数の上限もありません。

オンラインでPDFを圧縮する手順

  1. パソコンでもスマートフォンでも、最近のブラウザでPDForaのPDF圧縮ツールを開きます。
  2. PDFをドロップ領域にドラッグするか、クリックして端末内のファイルを選びます。
  3. 圧縮レベルを選びます。品質重視なら「低」、バランス重視なら「推奨」、最小サイズを狙うなら「強」です。
  4. 「圧縮」をクリックし、ブラウザがローカルでページを描き直すのを数秒待ちます。
  5. 結果パネルで、元のサイズ、圧縮後のサイズ、削減率を確認します。
  6. 圧縮したPDFをダウンロードします。まだ大きすぎる場合は、「強」の設定でもう一度実行してください。

When to use this tool

  • スキャンした賃貸借契約書を25MBから2MB未満に縮め、ビザ申請や行政のポータルでアップロードを受け付けてもらう。
  • デザインのポートフォリオを、GmailやOutlookの10MBという添付上限に収める。
  • ファイルサイズの制限が厳しい社内システムに経費精算を提出する前に、スマートフォンでスキャンした領収書の束を軽くする。
  • 講義ノートやスライドの配布資料を圧縮し、モバイル回線の遅い学生でもすぐダウンロードできるようにする。
  • 製品カタログを軽くしてからサイトに掲載し、ページの表示を速くして訪問者の通信量も抑える。
  • 署名済みの契約書を、WhatsAppで送っても弾かれないサイズにする。

Tips for the best results

  • スキャンしたPDFがもっとも小さくなります。ツールは各ページを描き直すため、300 DPIの重いスキャンは70〜90パーセント削減できることもありますが、もともと軽いテキスト中心のPDFはわずかしか減りません。
  • まず「推奨」から試しましょう。それでも上限を超える場合にだけ「強」に切り替え、正式な提出先に送る前に小さな文字のあるページを確認してください。
  • 元のファイルは残しておきましょう。圧縮は元に戻せないので、高品質の控えを保管し、共有するのは圧縮版にします。
  • 大きな書類から数ページだけ必要な場合は、先に分割してから圧縮しましょう。ページ数が少なければ、圧縮を始める前からファイルが小さく済みます。
  • 50ページを超える書類は、スマートフォンよりノートパソコンのほうが速いのが普通です。処理はお使いの機器の性能で動くためです。

よくある質問

ここでのPDF圧縮は本当に無料ですか。

はい。支払いの手続きも、登録も、出力への透かしも、1日あたりのファイル数制限もありません。ツールはブラウザ内で動くため、利用者に転嫁するサーバー費用が発生しません。

圧縮するとPDFの画質は落ちますか。

画質がある程度落ちるのは圧縮の性質上避けられませんが、程度は選んだレベル次第です。「低」は元とほとんど見分けがつかず、「推奨」は閲覧にも印刷にも十分きれいで、「強」は鮮明さを目に見えて犠牲にして最小のファイルを作ります。

圧縮後もテキストを選択してコピーできますか。

いいえ。ここは正直にお伝えすべき割り切りです。大幅にサイズを減らすため、ツールは全ページを画像として描き直します。そのため選択できたテキストはページ画像の一部になります。テキストを選択できる状態で残したい場合は、圧縮版とは別に元のファイルを保管してください。

どのくらい小さくなりますか。

内容によって変わります。スキャン書類や画像の多いファイルは60〜90パーセント小さくなることが多い一方、ほぼ文字だけのPDFでは削減幅は小さめです。ダウンロードの前に、結果画面で実際の削減率を確認できます。

書類はサーバーにアップロードされますか。

いいえ。圧縮はすべてブラウザ内で、お使いの端末のプロセッサを使って実行されます。ファイルがパソコンやスマートフォンから出ることはないため、社外秘の契約書、身分証のスキャン、金融関係の書類にも安心して使えます。

ファイルサイズの上限はありますか。

処理はお使いの端末で行われるため、当社側で設けている厳密な上限はありません。数百メガバイトに及ぶ非常に大きなファイルは、利用できるメモリ次第です。100MB程度までのPDFなら、一般的なノートパソコンで問題なく圧縮できます。

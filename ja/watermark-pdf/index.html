ウォーターマーク

半透明のグレーの文字を1行、水平または45度の斜めで、PDFの全ページに入れます。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。

身分証のコピーや契約書の下書きを送るとき、「念のため透かしを入れておこう」と考える人は多いはずです。ただ、最初に押さえておきたいのは、透かしは鍵ではなくラベルだということです。ファイルを開いた人に、それが下書きなのか、確認用なのか、社外秘なのかを伝え、出回ったスクリーンショットや印刷物がどこから来たのかをたどれるようにする。透かしの役目はそこまでで、コピーや編集、透かしそのものの削除を防ぐ力はありません。この線引きを知っておけば、本来はパスワードや墨消しが必要な場面で、透かしだけに頼ってしまう失敗を避けられます。

PDForaのウォーターマークは、既存の内容の上に新しい層を重ねる形で、全ページに文字を描き込みます。フォントは組み込みのHelvetica Bold、色は中間のグレーで、指定したサイズと不透明度（初期値は50ポイントと0.3）で各ページの中央付近に置かれます。［斜め］にチェックを入れれば45度に傾き、外せば水平になります。元のページの内容は画像にも変換されず、手も加えられないので、下の文字は選択できるままで、ファイルサイズも数KB増えるだけです。

処理は文書をブラウザのメモリに置いたままpdf-libライブラリで行われるため、まだ外に出せない契約書の草案や未公開の報告書にも、誰かに送ることなく透かしを入れられます。結果は「元の名前-watermarked.pdf」としてダウンロードされ、元のファイルはそのまま残ります。

PDFに文字の透かしを入れる方法

  1. 「ウォーターマーク」を開き、PDFを1つ選びます。一度に扱えるのは1ファイルです。
  2. 透かしの文字を入力します。DRAFT、COPY、SAMPLEのような短い単語がいちばん読みやすく、長い文は小さくなりすぎるか、ページからはみ出します。
  3. フォントサイズと不透明度を設定します。下のページを読める状態にしておくなら、不透明度はおよそ0.15〜0.35にしましょう。
  4. 定番の45度の透かしなら［斜め］にチェックを入れたまま、中央を横切る水平の線にするならチェックを外します。
  5. ［透かしを追加］をクリックし、「元の名前-watermarked.pdf」をダウンロードして、1ページ目だけでなく、いちばん内容が詰まったページも確認します。

このツールを使う場面

  • 賃貸の入居申込や携帯電話の契約で求められた身分証や公共料金の領収書のコピーに、FOR RENTAL APPLICATION 2026-10 のように用途と日付を入れ、ほかの目的に使い回されにくくする。
  • 不動産の査定や見積もりを複数の会社に依頼するとき、送る資料に FOR VALUATION ONLY と入れておく。
  • 取引先に意見を聞くために送る契約書の草案に DRAFT と入れ、古い版に署名されたり保管されたりするのを防ぐ。
  • 入金前のクライアントに見せるデザインの校正やサンプルに、SAMPLE や PROOF と入れる。
  • 取締役会や委員会で回覧する社内資料に、取り扱い注意の目印として CONFIDENTIAL と入れる。
  • 保管している古い規程や価格表に SUPERSEDED と入れ、現行版と取り違えられないようにする。

始める前に知っておきたいこと

  • 透かしは、別の描画層にある普通のPDFテキストです。PDF編集ソフトがあれば誰でも選択して削除でき、コピー＆ペーストや検索結果にも出てくることがよくあります。コピーを本当に防ぎたいなら、パスワードを使う、文書を画像に平坦化する、またはその両方を行ってください。
  • 対応しているのは文字の透かしだけです。画像やロゴ、ページ全体への敷き詰め、色の選択はありません。透かしは常に中間グレーのHelvetica Boldです。
  • 組み込みのHelveticaフォントが対応しているのは、基本的な欧文の文字だけです。日本語（ひらがな・カタカナ・漢字）、中国語、ヒンディー語、アラビア語、キリル文字や特殊な記号はエンコードできず、ツールはエラーで止まります。ラテン文字、数字、一般的な記号だけを使ってください。
  • 配置は各ページの全体サイズから計算されます。変わったトリミング範囲があるページや、回転した状態で保存されているページ（ビューアーで回したスキャンによくあります）では、透かしが中央からずれたり、横向きになったりすることがあります。
  • 斜めモードでは、文字は書き出しの位置を軸に回転し、その位置はページ中央より左に置かれます。そのため、線はきっちり中央に来るのではなく、中央から右上に向かって上がっていきます。小さなページに大きなフォントを使うと、末尾が切れることがあります。
  • 透かしはすべての内容の一番上に描かれます。暗い写真やグラフのページではグレーの透かしが見えなくなることがあり、淡いページで不透明度を高くすると内容が読みにくくなります。

きれいに仕上げるコツ

  • まず全面写真や細かい表のような極端なページを含むコピーで試し、それから不透明度を決めましょう。
  • ページに合ったサイズを選びましょう。目安として、7文字の単語を50ポイントにすると幅は約3インチ（約7.6cm）で、A4やLetterならちょうどよい大きさです。A5やレシートサイズのページなら半分にしてください。
  • 編集されても透かしを残したいなら、透かしを入れたファイルを平坦化しましょう（「PDFからJPG」で画像にし、「JPG / PNGからPDF」でPDFに戻す）。透かしがページの画像の一部になります。ただし、テキストは選択できなくなります。
  • SHARED WITH K. SATO 22/10 のように、日付や渡した相手の名前を文字に入れておけば、流出したコピーから誰に渡したものかがわかります。
  • 透かしは最後に入れましょう。結合、並べ替え、圧縮がまだなら先に済ませてください。透かしの後の圧縮は問題ありませんが、透かしが重なった状態でページ内容をあとから編集するのは面倒です。

例：マンション売却の査定を3社に依頼する

住み替えを考えている松井さんは、自宅マンションの査定を不動産会社3社に頼むことにしました。送るのは、間取り図、管理規約の抜粋、リフォーム履歴、室内写真をまとめた14ページのPDFです。査定のためだけの資料が、知らないうちに販売用の広告などに使われるのは避けたいと考え、ウォーターマークで目印を入れることにしました。

最初に「査定用」と日本語で入力したところ、ツールはエラーで止まりました。組み込みのHelveticaフォントは基本的な欧文の文字しか扱えないためです。松井さんは文字を FOR VALUATION ONLY 2026-10 に変え、40ポイント、不透明度0.25、斜めありで入れ直しました。間取り図や規約のページでは、グレーの斜めの文字がちょうどよい濃さで入りました。ところが、夜に撮ったリビングの写真のページでは、暗い背景に紛れて透かしがほとんど見えません。不透明度を0.4に上げて試したところ、写真では見えるようになったものの、今度は規約のページの本文が読みにくくなりました。最終的に0.3に落ち着き、どのページでも透かしが判別でき、本文も読める状態になりました。

会社ごとに区別したかったので、3回に分けて、文字の末尾に会社名の頭文字を加えたものをそれぞれ作りました。透かしはただの文字の層で、編集ソフトがあれば消せることも松井さんは理解しています。それでも、どの資料をどの会社に渡したのかがひと目でわかり、何の目的で渡したかも伝わる。透かしに期待できるのはその程度で、それで十分だという判断です。透かしのない元ファイルは、手元にそのまま残しています。

トラブルシューティング

［透かしを追加］をクリックするとすぐエラーになる
文字に、組み込みフォントでエンコードできない文字（日本語などラテン文字以外の文字、絵文字、特殊な記号）が含まれている可能性がほぼ確実です。ラテン文字と数字だけで書き直してください。
透かしがページの端からはみ出す
ページに対してフォントサイズが大きすぎるか、文字が長すぎます。サイズを下げる、文字を短くする、または［斜め］のチェックを外してください。水平ならページの幅いっぱいを使えます。
一部のページで透かしが横向き、または隅に寄る
それらのページは回転やトリミング範囲付きで保存されています。「PDF回転」で向きを直すか、「PDFトリミング」や「PDFリサイズ」でページを整えてから、直したファイルにもう一度透かしを入れてください。
写真のページで透かしが見えない
不透明度の低い中間グレーは、暗い画像や情報量の多い画像では見えなくなります。その文書では不透明度を0.45程度まで上げるか、先にファイルを分割して文字のページだけに透かしを入れてください。
誰かに透かしを消された
文字の透かしであれば、どれでも起こりうることです。ファイルを再利用されたくないなら、透かしを入れた後に画像に平坦化する、「PDF保護」でパスワードを付ける、または低解像度版だけを共有してください。
出力が文字化けする、または白紙になる
元ファイルが暗号化されていた可能性が高いです。暗号化されたファイルを開けることはありますが、正しく再暗号化はできません。「PDFロック解除」かファイルを作ったアプリで保護を外し、保護なしのコピーに透かしを入れてから、必要なら「PDF保護」でもう一度保護してください。

よくある質問

会社のロゴやハンコの画像を透かしにできますか？

このツールではできません。入れられるのは文字だけです。ロゴを入れたい場合は、ページごとに画像を追加できる「PDF編集」を使ってください。

透かしを入れておけば、PDFを勝手に使われる心配はなくなりますか？

なくなりません。透かしは普通のテキストとして描かれた目に見えるラベルなので、PDF編集ソフトで選択して削除できます。内容の再利用を本当に防ぎたいなら、平坦化やパスワードと組み合わせてください。

透かしを入れたあとも文字検索はできますか？

できます。元のページの内容には手を加えず、画像化もしないので、テキストは選択も検索もできます。透かしの文字そのものが検索結果に出てくることもあります。

特定のページだけに透かしを入れることはできますか？

このツールは全ページに入れます。入れたいページだけを分割して取り出し、透かしを入れてから、元の順番に結合し直してください。

斜めの透かしが真ん中からずれて見えるのはなぜですか？

文字が中心ではなく書き出しの位置を軸にして回転するため、中央付近から右上に向かって伸びる形になります。文字を短くするかサイズを小さくすると、ページの内側に収まりやすくなります。

料金はかかりますか？登録は必要ですか？

どちらも不要です。無料で使え、会員登録もいりません。PDForaのロゴなどが勝手に入ることもありません。

ウォーターマーク

好きな文字のウォーターマークを追加できます。斜めの角度、サイズ、濃さも自由に調整できます。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

何かをインストールすることも、見知らぬ相手のサーバーに文書を預けることもなく、PDFにウォーターマークを追加できます。PDForaは、指定した文字（DRAFT、CONFIDENTIAL、会社名、クライアントの参照番号など）を文書のすべてのページに重ねます。処理はすべてブラウザ内のローカル処理で完結するため、ファイルがパソコンから出ることはありません。ウォーターマークを入れたいPDFは、まさに外に出回ってほしくない種類の文書であることが多いので、この点は重要です。

ウォーターマークの見た目は自由に調整できます。好きなテキストを入力し、ページに合わせて文字サイズを変え、不透明度を0.1のかすかな影から、はっきりした完全な不透明の刻印まで自在に設定できます。45度の斜め表示をオンにすれば、昔ながらのDRAFTスタンプのように、文字がページを斜めに横切ります。マークはすべてのページに一貫して適用されるので、200ページの契約書でも2ページの社内メモと同じく数秒で終わります。

PDForaは無料で、登録もファイル数の制限もありません。はっきり言っておく価値があります。多くのウォーターマークツールは、出力に自社のブランド表示を追加します。当社は決してそれをしません。仕上がったPDFに入るウォーターマークは、あなたが選んだものだけです。1日に1回でも100回でも、数えられることも制限されることもありません。

PDFにウォーターマークをオンラインで追加する方法

  1. getpdfora.comでウォーターマークツールを開き、PDFを選ぶか、ファイルをページに直接ドラッグします。
  2. すべてのページに重ねたいウォーターマークのテキストを入力します。たとえばCONFIDENTIAL、DRAFT、社名などです。
  3. 下の内容が埋もれず、かつ読み取れる大きさになるよう文字サイズを設定します。
  4. 不透明度のスライダーを0から1の間で調整します。0.2〜0.3あたりにすると、本文が読める控えめなマークになります。
  5. 文字をページに45度の角度で入れたい場合は斜めのオプションにチェックを入れます。水平の刻印にしたい場合はオフのままにします。
  6. クリックして適用し、ウォーターマーク入りのPDFをダウンロードします。すべての処理はブラウザ内でローカルに行われます。

When to use this tool

  • 契約書を相手方に送る前にDRAFTを重ね、最終版ではないものに署名されるのを防ぐ。
  • 社内レポートを直属のチームの外に回覧する前に、CONFIDENTIALと表示する。
  • デザインの校正版や提案書に事務所やスタジオの名前を入れ、こっそり他所で使われないようにする。
  • 電子書籍の見本の章やプレビュー版にNOT FOR DISTRIBUTIONと表示する。
  • 請求書や明細書にPAIDやCOPYと表示し、原本と複製が混同されないようにする。
  • 学生向けの配布資料や試験問題に科目コードと学期を入れ、古い版をすぐ見分けられるようにする。

Tips for the best results

  • 文書をしっかり読む必要がある場合は、不透明度を0.15〜0.3と低めに保ちましょう。0.6以上は、コピーとして使えないようにしたいページのために取っておきます。
  • 45度の斜め表示は、一行のテキストでページのより広い範囲を覆うため、切り取って消すのが難しくなります。
  • 小さな文字の長い一文よりも、大きな文字の短いテキストのほうが読み取りやすくなります。長い免責文言より「DRAFT — v3」です。
  • 原本ではなくコピーにウォーターマークを入れましょう。このツールが元のファイルに触れることはありませんが、きれいなマスターを残しておくのはよい習慣です。
  • 法務やクライアント向けの文書では、ウォーターマークに受取人の名前を入れておきましょう。流出したコピーが、それ自体で出所を示してくれます。

よくある質問

ウォーターマークを追加するとPDFはアップロードされますか。

いいえ。このツールはローカル処理により完全にブラウザ内で動作します。ファイルはご自身の端末で開かれ、加工され、保存されます。PDForaのサーバーには何も送信されません。

PDForaが独自のウォーターマークをファイルに入れることはありますか。

決してありません。多くの無料ツールとは違い、当社が出力にブランド表示を入れることはありません。仕上がったPDFに入るウォーターマークは、ご自身で入力したテキストだけです。

ウォーターマークの透明度は調整できますか。

はい。不透明度は0から1まで調整できます。0.2のような低い値なら背景に薄く入るマークになり、1にすると完全に不透明なはっきりした文字になります。

ウォーターマークはすべてのページに入りますか。

入ります。ファイルが2ページでも数百ページでも、入力したテキストが文書の各ページに自動的に重ねられます。

ウォーターマークを斜めに配置できますか。

はい。テキストを45度回転させるオプションがあり、角から角へと走る定番のDRAFT表示になります。水平の刻印にしたい場合は、チェックを外したままにしてください。

ファイルサイズや数に制限はありますか。

固定の上限も1日あたりの割り当てもありません。無料かつ無制限で、登録も不要です。処理がローカルで行われるため、非常に大きなファイルの限界はお使いの端末のメモリだけです。

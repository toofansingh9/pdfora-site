PDFからWord

PDFを編集可能なWord文書に戻します。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

PDFは読むために作られた形式で、書き直すためのものではありません。取引先から届いた契約書の条項を3か所直したいときや、元データが何年も前に消えた古いレポートが出てきたとき、全部を打ち直すのは何より避けたい作業です。PDForaのPDFからWordへの変換ツールは、PDFを編集可能なDOCXファイルに変換し、レイアウト、フォント、表、画像をできる限り元に近い形で保ちます。

変換はPDForaの安全なクラウドエンジン上で実行されます。ファイルは暗号化された通信で送られ、サーバー上で変換され、処理が終わると自動的に削除されます。どこかに蓄積されたり、再利用されたりすることはありません。PDForaのツールの多くはブラウザ内で完結しますが、PDFからDOCXのような形式変換にはより重い処理が必要なため、このツールは暗号化された経路を使います。いずれにせよ、書類はあなたのものであり続けます。

すべて無料です。登録も、透かしも、有料プランへ誘導するためのページ数制限もありません。PDFをアップロードしてWord文書をダウンロードすれば、すぐ編集に戻れます。1点だけ先にお伝えします。スキャンしたPDFは文字の写真なので、先にOCRを実行しない限り画像として変換されます。

オンラインでPDFをWordに変換する手順

  1. getpdfora.comのPDFからWordへの変換ツールを開きます。アカウントもインストールも不要です。
  2. アップロード領域をクリックしてPDFを選ぶか、ファイルをページ上に直接ドラッグします。
  3. 安全な変換エンジンが、フォント、表、レイアウトをできる限り再現しながら、書類を編集可能なDOCXとして組み直すのを数秒待ちます。
  4. 「ダウンロード」をクリックし、Wordファイルを端末に保存します。
  5. Microsoft Word、Googleドキュメント、LibreOfficeなどで開いて編集を始めます。
  6. 一度ざっと目を通しましょう。要素が詰まったレイアウトは、少し手直しが必要になることがあります。

When to use this tool

  • 元のWordファイルがとうに失われ、署名済みのPDFしか残っていない賃貸借契約書やサービス契約書を更新する。
  • 研究論文から引用や段落を取り出し、引用を打ち直さずに文献レビューに取り込む。
  • 白紙から作り直すのではなく、昨年の企画書を今年の提案に作り替える。
  • デザイナーが編集不可のPDFで納品したメニュー、チラシ、価格表の誤字を直す。
  • PDFのマニュアルをまずDOCXに変換し、翻訳ツールや編集者が実際のテキストとして扱えるようにする。
  • 特定の求人に合わせて調整する必要があるとき、PDFの履歴書を編集可能な文書に戻す。

Tips for the best results

  • PDFがスキャンやページの写真である場合は、先にOCRツールにかけてください。そうしないとDOCXの中身は編集できる文字ではなく、文字の画像になります。
  • Arial、Calibri、Times New Romanのような一般的なフォントで作られた文書がもっとも忠実に変換されます。珍しい装飾フォントは、近いフォントに置き換えられることがあります。
  • 多段組みのニュースレターや作り込まれたデザインは、変換後にテキストボックスを1分ほど整えるつもりでいると、うまく仕上がります。
  • 変換後は表を確認しましょう。たいていはそのまま再現されますが、結合セルがずれることがあり、Wordで簡単に直せます。
  • 巨大なファイルを変換しますか。必要なページだけを先に分割しておきましょう。小さいファイルのほうが変換が速く、後の手直しも楽になります。

よくある質問

変換したWord文書はPDFとまったく同じ見た目になりますか。

単純な文書や、ある程度の書式設定にとどまる文書なら、ほぼ同一の仕上がりになるのが普通です。多段組み、重なり合う図版、珍しいフォントを含む複雑なレイアウトは、変換後に軽い手直しが必要になることがあります。エンジンはPDFの内部構造が許す範囲で、できる限り構造を保ちます。

スキャンしたPDFを編集可能なWordに変換できますか。

そのままではできません。スキャンしたPDFは実質的にページの写真なので、編集可能な文字ではなく画像として変換されます。まずスキャンにOCRをかけ、そのPDFをDOCXに変換してください。

PDFからWordへの変換は本当に無料ですか。

はい。登録も、出力への透かしも、試用回数のカウントもありません。必要なだけ何度でも変換できます。

変換後、ファイルはどうなりますか。

このツールはPDForaの安全なクラウドエンジンを使います。PDFは暗号化された通信で送信され、変換され、処理後に自動的に削除されます。長期間保存されることも、共有されることもありません。

変換したDOCXファイルはどのソフトで開けますか。

最近のワープロソフトであれば開けます。Microsoft Word、Googleドキュメント、LibreOffice Writer、Apple PagesはいずれもDOCXに対応しています。編集も書式変更も、保存し直すのも自由です。

表や画像は変換後も残りますか。

はい。表はWordの実際の表として組み直され、画像は元の位置に埋め込まれます。結合セルを多用した非常に複雑な表は微調整が必要になることもありますが、データそのものは引き継がれます。

入力と署名

PDFのフォームに回答を入力し、署名を手書きまたは文字入力で作ってページに配置し、署名済みのコピーをダウンロードできます。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

「署名して今日中に返送してください」とPDFが届いたのに、家にプリンターがない。コンビニまで印刷しに行き、書いて、スキャンして……と考えるだけで気が重くなります。「入力と署名」はそんなときのためのツールです。PDFを開いて空欄に回答を打ち込み、マウスや指、タッチペンで書いた署名（または筆記体フォントで入力した名前）を置けば、ファイル名の末尾が -signed.pdf の新しいファイルとしてダウンロードできます。

ただし、ここで作られる署名の性質は正しく理解しておきましょう。これはページの上に置いた署名の画像で、紙に印刷して署名し、スキャンして送り返すのと同じことをデジタルで行っているにすぎません。証明書を使った暗号技術による電子署名ではないので、PDFリーダーに「署名者」のパネルが表示されることもありません。日常の書類の多くは相手もこれで十分と考えていますが、証明書ベースの電子署名や認定された電子署名をはっきり求められている書類には使えません。

仕組みは「PDF編集」と同じレイヤーエディターです。ページは PDF.js で描画され、回答と署名はその上のオーバーレイに置かれます。保存するとページごとのオーバーレイが1枚の画像になり、pdf-lib が元のページの上に重ねます。下にあるフォームの印刷内容は変わりません。

PDFに入力して署名する手順

  1. 「入力と署名」を開き、PDFをドロップします。すべてのページが上から順に画面に表示されます。
  2. 「テキスト」を選び、空欄に収まるサイズ（ほとんどのフォームは10〜12が目安）に設定してから、空欄の線の書き始めの位置をクリックして入力します。各項目で繰り返し、ボックスをドラッグして位置を微調整します。
  3. 「署名」を選び、署名したい場所をクリックします。開いたウィンドウでパッドに手書きするか、「入力」に切り替えて名前を入力し、「挿入」を押します。
  4. 署名を線の上までドラッグし、角のハンドルでサイズを調整します。横に別の「テキスト」ボックスで日付を書き添えます。
  5. 「PDFを保存」をクリックし、ダウンロードした -signed.pdf を開いて、返送する前に全ページを確認します。

このツールを使う場面

  • 修学旅行、遠足、ホームページへの写真掲載などについて、学校からPDFで届く同意書や確認書。
  • 最終ページに入居者の署名と日付が必要な、賃貸の更新書類や入居時のチェックリスト。
  • 取引先から署名を頼まれる、フリーランスの業務委託契約書や秘密保持契約書。
  • 入力欄がなく記入用の線だけが引かれた平らなPDFで届く、銀行や勤務先の人事関係の書類。
  • メールで返す前にさっと署名を入れたい納品書や勤務表。
  • スポーツ少年団、習い事、地域のサークルなどの入会申込書。

始める前に知っておきたいこと

  • このツールは本物のフォームフィールドには入力しません。PDFにすでに操作できる入力欄がある（普通のリーダーでクリックして入力できる）場合は、PDFリーダーでその欄に入力してください。「入力と署名」を使うと、その上に文字を重ねて描くだけになります。
  • 署名は画像であり、証明書ベースの電子署名ではありません。それだけでは誰が配置したかの証明にはならず、ファイルを持っている人なら誰でもそれが画像だと分かります。
  • 手書きの署名は、420 × 170ピクセルのパッドに濃紺のインクで描かれます。入力した署名は Segoe Script や Brush Script などのシステムの筆記体フォントで描かれるため、Windows と Mac では見た目が異なります。
  • 署名は最大180ピクセル幅で挿入され、拡大することもできますが、ビットマップ画像なので、それを大きく超えて引き伸ばすとぼやけます。
  • 入力した内容はすべて保存時に画像として統合されるため、回答は検索できず、完成したファイルからコピーすることもできません。
  • 署名はどこにも保存されません。タブを閉じれば消えるので、次回はもう一度描く必要があります。その代わり、同じパソコンを使う他の人に使い回される心配もありません。

きれいに仕上げるコツ

  • タッチスクリーンがあるなら、タッチペンや指でゆっくり署名を描きましょう。マウスでも描けますが、線が震えがちです。
  • クリックする前に文字サイズを選びましょう。各ボックスは作成した時点で選ばれていたサイズと色を保ちます。
  • 回答の文字色は青か黒にしましょう。明るい色は、受け取った人がグレースケールで印刷すると見えなくなることがあります。
  • 文字は印刷された線の上ぴったりではなく、少し上に置くと揃います。保存後の文字は、多くの人が思うよりわずかに下に来ます。
  • 署名していない元のPDFのコピーを残しておきましょう。保存後に間違いに気づいたら、間違いを隠すよりきれいなファイルからやり直すほうが早く済みます。

具体例：フリーランスのデザイナーが秘密保持契約書に署名する

フリーランスでWebデザインをしている石田さんのもとに、新しい取引先から3ページの秘密保持契約書がPDFで届きました。最終ページに住所と氏名を書く線、その下に署名欄と日付欄があります。PDFリーダーで線をクリックしても何も起きないので、入力欄のない平らなPDFです。取引先は「印刷して署名し、スキャンして返送してください」と書いていましたが、石田さんの家にはプリンターがありません。

石田さんは「入力と署名」で「テキスト」を選び、サイズを10にして、住所と氏名の線のすぐ上をクリックして入力しました。次に「署名」を選び、iPadとタッチペンでパッドにゆっくり署名して「挿入」を押し、署名欄までドラッグして、印刷された「署名」の文字に重ならないよう少し小さくしました。日付は別の「テキスト」ボックスで添えています。ダウンロードされた nda-signed.pdf を開いて3ページとも確認してから、メールに添付して返送しました。

もしこの取引先が今後、電子契約サービスを通じた締結を求めてくるようなら、そちらは証明書ベースの仕組みなので、このツールの署名画像では代わりになりません。そのときは先方の指定する方法に従うことになります。

トラブルシューティング

署名ウィンドウで「挿入」を押しても何も起きない
パッドが空か、「入力」の欄が空白です。少なくとも1本線を描くか名前を入力してから「挿入」を押してください。パッドに何もない状態で「挿入」を押すと、ウィンドウが閉じるだけです。
署名がギザギザに見える
挿入時のサイズよりかなり大きく引き伸ばされています。× で削除し、クリックして新しく挿入し直し、初期サイズに近い大きさで使ってください。パッドに大きめに、ゆっくり描くのも効果があります。
保存したファイルで回答が線とずれる
保存時に標準的なサンセリフ体で文字を描き直すため、数ピクセルずれることがあります。文字は線より少し上に置き、送信前にダウンロードしたファイルを確認してください。
フォームにもともと入力欄があり、文字が重なってしまった
そのPDFには操作できるフィールドがあります。元のファイルをPDFリーダーで開いてその欄に入力して保存し、署名を加えるためだけにそのコピーをここで開いてください。
相手から署名が「有効ではない」と言われた
相手が求めているのは証明書ベースの電子署名や認定された電子署名で、このツールでは作成できません。どの署名サービスなら受け付けるかを確認するか、印刷して手で署名し、スキャンしてください。
「このPDFを表示できませんでした。」と表示される
ファイルにパスワードがかかっているか、破損しています。作成したアプリケーションでパスワードを解除するか、「PDF修復」にかけてから、もう一度試してください。

よくある質問

ここで入れた署名に法的な効力はありますか？

書類の種類や、どの国・地域の手続きかによって変わります。日常的な取り決めの多くは、スキャンした署名と同じように署名の画像で受け付けてもらえますが、証明書ベースの電子署名や認定された電子署名が必要な書類もあります。迷ったときは、提出先に何なら受け付けるか確認してください。

手書きが苦手なので、署名を文字入力で作れますか？

作れます。署名ウィンドウで「入力」に切り替えて名前を入れると、お使いの端末に入っている筆記体フォントで描かれます。

1つの書類の何か所かに署名できますか？

できます。「署名」を選んで場所ごとにクリックすると、そのたびにパッドが開いて新しい署名を挿入できます。イニシャルも同じ方法で入れられます。

保存したあとで、入力した文字を直せますか？

直せません。保存すると文字と署名は各ページの画像レイヤーにまとめられます。回答を変えたいときは、元のファイルからやり直してください。

スマホだけで記入と署名ができますか？

できます。タッチスクリーンに指で書くほうが、マウスより書きやすいことも多いです。ただし全ページを描画するので、古いスマホでは長い書類の処理に時間がかかることがあります。

保存したファイル名に -signed と付くのはなぜですか？

出力ファイルは元のファイル名に -signed.pdf を付けた名前になります。署名前の元のファイルが上書きされることはありません。

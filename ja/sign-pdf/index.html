入力と署名

PDFに直接入力し、手書きまたは入力した署名を配置して、そのままダウンロードできます。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

誰かからフォームがメールで届く。それを印刷し、ペンで記入し、署名し、写真を撮って、傾いたJPEGを送り返す。PDForaの「記入と署名」ツールは、この一連の儀式をまるごと置き換えます。文書に直接回答を入力し、署名を加えて、きれいに仕上がったPDFをダウンロードするだけです。無料で、ブラウザ内で動作し、登録も不要です。

署名の作り方は2通りあります。マウスや指でそのまま書く方法（スマートフォンなら紙にサインする感覚に近くなります）と、氏名を入力して筆記体フォントを選び、署名として描画させる方法です。どちらの場合も、署名欄にぴったり合うようにドラッグして配置し、サイズを調整できます。PDFへの署名は1分もかかりません。

ここで電子署名を行う本当の理由はプライバシーです。署名する文書は、雇用契約書、初診の問診票、税務書類など、機密性の高いものになりがちです。PDForaはすべてをブラウザ内でローカルに処理するため、署名済みの契約書が端末から出たりサーバーに触れたりすることはありません。アップロードもウォーターマークもなく、記入・署名できる文書の数にも制限はありません。

PDFにオンラインで記入して署名する方法

  1. getpdfora.comで「記入と署名」ツールを開き、PDFを選びます。ファイルはどこにもアップロードされず、ブラウザ内に読み込まれます。
  2. フォームの空欄や罫線をクリックして回答を入力します。氏名、日付、住所、チェック印など、必要なものは何でも入力できます。
  3. 入力した文字がフォームの罫線に収まるように、文字サイズを調整します。
  4. クリックして署名を追加します。マウスや指で書くか、氏名を入力して筆記体のスタイルを選びます。
  5. 署名を署名欄までドラッグし、見た目が整うまでサイズを調整します。
  6. 完成したPDFをダウンロードして送信します。入力した文字と署名はファイルに焼き込まれています。

When to use this tool

  • 内定通知やフリーランスの契約書が届いたその場で署名する。プリンターを探し回る必要はありません。
  • 初診の問診票を自宅で記入しておき、待合室でクリップボードに書き込まずに済ませる。
  • 内見中の部屋に立ったまま、スマートフォンで賃貸の入居申込書に記入して署名する。
  • 学校の同意書に署名し、その日の夜のうちに先生へメールで返送する。
  • クライアントから届いたNDAに、機密文書を第三者のサーバーに通すことなく署名して返す。
  • 印刷して手書きすることを前提に作られたビザや行政の申請PDFに記入する。

Tips for the best results

  • 署名を手書きするならタッチスクリーンのほうが簡単です。パソコンをお使いなら、スマートフォンで署名してみてください。
  • 大きく書いてから縮小しましょう。大きく書いて縮めた署名のほうが、小さく書いたものよりなめらかに見えます。
  • 入力する文字サイズはフォームの印字に合わせます。だいたい10〜12ポイント程度が目安です。
  • チェックボックスには、手書きのチェックよりも入力した大文字のXのほうが枠内にきれいに収まります。
  • ダウンロードする前に最終ページをプレビューし、罫線からずれた入力がないか確認してください。

よくある質問

この方法で追加した署名は法的に有効ですか。

米国のESIGN法やEUのeIDAS規則をはじめ、多くの国では通常の電子署名が大半の契約について法的に認められています。ただし遺言書や公証を要する証書など、追加の要件がある文書もあるため、対象となる文書の種類ごとに規則をご確認ください。

署名した文書はどこかにアップロードされますか。

いいえ。記入と署名は完全にブラウザ内で行われるため、署名入りの契約書が端末から出ることはありません。サーバー上にコピーが残る心配もなく、機密性の高い書類にはまさに望ましい形です。

指で署名を書けますか。

はい。スマートフォンやタブレットでは、署名パネルを開いて指先やスタイラスで画面に直接署名できます。マウスで描くよりも自然な仕上がりになり、普段のペンによる署名に近くなります。

PDFに対話型のフォームフィールドがない場合はどうなりますか。

それが通常のケースで、問題なく使えます。ページの好きな位置をクリックして入力できます。このツールはPDF側に入力可能なフィールドがあることを前提としていないので、スキャンしたフォームや印刷向けに作られたフォームでも同じように扱えます。

文書や署名の数に制限はありますか。

制限はありません。必要なだけPDFに記入・署名でき、1つの文書に複数の署名やイニシャルを追加することも、すべて無料でダウンロードすることもできます。登録も、ウォーターマークも、月間の上限もありません。

2人が同じPDFに署名できますか。

はい。まずご自身が署名してファイルをダウンロードし、相手に送ります。相手は同じツールで開いて署名を追加し、最終版をダウンロードします。各署名は統合（フラット化）されるので、署名者の間で内容が失われることはありません。

PDFトリミング

すべてのページの上下左右から同じ幅の余白を取り除きます。新しい表示範囲を設定するだけで、描画し直すことはありません。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

A4の資料をスマホで開くと、上下左右の白い余白のせいで本文が小さくなり、結局ピンチで拡大しながら読むことになりがちです。自炊（自分で本をスキャンすること）したPDFなら、ノドに沿った黒い帯やスキャナーのガラスの縁が写り込んでいることもありますし、スライドをPDFに書き出すと何もない太い枠が付いてくることもあります。こうした空白を落とせば、同じ画面や同じ紙に内容を大きく収められます。

「PDFトリミング」で指定するのは数値1つだけです。ポイント単位の余白の幅を入れると、すべてのページの四辺から同じだけ取り除かれます。1ポイントは1/72インチなので、初期値の30ポイントは10mmより少し大きい程度です。注意したいのは、画像のようにピクセルを切り取るわけではない点です。ツールは各ページに新しい CropBox を書き込みます。これは「ページのどの長方形を表示・印刷するか」をビューアーやプリンターに伝えるPDFの指定で、範囲外の部分は見えなくなりますが、ファイルの中には残ったままです。

描画をやり直さないので、文字は選択できるまま、ベクター図形もぼやけず、ファイルサイズもほとんど変わりません。裏を返せば、見られたくない情報を消す手段にはならないということです。PDF編集ソフトを持っている人なら、CropBox を元に戻して隠れた端を表示できてしまいます。処理はブラウザ内で pdf-lib が行い、結果は yourfile-cropped.pdf としてダウンロードされます。

PDFの余白をトリミングする手順

  1. 「PDFトリミング」を開き、PDFファイルを1つ選びます。
  2. 余白の幅をポイントで入力します。初期値は30です。72ポイントが1インチ、約28ポイントが1センチメートルです。
  3. すべてのページの上・下・左・右から同じ幅が取られることを忘れずに。いちばん余白の狭いページに合わせて値を選んでください。
  4. 「余白をトリミング」をクリックし、元のファイル名に -cropped が付いたファイルがダウンロードされるのを待ちます。
  5. 結果を開き、レイアウトのいちばん窮屈なページを確認します。端に近いヘッダー、フッター、ページ番号が最初に消えやすい部分です。

このツールを使う場面

  • 自炊した本や雑誌のPDFから、ページの周りに写り込んだ影やスキャナーの縁を目立たなくする。
  • 会議資料を2-upや4-upで印刷して配る前に余白を詰め、小さなコマの中でも文字が縮みすぎないようにする。
  • 就業規則やマニュアルなどA4の文書を、通勤電車でスマホや電子書籍リーダーで読みやすくする。白い枠がなくなるだけで文字が目に見えて大きくなります。
  • 広い枠付きで書き出されたプレゼン資料のスライドを整える。
  • グラフや図面のPDFページを別の資料に貼り込む前に、周りの空白を取り除く。
  • 塾や学校のプリント、小テストを、教室のプロジェクターやモニターに映したときに見やすくする。

始める前に知っておきたいこと

  • トリミングは均一です。辺ごとの値やページごとの設定はないので、余白が不揃いな文書でも、どこも同じ幅だけ削られます。
  • 非表示になった部分は削除されていません。新しい範囲の外にある文字や画像はファイルに残り、再び表示させることができます。端を本当に取り除くには、まずトリミングし、「PDFからJPG」でページを画像に変換してから「JPG / PNGからPDF」でファイルを作り直してください。画像には表示範囲だけが含まれます。
  • ページがなくなってしまわないよう、余白には上限があります。非常に大きな数を入力しても、縦横それぞれ最低約2ポイントの表示範囲は残ります。
  • 新しい範囲は、ページ本来の用紙サイズ（メディアサイズ）を基準に測られます。ページにすでに独自のクロップボックスがあった場合は、さらに狭めるのではなく置き換えになります。
  • トリミング後は、ビューアーに表示されるページサイズが小さくなります。印刷時にプリンターがトリミングしたページを用紙いっぱいに拡大することがあり、その場合は文字の見た目の大きさが変わります。
  • ページは新しい文書にコピーされるのではなく元のファイル上で編集されるので、しおり、リンク、フォームフィールドはそのまま残ります。

きれいに仕上げるコツ

  • 先に測りましょう。ビューアーで、もっとも内容が詰まったページの文字がいちばん近い端からどれだけ離れているかを確認し、その距離より少し小さい値を選びます。
  • 最初は20〜30ポイントくらいの控えめな値から始めましょう。あとでページ番号が消えていたと気づくより、元のファイルでもっと大きな値を試し直すほうが早く済みます。
  • トリミング済みのコピーではなく、必ず元のファイルをトリミングしてください。2回目の処理はページ全体から測り直すので、結果は期待どおりに積み重なりません。
  • 片側だけに黒い縁があるスキャンでも、均一なトリミングなので残りの3辺も削られます。反対側の余白も同じだけ削ってよいか確認してください。
  • 社外に共有する文書で、端にメモや社内向けの情報があった場合は、トリミングに頼らないでください。共有する前に、その内容をきちんと削除しましょう。

具体例：合唱団の楽譜をiPadで見やすくする

市民合唱団でピアノ伴奏をしている松井さんは、A4でスキャンした12ページの楽譜をiPadで譜めくりしながら使っています。スキャンには四辺に約20mmの白い余白があり、さらに片側にはスキャナーのふたの影が細く写っていました。五線が始まるのは端から約22mmの位置で、余白のぶん音符が小さく、本番の照明の下では読みにくい状態でした。

20mmは約57ポイントなので、松井さんは55を入力して「余白をトリミング」をクリックしました。影と白い余白が消え、画面いっぱいに表示すると五線がひと回り大きく見えるようになりました。その前に65ポイント（約23mm）でも試しましたが、ページ上端の小節番号が数ページで欠けたため、元のファイルに戻って55でやり直しています。

スキャン画像自体はそのままなので、ファイルサイズは変わりません。印刷して団員に配る必要が出たときのために、トリミング前の元ファイルも別に残してあります。

トラブルシューティング

ページ番号やヘッダーが切れてしまった
そのページでは、余白の値が内容と端の間隔より大きかったためです。元のファイルで、もっと小さい値で処理し直してください。
隠したはずの内容が別のソフトでは見える
編集ソフトや印刷の仕組みの中には、クロップボックスを無視して用紙全体（メディアボックス）を表示するものがあります。トリミングは内容を隠すだけで、削除はしません。端を本当に消す必要があるなら、トリミングしたページを画像に変換してください（「PDFからJPG」の後に「JPG / PNGからPDF」）。
切りすぎのページと、ほとんど変わらないページがある
ツールはサイズの違うページにも同じ余白を適用します。小さいページほど、割合として多く削られます。サイズの違うページを別ファイルに分け、グループごとに値を変えてトリミングしてください。
印刷すると文字が以前より大きくなる
印刷ダイアログが、小さくなったページを用紙に合わせて拡大しています。元の文字サイズで印刷したい場合は「実際のサイズ」か倍率100%を選んでください。
何も変わらないように見える
余白が0になっていないか確認してください。また、入力した値より狭くすでにトリミングされていたページは、新しい範囲がページ全体から測られるため、かえって表示範囲が広がります。
ファイルがツールで開けない
ファイルが破損している可能性があります。「PDF修復」にかけ、修復したコピーをトリミングしてください。

よくある質問

トリミングするとファイルは軽くなりますか？

ほとんど変わりません。範囲の外に出た内容もファイルには残っているためです。容量を減らしたい場合は「PDF圧縮」を使ってください。

余白の数値は何の単位で入れるのですか？

PDFのポイントです。72ポイントが1インチ、約28.35ポイントが1センチなので、初期値の30ポイントはおよそ10.6mmになります。

上だけ、左だけなど、辺ごとに削る幅を変えられますか？

このツールでは変えられません。すべてのページの四辺から、同じ幅の余白を取り除きます。

特定のページだけトリミングすることはできますか？

直接はできません。「PDF分割」か「ページ抽出」で対象のページを別ファイルにしてトリミングし、残りのページと「PDF結合」でまとめ直してください。

トリミングした後も文字をコピーできますか？

できます。ページを描画し直していないので、表示範囲内の文字、リンク、ベクター図形はそのままです。

個人情報や社外秘の部分を隠す目的で使っても大丈夫ですか？

おすすめしません。トリミングで隠した部分は、PDF編集ソフトがあれば誰でも元に戻せます。見せてはいけない内容には専用の墨消しツールを使うか、トリミング後のページを「PDFからJPG」で画像にしてから「JPG / PNGからPDF」でPDFに戻してください。

しおりで分割

文書内の最上位のしおり(アウトライン)ごとに、1つのPDFを作成します。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

きちんと作られたPDFは、それ自体が目次を持っています。ビューアーの左側に表示されるしおりパネルです。PDForaのしおり分割ツールは、その項目を切り取り線として扱います。最上位のしおりごとに新しいファイルが始まり、各出力はしおりのタイトルで命名されるため、「第3章: 研究手法」はそのままの名前のファイルになります。生成されたファイル一式は1つのZIPとしてダウンロードできます。

分割するファイルがアップロードされることはありません。しおりのアウトラインの読み取りもページの分離も、お使いのブラウザ内でローカルに行われるため、取締役会資料、訴訟準備書面、未発表の原稿も最初から最後までご自分の端末に留まります。ツールは無料で、アカウントなしで使え、透かしも入らず、いくつ文書を投入しても分割できます。

手作業でやるとなると大変です。しおりパネルを開いて各章の開始ページを控え、ページ範囲の分割を十数回繰り返し、出力を1つずつ手で名前変更することになります。しおり分割は、その一切をワンクリックにまとめ、命名まで済ませてくれます。

オンラインでPDFをしおりごとに分割する方法

  1. getpdfora.com のしおり分割ツールを開きます。処理はブラウザ内で完結します。
  2. レポート、マニュアル、電子書籍など、しおりのアウトラインを持つPDFを追加します。
  3. ツールが最上位のしおりを読み取ります。それぞれが新しいファイルの開始位置になります。
  4. 「分割」をクリックします。あるしおりから次のしおりの手前までのページが、1つのPDFにまとめられます。
  5. 各出力ファイルはしおりのタイトルで自動的に命名されるため、手作業での名前変更は不要です。
  6. ZIPアーカイブをダウンロードして展開すると、各セクションが分かりやすい名前の個別ファイルとして手に入ります。

When to use this tool

  • 300ページの年次報告書をしおり単位のセクションに分割し、各部門長に担当の章だけを届ける。
  • 1レッスンにつき1ファイルを求める学習プラットフォーム向けに、技術マニュアルをモジュールごとのPDFに分ける。
  • 取締役会資料を議題ごとに分け、しおり名の付いたファイルとして各委員に配布する。
  • 訴訟資料をしおりごとの証拠に分け、証拠を個別に参照・共有できるようにする。
  • しおりの付いた料理本の原稿を章ごとのファイルにし、それぞれ別のセクションを担当する編集者に渡す。
  • 社員ハンドブックの各章を切り出し、人事部が他の部分に触れずに1セクションだけを更新できるようにする。

Tips for the best results

  • 分割前にPDFビューアーのしおりパネルを確認しましょう。最上位に見えている項目が、そのまま分割位置になります。
  • 分割が起きるのは最上位のしおりだけです。入れ子になった下位のしおりは親のファイル内に残るため、章と小見出しのまとまり方としてはたいてい妥当です。
  • PDFにしおりがない場合は、先にPDF編集ソフトで追加するか、テキストによる分割やページ範囲での分割を使ってください。
  • しおりのタイトルはZIP内のファイル名になるため、スラッシュやコロンといった文字はできるだけ避けましょう。
  • 長い文書ではZIPも大きくなります。アップロードは発生しませんが、ダウンロードが完了するまでタブは開いたままにしてください。

よくある質問

PDFのしおりとは具体的に何ですか。

しおり(アウトラインとも呼ばれます)は、多くのPDFビューアーでサイドバーに表示されるクリック可能な目次です。著者やWord、InDesignなどの書き出しツールが章やセクションの目印として追加するもので、このツールはその目印をそのまま分割位置として使います。

出力ファイルの名前はどう決まりますか。

各ファイルは、その開始位置となったしおりのタイトルを名前にします。「付録B」というしおりなら、その名前のファイルになります。ファイル名に使えない文字は自動的に調整されるので、すべてのファイルがZIPからきれいに展開できます。

PDFにしおりがありません。それでも使えますか。

そのままでは使えません。分割位置を決めるのがアウトラインだからです。先にPDF編集ソフトでしおりを追加するか、繰り返し登場するキーワードがセクションの開始を示しているなら、PDForaのテキスト分割ツールを使ってください。

結果がZIPファイルでダウンロードされるのはなぜですか。

しおりの付いた文書は10個、20個、あるいはそれ以上に分割されることが多く、ファイルごとにクリックし続けるより1つのZIPのほうがはるかに楽だからです。展開すれば、名前の付いたPDFがすべて1つのフォルダに入っています。

入れ子のしおりでも分割されますか。

いいえ。新しいファイルが始まるのは最上位の項目だけで、その下に入れ子になっているものはすべて一緒に付いてきます。そのため、小見出しは章の中に留まり、文書が数十個の断片に散らばることはありません。

本当に無料ですか。文書のプライバシーは守られますか。

どちらもはいです。登録も透かしも利用回数の上限もなく、ファイルの解析と分割は完全にブラウザ内で行われるため、サーバーに送信されることはありません。処理時間はお使いの端末と文書のサイズによって変わります。

PDF分割

ページ範囲指定、Nページごと、または1ページずつにPDFを分割できます。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。
1

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

90ページのPDFが90ページのまま役に立つことは、ほとんどありません。同僚に渡したいのは第2章だけ、クライアントに必要なのは40〜55ページ、保管用には1ページずつ別ファイル、といった具合です。PDForaの分割ツールは1つのPDFを複数に分けるもので、方法は3通りあります。全ページを個別のPDFにする、自分で入力したページ範囲で分ける、Nページごとに自動で区切る、のいずれかです。

処理はすべてブラウザ内で行われます。分割するファイルはお使いの端末上でローカルに開かれて処理され、サーバーに送信されることも、クラウドストレージに保存されることも、誰かの処理待ち行列を通ることもありません。法務資料、人事書類など、他人のコンピューターにアップロードしたくない文書にとって、この違いはどんな機能よりも重要です。

無料で、登録は不要、透かしも入りません。分割で複数のファイルができた場合は1つのZIPにまとめられるので、何個もダウンロードせずに済みます。1回でも100回でも、カウンターが回ることはありません。

オンラインでPDFを分割する方法

  1. getpdfora.com のPDF分割ツールを開き、PDFを選択するかドラッグして追加します。
  2. 分割方法を選びます。全ページを個別のPDFにする、任意の範囲で分ける、Nページごとに分ける、のいずれかです。
  3. 任意の範囲の場合は、言葉で説明するように入力します。たとえば 1-3, 4-6 と入力すると2つのファイルができます。
  4. 固定ページ数で分ける場合は、1ファイルあたりのページ数(10など)を入力すると、自動的に文書が分割されます。
  5. 「分割」をクリックします。ブラウザが数秒でPDFをローカルに切り分けます。
  6. 生成されたPDFがすべて入ったZIPファイルをダウンロードし、好きな場所で展開します。

When to use this tool

  • スキャンした署名済みフォームの束を、書類ごとに1つのPDFに分けてから保管する。
  • 教科書や講読資料を章ごとに分割し、学生が必要な部分だけをダウンロードできるようにする。
  • 長い取締役会資料を分割し、各部署に自分の担当セクションだけを届ける。
  • 1件ずつの明細を前提とする会計ソフトのために、書き出した銀行取引明細を月別ファイルに切り分ける。
  • 学会予稿集のPDFを論文単位に分け、引用や共有をしやすくする。
  • メール添付の容量制限を回避するため、大きなレポートを10ページずつのかたまりに分ける。

Tips for the best results

  • 範囲を入力する前にPDFにざっと目を通し、各セクションが始まるページ番号を控えておくと、やり直しの手間が省けます。
  • 範囲の長さは不ぞろいでも構いません。セクションの長さが違うなら 1-3, 4-6, 7-20 のような指定でまったく問題ありません。
  • 同じ書式のフォームや決まった長さの明細書のように構造が規則的な場合は、Nページごとのモードを選びましょう。
  • 全部ではなく1つのセクションだけが必要なら、すべてを分割するよりページ抽出ツールのほうが早く済みます。
  • 非常に長いスキャン文書の分割は端末のメモリを使うため、古い機種では少し時間の余裕を見てください。

よくある質問

PDFを1ページずつに分割するには。

全ページを個別のPDFとして保存するモードを選び、「分割」をクリックします。30ページの文書は30個のファイルになり、1つのZIPにまとめてダウンロードされます。

任意のページ範囲で分割できますか。

はい。1-3, 4-6 のように範囲を入力すると、それぞれが別のPDFになります。範囲はいくつでも指定でき、長さをそろえる必要もありません。

結果がZIPファイルでダウンロードされるのはなぜですか。

分割では通常複数のPDFが一度にできるため、何十件もの保存が個別に発生する代わりに、ZIPで1つのダウンロードにまとめています。展開すればすべてのPDFが順番どおりの名前で入っています。

分割時に文書はアップロードされますか。

いいえ。PDForaはブラウザ内でファイルをローカルに処理するため、PDFが端末から出ることはありません。契約書や人事ファイルのような機密資料でも安心して使えます。

分割できるファイルサイズに上限はありますか。

こちらで設けている上限はありません。処理はお使いの端末が行うため、非常に大きなファイルは利用可能なメモリ次第です。ほとんどの文書は数秒で分割できますが、巨大なスキャン資料は時間がかかることがあります。

分割するとPDFの品質は落ちますか。

いいえ。ページは再圧縮なしでそのまま新しいファイルにコピーされます。テキストは鮮明で検索も可能なまま、画像も元の解像度を保ちます。

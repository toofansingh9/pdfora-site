N-up（1枚あたりのページ数）

複数のページを1枚にまとめて配置し、印刷時の用紙を節約します。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

N-up印刷は印刷所で昔から使われてきた手法です。複数のページを縮小して1枚の用紙に並べます。PDForaのN-upツールは、これをブラウザ上で手軽に実現します。1枚あたり2ページか4ページを選ぶと、横向きA4に割り付けられた印刷用のPDFができあがります。60ページのスライド資料なら15枚、40ページのマニュアルなら10枚です。紙もトナーも減り、ファイルにきちんと収まる厚さになります。

処理はすべてお使いの端末の中で完結します。PDFはブラウザが読み込んで組み直すので、サーバーに送られることはありません。社外秘の取締役会資料や未発表の原稿も、手元から動きません。ツールは無料で、登録不要、透かしも入らず、1日に処理できる書類の数にも制限はありません。

プリンタードライバーにも「用紙1枚あたりのページ数」の設定はありますが、機種ごとに場所が違ううえ、ファイルを共有すると設定は引き継がれません。N-upのレイアウトをPDF自体に組み込んでおけば、受け取った人が普通に印刷するだけで、まとまった状態で出力されます。

オンラインでPDFの複数ページを1枚にまとめる手順

  1. getpdfora.comでN-upツールを開き、PDFをドラッグするか選択して追加します。ファイルはアップロードされず、ブラウザ内で読み込まれます。
  2. レイアウトを選びます。1枚に2ページ（左右に並べる）か、1枚に4ページ（2×2のグリッド）です。
  3. 出力用紙は横向きA4です。どちらの設定でも縦長ページが読みやすいサイズに収まります。
  4. ボタンを押してN-up版を生成します。各ページは自動的に縮小・配置されます。
  5. プレビューで、ページ順とサイズが目的に合っているかを確認します。
  6. 新しいPDFをダウンロードし、通常の書類と同じように印刷します。1枚の用紙がPDFの1ページに対応します。

When to use this tool

  • 講義スライドを4-upの配布資料として印刷し、ゼミ1学期分のノートを薄いバインダーに収める。
  • 100ページのレポートを2-upの校正用に印刷し、全ページ印刷の半分の紙で赤入れをする。
  • 楽譜を圧縮して2ページ分を同時に表示し、フレーズの途中でめくらずに演奏できるようにする。
  • ソフトウェアのチートシートを4ページ分1枚に並べて印刷し、4等分に切って携帯用のリファレンスカードを作る。
  • 参加者30名のワークショップで配る研修マニュアルの印刷代を抑える。
  • 絵コンテのコマを並べて見比べ、全ページ印刷を1枚ずつめくる手間をなくす。

Tips for the best results

  • 4-upでは小さな文字が読みにくくなります。元の資料が10ポイント以下のフォントなら、1枚2ページのほうが無難です。
  • 文字の大きなスライドは4-upでも十分読めますが、文字が詰まった契約書などはそうはいきません。全部を印刷する前にテストで1枚出してみてください。
  • N-upと両面印刷を組み合わせれば、4-upのレイアウトで紙1枚に8ページ分が入ります。
  • 白紙や不要なページは先に削除しましょう。そのまま残すとグリッドの枠を占有し、すべての用紙で無駄が生じます。
  • 画面で読む用には元の1ページずつのPDFを残し、N-up版は印刷専用に使いましょう。それぞれの用途に合った形式があります。

よくある質問

N-upとは何のことですか。

Nは1枚の用紙に配置するページ数を表します。2-upなら1枚に2ページ、4-upならグリッド状に4ページという意味です。印刷業界で何十年も使われてきた、紙を節約するための標準的な面付け手法です。

なぜ出力が横向きA4なのですか。

縦長のページを2ページまたは4ページ並べるには横向きの用紙が自然で、縮小率を抑えて文字を読みやすく保てるからです。印刷時はプリンター側も横向きに設定してください。

書類はどこかにアップロードされますか。

いいえ。PDForaはN-upのレイアウトをすべてブラウザ内で組み立てるため、ファイルが端末から出ることはありません。処理速度はサーバーではなくお使いのパソコンの性能に依存しますが、たいていの書類は数秒で終わります。

N-up印刷でどのくらい紙を節約できますか。

2-upならページ数は半分、4-upなら4分の1になります。両面印刷と組み合わせれば、200ページの書類がわずか25枚で出力できます。

縮小しても文字は読めますか。

2-upなら通常は問題ありません。各ページは元の寸法の約70パーセントを保ちます。4-upでは縦横ともおよそ半分になるため、スライドには適していますが、細かい文字は目に負担がかかります。

料金がかかったり、透かしが入ったりしますか。

いいえ。N-upツールは完全に無料で、アカウントも不要、用紙に透かしが入ることもなく、ファイル数や利用回数の上限もありません。

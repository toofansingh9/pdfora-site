N-up（1枚あたりのページ数）

PDFの2ページまたは4ページを横向きA4用紙1枚に並べ、長い文書を少ない枚数で印刷できるようにします。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。

ファイルを選択するか、ドラッグ＆ドロップします。

オプションを選びます — すべてブラウザ内で処理されます。

60枚のスライドを1枚1ページで印刷すると、用紙は60枚。しかも部屋の反対側からでも読めそうな大きさのスライドになります。Nアップ印刷（割り付け印刷）なら、1枚の用紙に複数ページを並べられます。PDForaのNアップツールは、元のページを2ページまたは4ページずつ1枚に配置した新しいPDFを作ります。プリンタードライバーの設定をいじらなくても、どのプリンターでもそのまま印刷できます。印刷ダイアログではなくPDF側で割り付けておくことには実用的な利点があります。レイアウトがファイルに固定されるので、自宅のインクジェットでも、会社の複合機でも、印刷所の機械でも同じように印刷でき、用紙を1枚も使わずに画面で確認できます。割り付け済みのファイルを人にメールで送れば、ドライバーの設定を説明しなくても印刷してもらえます。

レイアウトは固定で、結果は予想しやすくなっています。出力される用紙はすべて横向きのA4（842×595ポイント）です。2-upでは用紙を左右2列に、4-upでは2×2のマスに分け、上の段から左→右の順に埋めていきます。元の各ページは、マスに収まるよう縦横比を保ったまま縮小され、さらにページ間に少し隙間ができるようマスの95%の大きさにして中央に配置されます。

ページは画像に変換されません。pdf-libが元の各ページをベクターオブジェクトとして新しい用紙に埋め込むため、元の4分の1の大きさになっても、文字や線画は印刷してもくっきりしています。処理はブラウザ内で行われ、ファイルは「元のファイル名-nup.pdf」としてダウンロードされます。縮小率はページごとに計算されるので、縦向きの本文ページと横向きのグラフが混在する文書でも、各ページがそれぞれのマスに収まる最大の大きさで配置されます。

PDFの複数ページを1枚にまとめる手順

  1. Nアップツールを開き、PDFを1つ選びます。
  2. 「1枚あたりのページ数」で 2-up か 4-up を選びます。初期値は 2-up です。
  3. 「Nアップを作成」をクリックします。ページ数の多い文書は、全ページの埋め込みに少し時間がかかります。
  4. 結果を開いて用紙を拡大し、いちばん小さい文字がそのサイズでも読めるか確認します。
  5. A4用紙に100%または「用紙に合わせる」で印刷します。Letter用紙の場合は、端が切れないよう「用紙に合わせる」を選んでください。

このツールを使う場面

  • 講義スライドを1枚に2つまたは4つずつ並べて、余白にメモできる配布資料にする。
  • 長い原稿を紙で校正するときに、用紙を半分や4分の1に減らす。
  • マニュアル、書式、チェックリストを、ファイルに綴じておけるコンパクトな控えにする。
  • 見開きのように連続する2ページを並べて、レイアウトをざっと目で確認する。
  • 大きな見出しと図が中心の会議資料で、印刷コストを抑える。
  • 1ページに1枚ずつ保存した小さなレシートやチケットを、1枚の用紙にまとめて印刷・保管する。

始める前に知っておきたいこと

  • 選べるのは 2-up と 4-up だけです。6-up、8-up、任意のマス割りはありません。
  • 元のページサイズにかかわらず、出力用紙は常に横向きのA4です。US Letterに印刷する場合は、印刷ダイアログで「用紙に合わせる」を選んでください。
  • 縦向きのページは、2-upでは左右に並び、用紙の高さのほとんどを使います。4-upではかなり小さくなり、A4のページなら幅・高さとも元のおよそ3分の1になります。
  • ページの順番は保たれます。4-upでは1ページ目が左上、2ページ目が右上、3ページ目が左下、4ページ目が右下です。ページ数が2や4の倍数でない場合、最後の用紙には空いたマスができます。空いたマスは白のままで、ページを繰り返して埋めることはしません。
  • リンク、フォームフィールド、コメント、しおりは引き継がれません。ページの内容は描画としてコピーされ、元のファイルの操作できる要素は残りません。
  • 元のファイルで設定されたページの回転が、埋め込み時に反映されないことがあります。回転情報のおかげで正しい向きに見えているだけのページは、横向きで出力される場合があります。その場合は先に「PDFを回転」で直して保存してください。

きれいに仕上げるコツ

  • スライドなら、横向きで文字も大きいので、たいてい 4-up で大丈夫です。縦向きの文章中心の文書なら、用紙の節約と読みやすさのバランスで 2-up がおすすめです。
  • 先に「余白をトリミング」で広い白い余白を切り落としましょう。内容が各マスの中でより大きく配置され、文字も大きく印刷されます。
  • 白紙や不要なページは、Nアップを作る前に削除しておきましょう。そのままだとマスを1つ使ってしまいます。
  • 配布資料を特定の順番にしたい場合は、先に「ページを整理」で並べ替えてください。Nアップはページを厳密に順番どおりに配置します。
  • 長い印刷を流す前に、まず1枚だけ試し刷りしましょう。

具体例：NPOの研修会の配布資料

ある小さなNPOが、ボランティア25人を対象に1日研修を開き、48枚のスライドを全員に紙で配ろうとしています。1ページに1スライドだと、1人48枚、合計1,200枚です。

担当者はスライドをPDFに書き出し、4-upを選んでNアップにかけました。結果は1人あたり横向きA4で12枚。スライドは見出しが大きく図もシンプルなので、4分の1の大きさでも十分読めます。両面印刷すれば、ボランティア1人あたり用紙6枚、合計150枚で済みます。

ただ、細かい表が入った2枚のスライドは、4-upでは小さすぎました。担当者は資料全体を2-upにして用紙を倍にする代わりに、その2ページだけを抽出して原寸で別に印刷しました。そしてNアップの配布資料と原寸の2ページを結合し、ボランティア一人ひとりがホチキス留めの1セットを受け取れるようにしました。元のスライドは当日のプロジェクター投影用にそのまま残しています。

トラブルシューティング

文字が小さすぎて読めない
4-upから2-upに切り替える、先に元ファイルの白い余白をトリミングする、または文字の詰まったページだけ原寸で別に印刷してください。
印刷すると端が切れる
プリンターの用紙がA4ではないか、プリンターが端まで印刷できない可能性があります。印刷ダイアログで「用紙に合わせる」や大きいページの縮小を選んでください。
一部のページが横向きになる
元のページが回転の設定に頼っている可能性があります。元のページを正しい向きに回転して保存し、もう一度Nアップを実行してください。
元のファイルのリンクが機能しない
これは仕様です。Nアップでコピーされるのはページの内容だけです。画面で読む用には元のファイルを残しておいてください。
最後の用紙が半分空いている
ページ数が1枚あたりのページ数の倍数になっていないためです。そのままにするか、Nアップを作る前にページを削除または追加してください。
ファイルによってはツールが失敗する
破損したPDFや特殊なPDFは、埋め込みに失敗することがあります。「PDFを修復」にかけ、修復したファイルでもう一度お試しください。

よくある質問

Nアップにしても文字はくっきりしていますか？

はい。各ページは画像ではなくベクターの内容として埋め込まれるので、縮小しても文字や線画はきれいに印刷されます。

出力の用紙サイズは選べますか？

選べません。出力は常に横向きのA4です。ほかの用紙サイズには、印刷ダイアログの「用紙に合わせる」を使ってください。

1枚に6ページや9ページを並べられますか？

現在はできません。このツールで選べるのは 2-up と 4-up だけです。それ以上のページを1枚にまとめたい場合は、プリンタードライバーの割り付け印刷機能が使えるかもしれません。

ページの間に枠線は入りますか？

線は描かれません。各ページはマスの95%の大きさに縮小されるため、ページ間に小さな白い隙間ができます。

サイズの異なるページはどうなりますか？

各ページは縦横比を保ったまま、それぞれのマスに収まるよう個別に縮小されます。そのため、サイズが混在していると用紙上での縮尺もページごとに異なります。

アカウントは必要ですか？

必要ありません。登録なしで、ブラウザ上ですぐに使えます。

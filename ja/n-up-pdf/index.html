N-up（1枚あたりのページ数）

PDFの2ページまたは4ページを横向きA4用紙1枚に並べ、長い文書を少ない枚数で印刷できるようにします。

会議のたびに分厚い資料をコピー機で刷り、終わったら半分も読まれずに捨てられる。そんな職場は今でも珍しくありません。1枚に2ページや4ページを並べる割り付け印刷を使えば、紙はぐっと減ります。ただ、プリンタードライバーの割り付け設定は機種ごとに場所も名前も違い、人に印刷を頼むたびに説明が必要になります。「N-up（1枚あたりのページ数）」は、割り付けをPDFそのものに組み込むツールです。元のページを2ページまたは4ページずつ1枚に並べた新しいPDFを作るので、自宅のインクジェットでも会社の複合機でも印刷所でも同じように刷れますし、紙を使う前に画面で仕上がりを確かめられます。割り付け済みのファイルをメールで渡せば、相手に設定を説明する必要もありません。

レイアウトは固定なので、仕上がりは予想しやすいはずです。出力される用紙はすべて横向きのA4（842×595ポイント）。2-upなら用紙を左右2つに、4-upなら縦横2×2のマスに分け、上の段の左から右へと順に埋めていきます。元の各ページはマスに収まるよう縦横比を保って縮小され、さらにページ同士の間に少し隙間ができるよう、マスの95%の大きさで中央に置かれます。

ページを画像に変換することはありません。pdf-libが元のページをベクターのまま新しい用紙に埋め込むので、4分の1の大きさになっても文字や線はくっきり印刷されます。縮小率はページごとに計算されるため、縦向きの本文と横向きのグラフが混ざった文書でも、それぞれのページがマスに収まる最大の大きさで配置されます。処理はブラウザの中で完結し、ファイルは「元のファイル名-nup.pdf」としてダウンロードされます。

PDFの複数ページを1枚にまとめる手順

  1. 「N-up（1枚あたりのページ数）」を開き、PDFを1つ選びます。
  2. 「1枚あたりのページ数」で 2-up か 4-up を選びます。初期値は 2-up です。
  3. 「Nアップを作成」をクリックします。ページ数の多い文書は、全ページの埋め込みに少し時間がかかります。
  4. 結果を開いて用紙を拡大し、いちばん小さい文字がそのサイズでも読めるか確認します。
  5. A4用紙に100%または「用紙に合わせる」で印刷します。Letter用紙の場合は、端が切れないよう「用紙に合わせる」を選んでください。

このツールを使う場面

  • 大学の講義スライドを4-upにして、余白に書き込めるノート代わりのプリントにする。
  • 簿記や宅建などの資格試験の勉強用に配られたPDF教材を2-upで印刷し、紙の量を半分にする。
  • 社内会議の資料を4-upと両面印刷で刷り、配布する枚数を減らす。
  • 長い原稿や報告書を紙で校正するとき、用紙の枚数を半分や4分の1にする。
  • 業務マニュアルやチェックリストを縮小して、ファイルに綴じておける控えにする。
  • 1ページずつ保存した電子チケットや小さな領収書を、1枚の用紙にまとめて印刷し保管する。

始める前に知っておきたいこと

  • 選べるのは 2-up と 4-up だけです。6-up、8-up、任意のマス割りはありません。
  • 元のページサイズにかかわらず、出力用紙は常に横向きのA4です。US Letterに印刷する場合は、印刷ダイアログで「用紙に合わせる」を選んでください。
  • 縦向きのページは、2-upでは左右に並び、用紙の高さのほとんどを使います。4-upではかなり小さくなり、A4のページなら幅・高さとも元のおよそ3分の1になります。
  • ページの順番は保たれます。4-upでは1ページ目が左上、2ページ目が右上、3ページ目が左下、4ページ目が右下です。ページ数が2や4の倍数でない場合、最後の用紙には空いたマスができます。空いたマスは白のままで、ページを繰り返して埋めることはしません。
  • リンク、フォームフィールド、コメント、しおりは引き継がれません。ページの内容は描画としてコピーされ、元のファイルの操作できる要素は残りません。
  • 元のファイルで設定されたページの回転が、埋め込み時に反映されないことがあります。回転情報のおかげで正しい向きに見えているだけのページは、横向きで出力される場合があります。その場合は先に「PDF回転」で直して保存してください。

きれいに仕上げるコツ

  • スライドなら、横向きで文字も大きいので、たいてい 4-up で大丈夫です。縦向きの文章中心の文書なら、用紙の節約と読みやすさのバランスで 2-up がおすすめです。
  • 先に「PDFトリミング」で広い白い余白を切り落としましょう。内容が各マスの中でより大きく配置され、文字も大きく印刷されます。
  • 白紙や不要なページは、Nアップを作る前に削除しておきましょう。そのままだとマスを1つ使ってしまいます。
  • 配布資料を特定の順番にしたい場合は、先に「ページ整理」で並べ替えてください。Nアップはページを厳密に順番どおりに配置します。
  • 長い印刷を流す前に、まず1枚だけ試し刷りしましょう。

具体例：中学校の授業プリントを4-upで刷る

ある中学校の数学の先生が、授業で使ったスライドを生徒に紙で配ることにしました。スライドは16:9で38枚、受け持ちは3クラス計96人です。1枚1ページで印刷すると1人38枚、全部で3,648枚になります。

PDFに書き出したスライドを「N-up（1枚あたりのページ数）」で4-upにしてみると、10枚になり、最後の1枚は2マス分が空いていました。よく見ると、単元の区切りに入れていた白紙のスライドが2枚混ざっています。先にその2枚を「ページ削除」で取り除いてから実行し直すと、36ページがちょうど9枚に収まりました。スライドは見出しが大きく、図もシンプルなので、4分の1の大きさでも教室の後ろの席の生徒が手元で読むには十分です。

これを両面で刷ると、1人あたり用紙5枚（最後の1枚は裏が白紙）、96人分で480枚です。元のまま印刷するのに比べて、8分の1近くまで減りました。授業でプロジェクターに映すのは、元のスライドのPDFのままです。

トラブルシューティング

文字が小さすぎて読めない
4-upから2-upに切り替える、先に元ファイルの白い余白をトリミングする、または文字の詰まったページだけ原寸で別に印刷してください。
印刷すると端が切れる
プリンターの用紙がA4ではないか、プリンターが端まで印刷できない可能性があります。印刷ダイアログで「用紙に合わせる」や大きいページの縮小を選んでください。
一部のページが横向きになる
元のページが回転の設定に頼っている可能性があります。元のページを正しい向きに回転して保存し、もう一度「N-up（1枚あたりのページ数）」を実行してください。
元のファイルのリンクが機能しない
これは仕様です。Nアップでコピーされるのはページの内容だけです。画面で読む用には元のファイルを残しておいてください。
最後の用紙が半分空いている
ページ数が1枚あたりのページ数の倍数になっていないためです。そのままにするか、Nアップを作る前にページを削除または追加してください。
ファイルによってはツールが失敗する
破損したPDFや特殊なPDFは、埋め込みに失敗することがあります。「PDF修復」にかけ、修復したファイルでもう一度お試しください。

よくある質問

2ページや4ページを1枚にまとめても、文字はぼやけませんか？

ぼやけません。ページは画像ではなくベクターのまま埋め込まれるので、縮小しても文字や線はきれいに印刷できます。

A4以外の用紙サイズで出力できますか？

できません。出力は常に横向きのA4です。B5やLetterなどに印刷するときは、印刷ダイアログで「用紙に合わせる」を選んでください。

1枚に6ページや9ページを並べることはできますか？

今のところできません。選べるのは 2-up と 4-up の2種類です。それ以上詰めたい場合は、プリンタードライバーの割り付け印刷を試してみてください。

ページとページの間に区切り線は入りますか？

線は入りません。各ページがマスの95%の大きさに縮小されるので、ページの間に細い白い隙間ができます。

大きさの違うページが混ざっていると、どうなりますか？

それぞれのページが縦横比を保ったまま、自分のマスに収まるよう個別に縮小されます。そのため、サイズが混在していると、用紙上での縮尺はページごとに違って見えます。

使うのに会員登録は必要ですか？

必要ありません。登録なしで、ブラウザからすぐに使えます。

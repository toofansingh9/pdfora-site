PDFロック解除

権利を持っているPDFからパスワードを取り除きます。

🔒 ファイルはブラウザ内でローカルに処理され、アップロードされることはありません。

アップロード

ファイルを選択するか、ドラッグ＆ドロップします。

2

設定

オプションを選びます — すべてブラウザ内で処理されます。

3

ダウンロード

完成したファイルをすぐに保存。ウォーターマークはありません。

パスワード保護されたPDFは便利ですが、それが自分のファイルで、20回目のパスワード入力画面が出てくると話は別です。銀行の取引明細、給与明細、保険関係の書類など、ロックされた状態で届くものは多く、開くたびにパスワードを打つのはすぐに面倒になります。PDForaのロック解除ツールは、ご自身が所有するPDFから既知のパスワードを取り除き、普通のファイルと同じように開けるきれいなコピーを作ります。

正直にお伝えすると、ロック解除ツールは現在PDFora上で「近日公開」と表示されており、準備中です。このページでは、公開されたときにどう動作するかを説明しています。無料で、登録不要、透かしなし、制限なしです。そしてロック解除はブラウザ内で行われるため、保護された文書も入力したパスワードも、最初から最後までお使いの端末に留まります。何もアップロードされません。

このツールがしないことが1つあります。パスワードの解読です。パスワードを取り除くには現在のパスワードを知っている必要があり、ロックを解除してよいのは、ご自身が所有しているPDFか、開く明確な許可を得ているPDFだけです。権限なく他人の文書から保護を取り除くことは違法になり得ます。ロック解除は正当な利便性のためにあるもので、セキュリティを回避するためのものではありません。

オンラインでPDFのパスワードを解除する方法

  1. getpdfora.com のロック解除ツールを開き、パスワード保護されたPDFを選びます。ファイルは端末に留まり、アップロードされません。
  2. 求められたら、その文書の現在のパスワードを入力します。これが開く権利を持っている証明になります。
  3. 保護を取り除いてよいか確認します。
  4. ツールがブラウザ内でローカルにファイルを復号し、ロックの外れたコピーを作成します。
  5. 新しいPDFをダウンロードします。どのビューアーでも、パスワード入力なしですぐに開きます。
  6. 保護されたコピーを手元に残しておきたいかどうかに応じて、元のロック済みファイルを保存するか削除します。

When to use this tool

  • 確定申告の時期に税理士のソフトウェアが読み込めるよう、毎月の銀行取引明細からパスワードを取り除く。
  • 勤務先が生年月日で保護して送ってくる給与明細のロックを解除し、記録用フォルダに保管する。
  • 急に必要になったときすぐ開けるよう、保険証券のPDFからパスワードを取り除く。
  • 電子チケットや予約確認書のロックを解除し、電波の有無に左右されずチェックインカウンターですぐ開けるようにする。
  • ロックされたレポートを結合や圧縮に備えて準備する。ほとんどのPDFツールは、暗号化されたファイルをロック解除するまで処理できません。
  • パスワードをまだ覚えているうちに、古い保護済みの保管ファイルを通常のファイルにまとめておく。

Tips for the best results

  • 明細書は届いたときにロックを解除しておきましょう。3年後には、どの四半期にどの形式のパスワードを使ったかなど思い出せません。
  • 銀行がファイルをロックしている場合、パスワードはメール本文に書かれていることが多く、たいていは生年月日か口座番号の一部です。
  • ロック解除後は、ファイルを人目に触れない場所に保管しましょう。それまで守っていたのはパスワードだけでした。
  • その文書を再びメールでやり取りする可能性があるなら、ロックされた原本は残しておきましょう。
  • 編集、結合、圧縮の前にロックを解除しましょう。復号は、他のあらゆる操作が待たされる最初の関門です。

よくある質問

ロック解除ツールはもう使えますか。

「近日公開」と表示されており、順次提供を開始しています。今日どうしてもPDFのパスワードを取り除く必要がある場合は、信頼できるデスクトップ環境での方法があります。パスワードを入力してPDFビューアーでファイルを開き、保護なしの新しいPDFとして印刷または書き出してください。

パスワードが分からないPDFのロックを解除できますか。

いいえ。これは意図的な仕様です。パスワードを取り除くには正しいパスワードを入力する必要があります。ツールはファイルを復号するのであって、解読するのではありません。忘れたパスワードの復元は、行いませんし、行えるとも謳っていません。

PDFのパスワードを取り除くのは合法ですか。

ご自身の文書、または開く権限がある文書からパスワードを取り除くことは一般に問題ありません。権利のないファイルの保護を回避することは、著作権法やコンピューター不正利用に関する法律に違反する可能性があります。解除する権利があるPDFだけを対象にしてください。

ファイルやパスワードはアップロードされますか。

いいえ。復号は完全にブラウザ内で実行されるため、ロックされたPDFも入力したパスワードも端末に留まります。金融や身分に関する書類にとって、これはアップロード型のロック解除サイトとの大きな違いです。

ロックを解除するとPDFの見た目は変わりますか。

いいえ。暗号化を取り除いても内容には手を加えないため、テキスト、画像、レイアウト、ページ順はそのまま引き継がれます。変わるのは、パスワード入力画面がなくなることだけです。

問題なく開けるのに、印刷やコピーができないPDFはどうですか。

それは開くためのパスワードではなく、オーナーパスワードによる保護です。こうした制限は文書の作成者が設定したものなので、その文書がご自身のものであるか、作成者が解除の許可を与えている場合を除き、尊重してください。

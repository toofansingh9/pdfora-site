把一整个文件夹的照片、扫描件或截图，变成一份整洁的 PDF。这个图片转 PDF 工具支持 JPG 和 PNG，你可以拖动缩略图排出想要的顺序，再把它们拼成一份可以发邮件、打印或归档的文档。一张图还是一百张都能处理，无需注册、不加水印，生成多少份 PDF 也不限量。

转换全程在浏览器内完成。你的图片绝不会上传到服务器——当你要合并的是签好字的合同页、护照照片，或者印着卡号的票据时，这一点至关重要。文件自始至终留在你的设备上，事后也不需要去谁的云端删除什么。关掉标签页，这次操作不留任何痕迹。

页面尺寸也由你掌控。既可以让每一页贴合图片自身的尺寸，也可以把每张图居中放在标准 A4 或 US Letter 页面上——如果这份 PDF 要拿去打印，后者更稳妥。竖构图的手机照片和横构图的截图混在一起也没关系，工具会替你安排好版面。

如何在线把图片转成 PDF

  1. 打开「JPG 转 PDF」工具，把图片拖到上传区，或点击浏览选择。JPG 和 PNG 可以一起选。
  2. 拖动缩略图调整顺序。左上角的那张就是第一页，后面依次排列。
  3. 选择页面尺寸：让页面贴合每张图片，或把每张图居中放在 A4 或 US Letter 页面上。
  4. 随时可以补充遗漏的图片，也可以移除不需要的。
  5. 点击「转换」，PDF 会在浏览器本地几秒钟内拼装完成。
  6. 下载做好的 PDF，发出去之前先核对一下页面顺序。

When to use this tool

  • 把手机拍的租房合同或协议照片合并成一份房东真正打得开的 PDF，而不是六张零散的 JPG。
  • 月底把扫描的票据整合成一个附件，作为报销单交给财务。
  • 把某个 bug 或一段聊天记录的截图按顺序合并成 PDF，用于提交客服工单。
  • 把画作、草图或设计稿打包成作品集 PDF，保证顺序不乱。
  • 把课堂上拍的手写笔记或白板照片汇总成一份复习资料。
  • 把证件页、水电账单和表格的照片汇编成签证申请或银行要求的那一份 PDF。

Tips for the best results

  • 添加之前先给图片文件按数字重命名（01、02、03），它们通常就会自动排到正确的位置。
  • 如果 PDF 要打印，请选 A4 或 US Letter；纯屏幕阅读则用贴合图片更好，因为不会留白边。
  • 手机直出的照片单张常常有 5 MB 以上。先把它们缩到约 1500 像素宽，最终 PDF 才小到能发邮件。
  • 转换前先把文档照片摆正、裁好，出来的 PDF 会像扫描件而不像随手拍。
  • 带文字的截图更适合用 PNG，可以避免 JPG 在字母边缘产生的压缩毛边。

常见问题

同一份 PDF 里能混用 JPG 和 PNG 吗？

可以。两种格式一起添加就行，每张图片各成一页。工具按你排列的顺序读取，与文件格式无关。

一次能转换多少张图片？

没有固定上限。由于处理在你自己的机器上进行，实际天花板取决于设备内存。较新的笔记本电脑或手机上，一次 50 到 100 张照片通常没问题。

我的照片会被上传到什么地方吗？

不会。PDF 由浏览器用 JavaScript 在本地生成，图片不会离开你的设备。因此用它处理证件、病历等私密材料是安全的。

该选哪种页面尺寸？

如果 PDF 主要在屏幕上看，用贴合图片。如果有人要打印，就选 A4（北美以外地区常用）或 US Letter，图片会居中放在标准纸张上。

工具会加水印或降低图片画质吗？

任何页面上都不会有水印。图片按你提供的画质嵌入，你放进去什么样，PDF 里就是什么样。

需要注册账号或付费吗？

不需要。这个图片转 PDF 工具免费、免注册，每天转换次数也不设上限。打开页面、转换、下载，完事。

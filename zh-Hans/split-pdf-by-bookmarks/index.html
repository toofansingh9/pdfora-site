制作精良的 PDF 自带目录：就是阅读器左侧那个书签面板。PDFora 的「按书签拆分」工具把这些条目当作切割线。每个顶层书签开启一个新文件，而每份输出都以其书签标题命名，所以「第三章：研究方法」会真的变成一个叫这个名字的文件。整套结果打包成一个 ZIP 下载。

拆分的内容不会被上传。书签大纲的读取和页面的分割都在你的浏览器里本地完成，董事会材料、法律文书和尚未出版的书稿因此自始至终留在你自己的机器上。工具免费、免账号、不留水印，你丢多少份文档进去都能拆。

另一条路很惨烈：打开书签面板，记下每章的起始页，跑十几次页码范围拆分，再手动给每个输出改名。按书签拆分把这一切压缩成一次点击，命名也替你做好了。

如何在线按书签拆分 PDF

  1. 打开 getpdfora.com 上的「按书签拆分」工具，处理全程保留在你的浏览器内。
  2. 添加一份带有书签大纲的 PDF，例如报告、手册或电子书。
  3. 工具会读取顶层书签，每一个都标示着一个新文件的起点。
  4. 点击「拆分」。从一个书签到下一个书签之间的页面会被归入各自的 PDF。
  5. 每个输出文件自动以其书签标题命名，不必手动改名。
  6. 下载 ZIP 压缩包并解压，即可得到每一节各成一个、命名合理的文件。

When to use this tool

  • 把 300 页的年度报告按书签分节，让每位部门负责人只拿到自己那一章。
  • 把技术手册拆成按模块划分的 PDF，交给要求一课一个文件的学习平台。
  • 把董事会材料分成一个个议题，各以其书签命名，分发给委员会成员。
  • 把法庭文件按书签拆成各份证据，方便单独引用和分享。
  • 把带书签的菜谱书稿拆成一章一个文件，供负责不同部分的编辑审阅。
  • 把公司手册的各个章节提取出来，人力资源部门可以只更新其中一节而不动其余。

Tips for the best results

  • 拆分前先在 PDF 阅读器里看看书签面板；你在顶层看到的条目，正是刀口落下的位置。
  • 只有顶层书签会触发拆分。嵌套的子书签留在其父级的文件里，这通常正好符合章节与小节应有的归属关系。
  • 如果你的 PDF 没有书签，请先在 PDF 编辑器里添加，或改用按文本拆分或页码范围拆分。
  • 书签标题尽量不要包含斜杠、冒号之类的字符，因为这些标题会成为 ZIP 里的文件名。
  • 长文档会产生很大的 ZIP；虽然全程不涉及上传，但请在下载完成前保持标签页开启。

常见问题

PDF 书签到底是什么？

书签（有时称为大纲）就是多数 PDF 阅读器侧边栏中那份可点击的目录。作者以及 Word、InDesign 之类的导出工具会添加它们来标示章节，本工具正是把这些标记当作拆分点。

输出文件是怎么命名的？

每个文件采用其起始书签的标题，所以名为「附录 B」的书签会生成同名文件。文件名中的非法字符会被自动调整，保证每个文件都能从 ZIP 中干净地解压出来。

我的 PDF 没有书签，还能用吗？

不能直接用，因为大纲正是拆分点的依据。你可以先在 PDF 编辑器里添加书签，或者，如果各节开头有重复出现的关键词，改用 PDFora 的按文本拆分工具。

为什么结果是以 ZIP 形式下载的？

带书签的文档常常会拆成十份、二十份甚至更多，下载一个 ZIP 远比一个个点着下载省事。解压之后，所有已命名的 PDF 都在同一个文件夹里。

工具也会在嵌套书签处拆分吗？

不会，只有顶层条目才开启新文件，书签之下嵌套的一切都随它一起走。这样小节会留在所属章节里，而不是把文档打散成几十个碎片。

这真的免费吗？我的文档私密吗？

两者都是肯定的。无需注册、没有水印、不限使用次数，而且文件完全在你的浏览器里解析和拆分，绝不会传输到服务器。处理时间取决于你的设备和文档的大小。

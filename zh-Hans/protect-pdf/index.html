保护 PDF

先把实际情况说清楚：“保护 PDF”工具目前还不能用。选好文件点按钮后，你只会看到“密码保护功能即将推出”的提示。这个功能需要一条专门的处理流程，我们还在开发中；与其给出一个看起来加了密、实际并不安全的文件，不如直接告诉你还没做好。本页会讲清楚 PDF 密码是怎么回事、这个工具上线后要做什么，以及现在用你电脑里多半已有的软件怎么给文件加密。

PDF 的安全设置其实有两种密码，把它们搞混是最常见的错误。打开密码（也叫用户密码）会对文件加密，没有密码就根本看不到内容。权限密码（也叫所有者密码）则允许任何人打开文件，只是要求阅读软件限制打印、复制文字或编辑等操作。前者是真正的保护；后者要靠阅读软件自觉遵守这些限制标记，而不少软件会直接无视。

保护强度取决于使用的加密方式。现在的 PDF 软件一般采用 128 位或 256 位密钥的 AES 加密；老文件可能用的是 RC4，这种算法已被认为不够安全。用了 AES-256 之后，真正的薄弱环节其实是密码本身：密码太短或太好猜，不管算法多强，都可能被逐个尝试破解出来。

现在怎样给 PDF 加密码

  1. 在 Microsoft Word 中，选择“文件 > 另存为”，类型选 PDF，点开“选项”，勾选“使用密码对文档进行加密”后再保存。
  2. 在 LibreOffice 或 WPS 等办公软件中，用“导出为 PDF”功能，在安全设置里设置打开密码、权限密码或两者都设。
  3. 在 Mac 上，用“预览”打开 PDF，选择“文件 > 导出”，勾选“加密”（或使用权限选项）并输入密码。
  4. 在其他 PDF 编辑软件里，到文件或工具菜单中找“安全”“保护”或“加密”，如果可以选择，请选 AES-256。
  5. 关闭文件后重新打开一次，确认会弹出密码输入框，再发给对方。

适用场景

  • 通过邮件给员工发工资条和收入证明，打开密码另行约定。
  • 把病历或法律文书发给客户，确保只有当事人能看。
  • 房东需要保存租客的证件复印件和担保材料，但不希望它们在共享网盘里谁都能打开。
  • 提前出好的考试卷，在考试前发给同组老师传阅。
  • 通过邮件把纳税资料和银行流水发给会计。
  • 给公开发布的小册子加权限密码，防止别人随手复制内容（要清楚这只是一道门槛，不是一把锁）。

开始前需要了解

  • “保护 PDF”工具目前只会显示“即将推出”，不会改动你的文件。上线之前请用上面介绍的方法。
  • 打开密码会加密内容，没有密码就无法读取文件。机密文档应该用这一种。
  • 权限密码只是设置了限制标记，文字照样可读，而且有些软件根本不执行这些限制。
  • 如果正确加密的文件丢了打开密码，没有任何后门可走。请把密码存在密码管理器里，不要和文件写在同一封邮件里。
  • 加密 PDF 并不能隐藏文件本身或它的文件名，部分元数据也可能仍然可见，具体取决于所用软件。如果文件名本身就敏感，请先改名。
  • PDFora 的其他工具无法打开加密的 PDF；请先完成合并、压缩或编辑，最后再加密码。加了打开密码的文件就算发错了人，对方也打不开，这正是它比直接发附件更实用的地方。

获得最佳效果的技巧

  • 用较长的密码短语，比如四个以上互不相关的词，比一个夹带符号的短密码更好。
  • 密码和文件分开发送，比如 PDF 走邮件，密码用短信或电话告知。
  • 软件允许选择时，选 AES-256；40 位或 RC4 选项只是为了兼容非常老的阅读器，尽量别用。
  • 在安全的地方留一份未加密的原件，以后需要修改时就不必先解锁。
  • 加密放在最后一步：编辑、压缩、合并都做完，再加密码。

实例：一家小型代理记账公司发送报税资料

一家只有两个人的代理记账公司，每到报税季都要把整理好的申报资料发给客户确认。以前他们直接把 PDF 当附件发出去，这意味着任何能看到邮箱、看到被转发的邮件，或者用家里那台共用电脑的人，都能打开。

他们只改了一个环节：资料照常从财务软件导出，再用 LibreOffice 打开，以 AES 加密、带打开密码重新导出一次。密码是客户自己定的一句密码短语，在合作开始时打电话约定好，从不通过邮件发送。邮件照旧发出，客户用只有自己和事务所知道的短语打开文件。

每个客户大约多花一分钟。它防不了客户自己把文件连同密码一起转发出去，弱密码也仍可能被猜中，所以他们要求客户至少用四个词。PDFora 的“保护 PDF”工具上线后，也能放在同一个环节里用；在那之前，桌面软件完全够用。另外值得提前定好由谁来保管密码：在小办公室里，为每个客户在共享密码管理器里建一条记录，就不会出现只有某一个人才能打开去年文件的尴尬。把密码写进邮件正文、文件名，或者贴在显示器边的便签上，等于前功尽弃。加密本身是最简单的部分；现实中的保护大多失败在密码管理上，无论用的是哪款工具。

故障排除

“保护 PDF”工具显示“即将推出”
这是工具目前的状态，它还不会处理文件。请按上文用 Word、LibreOffice、预览或其他 PDF 编辑软件操作。
对方不用密码也能打开我的文件
你多半只设置了权限密码。请设置打开（用户）密码，这样文档才会被加密。
对方的软件不接受密码
非常老的阅读器可能不支持 AES-256。请让对方换用较新的 PDF 阅读器，而不是降低加密强度。
加密后无法再合并或压缩
大多数工具（包括 PDFora）都处理不了加密的 PDF。请在未加密的原件上操作，完成后再重新加密。
禁止打印的限制没起作用
权限标记要靠阅读软件来执行。如果文档绝对不能被打印或复制，光靠 PDF 权限密码不够，应该控制发给谁。
我忘了打开密码
强加密没有找回密码的办法。请回到未加密的原件，或者用当初生成文件的程序重新导出。

常见问题

“保护 PDF”工具现在能用吗？

还不能。目前只会显示“即将推出”的提示，不会改动你的文件。

打开密码和权限密码有什么区别？

打开密码会加密文件，没有密码就看不了。权限密码只是要求阅读软件限制打印、复制或编辑。

加了密码的 PDF 真的安全吗？

使用 AES 加密并配一个足够长的密码，就很难被破解。真正的弱点是太短或太常见的密码。

手机上能给 PDF 加密码吗？

部分手机 PDF 应用支持，一般在分享、安全或导出菜单里。电脑上的 Word、LibreOffice 和预览都自带这个功能。

加密后 PDF 的样子会变吗？

不会。加密不改变内容和版式，只决定谁能打开、阅读软件允许做哪些操作。

这个工具上线后免费吗？

是的，和网站上的其他工具一样，计划免费提供。

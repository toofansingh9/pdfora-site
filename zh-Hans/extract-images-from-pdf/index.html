你真正想要的那张图就藏在 PDF 里——产品照、公司标志、某张图表。截屏只能得到一份被裁切又被压缩的副本。提取则完全不同：这个工具会把 PDF 中原始嵌入的图像以 PNG 文件的形式取出来，分辨率就是当初制作文档时放进去的那一份。所有找到的图片会打包成一个 ZIP，一次下载完事。

整个提取过程都在浏览器里运行。你的 PDF 在自己的设备上被打开、读取，不会上传，因此从机密演示稿、体检报告或尚未发布的宣传册里取图，并不意味着要先把文件交给服务器。无需注册账号，提取出来的文件不带水印，文档数量和图片数量也都不设上限。

有必要弄清楚什么才算「图像」。工具能取回的是以图片文件形式插入文档的照片和图形。文字、矢量标志和绘制的图形属于绘制指令而非图片，因此不会出现在结果里；而扫描版 PDF 本质上每页就是一整张大图，提取出来也正是这样。

如何在线提取 PDF 中的图片

  1. 打开提取图片工具，把 PDF 拖到页面上，或点击选择文件。
  2. 浏览器会在本地扫描文档中嵌入的图像，文件本身哪儿也不去。
  3. 查看在各页中一共找到了多少张图片。
  4. 点击「提取」，把每一张都导出为 PNG 文件。
  5. 下载包含全部提取图片的 ZIP 压缩包。
  6. 解压后挑出需要的图片，其余的删掉即可。

适用场景

  • 中介一直没发原图时，从房源介绍或楼盘宣传册 PDF 里把照片取回来。
  • 从旧的媒体资料包里取出公司标志或产品图，用在新的演示文稿中。
  • 换电脑后源文件丢了，从多年前自己写的报告里提取插图和照片。
  • 从供应商的 PDF 图册中一次性收集全部产品照，用于自家网店，不必逐页截屏。
  • 把导出成 PDF 的幻灯片里的示意图保存下来，方便在图像编辑器里修改或重新裁剪。
  • 从活动手册或电子刊物里取出图片，发到社交媒体上。

获得最佳效果的技巧

  • 提取出来的图片保持嵌入时的分辨率，往往比它在页面上显示的尺寸大得多——用于印刷时常有惊喜。
  • 如果工具没找到任何图片，那些视觉元素多半是矢量图形或纯文字。改用「PDF 转 PNG」把整页转成图片即可拿到它们。
  • PDF 有时会在多个页面复用同一张图，所以 ZIP 里出现少量重复很正常，留下最好的一份即可。
  • 扫描文档每页会得到一张整页图像。那就是扫描件本身，属于正常现象，不是出错。
  • 文档里同时含有几十个小图标时，把解压后的文件夹按图片尺寸排序，能迅速找到高分辨率照片。

常见问题

提取出的图片是什么画质？

每张图都按嵌入时的分辨率提取，并保存为 PNG，导出过程中不会二次压缩。如果文档作者放进去的是高分辨率照片，你拿到的就是它，哪怕它在页面上显示得很小。

提取为什么比截屏好？

截屏得到的是屏幕缩放级别下的画面，通常比原图更小、更糊。提取取回的是真正嵌入的那个文件，尺寸完整、画面干净。

提取过程中我的 PDF 会被上传吗？

不会。文件由你的浏览器在本机解析，提取出的图片也只存在于你的机器上。因此这个工具很适合处理内部资料和机密文档。

为什么有些图形没出现在结果里？

以矢量方式绘制的图表、标志和形状并不是嵌入的图片文件，自然无从提取。用「PDF 转 PNG」工具把那一页渲染出来，就能把它们保存成图像。

提取出的图片以什么形式交付？

每张图都保存为 PNG，并打包进一个 ZIP 压缩包，所以哪怕文档里有四十张图片，也只需下载一次。解压后就能逐一浏览、按需保留。

有数量限制或收费吗？

没有。工具免费、免注册、不加水印，也不限制 PDF 的数量或其中的图片数量。

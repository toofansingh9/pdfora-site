扁平化 PDF

把 PDF 表单中的可填写字段变成固定的页面内容，答案保持原样，再也不能在字段里修改。

一份填好的 PDF 表单，其实是两层内容伪装成一层。页面上显示的是一个写着答案的方框，但方框背后是一个可交互的字段，任何阅读器都能改动它的值，而且不同阅读器有时显示得还不一样。把这样的文件转发出去，对方可能看到空白的框、被替换的字体，或者某个被人不小心重新输入过的字段。扁平化会去掉这层可交互内容，只保留页面上实际画出来的东西。

具体来说，工具用 pdf-lib 打开 PDF，取出表单中的各个字段，把每个字段当前的外观（可见的文字、勾选或选项）画进页面本身，然后删除这些字段。文档的其余部分原样保存，普通文字仍可选中，图片质量也不变。输出文件会在文件名后加上 -flattened。

扁平化是单向操作。字段一旦成为页面的一部分，就再也没有人能重新填写它，也无法把它的值当作数据读出来，包括你自己。对于已签字的申请表或已提交的申报材料，这正是你想要的；对于还要反复使用的模板，则恰恰相反。比较好的习惯是：扁平化后的文件用来发送，可填写的文件自己留着。

如何扁平化 PDF 表单

  1. 先在 PDF 阅读器中或用“填写并签名”把表单全部填好并保存。
  2. 打开“扁平化 PDF”工具，添加填好的 PDF。
  3. 点击“平面化表单”。字段会被画进页面并删除，通常一眨眼就完成。
  4. 下载文件，例如 application-flattened.pdf。
  5. 换一个与填写时不同的阅读器打开它，检查每个答案、勾选和签名是否都显示出来了。

适用场景

  • 填好的租房申请表在发给中介之前先锁定，防止数值被改动。
  • 向不接受带可交互字段 PDF 的在线平台提交入学或奖学金申请表。
  • 在合并多份填好的表单之前先做处理，因为不同文件中同名的字段合并时可能互相冲突。
  • 把已签字的人事或入职表格作为固定记录归档。
  • 确保填好的表单在任何打印机和阅读器上显示一致，包括会忽略表单字段的手机阅读器。
  • 把填好的问卷发给公益组织或调研团队，对方会打印归档，而不是处理字段数据。

开始前需要了解

  • 扁平化只影响可交互的表单字段。评论、高亮和便笺属于另一类批注，不会被处理；如需去掉它们，请使用“移除批注”。
  • 所见即所得。工具绘制的是每个字段保存下来的外观。如果你的阅读器没有为某个字段保存外观，那个答案就可能变成空白。
  • 处理结果无法再填写，字段的值以后也不能作为数据导出。
  • 如果 PDF 中没有表单字段，工具仍会生成一个副本，页面内容没有任何变化。
  • 本来就属于页面的文字不会被动到，因此文档其余部分仍可搜索。来自字段的文字也会成为页面内容。
  • 设有密码或带数字签名的文件不适合处理。加载时会忽略加密，受保护的文件可能输出为无法阅读的内容；而带证书的数字签名在文件有任何改动后都会失效。

获得最佳效果的技巧

  • 扁平化之前先保存一份可填写的副本。万一发现某项写错了，你会希望改字段，而不是从头再填一遍。
  • 在阅读器中保存前，先在最后一个字段外点一下。有些阅读器只有在焦点离开字段时才会保存它的值。
  • 扁平化后要特别检查下拉框和复选框，这两类字段最容易依赖特定阅读器生成的外观。
  • 如果要把多份填好的表单合在一起，先逐个扁平化，再合并这些扁平化后的副本。
  • 如果文档还需要彻底“锁死”成纯图片（任何地方都选不中文字），之后再用“灰度 PDF”或“压缩 PDF”处理一下，这两个工具都会把页面重建为图片。

实例：小企业填写供应商登记表

一家小型餐饮公司被新客户要求填写一份 4 页的供应商登记表：公司信息、银行资信、保险单号，还有一组关于食品安全证书的复选框。客户的采购平台注明只接受不可编辑的 PDF。

老板在浏览器的 PDF 阅读器里填好表格、保存，然后用“扁平化 PDF”处理。在扁平化后的副本中，公司名称、保单号和勾选都显示在页面上，但点击它们没有任何反应，平台也顺利接受了上传。用手机打开同一个文件也能看到答案——而可填写的版本在手机上看不到，因为那部手机的阅读器会忽略表单字段。

检查时发现了一个问题：企业类型的下拉框变成了空白，原因是阅读器没有为它保存外观。重新打开可填写的副本，再选一次该选项，点击别处，保存后再扁平化一次，问题就解决了。

公司把两个版本都存在客户文件夹里：可填写的副本留着明年续签时用，那时大部分答案都不会变；扁平化的副本则作为实际提交内容的记录。文件名写清楚并带上日期，就不会误发可编辑的那一份。

故障排除

扁平化后有些答案不见了
你填写表单时用的阅读器没有为这些字段保存外观。打开可填写的副本，重新输入这些值，每填完一个字段就在外面点一下，保存后再扁平化；或者改用“填写并签名”来填写。
我的文件没有任何变化
这个 PDF 很可能根本没有可交互字段，那些方框只是印上去的线。请改用“填写并签名”或“编辑 PDF”在上面放置文字。
字段里的文字和我输入的看起来不一样
字段是按照它保存的外观和字体设置绘制的。使用特殊字体或自动字号的字段，显示时可能略有不同；检查一下间距，如果文字溢出就重新处理该字段。
评论和高亮还在
这是正常的。扁平化只处理表单字段。如果这些也要去掉，请再运行“移除批注”。
扁平化后的文件内容错乱
源文件很可能设有密码保护。请在生成它的程序中解除保护，再对未加密的副本进行扁平化。
数字签名现在失效了
对已签名文件做任何改动都会破坏基于证书的签名。请在签名之前扁平化，或者直接发送已签名的原文件。

常见问题

扁平化 PDF 和可填写 PDF 有什么区别？

可填写 PDF 带有可交互字段，其中的值可以修改。扁平化 PDF 把同样的答案作为普通内容画在页面上，不再保留任何字段。

扁平化之后还能恢复吗？

不能。字段已经被删除。如果以后可能要改答案，请保留可填写的版本。

扁平化会顺带删除批注吗？

不会。评论、高亮和图章都会保留。如需删除，请单独使用“移除批注”。

文档其余部分的质量会下降吗？

不会。页面不会被重新渲染，只有表单字段被转换，其他文字和图片都原样保存。

扁平化后的文字还能搜索吗？

一般可以，因为字段文字是作为页面文字而不是图片绘制的；不过具体效果取决于该字段外观的生成方式。

扁平化足以防止文档被修改吗？

它能防止别人随手改表单字段，但有 PDF 编辑器的人仍然可以修改页面内容。如果需要法律层面的完整性保障，请在扁平化之后再加数字签名。

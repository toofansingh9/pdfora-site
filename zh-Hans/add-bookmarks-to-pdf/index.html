为了找一节内容，在 90 页的 PDF 里一路滚动，很快就让人厌烦。书签正是解药：阅读器侧边栏里一份可点击的大纲，一下就跳到任意章节或标题。制作精良的 PDF 自带书签，而多数导出件和扫描件都没有。这个工具让你给任意 PDF 添加书签，配上一份真正可导航的目录。

格式再简单不过。每个书签写一行：页码、逗号、标题——第一行「1, 封面」，第二行「3, 第一章」，再往下「12, 附录 A」。工具会根据你的列表生成大纲并写入 PDF。读者随后就能在侧边栏看到文档结构，一次点击跳到任何位置。

和 PDFora 的每个工具一样，文件在你的浏览器里本地处理，绝不上传，内部手册和客户报告因此保持私密。工具免费、免账号、不加水印，文档多长都能处理。

如何在线给 PDF 添加书签

  1. 在工具中打开你的 PDF——它在浏览器内载入，不会发送到任何服务器。
  2. 快速浏览文档，记下每一节开始的页码。
  3. 在书签输入框中，每行写一条，格式为「页码, 标题」——例如先写「1, 封面」，再写「3, 第一章」。
  4. 为你希望出现在大纲里的每一节各写一行：章节、附录、重要附件。
  5. 点击应用，工具会把可点击的大纲写入 PDF。
  6. 下载文件，在阅读器中打开书签面板，逐条测试跳转。

When to use this tool

  • 给自出版电子书加上章节大纲，读者就能像翻正规出版物那样导航。
  • 给 120 页的员工手册配上侧边栏目录——规章、休假、福利、行为准则——同事不用再逢人就问某条在哪。
  • 给合并后的法庭文件里每一份证据加书签，法官助理可以直接跳到「证据 C」。
  • 把课堂笔记按周分节再发给全班，学生能直接翻到自己缺的那一讲。
  • 给扫描版设备手册补上分节书签，原有的导航结构在扫描过程中已经丢失。
  • 把冗长的财务报告按季度和报表类型编成大纲，再分发给董事会。

Tips for the best results

  • 使用 PDF 文件本身的页码，而不是印在页面上的页码——有序言时两者往往对不上。
  • 标题要短、要好扫读；在狭窄的侧边栏里，「第 4 章：定价」胜过一整句话。
  • 按页码顺序列出条目，大纲才能像真正的目录一样自上而下读下来。
  • 封面和目录页也加上书签——读者总希望有条路回到开头。
  • 对超长文档，不要只标章，把每个主要标题都标上；200 页的文件值得有 20 条书签，而不是 5 条。

常见问题

PDF 书签究竟是什么？

书签又叫大纲，就是多数 PDF 阅读器侧边栏里那个可点击的导航面板。每一条都是一个链接到某页的标题，点「第三章」就直接跳过去。它们随文件一起走，所以你发给谁，谁都能用上同样的导航。

书签列表怎么写？

每行一条书签，写成页码、逗号、标题。例如第一行「1, 封面」，第二行「3, 第一章」，第三行「15, 第二章」。语法就这么多。

这和目录页是一回事吗？

作用相同，但它在阅读器侧边栏里，而不是印在纸面上，而且每一条都能点击。很多人添加书签，恰恰是因为自己的 PDF 只有一页点不动的印刷目录。

书签会改变我 PDF 的页面吗？

不会。页面、文字和排版分毫未动。书签存放在文件内部一套独立的导航结构里，因此文档打印和显示效果与之前完全一致——只是导航方便太多了。

书签在所有 PDF 阅读器里都能用吗？

能。工具写入的是标准 PDF 大纲，Adobe Acrobat、浏览器内置阅读器、Mac 上的「预览」以及手机 PDF 应用都能识别。视阅读器不同，这个面板可能叫「书签」「大纲」或「目录」。

我的文档能保密吗？

能。PDF 完全在浏览器内处理，绝不上传，机密报告和手册始终留在你的机器上。工具同样免费，无需注册，也不加水印。

解锁 PDF

在浏览器里直接去掉你有权解锁的 PDF 的打开密码，以及打印、复制和编辑限制。

🔒 你的文件在浏览器本地处理，绝不会被上传。

银行发来的电子流水、信用卡账单、保险通知书，常常用身份证后六位或出生日期加了密码。文件通过邮件传递时，这样做很合理；可到了自己手里，它就成了麻烦：贷款平台不接收加密文件，合并、压缩、OCR 工具也打不开它们。“解锁 PDF”会另存一份没有密码的副本，文件直接就能打开，也能在本站的其他工具里接着用。

解锁不是破解。如果 PDF 打开时要求输入密码，工具也需要这个密码：它先核对密码，用它解密内容，再写出一份去掉加密和全部限制的副本。密码不对，它会直接告诉你并停下，不会去猜。另一种情况是文件不用密码就能打开，只是禁止打印、复制或编辑：这类文件的内容本来就可读，所以工具不需要密码就能去掉这些限制。

实际处理由 qpdf 完成，这是一个开源 PDF 库，编译成 WebAssembly 后在你第一次使用时从本站加载到浏览器标签页里（约 1.3 MB）。你的文件和输入的密码都留在你的设备上。页面不会被重新渲染，所以文字依然可以选中，链接和书签照常可用，结果看起来和受保护的原文件一模一样。

如何去掉 PDF 的密码

  1. 打开“解锁 PDF”，添加一个受保护的文件。
  2. 如果这个 PDF 打开时要求输入密码，就把密码填进“当前密码”。如果它不用密码就能打开，只是不能打印或复制，这一栏留空即可。
  3. 点击“解锁 PDF”。工具会先检查文件是否真的受保护，以及密码是否正确。
  4. 下载 yourfile-unlocked.pdf。
  5. 打开新副本，确认不再弹出密码提示，然后继续用“合并 PDF”“压缩 PDF”或你原本要用的工具处理。

适用场景

  • 每月用身份证后六位加密的银行流水或信用卡账单，贷款机构要求合并成一个文件上传。
  • 因为加了密而被签证申请或招聘平台拒收的工资单、收入证明。
  • 你自己多年前加过密码的旧文件，密码还记得，但不想每次都输。
  • 一份可以直接打开但禁止打印的报告，而你是作者本人，或已征得所有者同意打印。
  • 需要交给“压缩 PDF”“OCR PDF”“拆分 PDF”或“页码”处理的文件，这些工具无法处理加密 PDF。
  • 需要长期归档的文件，不希望将来能否打开取决于记住每个文件各自的密码。

开始前需要了解

  • 如果 PDF 打开时需要密码，就必须提供这个密码。工具会先核对，密码不对时提示“密码错误 — 文件未解锁。”，而不会写出一个打不开的文件。
  • 它无法找回或破解忘记的密码。一个正确加密的文件，没有密码就始终是锁着的；请向发件方索要密码或一份未加密的副本。
  • 不用密码就能打开、但带有权限限制的文件，可以不输密码直接解锁，打印、复制和编辑限制会全部去掉。
  • 如果文件根本没有任何保护，工具会提示“此 PDF 没有密码保护 — 无需移除。”，而不是给你一份一模一样的副本。
  • 移除是彻底的：加密和所有限制一并去掉，没有只保留部分限制的选项。如果想恢复限制，就把解锁后的副本用“保护 PDF”按新设置重新保护。
  • 只对你有权解锁的文件使用：你自己的文件，或者所有者同意解锁的文件。出版社电子书或付费报告上的限制通常是有意设置的，去掉它们可能违反使用条款或著作权法。

获得最佳效果的技巧

  • 翻一翻随加密账单一起发来的邮件或短信，密码规则通常写在那里，比如“身份证号后六位”或“出生日期八位数字”。
  • 密码最好手动输入，不要粘贴。粘贴的密码常常在末尾带一个看不见的空格，这就会被当成密码错误。
  • 解锁一份工作副本，把受保护的原件留作存档。
  • 如果上传平台报错时提到“加密”“受保护”或“密码”，解锁就是解决办法。
  • 临时用完的解锁副本要删掉；如果还得把结果再通过邮件发出去，先用“保护 PDF”重新加密。

实际示例：为房贷申请准备六个月的银行流水

一对夫妻申请首套房贷，银行要求把丈夫工资卡最近六个月的流水合并成一个 PDF 上传。手机银行导出的电子流水每月一份，每份 3 到 5 页、约 250 KB，全部用他身份证号的后六位加了密。可贷款平台的上传页面不接收加密文件。

他们把六份流水依次放进“解锁 PDF”，每次输入同样的密码。第一份因为要加载引擎花了几秒钟，后面五份几乎瞬间完成，每份解锁后的副本都和原文件大小相近，文字也照样能选中。处理第三份时，他手快把身份证末尾的大写 X 输成了小写，工具提示“密码错误 — 文件未解锁。”，改成大写后重新运行就好了。接着他们把六份副本按月份顺序放进“合并 PDF”，得到一个 25 页、约 1.5 MB 的文件，平台顺利接收。

上传完成后，他们把下载文件夹里的六份解锁副本和合并文件都删掉，银行发来的加密原件则留在手机银行和邮箱里作为存档。银行加的密码在流水通过网络传递时已经尽到了职责；文件到了自己电脑上之后，解锁一份工作副本是很正常的操作，前提是解锁后的文件不要再不加保护地发出去。

故障排除

提示“此 PDF 需要打开密码”
文件设置了打开密码。把密码填进“当前密码”，再运行一次。
提示“密码错误”
检查大写锁定、输入法状态和末尾空格，再重新看一遍发件方给的密码规则。有的银行要求身份证号里的 X 大写，有的要求小写。
提示“此 PDF 没有密码保护”
没有需要去掉的东西。如果别的工具还是拒绝这个文件，那多半是文件损坏而不是受保护，可以试试“修复 PDF”。
我不知道密码
工具无法查出或猜出密码。请查看随文件发来的邮件或短信，或者向发件方索要密码或未加密的副本。
加密引擎加载不出来
引擎在第一次使用时从本站加载。脚本拦截插件、公司网络过滤或网速太慢都可能让它卡住；请刷新页面后重试。
提示“无法解锁此 PDF”
文件很可能已经损坏。先用密码在阅读器里打开，通过“打印为 PDF”或“另存为”得到一份副本，再对这份副本解锁或修复。

常见问题

“解锁 PDF”能去掉我不知道的密码吗？

不能。对于打开时要求密码的文件，它需要这个密码，而且不会猜测或破解密码。只有文件本来就能直接打开时，它才能在没有密码的情况下去掉限制。

我的文件或密码会被上传吗？

不会。解锁引擎在浏览器里运行，PDF 和密码都留在你的设备上，关闭标签页后什么也不会保留。

打印和复制限制也会去掉吗？

会。解锁后的副本既没有加密，也没有权限限制，在任何阅读器里都能打印、复制和编辑。

解锁会改变内容或画质吗？

不会。页面不会被重新渲染，文字、图片、链接和书签都保持原样，去掉的只是加密。

去掉 PDF 密码合法吗？

去掉你自己文件上的保护，或在所有者许可下去掉，一般没有问题。去掉你无权处理的内容上的限制，可能违反出版方的条款或著作权法。

可以一次解锁好几份账单吗？

工具一次处理一个文件。第一次运行后引擎已经加载好，之后每个文件只需片刻。

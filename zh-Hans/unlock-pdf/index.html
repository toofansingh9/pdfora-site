带密码的 PDF 挺好，直到它是你自己的文件、而密码提示框第二十次弹出来。银行对账单、工资单、保单——很多文件到手就是锁着的，每次打开都要输一遍密码，很快就让人烦躁。PDFora 的解锁工具能从你自己拥有的 PDF 上移除已知密码，给你一份像普通文件一样直接打开的干净副本。

把话说在前面：解锁功能目前在 PDFora 上标注为「即将推出」，正在路上。本页说明的是它上线后的工作方式——免费、免注册、无水印、不限量。而且由于解锁在浏览器本地进行，受保护的文档和你输入的密码自始至终留在你的设备上，什么都不会被上传。

有一点它绝不是：密码破解器。你必须知道当前密码才能移除它，而且你只应解锁自己拥有或明确获准打开的 PDF。未经授权去掉他人文档的保护可能违法。解锁功能的存在是为了正当的便利，而不是为了绕过安全措施。

如何在线移除 PDF 密码

  1. 打开 getpdfora.com 上的「解锁」工具，选择有密码保护的 PDF。文件留在你的设备上，不会上传。
  2. 按提示输入文档当前的密码，以此证明你有权打开它。
  3. 确认你要移除保护。
  4. 工具会在你的浏览器里本地解密文件，生成一份已解锁的副本。
  5. 下载新的 PDF。它在任何阅读器中都能立即打开，不再弹出密码框。
  6. 视你是否还想留一份受保护的副本，决定保留还是删除原来的加锁版本。

When to use this tool

  • 去掉每月银行对账单的密码，好让会计的软件在报税时能读取它们。
  • 解锁雇主用你的出生日期加密发来的工资单，再归入自己的资料文件夹。
  • 移除保单 PDF 的密码，真正着急要用的时候能立刻打开。
  • 解锁电子票或预订确认单，在值机柜台前秒开，不必依赖信号去查密码。
  • 为合并或压缩准备加锁的报告——多数 PDF 工具在文件解锁之前都无法处理加密文件。
  • 趁密码还记得，把那些受保护的旧档案整理成普通文件，免得日后彻底忘掉。

Tips for the best results

  • 对账单一到手就解锁。三年之后，你不会记得哪个季度用的是哪种密码格式。
  • 如果文件是银行加的锁，密码往往就印在邮件里——通常是出生日期或账号片段。
  • 解锁之后请把文件存放在私密的地方；此前守护它的就只有那个密码。
  • 如果这份文档以后还要通过邮件传送，请把加锁的原件留着。
  • 先解锁，再编辑、合并或压缩——解密是其他所有操作都得等着的那道门。

常见问题

解锁工具已经上线了吗？

它目前标注为「即将推出」，正在逐步放出。如果你今天就急需移除 PDF 密码，有一条可靠的桌面端路径：用密码在 PDF 阅读器中打开文件，然后打印或导出为一份不带保护的新 PDF。

不知道密码的话，这个工具能解锁 PDF 吗？

不能，这是刻意为之。你必须输入正确的密码才能移除它——工具是在解密你的文件，而不是破解它。找回遗忘的密码既不在它的能力范围内，我们也从不这样宣称。

移除 PDF 密码合法吗？

移除你自己文档的密码，或者你获准打开的文档的密码，一般没有问题。绕过你并无权限的文件的保护，则可能触犯著作权法和计算机滥用相关法律。请只解锁你有权解锁的 PDF。

我的文件或密码会被上传吗？

不会。解密完全在你的浏览器里运行，加锁的 PDF 和你输入的密码都留在你的设备上。对于财务和身份类文档来说，这与基于上传的解锁网站是实实在在的区别。

解锁会改变 PDF 的外观吗？

不会。移除加密不触碰内容——文字、图片、版式和页序都原样保留，唯一的变化是密码提示框消失了。

那些能正常打开、却禁止打印或复制的 PDF 呢？

那属于所有者密码保护，而不是打开密码。这类限制由文档创建者设定，除非文档是你自己的，或作者已允许解除，否则你应当尊重这些限制。

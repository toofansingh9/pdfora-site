扫描的合同一打开是躺着的。横向图表被困在纵向文档里。页面不知在扫描仪到收件箱之间的哪一步翻了个底朝天。PDFora 的旋转工具几秒钟就能全部修好：把每一页，或者只把你挑中的那几页，顺时针旋转 90 度、逆时针旋转 90 度，或整整转 180 度。旋转结果写入文件本身，因此这份 PDF 走到哪里，页面都保持正立。

与多数在线转换工具不同，PDFora 绝不会把你的文档上传到服务器。整个旋转过程用 JavaScript 在浏览器本地完成，这意味着已签署的租约或体检报告绝不会离开你的电脑。无需安装，无需注册账号，事后也不会在页面上打水印。连续旋转一个文件还是五十个都行，没有每日限制。

选择性旋转才是这个工具真正的价值所在。输入类似「1,3-5」的页码范围，就只有这些页面被旋转，其余保持原样。这样，要修正埋在四十页纵向报告里的某一张横向表格，根本不必打开付费 PDF 编辑器。

如何在线旋转 PDF

  1. 在任意现代浏览器中打开 getpdfora.com 上的 PDF 旋转工具。
  2. 把 PDF 拖到页面上，或点击浏览选择。文件在本地加载，绝不上传。
  3. 选择角度：顺时针 90°、180°，或逆时针 90°。
  4. 决定是旋转全部页面还是仅特定页面。若为指定页面，输入类似「1,3-5」的范围。
  5. 点击旋转，查看预览，确认每一页的朝向都正确了。
  6. 下载修正后的 PDF。新的方向已永久保存在文件中。

适用场景

  • 提交报销单前，修正手机扫描应用横着拍下的一批收据。
  • 把年报中横向的财务表格转正，评审无需歪着脑袋阅读。
  • 修正已签署协议中因送纸方向反了而颠倒的那一页。
  • 整理方向混杂的导出课件，让它们都能按纵向讲义一致地打印。
  • 把建筑图纸旋转 90 度，让标题栏落在印刷店预期的位置。
  • 把传真来的采购订单转正，再转交给财务。

获得最佳效果的技巧

  • 旋转以 90 度为步进。如果某页只是扫描时略微歪斜，那属于倾斜问题，应重新扫描或做纠偏处理。
  • 拿不准该往哪边转？想象页面的上边缘：顺时针把它送到右边，逆时针把它送到左边。
  • 扫反的文档用 180°；转两次 90° 也能到位，但点一下显然更快。
  • 页码范围同时支持逗号和短横线，所以「2,6-9,14」会精确旋转这五页，别的都不动。
  • 先旋转，再合并或拆分。先把方向修好，后续所有副本都会继承这个修正。

常见问题

旋转是永久性的，还是只是一个查看设置？

是永久性的。PDFora 会把页面方向重写进文件内部，因此在 Adobe Reader、手机、打印对话框以及其他任何地方，页面都保持旋转后的状态。不必每次打开文件都重新转一遍。

可以只旋转 PDF 中的部分页面吗？

可以。切换到指定页面模式，输入类似「1,3-5」的范围。只有这些页面会转，文档其余部分保持原有方向。

我的文件会被上传到服务器吗？

不会。工具完全在浏览器中运行，PDF 在你自己的设备上处理，绝不经由互联网传输。因此处理合同、证件扫描件等私人材料都很安全。

有文件大小或使用次数限制吗？

PDFora 免费，无需注册，没有水印，也没有每日上限。由于处理在本地进行，超大文件取决于你设备的内存而不是服务器配额，大多数文档一两秒就转好了。

旋转会降低 PDF 的质量吗？

不会。旋转只改变每页的方向标记；内部的文字、图片和矢量内容都不受影响。输出质量与原件相同，文件体积通常也几乎不变。

可以旋转有密码保护的 PDF 吗？

如果文件需要密码才能打开，请先移除或输入密码，因为浏览器没有密码就无法读取加密内容。PDF 能正常打开后，旋转与其他文件别无二致。

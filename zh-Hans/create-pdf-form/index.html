大多数表单一开始都是静态文档：一份 Word 导出件、一张扫描图，或者一个设计精美却指望别人凭空填写的 PDF。人们只好打印出来、手写、再扫描回去——或者在编辑器里别扭地覆盖输入。这个工具终结了这套循环：它让你在现有文档上放置真正可交互的文本框和复选框，做出一份可填写的 PDF 表单。

操作方式很直接。PDF 显示在屏幕上，你在需要填答案的位置一点，那里就出现一个字段。拖动字段微调位置，调整大小让它正好盖住下方的空格，在“是/否”选项旁边加上复选框。导出时，你得到的是真正的 AcroForm PDF——Adobe Acrobat、浏览器和手机阅读器都能填写的标准交互格式。

被改造的文档始终不会离开你的电脑，因为一切都在浏览器本地运行。无需注册，表单上不会被打上水印，不收费，做多少份表单也没有限制。

如何在线制作可填写的 PDF 表单

  1. 打开你想改成可填写的 PDF——申请表、合同或问卷。文件在浏览器本地加载。
  2. 在页面上需要输入答案的位置点击，该处即出现一个文本框。
  3. 在“是/否”项目或多选选项旁边点击，添加复选框。
  4. 拖动每个字段与印在页面上的空格对齐，并调整大小，让较长的答案也有足够空间。
  5. 逐页重复，直到每个问题都有对应的字段。
  6. 导出文件——你会得到一份真正可填写的 AcroForm PDF，可以直接发出去，收件人用任何标准 PDF 阅读器都能填写。

When to use this tool

  • 把租客过去要打印再扫描的租房申请表，变成可以在手机上直接填完的表单。
  • 让俱乐部入会表或活动报名表可填写，收回来的就是打字内容而不是手写字迹。
  • 把患者初诊问卷做成交互表单，诊所可以在就诊前用邮件发给患者。
  • 给自由职业合同模板加上字段，每位新客户的姓名、日期和费率都能干净地填进去。
  • 把一张老旧的扫描版家长同意书重建成可填写 PDF，家长通过邮件回传。
  • 为内部报销单或请假申请配上正规字段和复选框，不必再让同事直接改文件。

Tips for the best results

  • 文本框尺寸要留富余——邮箱地址所需的宽度往往超出你的预估，字段太挤会让填写者很烦躁。
  • 让字段与页面上印好的空格和标签对齐：底层文档负责提供说明文字，你的字段负责承接输入。
  • 凡是选项固定的内容都用复选框，别指望别人在文本框里打一个 X。
  • 发出去之前自己先完整填一遍——两分钟的测试就能揪出错位或遗漏的字段。
  • 把导出的可填写版本留作母版模板，填好的副本日后可以考虑做扁平化处理，防止答案被改动。

常见问题

AcroForm 是什么？

AcroForm 是交互式 PDF 表单的标准格式，几乎所有 PDF 阅读器都支持——Acrobat、浏览器内置查看器、预览、手机 App 都可以。本工具导出的是真正的 AcroForm 字段，而不是外观相似的覆盖层，所以你的表单在任何环境下都能填写和保存。

必须有一个现成的 PDF 才能开始吗？

是的——本工具是在你已有的文档上添加字段，比如设计好的表单、合同或扫描件。你可以在任意软件里做好版式，导出为 PDF，然后到这里放置字段。

字段放好之后还能调整吗？

可以。每个字段都能拖动到新位置，也能拖边框调整大小，直到正好落在它对应的横线或方框上。放错位置只是两秒钟的事，不用推倒重来。

可以添加哪些字段类型？

用于输入文字的文本框，以及用于选项的复选框——这两种基础组件足以覆盖绝大多数现实中的表单：申请表、登记表、合同、报名表和签核单。

收件人能保存填好的答案吗？

能。因为导出的是标准可填写 PDF 表单，收件人用任何现代阅读器打开、输入答案、勾选方框，然后保存或回传文件，数据都会保留。

我上传的文档会保密吗？

根本没有上传这一步——PDF 完全在你的浏览器里处理，绝不接触服务器。再加上无需注册、没有水印、没有使用次数限制，你可以免费制作任意数量的可填写表单。

翻转 PDF 就是把页面做成镜像：水平翻转让左右对调，垂直翻转则让页面上下颠倒。这听上去像个冷门需求，直到你真的碰上——需要反着印的 T 恤烫画、扫描出来变成镜像的文件，或者要送去丝网印刷、工艺上就要求反版的稿件。

PDFora 的翻转工具做的正是这件事，每个方向一键搞定。选「水平」就像照浴室镜子那样左右镜像，选「垂直」则上下对折镜像。变换会应用到整份文档，下载前还能先预览，不必猜自己到底需要哪个方向。

和 PDFora 上的其他工具一样，翻转在你的浏览器里完成，文件不会接触任何服务器。设计稿和文档因此保持私密，而且省去了上传等待，速度很快。工具免费、免账号、不加水印，文件数和页数都不设限。

如何在线翻转 PDF

  1. 用任意较新的浏览器打开 PDFora 的「翻转 PDF」工具。
  2. 把 PDF 拖到上传区，或点击从设备中选择文件。
  3. 选择方向：「水平」左右镜像，「垂直」上下镜像。
  4. 点击「翻转」，浏览器会在本地完成镜像变换。
  5. 查看预览，确认页面的翻转方向符合预期。
  6. 下载镜像后的 PDF，可直接付印或继续编辑。

When to use this tool

  • 把设计稿水平镜像后再印到烫画纸上，烫压到布料上时图案方向才是正的。
  • 为丝网印刷或菲林输出准备稿件，这类流程要求提供反版的母版。
  • 修正扫描仪或拍摄应用设置不当、把文件存成了镜像的问题。
  • 把车窗贴纸上的文字反过来，贴在玻璃内侧时从外面看才正常。
  • 翻转木工或手工用的镂空模板图样，让描线的那面最终藏在材料背面。
  • 为需要照着反向范本练习的书法或美术字学员制作镜像练习页。

Tips for the best results

  • 做烫画请用水平翻转。文字在屏幕上和烫画纸上看起来应该是反的，压烫到衣服上之后才是正的。
  • 别把翻转和旋转搞混。垂直翻转得到的是镜像，不是旋转 180 度，文字依然无法阅读，而不只是倒过来。如果页面只是上下颠倒，请改用旋转工具。
  • 打印前先预览。烫画纸不便宜，花十秒钟检查一下镜像预览，就能省下一张废纸。
  • 保留未翻转的原件。你往往两个版本都要用：一个用来打样，一个用来生产。
  • 翻转的逆操作还是它自己。对镜像文件再做一次同方向翻转就能还原，用来把翻反的扫描件掰正很方便。

常见问题

水平翻转和垂直翻转有什么区别？

水平翻转把页面左右镜像，像把纸举到镜子前一样，文字会变成反的。垂直翻转则是上下镜像。两者都产生镜像，区别只在对称轴不同。

翻转和旋转 PDF 是一回事吗？

不是。旋转是把页面转个方向，在新方向上文字依然可读；翻转产生的是镜像，文字是反的。如果页面只是横倒或上下颠倒，你需要的是旋转工具。

我为什么会需要镜像的 PDF？

最常见的原因是转印类印刷：烫画、丝网印刷和贴在玻璃内侧的贴纸都要求反版稿件，成品方向才正确。镜像还能修正意外被拍成镜像的扫描件。

翻转会作用于文档中的每一页吗？

会，所选方向会应用到全部页面，保证输出前后一致。如果只需要翻转其中某些页面，可以先拆分 PDF，翻转需要的部分，再把文档合并回去。

翻转时我的文件会被上传吗？

不会。镜像变换完全在你的浏览器里计算，PDF 不会离开你的设备。机密设计稿和文档保持私密，而且因为不用上传下载，处理很快。

使用这个工具要花钱或有限制吗？

都没有。翻转免费、免注册、不在页面上打水印，文件大小、页数和使用次数也都不设上限。翻一页还是翻一百份文档，都一样好用。

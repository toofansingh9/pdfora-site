扫描时混进来的空白页、重复的一张幻灯片、一份绝对不能发给客户的内部报价单——几乎每份 PDF 都会夹带一两页非删不可的内容，而 PDFora 的删除工具能把它们干净利落地拿掉。输入要删除的页码，比如 2, 5-7，然后下载一份只包含其余内容的新 PDF。

和大多数网页工具不同，PDFora 从不接收你的文件。删页操作由你的浏览器在本机完成，装满姓名、数字或谈判条款的文档始终留在原处。删页本身往往就是为了拿掉不该外传的内容，若在这个过程中还要把文档交给第三方服务器，未免自相矛盾。

工具免费，也不需要注册账号。下载的文件不带水印，删多少页、清理多少份文档都没有限制。原始 PDF 保持不变，万一某一页删了才发现有用，还有退路。

如何在线删除 PDF 页面

  1. 打开 getpdfora.com 上的「删除页面」工具，无需登录，秒开即用。
  2. 选择要精简的 PDF，或直接把文件拖到页面上。
  3. 输入要删除的页码，单页和范围可以混着写，例如 2, 5-7。
  4. 继续之前核对一遍页码，把封面页算错是最常见的失误。
  5. 点击「删除」，浏览器会在本地重建不含这些页面的 PDF。
  6. 下载精简后的文件——凡是你没列出的页面，都按原顺序保留着。

When to use this tool

  • 去掉双面扫描仪在每张正页之间插入的空白背面。
  • 把宣传册里过期的报价页删掉，再发给新的潜在客户。
  • 存档杂志 PDF 前，剪掉其中的广告页和订阅回执卡。
  • 从合同里删除草稿页或已被取代的版本，确保外传的只有终稿。
  • 把练习册 PDF 里的答案页删掉，再发给学生。
  • 删掉报告里大段的格式化条款页，把文件压到上传大小限制以内。

Tips for the best results

  • 整块删除时用范围而不是逐个页码——写 12-19 比手动敲八个数字省事得多。
  • 删除页面和提取页面是一体两面：如果最终保留的还不到全文的一半，直接提取要留的那部分更快。
  • 分享之前先打开成品翻一遍，尤其是页码本来就印在页面上的文档。
  • 长文档里零散删页时，可以用「整理」工具的缩略图视图，用眼睛直接标记要删的页，不必逐个数页码。
  • 在精简版完成使命之前，先把没动过的原件留着。

常见问题

怎样一次性删除 PDF 中的多个页面？

把它们一次全列出来，用逗号隔开——写成 2, 5-7, 11 就能一次删掉第 2 页、第 5 到 7 页和第 11 页，不必一页一页反复操作。

被删掉的页面还能从新文件里恢复出来吗？

不能，这正是重点：下载的 PDF 从一开始就不含这些页面，接收方无从挖出。而你手上的原始文件仍然保留着全部页面，本地并没有任何损失。

在线删除敏感文档的页面安全吗？

用 PDFora 是安全的，因为文件根本不离开你的浏览器。处理在本地完成，删除机密页面并不意味着要把这份机密文档上传到什么地方。

删除 PDF 页面会破坏链接或书签吗？

保留下来的页面内容和排版完好无损。原本指向被删页面的书签或内部链接会失去目标，这在任何删页工具中都是正常现象。

需要安装软件或注册吗？

都不需要。工具在电脑或手机的任意现代浏览器中运行，免费、免账号，输出文件也不带水印。

能处理非常大的 PDF 吗？

可以，上限取决于你的设备而不是服务器配额。由于计算由浏览器完成，几百页的文件在多数机器上处理得很快，不过体量惊人的扫描文档需要更多内存。

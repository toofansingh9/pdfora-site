批量扫描很高效，直到你需要把文档重新分开。40 张发票一次过扫描仪，你得到的是一份没有明显接缝的长 PDF。PDFora 的按文本拆分工具会替你找出这些接缝：选一个关键词，比如“发票”，凡是包含它的页面就成为一个新文件的首页。跑一遍，这批材料又变回 40 份独立文档。

由于文本搜索在你的浏览器本地运行，被拆分的发票、工资单或客户对账单绝不会上传到任何地方。这与基于服务器的拆分工具有实质区别——在那里，财务文档在处理期间要待在别人的机器上。PDFora 免费、无需注册、不加水印，文件数量和拆分次数也不设限。

还有一个不区分大小写的选项，让“INVOICE”“Invoice”和“invoice”都能触发同一次拆分，在文档来自使用不同模板的多家供应商时很实用。请挑一个能稳定出现在每份文档首页、且只出现在那里的词。

如何在线按关键词拆分 PDF

  1. 打开 getpdfora.com 上的“按文本拆分”工具。你的文件将完全在浏览器中处理。
  2. 添加合并在一起的 PDF，例如一批扫描的发票或对账单。
  3. 输入标记每份文档起始位置的关键词，比如“发票”或“账户对账单”。
  4. 如果各文档中该词的大小写不一致，请开启不区分大小写选项。
  5. 点击拆分。每当某页出现该关键词，就会开始一个新文件。
  6. 核对输出文件的数量是否与你预期的文档份数一致，然后下载。

When to use this tool

  • 以“发票”为分隔词，把扫描成一叠的供应商发票拆成一票一档。
  • 按“员工工号”拆分工资发放批次，生成一份份独立工资单，每个人只收到属于自己的页面。
  • 为贷款申请，按“账单周期”把一整年合并的银行对账单拆开。
  • 按“采购订单号”把导出为单一 PDF 的一批采购订单分开。
  • 按“保单号”拆分保险批次，让每位客户的凭证能单独归档。
  • 打印面单前，按“运单号”把合并的运输标签文件切分开来。

Tips for the best results

  • 关键词必须以可搜索文本的形式存在。如果你的 PDF 是没有 OCR 图层的纯图像扫描件，请先做 OCR，否则搜索什么也找不到。
  • 选一个只出现在首页的词组。若“发票”仅作为每份文档的标题出现，它就好用；如果页脚里也有，请改用“发票号：”之类的词。
  • 词组通常比单个词更保险；“税务发票”比单独的“税务”产生的误拆要少得多。
  • 在处理 500 页的大批量之前，先用小样本测试，并把输出文件数与你扫描的文档份数对一对。
  • 如果多出一个文件，多半是关键词恰好也出现在最开头那一页，这是意料之中的；若多出更多，说明你的关键词在文档中间的页面上也匹配到了。

常见问题

按文本拆分 PDF 是怎么工作的？

工具会读取每一页的文本层，每当某页包含你的关键词，就开启一个新的输出文件。两次匹配之间的页面留在一起，因此每个输出文件都包含一份完整文档：从关键词所在页起，到下一次匹配的前一页止。

为什么找不到我的关键词？

十有八九是因为这份 PDF 是没有可选中文本的扫描图像。在 PDF 查看器里试着选中文字；如果无法选中词句，请先对文件做 OCR，然后再拆分。

不区分大小写这个选项重要吗？

多数时候重要。各供应商模板对大小写的处理并不统一，一份写“INVOICE”、另一份写“Invoice”，不开这个选项就会拆得不一致。除非你确实需要严格匹配大小写，否则建议开启。

用这个工具处理财务文档安全吗？

安全，因为它们从不离开你的设备。搜索和拆分都在浏览器本地进行，不上传、不在服务器端存储，也不会有账号与你的文件绑定。

可以按多词词组拆分吗？

可以，“账户对账单”这类词组是有效的，而且通常比单个词更精确。词组越长、越具体，就越不容易在只是顺带提到该词的页面上误拆。

文件大小或拆分数量有限制吗？

没有。PDFora 免费、无需注册、不加水印，对页数、输出文件数以及处理多少批材料都不设上限。超大文件只是耗时更久，因为干活的是你自己的电脑。

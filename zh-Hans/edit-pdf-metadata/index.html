每个 PDF 都带着一层隐藏信息：标题、作者名、主题和一组关键词。搜索工具、文件管理器和文档库读取的第一样东西就是这些字段。当元数据不对时——一份报告标题写着“无标题”，作者是“user123”——文件既显得草率，也更难被找到。这个工具让你直接在浏览器里编辑 PDF 元数据。

打开文件，当前的标题、作者、主题和关键词就会出现在普通文本框里。改掉需要改的，其余原样保留，然后下载一份干净的副本。很多 PDF 的元数据是从多年前制作模板的人那里继承下来的，所以一份客户提案的作者可能还挂着已离职员工的名字。在这里修正只需约三十秒，也不用安装任何软件。

所有操作都在浏览器本地运行。PDF 绝不会离开你的电脑，这在整理合同、病历或其他机密资料时格外重要。工具免费，不要求注册，不添加水印，处理多少文件也没有限制。

如何在线编辑 PDF 元数据

  1. 点击上传区域或把 PDF 拖进去——文件在本地打开，不会发送到服务器。
  2. 查看自动载入的现有元数据：标题、作者、主题和关键词。
  3. 输入新的标题。大多数搜索工具和阅读器显示的就是这段文字，所以要写得有描述性。
  4. 更新作者字段；如果希望文件日后更容易被找到，也可以调整主题和关键词。
  5. 把不想保留的字段清空——留白也好过填错。
  6. 点击应用更改，下载更新后的 PDF。

When to use this tool

  • 修正一份在所有 PDF 阅读器里都显示为“Microsoft Word - draft_v3_FINAL.docx”的报告标题。
  • 在把提案发给客户之前，替换掉作者字段里已离职同事的名字。
  • 给数百份归档发票补上关键词，让文档管理系统真的能在搜索中找到它们。
  • 在发布电子书或白皮书之前设置正确的 PDF 标题和作者，因为某些搜索引擎会在结果中展示元数据里的标题。
  • 在对外分享前清除 PDF 的主题和关键词字段，抹掉内部项目代号。
  • 统一一批扫描件的标题和作者——它们从扫描仪出来时全叫“Scan0001”。

Tips for the best results

  • 元数据标题不等于文件名——有些 PDF 阅读器在窗口标题栏里显示的是元数据标题，所以两者都要设置好。
  • 关键词之间用逗号分隔；简短具体的词组比冗长的句子更有效。
  • 匿名发布的文档要把作者字段清空，因为 PDF 制作软件常常悄悄替你填上。
  • 打算在网上发布的文件，标题就照页面大标题的写法来写——它可能影响文档在搜索结果中的呈现方式。
  • 在组织内部统一作者字段的写法，比如“Acme Ltd 市场部”，这样文件排序才有规律可循。

常见问题

什么是 PDF 元数据？

元数据是存储在 PDF 内部的描述性信息：标题、作者、主题和关键词。它不会出现在页面上，但文件管理器、搜索工具和 PDF 阅读器会显示并索引它——相当于贴在文档外面的标签。

编辑元数据会改变 PDF 的外观吗？

不会。页面、字体、图片和版式都保持原样。被改写的只有隐藏的描述性字段，因此下载到的文档在打印和显示上与原件完全一致。

我的文件会上传到服务器吗？

不会。工具完全在浏览器中以本地方式处理，PDF 绝不离开你的设备。因此用来处理机密合同、财务报表和个人档案都很安全。

为什么我的 PDF 在阅读器里显示错误的标题？

大多数 PDF 生成程序会自动把源文档的文件名或模板标题写进元数据。如果原来的 Word 文件叫“draft_v3”，这串字符就会一路跟着 PDF。在这里编辑标题字段可以永久替换掉它。

能不能不编辑而是直接删除元数据？

可以。把任意字段清空后保存即可——下载到的文件该字段就是空的。在发布不希望暴露作者名或内部关键词的文档前，这是常见的一步。

有费用或文件数量限制吗？

工具完全免费，无需注册，没有水印，可编辑的 PDF 数量也没有上限。处理一个文件还是一百个，都是一样的。

校正倾斜

自动检测并校正扫描页面的倾斜，让内容摆正。

没人能扫得完全端正。纸张送进扫描仪时稍微歪一点，或者随手拍文档时有点斜，文字就会在页面上一路往下滑。PDFora 的纠偏工具能在浏览器里把歪掉的扫描件扶正：它测量每页倾斜了多少，再转回水平，结果看上去就像用正经平板扫描仪扫出来的一样。

有两种用法。自动检测会分析页面、自行找出倾角并加以校正，多数扫描件一键即可搞定。手动模式则给你一个角度控件，适合页面文字太少、检测器抓不到线索的情况，也方便你自己按零点几度微调。

校正在本地运行，扫描的合同和档案不会被上传到任何地方。纠偏免费、免注册、不留水印，也没有使用上限。它的好处还会延续到后续环节：摆正的页面 OCR 更准、打印更干净，看上去也更像用心做过。

如何在线为 PDF 纠偏

  1. 在浏览器中打开 PDFora 的「纠偏」工具。
  2. 把歪斜的扫描件拖进来，或从设备中选择该 PDF。
  3. 选择「自动检测」让工具找出每页的倾角，或切换到手动模式。
  4. 在手动模式下，按度数设置旋转量，直到预览中的文字水平为止。
  5. 应用校正，浏览器会在本地把每一页摆正。
  6. 把预览与原件对比，然后下载摆正后的 PDF。

When to use this tool

  • 把手机斜着拍下的租房合同扶正，再发给房东。
  • 修正一批经过走纸式扫描仪时略微转偏的票据，让它们在报销系统里归档整齐。
  • 把从鞋盒里翻出来数字化的旧家书和证书摆正，那些页面每张歪的角度还都不一样。
  • 在 OCR 之前先处理歪斜的扫描件，因为文字行不水平时识别准确率会明显下降。
  • 整理扫描的书籍章节，页面靠近书脊处弯曲而带上了倾斜。
  • 把签好字的表单摆正，再提交到会被工作人员查看和打印的官方系统。

Tips for the best results

  • 务必先纠偏再 OCR。哪怕两度的倾斜也会实实在在拉低文字识别率，而摆正输入是提升准确率最省事的办法。
  • 文字密集的页面放心交给自动检测。它靠读取文字行来判断角度，普通信函、表单和报告都能可靠地自动校正。
  • 内容稀疏的页面就切到手动。图纸、照片或只有几个字的页面留给检测器的线索太少，自己填个度数反而更快。
  • 小角度也要在意。哪怕一度的校正在打印稿上都看得出来，别因为屏幕上看着歪得不多就跳过纠偏。
  • 纠偏解决的是旋转，不是透视。斜着拍的照片带有梯形畸变，旋转治不好；页面若呈梯形，请摊平重扫。

常见问题

纠偏到底对我的 PDF 做了什么？

它把每页内容按一个精确角度旋转，使倾斜的文字回到水平。自动检测替你测量倾角，手动模式让你输入确切度数。输出是一份页面已摆正的普通 PDF。

自动检测是怎么算出角度的？

它分析页面图像，寻找文字行和边缘的主导方向，再计算它们偏离水平多少。在典型文档上，误差可控制在一度以内，而且每一页都独立测量。

什么时候该改用手动模式？

页面文字极少、内容以图像为主，或者你不认同自动校正结果时。你可以按度数设置旋转量，反复微调到预览满意为止。

摆正扫描件会损害画质吗？

旋转需要重新渲染页面，因此存在轻微的重采样，但在普通扫描件上，这点差别在阅读和打印时是察觉不到的。文字变水平带来的可读性提升远远盖过了它。

处理过程中我的文档保密吗？

保密。角度检测和旋转都在你自己设备上的浏览器里运行，文件绝不上传。哪怕是多页大扫描件也是如此，这也是为什么页面加载之后离线也能用。

这要花钱吗？能纠偏很多文件吗？

工具免费，无需账号，不加水印，也没有任何限制。如果你有一整个文件夹的歪斜扫描件，可以一个接一个跑完，不会撞上配额。

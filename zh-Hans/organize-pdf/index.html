当你确切知道要改哪一页时，页码很好用。可如果不知道呢？那就得把文档看见才行。PDFora 的整理工具把 PDF 的每一页铺成一块缩略图面板，你可以拖动页面重新排序、把扫歪成横向的页面转正、把多余的页面标记为待删除——全在同一个视图里完成，然后导出一份修好的文件。

整块面板都在浏览器里运行。你的 PDF 在本地渲染和重建，绝不上传，这意味着你可以调整租约、病历或工资单批次的页序，而这份文档不会接触任何人的服务器。这也意味着没有上传等待：再厚的文件，你的设备画多快它就开多快。

这一切都免费，无需账号，导出的 PDF 不带水印。改一页还是大改五十页都行，反复折腾到文档满意为止。

如何在线重排和整理 PDF 页面

  1. 打开 getpdfora.com 上的「整理 PDF」工具，载入你的文件。
  2. 稍等片刻，每一页都会以缩略图形式出现在面板上。
  3. 把任意缩略图拖到新位置即可调整页序——版面会随拖随更新。
  4. 对横倒或颠倒的页面点击旋转控件，直到它摆正为止。
  5. 把不需要的页面标记为待删除；它们会在面板上被标出，正式执行前你还能反悔。
  6. 点击「导出」，下载应用了新页序、旋转和删除操作的成品 PDF。

When to use this tool

  • 修正一次扫描作业：纸叠进纸时顺序反了或被打乱了。
  • 把一份纵向报告里的两张横向图表转正，其余页面一律不动。
  • 按投稿指南的要求，把附录移到参考文献前面。
  • 合并幻灯片后各章节交错在一起，重新整理成一份像样的演示讲义。
  • 在提交前用眼睛过一遍 40 页的申请材料包，把重复页挑出来。
  • 重排作品集页面，让每次提案时最强的作品都排在最前面。

Tips for the best results

  • 旋转、重排和删除在同一次会话里一并处理——导出一次胜过跑三个独立工具。
  • 旋转是按页生效的，所以你可以只把一张歪掉的扫描件转正，而不必翻转整份文档。
  • 标记为待删除的页面在导出之前并没有真的消失，把这些标记当作一份可随时修改的候选清单。
  • 缩略图很小；两页长得像的时候，请放大查看或另开原件对照，确认自己动的是对的那一页。
  • 在手机上把设备转成横屏，拖动时屏幕上能容纳更多面板内容。

常见问题

没有 Acrobat 怎么重排 PDF 页面？

把文件载入 PDFora 的整理工具，把页面缩略图拖成想要的顺序，然后导出。它在任何现代浏览器中都能用，免费，无需安装软件。

能只旋转其中一页而不是整份 PDF 吗？

可以。每张缩略图都有各自的旋转控件，你可以只把某一张横向扫描件转正，其余页面原封不动。

能同时删除页面并重新排序吗？

可以。把要删的页面标记好，把其余页面拖到位，再把歪的转正，所有改动会在一次导出的 PDF 中一并生效。

整理过程中我的文档会被上传吗？

不会。缩略图由你自己的浏览器渲染，编辑后的 PDF 也在本地组装，文件全程不会离开你的设备。

为什么大文件的缩略图要等一会儿才出来？

浏览器要为每一页绘制预览，长文档或图片密集的 PDF 需要渲染的内容本来就更多。速度取决于你的设备而非服务器，面板一旦加载完成，拖动是瞬时的。

导出会改变页面质量吗？

不会。重排、旋转和删除属于结构性改动——页面内容本身不会被二次压缩，所以文字和图片进去什么样，出来还是什么样。

重命名 PDF

给 PDF 起一个干净、统一的文件名，并以新副本的形式下载。

文件名比很多人想象的重要。“scan_20261003_0007.pdf”或“文档(3) 最终版 最终.pdf”这种名字对收件人毫无信息量，在下载文件夹里一放就找不到，有些上传平台还会因为含有空格、括号或名字太长而直接拒收。在电脑桌面上改个名很简单，但在手机上、在权限受限的办公电脑上，或者整个流程都在浏览器里完成时，改名反而会意外地麻烦。

这个工具只做一件事：你输入新名字，它把 PDF 以这个名字还给你。Windows、macOS 和多数平台不允许出现在文件名里的字符（反斜杠、斜杠、冒号、星号、问号、引号、尖括号和竖线）会被自动去掉；如果你没写 .pdf，会自动补上。输入框留空则保留原文件名；如果清理之后什么都不剩，文件会被命名为 document.pdf。首尾的空格也会被去掉，所以从邮件里复制来的名字末尾多了个空格，也不会生成“invoice .pdf”这样的文件。

有一个细节值得了解：这个工具并不只是给下载换个标签，而是用 pdf-lib 打开 PDF 再重新保存。页面和内容不变，但文件被重写了，所以大小可能略有差异，文档内部的元数据也会更新：pdf-lib 会写入修改日期，并把自己记为生成程序（Producer）。阅读器标题栏里显示的文档标题是 PDF 内部另一个独立字段，改文件名不会改动它。

如何给 PDF 文件重命名

  1. 打开“重命名 PDF”工具，添加要改名的 PDF。
  2. 在“新文件名”框中输入新名字，例如 2026-10-发票-0142。.pdf 后缀写不写都可以。
  3. 点击“重命名并下载”。文件会被加载，并以新名字重新保存。
  4. 把下载的文件保存到需要的位置；浏览器可能会询问保存位置，或者直接放进“下载”文件夹。
  5. 在文件管理器里确认名字，如果旧副本不再需要，可以删掉。

适用场景

  • 自由职业者按“客户-年-月-编号”这样的统一格式给发票命名，双方以后都好找。名字有规律，客户的财务也不用打开文件就能和采购单对上。
  • 学生向要求固定格式（比如“姓名-学号-作业名”）的系统提交作业。
  • 房东按房屋地址和日期整理租房合同和验房报告，而不是留着扫描软件自动生成的名字。
  • 在文件管理器不好用的手机或平板上改名。
  • 去掉冒号、斜杠、引号等导致文件无法上传或同步到其他系统的字符。
  • 转发之前，给下载下来的账单或电子票换个一眼能看懂的名字。

开始前需要了解

  • 禁用字符 \ / : * ? " < > | 会被直接删除而不是替换，所以“Report: Q3”会变成“Report Q3”。空格会保留；如果平台不接受空格，请自己换成连字符。
  • 缺少 .pdf 后缀时会自动加上。已经以 .pdf 结尾的名字（不论大小写）按你输入的保留。
  • PDF 会被 pdf-lib 重新保存，元数据里的修改日期和生成程序字段会更新。标题、作者和页面内容保持不变。
  • 带数字签名的 PDF 不要用本工具改名。重新保存会重写文件，即使看起来内容一样，签名也会失效。请在文件管理器里给签名文件改名。
  • 加了密码的 PDF 同样不适合。工具也许能加载，但保存出来的副本多半打不开。请在文件管理器里改名。
  • 每次处理一个文件。批量改名请逐个重复操作，或者使用操作系统自带的批量重命名功能。同一个文件改两次，就会得到两个新下载；工具从不改动你磁盘上的文件，原文件会以旧名字原地保留，直到你自己删除。

获得最佳效果的技巧

  • 名字以“年-月-日”格式的日期开头（2026-10-22），在任何文件夹里都会按时间排序。
  • 用连字符代替空格；在邮件系统、网址和命令行工具里，连字符不会被转成 %20。
  • 名字控制在 60 个字符左右以内。有些平台和老系统会截断过长的名字。
  • 把最重要的词放在最前面：客户名、文件类型、编号依次排列。别人在列表里扫一眼时，看的就是开头。
  • 如果 PDF 阅读器里显示的标题也要改，请在生成该文件的程序里修改文档属性；改文件名不会动它。上传平台有时有自己的命名规则，比如只能小写或不能有空格，本工具不会替你检查，请按平台要求的格式输入。

实例：房东整理租房资料

一位手里有三套房的房东，用手机扫描 App 扫验房报告，生成的文件名都是“扫描 2026年10月14日 10:42.pdf”这种。上传到中介平台时总是失败，因为平台不接受文件名里的冒号；笔记本里的文件夹也成了一串几乎一样的日期。

她在手机上把每份报告都按“b座-验房-2026-10-14”的格式改名。就算她复制了旧名字的一部分，工具也会去掉多余的冒号并补上 .pdf，平台顺利接收。文件夹里的文件现在先按房屋、再按日期排好了。

对已经签好的租房合同，她换了做法。这些合同带有数字签名，重新保存会让签名失效，所以她直接在手机的文件管理器里改名。重命名工具适合普通 PDF；带签名或密码的文件，应该在文件系统层面改名。

故障排除

下载的文件还是旧名字
可能是同名文件已经存在，浏览器自动加了编号，或者浏览器设置了重复文件自动改名。检查“下载”文件夹，删掉旧副本。
新名字里有些字符不见了
常见系统不允许用于文件名的字符（\ / : * ? " < > |）会被自动删除。需要分隔的地方请用连字符或下划线。
文件大小略有变化
PDF 被 pdf-lib 重新保存，对象的存储方式可能不同。页面完全一样，只是内部结构被重写了。
PDF 的数字签名显示无效了
重新保存改变了签名所覆盖的字节。请使用原来已签名的文件，在文件管理器里改名。
改名后的文件打不开
源文件多半是加密的或已损坏。请在文件管理器里给原文件改名，或者先用“修复 PDF”修复。
阅读器顶部显示的还是旧标题
阅读器显示的是 PDF 内部存储的标题，而不是文件名。改文件名不会改动这个字段。
手机上新名字被截短了
有些手机浏览器会截短很长的下载文件名。名字尽量简短，把关键部分放在前面。

常见问题

改名会改变 PDF 的内容吗？

不会。页面完全一样。文件会被重新保存，所以修改日期和生成程序的元数据会更新。

哪些字符不能用？

反斜杠、斜杠、冒号、星号、问号、双引号、尖括号和竖线会从文件名中删除。

末尾需要输入 .pdf 吗？

不需要，没写的话会自动加上。

能一次给多个 PDF 改名吗？

不能，每次一个文件。数量多时，用操作系统的批量重命名更快。

改名会破坏数字签名吗？

会，因为文件被重写了。带签名的 PDF 请在文件管理器里改名。

要收费或注册吗？

不用。重命名免费，也不需要账号。

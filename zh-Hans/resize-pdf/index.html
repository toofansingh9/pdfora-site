调整 PDF 大小

把 PDF 的每一页都放到 A4、US Letter、A5 或 A3 纸张上，等比缩放并居中，让整份文档统一成一种页面尺寸。

从不同来源拼起来的 PDF，页面尺寸很少是统一的。国内的公文是 A4，美国办公室扫过来的是 Letter，手机照片转成的 PDF 可能是任意奇怪的比例，而某些办事平台或打印店只认一种标准尺寸，可能整份退回。“调整 PDF 大小”的做法是把每一页放到你所选尺寸的新纸张上。即使每一页单独看都没问题，尺寸混杂也会在后面惹麻烦：打印机中途停下来要求换纸盒，小册子排版参差不齐，或者加页码时，不同尺寸页面上的页码位置都不一样。

可选四种目标尺寸：A4（595×842 点）、US Letter（612×792）、A5（420×595）和 A3（842×1191），全部为纵向。每个原始页面都会在保持比例的前提下缩放到完全放进新纸张，然后居中。如果形状不同，多出来的空间会变成上下或左右的白边。不会拉伸，也不会裁掉任何内容。

页面内容通过 pdf-lib 以矢量形式嵌入新纸张，所以文字和图形在任何缩放比例下都清晰锐利。由于生成的是一份全新的文档，输出就是可见页面的干净副本；下载文件名为原名加尺寸，例如 contract-A4.pdf。这也意味着原文件中一些奇怪的页面框设置（比如以前留下的裁切设置）会被一并理顺：新文件显示的正是之前可见的内容，只是换到了所选尺寸的纸张上。

如何更改 PDF 的页面尺寸

  1. 打开“调整 PDF 大小”工具，选择一个 PDF。
  2. 选择目标尺寸：A4、US Letter、A5 或 A3。默认选中 A4。
  3. 点击“调整页面大小”。每一页都会被放到新纸张上，缩放并居中。
  4. 下载文件，文件名中带有尺寸，例如 report-Letter.pdf。
  5. 检查一下横向页面和来自其他来源的页面；它们最容易出现白边或明显的缩放变化。

适用场景

  • 向只接受 A4 或只接受 Letter 的政务或法院平台上传材料。
  • 和欧美办公室互传文件时，A4 和 Letter 差了几毫米，打印机就会提示纸张不匹配。
  • 把一堆尺寸各异的扫描件和照片整理成页面尺寸统一的规整文档。
  • 把 A4 页面缩小到 A5，打印成小册子或口袋手册。
  • 把 A4 图纸或平面图放大到 A3，打印出来更好看清。
  • 给要求所有页面统一标准尺寸的打印店准备文件。

开始前需要了解

  • 页面只会等比缩放，不会拉伸或裁剪。原页面比例和目标尺寸不同时，两侧会出现白边。
  • 四种目标尺寸都是纵向。横向页面会被放进纵向纸张里，结果会变小，上下留出很宽的白边。如果希望它们铺满纸张，请先旋转。
  • 小页面会被放大，大页面会被缩小。把手机尺寸的页面放大到 A3，矢量文字会变大且依旧清晰，但低分辨率的扫描件会显得发虚。
  • 链接、表单字段、注释和书签不会复制到调整后的文件中，因为每一页都是作为内容重新绘制到新纸张上的。需要这些的话请保留原件。
  • A4 和 Letter 互转时缩放幅度很小，但白边依然存在：A4 放到 Letter 上，左右会有细白边；Letter 放到 A4 上，上下会有白边。实际上转换后的 A4 和 Letter 内容看起来几乎一样，区别只在白边，不影响阅读。
  • 调整页面大小不会改变扫描图片的分辨率，只改变它在页面上显示的大小。

获得最佳效果的技巧

  • 如果有几页是横向的表格，调整大小之前先用“旋转 PDF”把它们转成纵向，否则就得接受它们变小。
  • 要缩小到 A5 时，先裁掉过宽的页边距，这样内容在小页面上能占得更满。
  • 做 A5 小册子时，确认原文中最小的字缩到约 70% 后还能看清，因为 A4 到 A5 就是这个比例。
  • 把调整大小放在最后几步做。调整之后再加页码或页眉，位置才会落在最终尺寸的正确位置上。
  • 对方要求“A4”时，顺便问一句是否只要纵向；本工具始终输出纵向纸张。

实例：房东向办事平台提交租赁备案材料

一位房东需要把租赁材料上传到一个要求 A4 的办事平台。这份文件里有租赁合同（A4）、一份在办公室复印机上误用了 US Letter 设置扫描的燃气安全检查单，还有三张用手机拍的水电表读数照片，存成 PDF 后是细长的奇怪比例。

他把合并后的文件放进“调整 PDF 大小”，选择 A4。合同页面看上去毫无变化。Letter 扫描件略微缩小，以适应更窄的 A4 宽度，上下多了细细的白边。细长的手机照片按 A4 高度缩放，左右留出白边。

平台一次就接收了 tenancy-A4.pdf。唯一的损失是合同里指向押金托管网站的链接点不动了，所以他把网址直接写在了留言里。

他也保留了尺寸混杂的原文件。如果之后对方单独要燃气检查单，他可以从原文件中以完整扫描质量提取，而不是从为适应 A4 宽度而缩小过的副本里提取。

故障排除

页面四周有白边
原页面比例和目标尺寸不同。工具在不拉伸、不裁剪的前提下适配，多出来的空间就留白。如果白边来自原有的页边距，请先裁剪原文件。
横向页面变得很小
目标纸张是纵向的。请先把这些页面旋转成纵向，或者把它们单独放在一个保持原尺寸的文件里。
链接或表单字段失效了
交互元素不会带到新纸张上。请在调整大小之前填好并平面化表单，或者保留原件用于屏幕查看。
扫描页放大后变模糊
调整大小只是缩放现有图像，无法增加细节。如果需要把扫描件放大到 A3，请用更高分辨率重新扫描。
输出文件打印出来尺寸还是不对
检查打印对话框。“适合可打印区域”之类的选项可能会把页面再次缩小。请选择按实际大小打印。
工具打不开文件
PDF 可能已损坏。先用“修复 PDF”处理，再对修复后的副本调整大小。

常见问题

调整大小会让页面变形吗？

不会。横向和纵向的缩放比例相同，比例保持不变，多余的空间留白。

能设置自定义页面尺寸吗？

目前不能。可选的是 A4、US Letter、A5 和 A3。

能调整成横向吗？

不能。所有目标尺寸都是纵向，横向原页面会被放进纵向纸张中。

调整后文字还能搜索吗？

大多数文件可以。页面以矢量内容嵌入，真正的文字依然是文字。没做过 OCR 的扫描页本来就无法搜索。

文件会变大吗？

通常只大一点点。页面内容是被复用而不是重新渲染的，所以大小和原文件接近。

手机上能用吗？

能。在手机浏览器里就能运行；很长的文档只是会多花点时间。

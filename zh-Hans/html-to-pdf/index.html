很多有用的文档只以 HTML 形式存在：从浏览器保存的订单确认页、某个软件导出的报表、电子期刊、生成为单页的说明文档，或者你自己做的网页。HTML 会随窗口大小重新排版，而当文档需要归档、打印或作为报销凭证提交时，这恰恰是你不想要的。PDF 能把它固定在一个页面尺寸上。

这个工具接收的是你电脑上的 .html 或 .htm 文件，而不是网址。文件会经 PDFora 的中转加密上传到 CloudConvert 服务，由渲染引擎排版并打印成 PDF；结果以你的文件名返回，随后从该服务上删除。转换不在你的浏览器里进行，页面上也没有页面尺寸或边距的设置项。

大多数人最意外的是 HTML 文件所引用的那些东西。一个网页很少只有一个文件：图片、样式表和字体通常是单独的文件，由 HTML 引用。上传的只有你选的那一个文件，所以凡是用相对路径指向你本地硬盘的资源，服务器都找不到。想得到忠实的 PDF，关键就在于转换前先让 HTML 文件自成一体。

HTML 转 PDF 的步骤

  1. 确认 HTML 文件是自包含的，或者图片和样式表用的是完整网址（https://...）；详见下文说明。
  2. 打开“HTML 转 PDF”，选择 .html 或 .htm 文件。
  3. 点击“转换”，等待文件上传并在服务器上渲染。
  4. 下载 PDF，文件名与原文件相同，扩展名为 .pdf。
  5. 检查图片、颜色和版式是否正常，右侧边缘有没有内容被截掉。

适用场景

  • 从浏览器保存的电子收据和预订确认，转成 PDF 留作记账或法律凭证。
  • 软件以 HTML 格式导出的报表，需要作为邮件附件发送或归档。
  • 开发者把程序生成的 HTML 发票、证书或信函模板转成 PDF，检查打印版式。
  • 以单个长 HTML 页面发布的文档或用户手册，打印出来离线阅读。
  • 保存下来做研究用的网页文章，转成即使原网站改版也不会变的格式。
  • 保存为 HTML 的邮件简报，转换后留存一份发送记录。

开始前需要了解

  • 相对链接会失效。如果 HTML 里写的是 <img src="images/logo.png"> 或 <link href="style.css">，这些文件还留在你电脑上，服务器看不到，PDF 里就会出现图片缺失、文字没有样式。请改用 https:// 绝对地址，或者把 CSS 写进 <style> 块、图片以 data URI 方式嵌入。
  • 使用绝对网址的资源，服务器在渲染页面时可能会去抓取，所以公开可访问的图片和样式表通常能正常显示。需要登录、位于内网或 localhost 上的资源则不行。
  • 没有网址输入框。要转换在线网页，得先保存下来；浏览器“另存为”里的“网页，单个文件 (.mhtml)”不被接受，请选“网页，仅 HTML”，并预期相对路径的图片会缺失；或者直接用浏览器自带的“打印 > 另存为 PDF”。
  • 打印样式会生效。如果页面有针对 @media print 的 CSS，转换器通常会采用，这可能导致导航栏被隐藏或颜色与屏幕上看到的不同。分页可以用 CSS 的 break-before 和 break-inside 控制。
  • 由 JavaScript 生成的内容不可靠。加载后再用脚本拉取内容的页面，转换出来可能只是个空壳。请在页面完全加载后再保存，或者在服务端把内容直接渲染进 HTML。
  • 宽于打印页面的版式，比如固定 1400 像素宽的设计或很宽的表格，可能被截断或缩小。改成响应式布局，或给主要内容设置 max-width，通常就能解决。

获得最佳效果的技巧

  • 自己的模板，把所有 CSS 放进 <head> 里的 <style> 块；这是得到带样式 PDF 最可靠的办法。
  • 需要特定页面尺寸或边距时，在 CSS 里加上 @page { size: A4; margin: 15mm; }。
  • 给表格行、卡片和图片加上 break-inside: avoid，避免它们被拆到两页上。
  • 图片大小要合理：一张 5 MB 的大图即使以 data URI 嵌入，生成的 PDF 也还是 5 MB。
  • 先在浏览器的打印预览里看一下 HTML 文件；如果那里显示就不对，转换出来的 PDF 多半也不对。

实际示例：一家小网店的 HTML 发票模板

一家两个人经营的网店用一个简单脚本生成 HTML 格式的发票，每个文件都引用同一文件夹里的 invoice.css 和 logo.png。直接转换的话，PDF 只有默认字体的黑色纯文本，没有 logo，合计表格横跨整个页面宽度，因为服务器收到的 HTML 文件既没有样式表也没有图片。

解决办法是让文件能独立成立。现在脚本会把 invoice.css 的内容复制进 <style> 块，加上 @page { size: A4; margin: 18mm; }，给商品明细表格的行加上 break-inside: avoid，并把 logo 指向网店官网上的公开 https 地址，而不是本地路径。其他都不用改。

再次转换后，发票变成一页 A4 PDF，有 logo、有店铺配色，订单行数多时合计表格也不会再被拆开。因为模板现在是自包含的，脚本生成的每张发票都能同样顺利地转换。

故障排除

PDF 没有样式，只有纯文字
样式表是用相对路径引用的，没有被上传。把 CSS 嵌入 <style> 块，或用完整的 https:// 地址链接。
图片缺失
用相对路径引用的本地图片服务器无法访问。改用公开的 https:// 网址，或把图片以 data URI 嵌入，然后重新转换。
页面右侧被截掉了
版式的固定宽度大于页面。给主要容器和图片加上 max-width: 100%，或者写一个让版式变窄的打印样式表。
PDF 是空白的或几乎空白
内容可能是加载后由 JavaScript 生成的，或者文件只是一个跳转页。等页面完全渲染后再保存，或直接在 HTML 里写入内容。
文字字体变了
本地引用的网络字体不可用。从公开网址链接字体，用 @font-face 加 data URI 嵌入，或改用常见字体组合。
工具不接受我的文件
只接受 .html 和 .htm。保存下来的 .mhtml 或 .webarchive 文件需要重新保存为“仅 HTML”。

常见问题

能输入网址直接转换网站吗？

不能。工具转换的是你选择的 HTML 文件。先把网页保存为 HTML，或者对在线网页使用浏览器的“打印 > 另存为 PDF”。

HTML 文件会被上传吗？

会。文件加密发送到转换服务，在那里渲染，之后删除。含有你不希望第三方处理的个人信息的页面，最好不要用它转换。

为什么图片和 CSS 丢了？

上传的只有 HTML 文件本身。它用相对路径引用的文件还在你电脑上；请使用 https:// 绝对链接，或把它们嵌入 HTML。

能设置页面尺寸或边距吗？

工具页面上不能。请在 HTML 中用 CSS 的 @page 规则设置，例如 @page { size: A4; margin: 15mm; }。

PDF 里的链接能点击吗？

指向网址的链接一般可以点击。指向其他本地文件的相对链接则打不开有用的内容。

转换时会运行 JavaScript 吗？

可能会部分运行，但加载较晚或依赖用户操作的内容经常缺失。想要稳定的结果，HTML 里应该已经包含最终内容。

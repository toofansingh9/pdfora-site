给 PDF 加水印，不用安装任何软件，也不用把文档交到陌生人的服务器上。PDFora 会把你自定义的文字——DRAFT、CONFIDENTIAL、公司名称、客户编号——打在文档的每一页上。整个过程在浏览器内部以本地方式处理，文件绝不离开你的电脑。当你要标记的 PDF 恰恰是那种不希望到处流传的文件时，这一点非常重要。

水印的样子由你掌控。文字随你输入，字号可以按版面调整，透明度可以从淡如幻影的 0.1 一直设到浓重不透的完全实心。打开 45 度斜排选项，文字就会像经典的 DRAFT 印章那样横贯页面。水印会一致地应用到每一页，因此一份 200 页的合同和一份两页的备忘录耗时同样只有几秒。

PDFora 免费，无需注册，也没有文件数量限制。有一点值得直说：很多水印工具会在你的成品上加自家品牌标识。我们从不这样做。成品 PDF 上唯一的水印，就是你自己选择加上去的那一个。一天用一次还是一百次都行——我们不计数，也不限速。

如何在线为 PDF 添加水印

  1. 打开 getpdfora.com 上的水印工具并选择 PDF，或者直接把文件拖到页面上。
  2. 输入要打在每一页上的水印文字——例如 CONFIDENTIAL、DRAFT 或你的公司名称。
  3. 设置字号，让水印清晰可见，又不至于淹没下面的内容。
  4. 在 0 到 1 之间调整透明度滑块——0.2 到 0.3 左右能做出淡雅的水印，同时保证正文依然可读。
  5. 如果希望文字以 45 度斜贯页面，勾选斜排选项；不勾则是水平印记。
  6. 点击应用，然后下载加好水印的 PDF。一切都在你的浏览器本地完成。

When to use this tool

  • 在合同发给对方之前打上 DRAFT，避免有人签了一份从来就不是终稿的版本。
  • 内部报告在流转到本团队之外前标注 CONFIDENTIAL。
  • 在设计稿和提案上加上工作室或事务所名称，防止被人悄悄挪作他用。
  • 给电子书的样章或试读本标上 NOT FOR DISTRIBUTION。
  • 在发票或对账单上标注 PAID 或 COPY，让原件和副本不再混淆。
  • 给学生讲义或试卷加上课程代码和学期水印，旧版本一眼可辨。

Tips for the best results

  • 文档仍需仔细阅读时，把透明度压低——0.15 到 0.3；0.6 及以上留给那些本就不打算让人当作可用副本的页面。
  • 45 度斜排能用一行文字覆盖更大的页面面积，也更难被裁掉。
  • 大字号的短文字比小字号的长句子更易读；“DRAFT — v3”胜过一整段免责声明。
  • 给副本加水印，不要动你唯一的原件。工具不会改动源文件，但保留一份干净母版终归是好习惯。
  • 法律或客户文档可以把收件人姓名写进水印——一旦泄露，副本自己就能表明出处。

常见问题

添加水印时我的 PDF 会被上传吗？

不会。本工具完全在浏览器中以本地方式处理。文件的打开、加印和保存都在你自己的机器上完成，不会向 PDFora 的服务器发送任何内容。

PDFora 会往我的文件上加自家水印吗？

绝不会。与许多免费工具不同，我们不会在你的成品上打品牌标识。成品 PDF 上唯一的水印，就是你自己输入的文字。

可以控制水印的透明程度吗？

可以。透明度可在 0 到 1 之间调节。0.2 这样的低值会形成淡淡的背景印记，而 1 则是实心、完全不透明的文字。

水印会出现在每一页上吗？

会。无论文件是两页还是几百页，你的文字都会自动打在文档的每一页上。

可以把水印斜着放吗？

可以。有一个把文字旋转 45 度的选项，能做出经典的对角线 DRAFT 效果。不勾选则是水平印记。

文件大小或数量有限制吗？

没有固定上限，也没有每日配额——工具免费、不限次数、无需注册。由于处理在本地进行，超大文件的唯一限制是你设备的内存。

彩色墨水很贵，而多数文档根本用不上。PDFora 的灰度工具直接在浏览器里几秒钟就把 PDF 的每一页转成黑白。要为黑白激光打印机准备文件、要满足印刷店的灰度要求，或者只是不想让喷墨打印机为一份五十页的报告耗光彩色墨盒，这都是最快的办法。

把 PDF 转成灰度往往还能让文件变小。色彩信息本身占空间，去掉之后页面存储的数据变少，图片多的文档体积会明显减轻。所以即便不为打印，灰度也有用——比如提交系统限制文件大小，而你那份色彩缤纷的幻灯正好超标。

和 PDFora 的每个工具一样，这个工具在本地处理你的文件。什么都不会上传，护照扫描件或签好字的协议自始至终留在你自己的设备上。无需注册，输出不打水印，不收费，转换多少份 PDF 也不设限。

如何在线把 PDF 转为灰度

  1. 在浏览器中打开 PDFora 的「PDF 转灰度」工具。
  2. 把 PDF 拖到上传区，或点击它从设备中选择文件。
  3. 稍等片刻，工具会加载预览，让你确认是正确的文档。
  4. 点击「转换」，浏览器会在本地把每一页处理成黑白。
  5. 查看成品页面，确认照片和图表在灰度下仍然清楚可读。
  6. 下载灰度 PDF，按需打印或分享。

When to use this tool

  • 把色彩浓重的演示文稿转成黑白，再用办公室激光打印机印 30 份。
  • 满足学校要求：论文初稿须以灰度提交，便于评审打印。
  • 为按需印刷服务准备书稿，这类服务对彩色内页按页加收费用。
  • 去掉扫描表单上的颜色，复印时才不会出现脏兮兮的灰调。
  • 发邮件前去掉色彩数据，缩小图片密集的宣传册 PDF 的体积。
  • 归档工作文档前，把荧光笔标记和彩色批注统一处理掉。

Tips for the best results

  • 转换后检查图表。原本只靠颜色区分的线条（比如红对绿）在灰度下可能看着一模一样，图表重要的话请改用带标签或纹理的版本。
  • 先转灰度再打印，而不是反过来。让工具来做转换，比指望各家打印机驱动自己的黑白模式，结果更可预期。
  • 工具组合能把文件压到最小。先转灰度、再用压缩工具，臃肿的彩色扫描件能缩到原来的一小部分。
  • 保留彩色原件。转换在输出文件中是不可逆的，以后可能还要用彩色版就先存好。
  • 照片转得比浅色文字好。淡黄或粉彩色的文字在灰度下容易发虚，送印前请把装饰性页面快速过一遍。

常见问题

转为灰度能减小 PDF 体积吗？

通常能。去掉色彩数据意味着每页存储的信息更少，满是照片或彩色图形的文档会明显变小。本来就以黑字为主的纯文本 PDF 则变化不大。

转换后文字还清晰吗？

黑色文字依然锐利，因为它本来就等同于灰度。彩色文字会按亮度映射成某个灰阶，因此非常浅的颜色打印出来可能比你预期的更淡。打印前快速预览一下就能发现这个问题。

这个工具免费吗？有页数限制吗？

完全免费，无需注册，不加水印，我们也不设页数或文件大小限制。由于处理由你的浏览器完成，再长的文档也能处理，只是超大文件在老设备上会慢一些。

转换过程中我的 PDF 会被上传吗？

不会。转换完全在浏览器内以本地方式运行，文档不会前往任何服务器。你可以转换机密材料而不让它离开你的机器。

为什么要转成灰度 PDF，而不直接用打印机的黑白设置？

灰度 PDF 在任何打印机上都能得到一致的结果，而且还没上纸之前你就能看到每一页的确切效果。打印机驱动各不相同，有些在渲染彩色文件的灰调时仍会消耗彩色墨水。

能只把部分页面转成灰度吗？

工具会一次性转换整份文档。如果需要彩灰混排，可以先拆分 PDF，把要转灰的页面转好，再用 PDFora 的拆分和合并工具把一切拼回去。

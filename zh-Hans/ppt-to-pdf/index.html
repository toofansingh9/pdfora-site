幻灯片是用来演讲的。一旦需要通过邮件发送、上传到教学平台或打印成讲义，PDF 对所有人都更省事：任何手机都能打开，不需要装 PowerPoint，也不会因为屏幕尺寸不同或缺少字体而导致版面错位。它还能防止收件人在转发之前悄悄改动你的数据。

这个工具每次转换一个 .ppt 或 .pptx 文件。演示文稿通过加密连接、经由 PDFora 的中转服务上传到 CloudConvert，由那里的演示文稿引擎渲染，生成的 PDF 再下载回你这里，文件名与原文件相同。转换不在你的浏览器里完成；任务结束后，文件会从该服务上删除。

你得到的是一份静态文档：每张幻灯片变成一页，保持幻灯片本身的宽高比，通常是 16:9。凡是只在放映时才会发生的东西——动画、切换效果、嵌入的视频或音频、点击后逐步出现的内容——都不可能存在于纸面上。本页大部分内容讲的就是转换之前该如何处理这些部分，让没听过你讲解的人也能看懂这份 PDF。

如何把 PowerPoint 转换为 PDF

  1. 保存并关闭演示文稿。删除或隐藏不想放进 PDF 的幻灯片。
  2. 打开“PowerPoint 转 PDF”，选择 .pptx 或 .ppt 文件。
  3. 点击“转换”，等待上传和转换完成。大照片较多的文稿会慢一些。
  4. 下载 PDF，文件名沿用演示文稿的名称。
  5. 逐页翻看：检查依赖动画的幻灯片，留意有没有文字溢出文本框或字体变了。

适用场景

  • 把课件上传到学校的教学平台，供学生阅读和批注。
  • 会后用邮件发送销售或融资路演文稿，让对方看到的与现场展示的完全一致。
  • 把会议演讲稿交给主办方，由主办方以 PDF 形式发布讲者的幻灯片。
  • 为培训学员打印培训资料。
  • 把文稿发给只有手机或 Chromebook 的人。
  • 保留一份某次演讲当天实际所用内容的固定记录。

开始前需要了解

  • 动画会被“压平”。逐条出现项目符号的幻灯片，在 PDF 中会一次全部显示；叠放在一起、准备依次出现的对象，在页面上会互相重叠。
  • 视频和音频在 PDF 中无法播放，通常只保留视频的封面帧。如果对方需要看，请在幻灯片上附上在线版本的链接。
  • 演讲者备注不会包含在内，转换器只输出幻灯片页面。如果备注很重要，请把它复制到幻灯片上，或者直接在 PowerPoint 中导出带备注的版本。
  • 隐藏的幻灯片一般不会出现在 PDF 中，这是让备用幻灯片不外传的好办法，但请核对一下页数是否符合预期。
  • 服务器上没有的字体会被替换，所以使用特殊品牌字体制作的文稿可能出现换行位置不同或文字溢出文本框的情况。请嵌入字体（文件 > 选项 > 保存 > 将字体嵌入文件），或者使用常见字体。
  • 指向网站的超链接通常仍可点击。在幻灯片之间跳转的动作按钮是否有效，取决于它们的制作方式，值得测试一下。

获得最佳效果的技巧

  • 如果是给人阅读的版本，补上一两页你平时会口头讲的背景说明；PDF 文稿可没有人在旁边讲解。
  • 如果逐步展开的顺序对理解很重要，就把这类幻灯片复制成几张，分别显示每个阶段。
  • 如果 PDF 必须控制在邮件附件大小以内，转换前先在 PowerPoint 中压缩图片（图片格式 > 压缩图片）。
  • 如果 PDF 要黑白打印，请使用高对比度的主题；深色背景的幻灯片既费墨粉又会丢失细节。
  • 如果需要每张纸打印多张幻灯片，先转换，再对 PDF 使用“N-up（每张纸多页）”，每张纸放两张或四张。

实例：老师为缺课学生准备课件

一位中学生物老师想把一节 28 张幻灯片的光合作用课件发给缺课的学生。课堂上有几张幻灯片是逐步展开的：一张叶片结构图，标注一个接一个飞入；还有一张先显示错误答案，再用正确答案盖住。另外还有一段两分钟的视频，以及写着讲解要点的备注。

直接转换的话，PDF 中叶片图的标注全部同时出现，这没问题；但答案那一页两个答案叠在一起，视频也只剩一帧静止画面。于是她把答案页复制一份，在副本中删掉错误答案，在静止画面下方用文字写上视频的网址，再把备注中的两个要点移到相应幻灯片的文本框里。

第二次转换得到一份 29 页的 PDF，学生用手机就能独立看懂。因为 PDF 保持了 16:9 的比例，在屏幕上阅读效果很好；少数想要纸质版的学生，她用“N-up（每张纸多页）”按每页两张幻灯片打印。

再检查一遍时，她发现了一个没料到的问题。叶绿体示意图是由十几个形状组合而成的，其中一个标注用的是她下载的一款装饰性手写字体。在转换后的页面上，这个标注被换成了普通字体，文字超出了箭头的范围。她不确定自己是否有权分发那款字体，所以没有选择嵌入，而是把标注改成与整份文稿一致的字体，又转换了一次。逐页对照原幻灯片只需几分钟，却是在三十名学生看到之前发现这类细小替换的唯一可靠办法。

故障排除

有些幻灯片上的文字重叠或溢出文本框
某个字体被替换成了更宽的字体。在演示文稿中嵌入字体或改用常见字体，然后重新转换。
好几个对象叠在了一起
这些对象原本是通过动画依次出现的。把这张幻灯片拆成几张，每个阶段一张，或者删掉原本应该消失的对象。
我的视频不见了
媒体无法在 PDF 中播放。请在幻灯片上添加视频链接，或者单独分享视频。
PDF 中少了几张幻灯片
它们很可能是隐藏的幻灯片。如果需要包含，请在 PowerPoint 中取消隐藏（右键点击缩略图 > 隐藏幻灯片）。
转换失败或超时
包含大量高分辨率图片的超大文稿可能很慢，损坏或设有密码的文件会失败。请压缩图片、去掉密码、另存一份新的 .pptx 副本，然后再试。
PDF 文件非常大
照片保留了原始分辨率。转换前在 PowerPoint 中压缩图片，或者用“压缩 PDF”处理生成的 PDF。

常见问题

我的演示文稿会被上传吗？

会。文件以加密方式发送到转换服务，处理完成后即被删除。如果文稿必须留在你的电脑上，请使用 PowerPoint 自带的导出功能。

会包含演讲者备注吗？

不会。每张幻灯片变成一页，不带备注。转换前请把重要的备注移到幻灯片上。

动画和切换效果在 PDF 中还有效吗？

没有。PDF 页面是静态的，所有带动画的元素都显示在其最终位置。

PDF 会保持我的幻灯片尺寸吗？

会。页面采用演示文稿的幻灯片尺寸，16:9 的文稿会变成宽页面，4:3 的则更接近方形。

可以转换 Google 幻灯片或 Keynote 文件吗？

先把 Google 幻灯片下载为 .pptx，或把 Keynote 演示文稿导出为 PowerPoint 格式，再转换那个文件。

可以把多张幻灯片放在一页上吗？

转换时不行。先转换，再用 N-up 工具在每页放两张或四张幻灯片。

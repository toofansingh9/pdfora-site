合并 PDF 听着简单，真要做才知道麻烦。也许求职信在一个文件里，简历在另一个里，还有三份扫描的证书，全都得作为一个附件发出去。PDFora 的合并工具能把任意数量的 PDF 文件拼成一份干净的文档，就在你的浏览器里完成。不用账号，页面上不会盖水印，也不必在上传队列里排队。

多数人忽略的一点是：你的文件从未离开电脑。其他合并工具会把文档发到服务器上处理，再把结果邮件发回或给你一个链接。PDFora 借助浏览器自身的算力在本地合并。合同、体检报告、工资单——统统不经过互联网，所以处理任何机密材料，这都是个明智的选择。

工具免费，不限页数，也没有每日上限。把文件放进去，拖成想要的顺序，下载合并后的 PDF 即可。如果你每周都要合并文档——月末的发票、书稿的各个章节、课堂讲义——想来多少次就来多少次，不会撞上付费墙。

如何在线合并 PDF 文件

  1. 打开 getpdfora.com 的「合并 PDF」工具——不用安装，也没有注册页面。
  2. 点击上传区，或把 PDF 文件拖进去，需要多少份就添加多少份。
  3. 查看文件列表，每个 PDF 会显示为一张带文件名的卡片。
  4. 拖动卡片调整顺序——从上到下的排列就是页面在最终文档中出现的顺序。
  5. 点击「合并」，浏览器会在几秒内于本地把文件拼合。
  6. 下载这一份合并好的 PDF，完成。

When to use this tool

  • 把求职信、简历和推荐信合成一个文件，作为一份完整的求职材料发出。
  • 把一个月里零散的发票 PDF 合并成一份文档，交给会计。
  • 合并手机扫描应用生成的页面，这类应用常常把每一页各存成一个 PDF。
  • 用报价单、作品样例和合同草案组装出一份客户提案。
  • 把分别导出的书稿或论文章节整合成一份完整稿件，供人评阅。
  • 把机票、酒店确认单和保单等出行材料打包成一个文件，在机场一找就到。

Tips for the best results

  • 添加之前先给文件按数字重命名（01-intro.pdf、02-body.pdf），预期顺序一眼可见。
  • 点「合并」之前先拖好顺序——事后再改顺序就意味着整件事得重做。
  • 如果某个源 PDF 里有不想要的页面，先用「删除页面」工具处理，再合并清理后的版本。
  • 合并多个大体积扫描件会占用设备内存，如果感觉变慢，请关掉多余的标签页。
  • 在打开并检查过合并结果之前，先把原始文件留着。

常见问题

在线合并机密 PDF 安全吗？

用 PDFora 是安全的——合并完全在你的浏览器里进行，文件绝不会上传到服务器。合同、财务报表和病历自始至终留在你的设备上。

一次能合并多少份 PDF？

没有固定上限。由于干活的是你自己的浏览器，实际性能取决于设备，但在普通笔记本或手机上，合并几十份常规文档毫无压力。

合并后的 PDF 会有水印吗？

不会。输出是一份干净的 PDF，不添加任何东西——没有水印、没有品牌标识、没有试用戳记，无论你合并多少文件、用得多频繁。

合并前可以调整文件顺序吗？

可以。添加文件之后，随意拖成你想要的顺序。最终 PDF 会遵循列表中自上而下的排列。

需要注册账号或付费吗？

不需要。合并工具免费，无需任何注册即可使用。也没有每日限制，你想合并多少次 PDF 都可以。

文件非常大会怎样？

由于处理在本地进行，大规模合并取决于你设备的内存，而不是服务器配额。多数文件几秒就合并完；一叠超大的扫描版 PDF 在老硬件上可能更久。

有时候你要的并不是整份文档，而是中间那三页。PDFora 的提取工具能从任意 PDF 中把选定页面取出来，保存为新文件。输入 1-3, 5, 8 之类的内容，你就会得到正是这些页面、按这个顺序排列的一份新 PDF。原文件毫发无损。

提取完全在你的设备上进行。PDF 由你的浏览器读取和重建，而不是远程服务器，因此无论你要从什么文件里取页——签好字的协议、纳税申报表、评估报告——都不会被传输到任何地方。如果你一直不敢用在线 PDF 工具处理敏感文件，这就是解法：「在线」的只是这个网页，不是你的数据。

无需注册、不收费，输出也不带水印。取两页还是两百页，从一份文档还是二十份里取，随时都行，没有任何东西会被计入配额。

如何在线从 PDF 中提取页面

  1. 用任意现代浏览器打开 getpdfora.com 上的「提取页面」工具。
  2. 点击选择器添加 PDF，或把文件拖到页面上。
  3. 在选择框中输入想要的页面——单页、范围或两者混用，如 1-3, 5, 8。
  4. 对照实际文档再核对一遍页码；印在纸面上的页码未必与 PDF 的页序一致。
  5. 点击「提取」，浏览器会把选定页面组装成一份新 PDF。
  6. 下载结果。你的原文件保持原样。

When to use this tool

  • 从长合同里只取出签字页，发过去请对方会签。
  • 从 60 页的报告中提取内容摘要，给那些不会看完全文的人。
  • 从整期期刊或会议论文集 PDF 里只保存自己的那篇论文。
  • 从诉讼材料中取出相关的证据页，而不是把整本卷宗转发出去。
  • 从买来的电子书里单独取出一份食谱、练习页或图样，用于打印。
  • 从产品手册中抽出规格参数页，作为附件提交客服工单。

Tips for the best results

  • 范围和单页可以随意混用——2, 5-9, 14 的效果正如你所料。
  • 页面在新 PDF 中按你列出的顺序排列，所以请按想要的次序书写选择内容。
  • 先在阅读器里打开 PDF，记下阅读器显示的页序，因为一张封面就可能让所有页码错开一位。
  • 如果你是想删掉几页而不是留下几页，用「删除页面」工具这个反向操作更快。
  • 先提取再合并：先从几份文档里挑出好的页面，合并出来的文件会干净得多。

常见问题

可以从 PDF 中提取不连续的页面吗？

可以。用逗号隔开即可——1, 4, 9-11 会把第 1、4、9、10、11 页提取进一份新 PDF。单页与范围的任意组合都没问题。

提取页面会改动我的原始 PDF 吗？

不会。工具读取你的文件，用选定页面构建一份全新的 PDF。你设备上的源文档不会被修改。

处理税务或法律文件够私密吗？

够。提取在你的浏览器本地运行，文件绝不上传，因此包括 PDFora 在内的任何人都看不到其内容。私密程度和你在自己电脑上打开这个文件一样。

提取出的页面会保留原有排版吗？

会。页面原样复制，字体、图片、链接和版式都完整带过去，不会被压平或二次压缩。

能从有密码保护的 PDF 中提取页面吗？

锁着的时候不行——浏览器读不出加密文件的页面。请先去掉密码（你得知道密码），然后照常提取。

一次能提取多少页有限制吗？

没有固定上限，也不收费。由于工作在你的设备上完成，从超大文件里做超大规模提取只取决于可用内存，不过一般任务几秒就完成了。

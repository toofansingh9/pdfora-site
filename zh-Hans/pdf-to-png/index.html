PDF 转 PNG

把 PDF 的每一页保存为无损 PNG 图片，足够清晰，图纸、图表和小字都不在话下。

当页面主要由线条而不是照片构成时，就该选 PNG。平面图、电路图、表格、数学练习卷，以及满是细线的幻灯片，在 JPEG 压缩下都会吃亏，黑色笔画周围会留下灰色光晕。PNG 精确保存每一个像素，所以渲染出来的图片和你在 PDF 阅读器屏幕上看到的一模一样。

转换逐页进行。Firefox 使用的渲染引擎 PDF.js 把每一页画到画布上，再把画布写成 PNG 文件。画布有多少像素由你决定：“屏幕”按页面磅值尺寸的 1.5 倍绘制（约 108 dpi），“标准”2 倍（约 144 dpi，默认），“高”3 倍（约 216 dpi）。由于 PNG 是无损的，这几个预设是唯一影响画质的因素，而且对文件大小影响很大。

代价是体积。存成 PNG 的文字页通常很小巧，因为大片白色区域压缩效果好；但带全彩照片的页面，可能比同一页的 JPG 大好几倍。如果你的 PDF 是扫描文档或相册，JPG 转换器一般更实用；PNG 的体积花在清晰的图形和文字上才值得。

把 PDF 页面转成 PNG 的步骤

  1. 打开“PDF 转 PNG”，拖入一个 PDF 文件。
  2. 选择“质量”预设。说明文档和网页用途选“标准”；打印、近距离放大查看，或要拿到其他软件里做 OCR 时，值得选“高（打印）”。
  3. 点击“转换”，等待每页渲染完成；每完成一页，进度条前进一格。
  4. 用“全部下载 (.zip)”获取所有页面，或点击某个文件按钮只下载一张 PNG。
  5. 在一张图片上放大到最细的细节，比如尺寸标注或脚注，确认所选预设够高。

适用场景

  • 把工程图或接线图放进 wiki、工单或 README，细线必须保持清晰可读。
  • 把导出为 PDF 的课件变成图片，上传到只接受图片的学习平台。
  • 生成干净的表格图片，粘贴到报告或聊天里，每条单元格边框都不会带上 JPEG 的灰边。
  • 给设计师提供高分辨率的页面图片，在修图软件里描摹、裁剪或合成。
  • 存档页面的准确外观，比如签好字的表格，以便日后比对，任何压缩瑕疵都会碍事。
  • 为 OCR 软件或翻译工具准备页面图片，清晰无瑕疵的输入效果更好。

开始前需要了解

  • 页面是画在白色背景上的，所以虽然 PNG 格式支持透明，输出的文件也不是透明的。
  • PDF 中的每一页都会被导出；只想转换其中几页，先用“提取页面”把它们取出来。
  • 文件以原文件名加补零页码命名，例如 plans-001.png、plans-002.png，ZIP 包名为 plans-png.zip。
  • 可选中的文字、超链接、书签和表单字段都不会保留。PNG 只呈现页面的样子，仅此而已。
  • 像素尺寸取决于 PDF 中存储的页面尺寸。A3 图纸在“标准”下约为 1684 x 2382 像素，A4 页面约为 1191 x 1684。
  • 文件大小的差异比 JPG 大得多。纯文字页面可能很小；照片多的页面或带噪点的深色背景，在“高”质量下每页可能达到好几 MB。深色幻灯片和带渐变的页面用 PNG 压缩效果很差。如果一套课件每页都是黑色背景，用“高”会得到很大的文件，可以考虑改用“标准”。

获得最佳效果的技巧

  • 对于混合文档，转换两次：图纸页用 PNG，照片页用 JPG，每页各取合适的那一份。
  • 如果有人要打印图片，或要从中看清 6 磅的小字，就用“高”；屏幕查看用“标准”完全够了。
  • 如果 PNG 对网站来说太大，保持 PNG 格式，用图片优化工具处理一下，可以在不损失像素的情况下缩小体积。
  • 矢量图纸用“高”检查一下。在 108 dpi 下看起来断断续续的细线，到 216 dpi 往往就是连续的了。
  • 图片旁边保留 PDF，它仍是可搜索、可缩放的母版。图片是在转换那一刻渲染的，所以阅读器里显示的批注，只有在 PDF.js 也绘制它们时才会包含；默认关闭的隐藏图层仍然保持隐藏。

实际示例：装修师傅分享平面图

一位装修工长从设计师那里收到一份 A3 矢量 PDF 平面图，需要通过微信把各房间尺寸发给瓷砖师傅。瓷砖师傅什么都在手机上看，不想折腾 PDF。

转成 JPG 时，尺寸标注（细线旁边的灰色小字）边缘出现斑驳，放大后 3 和 8 很难分清。用“高”转成 PNG，页面约为 2526 x 3573 像素，每个标注都很清晰，因为没有经过有损压缩。文件比 JPG 大，但发送起来仍然很轻松。

工长还注意到，设计图上有些细细的填充图案在“屏幕”质量下消失了。这不是图纸的问题：在 108 dpi 下，这些线条比一个像素还细。选“高”就解决了，这也是设置三个预设的主要原因。如果平面图是扫描的纸质图纸而不是矢量导出，结果就不一样了：PNG 会忠实还原纸张纹理和灰色噪点，文件会很大。扫描件一般用“标准”质量的 JPG 是比较合理的折中，PNG 留给必须看清细小标注的页面。

故障排除

PNG 文件特别大
PNG 是无损的，照片多的页面自然大。换个低一点的预设，或者把这些页面改用“PDF 转 JPG”转换。
细线缺失或断断续续
在所选分辨率下它们比一个像素还细。用“高”重新转换。
我以为背景会是透明的
页面渲染在白底上，所以输出是不透明的。如果需要透明，在修图软件里去掉背景。
工具打不开我的 PDF
通常是因为有密码或文件损坏。在原软件里解除保护，或试试“修复 PDF”，再转换修好的副本。
长文档只显示了 50 个下载按钮
为了便于阅读，列表最多显示 50 个按钮。ZIP 下载包含所有页面。
文字看起来和原文件略有不同
PDF 可能用了未嵌入的字体，PDF.js 换成了相近的字体。重新导出嵌入字体的 PDF。

常见问题

PDF 页面转 PNG 比 JPG 好吗？

对文字、图表和线条图来说是的：PNG 能精确保留边缘。对照片和扫描件，JPG 通常能以小得多的体积提供相近的视觉效果。

各预设对应多少 dpi？

“屏幕”约 108 dpi，“标准”约 144 dpi，“高”约 216 dpi，以 PDF 中存储的页面尺寸为基准。

PNG 能有透明背景吗？

不能。渲染器保存前会把页面画在白底上，所以每张 PNG 都是不透明的。

能从 PNG 里复制文字吗？

不能，文字已经变成像素。复制文字请用 PDF；如果没有 PDF，可以对图片做 OCR。

转换需要注册或付费吗？

不需要。工具免费使用，无需登录。

看起来差不多的页面，为什么 PNG 文件大小差很多？

PNG 对平坦区域压缩得很好，对有噪点的区域压缩得很差。即使分辨率相同，带照片、渐变或扫描纹理的页面也会比白底文字页大得多。

打不开的 PDF 让人焦虑，尤其当它是一张发票、一份证书或一份签好字的合同的唯一副本时。PDFora 的修复工具会重新解析受损文件，抢救出仍能读取的对象，再把 PDF 的内部结构重建成一份全新的、符合标准的文档。对最常见的几类损坏而言，这就足以让一个「死掉」的文件复活。

损坏通常源于下载中断、邮件附件被截断、导出过程崩溃，或者文件在系统之间传输时字节被弄乱。症状从直接报错到更隐晦的怪象都有，比如空白页、图片丢失，或者阅读器翻到第三页就卡死。修复的思路是丢掉坏掉的骨架，重写一副干净的。

整个过程在你的浏览器里运行。损坏的文件绝不上传，这意味着受损的税务文档或体检报告在修复期间依然保持私密。工具免费、无需账号、不加水印，你需要试多少次都可以。它目前处于测试阶段，我们如实说明这一点。

如何在线修复损坏的 PDF

  1. 用任意较新的浏览器打开 PDFora 的「修复 PDF」工具。
  2. 从设备中选择受损的 PDF，或把它拖到上传区。
  3. 点击「修复」开始。工具会在本地重新解析文件并重建其内部结构。
  4. 等待可恢复的页面、文字和图片被收拢进一份新文档。
  5. 下载修复后的 PDF，用你常用的阅读器打开，确认问题已解决。
  6. 把整份文档翻一遍，因为有些内容能恢复，另一些则可能确实已经丢失。

When to use this tool

  • 抢救一张下载到一半就断网的发票，它现在会提示「文件已损坏」。
  • 修复一份邮件附件 PDF：它在发件人机器上能打开，在你这里却报错。
  • 从出现读取错误的备份硬盘中救回一份旧的扫描版证书。
  • 修复某个有 bug 的导出功能写出的报告，其交叉引用表已经坏掉。
  • 让 PDF 能在严格的阅读器（比如印刷店的软件）中打开，此前它只能在容错度高的浏览器阅读器里显示。
  • 重建那种虽然技术上能打开、却显示空白页或乱码图片的文件。

Tips for the best results

  • 先试着重新下载。如果原始来源还在，重新下载比任何修复都可靠，因为修复只能利用幸存下来的字节。
  • 永远不要覆盖损坏的文件。把修复版另存为新名称，必要时你还能尝试其他恢复途径。
  • 如果修复后的文件能打开但内容不全，缺失的部分多半是真的被毁掉了，而不只是引用错乱。修复重建的是结构，它无法凭空造出丢失的数据。
  • 提示输入密码的 PDF 是被锁住了，不是损坏。修复无法处理加密文件，如果你有密码，请先解锁文档。
  • 修复后检查页数。与你预期的页数一比，最快就能看出是否有页面在损坏中丢失。

常见问题

修复具体是怎么进行的？

工具通读原始文件，提取出所有仍可解析的对象，然后把这些对象写进一份内部结构正确的全新 PDF。损坏的引用、受损的表和格式错误的文件头会被替换掉，而不是打补丁。

它能修好任何损坏的 PDF 吗？

不能，这一点我们宁愿直说。它对常见损坏处理得不错，比如交叉引用表损坏和文件被截断，但如果页面数据本身已被毁掉，就没有可供重建的素材了。工具尚在测试阶段，效果会持续改进。

能修复有密码保护的 PDF 吗？

不能。没有密码就无法重新解析加密文件，因此修复对它们无效。如果你知道密码，请先去掉保护，再执行修复。

我损坏的文件会被上传到服务器吗？

不会。重新解析和重建全部在浏览器内完成，文件不会离开你的设备。因此修复合同、证件扫描件和财务报表这类敏感文档是安全的。

修复后的 PDF 能打开，但有些页面是空白的，为什么？

空白页通常意味着这些页面的内容确实丢失了，而不只是排布错乱。修复找回了页面条目，却没有在其背后找到可绘制的数据。请查一查别处是否还留有这个文件的早期副本。

修复收费吗？需要账号吗？

都不需要。修复免费、免注册、输出不带水印，尝试次数也不设限。同一个文件可以反复跑几次，整个文件夹的文档也可以一个个修。

修复 PDF

重新读取其他程序打不开或报错的 PDF，并用干净、重建过的文件结构重新输出。

PDF 并不是一整段连续内容，而是由许多编号对象，加上一张告诉阅读器每个对象从哪里开始的交叉引用表组成。下载中途断掉、某个程序把这张表写错，或者文件被好几个工具轮番编辑过，这张表就可能指错位置。有的阅读器能默默兼容，有的显示空白页，上传平台则常常只给一句含糊的报错就拒收。“修复 PDF”针对的正是这种中间状态：结构乱了，但内容其实还在。

这个工具做的事情很明确。它用 pdf-lib 库加载文件，读取能找到的对象，自行理清结构，而不是去相信那张坏掉的表，然后保存一份新副本。新文件会有一张重新写好的交叉引用表，每个对象都单独写出，不再打包进压缩对象流；这是一种更老式的布局，严格或老旧的阅读器更容易接受。页面内容是复制过去的，不会重新渲染，所以文字、字体和图片都和原来一模一样。

也得坦白说明它的上限：这是重建，不是数据恢复。如果数据确实缺失，比如下载只下了一半，后半部分的页面根本无从重建，任何工具都变不出来。这种情况下，正确的办法是从源头重新拿一份文件。

如何修复 PDF 文件

  1. 打开“修复 PDF”工具，添加出问题的文件。每次只处理一个文件。
  2. 点击“修复并重建”。文件会被解析并重新保存，大多数文档一两秒就好。
  3. 如果工具报错，说明文件完全无法解析，请看下面的故障排除部分。
  4. 下载结果，文件名为原名加 -repaired，例如 contract-repaired.pdf。
  5. 在之前出错的阅读器或平台里打开修复后的副本，逐页翻看，确认每一页都有内容。

适用场景

  • 学校的论文提交系统提示 PDF 无效，可它在你自己的电脑上明明能打开。
  • 从老式扫描仪或财务软件导出的文件，在一个阅读器里正常，在另一个里却显示空白页。
  • 被不同程序反复编辑多次的 PDF 变得很卡，或者一打开就提示文件已损坏。
  • 给打印店或电子申报系统准备文件，它们的校验比普通阅读器更严格。
  • 合并或拆分之前先把文档规范一下，因为那些工具拒绝加载原文件。
  • 在请对方重新导出之前，先快速检查一下文件结构能不能读。

开始前需要了解

  • 修复只重建结构，不恢复丢失的内容。被截断的文件，最多只能找回那些完整的页面。
  • 输出文件不使用压缩对象流。这样兼容性更好，但通常比原文件略大；对大量使用对象流的文件，有时会大 10% 到 30%。
  • 页面按原样复制。如果某一页本身的内容流就坏了，重建之后它可能依然显示不正常。
  • 文件是在关闭加密检查的情况下打开的。加了密码的 PDF 也许能加载，但内容仍是加密的，保存出来的副本多半无法正常显示；请先在源头去掉密码。
  • 因为保存的是整份文档而不只是页面，pdf-lib 能读取的表单、书签和注释都会带到新文件中。
  • 处理在你的浏览器里完成，所以就算是不想发给在线恢复服务的文件，也可以放心在这里试。

获得最佳效果的技巧

  • 逐页检查结果之前，原文件和修复后的副本都要留着。
  • 把修复后文件的页数和你预期的页数对一下。页数变少，是源文件被截断最明显的信号。
  • 如果平台仍然拒收修复后的文件，可以在阅读器里“打印为 PDF”；这会重新渲染每一页，能解决重建处理不到的页面内部问题。
  • 通过邮件或下载得到的文件，在花时间修复之前，先请对方重新发一份。一份干净的副本胜过任何修复。
  • 修复成功后，如果文件变大了而且主要是扫描件，可以再用“压缩 PDF”处理一下。

实例：自由译者的全年发票合集

一位自由译者从一款老旧的开票软件里，把十二个月的发票导出成一个 PDF，准备用于年度个税汇算的材料。文件在浏览器自带的阅读器里能打开，但申报系统的上传页面提示文档无效，“合并 PDF”也拒绝把它和其他材料合在一起。

经过“修复 PDF”处理后，文件被成功加载，重写了交叉引用表，并以不含对象流的方式保存。上传页面接受了修复后的副本，合并工具也能读取了。文件从 410 KB 变成了约 460 KB，这是更保守的布局带来的代价，在这里完全无所谓。

提交之前，译者数了一下页数：十二张发票，十二页。如果只有九页，就说明当初的导出本身不完整，唯一真正的办法是从开票软件里重新导出。

故障排除

工具报错，没有任何输出
文件完全无法解析，通常是因为它其实不是 PDF（比如一个被存成 .pdf 名字的 HTML 错误页面），或者被严重截断。用文本编辑器打开看看：真正的 PDF 以 %PDF 开头。否则请重新获取一份。
修复后的文件少了几页
这些页面在源文件中就已经无法读取，通常是下载中途断了。请重新下载或导出文档。
页面仍然空白或乱码
页面内容本身已损坏，而结构重建不会触及页面内容。试着在显示效果最好的阅读器里把原文件“打印为 PDF”，或者请发件人重新导出。
修复后的文件比原文件大
工具会把对象逐个写出，而不是放进压缩对象流。这是为了兼容性有意为之；如果在意大小，可以再压缩一下。
修复后的副本显示的内容无法阅读
源文件多半是加密的。加载时忽略了加密，所以内容仍是乱的。请在生成文件的程序里去掉密码，再修复那份副本。
平台还是拒收
校验程序可能针对的不是结构，而是文件大小、页面尺寸或嵌入字体等。请查看平台的具体要求，相应地调整页面大小、压缩或“打印为 PDF”。

常见问题

“修复 PDF”具体改了什么？

它重新读取文档对象，写一张新的交叉引用表，并把每个对象单独保存，不使用对象流。页面内容原样复制。

在哪里都打不开的 PDF 能救回来吗？

有时可以。如果对象完好、只是结构坏了，就能救。如果数据本身缺失，或者文件根本不是 PDF，任何修复工具都无能为力。

修复会降低质量吗？

不会。没有任何重新渲染或重新压缩，文字和图片看起来和原来完全一样。

为什么文件变大了？

输出不使用压缩对象流，文件会略大一些，但老旧和严格的软件都能读取。

修复会去掉密码吗？

不会。它不解密任何内容，加密文件在重建后通常无法正常显示。

能一次修复多个文件吗？

每次处理一个文件。请逐个处理；普通文档都很快。

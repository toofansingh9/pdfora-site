HTML în PDF

Convertește un fișier HTML salvat în PDF pe un server de conversie, transformând o pagină web sau un export HTML în pagini fixe, gata de tipărit.

🔒 Fișierele tale sunt procesate local, în browserul tău, și nu sunt niciodată încărcate.
1

Încarcă

Selectează fișierul sau trage-l și plasează-l.

2

Ajustează

Alege-ți opțiunile — totul se întâmplă în browserul tău.

3

Descarcă

Salvează instantaneu fișierul finalizat. Fără filigrane.

Multe documente utile există doar ca HTML: o confirmare de comandă salvată din browser, un raport exportat dintr-o aplicație, un newsletter, o documentație generată ca o singură pagină sau o pagină construită chiar de tine. HTML-ul se reașază după fereastra în care e deschis, iar exact asta nu vrei când documentul trebuie arhivat, tipărit sau atașat la o reclamație. Un PDF îl fixează la o singură dimensiune de pagină.

Instrumentul primește un fișier .html sau .htm de pe calculatorul tău, nu o adresă web. Fișierul este încărcat, criptat, la serviciul CloudConvert prin releul PDFora, unde un motor de randare așază pagina și o tipărește în PDF; rezultatul se întoarce cu numele fișierului tău și este apoi șters de pe serviciu. Conversia nu are loc în browser, iar pe pagina instrumentului nu există setări pentru dimensiunea paginii sau margini.

Cea mai mare surpriză pentru cei mai mulți e ce se întâmplă cu tot ce indică fișierul HTML. O pagină web e rareori un singur fișier: imaginile, foile de stil și fonturile sunt de obicei fișiere separate, la care HTML-ul face referire. Se încarcă doar fișierul pe care îl alegi, așa că serverul nu poate găsi nimic din ce e referit printr-o cale relativă de pe discul tău. Ca să obții un PDF fidel, totul se reduce, de fapt, la a face fișierul HTML autonom înainte de conversie.

Cum convertești HTML în PDF

  1. Asigură-te că fișierul HTML este autonom sau folosește adrese web complete (https://...) pentru imagini și foi de stil; vezi observațiile de mai jos.
  2. Deschide HTML în PDF și alege fișierul .html sau .htm.
  3. Apasă Convertește și așteaptă cât fișierul este încărcat și randat pe server.
  4. Descarcă PDF-ul, care păstrează numele fișierului tău, cu extensia .pdf.
  5. Verifică dacă au ajuns imaginile, culorile și așezarea și dacă nu e tăiat nimic la marginea din dreapta.

Când să folosiți acest instrument

  • Bonuri și confirmări de rezervare salvate din browser, păstrate ca PDF pentru contabilitate sau ca dovadă.
  • Rapoarte exportate de un program în HTML, care trebuie atașate la un e-mail sau arhivate.
  • Dezvoltatori care transformă un șablon HTML generat de factură, diplomă sau scrisoare în PDF, ca să verifice cum arată la tipar.
  • Documentații sau ghiduri de utilizare publicate ca o singură pagină HTML lungă, tipărite pentru citit offline.
  • Articole web salvate pentru documentare, într-un format care nu se schimbă dacă se schimbă site-ul.
  • Newslettere salvate ca HTML și convertite, ca evidență a ce s-a trimis.

Ce trebuie să știi înainte să începi

  • Linkurile relative nu funcționează. Dacă HTML-ul conține <img src="images/logo.png"> sau <link href="style.css">, acele fișiere rămân pe calculatorul tău, iar serverul nu le vede. PDF-ul va avea imagini lipsă și text fără stil. Folosește adrese absolute https:// sau include CSS-ul într-un bloc <style> și imaginile ca data URI.
  • Resursele cu adrese web absolute pot fi descărcate de server la randare, așa că imaginile și foile de stil accesibile public apar de obicei. Ce se află în spatele unei autentificări, pe un intranet sau pe localhost nu va apărea.
  • Nu există câmp pentru URL. Ca să convertești o pagină live, salveaz-o mai întâi; opțiunea browserului Salvare pagină ca > Pagină web, un singur fișier (.mhtml) nu este acceptată, așa că alege Pagină web, doar HTML și așteaptă-te ca imaginile relative să lipsească, sau folosește direct Imprimare > Salvare ca PDF din browser.
  • Se aplică stilurile de tipărire. Dacă pagina are CSS pentru @media print, convertorul îl folosește de regulă, ceea ce poate ascunde bare de navigare sau schimba culorile față de ce vezi pe ecran. Întreruperile de pagină se pot controla în CSS cu break-before și break-inside.
  • Conținutul construit cu JavaScript nu e de încredere. Paginile care își aduc conținutul prin scripturi după încărcare pot ieși ca o carcasă goală. Salvează pagina după ce s-a încărcat complet sau generează conținutul direct în HTML, pe server.
  • Așezările mai late decât o pagină tipărită, cum ar fi designurile fixe de 1400 de pixeli sau tabelele late, pot fi tăiate sau micșorate. De obicei rezolvă problema un layout responsive sau un max-width pe conținutul principal.

Sfaturi pentru rezultate optime

  • La propriile șabloane, pune tot CSS-ul într-un bloc <style> în <head>; e cel mai sigur mod de a obține un PDF cu stil.
  • Adaugă @page { size: A4; margin: 15mm; } în CSS dacă ai nevoie de o anumită dimensiune a paginii sau de anumite margini.
  • Folosește break-inside: avoid pe rândurile de tabel, carduri și figuri, ca să nu fie rupte pe două pagini.
  • Ține imaginile la dimensiuni rezonabile: o imagine de 5 MB inclusă ca data URI tot un PDF de 5 MB face.
  • Deschide mai întâi fișierul HTML în previzualizarea de imprimare a browserului; dacă arată greșit acolo, probabil va arăta greșit și în PDF-ul convertit.

Exemplu practic: șablonul HTML de factură al unui mic magazin

Un magazin online cu doi angajați, din Brașov, generează facturile ca fișiere HTML dintr-un script simplu. Fiecare fișier face legătura cu invoice.css și logo.png din același folder. Convertit direct, PDF-ul iese ca text negru simplu, cu font implicit, fără logo și cu tabelul de totaluri întins pe toată lățimea, pentru că serverul a primit fișierul HTML fără foaia de stil și fără imagine.

Soluția e ca fișierul să fie autonom. Scriptul copiază acum conținutul lui invoice.css într-un bloc <style>, adaugă @page { size: A4; margin: 18mm; } și break-inside: avoid pe rândurile tabelului cu produse și trimite logo-ul la adresa lui publică https de pe site-ul magazinului, în loc de o cale locală. Nimic altceva nu se schimbă.

Convertită din nou, factura e un PDF A4 de o pagină, cu logo, culorile magazinului și un tabel de totaluri care nu se mai rupe când o comandă are multe rânduri. Pentru că șablonul e acum autonom, fiecare factură produsă de script se convertește la fel.

Depanare

PDF-ul nu are stil, e doar text simplu
Foaia de stil era referită printr-o cale relativă și nu a fost încărcată. Include CSS-ul într-un bloc <style> sau leag-o cu o adresă completă https://.
Lipsesc imaginile
Imaginile de pe disc referite cu căi relative nu pot fi accesate. Folosește URL-uri publice https:// sau include imaginile ca data URI, apoi convertește din nou.
Pagina e tăiată în dreapta
Layout-ul are o lățime fixă mai mare decât pagina. Adaugă max-width: 100% pe containerele principale și pe imagini sau o foaie de stil pentru tipar care îngustează așezarea.
PDF-ul e gol sau aproape gol
Probabil conținutul e creat de JavaScript după încărcare sau fișierul e doar o redirecționare. Salvează pagina după ce s-a randat complet sau pune conținutul direct în HTML.
Textul apare cu alt font
Fonturile web referite local nu erau disponibile. Leagă fontul de la un URL public, include-l cu @font-face și un data URI sau folosește o listă de fonturi uzuale.
Instrumentul îmi respinge fișierul
Sunt acceptate doar .html și .htm. Fișierele salvate ca .mhtml sau .webarchive trebuie salvate din nou ca doar HTML.

Întrebări frecvente

Pot converti un site introducând adresa lui?

Nu. Instrumentul convertește un fișier HTML pe care îl alegi. Salvează mai întâi pagina ca HTML sau folosește Imprimare > Salvare ca PDF din browser pentru o pagină live.

Fișierul HTML este încărcat pe un server?

Da. E trimis criptat la serviciul de conversie, randat acolo și apoi șters. Evită să convertești pagini cu date personale pe care nu ai vrea să le proceseze un terț.

De ce lipsesc imaginile și CSS-ul?

Se încarcă doar fișierul HTML propriu-zis. Fișierele la care face referire prin căi relative rămân pe calculatorul tău; folosește linkuri absolute https:// sau include-le în HTML.

Pot seta dimensiunea paginii sau marginile?

Nu din pagina instrumentului. Setează-le în HTML cu o regulă CSS @page, de exemplu @page { size: A4; margin: 15mm; }.

Linkurile se pot accesa în PDF?

Linkurile spre adrese web rămân de obicei active. Linkurile relative spre alte fișiere locale nu vor duce nicăieri util.

Se rulează JavaScript în timpul conversiei?

Poate rula parțial, dar conținutul care se încarcă târziu sau depinde de interacțiunea utilizatorului lipsește adesea. Pentru rezultate sigure, HTML-ul ar trebui să conțină deja conținutul final.

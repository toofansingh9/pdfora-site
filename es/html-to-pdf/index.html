HTML a PDF

Convierte un archivo HTML guardado en PDF en un servidor de conversión, para que una página web o una exportación HTML quede en páginas fijas e imprimibles.

🔒 Tus archivos se procesan localmente en tu navegador y nunca se suben.
1

Sube

Selecciona o arrastra y suelta tu archivo.

2

Ajusta

Elige tus opciones: todo ocurre en tu navegador.

3

Descarga

Guarda el archivo terminado al instante. Sin marcas de agua.

Muchos documentos útiles solo existen en HTML: una confirmación de pedido guardada desde el navegador, un informe que exporta una aplicación, un boletín, una documentación generada como una sola página o una página que hiciste tú. El HTML se recoloca para adaptarse a la ventana en la que se abre, y eso es justo lo que no quieres cuando hay que archivar el documento, imprimirlo o adjuntarlo a una reclamación. Un PDF lo deja fijo en un tamaño de página.

Esta herramienta trabaja con un archivo .html o .htm de tu ordenador, no con una dirección web. El archivo se sube cifrado al servicio CloudConvert a través del relé de PDFora, donde un motor de renderizado maqueta la página y la imprime en PDF; el resultado vuelve con el nombre de tu archivo y después se borra del servicio. La conversión no ocurre en tu navegador, y en la página no hay ajustes de tamaño de página ni de márgenes.

Lo que más sorprende a la mayoría es qué pasa con todo aquello a lo que apunta el HTML. Una página web casi nunca es un solo archivo: las imágenes, las hojas de estilo y las fuentes suelen ser archivos aparte enlazados desde el HTML. Solo se sube el archivo que eliges, así que el servidor no puede encontrar nada que esté enlazado con una ruta relativa de tu disco. Para conseguir un PDF fiel, lo importante es dejar el HTML autosuficiente antes de convertirlo.

Cómo pasar un HTML a PDF

  1. Asegúrate de que el archivo HTML es autosuficiente o de que usa direcciones web completas (https://...) para sus imágenes y hojas de estilo; mira las notas de abajo.
  2. Abre HTML a PDF y elige el archivo .html o .htm.
  3. Pulsa Convertir y espera mientras el archivo se sube y se renderiza en el servidor.
  4. Descarga el PDF, que conserva el nombre de tu archivo con la extensión .pdf.
  5. Comprueba que las imágenes, los colores y la maquetación han llegado bien y que no hay contenido cortado en el borde derecho.

Cuándo usar esta herramienta

  • Recibos y confirmaciones de reserva guardados desde el navegador, conservados en PDF para la contabilidad o como prueba.
  • Informes que un programa exporta en HTML y que hay que adjuntar a un correo o archivar.
  • Desarrolladores que convierten una plantilla HTML de factura, certificado o carta en PDF para revisar cómo queda impresa.
  • Documentación o un manual de usuario publicado como una única página HTML larga, impreso para leerlo sin conexión.
  • Artículos web guardados para una investigación en un formato que no cambie aunque cambie la web.
  • Boletines de correo guardados en HTML y convertidos para tener constancia de lo que se envió.

Lo que debes saber antes de empezar

  • Los enlaces relativos se rompen. Si el HTML dice <img src="images/logo.png"> o <link href="style.css">, esos archivos se quedan en tu ordenador y el servidor no los ve. El PDF muestra entonces imágenes que faltan y texto sin estilo. Usa direcciones https:// absolutas, o mete el CSS en un bloque <style> y las imágenes como data URIs.
  • El servidor puede descargar los recursos con direcciones web absolutas al renderizar la página, así que las imágenes y hojas de estilo públicas suelen aparecer. Lo que esté detrás de un inicio de sesión, en una intranet o en localhost, no.
  • No hay casilla para URL. Para convertir una página en línea, guárdala primero; la opción del navegador Guardar como > Página web, archivo único (.mhtml) no se acepta, así que usa Página web, solo HTML, y cuenta con que faltarán las imágenes relativas, o usa Imprimir > Guardar como PDF del propio navegador.
  • Se aplican los estilos de impresión. Si la página tiene CSS para @media print, el conversor normalmente lo usa, lo que puede ocultar menús o cambiar colores respecto a lo que ves en pantalla. Los saltos de página se controlan con break-before y break-inside en CSS.
  • El contenido generado con JavaScript no es fiable. Las páginas que cargan su contenido con scripts después de abrirse pueden convertirse en un esqueleto vacío. Guarda la página cuando haya terminado de cargar o genera el contenido en el HTML desde el servidor.
  • Los diseños más anchos que una página impresa, como maquetas fijas de 1400 píxeles o tablas anchas, pueden salir cortados o encogidos. Un diseño responsive o un max-width en el contenido principal suele arreglarlo.

Consejos para obtener los mejores resultados

  • En tus propias plantillas, pon todo el CSS en un bloque <style> dentro del <head>; es la forma más fiable de conseguir un PDF con estilo.
  • Añade @page { size: A4; margin: 15mm; } a tu CSS si necesitas un tamaño de página o unos márgenes concretos.
  • Usa break-inside: avoid en filas de tabla, tarjetas e imágenes para que no queden partidas entre dos páginas.
  • Controla el peso de las imágenes: una imagen de cabecera de 5 MB metida como data URI sigue dando un PDF de 5 MB.
  • Abre antes el HTML en la vista previa de impresión del navegador; si ahí se ve mal, lo más probable es que en el PDF también.

Ejemplo práctico: la plantilla HTML de facturas de una tienda pequeña

Una tienda online de dos personas en Sevilla genera sus facturas como archivos HTML con un script sencillo. Cada archivo enlaza a invoice.css y logo.png en la misma carpeta. Al convertirla directamente, el PDF sale en texto negro con la fuente por defecto, sin logotipo y con la tabla de totales estirada a todo el ancho, porque el servidor recibió el HTML sin su hoja de estilos ni su imagen.

La solución es que el archivo se valga por sí mismo. Ahora el script copia el contenido de invoice.css en un bloque <style>, añade @page { size: A4; margin: 18mm; } y break-inside: avoid en las filas de la tabla de conceptos, y apunta el logotipo a su dirección https pública en la web de la tienda en lugar de a una ruta local. No cambia nada más.

Al volver a convertirla, la factura es un PDF A4 de una página con el logotipo, los colores de la tienda y una tabla de totales que ya no se parte cuando un pedido tiene muchas líneas. Como la plantilla ahora es autosuficiente, todas las facturas que genera el script se convierten igual.

Solución de problemas

El PDF no tiene estilos, solo texto plano
La hoja de estilos estaba enlazada con una ruta relativa y no se subió. Mete el CSS en un bloque <style> o enlázalo con una dirección https:// completa.
Faltan las imágenes
No se puede acceder a las imágenes de tu disco enlazadas con rutas relativas. Usa URL https:// públicas o incrusta las imágenes como data URIs y vuelve a convertir.
La página sale cortada por la derecha
El diseño tiene un ancho fijo mayor que la página. Añade max-width: 100% a los contenedores principales y a las imágenes, o una hoja de estilos de impresión que estreche el diseño.
El PDF sale en blanco o casi en blanco
Probablemente el contenido lo crea JavaScript después de cargar, o el archivo es solo una redirección. Guarda la página cuando esté completamente cargada o pon el contenido directamente en el HTML.
El texto aparece con otra fuente
Las fuentes web enlazadas en local no estaban disponibles. Enlaza la fuente desde una URL pública, incrústala con @font-face y un data URI, o usa una pila de fuentes comunes.
La herramienta rechaza mi archivo
Solo se aceptan .html y .htm. Los archivos .mhtml o .webarchive hay que volver a guardarlos como solo HTML.

Preguntas frecuentes

¿Puedo convertir una web escribiendo su URL?

No. La herramienta convierte un archivo HTML que eliges tú. Guarda antes la página como HTML o, para una página en línea, usa Imprimir > Guardar como PDF del navegador.

¿Se sube el archivo HTML?

Sí. Se envía cifrado al servicio de conversión, se renderiza allí y después se borra. No conviertas páginas con datos personales que no quieras que procese un tercero.

¿Por qué faltan mis imágenes y mi CSS?

Solo se sube el propio archivo HTML. Los archivos a los que enlaza con rutas relativas se quedan en tu ordenador; usa enlaces https:// absolutos o incrústalos en el HTML.

¿Puedo elegir el tamaño de página o los márgenes?

En la página de la herramienta no. Defínelos en el HTML con una regla CSS @page, por ejemplo @page { size: A4; margin: 15mm; }.

¿Los enlaces se pueden pulsar en el PDF?

Los enlaces a direcciones web normalmente siguen funcionando. Los enlaces relativos a otros archivos locales no llevarán a ningún sitio útil.

¿Se ejecuta JavaScript durante la conversión?

Puede ejecutarse en parte, pero el contenido que carga tarde o que depende de la interacción del usuario a menudo falta. Para un resultado fiable, el HTML ya debe contener el contenido final.

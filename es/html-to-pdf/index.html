HTML a PDF

Convierte un archivo HTML guardado en PDF en un servidor de conversión, para que una página web o una exportación HTML quede en páginas fijas e imprimibles.

🔒 Tus archivos se procesan localmente en tu navegador y nunca se suben.
1

Sube

Selecciona o arrastra y suelta tu archivo.

2

Ajusta

Elige tus opciones: todo ocurre en tu navegador.

3

Descarga

Guarda el archivo terminado al instante. Sin marcas de agua.

La confirmación de una compra que guardaste desde el navegador, el informe que una aplicación exporta en HTML, el boletín que mandaste a tus clientes o la página que montaste tú para unos certificados: todos existen solo como HTML, y el HTML se recoloca según la ventana en la que se abra. Eso está bien para leer en pantalla y mal para archivar, imprimir o adjuntar a una reclamación. Convertirlo a PDF lo deja fijado en un tamaño de página.

HTML a PDF trabaja con un archivo .html o .htm de tu equipo, no con una dirección web. El archivo se sube cifrado al servicio CloudConvert a través del relé de PDFora, donde un motor de renderizado maqueta la página y la imprime a PDF; el resultado vuelve con el nombre de tu archivo y después se borra del servicio. Es decir, esta conversión no ocurre en tu navegador, y la página de la herramienta no tiene ajustes de tamaño de página ni de márgenes.

Lo que más desconcierta es lo que pasa con todo a lo que apunta el HTML. Una página web casi nunca es un único archivo: imágenes, hojas de estilo y fuentes suelen ser archivos aparte enlazados desde el HTML. Como solo se sube el archivo que eliges, el servidor no puede encontrar nada enlazado con una ruta relativa de tu disco. La clave para un PDF fiel es dejar el HTML autosuficiente antes de convertirlo.

Cómo pasar un HTML a PDF

  1. Asegúrate de que el archivo HTML es autosuficiente o de que usa direcciones web completas (https://...) para sus imágenes y hojas de estilo; mira las notas de abajo.
  2. Abre HTML a PDF y elige el archivo .html o .htm.
  3. Pulsa Convertir y espera mientras el archivo se sube y se renderiza en el servidor.
  4. Descarga el PDF, que conserva el nombre de tu archivo con la extensión .pdf.
  5. Comprueba que las imágenes, los colores y la maquetación han llegado bien y que no hay contenido cortado en el borde derecho.

Cuándo usar esta herramienta

  • Facturas, recibos y confirmaciones de compra guardados desde el navegador y conservados en PDF para la contabilidad o para una reclamación.
  • Certificados de asistencia o diplomas de un curso generados como HTML, convertidos a PDF para enviarlos a cada alumno.
  • Informes que un programa de gestión exporta en HTML y que hay que adjuntar a un correo o archivar.
  • Desarrolladores que convierten una plantilla HTML de factura, carta o presupuesto para comprobar cómo queda impresa.
  • Manuales o documentación publicados como una sola página HTML larga, convertidos para leerlos sin conexión.
  • Boletines y correos guardados en HTML, convertidos para tener constancia de lo que se envió y cuándo.

Lo que debes saber antes de empezar

  • Los enlaces relativos se rompen. Si el HTML dice <img src="images/logo.png"> o <link href="style.css">, esos archivos se quedan en tu ordenador y el servidor no los ve. El PDF muestra entonces imágenes que faltan y texto sin estilo. Usa direcciones https:// absolutas, o mete el CSS en un bloque <style> y las imágenes como data URIs.
  • El servidor puede descargar los recursos con direcciones web absolutas al renderizar la página, así que las imágenes y hojas de estilo públicas suelen aparecer. Lo que esté detrás de un inicio de sesión, en una intranet o en localhost, no.
  • No hay casilla para URL. Para convertir una página en línea, guárdala primero; la opción del navegador Guardar como > Página web, archivo único (.mhtml) no se acepta, así que usa Página web, solo HTML, y cuenta con que faltarán las imágenes relativas, o usa Imprimir > Guardar como PDF del propio navegador.
  • Se aplican los estilos de impresión. Si la página tiene CSS para @media print, el conversor normalmente lo usa, lo que puede ocultar menús o cambiar colores respecto a lo que ves en pantalla. Los saltos de página se controlan con break-before y break-inside en CSS.
  • El contenido generado con JavaScript no es fiable. Las páginas que cargan su contenido con scripts después de abrirse pueden convertirse en un esqueleto vacío. Guarda la página cuando haya terminado de cargar o genera el contenido en el HTML desde el servidor.
  • Los diseños más anchos que una página impresa, como maquetas fijas de 1400 píxeles o tablas anchas, pueden salir cortados o encogidos. Un diseño responsive o un max-width en el contenido principal suele arreglarlo.

Consejos para obtener los mejores resultados

  • En tus propias plantillas, pon todo el CSS en un bloque <style> dentro del <head>; es la forma más fiable de conseguir un PDF con estilo.
  • Añade @page { size: A4; margin: 15mm; } a tu CSS si necesitas un tamaño de página o unos márgenes concretos.
  • Usa break-inside: avoid en filas de tabla, tarjetas e imágenes para que no queden partidas entre dos páginas.
  • Controla el peso de las imágenes: una imagen de cabecera de 5 MB metida como data URI sigue dando un PDF de 5 MB.
  • Abre antes el HTML en la vista previa de impresión del navegador; si ahí se ve mal, lo más probable es que en el PDF también.

Ejemplo práctico: los certificados de un curso de formación

Julia organiza cursos de fotografía en Montevideo y, al terminar cada edición, genera un certificado de asistencia por alumno con una plantilla HTML y un pequeño script. La plantilla enlaza a una fuente de Google Fonts, a estilos.css y a una imagen de fondo, fondo.png, en la misma carpeta. Al convertir el primer certificado, el PDF sale en vertical, con una fuente genérica, sin el fondo y con el texto pegado al borde izquierdo: el servidor recibió el HTML solo, sin la hoja de estilos ni la imagen.

La solución es que el archivo se baste a sí mismo. Julia hace que el script copie el contenido de estilos.css en un bloque <style>, deje el enlace a la fuente con su dirección https:// completa, incruste fondo.png como imagen en base64 y añada @page { size: A4 landscape; margin: 0; } para que el certificado salga apaisado y a sangre. No toca nada más de la plantilla.

En la segunda conversión el certificado es un PDF A4 apaisado de una página, con la fuente correcta, el fondo completo y el nombre del alumno centrado. Como la plantilla ya es autosuficiente, los 18 certificados de esa edición se convierten igual, y los siguientes cursos solo requieren cambiar los nombres y las fechas.

Solución de problemas

El PDF no tiene estilos, solo texto plano
La hoja de estilos estaba enlazada con una ruta relativa y no se subió. Mete el CSS en un bloque <style> o enlázalo con una dirección https:// completa.
Faltan las imágenes
No se puede acceder a las imágenes de tu disco enlazadas con rutas relativas. Usa URL https:// públicas o incrusta las imágenes como data URIs y vuelve a convertir.
La página sale cortada por la derecha
El diseño tiene un ancho fijo mayor que la página. Añade max-width: 100% a los contenedores principales y a las imágenes, o una hoja de estilos de impresión que estreche el diseño.
El PDF sale en blanco o casi en blanco
Probablemente el contenido lo crea JavaScript después de cargar, o el archivo es solo una redirección. Guarda la página cuando esté completamente cargada o pon el contenido directamente en el HTML.
El texto aparece con otra fuente
Las fuentes web enlazadas en local no estaban disponibles. Enlaza la fuente desde una URL pública, incrústala con @font-face y un data URI, o usa una pila de fuentes comunes.
La herramienta rechaza mi archivo
Solo se aceptan .html y .htm. Los archivos .mhtml o .webarchive hay que volver a guardarlos como solo HTML.

Preguntas frecuentes

¿Puedo pegar la URL de una web y convertirla?

No. La herramienta convierte un archivo HTML que tienes guardado. Para una página en línea, guárdala antes como HTML o usa Imprimir > Guardar como PDF en el navegador.

¿El archivo HTML sale de mi ordenador?

Sí. Se envía cifrado al servicio de conversión, se renderiza allí y después se borra. Si la página contiene datos personales que no quieres que procese un tercero, no la conviertas aquí.

¿Por qué el PDF sale sin imágenes y sin estilos?

Porque solo se sube el propio archivo HTML. Lo que enlaza con rutas relativas se queda en tu disco; usa enlaces https:// absolutos o incrusta los recursos dentro del HTML.

¿Dónde elijo el tamaño de página y los márgenes?

En la herramienta no hay ajustes. Defínelos en el propio HTML con una regla CSS @page, por ejemplo @page { size: A4; margin: 15mm; }.

¿Los enlaces siguen funcionando en el PDF?

Los que apuntan a direcciones web suelen seguir funcionando. Los enlaces relativos a otros archivos de tu equipo no llevarán a ningún sitio útil.

¿Se ejecuta el JavaScript de la página al convertir?

Puede ejecutarse en parte, pero el contenido que se carga tarde o que depende de que alguien haga clic suele faltar. Para un resultado fiable, el HTML debe contener ya el contenido final.

Pisahkan Jadi Dua

Potong dokumen menjadi dua bagian sama besar hanya dengan satu klik.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.
1

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Pilih opsi Anda — semuanya berlangsung di browser Anda.

3

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

Ada pekerjaan yang tidak butuh banyak pilihan — cukup satu tombol. Alat split-in-half PDFora memotong PDF menjadi dua bagian sama besar dengan sekali klik. File 200 halaman menjadi halaman 1-100 dan halaman 101-200, tanpa perlu mengetik rentang, tanpa pengaturan apa pun. Kalau jumlah halamannya ganjil, alat ini menangani halaman tengahnya untuk Anda, jadi dokumen 101 halaman tetap terbagi secara masuk akal.

Seperti semua alat PDFora, pemotongan dilakukan oleh browser Anda, di perangkat Anda sendiri. Dokumen tidak pernah diunggah, jadi membelah berkas uji tuntas atau buku panduan karyawan tidak berarti menitipkannya ke server orang lain. Pemrosesan lokal itu juga membuatnya cepat — tidak ada waktu transfer, hanya satu dua detik yang dibutuhkan perangkat Anda untuk menulis dua file baru.

Sepenuhnya gratis: tanpa pendaftaran, tanpa watermark di kedua bagian, tanpa batas pemakaian. Pecah satu file hari ini dan lima puluh besok, alat ini memperlakukan Anda sama saja.

Cara memecah PDF menjadi dua bagian secara online

  1. Buka alat Split in Half di getpdfora.com — tidak perlu akun.
  2. Tambahkan PDF Anda dengan mengklik untuk memilih file atau menyeretnya ke halaman.
  3. Pastikan itu dokumen yang benar; alat ini menampilkan file yang sudah dimuat.
  4. Klik tombol split. Hanya itu seluruh konfigurasinya.
  5. Browser Anda membagi dokumen tepat di titik tengah menjadi dua PDF.
  6. Unduh kedua bagian dan ganti namanya kalau perlu, misalnya bagian-1 dan bagian-2.

When to use this tool

  • Membuat laporan muat di bawah batas lampiran penyedia email dengan mengirimnya sebagai dua bagian.
  • Membagi hasil pindaian dua buku dalam satu jilid, di mana masing-masing karya menempati kira-kira separuh file.
  • Membagikan manual pelatihan yang panjang untuk dua sesi, sehingga peserta hanya menerima bagian yang mereka butuhkan minggu itu.
  • Memecah pekerjaan proofreading di tengah supaya dua penyunting bisa bekerja paralel.
  • Memecah antrean cetak besar jadi dua agar printer kantor tidak tersendat oleh satu pekerjaan raksasa.
  • Membelah PDF berukuran berlebih yang ditolak portal web atau LMS jika dikirim utuh.

Tips for the best results

  • Cek dulu total halamannya supaya Anda tahu di mana potongan akan jatuh — titik tengah file 61 halaman bisa saja berada di tengah bab.
  • Kalau titik pemisah alaminya bukan di tengah, gunakan alat Split biasa dengan rentang khusus; alat ini dibuat untuk kecepatan, bukan presisi.
  • Membelah dua adalah solusi cepat untuk batas ukuran, tapi kalau file membengkak karena pindaian, mengompresnya mungkin membuat pemecahan tidak perlu sama sekali.
  • Ganti nama hasil unduhan segera — dua file dengan nama nyaris identik cepat sekali tertukar.
  • Anda bisa memasukkan salah satu belahan ke alat ini lagi untuk membagi dokumen menjadi seperempat dalam dua klik.

Pertanyaan yang sering diajukan

Apa yang terjadi kalau jumlah halaman PDF saya ganjil?

Alat ini tetap memecahnya dengan rapi — salah satu bagian sekadar mendapat satu halaman ekstra. File 25 halaman, misalnya, menjadi satu bagian 13 halaman dan satu bagian 12 halaman.

Bisakah saya menentukan sendiri titik pemotongannya?

Tidak dengan alat ini — ia selalu memotong di titik tengah, dan justru itu yang membuatnya cukup satu klik. Kalau Anda butuh pemisah di halaman tertentu, alat Split utama PDFora menerima rentang khusus seperti 1-40, 41-90.

Apakah kedua bagian mempertahankan kualitas aslinya?

Ya. Halaman dipindahkan tanpa perubahan, jadi teks, gambar, dan tata letak di kedua bagian identik dengan dokumen sumbernya.

Apakah file diunggah ke suatu tempat selama proses pemecahan?

Tidak. Pembagian terjadi secara lokal di browser Anda, dan baik file asli maupun kedua belahannya tidak pernah meninggalkan perangkat Anda. Dokumen rahasia sama amannya di sini seperti di meja Anda sendiri.

Apakah ini benar-benar gratis, tanpa jebakan?

Benar. Tanpa pendaftaran, tanpa watermark, tanpa batas halaman, dan tanpa kuota berapa banyak file yang Anda belah. Alat ini memakai daya proses perangkat Anda, jadi tidak ada tagihan server yang perlu dibebankan kepada Anda.

Sebesar apa PDF yang bisa saya belah dua?

Tidak ada batas atas yang kami tetapkan. Karena browser Anda yang bekerja, file sangat besar hanya dibatasi memori perangkat Anda — dokumen seribu halaman terbelah lancar di kebanyakan komputer modern, meski ponsel lawas mungkin butuh waktu lebih lama.

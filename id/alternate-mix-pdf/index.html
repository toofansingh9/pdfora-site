Selang-seling & Gabung

Gabungkan dua file PDF dengan menyelang-nyeling halamannya — solusi ideal untuk menyatukan hasil pindaian halaman ganjil dan genap yang terpisah.

Pemindai satu sisi selalu menghadirkan masalah klasik yang sama. Anda memindai setumpuk dokumen bolak-balik sekali untuk sisi depannya, lalu membalik tumpukan itu dan memindainya lagi untuk sisi belakangnya. Hasilnya, Anda kini punya dua file PDF: satu berisi seluruh halaman ganjil, satu lagi berisi seluruh halaman genap. Alat Alternate & Mix dari PDFora menganyam kembali keduanya, mengambil halaman 1 dari file A, halaman 1 dari file B, halaman 2 dari A, halaman 2 dari B, dan seterusnya, sampai dokumen kembali terbaca sesuai urutan aslinya.

Proses penyelangan halaman ini berjalan sepenuhnya di browser Anda. Kedua file PDF tidak diunggah ke mana pun, sehingga rekening koran hasil pindaian, rekam medis, maupun perjanjian yang sudah ditandatangani disusun ulang di komputer Anda sendiri dan tidak di tempat lain. Alat ini gratis, tidak meminta alamat email, tidak membubuhkan watermark apa pun pada hasilnya, dan membebaskan Anda menggabungkan sebanyak apa pun pasangan file yang Anda butuhkan hari itu.

Alternatif lainnya adalah menyusun ulang halaman satu per satu secara manual, dan untuk hasil pindaian setebal 60 halaman itu berarti 30 kali gerakan seret-dan-lepas yang harus dilakukan dengan sangat teliti, dengan peluang salah yang besar di setiap langkahnya. Penggabungan selang-seling menyelesaikan pekerjaan itu dalam sekali jalan, setiap kali, tanpa risiko salah hitung.

Cara menyelang-nyeling dan menggabungkan dua file PDF secara online

  1. Buka alat Alternate & Mix di situs getpdfora.com. Kedua berkas akan diproses secara lokal di dalam browser Anda.
  2. Tambahkan file PDF pertama, biasanya berisi halaman ganjil atau sisi depan dari tumpukan dokumen yang Anda pindai.
  3. Tambahkan file PDF kedua, biasanya berisi halaman genap atau sisi belakang dokumen tersebut.
  4. Periksa urutannya: file hasil gabungan selalu dimulai dari halaman 1 dokumen pertama, jadi tempatkan lembar yang seharusnya membuka dokumen pada slot nomor satu.
  5. Klik Mix. Alat ini akan menyelipkan halaman kedua file secara bergantian menjadi satu file PDF utuh.
  6. Tinjau dulu hasilnya untuk memastikan urutan halamannya sudah terbaca dengan benar, lalu unduh berkasnya.

When to use this tool

  • Menyusun ulang halaman hasil pindaian dokumen bolak-balik yang dipindai dengan pemindai kantor satu sisi, kasus penggabungan ganjil-genap yang paling klasik.
  • Membangun kembali kontrak dua sisi yang sudah ditandatangani setelah sisi depan dan sisi belakangnya dipindai dalam dua proses terpisah.
  • Menyelang-nyeling dokumen terjemahan dengan dokumen aslinya sehingga setiap halaman berbahasa Inggris langsung diikuti oleh padanannya dalam bahasa Spanyol untuk perbandingan berdampingan.
  • Menggabungkan halaman soal dengan halaman jawabannya sehingga naskah ujian terbaca berurutan: soal, pembahasan, soal, pembahasan.
  • Menyatukan hasil pindaian sisi depan dan sisi belakang arsip kartu indeks menjadi satu file tunggal yang mudah ditelusuri.
  • Memulihkan berkas pendaftaran pasien dua sisi dari klinik yang terpecah menjadi dua bagian karena keterbatasan mesin pemindainya.

Tips for the best results

  • Banyak pemindai satu sisi merekam tumpukan yang dibalik dalam urutan terbalik, sehingga file halaman genap bisa jadi tersusun mundur. Balik dulu urutan halamannya, baru lakukan penggabungan.
  • Lakukan pemeriksaan cepat sebelum menggabungkan: kedua file idealnya punya jumlah halaman yang sama, atau berselisih tepat satu halaman jika lembar terakhir kosong di bagian belakangnya.
  • Setelah diunduh, bacalah empat halaman pertamanya. Jika urutannya 1, 2, 3, 4 berarti penggabungan sudah benar; jika tidak, tukar file mana yang ditempatkan lebih dulu lalu jalankan ulang prosesnya.
  • Hapus dulu halaman belakang yang kosong dari hasil pindaian halaman genap, kalau tidak halaman kosong akan menyelip di antara setiap pasang halaman yang berisi tulisan.
  • Beri nama berkas pindaian Anda seperti laporan-ganjil.pdf dan laporan-genap.pdf sejak awal proses pemindaian agar Anda tidak perlu menebak-nebak mana bagian yang mana.

Pertanyaan yang sering diajukan

Apa arti alternate and mix dalam konteks PDF?

Ini adalah penggabungan yang menyelipkan halaman secara bergantian, bukan menyambungkannya di belakang: halaman 1 dokumen A, lalu halaman 1 dokumen B, kemudian halaman 2 dokumen A, dan seterusnya. Penggabungan biasa akan menempatkan seluruh isi dokumen A di depan seluruh isi dokumen B, dan urutan seperti itu jelas salah untuk menyusun halaman hasil pindaian.

Mengapa halaman ganjil dan genap hasil pindaian saya berada di file terpisah?

Pemindai satu sisi hanya sanggup membaca satu permukaan dalam sekali proses, sehingga dokumen bolak-balik harus dipindai dua kali, sekali untuk masing-masing sisi. Setiap proses pemindaian menghasilkan file PDF-nya sendiri, dan alat alternate mix hadir justru untuk merekatkan kembali kedua bagian tersebut.

File hasil gabungan saya terbaca 1, 3, 2, 5, 4. Apa yang salah?

Hampir bisa dipastikan file kedua Anda terpindai dalam urutan terbalik, yang biasa terjadi ketika tumpukan yang sudah dibalik masuk ke mesin dengan lembar terakhir lebih dulu. Baliklah urutan halaman pada file genap tersebut, lalu jalankan kembali proses penggabungannya.

Apakah dokumen saya tetap terjaga kerahasiaannya?

Ya. Kedua file PDF dibaca dan digabungkan secara lokal di browser Anda, dan tidak ada data apa pun yang dikirimkan ke server mana pun. Tutup tab-nya dan tidak akan ada salinan yang tersisa di mana pun kecuali file yang sudah Anda unduh sendiri.

Apakah kedua file PDF harus punya jumlah halaman yang persis sama?

Jumlahnya sebaiknya sama, atau berselisih satu halaman jika sisi belakang lembar terakhir memang kosong. Selisih yang lebih besar dari itu biasanya menandakan pemindai melewatkan satu lembar atau menarik dua lembar sekaligus, jadi sebaiknya pindai ulang sebelum Anda menggabungkannya.

Apakah ada biaya atau watermark pada hasilnya?

Tidak untuk keduanya. Alat ini gratis, tidak memerlukan pendaftaran, tidak menambahkan apa pun pada halaman Anda, dan tidak ada batasan berapa banyak dokumen yang boleh Anda susun.

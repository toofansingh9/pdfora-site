Selang-seling & Gabung

Susun halaman dari dua PDF atau lebih secara bergantian — halaman 1 dari tiap file, lalu halaman 2 dari tiap file, dan seterusnya — untuk menyatukan kembali dokumen yang dipindai dalam dua kali proses.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.
1

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Pilih opsi Anda — semuanya berlangsung di browser Anda.

3

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

Pernah memindai skripsi atau kontrak bolak-balik di tempat fotokopi, lalu pulang dengan dua file: satu berisi semua halaman ganjil, satu lagi semua halaman genap? Itu kejadian biasa kalau mesinnya hanya membaca satu sisi kertas. Masalahnya, kedua file itu tidak bisa sekadar digabung — hasilnya halaman depan semua di awal, halaman belakang semua di akhir, dan tidak ada yang bisa membacanya urut. Yang dibutuhkan adalah susunan berganti-ganti: depan 1, belakang 1, depan 2, belakang 2. Persis itulah yang dikerjakan Selang-seling & Gabung.

Cara kerjanya mudah ditebak, tetapi detailnya penting. Alat ini mengikuti urutan file di daftar, lalu mengambil halaman pertama dari tiap file secara bergiliran, kemudian halaman kedua dari tiap file, dan begitu seterusnya: A1, B1, A2, B2. Kalau ada tiga file, polanya menjadi A1, B1, C1, A2, B2, C2. File yang halamannya lebih sedikit akan habis lebih dulu, dan sisa halaman dari file lain tetap dilanjutkan di belakangnya — tidak ada halaman yang dibuang. Semua halaman disalin apa adanya memakai pdf-lib, tanpa dirender ulang, dan hasilnya tersimpan dengan nama alternated.pdf.

Satu hal yang harus Anda urus sendiri: urutan di dalam masing-masing file. Alat ini tidak pernah membalik urutan halaman. Padahal cara paling umum memindai sisi belakang adalah membalik seluruh tumpukan, sehingga halaman belakang keluar dari lembar terakhir ke lembar pertama. Kalau file Anda seperti itu, rapikan dulu urutannya sebelum diselang-seling — contoh di bawah menunjukkan trik yang paling cepat.

Cara menyelang-nyeling halaman dua PDF

  1. Buka Selang-seling & Gabung, lalu tambahkan minimal dua PDF — biasanya file halaman depan dan file halaman belakang.
  2. Seret barisnya sampai file yang halamannya harus muncul lebih dulu berada di posisi teratas. Untuk pindaian bolak-balik, itu adalah file halaman depan.
  3. Pastikan file halaman belakang sudah berurutan normal. Kalau dipindai dengan cara membalik tumpukan, balik dulu urutannya (lihat contoh).
  4. Klik Selang-seling & gabungkan. Alat ini mengambil halaman 1 dari tiap file sesuai urutan daftar, lalu halaman 2 dari tiap file, sampai semua halaman terpakai.
  5. Unduh alternated.pdf dan cek beberapa pasangan halaman — terutama dua pasangan pertama dan dua terakhir — sebelum kertas aslinya dibuang.

Kapan menggunakan alat ini

  • Menyatukan kembali skripsi, tesis, atau laporan PKL bolak-balik yang dipindai dua kali di tempat fotokopi dengan mesin satu sisi.
  • Merapikan berkas PPDB, formulir pendaftaran, atau kontrak kerja bolak-balik yang dipindai oleh staf tata usaha dengan pemindai sederhana.
  • Menyusun modul dwibahasa untuk kursus atau beasiswa, sehingga tiap halaman bahasa Indonesia langsung diikuti versi bahasa Inggrisnya.
  • Membuat bank soal: halaman soal dari satu file, halaman pembahasan dari file lain, berselang-seling supaya gampang dipelajari.
  • Menyisipkan lembar catatan kosong setelah setiap slide materi pelatihan, cukup dengan file kedua yang berisi halaman bergaris.
  • Memasangkan pindaian surat atau dokumen lama dengan ketikan transkripsinya untuk arsip keluarga, yayasan, atau penelitian.

Yang perlu diketahui sebelum mulai

  • Urutan file di daftar menentukan siapa yang muncul duluan di setiap pasangan. Kalau barisnya ditukar, hasilnya menjadi belakang 1, depan 1, belakang 2, depan 2.
  • Jumlah halaman tiap file tidak harus sama. Kalau A punya 10 halaman dan B 7 halaman, hasilnya A1, B1 sampai A7, B7, lalu A8, A9, A10. Jumlah halaman yang berbeda biasanya pertanda ada lembar yang terlewat atau terpindai dua kali.
  • Alat ini tidak pernah membalik urutan halaman. File halaman belakang yang dipindai dengan membalik tumpukan harus diurutkan ulang dulu; kalau tidak, belakang 1 akan bersanding dengan halaman depan terakhir.
  • Orientasi halaman dibiarkan apa adanya. Kalau halaman belakang terpindai terbalik, hasilnya juga terbalik; perbaiki dengan Putar PDF, baik pada file halaman belakang maupun pada hasil akhirnya.
  • Lebih dari dua file boleh dipakai dan akan diambil bergiliran sesuai urutan daftar — berguna untuk dokumen tiga bahasa atau set soal, jawaban, dan catatan.
  • Seperti alat lain yang menyalin halaman ke dokumen baru, bookmark tidak ikut terbawa dan tautan internal antarhalaman bisa tidak berfungsi lagi.

Tips untuk hasil terbaik

  • Hitung jumlah halaman tiap file sebelum menyelang-nyeling. Untuk pindaian bolak-balik, jumlahnya harus sama; kalau tidak, cari lembar yang hilang sekarang juga.
  • Beri nama file depan.pdf dan belakang.pdf. Kedengarannya sepele, tetapi langkah seret-untuk-mengurutkan jadi tidak membingungkan.
  • Kalau ada lembar asli yang sisi belakangnya kosong, biarkan halaman kosong itu tetap ada di pindaian belakang. Menghapusnya akan menggeser semua pasangan setelahnya; hapus halaman kosong dari file jadinya saja.
  • Untuk pasangan dwibahasa, ingat bahwa halaman hasil pindaian tetap berupa gambar setelah digabung; kalau Anda butuh isi teksnya, jalankan OCR PDF pada file hasil selang-seling agar bisa dicari, atau ambil teksnya sebagai file .txt.
  • Periksa juga bagian tengah hasilnya, jangan hanya awalnya: satu lembar yang salah masuk di tengah jalan akan menggeser semua pasangan sesudahnya.

Contoh nyata: formulir PPDB bolak-balik yang pindaian belakangnya terbalik

Staf tata usaha sebuah SMP di Semarang harus mengarsipkan 20 lembar formulir pendaftaran bolak-balik, dan pemindai di ruang TU hanya membaca satu sisi. Pindaian pertama menghasilkan depan.pdf berisi 20 halaman yang urut. Untuk sisi belakang, ia membalik tumpukan begitu saja dan memasukkannya lagi, sehingga belakang.pdf justru dimulai dari sisi belakang lembar ke-20 dan berakhir di sisi belakang lembar pertama.

Kalau dua file itu langsung diselang-seling, formulir siswa pertama akan dipasangkan dengan halaman belakang siswa ke-20. Jadi belakang.pdf dibuka dulu di Ekstrak Halaman, dan di kolom halamannya diketik 20, 19, 18, dan seterusnya sampai 1. Karena Ekstrak Halaman mengikuti urutan yang Anda ketik, file unduhannya adalah halaman belakang dalam urutan normal. Setelah itu depan.pdf dan file belakang yang sudah dibalik dimasukkan ke Selang-seling & Gabung dengan file depan di baris teratas, dan alternated.pdf setebal 40 halaman keluar dalam urutan depan 1, belakang 1, depan 2, belakang 2.

Kalau sisi belakangnya ikut terbalik atas-bawah — biasa terjadi pada pengumpan kertas tertentu — putar dulu file belakang yang sudah dibalik itu 180 derajat dengan Putar PDF, atau putar halaman genap pada file hasilnya dengan mengetik 2, 4, 6, dan seterusnya sampai 40.

Pemecahan masalah

Depan 1 berpasangan dengan halaman belakang terakhir
Urutan file halaman belakang Anda terbalik. Balik dulu urutannya, misalnya dengan Ekstrak Halaman sambil mengetik nomor halaman dari yang terbesar ke terkecil, lalu selang-seling lagi.
Pasangan awalnya benar, tetapi kacau di tengah
Ada satu lembar yang terlewat atau masuk dua kali di salah satu pindaian. Bandingkan jumlah halamannya, temukan celahnya, lalu pindai ulang atau hapus duplikatnya sebelum diselang-seling.
Hasilnya diawali halaman belakang
File halaman belakang berada di posisi teratas daftar. Seret file halaman depan ke atasnya, lalu jalankan lagi.
Setiap halaman kedua terbalik
Halaman belakang terpindai dalam posisi terbalik. Putar file belakang 180 derajat dengan Putar PDF, atau putar halaman bernomor genap pada hasilnya.
Muncul pesan "Tambahkan minimal dua PDF."
Selang-seling & Gabung butuh dua file atau lebih. Untuk mengubah urutan halaman di dalam satu file, gunakan Atur Halaman.
Halaman-halaman terakhir semuanya dari satu file
File itu punya halaman lebih banyak daripada yang lain; sisa halamannya ditambahkan di akhir setelah file yang lebih pendek habis. Cek apakah ada halaman yang hilang dari file yang lebih pendek.

Pertanyaan yang sering diajukan

Bedanya apa dengan Gabungkan PDF biasa?

Gabungkan PDF menempelkan file secara utuh, satu setelah yang lain. Selang-seling & Gabung mengambil halamannya bergantian: halaman 1 dari tiap file, lalu halaman 2 dari tiap file, dan seterusnya sampai habis.

Apakah urutan file belakang bisa dibalik otomatis?

Tidak bisa. Halaman selalu dipakai sesuai urutan yang ada di filenya. Balik dulu urutannya, misalnya lewat Ekstrak Halaman dengan mengetik nomor halaman dari yang terbesar ke yang terkecil.

Kalau jumlah halaman kedua file tidak sama, bagaimana?

Penyelangan berjalan sampai file yang lebih pendek habis, lalu sisa halaman dari file yang lebih panjang ditempelkan di belakang sesuai urutan. Tidak ada halaman yang hilang.

Boleh lebih dari dua file?

Boleh. Di setiap posisi halaman, alat ini mengambil satu halaman dari tiap file mengikuti urutan daftar, sehingga tiga file menghasilkan A1, B1, C1, A2, B2, C2.

Apakah kualitas pindaian ikut turun?

Tidak. Halaman hanya disalin ke dokumen baru, bukan dirender ulang, jadi teks dan gambarnya sama persis dengan file asal.

File saya diunggah ke server atau tidak?

Tidak. Penyelangan dikerjakan pdf-lib di dalam tab browser Anda, dan alternated.pdf langsung dibuat di perangkat Anda sendiri.

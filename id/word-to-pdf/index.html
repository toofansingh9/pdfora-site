Word ke PDF

Ubah file DOC atau DOCX menjadi PDF lewat server konversi, sehingga tata letaknya terkunci dan dokumen tampil sama di perangkat siapa pun.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.
1

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Pilih opsi Anda — semuanya berlangsung di browser Anda.

3

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

File Word adalah sekumpulan instruksi, bukan halaman jadi. Di mana baris terpotong, di halaman mana sebuah judul jatuh, dan seberapa lebar kolom tabel, semuanya dihitung ulang oleh program yang membukanya, dengan font apa pun yang ada di komputer itu. Itulah sebabnya CV yang tampak rapi di laptop Anda bisa sampai ke penerima dengan judul yang tertinggal sendirian di bawah halaman satu. PDF menyimpan halaman yang sudah jadi, dan karena itulah portal lowongan kerja, pengadilan, dan percetakan meminta PDF.

Berbeda dengan kebanyakan alat PDFora, alat ini tidak berjalan di browser Anda. Mengubah DOCX menjadi halaman yang tersusun rapi membutuhkan mesin pengolah kata yang lengkap, jadi file Anda diunggah ke layanan konversi CloudConvert melalui relay PDFora, dikonversi di sana, lalu PDF hasilnya diunduh kembali ke perangkat Anda. Transfer dienkripsi dan file dihapus dari layanan tersebut setelah selesai; jika sebuah dokumen sama sekali tidak boleh keluar dari komputer Anda, gunakan Save as PDF di Word atau LibreOffice.

Alat ini mengonversi satu file setiap kali dan menerima .doc maupun .docx. Tidak ada pengaturan: PDF mengikuti ukuran kertas, margin, header, dan footer yang ditentukan di dokumen. Hasilnya dinamai sesuai file asli, jadi Proposal.docx kembali sebagai Proposal.pdf. Karena tata letaknya dihitung di mesin lain, kualitas hasilnya terutama bergantung pada cara dokumen itu dibuat, dan bagian-bagian di bawah menjelaskan apa yang bertahan dan apa yang perlu dicek.

Cara mengubah Word ke PDF

  1. Simpan dan tutup dulu dokumen di Word, agar file di disk berisi suntingan terakhir Anda dan tracked changes yang memang ingin diterima.
  2. Buka Word to PDF dan pilih file .docx atau .doc. Hanya satu file yang dikonversi per proses.
  3. Klik Konversi. Baris status akan bergerak dari Menyiapkan, Mengunggah, ke Mengonversi; kebanyakan dokumen selesai dalam waktu jauh di bawah satu menit.
  4. Unduh PDF begitu muncul. Namanya sama dengan dokumen Anda, dengan ekstensi .pdf.
  5. Buka file itu dan bandingkan pemisah halaman, tabel, serta font yang tidak umum dengan aslinya sebelum dikirim.

Kapan menggunakan alat ini

  • Invoice dan penawaran harga pekerja lepas yang ditulis dengan template Word, dikirim sebagai PDF agar klien tidak sengaja mengubah totalnya.
  • CV dan surat lamaran kerja untuk portal yang hanya menerima PDF, atau ketika Anda ingin tata letaknya tetap persis seperti yang dirancang.
  • Skripsi dan tugas kuliah yang dikumpulkan ke sistem kampus yang mewajibkan PDF.
  • Kontrak dan surat yang disiapkan di Word dan perlu dicetak, ditandatangani, atau diarsipkan dalam bentuk tetap.
  • Mengonversi dokumen di HP atau di komputer bersama, misalnya di warnet atau tempat fotokopi, yang tidak terpasang Office.
  • Mengubah file .doc lama dari sistem lawas menjadi sesuatu yang bisa dibuka di perangkat apa pun.

Yang perlu diketahui sebelum mulai

  • Font adalah penyebab perbedaan yang paling umum. Server hanya bisa memakai font yang dimilikinya atau font yang disematkan di DOCX. Font khusus atau berbayar yang terpasang di komputer Anda tetapi tidak disematkan akan diganti dengan font serupa, yang bisa menggeser pemotongan baris dan jumlah halaman. Di Word Anda bisa mengaktifkan Embed fonts in the file di Options > Save sebelum mengonversi.
  • Tracked changes dan komentar bisa ikut muncul di PDF jika masih ada di dokumen. Terima atau tolak semua perubahan dan hapus komentar lebih dulu jika penerima harus melihat salinan yang bersih.
  • Judul biasanya baru menjadi kerangka yang bisa diklik jika memakai style Heading bawaan Word; teks yang sekadar ditebalkan dan diperbesar tetap hanya teks biasa.
  • Tautan ke situs web biasanya tetap bisa diklik. Field seperti daftar isi atau rujukan halaman dikonversi sesuai kondisi terakhir saat diperbarui, jadi tekan F9 di Word sebelum menyimpan jika Anda mengedit dokumen sesudahnya.
  • PDF hasil konversi tidak bisa diisi. Content control, drop-down, dan kotak centang menjadi teks tetap. Gunakan Create Forms pada PDF jika Anda membutuhkan kolom isian.
  • Dokumen yang sangat panjang atau berisi banyak gambar besar butuh waktu lebih lama. Alat ini menunggu server sekitar tiga menit; jika belum selesai, alat ini melaporkan waktu habis (time-out).

Tips untuk hasil terbaik

  • Gunakan style bawaan Word untuk judul dan daftar. Hasil konversinya lebih bisa ditebak daripada format manual, dan Anda mendapat kerangka navigasi.
  • Pakai font umum (Calibri, Arial, Times New Roman, Cambria) untuk dokumen yang akan dikonversi di mesin lain, atau sematkan font Anda.
  • Kompres gambar besar di Word (Picture Format > Compress Pictures) sebelum konversi jika PDF-nya harus masuk batas unggahan.
  • Cek ukuran kertas di Layout > Size. Dokumen yang diatur ke US Letter akan menghasilkan halaman Letter meskipun Anda tinggal di negara yang memakai A4.
  • Simpan file .docx-nya. PDF untuk dibaca dan dicetak; pengeditan berikutnya jauh lebih mudah di file aslinya.

Contoh nyata: proposal pekerja lepas dengan font merek

Seorang penerjemah lepas di Medan menulis proposal tiga halaman di Word dengan font display berbayar untuk judul dan Calibri untuk isinya. Setelah dikonversi di sini, PDF-nya kembali menjadi empat halaman: server tidak punya font display tersebut, menggantinya dengan font yang lebih lebar, dan tabel harga terdorong ke halaman tersendiri.

Perbaikannya hanya dua menit. Di Word ia membuka File > Options > Save, mencentang Embed fonts in the file (dengan Do not embed common system fonts tetap aktif agar ukuran file tidak membengkak), menyimpan, lalu mengonversi lagi. Kali ini judul memakai font yang benar dan dokumen kembali tiga halaman, dengan tabel di bawah judulnya. Seandainya lisensi font melarang penyematan, alternatifnya adalah memakai font yang tersedia luas untuk judul.

Sebelum mengirim, ia menerima semua tracked changes dan menghapus komentar di margin dari rekan kerjanya yang berbunyi “harganya kemurahan?”, yang kalau tidak dihapus akan ikut tercetak di margin PDF dan terbaca oleh klien.

Pemecahan masalah

PDF punya lebih banyak halaman daripada dokumen Word
Ada font yang diganti, atau ukuran kertasnya berbeda. Sematkan font di dokumen atau ganti ke font umum, dan pastikan Layout > Size sesuai harapan.
Komentar atau tracked changes merah muncul di PDF
Semua itu masih bagian dari dokumen. Di Word, gunakan Review > Accept All Changes dan hapus semua komentar, simpan, lalu konversi lagi.
Alat menyebut konversi gagal
File mungkin rusak, dikunci kata sandi, atau sebenarnya bukan file Word meskipun ekstensinya begitu. Buka di Word, hapus kata sandinya jika ada, gunakan Save As untuk membuat .docx baru, lalu coba salinan itu.
Konversi kehabisan waktu
Dokumennya sangat besar, biasanya karena gambar beresolusi tinggi. Kompres gambar di Word atau pecah dokumen menjadi beberapa bagian, konversi masing-masing, lalu satukan dengan Merge PDF.
Daftar isi menampilkan nomor halaman yang salah
Field-nya tidak diperbarui sebelum disimpan. Klik kanan daftar isi di Word, pilih Update Field > Update entire table, simpan, lalu konversi lagi.
Tidak terjadi apa-apa setelah Mengunggah
Penyebab umumnya adalah koneksi yang terputus atau ekstensi browser yang memblokir unggahan. Muat ulang halaman, nonaktifkan pemblokir konten untuk situs ini, dan coba lagi dengan koneksi yang stabil.

Pertanyaan yang sering diajukan

Apakah file Word saya diunggah?

Ya. Konversi ini membutuhkan mesin di sisi server, jadi file dikirim secara terenkripsi ke layanan konversi dan dihapus setelah diproses. Untuk dokumen yang harus tetap offline, gunakan Save as PDF di Word.

Apakah mendukung .doc dan .docx?

Ya, keduanya diterima. Format .doc yang lebih lama lebih mungkin menunjukkan sedikit perbedaan tata letak, jadi periksa hasilnya dengan teliti.

Apakah hyperlink masih berfungsi di PDF?

Tautan web biasanya tetap bisa diklik. Rujukan silang internal bergantung pada cara pembuatannya di Word dan sebaiknya diuji.

Bisakah saya mengonversi beberapa file Word sekaligus?

Tidak, satu file per konversi. Konversi setiap dokumen, lalu gabungkan PDF-nya dengan Merge PDF jika Anda butuh satu file.

Kenapa PDF memakai font yang berbeda dari dokumen saya?

Font tersebut tidak tersedia di server konversi dan tidak disematkan di DOCX, jadi dipakai font yang mirip. Sematkan font di Word lalu konversi lagi.

Bisakah PDF diubah kembali menjadi file Word yang bisa diedit?

PDF to Word bisa menghasilkan DOCX, tetapi alat itu menyusun ulang tata letaknya dan jarang sama persis dengan aslinya. Menyimpan .docx asli selalu lebih baik.

Ganti Nama PDF

Beri PDF nama file yang rapi dan konsisten, lalu unduh sebagai salinan baru.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.
1

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Pilih opsi Anda — semuanya berlangsung di browser Anda.

3

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

Coba buka folder Download di HP Anda dan hitung berapa file yang bernama seperti “IMG-20261022-WA0007.pdf” atau “Dokumen (3) final FIX banget.pdf”. Nama seperti itu tidak memberi tahu penerima apa pun, gampang tenggelam di antara file lain, dan kadang langsung ditolak portal unggahan yang tidak menerima spasi, tanda kurung, atau nama yang terlalu panjang. Di laptop sendiri, mengganti nama file hanya butuh dua detik. Di HP, di komputer kantor yang aksesnya dibatasi, atau saat semua pekerjaan dilakukan lewat browser, urusan kecil ini bisa jadi merepotkan.

Ganti Nama PDF hanya mengerjakan satu hal: Anda mengetik nama baru, dan PDF dikembalikan dengan nama itu. Karakter yang ditolak Windows, macOS, dan sebagian besar portal (backslash, garis miring, titik dua, tanda bintang, tanda tanya, tanda kutip, kurung sudut, dan garis tegak) dibuang otomatis, dan .pdf ditambahkan jika Anda lupa menuliskannya. Jika kotaknya dibiarkan kosong, nama asli dipertahankan; jika setelah dibersihkan tidak ada karakter yang tersisa, file diberi nama document.pdf. Spasi di awal dan akhir juga dipangkas, jadi nama yang disalin dari email dengan spasi nyasar di ujungnya tidak berubah menjadi 'faktur .pdf'.

Satu detail teknis yang perlu Anda tahu: alat ini tidak sekadar mengganti label unduhan. PDF dibuka dengan pdf-lib lalu disimpan ulang. Halaman dan isinya tetap sama, tetapi filenya ditulis ulang, sehingga ukurannya bisa sedikit berbeda dan metadata internal ikut diperbarui, yaitu tanggal modifikasi diisi dan pdf-lib tercatat sebagai producer. Judul dokumen yang tampil di bilah judul aplikasi pembaca adalah kolom tersendiri di dalam PDF, dan kolom itu tidak berubah karena penggantian nama.

Cara mengganti nama file PDF

  1. Buka Ganti Nama PDF dan tambahkan PDF yang ingin diganti namanya.
  2. Ketik nama baru di kotak Nama file baru, misalnya 2026-10-faktur-0142. Akhiran .pdf boleh ditulis, boleh juga tidak.
  3. Klik Ganti nama & unduh. File dimuat lalu disimpan ulang dengan nama baru.
  4. Simpan hasil unduhan di tempat yang Anda perlukan; browser mungkin menanyakan lokasi atau langsung menaruhnya di folder Download.
  5. Periksa namanya di pengelola file dan hapus salinan lama jika sudah tidak diperlukan.

Kapan menggunakan alat ini

  • Pelamar kerja yang harus mengunggah CV, ijazah, dan transkrip ke portal lowongan dengan format nama tertentu dan tanpa karakter khusus.
  • Mahasiswa yang mengumpulkan tugas ke portal kampus yang mewajibkan pola seperti NIM-nama-tugas.
  • Pekerja lepas yang mengirim invoice dengan pola tetap seperti klien-tahun-bulan-nomor, supaya kedua pihak mudah mencarinya. Nama yang bisa ditebak juga membantu bagian keuangan klien mencocokkan file dengan nomor PO tanpa membukanya.
  • Memberi nama yang jelas pada rekening koran, bukti transfer, atau e-tiket hasil unduhan sebelum diteruskan lewat WhatsApp.
  • Mengganti nama file di HP atau tablet yang pengelola filenya kurang praktis.
  • Membuang titik dua, garis miring, atau tanda kutip yang membuat file gagal diunggah atau disinkronkan ke sistem lain.

Yang perlu diketahui sebelum mulai

  • Karakter terlarang \ / : * ? " < > | dihapus, bukan diganti, sehingga nama seperti Laporan: Q3 menjadi Laporan Q3. Spasi tetap dipertahankan; ganti sendiri dengan tanda hubung jika portal tidak menerima spasi.
  • Ekstensi .pdf ditambahkan otomatis jika tidak ada. Nama yang sudah berakhiran .pdf (huruf besar maupun kecil) dibiarkan seperti yang diketik.
  • PDF disimpan ulang oleh pdf-lib, yang memperbarui kolom tanggal modifikasi dan producer di metadata file. Judul, penulis, dan isi halaman tetap seperti semula.
  • PDF yang ditandatangani secara digital sebaiknya tidak diganti namanya dengan alat ini. Penyimpanan ulang menulis ulang file, sehingga tanda tangannya menjadi tidak valid walaupun isi yang terlihat sama persis. Ganti nama file bertanda tangan di pengelola file saja.
  • PDF yang dikunci kata sandi juga tidak cocok. Alat ini mungkin bisa memuatnya, tetapi salinan yang disimpan kemungkinan besar tidak akan terbuka dengan benar. Ganti nama file seperti itu di pengelola file.
  • Satu file per proses. Untuk banyak file sekaligus, ulangi langkahnya untuk setiap file atau gunakan fitur ganti nama massal di sistem operasi Anda. Jika file yang sama diganti namanya dua kali, setiap proses menghasilkan unduhan baru; alat ini tidak pernah mengubah file di perangkat Anda. File asli tetap di tempatnya dengan nama lamanya sampai Anda menghapusnya.

Tips untuk hasil terbaik

  • Awali nama dengan tanggal berurutan tahun-bulan-hari (2026-10-22) agar file otomatis tersusun kronologis di folder mana pun.
  • Pakai tanda hubung, bukan spasi; tanda hubung aman di sistem email, URL, dan command line tanpa berubah menjadi %20.
  • Usahakan nama tidak lebih dari sekitar 60 karakter. Sebagian portal dan sistem lama memotong nama yang lebih panjang.
  • Letakkan kata terpenting di depan: nama klien, lalu jenis dokumen, lalu nomor. Bagian itulah yang pertama dilihat orang saat membaca daftar file.
  • Jika judul yang tampil di aplikasi pembaca PDF juga perlu diubah, edit properti dokumen di aplikasi yang membuat file tersebut; penggantian nama tidak menyentuhnya. Portal unggahan kadang punya aturan penamaan sendiri, misalnya harus huruf kecil semua atau tanpa spasi. Alat ini tidak memaksakan aturan itu, jadi ketik nama sesuai format yang diminta portal.

Contoh nyata: lulusan baru menyiapkan berkas lamaran kerja

Andi baru lulus dari sebuah kampus di Makassar dan sedang melamar ke beberapa perusahaan lewat portal lowongan kerja. Berkasnya berasal dari macam-macam sumber: CV hasil ekspor dari HP bernama “CV terbaru (2).pdf”, ijazah dan KTP hasil aplikasi pemindai bernama “Dokumen 22 Okt 2026 08:15.pdf”, serta transkrip nilai yang ia unduh dari sistem akademik kampus. Portal pertama menolak unggahan ijazah karena titik dua di namanya, dan HRD sebuah perusahaan lain meminta semua berkas diberi nama dengan format nama-jenis dokumen.

Ia mengganti nama berkasnya satu per satu langsung di HP: andi-pratama-cv, andi-pratama-ijazah, andi-pratama-ktp. Saat ia menempelkan sebagian nama lama yang masih mengandung titik dua, alat ini membuangnya, lalu menambahkan .pdf di akhir. Unggahan berikutnya diterima, dan di sisi HRD keempat file itu tersusun rapi dengan nama yang langsung bisa dikenali.

Transkrip nilai ia perlakukan berbeda. File dari kampus itu memakai tanda tangan digital, dan menyimpan ulang PDF akan membuat tanda tangan tersebut tidak valid, jadi ia mengganti namanya lewat aplikasi pengelola file di HP, tanpa membuka isinya. Polanya sederhana: PDF biasa bisa diganti namanya dengan Ganti Nama PDF, sedangkan file bertanda tangan digital atau berkata sandi sebaiknya diganti namanya di tingkat sistem file.

Pemecahan masalah

File hasil unduhan masih bernama lama
Browser mungkin menambahkan angka karena sudah ada file dengan nama yang sama, atau diatur untuk mengganti nama file duplikat. Periksa folder Download dan hapus salinan lama.
Beberapa karakter hilang dari nama baru
Karakter yang tidak diizinkan dalam nama file di sistem umum (\ / : * ? " < > |) dihapus otomatis. Gunakan tanda hubung atau garis bawah sebagai gantinya.
Ukuran file sedikit berubah
PDF disimpan ulang oleh pdf-lib, yang bisa menyimpan objek dengan cara berbeda. Halamannya sama; hanya struktur internalnya yang ditulis ulang.
Tanda tangan digital PDF saya sekarang tidak valid
Penyimpanan ulang mengubah byte yang dilindungi tanda tangan. Gunakan file asli yang ditandatangani dan ganti namanya di pengelola file.
File yang sudah diganti namanya tidak mau terbuka
File sumbernya kemungkinan terenkripsi atau rusak. Ganti nama file asli di pengelola file, atau perbaiki dulu dengan Perbaiki PDF.
Aplikasi pembaca masih menampilkan judul lama di bagian atas
Aplikasi pembaca menampilkan judul yang tersimpan di dalam PDF, bukan nama file. Kolom itu tidak berubah karena penggantian nama.
Nama baru terpotong di HP saya
Sebagian browser di ponsel memendekkan nama unduhan yang sangat panjang. Buat nama yang singkat dan taruh bagian pengenalnya di depan.

Pertanyaan yang sering diajukan

Isi PDF-nya berubah tidak kalau namanya diganti?

Tidak. Halamannya identik. Karena file disimpan ulang, metadata tanggal modifikasi dan producer ikut diperbarui.

Karakter apa saja yang tidak boleh dipakai di nama file?

Backslash, garis miring, titik dua, tanda bintang, tanda tanya, tanda kutip ganda, kurung sudut, dan garis tegak. Semuanya akan dibuang dari nama.

Harus mengetik .pdf di belakang nama?

Tidak perlu. Akhiran itu ditambahkan otomatis jika Anda tidak menuliskannya.

Bisa mengganti nama banyak PDF sekaligus?

Tidak, satu file per proses. Untuk jumlah besar, fitur ganti nama massal di sistem operasi Anda lebih cepat.

Benarkah ganti nama bisa merusak tanda tangan digital?

Ya, karena filenya ditulis ulang. Ganti nama PDF bertanda tangan digital di pengelola file saja.

Berbayar atau perlu daftar?

Tidak keduanya. Mengganti nama gratis dan tidak memerlukan akun.

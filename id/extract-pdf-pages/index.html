Ekstrak Halaman

Pilih halaman yang persis Anda butuhkan dan simpan sebagai PDF baru.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.
1

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Pilih opsi Anda — semuanya berlangsung di browser Anda.

3

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

Kadang Anda tidak butuh seluruh dokumen — Anda hanya butuh tiga halaman dari bagian tengahnya. Alat extract PDFora memungkinkan Anda menarik halaman-halaman pilihan dari PDF mana pun dan menyimpannya sebagai file baru. Ketik sesuatu seperti 1-3, 5, 8 dan Anda mendapat persis halaman itu, dalam urutan itu, sebagai satu PDF baru. File aslinya tetap utuh.

Ekstraksi berlangsung sepenuhnya di perangkat Anda. PDF dibaca dan disusun ulang oleh browser Anda, bukan oleh server jarak jauh, jadi apa pun yang Anda ekstrak — perjanjian bertanda tangan, laporan pajak, dokumen penilaian aset — tidak pernah dikirim ke mana pun. Kalau selama ini Anda ragu memakai alat PDF online untuk file sensitif, inilah jalan keluarnya: bagian "online"-nya hanya halaman webnya, bukan data Anda.

Tidak ada pendaftaran, tidak ada biaya, dan tidak ada watermark pada hasilnya. Ekstrak dua halaman atau dua ratus, dari satu dokumen atau dua puluh, kapan pun Anda butuh. Tidak ada yang dihitung sebagai kuota.

Cara mengekstrak halaman dari PDF secara online

  1. Buka alat Extract Pages di getpdfora.com lewat browser modern mana pun.
  2. Tambahkan PDF Anda dengan mengklik pemilih file atau menyeret file ke halaman.
  3. Ketik halaman yang Anda inginkan di kotak seleksi — halaman tunggal, rentang, atau campuran keduanya, seperti 1-3, 5, 8.
  4. Periksa ulang nomornya terhadap dokumen aslinya; nomor halaman yang tercetak tidak selalu cocok dengan hitungan halaman PDF.
  5. Klik Extract dan browser Anda menyusun halaman terpilih menjadi PDF baru.
  6. Unduh hasilnya. File asli Anda tetap persis seperti semula.

When to use this tool

  • Menarik hanya halaman tanda tangan dari kontrak panjang untuk dikirim agar ditandatangani balik.
  • Mengekstrak ringkasan eksekutif dari laporan 60 halaman untuk orang-orang yang tidak akan membaca sisanya.
  • Menyimpan hanya makalah Anda sendiri dari satu edisi jurnal atau PDF prosiding konferensi.
  • Mengambil halaman bukti yang relevan dari berkas hukum alih-alih meneruskan seluruh bundelnya.
  • Mengangkat satu resep, lembar kerja, atau pola dari e-book berbayar untuk dicetak.
  • Mengambil halaman spesifikasi dari manual produk untuk dilampirkan ke tiket dukungan teknis.

Tips for the best results

  • Campur rentang dan halaman tunggal sesuka Anda — 2, 5-9, 14 bekerja persis seperti yang Anda harapkan.
  • Halaman muncul di PDF baru sesuai urutan yang Anda tulis, jadi tuliskan seleksinya dalam urutan yang Anda inginkan.
  • Buka dulu PDF di penampil dan catat posisi halaman menurut penampil itu, karena halaman sampul bisa menggeser semuanya satu angka.
  • Kalau yang ingin Anda lakukan justru menghapus beberapa halaman dan bukan menyimpan beberapa, alat Delete Pages adalah kebalikannya yang lebih cepat.
  • Ekstrak dulu sebelum menggabungkan: menarik halaman yang bagus dari beberapa dokumen lebih dulu menghasilkan file gabungan yang jauh lebih rapi.

Pertanyaan yang sering diajukan

Bisakah saya mengekstrak halaman yang tidak berurutan dari PDF?

Bisa. Pisahkan dengan koma — 1, 4, 9-11 menarik halaman satu, empat, sembilan, sepuluh, dan sebelas ke dalam satu PDF baru. Kombinasi apa pun antara halaman tunggal dan rentang diperbolehkan.

Apakah mengekstrak halaman mengubah PDF asli saya?

Tidak. Alat ini membaca file Anda lalu membangun PDF yang benar-benar baru dari halaman terpilih. Dokumen sumber di perangkat Anda tidak pernah dimodifikasi.

Apakah cukup aman untuk dokumen pajak atau hukum?

Ya. Ekstraksi berjalan secara lokal di browser Anda dan file tidak pernah diunggah, jadi tidak ada siapa pun — termasuk PDFora — yang bisa melihat isinya. Sama pribadinya seperti membuka file di komputer Anda sendiri.

Apakah halaman hasil ekstraksi mempertahankan formatnya?

Ya. Halaman disalin apa adanya, sehingga font, gambar, tautan, dan tata letak terbawa persis. Tidak ada yang diratakan atau dikompres ulang.

Bisakah saya mengekstrak halaman dari PDF yang dilindungi kata sandi?

Tidak selama file itu masih terkunci — browser tidak bisa membaca halaman file terenkripsi. Hapus dulu kata sandinya (Anda harus mengetahuinya), lalu ekstrak seperti biasa.

Apakah ada batas berapa banyak halaman yang bisa saya ekstrak?

Tidak ada batas dan tidak ada biaya. Karena pekerjaannya terjadi di perangkat Anda, ekstraksi raksasa dari file yang sangat besar hanya bergantung pada memori yang tersedia, tapi pekerjaan biasa selesai dalam hitungan detik.

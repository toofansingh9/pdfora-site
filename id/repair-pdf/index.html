Perbaiki PDF

Baca ulang PDF yang bikin program lain macet, lalu tulis kembali dengan struktur file yang bersih dan dibangun ulang.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.
1

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Pilih opsi Anda — semuanya berlangsung di browser Anda.

3

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

File yang terbuka normal di laptop Anda, tetapi ditolak portal dengan pesan "file tidak valid", hampir selalu bermasalah di strukturnya, bukan di isinya. PDF bukanlah satu aliran isi yang utuh. Di dalamnya ada kumpulan objek bernomor dan sebuah tabel referensi silang yang memberi tahu aplikasi pembaca di mana setiap objek dimulai. Jika unduhan terputus di tengah jalan, sebuah program menulis tabel itu dengan buruk, atau file diedit bergantian oleh beberapa aplikasi, tabel tersebut bisa menunjuk ke tempat yang salah. Sebagian aplikasi pembaca diam-diam tetap bisa menanganinya, yang lain menampilkan halaman kosong, dan portal unggahan biasanya langsung menolak.

Perbaiki PDF dibuat untuk kasus seperti itu: struktur berantakan, isi masih ada. File dimuat dengan pustaka pdf-lib, yang membaca objek-objek yang bisa ditemukannya dan menyusun strukturnya sendiri tanpa memercayai tabel yang rusak, lalu menyimpan salinan baru. Salinan itu mendapat tabel referensi silang yang ditulis ulang, dan setiap objek ditulis satu per satu, tidak dikemas dalam object stream terkompresi. Tata letak yang lebih kuno ini justru lebih mudah diterima aplikasi pembaca yang ketat atau sudah tua. Isi halaman disalin, bukan dirender ulang, jadi teks, font, dan gambar tetap persis seperti semula.

Batasnya juga perlu jelas sejak awal. Ini pembangunan ulang struktur, bukan pemulihan data. Jika ada byte yang memang hilang, misalnya separuh akhir dari unduhan yang terputus, tidak ada bahan untuk menyusun ulang halaman-halaman itu, dan tidak ada alat yang bisa mengarangnya. Untuk kasus seperti itu, jalan keluarnya adalah mengambil salinan baru dari sumbernya.

Cara memperbaiki file PDF yang rusak

  1. Buka Perbaiki PDF dan tambahkan file yang bermasalah. Hanya satu file yang diproses setiap kali.
  2. Klik Perbaiki & bangun ulang. File diurai lalu disimpan lagi; untuk kebanyakan dokumen, prosesnya hanya satu atau dua detik.
  3. Jika alat ini menampilkan error, berarti file sama sekali tidak bisa diurai; lihat bagian pemecahan masalah di bawah.
  4. Unduh hasilnya, yang disimpan dengan nama asli ditambah -repaired, misalnya kontrak-repaired.pdf.
  5. Buka salinan hasil perbaikan di aplikasi pembaca atau portal yang tadinya gagal, lalu periksa setiap halaman untuk memastikan semuanya berisi.

Kapan menggunakan alat ini

  • Portal unggah skripsi, tugas akhir, atau berkas lamaran menolak PDF sebagai file tidak valid, padahal file itu terbuka normal di laptop Anda.
  • Rekening koran atau laporan dari aplikasi akuntansi versi lama yang terbuka di satu aplikasi pembaca, tetapi tampil kosong di aplikasi lain.
  • PDF yang sudah berkali-kali diedit dengan berbagai program menjadi lambat atau memunculkan peringatan rusak saat dibuka.
  • Menyiapkan file untuk percetakan atau sistem pelaporan elektronik yang validatornya lebih ketat daripada aplikasi pembaca biasa.
  • Merapikan dokumen sebelum digabung atau dipisah, ketika alat-alat tersebut menolak memuat file aslinya.
  • Mengecek dengan cepat apakah struktur file masih terbaca sebelum meminta pengirim mengekspor ulang.

Yang perlu diketahui sebelum mulai

  • Perbaiki PDF membangun ulang struktur, bukan mengembalikan isi yang hilang. File yang terpotong paling banter hanya kembali dengan halaman-halaman yang lengkap.
  • Hasilnya ditulis tanpa object stream terkompresi. Ini membuatnya lebih kompatibel, tetapi sering sedikit lebih besar dari file masukan, kadang 10 sampai 30 persen pada file yang banyak memakai object stream.
  • Halaman disalin apa adanya. Jika sebuah halaman tampak salah karena content stream-nya sendiri rusak, halaman itu bisa tetap tampak salah setelah dibangun ulang.
  • File dibuka dengan pemeriksaan enkripsi dimatikan. PDF yang dikunci kata sandi mungkin bisa dimuat, tetapi isinya tetap terenkripsi dan salinan yang disimpan kemungkinan tidak tampil dengan benar; hapus dulu kata sandinya dengan Buka Kunci PDF atau di sumbernya.
  • Formulir, bookmark, dan anotasi yang bisa dibaca pdf-lib ikut terbawa ke file baru, karena yang disimpan adalah seluruh dokumen, bukan hanya halamannya.
  • Prosesnya berjalan di browser Anda, jadi file yang tidak ingin Anda kirim ke layanan pemulihan online pun bisa dicoba di sini.

Tips untuk hasil terbaik

  • Selalu simpan file asli di samping salinan hasil perbaikan sampai Anda selesai memeriksa hasilnya halaman demi halaman.
  • Bandingkan jumlah halaman file hasil perbaikan dengan yang Anda harapkan. Jumlah yang lebih sedikit adalah tanda paling jelas bahwa file sumbernya terpotong.
  • Jika portal masih menolak file hasil perbaikan, coba cetak ke PDF dari aplikasi pembaca Anda; cara itu merender ulang setiap halaman dan memperbaiki masalah di dalam isi halaman yang tidak bisa diatasi lewat pembangunan ulang struktur.
  • Untuk file yang diterima lewat email atau hasil unduhan, mintalah kiriman ulang sebelum menghabiskan waktu untuk memperbaikinya. Salinan yang bersih selalu lebih baik daripada hasil perbaikan apa pun.
  • Setelah berhasil diperbaiki, jalankan Kompres PDF jika ukurannya membesar dan isinya kebanyakan hasil scan.

Contoh nyata: skripsi yang ditolak repositori kampus

Nadia, mahasiswi tingkat akhir di Padang, menggabungkan skripsinya dari beberapa sumber: bab 1 sampai 5 hasil ekspor Word, lembar pengesahan yang dipindai dengan aplikasi di HP, dan lampiran kuesioner yang ia ubah ke PDF lewat aplikasi lain. File gabungan setebal 86 halaman itu terbuka biasa di laptopnya, tetapi formulir unggah repositori kampus menolaknya sebagai file tidak valid, dan Pisahkan PDF pun gagal memuatnya ketika ia ingin memisahkan lampiran.

Setelah diproses dengan Perbaiki PDF, file bisa dimuat dan mendapat tabel referensi silang baru. Repositori menerima salinan bernama skripsi-repaired.pdf pada percobaan berikutnya, dan Pisahkan PDF kini bisa membacanya. Ukurannya naik dari sekitar 2,4 MB menjadi sekitar 2,9 MB karena object stream tidak lagi dipakai, masih jauh dari masalah untuk unggahan biasa.

Sebelum menekan tombol kirim, Nadia membuka hasilnya dan menghitung halaman: 86, sama dengan daftar isinya, dan lembar pengesahan yang dipindai tampil utuh. Seandainya jumlahnya kurang, itu tanda file gabungannya memang tidak lengkap, dan satu-satunya solusi adalah menggabungkan ulang dari file per bab yang masih ia simpan.

Pemecahan masalah

Alat menampilkan error dan tidak menghasilkan apa-apa
File sama sekali tidak bisa diurai, biasanya karena sebenarnya bukan PDF (misalnya halaman error HTML yang tersimpan dengan nama .pdf) atau terpotong parah. Buka di editor teks: PDF asli selalu diawali %PDF. Jika tidak, ambil salinan baru.
Beberapa halaman hilang di file hasil perbaikan
Halaman-halaman itu memang tidak ada dalam bentuk yang bisa dibaca di file sumber, biasanya karena unduhan terputus. Unduh atau ekspor ulang dokumennya.
Halaman masih kosong atau berantakan
Isi halamannya sendiri yang rusak, dan itu tidak disentuh oleh pembangunan ulang struktur. Coba cetak file asli ke PDF dari aplikasi pembaca yang menampilkannya paling baik, atau minta pengirim mengekspor ulang.
File hasil perbaikan lebih besar dari aslinya
Alat ini menulis objek satu per satu, bukan dalam object stream terkompresi. Itu disengaja demi kompatibilitas; kompres hasilnya jika ukuran penting.
Salinan hasil perbaikan menampilkan isi yang tidak terbaca
File sumbernya kemungkinan terenkripsi. Enkripsi diabaikan saat file dimuat, jadi isinya tetap teracak. Hapus kata sandi di program pembuat file atau dengan Buka Kunci PDF jika Anda tahu kata sandinya, lalu perbaiki salinan itu.
Portal masih menolak file
Validator mungkin mempersoalkan hal lain selain struktur, misalnya ukuran file, ukuran halaman, atau font yang disematkan. Cek persyaratan yang dicantumkan portal, lalu ubah ukuran halaman, kompres, atau cetak ke PDF sesuai kebutuhan.

Pertanyaan yang sering diajukan

Sebenarnya apa yang diubah Perbaiki PDF di file saya?

Alat ini membaca ulang objek-objek dokumen, menulis tabel referensi silang baru, dan menyimpan setiap objek secara terpisah tanpa object stream. Isi halaman disalin tanpa perubahan.

PDF yang tidak bisa dibuka di aplikasi mana pun, masih bisa diselamatkan?

Kadang bisa. Jika objeknya utuh dan hanya strukturnya yang rusak, hasilnya biasanya berhasil. Jika datanya memang hilang atau file itu sebenarnya bukan PDF, tidak ada alat perbaikan yang bisa mengembalikannya.

Kualitasnya turun tidak setelah diperbaiki?

Tidak. Tidak ada yang dirender ulang atau dikompres ulang, jadi teks dan gambar tampil persis seperti sebelumnya.

Kenapa ukuran file malah bertambah?

Hasilnya tidak memakai object stream terkompresi. File jadi sedikit lebih besar, tetapi bisa dibaca aplikasi yang lebih lama dan lebih ketat.

Apakah kata sandi PDF ikut hilang setelah diperbaiki?

Tidak. Alat ini tidak mendekripsi apa pun, dan file terenkripsi biasanya tidak akan tampil dengan benar setelah dibangun ulang. Gunakan Buka Kunci PDF untuk menghapus kata sandi yang Anda ketahui.

Bisa memperbaiki beberapa file sekaligus?

Tidak, satu file per proses. Untuk dokumen biasa prosesnya cepat, jadi file berikutnya bisa langsung menyusul.

Perbaiki PDF

Baca ulang PDF yang bikin program lain macet, lalu tulis kembali dengan struktur file yang bersih dan dibangun ulang.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.
1

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Pilih opsi Anda — semuanya berlangsung di browser Anda.

3

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

PDF bukan satu aliran isi yang utuh; PDF adalah kumpulan objek bernomor ditambah tabel referensi silang yang memberi tahu aplikasi pembaca di mana setiap objek dimulai. Ketika unduhan terputus di tengah jalan, sebuah program menulis tabel itu dengan buruk, atau file diedit bergantian oleh beberapa aplikasi, tabel tersebut bisa menunjuk ke tempat yang salah. Sebagian aplikasi pembaca diam-diam masih bisa menanganinya, yang lain menampilkan halaman kosong, dan portal unggahan sering menolak file dengan pesan error yang tidak jelas. Repair PDF dibuat untuk kasus di tengah-tengah itu: file yang strukturnya berantakan tetapi isinya masih ada.

Yang dilakukan alat ini cukup spesifik. File dimuat dengan pustaka pdf-lib, yang membaca objek-objek yang bisa ditemukannya dan menyusun strukturnya sendiri alih-alih memercayai tabel yang rusak, lalu menyimpan salinan baru. File baru mendapat tabel referensi silang yang ditulis ulang, dan setiap objek ditulis satu per satu, bukan dikemas dalam object stream terkompresi. Tata letak lama ini lebih mudah diterima oleh aplikasi pembaca yang ketat atau sudah tua. Isi halaman disalin, bukan dirender ulang, sehingga teks, font, dan gambar tetap persis seperti semula.

Perlu dikatakan terus terang di mana batasnya. Ini pembangunan ulang struktur, bukan pemulihan data. Jika ada byte yang memang hilang, misalnya separuh akhir dari unduhan yang terputus, tidak ada bahan untuk membangun ulang halaman-halaman itu, dan tidak ada alat yang bisa mengarangnya. Dalam kasus seperti itu, solusi yang benar adalah mengambil salinan baru dari sumbernya.

Cara memperbaiki file PDF yang rusak

  1. Buka Repair PDF dan tambahkan file yang bermasalah. Hanya satu file yang diproses setiap kali.
  2. Klik Perbaiki & bangun ulang. File diurai lalu disimpan lagi; untuk kebanyakan dokumen, prosesnya hanya satu atau dua detik.
  3. Jika alat ini menampilkan error, berarti file sama sekali tidak bisa diurai; lihat bagian pemecahan masalah di bawah.
  4. Unduh hasilnya, yang disimpan dengan nama asli ditambah -repaired, misalnya kontrak-repaired.pdf.
  5. Buka salinan hasil perbaikan di aplikasi pembaca atau portal yang tadinya gagal, lalu periksa setiap halaman untuk memastikan semuanya berisi.

Kapan menggunakan alat ini

  • Portal unggah skripsi kampus menolak PDF sebagai file tidak valid, padahal file itu terbuka normal di laptop Anda sendiri.
  • File hasil ekspor dari scanner lama atau aplikasi akuntansi versi lama terbuka di satu aplikasi pembaca, tetapi menampilkan halaman kosong di aplikasi lain.
  • PDF yang sudah berkali-kali diedit dengan berbagai program menjadi lambat atau memunculkan peringatan rusak saat dibuka.
  • Menyiapkan file untuk percetakan atau sistem pelaporan elektronik yang validatornya lebih ketat daripada aplikasi pembaca biasa.
  • Merapikan dokumen sebelum digabung atau dipisah, ketika alat-alat tersebut menolak memuat file aslinya.
  • Mengecek dengan cepat apakah struktur file masih bisa dibaca sebelum meminta pengirim mengekspor ulang.

Yang perlu diketahui sebelum mulai

  • Repair membangun ulang struktur, bukan mengembalikan isi yang hilang. File yang terpotong paling banter hanya kembali dengan halaman-halaman yang lengkap.
  • Hasilnya ditulis tanpa object stream terkompresi. Ini membuatnya lebih kompatibel, tetapi sering sedikit lebih besar dari file masukan, kadang 10 sampai 30 persen pada file yang banyak memakai object stream.
  • Halaman disalin apa adanya. Jika sebuah halaman tampak salah karena content stream-nya sendiri rusak, halaman itu bisa tetap tampak salah setelah dibangun ulang.
  • File dibuka dengan pemeriksaan enkripsi dimatikan. PDF yang dikunci kata sandi mungkin bisa dimuat, tetapi isinya tetap terenkripsi dan salinan yang disimpan kemungkinan tidak tampil dengan benar; hapus dulu kata sandinya di sumber.
  • Formulir, bookmark, dan anotasi yang bisa dibaca pdf-lib ikut terbawa ke file baru, karena yang disimpan adalah seluruh dokumen, bukan hanya halamannya.
  • Prosesnya berjalan di browser Anda, jadi file yang tidak ingin Anda kirim ke layanan pemulihan online pun bisa dicoba di sini.

Tips untuk hasil terbaik

  • Selalu simpan file asli di samping salinan hasil perbaikan sampai Anda selesai memeriksa hasilnya halaman demi halaman.
  • Bandingkan jumlah halaman file hasil perbaikan dengan yang Anda harapkan. Jumlah yang lebih sedikit adalah tanda paling jelas bahwa file sumbernya terpotong.
  • Jika portal masih menolak file hasil perbaikan, coba cetak ke PDF dari aplikasi pembaca Anda; cara itu merender ulang setiap halaman dan memperbaiki masalah di dalam isi halaman yang tidak bisa diatasi lewat pembangunan ulang struktur.
  • Untuk file yang diterima lewat email atau hasil unduhan, mintalah kiriman ulang sebelum menghabiskan waktu untuk memperbaikinya. Salinan yang bersih selalu lebih baik daripada hasil perbaikan apa pun.
  • Setelah berhasil diperbaiki, jalankan Compress PDF jika ukurannya membesar dan isinya kebanyakan hasil scan.

Contoh nyata: kumpulan invoice seorang penerjemah lepas

Seorang penerjemah lepas di Surabaya mengekspor dua belas invoice bulanan dari aplikasi penagihan lama menjadi satu PDF untuk keperluan laporan pajak tahunan. File itu terbuka di penampil PDF bawaan browser, tetapi formulir unggah kantor pajak menolaknya sebagai dokumen tidak valid, dan Merge PDF juga menolak menggabungkannya dengan berkas lain.

Setelah diproses dengan Repair PDF, file berhasil dimuat, mendapat tabel referensi silang yang baru, dan disimpan tanpa object stream. Formulir unggah menerima salinan hasil perbaikan, dan alat penggabung kini bisa membacanya. Ukuran file naik dari 410 KB menjadi sekitar 460 KB, harga dari tata letak yang lebih konservatif, dan di sini sama sekali tidak masalah.

Sebelum mengirim, ia menghitung halamannya: dua belas invoice, dua belas halaman. Seandainya jumlahnya sembilan, berarti ekspor aslinya tidak lengkap, dan satu-satunya solusi nyata adalah mengekspor ulang dari aplikasi penagihan.

Pemecahan masalah

Alat menampilkan error dan tidak menghasilkan apa-apa
File sama sekali tidak bisa diurai, biasanya karena sebenarnya bukan PDF (misalnya halaman error HTML yang tersimpan dengan nama .pdf) atau terpotong parah. Buka di editor teks: PDF asli selalu diawali %PDF. Jika tidak, ambil salinan baru.
Beberapa halaman hilang di file hasil perbaikan
Halaman-halaman itu memang tidak ada dalam bentuk yang bisa dibaca di file sumber, biasanya karena unduhan terputus. Unduh atau ekspor ulang dokumennya.
Halaman masih kosong atau berantakan
Isi halamannya sendiri yang rusak, dan itu tidak disentuh oleh pembangunan ulang struktur. Coba cetak file asli ke PDF dari aplikasi pembaca yang menampilkannya paling baik, atau minta pengirim mengekspor ulang.
File hasil perbaikan lebih besar dari aslinya
Alat ini menulis objek satu per satu, bukan dalam object stream terkompresi. Itu disengaja demi kompatibilitas; kompres hasilnya jika ukuran penting.
Salinan hasil perbaikan menampilkan isi yang tidak terbaca
File sumbernya kemungkinan terenkripsi. Enkripsi diabaikan saat file dimuat, jadi isinya tetap teracak. Hapus kata sandi di program pembuat file, lalu perbaiki salinan itu.
Portal masih menolak file
Validator mungkin mempersoalkan hal lain selain struktur, misalnya ukuran file, ukuran halaman, atau font yang disematkan. Cek persyaratan yang dicantumkan portal, lalu ubah ukuran halaman, kompres, atau cetak ke PDF sesuai kebutuhan.

Pertanyaan yang sering diajukan

Apa sebenarnya yang diubah oleh Repair PDF?

Alat ini membaca ulang objek-objek dokumen, menulis tabel referensi silang baru, dan menyimpan setiap objek secara terpisah tanpa object stream. Isi halaman disalin tanpa perubahan.

Bisakah alat ini menyelamatkan PDF yang tidak bisa dibuka di mana pun?

Kadang-kadang. Jika objeknya utuh dan hanya strukturnya yang rusak, bisa. Jika datanya memang hilang atau file itu bukan PDF, tidak ada alat perbaikan yang bisa mengembalikannya.

Apakah kualitas file turun setelah diperbaiki?

Tidak. Tidak ada yang dirender ulang atau dikompres ulang, jadi teks dan gambar tampil persis seperti sebelumnya.

Kenapa ukuran filenya bertambah?

Hasilnya tidak memakai object stream terkompresi, sehingga file sedikit lebih besar tetapi bisa dibaca oleh aplikasi yang lebih lama dan lebih ketat.

Apakah perbaikan menghapus kata sandi?

Tidak. Alat ini tidak mendekripsi apa pun, dan file terenkripsi biasanya tidak akan tampil dengan benar setelah dibangun ulang.

Bisakah saya memperbaiki beberapa file sekaligus?

Alat ini menerima satu file per proses. Proses file satu per satu; untuk dokumen biasa prosesnya cepat.

Pisahkan PDF

Pecah PDF berdasarkan rentang halaman, setiap N halaman, atau menjadi satu file per halaman.

Simpan file yang selesai secara instan. Tanpa watermark.

PDF setebal 90 halaman jarang berguna sebagai satu file 90 halaman. Biasanya Anda hanya butuh bab dua untuk rekan kerja, halaman 40 sampai 55 untuk klien, atau setiap halaman sebagai file terpisah untuk arsip. Alat split PDFora memecah satu PDF menjadi beberapa file, dan menyediakan tiga cara: setiap halaman jadi PDF tersendiri, rentang halaman khusus yang Anda ketik, atau potongan otomatis setiap N halaman.

Semuanya berjalan di dalam browser Anda. File yang Anda pecah dibuka dan diproses secara lokal di perangkat Anda — tidak pernah dikirim ke server, tidak disimpan di penyimpanan cloud, dan tidak melewati antrean siapa pun. Untuk berkas hukum, dokumen HRD, atau apa pun yang enggan Anda unggah ke komputer orang asing, perbedaan itu jauh lebih penting daripada fitur lain mana pun.

Alat ini gratis, tanpa pendaftaran, dan tanpa watermark. Ketika hasil pemecahan menghasilkan banyak file, semuanya dikemas dalam satu ZIP sehingga Anda mendapat satu unduhan rapi alih-alih selusin. Pakai sekali atau seratus kali; tidak ada penghitung yang berjalan.

Cara memecah PDF secara online

  1. Buka alat Split PDF di getpdfora.com lalu pilih atau seret PDF Anda ke halaman.
  2. Pilih mode pemecahan: setiap halaman jadi PDF terpisah, rentang khusus, atau setiap N halaman.
  3. Untuk rentang khusus, ketik sebagaimana Anda menyebutnya — misalnya 1-3, 4-6 akan menghasilkan dua file.
  4. Untuk potongan tetap, masukkan jumlah halaman per file, misalnya 10, dan alat ini membagi dokumen secara otomatis.
  5. Klik Split. Browser Anda memotong PDF secara lokal dalam hitungan detik.
  6. Unduh file ZIP berisi semua PDF hasilnya lalu ekstrak di mana saja.

When to use this tool

  • Memecah setumpuk pindaian formulir bertanda tangan menjadi satu PDF per formulir sebelum diarsipkan.
  • Memecah buku teks atau bahan bacaan kuliah per bab agar mahasiswa hanya mengunduh bagian yang mereka butuhkan.
  • Membagi berkas rapat direksi yang tebal sehingga setiap divisi hanya menerima bagiannya sendiri.
  • Memotong ekspor rekening koran menjadi file bulanan untuk software pembukuan yang hanya menerima satu periode sekaligus.
  • Memisahkan prosiding konferensi menjadi makalah-makalah individual untuk keperluan sitasi dan berbagi.
  • Memotong laporan besar menjadi bagian 10 halaman agar lolos batas ukuran lampiran email.

Tips for the best results

  • Telusuri dulu PDF-nya dan catat nomor halaman tempat tiap bagian dimulai sebelum mengetik rentang — ini menghemat satu putaran kerja.
  • Rentang boleh tidak sama panjang: 1-3, 4-6, 7-20 benar-benar valid kalau panjang tiap bagian berbeda.
  • Pilih mode setiap N halaman ketika strukturnya teratur, seperti formulir berulang atau laporan berpanjang tetap.
  • Kalau Anda hanya butuh satu bagian dan bukan semuanya, alat Extract Pages lebih cepat daripada memecah seluruh dokumen.
  • Memecah dokumen pindaian yang sangat panjang memakan memori perangkat Anda, jadi beri waktu sejenak pada komputer lawas.

Pertanyaan yang sering diajukan

Bagaimana cara memecah PDF menjadi halaman terpisah?

Pilih mode yang menyimpan setiap halaman sebagai PDF tersendiri, lalu klik Split. Dokumen 30 halaman menjadi 30 file terpisah, dikirim sekaligus dalam satu unduhan ZIP.

Bisakah saya memecah berdasarkan rentang halaman khusus?

Bisa. Ketik rentang seperti 1-3, 4-6 dan setiap rentang menjadi PDF-nya sendiri. Anda boleh menentukan sebanyak apa pun rentang, dan panjangnya tidak harus sama.

Kenapa hasilnya terunduh sebagai file ZIP?

Pemecahan biasanya menghasilkan beberapa PDF sekaligus, dan ZIP menjaga semuanya dalam satu unduhan rapi alih-alih memicu belasan penyimpanan terpisah. Ekstrak saja, semua PDF ada di dalamnya, dinamai berurutan.

Apakah dokumen saya diunggah saat dipecah?

Tidak. PDFora memproses file secara lokal di browser Anda, jadi PDF tidak pernah meninggalkan perangkat. Itu membuatnya aman untuk materi rahasia seperti kontrak dan berkas kepegawaian.

Apakah ada batas ukuran file untuk pemecahan?

Tidak ada batas yang kami tetapkan. Karena perangkat Anda sendiri yang memproses, file sangat besar bergantung pada memori yang tersedia — kebanyakan dokumen terpecah dalam hitungan detik, sedangkan pindaian raksasa mungkin butuh waktu lebih lama.

Apakah memecah PDF menurunkan kualitasnya?

Tidak. Halaman disalin ke file baru persis apa adanya, tanpa kompresi ulang. Teks tetap tajam dan dapat dicari, dan gambar mempertahankan resolusi aslinya.

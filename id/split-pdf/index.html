Pisahkan PDF

Pecah satu PDF menjadi beberapa PDF yang lebih kecil: satu file per halaman, potongan berukuran tetap, atau persis sesuai rentang halaman yang Anda ketik.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.
1

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Pilih opsi Anda — semuanya berlangsung di browser Anda.

3

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

Seberapa sering Anda mengirim PDF 40 halaman padahal penerimanya hanya butuh tiga? Bendahara cuma perlu lampiran kuitansi dari laporan kegiatan, pemilik kontrakan hanya ingin halaman tanda tangan dari surat perjanjian, dan scanner kantor menghasilkan satu file raksasa dari setumpuk surat yang tidak saling berhubungan. Memisahkan PDF mengubah satu dokumen panjang itu menjadi beberapa PDF mandiri yang masing-masing bisa diberi nama, dikirim, atau diarsipkan sendiri.

Pisahkan PDF di PDFora punya tiga mode. Setiap halaman menghasilkan satu PDF per halaman. Setiap N halaman memotong dokumen menjadi potongan sama besar (bawaannya 2 halaman per file; potongan terakhir cukup berisi sisa halamannya). Rentang khusus memungkinkan Anda mengetik kelompok seperti 1-3, 4-6, 7-10, dan setiap koma memulai file keluaran baru. Di ketiga mode, halaman disalin apa adanya dengan pdf-lib: teks tetap bisa diseleksi, resolusi gambar tidak berubah, dan tidak ada yang digambar ulang, sehingga setiap halaman di file hasil tercetak persis sama dengan halaman yang sama di file asli.

File hasilnya bernomor dan mengikuti nama file asli: kontrak.pdf menjadi kontrak-1.pdf, kontrak-2.pdf, dan seterusnya. Semuanya bisa diunduh sekaligus sebagai kontrak-split.zip, atau diklik satu per satu dari daftar. Penyalinan berlangsung di tab browser, jadi kecepatannya bergantung pada perangkat Anda, bukan pada antrean server.

Cara memisahkan PDF menjadi beberapa file

  1. Buka Pisahkan PDF dan tambahkan satu file. Alat ini memproses satu dokumen setiap kali.
  2. Pilih mode: Setiap halaman, Setiap N halaman, atau Rentang khusus.
  3. Untuk Setiap N halaman, isi jumlah halaman per potongan. Untuk Rentang khusus, ketik kelompok halaman yang dipisahkan koma, misalnya 1-2, 3, 4-9. Setiap kelompok menjadi satu file.
  4. Klik Pisahkan PDF dan tunggu bilah progres; satu file keluaran dibuat untuk setiap kelompok.
  5. Klik Unduh semua (.zip) atau unduh bagiannya satu per satu, lalu buka beberapa file untuk memastikan titik potongnya benar.

Kapan menggunakan alat ini

  • Laporan kegiatan RT, karang taruna, atau organisasi kampus: memisahkan lampiran kuitansi dari dokumentasi foto agar setiap pihak hanya menerima bagian yang dibutuhkan.
  • Sekolah: memecah hasil ekspor rapor atau sertifikat menjadi satu file per siswa sebelum dikirim ke orang tua lewat WhatsApp.
  • Bagian keuangan: memecah tumpukan faktur satu halaman hasil scan menjadi satu PDF per faktur untuk diunggah ke aplikasi pembukuan.
  • Urusan sewa: mengambil halaman tanda tangan atau satu lampiran dari surat perjanjian yang panjang untuk dikirim ke pemilik rumah.
  • Portal dengan batas halaman: sebagian sistem pendaftaran hanya menerima beberapa halaman per unggahan, sehingga potongan N halaman pas dengan aturannya.
  • Urusan cetak: mengirim hanya halaman berwarna dari sebuah laporan ke percetakan sebagai file tersendiri.

Yang perlu diketahui sebelum mulai

  • Di mode Rentang khusus, rentang seperti 4-6 berarti halaman 4, 5, dan 6. Salah satu ujungnya boleh dibiarkan terbuka: -5 berarti halaman 1 sampai 5, dan 8- berarti halaman 8 sampai halaman terakhir.
  • Nomor yang melewati akhir dokumen dipangkas, bukan ditolak. Mengetik 20-30 pada file 25 halaman menghasilkan halaman 20 sampai 25. Bagian yang sama sekali tidak berisi halaman valid dilewati, dan jika tidak ada yang valid tersisa, muncul pesan agar Anda memasukkan minimal satu rentang yang valid.
  • Rentang boleh tumpang-tindih. 1-5, 3-8 menghasilkan dua file yang sama-sama berisi halaman 3 sampai 5. Ini berguna jika setiap penerima perlu halaman sampul yang sama, tetapi juga mudah terjadi tanpa sengaja.
  • Setiap file keluaran hanya berisi halaman. Kerangka bookmark tidak disalin, tautan yang menuju halaman yang kini ada di file lain berhenti berfungsi, dan kolom formulir yang bisa diisi mungkin tidak bertahan. Tautan ke situs web di halaman tetap berfungsi.
  • Font dan gambar yang dipakai di beberapa halaman disimpan ulang di setiap bagian yang membutuhkannya, sehingga total ukuran semua bagian biasanya sedikit lebih besar dari file aslinya.
  • Daftar hasil menampilkan tombol unduh terpisah untuk maksimal 50 file. Memecah dokumen 300 halaman per halaman tetap bisa, tetapi gunakan unduhan zip untuk mendapatkan semuanya.

Tips untuk hasil terbaik

  • Catat rentangnya dari thumbnail halaman di aplikasi pembaca sebelum mulai; nomor halaman yang dipakai alat ini adalah posisi fisik di dalam file, bukan nomor yang tercetak di footer.
  • Jika Anda hanya butuh satu blok halaman, Ekstrak Halaman langsung memberi satu file, bukan zip berisi satu file.
  • Ganti nama bagian-bagiannya segera setelah zip diekstrak. kontrak-3.pdf tidak berarti apa-apa sebulan lagi; kontrak-lampiran-B.pdf jelas maksudnya.
  • Untuk tumpukan hasil scan yang panjang tiap dokumennya berbeda-beda, pisahkan berdasarkan teks atau bookmark, jangan menghitung halaman secara manual.
  • Simpan file aslinya. Pemisahan tidak bisa dibatalkan, tetapi Anda selalu bisa menggabungkan kembali bagian-bagiannya dengan Gabungkan PDF jika salah memotong.

Contoh: laporan panitia lomba Agustusan tingkat RT

Pak Arif, ketua panitia lomba tujuh belasan di RT-nya, menyusun laporan pertanggungjawaban dalam satu PDF setebal 24 halaman: sampul dan ringkasan di halaman 1 sampai 3, foto nota dan kuitansi di halaman 4 sampai 15, dokumentasi foto kegiatan di halaman 16 sampai 20, dan daftar donatur di halaman 21 sampai 24. Bendahara RW hanya meminta bagian keuangan, grup WhatsApp warga cukup diberi dokumentasi, dan file 24 halaman penuh foto terlalu berat untuk dikirim ke semua orang.

Ia memilih Rentang khusus dan mengetik 1-3, 4-15, 16-20, 21-. Keluar empat file, laporan-1.pdf sampai laporan-4.pdf, yang langsung ia ganti namanya menjadi ringkasan, kuitansi, dokumentasi, dan donatur. Sebelum mengetik rentang, ia sempat mengecek thumbnail di aplikasi pembaca, karena sampulnya tidak bernomor sehingga halaman yang tercetak "1" sebenarnya halaman fisik ke-2; alat ini memakai posisi fisik, jadi rentangnya ia tulis berdasarkan thumbnail, bukan nomor di footer. Bendahara RW menerima ringkasan dan kuitansi, warga menerima ringkasan dan dokumentasi, dan file asli tetap tersimpan utuh di laptopnya.

Pemecahan masalah

Muncul pesan 'Masukkan minimal satu rentang yang valid'
Tidak satu pun rentang cocok dengan halaman yang ada. Periksa salah ketik, misalnya 1–3 yang diketik dengan tanda pisah panjang dari pengolah kata, huruf, atau nomor halaman yang melebihi jumlah halaman dokumen. Gunakan tanda hubung biasa dan koma.
Bagian-bagiannya bergeser satu halaman
Alat ini menghitung halaman berdasarkan posisinya di file. Jika dokumen Anda punya sampul atau halaman depan tanpa nomor, halaman 1 yang tercetak bisa jadi halaman fisik ke-2. Sesuaikan rentangnya dengan selisih tersebut.
Saya mengetik rentang, tetapi hasilnya satu file besar
Kelompok hanya dipisahkan oleh koma. 1-3 4-6 yang ditulis dengan spasi dibaca sebagai satu rentang yang keliru. Tulis 1-3, 4-6.
Halaman hasil kosong atau alat error saat memuat
File sumbernya kemungkinan terenkripsi atau rusak. Hapus kata sandinya dengan Buka Kunci PDF atau di aplikasi pembuatnya, atau jalankan Perbaiki PDF dulu, lalu pisahkan salinan yang sudah bersih.
Bookmark dan tautan internal tidak berfungsi lagi
Pemisahan hanya menyalin isi halaman. Jika bagian-bagiannya perlu navigasi, tambahkan bookmark di masing-masing dengan Buat Bookmark; tautan internal yang menuju bagian lain tidak bisa dipertahankan.
Browser jadi lambat saat memproses file yang sangat besar
Setiap file keluaran dibangun di memori. Tutup tab lain, atau pisahkan dulu menjadi potongan besar, lalu pisahkan lagi potongan-potongan itu.

Pertanyaan yang sering diajukan

Kualitas halaman berubah tidak setelah dipisah?

Tidak. Halaman disalin objek demi objek, bukan dirender menjadi gambar, jadi teks, gambar vektor, dan foto identik dengan aslinya.

Nama file hasilnya nanti seperti apa?

Nama file asli ditambah nomor urut: laporan.pdf menghasilkan laporan-1.pdf, laporan-2.pdf, dan seterusnya, dikemas bersama dalam laporan-split.zip.

Bisa satu halaman masuk ke lebih dari satu file?

Bisa, di mode Rentang khusus. Rentang yang tumpang-tindih seperti 1-2, 1, 3-5 memasukkan halaman 1 ke dua file pertama.

Kalau jumlah halamannya tidak habis dibagi, potongan terakhir bagaimana?

Potongan terakhir berisi sisa halaman. Dokumen 10 halaman yang dipisah setiap 3 halaman menghasilkan file berisi 3, 3, 3, dan 1 halaman.

Bisa memisahkan beberapa PDF sekaligus?

Tidak, satu file per proses. Pisahkan setiap dokumen sendiri-sendiri, atau gabungkan dulu jika memang harus dipotong sebagai satu urutan.

Harus punya akun dulu?

Tidak. Tidak perlu daftar dan tidak ada batas jumlah pemisahan.

Pisahkan berdasarkan Bookmark

Buat satu PDF untuk setiap bookmark / entri outline tingkat teratas di dalam dokumen.

Simpan file yang selesai secara instan. Tanpa watermark.

PDF yang dibuat dengan rapi membawa daftar isinya sendiri: panel bookmark di sisi kiri pembaca Anda. Alat split by bookmarks PDFora memperlakukan entri-entri itu sebagai garis potong. Setiap bookmark tingkat teratas memulai file baru, dan setiap hasilnya dinamai sesuai judul bookmark-nya, jadi "Bab 3: Metodologi" benar-benar menjadi file dengan nama itu. Seluruh kumpulannya datang sebagai satu unduhan ZIP.

Tidak ada yang diunggah saat Anda memecah. Outline bookmark dibaca dan halaman dipisahkan secara lokal di browser Anda, yang menjaga berkas rapat direksi, dokumen hukum, dan naskah yang belum terbit tetap ada di perangkat Anda dari awal sampai akhir. Alat ini gratis, bekerja tanpa akun, tidak meninggalkan watermark, dan bisa memecah sebanyak apa pun dokumen yang Anda berikan.

Alternatifnya menyedihkan: buka panel bookmark, catat halaman awal setiap bab, jalankan pemecahan berdasarkan rentang halaman belasan kali, lalu ganti nama setiap hasilnya satu per satu. Pemecahan berdasarkan bookmark meringkas semua itu menjadi satu klik, lengkap dengan penamaan yang dikerjakan untuk Anda.

Cara memecah PDF berdasarkan bookmark secara online

  1. Buka alat Split by Bookmarks di getpdfora.com. Pemrosesan tetap lokal di browser Anda.
  2. Tambahkan PDF yang memuat outline bookmark, seperti laporan, manual, atau ebook.
  3. Alat ini membaca bookmark tingkat teratas; setiap bookmark menandai tempat sebuah file baru akan dimulai.
  4. Klik Split. Halaman dari satu bookmark sampai bookmark berikutnya dikumpulkan menjadi PDF tersendiri.
  5. Setiap file hasilnya otomatis dinamai sesuai judul bookmark-nya, jadi tidak perlu mengganti nama secara manual.
  6. Unduh arsip ZIP-nya lalu ekstrak untuk mendapatkan setiap bagian sebagai file terpisah dengan nama yang masuk akal.

When to use this tool

  • Memecah laporan tahunan setebal 300 halaman menjadi bagian-bagian sesuai bookmark supaya setiap kepala divisi hanya menerima babnya sendiri.
  • Memecah manual teknis menjadi PDF per modul untuk platform pembelajaran yang menginginkan satu file per pelajaran.
  • Memisahkan berkas rapat direksi menjadi butir-butir agenda tersendiri, masing-masing dinamai sesuai bookmark-nya, untuk dibagikan ke anggota komite.
  • Membagi berkas perkara menjadi bukti-bukti sesuai bookmark supaya setiap bukti bisa dirujuk dan dibagikan secara terpisah.
  • Mengubah naskah buku resep yang ber-bookmark menjadi satu file per bab untuk editor yang meninjau bagian berbeda-beda.
  • Mengeluarkan bab-bab dari buku panduan perusahaan supaya HRD bisa memperbarui satu bagian tanpa menyentuh sisanya.

Tips for the best results

  • Periksa panel bookmark di pembaca PDF Anda sebelum memecah; apa yang Anda lihat di tingkat teratas persis itulah tempat potongan akan jatuh.
  • Hanya bookmark tingkat teratas yang memicu pemecahan. Sub-bookmark yang bersarang tetap berada di dalam file induknya, dan itu biasanya sesuai dengan cara bab dan subbab semestinya dikelompokkan.
  • Kalau PDF Anda tidak punya bookmark, tambahkan dulu lewat editor PDF, atau gunakan pemecahan berdasarkan teks atau rentang halaman sebagai gantinya.
  • Usahakan judul bookmark bebas dari karakter seperti garis miring atau titik dua, karena judul itu akan menjadi nama file di dalam ZIP.
  • Dokumen panjang menghasilkan ZIP yang besar; tidak ada unggahan yang terlibat, tapi biarkan tab tetap terbuka sampai unduhannya selesai.

Pertanyaan yang sering diajukan

Apa sebenarnya bookmark PDF itu?

Bookmark, kadang disebut outline, adalah daftar isi yang bisa diklik dan ditampilkan di panel samping pada kebanyakan pembaca PDF. Penulis dan perangkat ekspor seperti Word atau InDesign menambahkannya untuk menandai bab dan bagian, dan alat ini memakai penanda yang sama sebagai titik pemecahan.

Bagaimana file hasilnya dinamai?

Setiap file mengambil judul bookmark tempat ia dimulai, jadi bookmark bernama "Lampiran B" menghasilkan file dengan nama itu. Karakter yang ilegal untuk nama file otomatis disesuaikan supaya semua file terekstrak dengan bersih dari ZIP.

PDF saya tidak punya bookmark. Bisakah saya tetap memakai alat ini?

Tidak secara langsung, karena outline itulah yang menentukan titik pemecahan. Anda bisa menambahkan bookmark dulu lewat editor PDF, atau gunakan alat split by text milik PDFora kalau ada kata kunci berulang yang menandai awal tiap bagian.

Kenapa hasilnya terunduh sebagai file ZIP?

Dokumen ber-bookmark sering terpecah menjadi sepuluh, dua puluh, atau lebih bagian, dan satu ZIP jauh lebih mudah diunduh daripada maraton klik per file. Ekstrak saja dan semua PDF bernama itu muncul dalam satu folder.

Apakah alat ini juga memecah pada bookmark bersarang?

Tidak, hanya entri tingkat teratas yang memulai file baru, dan semua yang bersarang di bawah sebuah bookmark ikut bersamanya. Itu menjaga subbab tetap berada di dalam babnya alih-alih memecah dokumen menjadi puluhan serpihan.

Apakah ini benar-benar gratis, dan apakah dokumen saya terjaga?

Ya untuk keduanya. Tidak ada pendaftaran, tidak ada watermark, dan tidak ada batas pemakaian, dan file diurai serta dipecah sepenuhnya di browser Anda, jadi ia tidak pernah dikirim ke server. Lama pemrosesan bergantung pada perangkat Anda dan ukuran dokumennya.

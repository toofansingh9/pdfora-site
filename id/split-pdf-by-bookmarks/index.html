Pisahkan berdasarkan Bookmark

Jadikan setiap bookmark tingkat teratas di PDF sebagai file tersendiri yang dinamai sesuai bookmark-nya, sehingga bab dan bagian langsung siap dibagikan.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.
1

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Pilih opsi Anda — semuanya berlangsung di browser Anda.

3

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

Kalau Anda membuka PDF panjang dan di sisi kiri aplikasi pembaca muncul daftar bab yang bisa diklik, dokumen itu sebenarnya sudah "tahu" di mana setiap bagiannya dimulai. Daftar itu disebut kerangka (outline) atau bookmark, dan biasanya ikut terbawa saat skripsi, buku panduan karyawan, modul kuliah, atau laporan tahunan diekspor dari pengolah kata. Pisahkan berdasarkan Bookmark memanfaatkan kerangka itu: dokumen dipotong di setiap bookmark tingkat teratas, sehingga Anda tidak perlu mencari nomor halaman atau mengetik rentang. Jika kerangkanya disusun dengan cermat, hasil pemisahan akan mengikuti struktur yang dimaksud penulisnya.

Untuk membaca kerangka dan menemukan halaman yang dituju setiap bookmark, alat ini memakai PDF.js. Bookmark kemudian diurutkan berdasarkan halaman, dan satu file dibuat untuk setiap bookmark, mulai dari halamannya sampai halaman sebelum bookmark berikutnya; bookmark terakhir berlanjut sampai akhir dokumen. Halaman disalin tanpa perubahan dengan pdf-lib, jadi teks tetap bisa dicari dan kualitas gambar tetap terjaga.

Kelebihan terbesarnya dibanding pemisahan bernomor ada pada nama file: setiap file dinamai sesuai bookmark-nya. File panduan.pdf dengan bookmark Pendahuluan, Keselamatan, dan Lampiran menghasilkan 'panduan - Pendahuluan.pdf', 'panduan - Keselamatan.pdf', dan 'panduan - Lampiran.pdf', dikemas dalam panduan-bookmarks.zip. Karakter yang ditolak sistem file, seperti / : * ? " < > |, dibuang, dan judul dipendekkan menjadi 40 karakter.

Cara memisahkan PDF berdasarkan bookmark

  1. Buka PDF di aplikasi pembaca yang biasa Anda pakai dan lihat panel bookmark atau outline; itulah yang akan dipakai alat ini.
  2. Buka Pisahkan berdasarkan Bookmark dan tambahkan filenya. Tidak ada opsi yang perlu diatur.
  3. Klik Pisahkan berdasarkan bookmark.
  4. Unduh zip-nya atau file satu per satu; setiap file dinamai sesuai bookmark-nya.
  5. Periksa file pertama: jika dokumen Anda punya halaman sebelum bookmark pertama, baca catatan tentang halaman sampul di bawah. Halaman sebelum bookmark pertama tidak ikut diekspor.

Kapan menggunakan alat ini

  • Asisten lab atau dosen yang membagikan modul praktikum atau diktat kuliah per bab, supaya mahasiswa tidak perlu mengunduh file ratusan halaman di HP.
  • Mahasiswa yang mengirim skripsi atau tesis per bab ke dosen pembimbing yang memeriksanya satu per satu. Setiap file bab tetap mempertahankan tata letak dan catatan kakinya.
  • Memecah buku panduan karyawan per bab agar setiap divisi hanya menerima kebijakan yang berlaku untuknya.
  • Mengambil bagian tertentu dari dokumen tender atau kontrak panjang yang disusun dengan bookmark per lampiran.
  • Membagi manual teknis menjadi bagian per produk untuk diterbitkan di halaman dukungan.
  • Memisahkan prosiding seminar atau konferensi menjadi makalah satuan, jika setiap makalah punya bookmark.

Yang perlu diketahui sebelum mulai

  • Hanya bookmark tingkat teratas yang dipakai. Entri bersarang (subbab di bawah bab) tetap berada di file induknya dan tidak menimbulkan potongan sendiri.
  • Halaman sebelum bookmark pertama tidak dimasukkan ke file mana pun. Jika bookmark pertama menunjuk ke halaman 3, sampul dan daftar isi di halaman 1 dan 2 tidak ikut. Tambahkan dulu bookmark di halaman 1 dengan Buat Bookmark jika Anda membutuhkannya. Ini hal yang paling sering mengejutkan pengguna alat ini, jadi periksa halaman yang dibuka oleh bookmark pertama.
  • Jika dua bookmark menunjuk ke halaman yang sama, bookmark yang lebih awal tidak punya halaman sendiri dan dilewati; bagiannya menjadi milik bookmark berikutnya.
  • Bookmark yang membuka alamat web atau menjalankan aksi, bukan menunjuk ke halaman, tidak bisa ditelusuri dan diabaikan. Jika tidak ada satu pun yang bisa ditelusuri, alat ini melaporkan bahwa tujuan bookmark tidak dapat ditentukan.
  • Bookmark diurutkan berdasarkan halaman, bukan urutannya di panel, jadi kerangka yang urutannya acak tetap menghasilkan bagian sesuai urutan dokumen.
  • File hasilnya sendiri tidak punya kerangka bookmark; sub-bookmark tidak dibuat ulang di dalam setiap bagian.

Tips untuk hasil terbaik

  • Belum ada bookmark? Tambahkan dalam semenit dengan Buat Bookmark (satu baris per bagian, dalam format halaman, Judul), lalu jalankan alat ini pada hasilnya. Bookmark yang dibuat dengan cara itu berada di tingkat teratas, persis yang dipakai alat ini untuk memotong.
  • Ganti nama bookmark sebelum memisahkan jika judulnya panjang. Hanya 40 karakter pertama yang masuk ke nama file, dan dua judul dengan awalan sama akan sulit dibedakan.
  • Jika kerangka Anda hanya punya satu entri tingkat teratas dengan semua bagian bersarang di bawahnya, Anda hanya akan mendapat satu file. Gunakan Pisahkan PDF dengan rentang yang diambil dari entri-entri bersarang itu.
  • Gunakan judul yang aman untuk sistem file di dokumen sumber (hindari garis miring dan titik dua) agar nama file keluar persis seperti yang ditulis.
  • Periksa bagian di tengah, bukan hanya yang pertama dan terakhir; bookmark yang menunjuk ke halaman yang salah di sumbernya akan tampak sebagai bagian yang mulai terlalu awal atau terlambat. Mengklik setiap bookmark tingkat teratas di aplikasi pembaca sebelum memisahkan menunjukkan dengan tepat di mana setiap file akan dimulai.

Contoh: modul praktikum yang dibagikan per minggu

Laras, asisten laboratorium kimia di sebuah kampus di Bandung, memegang modul praktikum setebal 156 halaman dalam satu PDF. Kerangkanya berisi sebelas bookmark tingkat teratas: Tata Tertib Laboratorium, lalu Praktikum 1 sampai Praktikum 10, masing-masing dengan sub-bookmark untuk tujuan, alat dan bahan, prosedur, dan lembar pengamatan. Mahasiswa sering mengeluh file 156 halaman terlalu berat dibuka di HP, jadi Laras ingin membagikan satu praktikum per minggu di grup kelas.

Pisahkan berdasarkan Bookmark menghasilkan sebelas file, misalnya 'modul - Praktikum 3 Titrasi Asam Basa.pdf', masing-masing lengkap dengan prosedur dan lembar pengamatannya, karena sub-bookmark tidak dipakai sebagai titik potong. Dua hal perlu Laras perhatikan. Halaman 1 sampai 4 (sampul, kata pengantar, dan daftar isi) berada sebelum bookmark pertama, jadi tidak masuk ke file mana pun. Lalu judul bookmark Praktikum 7 yang panjang terpotong di nama file karena hanya 40 karakter pertama yang dipakai, sehingga ia menggantinya sendiri setelah diunduh.

Untuk semester berikutnya, Laras menambahkan bookmark bernama Pendahuluan di halaman 1 dengan Buat Bookmark sebelum memisahkan, sehingga sampul dan daftar isi ikut menjadi file tersendiri. Seluruh proses berjalan di dalam tab browser, jadi modul yang belum boleh beredar di luar kelas tidak pernah diunggah ke mana pun.

Pemecahan masalah

Error: 'PDF ini tidak memiliki bookmark untuk dipisahkan'
File tidak punya kerangka. Tambahkan bookmark dengan Buat Bookmark, atau pisahkan berdasarkan rentang halaman atau teks.
Error: 'Tujuan bookmark tidak dapat ditentukan'
Bookmark-nya ada, tetapi tidak menunjuk ke halaman, misalnya karena berupa tautan atau skrip, atau karena kerangkanya rusak. Jalankan Perbaiki PDF, atau buat ulang bookmark dengan Buat Bookmark.
Halaman sampul dan daftar isi saya hilang
Halaman-halaman itu berada sebelum bookmark pertama dan tidak masuk bagian mana pun. Tambahkan bookmark di halaman 1, lalu pisahkan lagi.
Saya hanya mendapat satu file
Semua bagian Anda bersarang di bawah satu bookmark tingkat teratas. Gunakan Pisahkan PDF dengan Rentang khusus berdasarkan entri-entri bersarang itu.
Ada bagian yang hilang
Bookmark-nya kemungkinan menunjuk ke halaman yang sama dengan bookmark berikutnya, atau ke tautan web. Betulkan bookmark di dokumen sumber lalu pisahkan lagi.
Nama file terpotong atau terlihat berbeda
Judul dipendekkan menjadi 40 karakter dan karakter seperti / : ? dihapus. Ganti nama file setelah diunduh jika perlu. Dokumen aslinya tidak berubah.

Pertanyaan yang sering diajukan

Sub-bookmark ikut dipakai sebagai titik potong tidak?

Tidak. Hanya bookmark tingkat teratas yang menghasilkan file baru; bagian bersarang tetap ikut bab induknya.

Sampul dan daftar isi sebelum bookmark pertama ke mana?

Halaman-halaman itu tidak masuk ke file mana pun. Beri bookmark di halaman 1 lebih dulu jika Anda membutuhkannya.

Bisa memilih bookmark mana saja yang dipakai untuk memotong?

Tidak dengan alat ini. Pisahkan berdasarkan semua bookmark lalu simpan file yang Anda perlukan, atau gunakan Pisahkan PDF dengan rentang khusus.

File hasilnya masih punya bookmark sendiri?

Tidak. Kerangka dipakai untuk menentukan titik potong, tetapi tidak disalin ke bagian-bagiannya.

Kualitas halamannya terpengaruh?

Tidak. Halaman disalin apa adanya, tidak dirender ulang.

Bisa dipakai untuk PDF hasil scan?

Bisa, selama PDF hasil scan itu punya bookmark. Bookmark tidak bergantung pada ada atau tidaknya teks asli di halaman, dan bookmark yang ditambahkan dengan Buat Bookmark juga bekerja dengan cara yang sama.

HTML ke PDF

Ubah file HTML yang tersimpan menjadi PDF melalui server konversi, sehingga halaman web atau hasil ekspor HTML menjadi halaman tetap yang siap dicetak.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.
1

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Pilih opsi Anda — semuanya berlangsung di browser Anda.

3

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

Banyak dokumen penting yang hanya tersedia dalam bentuk HTML: konfirmasi pesanan yang disimpan dari browser, laporan yang diekspor oleh aplikasi, newsletter, dokumentasi yang dibuat sebagai satu halaman panjang, atau halaman yang Anda buat sendiri. HTML selalu menyesuaikan diri dengan lebar jendela tempat ia dibuka, dan justru itu yang tidak Anda inginkan ketika dokumen harus diarsipkan, dicetak, atau dilampirkan ke pengajuan klaim. PDF membekukannya dalam satu ukuran halaman.

Alat ini menerima file .html atau .htm dari komputer Anda, bukan alamat web. File diunggah secara terenkripsi ke layanan CloudConvert melalui relay PDFora; di sana mesin rendering menyusun tata letak halaman lalu mencetaknya ke PDF. Hasilnya dikembalikan dengan nama yang sama seperti file Anda, dan file dihapus dari layanan tersebut setelahnya. Konversi tidak terjadi di browser Anda, dan tidak ada pengaturan ukuran halaman atau margin di halaman alat.

Hal yang paling sering mengejutkan pengguna adalah nasib semua file yang dirujuk oleh HTML. Sebuah halaman web jarang terdiri dari satu file saja: gambar, stylesheet, dan font biasanya file terpisah yang dipanggil dari HTML. Hanya satu file yang Anda pilih yang diunggah, sehingga apa pun yang dirujuk dengan path relatif di disk Anda tidak akan ditemukan oleh server. Jadi, kunci mendapatkan PDF yang sesuai aslinya adalah membuat file HTML itu mandiri sebelum dikonversi.

Cara mengubah HTML ke PDF

  1. Pastikan file HTML sudah mandiri atau memakai alamat web lengkap (https://...) untuk gambar dan stylesheet-nya; lihat catatan di bawah.
  2. Buka alat HTML ke PDF dan pilih file .html atau .htm Anda.
  3. Klik Konversi, lalu tunggu selama file diunggah dan dirender di server.
  4. Unduh PDF-nya; nama file tetap sama seperti file Anda, hanya ekstensinya menjadi .pdf.
  5. Periksa apakah gambar, warna, dan tata letak terbawa dengan benar, dan tidak ada konten yang terpotong di tepi kanan.

Kapan menggunakan alat ini

  • Bukti pembayaran dan konfirmasi pemesanan tiket atau hotel yang disimpan dari browser, diarsipkan sebagai PDF untuk pembukuan atau bukti tertulis.
  • Laporan yang diekspor aplikasi dalam format HTML dan perlu dilampirkan ke email atau diarsipkan.
  • Developer yang mengubah template faktur, sertifikat, atau surat berbasis HTML menjadi PDF untuk mengecek tampilan cetaknya.
  • Dokumentasi atau panduan pengguna yang terbit sebagai satu halaman HTML panjang, dicetak untuk dibaca secara offline.
  • Artikel web yang disimpan sebagai bahan riset dalam format yang tidak ikut berubah meskipun situsnya berubah.
  • Newsletter email yang disimpan sebagai HTML lalu dikonversi sebagai arsip dari apa yang sudah dikirim.

Yang perlu diketahui sebelum mulai

  • Path relatif akan putus. Jika HTML berisi <img src="images/logo.png"> atau <link href="style.css">, file-file itu tetap di komputer Anda dan tidak bisa dilihat server. Akibatnya PDF menampilkan gambar yang hilang dan teks tanpa gaya. Gunakan alamat https:// absolut, atau masukkan CSS ke dalam blok <style> dan gambar sebagai data URI.
  • Sumber daya dengan alamat web absolut mungkin diambil oleh server saat merender halaman, jadi gambar dan stylesheet yang bisa diakses publik biasanya muncul. Apa pun yang berada di balik login, di intranet, atau di localhost tidak akan muncul.
  • Tidak ada kolom URL. Untuk mengonversi halaman yang sedang tayang, simpan dulu halamannya. Format Save Page As > Web Page, Single File (.mhtml) di browser tidak diterima, jadi pilih Web Page, HTML Only dan bersiaplah gambar relatifnya hilang, atau gunakan fitur Print > Save as PDF bawaan browser.
  • Gaya cetak ikut berlaku. Jika halaman punya CSS untuk @media print, konverter biasanya memakainya, sehingga bilah navigasi bisa tersembunyi atau warnanya berbeda dari tampilan di layar. Pergantian halaman bisa diatur dengan break-before dan break-inside di CSS.
  • Konten yang dibangun JavaScript tidak bisa diandalkan. Halaman yang mengambil isinya lewat skrip setelah dimuat bisa terkonversi sebagai kerangka kosong. Simpan halaman setelah benar-benar selesai dimuat, atau render kontennya ke dalam HTML dari sisi server.
  • Tata letak yang lebih lebar dari halaman cetak, misalnya desain dengan lebar tetap 1400 piksel atau tabel yang lebar, bisa terpotong atau mengecil. Tata letak responsif atau max-width pada konten utama biasanya menyelesaikannya.

Tips untuk hasil terbaik

  • Untuk template buatan sendiri, taruh semua CSS di blok <style> di dalam <head>; inilah cara paling andal untuk mendapatkan PDF yang tetap bergaya.
  • Tambahkan @page { size: A4; margin: 15mm; } ke CSS jika Anda butuh ukuran halaman atau margin tertentu.
  • Pakai break-inside: avoid pada baris tabel, kartu, dan gambar agar tidak terbelah di dua halaman.
  • Jaga ukuran gambar tetap wajar: gambar banner 5 MB yang ditanam sebagai data URI tetap menghasilkan PDF 5 MB.
  • Buka dulu file HTML di print preview browser; kalau tampilannya sudah salah di sana, kemungkinan besar PDF hasil konversinya juga salah.

Contoh nyata: template faktur HTML toko online kecil

Sebuah toko online batik yang dikelola dua orang di Pekalongan membuat faktur berupa file HTML dari skrip sederhana. Setiap file memanggil invoice.css dan logo.png dari folder yang sama. Saat langsung dikonversi, PDF-nya hanya berisi teks hitam polos dengan font standar, tanpa logo, dan tabel totalnya melebar memenuhi halaman, karena server hanya menerima file HTML tanpa stylesheet dan gambarnya.

Solusinya adalah membuat file itu mandiri. Skripnya kini menyalin isi invoice.css ke dalam blok <style>, menambahkan @page { size: A4; margin: 18mm; } serta break-inside: avoid pada baris tabel item, dan mengarahkan logo ke alamat https publik di situs toko, bukan ke path lokal. Selain itu tidak ada yang diubah.

Setelah dikonversi ulang, fakturnya menjadi PDF A4 satu halaman lengkap dengan logo, warna khas toko, dan tabel total yang tidak lagi terbelah ketika pesanan berisi banyak item. Karena template-nya kini mandiri, setiap faktur yang dihasilkan skrip akan terkonversi dengan cara yang sama.

Pemecahan masalah

PDF tidak bergaya, hanya teks polos
Stylesheet dirujuk dengan path relatif sehingga tidak ikut terunggah. Masukkan CSS ke blok <style> atau tautkan dengan alamat https:// lengkap.
Gambar tidak muncul
Gambar di disk Anda yang dirujuk dengan path relatif tidak bisa dijangkau. Pakai URL https:// publik atau tanam gambar sebagai data URI, lalu konversi ulang.
Halaman terpotong di sisi kanan
Tata letaknya memakai lebar tetap yang melebihi halaman. Tambahkan max-width: 100% pada kontainer utama dan gambar, atau stylesheet cetak yang mempersempit tata letak.
PDF kosong atau hampir kosong
Kemungkinan kontennya dibuat oleh JavaScript setelah halaman dimuat, atau file itu hanya berisi pengalihan. Simpan halaman setelah selesai dirender sepenuhnya, atau tulis kontennya langsung di dalam HTML.
Teks muncul dengan font yang berbeda
Web font yang dirujuk secara lokal tidak tersedia. Tautkan font dari URL publik, tanam dengan @font-face dan data URI, atau gunakan font yang umum.
Alat menolak file saya
Hanya .html dan .htm yang diterima. File .mhtml atau .webarchive perlu disimpan ulang sebagai HTML saja.

Pertanyaan yang sering diajukan

Bisakah saya mengonversi situs web dengan memasukkan URL-nya?

Tidak. Alat ini mengonversi file HTML yang Anda pilih. Simpan dulu halamannya sebagai HTML, atau gunakan Print > Save as PDF di browser untuk halaman yang sedang tayang.

Apakah file HTML saya diunggah?

Ya. File dikirim secara terenkripsi ke layanan konversi, dirender di sana, lalu dihapus. Hindari mengonversi halaman yang berisi data pribadi yang tidak ingin Anda serahkan untuk diproses pihak ketiga.

Kenapa gambar dan CSS saya hilang?

Hanya file HTML itu sendiri yang diunggah. File yang dirujuk dengan path relatif tetap berada di komputer Anda; gunakan tautan https:// absolut atau tanam langsung ke dalam HTML.

Bisakah saya mengatur ukuran halaman atau margin?

Tidak di halaman alat. Atur langsung di HTML dengan aturan CSS @page, misalnya @page { size: A4; margin: 15mm; }.

Apakah tautan di PDF bisa diklik?

Tautan ke alamat web biasanya tetap bisa diklik. Tautan relatif ke file lokal lain tidak akan mengarah ke tempat yang berguna.

Apakah JavaScript dijalankan saat konversi?

Mungkin sebagian berjalan, tetapi konten yang dimuat belakangan atau bergantung pada interaksi pengguna sering tidak muncul. Agar hasilnya andal, HTML sebaiknya sudah berisi konten final.

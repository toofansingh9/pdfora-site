Buka Kunci PDF

Penjelasan cara kerja penghapusan kata sandi PDF, apa yang nanti dilakukan Buka Kunci PDF dari PDFora, dan cara membuka kunci file milik Anda hari ini.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

Hampir semua orang yang menerima e-statement bank pernah mengalaminya: file dibuka, diminta kata sandi tanggal lahir, lalu portal tempat file itu harus diunggah menolaknya karena "terenkripsi". Untuk saat ini, Buka Kunci PDF belum bisa membantu. Jika Anda memilih file dan menekan tombolnya, yang muncul hanya pesan "Penghapusan kata sandi segera hadir." dan dokumen Anda tidak diubah. Alat ini bergantung pada jalur pemrosesan yang masih dikerjakan. Sambil menunggu, halaman ini menjelaskan cara kerja penghapusan kata sandi PDF, apa yang nanti akan dan tidak akan dilakukan alat ini, dan cara membuka proteksi hari ini juga untuk file yang kata sandinya Anda ketahui.

Satu hal yang perlu diluruskan: menghapus proteksi tidak sama dengan membobolnya. Untuk mendekripsi PDF yang memiliki kata sandi pembuka, aplikasi membutuhkan kata sandi itu. Kata sandi dipakai untuk menurunkan kunci, mendekripsi isi, lalu menyimpan salinan tanpa enkripsi. File yang dienkripsi dengan benar dengan kata sandi kuat tidak bisa dibuka begitu saja tanpanya, dan alat PDFora tidak dirancang untuk menebak kata sandi. Tujuannya nanti adalah kemudahan untuk file yang memang berhak Anda buka, seperti rekening koran yang dikunci dengan tanggal lahir Anda sendiri.

File yang hanya memakai kata sandi izin lain lagi ceritanya. File seperti itu terbuka tanpa diminta kata sandi, tetapi pencetakan, penyalinan, atau pengeditan bisa diblokir. Banyak program mampu menyimpan salinan tanpa pembatasan dari file semacam itu; pantas atau tidaknya Anda melakukannya tergantung alasan pembatasan itu dipasang, yang dibahas di bawah. Kabar baiknya untuk urusan rutin: kata sandi rekening koran biasanya sama setiap bulan, jadi sekali formatnya ketemu, pekerjaan ini cepat menjadi kebiasaan.

Cara menghapus kata sandi PDF saat ini

  1. Buka PDF yang terkunci di aplikasi pembaca yang biasa Anda pakai dan masukkan kata sandinya untuk memastikan kata sandinya benar.
  2. Pilih Print dan gunakan 'Save as PDF' atau 'Microsoft Print to PDF' sebagai printer. File baru tidak terenkripsi, meskipun tautan dan kolom formulir bisa hilang.
  3. Cara lain di Mac: buka file di Preview, pilih File > Export, dan biarkan Encrypt tidak dicentang untuk menyimpan salinan tanpa proteksi.
  4. Di editor PDF lengkap, buka pengaturan keamanan atau proteksi dan pilih hapus keamanan; editor akan meminta kata sandinya.
  5. Buka salinan baru untuk memastikan tidak ada permintaan kata sandi, lalu simpan atau hapus file asli yang terkunci sesuai kebutuhan.

Kapan menggunakan alat ini

  • E-statement rekening koran, tagihan kartu kredit, atau tagihan bulanan yang dikunci dengan tanggal lahir, yang harus digabung menjadi satu file untuk pengajuan KPR, kredit, atau visa.
  • Slip gaji berkata sandi dari sistem penggajian yang harus diunggah ke portal yang menolak PDF terenkripsi.
  • Dokumen lama milik Anda sendiri yang dulu dikunci dengan kata sandi yang masih Anda ingat.
  • Sekolah atau kampus yang menerima laporan berkata sandi dan perlu menggabungkannya ke dalam berkas siswa.
  • File yang perlu diproses alat PDF lain, seperti kompresi atau OCR, yang tidak bisa membuka dokumen terenkripsi.
  • Mengarsipkan dokumen agar akses di masa depan tidak bergantung pada ingatan akan banyak kata sandi yang berbeda-beda.

Yang perlu diketahui sebelum mulai

  • Buka Kunci PDF saat ini hanya menampilkan 'segera hadir' dan tidak memproses file.
  • Menghapus kata sandi pembuka memerlukan kata sandi itu. Tanpanya, PDF yang terenkripsi dengan baik tidak bisa dibuka oleh alat sah mana pun.
  • Print to PDF menghasilkan file baru tanpa enkripsi, tetapi bisa menghilangkan tautan, bookmark, dan kolom formulir, dan sebagian aplikasi pembaca tidak mau mencetak file yang izinnya melarang pencetakan.
  • Pembatasan izin biasanya dipasang penerbit dengan sengaja. Hapus pembatasan hanya jika Anda berhak, misalnya pada dokumen milik sendiri atau dengan persetujuan pemiliknya.
  • Salinan yang sudah dibuka kuncinya bisa dibaca siapa saja yang memegangnya. Simpan di tempat aman, dan hapus jika Anda hanya membutuhkannya sementara.
  • Setelah PDF dibuka kuncinya, alat PDFora lain seperti Gabungkan PDF, Kompres PDF, dan OCR PDF bisa memprosesnya. Jika bank atau kantor nanti meminta dokumennya lagi, buat salinan baru tanpa kunci dari file asli yang terlindungi, jangan membiarkan file tanpa kunci tersimpan di mana-mana.

Tips untuk hasil terbaik

  • Cek email yang menyertai rekening koran berkata sandi; format kata sandinya (misalnya tanggal dan bulan lahir ditambah beberapa digit terakhir nomor rekening) biasanya dijelaskan di situ.
  • Jika portal menolak PDF Anda, perhatikan kata seperti 'encrypted' atau 'secured' di pesan error-nya; itu petunjuk bahwa kata sandinya perlu dihapus.
  • Buka kunci hanya pada salinan yang perlu diproses, dan simpan file asli yang terlindungi sebagai arsip.
  • Setelah membuka kunci dan menggabungkan rekening koran, pertimbangkan untuk melindungi lagi file gabungannya sebelum dikirim lewat email.
  • Jika Print to PDF menghilangkan kolom formulir yang Anda perlukan, gunakan opsi 'remove security' di editor PDF, yang mempertahankan struktur dokumen.

Contoh: rekening koran tiga bulan untuk pengurusan visa

Mega, karyawati swasta di Surabaya, mengurus visa turis lewat agen perjalanan untuk liburan keluarga. Agen meminta rekening koran tiga bulan terakhir dalam satu file PDF, diunggah lewat formulir di situs mereka. Masalahnya, e-statement dari banknya dikunci dengan kata sandi pembuka berupa tanggal lahir, dan formulir agen menolak ketiga file itu dengan pesan bahwa dokumen terenkripsi.

Format kata sandinya sudah dijelaskan di email yang menyertai e-statement. Mega membuka setiap file di laptop Windows-nya, memasukkan kata sandi, lalu memilih Print dengan printer 'Microsoft Print to PDF' untuk menyimpan salinan tanpa enkripsi. Tautan di bagian bawah rekening koran tidak bisa diklik lagi di salinan itu, tetapi untuk keperluan visa hal tersebut tidak penting. Ketiga salinan lalu ia gabungkan dengan Gabungkan PDF sesuai urutan bulan, dan formulir agen menerima file gabungannya.

Setelah unggahan berhasil, Mega menghapus ketiga salinan tanpa kunci dan file gabungannya dari folder Download, karena siapa pun yang memegang file itu bisa membaca seluruh mutasi rekeningnya. E-statement asli tetap tersimpan di email, masih terkunci. Saat Buka Kunci PDF sudah tersedia, alat itu bisa menggantikan langkah Print to PDF, sementara alur lainnya tetap sama. Bank mengunci dokumen semacam ini karena email sering tersimpan tanpa enkripsi di beberapa server dan utas yang diteruskan bisa sampai ke mana-mana. Membuka proteksi pada salinan kerja di komputer sendiri adalah langkah wajar, asalkan salinan tanpa kunci itu tidak dikirim lagi lewat email tanpa perlindungan.

Pemecahan masalah

Buka Kunci PDF menampilkan 'segera hadir'
Alat ini memang belum berfungsi. Gunakan Print to PDF, ekspor dari Preview, atau pengaturan keamanan di editor PDF seperti dijelaskan di atas.
Saya tidak tahu kata sandinya
Cari di email atau surat yang menyertai file itu, atau minta pengirim mengirimkan salinan tanpa proteksi. Enkripsi yang kuat tidak bisa dihapus tanpa kata sandi.
Menu Print berwarna abu-abu
Izin file melarang pencetakan. Gunakan opsi 'remove security' di editor PDF dengan kata sandi izin, atau minta salinan tanpa pembatasan dari pemiliknya.
Salinan tanpa kunci kehilangan tautan dan kolom formulir
Print to PDF meratakan dokumen. Gunakan ekspor dari Preview atau editor PDF lengkap, yang lebih banyak mempertahankan strukturnya.
Portal masih menyebut file terenkripsi
Mungkin Anda tanpa sengaja mengunggah file asli. Pastikan salinan baru terbuka tanpa permintaan kata sandi, dan beri nama yang jelas, misalnya rekening-koran-unlocked.pdf.
Alat lain di situs ini tidak bisa membuka PDF saya
File masih terlindungi. Hapus proteksinya dulu, lalu gunakan Gabungkan PDF, Kompres PDF, atau OCR PDF pada salinan yang sudah tidak terkunci.

Pertanyaan yang sering diajukan

Buka Kunci PDF sudah bisa dipakai belum?

Belum. Alat ini hanya menampilkan pesan bahwa penghapusan kata sandi segera hadir, dan file Anda tidak diubah.

Kalau saya lupa kata sandinya, apakah alat ini bisa membukanya?

Tidak. Alat yang direncanakan akan tetap membutuhkan kata sandinya. Alat ini tidak dirancang untuk menebak atau membobol kata sandi.

Boleh tidak menghapus kata sandi dari PDF?

Menghapus proteksi dari dokumen milik sendiri, atau dengan izin pemiliknya, umumnya tidak bermasalah. Menghapus pembatasan dari konten yang bukan hak Anda bisa melanggar ketentuan penerbit atau hukum hak cipta.

Apa bedanya membuka kata sandi pembuka dengan menghapus pembatasan izin?

Kata sandi pembuka mengenkripsi file, dan menghapusnya memerlukan kata sandi itu. Pembatasan izin hanya membatasi tindakan seperti mencetak dan menyalin di aplikasi pembaca.

Isi PDF berubah tidak setelah kuncinya dibuka?

Menghapus keamanan dengan editor yang tepat mempertahankan isi apa adanya. Print to PDF bisa menghilangkan tautan, bookmark, dan kolom formulir.

Nanti setelah diluncurkan, berbayar tidak?

Rencananya gratis, sama seperti alat PDFora lainnya.

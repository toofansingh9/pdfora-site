Gabungkan PDF

Gabungkan dua PDF atau lebih menjadi satu file, dengan urutan yang Anda tentukan, tanpa mengunggah apa pun.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.
1

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Pilih opsi Anda — semuanya berlangsung di browser Anda.

3

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

Hampir semua orang pernah menggabungkan PDF, dan hampir semua orang pernah mengulanginya karena ada yang salah: urutan file berantakan, halaman yang mestinya dibuang ikut terkirim, atau file gabungan ternyata kebesaran untuk dilampirkan. Supaya itu tidak terjadi, ada baiknya Anda tahu apa yang sebenarnya dilakukan Gabungkan PDF terhadap file Anda, apa yang dipertahankan, dan apa yang tidak.

Saat menggabungkan, alat ini menyalin objek halaman dari setiap PDF sumber ke dokumen baru, satu file demi satu file sesuai urutan. Teks tetap teks asli yang bisa diblok dan dicari, grafik vektor tetap vektor, dan gambar disalin sekali dalam resolusi aslinya. Tidak ada yang dirender atau dikompres ulang, sehingga setiap halaman di file gabungan tampil sama persis dengan halaman aslinya. Akibatnya, ukuran hasil kurang lebih sama dengan jumlah ukuran semua file masukan: tiga hasil scan masing-masing 4 MB menjadi sekitar 12 MB, paling hanya selisih beberapa kilobyte.

Seluruh proses terjadi di browser Anda dengan library pdf-lib. Dokumen dibaca dari perangkat ke memori, digabung di sana, lalu hasilnya langsung tersedia untuk diunduh. Tidak ada tahap unggah, jadi tidak ada antrean, tidak ada batas ukuran dari server, dan tidak ada file yang perlu kami hapus setelahnya.

Cara menggabungkan file PDF secara online

  1. Buka alat Gabungkan PDF, lalu seret semua file sekaligus ke kotak yang tersedia atau klik kotaknya untuk memilih file. File lain bisa ditambahkan belakangan.
  2. Seret baris-baris file sesuai urutan yang Anda inginkan. Baris paling atas menjadi halaman 1 pada hasil akhir. Gunakan pegangan di sisi kiri setiap baris untuk menyeretnya.
  3. Perhatikan ukuran yang tertera di samping nama setiap file. Jika totalnya mendekati batas lampiran, kompres dulu file yang paling besar (lihat contoh di bawah).
  4. Klik Gabungkan PDF. Bilah progres akan berjalan melewati setiap file; hasil scan yang besar butuh beberapa detik per file.
  5. Unduh merged.pdf, buka filenya, dan periksa bagian sambungan antardokumen sebelum Anda mengirimkannya.

Kapan menggunakan alat ini

  • Berkas pengajuan KPR atau kredit kendaraan: slip gaji, rekening koran, scan KTP dan KK, serta surat keterangan kerja dalam satu file sesuai urutan yang diminta bank.
  • Lamaran kerja dan pendaftaran CPNS: surat lamaran, CV, ijazah, dan transkrip dijadikan satu lampiran.
  • Laporan pajak tahunan atau tutup buku: semua bukti potong dan faktur satu periode dikumpulkan dalam satu file untuk konsultan pajak atau bagian akuntansi.
  • Bahan kuliah: handout beberapa pertemuan atau bab-bab skripsi disatukan menjadi satu dokumen yang enak dibaca.
  • Berkas sewa rumah atau kontrakan: perjanjian, lampiran, dan halaman bertanda tangan yang dikumpulkan setelah semua pihak mengembalikan bagiannya.
  • Hasil scan bolak-balik: sisi depan dan belakang yang di-scan sebagai file terpisah digabung agar halamannya berurutan (pakai Selang-seling & Gabung kalau sisi belakang ada di file kedua dengan urutan terbalik).

Yang perlu diketahui sebelum mulai

  • Bookmark (panel daftar isi) tidak ikut terbawa. File gabungan tidak memiliki daftar isi meskipun file sumbernya punya. Jika perlu, tambahkan lagi dengan Buat Bookmark.
  • Kolom formulir yang bisa diisi dapat rusak saat dokumen digabung, terutama jika dua file memakai nama kolom yang sama. Jika formulir harus tetap bisa diisi, gabungkan hanya PDF yang tidak berisi formulir, atau ratakan dulu formulirnya lalu gabungkan salinan yang sudah diratakan.
  • File yang dilindungi kata sandi tidak bisa dibuka oleh alat penggabung. Hapus dulu kata sandinya (dengan memasukkan kata sandi tersebut, lewat Buka Kunci PDF setelah tersedia, atau di aplikasi yang membuat file itu), lalu coba lagi.
  • Ukuran halaman yang berbeda tetap dibiarkan apa adanya: surat ukuran A4, disusul scan ukuran US Letter, lalu tabel berorientasi lanskap akan tetap seperti itu. Gunakan Ubah Ukuran PDF jika Anda ingin ukurannya seragam.
  • Tautan internal yang mengarah ke halaman lain dalam dokumen yang sama bisa tidak berfungsi lagi setelah digabung, karena nomor halaman tujuannya sudah berubah. Tautan ke situs web tidak terpengaruh.
  • File gabungan dibangun di memori browser Anda. Menggabungkan beberapa dokumen biasa berlangsung seketika, tetapi menggabungkan beberapa hasil scan berukuran ratusan megabyte bisa menghabiskan memori di ponsel atau laptop lama. Jika tab browser macet, lakukan di komputer desktop atau gabungkan dalam dua tahap.

Tips untuk hasil terbaik

  • Beri awalan angka pada nama file (01-surat-lamaran.pdf, 02-cv.pdf) sebelum menambahkannya; urutannya langsung terlihat dan tetap aman jika Anda harus mengulang.
  • Bereskan urutan sebelum mengklik Gabungkan PDF. Mengubah urutan setelahnya berarti mengulang seluruh proses, karena file hasil tidak bisa di-undo.
  • Buang halaman yang tidak diperlukan dari file sumber terlebih dulu dengan Hapus Halaman, lalu gabungkan salinan yang sudah bersih. Jauh lebih mudah daripada mencari halaman itu di dokumen hasil yang panjang.
  • Simpan file asli sampai Anda sudah membuka PDF gabungan dan memeriksa jumlah halamannya: angkanya harus sama dengan total halaman semua file sumber.
  • Jika salah satu sumber berupa hasil scan dan yang lain dokumen digital, halaman scan itu tetap tidak bisa dicari di file gabungan; OCR PDF bisa memberikan teksnya sebagai file .txt terpisah.

Contoh nyata: berkas pengajuan KPR untuk bank

Andi, karyawan swasta di Bekasi, sedang mengajukan KPR. Petugas bank meminta semua berkas dikirim lewat email sebagai satu PDF dengan urutan sesuai daftar periksa, dan menyebutkan bahwa kotak masuk kantornya menolak lampiran di atas 15 MB. Berkas Andi terdiri dari tiga slip gaji digital (masing-masing sekitar 150 KB), rekening koran tiga bulan dari internet banking (800 KB), serta tiga hasil scan: KTP dan KK (5 MB), surat keterangan kerja (6 MB), dan buku nikah (5 MB). Kalau langsung digabung, totalnya sekitar 17 MB.

File digitalnya kecil karena teksnya tersimpan sebagai teks; yang membengkak adalah tiga hasil scan, karena setiap halamannya berupa foto. Jadi Andi memproses ketiga scan itu dengan Kompres PDF pada tingkat Disarankan lebih dulu. Hasil scan biasanya menyusut 60 sampai 90 persen, sehingga ketiganya kini masing-masing tinggal sekitar 0,5 sampai 2,5 MB. Setelah itu ia memberi nama file berawalan 01 sampai 07 sesuai daftar periksa bank, menambahkan ketujuh file ke Gabungkan PDF, dan mengecek urutannya sekali lagi sebelum mengklik Gabungkan PDF.

File merged.pdf yang ia dapat sekitar 3 sampai 7 MB, jauh di bawah batas. Sebelum mengirim, ia membuka hasilnya dan mencocokkan jumlah halamannya dengan total halaman ketujuh file sumber. Slip gaji dan rekening koran tetap berupa teks yang tajam dan bisa dicari, karena kedua file itu tidak ikut dikompres.

Pemecahan masalah

Tombol gabung tidak bisa diklik
Alat ini butuh minimal dua file. Tambahkan PDF kedua, atau jika Anda hanya ingin mengatur ulang halaman dalam satu file, gunakan Atur Halaman.
Salah satu file tidak mau dimuat
Kemungkinan besar file itu dilindungi kata sandi atau rusak. Buka di aplikasi pembaca PDF: jika diminta kata sandi, hapus dulu proteksinya; jika sama sekali tidak bisa dibuka, perbaiki dengan Perbaiki PDF lalu gabungkan salinan yang sudah diperbaiki.
PDF gabungan lebih besar daripada total file aslinya
Sedikit tambahan ukuran itu wajar, karena sumber daya bersama (font, profil warna) disalin sekali per file sumber, bukan dihilangkan duplikatnya. Jika hasilnya jauh lebih besar dari perkiraan, kemungkinan salah satu file berisi gambar beresolusi sangat tinggi; kompres file itu terlebih dulu.
Urutan halamannya salah
Urutan baris di daftar file adalah urutan hasil akhir. Seret baris ke posisi yang benar lalu gabungkan lagi; file unduhan hanya mengikuti urutan pada saat Anda mengklik Gabungkan PDF.
Bookmark atau kolom formulir saya hilang
Itu memang perilakunya: penggabungan menyalin halaman, bukan daftar isi atau struktur formulir di tingkat dokumen. Tambahkan bookmark setelahnya dengan Buat Bookmark, dan ratakan formulir sebelum digabung jika formulir itu cukup untuk dibaca saja.
Tab browser macet saat memproses file besar
Memori perangkat Anda habis karena harus menampung semua file sumber sekaligus. Tutup tab lain, lakukan di komputer desktop, atau gabungkan dalam dua tahap (separuh pertama dulu, lalu sisanya bersama hasil tahap pertama).

Pertanyaan yang sering diajukan

Kualitas PDF turun setelah digabung?

Tidak. Halaman disalin, bukan dirender ulang. Teks tetap teks, gambar tetap dalam resolusi aslinya, dan hasil cetaknya sama persis dengan file sumbernya.

Maksimal berapa file atau halaman yang bisa digabung?

Alat ini tidak memasang batas. Batas praktisnya adalah memori perangkat Anda: ratusan halaman biasa tidak masalah, sedangkan banyak hasil scan berukuran sangat besar mungkin perlu digabung dalam dua tahap.

PDF dengan ukuran kertas atau orientasi berbeda bisa digabung?

Bisa. Setiap halaman tetap memakai ukuran dan orientasinya sendiri. Kalau ingin seragam, proses file gabungannya dengan Ubah Ukuran PDF.

Bookmark dan kolom formulir saya ikut terbawa?

Bookmark tidak ikut disalin, dan kolom formulir bisa rusak. Tambahkan bookmark sesudahnya dengan Buat Bookmark; ratakan formulir sebelum digabung, kecuali formulir itu masih harus bisa diisi.

PDF yang dikunci kata sandi bisa langsung digabung?

Tidak selama proteksinya masih aktif. Hapus kata sandinya dulu, baru gabungkan. Gabungkan PDF tidak pernah meminta atau menyimpan kata sandi.

Aman nggak menggabungkan dokumen pribadi seperti KTP atau slip gaji di sini?

Penggabungan berjalan sepenuhnya di browser Anda dengan library pdf-lib, dan file tidak pernah diunggah. Begitu tab ditutup, tidak ada salinan yang tersisa selain di perangkat Anda sendiri.

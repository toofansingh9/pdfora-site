Gabungkan PDF

Seret PDF Anda ke urutan yang diinginkan lalu gabungkan menjadi satu dokumen dalam hitungan detik.

Menggabungkan PDF terdengar sepele sampai Anda benar-benar harus melakukannya. Misalnya Anda punya surat lamaran di satu file, CV di file lain, dan tiga pindaian sertifikat yang semuanya harus tiba sebagai satu lampiran. Alat merge PDFora menerima berapa pun jumlah file PDF dan menyatukannya menjadi satu dokumen yang rapi, langsung di browser Anda. Tanpa akun, tanpa watermark yang tercetak di halaman, tanpa antre unggahan.

Bagian yang sering luput diperhatikan: file Anda tidak pernah meninggalkan komputer Anda. Alat penggabung lain mengirim dokumen Anda ke server, memprosesnya di sana, lalu mengirim hasilnya kembali lewat email atau tautan. PDFora melakukan penggabungan secara lokal, memakai daya proses browser Anda sendiri. Sebuah kontrak, laporan medis, slip gaji — tidak ada satu pun yang melintasi internet, dan itu menjadikan alat ini pilihan masuk akal untuk apa pun yang bersifat rahasia.

Gratis, tanpa batas halaman dan tanpa kuota harian. Masukkan file Anda, seret ke urutan yang diinginkan, lalu unduh PDF gabungannya. Kalau Anda menggabungkan dokumen setiap minggu — faktur di akhir bulan, bab-bab naskah, materi kuliah — Anda bisa kembali sesering yang Anda mau tanpa terbentur dinding berbayar.

Cara menggabungkan file PDF secara online

  1. Buka alat Merge PDF di getpdfora.com — tidak ada yang perlu diinstal dan tidak ada layar pendaftaran.
  2. Klik area unggah atau seret file PDF Anda ke sana. Anda bisa menambahkan sebanyak yang diperlukan.
  3. Periksa daftar filenya. Setiap PDF tampil sebagai kartu yang menampilkan namanya.
  4. Seret kartu-kartu itu untuk mengubah urutannya — urutan dari atas ke bawah adalah urutan kemunculan halaman di dokumen akhir.
  5. Klik Merge. Browser Anda menggabungkan file secara lokal dalam beberapa detik.
  6. Unduh satu PDF gabungannya dan selesai.

When to use this tool

  • Mengirim lamaran kerja sebagai satu file dengan menyatukan surat lamaran, CV, dan surat rekomendasi.
  • Menggabungkan faktur sebulan penuh yang terpisah-pisah menjadi satu dokumen untuk akuntan Anda.
  • Menyatukan halaman hasil pindaian dari aplikasi pemindai ponsel, yang sering menyimpan tiap halaman sebagai PDF tersendiri.
  • Menyusun proposal klien dari lembar harga, contoh portofolio, dan draf kontrak.
  • Mengubah bab-bab buku atau skripsi yang diekspor terpisah menjadi satu naskah utuh untuk direview.
  • Membundel dokumen perjalanan — tiket, konfirmasi hotel, asuransi — menjadi satu file yang mudah dicari di bandara.

Tips for the best results

  • Beri nomor pada nama file Anda (01-pendahuluan.pdf, 02-isi.pdf) sebelum menambahkannya supaya urutan yang dimaksud langsung jelas terlihat.
  • Seret untuk mengatur urutan sebelum menekan Merge — memperbaiki urutan setelahnya berarti mengulang seluruh pekerjaan.
  • Kalau ada PDF sumber yang memuat halaman tak diinginkan, jalankan dulu lewat alat Delete Pages, baru gabungkan versi yang sudah bersih.
  • Menggabungkan banyak file pindaian berukuran besar memakan memori perangkat Anda, jadi tutup tab lain kalau prosesnya terasa lambat.
  • Simpan file aslinya sampai Anda membuka dan memeriksa hasil gabungannya.

Pertanyaan yang sering diajukan

Apakah aman menggabungkan PDF rahasia secara online?

Dengan PDFora, ya — penggabungan terjadi sepenuhnya di browser Anda dan file Anda tidak pernah diunggah ke server. Kontrak, laporan keuangan, dan rekam medis tetap ada di perangkat Anda dari awal sampai akhir.

Apakah ada batas berapa banyak PDF yang bisa saya gabungkan?

Tidak ada batas tetap. Performa praktisnya bergantung pada perangkat Anda, karena browser Anda sendiri yang bekerja, tapi menggabungkan puluhan dokumen biasa bukan masalah di laptop atau ponsel standar.

Apakah PDF hasil gabungan akan diberi watermark?

Tidak. Hasilnya PDF bersih tanpa tambahan apa pun — tanpa watermark, tanpa branding, tanpa cap masa uji coba, berapa pun banyak file yang Anda gabungkan dan sesering apa pun Anda melakukannya.

Bisakah saya mengubah urutan file sebelum menggabungkan?

Bisa. Setelah menambahkan file, seret ke urutan mana pun yang Anda suka. PDF akhir mengikuti urutan yang tampil di daftar, dari atas ke bawah.

Apakah saya perlu membuat akun atau membayar?

Tidak. Alat merge ini gratis dan bekerja tanpa pendaftaran apa pun. Tidak ada batas harian, jadi Anda bisa menggabungkan file PDF sesering yang Anda butuhkan.

Bagaimana kalau file saya sangat besar?

Karena pemrosesan bersifat lokal, penggabungan besar bergantung pada memori perangkat Anda, bukan pada kuota server. Sebagian besar file tergabung dalam hitungan detik; setumpuk PDF pindaian raksasa mungkin butuh waktu lebih lama di perangkat keras lawas.

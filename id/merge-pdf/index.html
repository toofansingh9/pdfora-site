Gabungkan PDF

Gabungkan dua PDF atau lebih menjadi satu file, dengan urutan yang Anda tentukan, tanpa mengunggah apa pun.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.
1

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Pilih opsi Anda — semuanya berlangsung di browser Anda.

3

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

Menggabungkan PDF adalah pekerjaan PDF yang paling sering dilakukan, sekaligus yang paling sering keliru: urutan file kacau, halaman yang seharusnya dibuang malah ikut terkirim ke klien, atau hasil gabungannya mendadak terlalu besar untuk dilampirkan ke email. Halaman ini menjelaskan apa persisnya yang dilakukan alat gabung PDF di PDFora terhadap file Anda, apa yang dipertahankan, apa yang tidak, dan cara menghindari kesalahan yang memaksa Anda mengulang dari awal.

Secara teknis, proses penggabungan menyalin objek halaman dari setiap PDF sumber ke dokumen baru, satu per satu secara berurutan. Teks tetap berupa teks asli (masih bisa diblok dan dicari), grafik vektor tetap vektor, dan gambar disalin sekali dalam resolusi aslinya. Tidak ada yang dirender ulang atau dikompres ulang, sehingga tampilan file gabungan sama persis dengan file aslinya, halaman demi halaman. Konsekuensinya, ukuran hasil kurang lebih sama dengan jumlah ukuran semua file masukan: tiga hasil scan berukuran 4 MB menjadi file sekitar 12 MB, selisihnya paling hanya beberapa kilobyte.

Semua proses berlangsung di dalam browser Anda menggunakan library pdf-lib. Dokumen dibaca dari perangkat ke memori, digabungkan di sana, lalu hasilnya langsung diberikan kepada Anda untuk diunduh. Tidak ada tahap unggah, jadi tidak ada antrean, tidak ada batas ukuran dari server, dan tidak ada file yang perlu kami hapus setelahnya.

Cara menggabungkan file PDF secara online

  1. Buka alat Gabungkan PDF, lalu seret semua file sekaligus ke kotak yang tersedia atau klik kotaknya untuk memilih file. File lain bisa ditambahkan belakangan.
  2. Seret baris-baris file sesuai urutan yang Anda inginkan. Baris paling atas menjadi halaman 1 pada hasil akhir. Gunakan pegangan di sisi kiri setiap baris untuk menyeretnya.
  3. Perhatikan ukuran yang tertera di samping nama setiap file. Jika totalnya mendekati batas lampiran, kompres dulu file yang paling besar (lihat contoh di bawah).
  4. Klik Gabungkan PDF. Bilah progres akan berjalan melewati setiap file; hasil scan yang besar butuh beberapa detik per file.
  5. Unduh merged.pdf, buka filenya, dan periksa bagian sambungan antardokumen sebelum Anda mengirimkannya.

Kapan menggunakan alat ini

  • Lamaran kerja: surat lamaran, CV, ijazah, dan sertifikat dijadikan satu lampiran, sesuai urutan yang diminta perusahaan.
  • Berkas pengajuan visa: scan paspor, pas foto, rekening koran, dan surat sponsor yang harus diunggah sebagai satu PDF.
  • Tutup buku bulanan: semua faktur dari satu pemasok selama periode itu dalam satu file untuk bagian akuntansi.
  • Bahan kuliah: handout dari beberapa pertemuan atau bab-bab skripsi disatukan menjadi satu dokumen yang enak dibaca.
  • Berkas properti dan hukum: perjanjian sewa, lampiran, dan halaman bertanda tangan yang dikumpulkan setelah setiap pihak mengembalikan bagiannya.
  • Hasil scan bertahap: sisi depan dan belakang yang di-scan sebagai file terpisah digabung agar halamannya berurutan (gunakan Selang-seling & gabungkan jika sisi belakang ada di file kedua dengan urutan terbalik).

Yang perlu diketahui sebelum mulai

  • Bookmark (panel daftar isi) tidak ikut terbawa. File gabungan tidak memiliki daftar isi meskipun file sumbernya punya. Jika perlu, tambahkan lagi dengan alat Tambahkan bookmark.
  • Kolom formulir yang bisa diisi dapat rusak saat dokumen digabung, terutama jika dua file memakai nama kolom yang sama. Jika formulir harus tetap bisa diisi, gabungkan hanya PDF yang tidak berisi formulir, atau ratakan dulu formulirnya lalu gabungkan salinan yang sudah diratakan.
  • File yang dilindungi kata sandi tidak bisa dibuka oleh alat penggabung. Hapus dulu kata sandinya (dengan memasukkan kata sandi tersebut, lewat alat Unlock setelah tersedia, atau di aplikasi yang membuat file itu), lalu coba lagi.
  • Ukuran halaman yang berbeda tetap dibiarkan apa adanya: surat ukuran A4, disusul scan ukuran US Letter, lalu tabel berorientasi lanskap akan tetap seperti itu. Gunakan Ubah ukuran halaman jika Anda ingin ukurannya seragam.
  • Tautan internal yang mengarah ke halaman lain dalam dokumen yang sama bisa tidak berfungsi lagi setelah digabung, karena nomor halaman tujuannya sudah berubah. Tautan ke situs web tidak terpengaruh.
  • File gabungan dibangun di memori browser Anda. Menggabungkan beberapa dokumen biasa berlangsung seketika, tetapi menggabungkan beberapa hasil scan berukuran ratusan megabyte bisa menghabiskan memori di ponsel atau laptop lama. Jika tab browser macet, lakukan di komputer desktop atau gabungkan dalam dua tahap.

Tips untuk hasil terbaik

  • Beri awalan angka pada nama file (01-surat-lamaran.pdf, 02-cv.pdf) sebelum menambahkannya; urutannya langsung terlihat dan tetap aman jika Anda harus mengulang.
  • Bereskan urutan sebelum mengklik Gabungkan. Mengubah urutan setelahnya berarti mengulang seluruh proses, karena file hasil tidak bisa di-undo.
  • Buang halaman yang tidak diperlukan dari file sumber terlebih dulu dengan Hapus halaman, lalu gabungkan salinan yang sudah bersih. Jauh lebih mudah daripada mencari halaman itu di dokumen hasil yang panjang.
  • Simpan file asli sampai Anda sudah membuka PDF gabungan dan memeriksa jumlah halamannya: angkanya harus sama dengan total halaman semua file sumber.
  • Jika salah satu sumber berupa hasil scan dan yang lain dokumen digital, pertimbangkan menjalankan OCR pada hasil scan itu terlebih dulu supaya seluruh file gabungan bisa dicari teksnya.

Contoh nyata: batas lampiran 10 MB

Misalkan Dimas, lulusan baru di Yogyakarta, melamar kerja lewat portal rekrutmen yang hanya menerima satu lampiran maksimal 10 MB. Ia punya surat lamaran (120 KB, digital), CV (300 KB, digital), dan tiga hasil scan ijazah serta sertifikat yang masing-masing sekitar 4 MB. Jika langsung digabung, hasilnya sekitar 12,4 MB dan unggahannya akan ditolak.

Masalahnya bukan pada dokumen digital; ukurannya kecil karena teksnya disimpan sebagai teks. Hasil scan-lah yang besar, karena setiap halamannya adalah foto. Jadi Dimas memproses setiap scan dengan Kompres PDF pada tingkat Disarankan terlebih dulu (scan satu halaman berukuran 4 MB biasanya turun menjadi kira-kira 0,5 sampai 1 MB), baru kemudian menggabungkan kelima file. Hasilnya sekitar 2 sampai 3,5 MB, ijazah dan sertifikatnya tetap terbaca jelas, sedangkan surat lamaran dan CV tetap berupa teks yang tajam dan bisa dicari karena sama sekali tidak tersentuh proses kompresi.

Urutan juga penting: surat lamaran di depan, CV kedua, lalu ijazah dan sertifikat sesuai urutan yang diminta di lowongan. Perekrut yang membuka file dari ponsel langsung melihat surat lamarannya, tanpa harus menggulir tiga halaman hasil scan lebih dulu.

Pemecahan masalah

Tombol gabung tidak bisa diklik
Alat ini butuh minimal dua file. Tambahkan PDF kedua, atau jika Anda hanya ingin mengatur ulang halaman dalam satu file, gunakan Atur Halaman.
Salah satu file tidak mau dimuat
Kemungkinan besar file itu dilindungi kata sandi atau rusak. Buka di aplikasi pembaca PDF: jika diminta kata sandi, hapus dulu proteksinya; jika sama sekali tidak bisa dibuka, perbaiki dengan Repair PDF lalu gabungkan salinan yang sudah diperbaiki.
PDF gabungan lebih besar daripada total file aslinya
Sedikit tambahan ukuran itu wajar, karena sumber daya bersama (font, profil warna) disalin sekali per file sumber, bukan dihilangkan duplikatnya. Jika hasilnya jauh lebih besar dari perkiraan, kemungkinan salah satu file berisi gambar beresolusi sangat tinggi; kompres file itu terlebih dulu.
Urutan halamannya salah
Urutan baris di daftar file adalah urutan hasil akhir. Seret baris ke posisi yang benar lalu gabungkan lagi; file unduhan hanya mengikuti urutan pada saat Anda mengklik Gabungkan.
Bookmark atau kolom formulir saya hilang
Itu memang perilakunya: penggabungan menyalin halaman, bukan daftar isi atau struktur formulir di tingkat dokumen. Tambahkan bookmark setelahnya dengan alat Tambahkan bookmark, dan ratakan formulir sebelum digabung jika formulir itu cukup untuk dibaca saja.
Tab browser macet saat memproses file besar
Memori perangkat Anda habis karena harus menampung semua file sumber sekaligus. Tutup tab lain, lakukan di komputer desktop, atau gabungkan dalam dua tahap (separuh pertama dulu, lalu sisanya bersama hasil tahap pertama).

Pertanyaan yang sering diajukan

Apakah menggabungkan PDF menurunkan kualitasnya?

Tidak. Halaman disalin, bukan dirender ulang. Teks tetap teks, gambar tetap dalam resolusi aslinya, dan hasil cetak dokumen gabungan sama persis dengan file sumbernya.

Apakah ada batas jumlah file atau halaman yang bisa digabung?

Alat ini tidak memasang batas. Batas praktisnya adalah memori perangkat Anda: ratusan halaman biasa tidak masalah, sedangkan banyak hasil scan yang sangat besar mungkin perlu digabung dalam dua tahap.

Bisakah saya menggabungkan PDF dengan ukuran atau orientasi halaman yang berbeda?

Bisa. Setiap halaman tetap memakai ukuran dan orientasinya sendiri di hasil akhir. Jika ingin semuanya seragam, proses file gabungan dengan Ubah ukuran halaman.

Apakah bookmark dan kolom formulir saya tetap ada?

Bookmark tidak ikut disalin dan kolom formulir bisa rusak. Tambahkan bookmark setelahnya dengan alat Tambahkan bookmark; ratakan formulir sebelum digabung, kecuali formulir itu harus tetap bisa diisi.

Bisakah saya menggabungkan PDF yang dilindungi kata sandi?

Tidak selama proteksinya masih aktif. Hapus kata sandinya dulu, baru gabungkan. Alat penggabung tidak pernah meminta atau menyimpan kata sandi.

Amankah menggabungkan dokumen rahasia di sini?

Proses penggabungan berjalan sepenuhnya di browser Anda dengan library pdf-lib; file tidak pernah diunggah. Begitu tab ditutup, tidak ada yang tersisa di mana pun selain di perangkat Anda sendiri.

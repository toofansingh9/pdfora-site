Edit Metadata

Atur Judul, Penulis, Subjek, dan Kata kunci yang tersimpan di dalam PDF, yaitu informasi yang ditampilkan oleh aplikasi pembaca, mesin pencari, dan pengelola file.

Setiap PDF menyimpan catatan kecil tentang dirinya sendiri, terpisah dari isi halamannya: judul, penulis, subjek, kata kunci, program yang membuatnya, serta tanggal dibuat dan diubah. Kebanyakan orang tidak pernah melihatnya, tetapi software lain membacanya. Tab browser dan banyak aplikasi pembaca PDF menampilkan judul yang tersimpan, bukan nama file; sistem manajemen dokumen mengindeks penulis dan kata kuncinya; dan file yang diekspor dari template bisa diam-diam bertuliskan “Microsoft Word - Document1” atau nama orang yang membuat template itu bertahun-tahun lalu.

Dengan alat ini Anda bisa mengetik Judul, Penulis, Subjek, dan Kata kunci (dipisahkan koma) yang baru, lalu menyimpannya ke kamus informasi dokumen. Hanya kolom yang Anda isi yang diubah; kolom kosong membiarkan nilai lama tetap ada. Tanggal perubahan diatur ke saat Anda menyimpan. Halamannya sendiri tidak disentuh, jadi teks, gambar, tautan, dan kolom formulir tetap seperti semula. Hasilnya diunduh sebagai namafile-meta.pdf.

Pengeditan dilakukan dengan library pdf-lib di browser Anda. Ada satu efek samping library ini yang perlu diketahui: saat menyimpan, ia juga mencatat dirinya sebagai Producer dan Creator serta memperbarui tanggal pembuatan. Jika tanggal pembuatan asli atau nama software pembuatnya penting, misalnya sebagai bukti, simpan file aslinya.

Cara mengedit metadata PDF

  1. Buka Edit Metadata dan pilih satu file PDF.
  2. Ketik Judul. Gunakan judul dokumen yang sebenarnya, misalnya “Laporan Tahunan 2025”, bukan nama filenya.
  3. Isi Penulis dan Subjek jika berguna bagi pembaca atau sistem dokumen Anda; biarkan kosong untuk mempertahankan nilai yang sudah ada.
  4. Masukkan kata kunci yang dipisahkan koma, misalnya “laporan tahunan, keuangan, 2025”. Spasi di sekitar koma akan dirapikan otomatis.
  5. Klik Simpan metadata, unduh filenya, lalu periksa di menu Properti Dokumen pada aplikasi pembaca Anda (sering lewat Ctrl+D atau Cmd+D).

Kapan menggunakan alat ini

  • Membetulkan laporan yang judulnya muncul sebagai “Untitled” atau “Document1” di tab browser atau hasil pencarian.
  • Mengganti nama mantan karyawan atau pembuat template di kolom Penulis sebelum dokumen dikirim keluar.
  • Memberi judul dan kata kunci yang seragam pada kumpulan peraturan sekolah sebelum diunggah ke situs web sekolah.
  • Menandai laporan hibah dengan kode proyek agar perpustakaan dokumen sebuah LSM bisa menemukannya lewat kata kunci.
  • Memberi judul yang layak pada ebook atau panduan, supaya aplikasi pembaca menampilkannya dengan nama itu, bukan nama file.
  • Menyiapkan dokumen untuk sistem arsip yang mewajibkan kolom Judul dan Penulis terisi.

Yang perlu diketahui sebelum mulai

  • Kolom kosong diabaikan, bukan dikosongkan. Alat ini tidak bisa dipakai untuk menghapus isi sebuah kolom; ia hanya bisa mengganti nilai dengan nilai lain yang tidak kosong. Mengetik satu spasi bukan solusi yang bisa diandalkan.
  • Hanya kamus informasi klasik yang diperbarui. Banyak PDF juga menyimpan blok metadata XMP. Aplikasi yang membaca XMP lebih dulu, termasuk sebagian sistem manajemen dokumen, mungkin masih menampilkan judul atau penulis lama sampai XMP ditulis ulang dengan editor PDF lengkap.
  • Producer dan Creator diisi dengan library pdf-lib, dan tanggal pembuatan serta perubahan diperbarui, apa pun nilai sebelumnya. Ini sifat bawaan library, bukan pilihan yang bisa diatur.
  • Metadata tidak sama dengan konten tersembunyi. Komentar, revisi sebelumnya, data formulir, layer, dan file tersemat tidak dihapus oleh alat ini. Gunakan Hapus anotasi atau Ratakan untuk itu, dan periksa hasilnya sebelum membagikan file yang sensitif.
  • Kata kunci disimpan sebagai daftar. Mesin pencari umumnya mengabaikan kolom kata kunci; kolom ini lebih berguna untuk perpustakaan dokumen internal dan pencarian di komputer. Beberapa istilah yang tepat lebih bermanfaat daripada daftar panjang.
  • File terenkripsi dibuka tanpa didekripsi, sehingga hasilnya bisa rusak. Hapus proteksinya di program pembuat file sebelum mengedit metadata.

Tips untuk hasil terbaik

  • Tulis judul seperti cara orang menyebutnya. “Buku Panduan Penghuni 2026” lebih baik daripada “panduan_penghuni_FINAL_v3”.
  • Untuk dokumen publik, isi Penulis dengan nama organisasi, bukan nama perorangan, agar file tidak cepat usang ketika orang berganti jabatan.
  • Edit metadata sebagai langkah terakhir. Alat lain yang dijalankan setelahnya bisa menulis ulang kolom seperti Producer dan tanggal.
  • Simpan salinan file asli jika tanggal pembuatan atau software pembuatnya suatu saat bisa menjadi penting, misalnya dalam sengketa.
  • Setelah menyimpan, ganti juga nama filenya dengan nama yang masuk akal; aplikasi pembaca berbeda-beda, ada yang menampilkan judul, ada yang menampilkan nama file.

Contoh: dokumen peraturan sebuah sekolah

Tata usaha sebuah SMP swasta di Semarang sedang mengunggah 14 PDF tata tertib dan peraturan sekolah ke situs web barunya. Saat orang tua murid membukanya, tab browser menampilkan tulisan seperti “Microsoft Word - Template_2019”, dan kolom Penulis masih berisi nama guru yang sudah lama pindah.

Bu Wulan, kepala tata usaha, memproses setiap file dengan Edit Metadata: Judul diisi nama peraturannya (“Kebijakan Anti-Perundungan, ditinjau September 2026”), Penulis diisi nama sekolah, Subjek “Peraturan sekolah”, dan kata kunci seperti “peraturan, perlindungan anak, orang tua”. Setiap file selesai kurang dari semenit, dan halamannya tidak berubah.

Saat memeriksa hasilnya, ia melihat satu PDF masih menampilkan judul lama di aplikasi pembaca tertentu. File itu ternyata berisi blok metadata XMP yang tidak ditulis ulang oleh alat ini. Ia lalu mengekspor ulang file tersebut dari pengolah kata aslinya dengan judul dokumen yang benar diatur di sana, dan masalahnya hilang.

Untuk file-file lainnya, ia juga mengganti nama setiap unduhan agar sesuai dengan judul barunya, misalnya kebijakan-anti-perundungan-2026.pdf, sehingga nama file dan judul yang tersimpan selalu sama, mana pun yang ditampilkan browser orang tua murid.

Pemecahan masalah

Judul lama masih muncul di aplikasi pembaca saya
Kemungkinan aplikasi membaca blok metadata XMP, yang tidak diperbarui oleh alat ini. Ekspor ulang dari program sumber dengan judul yang benar, atau gunakan editor PDF lengkap untuk memperbarui XMP.
Saya mengosongkan sebuah kolom tetapi nilai lamanya masih ada
Begitulah cara kerja alat ini: kolom kosong dilewati. Untuk mengubah nilai, ketik nilai yang baru.
Tanggal pembuatannya berubah
Library pdf-lib memperbarui tanggal pembuatan dan perubahan saat menyimpan. Simpan file asli jika tanggal aslinya penting.
Kolom Producer sekarang bertuliskan pdf-lib
Library ini menulis namanya sendiri di Producer dan Creator. Hal ini tidak memengaruhi tampilan maupun hasil cetak dokumen.
Tab browser masih menampilkan nama file
Sebagian browser dan aplikasi pembaca hanya menampilkan judul tersimpan jika PDF memintanya, sedangkan yang lain selalu menampilkan nama file. Ganti juga nama filenya.
File hasilnya tidak bisa dibuka
Kemungkinan file sumbernya terenkripsi. Hapus kata sandinya di program yang membuatnya, lalu edit salinan yang sudah tidak terproteksi.

Pertanyaan yang sering diajukan

Apa itu metadata PDF?

Sekumpulan kecil kolom yang tersimpan di dalam file, seperti Judul, Penulis, Subjek, Kata kunci, Producer, dan tanggal. Metadata menjelaskan dokumen, tetapi tidak tampil di halamannya.

Bisakah saya menghapus semua metadata dari PDF?

Tidak dengan alat ini. Alat ini bisa mengganti Judul, Penulis, Subjek, dan Kata kunci dengan nilai baru, tetapi tidak bisa mengosongkannya atau menghapus blok XMP.

Apakah mengedit metadata mengubah isi halaman?

Tidak. Teks, gambar, tautan, dan formulir tetap persis seperti semula. Yang berubah hanya kolom informasi dan tanggalnya.

Apakah metadata PDF membantu peringkat di Google?

Mesin pencari bisa memakai Judul yang tersimpan saat menampilkan PDF di hasil pencarian, jadi judul yang jelas membantu orang mengenali filenya. Kolom kata kunci hampir tidak berpengaruh pada pencarian web.

Bisakah saya melihat metadata yang ada sebelum mengubahnya?

Jendela Properti Dokumen di aplikasi pembaca PDF Anda menampilkannya; alat ini tidak menampilkan nilai yang sudah ada. Di kebanyakan aplikasi desktop, letaknya di menu File, lalu Properties, pada tab Description, yang memuat judul, penulis, subjek, kata kunci, producer, dan kedua tanggal.

Bisakah saya mengedit metadata beberapa file sekaligus?

Tidak. Proses file satu per satu; setiap file hanya butuh beberapa detik.

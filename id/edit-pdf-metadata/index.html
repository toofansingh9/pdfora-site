Edit Metadata

Atur Judul, Penulis, Subjek, dan Kata kunci yang tersimpan di dalam PDF, yaitu informasi yang ditampilkan oleh aplikasi pembaca, mesin pencari, dan pengelola file.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.
1

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Pilih opsi Anda — semuanya berlangsung di browser Anda.

3

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

Coba buka PDF hasil ekspor dari template, lalu lihat tulisan di tab browser. Sering yang muncul bukan judul dokumennya, melainkan “Microsoft Word - Document1”, “Desain tanpa judul”, atau nama orang yang membuat template itu bertahun-tahun lalu. Tulisan itu berasal dari metadata, yaitu catatan kecil yang disimpan PDF tentang dirinya sendiri, terpisah dari isi halaman: judul, penulis, subjek, kata kunci, program pembuatnya, serta tanggal dibuat dan diubah. Pembaca jarang memperhatikannya, tetapi software membacanya: tab browser dan banyak aplikasi pembaca PDF menampilkan judul tersimpan alih-alih nama file, dan sistem manajemen dokumen mengindeks penulis serta kata kuncinya.

Dengan Edit Metadata, Anda mengetik Judul, Penulis, Subjek, dan Kata kunci (pisahkan dengan koma) yang baru, lalu menyimpannya ke kamus informasi dokumen. Hanya kolom yang Anda isi yang berubah; kolom yang dibiarkan kosong tetap memakai nilai lamanya. Tanggal perubahan diatur ke waktu Anda menyimpan. Isi halaman tidak disentuh sama sekali, sehingga teks, gambar, tautan, dan kolom formulir tetap seperti semula. Hasilnya diunduh sebagai namafile-meta.pdf.

Semua pengeditan berjalan di browser Anda dengan library pdf-lib. Ada satu efek samping yang perlu diketahui: saat menyimpan, library ini mencatat dirinya sebagai Producer dan Creator serta memperbarui tanggal pembuatan. Kalau tanggal pembuatan asli atau nama software pembuatnya penting, misalnya sebagai bukti, simpan file aslinya.

Cara mengedit metadata PDF

  1. Buka Edit Metadata dan pilih satu file PDF.
  2. Ketik Judul. Gunakan judul dokumen yang sebenarnya, misalnya “Laporan Tahunan 2025”, bukan nama filenya.
  3. Isi Penulis dan Subjek jika berguna bagi pembaca atau sistem dokumen Anda; biarkan kosong untuk mempertahankan nilai yang sudah ada.
  4. Masukkan kata kunci yang dipisahkan koma, misalnya “laporan tahunan, keuangan, 2025”. Spasi di sekitar koma akan dirapikan otomatis.
  5. Klik Simpan metadata, unduh filenya, lalu periksa di menu Properti Dokumen pada aplikasi pembaca Anda (sering lewat Ctrl+D atau Cmd+D).

Kapan menggunakan alat ini

  • Merapikan judul ebook, modul les, atau katalog jualan yang muncul sebagai “Desain tanpa judul” atau “Document1” di HP pembeli.
  • Mengganti nama pribadi atau nama mantan karyawan di kolom Penulis dengan nama usaha atau instansi sebelum file dibagikan.
  • Memberi judul dan kata kunci yang seragam pada kumpulan tata tertib sekolah sebelum diunggah ke situs sekolah.
  • Menandai laporan kegiatan atau laporan hibah dengan kode proyek agar mudah dicari di arsip dokumen organisasi.
  • Memberi judul yang layak pada skripsi atau jurnal sebelum diunggah ke repositori kampus.
  • Menyiapkan dokumen untuk sistem arsip yang mewajibkan kolom Judul dan Penulis terisi.

Yang perlu diketahui sebelum mulai

  • Kolom kosong diabaikan, bukan dikosongkan. Alat ini tidak bisa dipakai untuk menghapus isi sebuah kolom; ia hanya bisa mengganti nilai dengan nilai lain yang tidak kosong. Mengetik satu spasi bukan solusi yang bisa diandalkan.
  • Hanya kamus informasi klasik yang diperbarui. Banyak PDF juga menyimpan blok metadata XMP. Aplikasi yang membaca XMP lebih dulu, termasuk sebagian sistem manajemen dokumen, mungkin masih menampilkan judul atau penulis lama sampai XMP ditulis ulang dengan editor PDF lengkap.
  • Producer dan Creator diisi dengan library pdf-lib, dan tanggal pembuatan serta perubahan diperbarui, apa pun nilai sebelumnya. Ini sifat bawaan library, bukan pilihan yang bisa diatur.
  • Metadata tidak sama dengan konten tersembunyi. Komentar, revisi sebelumnya, data formulir, layer, dan file tersemat tidak dihapus oleh alat ini. Gunakan Hapus Anotasi atau Ratakan PDF untuk itu, dan periksa hasilnya sebelum membagikan file yang sensitif.
  • Kata kunci disimpan sebagai daftar. Mesin pencari umumnya mengabaikan kolom kata kunci; kolom ini lebih berguna untuk perpustakaan dokumen internal dan pencarian di komputer. Beberapa istilah yang tepat lebih bermanfaat daripada daftar panjang.
  • File terenkripsi dibuka tanpa didekripsi, sehingga hasilnya bisa rusak. Hapus proteksinya di program pembuat file atau dengan Buka Kunci PDF jika Anda tahu kata sandinya, sebelum mengedit metadata.

Tips untuk hasil terbaik

  • Tulis judul seperti cara orang menyebutnya. “Buku Panduan Penghuni 2026” lebih baik daripada “panduan_penghuni_FINAL_v3”.
  • Untuk dokumen publik, isi Penulis dengan nama organisasi, bukan nama perorangan, agar file tidak cepat usang ketika orang berganti jabatan.
  • Edit metadata sebagai langkah terakhir. Alat lain yang dijalankan setelahnya bisa menulis ulang kolom seperti Producer dan tanggal.
  • Simpan salinan file asli jika tanggal pembuatan atau software pembuatnya suatu saat bisa menjadi penting, misalnya dalam sengketa.
  • Setelah menyimpan, ganti juga nama filenya dengan nama yang masuk akal; aplikasi pembaca berbeda-beda, ada yang menampilkan judul, ada yang menampilkan nama file.

Contoh: penjual ebook resep merapikan file jualannya

Mbak Sinta menjual ebook resep MPASI dalam bentuk PDF lewat tautan di bio Instagram-nya. Ebook itu ia susun di Canva, dan seorang pembeli mengirim tangkapan layar: di HP pembeli, judul yang muncul adalah “Desain tanpa judul (3)”. Saat Mbak Sinta memeriksa Properti Dokumen, kolom Penulis ternyata juga berisi nama lengkap pribadinya, yang sebenarnya tidak ingin ia tampilkan.

Di Edit Metadata, ia mengisi Judul “Buku Resep MPASI 8–12 Bulan”, Subjek “Resep makanan pendamping ASI”, dan kata kunci “MPASI, resep bayi, menu 8 bulan”. Awalnya kolom Penulis ia kosongkan dengan harapan nama pribadinya terhapus. Setelah dicek, nama itu masih ada, karena kolom kosong memang dilewati, bukan dihapus.

Ia lalu mengetik nama usahanya, “Dapur Sinta”, di kolom Penulis dan menyimpan ulang. Kini Properti Dokumen menampilkan judul dan penulis yang benar. Kolom Producer berubah menjadi pdf-lib, tetapi itu tidak memengaruhi tampilan ebook sama sekali.

Terakhir, ia mengganti nama file unduhan menjadi buku-resep-mpasi-8-12-bulan.pdf. Dengan begitu, baik aplikasi yang menampilkan judul tersimpan maupun yang menampilkan nama file sama-sama menunjukkan nama yang rapi. File hasil ekspor Canva yang asli tetap ia simpan untuk edisi revisi berikutnya.

Pemecahan masalah

Judul lama masih muncul di aplikasi pembaca saya
Kemungkinan aplikasi membaca blok metadata XMP, yang tidak diperbarui oleh alat ini. Ekspor ulang dari program sumber dengan judul yang benar, atau gunakan editor PDF lengkap untuk memperbarui XMP.
Saya mengosongkan sebuah kolom tetapi nilai lamanya masih ada
Begitulah cara kerja alat ini: kolom kosong dilewati. Untuk mengubah nilai, ketik nilai yang baru.
Tanggal pembuatannya berubah
Library pdf-lib memperbarui tanggal pembuatan dan perubahan saat menyimpan. Simpan file asli jika tanggal aslinya penting.
Kolom Producer sekarang bertuliskan pdf-lib
Library ini menulis namanya sendiri di Producer dan Creator. Hal ini tidak memengaruhi tampilan maupun hasil cetak dokumen.
Tab browser masih menampilkan nama file
Sebagian browser dan aplikasi pembaca hanya menampilkan judul tersimpan jika PDF memintanya, sedangkan yang lain selalu menampilkan nama file. Ganti juga nama filenya.
File hasilnya tidak bisa dibuka
Kemungkinan file sumbernya terenkripsi. Hapus kata sandinya di program yang membuatnya atau dengan Buka Kunci PDF jika Anda tahu kata sandinya, lalu edit salinan yang sudah tidak terproteksi.

Pertanyaan yang sering diajukan

Metadata PDF itu sebenarnya apa?

Sekumpulan kecil kolom yang tersimpan di dalam file, seperti Judul, Penulis, Subjek, Kata kunci, Producer, dan tanggal. Metadata menjelaskan dokumennya, tetapi tidak terlihat di halaman.

Bisa hapus semua metadata dari PDF?

Tidak dengan alat ini. Edit Metadata bisa mengganti Judul, Penulis, Subjek, dan Kata kunci dengan nilai baru, tetapi tidak bisa mengosongkannya atau menghapus blok XMP.

Isi halaman berubah kalau metadatanya diedit?

Tidak. Teks, gambar, tautan, dan formulir tetap persis seperti semula. Yang berubah hanya kolom informasi dan tanggalnya.

Metadata berpengaruh ke peringkat di Google, nggak?

Mesin pencari bisa memakai Judul yang tersimpan saat menampilkan PDF di hasil pencarian, jadi judul yang jelas membantu orang mengenali filenya. Kolom kata kunci hampir tidak berpengaruh pada pencarian web.

Bagaimana cara melihat metadata yang sekarang sebelum diubah?

Buka jendela Properti Dokumen di aplikasi pembaca PDF Anda; alat ini sendiri tidak menampilkan nilai yang sudah ada. Di kebanyakan aplikasi desktop, letaknya di menu File, lalu Properties, pada tab Description, yang memuat judul, penulis, subjek, kata kunci, producer, dan kedua tanggal.

Bisa edit metadata banyak file sekaligus?

Tidak. Proses file satu per satu; masing-masing hanya butuh beberapa detik.

Alur Kerja

Rangkai beberapa alat PDF menjadi satu urutan dan jalankan pada sebuah file dalam sekali proses, dengan pengaturan bawaan setiap alat.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.
1

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Pilih opsi Anda — semuanya berlangsung di browser Anda.

3

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

Coba hitung berapa kali seminggu Anda mengulang rangkaian yang sama: buka satu alat, unduh hasilnya, unggah lagi ke alat berikutnya, unduh lagi. Kontrak hasil scan perlu diluruskan, diberi nomor halaman, lalu diberi watermark. Laporan yang mau dikirim perlu kolom formulirnya diratakan, komentarnya dibersihkan, dan ukurannya diperkecil. Setiap putaran meninggalkan satu file perantara di folder Unduhan. Alur Kerja memangkas semua itu: Anda menyusun daftar langkah, meletakkan satu PDF, dan menerima satu file jadi bernama namafile-workflow.pdf.

Dua belas alat bisa dimasukkan ke dalam rangkaian: Kompres, Skala abu-abu, Putar 90°, Watermark, Nomor halaman, Pangkas margin, Ubah ke A4, Ratakan, Perbaiki, Hapus anotasi, Balik, dan Perbarui metadata. Langkah dijalankan dari atas ke bawah, dan hasil satu langkah langsung menjadi bahan langkah berikutnya. Tombol ↑ menaikkan sebuah langkah, tombol ✕ menghapusnya, dan alat yang sama boleh dipasang lebih dari sekali.

Kepraktisan ini ada konsekuensinya: tidak ada pengaturan untuk masing-masing langkah. Setiap alat berjalan dengan pengaturan bawaannya, yang dirinci di bawah, sehingga alur kerja hanya berguna kalau pengaturan bawaan itu memang yang Anda butuhkan. Teks watermark khusus atau arah putar yang lain harus dikerjakan di alatnya sendiri. Untungnya, untuk urusan kantor sehari-hari, pengaturan bawaan biasanya sudah pas: tanda kerahasiaan standar, nomor halaman sederhana, halaman A4, dan kompresi yang seimbang.

Cara menjalankan beberapa alat PDF sekaligus

  1. Buka Alur Kerja. Pilih alat dari daftar 'Tambah langkah…' lalu klik Tambah. Ulangi untuk setiap langkah.
  2. Periksa urutannya. Langkah berjalan dari nomor 1 ke bawah; gunakan ↑ untuk memajukan sebuah langkah dan ✕ untuk menghapusnya.
  3. Letakkan satu PDF di kotak di bawah daftar langkah, atau klik kotak itu untuk memilih file.
  4. Perhatikan baris status: tertulis 'Langkah 2/4: Watermark…' dan seterusnya selama setiap alat berjalan.
  5. Saat muncul 'Selesai', buka file -workflow.pdf yang terunduh dan pastikan setiap langkah bekerja sesuai harapan.

Kapan menggunakan alat ini

  • Tata usaha sekolah atau kampus yang mengarsipkan formulir hasil scan: menyamakan ukuran ke A4, memberi nomor halaman, lalu mengecilkan file.
  • Pemilik usaha kecil yang membubuhkan 'CONFIDENTIAL' dan nomor halaman pada surat penawaran sebelum dikirim ke calon klien.
  • Menyiapkan hasil scan untuk portal pendaftaran atau sistem administrasi yang meminta file kecil: Skala abu-abu lalu Kompres.
  • Staf kantor yang membersihkan komentar pemeriksa dan meratakan formulir yang sudah diisi sebelum dokumen masuk arsip.
  • Membetulkan tumpukan hasil scan yang semuanya miring ke arah yang sama: putar setiap halaman, lalu kompres hasilnya.
  • Memasang Perbaiki sebagai langkah pertama untuk file dari aplikasi lama yang kadang ditolak alat lain.

Yang perlu diketahui sebelum mulai

  • Pengaturan bawaannya tetap: Kompres memakai tingkat Disarankan; Putar memutar semua halaman 90° searah jarum jam; Watermark menulis 'CONFIDENTIAL' pada 50 pt, opasitas 30%, secara diagonal; Nomor halaman memasang angka 1, 2, 3 di tengah bawah dengan ukuran 11 pt, mulai dari 1; Pangkas margin membuang 30 poin (sekitar 10,5 mm) dari setiap sisi; Ubah ke A4 menyesuaikan halaman ke A4; Balik mencerminkan secara horizontal.
  • Kompres, Skala abu-abu, dan Balik menggambar ulang setiap halaman sebagai gambar JPEG. Langkah apa pun sesudahnya bekerja pada gambar halaman, dan file akhirnya tidak punya teks yang bisa diseleksi, tautan, atau kolom formulir. Taruh langkah-langkah ini paling akhir, kecuali memang itu yang Anda mau.
  • Perbarui metadata tanpa nilai apa pun hanya memperbarui tanggal modifikasi file. Judul atau penulis tidak berubah, karena di alur kerja tidak ada tempat untuk mengetiknya.
  • Hanya satu PDF yang bisa diproses per jalan. Untuk memperlakukan beberapa file dengan cara yang sama, letakkan satu per satu; daftar langkah tetap tersedia di antara proses.
  • Daftar langkah tidak disimpan. Memuat ulang atau menutup halaman akan menghapusnya, jadi catat alur kerja yang rutin Anda pakai. Dengan begitu, alur kerja tetap praktis untuk selusin file serupa, meskipun setiap file tetap harus diletakkan secara manual.
  • Jika ada langkah yang gagal, proses berhenti dengan error dari langkah itu dan tidak ada yang diunduh. Hasil langkah-langkah sebelumnya tidak disimpan terpisah.

Tips untuk hasil terbaik

  • Jalankan Perbaiki lebih dulu jika sebuah file pernah bermasalah di alat lain, agar setiap langkah berikutnya menerima dokumen yang sudah dibangun ulang dengan bersih.
  • Urutan penting untuk stempel: taruh Nomor halaman dan Watermark setelah Ubah ke A4 dan Pangkas margin, jika tidak stempelnya bisa mengecil atau terpotong oleh langkah berikutnya.
  • Taruh Ratakan sebelum Kompres. Kompres memang mengubah halaman menjadi gambar, tetapi meratakan lebih dulu memastikan isian formulir benar-benar terlihat di gambar itu.
  • Uji alur kerja baru pada file pendek sebelum menjalankan dokumen 200 halaman. Dua atau tiga halaman sudah cukup untuk melihat apakah stempel berada di tempat yang diharapkan dan kualitas setelah kompresi masih bisa diterima.
  • Menambahkan Putar 90° dua kali memberi putaran 180°; tiga kali sama dengan 90° berlawanan arah jarum jam.

Contoh: tata usaha sekolah mengarsipkan formulir hasil scan

Bu Ratna mengurus tata usaha di sebuah SMA di Palembang. Setiap akhir semester ia mengarsipkan formulir dan surat keterangan yang sudah diisi, dan tahun ini ada 15 file hasil scan. Sebagian besar dokumennya dicetak di kertas F4, sementara folder arsip digital sekolah memakai A4, file harus bernomor halaman, berwarna abu-abu, dan cukup kecil untuk disimpan di drive bersama. Mengerjakan empat alat satu per satu untuk setiap file berarti 60 kali proses.

Ia menyusun alur kerja: 1 Ubah ke A4, 2 Nomor halaman, 3 Skala abu-abu, 4 Kompres. Ukuran halaman disamakan lebih dulu supaya nomor halaman jatuh di posisi yang benar pada lembar A4; Skala abu-abu dan Kompres ditaruh paling belakang karena keduanya menggambar ulang halaman sebagai gambar. Daftar langkahnya tetap terpasang di antara proses, jadi setelah file pertama selesai, ia tinggal meletakkan file berikutnya. Kelima belas file selesai dalam satu sesi, masing-masing keluar dengan nama seperti formulir-kelas-x-workflow.pdf.

Ada yang perlu ia terima: halaman F4 lebih panjang daripada A4, jadi Ubah ke A4 mengecilkan isinya agar muat dan menyisakan pita putih tipis di kiri dan kanan. Untuk arsip, itu tidak masalah. Karena semua file memang hasil scan, langkah Kompres juga tidak menghilangkan teks yang bisa diseleksi, sebab sejak awal memang tidak ada teks seperti itu. Untuk dokumen ketikan yang masih perlu dicari isinya, Bu Ratna akan menghapus dua langkah terakhir.

Pemecahan masalah

'Tambahkan minimal satu langkah terlebih dahulu'
Daftar langkah kosong. Pilih alat di daftar 'Tambah langkah…' lalu klik Tambah sebelum meletakkan PDF.
Watermark atau nomor halaman berada di tempat yang salah
Ada langkah sesudahnya yang mengubah ukuran atau bentuk halaman. Pindahkan Ubah ke A4, Pangkas margin, dan Putar ke atas Watermark dan Nomor halaman dengan tombol ↑, lalu jalankan lagi.
Teks saya tidak bisa diseleksi lagi
Ada Kompres, Skala abu-abu, atau Balik di dalam rangkaian; langkah-langkah ini menghasilkan halaman berupa gambar saja. Hapus, atau pindahkan ke akhir dan terima halaman berupa gambar di hasilnya.
Proses berhenti di satu langkah dengan error
Alat itu tidak bisa memproses file pada tahap tersebut, sering karena file dikunci kata sandi atau rusak. Tambahkan Perbaiki sebagai langkah 1 atau betulkan file lebih dulu, lalu jalankan alur kerjanya lagi. Baris status menyebutkan langkah yang gagal, jadi Anda tahu alat mana yang perlu diuji sendiri.
Langkah-langkah saya hilang
Daftarnya hanya ada selama halaman terbuka. Susun ulang; simpan catatan singkat urutannya untuk alur kerja yang sering Anda ulangi.
Saya butuh teks watermark atau rotasi yang berbeda
Alur Kerja selalu memakai pengaturan bawaan. Jalankan alat Watermark atau Putar PDF secara terpisah dengan pengaturan Anda, lalu gunakan Alur Kerja untuk langkah-langkah sisanya.

Pertanyaan yang sering diajukan

Pengaturan tiap langkah bisa saya ubah sendiri?

Tidak. Setiap langkah memakai pengaturan bawaan alatnya. Kalau butuh opsi khusus, jalankan alat itu secara terpisah.

Bisa dipakai untuk banyak PDF sekaligus?

Tidak dalam sekali jalan. Alur kerja memproses satu file setiap kali, tetapi daftar langkahnya tetap siap, jadi file berikutnya bisa langsung diletakkan.

Rangkaian langkahnya bisa disimpan untuk dipakai besok?

Untuk saat ini belum. Daftar langkah hanya bertahan selama halaman masih terbuka, jadi catat urutannya kalau sering dipakai.

Kenapa tidak semua alat bisa dijadikan langkah?

Sebuah langkah harus menerima satu PDF dan mengembalikan satu PDF. Alat yang butuh beberapa file, menghasilkan ZIP, mengekspor gambar atau teks, atau memerlukan konversi di server tidak bisa dirangkai.

Apakah file saya dikirim ke server selama proses?

Tidak. Kedua belas alat yang bisa dirangkai berjalan di tab browser Anda; PDF berpindah dari langkah ke langkah di memori, dan hanya hasil akhirnya yang diunduh.

Apa jadinya kalau alat yang sama saya pasang dua kali?

Alat itu dijalankan dua kali. Dua langkah Putar memutar halaman 180°, sedangkan dua langkah Kompres biasanya hanya menambah sedikit penghematan tetapi menurunkan kualitas lebih jauh.

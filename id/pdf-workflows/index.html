Alur Kerja

Rangkai beberapa alat PDF menjadi satu urutan dan jalankan pada sebuah file dalam sekali proses, dengan pengaturan bawaan setiap alat.

🔒 File Anda diproses secara lokal di browser dan tidak pernah diunggah.
1

Unggah

Pilih file Anda atau seret dan lepas.

2

Sesuaikan

Pilih opsi Anda — semuanya berlangsung di browser Anda.

3

Unduh

Simpan file yang selesai secara instan. Tanpa watermark.

Sebagian pekerjaan PDF selalu datang dalam kombinasi yang sama. Kontrak hasil scan perlu diluruskan, diberi nomor halaman, dan diberi watermark; laporan yang akan dikirim perlu kolom formulirnya diratakan, komentarnya dibuang, dan ukuran filenya diperkecil. Mengerjakannya satu alat demi satu alat berarti mengunduh dan mengunggah ulang file tiga atau empat kali, dengan file perantara di setiap putaran. Workflows merangkai langkah-langkah itu: Anda menyusun daftar, meletakkan PDF, dan mendapat satu file jadi bernama namafile-workflow.pdf.

Ada dua belas alat yang bisa dirangkai: Kompres, Skala abu-abu, Putar 90°, Watermark, Nomor halaman, Pangkas margin, Ubah ke A4, Ratakan, Perbaiki, Hapus anotasi, Balik, dan Perbarui metadata. Semuanya berjalan dari atas ke bawah, dan hasil setiap langkah menjadi masukan bagi langkah berikutnya. Anda bisa menaikkan sebuah langkah dengan tombol ↑ atau menghapusnya dengan ✕, dan menambahkan alat yang sama lebih dari sekali.

Imbalan dari kecepatan ini adalah tidak adanya pengaturan per langkah. Setiap langkah memakai pengaturan bawaan alatnya, yang dirinci di bawah, jadi alur kerja hanya berguna jika pengaturan bawaan itu memang yang Anda inginkan. Jika butuh teks watermark khusus atau rotasi yang berbeda, jalankan alat itu secara terpisah. Dalam praktiknya, pengaturan bawaan cocok untuk pekerjaan kantor rutin: tanda kerahasiaan standar, nomor halaman sederhana, hasil berukuran A4, dan tingkat kompresi yang seimbang.

Cara menjalankan beberapa alat PDF sekaligus

  1. Buka Workflows. Pilih alat dari daftar 'Tambah langkah…' lalu klik Tambah. Ulangi untuk setiap langkah.
  2. Periksa urutannya. Langkah berjalan dari nomor 1 ke bawah; gunakan ↑ untuk memajukan sebuah langkah dan ✕ untuk menghapusnya.
  3. Letakkan satu PDF di kotak di bawah daftar langkah, atau klik kotak itu untuk memilih file.
  4. Perhatikan baris status: tertulis 'Langkah 2/4: Watermark…' dan seterusnya selama setiap alat berjalan.
  5. Saat muncul 'Selesai', buka file -workflow.pdf yang terunduh dan pastikan setiap langkah bekerja sesuai harapan.

Kapan menggunakan alat ini

  • Usaha kecil yang membubuhkan 'CONFIDENTIAL' pada surat penawaran dan memberi nomor halaman sebelum dikirim ke klien.
  • Kantor yang membersihkan komentar pemeriksa dan meratakan formulir yang sudah diisi sebelum diarsipkan.
  • Menyiapkan hasil scan untuk portal yang meminta file abu-abu berukuran kecil: Skala abu-abu lalu Kompres.
  • Menyeragamkan dokumen beragam ukuran menjadi A4 dan menambahkan nomor halaman agar tercetak konsisten.
  • Membetulkan tumpukan hasil scan yang miring, di mana setiap halaman perlu diputar dan hasilnya perlu dikompres.
  • Menjalankan Perbaiki sebagai langkah pertama untuk file dari sistem lama yang kadang ditolak alat lain.

Yang perlu diketahui sebelum mulai

  • Pengaturan bawaannya tetap: Kompres memakai tingkat Disarankan; Putar memutar semua halaman 90° searah jarum jam; Watermark menulis 'CONFIDENTIAL' pada 50 pt, opasitas 30%, secara diagonal; Nomor halaman memasang angka 1, 2, 3 di tengah bawah dengan ukuran 11 pt, mulai dari 1; Pangkas margin membuang 30 poin (sekitar 10,5 mm) dari setiap sisi; Ubah ke A4 menyesuaikan halaman ke A4; Balik mencerminkan secara horizontal.
  • Kompres, Skala abu-abu, dan Balik menggambar ulang setiap halaman sebagai gambar JPEG. Langkah apa pun sesudahnya bekerja pada gambar halaman, dan file akhirnya tidak punya teks yang bisa diseleksi, tautan, atau kolom formulir. Taruh langkah-langkah ini paling akhir, kecuali memang itu yang Anda mau.
  • Perbarui metadata tanpa nilai apa pun hanya memperbarui tanggal modifikasi file. Judul atau penulis tidak berubah, karena di alur kerja tidak ada tempat untuk mengetiknya.
  • Hanya satu PDF yang bisa diproses per jalan. Untuk memperlakukan beberapa file dengan cara yang sama, letakkan satu per satu; daftar langkah tetap tersedia di antara proses.
  • Daftar langkah tidak disimpan. Memuat ulang atau menutup halaman akan menghapusnya, jadi catat alur kerja yang rutin Anda pakai. Dengan begitu, alur kerja tetap praktis untuk selusin file serupa, meskipun setiap file tetap harus diletakkan secara manual.
  • Jika ada langkah yang gagal, proses berhenti dengan error dari langkah itu dan tidak ada yang diunduh. Hasil langkah-langkah sebelumnya tidak disimpan terpisah.

Tips untuk hasil terbaik

  • Jalankan Perbaiki lebih dulu jika sebuah file pernah bermasalah di alat lain, agar setiap langkah berikutnya menerima dokumen yang sudah dibangun ulang dengan bersih.
  • Urutan penting untuk stempel: taruh Nomor halaman dan Watermark setelah Ubah ke A4 dan Pangkas margin, jika tidak stempelnya bisa mengecil atau terpotong oleh langkah berikutnya.
  • Taruh Ratakan sebelum Kompres. Kompres memang mengubah halaman menjadi gambar, tetapi meratakan lebih dulu memastikan isian formulir benar-benar terlihat di gambar itu.
  • Uji alur kerja baru pada file pendek sebelum menjalankan dokumen 200 halaman. Dua atau tiga halaman sudah cukup untuk melihat apakah stempel berada di tempat yang diharapkan dan kualitas setelah kompresi masih bisa diterima.
  • Menambahkan Putar 90° dua kali memberi putaran 180°; tiga kali sama dengan 90° berlawanan arah jarum jam.

Contoh: staf kantor hukum menyiapkan salinan dokumen untuk pihak lawan

Seorang staf kantor hukum harus mengirim satu set perjanjian yang sudah ditandatangani kepada pihak lawan. Setiap dokumen harus berukuran A4, bernomor halaman, bertanda rahasia, bersih dari komentar review internal, dan cukup kecil untuk dikirim lewat email. Ada sembilan file, jadi menjalankan empat alat secara manual untuk masing-masing berarti 36 kali proses terpisah.

Alur kerjanya disusun begini: 1 Hapus anotasi, 2 Ubah ke A4, 3 Watermark, 4 Nomor halaman, 5 Kompres. Komentar dibuang paling awal agar tidak ikut terpanggang ke dalam gambar nanti; pengubahan ukuran dilakukan sebelum stempel agar posisinya sesuai A4; Kompres paling akhir karena mengubah setiap halaman menjadi gambar. Setiap perjanjian cukup diletakkan sekali dan keluar sebagai, misalnya, perjanjian-pasokan-workflow.pdf. Sembilan file hanya memakan beberapa menit secara keseluruhan, sebagian besar di langkah Kompres yang merender setiap halaman.

Ada satu hal yang perlu diperhatikan: karena Kompres ada di dalam rangkaian, salinan yang dikirim tidak lagi bisa dicari teksnya. Itu cocok untuk salinan yang memang tidak boleh mudah diedit, tetapi jika pihak lawan perlu mencari di dalamnya, hapus langkah 5 dan kompres hanya file yang terlalu besar untuk dikirim lewat email.

Pemecahan masalah

'Tambahkan minimal satu langkah terlebih dahulu'
Daftar langkah kosong. Pilih alat di daftar 'Tambah langkah…' lalu klik Tambah sebelum meletakkan PDF.
Watermark atau nomor halaman berada di tempat yang salah
Ada langkah sesudahnya yang mengubah ukuran atau bentuk halaman. Pindahkan Ubah ke A4, Pangkas margin, dan Putar ke atas Watermark dan Nomor halaman dengan tombol ↑, lalu jalankan lagi.
Teks saya tidak bisa diseleksi lagi
Ada Kompres, Skala abu-abu, atau Balik di dalam rangkaian; langkah-langkah ini menghasilkan halaman berupa gambar saja. Hapus, atau pindahkan ke akhir dan terima halaman berupa gambar di hasilnya.
Proses berhenti di satu langkah dengan error
Alat itu tidak bisa memproses file pada tahap tersebut, sering karena file dikunci kata sandi atau rusak. Tambahkan Perbaiki sebagai langkah 1 atau betulkan file lebih dulu, lalu jalankan alur kerjanya lagi. Baris status menyebutkan langkah yang gagal, jadi Anda tahu alat mana yang perlu diuji sendiri.
Langkah-langkah saya hilang
Daftarnya hanya ada selama halaman terbuka. Susun ulang; simpan catatan singkat urutannya untuk alur kerja yang sering Anda ulangi.
Saya butuh teks watermark atau rotasi yang berbeda
Workflows selalu memakai pengaturan bawaan. Jalankan alat Watermark atau Rotate secara terpisah dengan pengaturan Anda, lalu gunakan Workflows untuk langkah-langkah sisanya.

Pertanyaan yang sering diajukan

Bisakah saya mengubah pengaturan sebuah langkah?

Tidak. Setiap langkah berjalan dengan pengaturan bawaan alatnya. Untuk opsi khusus, gunakan alat masing-masing.

Bisakah alur kerja dijalankan pada beberapa PDF sekaligus?

Tidak dalam sekali jalan. Alat ini memproses satu file setiap kali, tetapi daftar langkahnya tetap siap, jadi Anda bisa langsung meletakkan file berikutnya.

Bisakah alur kerja disimpan untuk nanti?

Untuk saat ini belum. Langkah-langkahnya hanya tersimpan selama halaman terbuka.

Kenapa hanya sebagian alat yang tersedia sebagai langkah?

Sebuah langkah harus menerima satu PDF dan mengembalikan satu PDF. Alat yang membutuhkan beberapa file, menghasilkan ZIP, mengekspor gambar atau teks, atau memerlukan konversi di server tidak bisa dirangkai.

Apakah file diproses di server?

Tidak. Kedua belas alat yang bisa dirangkai berjalan di dalam tab browser Anda; PDF diteruskan dari langkah ke langkah di memori dan hanya hasil akhirnya yang diunduh.

Apa yang terjadi jika saya menambahkan alat yang sama dua kali?

Alat itu berjalan dua kali. Dua langkah Putar memutar halaman 180°; dua langkah Kompres biasanya hanya sedikit menambah penghematan, tetapi menurunkan kualitas lebih banyak.

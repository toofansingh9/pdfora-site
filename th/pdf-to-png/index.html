PDF เป็น PNG

บันทึกทุกหน้าของ PDF เป็นรูป PNG แบบไม่สูญเสียคุณภาพ คมพอสำหรับแผนภาพ กราฟ และตัวหนังสือเล็ก

🔒 ไฟล์ของคุณถูกประมวลผลภายในเบราว์เซอร์ของคุณและไม่เคยถูกอัปโหลด
1

อัปโหลด

เลือกหรือลากแล้ววางไฟล์ของคุณ

2

ปรับแต่ง

เลือกตัวเลือกของคุณ — ทุกอย่างเกิดขึ้นในเบราว์เซอร์ของคุณ

3

ดาวน์โหลด

บันทึกไฟล์ที่เสร็จแล้วได้ทันที ไม่มีลายน้ำ

PNG คือฟอร์แมตที่ควรเลือกเมื่อหน้าประกอบด้วยเส้นขอบมากกว่ารูปถ่าย แบบแปลนบ้าน แผนผังวงจร สเปรดชีต ใบงานคณิตศาสตร์ และสไลด์ที่เต็มไปด้วยเส้นบางๆ ล้วนเสียหายจากการบีบอัด JPEG ที่ทิ้งรัศมีสีเทาไว้รอบเส้นดำ PNG เก็บทุกพิกเซลตรงตามจริง หน้าที่เรนเดอร์แล้วจึงหน้าตาเหมือนที่เห็นบนจอในโปรแกรมอ่าน PDF

การแปลงทำทีละหน้า PDF.js ซึ่งเป็นเอนจินเรนเดอร์ที่ใช้ใน Firefox วาดแต่ละหน้าลงบน canvas แล้วเขียน canvas ออกมาเป็นไฟล์ PNG คุณเลือกได้ว่า canvas จะมีกี่พิกเซล หน้าจอ วาดหน้าที่ 1.5 เท่าของขนาดเป็นพอยต์ (ราว 108 dpi) มาตรฐาน ที่ 2 เท่า (ราว 144 dpi เป็นค่าเริ่มต้น) และ สูง ที่ 3 เท่า (ราว 216 dpi) เพราะ PNG ไม่สูญเสียคุณภาพ ระดับเหล่านี้จึงเป็นสิ่งเดียวที่มีผลต่อคุณภาพ และมีผลต่อขนาดไฟล์มาก

สิ่งที่ต้องแลกคือน้ำหนักไฟล์ หน้าข้อความที่บันทึกเป็น PNG มักกะทัดรัด เพราะพื้นที่ขาวกว้างๆ บีบอัดได้ดี แต่หน้าที่มีรูปถ่ายสีเต็มหน้าอาจใหญ่กว่าหน้าเดียวกันที่เป็น JPG หลายเท่า ถ้า PDF ของคุณเป็นเอกสารสแกนหรืออัลบั้มรูป ตัวแปลงเป็น JPG มักใช้งานได้จริงกว่า PNG คุ้มขนาดก็ต่อเมื่อเป็นกราฟิกและข้อความที่ต้องการความคม

วิธีแปลงหน้า PDF เป็น PNG

  1. เปิดเครื่องมือ PDF เป็น PNG แล้ววางไฟล์ PDF หนึ่งไฟล์
  2. เลือกระดับคุณภาพ มาตรฐาน เหมาะกับเอกสารประกอบและการใช้บนเว็บ สูง คุ้มค่าสำหรับงานพิมพ์ การซูมดูใกล้ๆ หรือการทำ OCR ในโปรแกรมอื่น
  3. กด แปลง แล้วรอระหว่างที่แต่ละหน้าถูกเรนเดอร์ แถบจะขยับหนึ่งครั้งต่อหน้า
  4. ใช้ ดาวน์โหลดทั้งหมด (.zip) เพื่อเอาทุกหน้า หรือคลิกปุ่มไฟล์เพื่อเอา PNG ทีละรูป
  5. ซูมเข้าไปดูรายละเอียดที่เล็กที่สุดในรูปหนึ่ง เช่น ตัวเลขบอกขนาดหรือเชิงอรรถ เพื่อยืนยันว่าระดับที่เลือกสูงพอ

ควรใช้เครื่องมือนี้เมื่อใด

  • ใส่แบบทางเทคนิคหรือแผนผังสายไฟลงในวิกิ ทิกเก็ต หรือ README ที่เส้นบางๆ ต้องยังอ่านออก
  • แปลงสไลด์บรรยายที่ส่งออกเป็น PDF ให้เป็นรูป สำหรับระบบเรียนออนไลน์ที่รับอัปโหลดเฉพาะรูปภาพ
  • ทำรูปสเปรดชีตหรือตารางที่สะอาด ไว้วางในรายงานหรือแชต โดยไม่มีขอบเทาแบบ JPEG รอบเส้นเซลล์ทุกเส้น
  • ส่งรูปหน้าความละเอียดสูงให้นักออกแบบไปลอกลาย ครอป หรือนำไปซ้อนในโปรแกรมแต่งภาพ
  • เก็บหน้าตาที่แน่นอนของหน้าหนึ่งไว้ เช่น แบบฟอร์มที่เซ็นแล้ว เพื่อเทียบในภายหลัง ซึ่งรอยบีบอัดใดๆ จะเป็นตัวกวน
  • เตรียมรูปหน้าให้โปรแกรม OCR หรือเครื่องมือแปลภาษาที่ทำงานได้ดีกว่ากับรูปที่คมและไม่มีรอยบีบอัด

สิ่งที่ควรรู้ก่อนเริ่ม

  • หน้าถูกวาดบนพื้นขาว ไฟล์ PNG จึงไม่โปร่งใส แม้ฟอร์แมตจะรองรับความโปร่งใส
  • ทุกหน้าใน PDF ถูกส่งออก ถ้าจะแปลงแค่บางหน้า ให้ตัดออกมาด้วยเครื่องมือแยกหน้าก่อน
  • ไฟล์ตั้งชื่อตามต้นฉบับพร้อมเลขหน้าที่เติมศูนย์ เช่น plans-001.png และ plans-002.png และไฟล์ ZIP ชื่อ plans-png.zip
  • ข้อความที่เลือกได้ ไฮเปอร์ลิงก์ บุ๊กมาร์ก และช่องฟอร์มไม่รอด PNG แสดงว่าหน้าเคยหน้าตาเป็นอย่างไร ไม่มีอะไรมากกว่านั้น
  • ขนาดพิกเซลตามขนาดหน้าที่เก็บไว้ใน PDF แบบ A3 ที่ระดับมาตรฐานประมาณ 1684 x 2382 พิกเซล หน้า A4 ประมาณ 1191 x 1684
  • ขนาดไฟล์แกว่งมากกว่า JPG มาก หน้าข้อความล้วนอาจเล็ก หน้าที่รูปเยอะหรือพื้นหลังเข้มที่มีนอยส์อาจใหญ่หลายเมกะไบต์ต่อหน้าที่ระดับสูง สไลด์พื้นเข้มและหน้าที่มีไล่สีบีบอัดเป็น PNG ได้ไม่ดี ถ้าสไลด์ทุกแผ่นพื้นดำ เตรียมรับไฟล์ใหญ่ที่ระดับสูง และพิจารณาใช้มาตรฐานแทน

เคล็ดลับเพื่อผลลัพธ์ที่ดีที่สุด

  • เอกสารผสม ให้แปลงสองรอบ: PNG สำหรับหน้าแผนภาพ JPG สำหรับหน้ารูปถ่าย แล้วเก็บไฟล์ที่เหมาะกับแต่ละหน้า
  • ใช้ระดับสูงเมื่อจะมีคนพิมพ์รูปหรืออ่านตัวหนังสือ 6 พอยต์จากรูป มาตรฐานพอเหลือเฟือสำหรับดูบนจอ
  • ถ้า PNG หนักเกินไปสำหรับเว็บไซต์ ให้เก็บเป็น PNG แต่ผ่านโปรแกรมปรับแต่งรูป ซึ่งลดขนาดได้โดยไม่เสียพิกเซล
  • เช็กแบบเวกเตอร์ที่ระดับสูง เส้นผมที่ดูขาดๆ ที่ 108 dpi มักเรนเดอร์เป็นเส้นต่อเนื่องที่ 216 dpi
  • เก็บ PDF ไว้คู่กับรูป มันยังเป็นต้นฉบับที่ค้นหาได้และขยายได้ไม่แตก รูปถูกเรนเดอร์ ณ ตอนที่คุณแปลง คำอธิบายประกอบและความคิดเห็นที่โปรแกรมอ่านแสดงจะติดมาด้วยก็ต่อเมื่อ PDF.js วาดมัน ส่วนเลเยอร์ซ่อนที่ปิดไว้เป็นค่าเริ่มต้นจะยังถูกซ่อน

ตัวอย่างจริง: ผู้รับเหมาส่งแบบแปลนให้ช่าง

ผู้รับเหมารีโนเวตบ้านคนหนึ่งได้แบบแปลน A3 จากสถาปนิกเป็น PDF แบบเวกเตอร์ และต้องส่งขนาดห้องให้ช่างปูกระเบื้องทาง LINE ช่างเปิดทุกอย่างบนมือถือและไม่อยากวุ่นกับ PDF

ถ้าแปลงเป็น JPG ตัวเลขบอกขนาด (ตัวหนังสือเทาเล็กๆ ข้างเส้นบาง) จะมีขอบเป็นด่าง จนซูมแล้วแยก 3 กับ 8 ไม่ค่อยออก แปลงเป็น PNG ที่ระดับสูง หน้าเรนเดอร์ที่ประมาณ 2526 x 3573 พิกเซล และป้ายทุกตัวคมชัด เพราะไม่มีการบีบอัดแบบสูญเสียคุณภาพ ไฟล์ใหญ่กว่า JPG แต่ยังส่งได้สบาย

ผู้รับเหมายังสังเกตว่าแบบของสถาปนิกมีลายแรเงาเส้นบางที่หายไปที่ระดับหน้าจอ นั่นไม่ใช่ข้อผิดพลาดของแบบ ที่ 108 dpi เส้นเหล่านั้นแคบกว่าหนึ่งพิกเซล เลือกระดับสูงก็แก้ได้ ซึ่งเป็นเหตุผลหลักที่มีสามระดับ ถ้าแบบเป็นกระดาษที่สแกนมาแทนไฟล์เวกเตอร์ ผลจะต่างไป PNG จะเก็บเนื้อกระดาษและนอยส์สีเทาไว้ครบถ้วน และไฟล์จะหนัก สำหรับไฟล์สแกน JPG ที่ระดับมาตรฐานมักเป็นจุดกึ่งกลางที่สมเหตุสมผล และเก็บ PNG ไว้ใช้กับหน้าที่ต้องอ่านป้ายเล็กๆ

การแก้ปัญหา

ไฟล์ PNG ใหญ่มาก
PNG ไม่สูญเสียคุณภาพ หน้าที่รูปเยอะจึงใหญ่ ใช้ระดับที่ต่ำลง หรือแปลงหน้าเหล่านั้นด้วย PDF เป็น JPG แทน
เส้นบางหายหรือขาด
เส้นบางกว่าหนึ่งพิกเซลที่ความละเอียดที่เลือก แปลงใหม่ที่ระดับสูง
คาดว่าจะได้พื้นหลังโปร่งใส
หน้าถูกเรนเดอร์บนพื้นขาว ผลลัพธ์จึงทึบ ถ้าต้องการความโปร่งใสให้ลบพื้นหลังในโปรแกรมแต่งภาพ
เครื่องมือเปิด PDF ของฉันไม่ได้
สาเหตุที่พบบ่อยคือรหัสผ่านหรือไฟล์เสีย ลบการป้องกันด้วย ปลดล็อก PDF หรือในแอปต้นทางหรือลองเครื่องมือซ่อม PDF แล้วแปลงสำเนาที่แก้แล้ว
เอกสารยาวแต่แสดงปุ่มดาวน์โหลดแค่ 50 ปุ่ม
รายการจำกัดไว้ 50 ปุ่มเพื่อให้อ่านง่าย ไฟล์ ZIP มีครบทุกหน้า
ตัวหนังสือดูต่างจากต้นฉบับเล็กน้อย
PDF น่าจะใช้ฟอนต์ที่ไม่ได้ฝังไว้ และ PDF.js ใช้ฟอนต์ที่คล้ายกันแทน ให้ส่งออก PDF ใหม่โดยฝังฟอนต์

คำถามที่พบบ่อย

PNG ดีกว่า JPG สำหรับหน้า PDF ไหม?

สำหรับข้อความ กราฟ และลายเส้น ใช่ PNG เก็บขอบได้แม่นยำ สำหรับรูปถ่ายและไฟล์สแกน JPG มักให้คุณภาพที่ตาเห็นใกล้เคียงกันในขนาดที่เล็กกว่ามาก

แต่ละระดับเท่ากับกี่ dpi?

หน้าจอประมาณ 108 dpi มาตรฐานประมาณ 144 dpi และสูงประมาณ 216 dpi โดยอิงขนาดหน้าที่เก็บไว้ใน PDF

PNG มีพื้นหลังโปร่งใสได้ไหม?

ไม่ได้ ตัวเรนเดอร์วาดหน้าบนพื้นขาวก่อนบันทึก PNG ทุกไฟล์จึงทึบ

คัดลอกข้อความจาก PNG ได้ไหม?

ไม่ได้ ข้อความกลายเป็นพิกเซล เก็บ PDF ไว้สำหรับคัดลอก หรือใช้ OCR กับรูปถ้าไม่มี PDF

การแปลงต้องมีบัญชีหรือจ่ายเงินไหม?

ไม่ต้อง ใช้เครื่องมือได้ฟรีโดยไม่ต้องล็อกอิน

ทำไมไฟล์ PNG ของหน้าที่ดูคล้ายกันถึงขนาดต่างกัน?

PNG บีบอัดพื้นที่สีเรียบได้ดีมาก และบีบอัดพื้นที่ที่มีนอยส์ได้แย่ หน้าที่มีรูปถ่าย ไล่สี หรือพื้นผิวจากการสแกน จะได้ไฟล์ใหญ่กว่าหน้าข้อความบนพื้นขาวมาก แม้จะความละเอียดเท่ากัน

PDF ขาวดำ

แปลงไฟล์ PDF สีให้เป็นโทนสีเทา เพื่อประหยัดหมึกและลดขนาดไฟล์

🔒 ไฟล์ของคุณถูกประมวลผลภายในเบราว์เซอร์ของคุณและไม่เคยถูกอัปโหลด
1

อัปโหลด

เลือกหรือลากแล้ววางไฟล์ของคุณ

2

ปรับแต่ง

เลือกตัวเลือกของคุณ — ทุกอย่างเกิดขึ้นในเบราว์เซอร์ของคุณ

3

ดาวน์โหลด

บันทึกไฟล์ที่เสร็จแล้วได้ทันที ไม่มีลายน้ำ

หมึกสีนั้นราคาแพง และเอกสารส่วนใหญ่ก็ไม่ได้จำเป็นต้องใช้สี เครื่องมือแปลงเป็นโทนสีเทาของ PDFora เปลี่ยนทุกหน้าของไฟล์ PDF ให้เป็นขาวดำได้ในไม่กี่วินาที ทำงานในเบราว์เซอร์ของคุณโดยตรง นี่คือวิธีที่เร็วที่สุดในการเตรียมไฟล์สำหรับเครื่องพิมพ์เลเซอร์ขาวดำ ทำตามข้อกำหนดของร้านพิมพ์ที่ขอไฟล์โทนสีเทา หรือแค่หยุดไม่ให้เครื่องอิงก์เจ็ตของคุณผลาญหมึกสีไปกับรายงานห้าสิบหน้า

การแปลง PDF เป็นโทนสีเทามักช่วยลดขนาดไฟล์ไปด้วย เพราะข้อมูลสีกินพื้นที่ และเมื่อมันหายไป หน้าเอกสารก็เก็บข้อมูลน้อยลง เอกสารที่เต็มไปด้วยรูปภาพจึงอาจเบาลงอย่างเห็นได้ชัด นั่นทำให้โทนสีเทามีประโยชน์แม้ไม่ได้มีเป้าหมายเพื่อการพิมพ์ เช่น เมื่อระบบรับส่งเอกสารจำกัดขนาดไฟล์ แต่สไลด์สีสันจัดจ้านของคุณดันเกินเพดานอยู่นิดเดียว

เช่นเดียวกับเครื่องมือทุกตัวของ PDFora ตัวนี้ประมวลผลไฟล์บนเครื่องของคุณ ไม่มีการอัปโหลด สแกนหนังสือเดินทางหรือสัญญาที่เซ็นแล้วจึงอยู่บนอุปกรณ์ของคุณตั้งแต่ต้นจนจบ ไม่ต้องสมัครสมาชิก ไม่มีลายน้ำประทับลงบนผลลัพธ์ ไม่มีค่าใช้จ่าย และไม่จำกัดจำนวน PDF ที่คุณแปลง

วิธีแปลงไฟล์ PDF เป็นโทนสีเทาแบบออนไลน์

  1. เปิดเครื่องมือ PDF to Grayscale บน PDFora ในเบราว์เซอร์ของคุณ
  2. ลากไฟล์ PDF มาวางในพื้นที่รับไฟล์ หรือคลิกเพื่อเลือกไฟล์จากอุปกรณ์
  3. รอสักครู่ให้เครื่องมือโหลดตัวอย่างขึ้นมา เพื่อยืนยันว่าเป็นเอกสารที่ถูกต้อง
  4. กดปุ่มแปลงไฟล์ แล้วปล่อยให้เบราว์เซอร์ประมวลผลแต่ละหน้าให้เป็นขาวดำบนเครื่องของคุณ
  5. ตรวจดูหน้าที่แปลงเสร็จแล้วว่าภาพถ่ายและกราฟยังอ่านรู้เรื่องในโทนสีเทา
  6. ดาวน์โหลดไฟล์ PDF โทนสีเทา แล้วนำไปสั่งพิมพ์หรือส่งต่อได้ตามต้องการ

When to use this tool

  • แปลงงานนำเสนอที่ใช้สีจัดจ้านให้เป็นขาวดำก่อนพิมพ์ 30 ชุดด้วยเครื่องพิมพ์เลเซอร์ในสำนักงาน
  • ทำตามข้อกำหนดของมหาวิทยาลัยที่ให้ส่งร่างวิทยานิพนธ์เป็นโทนสีเทาสำหรับพิมพ์ตรวจทาน
  • เตรียมต้นฉบับหนังสือสำหรับบริการพิมพ์ตามสั่ง ซึ่งคิดค่าหน้าเนื้อในแบบสีแพงกว่า
  • ตัดสีออกจากแบบฟอร์มที่สแกนมา เพื่อให้ถ่ายเอกสารออกมาสะอาดไม่ขุ่นมัว
  • ลดขนาดไฟล์ PDF โบรชัวร์ที่มีรูปเยอะ ด้วยการตัดข้อมูลสีออกก่อนส่งทางอีเมล
  • ทำให้รอยปากกาไฮไลต์และคำอธิบายประกอบสีต่าง ๆ มีโทนเดียวกันก่อนเก็บเอกสารทำงานเข้าคลัง

Tips for the best results

  • ตรวจกราฟหลังแปลงเสมอ เส้นที่แยกแยะกันด้วยสีอย่างเดียว เช่น แดงกับเขียว อาจดูเหมือนกันเป๊ะในโทนสีเทา ถ้ากราฟนั้นสำคัญ ให้ใช้เวอร์ชันที่มีป้ายกำกับหรือลวดลายแทน
  • แปลงเป็นโทนสีเทาก่อนพิมพ์ ไม่ใช่หลังพิมพ์ การให้เครื่องมือแปลงให้ได้ผลลัพธ์ที่คาดเดาได้มากกว่าการฝากความหวังไว้กับโหมดขาวดำของไดรเวอร์เครื่องพิมพ์แต่ละรุ่น
  • ใช้เครื่องมือร่วมกันเพื่อให้ไฟล์เล็กที่สุด ให้แปลงเป็นโทนสีเทาก่อน แล้วค่อยใช้เครื่องมือบีบอัด ไฟล์สแกนสีก้อนใหญ่อาจเหลือขนาดเพียงเศษเสี้ยวของเดิม
  • เก็บต้นฉบับสีไว้ด้วย เพราะการแปลงในไฟล์ผลลัพธ์เป็นการเปลี่ยนแบบถาวร ควรบันทึกเวอร์ชันสีไว้เผื่อต้องใช้ภายหลัง
  • ภาพถ่ายแปลงออกมาดีกว่าตัวหนังสือสีอ่อน ข้อความสีเหลืองอ่อนหรือสีพาสเทลอาจจางหายในโทนสีเทา ควรไล่ดูหน้าที่ตกแต่งสวยงามก่อนส่งไฟล์ไปพิมพ์

คำถามที่พบบ่อย

การแปลงเป็นโทนสีเทาช่วยลดขนาดไฟล์ PDF ไหม

บ่อยครั้งช่วยได้ การตัดข้อมูลสีออกทำให้แต่ละหน้าเก็บข้อมูลน้อยลง เอกสารที่เต็มไปด้วยภาพถ่ายหรือกราฟิกสีจึงเล็กลงอย่างสังเกตได้ ส่วนไฟล์ PDF ที่เป็นข้อความสีดำล้วนอยู่แล้วจะเปลี่ยนแปลงไม่มากนัก

ข้อความจะยังคมชัดหลังแปลงหรือไม่

ข้อความสีดำยังคมชัดเหมือนเดิม เพราะโดยพื้นฐานมันเป็นโทนสีเทาอยู่แล้ว ส่วนข้อความสีจะถูกจับคู่เป็นเฉดเทาตามค่าความสว่าง สีที่อ่อนมากจึงอาจพิมพ์ออกมาจางกว่าที่คิด การดูตัวอย่างสักครู่ก่อนพิมพ์จะช่วยจับจุดนี้ได้

เครื่องมือนี้ฟรีไหม และจำกัดจำนวนหน้าหรือเปล่า

ฟรีสมบูรณ์ ไม่ต้องสมัครสมาชิกและไม่มีลายน้ำ อีกทั้งเราไม่ได้กำหนดขีดจำกัดจำนวนหน้าหรือขนาดไฟล์ไว้ เนื่องจากเบราว์เซอร์ของคุณเป็นผู้ประมวลผล เอกสารยาว ๆ จึงทำได้เช่นกัน เพียงแต่ไฟล์ที่ใหญ่มากอาจใช้เวลานานขึ้นบนอุปกรณ์รุ่นเก่า

ระหว่างแปลงไฟล์ PDF ของฉันถูกอัปโหลดไปที่ใดหรือไม่

ไม่ การแปลงทำงานภายในเบราว์เซอร์ของคุณด้วยการประมวลผลบนเครื่อง เอกสารจึงไม่เคยเดินทางไปยังเซิร์ฟเวอร์ คุณจึงแปลงเอกสารลับได้โดยที่มันไม่ออกจากเครื่องของคุณเลย

ทำไมต้องพิมพ์จากไฟล์โทนสีเทา แทนที่จะตั้งค่าขาวดำที่เครื่องพิมพ์

ไฟล์ PDF โทนสีเทาให้ผลลัพธ์เหมือนกันบนเครื่องพิมพ์ทุกเครื่อง และทำให้คุณเห็นล่วงหน้าว่าทุกหน้าจะออกมาหน้าตาอย่างไรก่อนจะเสียกระดาษ ไดรเวอร์เครื่องพิมพ์แต่ละตัวทำงานต่างกัน และบางตัวยังคงดึงหมึกสีมาผสมเป็นเฉดเทาเมื่อพิมพ์จากไฟล์สี

แปลงเป็นโทนสีเทาเฉพาะบางหน้าได้ไหม

เครื่องมือแปลงทั้งเอกสารในครั้งเดียว หากคุณต้องการผลลัพธ์แบบผสม ให้แยกไฟล์ PDF ออกก่อน แปลงเฉพาะหน้าที่ต้องการให้เป็นสีเทา แล้วรวมทุกอย่างกลับเข้าด้วยกันด้วยเครื่องมือแยกและรวมไฟล์ของ PDFora

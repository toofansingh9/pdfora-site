ซ่อม PDF

อ่าน PDF ที่โปรแกรมอื่นเปิดไม่ผ่านขึ้นมาใหม่ แล้วเขียนออกเป็นไฟล์ที่มีโครงสร้างสะอาดซึ่งสร้างขึ้นใหม่

3

ดาวน์โหลด

บันทึกไฟล์ที่เสร็จแล้วได้ทันที ไม่มีลายน้ำ

PDF ไม่ใช่เนื้อหาก้อนเดียว แต่เป็นชุดของออบเจกต์ที่มีหมายเลขกำกับ บวกกับตารางอ้างอิงไขว้ (cross-reference table) ที่บอกโปรแกรมอ่านว่าแต่ละออบเจกต์เริ่มตรงไหน เมื่อดาวน์โหลดไม่ครบ โปรแกรมเขียนตารางผิด หรือไฟล์ถูกแก้ด้วยหลายโปรแกรมต่อๆ กัน ตารางนี้อาจชี้ไปผิดที่ โปรแกรมอ่านบางตัวแก้ปัญหาเองเงียบๆ บางตัวแสดงหน้าว่าง และระบบอัปโหลดมักปฏิเสธไฟล์พร้อมข้อความผิดพลาดที่ไม่ชัดเจน เครื่องมือซ่อม PDF ทำมาสำหรับกรณีกลางๆ แบบนี้ คือไฟล์ที่โครงสร้างไม่เรียบร้อยแต่เนื้อหายังอยู่

สิ่งที่เครื่องมือทำนั้นเจาะจง มันโหลดไฟล์ด้วยไลบรารี pdf-lib ซึ่งอ่านออบเจกต์ที่หาเจอและหาโครงสร้างเอง แทนที่จะเชื่อตารางที่เสีย แล้วบันทึกเป็นสำเนาใหม่ ไฟล์ใหม่จะมีตารางอ้างอิงไขว้ที่เขียนขึ้นใหม่ และทุกออบเจกต์ถูกเขียนแยกทีละตัว ไม่ได้อัดรวมไว้ใน object stream แบบบีบอัด ซึ่งเป็นรูปแบบเก่ากว่าที่โปรแกรมอ่านแบบเข้มงวดหรือรุ่นเก่ายอมรับได้ง่ายกว่า เนื้อหาของหน้าถูกคัดลอกมา ไม่ได้เรนเดอร์ใหม่ ข้อความ ฟอนต์ และรูปภาพจึงเหมือนเดิมทุกอย่าง

ขอบอกขีดจำกัดตามตรง นี่คือการสร้างโครงสร้างใหม่ ไม่ใช่การกู้ข้อมูล ถ้าข้อมูลหายไปจริงๆ เช่น ครึ่งหลังของไฟล์ที่ดาวน์โหลดไม่จบ ก็ไม่มีอะไรให้สร้างหน้าเหล่านั้นขึ้นมาใหม่ และไม่มีเครื่องมือไหนเสกขึ้นมาได้ กรณีนั้นทางแก้ที่ถูกคือขอไฟล์ใหม่จากต้นทาง

วิธีซ่อมไฟล์ PDF

  1. เปิดเครื่องมือซ่อม PDF แล้วเพิ่มไฟล์ที่มีปัญหา ทำได้ครั้งละหนึ่งไฟล์
  2. กด ซ่อมแซมและสร้างใหม่ ไฟล์จะถูกอ่านและบันทึกใหม่ เอกสารส่วนใหญ่ใช้เวลาแค่วินาทีหรือสองวินาที
  3. ถ้าเครื่องมือแจ้งข้อผิดพลาด แปลว่าอ่านไฟล์ไม่ได้เลย ให้ไปดูหัวข้อการแก้ปัญหาด้านล่าง
  4. ดาวน์โหลดผลลัพธ์ ซึ่งใช้ชื่อเดิมต่อท้ายด้วย -repaired เช่น contract-repaired.pdf
  5. เปิดสำเนาที่ซ่อมแล้วในโปรแกรมหรือระบบที่เคยไม่ผ่าน แล้วไล่ดูทุกหน้าว่ามีเนื้อหาครบ

ควรใช้เครื่องมือนี้เมื่อใด

  • ระบบส่งวิทยานิพนธ์ของมหาวิทยาลัยปฏิเสธไฟล์ PDF ว่าไม่ถูกต้อง ทั้งที่เปิดในโน้ตบุ๊กของตัวเองได้ปกติ
  • ไฟล์ที่ส่งออกจากเครื่องสแกนหรือโปรแกรมบัญชีรุ่นเก่า เปิดในโปรแกรมหนึ่งได้ แต่อีกโปรแกรมแสดงหน้าว่าง
  • PDF ที่ถูกแก้หลายครั้งด้วยหลายโปรแกรม จนเปิดช้าหรือขึ้นเตือนว่าไฟล์เสียหาย
  • เตรียมไฟล์ส่งโรงพิมพ์หรือระบบยื่นเอกสารออนไลน์ที่ตรวจไฟล์เข้มกว่าโปรแกรมอ่านทั่วไป
  • ปรับไฟล์ให้เป็นมาตรฐานก่อนรวมหรือแยก ในกรณีที่เครื่องมือเหล่านั้นโหลดต้นฉบับไม่ได้
  • เช็กอย่างรวดเร็วว่าไฟล์ยังอ่านโครงสร้างได้หรือไม่ ก่อนขอให้ผู้ส่งส่งออกไฟล์ใหม่

สิ่งที่ควรรู้ก่อนเริ่ม

  • การซ่อมสร้างโครงสร้างใหม่ ไม่ได้กู้เนื้อหาที่หายไป ไฟล์ที่ขาดหายจะได้กลับมาอย่างมากแค่หน้าที่สมบูรณ์
  • ไฟล์ผลลัพธ์เขียนโดยไม่ใช้ object stream แบบบีบอัด ทำให้เข้ากันได้ดีขึ้น แต่มักใหญ่กว่าต้นฉบับเล็กน้อย บางครั้ง 10 ถึง 30 เปอร์เซ็นต์ในไฟล์ที่ใช้ object stream เยอะ
  • หน้าถูกคัดลอกตามที่เป็น ถ้าหน้าดูผิดเพราะ content stream ของหน้านั้นเองเสีย ก็อาจยังดูผิดหลังสร้างใหม่
  • ไฟล์ถูกเปิดโดยปิดการตรวจการเข้ารหัส PDF ที่มีรหัสผ่านอาจโหลดได้ แต่เนื้อหายังถูกเข้ารหัสอยู่ และสำเนาที่บันทึกมักแสดงผลไม่ถูกต้อง ให้เอารหัสผ่านออกที่ต้นทางก่อน
  • ฟอร์ม บุ๊กมาร์ก และคำอธิบายประกอบที่ pdf-lib อ่านได้ จะติดไปในไฟล์ใหม่ด้วย เพราะบันทึกทั้งเอกสาร ไม่ใช่แค่หน้า
  • การทำงานเกิดขึ้นในเบราว์เซอร์ของคุณ ไฟล์ที่ไม่อยากส่งไปบริการกู้ไฟล์ออนไลน์ก็ลองที่นี่ได้

เคล็ดลับเพื่อผลลัพธ์ที่ดีที่สุด

  • เก็บต้นฉบับไว้คู่กับสำเนาที่ซ่อมเสมอ จนกว่าจะตรวจผลลัพธ์ครบทุกหน้า
  • เทียบจำนวนหน้าของไฟล์ที่ซ่อมกับจำนวนที่ควรมี ถ้าน้อยกว่า นั่นคือสัญญาณชัดที่สุดว่าต้นฉบับขาดหาย
  • ถ้าระบบยังไม่รับไฟล์ที่ซ่อมแล้ว ลองสั่งพิมพ์เป็น PDF จากโปรแกรมอ่าน วิธีนี้เรนเดอร์ทุกหน้าใหม่และแก้ปัญหาในเนื้อหาหน้าที่การสร้างโครงสร้างใหม่แก้ไม่ได้
  • ถ้าเป็นไฟล์ที่ได้มาทางอีเมลหรือดาวน์โหลด ให้ขอใหม่ก่อนเสียเวลาซ่อม ไฟล์ที่สมบูรณ์ดีกว่าการซ่อมทุกแบบ
  • หลังซ่อมสำเร็จ ถ้าไฟล์ใหญ่ขึ้นและส่วนใหญ่เป็นภาพสแกน ให้ใช้ บีบอัด PDF ต่อ

ตัวอย่างจริง: ชุดใบแจ้งหนี้ของฟรีแลนซ์

นักแปลอิสระส่งออกใบแจ้งหนี้รายเดือนสิบสองฉบับจากโปรแกรมออกใบแจ้งหนี้รุ่นเก่ารวมเป็น PDF ไฟล์เดียว เพื่อใช้ประกอบการยื่นภาษีประจำปี ไฟล์เปิดในโปรแกรมดู PDF ของเบราว์เซอร์ได้ แต่แบบฟอร์มอัปโหลดปฏิเสธว่าเป็นเอกสารไม่ถูกต้อง และเครื่องมือรวม PDF ก็ไม่ยอมนำไปรวมกับเอกสารอื่น

เมื่อผ่านเครื่องมือซ่อม PDF ไฟล์โหลดได้ ได้ตารางอ้างอิงไขว้ที่เขียนใหม่ และบันทึกโดยไม่ใช้ object stream แบบฟอร์มอัปโหลดรับสำเนาที่ซ่อมแล้ว และเครื่องมือรวม PDF ก็อ่านได้ ไฟล์โตจาก 410 KB เป็นราว 460 KB ซึ่งเป็นราคาของรูปแบบที่ระมัดระวังกว่า และไม่ใช่ปัญหาในกรณีนี้

ก่อนส่ง นักแปลนับหน้า: ใบแจ้งหนี้สิบสองฉบับ สิบสองหน้า ถ้านับได้เก้า แปลว่าการส่งออกครั้งแรกไม่ครบ และทางแก้จริงๆ ทางเดียวคือส่งออกใหม่จากโปรแกรมออกใบแจ้งหนี้

การแก้ปัญหา

เครื่องมือแจ้งข้อผิดพลาดและไม่ได้ไฟล์อะไร
อ่านไฟล์ไม่ได้เลย มักเพราะไม่ใช่ PDF จริง (เช่น หน้าข้อผิดพลาด HTML ที่บันทึกเป็นชื่อ .pdf) หรือขาดหายมาก ลองเปิดด้วยโปรแกรมแก้ไขข้อความ PDF จริงจะขึ้นต้นด้วย %PDF ถ้าไม่ใช่ ให้ขอไฟล์ใหม่
บางหน้าหายไปในไฟล์ที่ซ่อม
หน้าเหล่านั้นไม่ได้อยู่ในต้นฉบับในรูปที่อ่านได้ มักเพราะดาวน์โหลดไม่จบ ให้ดาวน์โหลดหรือส่งออกเอกสารใหม่
หน้ายังว่างหรือเพี้ยน
เนื้อหาของหน้าเองเสียหาย ซึ่งการสร้างโครงสร้างใหม่ไม่ได้แตะ ลองสั่งพิมพ์ต้นฉบับเป็น PDF จากโปรแกรมที่แสดงผลได้ดีที่สุด หรือขอให้ผู้ส่งส่งออกใหม่
ไฟล์ที่ซ่อมใหญ่กว่าต้นฉบับ
เครื่องมือเขียนออบเจกต์แยกทีละตัวแทนที่จะอัดใน object stream ตั้งใจทำแบบนี้เพื่อความเข้ากันได้ ถ้าขนาดสำคัญให้บีบอัดผลลัพธ์
สำเนาที่ซ่อมแสดงเนื้อหาอ่านไม่ออก
ต้นฉบับน่าจะถูกเข้ารหัส การเข้ารหัสถูกข้ามไปตอนโหลด เนื้อหาจึงยังเป็นรหัสอยู่ ให้เอารหัสผ่านออกในโปรแกรมที่สร้างไฟล์ แล้วซ่อมสำเนานั้น
ระบบยังไม่รับไฟล์
ตัวตรวจอาจติดเรื่องอื่นที่ไม่ใช่โครงสร้าง เช่น ขนาดไฟล์ ขนาดหน้า หรือฟอนต์ที่ฝัง ตรวจข้อกำหนดของระบบ แล้วปรับขนาด บีบอัด หรือพิมพ์เป็น PDF ตามนั้น

คำถามที่พบบ่อย

ซ่อม PDF เปลี่ยนอะไรบ้าง?

อ่านออบเจกต์ของเอกสารใหม่ เขียนตารางอ้างอิงไขว้ใหม่ และบันทึกทุกออบเจกต์แยกกันโดยไม่ใช้ object stream เนื้อหาหน้าถูกคัดลอกโดยไม่เปลี่ยน

กู้ PDF ที่เปิดที่ไหนก็ไม่ได้ได้ไหม?

บางครั้งได้ ถ้าออบเจกต์ยังครบและเสียแค่โครงสร้าง แต่ถ้าข้อมูลหายไปหรือไฟล์ไม่ใช่ PDF ไม่มีเครื่องมือซ่อมไหนเอากลับมาได้

ซ่อมแล้วคุณภาพลดลงไหม?

ไม่ลด ไม่มีการเรนเดอร์หรือบีบอัดใหม่ ข้อความและรูปภาพจึงเหมือนเดิมทุกอย่าง

ทำไมไฟล์ใหญ่ขึ้น?

ผลลัพธ์ไม่ใช้ object stream แบบบีบอัด ไฟล์จึงใหญ่ขึ้นเล็กน้อย แต่โปรแกรมรุ่นเก่าและแบบเข้มงวดอ่านได้

ซ่อมแล้วรหัสผ่านหายไหม?

ไม่หาย เครื่องมือไม่ได้ถอดรหัสอะไร และไฟล์ที่เข้ารหัสมักแสดงผลไม่ถูกต้องหลังสร้างใหม่

ซ่อมหลายไฟล์พร้อมกันได้ไหม?

เครื่องมือรับครั้งละหนึ่งไฟล์ ให้ทำทีละไฟล์ สำหรับเอกสารทั่วไปใช้เวลาไม่นาน

ดาวน์โหลด

บันทึกไฟล์ที่เสร็จแล้วได้ทันที ไม่มีลายน้ำ

ไฟล์ PDF ทุกไฟล์มีข้อมูลอีกชั้นหนึ่งซ่อนอยู่ ทั้งชื่อเรื่อง ชื่อผู้แต่ง หัวเรื่อง และชุดคำสำคัญ เครื่องมือค้นหา ตัวจัดการไฟล์ และระบบคลังเอกสารจะอ่านฟิลด์เหล่านี้ก่อนอ่านอย่างอื่นเสมอ เมื่อข้อมูลเมตาดาต้าผิด เช่น รายงานที่มีชื่อเรื่องว่า "Untitled" หรือมีผู้แต่งเป็น "user123" ไฟล์นั้นก็ดูไม่ใส่ใจและค้นหายากขึ้น เครื่องมือนี้ให้คุณแก้ไขเมตาดาต้าของ PDF ได้โดยตรงในเบราว์เซอร์

เปิดไฟล์ขึ้นมา แล้วชื่อเรื่อง ผู้แต่ง หัวเรื่อง และคำสำคัญที่มีอยู่เดิมจะปรากฏในกล่องข้อความธรรมดา แก้เฉพาะส่วนที่ต้องการ ปล่อยส่วนที่เหลือไว้ แล้วดาวน์โหลดสำเนาที่สะอาดออกมา ไฟล์ PDF จำนวนมากรับเมตาดาต้าติดมาจากคนที่สร้างเทมเพลตไว้เมื่อหลายปีก่อน ข้อเสนอที่ส่งให้ลูกค้าจึงอาจยังระบุชื่อพนักงานที่ลาออกไปแล้วเป็นผู้แต่ง การแก้เรื่องนี้ที่นี่ใช้เวลาราวสามสิบวินาที และไม่ต้องติดตั้งซอฟต์แวร์ใด ๆ

ทุกอย่างทำงานในเบราว์เซอร์บนเครื่องของคุณ ไฟล์ PDF ไม่เคยออกจากคอมพิวเตอร์ ซึ่งสำคัญมากเมื่อคุณกำลังจัดการสัญญา เวชระเบียน หรืออะไรก็ตามที่เป็นความลับ เครื่องมือนี้ใช้ฟรี ไม่ต้องสมัครสมาชิก ไม่เพิ่มลายน้ำ และไม่จำกัดจำนวนไฟล์ที่คุณจะประมวลผล

วิธีแก้ไขเมตาดาต้าของ PDF ออนไลน์

  1. คลิกพื้นที่อัปโหลดหรือลากไฟล์ PDF มาวาง ไฟล์จะถูกเปิดในเครื่อง ไม่มีอะไรถูกส่งไปยังเซิร์ฟเวอร์
  2. ตรวจดูเมตาดาต้าเดิมที่โหลดขึ้นมาโดยอัตโนมัติ ทั้งชื่อเรื่อง ผู้แต่ง หัวเรื่อง และคำสำคัญ
  3. พิมพ์ชื่อเรื่องใหม่ นี่คือข้อความที่เครื่องมือค้นหาและโปรแกรมอ่านส่วนใหญ่นำไปแสดง จึงควรเขียนให้สื่อความ
  4. อัปเดตช่องผู้แต่ง และปรับหัวเรื่องกับคำสำคัญหากอยากให้ค้นเจอไฟล์ได้ง่ายขึ้นในภายหลัง
  5. ล้างช่องใดก็ตามที่คุณอยากให้ว่างไว้ เพราะช่องว่างยังดีกว่าช่องที่ใส่ข้อมูลผิด
  6. กดเพื่อบันทึกการเปลี่ยนแปลง แล้วดาวน์โหลดไฟล์ PDF ฉบับอัปเดตของคุณ

ควรใช้เครื่องมือนี้เมื่อใด

  • แก้รายงานที่แสดงชื่อเรื่องว่า "Microsoft Word - draft_v3_FINAL.docx" ในโปรแกรมอ่าน PDF ทุกตัว
  • เปลี่ยนชื่อเพื่อนร่วมงานที่ลาออกไปแล้วในช่องผู้แต่ง ก่อนส่งข้อเสนอให้ลูกค้า
  • เพิ่มคำสำคัญให้ใบแจ้งหนี้ที่เก็บในคลังเอกสารนับร้อยไฟล์ เพื่อให้ระบบจัดการเอกสารค้นเจอได้จริง
  • ตั้งชื่อเรื่องและผู้แต่งให้ถูกต้องบนอีบุ๊กหรือเอกสารไวท์เปเปอร์ก่อนเผยแพร่ เพราะเครื่องมือค้นหาบางเจ้าแสดงชื่อเรื่องจากเมตาดาต้าในผลการค้นหา
  • ลบข้อมูลในช่องหัวเรื่องและคำสำคัญออกจากไฟล์ PDF ก่อนแชร์ออกไปภายนอก เพื่อเอาชื่อรหัสโครงการภายในออก
  • จัดชื่อเรื่องและผู้แต่งให้เป็นมาตรฐานเดียวกันสำหรับเอกสารสแกนทั้งชุดที่ออกมาจากเครื่องสแกนในชื่อ "Scan0001" เหมือนกันหมด

เคล็ดลับเพื่อผลลัพธ์ที่ดีที่สุด

  • ชื่อเรื่องในเมตาดาต้าไม่ใช่สิ่งเดียวกับชื่อไฟล์ โปรแกรมอ่าน PDF บางตัวแสดงชื่อเรื่องจากเมตาดาต้าบนแถบหน้าต่าง จึงควรตั้งให้ถูกทั้งสองอย่าง
  • คั่นคำสำคัญด้วยเครื่องหมายจุลภาค วลีสั้นและเฉพาะเจาะจงใช้ได้ผลดีกว่าประโยคยาว ๆ
  • ล้างช่องผู้แต่งให้ว่างในเอกสารที่คุณเผยแพร่แบบไม่ระบุชื่อ เพราะซอฟต์แวร์สร้าง PDF มักกรอกช่องนี้ให้เองเงียบ ๆ
  • สำหรับไฟล์ที่คุณตั้งใจเผยแพร่ออนไลน์ ให้เขียนชื่อเรื่องแบบเดียวกับที่เขียนหัวข้อหน้าเว็บ เพราะมันมีผลต่อการที่เอกสารจะปรากฏในผลการค้นหาอย่างไร
  • ใช้รูปแบบชื่อผู้แต่งให้สอดคล้องกันทั้งองค์กร เช่น "ฝ่ายการตลาด, บริษัท เอซีเม จำกัด" เพื่อให้ไฟล์เรียงลำดับได้อย่างคาดเดาได้

คำถามที่พบบ่อย

เมตาดาต้าของ PDF คืออะไร

เมตาดาต้าคือข้อมูลบรรยายที่เก็บอยู่ภายในไฟล์ PDF เอง ได้แก่ ชื่อเรื่อง ผู้แต่ง หัวเรื่อง และคำสำคัญ มันไม่ปรากฏบนหน้ากระดาษ แต่ตัวจัดการไฟล์ เครื่องมือค้นหา และโปรแกรมอ่าน PDF จะแสดงและทำดัชนีจากข้อมูลนี้ เปรียบได้กับป้ายชื่อที่ติดอยู่ด้านนอกเอกสาร

การแก้เมตาดาต้าจะเปลี่ยนหน้าตาของไฟล์ PDF ไหม

ไม่ หน้ากระดาษ ฟอนต์ รูปภาพ และเลย์เอาต์ยังคงเหมือนเดิมทุกประการ มีเพียงฟิลด์บรรยายที่ซ่อนอยู่เท่านั้นที่ถูกเขียนใหม่ เอกสารที่คุณดาวน์โหลดจึงพิมพ์และแสดงผลเหมือนต้นฉบับ

ไฟล์ของฉันถูกอัปโหลดขึ้นเซิร์ฟเวอร์ไหม

ไม่ เครื่องมือนี้ทำงานในเบราว์เซอร์ของคุณทั้งหมดด้วยการประมวลผลในเครื่อง ไฟล์ PDF จึงไม่เคยออกจากอุปกรณ์ ทำให้ปลอดภัยสำหรับสัญญาที่เป็นความลับ งบการเงิน และเอกสารส่วนบุคคล

ทำไมไฟล์ PDF ของฉันถึงแสดงชื่อเรื่องผิดในโปรแกรมอ่าน

โปรแกรมสร้าง PDF ส่วนใหญ่คัดลอกชื่อไฟล์หรือชื่อเทมเพลตของเอกสารต้นทางลงในเมตาดาต้าโดยอัตโนมัติ ถ้าไฟล์ Word ต้นฉบับชื่อ "draft_v3" ข้อความนั้นก็จะติดไปกับ PDF ด้วย การแก้ไขช่องชื่อเรื่องที่นี่จะเปลี่ยนมันอย่างถาวร

ฉันลบเมตาดาต้าออกแทนการแก้ไขได้ไหม

ได้ เพียงล้างช่องใดก็ได้ให้ว่างแล้วบันทึก ไฟล์ที่ดาวน์โหลดออกมาจะมีช่องนั้นว่างเปล่า นี่เป็นขั้นตอนที่ทำกันบ่อยก่อนเผยแพร่เอกสารที่คุณไม่อยากให้เห็นชื่อผู้แต่งหรือคำสำคัญภายใน

มีค่าใช้จ่ายหรือจำกัดจำนวนไฟล์ไหม

เครื่องมือนี้ใช้ฟรีอย่างสมบูรณ์ ไม่ต้องสมัครสมาชิก ไม่มีลายน้ำ และไม่จำกัดจำนวนไฟล์ PDF ที่คุณจะแก้ไข จะทำไฟล์เดียวหรือร้อยไฟล์ก็ไม่ต่างกัน

แยกรูปภาพ

ดึงภาพแบบราสเตอร์ที่ฝังอยู่ในไฟล์ PDF ออกมาและดาวน์โหลดเป็นไฟล์ PNG

🔒 ไฟล์ของคุณถูกประมวลผลภายในเบราว์เซอร์ของคุณและไม่เคยถูกอัปโหลด

ดาวน์โหลด

บันทึกไฟล์ที่เสร็จแล้วได้ทันที ไม่มีลายน้ำ

ที่ไหนสักแห่งในไฟล์ PDF นั้นมีรูปที่คุณต้องการอยู่จริง ๆ ไม่ว่าจะเป็นภาพสินค้า โลโก้ หรือกราฟ การจับภาพหน้าจอจะให้สำเนาที่ถูกครอบตัดและถูกบีบอัดมาแล้ว แต่การดึงภาพออกมานั้นต่างออกไป เครื่องมือนี้จะดึงภาพต้นฉบับที่ฝังอยู่ใน PDF ออกมาเป็นไฟล์ PNG ที่ความละเอียดเดียวกับตอนที่ถูกวางลงไปตอนสร้างเอกสาร ทุกภาพที่พบจะถูกรวมไว้ในไฟล์ ZIP เดียวสำหรับดาวน์โหลดครั้งเดียวจบ

การดึงภาพทำงานในเบราว์เซอร์ของคุณทั้งหมด ไฟล์ PDF ถูกเปิดและอ่านบนอุปกรณ์ของคุณเอง ไม่มีการอัปโหลด การดึงรูปออกจากสไลด์ลับ ผลตรวจทางการแพทย์ หรือโบรชัวร์ที่ยังไม่เผยแพร่ จึงไม่ได้แปลว่าคุณต้องยื่นไฟล์นั้นให้เซิร์ฟเวอร์ก่อน ไม่ต้องสร้างบัญชี ไม่มีลายน้ำบนไฟล์ที่ดึงออกมา และไม่จำกัดจำนวนเอกสารหรือจำนวนรูป

มีเรื่องที่ควรรู้อยู่อย่างหนึ่งว่าอะไรถือเป็นรูปภาพบ้าง เครื่องมือนี้กู้ภาพถ่ายและกราฟิกที่ถูกใส่เข้ามาในเอกสารในฐานะไฟล์รูปภาพ ส่วนข้อความ โลโก้แบบเวกเตอร์ และรูปทรงที่วาดขึ้นนั้นเป็นชุดคำสั่งไม่ใช่รูปภาพ จึงจะไม่ปรากฏออกมา และไฟล์ PDF ที่มาจากการสแกนก็คือภาพใหญ่หนึ่งภาพต่อหนึ่งหน้า ซึ่งจะถูกดึงออกมาแบบนั้นตรง ๆ

วิธีดึงรูปภาพออกจากไฟล์ PDF แบบออนไลน์

  1. เปิดเครื่องมือดึงรูปภาพ แล้วลากไฟล์ PDF มาวางบนหน้าเว็บ หรือคลิกเพื่อเลือกไฟล์
  2. เอกสารจะถูกสแกนหารูปภาพที่ฝังอยู่ภายในเบราว์เซอร์ของคุณ ตัวไฟล์ไม่ได้ถูกส่งไปไหนทั้งสิ้น
  3. ดูว่าพบรูปภาพทั้งหมดกี่รูปกระจายอยู่ในหน้าไหนบ้าง
  4. กดปุ่ม Extract เพื่อดึงแต่ละรูปออกมาเป็นไฟล์ PNG
  5. ดาวน์โหลดไฟล์ ZIP ที่บรรจุรูปภาพที่ดึงออกมาทั้งหมด
  6. แตกไฟล์ ZIP แล้วเลือกเก็บเฉพาะรูปที่คุณต้องการ ส่วนที่เหลือก็ลบทิ้งได้

When to use this tool

  • กู้ภาพถ่ายจากไฟล์ PDF ประกาศขายบ้านหรือโบรชัวร์อสังหาริมทรัพย์ เมื่อนายหน้าไม่เคยส่งไฟล์ต้นฉบับมาให้
  • ดึงโลโก้บริษัทหรือภาพสินค้าออกจากชุดสื่อประชาสัมพันธ์เก่า เพื่อนำไปใช้ในพรีเซนเทชันชุดใหม่
  • ดึงภาพประกอบและรูปถ่ายจากรายงานที่คุณเขียนไว้เมื่อหลายปีก่อน หลังไฟล์ต้นฉบับหายไปตอนเปลี่ยนเครื่องแล็ปท็อป
  • รวบรวมภาพถ่ายสินค้าทั้งหมดจากแค็ตตาล็อก PDF ของซัพพลายเออร์มาใช้กับร้านออนไลน์ของคุณ โดยไม่ต้องนั่งจับภาพหน้าจอทีละหน้า
  • เก็บแผนภาพจากสไลด์ที่ส่งออกมาเป็น PDF เพื่อนำไปแก้ไขหรือครอบตัดใหม่ในโปรแกรมตัดต่อภาพ
  • ดึงรูปจากสูจิบัตรงานอีเวนต์หรือจดหมายข่าวมาโพสต์ลงโซเชียลมีเดีย

Tips for the best results

  • รูปที่ดึงออกมาจะมาที่ความละเอียดตามที่ฝังไว้ ซึ่งมักใหญ่กว่าที่เห็นบนหน้ากระดาษ ถือเป็นเซอร์ไพรส์ที่น่ายินดีเมื่อต้องนำไปใช้งานพิมพ์
  • ถ้าเครื่องมือไม่พบรูปภาพเลย ภาพที่คุณเห็นน่าจะเป็นกราฟิกแบบเวกเตอร์หรือข้อความล้วน ลองแปลงหน้านั้นด้วย PDF to PNG เพื่อจับภาพทั้งหน้าออกมาเป็นรูปแทน
  • ไฟล์ PDF บางไฟล์ใช้รูปเดียวกันซ้ำในหลายหน้า จึงอาจเจอไฟล์ซ้ำอยู่บ้างใน ZIP ให้เก็บสำเนาที่ดีที่สุดไว้
  • เอกสารที่มาจากการสแกนจะให้ภาพเต็มหน้าหนึ่งภาพต่อหนึ่งหน้า นั่นคือตัวสแกนเอง เป็นเรื่องปกติ ไม่ใช่ความผิดพลาด
  • เรียงไฟล์ในโฟลเดอร์ที่แตกออกมาตามขนาดภาพ จะช่วยให้หาภาพความละเอียดสูงได้เร็ว เมื่อเอกสารนั้นมีไอคอนเล็ก ๆ ปนอยู่หลายสิบชิ้น

ฉันจะได้รูปที่คุณภาพระดับไหน

แต่ละรูปถูกดึงออกมาที่ความละเอียดเดียวกับตอนที่ฝังไว้ และบันทึกเป็น PNG จึงไม่มีการบีบอัดซ้ำระหว่างทาง ถ้าผู้สร้างเอกสารวางภาพความละเอียดสูงเอาไว้ คุณก็จะได้ภาพนั้น แม้มันจะแสดงผลเล็กนิดเดียวบนหน้ากระดาษก็ตาม

ทำไมการดึงภาพถึงดีกว่าการจับภาพหน้าจอ

ภาพหน้าจอจับรูปมาที่ระดับการซูมของหน้าจอคุณ ซึ่งมักเล็กกว่าและเบลอกว่าต้นฉบับ ส่วนการดึงภาพจะได้ไฟล์ที่ฝังอยู่จริง ๆ ออกมาแบบเต็มขนาดและสะอาด

ไฟล์ PDF ของฉันถูกอัปโหลดระหว่างการดึงภาพไหม

ไม่ ไฟล์ถูกอ่านโดยเบราว์เซอร์บนอุปกรณ์ของคุณเอง และรูปภาพก็ไม่เคยไปอยู่ที่ใดนอกจากเครื่องของคุณ เครื่องมือนี้จึงเหมาะกับเอกสารภายในและเอกสารลับ

ทำไมกราฟิกบางชิ้นถึงไม่ปรากฏในผลลัพธ์

กราฟ โลโก้ และรูปทรงที่วาดขึ้นแบบเวกเตอร์ไม่ใช่ไฟล์รูปภาพที่ฝังไว้ จึงไม่มีอะไรให้ดึงออกมา ให้เรนเดอร์หน้านั้นด้วยเครื่องมือ PDF to PNG เพื่อจับภาพเหล่านั้นออกมาเป็นรูป

ภาพที่ดึงออกมาถูกส่งมอบในรูปแบบไหน

ทุกภาพถูกบันทึกเป็น PNG และแพ็กรวมไว้ในไฟล์ ZIP เดียว เอกสารที่มีรูปสี่สิบรูปจึงยังดาวน์โหลดเพียงครั้งเดียว แตกไฟล์ออกมาแล้วเลือกเก็บเฉพาะที่ต้องการ

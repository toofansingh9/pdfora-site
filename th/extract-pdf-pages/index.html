ดาวน์โหลด

บันทึกไฟล์ที่เสร็จแล้วได้ทันที ไม่มีลายน้ำ

บางครั้งคุณไม่ได้ต้องการทั้งเอกสาร แต่ต้องการแค่สามหน้าที่อยู่ตรงกลางเท่านั้น เครื่องมือแยกหน้าของ PDFora ช่วยให้คุณดึงหน้าที่เลือกไว้ออกจากไฟล์ PDF ใดก็ได้ แล้วบันทึกเป็นไฟล์ใหม่ พิมพ์อะไรทำนอง 1-3, 5, 8 คุณก็จะได้หน้าเหล่านั้นเป๊ะ ๆ ตามลำดับที่ระบุ รวมเป็น PDF ไฟล์ใหม่หนึ่งไฟล์ ส่วนไฟล์ต้นฉบับยังคงเดิมไม่ถูกแตะต้อง

การแยกหน้าเกิดขึ้นบนอุปกรณ์ของคุณทั้งหมด ไฟล์ PDF ถูกอ่านและประกอบใหม่โดยเบราว์เซอร์ ไม่ใช่โดยเซิร์ฟเวอร์ที่ไหน สิ่งที่คุณดึงหน้าออกมา ไม่ว่าจะเป็นสัญญาที่เซ็นแล้ว แบบแสดงรายการภาษี หรือรายงานประเมินราคา จึงไม่เคยถูกส่งไปที่ใดเลย ถ้าคุณเคยลังเลที่จะใช้เครื่องมือ PDF ออนไลน์กับไฟล์ที่มีข้อมูลอ่อนไหว นี่คือทางออก เพราะคำว่าออนไลน์ในที่นี้หมายถึงตัวหน้าเว็บ ไม่ใช่ข้อมูลของคุณ

ไม่ต้องสมัครสมาชิก ไม่มีค่าใช้จ่าย และไม่มีลายน้ำบนผลลัพธ์ จะแยกสองหน้าหรือสองร้อยหน้า จากเอกสารเดียวหรือยี่สิบเอกสาร ก็ทำได้ทุกเมื่อที่ต้องการ ไม่มีอะไรถูกนับเข้าโควตา

วิธีแยกหน้าออกจากไฟล์ PDF ออนไลน์

  1. เปิดเครื่องมือ Extract Pages บน getpdfora.com ด้วยเบราว์เซอร์รุ่นใหม่ตัวใดก็ได้
  2. เพิ่มไฟล์ PDF ของคุณ ด้วยการคลิกเลือกไฟล์หรือลากไฟล์มาวางบนหน้าเว็บ
  3. พิมพ์หน้าที่ต้องการลงในช่องเลือกหน้า จะเป็นหน้าเดี่ยว ช่วงหน้า หรือผสมกันก็ได้ เช่น 1-3, 5, 8
  4. ตรวจทานเลขหน้ากับตัวเอกสารจริงอีกครั้ง เพราะเลขหน้าที่พิมพ์อยู่บนกระดาษไม่ได้ตรงกับลำดับหน้าใน PDF เสมอไป
  5. กดปุ่มแยกหน้า แล้วเบราว์เซอร์จะประกอบหน้าที่เลือกไว้ให้เป็นไฟล์ PDF ใหม่
  6. ดาวน์โหลดผลลัพธ์ ส่วนไฟล์ต้นฉบับของคุณยังคงเหมือนเดิมทุกอย่าง

When to use this tool

  • ดึงเฉพาะหน้าสำหรับลงนามออกจากสัญญาเล่มยาว เพื่อส่งไปให้อีกฝ่ายเซ็นกำกับ
  • แยกบทสรุปผู้บริหารออกจากรายงาน 60 หน้า สำหรับคนที่ไม่ได้จะอ่านส่วนที่เหลือ
  • บันทึกเฉพาะบทความของคุณเองจากวารสารทั้งฉบับหรือไฟล์รวมงานประชุมวิชาการ
  • หยิบเฉพาะหน้าเอกสารแนบที่เกี่ยวข้องออกจากสำนวนคดี แทนที่จะส่งต่อทั้งชุด
  • ดึงสูตรอาหาร ใบงาน หรือแพตเทิร์นเพียงชิ้นเดียวออกจากอีบุ๊กที่ซื้อมาเพื่อสั่งพิมพ์
  • แยกหน้าข้อมูลจำเพาะออกจากคู่มือผลิตภัณฑ์ เพื่อแนบไปกับการแจ้งปัญหาฝ่ายบริการ

Tips for the best results

  • ผสมช่วงหน้ากับหน้าเดี่ยวได้อย่างอิสระ เช่น 2, 5-9, 14 ทำงานตรงตามที่คุณคาดหวังทุกประการ
  • หน้าเอกสารจะเรียงในไฟล์ PDF ใหม่ตามลำดับที่คุณพิมพ์ ดังนั้นให้เขียนรายการตามลำดับที่ต้องการจริง ๆ
  • ลองเปิดไฟล์ PDF ในโปรแกรมอ่านก่อนแล้วจดตำแหน่งหน้าที่โปรแกรมแสดง เพราะหน้าปกเพียงหน้าเดียวก็ทำให้เลขทุกหน้าเลื่อนไปหนึ่งได้
  • ถ้าคุณต้องการลบไม่กี่หน้าออกมากกว่าจะเก็บไว้ไม่กี่หน้า เครื่องมือ Delete Pages คือด้านกลับที่เร็วกว่า
  • แยกหน้าก่อนแล้วค่อยรวมไฟล์ การดึงเฉพาะหน้าที่ดีออกจากเอกสารหลายฉบับก่อน จะทำให้ไฟล์ที่รวมออกมาสะอาดกว่ามาก

คำถามที่พบบ่อย

แยกหน้าที่ไม่ได้อยู่ติดกันออกมาได้ไหม

ได้ ให้คั่นด้วยเครื่องหมายจุลภาค เช่น 1, 4, 9-11 จะดึงหน้าหนึ่ง สี่ เก้า สิบ และสิบเอ็ด ออกมารวมเป็น PDF ไฟล์ใหม่ไฟล์เดียว จะผสมหน้าเดี่ยวกับช่วงหน้าอย่างไรก็ได้

การแยกหน้าทำให้ไฟล์ PDF ต้นฉบับเปลี่ยนไปไหม

ไม่ เครื่องมืออ่านไฟล์ของคุณแล้วสร้าง PDF ไฟล์ใหม่ขึ้นมาจากหน้าที่เลือก เอกสารต้นทางบนอุปกรณ์ของคุณไม่ถูกแก้ไขเลย

ปลอดภัยพอสำหรับเอกสารภาษีหรือเอกสารทางกฎหมายหรือไม่

ปลอดภัย การแยกหน้าทำงานภายในเบราว์เซอร์ของคุณและไฟล์ไม่ถูกอัปโหลด จึงไม่มีใครเห็นเนื้อหาได้ รวมถึง PDFora เองด้วย เป็นความเป็นส่วนตัวระดับเดียวกับการเปิดไฟล์บนเครื่องของคุณเอง

หน้าที่แยกออกมายังคงรูปแบบเดิมไหม

ยังคงเดิม หน้าเอกสารถูกคัดลอกตามสภาพจริง ฟอนต์ รูปภาพ ลิงก์ และเลย์เอาต์จึงติดตามมาครบถ้วน ไม่มีการรวมชั้นหรือบีบอัดซ้ำ

แยกหน้าจาก PDF ที่ตั้งรหัสผ่านไว้ได้ไหม

ไม่ได้ตราบใดที่ไฟล์ยังถูกล็อกอยู่ เพราะเบราว์เซอร์อ่านหน้าของไฟล์ที่เข้ารหัสไม่ได้ ให้ปลดรหัสผ่านออกก่อน (ซึ่งคุณต้องรู้รหัสผ่านนั้น) แล้วค่อยแยกหน้าตามปกติ

มีข้อจำกัดว่าแยกได้กี่หน้าไหม

ไม่มีข้อจำกัดที่กำหนดไว้และไม่มีค่าใช้จ่าย เนื่องจากการทำงานเกิดขึ้นบนอุปกรณ์ของคุณ การแยกหน้าจำนวนมหาศาลจากไฟล์ขนาดใหญ่จึงขึ้นอยู่กับหน่วยความจำที่คุณมี แต่งานทั่วไปเสร็จภายในไม่กี่วินาที

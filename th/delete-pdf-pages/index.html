ดาวน์โหลด

บันทึกไฟล์ที่เสร็จแล้วได้ทันที ไม่มีลายน้ำ

หน้าว่างจากเครื่องสแกน สไลด์ที่ซ้ำกัน หรือใบราคาภายในที่ไม่ควรหลุดไปถึงมือลูกค้าเด็ดขาด ไฟล์ PDF ทุกไฟล์ดูจะมีหน้าสักหน้าสองหน้าที่ต้องกำจัดทิ้งเสมอ และเครื่องมือลบหน้าของ PDFora ก็จัดการให้อย่างเรียบร้อย เพียงพิมพ์หมายเลขหน้าที่ต้องการตัดออก เช่น 2, 5-7 แล้วดาวน์โหลดไฟล์ PDF ใหม่ที่มีทุกอย่างที่เหลืออยู่ครบ

ต่างจากเครื่องมือบนเว็บส่วนใหญ่ PDFora ไม่เคยได้รับไฟล์ของคุณเลย การลบหน้าทำโดยเบราว์เซอร์บนเครื่องของคุณเอง เอกสารที่เต็มไปด้วยชื่อคน ตัวเลข หรือเงื่อนไขการเจรจา จึงอยู่ที่เดิมที่มันเริ่มต้น การลบหน้ามักเป็นเรื่องของการเอาเนื้อหาที่ไม่ควรเผยแพร่ออก มันจึงดูแปลกมากถ้าต้องส่งเอกสารนั้นให้เซิร์ฟเวอร์ของบุคคลที่สามระหว่างทาง

ใช้ฟรี ไม่ต้องสร้างบัญชี ไฟล์ที่ดาวน์โหลดมาไม่มีลายน้ำ และไม่จำกัดว่าคุณจะลบกี่หน้าหรือจัดการเอกสารกี่ไฟล์ ส่วนไฟล์ PDF ต้นฉบับของคุณยังคงอยู่ครบ เผื่อวันหนึ่งหน้าที่ลบไปกลับกลายเป็นเรื่องสำคัญขึ้นมา

วิธีลบหน้าออกจากไฟล์ PDF แบบออนไลน์

  1. เข้าไปที่เครื่องมือ Delete Pages บน getpdfora.com หน้าเว็บโหลดขึ้นมาทันทีโดยไม่ต้องล็อกอิน
  2. เลือกไฟล์ PDF ที่ต้องการตัดแต่ง หรือลากมาวางบนหน้าเว็บได้เลย
  3. ใส่หมายเลขหน้าที่ต้องการลบ ใช้เลขเดี่ยวและช่วงหน้าผสมกันได้ เช่น 2, 5-7
  4. ตรวจตัวเลขให้แน่ใจก่อนไปต่อ การนับหน้าปกผิดคือความผิดพลาดคลาสสิกที่เจอบ่อยที่สุด
  5. กดปุ่มลบ เบราว์เซอร์ของคุณจะประกอบไฟล์ PDF ขึ้นใหม่บนเครื่องโดยไม่มีหน้าเหล่านั้น
  6. ดาวน์โหลดไฟล์ที่ตัดแต่งแล้ว ทุกหน้าที่คุณไม่ได้ระบุไว้ยังอยู่ครบและเรียงตามลำดับเดิม

When to use this tool

  • ตัดหน้าหลังที่ว่างเปล่าซึ่งเครื่องสแกนสองหน้าแทรกไว้ระหว่างหน้าจริงทุกหน้า
  • ลบหน้าราคาที่ล้าสมัยออกจากโบรชัวร์ ก่อนส่งให้ลูกค้าเป้าหมายรายใหม่
  • ตัดหน้าโฆษณาและใบสมัครสมาชิกออกจากไฟล์ PDF ของนิตยสารที่คุณกำลังเก็บเข้าคลัง
  • ลบหน้าฉบับร่างหรือหน้าที่ถูกแทนที่แล้วออกจากสัญญา เพื่อให้มีเพียงฉบับสุดท้ายเท่านั้นที่หมุนเวียนอยู่
  • ตัดหน้าเฉลยออกจากไฟล์ PDF ของใบงาน ก่อนแจกให้นักเรียน
  • ตัดหน้าข้อความมาตรฐานที่ยาวเหยียดออกจากรายงาน เพื่อให้ไฟล์เล็กลงต่ำกว่าขีดจำกัดในการอัปโหลด

Tips for the best results

  • ถ้าจะตัดหน้าติดกันเป็นกลุ่ม ให้ใส่เป็นช่วงแทนการพิมพ์ทีละเลข เช่น 12-19 ย่อมดีกว่าพิมพ์แปดหมายเลขด้วยมือ
  • การลบหน้าคือภาพสะท้อนของการแยกหน้าออกมา ถ้าคุณจะเก็บไว้น้อยกว่าครึ่งเล่ม การดึงเฉพาะหน้าที่ต้องการเก็บออกมาจะเร็วกว่า
  • เปิดไฟล์ผลลัพธ์ไล่ดูก่อนส่งต่อเสมอ โดยเฉพาะเมื่อเลขหน้าถูกพิมพ์ติดอยู่บนตัวหน้ากระดาษเอง
  • ถ้าต้องลบหน้ากระจัดกระจายในไฟล์ยาว ๆ มุมมองภาพย่อของเครื่องมือ Organize จะให้คุณเลือกหน้าที่จะลบด้วยสายตาแทนการพิมพ์เลข
  • เก็บไฟล์ต้นฉบับที่ยังไม่ถูกแตะต้องไว้ จนกว่าเวอร์ชันที่ตัดแต่งแล้วจะทำหน้าที่ของมันเสร็จเรียบร้อย

คำถามที่พบบ่อย

จะลบหลายหน้าออกจาก PDF พร้อมกันได้อย่างไร

ใส่ทั้งหมดในครั้งเดียวโดยคั่นด้วยจุลภาค เช่น 2, 5-7, 11 จะลบหน้าสอง หน้าห้าถึงเจ็ด และหน้าสิบเอ็ดในรอบเดียว ไม่จำเป็นต้องทำซ้ำทีละหน้า

หน้าที่ลบไปแล้วกู้กลับมาจากไฟล์ใหม่ได้ไหม

ไม่ได้ และนั่นคือจุดประสงค์ ไฟล์ PDF ที่ดาวน์โหลดมาถูกสร้างขึ้นโดยไม่มีหน้าเหล่านั้นอยู่เลย ผู้รับจึงขุดมันออกมาไม่ได้ ส่วนไฟล์ต้นฉบับของคุณยังมีทุกหน้าครบ จึงไม่มีอะไรสูญหายในฝั่งของคุณ

ลบหน้าจากเอกสารที่อ่อนไหวผ่านเว็บปลอดภัยไหม

กับ PDFora ปลอดภัย เพราะไฟล์ไม่เคยออกจากเบราว์เซอร์ของคุณ การประมวลผลเกิดขึ้นบนเครื่องของคุณ การลบหน้าที่เป็นความลับจึงไม่ต้องอัปโหลดเอกสารลับนั้นไปที่ไหนเลย

การลบหน้า PDF จะทำให้ลิงก์หรือบุ๊กมาร์กเสียไหม

หน้าที่เหลืออยู่ยังคงเนื้อหาและการจัดรูปแบบไว้ครบถ้วน ส่วนบุ๊กมาร์กหรือลิงก์ภายในที่เคยชี้ไปยังหน้าที่ถูกลบจะไม่มีปลายทางอีกต่อไป ซึ่งเป็นเรื่องปกติของเครื่องมือลบหน้าทุกตัว

ต้องติดตั้งโปรแกรมหรือสมัครสมาชิกไหม

ไม่ต้องทั้งสองอย่าง เครื่องมือทำงานบนเบราว์เซอร์รุ่นใหม่ทุกตัวทั้งบนคอมพิวเตอร์และมือถือ ใช้ฟรี ไม่ต้องมีบัญชี และไม่มีลายน้ำบนผลลัพธ์

รองรับไฟล์ PDF ขนาดใหญ่มากได้ไหม

ได้ ภายในขีดจำกัดของอุปกรณ์คุณเองมากกว่าโควตาของเซิร์ฟเวอร์ เพราะเบราว์เซอร์เป็นผู้ทำงาน ไฟล์หลายร้อยหน้าจึงประมวลผลได้เร็วบนเครื่องส่วนใหญ่ แม้เอกสารสแกนขนาดมหึมาจะต้องการหน่วยความจำมากขึ้นก็ตาม

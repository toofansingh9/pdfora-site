เลือกตัวเลือกของคุณ — ทุกอย่างเกิดขึ้นในเบราว์เซอร์ของคุณ

3

ดาวน์โหลด

บันทึกไฟล์ที่เสร็จแล้วได้ทันที ไม่มีลายน้ำ

แบบฟอร์มส่วนใหญ่เริ่มต้นชีวิตในฐานะเอกสารนิ่ง ๆ ไม่ว่าจะเป็นไฟล์ที่ส่งออกจาก Word ไฟล์สแกน หรือ PDF ที่ออกแบบมาสวยงามแต่กลับคาดหวังให้คนกรอกได้เอง สุดท้ายคนก็ต้องพิมพ์ออกมา เขียนด้วยปากกา แล้วสแกนกลับ หรือไม่ก็มานั่งพิมพ์ทับอย่างทุลักทุเลในโปรแกรมแก้ไข เครื่องมือนี้ยุติวงจรนั้น เพราะมันให้คุณสร้างแบบฟอร์ม PDF ที่กรอกได้จริง ด้วยการวางช่องข้อความและช่องติ๊กแบบโต้ตอบลงบนเอกสารเดิมของคุณได้ทุกตำแหน่ง

ขั้นตอนการทำงานตรงไปตรงมา ไฟล์ PDF ของคุณจะปรากฏบนหน้าจอ คุณคลิกตรงจุดที่ควรมีคำตอบ แล้วช่องกรอกก็จะไปวางอยู่ตรงนั้น ลากช่องเพื่อปรับตำแหน่งให้พอดี ปรับขนาดให้ครอบเส้นว่างที่มันวางทับอยู่ เพิ่มช่องติ๊กข้างตัวเลือกใช่หรือไม่ใช่ เมื่อคุณส่งออกไฟล์ คุณจะได้ PDF แบบ AcroForm ของจริง ซึ่งเป็นรูปแบบฟอร์มโต้ตอบมาตรฐานที่ Adobe Acrobat เบราว์เซอร์ และแอปอ่านเอกสารบนมือถือรู้จักและกรอกได้ทั้งหมด

เอกสารที่คุณกำลังแปลงไม่เคยออกจากคอมพิวเตอร์ของคุณ เพราะทุกอย่างทำงานในเบราว์เซอร์บนเครื่องคุณเอง ไม่ต้องสมัครสมาชิก ไม่มีลายน้ำประทับลงบนแบบฟอร์ม ไม่มีค่าใช้จ่าย และไม่จำกัดจำนวนแบบฟอร์มที่คุณจะสร้าง

วิธีสร้างแบบฟอร์ม PDF ที่กรอกได้แบบออนไลน์

  1. เปิดไฟล์ PDF ที่คุณต้องการทำให้กรอกได้ ไม่ว่าจะเป็นใบสมัคร สัญญา หรือแบบสอบถาม ไฟล์จะถูกโหลดในเบราว์เซอร์บนเครื่องของคุณ
  2. คลิกบนหน้าเอกสารตรงจุดที่ควรมีคำตอบพิมพ์ลงไป ช่องกรอกข้อความจะปรากฏขึ้นตรงจุดนั้น
  3. เพิ่มช่องติ๊กข้างรายการที่เป็นใช่หรือไม่ใช่ หรือตัวเลือกแบบหลายตัวเลือก ด้วยการคลิกลงตำแหน่งที่ต้องการ
  4. ลากแต่ละช่องให้ตรงกับเส้นว่างที่พิมพ์ไว้ และปรับขนาดเพื่อให้คำตอบยาว ๆ มีพื้นที่พอ
  5. ทำซ้ำในทุกหน้า จนกระทั่งทุกคำถามมีช่องกรอกของตัวเอง
  6. ส่งออกไฟล์ คุณจะได้ PDF แบบ AcroForm ที่กรอกได้จริงพร้อมส่งต่อ ผู้รับสามารถกรอกได้ในโปรแกรมอ่าน PDF มาตรฐานทั่วไป

When to use this tool

  • เปลี่ยนใบสมัครเช่าที่ผู้เช่าเคยต้องพิมพ์ออกมาแล้วสแกนกลับ ให้กลายเป็นแบบฟอร์มที่กรอกจบได้บนมือถือ
  • ทำใบสมัครสมาชิกชมรมหรือใบลงทะเบียนงานให้กรอกได้ เพื่อให้คำตอบกลับมาเป็นตัวพิมพ์แทนลายมือ
  • แปลงแบบสอบถามประวัติผู้ป่วยให้เป็นแบบฟอร์มโต้ตอบที่คลินิกส่งอีเมลไปให้กรอกล่วงหน้าก่อนถึงวันนัดได้
  • เพิ่มช่องกรอกลงในเทมเพลตสัญญาฟรีแลนซ์ เพื่อให้พิมพ์ชื่อลูกค้า วันที่ และอัตราค่าจ้างของแต่ละงานได้อย่างเรียบร้อย
  • สร้างใบขออนุญาตผู้ปกครองฉบับสแกนเก่าขึ้นใหม่เป็น PDF ที่กรอกได้ ให้ผู้ปกครองส่งกลับทางอีเมล
  • ใส่ช่องกรอกและช่องติ๊กที่ถูกต้องให้กับเอกสารเบิกค่าใช้จ่ายหรือใบลาภายในองค์กร แทนที่จะปล่อยให้ทุกคนไปแก้ไขตัวไฟล์เอง

Tips for the best results

  • เผื่อขนาดช่องข้อความให้กว้างไว้ก่อน ที่อยู่อีเมลกินพื้นที่มากกว่าที่คุณคิด และช่องที่คับแคบสร้างความหงุดหงิดให้คนกรอก
  • จัดช่องกรอกให้ตรงแนวกับเส้นว่างและป้ายกำกับที่พิมพ์อยู่บนหน้า เอกสารต้นฉบับทำหน้าที่เป็นคำอธิบาย ส่วนช่องของคุณทำหน้าที่รับข้อมูล
  • ใช้ช่องติ๊กกับทุกอย่างที่มีตัวเลือกตายตัว ดีกว่าคาดหวังให้คนพิมพ์เครื่องหมาย X ลงในช่องข้อความ
  • ลองกรอกแบบฟอร์มที่ส่งออกมาด้วยตัวเองสักหนึ่งรอบก่อนส่งจริง การทดสอบสองนาทีช่วยจับช่องที่วางผิดตำแหน่งหรือช่องที่ลืมใส่ได้
  • เก็บไฟล์ฉบับกรอกได้ที่ส่งออกไว้เป็นเทมเพลตต้นแบบ และพิจารณาแฟลตเทนสำเนาที่กรอกเสร็จแล้วในภายหลัง เพื่อไม่ให้คำตอบถูกแก้ไขได้อีก

AcroForm คืออะไร

AcroForm คือรูปแบบมาตรฐานของแบบฟอร์ม PDF แบบโต้ตอบ ซึ่งรองรับโดยโปรแกรมอ่าน PDF แทบทุกตัว ทั้ง Acrobat โปรแกรมดูในเบราว์เซอร์ Preview และแอปบนมือถือ เครื่องมือนี้ส่งออกช่อง AcroForm ของแท้ ไม่ใช่ภาพซ้อนที่ทำเลียนแบบ แบบฟอร์มของคุณจึงกรอกและบันทึกได้ทุกที่

ฉันจำเป็นต้องมีไฟล์ PDF อยู่ก่อนไหมถึงจะเริ่มได้

ใช่ เครื่องมือนี้ทำหน้าที่วางช่องกรอกลงบนเอกสารที่คุณมีอยู่แล้ว เช่น แบบฟอร์มที่ออกแบบไว้ สัญญา หรือไฟล์สแกน คุณสามารถออกแบบเลย์เอาต์ในโปรแกรมใดก็ได้ ส่งออกเป็น PDF แล้วมาวางช่องกรอกที่นี่

ฉันปรับช่องกรอกหลังจากวางไปแล้วได้ไหม

ได้ ทุกช่องสามารถลากไปยังตำแหน่งใหม่และปรับขนาดจากขอบได้ จนกว่าจะวางทับเส้นหรือกล่องที่มันควรอยู่ได้พอดี ช่องที่วางผิดที่แก้ได้ในสองวินาที ไม่ต้องเริ่มใหม่ทั้งหมด

ฉันเพิ่มช่องประเภทใดได้บ้าง

ช่องข้อความสำหรับคำตอบที่พิมพ์ และช่องติ๊กสำหรับตัวเลือก สององค์ประกอบพื้นฐานนี้ครอบคลุมแบบฟอร์มในชีวิตจริงเกือบทั้งหมด ทั้งใบสมัคร แบบฟอร์มรับข้อมูล สัญญา ใบลงทะเบียน และเอกสารอนุมัติ

ผู้รับสามารถบันทึกคำตอบที่กรอกไว้ได้ไหม

ได้ เพราะไฟล์ที่ส่งออกเป็นแบบฟอร์ม PDF ที่กรอกได้ตามมาตรฐาน ผู้รับจึงเปิดในโปรแกรมอ่านสมัยใหม่ตัวใดก็ได้ พิมพ์คำตอบ ติ๊กช่อง แล้วบันทึกหรือส่งไฟล์กลับโดยข้อมูลยังอยู่ครบ

เอกสารที่ฉันอัปโหลดถูกเก็บเป็นความลับไหม

ไม่มีการอัปโหลดตั้งแต่แรก ไฟล์ PDF ถูกประมวลผลในเบราว์เซอร์ของคุณทั้งหมดและไม่เคยแตะเซิร์ฟเวอร์ เมื่อรวมกับการที่ไม่ต้องสมัครสมาชิก ไม่มีลายน้ำ และไม่จำกัดการใช้งาน คุณจึงสร้างแบบฟอร์มที่กรอกได้มากเท่าที่ต้องการโดยไม่เสียค่าใช้จ่าย

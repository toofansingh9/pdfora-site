PDF เป็นข้อความ

ดึงข้อความที่เลือกได้ทั้งหมดออกจากไฟล์ PDF ให้เป็นไฟล์ .txt

🔒 ไฟล์ของคุณถูกประมวลผลภายในเบราว์เซอร์ของคุณและไม่เคยถูกอัปโหลด

ปรับแต่ง

เลือกตัวเลือกของคุณ — ทุกอย่างเกิดขึ้นในเบราว์เซอร์ของคุณ

3

ดาวน์โหลด

บันทึกไฟล์ที่เสร็จแล้วได้ทันที ไม่มีลายน้ำ

ดึงข้อความออกจากไฟล์ PDF แล้วบันทึกเป็นเอกสาร .txt ธรรมดาที่เปิดได้ทุกที่ การนั่งคัดลอกจากโปรแกรมอ่าน PDF ด้วยมือมักทำให้การขึ้นบรรทัดใหม่เพี้ยน ตัวอักษรบางตัวหายไป และกินเวลามหาศาลถ้าเอกสารยาว เครื่องมือ PDF to text นี้จะดึงข้อความที่เลือกได้ทุกบรรทัดจากทุกหน้าในครั้งเดียว แล้วส่งไฟล์ที่สะอาดกลับมาให้คุณ ใช้ฟรี ไม่ต้องสมัครสมาชิก และไม่จำกัดความยาวของเอกสาร

การดึงข้อความทำงานภายในเบราว์เซอร์ของคุณเอง ไฟล์ PDF ถูกอ่านบนอุปกรณ์ของคุณโดยตรง ดังนั้นสัญญา วิทยานิพนธ์ หรือรายงานการเงินจึงไม่เคยถูกอัปโหลดขึ้นเซิร์ฟเวอร์เพียงเพื่อดึงตัวหนังสือออกมา การออกแบบให้ทำงานเฉพาะบนเครื่องแบบนี้ยังทำให้มันเร็วด้วย เพราะไม่ต้องรออัปโหลดแม้ไฟล์จะยาวหลายร้อยหน้า และเมื่อคุณปิดแท็บ ก็ไม่มีร่องรอยของเอกสารหลงเหลืออยู่ที่ใดเลย

มีข้อจำกัดหนึ่งที่เราขอบอกตรง ๆ เครื่องมือนี้อ่านชั้นข้อความที่ฝังอยู่ใน PDF เอกสารที่สแกนมาและหน้าที่ถ่ายด้วยกล้องเป็นเพียงรูปภาพ ไม่มีชั้นข้อความให้ดึง ผลลัพธ์จึงจะว่างเปล่า สำหรับกรณีแบบนั้นให้ใช้เครื่องมือ OCR แทน ซึ่งจะรู้จำตัวอักษรในภาพและเปลี่ยนให้เป็นข้อความจริง

วิธีดึงข้อความออกจากไฟล์ PDF แบบออนไลน์

  1. เปิดเครื่องมือ PDF to text แล้วลากไฟล์ PDF มาวางบนหน้าเว็บ หรือกดเลือกไฟล์จากอุปกรณ์ของคุณ
  2. ไฟล์จะถูกอ่านในเบราว์เซอร์ของคุณทันที โดยไม่มีการอัปโหลดใด ๆ ระหว่างนั้น
  3. ตรวจสอบเร็ว ๆ ถ้าคุณเลือกและคัดลอกข้อความในโปรแกรมอ่าน PDF ทั่วไปได้ การดึงข้อความก็จะทำงานได้ แต่ถ้าหน้าทั้งหมดเป็นภาพสแกน ให้เปลี่ยนไปใช้เครื่องมือ OCR
  4. กดปุ่ม Extract เพื่อดึงข้อความจากทุกหน้าตามลำดับ
  5. ดาวน์โหลดไฟล์ .txt ที่สร้างขึ้น
  6. เปิดด้วยโปรแกรมแก้ไขข้อความใดก็ได้ แล้วจัดระเบียบช่องว่างหรือการขึ้นบรรทัดใหม่ ถ้างานขั้นถัดไปของคุณต้องการความเรียบร้อย

When to use this tool

  • ดึงเนื้อหาทั้งหมดของงานวิจัยมาเป็นไฟล์ .txt เพื่อค้นหา อ้างอิง และจดโน้ตในแอปจดบันทึกของคุณเอง
  • ดึงถ้อยคำในสัญญาออกมาเปรียบเทียบสองเวอร์ชันด้วยเครื่องมือ diff ทีละบรรทัด แทนการเพ่งไฟล์ PDF สองไฟล์วางคู่กัน
  • แปลงอีบุ๊กหรือรายงานให้เป็นข้อความธรรมดาสำหรับโปรแกรมอ่านหน้าจอหรือแอปอ่านออกเสียงระหว่างเดินทาง
  • ป้อนเนื้อหาของเอกสารยาว ๆ เข้าเครื่องมือแปลภาษาหรือ AI สรุปความที่รับเฉพาะข้อความธรรมดา แต่ไม่รับไฟล์ PDF
  • กู้งานเขียนจากไฟล์ PDF เก่าที่ไฟล์ Word ต้นฉบับหายไปนานแล้ว เมื่อคุณจำเป็นต้องกลับมาแก้ไขอีกครั้ง
  • ดึงคำอธิบายสินค้าหรือสเปกจากแค็ตตาล็อก PDF ของซัพพลายเออร์เพื่อนำไปวางในหน้าสินค้าของร้าน

Tips for the best results

  • ทดสอบไฟล์ PDF ก่อน ลองเปิดขึ้นมาแล้วลากเลือกสักประโยค ถ้าไม่มีอะไรถูกไฮไลต์ แสดงว่าเป็นไฟล์สแกน ให้ใช้ OCR แทนการดึงข้อความ
  • เอกสารที่จัดหลายคอลัมน์ เช่น บทความวิชาการ อาจถูกดึงออกมาในลำดับที่กระโดดข้ามคอลัมน์ไปมา ควรอ่านผลลัพธ์คร่าว ๆ ก่อนนำไปใช้จริง
  • หัวกระดาษ ท้ายกระดาษ และเลขหน้าจะติดมากับเนื้อหาด้วย ใช้คำสั่งค้นหาและแทนที่ในโปรแกรมแก้ไขข้อความจะลบส่วนที่ซ้ำ ๆ ออกได้เร็ว
  • ไฟล์ .txt ตัดการจัดรูปแบบทั้งหมดทิ้งโดยธรรมชาติ ดังนั้นเก็บไฟล์ PDF ต้นฉบับไว้ด้วย เผื่อวันหนึ่งคุณต้องการตัวหนา ตาราง หรือเลย์เอาต์เดิม
  • สำหรับเอกสารที่ยาวมาก ลองค้นหาวลีที่คุณรู้ว่าอยู่ใกล้ ๆ ท้ายเล่มในไฟล์ .txt ที่ได้ เป็นวิธีเร็ว ๆ ในการยืนยันว่าทุกหน้าถูกดึงมาครบ

คำถามที่พบบ่อย

ทำไมไฟล์ PDF ของฉันดึงออกมาแล้วได้ไฟล์ข้อความว่างเปล่า

เอกสารนั้นเกือบแน่นอนว่าเป็นไฟล์สแกนหรือรูปถ่าย ซึ่งบรรจุภาพของตัวหนังสือ ไม่ใช่ข้อความจริง ให้นำไปผ่านเครื่องมือ OCR ซึ่งจะรู้จำตัวอักษรในภาพและสร้างข้อความที่แก้ไขได้ออกมา

เอกสารของฉันถูกอัปโหลดระหว่างการดึงข้อความไหม

ไม่ ไฟล์ PDF ถูกอ่านภายในเบราว์เซอร์บนอุปกรณ์ของคุณทั้งหมด ไม่มีการส่ง จัดเก็บ หรือบันทึกล็อกไว้บนเซิร์ฟเวอร์ ซึ่งเป็นสิ่งที่คุณต้องการอย่างยิ่งสำหรับเอกสารกฎหมายและการเงิน

การจัดรูปแบบอย่างตัวหนา ฟอนต์ และตาราง จะยังอยู่ไหม

ไม่ ผลลัพธ์เป็นข้อความธรรมดา สไตล์และเลย์เอาต์จึงถูกตัดทิ้ง และตารางจะถูกแผ่ออกเป็นบรรทัด ข้อแลกเปลี่ยนนี้เองที่ทำให้ .txt เปิดได้ทุกที่และนำไปประมวลผลต่อได้ง่าย

ดึงข้อความจากไฟล์ PDF ขนาดใหญ่มากได้ไหม

ได้ ไม่มีการจำกัดจำนวนหน้า และเพราะไม่มีขั้นตอนอัปโหลด เอกสาร 500 หน้าก็ยังประมวลผลได้เร็ว ข้อจำกัดที่แท้จริงมีเพียงหน่วยความจำของอุปกรณ์คุณเท่านั้น

ข้อความจะออกมาเรียงลำดับถูกต้องไหม

สำหรับเอกสารคอลัมน์เดียวแบบมาตรฐาน ใช่ เรียงทีละหน้าตามลำดับ ส่วนเลย์เอาต์ซับซ้อนที่มีหลายคอลัมน์ แถบข้าง หรือกล่องข้อความ อาจอ่านออกมาในลำดับที่ต่างจากที่สายตากวาด จึงควรตรวจสอบสักหน่อย

ใช้ฟรีจริง ๆ โดยไม่ต้องมีบัญชีใช่ไหม

ใช่ ไม่ต้องสมัครสมาชิก ไม่มีลายน้ำใด ๆ และไม่จำกัดจำนวนไฟล์ PDF ที่คุณจะแปลงเป็นข้อความ ใช้งานได้บนเบราว์เซอร์รุ่นใหม่ทุกตัวทั้งบนคอมพิวเตอร์และมือถือ

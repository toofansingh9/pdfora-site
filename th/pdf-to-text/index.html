PDF เป็นข้อความ

ดึงชั้นข้อความออกจาก PDF มาเป็นไฟล์ .txt ล้วน ที่ค้นหา วาง หรือประมวลผลต่อได้

🔒 ไฟล์ของคุณถูกประมวลผลภายในเบราว์เซอร์ของคุณและไม่เคยถูกอัปโหลด
1

อัปโหลด

เลือกหรือลากแล้ววางไฟล์ของคุณ

2

ปรับแต่ง

เลือกตัวเลือกของคุณ — ทุกอย่างเกิดขึ้นในเบราว์เซอร์ของคุณ

3

ดาวน์โหลด

บันทึกไฟล์ที่เสร็จแล้วได้ทันที ไม่มีลายน้ำ

การคัดลอกข้อความจาก PDF ด้วยมือช้าและเละ การเลือกข้อความกระโดดข้ามคอลัมน์ หัวกระดาษซ้ำทุกหน้า และเอกสารยาวๆ หมายถึงการกดเลือกทั้งหมดหลายสิบรอบ เครื่องมือนี้อ่านข้อความที่เก็บอยู่ใน PDF แล้ว และเขียนทั้งหมดลงไฟล์ข้อความล้วนไฟล์เดียว เรียงทีละหน้า พร้อมใช้กับโปรแกรมแก้ไขข้อความ สเปรดชีต หรือสคริปต์

ต้องเข้าใจก่อนว่า "ข้อความ" ในที่นี้หมายถึงอะไร PDF ที่สร้างจากโปรแกรมพิมพ์เอกสาร เบราว์เซอร์ หรือโปรแกรมบัญชี มีตัวอักษรจริงพร้อมตำแหน่ง PDF.js อ่านตัวอักษรเหล่านั้นทีละหน้า ต่อชิ้นส่วนในแต่ละหน้าด้วยช่องว่าง และคั่นหน้าด้วยบรรทัดว่าง ส่วนหน้าที่สแกนมาเป็นรูปถ่ายของกระดาษ ไม่มีตัวอักษรเลยสักตัว เครื่องมือนี้จึงไม่คืนอะไรให้ สำหรับไฟล์สแกนต้องใช้ OCR ซึ่งรู้จำตัวอักษรในรูป

ผลลัพธ์ตั้งใจให้เรียบที่สุด ไม่มีตัวหนา ไม่มีฟอนต์ ไม่มีตาราง ไม่มีรูป และการขึ้นบรรทัดใหม่ภายในหน้าเดิมไม่ถูกสร้างซ้ำ แต่ละหน้ามาเป็นข้อความยาวต่อเนื่องก้อนเดียว ไฟล์จึงค้นหาง่ายและป้อนเข้าเครื่องมืออื่นได้สะดวก แต่ไม่ใช่วิธีสร้างเลย์เอาต์ของเอกสารขึ้นใหม่ ถ้าเลย์เอาต์สำคัญ PDF เป็น Word คือทางที่ดีกว่า

วิธีดึงข้อความออกจาก PDF

  1. เปิดเครื่องมือ PDF เป็นข้อความ แล้วเลือก PDF หนึ่งไฟล์
  2. คลิก แยกข้อความ ข้อความของแต่ละหน้าจะถูกอ่านตามลำดับ แถบความคืบหน้าขยับทีละหน้า
  3. เมื่อเสร็จ ผลลัพธ์จะบอกว่าประมวลผลไปกี่หน้า ดาวน์โหลดไฟล์ .txt ซึ่งตั้งชื่อตาม PDF ของคุณ (thesis.pdf จะได้ thesis.txt)
  4. เปิดไฟล์ในโปรแกรมแก้ไขข้อความ แล้วค้นหาวลีที่คุณรู้ว่ามีในเอกสาร เพื่อยืนยันว่าข้อความมาครบ
  5. ถ้ามีทั้งหน้าที่ว่างเปล่า แปลว่าหน้านั้นเป็นรูป สำหรับหน้าแบบนั้นให้ใช้เครื่องมือ OCR PDF ซึ่งอ่านรูปหน้าและให้ข้อความเป็นไฟล์ .txt

ควรใช้เครื่องมือนี้เมื่อใด

  • ยกข้อความจากงานวิจัยหรือรายงานมาใส่โน้ตของตัวเองโดยไม่ต้องพิมพ์ใหม่
  • ค้นหาทุกจุดที่พูดถึงคำหนึ่งในสัญญาหรือระเบียบยาวๆ ด้วยฟังก์ชันค้นหาของโปรแกรมแก้ไขข้อความ
  • ป้อนเอกสารเข้าตัวนับคำ เครื่องมือแปลภาษา หรือสคริปต์ที่ต้องการข้อความล้วน
  • กู้ถ้อยคำของเอกสารที่ไฟล์ต้นฉบับแก้ไขได้หายไปแล้ว เพื่อใช้เป็นจุดเริ่มของฉบับใหม่
  • เช็กว่าโปรแกรมอ่านหน้าจอหรือเครื่องมือค้นหาน่าจะเห็นอะไรใน PDF เพราะพวกมันใช้ชั้นข้อความเดียวกัน
  • ดึงตัวเลขออกจากรายการเดินบัญชีเพื่อวางลงสเปรดชีตแล้วจัดให้เรียบร้อย

สิ่งที่ควรรู้ก่อนเริ่ม

  • อ่านเฉพาะชั้นข้อความ หน้าที่สแกน รูปถ่ายเอกสาร และข้อความที่ถูกแปลงเป็นเส้นโครงร่าง จะได้หน้าว่างหรือเกือบว่างในผลลัพธ์
  • ชิ้นส่วนข้อความในหน้าถูกต่อด้วยช่องว่างหนึ่งตัว และหน้าถูกคั่นด้วยบรรทัดว่าง การขึ้นบรรทัดภายในหน้าไม่ถูกเก็บไว้ ย่อหน้าและแถวตารางจึงวิ่งต่อกัน
  • ลำดับการอ่านตามลำดับที่ข้อความถูกเก็บใน PDF ซึ่งมักตรงกับลำดับที่ตาเห็นแต่ไม่เสมอไป เลย์เอาต์สองคอลัมน์ แถบข้าง และเชิงอรรถ อาจออกมาสลับปนกัน
  • หัวกระดาษ ท้ายกระดาษ และเลขหน้าติดมาทุกหน้า เพราะสำหรับ PDF มันคือข้อความธรรมดา
  • PDF บางไฟล์เก็บคำทีละตัวอักษรหรือเว้นระยะแปลกๆ ซึ่งอาจทำให้มีช่องว่างเกินกลางคำ บางไฟล์ใช้ฟอนต์ที่ไม่มีตารางจับคู่ตัวอักษรที่ถูกต้อง ทำให้ได้สัญลักษณ์มั่วแทนตัวอักษร
  • ข้อความในรูป กราฟ และแผนภาพไม่ถูกดึงออกมา รวมถึงข้อความในช่องฟอร์มที่ยังไม่ได้แฟลตเทนลงหน้า คำภาษาอังกฤษที่ถูกตัดด้วยยัติภังค์ข้ามสองบรรทัดใน PDF มักยังแยกกันอยู่ มียัติภังค์และช่องว่างคั่นตรงกลาง ค้นหา '- ' สักครั้งก็เจอเกือบหมด

เคล็ดลับเพื่อผลลัพธ์ที่ดีที่สุด

  • ถ้าผลลัพธ์อ่านไม่รู้เรื่องหรือว่างเปล่า ลองเลือกข้อความในโปรแกรมอ่าน PDF ปกติก่อน ถ้าเลือกตรงนั้นไม่ได้ การดึงข้อความก็จะไม่ได้ผลเช่นกัน ให้ใช้ OCR PDF แทน ซึ่งอ่านรูปหน้าและให้ข้อความเป็นไฟล์ .txt
  • ใช้ค้นหาและแทนที่ในโปรแกรมแก้ไขเพื่อลบหัวและท้ายกระดาษที่ซ้ำในครั้งเดียว แทนการแก้ทีละหน้าด้วยมือ
  • สำหรับตาราง PDF เป็น Excel แยกแถวและคอลัมน์ไว้ให้ ข้อความล้วนจะบีบแต่ละแถวเป็นบรรทัดเดียว
  • บันทึก .txt เป็น UTF-8 ถ้าโปรแกรมถาม ตัวอักษรที่มีเครื่องหมายและอักษรที่ไม่ใช่ละติน (รวมถึงภาษาไทย) ที่ดึงจาก PDF ถูกเก็บเป็น Unicode
  • แยก PDF ขนาดใหญ่มากก่อนถ้าต้องการแค่บทเดียว ไฟล์ข้อความที่เล็กกว่าทำงานด้วยง่ายกว่า ข้อความที่ซ่อนอยู่ เช่น ชั้นข้อความที่ OCR ของโปรแกรมอื่นวางไว้ใต้รูปสแกน ก็ถูกดึงออกมาเหมือนข้อความอื่น

ตัวอย่างจริง: นักศึกษานิติศาสตร์ทำรายการอ่าน

นักศึกษานิติศาสตร์คนหนึ่งมีคำพิพากษา 60 หน้าเป็น PDF ที่ดาวน์โหลดจากเว็บไซต์ศาล และอยากหาทุกย่อหน้าที่อ้างถึงคดีก่อนหน้าคดีหนึ่ง แล้ววางตอนเหล่านั้นลงในโน้ต การเลื่อนและคัดลอกในโปรแกรมอ่าน PDF คอยดึงหัวกระดาษติดมากับทุกย่อหน้า

เธอดึงข้อความแล้วเปิด judgment.txt ในโปรแกรมแก้ไขข้อความธรรมดา ค้นหาชื่อคดีเจอสิบเอ็ดจุด เพราะแต่ละหน้าเป็นข้อความก้อนเดียว เธอจึงนับบรรทัดว่างแล้วรู้คร่าวๆ ว่าแต่ละจุดอยู่หน้าไหน และบรรทัดหัวกระดาษที่โผล่ต้นทุกก้อนหน้าก็มองข้ามได้ง่าย

มีหน้าหนึ่งออกมาว่างเปล่า พอเปิด PDF ดูอีกครั้ง เธอเห็นว่าเป็นเอกสารแนบที่สแกนแทรกไว้ในคำพิพากษา เธอนำคำพิพากษาไปผ่าน OCR PDF คัดลอกข้อความของเอกสารแนบจากไฟล์ .txt นั้น แล้ววางเติมช่องที่ขาดไป บทเรียนนี้ใช้ได้ทั่วไป PDF หนึ่งไฟล์อาจผสมหน้าข้อความจริงกับหน้ารูปภาพ และมีแต่แบบแรกเท่านั้นที่ดึงข้อความได้โดยตรง

การแก้ปัญหา

ไฟล์ข้อความว่างเปล่าหรือมีแต่บรรทัดว่าง
PDF เป็นไฟล์สแกนหรือประกอบด้วยรูปภาพ ให้ใช้เครื่องมือ OCR PDF แทน ซึ่งอ่านรูปหน้าและให้ข้อความเป็นไฟล์ .txt
ผลลัพธ์เต็มไปด้วยสัญลักษณ์แปลกๆ
PDF ใช้ฟอนต์ที่ไม่มีตารางจับคู่ตัวอักษรที่ใช้ได้ จึงแปลงกลับเป็นตัวอักษรไม่ได้ OCR บนหน้าที่เรนเดอร์แล้วมักได้ผลในกรณีที่การดึงข้อความล้มเหลว
คำถูกแยกด้วยช่องว่างเกิน
PDF เก็บข้อความเป็นชิ้นเล็กๆ และเครื่องมือต่อชิ้นส่วนด้วยช่องว่าง ใช้ค้นหาและแทนที่ในโปรแกรมแก้ไขเพื่อเก็บรูปแบบที่เจอบ่อย
คอลัมน์ปนกัน
ข้อความถูกอ่านตามลำดับที่เก็บไว้ ซึ่งในหน้าหลายคอลัมน์อาจกระโดดไปมาระหว่างคอลัมน์ ให้คัดลอกคอลัมน์ที่ต้องการจากโปรแกรมอ่าน PDF หรือใช้ PDF เป็น Word ที่แปลงโดยคำนึงถึงเลย์เอาต์
เครื่องมือเปิด PDF ไม่ได้
ไฟล์อาจใส่รหัสผ่านหรือเสียหาย ลบรหัสผ่านในแอปที่สร้างไฟล์ หรือใช้เครื่องมือซ่อม PDF ก่อน
การขึ้นบรรทัดในย่อหน้าหายไป
เครื่องมือทำงานแบบนั้น แต่ละหน้ากลายเป็นข้อความต่อเนื่องก้อนเดียว วางลงโปรแกรมพิมพ์เอกสารแล้วขึ้นบรรทัดเองตามต้องการ หรือใช้ PDF เป็น Word ถ้าโครงสร้างสำคัญ

คำถามที่พบบ่อย

เครื่องมือนี้อ่าน PDF ที่สแกนได้ไหม?

ไม่ได้ ไฟล์สแกนมีรูปภาพ ไม่มีตัวอักษร ให้ใช้เครื่องมือ OCR PDF แทน ซึ่งอ่านรูปและบันทึกข้อความเป็นไฟล์ .txt

การจัดรูปแบบอย่างตัวหนาและหัวข้อยังอยู่ไหม?

ไม่ ผลลัพธ์เป็นข้อความล้วน ไม่มีฟอนต์ สไตล์ ตาราง หรือรูปภาพ

ทำไมทุกหน้าขึ้นต้นด้วยบรรทัดเดียวกัน?

บรรทัดนั้นคือหัวกระดาษใน PDF ซึ่งเป็นข้อความธรรมดา จึงถูกดึงออกมาทุกหน้า

รองรับภาษาอะไรบ้าง?

ทุกภาษาที่ตัวอักษรถูกเก็บไว้อย่างถูกต้องใน PDF ข้อความถูกเก็บเป็น Unicode ข้อความที่เขียนจากขวาไปซ้ายอาจออกมาตามลำดับที่เก็บ ไม่ใช่ลำดับที่แสดง

ในไฟล์ .txt แต่ละหน้าถูกคั่นอย่างไร?

ข้อความของแต่ละหน้าตามด้วยบรรทัดว่าง หน้าจึงแสดงเป็นก้อนแยกกัน

การดึงข้อความเกิดบนเซิร์ฟเวอร์ไหม?

ไม่ PDF.js อ่านข้อความในเบราว์เซอร์ของคุณ และสร้างไฟล์ .txt ตรงนั้น ซึ่งสำคัญเมื่อเอกสารเป็นร่างสัญญาหรือข้อสอบที่คุณไม่อยากอัปโหลด

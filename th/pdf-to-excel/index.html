PDF เป็น Excel

ดึงตารางออกจาก PDF มาเป็นเวิร์กบุ๊ก Excel (.xlsx) ที่เรียงลำดับ กรอง และคำนวณต่อได้

เหตุผลที่คนอยากแปลง PDF เป็น Excel ส่วนใหญ่คือตาราง เช่น รายการเดินบัญชี ใบราคา ภาคผนวกของรายงาน หรือใบประกาศผลสอบ ใน PDF ตัวเลขดูเป็นระเบียบ แต่ข้างใต้ไม่มีตารางจริง ตัวเลขแต่ละตัวเป็นข้อความแยกชิ้นที่วางไว้ตามตำแหน่งบนหน้า และเส้นที่ดูเหมือนขอบเซลล์ก็เป็นแค่ภาพวาด การคัดลอกจากโปรแกรมอ่าน PDF ไปวางในสเปรดชีตจึงมักกองทุกอย่างไว้ในคอลัมน์เดียว

ตัวแปลงที่ดีจะดูว่าข้อความอยู่ตรงไหน ตัดสินว่าชิ้นไหนเรียงตรงกันในแนวตั้งเป็นคอลัมน์และแนวนอนเป็นแถว แล้วเขียนลงเซลล์สเปรดชีตจริง PDFora ส่ง PDF ไปยังเอนจินแปลงไฟล์ฝั่งเซิร์ฟเวอร์สำหรับงานนี้ (CloudConvert ผ่านตัวส่งต่อของเราเอง) เพราะการวิเคราะห์แบบนี้เกินกว่าที่หน้าเว็บจะทำได้อย่างน่าเชื่อถือ ไฟล์ถูกอัปโหลดผ่านการเชื่อมต่อที่เข้ารหัส แปลงเป็น .xlsx แล้วดาวน์โหลดกลับมาให้คุณ สำเนาที่อัปโหลดจะถูกลบออกจากบริการหลังงานเสร็จ

ไม่มีตัวเลือกให้ตั้ง PDF หนึ่งไฟล์เข้า เวิร์กบุ๊กหนึ่งไฟล์ออก ครอบคลุมทั้งเอกสาร คาดหวังผลที่สะอาดได้จาก PDF ที่ส่งออกจากโปรแกรมบัญชีหรือสเปรดชีต และต้องเก็บกวาดมากขึ้นกับรายงานที่ออกแบบสวยงาม ตารางที่หมุน หรือไฟล์สแกน ตัวเลขยิ่งต้องตรวจเป็นพิเศษ เพราะค่าที่ดูถูกต้องอาจยังถูกเก็บเป็นข้อความ

วิธีแปลง PDF เป็น Excel

  1. เปิดเครื่องมือ PDF เป็น Excel แล้วเลือก PDF หนึ่งไฟล์ ถ้าต้องการแค่ตารางเดียว ให้แยกหน้านั้นออกมาก่อน เวิร์กบุ๊กจะได้ไม่มีอย่างอื่นปน
  2. คลิก แปลง แล้วดูสถานะเปลี่ยนจาก กำลังอัปโหลด… เป็น กำลังแปลง…
  3. รอการดาวน์โหลด เครื่องมือจะถามสถานะจากเซิร์ฟเวอร์ทุกสองสามวินาที และหยุดหลังราวสามนาทีถ้างานยังไม่เสร็จ
  4. บันทึกไฟล์ .xlsx (ชื่อเดิมของไฟล์แต่เป็นนามสกุล .xlsx เว้นแต่เซิร์ฟเวอร์ส่งชื่ออื่นกลับมา)
  5. เปิดเวิร์กบุ๊ก เลือกคอลัมน์ตัวเลข แล้วเช็กว่า Excel มองเป็นตัวเลขจริง เช่น ลองรวมผลคอลัมน์แล้วเทียบยอดกับใน PDF

ควรใช้เครื่องมือนี้เมื่อใด

  • เจ้าของร้านเล็กๆ ที่แปลงใบราคา PDF ของซัพพลายเออร์เป็นชีต เพื่อเพิ่มคอลัมน์กำไรของตัวเอง
  • กระทบยอดรายการเดินบัญชีธนาคารหรือบัตรเครดิตกับรายการในบัญชี
  • องค์กรที่รวบรวมสรุปผลสำรวจซึ่งสำนักงานเครือข่ายส่งมาเป็นรายงาน PDF
  • นักศึกษาที่วิเคราะห์ตารางจาก PDF สถิติที่หน่วยงานเผยแพร่
  • ปรับตารางเรียนหรือตารางเวรที่ได้มาเป็น PDF ให้กรองตามคนหรือตามวันได้
  • ดึงรายการสต็อกออกจากรายงานเก่าที่ไม่มีสเปรดชีตต้นฉบับเหลืออยู่แล้ว

สิ่งที่ควรรู้ก่อนเริ่ม

  • ไฟล์ถูกประมวลผลบนเซิร์ฟเวอร์ ไม่ใช่ในเบราว์เซอร์ของคุณ อัปโหลดแบบเข้ารหัส แปลง แล้วลบออกจากบริการแปลงไฟล์หลังจากนั้น
  • ตารางที่สแกนมาเป็นรูปภาพ ถ้าไม่มีชั้นข้อความก็ไม่มีตัวเลขให้ใส่เซลล์ ทำ OCR PDF ก่อน (ผลลัพธ์แบบ PDF ที่ค้นหาได้) ตัวแปลงจะได้ข้อความจริงไปใช้ แม้เลย์เอาต์ตารางอาจยังต้องจัดเพิ่ม หรือจะเอาตัวเลขออกมาเป็นไฟล์ .txt แล้ววางลงสเปรดชีตเองก็ได้ และต้องตรวจทุกตัวเลข เพราะ OCR อาจอ่านตัวเลขผิด เช่น 1 กับ 7 หรือ 0 กับ 8
  • รูปแบบตัวเลขอาจมาเป็นข้อความ ตัวคั่นหลักพัน สัญลักษณ์สกุลเงิน เครื่องหมายลบที่เขียนเป็นวงเล็บ หรือ CR ต่อท้าย อาจทำให้ Excel ไม่ยอมรับว่าเป็นตัวเลข
  • หัวตารางที่ผสานเซลล์ ข้อความที่ตัดบรรทัดในเซลล์ และแถวที่กินสองบรรทัดใน PDF มักแตกไปเป็นหลายแถวในสเปรดชีต
  • เนื้อหาที่ไม่ใช่ตาราง (ย่อหน้า เชิงอรรถ หัวกระดาษ) ก็ลงไปอยู่ในเซลล์ด้วย เตรียมใจว่าต้องลบออกบ้าง
  • PDF ที่ใส่รหัสผ่านแปลงไม่ได้ ให้ลบการป้องกันก่อนด้วย ปลดล็อก PDF หรือในแอปต้นทาง ถ้าสร้างสูตรยอดคงเหลือสะสมไว้ข้างคอลัมน์ยอดคงเหลือที่แปลงมา สเปรดชีตจะชี้แถวแรกที่ตัวเลขสองค่าไม่ตรงกัน ซึ่งมักเป็นแถวที่ตัวแปลงเลื่อนไป

เคล็ดลับเพื่อผลลัพธ์ที่ดีที่สุด

  • แยกเฉพาะหน้าที่มีตารางออกมาก่อนแปลง เวิร์กบุ๊กจะเล็กและเก็บกวาดง่าย
  • ถ้าตัวเลขชิดซ้ายในเซลล์ แปลว่าเป็นข้อความ ใช้ ข้อมูล > ข้อความเป็นคอลัมน์ โดยไม่ต้องเปลี่ยนอะไร หรือคูณด้วย 1 เพื่อแปลงเป็นตัวเลข
  • เช็กการตั้งค่าภูมิภาค PDF ที่ใช้จุลภาคเป็นจุดทศนิยมอาจทำให้สเปรดชีตที่ตั้งให้ใช้จุดสับสน และกลับกันก็เช่นกัน
  • ลบแถวหัวตารางที่ซ้ำ (หน้าละหนึ่งแถวใน PDF) ด้วยการกรองข้อความหัวตาราง แทนการลบทีละแถวด้วยมือ
  • เทียบยอดรวมอย่างน้อยหนึ่งคอลัมน์กับ PDF ทุกครั้ง ก่อนเชื่อตัวเลขที่แปลงมา

ตัวอย่าง: ฟรีแลนซ์กระทบยอดรายการรายไตรมาส

นักออกแบบฟรีแลนซ์คนหนึ่งได้รายการเดินบัญชี PDF สี่หน้าจากผู้ให้บริการรับชำระเงิน มีรายการเงินเข้า 63 รายการในไตรมาส นักบัญชีของเธอต้องการเป็นสเปรดชีตที่แยกคอลัมน์ชื่อลูกค้า วันที่ ยอดก่อนหัก และค่าธรรมเนียม

เธอแปลง PDF แล้วเปิดเวิร์กบุ๊ก แถวมาครบ แต่ทุกหน้าเริ่มด้วยแถวหัวตารางซ้ำ และคอลัมน์ค่าธรรมเนียมแสดงค่าอย่าง (2.40) สำหรับรายการหัก ซึ่ง Excel อ่านเป็นข้อความ เธอกรองแถวหัวตารางออก ใช้ค้นหาและแทนที่เปลี่ยนวงเล็บเป็นเครื่องหมายลบข้างหน้า แล้วแปลงคอลัมน์เป็นตัวเลข วันที่มาเป็นวันที่จริง เพราะ PDF ใช้รูปแบบปี-เดือน-วันที่ไม่กำกวม

ขั้นสุดท้ายเธอรวมคอลัมน์ยอดก่อนหักแล้วเทียบกับยอดรวมที่พิมพ์ไว้หน้าสุดท้าย ตรงกันถึงหลักสตางค์ จึงรู้ว่าไม่มีแถวไหนหายหรือแตก การเทียบแบบนี้ครั้งเดียวคุ้มค่าที่จะทำกับทุกตารางที่แปลง รายการเดินบัญชีธนาคารมีข้อควรระวังเฉพาะ ธนาคารหลายแห่งพิมพ์ยอดคงเหลือสะสมในคอลัมน์ของตัวเอง และเว้นเซลล์ว่างเมื่อรายการไม่มีถอนหรือไม่มีฝาก หลังแปลง ช่องว่างเหล่านั้นบางทีก็ยุบหายไป ทำให้ยอดฝากเลื่อนไปอยู่คอลัมน์ถอนเฉพาะแถวนั้น การเรียงหรือกรองจะไม่เผยให้เห็น มีแต่ยอดรวม หรือสูตรยอดคงเหลือสะสมที่เทียบกับยอดที่พิมพ์ไว้เท่านั้นที่จับได้ สร้างตัวตรวจนี้ไว้ครั้งเดียวแล้วใช้ชีตเดิมได้ทุกเดือนต่อจากนั้น

การแก้ปัญหา

ทุกอย่างอยู่ในคอลัมน์ A
ตัวแปลงหาคอลัมน์ไม่เจอ มักเพราะ PDF ใช้ช่องว่างจัดแนวข้อความแทนตำแหน่ง ให้ใช้ ข้อมูล > ข้อความเป็นคอลัมน์ แบ่งด้วยช่องว่างหรือความกว้างคงที่
ตัวเลขรวมผลไม่ได้
ตัวเลขถูกเก็บเป็นข้อความ ลบสัญลักษณ์สกุลเงินและตัวคั่นหลักพัน แล้วแปลงเซลล์เป็นตัวเลข เช็กวงเล็บที่ใช้แทนเครื่องหมายลบด้วย
แถวเดียวใน PDF กลายเป็นสองแถวในสเปรดชีต
เซลล์ใน PDF ตัดขึ้นบรรทัดที่สอง ให้รวมสองส่วนด้วยสูตรอย่าง =A2&" "&A3 หรือแก้ด้วยมือ แล้วลบแถวที่เกิน
เวิร์กบุ๊กเต็มไปด้วยรูปภาพแทนตัวเลข
PDF เป็นไฟล์สแกน จึงไม่มีตัวเลขจริงให้แปลง ให้ทำ OCR PDF ก่อนเพื่อให้ค้นหาได้แล้วแปลงสำเนานั้น หรือเอาตัวเลขออกมาเป็นไฟล์ .txt ไม่ว่าทางไหนก็ต้องตรวจทานตัวเลข
งานหมดเวลา
รายงานใหญ่อาจใช้เวลานานกว่าที่เครื่องมือรอไว้ราวสามนาที ให้แยกหน้าที่มีตารางออกมาแล้วแปลงเฉพาะหน้านั้น
การแปลงบนเซิร์ฟเวอร์ล้มเหลว
เช็กว่า PDF ถามรหัสผ่านหรือเสียหายหรือไม่ ลบการป้องกันด้วย ปลดล็อก PDF หรือใช้เครื่องมือซ่อม PDF แล้วลองใหม่

ขึ้นอยู่กับว่าเอนจินแปลงอ่านเอกสารของคุณอย่างไร ตารางหลายหน้ามักถูกแยกตามหน้า ถ้าจำเป็นให้รวมด้วยการคัดลอกวาง หรือ Power Query

สูตรจากสเปรดชีตต้นฉบับจะกลับมาไหม?

ไม่ PDF เก็บแค่ค่าที่แสดง เวิร์กบุ๊กจึงมีตัวเลขและข้อความ ไม่มีสูตรที่สร้างค่าเหล่านั้น

อ่านตารางจากเอกสารสแกนได้ไหม?

ไม่ได้โดยตรง ให้ทำ OCR PDF ก่อน ตัวแปลงจะได้ข้อความจริงไปใช้ แต่ต้องเตรียมจัดเลย์เอาต์และตรวจทุกตัวเลข

ใช้กับ Google Sheets หรือ LibreOffice ได้ไหม?

ได้ ผลลัพธ์เป็นไฟล์ .xlsx มาตรฐานที่ทั้งสองโปรแกรมเปิดได้

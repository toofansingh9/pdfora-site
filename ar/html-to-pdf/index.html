HTML إلى PDF

حوّل ملف HTML محفوظًا إلى PDF عبر خادم تحويل، لتصبح صفحة الويب أو ملف HTML المُصدَّر صفحات ثابتة جاهزة للطباعة.

كثير من المستندات المفيدة لا توجد إلا بصيغة HTML: تأكيد طلب حفظته من المتصفح، أو تقرير صدّره تطبيق ما، أو نشرة بريدية، أو توثيق مولَّد في صفحة واحدة، أو صفحة صممتها بنفسك. صفحة HTML تعيد ترتيب نفسها لتناسب أي نافذة تُفتح فيها، وهذا تحديدًا ما لا تريده حين تحتاج إلى أرشفة المستند أو طباعته أو إرفاقه بمطالبة. ملف PDF يثبّته على مقاس صفحة واحد.

تأخذ هذه الأداة ملف ‎.html أو ‎.htm من جهازك، لا عنوان موقع. يُرفع الملف مشفّرًا إلى خدمة CloudConvert عبر وسيط PDFora، حيث يتولى محرك عرض ترتيب الصفحة وطباعتها إلى PDF، ثم تعود النتيجة باسم ملفك وتُحذف من الخدمة بعد ذلك. التحويل لا يتم داخل متصفحك، ولا توجد في الصفحة إعدادات لمقاس الورق أو الهوامش.

المفاجأة الكبرى لمعظم المستخدمين هي ما يحدث لكل ما يشير إليه ملف HTML. صفحة الويب نادرًا ما تكون ملفًا واحدًا: الصور وأوراق الأنماط والخطوط عادةً ملفات منفصلة يستدعيها ملف HTML. لا يُرفع إلا الملف الذي تختاره، فلا يستطيع الخادم الوصول إلى أي شيء مُشار إليه بمسار نسبي على قرصك. لذلك فإن الحصول على PDF مطابق يعتمد في الأساس على جعل ملف HTML مكتفيًا بذاته قبل تحويله.

طريقة تحويل HTML إلى PDF

  1. تأكد أن ملف HTML مكتفٍ بذاته أو يستخدم عناوين ويب كاملة (https://...) لصوره وأوراق أنماطه؛ راجع الملاحظات أدناه.
  2. افتح أداة HTML إلى PDF واختر ملف ‎.html أو ‎.htm.
  3. انقر «تحويل» وانتظر حتى يُرفع الملف ويُعرض على الخادم.
  4. نزّل ملف PDF، وسيحمل اسم ملفك مع الامتداد ‎.pdf.
  5. تحقّق من ظهور الصور والألوان والتخطيط، ومن أن أي محتوى لم يُقصّ عند الحافة اليمنى.

متى تستخدم هذه الأداة

  • إيصالات وتأكيدات حجز محفوظة من المتصفح تحتفظ بها كملفات PDF للحسابات أو كسجل رسمي.
  • تقارير تصدّرها البرامج بصيغة HTML وتحتاج إلى إرفاقها ببريد إلكتروني أو أرشفتها.
  • مطوّرون يحوّلون قالب فاتورة أو شهادة أو خطاب مولَّدًا بـ HTML إلى PDF لاختبار شكله عند الطباعة.
  • توثيق أو دليل استخدام منشور كصفحة HTML طويلة واحدة، يُطبع للقراءة دون اتصال.
  • مقالات ويب محفوظة لأغراض البحث بصيغة لا تتغير إن تغيّر الموقع.
  • نشرات بريدية محفوظة كـ HTML تُحوَّل لتوثيق ما أُرسل.

ما يجب معرفته قبل البدء

  • الروابط النسبية لا تعمل. إذا كان في ملف HTML مثلًا <img src="images/logo.png"> أو <link href="style.css">، فهذه الملفات تبقى على جهازك ولا يراها الخادم، فيظهر ملف PDF بصور مفقودة ونص بلا تنسيق. استخدم عناوين https:// مطلقة، أو ضع CSS داخل وسم <style> والصور على هيئة data URI.
  • الموارد ذات عناوين الويب المطلقة قد يجلبها الخادم أثناء عرض الصفحة، لذا تظهر عادةً الصور وأوراق الأنماط المتاحة للعموم. أما ما يقع خلف تسجيل دخول أو على شبكة داخلية أو على localhost فلن يظهر.
  • لا يوجد حقل لإدخال رابط. لتحويل صفحة حية احفظها أولًا؛ خيار المتصفح «حفظ الصفحة باسم > صفحة ويب، ملف واحد (‎.mhtml)» غير مقبول، فاختر «صفحة ويب، HTML فقط» وتوقّع غياب الصور النسبية، أو استخدم أمر المتصفح «طباعة > حفظ كملف PDF».
  • أنماط الطباعة تُطبَّق. إذا كان للصفحة CSS خاص بـ ‎@media print فسيستخدمه المحوّل عادةً، وقد يخفي ذلك أشرطة التنقل أو يغيّر الألوان مقارنة بما تراه على الشاشة. ويمكن التحكم في فواصل الصفحات بخاصيتي break-before وbreak-inside في CSS.
  • المحتوى الذي يبنيه JavaScript غير مضمون. الصفحات التي تجلب محتواها بالسكربتات بعد التحميل قد تتحول إلى هيكل فارغ. احفظ الصفحة بعد اكتمال تحميلها، أو أنشئ المحتوى داخل HTML من جهة الخادم.
  • التخطيطات الأعرض من الصفحة المطبوعة، مثل التصاميم الثابتة بعرض 1400 بكسل أو الجداول العريضة، قد تُقصّ أو تُصغَّر. التخطيط المتجاوب أو تحديد max-width للمحتوى الرئيسي يحل ذلك غالبًا.

نصائح لأفضل النتائج

  • في قوالبك الخاصة، ضع كل CSS داخل وسم <style> في <head>؛ إنها الطريقة الأضمن للحصول على PDF منسّق.
  • أضف ‎@page { size: A4; margin: 15mm; } إلى CSS إذا احتجت إلى مقاس صفحة أو هوامش محددة.
  • استخدم break-inside: avoid على صفوف الجداول والبطاقات والأشكال حتى لا تنقسم بين صفحتين.
  • انتبه لأحجام الصور: صورة رئيسية بحجم 5 MB مضمّنة كـ data URI ستنتج ملف PDF بحجم 5 MB أيضًا.
  • افتح ملف HTML في معاينة الطباعة بمتصفحك أولًا؛ إن بدا خاطئًا هناك فالأرجح أنه سيبدو كذلك في ملف PDF المحوَّل.

مثال عملي: قالب فواتير HTML لمتجر صغير

متجر إلكتروني صغير في جدة يديره شخصان يولّد فواتيره كملفات HTML بسكربت بسيط. كل ملف يستدعي invoice.css وlogo.png من المجلد نفسه. عند تحويله مباشرة يخرج ملف PDF نصًا أسود بخط افتراضي، بلا شعار، وجدول المجاميع ممتد بعرض الصفحة كله، لأن الخادم استلم ملف HTML دون ورقة الأنماط والصورة.

الحل أن يصبح الملف مستقلًا بذاته. صار السكربت ينسخ محتوى invoice.css داخل وسم <style>، ويضيف ‎@page { size: A4; margin: 18mm; } وbreak-inside: avoid لصفوف جدول البنود، ويوجّه الشعار إلى عنوانه العام بصيغة https على موقع المتجر بدل المسار المحلي. لا شيء آخر تغيّر.

عند التحويل مرة أخرى تخرج الفاتورة ملف PDF من صفحة A4 واحدة بالشعار وألوان المتجر وجدول مجاميع لم يعد ينقسم حين يحتوي الطلب على بنود كثيرة. ولأن القالب صار مكتفيًا بذاته، فكل فاتورة ينتجها السكربت تتحول بالطريقة نفسها.

حل المشكلات

ملف PDF بلا تنسيق، مجرد نص عادي
ورقة الأنماط مُشار إليها بمسار نسبي ولم تُرفع. ضع CSS داخل وسم <style> أو اربطها بعنوان https:// كامل.
الصور مفقودة
لا يمكن الوصول إلى الصور الموجودة على قرصك عبر مسارات نسبية. استخدم روابط https:// عامة أو ضمّن الصور كـ data URI ثم حوّل من جديد.
الصفحة مقصوصة من اليمين
للتخطيط عرض ثابت أكبر من الصفحة. أضف max-width: 100%‎ للحاويات الرئيسية والصور، أو ورقة أنماط للطباعة تضيّق التخطيط.
ملف PDF فارغ أو شبه فارغ
الأرجح أن المحتوى يُنشأ بـ JavaScript بعد التحميل، أو أن الملف مجرد إعادة توجيه. احفظ الصفحة بعد اكتمال عرضها، أو ضع المحتوى في HTML نفسه.
النص يظهر بخط مختلف
خطوط الويب المُشار إليها محليًا لم تكن متاحة. اربط الخط من عنوان عام، أو ضمّنه بـ ‎@font-face وdata URI، أو استخدم مجموعة خطوط شائعة.
الأداة ترفض ملفي
لا تُقبل إلا الامتدادات ‎.html و‎.htm. ملفات ‎.mhtml أو ‎.webarchive المحفوظة يجب إعادة حفظها كـ HTML فقط.

الأسئلة الشائعة

هل يمكنني تحويل موقع بإدخال رابطه؟

لا. الأداة تحوّل ملف HTML تختاره أنت. احفظ الصفحة كـ HTML أولًا، أو استخدم «طباعة > حفظ كملف PDF» في متصفحك للصفحات الحية.

هل يُرفع ملف HTML؟

نعم. يُرسل مشفّرًا إلى خدمة التحويل، ويُعرض هناك ثم يُحذف. تجنّب تحويل صفحات تحتوي على بيانات شخصية لا تريد أن يعالجها طرف ثالث.

لماذا اختفت صوري وتنسيقات CSS؟

لا يُرفع إلا ملف HTML نفسه. الملفات التي يستدعيها بمسارات نسبية تبقى على جهازك؛ استخدم روابط https:// مطلقة أو ضمّنها في HTML.

هل يمكنني ضبط مقاس الصفحة أو الهوامش؟

ليس من صفحة الأداة. اضبطها داخل HTML بقاعدة ‎@page في CSS، مثل ‎@page { size: A4; margin: 15mm; }.

هل تبقى الروابط قابلة للنقر في ملف PDF؟

الروابط إلى عناوين الويب تبقى قابلة للنقر عادةً. أما الروابط النسبية إلى ملفات محلية أخرى فلن تقود إلى أي مكان مفيد.

هل يعمل JavaScript أثناء التحويل؟

قد يعمل جزئيًا، لكن المحتوى الذي يتأخر تحميله أو يعتمد على تفاعل المستخدم يغيب غالبًا. للحصول على نتيجة موثوقة يجب أن يحتوي HTML على المحتوى النهائي مسبقًا.

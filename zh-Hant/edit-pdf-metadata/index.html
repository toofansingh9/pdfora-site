每一份 PDF 都帶著一層看不見的資訊：標題、作者名稱、主旨與一組關鍵字。搜尋工具、檔案管理程式與文件庫在讀取其他內容之前，會先讀這些欄位。當中繼資料出錯時，例如一份報告的標題是「Untitled」、作者是「user123」，檔案看起來就很隨便，也更難被找到。這項工具讓你直接在瀏覽器中編輯 PDF 中繼資料。

開啟檔案後，現有的標題、作者、主旨與關鍵字會顯示在單純的文字方塊中。改掉需要調整的部分，其餘保持原樣，然後下載一份乾淨的副本。許多 PDF 沿用了多年前建立範本者留下的中繼資料，因此一份客戶提案可能仍把離職同事列為作者。在這裡修正大約只要三十秒，也不必安裝任何軟體。

一切都在你的瀏覽器中本機執行。PDF 不會離開你的電腦，當你在整理合約、病歷或任何機密文件時，這一點格外重要。這項工具免費、不必註冊、不加浮水印，處理的檔案數量也沒有上限。

如何線上編輯 PDF 中繼資料

  1. 點擊上傳區域或把 PDF 拖進去，檔案會在本機開啟，不會送到伺服器。
  2. 檢視自動載入的現有中繼資料：標題、作者、主旨與關鍵字。
  3. 輸入新的標題。多數搜尋工具與閱讀器顯示的就是這段文字，所以請寫得具體一些。
  4. 更新作者欄位，若希望日後更容易找到檔案，也可以調整主旨與關鍵字。
  5. 把想留空的欄位清空，空白欄位總比錯誤內容好。
  6. 點擊套用變更，並下載更新後的 PDF。

When to use this tool

  • 修正那種在每個 PDF 閱讀器中都顯示為「Microsoft Word - draft_v3_FINAL.docx」的報告標題。
  • 把提案寄給客戶之前，先換掉作者欄位裡已離職同事的名字。
  • 為數百份封存的發票加上關鍵字，讓你的文件管理系統真的能在搜尋時找出它們。
  • 在發布電子書或白皮書之前設定正確的 PDF 標題與作者，因為部分搜尋引擎會在結果中顯示中繼資料標題。
  • 在對外分享前清除 PDF 的主旨與關鍵字欄位，把內部專案代號一併移除。
  • 統一一批掃描文件的標題與作者，這些檔案從掃描器出來時全都叫「Scan0001」。

Tips for the best results

  • 中繼資料標題和檔案名稱不是同一回事，有些 PDF 閱讀器會在視窗列顯示中繼資料標題，所以兩者都要設定。
  • 關鍵字之間用逗號分隔；簡短而具體的詞組比冗長句子有效。
  • 匿名發布的文件請把作者欄位清空，因為 PDF 製作軟體常會在你不知情時自動填入。
  • 打算在網路上發布的檔案，標題請比照頁面主標的寫法，因為它可能影響文件在搜尋結果中的呈現。
  • 在組織內維持一致的作者格式，例如「行銷團隊，Acme Ltd」，檔案排序才會有規律。

常見問題

什麼是 PDF 中繼資料？

中繼資料是儲存在 PDF 內部的描述性資訊：標題、作者、主旨與關鍵字。它不會顯示在頁面上，但檔案管理程式、搜尋工具與 PDF 閱讀器會顯示並索引它，就像貼在文件外面的標籤。

編輯中繼資料會改變 PDF 的外觀嗎？

不會。頁面、字型、圖片與版面都維持原樣，只有隱藏的描述性欄位被改寫，因此你下載的文件在列印與顯示上都與原檔完全相同。

我的檔案會上傳到伺服器嗎？

不會。這項工具採用本機處理，完全在你的瀏覽器中執行，PDF 不會離開你的裝置。因此用來處理機密合約、財務報表與個人紀錄都很安全。

為什麼我的 PDF 在閱讀器中顯示錯誤的標題？

多數 PDF 製作程式會自動把來源文件的檔名或範本標題複製到中繼資料裡。如果原始 Word 檔叫「draft_v3」，這串文字就會跟著 PDF 走。在這裡編輯標題欄位就能永久替換它。

我可以移除中繼資料而不是編輯它嗎？

可以。只要把欄位清空再儲存，下載的檔案該欄位就是空的。在不希望顯示作者姓名或內部關鍵字的情況下，這是發布文件前常見的步驟。

會收費或有檔案數量限制嗎？

這項工具完全免費，不必註冊、沒有浮水印，可編輯的 PDF 數量也沒有上限。處理一份或一百份檔案，條件都一樣。

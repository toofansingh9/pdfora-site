重新命名 PDF

替 PDF 取一個乾淨、一致的檔名，並下載成新的副本。

🔒 你的檔案在瀏覽器中本機處理，絕不會上傳。
1

上傳

選擇檔案或直接拖放。

2

選擇你的選項 — 一切都在你的瀏覽器中完成。

立即儲存完成的檔案。沒有浮水印。

檔名比大家想的更重要。「scan_20261003_0007.pdf」或「文件 (3) 最終版 FINAL.pdf」這種名稱，收件人看了一頭霧水，丟進下載資料夾就找不到，有些上傳平台還會因為有空格、括號或名稱太長而直接拒收。在電腦上改名很簡單，但換成手機、權限被鎖住的公司電腦，或只能用瀏覽器的情況，就會意外地麻煩。

這個工具只做一件事：輸入新名稱，它就把 PDF 用這個名稱還給你。Windows、macOS 和大多數平台不接受的檔名字元（反斜線、斜線、冒號、星號、問號、引號、角括號和直線符號）會自動刪除；沒打 .pdf 也會自動補上。輸入框留白就沿用原檔名；清理後如果什麼都不剩，檔案會命名為 document.pdf。開頭和結尾的空格也會被去掉，所以從信件裡複製來、尾巴多一個空格的名稱，不會變成「invoice .pdf」。

有一個細節值得知道。這個工具不只是換掉下載時的名稱，而是用 pdf-lib 打開 PDF 再重新儲存。頁面和內容都不變，但檔案會被重寫，所以大小可能略有不同，文件內部的中繼資料也會更新：pdf-lib 會改寫修改日期，並把自己記錄為製作程式。閱讀器標題列顯示的文件標題是 PDF 內另一個欄位，不會因為改檔名而變動。

如何替 PDF 檔案重新命名

  1. 打開「重新命名 PDF」，加入要改名的 PDF。
  2. 在「新檔名」欄位輸入名稱，例如 2026-10-invoice-0142。要不要加 .pdf 都可以。
  3. 按下「重新命名並下載」，檔案會被載入，再以新名稱儲存。
  4. 把下載的檔案存到需要的位置；瀏覽器可能會問你存放位置，或直接放進「下載」資料夾。
  5. 在檔案總管或 Finder 確認名稱，舊的那份不需要的話就刪掉。

適用情境

  • 接案者用「客戶-年-月-編號」這類固定格式寄發票，雙方日後都好找。名稱有規則，客戶的會計也不用打開檔案就能對上採購單。
  • 學生繳交報告到平台，平台要求「姓名-學號-作業名稱」之類的固定格式。
  • 房東把租賃契約和點交紀錄依物件地址和日期歸檔，不再用掃描器自動產生的名稱。
  • 在手機或平板上改檔名，那裡的檔案管理程式改名特別不順手。
  • 拿掉冒號、斜線、引號等會讓檔案無法上傳或同步到其他系統的字元。
  • 轉寄前先把下載的對帳單或電子票券改成看得懂的名稱。

開始前需要了解

  • 禁用字元 \ / : * ? " < > | 會被直接刪除，不會替換成別的字，所以「Report: Q3」會變成「Report Q3」。空格會保留；如果平台不接受空格，請自己換成連字號。
  • 沒有 .pdf 副檔名會自動補上。已經以 .pdf 結尾（大小寫不拘）的名稱則照你輸入的保留。
  • PDF 會由 pdf-lib 重新儲存，檔案中繼資料裡的修改日期和製作程式欄位會更新。標題、作者和頁面內容維持不變。
  • 有數位簽章的 PDF 不要用這個工具改名。重新儲存會重寫檔案，即使看起來內容完全相同，簽章也會失效。有簽章的檔案請在檔案總管裡改名。
  • 有密碼保護的 PDF 也不適合。工具或許能載入，但存出來的檔案多半打不開。這類檔案請在檔案總管裡改名。
  • 一次處理一個檔案。要大量改名，請對每個檔案重複這些步驟，或用作業系統內建的批次重新命名。同一個檔案改兩次，就會下載兩份；工具不會動到你電腦裡的檔案，原檔會以舊名稱留在原位，直到你自己刪除。

獲得最佳效果的訣竅

  • 檔名開頭放「年-月-日」順序的日期（2026-10-22），在任何資料夾裡都會依時間排好。
  • 用連字號取代空格；經過郵件系統、網址或命令列工具都不會變成 %20。
  • 名稱盡量控制在 60 個字元左右以內，有些平台和舊系統會截斷太長的名稱。
  • 最重要的字放最前面：先客戶名稱、再文件類型、最後編號。大家掃過清單時看的就是開頭。
  • 如果閱讀器裡顯示的標題也要改，請在當初產生檔案的程式裡修改文件內容，改檔名不會動到它。上傳平台有時有自己的命名規定，例如只能小寫或不能有空格；工具不會幫你套用，請依平台要求的格式輸入。

實例：房東整理租屋文件

一位在台中有三間套房出租的房東，用手機掃描 App 掃點交紀錄，產生的檔名像是「Scan 14 Oct 2026 10:42.pdf」。上傳到代管公司的平台時失敗，因為平台不接受檔名有冒號，而她筆電裡的資料夾也只是一排幾乎一模一樣的日期。

她在手機上把每份紀錄依「b房-點交-2026-10-14」的格式重新命名。就算複製到舊名稱裡的冒號，工具也會自動刪掉，再補上 .pdf，平台就順利收件了。資料夾裡的檔案現在會先依房間、再依日期排列。

已簽好的租賃契約她則用另一種做法。那些契約有數位簽章，重新儲存會讓簽章失效，所以她改在手機的檔案管理程式裡改名。這個工具最適合一般 PDF；只要有簽章或密碼，就在檔案系統層級改名。

疑難排解

下載的檔案還是舊名稱
可能因為已經有同名檔案，瀏覽器自動加了編號，或設定成會替重複檔案改名。檢查「下載」資料夾，把舊的副本刪掉。
新名稱裡有些字元不見了
常見系統不允許出現在檔名中的字元（\ / : * ? " < > |）會被自動刪除。原本想放這些字元的地方，請改用連字號或底線。
檔案大小變了一點
PDF 由 pdf-lib 重新儲存，內部物件的存放方式可能不同。頁面一樣，只是內部結構被重寫。
PDF 的數位簽章顯示無效
重新儲存改動了簽章所涵蓋的位元組。請用簽好的原檔，在檔案總管裡改名。
改名後的檔案打不開
原檔可能有加密或已損毀。請在檔案總管裡替原檔改名，或先用「修復 PDF」修好。
閱讀器上方還是顯示舊標題
閱讀器顯示的是 PDF 內儲存的標題，不是檔名。改檔名不會動到那個欄位。
手機上新名稱被截短了
有些手機瀏覽器會縮短很長的下載檔名。名稱盡量簡短，把辨識用的部分放前面。

常見問題

改名會改到 PDF 的內容嗎？

不會，頁面完全一樣。檔案會重新儲存，所以修改日期和製作程式的中繼資料會更新。

哪些字元不能用？

反斜線、斜線、冒號、星號、問號、雙引號、角括號和直線符號都會從名稱中刪除。

結尾一定要打 .pdf 嗎？

不用，沒打會自動補上。

可以一次替好幾個 PDF 改名嗎？

不行，一次一個檔案。數量多的話，用作業系統的批次重新命名比較快。

改名會讓數位簽章失效嗎？

會，因為檔案被重寫了。有簽章的 PDF 請在檔案總管裡改名。

需要付費或註冊嗎？

不用。重新命名完全免費，也不需要帳號。

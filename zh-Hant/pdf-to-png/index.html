PDF 轉 PNG

把 PDF 的每一頁存成無損的 PNG 圖片，清晰度足以呈現圖表、示意圖和小字。

當頁面主要由線條邊緣而不是照片構成時，就該選 PNG。平面圖、電路圖、試算表、數學學習單，以及滿是細線的簡報，在 JPEG 壓縮下都會受損，黑色線條周圍會出現灰色光暈。PNG 會精確儲存每一個像素，所以轉譯出來的頁面，在圖片中看起來和在 PDF 檢視器螢幕上一模一樣。

轉換是逐頁進行的。Firefox 使用的轉譯引擎 PDF.js 會把每一頁畫到畫布上，再把畫布寫出成 PNG 檔。畫布要有多少像素由你決定：「螢幕」以頁面點數尺寸的 1.5 倍繪製（約 108 dpi），「標準」為 2 倍（約 144 dpi，預設值），「高」為 3 倍（約 216 dpi）。由於 PNG 是無損格式，這些預設值是唯一影響品質的因素，而且對檔案大小影響很大。

代價是檔案重量。存成 PNG 的文字頁面通常很精簡，因為大片白色區域很好壓縮；但放了全彩照片的頁面，可能比同一頁存成 JPG 大上好幾倍。如果你的 PDF 是掃描文件或相簿，一般來說 JPG 轉換器比較實際；PNG 的檔案大小，要花在清晰的圖像和文字上才值得。

如何把 PDF 頁面轉成 PNG

  1. 開啟「PDF 轉 PNG」並拖放一個 PDF 檔案。
  2. 選擇「品質」預設值。「標準」適合文件說明和網頁使用；要列印、近距離放大，或要在其他程式中做 OCR 時，值得選「高」。
  3. 按下「轉換」並等待每一頁轉譯完成，進度列每完成一頁前進一格。
  4. 用「全部下載 (.zip)」取得所有頁面，或點按其中一個檔案按鈕下載單張 PNG。
  5. 在其中一張圖片上放大最細的地方，例如尺寸標註或註腳，確認預設值夠高。

適用情境

  • 把施工圖或配線圖放進 wiki、工單或 README，細線必須清楚可讀。
  • 把匯出成 PDF 的上課投影片轉成圖片，上傳到只接受圖片的線上學習平台。
  • 把試算表或表格做成乾淨的圖片，貼到報告或聊天中，每條格線周圍都不會有 JPEG 的灰邊。
  • 提供高解析度的頁面圖片給設計師，在修圖軟體中描圖、裁切或合成。
  • 保存某個頁面（例如已簽名的表單）的精確外觀，供日後比對；任何壓縮瑕疵都會造成困擾。
  • 為 OCR 程式或翻譯工具準備頁面圖片；輸入越銳利、沒有瑕疵，效果越好。

開始前需要了解

  • 頁面是畫在白色背景上的，所以雖然 PNG 格式支援透明，輸出的檔案並不透明。
  • PDF 中的每一頁都會匯出；只想轉換其中幾頁的話，請先用「擷取頁面」把它們切出來。
  • 檔案以原始檔名加上補零的頁碼命名，例如 plans-001.png、plans-002.png，ZIP 檔則叫 plans-png.zip。
  • 可選取的文字、超連結、書籤和表單欄位都不會保留。PNG 只呈現頁面看起來的樣子，僅此而已。
  • 像素尺寸依照 PDF 中儲存的頁面尺寸。A3 圖面在「標準」下約為 1684 x 2382 像素；A4 頁面約為 1191 x 1684。
  • 檔案大小的差異比 JPG 大得多。純文字頁面可能很小；照片多的頁面，或帶雜訊的深色背景，在「高」品質下每頁可能達到好幾 MB。深色投影片和有漸層的頁面，存成 PNG 時壓縮效果很差。如果簡報每一張都是黑底，用「高」會得到很大的檔案，可以考慮改用「標準」。

獲得最佳效果的訣竅

  • 圖文混合的文件可以轉兩次：示意圖頁面用 PNG，照片頁面用 JPG，然後每一頁留下最適合的檔案。
  • 有人要把圖片印出來，或要從中讀 6 pt 的小字時，用「高」；只在螢幕上看，「標準」就很夠了。
  • 如果 PNG 對網站來說太重，維持 PNG 格式，但用圖片最佳化工具處理，可以在不損失像素的情況下縮小檔案。
  • 向量圖請用「高」檢查。在 108 dpi 下看起來斷斷續續的極細線，在 216 dpi 下通常會呈現為連續線條。
  • 把 PDF 和圖片放在一起保存；PDF 仍然是可搜尋、可縮放的主檔。圖片是在轉換當下轉譯的，因此檢視器顯示的註解和評論，只有在 PDF.js 會繪製時才會出現；預設關閉的隱藏圖層則仍會保持隱藏。

實際範例：統包師傅分享平面圖

一位裝修統包師傅從建築師那裡拿到一份 A3 向量 PDF 平面圖，需要透過通訊軟體把各房間尺寸傳給磁磚師傅。磁磚師傅什麼都用手機看，不想跟 PDF 打交道。

轉成 JPG 時，尺寸標註（細線旁邊的灰色小字）邊緣會變得斑駁，放大後 3 和 8 很難分辨。以「高」轉成 PNG，頁面轉譯為約 2526 x 3573 像素，每個標註都清清楚楚，因為沒有套用任何有損壓縮。檔案比 JPG 大，但傳送起來仍然很輕鬆。

師傅也注意到，建築師的圖上有一些細密的剖面線，在「螢幕」品質下會消失。這不是圖面的問題：在 108 dpi 下，那些線就是比一個像素還細。改選「高」就解決了，這也正是要提供三種預設值的主要原因。如果平面圖是紙本掃描而不是向量匯出，結果就不同了：PNG 會忠實重現紙張紋理和灰色雜訊，檔案會很重。掃描檔通常用「標準」轉 JPG 是比較合理的折衷，PNG 則留給必須看清細小標註的頁面。

疑難排解

PNG 檔案超大
PNG 是無損格式，所以照片多的頁面會很大。請改用較低的預設值，或把那些頁面改用「PDF 轉 JPG」轉換。
細線不見了或斷斷續續
在所選解析度下，這些線比一個像素還細。請以「高」重新轉換。
我以為背景會是透明的
頁面是畫在白底上轉譯的，所以輸出不透明。如果需要透明，請在修圖軟體中去背。
工具打不開我的 PDF
通常是因為有密碼或檔案損毀。請在原本的應用程式中移除保護，或試試「修復 PDF」，再轉換修好的副本。
長篇文件只顯示 50 個下載按鈕
為了方便閱讀，清單最多只顯示 50 個按鈕。ZIP 下載檔包含所有頁面。
文字看起來和原稿有點不同
PDF 可能使用了沒有內嵌的字型，PDF.js 以相似字型替代了。請以內嵌字型的方式重新匯出 PDF。

常見問題

PDF 頁面轉 PNG 比轉 JPG 好嗎？

文字、圖表和線條圖的話，是的：PNG 能讓邊緣保持精確。照片和掃描檔則通常用 JPG 就能達到相近的視覺品質，檔案卻小得多。

各預設值對應多少 dpi？

以 PDF 中儲存的頁面尺寸為準，「螢幕」約 108 dpi，「標準」約 144 dpi，「高」約 216 dpi。

PNG 可以是透明背景嗎？

不行。轉譯器在儲存前會先把頁面畫在白底上，所以每張 PNG 都不透明。

我可以從 PNG 複製文字嗎？

不行，文字已經變成像素了。要複製的話請保留 PDF；如果沒有 PDF，可以對圖片執行 OCR。

轉換需要帳號或付費嗎？

不需要。這個工具免費使用，不用登入。

為什麼看起來差不多的頁面，PNG 檔案大小卻不一樣？

PNG 對平坦區域壓縮效果很好，對有雜訊的區域則很差。即使解析度相同，含照片、漸層或掃描紋理的頁面，檔案也會比白底文字頁大得多。

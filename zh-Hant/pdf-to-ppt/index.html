PDF 轉 PowerPoint

把 PDF 轉成 PowerPoint（.pptx）簡報，每一頁變成一張投影片，方便調整後直接上台。

會用到 PDF 轉 PowerPoint 的，通常是兩種情況：一是收到一份 PDF 格式的簡報，需要拿來報告或改寫；二是手上有一份 PDF 報告，想把裡面的頁面做成投影片。兩種需求都很合理，但期待會不太一樣，事先了解轉換後的簡報能給你什麼、不能給你什麼，會很有幫助。

PDF 頁面根本不知道什麼是投影片標題、項目符號層級、動畫或演講者備忘稿。轉換器只能看著頁面，把看到的東西重建出來：一段段文字變成文字方塊，圖片還是圖片，形狀還是形狀，每一頁變成一張投影片。PDFora 是透過伺服器上的轉換引擎（CloudConvert，經由我們的中繼服務呼叫）來完成這件事，因為瀏覽器無法可靠地重建 PowerPoint 物件。你的 PDF 會以加密方式上傳，轉成 .pptx 後傳回，上傳的副本在工作完成後會從該服務中刪除。

這個工具沒有任何設定：整份 PDF 一次轉換，每次一個檔案。投影片尺寸依照 PDF 頁面，所以原本從 PowerPoint 以 16:9 匯出的簡報，轉回來仍是相同比例；A4 報告則會變成偏直長的投影片，要在投影機上好看，得重新規劃。從簡報軟體匯出的檔案通常轉得最好，因為它們的頁面本來就是投影片，文字也是排成幾個大區塊。

如何把 PDF 轉成 PowerPoint

  1. 開啟「PDF 轉 PowerPoint」並選擇一個 PDF 檔案。
  2. 按下「轉換」。檔案會開始上傳，伺服器處理時狀態會變成「轉換中…」。
  3. 等待結果；圖片多的簡報最花時間，工具等待約三分鐘後就會停止。
  4. 儲存 .pptx，檔名通常就是你的 PDF 檔名換上新的副檔名。
  5. 用 PowerPoint、Keynote、Google 簡報或 LibreOffice Impress 開啟，點進幾個文字方塊，看看哪些部分是可編輯文字、哪些是圖片。

適用情境

  • 研討會講者手上只剩去年演講的 PDF 講義，想更新裡面的數據。
  • 學校老師把 PDF 教案轉成投影片，在教室投影使用。
  • 在自己團隊的會議上，重新報告合作單位提供的 PDF 簡報資料。
  • 從報告中取出圖表和示意圖，放進現有的簡報裡。
  • 業務團隊把 PDF 產品型錄改成一份簡短簡報，用在客戶線上會議。
  • 設計師的原始檔找不到時，讓印刷用的 PDF 海報變得可以編輯。

開始前需要了解

  • 轉換在伺服器上執行：PDF 以加密方式上傳，工作完成後會從轉換服務中刪除。
  • 每一頁 PDF 變成一張投影片。原始簡報的投影片母片和版面配置都不會回來；標題和內文會變成一般的文字方塊。
  • PDF 不會儲存動畫、轉場、內嵌影片和演講者備忘稿，所以這些都無法還原。
  • 圖表會以圖片或零散的形狀呈現，而不是背後帶有資料、可編輯的圖表物件。要改數字的話，請重新製作圖表。
  • 掃描頁或存成圖片的頁面，每張投影片只會是一張圖片，沒有可編輯的文字。OCR 可以加上文字層，但無法讓版面變得可編輯。
  • 電腦上沒有的字型在開啟時會被替換，文字可能因此超出方塊。用投影片瀏覽模式，最快能找出哪些投影片轉回來只是一整張平面圖片，而不是分開、可編輯的物件。

獲得最佳效果的訣竅

  • 如果簡報裡有很多用不到的頁面，先擷取有用的頁面；投影片越少，轉換越快，整理起來也越輕鬆。
  • 轉換後套用投影片母片：選取同一類的所有文字方塊，一次設定統一的字型和大小。
  • 用 PowerPoint 的「選取窗格」查看投影片上的每個物件；轉換來的投影片常有許多小文字方塊疊在一起。
  • A4 或 Letter 尺寸的報告，可以考慮把轉換後的內容搬到新的 16:9 投影片上，而不是直接拿直長的頁面來報告。
  • 如果只需要投影片的圖片，「PDF 轉 JPG」或「PDF 轉 PNG」更簡單，也不會有版面上的意外。圖片會保持完全相同的外觀，而講義往往只需要這樣就夠了。

範例：學校重複使用教育局的研習簡報

一所國小的教務主任被交代要為新進教職員重新辦一場校園安全研習。教育局寄來的原始資料是一份從簡報軟體匯出的 24 頁 PDF，她需要更換其中四張投影片上的聯絡人姓名，並加入學校自己的處理流程。

她把 PDF 轉換後開啟 .pptx。因為來源本身就是 16:9 的簡報，投影片比例正確。標題和條列文字都是可編輯的文字方塊，所以改姓名只花了幾分鐘。不過第 9 張的流程圖轉回來是一組分散的形狀和線條，教育局的標誌則是一張圖片。她把流程圖取消群組，修改其中一個方塊，標誌不動，再用自己的版面配置新增三張投影片。

原本的演講者備忘稿和逐項出現的動畫是拿不回來的，因為 PDF 裡從來沒有這些東西。她自己為新投影片寫了簡短的備忘稿。轉換讓她省去重做 24 張投影片的工夫，時間可以花在真正需要修改的地方。每次轉換後都用投影片瀏覽模式快速看一遍，是個好習慣。一眼就能看出哪些投影片保有真正的版面，哪些只是一整張平面圖片，在排練前就知道編輯時間會花在哪裡。一般匯出的簡報，大部分投影片都沒問題，只有少數幾張——通常是以複雜圖表或截圖為主的——需要手動處理。先把這些標出來修好，沒問題的投影片就不要動。

疑難排解

每張投影片都只是一張圖片
PDF 頁面本身就是圖片（掃描檔或以「列印成圖片」方式匯出）。文字無法編輯，只能在上面另外加文字或重新輸入。
文字被拆成很多小方塊
PDF 是以逐行的方式定位文字的。請把方塊中的文字複製出來，每張投影片放進一個新的文字方塊，再刪掉那些碎片。
投影片比例不對
投影片尺寸依照 PDF 頁面而定。請在「設計 > 投影片大小」中修改，並選擇縮放或符合內容。
文字超出方塊
你的電腦沒有原始字型。選取文字，改用已安裝、寬度相近的字型，或把字級稍微調小。
工作逾時
大型、圖片多的 PDF 可能超過工具約三分鐘的等待時間。請把 PDF 分割後分段轉換，再在 PowerPoint 中合併投影片。
伺服器轉換失敗
PDF 可能有保護或已損毀。請先用檢視器開啟檢查，移除保護或執行「修復 PDF」，然後再試一次。

常見問題

動畫和轉場效果會回來嗎？

不會。PDF 不會儲存這些，所以無法還原。請在 PowerPoint 中重新加上。

可以編輯圖表嗎？

圖表通常會以不帶資料的圖片或形狀呈現。數字需要更改的話，請重新製作圖表。

可以在 Google 簡報或 Keynote 中使用嗎？

可以。輸出的是標準 .pptx 檔案，Google 簡報、Keynote 和 LibreOffice Impress 都能開啟。

會包含演講者備忘稿嗎？

不會。備忘稿不是 PDF 頁面的一部分，所以沒有東西可以轉換。

可以一次轉換多個 PDF 嗎？

每次工作只能處理一個 PDF。請逐一轉換；如果它們屬於同一份簡報，也可以先合併。

我的檔案會被上傳嗎？

會。這項轉換在伺服器上執行；PDF 以加密方式傳送，工作完成後會從轉換服務中移除。

批次掃描很有效率，直到你又需要把文件分開為止。把 40 張發票一次送進掃描器，得到的是一份看不出接縫的長篇 PDF。PDFora 的「依文字分割」工具會替你找出那些接縫：選一個關鍵字，例如「發票」，凡是含有該字的頁面就成為新檔案的第一頁。跑一次，這批資料就又變回 40 份獨立文件。

由於文字搜尋在你的瀏覽器本機執行，你分割的發票、薪資單或客戶對帳單都不會被上傳到任何地方。這與伺服器端的分割服務有實質差異——在那些服務中，財務文件處理期間是放在別人的機器上的。PDFora 免費、不必註冊、不加浮水印，檔案數量與分割次數也沒有限制。

「不分大小寫」選項讓 INVOICE、Invoice 與 invoice 都能觸發相同的分割，當文件來自使用不同範本的多家廠商時特別實用。請挑選一個能穩定出現在每份文件首頁、而且只出現在那裡的字詞。

如何線上依關鍵字分割 PDF

  1. 前往 getpdfora.com 開啟「依文字分割」工具。你的檔案將完全在瀏覽器中處理。
  2. 加入合併後的 PDF，例如一批掃描好的發票或對帳單。
  3. 輸入標示每份文件起點的關鍵字，例如「發票」或「帳戶對帳單」。
  4. 如果各份文件的大小寫寫法不一致，請開啟不分大小寫選項。
  5. 點擊分割。凡是出現關鍵字的頁面都會開始一個新檔案。
  6. 確認輸出檔案數量與你預期的文件份數相符，再下載它們。

When to use this tool

  • 以「發票」為分隔字，把一疊掃描的供應商發票拆成一張一檔。
  • 以「員工編號」分割薪資批次檔，拆成一份份薪資單，讓每個人只收到屬於自己的頁面。
  • 申請貸款時，以「帳單期間」把整年合併的銀行對帳單拆開。
  • 以「採購單號」把匯出成單一 PDF 的一整包採購單拆分開來。
  • 以「保單號碼」分割保險批次檔，讓每位客戶的保單證明能分開歸檔。
  • 在逐一列印之前，以「追蹤」把合併的出貨標籤檔案切開。

Tips for the best results

  • 關鍵字必須以可搜尋的文字形式存在。如果你的 PDF 只是沒有 OCR 圖層的影像掃描檔，請先執行 OCR，否則搜尋會一無所獲。
  • 請挑選只出現在首頁的字詞。若「發票」只作為每份文件的抬頭就沒問題；若它也出現在頁尾，請改用「發票號碼：」之類的字串。
  • 詞組通常比單一字詞安全；「統一發票」造成的誤判分割會比只用「發票」少得多。
  • 在處理 500 頁的批次檔之前，先用小樣本測試，並把輸出檔案數與你掃描的文件份數對照。
  • 如果多出一個檔案，通常是因為關鍵字出現在最開頭那一頁，這屬於正常現象；若多出更多，代表你的關鍵字也命中了文件中段的頁面。

常見問題

依文字分割 PDF 是怎麼運作的？

工具會讀取每一頁的文字圖層，每當某頁含有你的關鍵字，就開啟一個新的輸出檔。相符頁面之間的頁面會留在一起，因此每份輸出都是從關鍵字所在頁到下一個相符頁前一頁的完整文件。

為什麼找不到我的關鍵字？

十次有九次是因為這份 PDF 是沒有可選取文字的掃描影像。請試著在 PDF 檢視器中選取文字；如果無法反白任何字，請先對檔案執行 OCR 再進行分割。

不分大小寫的選項重要嗎？

通常很重要。各家廠商的範本在大小寫上並不一致，若一份寫 INVOICE、另一份寫 Invoice，分割結果就會前後不一。除非你確實需要精確比對大小寫，否則建議開啟。

用這個工具處理財務文件安全嗎？

安全，因為它們不會離開你的裝置。搜尋與分割都在你的瀏覽器本機執行，不上傳、不在伺服器端儲存，也沒有任何帳號會與你的檔案綁在一起。

可以用多個字組成的詞組分割嗎？

可以，像「帳戶對帳單」這樣的詞組完全可行，而且通常比單一字詞更精確。詞組愈長、愈具體，就愈不容易在只是提到該字的頁面上誤切。

檔案大小或分割數量有上限嗎？

沒有。PDFora 免費、免註冊、不加浮水印，對頁數、輸出檔案數或處理的批次量都不設上限。超大檔案只是會久一點，因為是你自己的電腦在運算。

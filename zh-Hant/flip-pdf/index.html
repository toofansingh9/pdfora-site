翻轉 PDF 就是把頁面做鏡射：水平翻轉會讓左右對調，垂直翻轉則讓上下顛倒。聽起來像很冷門的需求，直到你真的遇上——要反著印的燙印 T 恤圖樣、掃出來變成鏡像的檔案，或是送去網版印刷、對方要求提供翻轉版原稿的作品。

PDFora 的翻轉工具做的就是這件事，一個方向一鍵搞定。選「水平」，頁面就像照浴室鏡子一樣左右鏡射；選「垂直」，則是上下鏡射。轉換會套用到整份文件，而且下載前可以先預覽結果，不必猜自己到底需要哪個方向。

和 PDFora 上的所有工具一樣，翻轉在你的瀏覽器裡完成，檔案完全不會碰到伺服器。設計稿與文件因此保持私密，而且因為不用等上傳，速度也很快。工具免費、免帳號、不加浮水印，檔案數與頁數都沒有限制。

如何線上翻轉 PDF

  1. 在任何目前版本的瀏覽器中開啟 PDFora 的翻轉 PDF 工具。
  2. 把 PDF 拖到上傳區，或點一下從裝置中選擇檔案。
  3. 選擇方向：「水平」左右鏡射頁面，「垂直」上下鏡射。
  4. 點「翻轉」，讓瀏覽器在本機套用鏡射轉換。
  5. 查看預覽，確認頁面翻轉的方向就是你要的。
  6. 下載鏡像後的 PDF，可直接拿去列印或繼續編輯。

When to use this tool

  • 把設計圖水平鏡射後再印到轉印紙上，燙到布料後圖案才會是正的。
  • 為網版印刷或分色片準備稿件，這類流程通常要求提供反轉的原稿。
  • 修正被設定錯誤的掃描機或拍攝 App 存成鏡像的文件。
  • 把要貼在玻璃內側、從外面觀看的窗貼字樣先做反轉。
  • 翻轉木工或手作用的型板圖樣，讓描繪的那一面最後藏在材料背面。
  • 為需要對照反轉範本練習的書法或招牌字學生，製作鏡像練習頁。

Tips for the best results

  • 做燙印轉印時請用水平翻轉。文字在螢幕上與轉印紙上看起來應該是反的，燙上去之後才會是正的。
  • 別把翻轉和旋轉搞混。垂直翻轉是鏡像，不是旋轉 180 度，文字會變成無法閱讀，而不只是上下顛倒。如果頁面只是上下顛倒，請改用旋轉工具。
  • 列印前先預覽。轉印紙不便宜，花十秒檢查鏡像預覽，就能省下一張浪費掉的紙。
  • 保留未翻轉的原檔。你常常兩個版本都會用到，一份打樣、一份生產。
  • 翻轉是自己的反運算。對鏡像檔再翻一次同方向就會回到原狀，拿來救回掃壞的鏡像檔很方便。

常見問題

水平翻轉和垂直翻轉差在哪裡？

水平翻轉是左右鏡射，就像把頁面拿到鏡子前，文字會變成反的。垂直翻轉則是上下鏡射。兩者都會產生鏡像，差別只在鏡射的軸。

翻轉和旋轉 PDF 是同一件事嗎？

不是。旋轉是把頁面轉向，在新的方向上仍可正常閱讀；翻轉則會產生反著讀的鏡像。如果你的頁面只是躺著或上下顛倒，你要的是旋轉工具。

我究竟為什麼會需要鏡像 PDF？

最常見的原因是轉印列印：燙印、網版印刷與貼在玻璃內側的貼紙，都需要反轉的圖稿，成品才會是正的。鏡像也能修正不小心被拍成鏡像的掃描檔。

翻轉會套用到文件中的每一頁嗎？

會，選定的方向會套用到所有頁面，讓輸出保持一致。如果你只需要翻轉部分頁面，可以先分割 PDF，翻轉需要的那幾頁，再把文件合併回去。

翻轉時我的檔案會被上傳嗎？

不會。鏡射轉換完全在你的瀏覽器中計算，PDF 從不離開你的裝置。機密設計與文件保持私密，而且因為沒有上傳與從伺服器下載的過程，速度也很快。

使用這個工具有費用或限制嗎？

都沒有。翻轉免費、免註冊、不會在頁面上蓋浮水印，檔案大小、頁數與使用次數也都沒有上限。翻一頁或翻一百份文件，都是一樣的。

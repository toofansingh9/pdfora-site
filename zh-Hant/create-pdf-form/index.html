多數表單一開始都是靜態文件：Word 匯出的檔案、一份掃描件，或設計精美卻不知道該怎麼填的 PDF。大家只好列印出來手寫，再掃描回去，或是硬用編輯器在上面打字。這項工具終結了這個循環。它讓你在現有文件上放置真正可互動的文字欄位與核取方塊，做出可填寫的 PDF 表單。

操作流程很直接。PDF 顯示在畫面上，你點一下答案該出現的位置，欄位就放在那裡。拖曳欄位微調位置、調整大小以貼合底下的空白線，並在是／否選項旁加上核取方塊。匯出時，你會得到一份真正的 AcroForm PDF，也就是 Adobe Acrobat、瀏覽器與行動裝置閱讀器都能填寫的標準互動格式。

你要轉換的文件不會離開你的電腦，因為一切都在瀏覽器中本機執行。不必註冊、表單上不會蓋浮水印、不收費，做幾份表單也沒有上限。

如何線上製作可填寫的 PDF 表單

  1. 開啟你想改成可填寫的 PDF，例如申請書、合約或問卷。檔案會在你的瀏覽器中本機載入。
  2. 在頁面上點擊該輸入答案的位置，該處就會出現一個文字欄位。
  3. 在任何是／否項目或多選選項旁點一下，加上核取方塊。
  4. 拖曳每個欄位，讓它對齊列印出來的空白處，並調整大小，讓較長的答案有足夠空間。
  5. 在每一頁重複同樣的動作，直到每個問題都有對應的欄位。
  6. 匯出檔案，你會得到一份真正可填寫的 AcroForm PDF，可以直接寄出，收件者用任何標準 PDF 閱讀器就能填寫。

When to use this tool

  • 把房客過去得列印再掃描的租屋申請表，變成他們用手機就能填完的表單。
  • 讓社團入會表或活動報名表可填寫，收回來的答案是打字而非手寫。
  • 把病患初診問卷改成互動表單，診所可在看診前先用電子郵件寄出。
  • 在接案合約範本上加入欄位，讓每位新客戶的姓名、日期與費率都能乾淨地輸入。
  • 把舊的掃描版家長同意書重製成可填寫的 PDF，家長用電子郵件回傳即可。
  • 為內部報帳單或請假單加上正式欄位與核取方塊，不必再讓同仁自行修改檔案內容。

Tips for the best results

  • 文字欄位寬度要抓得寬鬆一些，電子郵件地址需要的空間比你想的多，太擠的欄位只會讓人惱火。
  • 讓欄位對齊頁面上列印好的空白線與標籤；底層文件提供說明文字，你的欄位負責接收輸入。
  • 凡是選項固定的項目就用核取方塊，別指望大家在文字欄位裡打一個 X。
  • 寄出前先自己把匯出的表單填一次，兩分鐘的測試就能揪出位置錯誤或漏放的欄位。
  • 把匯出的可填寫版本留作母版範本，並考慮日後將填好的副本平面化，讓答案無法再被更動。

常見問題

什麼是 AcroForm？

AcroForm 是互動式 PDF 表單的標準格式，幾乎所有 PDF 閱讀器都支援，包括 Acrobat、瀏覽器檢視器、Preview 與行動 App。這項工具匯出的是真正的 AcroForm 欄位，而非外觀相似的覆蓋圖層，因此你的表單在任何環境都能填寫並儲存。

我一定要先有一份 PDF 才能開始嗎？

是的，這項工具是在你既有的文件上加入欄位，例如設計好的表單、合約或掃描件。你可以用任何軟體排好版面、匯出成 PDF，再到這裡放置欄位。

欄位放好之後還能調整嗎？

可以。每個欄位都能拖曳到新位置，也能從邊緣調整大小，直到剛好蓋在對應的空白線或方框上。放錯位置只要兩秒就能修正，不必重來。

我可以加入哪些欄位類型？

用於輸入答案的文字欄位，以及用於選項的核取方塊，這兩種基本元件足以應付大多數實際表單：申請書、初診表、合約、報名表與簽核文件。

收件者可以儲存填好的答案嗎？

可以。因為匯出的是標準的可填寫 PDF 表單，收件者用任何現代閱讀器開啟後輸入答案、勾選方塊，就能儲存或回傳檔案，資料都會保留。

我上傳的文件會被保密嗎？

根本沒有上傳這回事，PDF 完全在你的瀏覽器中處理，從不接觸伺服器。加上不必註冊、沒有浮水印、沒有使用次數限制，你想做多少可填寫表單都免費。

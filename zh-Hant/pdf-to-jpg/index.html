PDF 轉 JPG

把 PDF 的每一頁轉成獨立的 JPG 圖片，可選螢幕、標準或列印等級的解析度。

在需要圖片的場合，PDF 常常卡卡的。通訊軟體只會把它顯示成一個檔案圖示，簡報不能把它當圖片插入，很多網頁表單和社群平台也只收 JPG 或 PNG。把頁面轉成 JPG 就解決了：每一頁都變成一般的相片式圖片，任何手機、瀏覽器或編輯軟體都能直接開，不需要 PDF 閱讀器。

這個工具的做法說起來很簡單，但值得了解一下。PDF.js 會把每一頁畫到畫布上，和檢視器顯示的樣子完全相同，再把畫布存成品質 0.92 的 JPEG。「品質」選單控制的是像素尺寸，而不是壓縮率：「螢幕」以頁面點數尺寸的 1.5 倍轉譯（約 108 dpi），「標準」為 2 倍（約 144 dpi），「高」為 3 倍（約 216 dpi）。所以一張 A4 頁面，在「螢幕」下約為 893 x 1263 像素，「標準」約為 1191 x 1684，「高」約為 1786 x 2526。

因為結果是一張平面圖片，讓頁面之所以是 PDF 的那些特性全都沒了：文字無法選取或搜尋，連結不能點，表單欄位只剩方框的圖案。JPEG 壓縮也會在銳利的邊緣附近留下淡淡的暈染，例如白底上的黑色小字。照片和掃描檔看不出來；但線條圖、圖表和程式碼截圖，通常改用 PNG 轉換器比較好。

如何把 PDF 轉成 JPG 圖片

  1. 開啟「PDF 轉 JPG」並加入一個 PDF。每次只處理一個檔案，其他檔案請逐一轉換。
  2. 選擇「品質」：「螢幕」適合聊天和 email 預覽，「標準」（預設）適合大多數用途，要印出來或會放大檢視時選「高」。
  3. 按下「轉換」。頁面會一頁一頁轉譯，進度列也隨之前進，所以長篇文件需要一點時間。
  4. 用「全部下載 (.zip)」下載所有頁面，或點按個別的檔案按鈕只存一頁。清單最多只會列出前 50 頁的按鈕。
  5. 張貼或寄出前，挑幾張圖片以 100% 縮放開啟，確認小字仍然看得清楚。

適用情境

  • 在臉書、IG 或 LINE 群組張貼單頁的活動傳單、菜單或公告；圖片能直接顯示，PDF 則不行。
  • 把報告中的某一頁以圖片形式放進 PowerPoint 或 Google 簡報，避免在別人的電腦上跑版。
  • 上傳文件到只接受 JPG 的網頁表單，例如某些考試、求職或公家機關網站，要求以圖片上傳證書掃描檔。
  • 為型錄或電子書製作縮圖或預覽圖，用在商品頁或部落格文章上。
  • 把已簽名的頁面傳給習慣用手機看所有東西、打不開 PDF 附件的人。
  • 把頁面匯入修圖軟體，進行裁切、加註或和其他圖像合成。

開始前需要了解

  • 每一頁都會轉換，沒有頁面範圍選項。如果只需要第 4 到 6 頁，請先用「擷取頁面」，再轉換較小的檔案。
  • 輸出檔以 PDF 檔名加上三位數頁碼命名：report.pdf 會產生 report-001.jpg、report-002.jpg 等，並打包成 report-jpg.zip。補零是為了依名稱排序時順序正確。
  • JPEG 不支援透明。頁面是在白色背景上轉譯的，所以背景透明或空白的 PDF，會產生白色區域，而不是透明區域。
  • 非標準尺寸的頁面會保持原本比例。橫向的試算表頁面會變成寬圖，收據形狀的頁面則會變成又高又窄的圖。
  • dpi 數字是以 PDF 中儲存的頁面尺寸為準。以特殊頁面尺寸存檔的掃描檔，轉譯出的像素尺寸會依照那個頁面尺寸，而不是原始掃描解析度。
  • 轉譯在瀏覽器中進行，所以長篇文件用「高」品質會佔用大量記憶體。200 頁的檔案以 216 dpi 轉換，等於同時要處理大量大尺寸圖片；手機可能會變慢，或重新載入分頁。

獲得最佳效果的訣竅

  • 只在螢幕上看的，用「標準」就好。「高」的像素數是「螢幕」的四倍，多半只是產生沒人會放大看的大檔案。
  • 如果頁面以文字或細線圖為主，也試試「PDF 轉 PNG」比較看看；JPG 會讓邊緣變柔和，PNG 則能保持銳利。
  • 網站有檔案大小上限時，選「螢幕」品質是最快的過關方法，完全不必開修圖軟體。
  • 如果圖片要分開上傳，下載後先重新命名；report-003.jpg 對收件人來說沒什麼意義。
  • 保留原始 PDF。把 JPG 再轉回 PDF，只會得到沒有可選取文字的純圖片文件。

實際範例：咖啡店菜單要上 IG 也要印成看板

一位小咖啡店老闆用文書軟體設計了兩頁菜單，匯出成 A4 PDF。她想把第 1 頁發成 IG 貼文，再把兩頁都印出來裱框放在櫃檯旁。PDF 沒辦法直接發，用手機截圖又會模糊，角落還帶著狀態列。

發 IG 用的，她以「標準」執行「PDF 轉 JPG」。第 1 頁輸出約 1191 x 1684 像素，比 App 需要的還多，在任何手機上都很清楚。看板用的，她再以「高」轉換一次，每頁約 1786 x 2526 像素，印成 A4 大約是每英寸 216 點——對一公尺外閱讀的文字來說綽綽有餘。兩次轉換都會產生 menu-001.jpg 和 menu-002.jpg，所以她分別存到名為 web 和 print 的資料夾。

她唯一特別檢查的是小字的價目表。「螢幕」品質下看得懂但有點糊，「標準」就很清楚了。這是很典型的結果：你用的最小字級越小，需要的設定就越高。

疑難排解

圖片中的文字看起來模糊
把「品質」調高到「高」。如果還是不夠清楚，原始頁面本身可能就是低解析度的掃描；轉譯無法憑空增加 PDF 中沒有的細節。要銳利的文字和線條圖，請用「PDF 轉 PNG」。
PDF 無法載入
檔案可能有密碼保護或已損毀。請在建立它的應用程式中移除密碼，或先用「修復 PDF」處理，然後再試一次。
只有部分頁面有單獨的下載按鈕
結果清單只會為前 50 頁顯示個別按鈕。「全部下載 (.zip)」則一定包含所有頁面。
圖片太大無法上傳
改用「螢幕」設定重新轉換，或在修圖軟體中縮小圖片。JPEG 品質固定為 0.92，所以能調整的是解析度設定。
有些字型或符號跟我的 PDF 檢視器顯示的不一樣
當字型沒有內嵌在 PDF 中時，PDF.js 會用替代字型。請以內嵌字型的方式重新匯出 PDF，再轉換一次。
瀏覽器變慢或分頁重新載入
長篇文件用「高」品質會佔用大量記憶體。請把 PDF 分割成較小的部分，或改用「標準」，並關閉其他吃資源的分頁。

常見問題

JPG 檔案的解析度是多少？

「螢幕」為 PDF 頁面點數尺寸的 1.5 倍，「標準」為 2 倍，「高」為 3 倍，換算約為 108、144 和 216 dpi。A4 頁面在「標準」下約為 1191 x 1684 像素。

可以自己選 JPEG 壓縮等級嗎？

不行。壓縮固定在品質 0.92，可見的瑕疵很少。檔案大小改由解析度預設值控制。

圖片中的文字可以搜尋嗎？

不行。每一頁都是平面圖片。如果之後需要文字，請保留 PDF，或對圖片執行 OCR。

可以只轉換特定頁面嗎？

這個工具不行，它會轉換所有頁面。請用「擷取頁面」做出只含所需頁面的 PDF，再轉換那份檔案。

為什麼 PDF 原本透明的地方變成白色背景？

JPEG 無法儲存透明度，所以頁面是畫在白底上的。如果需要透明，JPG 就不是適合那一頁的格式。

轉換時 PDF 會被上傳嗎？

不會。PDF.js 在你的瀏覽器分頁中轉譯頁面，JPG 也是在那裡產生的，所以這項轉換不會把文件傳到伺服器。

擷取圖片

把 PDF 內嵌的點陣圖抽出來，以 PNG 格式下載。

你真正需要的那張照片，就藏在那份 PDF 裡——可能是產品照、商標，或是圖表。截圖只能得到一份被裁切又被壓縮的副本。擷取則完全不同：這個工具會把 PDF 內嵌的原始影像以 PNG 檔抽出來，解析度就是當初製作文件時放進去的那個解析度。所有找到的影像會打包成一個 ZIP，一次下載完成。

整個擷取過程都在你的瀏覽器裡執行。PDF 是在你自己的裝置上開啟與讀取的，絕不上傳，所以要從機密簡報、醫療報告或尚未發表的宣傳冊中取圖，不必先把檔案交給伺服器。不用註冊帳號，擷取出來的檔案沒有浮水印，文件數與影像數也都沒有上限。

有一點值得先了解：什麼才算「影像」。這個工具能取回以影像檔形式插入文件的照片與圖像。文字、向量商標和繪製的圖形屬於繪圖指令而不是圖片，因此不會出現在結果中；至於掃描版 PDF，本質上每一頁就是一張大圖，擷取出來也正是那樣。

如何線上從 PDF 擷取影像

  1. 開啟擷取影像工具，把 PDF 拖到頁面上，或點一下選檔。
  2. 文件會在你的瀏覽器裡就地掃描內嵌影像；檔案本身哪裡也不會去。
  3. 查看整份文件各頁共找到多少張影像。
  4. 點「擷取」，把每一張都輸出成 PNG 檔。
  5. 下載包含所有擷取影像的 ZIP 壓縮檔。
  6. 解壓縮後挑出你需要的圖片，其餘刪除即可。

When to use this tool

  • 仲介一直沒把原圖寄來時，從房屋物件或建案宣傳 PDF 中把照片救回來。
  • 從舊的媒體資料袋裡取出公司商標或產品圖，用在新的簡報中。
  • 換筆電時原始檔遺失後，從自己多年前寫的報告中把圖表與照片抽出來。
  • 把供應商 PDF 型錄中的所有產品攝影一次收集起來放到網路商店，不必一頁一頁截圖。
  • 把匯出成 PDF 的簡報中的示意圖存下來，方便在影像編輯軟體中修改或重新裁切。
  • 從活動節目單或電子報中取回圖片，發布到社群媒體。

Tips for the best results

  • 擷取出來的影像維持內嵌時的解析度，往往比它在頁面上看起來要大——要拿去印刷時常有驚喜。
  • 如果工具找不到任何影像，那些視覺元素多半是向量圖或純文字。改用 PDF 轉 PNG 把整頁轉成圖片，就能一併保留。
  • PDF 有時會在多頁重複使用同一張圖，所以 ZIP 裡偶爾會有重複檔案；留下最好的那份即可。
  • 掃描文件每頁會產出一張整頁影像。那就是掃描檔本身，屬於正常現象，不是錯誤。
  • 文件裡若同時有幾十個小圖示，解壓後依影像尺寸排序，就能快速找出高解析度的照片。

常見問題

我會得到什麼樣的影像品質？

每張圖片都以內嵌時的解析度擷取，並存成 PNG，過程中不會重新壓縮。如果文件作者當初放的是高解析度照片，你拿到的就是那張，即使它在頁面上顯示得很小。

為什麼擷取比截圖好？

截圖只會依你螢幕的縮放比例擷取畫面，通常比原圖更小也更糊。擷取取回的是真正的內嵌檔案，尺寸完整、畫面乾淨。

擷取過程中我的 PDF 會被上傳嗎？

不會。檔案是由你裝置上的瀏覽器解析的，影像也只存在於你的電腦裡。因此這個工具很適合處理內部與機密文件。

為什麼有些圖形沒有出現在結果裡？

以向量方式繪製的圖表、商標與形狀並不是內嵌的影像檔，所以沒有東西可以擷取。用 PDF 轉 PNG 工具算繪該頁，就能把它們變成圖片保存下來。

擷取出來的影像怎麼交付？

每張影像都會存成 PNG，並打包成一個 ZIP 壓縮檔，所以就算文件裡有四十張圖，也只要下載一次。解壓縮後就能瀏覽並留下需要的部分。

有限制或費用嗎？

沒有。這個工具免費、免註冊、不加浮水印，也不限制 PDF 份數或其中的影像數量。

有時候你要的不是整份文件，而是中間那三頁。PDFora 的擷取工具讓你從任何 PDF 中抽出指定頁面，另存成新檔案。輸入類似 1-3, 5, 8 的內容，就會依照這個順序得到那幾頁，組成一份全新的 PDF，原始檔案則毫髮無傷。

擷取完全在你的裝置上完成。PDF 是由你的瀏覽器讀取與重新組建，而不是遠端伺服器，因此你所擷取的內容——簽好的合約、報稅資料、鑑價報告——都不會被傳送到任何地方。如果你一直不敢用線上 PDF 工具處理機密檔案，這就是解方：「線上」的只有網頁本身，不包括你的資料。

不必註冊、不用付費，輸出也沒有浮水印。不論是抽兩頁還是兩百頁，從一份文件還是二十份，隨時都能用，也不會累計任何額度。

如何線上從 PDF 擷取頁面

  1. 用任何現代瀏覽器前往 getpdfora.com 開啟「擷取頁面」工具。
  2. 點擊選擇器或把檔案拖曳到頁面上，加入你的 PDF。
  3. 在選取欄位輸入想要的頁面——單頁、範圍或兩者混用皆可，例如 1-3, 5, 8。
  4. 對照實際文件再確認一次頁碼；頁面上印的頁碼未必等於 PDF 的實際頁次。
  5. 點擊擷取，瀏覽器就會把選定的頁面組成一份新的 PDF。
  6. 下載結果。你的原始檔案維持原狀，完全沒有變動。

When to use this tool

  • 只抽出長合約中的簽名頁，寄出去請對方會簽。
  • 從 60 頁的報告中擷取執行摘要，給那些不會讀完全文的人。
  • 從整期期刊或研討會論文集 PDF 中，只留下自己的那篇論文。
  • 從訴訟文件中取出相關的證物頁，而不是把整包資料轉寄出去。
  • 從購買的電子書中抽出某道食譜、學習單或版型來列印。
  • 從產品手冊中取出規格頁，附加到客服工單裡。

Tips for the best results

  • 範圍與單頁可以自由混用——2, 5-9, 14 的結果完全如你所想。
  • 新 PDF 中的頁面會依你列出的順序排列，所以請按想要的順序書寫。
  • 先在檢視器中打開 PDF 並記下實際的頁次位置，因為多一張封面就可能讓所有頁碼位移一頁。
  • 如果你是想刪掉幾頁而不是留下幾頁，「刪除頁面」工具是更快的反向做法。
  • 先擷取再合併：先從各份文件中挑出需要的頁面，合併後的檔案會乾淨許多。

常見問題

可以擷取不連續的頁面嗎？

可以。用逗號分隔即可——1, 4, 9-11 會把第 1、4、9、10、11 頁抽進同一份新 PDF。單頁與範圍的任何組合都沒問題。

擷取頁面會改到我的原始 PDF 嗎？

不會。工具會讀取你的檔案，再用選定的頁面建立一份全新的 PDF。你裝置上的來源文件完全不會被修改。

用來處理報稅或法律文件夠隱密嗎？

夠。擷取在你的瀏覽器本機執行，檔案不會上傳，因此沒有任何人（包括 PDFora）看得到內容。隱密程度就跟你在自己電腦上打開檔案一樣。

擷取出來的頁面會保留原本的格式嗎？

會。頁面是原樣複製的，字型、影像、連結與版面都完整保留，不會被平面化或重新壓縮。

可以從有密碼保護的 PDF 擷取頁面嗎？

在鎖定狀態下不行——瀏覽器無法讀取加密檔案的頁面。請先移除密碼（你必須知道密碼），再正常擷取。

可擷取的頁數有上限嗎？

沒有固定上限，也不收費。由於作業在你的裝置上進行，從超大檔案中做超大量擷取時，唯一的限制是你可用的記憶體，但一般工作幾秒就能完成。

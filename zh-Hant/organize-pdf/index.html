當你很清楚要改哪裡時，用頁碼就夠了；不確定的時候，你會想「看見」整份文件。PDFora 的整理工具會把 PDF 的每一頁排成縮圖版面，讓你拖曳調整順序、把掃歪掃橫的頁面轉正，並標記要刪除的頁面——全部在同一個畫面完成，最後匯出一份修好的檔案。

整個版面都在你的瀏覽器中運作。你的 PDF 在本機算繪與重組，不會被上傳，因此你可以放心重排租約、病歷或薪資批次文件的頁面，而這些檔案不會碰到任何人的伺服器。這也代表不必等待上傳：再厚的檔案，開啟速度就看你的裝置畫得多快。

以上功能全部免費、不需帳號，匯出的 PDF 也沒有浮水印。改一頁或翻修五十頁都行，要來回幾次才把文件弄對都沒關係。

如何線上重新排序與整理 PDF 頁面

  1. 前往 getpdfora.com 開啟「整理 PDF」工具並載入你的檔案。
  2. 稍候片刻，每一頁都會以縮圖形式出現在版面上。
  3. 把任一縮圖拖到新位置即可重新排序——版面會即時更新。
  4. 對橫躺或上下顛倒的頁面點擊旋轉控制項，直到方向正確為止。
  5. 把不要的頁面標記為刪除；它們會在版面上標示出來，正式套用前你隨時能改變主意。
  6. 點擊匯出，下載已套用新頁序、旋轉與刪除的完成版 PDF。

When to use this tool

  • 修正掃描結果：一疊紙送進饋紙器時順序顛倒或被弄亂了。
  • 把一份直式報告中的兩張橫式圖表轉正，其他頁面完全不動。
  • 依投稿規定把附錄移到參考文獻之前。
  • 合併簡報後章節交錯混在一起，重新整理成一份可用的講義。
  • 以視覺方式檢視 40 頁的申請文件包，送件前把重複頁抽掉。
  • 重排作品集頁面，讓每次提案時最強的作品都排在最前面。

Tips for the best results

  • 在同一次作業中一併處理旋轉、排序與刪除——一次匯出勝過分別跑三個工具。
  • 旋轉是逐頁套用的，所以你可以只把一張歪掉的掃描頁轉正，而不會動到整份文件。
  • 被標記刪除的頁面在你匯出之前都還在，把那些標記當成可隨時修改的候選清單即可。
  • 縮圖很小；當兩頁長得很像時，請放大檢視或同時打開原檔，確保你搬動的是正確的那一頁。
  • 在手機上請把裝置轉成橫向，拖曳時螢幕能容納更多版面內容。

常見問題

沒有 Acrobat 要怎麼重新排列 PDF 頁面？

把檔案載入 PDFora 的整理工具，將頁面縮圖拖成你想要的順序，再匯出即可。它能在任何現代瀏覽器中執行，免費，也不必安裝任何軟體。

可以只旋轉其中一頁，而不是整份 PDF 嗎？

可以。每張縮圖都有各自的旋轉控制項，你能把單獨一張橫式掃描頁轉正，其他頁面完全不受影響。

可以同時刪除頁面又重新排序嗎？

可以。標記要刪的頁面、把其餘頁面拖到定位、把歪掉的頁面轉正，所有變更都會在一次匯出的 PDF 中同時套用。

整理過程中我的文件會被上傳嗎？

不會。縮圖是由你自己的瀏覽器算繪，編輯後的 PDF 也在本機組建，因此檔案在任何階段都不會離開你的裝置。

為什麼大檔案的縮圖要等一下才出現？

你的瀏覽器要替每一頁畫出預覽，頁數多或圖片多的 PDF 需要算繪的內容自然更多。速度取決於你的裝置而非伺服器，版面一旦載入完成，拖曳就毫無延遲。

匯出會影響頁面品質嗎？

不會。排序、旋轉與刪除都屬於結構性變更，頁面內容本身不會被重新壓縮，因此文字與影像進去是什麼樣，出來就是什麼樣。

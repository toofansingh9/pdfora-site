HTML 轉 PDF

在轉檔伺服器上把儲存好的 HTML 檔案轉成 PDF，讓網頁或 HTML 匯出檔變成固定、可列印的頁面。

🔒 你的檔案在瀏覽器中本機處理，絕不會上傳。

很多實用的文件只有 HTML 版本：從瀏覽器存下來的訂單確認頁、某個 App 匯出的報表、電子報、產生成單一頁面的說明文件，或是你自己做的網頁。HTML 會隨著視窗大小重新排版，但當文件要歸檔、列印或附在申請資料裡時，你要的偏偏不是這種特性。轉成 PDF 就能把它固定在一種頁面尺寸上。

這個工具接受的是你電腦裡的 .html 或 .htm 檔案，不是網址。檔案會經由 PDFora 的中繼，以加密方式上傳到 CloudConvert 服務，由那裡的轉譯引擎排版並輸出成 PDF；結果會以你的原檔名傳回，之後從該服務刪除。轉換不是在你的瀏覽器裡進行，工具頁面上也沒有頁面尺寸或邊界的設定。

大多數人最意外的，是 HTML 檔案所引用的那些東西會怎樣。網頁很少只有一個檔案：圖片、樣式表和字型通常都是另外的檔案，由 HTML 去引用。上傳的只有你選的那一個檔案，所以凡是以相對路徑指向你硬碟上的東西，伺服器都找不到。要得到忠實的 PDF，關鍵幾乎都在轉換前先讓 HTML 檔案自給自足。

如何把 HTML 轉成 PDF

  1. 確認 HTML 檔案是自給自足的，或圖片和樣式表都使用完整網址（https://...）；詳見下方說明。
  2. 開啟「HTML 轉 PDF」，選擇 .html 或 .htm 檔案。
  3. 按下「轉換」，等待檔案上傳並在伺服器上轉譯。
  4. 下載 PDF，檔名與原檔相同，副檔名改為 .pdf。
  5. 檢查圖片、顏色和版面是否都有出來，右側邊緣有沒有內容被切掉。

適用情境

  • 從瀏覽器存下的收據和訂房確認信，轉成 PDF 留作報帳或法律紀錄。
  • 軟體以 HTML 匯出的報表，需要夾在電子郵件裡寄出或歸檔。
  • 工程師把程式產生的 HTML 發票、證書或信件範本轉成 PDF，檢查列印版面。
  • 以一整頁長 HTML 發布的說明文件或使用手冊，印出來離線閱讀。
  • 存下來做研究用的網路文章，保存成不會因網站改版而變動的格式。
  • 存成 HTML 的電子報，轉成 PDF 作為寄送紀錄。

開始前需要了解

  • 相對路徑的連結會失效。如果 HTML 裡寫的是 <img src='images/logo.png'> 或 <link href='style.css'>，那些檔案留在你的電腦裡，伺服器看不到，PDF 就會缺圖、文字也沒有樣式。請改用絕對的 https:// 網址，或把 CSS 寫進 <style> 區塊、圖片改成 data URI 內嵌。
  • 使用絕對網址的資源，伺服器在轉譯頁面時可能會去抓取，所以公開可存取的圖片和樣式表通常都會出現。需要登入、放在內部網路或 localhost 上的則不會。
  • 沒有輸入網址的欄位。要轉換線上網頁，得先存檔；瀏覽器「另存網頁」裡的「網頁，單一檔案（.mhtml）」不被接受，請選「網頁，僅 HTML」，並預期相對路徑的圖片會不見；或直接用瀏覽器的「列印 > 另存為 PDF」。
  • 列印樣式會套用。如果頁面有 @media print 的 CSS，轉檔器通常會採用它，因此導覽列可能被隱藏、顏色也可能和螢幕上看到的不同。分頁位置可以用 CSS 的 break-before 和 break-inside 控制。
  • 由 JavaScript 產生的內容不可靠。載入後才用程式抓取內容的頁面，轉出來可能只剩空殼。請在頁面完全載入後再存檔，或在伺服器端就把內容寫進 HTML。
  • 比列印頁面還寬的版面，例如固定 1400 像素的設計或很寬的表格，可能會被切掉或縮小。改用響應式版面，或替主要內容設定 max-width，通常就能解決。

獲得最佳效果的訣竅

  • 自己的範本請把所有 CSS 放進 <head> 裡的 <style> 區塊，這是取得有樣式 PDF 最可靠的方法。
  • 需要特定頁面尺寸或邊界時，在 CSS 加上 @page { size: A4; margin: 15mm; }。
  • 在表格列、卡片和圖片上使用 break-inside: avoid，避免被拆到兩頁。
  • 圖片大小要合理：以 data URI 內嵌一張 5 MB 的主視覺圖，PDF 一樣會是 5 MB。
  • 先在瀏覽器的預覽列印裡開啟 HTML 檔案；如果那裡看起來就不對，轉出的 PDF 多半也不對。

實例：小網店的 HTML 發票範本

一家兩個人經營的網路商店，用一支簡單的程式把發票產生成 HTML 檔案。每個檔案都連結到同一個資料夾裡的 invoice.css 和 logo.png。直接轉換的話，PDF 只有預設字型的黑色純文字，沒有 logo，金額合計表還被拉滿整個頁寬，因為伺服器收到的 HTML 檔案沒有附帶樣式表和圖片。

解法是讓檔案能獨立存在。現在程式會把 invoice.css 的內容複製進 <style> 區塊，加上 @page { size: A4; margin: 18mm; }，在品項表格的每一列設定 break-inside: avoid，並把 logo 改成指向商店網站上的公開 https 網址，而不是本機路徑。其他都沒變。

再轉一次，發票就成了一頁 A4 的 PDF，有 logo、有商店的配色，品項很多的訂單，合計表也不會再被拆開。因為範本現在是自給自足的，程式產生的每一張發票都能用同樣的方式順利轉換。

疑難排解

PDF 沒有樣式，只有純文字
樣式表是用相對路徑引用的，沒有被上傳。請把 CSS 內嵌在 <style> 區塊，或用完整的 https:// 網址連結。
圖片不見了
以相對路徑引用的本機圖片無法取得。請改用公開的 https:// 網址，或把圖片內嵌成 data URI 後再轉一次。
頁面右側被切掉
版面設了比頁面還寬的固定寬度。替主要容器和圖片加上 max-width: 100%，或寫一份讓版面變窄的列印樣式表。
PDF 是空白或幾乎空白
內容可能是載入後才由 JavaScript 產生，或檔案只是一個轉址頁。請在頁面完全轉譯後再存檔，或直接在 HTML 裡產生內容。
文字變成別的字型
以本機路徑引用的網路字型無法使用。請從公開網址連結字型、用 @font-face 搭配 data URI 內嵌，或改用常見的字型組合。
工具不接受我的檔案
只接受 .html 和 .htm。存成 .mhtml 或 .webarchive 的檔案，需要重新以「僅 HTML」儲存。

常見問題

可以輸入網址直接轉換網站嗎？

不行。這個工具轉換的是你選擇的 HTML 檔案。請先把頁面存成 HTML，或對線上頁面使用瀏覽器的「列印 > 另存為 PDF」。

HTML 檔案會被上傳嗎？

會。檔案會加密傳送到轉檔服務，在那裡轉譯後刪除。含有你不希望交給第三方處理的個人資料的頁面，請避免用這個工具轉換。

為什麼我的圖片和 CSS 不見了？

上傳的只有 HTML 檔案本身。它以相對路徑引用的檔案都還留在你的電腦裡；請改用絕對的 https:// 連結，或把它們內嵌在 HTML 中。

可以設定頁面尺寸或邊界嗎？

工具頁面上不行。請在 HTML 裡用 CSS 的 @page 規則設定，例如 @page { size: A4; margin: 15mm; }。

PDF 裡的連結可以點嗎？

指向網址的連結通常仍可點擊。指向其他本機檔案的相對連結則不會連到有用的地方。

轉換時會執行 JavaScript 嗎？

可能會執行一部分，但較晚載入或需要使用者操作才出現的內容常常會缺漏。想要穩定的結果，HTML 本身就應該已經包含最終內容。

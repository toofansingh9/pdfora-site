保護 PDF

為 PDF 加上密碼加密，只有對的人才能開啟。

🔒 你的檔案在瀏覽器中本機處理，絕不會上傳。

有些 PDF 不該讓任何人都打得開：薪資通知、合約、醫療檢驗結果、財務報表。PDFora 的「加密保護」工具會為 PDF 加上密碼加密，只有知道密碼的人才能開啟。設定密碼、下載加密後的檔案，然後放心分享，就算郵件被轉寄或隨身碟遺失，內容也不會外洩。

在你繼續往下讀之前，先誠實說明一件事：加密保護功能正在 PDFora 上逐步推出，目前標示為「即將推出」。本頁描述的正是它上線時的運作方式，讓你先知道會有什麼。和 PDFora 的每項工具一樣，它將免費、不必註冊、不加浮水印，而且加密會在瀏覽器本機進行，你的文件與密碼都不會傳送到伺服器。

最後這一點值得強調。若要為 PDF 設密碼，卻得先把未受保護的檔案上傳到別人的電腦，那實在很奇怪。PDFora 的做法是把整個流程留在你的裝置上：檔案在你的瀏覽器中完成加密，只有加密後的副本會離開你的電腦，而且必須是你自己決定要分享時才會。

如何線上為 PDF 設定密碼保護

  1. 在 getpdfora.com 開啟「加密保護」工具，選擇你要加密的 PDF。檔案會在瀏覽器中載入，不會上傳。
  2. 輸入開啟文件時要求的密碼。
  3. 再輸入一次確認，這裡若打錯字，你會被鎖在自己的檔案外面。
  4. 套用保護。工具會在你的裝置上本機加密這份 PDF。
  5. 下載受保護的副本。之後任何人開啟它時，都會被要求輸入密碼。
  6. 密碼請與檔案分開傳遞，用電話或另一個通訊軟體，絕不要放在同一封郵件裡。

When to use this tool

  • 把薪資單或在職證明 PDF 寄給房貸業務前先加密。
  • 鎖住客戶合約，只有拿到密碼的交易對象才能讀到條款。
  • 在把匯出的病歷或檢驗報告放進共用雲端資料夾之前先加以保護。
  • 為要寄送給群組名單的董事會文件或財務報表設定密碼。
  • 把護照或身分證掃描檔寄給訂房代理之前先加密。
  • 在把懲處通知、薪資考核等人資文件存到辦公室共用磁碟前先加密。

Tips for the best results

  • 請使用由三、四個不相關詞語組成的通行短語，而不是很短的密碼；它更強韌，用電話轉述也更容易。
  • 絕不要用傳送檔案的同一個管道傳密碼。PDF 用電子郵件寄，密碼用簡訊傳。
  • 把密碼存放在可靠的地方，例如密碼管理程式；PDF 密碼一旦忘記，依設計往往無法救回。
  • 在安全的私人位置保留一份未加密的副本，這樣你永遠不會被自己的文件擋在門外。
  • 上傳到任何地方之前先加密：先保護檔案，再放到雲端儲存或寄出。

常見問題

「加密保護」工具現在可以用了嗎？

它目前標示為即將推出，正在 PDFora 上逐步上線。如果你現在就急需加密 PDF，可以先使用值得信賴的桌面軟體，例如 LibreOffice（匯出 PDF 時設定密碼）或 Adobe Acrobat。

它會像其他工具一樣免費嗎？

會。上線後，加密保護將遵循與 PDFora 其他工具相同的原則：免費、無使用上限、不必註冊，加密後的檔案上也不會蓋浮水印。

我的檔案或密碼會被送到伺服器嗎？

不會。加密將在瀏覽器本機執行，也就是 PDF 在你自己的裝置上完成加密，密碼從不離開這台裝置。只有完成加密的檔案會存進你的下載資料夾。

PDF 密碼加密的強度如何？

現代 PDF 加密採用 AES，與銀行和政府系統使用的是同一族加密演算法。實際的弱點幾乎永遠是密碼本身，所以請選一個夠長、無法從你的姓名或生日猜出來的密碼。

如果我忘記密碼會怎樣？

真正的加密沒有後門，因此沒有重設連結，PDFora 也無法幫你重設。請把 PDF 密碼當成家門鑰匙看待：記錄在密碼管理程式中，並把重要文件的未加密副本妥善保存在安全的地方。

之後如果不再需要，可以移除密碼嗎？

可以。PDFora 的「解除密碼」工具正是為此設計的，用來把你擁有的 PDF 中已知的密碼移除，這樣每次開啟就不必再輸入。它會與加密保護一起陸續推出。

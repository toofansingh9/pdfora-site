PowerPoint 轉 PDF

在轉換伺服器上把 PPT 或 PPTX 簡報轉成 PDF，每張投影片一頁，方便分享或列印。

簡報是拿來上台報告用的。但只要需要用 email 寄出、上傳到學習平台，或印成講義，PDF 對大家都方便得多：任何手機都能開，不需要 PowerPoint，投影片也不會因為螢幕尺寸不同或缺字型而跑版。它還能避免收件人在轉寄前偷偷改掉你的數字。

這個工具一次轉換一個 .ppt 或 .pptx 檔案。簡報會透過加密連線，經由 PDFora 的中繼服務上傳到 CloudConvert，在那裡由簡報引擎轉譯，再把 PDF 以和原檔相同的名稱下載回來給你。轉換不是在你的瀏覽器中進行，工作完成後檔案會從該服務中刪除。

你拿到的是一份靜態文件：每張投影片變成一頁，維持投影片本身的長寬比，通常是 16:9。只在播放時才會發生的東西，例如動畫、轉場、內嵌的影片或聲音，以及點一下才出現的逐項效果，都不可能存在於紙面上。本頁大部分篇幅在說明：轉換前該怎麼處理這些部分，讓沒聽過你報告的人看 PDF 也能看懂。

如何把 PowerPoint 轉成 PDF

  1. 儲存並關閉簡報。把不想放進 PDF 的投影片刪除或隱藏。
  2. 開啟「PowerPoint 轉 PDF」並選擇 .pptx 或 .ppt 檔案。
  3. 按下「轉換」，等待上傳和轉換完成。含有許多大張照片的簡報會花比較久。
  4. 下載 PDF，檔名會沿用簡報的名稱。
  5. 從頭到尾翻過每一頁：檢查原本依賴動畫的投影片，並留意有沒有文字超出方塊或字型改變。

適用情境

  • 把上課投影片上傳到學校或大學的學習平台，讓學生閱讀和做筆記。
  • 會議結束後 email 業務簡報或募資簡報，讓對方看到的和會議上展示的完全一樣。
  • 把研討會演講的投影片交給主辦單位，由他們以 PDF 公開講者簡報。
  • 把訓練教材印給工作坊學員。
  • 把簡報寄給只有手機或 Chromebook 的人。
  • 把某一天實際報告時的簡報版本保存成固定紀錄。

開始前需要了解

  • 動畫會被攤平。條列項目一個一個出現的投影片，在 PDF 中會一次全部顯示。原本疊在一起、要依序出現的物件，在頁面上會互相重疊。
  • 影片和聲音在 PDF 中無法播放，通常只會保留影片的預覽畫面。如果收件人需要看影片，請在投影片上放線上版本的連結。
  • 不包含演講者備忘稿；轉換器只產生投影片頁面。如果備忘稿很重要，請把內容複製到投影片上，或從 PowerPoint 本身匯出含備忘稿的版本。
  • 隱藏的投影片通常不會出現在 PDF 中，這是讓備用投影片不外流的好方法；不過還是要核對頁數是否符合預期。
  • 伺服器上沒有的字型會被替換，所以使用特殊品牌字型的簡報，可能會出現不同的換行位置，或文字超出方塊。請內嵌字型（檔案 > 選項 > 儲存 > 在檔案中內嵌字型），或改用常見字型。
  • 連到網站的超連結通常還是可以點。在投影片之間跳轉的動作按鈕，則要看當初的製作方式，值得測試一下。

獲得最佳效果的訣竅

  • 如果是給人自行閱讀的版本，加一兩張你平常會口頭補充的背景說明投影片；PDF 簡報沒有講者。
  • 如果逐步出現的順序對理解很重要，就把那張投影片複製成好幾張，每張呈現一個階段。
  • 如果 PDF 必須控制在 email 附件上限以下，轉換前先在 PowerPoint 中壓縮圖片（圖片格式 > 壓縮圖片）。
  • 如果 PDF 要用黑白列印，請使用高對比的佈景主題；深色投影片浪費碳粉，細節也會不見。
  • 如果每張紙要印好幾張投影片，先轉換，再對 PDF 使用「N-up（每張頁數）」，在每張紙上放兩張或四張投影片。

實際範例：老師為請假學生準備的課程

一位國中自然科老師想把一份 28 張投影片的光合作用課程上傳，給沒來上課的學生看。在教室裡，有幾張投影片是逐步呈現的：一張葉片構造圖的標籤一個一個飛進來，還有一張先顯示錯誤答案、再用正確答案蓋過去。另外還有一段兩分鐘的影片，以及老師自己寫的講述重點備忘稿。

直接轉換的話，PDF 中的葉片構造圖會一次顯示所有標籤，這沒問題；但答案那張投影片，兩個答案會疊在一起，影片也只剩一張靜態畫面。於是她把答案投影片複製一份，從複本中刪掉錯誤答案，在靜態畫面下方以文字加上影片網址，再把備忘稿中的兩個重點移到相關投影片的文字方塊裡。

第二次轉換得到一份 29 頁的 PDF，學生用手機也能自己看懂。因為 PDF 保留了 16:9 的比例，在螢幕上閱讀很舒服；少數想要紙本的學生，她用「N-up（每張頁數）」每頁印兩張投影片。

再多檢查一次，還抓到一個她沒料到的問題。一張葉綠體示意圖是由十幾個形狀群組而成，其中一個標籤用的是她自己下載的裝飾性手寫字型。在轉換後的頁面上，那個標籤被換成普通字型，結果超出了箭頭的範圍。她不確定自己有沒有權利分享那個字型，所以沒有選擇內嵌，而是把標籤改成和整份簡報相同的字型，再轉換一次。逐頁對照原始投影片只要幾分鐘，卻是在三十位學生看到之前，抓出這類小替換的唯一可靠方法。

疑難排解

有些投影片的文字重疊或超出方塊
某個字型被替換成較寬的字型。請在簡報中內嵌字型或改用常見字型，然後再轉換一次。
好幾個物件疊在一起
這些物件原本是靠動畫依序出現的。請把投影片拆成好幾張，每張一個階段，或刪掉原本應該消失的物件。
我的影片不見了
媒體無法在 PDF 中播放。請在投影片上加上影片連結，或另外分享影片。
PDF 少了幾張投影片
那些大概是隱藏的投影片。如果應該包含，請在 PowerPoint 中取消隱藏（在縮圖上按右鍵 > 隱藏投影片）。
轉換失敗或逾時
含有大量高解析度圖片的大型簡報可能很慢，損毀或有密碼保護的檔案則會失敗。請壓縮圖片、移除密碼，另存一份新的 .pptx 後再試一次。
PDF 檔案超大
照片保留了完整解析度。請在轉換前於 PowerPoint 中壓縮圖片，或用「壓縮 PDF」處理 PDF。

常見問題

我的簡報會被上傳嗎？

會，檔案會以加密方式傳送到轉換服務，處理完成後刪除。必須留在你電腦上的簡報，請使用 PowerPoint 本身的匯出功能。

會包含演講者備忘稿嗎？

不會。每張投影片會變成不含備忘稿的一頁。轉換前請把重要的備忘內容移到投影片上。

動畫和轉場在 PDF 中有效嗎？

沒有。PDF 頁面是靜態的，所以每個動畫元素都會顯示在最終位置。

PDF 會保留我的投影片尺寸嗎？

會。頁面採用簡報的投影片尺寸，所以 16:9 的簡報會變成寬版頁面，4:3 的則會比較接近正方形。

可以轉換 Google 簡報或 Keynote 檔案嗎？

請把 Google 簡報下載為 .pptx，或把 Keynote 簡報匯出成 PowerPoint 格式，再轉換那個檔案。

可以在一頁放好幾張投影片嗎？

轉換時不行。請先轉換，再用「N-up（每張頁數）」工具在每頁放兩張或四張投影片。

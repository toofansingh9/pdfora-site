分割 PDF

依頁面範圍、每 N 頁，或一頁一檔的方式分割 PDF。

🔒 你的檔案在瀏覽器中本機處理，絕不會上傳。

上傳

選擇檔案或直接拖放。

2

設定

選擇你的選項 — 一切都在你的瀏覽器中完成。

3

下載

立即儲存完成的檔案。沒有浮水印。

一份 90 頁的 PDF，以 90 頁的形式其實很少派得上用場。你通常是要把第二章給同事、把第 40 到 55 頁給客戶，或是把每一頁拆成獨立檔案供存檔。PDFora 的分割工具能把一份 PDF 拆成多份，並提供三種做法：每頁各存成一份 PDF、由你輸入的自訂頁面範圍，或每 N 頁自動切成一段。

一切都在你的瀏覽器中執行。你要分割的檔案是在自己的機器上本機開啟與處理——不會被送到伺服器、不會存進雲端儲存空間，也不會經過任何人的處理佇列。對於法律卷宗、人事文件，或任何你不願上傳到陌生人電腦的資料來說，這項差別比其他任何功能都重要。

工具免費、不必註冊，也不加浮水印。當分割產生多個檔案時，它們會打包成單一 ZIP，讓你只需下載一次，而不是一口氣存十幾個檔。用一次或用一百次都行，沒有任何計數器在跑。

如何線上分割 PDF

  1. 前往 getpdfora.com 的「分割 PDF」工具，選取或拖入你的 PDF。
  2. 挑選分割模式：每頁一份 PDF、自訂範圍，或每 N 頁一份。
  3. 使用自訂範圍時，就照你口語的說法輸入——例如 1-3, 4-6 會產生兩個檔案。
  4. 使用固定分段時，輸入每個檔案要幾頁（例如 10），工具就會自動切分文件。
  5. 點擊分割。你的瀏覽器會在片刻之間於本機完成切割。
  6. 下載包含所有結果 PDF 的 ZIP 檔，解壓縮到任何地方即可。

適用情境

  • 把掃描好的一疊簽署表單拆成一張一檔，再進行歸檔。
  • 把教科書或課程讀本依章節分割，讓學生只下載自己需要的部分。
  • 把冗長的董事會資料分開，讓每個部門只收到屬於自己的段落。
  • 把匯出的銀行對帳單切成每月一份，配合一次只吃一份對帳單的記帳軟體。
  • 把研討會論文集 PDF 拆成一篇篇論文，方便引用與分享。
  • 把大型報告切成 10 頁一段，突破郵件附件的大小限制。

獲得最佳效果的訣竅

  • 輸入範圍前先瀏覽 PDF、記下各段落開始的頁碼，可以省下重做一次的功夫。
  • 範圍不必等長：如果你的各節長短不一，1-3, 4-6, 7-20 完全沒問題。
  • 當結構規律時（例如重複的表單或固定長度的對帳單），請選擇每 N 頁模式。
  • 如果你只需要其中一段而不是全部，「擷取頁面」工具會比整份分割更快。
  • 分割非常長的掃描文件會佔用裝置記憶體，在較舊的機器上請多給它一點時間。

常見問題

要怎麼把 PDF 拆成一頁一個檔案？

選擇「每頁各存成一份 PDF」的模式，再點擊分割即可。一份 30 頁的文件會變成 30 個獨立檔案，一起以單一 ZIP 下載提供。

可以依自訂頁面範圍分割嗎？

可以。輸入像 1-3, 4-6 這樣的範圍，每個範圍都會成為獨立的 PDF。你想定義幾個範圍都行，長度也不必相同。

為什麼結果是以 ZIP 檔下載？

分割通常會一次產生好幾份 PDF，用 ZIP 能把它們整理成單次下載，而不是觸發數十個各自的存檔動作。解壓縮後，所有依序命名的 PDF 都在裡面。

分割時我的文件會被上傳嗎？

不會。PDFora 在你的瀏覽器本機處理檔案，PDF 不會離開你的裝置。因此處理合約與人事檔案這類機密資料也很安全。

分割有檔案大小限制嗎？

我們不設任何限制。由於是你自己的裝置在處理，超大檔案取決於你可用的記憶體——多數文件幾秒就能分割完成，龐大的掃描卷冊則可能久一些。

分割會降低 PDF 的品質嗎？

不會。頁面會原樣複製到新檔案中，不會重新壓縮。文字依然銳利且可搜尋，影像也維持原始解析度。

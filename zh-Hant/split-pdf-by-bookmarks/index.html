依書籤分割

為文件中的每一個頂層書籤（大綱項目）各產生一個 PDF。

🔒 你的檔案在瀏覽器中本機處理，絕不會上傳。

製作精良的 PDF 本身就帶著目錄：閱讀器左側那個書籤面板。PDFora 的「依書籤分割」工具把這些項目當成裁切線。每個頂層書籤就是一個新檔案的起點，而每份輸出都以其書籤標題命名，所以「第三章：研究方法」真的會變成同名的檔案。整批成果會以單一 ZIP 下載。

分割的內容不會被上傳。書籤大綱的讀取與頁面的分離都在你的瀏覽器本機完成，因此董事會資料、法律書狀與尚未出版的書稿從頭到尾都留在你自己的電腦上。工具免費、不必帳號、不留浮水印，你丟多少份文件進來它都能分割。

另一種做法很折磨：打開書籤面板、記下每一章的起始頁、跑十幾次頁面範圍分割，再一個個手動改檔名。依書籤分割把這一切壓縮成一次點擊，而且連命名都替你做好了。

如何線上依書籤分割 PDF

  1. 前往 getpdfora.com 開啟「依書籤分割」工具。處理過程全在你的瀏覽器本機進行。
  2. 加入一份含有書籤大綱的 PDF，例如報告、手冊或電子書。
  3. 工具會讀取頂層書籤；每一個都標示著新檔案的起點。
  4. 點擊分割。從某個書籤到下一個書籤之間的頁面會被收整成獨立的 PDF。
  5. 每份輸出檔都自動以其書籤標題命名，不必手動改名。
  6. 下載 ZIP 壓縮檔並解開，就能得到各自命名清楚的獨立檔案。

When to use this tool

  • 把 300 頁的年報依書籤章節分割，讓每位部門主管只收到自己那一章。
  • 把技術手冊拆成一個模組一份 PDF，符合學習平台「一課一檔」的需求。
  • 把董事會資料拆成各個議程項目，依書籤命名後分送給委員。
  • 把法院文件依書籤拆成各份證物，讓每份證物都能單獨引用與分享。
  • 把有書籤的食譜書稿拆成一章一檔，供負責不同章節的編輯審閱。
  • 把公司手冊的各章擷取出來，讓人資能更新其中一節而不動到其餘部分。

Tips for the best results

  • 分割前先在 PDF 閱讀器中查看書籤面板；你在頂層看到的位置，就是實際的切割點。
  • 只有頂層書籤會觸發分割。巢狀的子書籤會留在其上層書籤的檔案內，這通常正好符合章與節應有的歸屬關係。
  • 如果你的 PDF 沒有書籤，請先在 PDF 編輯器中加上，或改用依文字分割或頁面範圍分割。
  • 書籤標題盡量避免斜線或冒號之類的字元，因為這些標題會成為 ZIP 內的檔名。
  • 長文件會產生較大的 ZIP；過程中雖然沒有上傳，但請等下載完成後再關閉分頁。

常見問題

PDF 書籤到底是什麼？

書籤（有時稱為大綱）就是多數 PDF 閱讀器側邊欄中那份可點擊的目錄。作者以及 Word、InDesign 等匯出工具會加入書籤來標示章節，而這個工具正是用同一批標記作為分割點。

輸出檔案怎麼命名？

每個檔案都採用其起始書籤的標題，所以名為「附錄 B」的書籤會產生同名的檔案。檔名中不允許的字元會自動調整，確保每個檔案都能順利從 ZIP 中解開。

我的 PDF 沒有書籤，還能用嗎？

無法直接使用，因為大綱正是分割點的依據。你可以先在 PDF 編輯器中加入書籤，或者若各節開頭有重複出現的關鍵字，改用 PDFora 的依文字分割工具。

為什麼結果是以 ZIP 檔下載？

有書籤的文件常會分割成十份、二十份甚至更多，用單一 ZIP 下載遠比一個檔一個檔點下去輕鬆得多。解開之後，所有命名好的 PDF 都會出現在同一個資料夾裡。

工具也會在巢狀書籤處分割嗎？

不會，只有頂層項目會開啟新檔案，書籤底下的所有巢狀內容都會跟著它走。這能讓各小節留在自己的章節內，而不會把文件打散成幾十個碎片。

這真的免費嗎？我的文件會保密嗎？

兩者的答案都是肯定的。不必註冊、沒有浮水印、沒有使用上限，而檔案的解析與分割完全在你的瀏覽器中進行，不會傳送到伺服器。處理時間取決於你的裝置與文件大小。

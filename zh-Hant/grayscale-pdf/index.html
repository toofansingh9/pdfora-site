彩色墨水很貴，而大多數文件根本不需要它。PDFora 的灰階工具能直接在瀏覽器中，幾秒鐘內把 PDF 的每一頁轉成黑白。想準備給黑白雷射印表機列印、符合影印店的灰階規定，或單純不想讓噴墨印表機為了一份五十頁的報告耗光彩色墨水匣，這都是最快的做法。

把 PDF 轉成灰階通常還能讓檔案變小。色彩資訊會占空間，一旦移除，頁面儲存的資料就變少，圖片很多的文件往往會明顯瘦身。因此就算不是為了列印，灰階也很實用，例如投稿系統有檔案大小上限，而你那份色彩繽紛的簡報剛好超標。

與所有 PDFora 工具一樣，這項功能在本機處理你的檔案。不會上傳任何資料，因此掃描的護照或簽好的合約從頭到尾都留在你自己的裝置上。不需註冊、輸出不加浮水印、不收費，轉換份數也沒有上限。

如何線上把 PDF 轉成灰階

  1. 在瀏覽器中開啟 PDFora 的「PDF 轉灰階」工具。
  2. 把 PDF 拖到上傳區，或點擊該區域從裝置中選取檔案。
  3. 稍等片刻讓工具載入預覽，確認這確實是你要處理的文件。
  4. 點擊轉換，讓瀏覽器在本機把每一頁處理成黑白。
  5. 檢視完成的頁面，確認照片與圖表在灰階下仍然清楚可讀。
  6. 下載灰階 PDF，接著就能列印或分享到任何需要的地方。

When to use this tool

  • 在辦公室雷射印表機上印 30 份之前，先把色彩豐富的簡報轉成黑白。
  • 符合學校規定：論文初稿須以灰階提交，供審查列印使用。
  • 為隨需列印服務準備書稿，因為這類服務的彩色內頁每頁費用較高。
  • 去掉掃描表單的色彩，讓它影印起來乾淨、不會出現濁濁的色調。
  • 在寄出圖片繁多的宣傳手冊 PDF 前移除色彩資訊，縮小檔案。
  • 歸檔工作文件前，先把螢光筆標記與彩色註解統一成同一種色調。

Tips for the best results

  • 轉換後記得檢查圖表。原本只靠顏色區分的線條（例如紅色與綠色）在灰階下可能長得一模一樣，如果那張圖表很重要，請改用有標籤或花紋區分的版本。
  • 先轉灰階再列印，而不是反過來。交給工具轉換，結果會比依賴各家印表機驅動程式的黑白模式更可預期。
  • 想要最小的檔案就搭配工具使用。先轉灰階再用壓縮工具，笨重的彩色掃描檔可以縮到原本的一小部分。
  • 保留彩色原檔。轉換在輸出檔中是永久性的，日後若可能用到，請把彩色版本存起來。
  • 照片的轉換效果比淺色文字好。淡黃色或粉彩色文字在灰階下可能變得很淡，送印前請快速瀏覽一遍裝飾性頁面。

常見問題

轉成灰階能縮小 PDF 檔案嗎？

通常可以。移除色彩資訊代表每一頁儲存的資訊變少，充滿照片或彩色圖形的文件可能明顯縮水。原本就幾乎全是黑字的純文字 PDF 則不會有太大變化。

轉換後文字還會銳利嗎？

黑色文字依然清晰，因為它本來就等同灰階。彩色文字會依亮度對應到某個灰階濃度，因此非常淺的顏色印出來可能比你預期得更淡。列印前先快速預覽就能發現這種狀況。

這個工具免費嗎？有頁數上限嗎？

完全免費，不需註冊、沒有浮水印，我們也不設任何頁數或檔案限制。由於是你自己的瀏覽器在處理，就算是長文件也沒問題，只是超大檔案在較舊的裝置上會慢一些。

轉換過程中我的 PDF 會被上傳嗎？

不會。轉換完全在你的瀏覽器中以本機處理完成，文件不會傳到伺服器。你可以放心轉換機密文件，它不會離開你的電腦。

為什麼要轉成灰階 PDF，而不是直接用印表機的黑白設定？

灰階 PDF 讓你在任何印表機上都得到一致的結果，而且在動用紙張之前就能看清每一頁的實際樣貌。印表機驅動程式各有差異，有些甚至仍會用一點彩色墨水去表現彩色檔案中的灰階。

可以只把部分頁面轉成灰階嗎？

工具會一次轉換整份文件。若你需要黑白與彩色混合的輸出，可先分割 PDF，把要轉灰階的頁面處理好，再用 PDFora 的分割與合併工具把全部檔案組回去。

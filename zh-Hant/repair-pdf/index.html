打不開的 PDF 令人心慌，尤其當它是某張發票、某張證書或某份簽好合約的唯一副本時。PDFora 的修復工具會重新解析損毀的檔案，救出仍讀得到的物件，並把 PDF 的內部結構重建成一份全新、符合規範的文件。對於最常見的幾種損毀情況，這樣就足以讓失效的檔案起死回生。

檔案損毀通常來自中斷的下載、被截斷的郵件附件、匯出時當機，或是在系統之間傳輸時位元組被弄亂。症狀從直接跳出錯誤訊息，到比較隱晦的怪現象都有，例如空白頁、影像缺失，或閱讀器翻到第三頁就卡住。修復的做法是丟掉壞掉的骨架，重新寫一副乾淨的。

整個流程都在你的瀏覽器中執行。損壞的檔案不會被上傳，因此損毀的報稅文件或醫療報告在修復過程中仍保有隱私。工具免費、不需帳號、不加浮水印，你想嘗試修復幾次都可以。這項功能目前處於 beta 階段，我們也坦白說明。

如何線上修復損毀的 PDF

  1. 用任何最新版瀏覽器開啟 PDFora 的「修復 PDF」工具。
  2. 從裝置中選取損毀的 PDF，或把它拖到放置區。
  3. 點擊修復開始。工具會在本機重新解析檔案並重建其內部結構。
  4. 稍候，可救回的頁面、文字與影像會被收整成一份新文件。
  5. 下載修復後的 PDF，用你慣用的閱讀器開啟確認結果。
  6. 把整份文件翻過一遍，因為有些內容可以救回，另一些部分可能真的已經遺失。

When to use this tool

  • 救回一張下載到一半就斷線、現在顯示「檔案已損毀」錯誤的發票。
  • 修復一份在寄件者電腦上打得開、在你這裡卻報錯的 PDF 郵件附件。
  • 從出現讀取錯誤的備份硬碟中，搶救一張舊的掃描證書。
  • 修復由有瑕疵的「匯出成 PDF」功能寫出、交叉參照表壞掉的報告。
  • 讓一份只有在寬鬆的瀏覽器檢視器中才開得起來的 PDF，也能在嚴格的軟體（例如印刷廠的系統）中開啟。
  • 重建那種雖然打得開、卻顯示空白頁或亂掉影像的檔案。

Tips for the best results

  • 先試著重新下載。如果原始來源還在，重新下載一份會比任何修復都可靠，因為修復只能處理倖存下來的位元組。
  • 絕對不要覆蓋損壞的原檔。把修復後的版本另存新檔名，必要時你還能嘗試其他救援途徑。
  • 如果修復後的檔案打得開卻看起來不完整，缺少的部分多半是真的被破壞了，而不只是參照錯亂。修復能重建結構，但無法憑空生出已失去的資料。
  • 會要求輸入密碼的 PDF 是被鎖住，不是損毀。修復無法處理加密檔案，若你知道密碼，請先解鎖文件。
  • 修復後檢查頁數。把它與你預期的頁數比對，是最快判斷有沒有頁面在損毀中遺失的方法。

常見問題

修復實際上是怎麼運作的？

工具會通讀原始檔案，抽出所有仍能解析的物件，再把這些物件寫進一份具有正確內部結構的全新 PDF。壞掉的參照、受損的表格與格式錯誤的標頭都是被取代，而不是被修補。

任何損毀的 PDF 都修得好嗎？

不是，我們寧可先講清楚。它能妥善處理常見的損毀，例如交叉參照表壞掉或檔案被截斷，但如果實際的頁面資料已經被破壞，就沒有東西可以重建了。這項工具仍在 beta 階段，成效會逐步改善。

可以修復有密碼保護的 PDF 嗎？

不行。沒有密碼就無法重新解析加密檔案，因此修復對它們無效。若你知道密碼，請先移除保護再執行修復。

我損壞的檔案會被上傳到伺服器嗎？

不會。重新解析與重建完全在你的瀏覽器內完成，檔案不會離開你的裝置。因此修復合約、證件掃描檔與財務報表等敏感文件也很安全。

修復後的 PDF 打得開，但有些頁面是空白的，為什麼？

空白頁通常代表那些頁面的內容是真的遺失了，而不只是排列錯亂。修復救回了頁面項目，卻找不到背後可繪製的資料。請確認其他地方是否還存有這個檔案的較早版本。

修復要收費或需要帳號嗎？

不用。修復免費、不必註冊、輸出不加浮水印，嘗試次數也沒有上限。你可以把同一個檔案反覆處理多次，或把整個資料夾的文件一份份修復。

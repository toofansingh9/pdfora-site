貝茲編號

蓋上帶有前綴與補零的連續 Bates 編號，法律文件的標準做法。

在訴訟中，證據開示所提出的每一頁都需要唯一識別碼，而法律界的做法就是 Bates 編號。一個前綴加上一組連續數字，「那封談發票的電子郵件」就變成 ABC-000147，可以在證詞筆錄中引用、在特權文件清單中追蹤，在法庭上毫無歧義。這項工具讓你線上套用 Bates 編號，幾秒鐘就能為 PDF 的每一頁蓋上編號。

格式由你決定。設定自訂前綴，例如「SMITH-」或你的案號；選擇起始號碼，讓新一批提出的文件從上一批結束的地方接續；再挑選補零的位數，讓編號呈現為 000001 而不是 1。接著選擇印記位置：置底靠右、置底靠左或置底置中。工具會依序為每一頁編號，並把蓋好的檔案交還給你。

對律師事務所而言，最重要的是隱私模式：PDF 完全在你的瀏覽器中處理，絕不上傳，因此享有特權保護的機密文件始終留在你的電腦上。免費、不必註冊、沒有浮水印、沒有頁數上限。

如何線上加入 Bates 編號

  1. 把 PDF 拖進工具中，檔案會在你的瀏覽器中本機開啟，客戶文件不會被傳送出去。
  2. 輸入前綴，例如「ABC-」或案件識別碼「DOE2026-」。
  3. 設定起始號碼。首次提出文件時用 1；補充提出時，就從上一次蓋印的最後一頁接續。
  4. 選擇補零位數，六位數會產生 ABC-000001、ABC-000002 依此類推。
  5. 挑選印記位置：置底靠右、置底靠左或置底置中。
  6. 點擊為每一頁蓋印並下載加好 Bates 編號的 PDF，接著把號碼區間登記到你的文件提出索引中。

When to use this tool

  • 法務助理在證據開示提出前，把 400 頁電子郵件列印稿蓋成 PLAINTIFF-000001 到 PLAINTIFF-000400。
  • 獨立執業律師為病歷 PDF 蓋上 Bates 編號，讓對造律師能在人身傷害案的證詞中引用特定頁面。
  • 企業法務團隊為回應傳票的內部文件編號，並延續先前分批提出的號碼順序。
  • 會計師為查核工作底稿加上連續編號，讓每一頁都能在最終報告中被明確引用。
  • 紀錄管理人員為行政聽證會的證物編號，每一組證物使用不同的前綴。
  • 法遵人員逐頁為政策彙編蓋印，讓修訂內容能對照固定的頁面識別碼追蹤。

Tips for the best results

  • 為每一個案件維護一份最後使用號碼的紀錄，下一批提出的文件應從下一個號碼開始，絕不重複使用。
  • 六位補零是美國證據開示的常見慣例，能讓編號對齊，在任何檔案清單中也能正確排序。
  • 選擇能標示提出方的前綴，例如「SMITH-」或「DEF-」，讓不同當事人的頁面永遠不會撞號。
  • 印記位置很重要：挑一個不會壓到文件上既有頁尾或頁碼的角落。
  • 請對副本蓋 Bates 編號，而不是你唯一的原檔，保留乾淨版本以備案件進行中格式要求變更。

常見問題

什麼是 Bates 編號？

Bates 編號會在整組文件的每一頁蓋上唯一的連續識別碼，通常是前綴加上補零的號碼，例如 ABC-000123。它源自 1890 年代取得專利的手搖蓋印機，至今仍是法律團隊在證據開示中識別頁面的標準做法。

這項工具處理享有特權保護的法律文件安全嗎？

安全，而這正是它與多數線上蓋印工具的關鍵差異：PDF 在你的瀏覽器中本機處理，絕不會上傳到伺服器。享有特權或機密性質的資料從頭到尾都留在你的電腦上。

我可以接續前一批提出文件的編號嗎？

可以。把起始號碼設成上一批結束的地方，如果前一批停在 ABC-000400，這份檔案就從 401 開始，使用相同的前綴與補零位數，讓整個案件維持一條連續的號碼序列。

Bates 印記會放在頁面的哪個位置？

由你選擇：置底靠右、置底靠左或置底置中。置底靠右是美國實務上最常見的慣例，但各法院與各項規範不盡相同，請先確認你的 ESI 命令或文件提出協議。

Bates 印記是永久的嗎？

號碼會以頁面內容的形式繪製到每一頁上，因此在任何 PDF 閱讀器中都固定不動，列印與複印後也依然存在。它不是那種一鍵就能刪除的可移除註解。

這項工具收費或限制頁數嗎？

不會。它免費、不需要帳號、不加浮水印，頁數與文件數量也沒有上限，處理 2,000 頁的提出文件與 10 頁的檔案方式完全相同。

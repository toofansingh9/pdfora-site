刪掉不要的頁面，下載精簡後的文件。

立即儲存完成的檔案。沒有浮水印。

掃描機掃出來的空白頁、重複的投影片、還有那份絕對不能寄給客戶的內部報價單——每份 PDF 好像總會夾帶一兩頁該消失的內容，而 PDFora 的刪除頁面工具能乾淨地把它們移除。輸入要刪掉的頁碼，例如 2, 5-7，然後下載一份只留下其餘內容的新 PDF。

和多數網頁工具不同，PDFora 完全不會收到你的檔案。刪頁是由你自己電腦上的瀏覽器完成的，所以塞滿姓名、數字或談判細節的文件，會待在它原本的位置。刪頁的目的往往正是移除不該外流的內容，若過程中還得把整份文件交給第三方伺服器，那就太荒謬了。

工具免費，也不用註冊帳號。下載的檔案沒有浮水印，刪多少頁、整理多少份文件都沒有限制。原始 PDF 完全不會被更動，萬一哪天發現刪掉的那頁其實有用，也還救得回來。

如何線上刪除 PDF 頁面

  1. 前往 getpdfora.com 的刪除頁面工具——不用登入，開啟即用。
  2. 選擇要修剪的 PDF，或直接把檔案拖到頁面上。
  3. 輸入要移除的頁面，單一頁碼與範圍可以混用，例如 2, 5-7。
  4. 繼續之前先核對一下頁碼；把封面頁算錯是最經典的失誤。
  5. 點「刪除」。你的瀏覽器會在本機重建一份不含那些頁面的 PDF。
  6. 下載修剪好的檔案——沒被你列出的內容全都還在，順序也不變。

When to use this tool

  • 清掉雙面掃描機在每張正頁之間插入的空白背面。
  • 把型錄裡過期的價目頁刪掉，再寄給新的潛在客戶。
  • 存檔雜誌 PDF 前，先把廣告和訂閱回函頁剪掉。
  • 從合約中刪除草稿或已被取代的頁面，確保只有最終版本流通。
  • 把習題 PDF 裡的解答頁刪掉，再發給學生。
  • 刪掉報告裡制式的條款頁，讓檔案降到上傳大小限制以下。

Tips for the best results

  • 要刪掉一整段時就用範圍，而不是逐一列頁碼——12-19 遠比手動打八個數字省事。
  • 刪頁和擷取頁面互為鏡像；如果你要保留的不到全文一半，直接擷取要留的那些會更快。
  • 分享前先打開成品翻一遍，尤其是頁碼直接印在頁面上的文件。
  • 如果要在長文件裡零散刪除，「整理頁面」工具的縮圖檢視可以讓你用眼睛標記要刪的頁，而不必靠頁碼。
  • 在修剪版確定完成任務之前，先把沒動過的原始檔留著。

常見問題

如何一次刪除 PDF 裡的多個頁面？

一次全部列出來，用逗號分隔即可——2, 5-7, 11 會在同一次處理中刪掉第 2 頁、第 5 到 7 頁與第 11 頁，不需要一頁一頁重複操作。

刪掉的頁面能從新檔案裡還原嗎？

不行，而這正是重點——下載的 PDF 從一開始就不含那些頁面，收件者挖不出來。你的原始檔仍保有所有頁面，所以你這邊什麼都沒失去。

線上刪除機密文件的頁面安全嗎？

用 PDFora 就很安全，因為檔案從不離開你的瀏覽器。處理全在本機進行，移除機密頁面時，不需要把這份機密文件上傳到任何地方。

刪除 PDF 頁面會破壞連結或書籤嗎？

保留下來的頁面，內容與排版都原封不動。原本指向被刪頁面的書籤或內部連結會失去目的地，這對任何刪頁工具來說都是正常現象。

我需要安裝軟體或註冊嗎？

都不用。工具可在電腦或手機上的任何新版瀏覽器執行，免費、免帳號，輸出檔也不加浮水印。

它能處理非常大的 PDF 嗎？

可以，限制來自你的裝置而不是伺服器配額。因為工作由你的瀏覽器完成，好幾百頁的檔案在多數電腦上都能很快處理完，不過超大型掃描文件會需要更多記憶體。

浮水印

加入自訂文字浮水印，角度、大小與透明度都能自由調整。

為 PDF 加上浮水印，不必安裝任何軟體，也不必把文件交給陌生人的伺服器。PDFora 會把你自訂的文字，例如「草稿」、「機密」、公司名稱或客戶編號，蓋在文件的每一頁上。整個過程採用本機處理，在你的瀏覽器中完成，檔案不會離開你的電腦。當你要標記的 PDF 正好是那種不希望到處流傳的文件時，這一點格外重要。

浮水印的外觀由你掌控。輸入任何文字、依版面調整字級，並把不透明度設在從淡如幽靈的 0.1，到濃重不透明的實心印記之間。開啟 45 度斜角選項，文字就會像經典的「草稿」印章那樣斜貫整頁。標記會一致地套用到每一頁，因此 200 頁的合約和兩頁的備忘錄同樣只需幾秒鐘。

PDFora 免費、不必註冊、沒有檔案限制。有件事值得直說：許多浮水印工具會在你的輸出上加自家品牌標示。我們從不這麼做。完成的 PDF 上唯一的浮水印，就是你自己選擇加上去的那一個。一天用一次或一百次都行，不會被計次，也不會被限速。

如何線上為 PDF 加上浮水印

  1. 在 getpdfora.com 開啟浮水印工具並選擇你的 PDF，或直接把檔案拖到頁面上。
  2. 輸入要蓋在每一頁上的浮水印文字，例如「機密」、「草稿」或你的公司名稱。
  3. 設定字級，讓標記清楚可見，又不會把底下的內容蓋住。
  4. 調整不透明度滑桿，範圍在 0 到 1 之間；約 0.2 至 0.3 能形成低調的標記，同時保持文字可讀。
  5. 若希望文字以 45 度斜貫頁面，就勾選斜角選項；不勾選則為水平印記。
  6. 點擊套用，然後下載加好浮水印的 PDF。一切都在你的瀏覽器中本機完成。

When to use this tool

  • 在把合約寄給對方之前蓋上「草稿」，避免有人簽了一份根本不是定案的版本。
  • 在把內部報告分發到直屬團隊之外前標上「機密」。
  • 在設計稿與提案上加上工作室或事務所名稱，防止它們被悄悄挪用。
  • 為電子書的試閱章節或預覽版標上「禁止散布」。
  • 在發票或對帳單上標註「已付款」或「副本」，讓正本與複本永遠不會被搞混。
  • 在學生講義或考卷上加上課程代碼與學期，舊版本一眼就能辨識。

Tips for the best results

  • 當文件仍需要仔細閱讀時，把不透明度壓低在 0.15 到 0.3；0.6 以上留給那些刻意讓副本無法使用的頁面。
  • 45 度斜角能用同一行文字覆蓋更多頁面範圍，讓標記更難被裁掉。
  • 大字級的短文字比小字級的長句子更好讀，「草稿 — v3」勝過一整段免責聲明。
  • 請對副本加浮水印，而不是你唯一的原檔。這項工具不會更動你的來源檔案，但保留一份乾淨的母版本來就是好習慣。
  • 法律或客戶文件可以把收件者姓名放進浮水印，這樣外流的副本就能自己指認來源。

常見問題

加浮水印時我的 PDF 會被上傳嗎？

不會。這項工具採用本機處理，完全在你的瀏覽器中執行。檔案的開啟、加印與儲存都在你自己的電腦上完成，不會有任何內容傳送到 PDFora 的伺服器。

PDFora 會在我的檔案上加自己的浮水印嗎？

絕對不會。和許多免費工具不同，我們不會在你的輸出上加品牌標示。完成的 PDF 上唯一的浮水印，就是你自己輸入的文字。

我可以控制浮水印的透明度嗎？

可以。不透明度能在 0 到 1 之間調整。像 0.2 這樣的低數值會形成淡淡的背景標記，設為 1 則是實心、完全不透明的文字。

浮水印會出現在每一頁嗎？

會。不論檔案是兩頁還是好幾百頁，你的文字都會自動蓋在文件的每一頁上。

可以把浮水印放成斜角嗎？

可以。有一個把文字旋轉 45 度的選項，能呈現經典的對角「草稿」效果。不勾選的話就是水平印記。

檔案大小或檔案數量有限制嗎？

沒有固定上限，也沒有每日額度，這項工具免費、無限制，也不必註冊。由於處理在本機進行，超大檔案的唯一限制是你裝置的記憶體。

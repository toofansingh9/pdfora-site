旋轉 PDF

把所有頁面或指定頁面旋轉 90、180 或 270 度後儲存。

🔒 你的檔案在瀏覽器中本機處理，絕不會上傳。

上傳

下載

立即儲存完成的檔案。沒有浮水印。

打開就橫躺的掃描合約。困在直式文件裡的橫式圖表。在掃描器與收件匣之間某處被翻成上下顛倒的頁面。PDFora 的旋轉工具幾秒鐘就能全部解決：把每一頁、或只把你挑選的頁面順時針轉 90 度、逆時針轉 90 度，或整整轉 180 度。旋轉會寫進檔案本身，因此這份 PDF 走到哪裡，頁面都保持端正。

與多數線上轉換服務不同，PDFora 從不把你的文件上傳到伺服器。整個旋轉過程都以 JavaScript 在你的瀏覽器本機完成，也就是說簽好的租約或醫療報告永遠不會離開你的電腦。不必安裝、不必建立帳號，事後頁面上也不會被蓋浮水印。要轉一個檔案還是連續轉五十個都行，沒有每日限制。

選擇性旋轉才是這個工具真正好用的地方。輸入像「1,3-5」這樣的頁面範圍，就只有那幾頁會轉，其餘完全不動。這讓你不必打開付費 PDF 編輯器，就能修正埋在四十頁直式報告中的那一張橫式試算表。

如何線上旋轉 PDF

  1. 用任何現代瀏覽器前往 getpdfora.com 開啟「旋轉 PDF」工具。
  2. 把 PDF 拖到頁面上，或點擊瀏覽選取。檔案在本機載入，絕不會上傳。
  3. 選擇角度：順時針 90°、180°，或逆時針 90°。
  4. 決定要旋轉全部頁面還是特定頁面。若只轉部分頁面，請輸入類似「1,3-5」的範圍。
  5. 點擊旋轉，查看預覽確認每一頁的方向都正確了。
  6. 下載修正後的 PDF，新的方向已永久儲存在檔案中。

When to use this tool

  • 在提交費用報告前，修正一批被手機掃描 App 拍成橫向的收據。
  • 把年報中的橫式財務表格轉正，讓審閱者不必歪著頭看。
  • 修正簽署文件中那一頁上下顛倒的內容，它是進掃描器時方向放反了。
  • 整理以混合方向匯出的課堂投影片，讓它們能一致地印成直式講義。
  • 把建築圖說旋轉 90 度，使圖標欄位落在印刷廠預期的位置。
  • 把傳真過來的採購單轉正，再轉寄給會計部門。

Tips for the best results

  • 旋轉是以 90 度為單位。如果頁面只是掃描時稍微歪斜，那屬於傾斜問題，請重新掃描或使用傾斜校正。
  • 不確定該往哪個方向轉？想像頁面的上緣：順時針會把它帶到右邊，逆時針會帶到左邊。
  • 上下顛倒掃描的文件請用 180°；轉兩次 90° 也能達到相同效果，但點一下顯然更快。
  • 頁面範圍同時支援逗號與連字號，所以「2,6-9,14」正好只旋轉那五頁，其他一頁都不動。
  • 先旋轉，再合併或分割。方向先修好，後續產出的每一份副本都會繼承這個修正。

常見問題

旋轉是永久的，還是只是檢視設定？

是永久的。PDFora 會把頁面方向改寫進檔案內部，因此在 Adobe Reader、手機、列印對話框或任何其他地方，頁面都維持旋轉後的方向。你不必每次開檔都重轉一次。

可以只旋轉 PDF 的部分頁面嗎？

可以。切換到指定頁面模式，輸入像「1,3-5」的範圍即可。只有那些頁面會轉，文件其餘部分維持原本的方向。

我的檔案會被上傳到伺服器嗎？

不會。工具完全在你的瀏覽器中執行，PDF 在你自己的裝置上處理，不會經過網路傳輸。因此用來處理合約、證件掃描檔與其他私密文件都很安全。

有檔案大小或使用次數限制嗎？

PDFora 免費、不必註冊、沒有浮水印，也沒有每日上限。由於處理在本機進行，超大檔案取決於你裝置的記憶體而非伺服器額度，多數文件一兩秒就能旋轉完成。

旋轉會降低我的 PDF 品質嗎？

不會。旋轉只改變每一頁的方向旗標，內部的文字、影像與向量內容完全不受影響。輸出品質與原檔相同，檔案大小通常也幾乎一樣。

可以旋轉有密碼保護的 PDF 嗎？

如果檔案需要密碼才能開啟，請先移除或輸入密碼，因為瀏覽器沒有密碼就讀不到加密內容。PDF 能正常開啟之後，旋轉的操作與其他檔案完全相同。

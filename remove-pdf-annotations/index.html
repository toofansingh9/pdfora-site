Reviewed documents collect clutter. A draft contract comes back with sticky notes from three colleagues, a teacher's marked-up handout carries highlights and pen strokes, a report has a reviewer's question bubbles in the margin. Before that file goes to a client, a parent or a printer, the review layer usually needs to go, and deleting comments one by one in a viewer is slow and easy to get wrong.

In a PDF, all of these extras live in a per-page list called Annots, separate from the page's own content. PDFora's tool opens the file with pdf-lib and deletes that list from every page, then saves the document. The page content itself is not touched: the body text, images and layout come out exactly as they went in, and text stays selectable. The new file is saved with -clean added to its name. Because nothing is re-rendered, the cleaned file is usually about the same size as the original, slightly smaller if there were many comments.

The method is thorough rather than selective, and that has side effects you need to know about. The Annots list holds more than comments. Hyperlinks and form fields are annotations too, so they are removed along with the notes and highlights. If the document needs to keep working links or fillable fields, read the section on what to know before you run it.

How to remove comments and annotations from a PDF

  1. Open Remove Annotations and add the PDF you want to clean up.
  2. Click Remove annotations. The annotation list is deleted from every page; this is quick even for long files.
  3. Download the cleaned copy, named for example draft-clean.pdf.
  4. Open it and check a page that had comments, a page with links and any form you expected to keep.
  5. If links or fields were needed, go back to the original and use the approach described in the tips instead.

When to use this tool

  • Sending the final version of a contract or proposal to a client after an internal review round full of comments.
  • Re-using a teacher's handout or past exam paper without the previous year's highlights and marks.
  • Printing a document cleanly when comment pop-ups and stamps would otherwise print or clutter the margins.
  • Removing reviewer names that appear in comment metadata before a document is shared outside a team.
  • Clearing a PDF of old drawing marks and shapes before marking it up again for a new review.
  • Checking whether a disputed mark is part of the page or only an annotation: if it vanishes, it was an annotation.

What to know before you start

  • All annotation types are removed on every page: comments, sticky notes, highlights, underlines, strike-throughs, freehand ink, shapes, stamps and text boxes added as markups.
  • Hyperlinks are removed too, because a clickable link in a PDF is stored as a link annotation. The underlined text stays visible but no longer clicks through.
  • Form fields lose their widgets. The page may still show the field borders if they are drawn in the page content, but the boxes can no longer be filled; flatten first if the answers must stay visible.
  • Marks that were burned into the page are not annotations. Highlights made by a program that flattened them, or ink on a scanned page, are part of the content and stay.
  • This is not redaction. Removing annotations deletes the review layer, not text under black boxes; a black box drawn as content stays, and a black box drawn as an annotation is removed, revealing the text beneath.
  • There is no page selection. Every page of the file is cleaned in one pass.

Tips for the best results

  • Save the annotated original. Once comments are removed from the copy you cannot bring them back from it.
  • If you need to keep the answers of a filled form, run Flatten first, then remove annotations from the flattened file.
  • For a document full of links you want to keep, delete comments in your PDF viewer instead; most viewers can select comments by type.
  • Do not use this tool to hide sensitive text. If something must be removed, delete it from the source document and export again.
  • Open the cleaned file in a second viewer. Some viewers hide certain annotation types, so a second check confirms nothing remains.

A worked example: a legal assistant's final draft

A legal assistant receives a 30-page services agreement back from internal review with 46 comments, a dozen yellow highlights and a stamped DRAFT label added as an annotation. The client copy must go out today, and the agreement includes a table of contents whose entries link to each clause.

Running the file through Remove Annotations clears every comment, highlight and the DRAFT stamp in one pass. The body text and clause numbering are unchanged. The table-of-contents entries, however, no longer jump to their clauses, because those internal links were annotations too.

The assistant decides the client is better served by working links, goes back to the original, deletes comments by type in a desktop viewer, and keeps the cleaned file from this tool only as a print copy. For a document without links, the one-click version would have been enough.

Had the document contained no internal links, for example a scanned letter with a few sticky notes, the one-pass tool would have been the faster and safer choice, because it cannot miss a comment the way a manual clean-up in a viewer sometimes does when notes are hidden or collapsed.

Troubleshooting

Some highlights are still there
Those highlights are part of the page content, not annotations, usually because the document was flattened or printed to PDF after marking. They cannot be removed this way; use an earlier, unflattened version.
My links stopped working
Links are annotations and are removed with everything else. Remove comments in a viewer that can filter by type if links must stay.
Form fields can no longer be filled
Their field widgets were annotations and were removed. Use the original file for filling, or flatten it first if only the answers need to remain visible.
Text appeared where a black box used to be
The black box was an annotation, not real redaction. Treat that document as sensitive and redact the source properly before sharing it.
The file will not load
It may be damaged or password-protected. Try Repair PDF, or remove the password at the source and run the tool again.
Comments still show in my email preview
The preview may be cached or showing the original attachment. Check that you attached the -clean file and open it directly.

Frequently asked questions

What counts as an annotation in a PDF?

Anything stored in a page's annotation list: comments, notes, highlights, ink, shapes, stamps, links and form field widgets.

Can I remove only comments and keep highlights?

Not with this tool; it removes the whole annotation list on every page. Use a viewer that filters comments by type for selective removal.

Does it change the main text or images?

No. Page content is saved unchanged, so text stays selectable and images keep their quality.

Is this the same as redaction?

No. It removes the review layer only. It does not delete text from the page and should not be used to hide confidential information.

Are comment authors' names removed too?

Yes, as far as they are stored in the annotations. Document properties such as the author field are separate; use Edit Metadata for those.

Can I undo it?

Not on the cleaned file. Keep the original if you might need the comments again.

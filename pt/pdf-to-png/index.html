PNG é o formato a escolher quando uma página de PDF contém texto, tabelas, gráficos ou desenho de linha. Ao contrário do JPG, a compressão PNG não tem perdas, por isso as letras mantêm os contornos nítidos e as linhas finas dos diagramas não ganham artefactos de compressão. Esta ferramenta converte todas as páginas do seu PDF em imagens PNG e, nos documentos com várias páginas, entrega um ficheiro ZIP com as páginas numeradas por ordem.

A conversão é feita inteiramente pelo seu navegador. O seu PDF nunca é enviado, o que significa que um acordo jurídico, um enunciado de exame ou uma demonstração financeira fica no seu dispositivo o tempo todo. Não há nada guardado num servidor, nem nada que expire ou tenha de ser apagado depois. A ferramenta é gratuita, não exige conta e não impõe marca de água nem limite de páginas ao que converte.

Como o resultado é fiel ao pixel, converter PDF em PNG é a escolha habitual para capturas de documentação, diapositivos que seguem para ferramentas de design e qualquer sítio onde uma imagem vá ficar ao lado de texto de interface bem nítido. Se está a converter páginas cheias de fotografias e prefere ficheiros mais pequenos, a ferramenta de PDF para JPG serve-lhe melhor.

Como converter PDF para PNG online

  1. Abra a ferramenta de PDF para PNG e arraste o ficheiro para a página, ou clique para o escolher no seu dispositivo.
  2. Deixe o navegador ler o documento localmente; num instante verá as páginas detetadas.
  3. Inicie a conversão. Cada página é composta como uma imagem PNG sem perdas.
  4. Transfira o resultado: um único PNG se o PDF tiver uma página, ou um arquivo ZIP se tiver várias.
  5. Extraia o ZIP e confirme que as páginas de que precisa estão bem a 100% de zoom.
  6. Renomeie ou mova as imagens para o seu projeto; estão prontas para documentação, apresentações ou a web.

When to use this tool

  • Transformar páginas do manual de um software em PNG para um centro de ajuda, onde as capturas de ecrã e o texto da interface têm de ficar perfeitamente nítidos.
  • Converter um diagrama de arquitetura ou um fluxograma de um relatório em PDF numa imagem para o Confluence, o Notion ou um wiki.
  • Exportar diapositivos guardados em PDF para PNG e reutilizá-los no Figma, no Canva ou numa nova apresentação sem redesenhar nada.
  • Publicar online uma partitura, um gráfico de tricô ou um desenho técnico, onde a compressão JPG borraria as linhas finas.
  • Preparar a página de um certificado ou diploma como imagem limpa para uma publicação no LinkedIn ou para um site pessoal.
  • Captar tabelas de um artigo científico como imagens para uma apresentação, quando recriá-las à mão não compensa o tempo.

Tips for the best results

  • Use PNG para texto, diagramas e capturas de ecrã; use JPG para páginas que são sobretudo fotografias, onde os ficheiros PNG crescem muito sem ganho visível.
  • Os PNG de documentos longos acumulam-se depressa. Converta apenas o capítulo ou as páginas de que precisa se o ficheiro completo tiver centenas de páginas.
  • Verifique o resultado a 100% de zoom; uma página que parece desfocada quando afastada está normalmente apenas a ser reduzida pelo visualizador.
  • O PNG suporta transparência, mas as páginas de PDF são compostas com o respetivo fundo, normalmente branco. Remova o fundo num editor se precisar de uma versão transparente.
  • Mantenha os nomes numerados que vêm do ZIP até terminar o trabalho; facilitam associar cada imagem à página de origem.

Perguntas frequentes

Qual é a diferença entre PDF para PNG e PDF para JPG?

O PNG não tem perdas, por isso o texto e o desenho de linha ficam perfeitamente nítidos, à custa de ficheiros maiores. O JPG comprime com mais força e adequa-se a páginas fotográficas. Escolha PNG para tudo o que vai ler, e PNG ou JPG para aquilo que apenas vai olhar.

A conversão acontece no meu dispositivo?

Sim. O PDF é composto em imagens pelo seu navegador, localmente, e nunca é enviado para um servidor. Os documentos confidenciais continuam confidenciais porque nunca saem da sua máquina.

Como são entregues os PDF com várias páginas?

Cada página passa a ser um PNG próprio e todos eles são reunidos num único arquivo ZIP. Os ficheiros estão numerados por página, por isso ordenar a pasta por nome repõe a ordem do documento.

As imagens levam marca de água ou têm limites?

Sem marcas de água, sem quota diária, sem registo. A ferramenta é gratuita e trata a sua centésima conversão exatamente como a primeira.

Posso converter apenas uma página em vez do PDF inteiro?

A ferramenta converte todas as páginas do ficheiro que fornecer. Para obter uma única página, extraia-a ou separe-a primeiro e converta depois esse PDF mais pequeno.

Porque é que os meus ficheiros PNG são muito maiores do que o PDF?

Um PDF guarda o texto como instruções compactas, ao passo que um PNG guarda cada pixel da página composta. Isso é normal e é também a razão pela qual os PNG ficam idênticos ao original em qualquer tamanho que o seu ecrã mostre.

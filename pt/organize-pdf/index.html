Organizar páginas

Veja todas as páginas de um PDF em miniatura, arraste-as para uma nova ordem, gire ou exclua, e salve o resultado num arquivo novo.

🔒 Seus arquivos são processados localmente no seu navegador e nunca são enviados.
1

Enviar

Selecione ou arraste e solte o seu arquivo.

2

Ajustar

Escolha as suas opções — tudo acontece no seu navegador.

3

Baixar

Salve o arquivo pronto na hora. Sem marcas d'água.

Digitar números de página funciona quando você já sabe quais são. Quando não sabe, porque uma digitalização saiu embaralhada ou um documento longo precisa de várias correções ao mesmo tempo, você precisa ver as páginas. O Organizar páginas desenha uma pequena miniatura de cada página do arquivo e as coloca num quadro onde cada cartão pode ser arrastado para outra posição, girado para a esquerda ou para a direita, ou marcado para exclusão. Nada acontece com o arquivo até você clicar em Aplicar e baixar.

As miniaturas são desenhadas com o PDF.js a cerca de um terço do tamanho normal da página na tela, o suficiente para reconhecer uma página pelo layout, mas não para ler letra pequena. Elas são só uma pré-visualização. Quando você aplica as alterações, a ferramenta volta ao PDF original e usa a pdf-lib para copiar as páginas de verdade, na ordem do quadro, para um documento novo. Nas páginas que você girou, a configuração de rotação é atualizada, sem redesenhá-las, e as páginas marcadas para exclusão são puladas. O resultado é salvo como nome-do-arquivo-organized.pdf, com texto, links para sites e qualidade de imagem inalterados.

Em documentos longos, a exibição demora, porque todas as páginas são desenhadas antes de o quadro aparecer. Uma carta de 20 páginas aparece quase na hora; um livro digitalizado de 400 páginas pode demorar bastante e consome muita memória no celular. É o preço de poder ver as páginas em vez de adivinhar números.

Como reorganizar as páginas de um PDF

  1. Abra Organizar páginas e escolha um PDF. Espere a mensagem "Gerando páginas…" dar lugar às miniaturas.
  2. Arraste um cartão de página e solte onde ele deve ficar. Cada cartão mantém o número de página original como etiqueta, então você sempre sabe de onde veio cada página.
  3. Use os dois botões de seta de um cartão para girar aquela página 90 graus para a esquerda ou para a direita; clique mais de uma vez para 180 graus.
  4. Clique no botão da lixeira para marcar uma página para exclusão. O cartão fica acinzentado mas continua no quadro; clique de novo para recuperá-lo.
  5. Clique em Aplicar e baixar e confira o nome-do-arquivo-organized.pdf num visualizador antes de apagar ou substituir o original.

Quando usar esta ferramenta

  • Colocar de volta na ordem das questões as folhas de uma prova depois que o scanner travou e as folhas entraram de novo fora de sequência.
  • Corrigir numa só passada uma digitalização com páginas de cabeça para baixo e de lado, e remover as folhas em branco.
  • Passar o resumo executivo do fim de um relatório para o começo antes de enviá-lo para uma diretoria.
  • Refazer um portfólio em PDF para que os melhores projetos apareçam primeiro para um cliente específico.
  • Organizar uma coleção de receitas fotografadas ou um arquivo de anotações com páginas capturadas fora de ordem.
  • Revisar visualmente um documento página por página antes de enviá-lo, mesmo que no fim você só apague uma página perdida.

O que saber antes de começar

  • Só dá para organizar um PDF por vez. Para reordenar páginas de vários arquivos, junte-os primeiro com Juntar PDF e depois organize o arquivo resultante.
  • A rotação aqui muda a indicação de rotação da página, a mesma configuração que um visualizador usa quando você gira uma página e salva. Não perde qualidade e se soma à rotação que a página já tivesse.
  • Os cartões excluídos continuam visíveis, acinzentados, até você aplicar. Se todas as páginas estiverem marcadas para exclusão, a ferramenta para com "Não restam páginas para exportar."
  • A reordenação usa a função de arrastar e soltar do próprio navegador. Funciona com mouse nos navegadores de computador; muitos navegadores de celular e tablet não suportam esse tipo de arrasto, então, para reordenar muita coisa, o computador é a opção segura.
  • Como as páginas são copiadas para um documento novo, os marcadores se perdem, e os links que saltam entre páginas do documento podem parar de funcionar. Campos de formulário preenchíveis também podem não sobreviver.
  • Não há histórico para desfazer. Para recomeçar, recarregue a página e adicione o arquivo de novo; o seu arquivo original não foi alterado.

Dicas para obter os melhores resultados

  • Exclua primeiro. Os cartões acinzentados ocupam espaço no quadro e, mesmo continuando visíveis, é mais fácil pensar na ordem de um conjunto menor.
  • Em documentos longos, faça primeiro os movimentos grandes (seções inteiras para mais ou menos o lugar certo) e depois ajuste as páginas vizinhas.
  • Diminua o zoom do navegador para caberem mais miniaturas na tela; arrastar um cartão por muitas linhas é mais lento do que soltá-lo num destino visível.
  • Se só uma ou duas páginas estiverem de lado e nada mais precisar mudar, o Girar PDF é mais rápido e mantém os marcadores, porque edita o arquivo em vez de reconstruí-lo.
  • Abra o resultado e percorra tudo uma vez. Uma página fora do lugar custa muito menos para corrigir agora do que depois que o arquivo já foi enviado.

Exemplo prático: a digitalização embaralhada de uma professora

Uma professora de São Paulo digitaliza uma apostila de aula prática de Ciências com 14 páginas para um aluno que faltou. O alimentador travou depois da página 6, então as páginas 7 a 10 entraram de novo e foram parar no fim, depois das 11 a 14. Duas folhas passaram de cabeça para baixo, e uma folha em branco do fundo da pilha entrou na posição 15.

No quadro, o problema aparece na hora: os cartões 7 a 10 estão depois do 14, e duas miniaturas mostram o texto de ponta-cabeça. Colocar o bloco de quatro cartões depois da página 6 leva quatro arrastos. Clicar duas vezes num botão de rotação em cada cartão invertido gira a página 180 graus, e a lixeira no cartão 15 deixa ele acinzentado.

Aplicar e baixar gera um booklet-organized.pdf de 14 páginas, na ordem certa e todas em pé. Digitar números de página em várias ferramentas teria exigido três passadas e algumas contas cuidadosas; aqui a correção é conferida visualmente enquanto é feita.

Solução de problemas

O quadro fica muito tempo em "Gerando páginas…"
Todas as páginas são desenhadas antes de o quadro aparecer, então arquivos longos ou com muitas imagens demoram mais. Espere, feche outras abas, ou divida o arquivo em partes, organize cada uma e junte tudo de novo.
Não consigo arrastar páginas no celular
Muitos navegadores móveis não suportam os eventos de arrastar e soltar dos quais o quadro depende. Use um navegador de computador para reordenar; girar e excluir pelos botões continua funcionando em telas sensíveis ao toque.
Uma página que eu girei continua de lado no resultado
A rotação se soma à que a página já tinha. Se a página já estava girada, você pode tê-la girado para outra posição errada. Conte os cliques: um são 90 graus, dois são 180.
Aparece "Não restam páginas para exportar."
Todos os cartões estão marcados para exclusão. Clique na lixeira de pelo menos um cartão para recuperá-lo e aplique de novo.
Meus marcadores sumiram
O Organizar reconstrói o documento a partir de páginas copiadas, e os marcadores não são copiados. Crie-os de novo com Criar marcadores, ou use o Girar PDF se a rotação era a única alteração necessária.
As miniaturas aparecem em branco ou o arquivo não carrega
O PDF pode estar criptografado ou corrompido. Experimente primeiro o Reparar PDF, ou remova a proteção no programa que o criou, e organize a cópia nova.

Perguntas frequentes

As miniaturas são usadas no arquivo final?

Não. Elas são só pré-visualizações em baixa resolução. O resultado é feito a partir das páginas originais, então a qualidade é igual à da origem.

Posso acrescentar a este quadro páginas de outro PDF?

Não, o quadro mostra um arquivo. Junte os arquivos primeiro e depois organize o PDF resultante.

Posso girar 180 graus?

Sim. Clique duas vezes num dos botões de rotação. Cada clique gira a página 90 graus.

Organizar altera o meu arquivo original?

Não. Você baixa um arquivo novo chamado nome-do-arquivo-organized.pdf; o original no seu computador continua como estava.

Existe limite de páginas?

A ferramenta não impõe nenhum, mas cada página é desenhada como miniatura, então arquivos muito longos ficam lentos e consomem muita memória, principalmente no celular.

As páginas digitalizadas ficam pesquisáveis?

Não, organizar só move, gira e remove páginas. Passe o resultado pelo OCR de PDF se precisar de texto pesquisável.

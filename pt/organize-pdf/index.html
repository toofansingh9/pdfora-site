Organizar páginas

Veja todas as páginas de um PDF em miniatura, arraste-as para uma nova ordem, gire ou exclua, e salve o resultado num arquivo novo.

Corrigir um PDF digitando números de página só funciona quando você sabe quais páginas estão erradas. Quando o multifuncional do escritório embaralha a digitalização, ou quando um documento longo precisa de vários ajustes ao mesmo tempo, o que resolve é enxergar as páginas. É isso que o Organizar páginas oferece: uma miniatura de cada página num quadro, em que cada cartão pode ser arrastado para outra posição, girado para a esquerda ou para a direita, ou marcado para sair. Até você clicar em Aplicar e baixar, nada acontece com o arquivo.

As miniaturas são desenhadas com o PDF.js a mais ou menos um terço do tamanho normal da página na tela, o bastante para reconhecer cada página pelo layout, mas não para ler letra miúda. Elas servem só de pré-visualização. Na hora de aplicar, a ferramenta volta ao PDF original e usa a pdf-lib para copiar as páginas verdadeiras, na ordem do quadro, para um documento novo. Nas páginas giradas, só a configuração de rotação é atualizada, sem redesenhar nada, e as páginas marcadas para exclusão ficam de fora. O resultado é salvo como nome-do-arquivo-organized.pdf, com texto, links para sites e qualidade das imagens intactos.

Arquivos longos pedem um pouco de paciência, porque todas as páginas são desenhadas antes de o quadro aparecer. Uma carta de 20 páginas surge quase na hora; um livro digitalizado de 400 páginas pode demorar bastante e pesar na memória do celular. É o custo de ver as páginas em vez de adivinhar números.

Como reorganizar as páginas de um PDF

  1. Abra Organizar páginas e escolha um PDF. Espere a mensagem "Gerando as páginas…" dar lugar às miniaturas.
  2. Arraste um cartão de página e solte onde ele deve ficar. Cada cartão mantém o número de página original como etiqueta, então você sempre sabe de onde veio cada página.
  3. Use os dois botões de seta de um cartão para girar aquela página 90 graus para a esquerda ou para a direita; clique mais de uma vez para 180 graus.
  4. Clique no botão da lixeira para marcar uma página para exclusão. O cartão fica acinzentado mas continua no quadro; clique de novo para recuperá-lo.
  5. Clique em Aplicar e baixar e confira o nome-do-arquivo-organized.pdf num visualizador antes de apagar ou substituir o original.

Quando usar esta ferramenta

  • Deixar a ata da assembleia do condomínio, a lista de presença e os orçamentos na ordem certa antes de mandar o PDF para os moradores.
  • Organizar os documentos digitalizados para um financiamento imobiliário (holerites, extratos, certidões) na sequência do checklist que o banco entregou.
  • Recolocar na ordem das questões as folhas de uma prova ou simulado que entraram embaralhadas no scanner.
  • Corrigir de uma vez uma digitalização com páginas de ponta-cabeça e de lado, e ainda tirar os versos em branco.
  • Trazer o resumo executivo do fim do relatório para a primeira página antes de enviá-lo à diretoria, ou abrir o portfólio com os projetos que mais interessam a um cliente.
  • Passar o olho em cada página antes de enviar um documento importante, mesmo que no fim só uma folha perdida precise sair.

O que saber antes de começar

  • Só dá para organizar um PDF por vez. Para reordenar páginas de vários arquivos, junte-os primeiro com Juntar PDF e depois organize o arquivo resultante.
  • A rotação aqui muda a indicação de rotação da página, a mesma configuração que um visualizador usa quando você gira uma página e salva. Não perde qualidade e se soma à rotação que a página já tivesse.
  • Os cartões excluídos continuam visíveis, acinzentados, até você aplicar. Se todas as páginas estiverem marcadas para exclusão, a ferramenta para com "Não restam páginas para exportar."
  • A reordenação usa a função de arrastar e soltar do próprio navegador. Funciona com mouse nos navegadores de computador; muitos navegadores de celular e tablet não suportam esse tipo de arrasto, então, para reordenar muita coisa, o computador é a opção segura.
  • Como as páginas são copiadas para um documento novo, os marcadores se perdem, e os links que saltam entre páginas do documento podem parar de funcionar. Campos de formulário preenchíveis também podem não sobreviver.
  • Não há histórico para desfazer. Para recomeçar, recarregue a página e adicione o arquivo de novo; o seu arquivo original não foi alterado.

Dicas para obter os melhores resultados

  • Exclua primeiro. Os cartões acinzentados ocupam espaço no quadro e, mesmo continuando visíveis, é mais fácil pensar na ordem de um conjunto menor.
  • Em documentos longos, faça primeiro os movimentos grandes (seções inteiras para mais ou menos o lugar certo) e depois ajuste as páginas vizinhas.
  • Diminua o zoom do navegador para caberem mais miniaturas na tela; arrastar um cartão por muitas linhas é mais lento do que soltá-lo num destino visível.
  • Se só uma ou duas páginas estiverem de lado e nada mais precisar mudar, o Girar PDF é mais rápido e mantém os marcadores, porque edita o arquivo em vez de reconstruí-lo.
  • Abra o resultado e percorra tudo uma vez. Uma página fora do lugar custa muito menos para corrigir agora do que depois que o arquivo já foi enviado.

Exemplo prático: a ata do condomínio que saiu embaralhada

Seu Carlos é síndico de um prédio em Fortaleza e precisa mandar aos moradores a ata da última assembleia: 8 páginas de ata, 3 de lista de presença e 1 página com o quadro de orçamentos da reforma da fachada. Ele digitaliza tudo no multifuncional da administração, mas coloca a lista de presença por cima da pilha sem perceber, deixa o modo frente e verso ligado e passa o quadro de orçamentos, que é deitado, de lado. O PDF sai com 14 páginas: a lista na frente, a ata depois, o quadro girado e dois versos em branco no meio.

No quadro de miniaturas, tudo fica evidente em segundos. Ele arrasta os três cartões da lista de presença para depois da última página da ata, clica uma vez no botão de rotação do cartão do orçamento para deixá-lo na posição de leitura e marca com a lixeira os dois cartões em branco, que ficam acinzentados.

Aplicar e baixar gera um ata-organized.pdf de 12 páginas, na ordem que ele queria e com o orçamento legível. Ele percorre o arquivo inteiro uma vez antes de enviar e guarda a digitalização original até confirmar que nenhuma página ficou para trás.

Solução de problemas

O quadro fica muito tempo em "Gerando as páginas…"
Todas as páginas são desenhadas antes de o quadro aparecer, então arquivos longos ou com muitas imagens demoram mais. Espere, feche outras abas, ou divida o arquivo em partes, organize cada uma e junte tudo de novo.
Não consigo arrastar páginas no celular
Muitos navegadores móveis não suportam os eventos de arrastar e soltar dos quais o quadro depende. Use um navegador de computador para reordenar; girar e excluir pelos botões continua funcionando em telas sensíveis ao toque.
Uma página que eu girei continua de lado no resultado
A rotação se soma à que a página já tinha. Se a página já estava girada, você pode tê-la girado para outra posição errada. Conte os cliques: um são 90 graus, dois são 180.
Aparece "Não restam páginas para exportar."
Todos os cartões estão marcados para exclusão. Clique na lixeira de pelo menos um cartão para recuperá-lo e aplique de novo.
Meus marcadores sumiram
O Organizar páginas reconstrói o documento a partir de páginas copiadas, e os marcadores não são copiados. Crie-os de novo com Criar marcadores, ou use o Girar PDF se a rotação era a única alteração necessária.
As miniaturas aparecem em branco ou o arquivo não carrega
O PDF pode estar criptografado ou corrompido. Experimente primeiro o Reparar PDF, ou remova a proteção no programa que o criou, e organize a cópia nova.

Perguntas frequentes

O arquivo final usa essas miniaturas?

Não usa. As miniaturas são só uma pré-visualização em baixa resolução; o resultado é montado com as páginas originais, então a qualidade é a mesma da origem.

Dá para trazer páginas de outro PDF para este quadro?

Não, o quadro trabalha com um arquivo por vez. Junte os arquivos antes e depois organize o PDF resultante.

Como eu giro uma página de ponta-cabeça?

Clique duas vezes num dos botões de rotação. Cada clique gira a página 90 graus, então dois cliques dão 180.

Meu arquivo original é alterado?

Não. Você baixa um arquivo novo, nome-do-arquivo-organized.pdf, e o original no seu computador continua igual.

Tem limite de páginas?

A ferramenta não impõe limite, mas cada página vira uma miniatura, então arquivos muito longos ficam lentos e consomem bastante memória, principalmente no celular.

Depois de organizar, consigo pesquisar o texto das páginas digitalizadas?

Não, organizar só move, gira e remove páginas. Se precisar que as páginas digitalizadas fiquem pesquisáveis, passe o arquivo organizado pelo OCR de PDF.

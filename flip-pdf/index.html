Flipping is not the same as rotating. Rotation turns a page around its centre; a flip produces a mirror image, so text reads backwards. That sounds useless until you need it: T-shirt transfer paper, window decals printed on the reverse of clear film, signs read through glass, and the occasional scan or photo that was captured mirrored by a front camera. It is also a tool people reach for by mistake. If a page simply appears sideways or upside down, what you want is rotation, which keeps the text intact and readable. Use flip only when the final result genuinely has to be a mirror image, and check the direction on a plain-paper test print before using transfer paper, film or anything else that cannot be reused.

PDFora's flip tool offers two directions. Horizontal mirrors each page left to right, the usual choice for transfers. Vertical mirrors it top to bottom, which is not the same as turning the page upside down: the text ends up both upside down and reversed. Neither option rotates the page frame: a portrait page stays portrait, and the mirrored content occupies exactly the same area it did before, so margins that were on the left are now on the right.

To do this, each page is drawn by PDF.js onto a canvas at twice its normal scale, mirrored, and saved as a JPEG image at quality 0.9, then placed on a page of the original size. The output, yourfile-flipped.pdf, therefore contains pictures of your pages, not text. All of this happens in the browser. Converting to an image is the price of mirroring every kind of content consistently: text, vector drawings, embedded photos and form appearances all end up reversed together, with no element left the wrong way round. For a transfer or a decal that is exactly what you want; for a document that people still need to search or edit, it is not, so treat the flipped copy as a print file and keep the original as the working version.

How to flip or mirror a PDF

  1. Open Flip PDF and select one PDF.
  2. Choose the direction: Horizontal (mirror) is the default; Vertical mirrors top to bottom.
  3. Click Flip pages. A progress bar runs as each page is rendered.
  4. Download the flipped file and look at the first page: the text should read backwards.
  5. Print a test page on plain paper before using expensive transfer paper or film.

When to use this tool

  • Printing designs onto iron-on transfer paper, which must be printed mirrored so they read correctly on the fabric.
  • Making window or glass signs printed on the back of transparent film and read from the front.
  • Fixing scans or phone captures of documents that came out mirror-image.
  • Preparing artwork for screen printing or other processes where a reversed image is required.
  • Producing mirror-writing worksheets or puzzles for a classroom activity.
  • Creating reversed patterns for craft templates where the cutting side is the back of the material.

What to know before you start

  • Every page is flipped. There is no page selection; split off the pages you need first. Pages you leave out can be merged back unflipped afterwards.
  • The output is image-based. Text cannot be selected, copied or searched, and links, bookmarks and form fields are gone.
  • Pages are rendered at twice the PDF's normal scale, which corresponds to roughly 144 dots per inch. That is fine for most transfers and signs, but fine print and thin lines will be softer than in the original. For artwork you intend to enlarge or cut on a plotter, mirror the original design file instead.
  • Because each page becomes a JPEG, the file can grow considerably for documents that were mostly text, and very fine detail can show slight compression artefacts.
  • Page sizes are kept: each output page has the same dimensions as the original page.
  • Flipping a flipped file in the same direction gives you a readable page again, but as a second-generation image with slightly lower quality. Keep the original.

Tips for the best results

  • Many printer drivers have a 'mirror image' or 'transfer' option. Use either the driver option or this tool, not both, or you will mirror twice. If you are unsure which one the shop or printer will apply, ask before sending the file.
  • If you only want a page upside down, use Rotate PDF with 180 degrees instead of a vertical flip.
  • For transfers, put your design on a page with generous margins; the printable area of home printers stops a few millimetres from the edge.
  • Keep the unflipped original for editing and any future reprints.
  • If the flipped file is large, Compress PDF will usually shrink it further, at some cost to sharpness.

A worked example: club T-shirts for a school sports day

A teacher has a one-page PDF with the house logo and the words 'Blue House 2026' for iron-on transfers. Printed as is, the lettering would read backwards once ironed onto the shirts. Her printer driver has no mirror option, and the logo was supplied as a PDF by a parent volunteer, so editing the artwork itself was not practical.

She flips the PDF horizontally and prints the result on plain paper first. Held up to a window from the back, the test sheet reads correctly, which confirms the direction. She then prints on transfer paper with the printer's own mirror option turned off.

The logo's fine outline is slightly softer than in the original vector file because the page was rendered as an image, but at T-shirt size it is not noticeable.

Because the house colours were printed on four different shades of shirt, she kept the flipped PDF as the master print file and reprinted from it for each batch, rather than mirroring the design again each time. One file, checked once, avoided a second round of test prints.

Troubleshooting

The text still reads correctly after flipping
Your printer or viewer may be mirroring again. Turn off the mirror or transfer option in the print dialog.
I wanted the page upside down, not mirrored
Use Rotate PDF and choose 180 degrees. A vertical flip also reverses the text.
I cannot select text in the result
That is how the tool works: pages are converted to images. Keep the original for anything that needs text.
The output is much bigger than the input
Each page is stored as a JPEG image. Run the result through Compress PDF, or flip only the pages you need.
Small text looks fuzzy
Rendering is at about 144 dpi. Enlarge the design in the original before flipping, or use your printer driver's mirror function, which works on the original vector content.
The tab becomes slow on a long document
Every page is rendered in memory. Split the document and flip it in smaller parts.

Frequently asked questions

What is the difference between flip and rotate?

Rotation turns a page around its centre and the text still reads normally. Flipping produces a mirror image, so the text reads backwards.

Can I flip only one page?

Not inside this tool. Extract that page, flip it, and merge it back into the document.

Why does the flipped PDF lose its text?

Mirroring is done on a rendered picture of each page, so the result contains images rather than text objects.

What resolution are the flipped pages?

Pages are rendered at twice the PDF's default scale, roughly 144 dpi, and saved as JPEG at quality 0.9.

Can I flip both horizontally and vertically?

Run the tool twice, once in each direction. The result equals a 180-degree rotation, which Rotate PDF does without converting to images.

Is my file uploaded?

No. Rendering and mirroring happen in your browser tab; the PDF stays on your device.
